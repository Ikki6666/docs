LangGraph 是用于长时间运行的有状态智能体的低层级编排框架和运行时。你把工作流定义为由共享状态、节点和边组成的图，并可以在同一个图中混合确定性步骤和 LLM 驱动的步骤。

LangGraph 专注于[持久化执行](/oss/python/langgraph/persistence)、[流式传输](/oss/python/langgraph/streaming)和[人机交互](/oss/python/langgraph/interrupts)等编排能力。它不规定提示词或智能体架构。

开始之前，请先了解智能体使用的构建块，尤其是[模型](/oss/python/langchain/models)和[工具](/oss/python/langchain/tools)。文档示例通常使用 [LangChain](/oss/python/langchain/overview) 完成这些集成，但 LangGraph 并不需要 LangChain。

如果你希望先使用更高层级的智能体循环，请使用 [Deep Agents](/oss/python/deepagents/overview) 或 LangChain [智能体](/oss/python/langchain/agents)。当你需要显式控制状态和控制流时，使用 LangGraph。

<Expandable title="LangChain 产品如何协同工作" defaultOpen={false}>

- [Deep Agents](/oss/python/deepagents/overview) 是一个[智能体套件](/oss/python/concepts/products#agent-harnesses-like-the-deep-agents-sdk)：在 LangGraph 之上提供规划、子智能体、文件系统工具和上下文管理。
- [LangChain](/oss/python/langchain/overview) 是智能体框架：提供模型、工具和智能体循环的抽象与集成。
- [LangGraph](/oss/python/langgraph/overview) 是编排运行时：提供持久化执行、流式传输、人机交互和状态持久化。
- [LangSmith](/langsmith/observability) 是用于跨框架追踪、评估、提示词和部署的平台。
- [LangSmith Engine](/langsmith/engine) 会检测 LangGraph 智能体追踪记录中的问题并提出修复方案。你可以直接从 Engine 标签页发起包含修复方案的拉取请求。
- [LangSmith Fleet](/langsmith/fleet/index) 是无代码智能体构建工具，提供模板、集成和例行自动化。

关于开源技术栈的对比，请参阅[框架、运行时和套件](/oss/python/concepts/products)。
</Expandable>

## <Icon icon="download" size={20} /> 安装

<CodeGroup>
```bash pip
pip install -U langgraph
```

```bash uv
uv add langgraph
```
</CodeGroup>




创建一个最小图：

```python
from langgraph.graph import StateGraph, MessagesState, START, END

def mock_llm(state: MessagesState):
    return {"messages": [{"role": "ai", "content": "hello world"}]}

graph = StateGraph(MessagesState)
graph.add_node(mock_llm)
graph.add_edge(START, "mock_llm")
graph.add_edge("mock_llm", END)
graph = graph.compile()

graph.invoke({"messages": [{"role": "user", "content": "hi!"}]})
```




完整的计算器智能体示例请参阅 [LangGraph 快速入门](/oss/python/langgraph/quickstart)。

## 能力

LangGraph 为有状态、长时间运行的工作流提供运行时原语。它不抽象化提示词，也不强制固定的智能体架构。

- **确定性与智能体步骤**：在一个图中组合手写节点和模型驱动的节点。
- [**持久化**](/oss/python/langgraph/persistence)：对状态建立检查点，并在失败或暂停后恢复执行。
- [**人机交互**](/oss/python/langgraph/interrupts)：暂停执行，检查或编辑状态，然后继续。
- [**记忆**](/oss/python/concepts/memory)：短期线程状态和跨会话的长期记忆。
- [**流式传输**](/oss/python/langgraph/streaming)：在图运行时流式传输 token、状态更新和其他事件。
