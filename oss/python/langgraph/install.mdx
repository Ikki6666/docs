title: 安装 LangGraph
sidebarTitle: 安装
---

要安装基础 LangGraph 包：

<CodeGroup>
```bash pip
pip install -U langgraph
```

```bash uv
uv add langgraph
```
</CodeGroup>




使用 LangGraph 时，你通常还需要访问 LLM 并定义工具。
你可以用任何你习惯的方式来完成。

文档中会采用一种方式，也就是使用 [LangChain](/oss/python/langchain/overview)。

安装 LangChain：

<CodeGroup>
```bash pip
pip install -U langchain
# 需要 Python 3.10+
```

```bash uv
uv add langchain
# 需要 Python 3.10+
```
</CodeGroup>




如果你要使用特定的 LLM 提供商包，需要单独安装它们。

请参阅 [集成](/oss/python/integrations/providers/overview) 页面，查看各提供商的安装说明。
