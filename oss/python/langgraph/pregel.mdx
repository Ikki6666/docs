[`Pregel`](https://reference.langchain.com/python/langgraph/pregel/main/Pregel) 实现了 LangGraph 的运行时，负责管理 LangGraph 应用的执行。

编译 [StateGraph](https://reference.langchain.com/python/langgraph/graph/state/StateGraph)，或者创建 [`@entrypoint`](https://reference.langchain.com/python/langgraph/func/entrypoint)，都会生成一个可以接收输入的 [`Pregel`](https://reference.langchain.com/python/langgraph/pregel/main/Pregel) 实例。




本指南从高层介绍运行时，并说明如何直接使用 Pregel 实现应用。

> **注意：** [`Pregel`](https://reference.langchain.com/python/langgraph/pregel/main/Pregel) 运行时之所以叫这个名字，是因为它来自 [Google 的 Pregel 算法](https://research.google/pubs/pub37252/)，后者描述了一种使用图进行大规模并行计算的高效方法。




## 概览

在 LangGraph 中，Pregel 将 [**actors**](https://en.wikipedia.org/wiki/Actor_model) 和 **channels** 组合成一个应用。**Actors** 从 channels 中读取数据，也向 channels 写入数据。Pregel 按照 **Pregel Algorithm** / **Bulk Synchronous Parallel** 模型，把应用执行组织成多个步骤。

每个步骤都包含三个阶段：

* **Plan**：决定本步骤要执行哪些 **actors**。例如在第一步，选择订阅特殊 **input** channels 的 **actors**；在后续步骤，选择订阅前一步更新过的 channels 的 **actors**。
* **Execution**：并行执行所有被选中的 **actors**，直到全部完成、其中一个失败，或者触发超时。在这个阶段，channels 的更新对 **actors** 不可见，直到下一步才会生效。
* **Update**：把本步骤中 **actors** 写入的值更新到 channels 上。

重复这个过程，直到没有 **actors** 被选中执行，或者达到最大步骤数。

## Actors

**Actor** 就是一个 `PregelNode`。它会订阅 channels，从中读取数据，并向它们写入数据。你可以把它理解成 Pregel 算法中的一个 **actor**。`PregelNodes` 实现了 LangChain 的 Runnable 接口。

## Channels

Channels 用于在 actors（PregelNodes）之间通信。每个 channel 都有一个 value type、一个 update type，以及一个 update function，后者接收一组 updates 并修改已存储的值。Channels 可以用来把数据从一个 chain 传到另一个 chain，也可以把数据从某个 chain 传回它自己在未来步骤中使用。

### LastValue

[`LastValue`](https://reference.langchain.com/python/langgraph/channels/last_value/LastValue) 是默认的 channel 类型。它会保存写入的最后一个值，并覆盖之前的值。可以把它用于输入输出值，或者用于把数据从一步传给下一步。

```python
from langgraph.channels import LastValue

channel: LastValue[int] = LastValue(int)
```




### Topic

[`Topic`](https://reference.langchain.com/python/langgraph/channels/topic/Topic) 是一个可配置的 PubSub channel，适合在 actors 之间发送多个值，或者跨步骤累积输出。它可以配置为去重，或者把运行期间写入的所有值都累积起来。

```python
from langgraph.channels import Topic

# 累积跨步骤写入的所有值
channel: Topic[str] = Topic(str, accumulate=True)
```




### BinaryOperatorAggregate

[`BinaryOperatorAggregate`](https://reference.langchain.com/python/langgraph/channels/binop/BinaryOperatorAggregate) 会保存一个持久化值，并通过对当前值和每个新更新应用二元运算符来更新它。可以用它来计算跨步骤的累积值。

```python
import operator
from langgraph.channels import BinaryOperatorAggregate

# 累积总和：每次写入都会加到当前值上
total = BinaryOperatorAggregate(int, operator.add)
```




### DeltaChannel

<Warning>
`DeltaChannel` 需要 `langgraph>=1.2`，目前处于 **beta**。未来版本中 API 可能会变化。
</Warning>

[`DeltaChannel`](https://reference.langchain.com/python/langgraph/channels/delta/DeltaChannel) 在每个步骤中只保存增量 delta，而不是完整的累积值。这对于那些写入频繁、且随着时间推移会累积大量数据的 channels 最有用，例如长期运行线程中的对话消息列表。如果不使用 delta 存储，每个 checkpoint 都要重新序列化完整列表；而使用 `DeltaChannel` 时，只会保存每一步新增的消息。

<Tip>
如果某个 channel 写入频繁，并且会随着时间推移不断变大，可以考虑使用 `DeltaChannel`。一个很好的信号是：如果你发现某个 channel 的 checkpoint 大小会随着线程长度线性增长，那么 `DeltaChannel` 很可能很适合它。
</Tip>

和普通 reducer 一样，你可以在 `Annotated` 类型注解中使用 `DeltaChannel`：

```python
from typing import Annotated, Sequence
from typing_extensions import TypedDict
from langgraph.channels import DeltaChannel


def my_reducer(state: list[str], writes: Sequence[list[str]]) -> list[str]:
    result = list(state)
    for write in writes:
        result.extend(write)
    return result


class State(TypedDict):
    messages: Annotated[list[str], DeltaChannel(my_reducer)]
```

#### Bulk reducer 要求

传给 `DeltaChannel` 的 `reducer` 是一个 **bulk reducer**：它会在一次调用中接收当前状态，以及当前步骤里所有 writes 的 *序列*，而不是像标准 reducer 那样两两处理。这和 `StateGraph` 中配合 `Annotated` 使用的按 key reducer 不同，后者会对每次更新调用一次。

<Warning>
这个 bulk reducer **必须满足结合律**（batching-invariant）：

```
reducer(reducer(state, [xs]), [ys]) == reducer(state, [xs, ys])
```

如果 reducer 不满足结合律，那么重建出来的状态可能会因 LangGraph 如何分批处理写入而不同，从而导致行为不一致。
</Warning>

<Warning>
**reducer 是在重建时运行，不是在写入时运行。** 和 [`BinaryOperatorAggregate`](https://reference.langchain.com/python/langgraph/channels/binop/BinaryOperatorAggregate) 不同，后者的 reducer 会在写入时被调用，因此合并后的值会被序列化到 checkpoint 中；而 `DeltaChannel` 的 reducer 是在 channel 值从持久化 writes 中 *重建* 时才会调用。真正被序列化的是每一步的原始 writes；只有在值被具体化时，reducer 才会被调用，也就是下一次读取时、下一步的 actors 读取时，或者回放历史时。

在设计 reducer 时，实际影响有：

- **把它写成 `(state, writes)` 的纯函数。** 任何副作用、随机性，或者对墙钟时间的读取（例如 `uuid.uuid4()`、`datetime.now()`）都会在值每次重建时执行，并在每次回放时产生不同结果。它们不会被写入持久化的 writes 中。
- **不要依赖对输入 writes 的原地修改会被持久化。** 如果你的 reducer 修改了某个 write 对象（例如给一个没有 ID 的条目分配稳定 ID），这种修改只会存在于重建出来的值里。存储的 write 仍然保持原始形状，所以下一次重建时仍会看到未修改的输入。
- **把身份信息和其他稳定元数据放在上游。** 如果下游代码需要跨轮次引用某个条目（例如之后更新或删除它），请在值写入 channel 之前就分配好这个 ID，而不是在 reducer 里分配。
</Warning>

下面是两个最常见场景的 bulk reducer：

```python
from typing import Any, Sequence


# List: 按顺序追加所有 writes
def list_reducer(state: list[Any], writes: Sequence[list[Any]]) -> list[Any]:
    result = list(state)
    for write in writes:
        result.extend(write)
    return result


# Dict: 合并所有 writes，键冲突时以后写入的值为准
def dict_reducer(
    state: dict[str, Any], writes: Sequence[dict[str, Any]]
) -> dict[str, Any]:
    result = dict(state)
    for write in writes:
        result.update(write)
    return result
```

这两个 reducer 都满足结合律：一次一批地应用，结果和把它们一起应用是一样的。

#### 使用 snapshot_frequency 限制读取延迟

如果没有 snapshot，读取 `DeltaChannel` 的值就需要回放完整的写入历史，对于有 N 个步骤的线程来说是 O(N)。设置 `snapshot_frequency=K` 会每隔 K 个 pregel 步骤写入一个完整快照，把读取深度限制在最多 K 步：

```python
class State(TypedDict):
    messages: Annotated[
        list[str],
        DeltaChannel(my_reducer, snapshot_frequency=5),
    ]
```

更高的 `snapshot_frequency` 会减少存储开销，但会增加读取延迟。更低的值会更严格地限制延迟，但代价是 checkpoint 更大。`None`（默认值）会完全跳过快照，适合读取很少或者线程很短的场景。

#### 版本兼容性与回滚

<Warning>
不建议把已持久化的 channel 从 `DeltaChannel` 改为非 delta channel。Checkpoints 对这两类 channel 类型的编码方式不同，因此为已有线程更改类型可能导致状态重建不完整或不正确。请在线程的整个生命周期内保持 channel 定义稳定。在更改 channel 类型之前，请将受影响的线程迁移到新的表示形式，或者放弃它们并启动新线程。

**不支持回滚到不支持 `DeltaChannel` 的版本。** `langgraph>=1.2` 会以一种新格式写入 delta channel checkpoints，旧版本无法读取。一旦某个线程使用过 `DeltaChannel`，把 LangGraph 降级后，这些 checkpoints 就不可读了，因为旧运行时无法理解 delta 格式，也无法重建 channel 状态。如果你需要回滚，请在降级前使用 [delta-channel-dump recovery script](https://github.com/langchain-ai/langgraph/tree/main/examples/delta-channel-dump) 迁移受影响线程，或者直接放弃这些线程。
</Warning>


## 示例

虽然大多数用户会通过 [StateGraph](https://reference.langchain.com/python/langgraph/graph/state/StateGraph) API 或 [`@entrypoint`](https://reference.langchain.com/python/langgraph/func/entrypoint) 装饰器来使用 Pregel，但也可以直接和 Pregel 交互。




下面是几个不同的例子，用来帮助你理解 Pregel API。

<Tabs>
    <Tab title="单节点">
    ```python
    from langgraph.channels import EphemeralValue
    from langgraph.pregel import Pregel, NodeBuilder

    node1 = (
        NodeBuilder().subscribe_only("a")
        .do(lambda x: x + x)
        .write_to("b")
    )

    app = Pregel(
        nodes={"node1": node1},
        channels={
            "a": EphemeralValue(str),
            "b": EphemeralValue(str),
        },
        input_channels=["a"],
        output_channels=["b"],
    )

    app.invoke({"a": "foo"})
    ```

    ```con
    {'b': 'foofoo'}
    ```



    </Tab>
    <Tab title="多个节点">
    ```python
    from langgraph.channels import LastValue, EphemeralValue
    from langgraph.pregel import Pregel, NodeBuilder

    node1 = (
        NodeBuilder().subscribe_only("a")
        .do(lambda x: x + x)
        .write_to("b")
    )

    node2 = (
        NodeBuilder().subscribe_only("b")
        .do(lambda x: x + x)
        .write_to("c")
    )


    app = Pregel(
        nodes={"node1": node1, "node2": node2},
        channels={
            "a": EphemeralValue(str),
            "b": LastValue(str),
            "c": EphemeralValue(str),
        },
        input_channels=["a"],
        output_channels=["b", "c"],
    )

    app.invoke({"a": "foo"})
    ```

    ```con
    {'b': 'foofoo', 'c': 'foofoofoofoo'}
    ```



    </Tab>
    <Tab title="Topic">
    ```python
    from langgraph.channels import EphemeralValue, Topic
    from langgraph.pregel import Pregel, NodeBuilder

    node1 = (
        NodeBuilder().subscribe_only("a")
        .do(lambda x: x + x)
        .write_to("b", "c")
    )

    node2 = (
        NodeBuilder().subscribe_to("b")
        .do(lambda x: x["b"] + x["b"])
        .write_to("c")
    )

    app = Pregel(
        nodes={"node1": node1, "node2": node2},
        channels={
            "a": EphemeralValue(str),
            "b": EphemeralValue(str),
            "c": Topic(str, accumulate=True),
        },
        input_channels=["a"],
        output_channels=["c"],
    )

    app.invoke({"a": "foo"})
    ```

    ```pycon
    {'c': ['foofoo', 'foofoofoofoo']}
    ```



    </Tab>
    <Tab title="BinaryOperatorAggregate">
    这个示例演示了如何使用 [`BinaryOperatorAggregate`](https://reference.langchain.com/python/langgraph/channels/binop/BinaryOperatorAggregate) channel 来实现一个 reducer。

    ```python
    from langgraph.channels import EphemeralValue, BinaryOperatorAggregate
    from langgraph.pregel import Pregel, NodeBuilder


    node1 = (
        NodeBuilder().subscribe_only("a")
        .do(lambda x: x + x)
        .write_to("b", "c")
    )

    node2 = (
        NodeBuilder().subscribe_only("b")
        .do(lambda x: x + x)
        .write_to("c")
    )

    def reducer(current, update):
        if current:
            return current + " | " + update
        else:
            return update

    app = Pregel(
        nodes={"node1": node1, "node2": node2},
        channels={
            "a": EphemeralValue(str),
            "b": EphemeralValue(str),
            "c": BinaryOperatorAggregate(str, operator=reducer),
        },
        input_channels=["a"],
        output_channels=["c"],
    )

    app.invoke({"a": "foo"})
    ```

    ```console
    { 'c': 'foofoo | foofoofoofoo' }
    ```



    </Tab>
    <Tab title="循环">
    这个示例演示了如何通过让一个 chain 向它自己订阅的 channel 写入来引入一个循环。执行会一直继续，直到向该 channel 写入一个 `None` 值为止。

    ```python
    from langgraph.channels import EphemeralValue
    from langgraph.pregel import Pregel, NodeBuilder, ChannelWriteEntry

    example_node = (
        NodeBuilder().subscribe_only("value")
        .do(lambda x: x + x if len(x) < 10 else None)
        .write_to(ChannelWriteEntry("value", skip_none=True))
    )

    app = Pregel(
        nodes={"example_node": example_node},
        channels={
            "value": EphemeralValue(str),
        },
        input_channels=["value"],
        output_channels=["value"],
    )

    app.invoke({"value": "a"})
    ```

    ```pycon
    {'value': 'aaaaaaaaaaaaaaaa'}
    ```



    </Tab>
</Tabs>

## 高层 API

LangGraph 提供了两种创建 Pregel 应用的高层 API：[StateGraph (Graph API)](/oss/python/langgraph/graph-api) 和 [Functional API](/oss/python/langgraph/functional-api)。

<Tabs>
    <Tab title="StateGraph（Graph API）">
    [StateGraph (Graph API)](https://reference.langchain.com/python/langgraph/graph/state/StateGraph) 是一个更高层的抽象，用于简化 Pregel 应用的创建。它允许你定义由节点和边组成的图。当你编译这个图时，StateGraph API 会自动为你创建 Pregel 应用。

    ```python
    from typing import TypedDict

    from langgraph.constants import START
    from langgraph.graph import StateGraph

    class Essay(TypedDict):
        topic: str
        content: str | None
        score: float | None

    def write_essay(essay: Essay):
        return {
            "content": f"Essay about {essay['topic']}",
        }

    def score_essay(essay: Essay):
        return {
            "score": 10
        }

    builder = StateGraph(Essay)
    builder.add_node(write_essay)
    builder.add_node(score_essay)
    builder.add_edge(START, "write_essay")
    builder.add_edge("write_essay", "score_essay")

    # 编译图。
    # 这会返回一个 Pregel 实例。
    graph = builder.compile()
    ```




    编译后的 Pregel 实例会关联一组节点和 channels。你可以通过打印它们来查看 nodes 和 channels。

    ```python
    print(graph.nodes)
    ```

    你会看到类似这样的内容：

    ```pycon

     'score_essay': <langgraph.pregel.read.PregelNode at 0x7d05e3ba1710>}
    ```

    ```python
    print(graph.channels)
    ```

    <Tab title="Functional API">
    在 [Functional API](/oss/python/langgraph/functional-api) 中，你可以使用 [`@entrypoint`](https://reference.langchain.com/python/langgraph/func/entrypoint) 来创建 Pregel 应用。`entrypoint` 装饰器允许你定义一个接收输入并返回输出的函数。

    ```python
    from typing import TypedDict

    from langgraph.checkpoint.memory import InMemorySaver
    from langgraph.func import entrypoint

    class Essay(TypedDict):
        topic: str
        content: str | None
        score: float | None


    checkpointer = InMemorySaver()

    @entrypoint(checkpointer=checkpointer)
    def write_essay(essay: Essay):
        return {
            "content": f"Essay about {essay['topic']}",
        }

    print("Nodes: ")
    print(write_essay.nodes)
    print("Channels: ")
    print(write_essay.channels)
    ```

    ```pycon

    {'write_essay': <langgraph.pregel.read.PregelNode object at 0x7d05e2f9aad0>}
    Channels:
    ```
