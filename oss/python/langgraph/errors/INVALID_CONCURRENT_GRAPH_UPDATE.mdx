---
title: INVALID_CONCURRENT_GRAPH_UPDATE
---

LangGraph [`StateGraph`](https://reference.langchain.com/python/langgraph/graph/state/StateGraph) 收到了来自多个节点对同一个 state 属性的并发更新，但这个属性不支持并发更新。

一种常见情况是，你在图中使用了 [fanout](/oss/python/langgraph/use-graph-api#map-reduce-and-the-send-api) 或其他并行执行方式，并且定义了下面这样的图：

```python
from typing import TypedDict

from langgraph.graph import START, StateGraph

class State(TypedDict):
    some_key: str  # [!code highlight]

def node(state: State):
    return {"some_key": "some_string_value"}

def other_node(state: State):
    return {"some_key": "some_string_value"}


builder = StateGraph(State)
builder.add_node(node)
builder.add_node(other_node)
builder.add_edge(START, "node")
builder.add_edge(START, "other_node")
graph = builder.compile()
```




如果上面的图中的某个节点返回 `{ "some_key": "some_string_value" }`，这会把 `"some_key"` 的 state 值覆盖为 `"some_string_value"`。
但如果在同一步里有多个节点返回 `some_key` 的值，例如 fanout 场景，图就会抛出这个错误，因为内部 state 应该如何更新并不明确。




要绕过这个问题，你可以定义一个 reducer 来合并多个值：

```python
import operator
from typing import Annotated

class State(TypedDict):
    # operator.add reducer 会把它变成只追加模式  # [!code highlight]
    some_key: Annotated[list, operator.add]  # [!code highlight]
```




这样你就可以定义逻辑，处理多个并行执行节点返回同一个 key 的情况。

## 排查

下面这些方法可能有助于解决这个错误：

* 如果你的图会并行执行节点，请确保相关 state key 已定义 reducer。
