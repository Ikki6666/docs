---
title: GRAPH_RECURSION_LIMIT
---

你的 LangGraph [`StateGraph`](https://reference.langchain.com/python/langgraph/graph/state/StateGraph) 在到达停止条件之前，已经达到了允许的最大步数。
这通常是由无限循环引起的，比如下面的示例：

```python
from typing import TypedDict

from langgraph.graph import StateGraph

class State(TypedDict):
    some_key: str

builder = StateGraph(State)
builder.add_node("a", ...)
builder.add_node("b", ...)
builder.add_edge("a", "b")
builder.add_edge("b", "a")
...

graph = builder.compile()
```




不过，复杂图也可能自然触发默认上限。

## 排查

* 如果你本来不希望图经历很多轮迭代，那大概率存在一个循环。检查你的逻辑里是否有无限循环。

* 如果你的图确实很复杂，可以在调用图时向 `config` 对象传入更高的 `recursion_limit` 值，例如：

```python
graph.invoke({...}, {"recursion_limit": 1000})
```
