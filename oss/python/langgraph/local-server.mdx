本指南说明如何在本地运行 LangGraph 应用。

## 前提条件

开始之前，请确保你具备以下条件：

* 一个 [LangSmith](https://smith.langchain.com/settings) API key - 可免费注册

## 1. 安装 LangGraph CLI

<CodeGroup>
```bash pip
# 需要 Python >= 3.11。
pip install -U "langgraph-cli[inmem]"
```

```bash uv
# 需要 Python >= 3.11。
uv add "langgraph-cli[inmem]"
```
</CodeGroup>




## 2. 创建 LangGraph 应用

从 [`new-langgraph-project-python` 模板](https://github.com/langchain-ai/new-langgraph-project) 创建一个新应用。这个模板演示了一个单节点应用，你可以在此基础上扩展自己的逻辑。

```shell
langgraph new path/to/your/app --template new-langgraph-project-python
```

<Tip>
**额外模板**
如果你在使用 `langgraph new` 时没有指定模板，系统会显示一个交互式菜单，让你从可用模板列表中选择。
</Tip>




## 3. 安装依赖

在新 LangGraph 应用的根目录下，以 `edit` 模式安装依赖，这样服务就会使用你的本地改动：

<CodeGroup>
```bash pip
cd path/to/your/app
pip install -e .
```

```bash uv
cd path/to/your/app
uv sync
```
</CodeGroup>




## 4. 创建 `.env` 文件

你会在新 LangGraph 应用的根目录中找到一个 `.env.example`。在根目录创建一个 `.env` 文件，并把 `.env.example` 的内容复制进去，填入必要的 API key：

```bash
LANGSMITH_API_KEY=lsv2...
```

## 5. 启动 Agent server

在本地启动 LangGraph API server：

```shell
langgraph dev
```




示例输出：

```
INFO:langgraph_api.cli:

        Welcome to

╦  ┌─┐┌┐┌┌─┐╔═╗┬─┐┌─┐┌─┐┬ ┬
║  ├─┤││││ ┬║ ╦├┬┘├─┤├─┘├─┤
╩═╝┴ ┴┘└┘└─┘╚═╝┴└─┴ ┴┴  ┴ ┴

- 🚀 API: http://127.0.0.1:2024
- 🎨 Studio UI: https://smith.langchain.com/studio/?baseUrl=http://127.0.0.1:2024
- 📚 API Docs: http://127.0.0.1:2024/docs

This in-memory server is designed for development and testing.
For production use, please use LangSmith Deployment.
```

`langgraph dev` 命令会以 in-memory 模式启动 Agent Server。该模式适合开发和测试。对于生产环境，请使用带有持久化存储后端的 LangSmith Deployment。更多信息请参阅 [Platform setup 概览](/langsmith/platform-setup)。

## 6. 在 Studio 中测试应用

[Studio](/langsmith/studio) 是一个专用 UI，你可以连接到 LangGraph API server，在本地可视化、交互并调试你的应用。访问 `langgraph dev` 命令输出中提供的 URL，就可以在 Studio 中测试你的图：

```
>    - LangGraph Studio Web UI: https://smith.langchain.com/studio/?baseUrl=http://127.0.0.1:2024
```

如果 Agent Server 运行在自定义主机/端口上，请更新 URL 中的 `baseUrl` 查询参数。例如，如果你的服务器运行在 `http://myhost:3000`：

```
https://smith.langchain.com/studio/?baseUrl=http://myhost:3000
```

<Accordion title="Safari 兼容性">
    如果 Safari 在连接 localhost 服务器时存在限制，请在命令中使用 `--tunnel` 标志来创建安全隧道：

    ```shell
    langgraph dev --tunnel
    ```
</Accordion>

## 7. 测试 API

<Tabs>
    <Tab title="Python SDK（异步）">
    1. 安装 LangGraph Python SDK：
        ```shell
        pip install langgraph-sdk
        ```
    2. 向 assistant 发送消息（threadless run）：
        ```python
        from langgraph_sdk import get_client
        import asyncio

        client = get_client(url="http://localhost:2024")

        async def main():
            async for chunk in client.runs.stream(
                None,  # Threadless run
                "agent", # Name of assistant. Defined in langgraph.json.
                input={
                "messages": [{
                    "role": "human",
                    "content": "What is LangGraph?",
                    }],
                },
            ):
                print(f"Receiving new event of type: {chunk.event}...")
                print(chunk.data)
                print("\n\n")

        asyncio.run(main())
        ```
    </Tab>
    <Tab title="Python SDK（同步）">
    1. 安装 LangGraph Python SDK：
        ```shell
        pip install langgraph-sdk
        ```
    2. 向 assistant 发送消息（threadless run）：
        ```python
        from langgraph_sdk import get_sync_client

        client = get_sync_client(url="http://localhost:2024")

        for chunk in client.runs.stream(
            None,  # Threadless run
            "agent", # Name of assistant. Defined in langgraph.json.
            input={
                "messages": [{
                    "role": "human",
                    "content": "What is LangGraph?",
                }],
            },
            stream_mode="messages-tuple",
        ):
            print(f"Receiving new event of type: {chunk.event}...")
            print(chunk.data)
            print("\n\n")
        ```
    </Tab>
    <Tab title="Rest API">
    ```bash
    curl -s --request POST \
        --url "http://localhost:2024/runs/stream" \
        --header 'Content-Type: application/json' \
        --data "{
            \"assistant_id\": \"agent\",
            \"input\": {
                \"messages\": [
                    {
                        \"role\": \"human\",
                        \"content\": \"What is LangGraph?\"
                    }
                ]
            },
            \"stream_mode\": \"messages-tuple\"
        }"
    ```
    </Tab>
</Tabs>
