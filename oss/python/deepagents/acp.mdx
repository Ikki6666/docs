[Agent Client Protocol (ACP)](https://agentclientprotocol.com/get-started/introduction) 统一了编码代理与代码编辑器或 IDE 之间的通信方式。
借助 ACP，你可以让自定义 Deep Agents 与任何兼容 ACP 的客户端配合使用，从而让代码编辑器提供项目上下文并接收丰富的更新。

<Note>
    ACP 专为 agent 与编辑器的集成而设计。如果你想让你的 agent 调用外部服务器托管的工具，请参见 [Model Context Protocol (MCP)](/oss/python/langchain/mcp/)。
</Note>

## 快速开始

安装 ACP 集成包：

<CodeGroup>
```bash pip
pip install deepagents-acp
```

```bash uv
uv add deepagents-acp
```
</CodeGroup>




然后通过 ACP 公开一个 deep agent。

这会以 stdio 模式启动一个 ACP server（它从 stdin 读取请求，并将响应写入 stdout）。实际使用中，你通常会把它作为 ACP client（例如你的编辑器）启动的命令运行，然后由客户端通过 stdio 与 server 通信。

## 客户端

Deep Agents 可以在任何能运行 ACP agent server 的地方使用。常见的 ACP client 包括：

- [Zed](https://zed.dev/docs/ai/external-agents)
- [JetBrains IDEs](https://www.jetbrains.com/help/ai-assistant/acp.html)
- Visual Studio Code（通过 [vscode-acp](https://github.com/formulahendry/vscode-acp)）
- Neovim（通过兼容 ACP 的插件）

### Zed

`deepagents` 仓库包含一个 [示例 ACP 入口点](https://github.com/langchain-ai/deepagents/blob/main/libs/acp/run_demo_agent.sh)，你可以将它注册到 [Zed](https://zed.dev/docs/ai/external-agents)：

1. 克隆 `deepagents` 仓库并安装依赖：

```bash
git clone https://github.com/langchain-ai/deepagents.git
cd deepagents/libs/acp
uv sync --all-groups
chmod +x run_demo_agent.sh
```

2. 为示例 agent 配置凭据：

```bash
cp .env.example .env
```

然后在 `.env` 中设置 `ANTHROPIC_API_KEY`。

3. 在 Zed 的 `settings.json` 中配置你的 ACP agent server 命令：

```json
{
  "agent_servers": {
    "DeepAgents": {
      "type": "custom",
      "command": "/your/absolute/path/to/deepagents/libs/acp/run_demo_agent.sh"
    }
  }
}
```

4. 打开 Zed 的 Agents 面板并启动一个 Deep Agents 线程。





### Toad

如果你想把 ACP agent server 作为本地开发工具运行，可以使用 [Toad](https://github.com/batrachianai/toad) 来管理这个进程。

```bash
uv tool install -U batrachian-toad

toad acp "python path/to/your_server.py" .
# 或者
toad acp "uv run python path/to/your_server.py" .
```
