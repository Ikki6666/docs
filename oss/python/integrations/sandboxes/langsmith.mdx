title: "LangSmith sandbox 集成"

---

LangSmith sandboxes 是由 LangChain 为你管理的沙箱环境，因此无需单独设置 provider 账户、计费或基础设施。它们是运行 agent 代码时零配置的默认选项，而当你想自行引入 provider 时，仍可使用 AgentCore、Daytona、E2B、Modal、Runloop 和 Vercel 等第三方 provider。由于它们属于 LangChain 平台的一部分，你可以将其与其他 LangSmith 资源一并管理。关于 setup、snapshots、service URLs 和 auth proxy，请参阅 [LangSmith Sandboxes docs](/langsmith/sandboxes)。

## 安装

<CodeGroup>
```bash pip
pip install "langsmith[sandbox]" deepagents
```

```bash uv
uv add "langsmith[sandbox]" deepagents
```
</CodeGroup>

## 设置 API key

```bash
export LANGSMITH_API_KEY="<your-api-key>"
```

`SandboxClient()` 会从环境中读取这个 key，因此不需要进一步配置。

## 创建沙箱后端

使用 `SandboxClient` 创建一个 LangSmith sandbox，然后将其包装到 [LangSmithSandbox](https://reference.langchain.com/python/deepagents/backends/langsmith/LangSmithSandbox) 中，作为 [Deep Agents backend](/oss/python/deepagents/backends) 来运行。

```python
from deepagents.backends.langsmith import LangSmithSandbox
from langsmith.sandbox import SandboxClient

client = SandboxClient()
ls_sandbox = client.create_sandbox()
backend = LangSmithSandbox(sandbox=ls_sandbox)

result = backend.execute("echo hello")
print(result.output)

# Delete the sandbox when you are done (see Clean up)
client.delete_sandbox(ls_sandbox.name)
```

## 与 Deep Agents 搭配使用

将 backend 与 [create_deep_agent](https://reference.langchain.com/python/deepagents/graph/create_deep_agent) 和 [ChatAnthropic](https://reference.langchain.com/python/langchain-anthropic/chat_models/ChatAnthropic) 之类的聊天模型一起传入，然后调用 agent。`try`/`finally` 代码块会在 try 代码块结束或发生错误时删除沙箱。

```python
from deepagents import create_deep_agent
from deepagents.backends.langsmith import LangSmithSandbox
from langchain_anthropic import ChatAnthropic
from langsmith.sandbox import SandboxClient

client = SandboxClient()
ls_sandbox = client.create_sandbox()
backend = LangSmithSandbox(sandbox=ls_sandbox)

agent = create_deep_agent(
    model=ChatAnthropic(model="claude-sonnet-4-6"),
    system_prompt="You are a coding assistant with sandbox access.",
    backend=backend,
)

try:
    result = agent.invoke(
        {
            "messages": [
                {"role": "user", "content": "Create a hello world Python script and run it"}
            ]
        }
    )
    print(result["messages"][-1].content_blocks)
finally:
    client.delete_sandbox(ls_sandbox.name)
```

## 清理

完成后请删除沙箱，因为在删除之前它们会持续占用资源。

```python
client.delete_sandbox(ls_sandbox.name)
```

你也可以在 [LangSmith UI](https://smith.langchain.com?utm_source=docs&utm_medium=cta&utm_campaign=langsmith-signup&utm_content=oss-python-integrations-sandboxes-langsmith) 的 **Sandboxes** 下管理沙箱资源。
