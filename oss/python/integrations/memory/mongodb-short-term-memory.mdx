[短期记忆](/oss/python/langchain/short-term-memory)让你的 agent 能够在单个线程或对话中记住之前的交互。本指南展示如何使用 [MongoDB Atlas](https://www.mongodb.com/docs/atlas/) 作为持久化 checkpointer 后端。

MongoDB 将对话状态作为文档存储在 collection 中，因此线程可以在进程重启和部署之后恢复。

<Tip>
需要**跨**对话记住信息？请借助[使用 MongoDB Atlas 的长期记忆](/oss/python/integrations/memory/mongodb-long-term-memory)跨不同线程和会话存储与召回数据。
</Tip>

## 设置

### 安装

<CodeGroup>
```bash pip
pip install -U langgraph-checkpoint-mongodb pymongo
```

```bash uv
uv add langgraph-checkpoint-mongodb pymongo
```
</CodeGroup>

### 凭证

设置你的 Atlas 连接字符串：

```python
import getpass
import os

if not os.environ.get("MONGODB_ATLAS_URI"):
    os.environ["MONGODB_ATLAS_URI"] = getpass.getpass("Enter your MongoDB Atlas URI: ")
```

如果你希望对模型调用启用自动 tracing，请设置 [LangSmith](/langsmith/home) API key：

```python
if not os.environ.get("LANGSMITH_API_KEY"):
    os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

## 用法

使用 `from_conn_string` 创建 `MongoDBSaver`，并把它传给 `create_agent`。该上下文管理器在打开时会创建所需的 collection 和 index。你无需调用单独的 `setup()` 方法（与 Postgres checkpointer 不同）。

```python
import os

from langchain.agents import create_agent
from langgraph.checkpoint.mongodb import MongoDBSaver

def get_user_info() -> str:
    """Look up information about the current user."""
    return "No user profile on file."

MONGODB_ATLAS_URI = os.environ["MONGODB_ATLAS_URI"]

with MongoDBSaver.from_conn_string(MONGODB_ATLAS_URI) as checkpointer:
    agent = create_agent(
        "anthropic:claude-sonnet-4-6",
        tools=[get_user_info],
        checkpointer=checkpointer,
    )

    thread_config = {"configurable": {"thread_id": "1"}}
    response = agent.invoke(
        {"messages": [{"role": "user", "content": "Hi! My name is Bob."}]},
        thread_config,
    )["messages"][-1].content

    print(response)

    response = agent.invoke(
        {"messages": [{"role": "user", "content": "What's my name?"}]},
        thread_config,
    )["messages"][-1].content

    print(response)
```

`MongoDBSaver` 还暴露了 `aget` 和 `aput` 等异步方法，供异步 graph 使用。不存在单独的 `AsyncMongoDBSaver` 类。
