[Privy](https://privy.io) 是为 AI agent 打造、可大规模扩展的强大钱包基础设施。

为 agent 提供以下工具能力：

- 自动创建和管理钱包
- 使用多种数字资产进行支付，包括稳定币
- 对消息和交易进行签名
- 查询钱包余额和地址

### 工作原理
Privy 提供钱包基础设施，去除了区块链交互的复杂性：

1. 为你的 agent 提供一个强大的模块化钱包
2. 使用交易策略保护 agent 的资产
3. 快速完成支付
