>[Mistral AI](https://docs.mistral.ai/api/) 是一个为其强大开源模型提供托管的平台。

## 安装和设置

与 API 通信需要一个有效的 [API key](https://console.mistral.ai/users/api-keys/)。

您还需要 `langchain-mistralai` 包：

<CodeGroup>
```bash pip
pip install langchain-mistralai
```

```bash uv
uv add langchain-mistralai
```
</CodeGroup>

## 聊天模型

### ChatMistralAI

请参阅[用法示例](/oss/python/integrations/chat/mistralai)。

```python
from langchain_mistralai.chat_models import ChatMistralAI
```

## Embedding 模型

### MistralAIEmbeddings

请参阅[用法示例](/oss/python/integrations/embeddings/mistralai)。

```python
from langchain_mistralai import MistralAIEmbeddings
```
