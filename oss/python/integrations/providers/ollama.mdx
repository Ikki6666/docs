本页覆盖所有与 [Ollama](https://ollama.com/) 相关的 LangChain 集成。

Ollama 允许你在本地运行开源模型，例如 [`gpt-oss`](https://ollama.com/library/gpt-oss)。

有关受支持模型及其变体的完整列表，请参阅 [Ollama model library](https://ollama.ai/library)。
