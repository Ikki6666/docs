浏览面向 [Microsoft Foundry](https://learn.microsoft.com/en-us/azure/foundry/) 和 [Azure](https://azure.microsoft.com/) 的 LangChain Python 集成。关于包选择、共享 Azure 设置、memory、vector store 和托管 agents，请参阅 [Azure AI 集成](/oss/python/integrations/providers/azure_ai)。

<Tip>
    **推荐：Microsoft Foundry**

    对于以 [Microsoft Foundry](https://learn.microsoft.com/en-us/azure/foundry/) 为中心的新 LangChain、LangGraph 或 Deep Agents 应用，请从 [`langchain-azure-ai`](/oss/python/integrations/providers/azure_ai) 开始。它提供 Foundry 项目 endpoint、Azure 凭据集成、Agent Service、hosting、工具、Content Safety、检索和 Azure 可观测性。

    如需直接访问 [Azure OpenAI v1 API](https://learn.microsoft.com/en-us/azure/ai-foundry/openai/api-version-lifecycle?tabs=python)、运行会在 OpenAI 与 Azure 之间切换的代码、使用传统 Azure OpenAI API 版本或 completion LLM，或者希望依赖面更小，请使用 `langchain-openai` 包。

</Tip>

## 探索集成

<a id="use-models" />

### 聊天模型

选择一种集成来调用聊天模型：

- **Microsoft Foundry（推荐）**：要调用 Microsoft Foundry 中的模型，请使用 `langchain-azure-ai` 中的 `AzureAIOpenAIApiChatModel`。它通过 Azure 凭据处理 project endpoint 解析和 Microsoft Entra ID 认证。
- **Azure OpenAI**：对于直接的 v1 API 调用，或在 OpenAI 与 Azure 之间共享的代码，请使用 `langchain-openai` 中的 `ChatOpenAI`。对于传统的带日期的 Azure OpenAI API 版本，请使用 `AzureChatOpenAI`。

<Note>
    **Claude on Azure**

    Microsoft Foundry 也提供对全部 [Anthropic Claude models](https://learn.microsoft.com/en-us/azure/foundry/foundry-models/how-to/use-foundry-models-claude) 的访问，包括 Opus、Sonnet 和 Haiku。Claude 模型通过 Anthropic 原生专用 endpoint 提供，而不是 Azure OpenAI v1 API。对于 Foundry project endpoint 和 Microsoft Entra ID，优先使用 `langchain-azure-ai` 中的 `AzureAIAnthropicChatModel`。你也可以使用 `langchain-anthropic` 中指向 Foundry Anthropic endpoint 的 [`ChatAnthropic`](/oss/python/integrations/chat/anthropic)。

</Note>

#### 调用模型

调用部署在 Foundry 项目中的模型。安装 `langchain-azure-ai` 并设置 `AZURE_AI_PROJECT_ENDPOINT` 和 `AZURE_AI_MODEL_DEPLOYMENT_NAME`。

为你的环境配置 Microsoft Entra ID 认证。在 Azure 上，请使用 managed identity。对于本地开发，你可以使用 `az login` 登录。

```python
import os

from azure.identity import DefaultAzureCredential
from langchain_azure_ai.chat_models import AzureAIOpenAIApiChatModel

model = AzureAIOpenAIApiChatModel(
    model=os.environ["AZURE_AI_MODEL_DEPLOYMENT_NAME"],
    credential=DefaultAzureCredential(),
)
model.invoke("Tell me a joke and include some emojis.").pretty_print()
```

有关设置和使用示例，请参阅 [Microsoft Foundry 聊天模型](/oss/python/integrations/chat/azure_ai)。

#### 使用现有的 Foundry agent

安装 `langchain-azure-ai` 并设置 `AZURE_AI_PROJECT_ENDPOINT`。为你的环境配置 Microsoft Entra ID 认证。将 `my-echo-agent` 替换为你的 agent 名称。

```python
from langchain_azure_ai.agents import (
    AgentServiceAgentState,
    AgentServiceFactory,
)
from langgraph.graph import END, START, StateGraph

factory = AgentServiceFactory()
agent_node = factory.get_agent_node(
    name="my-echo-agent", version="latest"
)

workflow = StateGraph(AgentServiceAgentState)
workflow.add_node("foundry_agent", agent_node)
workflow.add_edge(START, "foundry_agent")
workflow.add_edge("foundry_agent", END)

graph = workflow.compile()
result = graph.invoke({"messages": [("user", "Hello, world!")]})
result["messages"][-1].pretty_print()
```

有关在 LangGraph 中使用 Foundry agents 的更多信息，请参阅 [Microsoft Foundry Agent Service](https://github.com/langchain-ai/langchain-azure/blob/main/libs/azure-ai/README.md#microsoft-foundry-agent-service)。

### 运行时

[Microsoft Foundry 托管 agents](https://learn.microsoft.com/en-us/azure/foundry/agents/concepts/hosted-agents) 在托管基础设施上运行你的 LangGraph 代码。Foundry 管理计算、会话生命周期和扩缩容。Responses 托管选项可以启用后台执行、进程中断后的故障恢复、流重放，以及针对新用户输入的引导。这些选项默认关闭。

通过 OpenAI 兼容的 Responses endpoint 或支持自定义 JSON 输入和输出的 Invocations endpoint 暴露你的 agent。LangGraph 托管适配器负责请求转换、响应映射和流式传输。Responses 还提供托管的对话历史记录。

托管 agents 可以使用专用的 Microsoft Entra agent 身份调用 Foundry 模型和 Toolbox 工具。Foundry 还支持 RBAC、专用网络和 Content Safety guardrails。Application Insights 追踪有助于排查故障。

#### 托管 LangGraph agent

使用 `langchain-azure-ai[hosting]` 在本地运行现有的已编译 LangGraph graph。在你配置好的项目目录中，将 `langgraph.json` 指向导出的 graph。设置 Foundry 项目 endpoint 和模型部署名称，然后启动 Responses endpoint：

```bash
pip install -U "langchain-azure-ai[hosting]"
export FOUNDRY_PROJECT_ENDPOINT="https://<account>.services.ai.azure.com/api/projects/<project>"
export AZURE_AI_MODEL_DEPLOYMENT_NAME="<model-deployment-name>"
python -m langchain_azure_ai.agents.hosting.run --protocol responses
```

如需部署，请使用 `azd ai agent init` 初始化一个托管 agent 项目，并在 `azure.yaml` 中使用相同的 hosting 入口点；使用 `azd ai agent run` 在本地测试；使用 `azd deploy` 进行部署。仅当你需要创建 Foundry 项目或其他 Azure 资源时，才需要先运行 `azd provision`：

```bash
azd ext install azure.ai.agents
azd auth login
azd ai agent init
azd ai agent run
azd provision
azd deploy
```

要了解为什么要在 Microsoft Foundry 上托管 LangGraph，请阅读[托管博客文章](https://techcommunity.microsoft.com/blog/azure-ai-foundry-blog/hosting-your-langgraph-application-on-microsoft-foundry-agents/4573342)。要迁移现有的 graph，请遵循 [LangGraph 到 Foundry 迁移指南](https://github.com/langchain-ai/langchain-azure/blob/main/libs/azure-ai/docs/hosting/host-langgraph-on-foundry.md)。对于新建或迁移后的 agents，请参阅 [Microsoft Foundry 托管 agents](/oss/python/integrations/providers/azure_ai#microsoft-foundry-hosted-agents) 和[托管 agent 示例](https://github.com/langchain-ai/langchain-azure/blob/main/samples/hosting/langgraph-hosted-agents/README.md#start-here)。
