>[Remembrall](https://remembrall.dev/) 是一个为语言模型提供
> long-term memory、retrieval augmented generation 和完整 observability 的平台。

## 安装与设置

开始使用时，请先[使用 GitHub 登录 Remembrall 平台](https://remembrall.dev/login)，
然后从[设置页面复制你的 API key](https://remembrall.dev/dashboard/settings)。
