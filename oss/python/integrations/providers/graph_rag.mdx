## 概览

[Graph RAG](https://datastax.github.io/graph-rag/) 提供了一个 retriever 接口，把基于向量的**非结构化**相似度搜索与对元数据属性的**结构化**遍历结合起来。这使得你可以在**已有** vector store 之上实现基于图的检索。

## 安装与设置

<CodeGroup>
```bash pip
pip install langchain-graph-retriever
```

```bash uv
uv add langchain-graph-retriever
```
</CodeGroup>

## Retrievers

```python
from langchain_graph_retriever import GraphRetriever
```

更多信息请参阅 [Graph RAG Integration Guide](/oss/python/integrations/retrievers/graph_rag)。
