>[Docugami](https://docugami.com) 会把业务文档转换为 Document XML Knowledge Graph，生成由 XML 语义树组成的森林来表示完整文档。这是一种丰富的表示方式，能以 XML 树的形式保留文档中各种 chunk 的语义和结构特征。

## 安装与设置


<CodeGroup>
```bash pip
pip install dgml-utils
pip install docugami-langchain
```

```bash uv
uv add dgml-utils
uv add docugami-langchain
```
</CodeGroup>

## Document loader

参阅[使用示例](/oss/python/integrations/document_loaders/docugami)。

```python
from docugami_langchain.document_loaders import DocugamiLoader
```
