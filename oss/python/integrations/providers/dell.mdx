Dell 是一家全球科技公司，提供多种硬件、软件和服务，其中包括 AI 解决方案。其 AI 产品组合包含面向 AI 工作负载的专用基础设施，包括针对 AI 数据管理优化的 Dell PowerScale 存储系统。

## PowerScale

Dell 的 [PowerScale](https://www.dell.com/en-us/shop/powerscale-family/sf/powerscale) 是一套企业级横向扩展存储系统，托管业界领先的 OneFS 文件系统，可部署在本地，也可部署在云端。

### 安装与设置

<CodeGroup>
```bash pip
pip install powerscale-rag-connector[langchain]
```

```bash uv
uv add powerscale-rag-connector[langchain]
```
</CodeGroup>
