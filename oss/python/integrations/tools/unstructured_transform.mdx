本指南简要介绍如何开始使用 Unstructured Transform [tools](/oss/python/langchain/tools)。[Unstructured Transform](https://docs.unstructured.io/transform/overview) MCP server 会摄取并转换文件（PDF、DOCX、图片以及 70 多种文件类型），为 RAG 和 AI pipeline 生成切分、富化、分块和嵌入后的数据。`langchain-unstructured-transform` 包将这些工具加载为原生 LangChain 工具。

### 特性

- 将托管 Transform MCP server 的工具加载为原生 LangChain 工具。
- 驱动完整的解析生命周期：请求上传 URL、转换文件、轮询状态，以及获取结果。
- 适用于任何 LangChain 或 LangGraph agent。
- 远程且托管：无需运行本地 server 或 bridge。

## 设置

要访问 Unstructured Transform 工具，你需要一个 Unstructured 账号和一个 API key，并且需要安装 `langchain-unstructured-transform` 包。

### 凭证

从 [Unstructured docs](https://docs.unstructured.io/transform/overview) 获取 API key，然后将其设置为环境变量：

```python Set API key icon="key"
import getpass
import os

if "UNSTRUCTURED_API_KEY" not in os.environ:
    os.environ["UNSTRUCTURED_API_KEY"] = getpass.getpass("Enter your Unstructured API key: ")
```

设置 LangSmith 以获得一流的可观测性（即对工具调用进行<Tooltip tip="记录模型执行的每个步骤，以调试和改进它">tracing</Tooltip>）也很有帮助（但不是必需的）。要启用自动 tracing，请设置你的 [LangSmith](/langsmith/observability) API key：

```python Enable tracing icon="flask"
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

### 安装

Unstructured Transform 工具位于 `langchain-unstructured-transform` 包中：

<CodeGroup>
    ```python pip
    pip install -U langchain-unstructured-transform
    ```
    ```python uv
    uv add langchain-unstructured-transform
    ```
</CodeGroup>

## 实例化

Transform 工具通过 MCP 加载，这是一个异步操作。使用 toolkit 的 `aget_tools()` 方法（或 `aget_transform_tools()` 辅助函数）加载它们：

```python Load the tools icon="robot"
from langchain_unstructured_transform import UnstructuredTransformToolkit

toolkit = UnstructuredTransformToolkit()  # reads UNSTRUCTURED_API_KEY
tools = await toolkit.aget_tools()
```

加载的 `tools` 包括 `request_file_upload_url`、`transform_files`、`check_transform_status` 和 `get_transform_results`。

## 调用

### 在 agent 中

这些工具被设计为由 agent 编排，agent 会将它们串联起来运行完整的解析作业。

```python Agent with tools icon="robot"
# pip install -qU "langchain[anthropic]" to call the model
from langchain.agents import create_agent
from langchain_unstructured_transform import aget_transform_tools

tools = await aget_transform_tools()
agent = create_agent(
    model="claude-sonnet-4-6",
    tools=tools,
)

response = await agent.ainvoke(
    {
        "messages": [
            {
                "role": "user",
                "content": (
                    "Use the Unstructured Transform tools to parse ./report.pdf. "
                    "Provide the results as JSON."
                ),
            }
        ]
    }
)
print(response["messages"][-1].content)
```

agent 会请求上传 URL、上传每个文件、启动转换、轮询状态，并返回结果——每个输入文件对应一个输出。

## 限制

解析请求有以下限制：

- 每个文件必须是[受支持的文件类型](https://docs.unstructured.io/transform/supported-file-types)。
- 每个文件的大小必须不超过 50 MB。
- 每个请求的文件数必须不超过 10 个。
- 同时只能运行 5 个请求。

Transform MCP server 会通过其工具响应把这些限制反馈给 agent，因此你可以在 system prompt 中指示你的 agent 相应地对文件分批，并按限制放缓节奏。
