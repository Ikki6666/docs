>[Hugging Face Text Embeddings Inference (TEI)](https://huggingface.co/docs/text-embeddings-inference/index) 是一套用于部署和提供开源文本 embeddings 与序列分类模型的工具包。`TEI` 可为最流行的模型提供高性能提取能力，包括 `FlagEmbedding`、`Ember`、`GTE` 和 `E5`。

TEI 提供与 OpenAI 兼容的 `/v1/embeddings` 端点，因此你可以使用 `langchain-openai` 包中的 `OpenAIEmbeddings`，从 LangChain 使用 TEI 部署。

<Note>
本指南的早期版本使用 `HuggingFaceEndpointEmbeddings(model="http://localhost:8080")`。`langchain-huggingface` 不再接受为 `model` 传入 URL，并会抛出 `` `model` must be a HuggingFace repo ID, not a URL. ``。请改为按下文所示，让 `OpenAIEmbeddings` 指向 TEI 服务器。
</Note>

## 安装

安装 `langchain-openai`：

```shell
pip install -qU langchain-openai
```

## 使用 TEI 部署模型

使用 TEI 暴露一个 embedding 模型。例如，使用 Docker 时，你可以像下面这样提供 `sentence-transformers/all-MiniLM-L6-v2`：

```bash
model=sentence-transformers/all-MiniLM-L6-v2
volume=$PWD/data  # share a volume with the Docker container to avoid downloading weights every run

docker run --gpus all -p 8080:80 -v $volume:/data --pull always ghcr.io/huggingface/text-embeddings-inference:cuda-1.9 --model-id $model
```

如要在仅 CPU 的硬件上提供服务，请使用 `cpu-1.9` 镜像并去掉 `--gpus all` 标志。Docker 的具体用法会因底层硬件而异。例如，要在 Intel Gaudi/Gaudi2 硬件上提供该模型，请参阅 [tei-gaudi 仓库](https://github.com/huggingface/tei-gaudi) 获取相应的 docker run 命令。

## 嵌入文本

针对 TEI 服务器实例化 `OpenAIEmbeddings`：

```python
from langchain_openai import OpenAIEmbeddings

embeddings = OpenAIEmbeddings(
    model="sentence-transformers/all-MiniLM-L6-v2",
    base_url="http://localhost:8080/v1",
    api_key="unused",  # TEI does not require authentication by default
    check_embedding_ctx_length=False,  # send raw text; TEI tokenizes server-side
)
```

<Note>
请设置 `check_embedding_ctx_length=False`。若不设置，`OpenAIEmbeddings` 会使用 `tiktoken` 对输入进行分词并发送 token ID，而 TEI 不接受这种输入。该标志会改为发送原始文本。如果你为 TEI 启动了 API key，请将相同的值作为 `api_key` 传入。
</Note>

然后嵌入你的文本：

```python
text = "What is deep learning?"

query_result = embeddings.embed_query(text)
query_result[:3]
```

```text
[-0.077851, -0.033281, 0.019743]
```

```python
doc_result = embeddings.embed_documents([text])
doc_result[0][:3]
```

```text
[-0.077851, -0.033281, 0.019743]
```
