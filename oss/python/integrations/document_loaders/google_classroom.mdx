> [Google Classroom](https://edu.google.com/workspace-for-education/classroom/) 是 Google 开发的一款免费学习管理系统，属于 Google Workspace for Education 的一部分。它可以帮助教育工作者管理课程、作业和沟通。

本页介绍如何使用 `GoogleClassroomLoader` 从 Google Classroom 加载数据。该 loader 会从 [Classroom API](https://developers.google.com/classroom) 获取课程、作业（courseWork）、公告、课程材料、学生提交、评分标准（rubrics）、主题（topics）和班级名单，并将每一项转换为 LangChain `Document`。

当课堂条目带有文件附件时，loader 会自动从 Google Drive 下载并解析它们——支持 PDF、DOCX、CSV、纯文本、Google Docs、Sheets、Slides 和图片。

在 [GitHub](https://github.com/ayanokojix21/langchain-google-classroom) 上了解关于该包的更多信息。

## 前提条件

要使用该 loader，你需要：

1. 一个 [Google Cloud project](https://developers.google.com/workspace/guides/create-project)
2. 启用 [Classroom API](https://console.cloud.google.com/apis/library/classroom.googleapis.com)
3. 启用 [Drive API](https://console.cloud.google.com/apis/library/drive.googleapis.com)（用于文件附件）
4. 以下认证方式之一：
   - **OAuth 2.0 credentials**—适用于个人 Google 账号或测试
   - **Service Account credentials**—适用于 Google Workspace 域（生产环境）

## 安装

安装该集成包：

```bash
pip install -qU langchain-google-classroom
```

要启用 PDF 和 DOCX 附件的解析，请使用可选的 `parsers` extra 安装：

```bash
pip install -qU "langchain-google-classroom[parsers]"
```

## 凭证

### 选项 A：OAuth 2.0（个人账号）

1. 在 [Google Cloud Console](https://console.cloud.google.com/apis/credentials) 中，创建一个 **OAuth 2.0 Client ID**（Desktop application 类型）。
2. 下载 client secrets 文件，并将其保存为工作目录中的 `credentials.json`。
3. 首次运行时会打开一个浏览器窗口，请求用户同意。生成的 token 会缓存到 `token.json`，供后续运行使用。

```python
from langchain_google_classroom import GoogleClassroomLoader

loader = GoogleClassroomLoader()
# Opens browser for OAuth consent on first run
docs = loader.load()
```

### 选项 B：Service Account（Google Workspace）

1. 在 [Google Cloud Console](https://console.cloud.google.com/iam-admin/serviceaccounts) 中，创建一个 Service Account。
2. 为该 service account 启用 [Domain-Wide Delegation](https://developers.google.com/identity/protocols/oauth2/service-account#delegatingauthority)。
3. 下载密钥文件，并将其保存为 `service_account.json`。

```python
from langchain_google_classroom import GoogleClassroomLoader

loader = GoogleClassroomLoader(
    service_account_file="service_account.json",
)
docs = loader.load()
```

## 实例化

```python
from langchain_google_classroom import GoogleClassroomLoader

loader = GoogleClassroomLoader(
    course_ids=["123456789"],  # Optional: specific courses. Loads all if omitted.
    load_assignments=True,     # courseWork items (default: True)
    load_announcements=True,   # announcements (default: True)
    load_materials=True,       # courseWorkMaterials (default: True)
    load_attachments=True,     # resolve Drive file attachments (default: True)
)
```

### 构造函数参数

| Parameter | Type | Default | Description |
|:----------|:-----|:--------|:------------|
| `course_ids` | `list[str]` or `None` | `None` | 要加载的课程 ID。为 `None` 时加载所有可访问的课程。 |
| `load_assignments` | `bool` | `True` | 加载 courseWork 条目。 |
| `load_announcements` | `bool` | `True` | 加载公告。 |
| `load_materials` | `bool` | `True` | 加载课程材料。 |
| `load_attachments` | `bool` | `True` | 下载并返回 Drive 文件附件。 |
| `parse_attachments` | `bool` | `True` | 使用内置解析器解析附件内容（安装 `langchain-google-classroom[parsers]` 以支持 PDF/DOCX，或设置 `parse_attachments=False` 跳过解析）。 |
| `file_parser_cls` | `type[BaseBlobParser]` or `None` | `None` | 用于附件的自定义解析器类（会替换内置解析器）。 |
| `load_submissions` | `bool` | `False` | 加载学生提交。会自动添加所需的 scope。 |
| `load_topics` | `bool` | `False` | 加载课程主题。会自动添加所需的 scope。 |
| `load_roster` | `bool` | `False` | 加载学生和教师名单。会自动添加所需的 scope。 |
| `load_images` | `bool` | `False` | 处理图片附件（需要一个 `vision_model`）。 |
| `vision_model` | `BaseChatModel` or `None` | `None` | 用于理解 PDF 和图片中视觉内容的多模态 LLM。 |
| `max_file_size` | `int` | `50000000` | 附件的最大文件大小（字节）。超过此大小的文件会被跳过。 |
| `service_account_file` | `str` or `None` | `None` | service-account 密钥 JSON 文件的路径。 |
| `token_file` | `str` or `None` | `None` | 缓存的 OAuth token JSON 文件的路径。 |
| `client_secrets_file` | `str` or `None` | `None` | OAuth client-secrets JSON 文件的路径。 |

## 加载文档

使用 `load()` 一次性获取所有文档：

```python
from langchain_google_classroom import GoogleClassroomLoader

loader = GoogleClassroomLoader(
    course_ids=["123456789"],
)
docs = loader.load()
print(f"Loaded {len(docs)} documents")
```

每个 `Document` 都有结构化的 `page_content` 和丰富的 `metadata`：

```python
doc = docs[0]
print(doc.page_content[:200])
print(doc.metadata)
```

```python
# Example metadata
{
    "source": "google_classroom",
    "content_type": "assignment",
    "course_id": "123456789",
    "course_name": "Introduction to Computer Science",
    "title": "Week 3: Data Structures",
    "created_time": "2025-03-15T10:30:00.000Z",
    "updated_time": "2025-03-15T10:30:00.000Z",
    "alternate_link": "https://classroom.google.com/...",
}
```

## 延迟加载

对于大型课程或内存受限的环境，使用 `lazy_load()` 逐个流式获取文档：

```python
from langchain_google_classroom import GoogleClassroomLoader

loader = GoogleClassroomLoader(
    course_ids=["123456789"],
)

for doc in loader.lazy_load():
    print(f"[{doc.metadata['content_type']}] {doc.metadata.get('title', '')}")
```

## 异步加载

该 loader 通过 `alazy_load()` 支持异步迭代：

```python
import asyncio
from langchain_google_classroom import GoogleClassroomLoader


async def main():
    loader = GoogleClassroomLoader(
        course_ids=["123456789"],
    )
    docs = []
    async for doc in loader.alazy_load():
        docs.append(doc)
    return docs


docs = asyncio.run(main())
```

## 文件附件解析

当 `load_attachments=True`（默认值）时，loader 会解析每个课堂条目上的 Google Drive 文件附件，并将它们解析为额外的 `Document` 对象。

### 支持的格式

| Format | Parser | Notes |
|:-------|:-------|:------|
| PDF | `PDFParser` | 提取文本；可选的 vision LLM 用于嵌入图片 |
| DOCX | `DocxParser` | 提取文本和表格 |
| CSV | `CSVParser` | 每行一个文档，带表头感知格式化 |
| 纯文本 | `TextParser` | UTF-8 解码 |
| 图片（PNG、JPEG 等） | `ImageParser` | 需要 `vision_model` 和 `load_images=True` |
| Google Docs/Sheets/Slides | 先导出再解析 | 通过 Drive API 自动导出为 PDF/CSV/纯文本 |

### 使用 vision LLM 处理图片

要处理图片附件并从 PDF 页面中提取视觉上下文，请提供一个具备视觉能力的模型：

```python
from langchain_google_genai import ChatGoogleGenerativeAI
from langchain_google_classroom import GoogleClassroomLoader

loader = GoogleClassroomLoader(
    course_ids=["123456789"],
    load_attachments=True,
    load_images=True,
    vision_model=ChatGoogleGenerativeAI(model="gemini-2.0-flash"),
)
docs = loader.load()
```

### 使用自定义文件解析器

你可以用任何 `BaseBlobParser` 子类替换内置解析器：

```python
from langchain_community.document_loaders.parsers.pdf import PyMuPDFParser
from langchain_google_classroom import GoogleClassroomLoader

loader = GoogleClassroomLoader(
    course_ids=["123456789"],
    file_parser_cls=PyMuPDFParser,
)
docs = loader.load()
```
