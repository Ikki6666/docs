[Azure AI Search](https://learn.microsoft.com/azure/search/search-what-is-azure-search)（以前称为 `Azure Search` 和 `Azure Cognitive Search`）是一项云搜索服务，为开发者提供用于大规模向量、关键词和混合查询信息检索的基础设施、API 和工具。

`AzureSearch` 向量存储位于 [`langchain-azure-ai`](https://pypi.org/project/langchain-azure-ai/) 包中，该包会将 Azure AI Search SDK（`azure-search-documents`）和 `azure-identity` 作为依赖项安装。

## 安装软件包

<CodeGroup>
    ```bash pip
    pip install -qU langchain-azure-ai
    ```

    ```bash uv
    uv add langchain-azure-ai
    ```
</CodeGroup>

## 导入所需库

这里假定使用 [`OpenAIEmbeddings`](https://reference.langchain.com/python/langchain-openai/embeddings/base/OpenAIEmbeddings)，但如果你使用的是 Azure OpenAI，请改为导入 [`AzureOpenAIEmbeddings`](https://reference.langchain.com/python/langchain-openai/embeddings/azure/AzureOpenAIEmbeddings)。

```python
import os

from langchain_azure_ai.vectorstores import AzureSearch
from langchain_openai import AzureOpenAIEmbeddings, OpenAIEmbeddings
```

## 配置 OpenAI 设置

为你的 OpenAI provider 设置变量。你需要一个 [OpenAI 账户](https://platform.openai.com/docs/quickstart?context=python) 或 [Azure OpenAI 账户](https://learn.microsoft.com/en-us/azure/ai-services/openai/how-to/create-resource) 来生成嵌入。

```python
# Option 1: use an OpenAI account
openai_api_key: str = "PLACEHOLDER FOR YOUR API KEY"

```

```python
# Option 2: use an Azure OpenAI account with a deployment of an embedding model

azure_openai_api_version: str = "2023-05-15"
azure_deployment: str = "text-embedding-3-small"
```

## 配置向量存储设置

你需要一个 [Azure 订阅](https://azure.microsoft.com/en-us/free/search) 和 [Azure AI Search 服务](https://learn.microsoft.com/azure/search/search-create-service-portal) 才能使用此向量存储集成。对于小型且有限的工作负载，可以使用免费版本。

为你的 Azure AI Search URL 和管理员 API key 设置变量。你可以从 [Azure portal](https://portal.azure.com/#blade/HubsExtension/BrowseResourceBlade/resourceType/Microsoft.Search%2FsearchServices) 获取这些变量。

```python
vector_store_address: str = "YOUR_AZURE_SEARCH_ENDPOINT"
vector_store_password: str = "YOUR_AZURE_SEARCH_ADMIN_KEY"
```

## 自定义 schema 和查询

本节介绍如何用自定义 schema 替换默认 schema。

### 创建带自定义可筛选字段的新索引

此 schema 展示了字段定义。它是默认 schema，再加上几个被标记为可筛选的新字段。由于它使用默认向量配置，这里不会看到向量配置或向量配置文件覆盖项。默认向量配置文件的名称为“myHnswProfile”，它使用 Hierarchical Navigable Small World (HNSW) 向量配置，针对 content_vector 字段进行索引和查询。

此步骤中这个 schema 还没有数据。执行该单元格后，你应该会在 Azure AI Search 上得到一个空索引。

```python
from azure.search.documents.indexes.models import (
    ScoringProfile,
    SearchableField,
    SearchField,
    SearchFieldDataType,
    SimpleField,
    TextWeights,
)

#  Replace OpenAIEmbeddings with AzureOpenAIEmbeddings if Azure OpenAI is your provider.
embeddings: OpenAIEmbeddings = OpenAIEmbeddings(
    openai_api_key=openai_api_key, openai_api_version=openai_api_version, model=model
)
embedding_function = embeddings.embed_query

fields = [
    SimpleField(
        name="id",
        type=SearchFieldDataType.String,
        key=True,
        filterable=True,
    ),
    SearchableField(
        name="content",
        type=SearchFieldDataType.String,
        searchable=True,
    ),
    SearchField(
        name="content_vector",
        type=SearchFieldDataType.Collection(SearchFieldDataType.Single),
        searchable=True,
        vector_search_dimensions=len(embedding_function("Text")),
        vector_search_profile_name="myHnswProfile",
    ),
    SearchableField(
        name="metadata",
        type=SearchFieldDataType.String,
        searchable=True,
    ),
    # Additional field to store the title
    SearchableField(
        name="title",
        type=SearchFieldDataType.String,
        searchable=True,
    ),
    # Additional field for filtering on document source
    SimpleField(
        name="source",
        type=SearchFieldDataType.String,
        filterable=True,
    ),
]

index_name: str = "langchain-vector-demo-custom"

vector_store: AzureSearch = AzureSearch(
    azure_search_endpoint=vector_store_address,
    azure_search_key=vector_store_password,
    index_name=index_name,
    embedding_function=embedding_function,
    fields=fields,
)
```

### 添加数据并执行包含筛选的查询

本示例基于自定义 schema 向向量存储添加数据。它会将文本加载到 title 和 source 字段中。source 字段是可筛选的。本节的示例查询会根据 source 字段中的内容筛选结果。

```python
# Data in the metadata dictionary with a corresponding field in the index will be added to the index.
# In this example, the metadata dictionary contains a title, a source, and a random field.
# The title and the source are added to the index as separate fields, but the random value is ignored because it's not defined in the schema.
# The random field is only stored in the metadata field.
vector_store.add_texts(
    ["Test 1", "Test 2", "Test 3"],
    [
        {"title": "Title 1", "source": "A", "random": "10290"},
        {"title": "Title 2", "source": "A", "random": "48392"},
        {"title": "Title 3", "source": "B", "random": "32893"},
    ],
)
```

<Warning>
请像本示例这样，将筛选器作为 `filters`（一个 OData 表达式）传入。这种形式在所有已发布版本中都有效。在 `langchain-azure-ai` 1.3.0 及更早版本中，retriever 的 `search_kwargs` 中的 `filter` 键不会被应用：`similarity` 和 `similarity_score_threshold` 搜索会返回未筛选的结果，其他搜索类型则会引发 `TypeError`。`langchain-azure-ai` 1.3.1 及更高版本也接受 `filter`。使用 `as_retriever` 时，除非你要求 1.3.1 或更高版本，否则请使用 `search_kwargs={"filters": "source eq 'A'"}`。如果筛选器用于隔离租户或权限，在依赖它之前请确认它已被应用。
</Warning>

### 创建带评分配置文件的新索引

下面是另一个包含评分配置文件定义的自定义 schema。评分配置文件用于对非向量内容进行相关性调优，这在混合搜索场景中很有帮助。

```python
from azure.search.documents.indexes.models import (
    FreshnessScoringFunction,
    FreshnessScoringParameters,
    ScoringProfile,
    SearchableField,
    SearchField,
    SearchFieldDataType,
    SimpleField,
    TextWeights,
)

#  Replace OpenAIEmbeddings with AzureOpenAIEmbeddings if Azure OpenAI is your provider.
embeddings: OpenAIEmbeddings = OpenAIEmbeddings(
    openai_api_key=openai_api_key, openai_api_version=openai_api_version, model=model
)
embedding_function = embeddings.embed_query

fields = [
    SimpleField(
        name="id",
        type=SearchFieldDataType.String,
        key=True,
        filterable=True,
    ),
    SearchableField(
        name="content",
        type=SearchFieldDataType.String,
        searchable=True,
    ),
    SearchField(
        name="content_vector",
        type=SearchFieldDataType.Collection(SearchFieldDataType.Single),
        searchable=True,
        vector_search_dimensions=len(embedding_function("Text")),
        vector_search_profile_name="myHnswProfile",
    ),
    SearchableField(
        name="metadata",
        type=SearchFieldDataType.String,
        searchable=True,
    ),
    # Additional field to store the title
    SearchableField(
        name="title",
        type=SearchFieldDataType.String,
        searchable=True,
    ),
    # Additional field for filtering on document source
    SimpleField(
        name="source",
        type=SearchFieldDataType.String,
        filterable=True,
    ),
    # Additional data field for last doc update
    SimpleField(
        name="last_update",
        type=SearchFieldDataType.DateTimeOffset,
        searchable=True,
        filterable=True,
    ),
]
# Adding a custom scoring profile with a freshness function
sc_name = "scoring_profile"
sc = ScoringProfile(
    name=sc_name,
    text_weights=TextWeights(weights={"title": 5}),
    function_aggregation="sum",
    functions=[
        FreshnessScoringFunction(
            field_name="last_update",
            boost=100,
            parameters=FreshnessScoringParameters(boosting_duration="P2D"),
            interpolation="linear",
        )
    ],
)

index_name = "langchain-vector-demo-custom-scoring-profile"

vector_store: AzureSearch = AzureSearch(
    azure_search_endpoint=vector_store_address,
    azure_search_key=vector_store_password,
    index_name=index_name,
    embedding_function=embeddings.embed_query,
    fields=fields,
    scoring_profiles=[sc],
    default_scoring_profile=sc_name,
)
```
