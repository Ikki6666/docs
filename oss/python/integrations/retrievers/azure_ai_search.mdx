[Azure AI Search](https://learn.microsoft.com/azure/search/search-what-is-azure-search)（以前称为 `Azure Cognitive Search`）是 Microsoft 的云搜索服务，为开发者提供用于大规模向量、关键词和混合查询信息检索的基础设施、API 和工具。

`AzureAISearchRetriever` 从非结构化查询中返回文档。它会将查询作为全文 `search` 请求发送到 Azure AI Search 的 2023-11-01 稳定版 REST API。它不会对查询进行嵌入，也不会运行向量查询。如需向量或混合检索，请使用[向量存储集成](/oss/python/integrations/vectorstores/azuresearch) 中的 `AzureSearch.as_retriever()`。

本指南介绍如何开始使用 Azure AI Search [retriever](/oss/python/langchain/retrieval)。有关 `AzureAISearchRetriever` 的全部特性和配置，请参阅 [API reference](https://reference.langchain.com/python/langchain-azure-ai)。

## 设置

要使用此模块，你需要：

+ 一个 Azure AI Search 服务。如果你注册 Azure 试用版，可以免费[创建一个](https://learn.microsoft.com/azure/search/search-create-service-portal)。免费服务的配额较低，但足以运行本 notebook 中的代码。

+ 一个现有索引，其中包含与 `content_key` 匹配的可搜索文本字段。[向量存储模块](/oss/python/integrations/vectorstores/azuresearch) 会创建一个可用于此 retriever 的索引。你也可以[使用 Azure AI Search REST API 创建索引](https://learn.microsoft.com/azure/search/search-get-started-vector)。

+ 一个 API key 或 Azure AD Token。
  + API key 在创建搜索服务时生成。如果你只是查询索引，可以使用查询 API key，否则请使用管理员 API key。详情请参阅 [Find your API keys](https://learn.microsoft.com/azure/search/search-security-api-keys?tabs=rest-use%2Cportal-find%2Cportal-query#find-existing-keys)。
  + Azure AD Token 可与 Azure Managed Identity 一起使用。详情请参阅 [Connect your app to Azure AI Search using identities](https://learn.microsoft.com/en-us/azure/search/keyless-connections?tabs=python%2Cazure-cli)。

将搜索服务名称、索引名称和 API key 设置为环境变量，或将它们作为参数传给 `AzureAISearchRetriever`。搜索索引提供可搜索的内容。

使用 API Key

```python
import os

os.environ["AZURE_AI_SEARCH_SERVICE_NAME"] = "<YOUR_SEARCH_SERVICE_NAME>"
os.environ["AZURE_AI_SEARCH_INDEX_NAME"] = "<YOUR_SEARCH_INDEX_NAME>"
os.environ["AZURE_AI_SEARCH_API_KEY"] = "<YOUR_API_KEY>"
```

使用 Azure AD Token

```python
import os

os.environ["AZURE_AI_SEARCH_SERVICE_NAME"] = "<YOUR_SEARCH_SERVICE_NAME>"
os.environ["AZURE_AI_SEARCH_INDEX_NAME"] = "<YOUR_SEARCH_INDEX_NAME>"
os.environ["AZURE_AI_SEARCH_AD_TOKEN"] = "<YOUR_AZURE_AD_TOKEN>"
```

如果你希望从单个查询获得自动 tracing，也可以取消下面的注释，设置 [LangSmith](/langsmith/observability) API key：

```python
import getpass

os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

## 实例化

对于 `AzureAISearchRetriever`，请提供 `index_name`、`content_key`，并将 `top_k` 设置为希望检索的结果数量。如果未设置 `top_k`，请求会省略 `$top`，Azure AI Search 会应用其默认的分页大小。

```python
from langchain_azure_ai.retrievers import AzureAISearchRetriever

retriever = AzureAISearchRetriever(
    content_key="content", top_k=1, index_name="langchain-vector-demo"
)
```

## 使用

现在你可以用它从 Azure AI Search 中检索文档。
调用 `invoke` 即可检索文档。它最多返回 `top_k` 个与查询匹配的文档。

```python
retriever.invoke("here is my unstructured query string")
```

## 示例

本节演示如何在内置示例数据上使用该 retriever。如果你的搜索服务上已有向量索引，可以跳过此步骤。

首先提供 endpoint 和 key。由于此步骤会创建向量索引，请指定一个文本嵌入模型来获得文本的向量表示。本示例假定使用部署了 text-embedding-3-small 的 Azure OpenAI。由于此步骤会创建索引，请务必为你的搜索服务使用管理员 API key。

```python
import os

from langchain_azure_ai.retrievers import AzureAISearchRetriever
from langchain_azure_ai.vectorstores import AzureSearch
from langchain_openai import AzureOpenAIEmbeddings

os.environ["AZURE_AI_SEARCH_SERVICE_NAME"] = "<YOUR_SEARCH_SERVICE_NAME>"
os.environ["AZURE_AI_SEARCH_INDEX_NAME"] = "langchain-vector-demo"
os.environ["AZURE_AI_SEARCH_API_KEY"] = "<YOUR_SEARCH_SERVICE_ADMIN_API_KEY>"
azure_endpoint: str = "<YOUR_AZURE_OPENAI_ENDPOINT>"
azure_openai_api_key: str = "<YOUR_AZURE_OPENAI_API_KEY>"
azure_openai_api_version: str = "2023-05-15"
azure_deployment: str = "text-embedding-3-small"
```

使用 Azure OpenAI 的嵌入模型将文档转换为嵌入，并存储在 Azure AI Search 向量存储中。将索引名称设置为 `langchain-vector-demo` 会创建一个与该索引名称关联的新向量存储。

```python
embeddings = AzureOpenAIEmbeddings(
    model=azure_deployment,
    azure_endpoint=azure_endpoint,
    openai_api_key=azure_openai_api_key,
)

vector_store: AzureSearch = AzureSearch(
    embedding_function=embeddings.embed_query,
    azure_search_endpoint=f"https://{os.environ['AZURE_AI_SEARCH_SERVICE_NAME']}.search.windows.net",
    azure_search_key=os.getenv("AZURE_AI_SEARCH_API_KEY"),
    index_name="langchain-vector-demo",
)
```

接下来，将数据加载到新的向量存储中。本示例加载 `state_of_the_union.txt` 文件，并将文本拆分为不重叠的 400 字符块。随后这些块会作为嵌入添加到向量存储中。

```python
from pathlib import Path

from langchain_text_splitters import CharacterTextSplitter

text = Path("state_of_the_union.txt").read_text(encoding="utf-8")
text_splitter = CharacterTextSplitter(chunk_size=400, chunk_overlap=0)
docs = text_splitter.create_documents([text])

vector_store.add_documents(documents=docs)
```

接下来，创建一个 retriever。当前的 `index_name` 变量是上一步中的 `langchain-vector-demo`。如果你跳过了向量存储创建步骤，请在参数中提供你的索引名称。在此查询中，会返回最佳结果。

```python
retriever = AzureAISearchRetriever(
    content_key="content", top_k=1, index_name="langchain-vector-demo"
)
```

现在从已上传的文档中检索与查询相关的数据。

```python
retriever.invoke("does the president have a plan for covid-19?")
```

## 在 chain 中使用

```python
from langchain_core.output_parsers import StrOutputParser
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.runnables import RunnablePassthrough
from langchain_openai import ChatOpenAI

prompt = ChatPromptTemplate.from_template(
    """Answer the question based only on the context provided.

Context: {context}

Question: {question}"""
)

llm = ChatOpenAI(model="gpt-5.4-mini")


def format_docs(docs):
    return "\n\n".join(doc.page_content for doc in docs)


chain = (
    {"context": retriever | format_docs, "question": RunnablePassthrough()}
    | prompt
    | llm
    | StrOutputParser()
)
```

```python
chain.invoke("does the president have a plan for covid-19?")
```
