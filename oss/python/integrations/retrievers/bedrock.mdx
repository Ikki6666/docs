本指南将帮助你开始使用 AWS Knowledge Bases [retriever](/oss/python/deepagents/retrieval)。

[Knowledge Bases for Amazon Bedrock](https://aws.amazon.com/bedrock/knowledge-bases/) 是 Amazon Web Services (AWS) 提供的一项能力，可通过使用你的私有数据定制 FM 响应，从而快速构建 RAG 应用。

实现 `RAG` 通常需要组织执行若干繁琐步骤，将数据转换为 embeddings（vectors），把 embeddings 存储到专用向量数据库中，并构建到数据库的自定义集成以搜索和检索与用户查询相关的文本。这一过程可能既耗时又低效。

有了 `Knowledge Bases for Amazon Bedrock`，你只需把数据指向 `Amazon S3` 中的位置，`Knowledge Bases for Amazon Bedrock` 就会负责把数据摄取到向量数据库的整个工作流。如果你没有现成的向量数据库，Amazon Bedrock 会为你创建一个 Amazon OpenSearch Serverless vector store。进行检索时，可通过 LangChain - Amazon Bedrock 集成中的 Retrieve API，从 knowledge bases 中为用户查询检索相关结果。

**Amazon Bedrock 现在还提供 [Managed Knowledge Bases](https://docs.aws.amazon.com/bedrock/latest/userguide/kb-build-managed.html)**，可自动处理 embedding、存储和检索，无需外部 vector store。请参阅下文的 [Managed Knowledge Base](#managed-knowledge-base) 部分。

## 设置

Knowledge Bases 可以通过 [AWS Console](https://aws.amazon.com/console/) 或 [AWS SDKs](https://aws.amazon.com/developer/tools/) 进行配置。我们需要 `knowledge_base_id` 来实例化 retriever。

如果你想从单个查询中获得自动 tracing，也可以取消下面的注释来设置你的 [LangSmith](/langsmith/observability) API key：

```python
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

### 安装

这个 retriever 位于 `langchain-aws` 包中：

```python
pip install -qU "langchain-aws>=1.6.3"
```

**SDK 要求：** 托管搜索和 agentic retrieval 需要 `langchain-aws>=1.6.3`，它会安装 `boto3>=1.43.32`。

## 实例化

### Vector Knowledge Base

对于传统的基于向量的 knowledge bases（使用 OpenSearch Serverless、Pinecone 等）：

```python
from langchain_aws.retrievers import AmazonKnowledgeBasesRetriever

retriever = AmazonKnowledgeBasesRetriever(
    knowledge_base_id="PUIJP4EQUA",
    retrieval_config={"vectorSearchConfiguration": {"numberOfResults": 4}},
)
```

### Managed Knowledge Base

对于 [Managed Knowledge Bases](https://docs.aws.amazon.com/bedrock/latest/userguide/kb-build-managed.html)（推荐，无需 vector store）：

```python
from langchain_aws.retrievers import AmazonKnowledgeBasesRetriever

retriever = AmazonKnowledgeBasesRetriever(
    knowledge_base_id="YOUR_MANAGED_KB_ID",
    retrieval_config={"managedSearchConfiguration": {"numberOfResults": 4}},
)
```

Managed knowledge bases 会自动处理 embedding、分块、存储和检索。它们还支持托管 reranking，以提升结果质量。

### Agentic Retrieval

对于能从查询分解和托管 reranking 中获益的复杂查询，请使用独立的 `agentic_retrieve` helper：

```python
from langchain_aws.retrievers import agentic_retrieve

result = agentic_retrieve(
    knowledge_base_id="YOUR_MANAGED_KB_ID",
    query="What are the differences between S3 storage classes?",
    region_name="us-west-2",
)

for doc in result["results"]:
    print(doc["content"]["text"])
```

Agentic retrieval 使用 `AgenticRetrieveStream`，它会执行智能查询分解和托管 reranking。它需要 `langchain-aws>=1.6.3`，并且只适用于 managed knowledge bases。

## 用法

```python
query = "What did the president say about Ketanji Brown?"

retriever.invoke(query)
```

## 在 chain 中使用

```python
from langchain_aws import ChatBedrock
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.runnables import RunnablePassthrough
from langchain_core.output_parsers import StrOutputParser

llm = ChatBedrock(model_id="anthropic.claude-sonnet-4-20250514-v1:0")

prompt = ChatPromptTemplate.from_template(
    "Answer the question based on the context:\n\nContext: {context}\n\nQuestion: {question}"
)

chain = (
    {"context": retriever, "question": RunnablePassthrough()}
    | prompt
    | llm
    | StrOutputParser()
)

chain.invoke("What are the key features?")
```

## 必需的 IAM 权限

```json
{
  "Effect": "Allow",
  "Action": [
    "bedrock:Retrieve",
    "bedrock:AgenticRetrieveStream"
  ],
  "Resource": "arn:aws:bedrock:<region>:<account-id>:knowledge-base/<kb-id>"
}
```
