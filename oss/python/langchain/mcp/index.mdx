[Model Context Protocol (MCP)](https://modelcontextprotocol.io) 是一个开放协议，用于标准化应用程序向语言模型提供工具和 context 的方式。LangChain 智能体通过 [`MCPAdapter`](https://reference.langchain.com/python/langchain/mcp/adapter/MCPAdapter) 调用在 MCP 服务器上定义的工具，它会发现服务器的工具，并将其适配成可以直接传给 [`create_agent`](https://reference.langchain.com/python/langchain/agents/factory/create_agent) 的 LangChain 工具。

[`MCPAdapter`](https://reference.langchain.com/python/langchain/mcp/adapter/MCPAdapter) 构建在 [FastMCP](https://gofastmcp.com) 之上，FastMCP 负责传输推断、协议协商、连接管理和身份验证。本节介绍 LangChain 特定的层，并链接到 FastMCP 客户端文档以了解底层的连接细节。

<Note>
`langchain.mcp` 命名空间需要 `langchain[mcp]>=1.4.0`，目前处于 beta 阶段。从它导入时，每个进程会引发一次 `LangChainBetaWarning`。API 可能会变化。

如果你在 v1.4.0 之前使用过 MCP，参见 [从 `langchain-mcp-adapters` 迁移](/oss/python/migrate/langchain-mcp-adapters)。
</Note>




## 安装

安装带有 `mcp` extra 的 LangChain，它会引入 FastMCP：

<CodeGroup>
```bash pip
pip install "langchain[mcp]"
```

```bash uv
uv add "langchain[mcp]"
```
</CodeGroup>

## 传输方式

[`MCPAdapter`](https://reference.langchain.com/python/langchain/mcp/adapter/MCPAdapter) 从你提供的目标推断传输方式。目标是在进程内服务器、通过 stdio 的本地脚本和远程 URL 之间的唯一区别：

<McpTransportsPy />

目标可以是以下任意一种：

- **一个 `http`/`https` URL**（`str`）：通过 Streamable HTTP 访问。
- **一个脚本路径**（`Path`）：作为子进程通过 stdio 启动。
- **一个传输对象**（`StreamableTransport`）：预先配置的传输对象。参见 [Client Transports](https://gofastmcp.com/clients/transports)。
- **一个进程内的 `FastMCP` 服务器**：在内存中连接，无需子进程或 socket。
- **一个 `MCPConfig` 字典**（`{"mcpServers": {...}}`）：一个 adapter 背后的多个服务器。参见 [Connections](/oss/python/langchain/mcp/connections#multiple-servers)。
- **一个预构建的 `fastmcp.Client`**：用于完全掌控传输、[缓存](https://gofastmcp.com/clients/client#response-caching)和[协议协商](https://gofastmcp.com/clients/client#protocol-negotiation)。

<Warning>
`str` 目标必须是 `http` 或 `https` URL。FastMCP 解析字符串时会先把它当作文件路径测试，再把它当作 URL 测试，因此命名了一个已存在的 `.py` 或 `.js` 文件的字符串会作为子进程启动该文件。由于字符串是目标最常从配置或模型中到达的形式，[`MCPAdapter`](https://reference.langchain.com/python/langchain/mcp/adapter/MCPAdapter) 会拒绝与 URL 形状不匹配的字符串。
</Warning>
