大多数远程 MCP 服务器都需要身份验证。[`MCPAdapter`](https://reference.langchain.com/python/langchain/mcp/adapter/MCPAdapter) 将身份验证委托给 FastMCP，因此 `fastmcp.Client` 接受的任何凭证都可以使用：静态 [Bearer 令牌](#bearer-token)、完整的 [OAuth 2.1](#oauth-authentication) 流程，或任何 [`httpx.Auth`](https://www.python-httpx.org/advanced/authentication/)。将凭证传给预构建的客户端，再把该客户端交给 adapter。当一个智能体与多个服务器通信时，使用[按服务器身份验证](#per-server-authentication)；在部署中，使用[按用户身份验证](#per-user-authentication)，让每次运行以调用者的身份访问服务器。
<Note>
`langchain.mcp` 命名空间需要 `langchain[mcp]>=1.4.0`，目前处于 beta 阶段。API 可能会变化。
</Note>

## Bearer 令牌

最简单的情况：服务器验证你预先配置的令牌，并将其放入 `Authorization: Bearer <token>` 头中。没有发现、浏览器或刷新流程。将令牌作为客户端的 `auth` 传入：

<McpAuthBearerPy />

`auth` 参数接受 Bearer 令牌字符串、字面量 `"oauth"`，或任何 `httpx.Auth`。在 `MCPConfig` 集群中，每个服务器使用相同的键。

## OAuth 身份验证

对于自己发放凭证的服务器，传入字面量字符串 `"oauth"`。FastMCP 运行完整的 OAuth 2.1 流程：发现、[动态客户端注册](https://modelcontextprotocol.io/specification/draft/basic/authorization)、浏览器重定向和令牌交换。动态客户端注册意味着客户端在运行时自行注册，而不是由你预先配置客户端 ID：

<McpAuthOauthPy />

默认情况下，令牌保存在内存中，因此每次运行都会重复浏览器步骤。传入一个带有令牌存储的预构建 `OAuth` provider，以便跨运行持久保存令牌：

```python
from fastmcp.client import Client
from fastmcp.client.auth import OAuth

oauth = OAuth(mcp_url="https://example.com/mcp", token_storage=...)
client = Client("https://example.com/mcp", auth=oauth)
```

FastMCP 为常见身份提供方（Auth0、WorkOS、Okta 等）提供了 provider；客户端运行的流程在它们之间完全相同。参见 FastMCP 文档中的 [OAuth authentication](https://gofastmcp.com/clients/auth/oauth)。

## 按服务器身份验证

当一个智能体与多个服务器通信时，每个服务器可能需要自己的凭证。使用 [`ClientGroup`](/oss/python/langchain/mcp/connections#independent-connections-with-clientgroup) 为每个服务器提供独立的连接，并为每个客户端设置 `auth`，这样每个服务器都可以独立进行身份验证：

## 按用户身份验证

在部署中，每次运行应该以发起该运行的用户身份访问 MCP 服务器，而不是使用一个共享凭证。这种模式有两个部分：

1. **在 LangGraph 服务器上对调用者进行身份验证。** 一个[自定义 auth 处理器](/langsmith/auth)将传入请求解析为用户身份，每次运行从其运行时中读取该身份。
2. **为该用户铸造或交换凭证。** 在[图工厂](/oss/python/langchain/mcp/connections#scale-a-deployment)内部，读取用户的身份并构建带有按用户令牌的 MCP 客户端，这样连接就携带了该用户的授权。

<McpAuthPerUserPy />

在生产环境中，`token_for` 代表部署中已有的机制：将 session 交换为按用户令牌的 OAuth 网关，或按身份运行授权码流程的 `fastmcp.client.auth` provider。按用户隔离任何[缓存的响应](/oss/python/langchain/mcp/connections#caching)，以验证后的身份为键，这样任何用户都不会看到其他用户缓存的工具列表。
