sidebarTitle: 实现

集成包是用户可以安装并在自己项目中使用的 Python 包。它们会实现一个或多个符合 LangChain 接口标准的组件。

LangChain 组件是 [`langchain-core`](https://github.com/langchain-ai/langchain/tree/master/libs/core) 中基础类的子类。示例包括[聊天模型](/oss/javascript/integrations/chat)、[工具](/oss/javascript/integrations/tools)、[检索器](/oss/javascript/integrations/retrievers)等。

你的集成包通常至少需要实现其中某一类组件的子类。展开下方标签页可查看各类组件的细节。

<Tabs>
    <Tab title="Chat Models">
        聊天模型是 [`BaseChatModel`](https://reference.langchain.com/javascript/langchain-core/language_models/chat_models/BaseChatModel) 类的子类。它们实现用于生成聊天补全、处理消息格式和管理模型参数的方法。

        <Warning>

            聊天模型集成指南目前仍在编写中。在此期间，请阅读[聊天模型概念指南](/oss/javascript/langchain/models)，了解 LangChain 聊天模型的工作方式。你也可以参考 [LangChain 仓库](https://github.com/langchain-ai/langchainjs/tree/main/libs/providers)中的现有集成

        </Warning>
    </Tab>
    <Tab title="Embeddings">
        嵌入模型是 [`Embeddings`](https://reference.langchain.com/javascript/langchain-core/embeddings/Embeddings) 类的子类。

        <Warning>
            嵌入模型集成指南目前仍在编写中。在此期间，请阅读[嵌入模型概念指南](/oss/javascript/integrations/embeddings)，了解 LangChain 嵌入模型的工作方式。
        </Warning>
    </Tab>
    <Tab title="Tools">
        工具主要有两种用途：

        1. 定义一个 "input schema" 或 "args schema"，并将其与文本请求一起传给聊天模型的工具调用功能，以便聊天模型生成一个 "tool call"，也就是调用该工具所需的参数。
        2. 接收上面生成的 "tool call"，执行某些动作，并返回一个响应，该响应可以作为 ToolMessage 传回聊天模型。

        Tools 类必须继承自 [`BaseTool`](https://reference.langchain.com/javascript/classes/_langchain_core.tools.StructuredTool.html) 基类。这个接口有 3 个属性和 2 个方法，需要在子类中实现。

        <Warning>
            工具集成指南目前仍在编写中。在此期间，请阅读[工具概念指南](/oss/javascript/langchain/tools)，了解 LangChain 工具的工作方式。
        </Warning>
    </Tab>
    <Tab title="Middleware">
        [Middleware](/oss/javascript/langchain/middleware/overview) 允许你通过挂接模型调用、工具调用和智能体生命周期事件来自定义智能体行为。中间件类是 [`AgentMiddleware`](https://reference.langchain.com/javascript/langchain/index/AgentMiddleware) 基类的子类。

        在构建集成之前，请先阅读[自定义中间件指南](/oss/javascript/langchain/middleware/custom)，理解钩子、状态更新和中间件模式。

        中间件集成通常分为两类：

        | Type | Description | Examples |
        |------|-------------|---------|
        | **Provider-specific** | 利用某个 provider 独有的能力 | 提示词缓存、原生工具执行、内容审核 |
        | **Cross-provider** | 可与任何模型或工具配合使用 | 限流、PII 检测、日志记录、护栏 |

        provider 特定的中间件应放在该 provider 的集成包中（例如 `langchain-anthropic`）。跨 provider 的中间件则可以作为独立包发布。

        你也可以把以下现有中间件集成作为参考：

    </Tab>
    <Tab title="Checkpointers">
        Checkpointer 用于在 LangGraph 中启用[persistence](/oss/javascript/langgraph/persistence)，让智能体能够跨交互保存和恢复状态。

        可在 [LangGraph 仓库](https://github.com/langchain-ai/langgraph/tree/main/libs)中查看现有 checkpointer 集成，作为实现示例。
    </Tab>
