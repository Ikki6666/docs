## 前置条件

开始之前，请确保你拥有模型提供商的 API key（例如 Gemini、Anthropic、OpenAI）。所有可用提供商请参阅[聊天模型集成](/oss/javascript/integrations/chat)。

如果使用 [LangSmith Gateway](/langsmith/llm-gateway)，你可以[自带提供商 key](/langsmith/llm-gateway-quickstart)，或使用 [Gateway Credits](/langsmith/llm-gateway-credits) 在没有提供商 key 的情况下访问模型。

## 设置



安装 `@langchain/langgraph`、`@langchain/core`、`@langchain/anthropic`、`langchain` 和 `zod`：

```bash
npm install @langchain/langgraph @langchain/core @langchain/anthropic langchain zod
```


本示例使用 Anthropic。请在 shell 或 `.env` 文件中设置 API key：

<CodeGroup>
```bash Shell
export ANTHROPIC_API_KEY="your-api-key"
```

```bash .env
ANTHROPIC_API_KEY=your-api-key
```
</CodeGroup>

如需使用其他提供商，请参阅[聊天模型集成](/oss/javascript/integrations/chat)，并在后续步骤中调整模型初始化。

模型可以调用工具，随后智能体再次调用模型，直到返回最终答案。

创建一个文件，把每个步骤的代码添加到前一步骤的代码下方。

概念背景请参阅 [Graph API 概述](/oss/javascript/langgraph/graph-api)。

## 1. 定义工具和模型

本示例使用 Claude Sonnet 模型，并定义加法、乘法和除法工具。

为智能体创建一个文件（`agent.py` 或 `agent.ts`）。添加以下代码：



```typescript
import { ChatAnthropic } from "@langchain/anthropic";
import { tool } from "@langchain/core/tools";
import * as z from "zod";

const model = new ChatAnthropic({
  model: "claude-sonnet-4-6",
  temperature: 0,
});

// Define tools
const add = tool(({ a, b }) => a + b, {
  name: "add",
  description: "Add two numbers",
  schema: z.object({
    a: z.number().describe("First number"),
    b: z.number().describe("Second number"),
  }),
});

const multiply = tool(({ a, b }) => a * b, {
  name: "multiply",
  description: "Multiply two numbers",
  schema: z.object({
    a: z.number().describe("First number"),
    b: z.number().describe("Second number"),
  }),
});

const divide = tool(({ a, b }) => a / b, {
  name: "divide",
  description: "Divide two numbers",
  schema: z.object({
    a: z.number().describe("First number"),
    b: z.number().describe("Second number"),
  }),
});

// Augment the LLM with tools
const toolsByName = {
  [add.name]: add,
  [multiply.name]: multiply,
  [divide.name]: divide,
};
const tools = Object.values(toolsByName);
const modelWithTools = model.bindTools(tools);
```


## 2. 定义状态

图的状态用于存储消息和 LLM 调用次数。

在工具和模型代码下方添加以下内容：



<Tip>
    LangGraph 中的状态会在智能体执行期间持续保留。

    `MessagesValue` 通过内置 reducer 追加消息。`llmCalls` 字段使用带有 `(x, y) => x + y` 的 `ReducedValue` 来累计计数。
</Tip>





```typescript
import {
  StateGraph,
  StateSchema,
  MessagesValue,
  ReducedValue,
  GraphNode,
  ConditionalEdgeRouter,
  START,
  END,
} from "@langchain/langgraph";
import { z } from "zod/v4";

const MessagesState = new StateSchema({
  messages: MessagesValue,
  llmCalls: new ReducedValue(
    z.number().default(0),
    { reducer: (x, y) => x + y }
  ),
});
```


## 3. 定义模型节点

模型节点调用 LLM，并决定是否调用工具。

在状态定义下方添加以下内容：



```typescript
import { SystemMessage } from "@langchain/core/messages";

const llmCall: GraphNode<typeof MessagesState> = async (state) => {
  const response = await modelWithTools.invoke([
    new SystemMessage(
      "You are a helpful assistant tasked with performing arithmetic on a set of inputs."
    ),
    ...state.messages,
  ]);
  return {
    messages: [response],
    llmCalls: 1,
  };
};
```


## 4. 定义工具节点

工具节点调用工具并返回结果。

在模型节点下方添加以下内容：



```typescript
import { AIMessage, ToolMessage } from "@langchain/core/messages";

const toolNode: GraphNode<typeof MessagesState> = async (state) => {
  const lastMessage = state.messages.at(-1);

  if (lastMessage == null || !AIMessage.isInstance(lastMessage)) {
    return { messages: [] };
  }

  const result: ToolMessage[] = [];
  for (const toolCall of lastMessage.tool_calls ?? []) {
    const tool = toolsByName[toolCall.name];
    const observation = await tool.invoke(toolCall);
    result.push(observation);
  }

  return { messages: result };
};
```


## 5. 定义结束逻辑

条件边函数根据 LLM 是否发起工具调用，路由到工具节点或结束。

在工具节点下方添加以下内容：



```typescript
const shouldContinue: ConditionalEdgeRouter<{ InputSchema: typeof MessagesState; Nodes: "toolNode" }> = (state) => {
  const lastMessage = state.messages.at(-1);

  // Check if it's an AIMessage before accessing tool_calls
  if (!lastMessage || !AIMessage.isInstance(lastMessage)) {
    return END;
  }

  // If the LLM makes a tool call, then perform an action
  if (lastMessage.tool_calls?.length) {
    return "toolNode";
  }

  // Otherwise, we stop (reply to the user)
  return END;
};
```


## 6. 构建并编译智能体

在路由函数下方添加以下内容。使用 [`StateGraph`](https://reference.langchain.com/javascript/langchain-langgraph/index/StateGraph) 构建图，并使用 [`compile`](https://reference.langchain.com/javascript/langchain-langgraph/index/StateGraph/compile) 编译它：



```typescript
const agent = new StateGraph(MessagesState)
  .addNode("llmCall", llmCall)
  .addNode("toolNode", toolNode)
  .addEdge(START, "llmCall")
  .addConditionalEdges("llmCall", shouldContinue, ["toolNode", END])
  .addEdge("toolNode", "llmCall")
  .compile();
```


## 7. 设置 LangSmith 追踪

[LangSmith](https://smith.langchain.com?utm_source=docs&utm_medium=cta&utm_campaign=langsmith-signup&utm_content=oss-langgraph-quickstart) 会在智能体运行时显示工具调用和模型响应。

此步骤为可选。在 [smith.langchain.com](https://smith.langchain.com?utm_source=docs&utm_medium=cta&utm_campaign=langsmith-signup&utm_content=oss-langgraph-quickstart) 注册并创建 API key，然后在运行智能体前在 shell 中设置以下环境变量：

```bash
export LANGSMITH_TRACING=true
export LANGSMITH_API_KEY="your-langsmith-api-key"
```

## 8. 运行智能体

在编译后的图下方添加以下内容：



```typescript
import { HumanMessage } from "@langchain/core/messages";

const result = await agent.invoke({
  messages: [new HumanMessage("Add 3 and 4.")],
});

for (const message of result.messages) {
  console.log(`[${message.type}]: ${message.text}`);
}
```


运行该文件：



```bash
npx tsx agent.ts
```


你应该会看到用户消息、对 `add` 的工具调用、工具结果 `7`，以及最终的助手回复。具体文本因模型而异，但工具结果是 `7`。
