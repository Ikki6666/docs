---
title: INVALID_GRAPH_NODE_RETURN_VALUE
---



LangGraph [`StateGraph`](https://reference.langchain.com/javascript/langchain-langgraph/index/StateGraph)
收到了来自某个节点的非 object 返回值。下面是一个示例：

```typescript
import { z } from "zod/v4";
import { StateGraph, StateSchema, GraphNode } from "@langchain/langgraph";

const State = new StateSchema({
  someKey: z.string(),
});

const badNode: GraphNode<typeof State> = (state) => {
  // 应该返回一个包含 "someKey" 的 object，而不是数组
  return ["whoops"];
};

const builder = new StateGraph(State).addNode("badNode", badNode);
// ...

const graph = builder.compile();
```

调用上面的图会得到类似下面的错误：

```typescript
await graph.invoke({ someKey: "someval" });
```

```
InvalidUpdateError: Expected object, got ['whoops']
For troubleshooting, visit: https://docs.langchain.com/oss/javascript/langgraph/errors/INVALID_GRAPH_NODE_RETURN_VALUE
```

你的图中的节点必须返回一个包含 state 中定义的一个或多个 key 的 object。


## 排查

下面这些方法可能有助于解决这个错误：



* 如果你的节点里逻辑比较复杂，请确保所有代码路径都返回适合你所定义 state 的 object。
