把编译后的图渲染为 Mermaid 文本或 PNG 图片，用于检查拓扑结构和调试路由。需要交互式界面时，可使用 [LangSmith Studio](/langsmith/studio) 配合[本地服务器](/oss/javascript/langgraph/local-server)。



可以可视化任何暴露 `getGraphAsync()` 的已编译图，包括 [`StateGraph`](https://reference.langchain.com/javascript/langchain-langgraph/index/StateGraph)。


下面的示例在两种语言中使用同一个小图：两个节点，一条从 `node1` 出发的条件边，以及一条从 `node2` 回到 `node1` 的循环。

## Mermaid

在 drawable graph 上调用 `draw_mermaid()` 获取 Mermaid 语法。可以把结果粘贴到任意 Mermaid 渲染器，或保留在文档和 PR 中。



<LanggraphGraphApiVisualizeMermaidJs />

```
---
config:
  flowchart:
    curve: linear
---
graph TD;
	__start__([<p>__start__</p>]):::first
	node1(node1)
	node2(node2)
	__end__([<p>__end__</p>]):::last
	__start__ --> node1;
	node1 -.-> __end__;
	node1 -.-> node2;
	node2 --> node1;
	classDef default fill:#f2f0ff,line-height:1.2
	classDef first fill-opacity:0
	classDef last fill:#bfb6fc
```


## PNG



把图渲染为 `.png`。这里使用 Mermaid.ink API 生成图表。

```typescript
import * as fs from "node:fs/promises";

const drawableGraph = await app.getGraphAsync();
const image = await drawableGraph.drawMermaidPng();
const imageBuffer = new Uint8Array(await image.arrayBuffer());

await fs.writeFile("graph.png", imageBuffer);
```
