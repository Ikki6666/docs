title: 安装 LangGraph
sidebarTitle: 安装
---

要安装基础 LangGraph 包：



<CodeGroup>
```bash npm
npm install @langchain/langgraph @langchain/core
```

```bash pnpm
pnpm add @langchain/langgraph @langchain/core
```

```bash yarn
yarn add @langchain/langgraph @langchain/core
```

```bash bun
bun add @langchain/langgraph @langchain/core
```
</CodeGroup>


使用 LangGraph 时，你通常还需要访问 LLM 并定义工具。
你可以用任何你习惯的方式来完成。

文档中会采用一种方式，也就是使用 [LangChain](/oss/javascript/langchain/overview)。

安装 LangChain：



<CodeGroup>
```bash npm
npm install langchain
```

```bash pnpm
pnpm add langchain
```

```bash yarn
yarn add langchain
```

```bash bun
bun add langchain
```
</CodeGroup>


如果你要使用特定的 LLM 提供商包，需要单独安装它们。

请参阅 [集成](/oss/javascript/integrations/providers/overview) 页面，查看各提供商的安装说明。
