[retriever](/oss/javascript/langchain/retrieval) 是一种接口，给定非结构化查询后返回文档。
它比 vector store 更通用。
Retriever 不需要具备存储文档的能力，只需要能够返回，或检索，文档即可。

Retrievers 接受字符串查询作为输入，并返回 `Document` 对象列表。

关于如何使用 retrievers 的具体细节，请参阅[这里相关的 how-to guides](/oss/javascript/langchain/retrieval)。

请注意，所有 [vector stores](/oss/javascript/integrations/vectorstores) 都可以[转换为 retrievers](/oss/javascript/langchain/retrieval)。
可用的 vector store retrievers 请参阅 vector store 的[integration docs](/oss/javascript/integrations/vectorstores/)。
