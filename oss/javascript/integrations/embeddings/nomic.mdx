---

`NomicEmbeddings` 类使用 Nomic AI API 为给定文本生成 embeddings。

## 设置

要使用 Nomic API，你需要[注册一个 Nomic 账号并创建 API key](https://atlas.nomic.ai/)。

首先需要安装 [`@langchain/nomic`](https://www.npmjs.com/package/@langchain/nomic) 包：

<Tip>
LangChain 包安装的一般说明，请参阅[这个部分](/oss/javascript/langchain/install)。
</Tip>

```bash npm
npm install @langchain/nomic @langchain/core
```

## 用法

```typescript
import { NomicEmbeddings } from "@langchain/nomic";

/* Embed queries */
const nomicEmbeddings = new NomicEmbeddings();
const res = await nomicEmbeddings.embedQuery("Hello world");
console.log(res);
/* Embed documents */
const documentRes = await nomicEmbeddings.embedDocuments([
  "Hello world",
  "Bye bye",
]);
console.log(documentRes);
```
