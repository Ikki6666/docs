## 设置与安装

要使用该功能，请安装 `@sap/hana-langchain` 包及其 peer dependencies：

```bash
npm install @sap/hana-langchain @langchain/core@latest @langchain/classic@latest langchain@latest
```

`HanaSparqlQAAgent` 是一种基于 agent 的方法，用于对存储在 SAP HANA Cloud 中的 RDF 数据进行问答。与基于 chain 的方法不同，该 agent 可以：

1. **动态检索本体（ontology）**，使用一个专用工具
2. **迭代地生成并执行 SPARQL 查询**
3. **自我纠错**，当查询失败或返回意外结果时
4. **逐步推理**复杂问题

## 初始化

你需要：

- 一个为 agent 提供推理能力的 **LLM**
- 一个 **`HanaRdfGraph`**（包含连接、`graphUri` 和本体）

按照此处的步骤 [HanaRdfGraph](/oss/javascript/integrations/graphs/sap_hana_rdf_graph) 了解更多关于创建 `HanaRdfGraph` 实例的内容。

导入 `HanaSparqlQAAgent`

```typescript
import { HanaSparqlQAAgent, HanaSparqlQAAgentOptions } from "@sap/hana-langchain";
const agentConfig : HanaSparqlQAAgentOptions = {
  graph: graph
};
const agent = HanaSparqlQAAgent.createAgent(llm, agentConfig);
```

## Agent 概览

该 agent 迭代地使用工具来：
1. 首先检索本体，以理解数据结构
2. 基于 schema 生成合适的 SPARQL 查询
3. 执行查询并解读结果
4. 构造自然语言回答

### 默认配置

- **Tools**：
  - `retrieveOntology` - 从 graph 中以 Turtle 格式检索 RDF 本体/schema
  - `executeSparql` - 对 HANA RDF graph 执行 SPARQL 查询
- **System Prompt**：提供了一个默认的 system prompt，其中包含 SPARQL 生成与工具使用说明。
- **Middleware**：默认添加 `ModelRetryMiddleware({maxRetries:3})` 和 `ToolRetryMiddleWare({maxRetries:2})`，以防止无限循环

### 自定义你的 Agent

你可以通过向 `createAgent` 提供额外参数来自定义 agent 的行为：

```typescript
const agentConfig : HanaSparqlQAAgentOptions = {
  graph: graph,  // Required: HanaRdfGraph instance
  systemPrompt: yourCustomPrompt,  // Custom system prompt (string or SystemMessage)
  tools: [yourCustomTools],  // Additional tools to include
  middleware: [yourCustomMiddlewares],  // Additional middleware to include
  includeDefaultTools: true,  // include default tools (default: True)
  includeDefaultMiddleware: true,  // include default middleware (default: True)
};
const agent = HanaSparqlQAAgent.createAgent(
    model, // Required LLM to power the agent
    agentConfig
)
```

## 示例：对 "Movies" 知识图谱进行问答

**前提条件**：
你必须拥有一个启用了 **triple store** 功能的 SAP HANA Cloud 实例。
详细说明请参阅：[Enable Triple Store](https://help.sap.com/docs/hana-cloud-database/sap-hana-cloud-sap-hana-database-knowledge-graph-guide/enable-triple-store/)<br />
加载 `kgdocu_movies` 示例数据。请参见 [Knowledge Graph Example](https://help.sap.com/docs/hana-cloud-database/sap-hana-cloud-sap-hana-database-knowledge-graph-guide/knowledge-graph-example)。

下面的示例：

1. 实例化指向 movies 数据 graph 的 `HanaRdfGraph`
2. 创建一个由 LLM 驱动的 `HanaSparqlQAAgent`
3. 提出自然语言问题，并让 agent 自行推理得出答案

该示例演示了 agent 如何动态检索本体、生成 SPARQL 查询，并返回人类可读的回答。

```typescript
import * as dotenv from 'dotenv';
// Load environment variables if needed
dotenv.config();

import hanaClient from "@sap/hana-client";

const connectionParams = {
  host: process.env.HANA_DB_ADDRESS,
  port: process.env.HANA_DB_PORT,
  user: process.env.HANA_DB_USER,
  password: process.env.HANA_DB_PASSWORD,
};
const client = hanaClient.createConnection(connectionParams);

// connect to hanaDB
await new Promise<void>((resolve, reject) => {
  client.connect((err: Error) => {
    // Use arrow function here
    if (err) {
      reject(err);
    } else {
      console.log("Connected to SAP HANA successfully.");
      resolve();
    }
  });
});
```

然后，设置知识图谱实例

```typescript
import { HanaRdfGraph, HanaRdfGraphOptions } from "@sap/hana-langchain";

const graphOptions: HanaRdfGraphOptions = {
  connection: client,
  graphUri: "kgdocu_movies",
  autoExtractOntology: true,
};

// create a Graph instance from a source URI
const graph = new HanaRdfGraph(graphOptions);

// need to initialize once an instance is created.
await graph.initialize(graphOptions);
```

```typescript
// Serialise the graph schema (optional)

  writer.addQuad(quad);

  if (error) {
    console.error("Error serialising schema:", error);
  } else {
    console.log("Graph Schema in Turtle format:\n", result);
  }
});
```

```typescript
import { ChatOpenAI } from "@langchain/openai"; // or your chosen LLM

const llm = new ChatOpenAI({ model: "gpt-4o" });

```

然后，创建 SPARQL QA Agent。

```typescript
const agentConfig: HanaSparqlQAAgentOptions = {
  graph: graph,
};

// Initialize the QA agent
const agent = HanaSparqlQAAgent.createAgent(llm, agentConfig);
```

```typescript
const query = "which actors acted in Blade Runner?";
// const query = "Which movies are in the data?"
// const query = "In which movies did Keanu Reeves and Carrie-Anne Moss play in together"
// const query = "which movie genres are in the data?"
// const query = "which are the two most assigned movie genres?"
// const query = "where were the actors of 'Blade Runner' born?"
// const query = "which actors acted together in a movie and were born in the same city?"

console.log("\n--- Streamed (messages: token-by-token) ---");
for await (const [chunk, _metadata] of await agent.stream(
  { messages: [{ role: "user", content: query }] },
  { streamMode: "messages" }
)) {
  if (chunk.content) {
    process.stdout.write(chunk.text);
  }
}
console.log();
```

### 底层发生了什么？

1. **本体检索**
   Agent 首先使用 `retrieveOntology` 工具以 Turtle 格式获取 RDF schema。这让 agent 了解可用的类、属性和关系。

2. **SPARQL 生成**
   基于本体和用户的问题，agent 会推理要查询哪些实体和属性，然后生成一个有效的 `SELECT` 查询。

3. **查询执行**
   Agent 调用 `executeSparql` 工具，对 HANA RDF graph 运行生成的查询。如果查询失败或返回意外结果，agent 可以自我纠错并重试。

4. **答案构造**
   Agent 解读查询结果，并严格基于检索到的数据构造一个简洁、人类可读的回答。
