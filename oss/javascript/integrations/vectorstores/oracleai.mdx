<Tip>
**兼容性**：仅支持 Node.js。
</Tip>

Oracle AI Database 支持 AI 工作负载，你可以按**语义**而不只是关键词查询数据。它把**非结构化内容上的语义搜索**与**业务数据上的关系型过滤**结合在同一个系统里，因此你可以构建检索工作流（例如 RAG），而无需额外引入单独的向量数据库，也无需把数据分散到多个平台。

本指南演示如何使用 `OracleVS`（Oracle AI Vector Search 的 LangChain vector store 集成）来：

- 将文档和 embeddings 写入 Oracle
- 运行相似度搜索
- 创建 HNSW 和 IVF 索引
- 使用 metadata filters 做高级检索
- 在 Oracle AI Database 26ai 中启用混合搜索（关键词 + 语义）
- 使用 Oracle Text 运行全文搜索

## 设置

安装 Oracle client bindings 和 LangChain Oracle 辅助包：

<CodeGroup>
```bash npm
npm install @oracle/langchain-oracledb @langchain/core
```
```bash yarn
yarn add @oracle/langchain-oracledb @langchain/core
```
```bash pnpm
pnpm add @oracle/langchain-oracledb @langchain/core
```
</CodeGroup>

设置将拥有 vector 表的 Oracle 用户的连接凭据：

```bash
export ORACLE_USER=testuser
export ORACLE_PASSWORD=testuser
export ORACLE_DSN="localhost:1521/free"
```

## 创建 vector store

下面的示例假设你已经创建了包含 vector 和 metadata 列的表，并使用 [`OracleEmbeddings`](/oss/javascript/integrations/embeddings/oracleai) 生成了 embeddings。

```typescript
import oracledb from "oracledb";
import { OracleEmbeddings, OracleVS } from "@oracle/langchain-oracledb";
import { Document } from "@langchain/core/documents";

const connection = await oracledb.getConnection({
  user: process.env.ORACLE_USER,
  password: process.env.ORACLE_PASSWORD,
  connectionString: process.env.ORACLE_DSN,
});

const embeddings = new OracleEmbeddings(connection, {
  provider: "database",
  model: "DEMO_MODEL",
});

const vectorStore = new OracleVS(embeddings, {
  client: connection,
  tableName: "DEMO_VECTORS",
  query: "Find documents about Oracle RAG patterns.",
  distanceStrategy: "DOT",
});
await vectorStore.initialize();

const docs: Document[] = [
  {
    pageContent: "LangChain works great with Oracle Database.",
    metadata: {
      doc_id: "doc-1",
      title: "RAG overview",
      status: "release",
      tags: ["AI", "rag"],
      category: "books",
      price: 18,
    },
  },
];

await vectorStore.addDocuments(docs);

// Close connections or pools in application shutdown hooks to avoid leaks.
// await connection.close();
```


如果你的应用已经管理了 Oracle Database 连接池，可以直接把 pool 传给 `OracleVS`。该 store 会按需获取和释放连接。

```typescript
const pool = await oracledb.createPool({
  user: process.env.ORACLE_USER,
  password: process.env.ORACLE_PASSWORD,
  connectString: process.env.ORACLE_DSN,
  poolIncrement: 1,
  poolMax: 4,
  poolMin: 0,
  poolPingInterval: 60,
});

const vectorStoreFromPool = new OracleVS(embeddings, {
  client: pool,
  tableName: "DEMO_VECTORS",
  query: "Find documents about Oracle RAG patterns.",
  distanceStrategy: "DOT",
});
await vectorStoreFromPool.initialize();

// Release resources during shutdown.
// await pool.close(0);
```


## 过滤搜索结果

你可以把丰富的 metadata filters 作为第三个参数传给 `similaritySearch`、`similaritySearchWithScore` 或 `similaritySearchVectorWithScore`。Filters 作用于 Oracle VS 为每个文档维护的 JSON `metadata` 列。

支持的比较操作符包括 `$eq`（默认）、`$ne`、`$lt`、`$lte`、`$gt`、`$gte`、`$in`、`$nin`、`$between` 和 `$exists`。可以使用 `$and` 和 `$or` 组合条件，构建更具表达力的谓词。

```typescript
const results = await vectorStore.similaritySearch("oracle rag", 3, {
  $and: [
    { status: "release" },
    { tags: { $in: ["AI"] } },
    { price: { $between: [10, 25] } },
  ],
});

// Or request scores alongside documents.
const scored = await vectorStore.similaritySearchWithScore(
  "oracle rag",
  3,
  { status: "release" },
);

console.log(results[0]?.pageContent);
console.log(scored[0]?.[1]); // similarity score
```


也支持嵌套的逻辑子句。例如：

```typescript
const complexFilter = {
  $or: [
    { status: "draft" },
    {
      $and: [
        { category: "books" },
        { price: { $lte: 20 } },
      ],
    },
  ],
};
```

## 使用向量索引加速搜索

Oracle Database 可以通过在 `embedding` 列上创建向量索引来加速相似度查询。`@oracle/langchain-oracledb` 辅助包提供了 `createIndex` 工具，可用于创建 HNSW（默认）或 IVF 索引。

### HNSW 索引（默认）

当你需要兼顾召回率和延迟的图结构索引时，使用 HNSW。省略 `idxType` 即使用默认配置，也可以覆盖 `neighbors`、`efConstruction` 和 `accuracy` 等参数。

```typescript
import { createIndex } from "@oracle/langchain-oracledb";

// Reuse the vectorStore and connection from the setup section,
// or create one with OracleVS.fromDocuments / initialize().
await createIndex(connection, vectorStore, {
  idxName: "demo_hnsw_idx",
  neighbors: 48,
  efConstruction: 400,
  accuracy: 95,
  parallel: 16,
});
```

### IVF 索引

传入 `idxType: "IVF"` 以及要创建的邻居分区数即可切换到 IVF。IVF 将向量划分到多个簇中，适合需要粗量化且内存占用可预测的场景。

```typescript
import { createIndex } from "@oracle/langchain-oracledb";

await createIndex(connection, vectorStore, {
  idxName: "demo_ivf_idx",
  idxType: "IVF",
  neighborPart: 64,
  accuracy: 90,
  parallel: 8,
});
```

在加载数据后（或在 `initialize` 之后）运行一次 `createIndex`，之后的搜索即可复用该索引。要重建或切换策略，请通过标准 SQL（`DROP INDEX ...`）删除现有索引，再用新参数重新运行 `createIndex`。
