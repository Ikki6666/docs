---
title: "按字符分割 - Text splitter integration guide"
---

基于字符的分割是最简单的文本分割方式。它使用指定的字符序列来切分文本（默认值：`"\n\n"`），并用字符数来衡量块长度。

**要点**：
1. **文本如何被分割**：按给定的字符分隔符分割。
2. **块大小如何衡量**：按字符数衡量。


你可以在以下两种方式之间选择：
- `.splitText`：返回普通字符串块。
- `.createDocuments`：返回 LangChain [Document](https://reference.langchain.com/javascript/langchain-core/documents/Document) 对象，在下游任务需要保留元数据时很有用。



<CodeGroup>
```bash npm
npm install @langchain/textsplitters
```

```bash pnpm
pnpm install @langchain/textsplitters
```

```bash yarn
yarn add @langchain/textsplitters
```

```bash bun
bun add @langchain/textsplitters
```
</CodeGroup>



```ts
import { CharacterTextSplitter } from "@langchain/textsplitters";
import { readFileSync } from "fs";

// Example: read a long document
const stateOfTheUnion = readFileSync("state_of_the_union.txt", "utf8");

const splitter = new CharacterTextSplitter({
    separator: "\n\n",
    chunkSize: 1000,
    chunkOverlap: 200,
});
const texts = splitter.createDocuments([{ pageContent: stateOfTheUnion }]);
console.log(texts[0]);
```

使用 `.createDocuments` 可以把与每个文档关联的元数据传递到输出块中：

```ts
const metadatas = [{"document": 1}, {"document": 2}]
const documents = splitter.createDocuments(
    [{ pageContent: stateOfTheUnion }, { pageContent: stateOfTheUnion }],
    { metadatas: metadatas }
);
console.log(documents[0]);
```

使用 `.splitText` 可以直接获取字符串内容：

```ts
splitter.splitText(stateOfTheUnion)[0]
```
