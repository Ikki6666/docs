title: "按 token 分割 - Text splitter integration guide"

语言模型有 token 上限，因此不应超过这个限制。所以在你把[文本分割](/oss/javascript/integrations/splitters/)成多个块时，按 token 数量进行计数通常是个好主意。可用的 tokenizer 有很多种，而在统计文本 token 时，你应当使用与你的语言模型一致的 tokenizer。



## js-tiktoken

<Note>
**[js-tiktoken](https://github.com/dqbd/tiktoken) 是由 `OpenAI` 创建的 `BPE` tokenizer 的 JavaScript 版本。**
</Note>

我们可以通过 [TokenTextSplitter](https://reference.langchain.com/javascript/langchain-textsplitters/TokenTextSplitter) 使用 `tiktoken` 来估算 token 使用量。对于 OpenAI 模型，这通常会更准确。

1. 文本如何被分割：按传入的字符分割。
2. 块大小如何衡量：按 `tiktoken` tokenizer 计数。

<CodeGroup>
```bash npm
npm install @langchain/textsplitters
```

```bash pnpm
pnpm install @langchain/textsplitters
```

```bash yarn
yarn add @langchain/textsplitters
```

```bash bun
bun add @langchain/textsplitters
```
</CodeGroup>

```ts
import { TokenTextSplitter } from "@langchain/textsplitters";
import { readFileSync } from "fs";

// Example: read a long document
const stateOfTheUnion = readFileSync("state_of_the_union.txt", "utf8");
```

如果你想使用 [TokenTextSplitter](https://reference.langchain.com/javascript/langchain-textsplitters/TokenTextSplitter) 进行分割，再结合 `tiktoken` 合并块，可以在初始化 [TokenTextSplitter](https://reference.langchain.com/javascript/langchain-textsplitters/TokenTextSplitter) 时传入 `encodingName`（例如 `cl100k_base`）。注意，这种方法得到的分块在按 `tiktoken` tokenizer 衡量时，可能会大于设定的块大小。

```ts
import { TokenTextSplitter } from "@langchain/textsplitters";

// Example: use cl100k_base encoding
const splitter = new TokenTextSplitter({ encodingName: "cl100k_base", chunkSize: 10, chunkOverlap: 0 });

const texts = splitter.splitText(stateOfTheUnion);
console.log(texts[0]);
```

```text
Madam Speaker, Madam Vice President, our First Lady and Second Gentleman. Members of Congress and the Cabinet. Justices of the Supreme Court. My fellow Americans.

With a duty to one another to the American people to the Constitution.
```
