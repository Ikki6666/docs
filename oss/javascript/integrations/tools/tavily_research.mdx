[Tavily](https://tavily.com/) 是一个专为 AI agents（LLMs）构建的搜索引擎，可快速提供实时、准确且真实的结果。Tavily 提供一个 [Research](https://docs.tavily.com/documentation/api-reference/endpoint/research) endpoint，可为 LLMs 和 RAG 生成量身定制的综合性研究报告。

## 设置

该集成位于 `@langchain/tavily` 包中：

<CodeGroup>
```bash npm
npm install @langchain/tavily @langchain/core
```
```bash yarn
yarn add @langchain/tavily @langchain/core
```
```bash pnpm
pnpm add @langchain/tavily @langchain/core
```

### 凭证

在 [Tavily dashboard](https://app.tavily.com) 上设置一个 API key，并将其设置为名为 `TAVILY_API_KEY` 的环境变量。

```typescript
process.env.TAVILY_API_KEY = "YOUR_API_KEY";
```

设置 [LangSmith](https://smith.langchain.com/?utm_source=docs&utm_medium=cta&utm_campaign=langsmith-signup&utm_content=oss-javascript-integrations-tools-tavily_research) 以获得可观测性也很有帮助（但不是必需的）：

```typescript
process.env.LANGSMITH_TRACING = "true";
process.env.LANGSMITH_API_KEY = "your-api-key";
```

## 实例化

你可以像这样导入并实例化 `TavilyResearch`：

```ts
import { TavilyResearch } from "@langchain/tavily";

const tool = new TavilyResearch({
  // model: "mini",
  // citationFormat: "apa",
  // stream: false,
});
```

- `model`（可选）：Research agent 模型。可选 `"mini"`、`"pro"` 或 `"auto"`（默认值）。
- `citationFormat`（可选）：来源的引用格式。可选 `"numbered"`、`"mla"`、`"apa"` 或 `"chicago"`（默认值为 `"numbered"`）。
- `outputSchema`（可选）：约束研究结果结构的 JSON Schema。
- `stream`（可选）：是否流式返回研究结果。默认值为 `false`。

## 调用

### [使用 args 直接调用](/oss/javascript/langchain/tools)

Tavily research 工具在调用时接受以下参数：

- `input`（必填）：要调查的研究任务或问题
- 可选覆盖项：`model`、`outputSchema`、`stream`、`citationFormat`

```ts
await tool.invoke({
  input: "What are the latest developments in AI?",
});
```

### [使用 ToolCall 调用](/oss/javascript/langchain/tools)

也可以使用模型生成的 `ToolCall` 调用该工具，这种情况下会返回一个 [`ToolMessage`](https://reference.langchain.com/javascript/langchain-core/messages/ToolMessage)：

```ts
// This is usually generated by a model, but we'll create a tool call directly for demo purposes.
const modelGeneratedToolCall = {
  args: {
    input: "What are the latest developments in AI?",
  },
  id: "1",
  name: tool.name,
  type: "tool_call",
};

await tool.invoke(modelGeneratedToolCall);
```

## 在 agent 中使用

把 research 工具传给 `createAgent`，这样 agent 就可以携带研究任务调用它：

```ts
import { ChatOpenAI } from "@langchain/openai";
import { TavilyResearch } from "@langchain/tavily";
import { createAgent } from "langchain";

const llm = new ChatOpenAI({
  model: "gpt-5.5",
});

const tavilyResearchTool = new TavilyResearch({
  model: "mini",
});

const agent = createAgent({
  model: llm,
  tools: [tavilyResearchTool],
});

const userInput =
  "Research the latest developments in AI agents and summarize key trends.";

const stream = await agent.streamEvents(
  { messages: [{ role: "user", content: userInput }] },
  { version: "v3" },
);

await Promise.all([
  (async () => {
    for await (const message of stream.messages) {
      for await (const token of message.text) {
        process.stdout.write(token);
      }
    }
  })(),
  (async () => {
    for await (const call of stream.toolCalls) {
      console.dir({ name: call.name, input: call.input }, { depth: null });
      await call.output;
    }
  })(),
]);

await stream.output;
```
