## 教程

下面按照框架整理了常见用例的教程。

### Managed Deep Agents

[Managed Deep Agents](/langsmith/javascript/managed-deep-agents-overview) 是构建和部署 deep agent 的推荐方式。你编写 agent，LangSmith 负责 harness 和运行时。

<Card title="深度研究" icon="search" href="/oss/javascript/deepagents/deep-research" horizontal>
  使用 Managed Deep Agents 或 Deep Agents SDK 构建一个多步骤 Web 研究智能体。
</Card>

<Card title="内容构建器" icon="pencil" href="/oss/javascript/deepagents/content-builder" horizontal>
  使用 Managed Deep Agents 或 Deep Agents SDK 构建一个具备品牌语气、skills 和图像工具的内容写作智能体。
</Card>

### Deep Agents

如果你希望在使用与 [Managed Deep Agents](#managed-deep-agents) 相同的 Deep Agents harness 时获得最大灵活性，可以使用 Deep Agents SDK 自行托管 agent，或运行自定义的 [LangSmith Deployment](/langsmith/deployment)。

</Card>

### LangGraph

LangChain 的 [agent](/oss/javascript/langchain/agents) 实现建立在 [LangGraph](/oss/javascript/langgraph/overview) 原语之上。
如果需要更深度的定制，也可以直接使用 LangGraph 实现智能体。

<Card title="自定义 RAG 智能体" icon="user-search" href="/oss/javascript/langgraph/agentic-rag" horizontal>
  使用 LangGraph 原语构建一个可进行细粒度控制的 RAG 智能体。
</Card>

  直接在 LangGraph 中实现 SQL 智能体，以获得最大的灵活性。
</Card>

### Multi-agent

这些教程展示了 [multi-agent 模式](/oss/javascript/langchain/multi-agent)，把 LangChain 智能体与 LangGraph 工作流结合起来。
