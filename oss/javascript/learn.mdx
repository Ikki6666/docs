## 教程

下面按照框架整理了常见用例的教程。

### Deep Agents

[Deep Agents](/oss/javascript/deepagents/overview) 内置了管理上下文、虚拟文件系统以及其他常见智能体需求的能力。

</Card>

  构建一个带有 subagent 委派和策略性反思的多步骤 Web 研究智能体。
</Card>

### LangChain

[LangChain](/oss/javascript/langchain/overview) 的 [agent](/oss/javascript/langchain/agents) 实现让你能够快速上手简单用例。

  使用 LangChain 组件为 PDF 构建语义搜索引擎。
</Card>

<Card title="RAG 智能体" icon="user-search" href="/oss/javascript/deepagents/rag" horizontal>
  创建一个检索增强生成（RAG）智能体。
</Card>

<Card title="SQL 智能体" icon="database" href="/oss/javascript/langchain/sql-agent" horizontal>
  构建一个可通过 human-in-the-loop 审查与数据库交互的 SQL 智能体。
</Card>

### LangGraph

LangChain 的 [agent](/oss/javascript/langchain/agents) 实现建立在 [LangGraph](/oss/javascript/langgraph/overview) 原语之上。
如果需要更深度的定制，也可以直接使用 LangGraph 实现智能体。

<Card title="自定义 RAG 智能体" icon="user-search" href="/oss/javascript/langgraph/agentic-rag" horizontal>
  使用 LangGraph 原语构建一个可进行细粒度控制的 RAG 智能体。
</Card>



### Multi-agent

这些教程展示了 [multi-agent 模式](/oss/javascript/langchain/multi-agent)，把 LangChain 智能体与 LangGraph 工作流结合起来。
