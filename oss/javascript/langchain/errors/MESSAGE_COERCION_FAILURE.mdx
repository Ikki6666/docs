## 故障排查

要解决此错误：

1. **确保格式正确**：传给聊天模型的所有输入都必须是 LangChain 消息类数组，或者是受支持的类消息格式
2. 确认消息在传递给模型之前，没有发生非预期的字符串化或转换
3. 检查错误堆栈，并添加日志语句，在消息对象传给模型之前先查看它们的内容
