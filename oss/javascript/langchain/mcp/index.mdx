[Model Context Protocol (MCP)](https://modelcontextprotocol.io) 是一个开放协议，用于标准化应用程序向语言模型提供工具和 context 的方式。LangChain 智能体通过 [`MCPAdapter`](https://reference.langchain.com/javascript/langchain-mcp-adapters/MCPAdapter) 调用在 MCP 服务器上定义的工具，它会发现服务器的工具，并将其适配成可以直接传给 [`createAgent`](https://reference.langchain.com/javascript/langchain/index/createAgent) 的 LangChain 工具。

<Note>
本指南需要 `@langchain/mcp-adapters` 2.0 或更高版本。如果你使用 1.x，参见 [1.x 文档](/oss/javascript/langchain/mcp-v1)或[迁移指南](/oss/javascript/migrate/langchain-mcp-adapters)。
</Note>


## 安装



安装 `@langchain/mcp-adapters` 包及其 peer 依赖：

<CodeGroup>
```bash npm
npm install @langchain/mcp-adapters@^2.0.0 @langchain/core @langchain/langgraph
```

```bash pnpm
pnpm add @langchain/mcp-adapters@^2.0.0 @langchain/core @langchain/langgraph
```

```bash yarn
yarn add @langchain/mcp-adapters@^2.0.0 @langchain/core @langchain/langgraph
```

```bash bun
bun add @langchain/mcp-adapters@^2.0.0 @langchain/core @langchain/langgraph
```
</CodeGroup>

如果你导入 SDK 类型或传输方式，还需要添加 `@modelcontextprotocol/client`。

## 传输方式



[`MCPAdapter`](https://reference.langchain.com/javascript/langchain-mcp-adapters/MCPAdapter) 接受一个由命名的服务器定义组成的映射。它从每个定义中选择传输方式，因此一个 adapter 可以同时连接到本地 stdio 服务器和远程 HTTP 服务器：

<McpTransportsJs />

每个服务器定义可以使用以下传输方式之一：

- **stdio**：提供 `command` 和 `args`。adapter 将该命令作为子进程启动，并通过标准输入和输出进行通信。
- **Streamable HTTP**：提供 `url`。这是基于 URL 的服务器的默认传输方式，因此 `transport: "http"` 是可选的。
- **SSE**：提供 `url` 并设置 `transport: "sse"`。仅对暴露 SSE 端点的旧式服务器使用此传输方式。

传输方式选择与协议协商是分开的。可选的 `mode` 设置控制客户端接受哪个 MCP 协议时代。参见 [Protocol eras](/oss/javascript/langchain/mcp/connections#protocol-eras)。

<Note>
对于新的远程服务器，同时省略 `transport` 和 `mode`。adapter 会使用 Streamable HTTP 和自动协议协商。仅在连接到具有已知旧式需求的服务器时才指定这些设置。
</Note>
