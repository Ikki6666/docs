## 概览

使用 LangChain 的 [embeddings](/oss/javascript/integrations/embeddings) 和 [vector stores](/oss/javascript/integrations/vectorstores)，围绕一个 PDF 构建语义搜索引擎。用它可以检索出与查询相似的段落，然后把 retriever 接入[检索增强生成（RAG）](/oss/javascript/deepagents/retrieval)或其他 LLM 工作流。

本教程涵盖：

1. 从 PDF 创建 `Document` 对象。
2. 生成 embeddings。
3. 加载并切分 PDF。
4. 在 vector store 中索引 chunk，并按相似度查询。
5. 把存储包装成 retriever。

本指南还会在搜索引擎之上实现一个最小版本的 RAG。

### 概念

本指南聚焦于文本数据检索，会覆盖以下概念：

- [`Document`](https://reference.langchain.com/javascript/langchain-core/documents/Document)
- [Text splitters](/oss/javascript/integrations/splitters)
- [Embeddings](/oss/javascript/integrations/embeddings)
- [Vector stores](/oss/javascript/integrations/vectorstores) 和 [retrievers](/oss/javascript/integrations/retrievers)

## 创建文档

LangChain 实现了 [`Document`](https://reference.langchain.com/javascript/langchain-core/documents/Document) 抽象，用来表示一段文本及其相关元数据。它有三个属性：


- `pageContent`：表示内容的字符串。
- `metadata`：包含任意元数据的 dict。
- `id`：（可选）文档的字符串标识。


`metadata` 可以保存文档来源、与其他文档的关系以及其他信息。一条单独的 [`Document`](https://reference.langchain.com/javascript/langchain-core/documents/Document) 往往代表更大文档的一个 chunk。

下面的代码会创建示例文档：


```typescript
import { Document } from "@langchain/core/documents";

const documents = [
  new Document({
    pageContent:
      "Dogs are great companions, known for their loyalty and friendliness.",
    metadata: { source: "mammal-pets-doc" },
  }),
  new Document({
    pageContent: "Cats are independent pets that often enjoy their own space.",
    metadata: { source: "mammal-pets-doc" },
  }),
];
```


## 生成 embeddings

向量搜索会存储与文本相关联的数值向量。把查询 embed 成同维度的向量，然后使用相似度指标（例如余弦相似度）找出相关文本。

LangChain 支持来自[众多提供方](/oss/javascript/integrations/embeddings/)的 embeddings。选择一个模型来指定文本如何转换为数值向量：


<EmbeddingsTabsJS />

```typescript
const vector1 = await embeddings.embedQuery(documents[0].pageContent);
const vector2 = await embeddings.embedQuery(documents[1].pageContent);

assert vector1.length === vector2.length;
console.log(`Generated vectors of length ${vector1.length}\n`);
console.log(vector1.slice(0, 10));
```

## 选择 vector store

LangChain 的 [`VectorStore`](https://reference.langchain.com/javascript/langchain-core/vectorstores/VectorStore) 对象可以往存储中添加文本和 [`Document`](https://reference.langchain.com/javascript/langchain-core/documents/Document) 对象，并用相似度指标查询它们。它们通常使用 [embedding](/oss/javascript/integrations/embeddings) 模型初始化，这些模型负责把文本转换为数值向量。

LangChain 包含与许多 vector store 技术的 [integrations](/oss/javascript/integrations/vectorstores)。有些由提供方托管并需要凭据，有些运行在独立基础设施中（本地或第三方），还有一些以内存方式运行，适合轻量工作负载。选择一个 vector store：

## 加载并切分 PDF

从 PDF 加载内容，然后在索引前把它切分成更小的 chunk。本例使用[一份 2023 年的 Nike 10-K 样例文件](https://github.com/langchain-ai/langchain/blob/v0.3/docs/docs/example_data/nke-10k-2023.pdf)。

运行示例前请先下载样例 PDF。将 `file_path`（Python）或 `filePath`（JavaScript）设置为下载文件的绝对路径，或使用相对于工作目录的路径。


```typescript
import { readFileSync } from "node:fs";
import { Document } from "@langchain/core/documents";
import { PDFParse } from "pdf-parse";

// Below is a minimal helper for demonstration purposes.
async function loadPdfPages(filePath: string): Promise<Document[]> {
  const parser = new PDFParse({
    data: new Uint8Array(readFileSync(filePath)),
  });
  try {
    const { pages } = await parser.getText();
    return pages.map(
      (page) =>
        new Document({
          pageContent: page.text,
          metadata: { source: filePath, page: page.num - 1 },
        })
    );
  } finally {
    await parser.destroy();
  }
}

const filePath = "../../data/nke-10k-2023.pdf";
const docs = await loadPdfPages(filePath);
console.log(docs.length);
```


```text
107
```

页面粒度对于检索来说往往太粗。进一步切分页面，这样相关段落就不会被周围文本冲淡。[`RecursiveCharacterTextSplitter`](https://reference.langchain.com/javascript/langchain-textsplitters/RecursiveCharacterTextSplitter) 会递归地按常见分隔符（例如换行）切分，直到每个 chunk 达到目标大小。这是通用文本场景下推荐的 text splitter。


```typescript
import { RecursiveCharacterTextSplitter } from "@langchain/textsplitters";

const textSplitter = new RecursiveCharacterTextSplitter({
  chunkSize: 1000,
  chunkOverlap: 200,
});

const allSplits = await textSplitter.splitDocuments(docs);

console.log(allSplits.length);
```


```text
516
```

## 索引文档

把 chunk 索引进 vector store：


```typescript
await vectorStore.addDocuments(allSplits);
```


大多数 vector store 集成也支持连接已有的 store（例如通过 client 或 index 名称）。详情请参阅具体 [integration](/oss/javascript/integrations/vectorstores) 的文档。

## 查询 vector store



把文档添加到 [`VectorStore`](https://reference.langchain.com/javascript/langchain-core/vectorstores/VectorStore) 之后，就可以查询它：

- 同步和异步
- 按字符串查询和按向量查询
- 返回或不返回相似度分数
- 按相似度和 [maximum marginal relevance](https://reference.langchain.com/javascript/langchain-core/vectorstores/VectorStore/maxMarginalRelevanceSearch)（在相似度和多样性之间取得平衡）



这些方法通常返回 [`Document`](https://reference.langchain.com/javascript/langchain-core/documents/Document) 对象列表。

### 按字符串搜索

embeddings 会把文本映射为稠密向量，因此语义相近的内容在几何空间中也彼此接近。这意味着你可以传入一个自然语言问题来检索相关段落：


```typescript
const results1 = await vectorStore.similaritySearch(
  "When was Nike incorporated?"
);

console.log(results1[0]);
```
```javascript
Document {
    pageContent: 'direct to consumer operations sell products...',
    metadata: {'page': 4, 'source': '../example_data/nke-10k-2023.pdf', 'start_index': 3125}
}
```




### 返回分数

你可以随文档一起返回相似度分数。分数的含义因提供方而异。在本例中，分数是一个与相似度成反比的距离度量：


```typescript
const results2 = await vectorStore.similaritySearchWithScore(
  "What was Nike's revenue in 2023?"
);

console.log(results2[0]);
```
```javascript
Score: 0.23699893057346344

Document {
    pageContent: 'Table of Contents...',
    metadata: {'page': 35, 'source': '../example_data/nke-10k-2023.pdf', 'start_index': 0}
}
```


### 按向量搜索

自己 embed 查询，然后用得到的向量执行搜索：


```typescript
const embedding = await embeddings.embedQuery(
  "How were Nike's margins impacted in 2023?"
);

const results3 = await vectorStore.similaritySearchVectorWithScore(
  embedding,
  1
);

console.log(results3[0]);
```
```javascript
Document {
    pageContent: 'FISCAL 2023 COMPARED TO FISCAL 2022...',
    metadata: {
        'page': 36,
        'source': '../example_data/nke-10k-2023.pdf',
        'start_index': 0
    }
}
```

## 使用 retrievers

LangChain [`VectorStore`](https://reference.langchain.com/javascript/langchain-core/vectorstores/VectorStore) 对象并不继承 [`Runnable`](https://reference.langchain.com/javascript/langchain-core/runnables/Runnable)。[Retrievers](https://reference.langchain.com/javascript/langchain-core/retrievers/BaseRetriever) 是 Runnables，因此它们支持标准方法，例如同步和异步的 `invoke` 与 `batch`。

你也可以从 vector store 构建 retriever，而 retriever 也可以包装非向量来源（例如外部 API）。



Vector stores 实现了 `as_retriever` 方法，它返回一个 [`VectorStoreRetriever`](https://reference.langchain.com/python/langchain-core/vectorstores/base/VectorStoreRetriever)。这些 retriever 暴露 `search_type` 和 `search_kwargs`，用于选择和参数化底层 store 方法。用下面的代码复现上面的示例：


```typescript
const retriever = vectorStore.asRetriever({
  searchType: "mmr",
  searchKwargs: {
    fetchK: 1,
  },
});

await retriever.batch([
  "When was Nike incorporated?",
  "What was Nike's revenue in 2023?",
]);
```
```javascript
[
    [Document {
        metadata: {'page': 4, 'source': '../example_data/nke-10k-2023.pdf', 'start_index': 3125},
        pageContent: 'direct to consumer operations sell products...',
    }],
    [Document {
        metadata: {'page': 3, 'source': '../example_data/nke-10k-2023.pdf', 'start_index': 0},
        pageContent: 'Table of Contents...',
    }],
]
```


你可以在更复杂的应用中使用 retrievers，例如[检索增强生成（RAG）](/oss/javascript/deepagents/retrieval)，它会把问题与检索到的上下文一起放入 prompt 交给 LLM。想了解如何构建这样的应用，请查看 [RAG 教程](/oss/javascript/deepagents/rag)。
