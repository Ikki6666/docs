OpenWiki 是一个开源 CLI，用于编写并持续维护关于你的代码库或个人知识的 Markdown wiki。该 wiki 捕捉架构、集成、evals 和工作流等细节，让 [coding agent](/oss/python/deepagents/overview) 可以把它当作持久上下文使用，而不是在每个任务上重新探索仓库。

这让 agent 的工作更快、token 成本更低：agent 先阅读一份精心整理的 wiki，然后只在需要更多细节的地方检查源码。人类可以浏览同一份 Markdown（以及本地 [visualizer](/oss/openwiki/visualize)），但主要的受众是 agent。

OpenWiki 构建在 [Deep Agents](/oss/python/deepagents/overview) 之上，并支持通过 [LangSmith](/langsmith/observability-quickstart) 进行 tracing。

## 开始使用

安装 CLI，然后为当前仓库初始化文档：

```bash
npm install -g openwiki
openwiki --init
```

关于选择模型 provider、生成文档并保持它们最新，请参见 [Quickstart](/oss/openwiki/quickstart)。要在 Codex、Claude Code、OpenCode 或 Cursor 中运行 OpenWiki，而不是使用独立的模型会话，请参见 [Coding-agent integrations](/oss/openwiki/integrations)。

## 模式

OpenWiki 有两种模式：

| 模式 | 命令 | 输出 | 适用场景 |
| --- | --- | --- | --- |
| **Code**（默认） | `openwiki` / `openwiki code` | 当前仓库中的 `openwiki/` | 你想要面向 coding agent 的仓库上下文和文档 |
| **Personal** | `openwiki personal` | `~/.openwiki/wiki` | 你想从已配置的来源构建一个本地个人 brain |

裸 `openwiki --init` 和 `openwiki --update` 以 code 模式运行。个人 wiki 请使用 `openwiki personal --init` 或 `openwiki personal --update`。
