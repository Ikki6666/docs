## Agent frameworks (like LangChain)

智能体框架提供抽象能力，让你在基于 LLM 构建应用时更容易上手。

[LangChain](/oss/langchain/overview) 是一个智能体框架，提供了结构化内容块、智能体循环和中间件等抽象。

LangChain 的这些抽象既易于上手，也能为高级用例保留所需的灵活性。

虽然 LangChain 构建在 [LangGraph](/oss/langgraph/overview) 之上，但使用 LangChain 并不要求你先了解 LangGraph。

其他智能体框架的例子包括 [Vercel's AI SDK](https://ai-sdk.dev/docs/introduction)、[CrewAI](https://www.crewai.com/)、[OpenAI Agents SDK](https://openai.github.io/openai-agents-python/)、[Google ADK](https://google.github.io/adk-docs/)、[LlamaIndex](https://www.llamaindex.ai/) 等等。

### 何时使用 LangChain

在以下情况下使用 LangChain：

- 你想快速构建智能体和自主应用。
- 你需要模型、工具和智能体循环的标准抽象。
- 你想要一个易用但依然灵活的框架。
- 你构建的是不需要复杂编排的直接型智能体应用。

## Agent runtimes (like LangGraph)

智能体运行时提供在生产环境中运行智能体所需的工具。
支持的能力可能包括：

- **持久执行**：智能体可以在故障后恢复，并长时间运行，从上次中断处继续。
- **流式传输**：支持工作流和响应的流式输出。
- **Human-in-the-loop**：通过检查和修改智能体状态引入人工监督。
- **持久化**：为状态管理提供线程级和跨线程持久化。
- **底层控制**：无需高层抽象，直接控制智能体编排。

[LangGraph](/oss/langgraph/overview) 是一个底层编排框架和运行时，用于构建、管理和部署长时运行的有状态智能体。

智能体框架通常位于更高层，并运行在智能体运行时之上。
例如，LangChain 1.0 就构建在 LangGraph 之上。

其他智能体运行时的例子包括 [Temporal](https://temporal.io/)、[Inngest](https://www.inngest.com/) 以及其他持久执行引擎。

### 何时使用 LangGraph

在以下情况下使用 LangGraph：

- 你需要对智能体编排进行细粒度、底层的控制。
- 你需要为长时运行、有状态的智能体提供持久执行能力。
- 你正在构建结合确定性步骤和 agentic 步骤的复杂工作流。
- 你需要面向生产的智能体部署基础设施。

## Agent harnesses (like the Deep Agents SDK)

智能体 harness 是带有鲜明倾向、开箱即用的框架，内置了用于构建复杂、长时运行智能体的工具和能力。
支持的能力可能包括：

- **规划能力**：通过待办列表跟踪多个任务。
- **任务委派**：用子智能体分担工作，并保持上下文整洁。
- **文件系统**：可在不同可插拔存储后端上读写文件。
- **Token 管理**：会话历史摘要，以及大型工具结果的淘汰。

[Deep Agents SDK](/oss/deepagents/overview) 构建在 LangGraph 之上，并增加了规划能力、用于上下文管理的文件系统、生成子智能体的能力等。
Deep Agents 面向需要规划与拆解的复杂多步骤任务。

典型任务包括处理搜索结果、脚本以及状态中的其他产物。

其他智能体 harness 的例子包括 [Claude Agent SDK](https://platform.claude.com/docs/en/agent-sdk/overview)、[Manus](https://manus.im/) 以及其他 coding CLI。

### 何时使用 Deep Agents SDK

在以下情况下使用 [Deep Agents SDK](/oss/deepagents/overview)：

- 你正在构建需要长时间运行的智能体。
- 你正在构建需要处理复杂多步骤任务的智能体。
- 你想使用预定义工具，例如文件系统操作、bash 执行和自动化上下文工程。
- 你想使用预定义提示词和子智能体。

## 功能对比

虽然 LangChain、LangGraph 和 Deep Agents 都能完成相近的任务，但它们接入的层级并不相同：

| ------- | --------- | ----------- | ----------- |
| Short-term memory | [Short-term memory](/oss/langchain/short-term-memory) | [Short-term memory](/oss/langgraph/add-memory#add-short-term-memory) | [`StateBackend`](/oss/deepagents/backends#statebackend) |
| Long-term memory | [Long-term memory](/oss/langchain/long-term-memory) | [Long-term memory](/oss/langgraph/add-memory#add-long-term-memory) | [Long-term memory](/oss/deepagents/memory) |
| Skills  | [Multi-agent skills](/oss/langchain/multi-agent/skills) | - | [Skills](/oss/deepagents/skills) |
| Subagents | [Multi-agent subagents](/oss/langchain/multi-agent/subagents) | [Subgraphs](/oss/langgraph/use-subgraphs) | [Subagents](/oss/deepagents/subagents) |
| Human-in-the-loop | [Human-in-the-loop middleware](/oss/langchain/human-in-the-loop) | [Interrupts](/oss/langgraph/interrupts) | [`interrupt_on` parameter](/oss/deepagents/harness#human-in-the-loop) |
