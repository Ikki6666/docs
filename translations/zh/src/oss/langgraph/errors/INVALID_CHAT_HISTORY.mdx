---
title: INVALID_CHAT_HISTORY
---

:::python
当 prebuilt @[`create_agent`] 中的 `call_model` 图节点接收到一个格式错误的消息列表时，就会抛出这个错误。具体来说，如果列表中存在带有 `tool_calls` 的 `AIMessage`（LLM 请求调用工具），却没有对应的 @[`ToolMessage`]（工具调用结果返回给 LLM），就会被视为格式错误。
:::

:::js
当 prebuilt @[`createAgent`] 中的 `callModel` 图节点接收到一个格式错误的消息列表时，就会抛出这个错误。具体来说，如果列表中存在带有 `tool_calls` 的 `AIMessage`s（LLM 请求调用工具），却没有对应的 @[`ToolMessage`]（工具调用结果返回给 LLM），就会被视为格式错误。
:::

你看到这个错误，可能有几种原因：

:::python
1. 你在调用图时手动传入了一个格式错误的消息列表，例如 `graph.invoke({'messages': [AIMessage(..., tool_calls=[...])]})`
2. 图在接收到 `tools` 节点的更新之前就被中断了（也就是一组 @[`ToolMessage`]），并且你用的输入既不是 `None` 也不是 `ToolMessage`，
    例如 `graph.invoke({'messages': [HumanMessage(...)]}, config)`。
    这个中断可能由以下原因触发：
        * 你在 `create_agent` 中手动设置了 `interrupt_before = ['tools']`
        * 某个工具抛出了一个没有被 @[`ToolNode`]（`"tools"`）处理的错误
:::

:::js
1. 你在调用图时手动传入了一个格式错误的消息列表，例如 `graph.invoke({messages: [new AIMessage({..., tool_calls: [...]})]})`
2. 图在接收到 `tools` 节点的更新之前就被中断了（也就是一组 @[`ToolMessage`]），并且你用的输入既不是 `null` 也不是 `ToolMessage`，
    例如 `graph.invoke({messages: [new HumanMessage(...)]}, config)`。
    这个中断可能由以下原因触发：
    * 你在 `createAgent` 中手动设置了 `interruptBefore: ['tools']`
    * 某个工具抛出了一个没有被 @[`ToolNode`]（`"tools"`）处理的错误
:::

## 排查

要解决这个问题，你可以这样做：

1. 不要向图传入格式错误的消息列表
2. 如果是由于中断（手动中断或错误导致）造成的，你可以：

:::python
* 提供与现有工具调用匹配的 @[`ToolMessage`] 对象，并调用 `graph.invoke({'messages': [ToolMessage(...)]})`。
  **注意**：这会把消息追加到历史记录中，并从 START 节点重新运行图。
  * 手动更新 state 并从中断点恢复图：
    1. 使用 `graph.get_state(config)` 获取最新消息列表
    2. 修改消息列表，要么移除 `AIMessage` 中未回答的工具调用

或添加与未回答工具调用的 `tool_call_ids` 匹配的 `ToolMessage` 对象
3. 使用 `graph.update_state(config, {'messages': ...})` 提交修改后的消息列表
4. 恢复图，例如调用 `graph.invoke(None, config)`
:::

:::js
* 提供与现有工具调用匹配的 `ToolMessage` 对象，并调用 `graph.invoke({messages: [new ToolMessage(...)]})`。
  **注意**：这会把消息追加到历史记录中，并从 START 节点重新运行图。
  * 手动更新 state 并从中断点恢复图：
    1. 使用 `graph.getState(config)` 获取最新消息列表
    2. 修改消息列表，要么移除 `AIMessage` 中未回答的工具调用

或添加与未回答工具调用的 `toolCallId`s 匹配的 `ToolMessage` 对象
3. 使用 `graph.updateState(config, {messages: ...})` 提交修改后的消息列表
4. 恢复图，例如调用 `graph.invoke(null, config)`
:::
