---
title: GRAPH_RECURSION_LIMIT
---

你的 LangGraph [`StateGraph`](https://langchain-ai.github.io/langgraph/reference/graphs/#langgraph.graph.state.StateGraph) 在到达停止条件之前，已经达到了允许的最大步数。
这通常是由无限循环引起的，比如下面的示例：

:::python
```python
class State(TypedDict):
    some_key: str

builder = StateGraph(State)
builder.add_node("a", ...)
builder.add_node("b", ...)
builder.add_edge("a", "b")
builder.add_edge("b", "a")
...

graph = builder.compile()
```
:::

:::js
```typescript
import { StateGraph, StateSchema } from "@langchain/langgraph";
import { z } from "zod/v4";

const State = new StateSchema({
  someKey: z.string(),
});

const builder = new StateGraph(State)
  .addNode("a", ...)
  .addNode("b", ...)
  .addEdge("a", "b")
  .addEdge("b", "a")
  ...

const graph = builder.compile();
```
:::

不过，复杂图也可能自然触发默认上限。

## 排查

* 如果你本来不希望图经历很多轮迭代，那大概率存在一个循环。检查你的逻辑里是否有无限循环。

:::python
* 如果你的图确实很复杂，可以在调用图时向 `config` 对象传入更高的 `recursion_limit` 值，例如：

```python
graph.invoke({...}, {"recursion_limit": 1000})
```
:::

:::js
* 如果你的图确实很复杂，可以在调用图时向 `config` 对象传入更高的 `recursionLimit` 值，例如：

```typescript
await graph.invoke({...}, { recursionLimit: 1000 });
```
:::
