## 并行运行 task

:::python
task 在被调用时立即启动，并返回一个 future。先收集这些 future，然后用 `.result()` 等待，这样工作会重叠执行。
:::

:::js
task 在被调用时立即启动，并返回一个 `Promise`。先收集这些 promise，然后用 `Promise.all` 等待，这样工作会重叠执行。
:::

这种模式适合 I/O 密集型工作，例如 LLM API 调用。

## 调用图

Functional API 和 [Graph API](/oss/langgraph/graph-api) 共享同一个运行时。编译后的图就是另一个可调用对象：像调用其他函数一样从 entrypoint 中调用它。

除非把 `config` 传入 `invoke`，否则嵌套图不会共享外层线程。在 entrypoint 上请求注入的 `config`，并把它转发下去。

## 调用其他 entrypoint

你可以从 entrypoint 或 task 内调用其他 entrypoint。
