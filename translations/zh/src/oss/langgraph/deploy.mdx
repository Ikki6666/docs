当你准备把 LangGraph 智能体部署到生产环境时，请选择一个适合你的技术栈的托管方式。**[LangSmith Cloud](/langsmith/deploy-to-cloud)** 为有状态、长时间运行的智能体提供完全托管的基础设施，支持持久状态和后台执行。

:::js
你也可以使用相同的 [Agent Streaming Protocol](https://github.com/langchain-ai/agent-protocol/tree/main/streaming)，将智能体部署到 **JavaScript 框架和平台**，例如 Next.js、SvelteKit、Nuxt、Cloudflare Workers 和 Deno Deploy。

<DeployFrameworksPlatformsReference />
:::

<Tip>
LangSmith 除了 Cloud 之外，还提供多种部署选项，包括 [hybrid](/langsmith/hybrid)、[standalone servers](/langsmith/deploy-standalone-server) 和 [self-hosted with control plane](/langsmith/deploy-with-control-plane)。更多信息请参阅 [LangSmith Deployment 概览](/langsmith/deployment)。
</Tip>

## LangSmith Cloud

本节介绍如何从 GitHub 仓库将智能体部署到 LangSmith Cloud。LangSmith 会处理基础设施、扩展和运维相关事项。

### 前提条件

开始之前，请确保你具备以下条件：

- 一个 [GitHub 账号](https://github.com/)
- 一个 [LangSmith 账号](https://smith.langchain.com)（可免费注册）

### 部署你的智能体

#### 1. 在 GitHub 上创建仓库

你的应用代码必须位于 GitHub 仓库中，才能部署到 LangSmith。公开仓库和私有仓库都受支持。对于这个快速入门，请先按照 [本地服务器设置指南](/oss/langgraph/studio#set-up-local-agent-server) 确保你的应用与 LangGraph 兼容，然后把代码推送到仓库中。

#### 2. 部署到 LangSmith

<Steps>
<Step title="进入 LangSmith Deployment">
    登录 [LangSmith](https://smith.langchain.com)。在左侧边栏中选择 **Deployments**。
</Step>
<Step title="创建新部署">
    点击 **+ New Deployment** 按钮。随后会打开一个面板，你可以在其中填写所需字段。
</Step>
<Step title="关联仓库">
    如果你是首次使用，或者正在添加一个此前尚未连接的私有仓库，请点击 **Add new account** 按钮，并按照提示连接你的 GitHub 账号。
</Step>
<Step title="部署仓库">
    选择你的应用仓库。点击 **Submit** 开始部署。这个过程大约需要 15 分钟。你可以在 **Deployment details** 视图中查看状态。
</Step>
</Steps>

#### 3. 在 Studio 中测试应用

应用部署完成后：

1. 选择刚刚创建的部署，查看详细信息。
2. 点击右上角的 **Studio** 按钮。Studio 会打开并显示你的图。

#### 4. 获取部署的 API URL

1. 在 LangGraph 的 **Deployment details** 视图中，点击 **API URL** 将其复制到剪贴板。
2. 点击 `URL` 将其复制到剪贴板。

#### 5. 测试 API

现在你可以测试这个 API：

<Tabs>
:::python
<Tab title="Python">
1. 安装 LangGraph SDK：
```shell
pip install langgraph-sdk
```
2. 向智能体发送消息：
```python
from langgraph_sdk import get_sync_client # or get_client for async

client = get_sync_client(url="your-deployment-url", api_key="your-langsmith-api-key")

for chunk in client.runs.stream(
    None,    # Threadless run
    "agent", # Name of agent. Defined in langgraph.json.
    input={
        "messages": [{
            "role": "human",
            "content": "What is LangGraph?",
        }],
    },
    stream_mode="updates",
):
    print(f"Receiving new event of type: {chunk.event}...")
    print(chunk.data)
    print("\n\n")
```
</Tab>
:::
:::js
<Tab title="TypeScript">
1. 安装 LangGraph SDK：
```shell
npm install @langchain/langgraph-sdk
```
2. 向智能体发送消息：
```ts
import { Client } from "@langchain/langgraph-sdk";

const client = new Client({ apiUrl: "your-deployment-url", apiKey: "your-langsmith-api-key" });

const streamResponse = client.runs.stream(
  null,    // Threadless run
  "agent", // Name of agent. Defined in langgraph.json.
  {
    input: {
      "messages": [
        { "role": "user", "content": "What is LangGraph?"}
      ]
    },
    streamMode: "messages",
  }
);

for await (const chunk of streamResponse) {
  console.log(`Receiving new event of type: ${chunk.event}...`);
  console.log(JSON.stringify(chunk.data));
  console.log("\n\n");
}
```
</Tab>
