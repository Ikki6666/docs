受到塑造智能体未来的公司信赖——包括 Klarna、Uber、摩根大通等——LangGraph 是一个低层级编排框架和运行时，用于构建、管理和部署长时间运行的有状态智能体。

LangGraph 非常底层，完全专注于智能体**编排**。在使用 LangGraph 之前，建议你先熟悉构建智能体的一些组件，从[模型](/oss/langchain/models)和[工具](/oss/langchain/tools)开始。

我们会在文档中频繁使用 [LangChain](/oss/langchain/overview) 组件来集成模型和工具，但你不必使用 LangChain 即可使用 LangGraph。如果你刚开始接触智能体或想要更高层级的抽象，建议你使用 LangChain 的[智能体](/oss/langchain/agents)，它为常见的 LLM 和工具调用循环提供了预构建的架构。

LangGraph 专注于智能体编排所需的核心底层能力：持久化执行、流式传输、人机交互等。

<Expandable title="LangChain 产品如何协同工作" defaultOpen={false}>

**LangChain、LangGraph 与 Deep Agents 的对比**

当你希望运行生产智能体又不想管理基础设施时，请从 [Managed Deep Agents](/langsmith/managed-deep-agents-overview) 开始，它提供开箱即用的套件（上下文压缩、虚拟文件系统、子智能体）。或者，如果你希望在使用同一套 Deep Agents 套件的同时获得最大灵活性，可以使用 [Deep Agents SDK](/oss/deepagents/overview#self-host-with-the-sdk) 自行托管智能体，或运行自定义的 [LangSmith Deployment](/langsmith/deployment)。Deep Agents 构建在 LangChain [智能体](/oss/langchain/agents/)之上，而 LangChain 智能体运行在 LangGraph 上。

如果你需要一个高度可定制的智能体框架，可使用 [LangChain](/oss/langchain/agents)（`create_agent`），它提供模型、工具和智能体循环的抽象与集成。

如果你有结合确定性与智能体工作流的高级需求，可使用 [LangGraph](/oss/langgraph/overview) 这一底层编排框架。
LangGraph 是编排运行时：提供持久化执行、流式传输、人机交互和状态持久化。

使用 [LangSmith](/langsmith/observability) 追踪、调试和评估用上述任一框架构建的智能体。按照[追踪快速入门](/langsmith/trace-with-langchain)进行设置。我们建议你还设置 [LangSmith Engine](/langsmith/engine)，它可以监控你的追踪记录、检测问题并提出修复方案。你可以直接从 Engine 标签页发起包含修复方案的拉取请求。

如果你需要模板、集成和例行自动化等无代码智能体构建能力，可使用 [LangSmith Fleet](/langsmith/fleet/index)。

阅读[框架、运行时和套件](/oss/concepts/products)，了解开源技术栈的对比。
</Expandable>

:::js


```bash pnpm
pnpm add @langchain/langgraph @langchain/core
```

```bash yarn
yarn add @langchain/langgraph @langchain/core
```

```bash bun
bun add @langchain/langgraph @langchain/core
```
</CodeGroup>
:::

然后，创建一个简单的 hello world 示例：

:::python
```python
from langgraph.graph import StateGraph, MessagesState, START, END

def mock_llm(state: MessagesState):
    return {"messages": [{"role": "ai", "content": "hello world"}]}

graph = StateGraph(MessagesState)
graph.add_node(mock_llm)
graph.add_edge(START, "mock_llm")
graph.add_edge("mock_llm", END)
graph = graph.compile()

graph.invoke({"messages": [{"role": "user", "content": "hi!"}]})
```
:::

:::js
```typescript
import { StateSchema, MessagesValue, type GraphNode, StateGraph, START, END } from "@langchain/langgraph";

const State = new StateSchema({
  messages: MessagesValue,
});

const mockLlm: GraphNode<typeof State> = (state) => {
  return { messages: [{ role: "ai", content: "hello world" }] };
};

const graph = new StateGraph(State)
  .addNode("mock_llm", mockLlm)
  .addEdge(START, "mock_llm")
  .addEdge("mock_llm", END)
  .compile();

await graph.invoke({ messages: [{ role: "user", content: "hi!" }] });
```
:::

<Tip>
使用 [LangSmith](/langsmith/observability) 来追踪请求、调试智能体行为并评估输出。设置 `LANGSMITH_TRACING=true` 和你的 API 密钥即可开始使用。按照[追踪快速入门](/langsmith/trace-with-langchain)进行设置。我们建议你还设置 [LangSmith Engine](/langsmith/engine)，它可以监控你的追踪记录、检测问题并提出修复方案。
</Tip>

## 核心优势

LangGraph 为*任何*长时间运行的有状态工作流或智能体提供底层支撑基础设施。LangGraph 不会抽象化提示词或架构，而是提供以下核心优势：

* [持久化](/oss/langgraph/persistence)：构建能够从容应对故障并长时间运行的智能体，支持从中断处恢复执行。
* [人机交互](/oss/langgraph/interrupts)：通过在任意节点检查和修改智能体状态，融入人工监督。
* [全面的记忆能力](/oss/concepts/memory)：创建具有短期工作记忆（用于持续推理）和跨会话长期记忆的有状态智能体。
* [使用 LangSmith 调试](/langsmith/observability)：通过可视化工具深入洞察复杂的智能体行为，追踪执行路径、捕获状态转换并提供详细的运行时指标。
* [生产就绪的部署](/langsmith/deployment)：借助专为处理有状态、长时间运行工作流的独特挑战而设计的可扩展基础设施，自信地部署复杂的智能体系统。
