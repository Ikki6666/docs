Trace 是 agent 从输入到输出的一系列步骤。每个步骤都会表示为一个 run。你可以使用 [LangSmith](https://smith.langchain.com) 来可视化这些执行步骤。要使用它，请[为 agent 启用 tracing](/langsmith/trace-with-langgraph)。这样你就可以完成以下操作：

* [调试本地运行的 agent](/langsmith/observability-studio#debug-langsmith-traces)。
* [评估 agent 性能](/oss/langchain/test/evals)。
* [监控 agent](/langsmith/dashboards)。

## 前提条件

开始之前，请确保你具备以下条件：

- **LangSmith 账号**：免费注册或登录 [smith.langchain.com](https://smith.langchain.com)。
- **LangSmith API key**：按照 [创建 API key](/langsmith/create-account-api-key) 指南操作。

## 启用 tracing

<AgentTracingPrerequisite />

要为 agent 启用 tracing，请设置以下环境变量：

```bash
export LANGSMITH_AGENT_ID="<your-agent-id>"
export LANGSMITH_AGENT_ENVIRONMENT="production"
export LANGSMITH_TRACING=true
export LANGSMITH_API_KEY=<your-api-key>
```

traces 会出现在设置期间配置的目标中。

更多信息请参阅 [Trace with LangGraph](/langsmith/trace-with-langgraph)。

## 有选择地 tracing

你可以使用 LangSmith 的 `tracing_context` 上下文管理器，只追踪特定调用或 agent 的一部分：

:::python
```python
import langsmith as ls

# 这段会被 traced
with ls.tracing_context(enabled=True):
    agent.invoke({"messages": [{"role": "user", "content": "Send a test email to alice@example.com"}]})

# 这段不会被 traced（如果没有设置 LANGSMITH_TRACING）
agent.invoke({"messages": [{"role": "user", "content": "Send another email"}]})
```
:::

:::js
```ts
import { LangChainTracer } from "@langchain/core/tracers/tracer_langchain";

// 这段会被 traced
const tracer = new LangChainTracer();
await agent.invoke(
  {
    messages: [{role: "user", content: "Send a test email to alice@example.com"}]
  },
  { callbacks: [tracer] }
);

// 这段不会被 traced（如果没有设置 LANGSMITH_TRACING）
await agent.invoke(
  {
    messages: [{role: "user", content: "Send another email"}]
  }
);
```
:::

## 选择 agent 和环境

使用 `LANGSMITH_AGENT_ID` 和 `LANGSMITH_AGENT_ENVIRONMENT` 选择已注册的 agent 和环境。如需按请求路由，请在代码中传入 agent address。请参阅[将 traces 记录到 agent](/langsmith/log-traces-to-agent)。

<Accordion title="基于 project 的工作区和自托管 LangSmith">
请改为把 `LANGSMITH_PROJECT` 设置为 tracing 项目名称，而不是设置 agent 变量。对于在 agent-based 工作区中需要 `project_name` 的集成，请使用该环境的 [`tracer_session_name`](/langsmith/create-an-agent#use-an-environment-project) 作为兼容性值。
</Accordion>

## 为 trace 添加元数据

你可以用自定义 metadata 和 tags 标注 trace：

:::python
```python
response = agent.invoke(
    {"messages": [{"role": "user", "content": "Send a welcome email"}]},
    config={
        "tags": ["production", "email-assistant", "v1.0"],
        "metadata": {
            "user_id": "user_123",
            "session_id": "session_456",
            "environment": "production"
        }
    }
)
```

`tracing_context` 也支持 tags 和 metadata，用于更细粒度控制：

```python
with ls.tracing_context(
    enabled=True,
    tags=["production", "email-assistant", "v1.0"],
    metadata={"user_id": "user_123", "session_id": "session_456", "environment": "production"}):
    response = agent.invoke(
        {"messages": [{"role": "user", "content": "Send a welcome email"}]}
    )
```
:::

:::js
```ts
import { LangChainTracer } from "@langchain/core/tracers/tracer_langchain";

const tracer = new LangChainTracer();
await agent.invoke(
  {
    messages: [{role: "user", content: "Send a test email to alice@example.com"}]
  },
  config: {
    tags: ["production", "email-assistant", "v1.0"],
    metadata: {
      userId: "user123",
      sessionId: "session456",
      environment: "production"
    }
  },
);

```
:::

这些自定义 metadata 和 tags 会附加到 LangSmith 中的 trace 上。

## 使用 anonymizer 防止敏感数据写入 trace

你可能希望在将敏感数据记录到 LangSmith 之前先将其掩码。你可以创建 [anonymizer](/langsmith/mask-inputs-outputs#rule-based-masking-of-inputs-and-outputs) 并将其应用到图中，方法是通过配置完成。下面这个示例会在发送到 LangSmith 的 traces 中，把所有匹配美国社会安全号码格式 `XXX-XX-XXXX` 的内容替换掉。

:::python
```python Python
from langchain_core.tracers.langchain import LangChainTracer
from langgraph.graph import StateGraph, MessagesState
from langsmith import Client
from langsmith.anonymizer import create_anonymizer

anonymizer = create_anonymizer([
    # 匹配 SSN
    { "pattern": r"\b\d{3}-?\d{2}-?\d{4}\b", "replace": "<ssn>" }
])

tracer_client = Client(anonymizer=anonymizer)
tracer = LangChainTracer(client=tracer_client)
# 定义图
graph = (
    StateGraph(MessagesState)
    ...
    .compile()
    .with_config({'callbacks': [tracer]})
)
```
:::
:::js
```typescript TypeScript
import { StateGraph } from "@langchain/langgraph";
import { LangChainTracer } from "@langchain/core/tracers/tracer_langchain";
import { StateAnnotation } from "./state.js";
import { createAnonymizer } from "langsmith/anonymizer"
import { Client } from "langsmith"

const anonymizer = createAnonymizer([
  // 匹配 SSN
  { pattern: /\b\d{3}-?\d{2}-?\d{4}\b/, replace: "<ssn>" }
])

const langsmithClient = new Client({ anonymizer })
const tracer = new LangChainTracer({
  client: langsmithClient,
});

export const graph = new StateGraph(StateAnnotation)
  .compile()
  .withConfig({ callbacks: [tracer] });
```
:::
