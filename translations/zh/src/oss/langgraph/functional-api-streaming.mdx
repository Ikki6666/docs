从 Functional API [entrypoint](/oss/langgraph/functional-api#entrypoint) 流式传输有两种方式。自定义数据是一条侧通道：你用 writer 推送进度，然后读取 `custom` chunk。Values 是运行时记录的状态快照，包括 entrypoint 的返回值。读取 values 时不需要调用 writer。

概念说明请参阅 [Functional API 概览](/oss/langgraph/functional-api)。消息和其他类型化投影请参阅 [事件流式传输](/oss/langgraph/event-streaming)。

## 发出自定义数据

Functional API 使用与 [Graph API](/oss/langgraph/graph-api) 相同的流。用 writer 发出数据，然后消费 `custom` chunk。流模式请参阅 [流式传输](/oss/langgraph/streaming)。

:::python
<LanggraphFunctionalApiStreamCustomDataPy />

1. 从 `langgraph.config` 导入 @[`get_stream_writer`]。
2. 在 entrypoint 内调用它来获得 writer。
3. 在计算前后发出自定义数据。
4. 调用 `stream(..., stream_mode="custom")` 并迭代 chunk。

<Warning>
**Python < 3.11 下的 async**
在 Python < 3.11 的异步代码中，@[`get_stream_writer`] 无法工作。请改用可注入的 `StreamWriter` 参数。请参阅 [Python < 3.11 下的 async](/oss/langgraph/streaming#async)。

<LanggraphFunctionalApiStreamWriterInjectPy />
</Warning>
:::

:::js
<LanggraphFunctionalApiStreamCustomDataJs />

1. 把 `config` 作为 entrypoint 的第二个参数。
2. 在计算前后用 `config.writer` 发出自定义数据。
3. 调用 `stream(..., { streamMode: "custom" })` 并迭代 chunk。
:::
