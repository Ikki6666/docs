使用 @[`interrupt`] 暂停 Functional API [entrypoint](/oss/langgraph/functional-api#entrypoint)，再用 [`Command`](/oss/langgraph/interrupts#resuming-interrupts) 恢复运行。

概念说明请参阅 [Functional API 概览](/oss/langgraph/functional-api)。interrupt 载荷和恢复格式请参阅 [Interrupts](/oss/langgraph/interrupts)。持久化需要 [checkpointer](/oss/langgraph/persistence) 和 `thread_id`。

## 暂停以收集反馈

创建三个 [task](/oss/langgraph/functional-api#task)：

1. 追加 `"bar"`。
2. 暂停等待人工输入。恢复时追加该输入。
3. 追加 `"qux"`。

在 entrypoint 中组合它们。`interrupt` 在 `step_1` 完成后于 `human_feedback` 内运行。这些结果会被持久化，因此恢复后 `step_1` 不会再次运行。

用 `thread_id` 标识本次运行。驱动流直到暂停，打印 interrupt 载荷，然后恢复。

## 审核 tool call

要在执行前审核 tool call，可从一个辅助函数中调用 `interrupt`。执行会暂停，直到你用 `Command` 恢复。

给定一个 tool call，选择以下之一：

* 接受该 tool call
* 修改该 tool call 并继续
* 生成一条自定义 tool message（例如，指示模型重新格式化它的 tool call）
