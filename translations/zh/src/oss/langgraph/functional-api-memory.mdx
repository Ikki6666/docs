为 Functional API [entrypoint](/oss/langgraph/functional-api#entrypoint) 添加记忆时，使用 [checkpointer](/oss/langgraph/persistence)，并可选地使用 [store](/oss/langgraph/stores)。Checkpoint 在同一 `thread_id` 的多次调用之间持久化状态。Store 在不同 thread ID 之间持久化事实。

概念说明请参阅 [Functional API 概览](/oss/langgraph/functional-api)。Graph API 的记忆示例请参阅 [记忆](/oss/langgraph/add-memory)。
