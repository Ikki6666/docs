title: 测试
sidebarTitle: 概览
description: LangChain 智能体的测试策略，包括单元测试、集成测试和轨迹评估。
---

智能体应用让 LLM 自己决定下一步要做什么来解决问题。这种灵活性很强，但模型的黑盒特性也让人很难预测，改动智能体某一部分会怎样影响整体。要构建可上线的智能体，全面测试是必不可少的。

测试智能体通常有几种方式：

- **单元测试**：使用内存中的假对象隔离测试智能体中小而确定的部分，这样你就能快速、稳定地断言精确行为。
- **集成测试**：使用真实网络调用测试智能体，确认各组件能协同工作、凭据和 schema 都正确，并且延迟可接受。
- **评估**：用 evaluator 评估智能体的执行轨迹，可以是确定性匹配，也可以是 LLM judge。

智能体应用通常更依赖集成测试，因为它们会串联多个组件，并且必须处理 LLM 非确定性带来的不稳定性。

<Tip>
使用 [LangSmith](https://smith.langchain.com) 大规模运行评估、跟踪结果变化，并比较实验。请参见 [Evaluate an LLM application](/langsmith/evaluate-llm-application) 开始使用。
</Tip>
