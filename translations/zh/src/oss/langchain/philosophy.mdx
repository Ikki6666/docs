LangChain 基于以下几个核心理念：

- 大语言模型（LLM）是一项强大的新技术。
- 将 LLM 与外部数据源结合使用时，效果更佳。
- LLM 将改变未来应用的形态。具体而言，未来的应用将越来越具有智能体特性。
- 这场变革目前仍处于早期阶段。
- 虽然构建智能体应用的原型很容易，但要构建足够可靠以投入生产的智能体仍然非常困难。

如今，开发者可以选择如何构建智能体：使用 [LangChain](/oss/langchain/overview) 获得最大的灵活性和控制力，或者使用 [Deep Agents](/oss/langchain/overview) 获得类似的灵活性和控制力，同时内置规划、文件系统工具、子智能体和上下文管理功能。两者都基于 [LangGraph](/oss/langgraph/overview) 构建。

LangChain 有两个核心方向：

<Steps>
    <Step title="让开发者能够使用最佳模型进行构建。">
        不同的提供商暴露不同的 API，具有不同的模型参数和消息格式。
        标准化这些模型输入和输出是一个核心方向，使开发者能够轻松切换到最新的先进模型，避免供应商锁定。
    </Step>
    <Step title="让模型能够轻松编排与其他数据和计算的复杂流程。">
        模型不仅应用于*文本生成*，还应用于编排与其他数据交互的复杂流程。LangChain 使定义 [工具](/oss/langchain/tools) 变得简单，LLM 可以动态使用这些工具，同时帮助解析和访问非结构化数据。
    </Step>
</Steps>

## 发展历程

鉴于该领域的快速变化，LangChain 也在不断演进。以下是 LangChain 多年来的简要时间线，展示了它如何随着 LLM 应用构建方式的演进而发展：

<Update label="2022-10-24" description="v0.0.1">
    在 ChatGPT 发布前一个月，**LangChain 作为 Python 包正式发布**。它由两个主要组件组成：

    - LLM 抽象
    - "链"（Chains），即为常见用例预设的计算步骤。例如 RAG：先执行检索步骤，再执行生成步骤。

    LangChain 这个名字来源于"Language"（如语言模型）和"Chains"（链）。
</Update>

<Update label="2022-12">
    LangChain 添加了首批通用智能体。

    这些通用智能体基于 [ReAct 论文](https://arxiv.org/abs/2210.03629)（ReAct 代表推理与行动）。它们使用 LLM 生成表示工具调用的 JSON，然后解析该 JSON 来确定调用哪些工具。
</Update>

<Update label="2023-01">
    OpenAI 发布了"Chat Completion"API。

    在此之前，模型接收字符串并返回字符串。在 ChatCompletions API 中，模型演变为接收消息列表并返回一条消息。其他模型提供商纷纷效仿，LangChain 也更新为支持消息列表。
</Update>

<Update label="2023-01">
    LangChain 发布了 JavaScript 版本。

    LLM 和智能体将改变应用的构建方式，而 JavaScript 是应用开发者的语言。
</Update>

<Update label="2023-02">
    **LangChain Inc. 围绕开源 LangChain 项目正式成立公司。**

    主要目标是"让智能智能体无处不在"。团队认识到，虽然 LangChain 是关键组成部分（LangChain 让 LLM 的入门变得简单），但还需要其他组件。
</Update>

<Update label="2023-03">
    OpenAI 在其 API 中发布了"函数调用"功能。

    这使 API 能够显式生成表示工具调用的载荷。其他模型提供商纷纷效仿，LangChain 也更新为使用这种方式作为首选的工具调用方法（而非解析 JSON）。
</Update>

<Update label="2023-06">
    **LangSmith 作为闭源平台由 LangChain Inc. 发布**，提供可观测性和评估功能。

    构建智能体的主要问题是使其足够可靠，而 LangSmith 通过提供可观测性和评估功能来解决这一需求。LangChain 更新为与 LangSmith 无缝集成。
</Update>

<Update label="2024-01" description="v0.1.0">
    **LangChain 发布 0.1.0**，这是首个非 0.0.x 版本。

    行业从原型阶段走向生产阶段，因此 LangChain 加强了对稳定性的关注。
</Update>

<Update label="2024-02">
    **LangGraph 作为开源库发布。**

    最初的 LangChain 有两个方向：LLM 抽象，以及用于快速上手常见应用的高级接口；但它缺少一个底层编排层，无法让开发者精确控制智能体的流程。LangGraph 应运而生。

    在构建 LangGraph 时，我们从构建 LangChain 的经验中汲取教训，添加了发现所需的功能：流式传输、持久化执行、短期记忆、人机交互等。
</Update>

<Update label="2024-10">
    LangGraph 成为构建任何超出单次 LLM 调用的 AI 应用的首选方式。

    随着开发者努力提高应用的可靠性，他们需要比高级接口更多的控制权。LangGraph 提供了这种底层灵活性。大多数链和智能体在 LangChain 中被标记为弃用，并提供了迁移到 LangGraph 的指南。LangGraph 中仍然保留了一个高级抽象：智能体抽象。它建立在底层 LangGraph 之上，与 LangChain 中的 ReAct 智能体具有相同的接口。
</Update>

<Update label="2026-03-15" description="v0.5.3">
    **Deep Agents 作为基于 LangGraph 构建的开源智能体框架发布。**

    LangChain 为自定义智能体架构提供灵活的构建块，而 [Deep Agents](/oss/langchain/overview) 为研究和编程等复杂、长时间运行的任务提供了开箱即用的选项。它添加了内置规划工具、具有可插拔后端（内存、磁盘、LangGraph store、沙箱）的虚拟文件系统，以及用于上下文隔离的子智能体生成。使用 Deep Agents 获得具有预定义工具的更自主的智能体；使用 LangChain 获得对智能体架构的完全控制。
</Update>
