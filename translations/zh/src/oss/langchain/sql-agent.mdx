## 概览

在本教程中，你会学习如何构建一个能用 LangChain [agents](/oss/langchain/agents) 回答 SQL 数据库问题的智能体。

从高层来看，这个智能体会：

1. 从数据库中获取可用表和 schema
1. 判断哪些表与问题相关
1. 获取相关表的 schema
1. 根据问题和 schema 信息生成查询
1. 用 LLM 对查询做常见错误检查
1. 执行查询并返回结果
1. 在数据库引擎报错后修正错误，直到查询成功
1. 基于结果组织回答

<Warning>
构建 SQL 数据库问答系统需要执行模型生成的 SQL 查询，这本身有风险。务必让数据库连接权限尽可能最小化，只给智能体完成任务所需的权限。这能缓解风险，但不能完全消除基于模型的系统风险。
</Warning>

### 概念

本教程会涉及以下概念：

- [Tools](/oss/langchain/tools) 用于读取 SQL 数据库
- LangChain [agents](/oss/langchain/agents)
- [Human-in-the-loop](/oss/langchain/human-in-the-loop) 流程

<Step title="创建智能体">

:::python
使用 @[`create_agent`] 来用最少代码构建一个 [ReAct agent](https://arxiv.org/pdf/2210.03629)。智能体会理解请求并生成 SQL 命令，然后由工具去执行。如果命令有误，错误信息会返回给模型。模型随后可以检查原始请求和新的错误信息，再生成一个新命令。这个过程会持续，直到 LLM 成功生成命令或者达到结束次数为止。让模型根据错误信息得到反馈，这种模式非常强大。
