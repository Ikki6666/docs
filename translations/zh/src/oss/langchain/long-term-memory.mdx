长期记忆允许你的智能体在不同的对话和会话之间存储并回忆信息。
与只作用于单个线程的 [短期记忆](/oss/langchain/short-term-memory) 不同，长期记忆会跨线程持久保存，并且可以在任何时候被调用。

长期记忆建立在 [LangGraph stores](/oss/langgraph/stores) 之上，它会将数据保存为按 namespace 和 key 组织的 JSON 文档。

## 记忆存储

LangGraph 会将长期记忆作为 JSON 文档存储在 [store](/oss/langgraph/stores) 中。

每条记忆都组织在一个自定义 `namespace` 下（类似文件夹），并使用一个独立的 `key`（类似文件名）。namespace 往往包含用户 ID、组织 ID，或者其他便于组织信息的标签。

这种结构支持记忆的层级化组织。随后可以通过内容过滤器支持跨 namespace 搜索。
