title: 获取帮助
---

连接 LangChain 社区，访问学习资源，并获得你构建时所需的支持。

## 学习资源

通过我们完整的学习材料，开启你的学习之旅，或者深入掌握更多知识。

- **[Chat LangChain](https://chat.langchain.com/)**：向基于实时文档的 LangChain 文档助手提问
- **[API Reference](https://reference.langchain.com/python/)**：LangChain 全部软件包的完整文档

## 社区支持

通过活跃的社区渠道，从其他开发者和 LangChain 团队那里获得帮助。

- **[Community Forum](https://forum.langchain.com/)**：提问、分享解决方案，并讨论最佳实践
- **[Community Slack](https://www.langchain.com/join-community)**：与其他构建者交流，并快速获得帮助

## 专业支持

对于企业需求和关键应用，可以使用专门的支持渠道。

- **[Support portal](https://support.langchain.com/)**：提交工单并跟踪支持请求
- **[LangSmith status](https://status.smith.langchain.com/)**：LangSmith 服务和 API 的实时状态

## 参与贡献

通过修复 bug、添加功能或改进文档，帮助我们为所有人完善 LangChain。

- **[Contributing Guide](/oss/contributing/overview)**：了解参与 LangChain 贡献所需的一切
