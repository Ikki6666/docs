准备将 LangChain 智能体部署到生产环境时，请选择最适合你技术栈的托管方式。**[LangSmith Cloud](/langsmith/deploy-to-cloud)** 为有状态、长时间运行的智能体提供完全托管的基础设施，支持持久状态和后台执行。

:::js
你也可以使用相同的 [Agent Streaming Protocol](https://github.com/langchain-ai/agent-protocol/tree/main/streaming)，通过 **JavaScript 框架和平台** 来部署，例如 Next.js、SvelteKit、Nuxt、Cloudflare Workers 和 Deno Deploy。

:::

<Tip>
LangSmith 除了 Cloud 之外，还提供多种部署选项，包括 [hybrid](/langsmith/hybrid)、[standalone servers](/langsmith/deploy-standalone-server) 和 [self-hosted with control plane](/langsmith/deploy-with-control-plane)。更多信息请参见 [LangSmith 部署概览](/langsmith/deployment)。
</Tip>

## LangSmith Cloud

本节介绍如何从 GitHub 仓库将智能体部署到 LangSmith Cloud。LangSmith 会处理基础设施、扩缩容和运维相关事项。

### 前置条件

开始之前，请确保你具备以下内容：

- 一个 [GitHub 账户](https://github.com/)
- 一个 [LangSmith 账户](https://smith.langchain.com)（可免费注册）

### 部署你的智能体

#### 1. 在 GitHub 上创建仓库

你的应用代码必须位于 GitHub 仓库中，才能部署到 LangSmith。公共仓库和私有仓库都受支持。对于这个快速开始示例，请先按照 [本地服务器设置指南](/oss/langchain/studio) 确保你的应用兼容 LangGraph。然后，将代码推送到仓库中。
