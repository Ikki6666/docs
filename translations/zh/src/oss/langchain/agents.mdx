<Note>
**智能体 = 模型 + 框架**

框架的职责：在给定任务中，在正确的时间为模型提供正确的上下文。
</Note>

框架是循环周围的一切：模型、提示词、工具，以及任何塑造其行为的中间件。

### Agent 状态

:::python
每个 agent 都通过 @[`AgentState`] 管理其执行上下文，这是一个类型化字典，保存当前对话历史以及你的工具和中间件所需的任何自定义字段。

内置字段是：

| 字段 | 类型 | 说明 |
|-------|------|-------------|
| `messages` | `list[BaseMessage]` | 当前 thread 的完整对话历史。只追加：新消息只会被添加，不会被替换。 |

`AgentState` 也是每个节点式中间件钩子（`before_model`、`after_model` 等）的类型签名。钩子接收当前状态，并可以返回一个更新字典合并回状态中。

要添加自定义字段（例如 `user_id` 或一个计数器），请继承 `AgentState` 并通过 `state_schema=` 将子类传给 `create_agent`：

<AgentsAgentStatePy />

完整细节、示例和中间件级别的状态 schema，请参见[短期记忆](/oss/langchain/short-term-memory#customizing-agent-memory)和[自定义中间件](/oss/langchain/middleware/custom#state-updates)。
:::

内置字段是：

|-------|------|-------------|
| `messages` | `BaseMessage[]` | 当前 thread 的完整对话历史。只追加：新消息只会被添加，不会被替换。 |

`AgentState` 也是传给每个节点式中间件钩子（`beforeModel`、`afterModel` 等）的类型。钩子接收当前状态，并可以返回一个更新对象合并回状态中。

## 配置框架

`create_agent` 具有很强的扩展性。中间件是自定义的基础单元：每个中间件负责一个关注点，在正确时机接入智能体循环，并且可以与任何其他中间件自由组合。只选择你的用例需要的部分，跳过其余部分。

常见模式已作为一等中间件预构建。其他任何能力都可以作为[自定义中间件](/oss/langchain/middleware/custom)构建。
