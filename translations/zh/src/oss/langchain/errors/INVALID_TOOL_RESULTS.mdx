---
title: INVALID_TOOL_RESULTS
---

<Note>
    目前仅在 `langchainjs`（JavaScript/TypeScript）中使用。
</Note>

当你在工具调用操作中，把不匹配、不足或过量的 @[`ToolMessage`] 对象传给模型时，就会出现此错误。

这个错误源于一项基本要求：带有 `tool_calls` 的 assistant 消息后面，必须跟随针对每个 `tool_call_id` 的 tool 消息。

当模型返回带有工具调用的 @[`AIMessage`] 时，你必须为每个工具调用提供**恰好一个**对应的 @[`ToolMessage`]，并且它们的 `tool_call_id` 必须匹配。

## 常见原因

* **响应不足**：如果模型请求了两个工具执行，但你只提供了一个响应消息，模型就会拒绝这条不完整的消息链
* **重复响应**：为同一个工具调用 ID 提供多个 @[`ToolMessage`] 会被拒绝，未匹配的 ID 也同样会被拒绝
* **孤立的 tool 消息**：在没有前置包含工具调用的 @[`AIMessage`] 的情况下发送 @[`ToolMessage`]，会违反协议要求

:::python
下面是一个有问题的模式示例：

```python
# 模型请求两个工具调用
response_message.tool_calls  # 返回 2 个调用

# 但只提供了一个 ToolMessage
chat_history.append(ToolMessage(
    content=str(tool_response),
    tool_call_id=tool_call.get("id")
))

model_with_tools.invoke(chat_history)
```
:::

:::js
下面是一个有问题的模式示例：

```javascript
// 模型请求两个工具调用
responseMessage.tool_calls // 返回 2 个调用

// 但只提供了一个 ToolMessage
chatHistory.push({
  role: "tool",
  content: toolResponse,
  tool_call_id: responseMessage.tool_calls[0].id
});

await modelWithTools.invoke(chatHistory); // 失败并返回 INVALID_TOOL_RESULTS
```
:::

## 故障排查

要解决此错误：

* **检查配对数量**：确保前一个 @[`AIMessage`] 中的每个工具调用都对应一个 @[`ToolMessage`]
* **验证 ID**：确认每个 `ToolMessage.tool_call_id` 都与真实存在的工具调用标识符匹配
