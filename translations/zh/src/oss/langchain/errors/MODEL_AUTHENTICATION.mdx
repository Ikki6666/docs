---
title: MODEL_AUTHENTICATION
---

<Note>
    目前仅在 `langchainjs`（JavaScript/TypeScript）中使用。
</Note>

你的模型提供方正在拒绝你访问其服务。

此错误通常是由于身份验证凭据或 API key 出现问题。

## 故障排查

* 确认你的 API key 或身份验证凭据准确且有效。
* 如果使用基于环境变量的身份验证，请检查：
    - 变量名拼写正确
    - 变量已经赋值
    - `dotenv` 等第三方包没有干扰加载过程
* 如果使用代理或非标准端点，请确保你的自定义提供方不需要其他身份验证方案。
* 通过显式传入凭据来绕过环境变量问题：

:::python
```python
from langchain_openai import ChatOpenAI

model = ChatOpenAI(api_key="YOUR_KEY_HERE")
```
:::
:::js
```typescript
import { ChatOpenAI } from "@langchain/openai";

const model = new ChatOpenAI({
  apiKey: "YOUR_KEY_HERE",
});
```
:::
