当 [prompt template](https://github.com/langchain-ai/langchain/blob/v0.3/docs/docs/concepts/prompt_templates.mdx) 收到缺失或无效的输入变量时，就会出现此错误。

:::js
一种意想不到的触发方式，是你把一个 JSON 对象直接放进 prompt template 中：

```typescript
import { PromptTemplate } from "@langchain/core/prompts";
import { ChatOpenAI } from "@langchain/openai";

const prompt = PromptTemplate.fromTemplate(`You are a helpful assistant.

Here is an example of how you should respond:

{
  "firstName": "John",
  "lastName": "Doe",
  "age": 21
}

Now, answer the following question:

{question}`);
```

你可能会以为，上面的 prompt template 只需要一个名为 question 的输入键，但 JSON 对象会被解释为额外变量，因为花括号 (`{`) 没有转义，必须改为再加一个左花括号，如下所示：

```typescript
import { PromptTemplate } from "@langchain/core/prompts";
import { ChatOpenAI } from "@langchain/openai";

const prompt = PromptTemplate.fromTemplate(`You are a helpful assistant.

Here is an example of how you should respond:

{{
  "firstName": "John",
  "lastName": "Doe",
  "age": 21
}}

Now, answer the following question:

{question}`);
```
:::


## 故障排查

要解决此错误，你可以：

1. 检查 prompt template 是否正确。使用 f-string 格式时，确保花括号已正确转义：
   * 在 f-string 中，单个左括号和右括号分别使用 `{{` 和 `}}`
   * 在 f-string 中，双层花括号分别使用 `{{{{` 和 `}}}}`
2. 使用 `MessagesPlaceholder` 组件时，确认你传入的是消息数组或类消息对象。如果使用简写元组，请把变量名包在花括号里，例如 `["placeholder", "{messages}"]`
3. 通过使用 [LangSmith](/langsmith/observability) 或日志来检查传给 prompt template 的实际输入，确认它们符合预期
4. 如果 prompt 来自 LangChain [Prompt Hub](https://smith.langchain.com/prompts)，请先用样例输入把它单独取出并测试，确保它能正常工作
