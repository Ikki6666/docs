**LangGraph v1 是一次聚焦稳定性的 agent runtime 发布。** 它保持核心 graph API 和执行模型不变，同时改进类型安全、文档和开发者体验。

它被设计为与 [LangChain v1](/oss/releases/langchain-v1)（其 `createAgent` 构建在 LangGraph 之上）协同工作，因此你可以先从高层 API 开始，需要时再下探到更细粒度的控制。

<CardGroup cols={1}>
    <Card title="稳定的核心 API" icon="sitemap">
        Graph primitives（state、nodes、edges）和 execution/runtime 模型保持不变，让升级更直接。
    </Card>
    <Card title="默认可靠" icon="database">
        通过 checkpointing、persistence、streaming 和 human-in-the-loop 实现的 durable execution 仍然是一等能力。
    </Card>
    <Card title="与 LangChain v1 无缝配合" icon="link">
        LangChain 的 `createAgent` 运行在 LangGraph 之上。用 LangChain 快速开始；需要自定义编排时再使用 LangGraph。
    </Card>
</CardGroup>

## 弃用 `createReactAgent`

LangGraph 的 `createReactAgent` prebuilt 已弃用，推荐使用 LangChain 的 `createAgent`。它提供更简单的接口，并通过引入 middleware 提供更大的自定义空间。

* 有关新的 `createAgent` API，请参见 [LangChain v1 发布说明](/oss/releases/langchain-v1#createagent)。
* 有关从 `createReactAgent` 迁移到 `createAgent`，请参见 [LangChain v1 迁移指南](/oss/migrate/langchain-v1#createagent)。

## 类型化 interrupts

@[`StateGraph`] 现在可以在构造函数中接收 interrupt 类型映射，从而更精确地限制 graph 内可用 interrupt 的类型。

```typescript expandable
import { StateGraph, MemorySaver, interrupt } from "@langchain/langgraph";
import * as z from "zod";

const stateSchema = z.object({
  foo: z.string(),
})

const graphConfig = {
  interrupts: {
    // Define a simple interrupt that accepts a reason and returns messages
    simple: interrupt<{ reason: string }, { messages: string[] }>, // [!code highlight]
    // Define a complex interrupt with the same signature
    complex: interrupt<{ reason: string }, { messages: string[] }>, // [!code highlight]
  }
}

const checkpointer = new MemorySaver();

const graph = new StateGraph(stateSchema, graphConfig)
  .addNode("node", async (state, runtime) => {
    // Trigger the simple interrupt with a reason
    const response = runtime.interrupt.simple({ reason: "test" });
    // Return the interrupt response as the new state
    return { foo: response };
  })
  // Compile the graph with the checkpointer
  .compile({ checkpointer });

// Invoke the graph with initial state
const result = await graph.invoke({ foo: "test" });

// Access the interrupt data
if (graph.isInterrupted(result)) {
  console.log(result.__interrupt__.messages);
}
```

有关 interrupts 的更多信息，请参见 [Interrupts](/oss/langgraph/interrupts) 文档。

## Frontend SDK 增强

LangGraph v1 在从前端与 LangGraph 应用交互时带来了一些增强。

### 事件流编码

底层 `toLangGraphEventStream` helper 已移除。流式响应现在由 SDK 原生处理，并且可以通过向 `graph.stream` 传入 `encoding` 格式来选择 wire format。这让你可以在 SSE 和普通 JSON 响应之间切换，而无需更改 UI 逻辑。

更多信息请参见[迁移指南](/oss/migrate/langgraph-v1#event-stream-encoding)。

### `useStream` 中的自定义 transports

React `useStream` hook 现在支持可插拔 transports，让你可以更好地控制网络层，而无需更改 UI 代码。

```typescript
const stream = useStream({
  transport: new FetchStreamTransport({
    apiUrl: "http://localhost:2024",
  }),
});
```

了解如何集成和自定义该 hook：[将 LangGraph 集成到 React 应用](/oss/langgraph/ui)。
