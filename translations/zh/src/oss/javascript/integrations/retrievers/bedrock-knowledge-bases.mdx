## 概览

本文将帮助你开始使用 `AmazonKnowledgeBaseRetriever` [retrieval](/oss/langchain/retrieval)。有关 `AmazonKnowledgeBaseRetriever` 全部功能和配置的详细文档，请参阅 [API reference](https://reference.langchain.com/javascript/langchain-aws/AmazonKnowledgeBaseRetriever)。

Knowledge Bases for Amazon Bedrock 是 Amazon Web Services，AWS，提供的端到端 RAG workflow 全托管支持。
它提供完整的数据摄取流程，可将你的文档转换为 embeddings，vectors，并把这些 embeddings 存储到专用向量数据库中。
Knowledge Bases for Amazon Bedrock 支持多种常见的向量存储数据库，包括 Amazon OpenSearch Serverless 的 vector engine、Pinecone、Redis Enterprise Cloud、Amazon Aurora，coming soon，以及 MongoDB，coming soon。

> AWS Knowledge Base Retriever 可以被理解为“self hosted”，即你可以在自己的 AWS 基础设施上运行它。但它不能运行在其他云提供方上，也不能运行在本地环境中。

## 设置

为了使用 AmazonKnowledgeBaseRetriever，你需要一个 AWS 账号，在其中管理你的 indexes 和 documents。设置好账号后，设置以下环境变量：

```bash
process.env.AWS_KNOWLEDGE_BASE_ID=your-knowledge-base-id
process.env.AWS_ACCESS_KEY_ID=your-access-key-id
process.env.AWS_SECRET_ACCESS_KEY=your-secret-access-key
```

如果你还想为单次查询开启自动 tracing，也可以取消下方注释并设置 [LangSmith](/langsmith/observability) API key：

```typescript
// process.env.LANGSMITH_API_KEY = "<YOUR API KEY HERE>";
// process.env.LANGSMITH_TRACING = "true";
```

### 安装

这个 retriever 位于 `@langchain/aws` 包中：

<CodeGroup>
```bash npm
npm install @langchain/aws @langchain/core
```
```bash yarn
yarn add @langchain/aws @langchain/core
```
```bash pnpm
pnpm add @langchain/aws @langchain/core
```
</CodeGroup>

## 实例化

现在可以实例化 retriever：

```typescript
import { AmazonKnowledgeBaseRetriever } from "@langchain/aws";

const retriever = new AmazonKnowledgeBaseRetriever({
  topK: 10,
  knowledgeBaseId: process.env.AWS_KNOWLEDGE_BASE_ID,
  region: "us-east-2",
  clientOptions: {
    credentials: {
      accessKeyId: process.env.AWS_ACCESS_KEY_ID,
      secretAccessKey: process.env.AWS_SECRET_ACCESS_KEY,
    },
  },
});
```

## 用法

```typescript
const query = "..."

await retriever.invoke(query);
```
