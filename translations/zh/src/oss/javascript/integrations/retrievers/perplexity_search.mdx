[Perplexity Search API](https://docs.perplexity.ai/docs/search/quickstart) 会返回实时、具备依据的网页搜索结果，你可以直接把它接入检索流水线中。

## 概览

本文将帮助你开始使用 `PerplexitySearchRetriever` [retrieval](/oss/langchain/retrieval)。有关 `PerplexitySearchRetriever` 全部功能和配置的详细文档，请参阅 [API reference](https://reference.langchain.com/javascript/langchain-perplexity/PerplexitySearchRetriever)。

### 集成详情

| Retriever | Source | Package | [PY support](https://python.langchain.com/docs/integrations/retrievers/perplexity_search/) |
| :--- | :--- | :---: | :---: |
| [`PerplexitySearchRetriever`](https://reference.langchain.com/javascript/langchain-perplexity/PerplexitySearchRetriever) | 网页内容，通过 Perplexity Search API 获取。 | [`@langchain/perplexity`](https://www.npmjs.com/package/@langchain/perplexity) | ✅ |

## 设置

你需要将 `PERPLEXITY_API_KEY` 环境变量设置为你的 Perplexity API key，或者在构造函数中通过 `apiKey` 传入。你可以从 [Perplexity API key dashboard](https://www.perplexity.ai/account/api/keys) 获取 key。

```typescript
process.env.PERPLEXITY_API_KEY = "your-api-key";
```

如果你还想为单次查询开启自动 tracing，也可以取消下方注释并设置 [LangSmith](/langsmith/observability) API key：

```typescript
// process.env.LANGSMITH_API_KEY = "<YOUR API KEY HERE>";
// process.env.LANGSMITH_TRACING = "true";
```

### 安装

这个 retriever 位于 `@langchain/perplexity` 包中：

<CodeGroup>
```bash npm
npm install @langchain/perplexity @langchain/core
```
```bash yarn
yarn add @langchain/perplexity @langchain/core
```
```bash pnpm
pnpm add @langchain/perplexity @langchain/core
```
</CodeGroup>

## 实例化

```typescript
import { PerplexitySearchRetriever } from "@langchain/perplexity";

const retriever = new PerplexitySearchRetriever({
  maxResults: 5,
  // searchDomainFilter: ["wikipedia.org"],
  // searchRecencyFilter: "week",
});
```

构造函数选项包括 `maxResults`、`country`、`searchDomainFilter`、`searchRecencyFilter`、`searchAfterDate` 和 `searchBeforeDate`。详情请参阅 [Perplexity Search API parameters](https://docs.perplexity.ai/docs/search/quickstart)。

## 用法

```typescript
const query = "Who won the most recent FIFA World Cup?";

const docs = await retriever.invoke(query);
```

每个返回的 `Document` 都会把搜索结果摘要放在 `pageContent` 中，并在 `metadata` 中包含 `{ title, url, date, lastUpdated }`。

## 在 chain 中使用

和其他 retrievers 一样，`PerplexitySearchRetriever` 也可以通过 [chains](/oss/langchain/retrieval) 融入 LLM 应用。

```typescript
import { ChatPromptTemplate } from "@langchain/core/prompts";
import { ChatAnthropic } from "@langchain/anthropic";
import {
  RunnablePassthrough,
  RunnableSequence,
} from "@langchain/core/runnables";
import { StringOutputParser } from "@langchain/core/output_parsers";
import { Document } from "@langchain/core/documents";

const prompt = ChatPromptTemplate.fromTemplate(`
Answer the question based only on the context provided.

Context: {context}

Question: {question}`);

const llm = new ChatAnthropic({ model: "claude-3-5-haiku-latest" });

const formatDocs = (docs: Document[]) =>
  docs.map((doc) => doc.pageContent).join("\n\n");

const ragChain = RunnableSequence.from([
  {
    context: retriever.pipe(formatDocs),
    question: new RunnablePassthrough(),
  },
  prompt,
  llm,
  new StringOutputParser(),
]);

await ragChain.invoke("Who won the most recent FIFA World Cup?");
```
