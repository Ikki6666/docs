## 概览

[Amazon Kendra](https://aws.amazon.com/kendra/) 是 Amazon Web Services，AWS，提供的智能搜索服务。
它利用高级自然语言处理，NLP，和机器学习算法，在组织内的多种数据源上提供强大的搜索能力。
Kendra 旨在帮助用户快速、准确地找到所需信息，从而提升生产力和决策效率。

借助 Kendra，用户可以在广泛的内容类型中搜索，包括 documents、FAQs、knowledge bases、manuals 和 websites。
它支持多种语言，并能够理解复杂查询、同义词和上下文语义，从而提供高度相关的搜索结果。

本文将帮助你开始使用 `AWSKendraRetriever` [retrieval](/oss/langchain/retrieval)。有关 `AWSKendraRetriever` 全部功能和配置的详细文档，请参阅 [API reference](https://reference.langchain.com/javascript/langchain-aws/AmazonKendraRetriever)。

## 设置

你需要一个 AWS 账号和一个 Amazon Kendra 实例才能开始使用。更多信息请参阅 AWS 提供的[这份教程](https://docs.aws.amazon.com/kendra/latest/dg/getting-started.html)。

如果你还想为单次查询开启自动 tracing，也可以取消下方注释并设置 [LangSmith](/langsmith/observability) API key：

```typescript
// process.env.LANGSMITH_API_KEY = "<YOUR API KEY HERE>";
// process.env.LANGSMITH_TRACING = "true";
```

### 安装

这个 retriever 位于 `@langchain/aws` 包中：

<CodeGroup>
```bash npm
npm install @langchain/aws @langchain/core
```
```bash yarn
yarn add @langchain/aws @langchain/core
```
```bash pnpm
pnpm add @langchain/aws @langchain/core
```
</CodeGroup>

## 实例化

现在可以实例化 retriever：

```typescript
import { AmazonKendraRetriever } from "@langchain/aws";

const retriever = new AmazonKendraRetriever({
  topK: 10,
  indexId: "YOUR_INDEX_ID",
  region: "us-east-2", // Your region
  clientOptions: {
    credentials: {
      accessKeyId: "YOUR_ACCESS_KEY_ID",
      secretAccessKey: "YOUR_SECRET_ACCESS_KEY",
    },
  },
});
```

## 用法

```typescript
const query = "..."

await retriever.invoke(query);
```
