Time-Weighted Retriever 是一种除了相似度之外，还会考虑时间新近性的 retriever。它的评分算法如下：

```typescript
let score = (1.0 - this.decayRate) ** hoursPassed + vectorRelevance;
```

需要注意的是，上面的 `hoursPassed` 指的是 retriever 中对象自上次被访问以来经过的时间，而不是自创建以来经过的时间。这意味着经常被访问的对象会保持“新鲜”，并获得更高分数。

`this.decayRate` 是一个可配置的小数，取值范围在 0 到 1 之间。数值越低，文档会被“记住”更久；数值越高，则会更强地偏向最近被访问的文档。

请注意，如果将 decay rate 精确设置为 0 或 1，那么 `hoursPassed` 就不再相关，这个 retriever 也就等价于标准的 vector lookup。

## 用法

本示例展示如何使用一个 vector store 来初始化 `TimeWeightedVectorStoreRetriever`。
需要特别注意的是，由于必须写入相关 metadata，所有 documents 都必须通过 **retriever** 上的 `addDocuments` 方法加入到底层 vector store 中，而不是直接加到 vector store 本身。

```typescript
import { TimeWeightedVectorStoreRetriever } from "@langchain/classic/retrievers/time_weighted";
import { MemoryVectorStore } from "@langchain/classic/vectorstores/memory";
import { OpenAIEmbeddings } from "@langchain/openai";

const vectorStore = new MemoryVectorStore(new OpenAIEmbeddings());

const retriever = new TimeWeightedVectorStoreRetriever({
  vectorStore,
  memoryStream: [],
  searchKwargs: 2,
});

const documents = [
  "My name is John.",
  "My name is Bob.",
  "My favourite food is pizza.",
  "My favourite food is pasta.",
  "My favourite food is sushi.",
].map((pageContent) => ({ pageContent, metadata: {} }));

// All documents must be added using this method on the retriever (not the vector store!)
// so that the correct access history metadata is populated
await retriever.addDocuments(documents);

const results1 = await retriever.invoke("What is my favourite food?");

console.log(results1);

/*
[
  Document { pageContent: 'My favourite food is pasta.', metadata: {} }
]
 */

const results2 = await retriever.invoke("What is my favourite food?");

console.log(results2);

/*
[
  Document { pageContent: 'My favourite food is pasta.', metadata: {} }
]
 */
```
