---
title: "Azure Cosmos DB NoSQL semantic 集成"
description: "集成 Azure Cosmos DB NoSQL semantic cache 以在 LangChain JavaScript 中使用。"
---

> Semantic Cache 功能支持与 Azure Cosmos DB for NoSQL 集成，这让用户能够基于用户输入与先前缓存结果之间的语义相似度来检索缓存响应。它依赖 [AzureCosmosDBNoSQLVectorStore](/oss/integrations/vectorstores/azure_cosmosdb_nosql)，后者会存储缓存 prompts 的向量 embeddings。这些 embeddings 支持基于相似度的搜索，使系统能够检索相关的缓存结果。

如果你还没有 Azure 账号，可以[创建一个免费账号](https://azure.microsoft.com/free/)开始使用。

## 设置

首先需要安装 [`@langchain/azure-cosmosdb`](https://www.npmjs.com/package/@langchain/azure-cosmosdb) 包：

<Tip>
LangChain 包安装的一般说明，请参阅[这个部分](/oss/langchain/install)。
</Tip>

```bash npm
npm install @langchain/azure-cosmosdb @langchain/core
```

你还需要一个正在运行的 Azure Cosmos DB for NoSQL 实例。你可以按照[这份指南](https://learn.microsoft.com/azure/cosmos-db/nosql/quickstart-portal)在 Azure Portal 上免费部署一个实例。

当实例运行起来后，请确保你已经拿到 connection string。如果你使用的是 Managed Identity，就需要 endpoint。你可以在 Azure Portal 中实例的 “Settings / Keys” 部分找到它们。

<Info>
**当使用 Azure Managed Identity 和基于角色的访问控制时，必须确保数据库和容器已经提前创建好。RBAC 不提供创建数据库和容器的权限。关于权限模型的更多信息，请参阅 [Azure Cosmos DB documentation](https://learn.microsoft.com/azure/cosmos-db/how-to-setup-rbac#permission-model)。**


</Info>

## 使用示例

```typescript
import {
  AzureCosmosDBNoSQLConfig,
  AzureCosmosDBNoSQLSemanticCache,
} from "@langchain/azure-cosmosdb";
import { ChatOpenAI, OpenAIEmbeddings } from "@langchain/openai";

const embeddings = new OpenAIEmbeddings();
const config: AzureCosmosDBNoSQLConfig = {
  databaseName: "<DATABASE_NAME>",
  containerName: "<CONTAINER_NAME>",
  // use endpoint to initiate client with managed identity
  connectionString: "<CONNECTION_STRING>",
};

/**
 * Sets the threshold similarity score for returning cached results based on vector distance.
 * Cached output is returned only if the similarity score meets or exceeds this threshold;
 * otherwise, a new result is generated. Default is 0.6, adjustable via the constructor
 * to suit various distance functions and use cases.
 * (see: https://aka.ms/CosmosVectorSearch).
 */

const similarityScoreThreshold = 0.5;
const cache = new AzureCosmosDBNoSQLSemanticCache(
  embeddings,
  config,
  similarityScoreThreshold
);

const model = new ChatOpenAI({ model: "gpt-5.4-mini", cache });

// Invoke the model to perform an action
const response1 = await model.invoke("Do something random!");
console.log(response1);
/*
  AIMessage {
    content: "Sure! I'll generate a random number for you: 37",
    additional_kwargs: {}
  }
*/

const response2 = await model.invoke("Do something random!");
console.log(response2);
/*
  AIMessage {
    content: "Sure! I'll generate a random number for you: 37",
    additional_kwargs: {}
  }
*/
```
