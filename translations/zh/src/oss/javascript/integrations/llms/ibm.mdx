## 设置

要访问 IBM WatsonxAI 模型，你需要创建 IBM watsonx.ai 账号，获取 API key 或其他类型的凭证，并安装 `@langchain/ibm` 集成包。

### 凭证

前往 [IBM Cloud](https://cloud.ibm.com/login) 注册 IBM watsonx.ai，并生成 API key，或使用下文所示的其他认证方式。

#### IAM 认证

```bash
export WATSONX_AI_AUTH_TYPE=iam
export WATSONX_AI_APIKEY=<YOUR-APIKEY>
```

#### Bearer token 认证

```bash
export WATSONX_AI_AUTH_TYPE=bearertoken
export WATSONX_AI_BEARER_TOKEN=<YOUR-BEARER-TOKEN>
```

#### IBM watsonx.ai software 认证

```bash
export WATSONX_AI_AUTH_TYPE=cp4d
export WATSONX_AI_USERNAME=<YOUR_USERNAME>
export WATSONX_AI_PASSWORD=<YOUR_PASSWORD>
export WATSONX_AI_URL=<URL>
```

将这些值设置到环境变量后，在对象初始化时会自动执行认证。

你也可以在创建新实例时直接通过参数传入这些值。

## IAM 认证

```typescript
import { WatsonxLLM } from "@langchain/ibm";

const props = {
  version: "YYYY-MM-DD",

  watsonxAIAuthType: "iam",
```

## 实例化

现在可以实例化模型对象并生成聊天补全：

```javascript
import { WatsonxLLM } from "@langchain/ibm";

const props = {
  decoding_method: "sample",
  maxNewTokens: 100,
  minNewTokens: 1,
  temperature: 0.5,
  topK: 50,
  topP: 1,
};
const instance = new WatsonxLLM({
  version: "YYYY-MM-DD",
  serviceUrl: process.env.API_URL,
  projectId: "<PROJECT_ID>",
  // spaceId: "<SPACE_ID>",
  // idOrName: "<DEPLOYMENT_ID>",
  model: "<MODEL_ID>",
  ...props,
});
```

注意：

- 除非你使用的是 lightweight engine，否则必须提供 `spaceId`、`projectId` 或 `idOrName`（deployment id）之一，该引擎无需指定这些字段即可工作，参见 [watsonx.ai docs](https://www.ibm.com/docs/en/cloud-paks/cp-data/5.0.x?topic=install-choosing-installation-mode)
- 根据你所开通服务实例所在的区域，使用正确的 `serviceUrl`
- 你需要通过 `model_id` 指定要用于推理的模型

### 使用 model Gateway
```typescript
import { WatsonxLLM } from "@langchain/ibm";

const props = {
  decoding_method: "sample",
  maxNewTokens: 100,
  minNewTokens: 1,
  temperature: 0.5,
  topK: 50,
  topP: 1,
};

const instance = new WatsonxLLM({
  version: "YYYY-MM-DD",
  serviceUrl: process.env.API_URL,
  model: "<MODEL_ID>",
  modelGateway: true,
  ...props,
});
```

要在 Langchain 中使用 model gateway，你需要先通过 `@ibm-cloud/watsonx-ai` SDK 或 `watsonx.ai` API 创建 provider 并添加模型。请参阅以下文档：
- [API](https://cloud.ibm.com/apidocs/watsonx-ai#create-watsonxai-provider).
- [SDK](https://ibm.github.io/watsonx-ai-node-sdk/modules/1_7_x.gateway.html).

## 调用与生成

```javascript
const result = await instance.invoke("Print hello world.");
console.log(result);

const results = await instance.generate([
  "Print hello world.",
  "Print bye, bye world!",
]);
console.log(results);
```

```javascript

print('Hello world.')<|endoftext|>
{
  generations: [ [ [Object] ], [ [Object] ] ],
  llmOutput: { tokenUsage: { generated_token_count: 28, input_token_count: 10 } }
}
```

## 链式调用

你可以像下面这样，将补全模型与 prompt template 链接起来：

```javascript
import { PromptTemplate } from "@langchain/core/prompts"

const prompt = PromptTemplate.fromTemplate("How to say {input} in {output_language}:\n")

const chain = prompt.pipe(instance);
await chain.invoke(
  {
    output_language: "German",
    input: "I love programming.",
  }
)
```

```text
Ich liebe Programmieren.

To express that you are passionate about programming in German,
```

## 覆盖 props

初始化时传入的 props 会在对象的整个生命周期内生效，不过你也可以像下面这样，在单次方法调用时通过第二个参数覆盖它们

```javascript
const result2 = await instance.invoke("Print hello world.", {
  parameters: {
    maxNewTokens: 100,
  },
});
console.log(result2);
```

```text
print('Hello world.')<|endoftext|>
```

## Tokenization

这个包提供了自定义的 `getNumTokens` 实现，会返回实际将要使用的 token 数量。

```javascript
const tokens = await instance.getNumTokens("Print hello world.");
console.log(tokens);
```

```text
4
```
