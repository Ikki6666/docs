[Google Vertex](https://cloud.google.com/vertex-ai) 是一项服务，提供 Google Cloud 中可用的所有基础模型，例如 `gemini-2.5-pro`、`gemini-2.5-flash` 等。

本文将帮助你开始使用 LangChain 中的 VertexAI 补全模型（LLM）。有关 `VertexAI` 功能和配置选项的详细文档，请参阅 [API reference](https://reference.langchain.com/javascript/langchain-google-vertexai/index/VertexAI)。

## 设置

LangChain.js 根据你是在 Node.js 环境还是 Web 环境中运行，支持两种不同的认证方式。

要访问 VertexAI 模型，你需要创建 Google Cloud Platform（GCP）账号、获取 API key，并安装 `@langchain/google-vertexai` 集成包。在 Node.js 中，这个包使用 [`@langchain/google-gauth`](https://github.com/langchain-ai/langchainjs/tree/main/libs/providers/langchain-google-gauth) 完成认证，你不需要单独安装它。

### 凭证

#### Node.js

你需要确保目标项目已启用 Vertex AI API，并且你已经通过以下任一方式完成了 Google Cloud 认证：

- 你已登录到有权访问该项目的账号，使用 `gcloud auth application-default login`
- 你运行代码的机器使用了有权访问该项目的服务账号
- 你已下载有权访问该项目的服务账号凭证，并将 `GOOGLE_APPLICATION_CREDENTIALS` 环境变量设置为该文件路径
  **or**
- 你将 `GOOGLE_API_KEY` 环境变量设置为该项目的 API key

#### Web

要在 Web 环境中调用 Vertex AI 模型，例如 Edge functions，你需要安装 `@langchain/google-vertexai-web` 包。

然后，将服务账号凭证设置到 `GOOGLE_WEB_CREDENTIALS` 中，或者使用已弃用的 `GOOGLE_VERTEX_AI_WEB_CREDENTIALS`：

```bash
export GOOGLE_WEB_CREDENTIALS='{"type":"service_account","project_id":"YOUR_PROJECT-12345",...}'
```

你也可以像下面这样，直接在代码中传入凭证：

```typescript
import { VertexAI } from "@langchain/google-vertexai";
// Or uncomment this line if you're using the web version:
// import { VertexAI } from "@langchain/google-vertexai-web";

const model = new VertexAI({
  authOptions: {
    credentials: {"type":"service_account","project_id":"YOUR_PROJECT-12345",...},
  },
});
```

如果你还想为模型调用开启自动追踪，也可以取消下方注释并设置 [LangSmith](/langsmith/observability) API key：

```bash
# export LANGSMITH_TRACING="true"
# export LANGSMITH_API_KEY="your-api-key"
```

### 安装

LangChain 的 VertexAI 集成位于 `@langchain/google-vertexai` 包中：

<CodeGroup>
```bash npm
npm install @langchain/google-vertexai @langchain/core
```
```bash yarn
yarn add @langchain/google-vertexai @langchain/core
```
```bash pnpm
pnpm add @langchain/google-vertexai @langchain/core
```
</CodeGroup>

或者，如果你运行在 Web 环境中：

<CodeGroup>
```bash npm
npm install @langchain/google-vertexai-web @langchain/core
```
```bash yarn
yarn add @langchain/google-vertexai-web @langchain/core
```
```bash pnpm
pnpm add @langchain/google-vertexai-web @langchain/core
```
</CodeGroup>

## 实例化

现在可以实例化模型对象并生成聊天补全：

```typescript
import { VertexAI } from "@langchain/google-vertexai-web"

const llm = new VertexAI({
  model: "gemini-pro",
  temperature: 0,
  maxRetries: 2,
  // other params...
})
```

## 调用

```typescript
const inputText = "VertexAI is an AI company that "

const completion = await llm.invoke(inputText)
completion
```

```txt
offers a wide range of cloud computing services and artificial intelligence solutions to businesses and developers worldwide.
```
