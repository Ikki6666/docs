LangChain.js 支持调用 [YandexGPT](https://cloud.yandex.com/en/services/yandexgpt) LLM。

## 设置

首先，你需要[创建服务账号](https://cloud.yandex.com/en/docs/iam/operations/sa/create)，并授予 `ai.languageModels.user` 角色。

接下来，你有两种认证方式：

- [IAM token](https://cloud.yandex.com/en/docs/iam/operations/iam-token/create-for-sa)。
  你可以在构造函数参数 `iam_token` 中指定该 token，或者通过环境变量 `YC_IAM_TOKEN` 提供。
- [API key](https://cloud.yandex.com/en/docs/iam/operations/api-key/create)
  你可以在构造函数参数 `api_key` 中指定该 key，或者通过环境变量 `YC_API_KEY` 提供。

## 用法

<Tip>
LangChain 包的通用安装说明，请参阅[这一节](/oss/langchain/install)。
</Tip>

```bash npm
npm install @langchain/yandex @langchain/core
```

```typescript
import { YandexGPT } from "@langchain/yandex/llms";

const model = new YandexGPT();
const res = await model.invoke(['Translate "I love programming" into French.']);
console.log({ res });
```
