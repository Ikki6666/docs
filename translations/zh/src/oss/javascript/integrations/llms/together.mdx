[Together AI](https://www.together.ai/) 提供 API，让你只用几行代码就能查询 [50+ 个领先的开源模型](https://docs.together.ai/docs/inference-models)。

本文将帮助你开始使用 LangChain 中的 Together AI 文本补全模型（LLM）。有关 `TogetherAI` 功能和配置选项的详细文档，请参阅 [API reference](https://reference.langchain.com/javascript/langchain-together-ai/TogetherAI)。

## 设置

要访问旧版 `TogetherAI` completions 类，请创建 Together 账号、[获取 API key](https://api.together.xyz/)，并安装 `@langchain/together-ai` 集成包。对于 chat 和 instruct 模型，优先使用 [`ChatTogetherAI`](/oss/integrations/chat/togetherai)。

### 凭证

前往 [api.together.ai](https://api.together.ai/) 注册 Together AI 并生成 API key。设置 `TOGETHER_AI_API_KEY` 环境变量：

```bash
export TOGETHER_AI_API_KEY="your-api-key"
```

如果你还想为模型调用开启自动追踪，也可以取消下方注释并设置 [LangSmith](/langsmith/observability) API key：

```bash
# export LANGSMITH_TRACING="true"
# export LANGSMITH_API_KEY="your-api-key"
```

### 安装

LangChain 的 TogetherAI 集成位于 `@langchain/together-ai` 包中：

<CodeGroup>
```bash npm
npm install @langchain/together-ai @langchain/core
```
```bash yarn
yarn add @langchain/together-ai @langchain/core
```
```bash pnpm
pnpm add @langchain/together-ai @langchain/core
```
</CodeGroup>

## 实例化

实例化 completions 模型：

```typescript
import { TogetherAI } from "@langchain/together-ai";

const llm = new TogetherAI({
  model: "meta-llama/Meta-Llama-3.1-8B-Instruct-Turbo",
  maxTokens: 256,
});
```
