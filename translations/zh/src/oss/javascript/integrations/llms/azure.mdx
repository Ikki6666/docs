<Info>
**此前，LangChain.js 使用专用的 [Azure OpenAI SDK](https://github.com/Azure/azure-sdk-for-js/tree/main/sdk/openai/openai) 来支持 Azure OpenAI 集成。现在这个 SDK 已被弃用，推荐改用 OpenAI SDK 中新的 Azure 集成。这样可以在最新 OpenAI 模型和特性发布当天就访问到它们，并且可以在 OpenAI API 与 Azure OpenAI 之间无缝切换。**

如果你正在使用已弃用 SDK 下的 Azure OpenAI，请参阅[迁移指南](#migration-from-azure-openai-sdk)，更新到新的 API。
</Info>

[Azure OpenAI](https://learn.microsoft.com/en-us/azure/ai-services/openai/) 是 Microsoft Azure 提供的一项服务，提供来自 OpenAI 的强大语言模型。

本文将帮助你开始在 LangChain 中使用 AzureOpenAI completion models（LLMs）。如需查看 `AzureOpenAI` 的特性和配置选项详情，请参阅 [API reference](https://reference.langchain.com/javascript/langchain-openai/AzureOpenAI)。

## 设置

要访问 AzureOpenAI 模型，需要创建 Azure 账号、获取 API key，并安装 `@langchain/openai` 集成包。

### 凭据

前往 [azure.microsoft.com](https://azure.microsoft.com/) 注册 AzureOpenAI 并生成 API key。

你还需要先部署一个 Azure OpenAI 实例。可以按照[这份指南](https://learn.microsoft.com/azure/ai-services/openai/how-to/create-resource?pivots=web-portal)在 Azure Portal 中完成部署。

当实例运行起来后，请确保已经拿到实例名称和 key。你可以在 Azure Portal 的实例页面中，在 “Keys and Endpoint” 部分找到 key。

如果你使用的是 Node.js，可以定义以下环境变量来使用这项服务：

```bash
AZURE_OPENAI_API_INSTANCE_NAME=<YOUR_INSTANCE_NAME>
AZURE_OPENAI_API_DEPLOYMENT_NAME=<YOUR_DEPLOYMENT_NAME>
AZURE_OPENAI_API_KEY=<YOUR_KEY>
AZURE_OPENAI_API_VERSION="2024-02-01"
```

或者，你也可以直接把这些值传给 `AzureOpenAI` 构造函数。

如果你还想为模型调用启用自动 tracing，也可以取消下面的注释来设置 [LangSmith](/langsmith/observability) API key：

```bash
# export LANGSMITH_TRACING="true"
# export LANGSMITH_API_KEY="your-api-key"
```

### 安装

LangChain 的 AzureOpenAI 集成位于 `@langchain/openai` 包中：

<CodeGroup>
```bash npm
npm install @langchain/openai @langchain/core
```
```bash yarn
yarn add @langchain/openai @langchain/core
```
```bash pnpm
pnpm add @langchain/openai @langchain/core
```
</CodeGroup>

## 实例化

现在可以实例化模型对象并生成 chat completions：

```typescript
import { AzureOpenAI } from "@langchain/openai"

const llm = new AzureOpenAI({
  model: "gpt-3.5-turbo-instruct",
  azureOpenAIApiKey: "<your_key>", // In Node.js defaults to process.env.AZURE_OPENAI_API_KEY
  azureOpenAIApiInstanceName: "<your_instance_name>", // In Node.js defaults to process.env.AZURE_OPENAI_API_INSTANCE_NAME
  azureOpenAIApiDeploymentName: "<your_deployment_name>", // In Node.js defaults to process.env.AZURE_OPENAI_API_DEPLOYMENT_NAME
  azureOpenAIApiVersion: "<api_version>", // In Node.js defaults to process.env.AZURE_OPENAI_API_VERSION
  temperature: 0,
  maxTokens: undefined,
  timeout: undefined,
  maxRetries: 2,
  // other params...
})
```

## 使用 Azure Managed identity

如果你使用 Azure Managed Identity，可以像下面这样配置凭据：

```typescript
import {
  DefaultAzureCredential,
  getBearerTokenProvider,
} from "@azure/identity";
import { AzureOpenAI } from "@langchain/openai";

const credentials = new DefaultAzureCredential();
const azureADTokenProvider = getBearerTokenProvider(
  credentials,
  "https://cognitiveservices.azure.com/.default"
);

const managedIdentityLLM = new AzureOpenAI({
  azureADTokenProvider,
  azureOpenAIApiInstanceName: "<your_instance_name>",
  azureOpenAIApiDeploymentName: "<your_deployment_name>",
  azureOpenAIApiVersion: "<api_version>",
});

```

## 使用不同的域名

如果你的实例托管在默认 `openai.azure.com` 之外的域名下，则需要改用 `AZURE_OPENAI_BASE_PATH` 环境变量。
例如，如果要连接 `https://westeurope.api.microsoft.com/openai/deployments/{DEPLOYMENT_NAME}` 这个域名，可以这样写：

```typescript
import { AzureOpenAI } from "@langchain/openai";

const differentDomainLLM = new AzureOpenAI({
  azureOpenAIApiKey: "<your_key>", // In Node.js defaults to process.env.AZURE_OPENAI_API_KEY
  azureOpenAIApiDeploymentName: "<your_deployment_name>", // In Node.js defaults to process.env.AZURE_OPENAI_API_DEPLOYMENT_NAME
  azureOpenAIApiVersion: "<api_version>", // In Node.js defaults to process.env.AZURE_OPENAI_API_VERSION
  azureOpenAIBasePath:
    "https://westeurope.api.microsoft.com/openai/deployments", // In Node.js defaults to process.env.AZURE_OPENAI_BASE_PATH
});

```

## 从 Azure OpenAI SDK 迁移

如果你正在使用已弃用的 Azure OpenAI SDK 配合 `@langchain/azure-openai` 包，可以按照以下步骤更新代码，迁移到新的 Azure 集成：

1. 安装新的 `@langchain/openai` 包，并移除之前的 `@langchain/azure-openai` 包：

   ```bash
   npm install @langchain/openai
   npm uninstall @langchain/azure-openai
   ```

2. 更新 import，改为使用 `@langchain/openai` 包中的 `AzureOpenAI` 和 @[`AzureChatOpenAI`] 类：

   ```typescript
   import { AzureOpenAI } from "@langchain/openai";
   ```

3. 更新代码，使用新的 `AzureOpenAI` 和 @[`AzureChatOpenAI`] 类并传入必需参数：

   ```typescript
   const model = new AzureOpenAI({
     azureOpenAIApiKey: "<your_key>",
     azureOpenAIApiInstanceName: "<your_instance_name>",
     azureOpenAIApiDeploymentName: "<your_deployment_name>",
     azureOpenAIApiVersion: "<api_version>",
   });
   ```

   注意，现在构造函数要求传入 `azureOpenAIApiInstanceName` 参数，而不是 `azureOpenAIEndpoint` 参数，同时增加了 `azureOpenAIApiVersion` 参数来指定 API 版本。

   - 如果你之前使用的是 Azure Managed Identity，现在需要在构造函数中使用 `azureADTokenProvider` 参数，而不是 `credentials`。详情请参阅 [Azure Managed Identity](#using-azure-managed-identity) 一节。

   - 如果你之前使用的是环境变量，现在需要设置 `AZURE_OPENAI_API_INSTANCE_NAME`，而不是 `AZURE_OPENAI_API_ENDPOINT`，并额外添加 `AZURE_OPENAI_API_VERSION` 环境变量来指定 API 版本。
