## 设置

要访问 OpenAI 模型，你需要创建 OpenAI 账号、获取 API key，并安装 `@langchain/openai` 集成包。

### 凭证

前往 [platform.openai.com](https://platform.openai.com/) 注册 OpenAI 并生成 API key。完成后，设置 `OPENAI_API_KEY` 环境变量：

```bash
export OPENAI_API_KEY="your-api-key"
```

如果你还想为模型调用开启自动追踪，也可以取消下方注释并设置 [LangSmith](/langsmith/observability) API key：

```bash
# export LANGSMITH_TRACING="true"
# export LANGSMITH_API_KEY="your-api-key"
```

### 安装

LangChain 的 OpenAI 集成位于 `@langchain/openai` 包中：

<CodeGroup>
```bash npm
npm install @langchain/openai @langchain/core
```
```bash yarn
yarn add @langchain/openai @langchain/core
```
```bash pnpm
pnpm add @langchain/openai @langchain/core
```
</CodeGroup>

## 实例化

现在你可以实例化模型并生成文本补全：

```typescript
import { OpenAI } from "@langchain/openai"

const llm = new OpenAI({
  model: "gpt-3.5-turbo-instruct",
  temperature: 0,
  maxTokens: undefined,
  timeout: undefined,
  maxRetries: 2,
  apiKey: process.env.OPENAI_API_KEY,
  // other params...
})
```

## 自定义 URL

你可以像下面这样，通过传入 `configuration` 参数，自定义 SDK 发送请求时使用的 base URL：

```typescript
const llmCustomURL = new OpenAI({
  temperature: 0.9,
  configuration: {
    baseURL: "https://your_custom_url.com",
  },
});
```

你也可以传入官方 SDK 支持的其他 `ClientOptions` 参数。

如果你使用的是 Azure OpenAI 托管环境，请改看[专门页面](/oss/integrations/llms/azure)。
