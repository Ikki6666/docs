[Tavily](https://tavily.com/) 是一个专为 AI agents 设计的搜索引擎，提供 search、extract、crawl 和 map API，让开发者能够把应用连接到实时在线信息。Tavily 的核心使命是从可信来源中提供事实性强、可靠的信息，从而提升 AI 生成内容和推理的准确性与可靠性。

`@langchain/tavily` 包将 Tavily 的 Search、Extract、Crawl、Map 和 Research endpoints 封装为 LangChain tools。

## 安装与设置

为 LangChain JavaScript 安装 Tavily 集成包：

<CodeGroup>
```bash npm
npm install @langchain/tavily @langchain/core
```
```bash yarn
yarn add @langchain/tavily @langchain/core
```
```bash pnpm
pnpm add @langchain/tavily @langchain/core
```
</CodeGroup>

[配置 Tavily API key](https://app.tavily.com)，并将其设置为名为 `TAVILY_API_KEY` 的环境变量：

```bash
export TAVILY_API_KEY="your-api-key"
```

## Tools

### TavilySearch

一个搜索工具，返回来自 Tavily Search API 的实时、适合 LLM 使用的结果。

请参阅[用法示例](/oss/integrations/tools/tavily_search)。

```typescript
import { TavilySearch } from "@langchain/tavily";
```

### TavilyExtract

一个返回一个或多个 URL 的清洗后、解析后内容的工具。

请参阅[用法示例](/oss/integrations/tools/tavily_extract)。

```typescript
import { TavilyExtract } from "@langchain/tavily";
```

### TavilyCrawl

一个从基础 URL 开始执行结构化网页遍历的工具，并支持可选的自然语言指令以及 path 或 domain 过滤。

请参阅[用法示例](/oss/integrations/tools/tavily_crawl)。

```typescript
import { TavilyCrawl } from "@langchain/tavily";
```

### TavilyMap

一个用于发现站点 URL 结构，但不提取页面内容的工具。

请参阅[用法示例](/oss/integrations/tools/tavily_map)。

```typescript
import { TavilyMap } from "@langchain/tavily";
```

### TavilyResearch

一个运行结构化研究任务并返回综合结果的工具，也可选择流式返回。

```typescript
import { TavilyResearch } from "@langchain/tavily";
```

### TavilyGetResearch

一个根据之前 `TavilyResearch` 调用返回的 `request_id` 检索研究结果的工具。

```typescript
import { TavilyGetResearch } from "@langchain/tavily";
```
