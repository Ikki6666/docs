[Daytona](https://daytona.io) 提供启动速度很快、支持多语言的 sandbox 环境，最适合 TypeScript 和 Python 开发。

## 设置

<CodeGroup>
    ```bash npm
    npm install @langchain/daytona
    ```

    ```bash yarn
    yarn add @langchain/daytona
    ```

    ```bash pnpm
    pnpm add @langchain/daytona
    ```
</CodeGroup>

### 认证

前往 [app.daytona.io](https://app.daytona.io) 获取你的 API key。

```bash
export DAYTONA_API_KEY=your_api_key
```

或者直接传入凭证：

```typescript
const sandbox = await DaytonaSandbox.create({
  auth: { apiKey: "your-api-key-here" },
});
```

## 与 deepagents 搭配使用

:::js
```typescript
import { createDeepAgent } from "deepagents";
import { ChatAnthropic } from "@langchain/anthropic";
import { DaytonaSandbox } from "@langchain/daytona";

const sandbox = await DaytonaSandbox.create({
  language: "typescript",
  timeout: 300,
});

try {
  const agent = createDeepAgent({
    model: new ChatAnthropic({ model: "claude-sonnet-4-20250514" }),
    systemPrompt: "You are a coding assistant with sandbox access.",
    backend: sandbox,
  });

  const result = await agent.invoke({
    messages: [{ role: "user", content: "Create a hello world TypeScript app and run it" }],
  });
} finally {
  await sandbox.close();
}
```
:::

## 独立使用

:::js
```typescript
import { DaytonaSandbox } from "@langchain/daytona";

const sandbox = await DaytonaSandbox.create({
  language: "typescript",
  timeout: 300,
});

const result = await sandbox.execute("npm --version");
console.log(result.output);

await sandbox.close();
```
:::

## 配置

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `language` | `string`  | `"typescript"` | 主语言运行时。可选值：`"typescript" \| "python" \| "javascript"` |
| `timeout` | `number` | `300` | 命令超时时间，单位为秒 |
| `target` | `string` | `"us"` | 区域。可选值：`"us" \| "eu"`  |
| `image` | `string` | - | 自定义 Docker image，例如 `"node:20"`、`"python:3.12"` |
| `snapshot` | `string` | - | Snapshot 名称，不能与 `image` 同时使用 |
| `resources` | `object` | - | CPU、内存、磁盘配额，需要搭配 `image` 使用 |
| `autoStopInterval` | `number` | `15` | 空闲 N 分钟后自动停止，`0` 表示禁用 |
| `labels` | `Record<string, string>` | - | 用于组织 sandboxes 的自定义 labels |
| `initialFiles` | `Record<string, string>` | - | 启动时创建的文件 |

## 自定义资源

如果要自定义 CPU、内存或磁盘，你必须指定一个 Docker image：

:::js
```typescript
const sandbox = await DaytonaSandbox.create({
  image: "node:20",
  language: "typescript",
  resources: {
    cpu: 4,       // Number of CPUs
    memory: 8,    // GiB
    disk: 50,     // GiB
  },
});
```
:::

## 访问 Daytona SDK

对于更高级的功能，可以访问底层 Daytona SDK：

:::js
```typescript
const daytonaSandbox = await DaytonaSandbox.create();
const sdk = daytonaSandbox.sandbox;

// Use any Daytona SDK feature directly
const workDir = await sdk.getWorkDir();
const homeDir = await sdk.getUserHomeDir();
await sdk.fs.createFolder("src", "755");
```
:::

## 重新连接已有 sandbox

:::js
```typescript
// Create sandbox with auto-stop interval
const sandbox = await DaytonaSandbox.create({
  language: "typescript",
  autoStopInterval: 60,
});
const sandboxId = sandbox.id;

// Stop the sandbox (keeps it available)
await sandbox.stop();

// Later: reconnect
const reconnected = await DaytonaSandbox.connect(sandboxId);
await reconnected.start();
const result = await reconnected.execute("ls -la");
```
:::

## Sandbox 生命周期

:::js
```typescript
const sandbox = await DaytonaSandbox.create();

await sandbox.stop();   // Stop (can be restarted)
await sandbox.start();  // Start a stopped sandbox
await sandbox.close();  // Delete permanently
```
:::

## Factory functions

:::js
```typescript
import { createDaytonaSandboxFactory, createDaytonaSandboxFactoryFromSandbox } from "@langchain/daytona";

// Create new sandbox per invocation
const factory = createDaytonaSandboxFactory({ language: "typescript" });

// Or reuse an existing sandbox across invocations
const sandbox = await DaytonaSandbox.create();
const reuseFactory = createDaytonaSandboxFactoryFromSandbox(sandbox);
```
:::

## 错误处理

```typescript
import { DaytonaSandboxError } from "@langchain/daytona";

try {
  await sandbox.execute("some command");
} catch (error) {
  if (error instanceof DaytonaSandboxError) {
    switch (error.code) {
      case "NOT_INITIALIZED":
        await sandbox.initialize();
        break;
      case "COMMAND_TIMEOUT":
        console.error("Command took too long");
        break;
      case "AUTHENTICATION_FAILED":
        console.error("Check your Daytona API key");
        break;
    }
  }
}
```

### 错误码

| Code | Description |
|------|-------------|
| `NOT_INITIALIZED` | Sandbox 尚未初始化，需要调用 `initialize()` |
| `ALREADY_INITIALIZED` | 不能重复初始化 |
| `AUTHENTICATION_FAILED` | Daytona API key 无效或缺失 |
| `SANDBOX_CREATION_FAILED` | 创建 sandbox 失败 |
| `SANDBOX_NOT_FOUND` | 找不到 sandbox ID，或 sandbox 已被删除 |
| `SANDBOX_NOT_STARTED` | Sandbox 当前不在已启动状态 |
| `COMMAND_TIMEOUT` | 命令执行超时 |
| `COMMAND_FAILED` | 命令执行失败 |
| `FILE_OPERATION_FAILED` | 文件读写失败 |
| `RESOURCE_LIMIT_EXCEEDED` | 超出 CPU、内存或存储限制 |
