[OpenRouter](https://openrouter.ai/) 是一个统一 API，可通过单一 endpoint 访问来自多个 providers，OpenAI、Anthropic、Google、Meta 等，的模型，并提供 provider routing 和 multi-model fallback 等能力。

## 安装

```bash
npm install @langchain/openrouter @langchain/core
```

在环境中设置 `OPENROUTER_API_KEY`。有关 setup 细节，请参阅 [ChatOpenRouter](/oss/integrations/chat/openrouter) 页面。
