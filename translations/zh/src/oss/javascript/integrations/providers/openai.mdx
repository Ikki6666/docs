LangChain 通过 `@langchain/openai` 包集成 OpenAI 和 Azure OpenAI。

> [OpenAI](https://en.wikipedia.org/wiki/OpenAI) 是一家美国人工智能，AI，研究实验室，
> 由非营利组织 `OpenAI Incorporated`
> 及其营利性子公司 `OpenAI Limited Partnership` 组成。
> OpenAI 进行 AI 研究，其公开声明的目标是促进和开发友好的 AI。
> OpenAI 系统运行在 `Microsoft` 提供的、基于 `Azure` 的超级计算平台上。

> [OpenAI API](https://platform.openai.com/docs/models) 由一组能力和价格各不相同的模型提供支持。
>
> [ChatGPT](https://chat.openai.com) 是由 `OpenAI` 开发的人工智能，AI，聊天机器人。

## Middleware

这是专为 OpenAI 模型设计的 middleware。有关更多信息，请参阅 [middleware](/oss/langchain/middleware/overview)。

| Middleware | Description |
|------------|-------------|
| [Content moderation](#content-moderation) | 使用 OpenAI moderation endpoint 对 agent 流量进行内容审查 |

### Content moderation

使用 OpenAI 的 moderation endpoint，对 agent 流量，用户输入、模型输出和工具结果，进行内容审查，以检测和处理不安全内容。Content moderation 适用于以下场景：

- 需要内容安全和合规的应用
- 过滤有害、仇恨或不适当内容
- 需要安全护栏的面向客户 agent
- 满足平台审核要求

<Info>
    进一步了解 [OpenAI's moderation models](https://platform.openai.com/docs/guides/moderation) 和分类。
</Info>

**API reference:** @[`openAIModerationMiddleware`]

```typescript
import { createAgent, openAIModerationMiddleware } from "langchain";

const agent = createAgent({
  model: "openai:gpt-5.5",
  tools: [searchTool, databaseTool],
  middleware: [
    openAIModerationMiddleware({
      model: "openai:gpt-5.5",
      moderationModel: "omni-moderation-latest",
      checkInput: true,
      checkOutput: true,
      exitBehavior: "end",
    }),
  ],
});
```

<Accordion title="Configuration options">

<ParamField body="model" type="string | BaseChatModel" required>
    用于 moderation 的 OpenAI 模型。既可以是模型名称字符串，例如 `"openai:gpt-5.5"`，也可以是 `BaseChatModel` 实例。middleware 会使用这个模型的 client 来访问 moderation endpoint。
</ParamField>

<ParamField body="moderationModel" type="ModerationModel" default="omni-moderation-latest">
    使用的 OpenAI moderation model。可选值：`'omni-moderation-latest'`、`'omni-moderation-2024-09-26'`、`'text-moderation-latest'`、`'text-moderation-stable'`
</ParamField>

<ParamField body="checkInput" type="boolean" default="true">
    是否在调用模型之前检查用户输入消息
</ParamField>

<ParamField body="checkOutput" type="boolean" default="true">
    是否在调用模型之后检查模型输出消息
</ParamField>

<ParamField body="checkToolResults" type="boolean" default="false">
    是否在调用模型之前检查工具结果消息
</ParamField>

<ParamField body="exitBehavior" type="'error' | 'end' | 'replace'" default="'end'">
    当内容被标记违规时的处理方式。可选值：

    - `'end'` - 立即结束 agent 执行，并返回违规消息
    - `'error'` - 抛出 `OpenAIModerationError` 异常
    - `'replace'` - 用违规消息替换被标记的内容，并继续执行
</ParamField>

<ParamField body="violationMessage" type="string | undefined">
    用于违规消息的自定义模板。支持以下模板变量：

    - `{categories}` - 以逗号分隔的被标记分类列表
    - `{category_scores}` - category scores 的 JSON 字符串
    - `{original_content}` - 原始被标记内容

    默认值：`"I'm sorry, but I can't comply with that request. It was flagged for {categories}."`
</ParamField>

</Accordion>

<Accordion title="Full example">

这个 middleware 会在不同阶段集成 OpenAI 的 moderation endpoint 来检查内容：

**Moderation stages:**
- `checkInput` - 在调用模型前检查用户消息
- `checkOutput` - 在调用模型后检查 AI 消息
- `checkToolResults` - 在调用模型前检查工具输出

**Exit behaviors:**
- `'end'`，默认值 - 停止执行并返回违规消息
- `'error'` - 抛出异常，由应用处理
- `'replace'` - 替换被标记内容并继续

```typescript
import { createAgent, openAIModerationMiddleware } from "langchain";

// Basic moderation
const agent = createAgent({
  model: "openai:gpt-5.5",
  tools: [searchTool, customerDataTool],
  middleware: [
    openAIModerationMiddleware({
      model: "openai:gpt-5.5",
      moderationModel: "omni-moderation-latest",
      checkInput: true,
      checkOutput: true,
    }),
  ],
});

// Strict moderation with custom message
const agentStrict = createAgent({
  model: "openai:gpt-5.5",
  tools: [searchTool, customerDataTool],
  middleware: [
    openAIModerationMiddleware({
      model: "openai:gpt-5.5",
      moderationModel: "omni-moderation-latest",
      checkInput: true,
      checkOutput: true,
      checkToolResults: true,
      exitBehavior: "error",
      violationMessage:
        "Content policy violation detected: {categories}. " +
        "Please rephrase your request.",
    }),
  ],
});

// Moderation with replacement behavior
const agentReplace = createAgent({
  model: "openai:gpt-5.5",
  tools: [searchTool],
  middleware: [
    openAIModerationMiddleware({
      model: "openai:gpt-5.5",
      checkInput: true,
      exitBehavior: "replace",
      violationMessage: "[Content removed due to safety policies]",
    }),
  ],
});
```
</Accordion>
