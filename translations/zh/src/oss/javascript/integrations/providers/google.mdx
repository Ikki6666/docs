LangChain 通过 `@langchain/google` 包提供与 [Google AI Studio](https://aistudio.google.com/) 和 [Google Cloud Vertex AI](https://cloud.google.com/vertex-ai) 的集成。

<Info>
  在找更早的 `@langchain/google-genai` 或 `@langchain/google-vertexai` 包吗？它们目前仍处于[长期支持](#legacy-packages)状态，但已经不再推荐用于新项目。
</Info>

## 聊天模型

[`ChatGoogle`](/oss/integrations/chat/google) 类是访问 Gemini 模型，例如 `gemini-2.5-pro`、`gemini-2.5-flash` 和 `gemini-3.1-pro-preview`，以及 Gemma 这类开放模型的推荐方式。它通过单一接口同时支持 Google AI Studio 和 Vertex AI

<Tip>
LangChain 包的通用安装说明，请参阅[这一节](/oss/langchain/install)。
</Tip>

<CodeGroup>
```bash npm
npm install @langchain/google @langchain/core
```
```bash yarn
yarn add @langchain/google @langchain/core
```
```bash pnpm
pnpm add @langchain/google @langchain/core
```
</CodeGroup>

配置你的 API key：

```bash
export GOOGLE_API_KEY=your-api-key
```

```typescript
import { ChatGoogle } from "@langchain/google";

const model = new ChatGoogle("gemini-2.5-flash");

const res = await model.invoke([
  ["human", "What would be a good company name for a company that makes colorful socks?"],
]);
```

`ChatGoogle` 支持 tool calling、structured output、多模态输入，图片、音频、视频、reasoning 或 thinking、image generation、text-to-speech，以及 Google Search grounding 和 code execution 等 Gemini 原生工具。

### Vertex AI 上的第三方模型

[Anthropic](/oss/integrations/chat/anthropic) 的 Claude 模型也可以通过 [Vertex AI](https://cloud.google.com/vertex-ai/generative-ai/docs/partner-models/use-claude) 平台使用。有关如何启用这些模型的访问权限，以及该使用哪些模型名称，请参阅 [using Claude on Vertex AI](https://cloud.google.com/vertex-ai/generative-ai/docs/partner-models/use-claude)。

### Postgres vector store，Cloud SQL

[`@langchain/google-cloud-sql-pg`](https://www.npmjs.com/package/@langchain/google-cloud-sql-pg) 包中的 [PostgresVectorStore](/oss/integrations/vectorstores/google_cloudsql_pg) 模块，提供了使用 CloudSQL for PostgreSQL 存储 vector embeddings 的方式。

```bash
npm install @langchain/google-cloud-sql-pg @langchain/core
```

## 旧版包

以下包会继续以长期支持形式维护，供现有用户使用。新项目应改用 `@langchain/google`。

### `@langchain/google-genai`

`@langchain/google-genai` 包提供 [`ChatGoogleGenerativeAI`](/oss/integrations/chat/google_generative_ai) 和 [`GoogleGenerativeAIEmbeddings`](/oss/integrations/embeddings/google_generative_ai)，用于通过 Google AI Studio 访问 Gemini 模型。这个包基于已弃用的 Google SDK 构建，不会再获得新特性。

```bash
npm install @langchain/google-genai @langchain/core
```

### `@langchain/google-vertexai`

`@langchain/google-vertexai` 包提供 [`ChatVertexAI`](/oss/integrations/chat/google_vertex_ai)、[`VertexAIEmbeddings`](/oss/integrations/embeddings/google_vertex_ai) 和 [`VertexAI`](/oss/integrations/llms/google_vertex_ai)，用于在 Node.js 上访问 Vertex AI。它依赖 [`@langchain/google-gauth`](#%40langchain%2Fgoogle-gauth) 完成认证。这个包已被 `@langchain/google` 中内置的 Vertex AI chat 支持所取代。

```bash
npm install @langchain/google-vertexai @langchain/core
```

### `@langchain/google-vertexai-web`

`@langchain/google-vertexai-web` 包为浏览器和 Edge 运行时提供相同的 Vertex AI chat、embedding 和 LLM 类。在 Web 环境中运行时，请安装这个包，而不是 `@langchain/google-vertexai`。它依赖 [`@langchain/google-webauth`](#%40langchain%2Fgoogle-webauth)。

```bash
npm install @langchain/google-vertexai-web @langchain/core
```

有关 `GOOGLE_WEB_CREDENTIALS` 和 Web import path，请参阅 [Vertex AI chat](/oss/integrations/chat/google_vertex_ai) 页面。

### `@langchain/google-webauth`

[`@langchain/google-webauth`](https://github.com/langchain-ai/langchainjs/tree/main/libs/providers/langchain-google-webauth) 包为旧版 Vertex AI 集成提供浏览器和 Edge 认证能力。安装 `@langchain/google-vertexai-web` 时会自动安装它，请不要再和 `@langchain/google-gauth` 一起安装。

将 service account JSON 设置到 `GOOGLE_WEB_CREDENTIALS` 中，或使用已弃用的 `GOOGLE_VERTEX_AI_WEB_CREDENTIALS`。你也可以在 model constructor 中传入 `apiKey` 或 `authOptions`，或者设置 `API_KEY` 环境变量。

### `@langchain/google-gauth`

[`@langchain/google-gauth`](https://github.com/langchain-ai/langchainjs/tree/main/libs/providers/langchain-google-gauth) 包为基于 [`@langchain/google-common`](#%40langchain%2Fgoogle-common) 构建的旧版 Google 集成提供 Node.js 认证能力。安装 `@langchain/google-vertexai` 时会自动安装它，通常**不需要**直接安装或导入 `@langchain/google-gauth`。

在 Node.js 中，凭证按以下顺序解析：

1. 传给 model constructor 的 `apiKey`
2. 传给 model constructor 的 `authOptions`
3. `API_KEY` 环境变量
4. `GOOGLE_APPLICATION_CREDENTIALS` 所指向路径中的 service account JSON
5. Application Default Credentials，例如运行 `gcloud auth application-default login` 后，或在 Google Cloud 环境中

不要在同一个项目中同时使用 `@langchain/google-gauth` 和 `@langchain/google-webauth`。

统一的 [`@langchain/google`](/oss/integrations/chat/google) 包直接使用 `google-auth-library`，不需要 `@langchain/google-gauth` 或 `@langchain/google-webauth`。

### `@langchain/google-cloud-sql-pg`

[`@langchain/google-cloud-sql-pg`](https://www.npmjs.com/package/@langchain/google-cloud-sql-pg) 包提供 [`PostgresVectorStore`](/oss/integrations/vectorstores/google_cloudsql_pg) 和 [`PostgresLoader`](/oss/integrations/document_loaders/web_loaders/google_cloudsql_pg)，用于 Cloud SQL for PostgreSQL。它与上面的 Gemini chat 包是分开的。

### `@langchain/google-common`

[`@langchain/google-common`](https://github.com/langchain-ai/langchainjs/tree/main/libs/providers/langchain-google-common) 包为 [`@langchain/google-vertexai`](/oss/integrations/chat/google_vertex_ai) 等旧版集成提供共享的 Gemini client 抽象。它不包含授权代码，也**不是**一个可独立使用的包，请不要直接安装或导入它。

<Tip>
  如果要从 `@langchain/google-genai` 或 `@langchain/google-vertexai` 迁移到 `@langchain/google`，请参阅 [ChatGoogle](/oss/integrations/chat/google) 页面中的 setup 说明。`ChatGoogle` 类提供等价能力，并统一支持 Google AI Studio 和 Vertex AI。
</Tip>
