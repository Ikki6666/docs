[You.com](https://you.com) 是一个 AI 生产力平台，提供专为 LLM 应用设计的实时网页搜索和内容提取 API。

## 安装与设置

<CodeGroup>
    ```bash npm
    npm install @youdotcom-oss/langchain
    ```

    ```bash yarn
    yarn add @youdotcom-oss/langchain
    ```

    ```bash pnpm
    pnpm add @youdotcom-oss/langchain
    ```
</CodeGroup>

设置你的 You.com API key。你可以在 [you.com/platform](https://you.com/platform) 获取 API key。

```typescript
process.env.YDC_API_KEY = "your-api-key";
```

## Tools

这个包提供三个 `DynamicStructuredTool` 实例：`youSearch`、`youResearch` 和 `youContents`。请参阅[用法示例](/oss/integrations/tools/youdotcom)。

```typescript
import { youSearch, youResearch, youContents } from "@youdotcom-oss/langchain";
```
