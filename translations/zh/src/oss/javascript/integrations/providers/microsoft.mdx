## LLM

### Azure OpenAI

> [Microsoft Azure](https://en.wikipedia.org/wiki/Microsoft_Azure) 通常简称为 `Azure`，是由 `Microsoft` 运营的云计算平台，通过全球数据中心提供应用和服务的访问、管理与开发能力。它提供多种能力，包括软件即服务，SaaS、平台即服务，PaaS，以及基础设施即服务，IaaS。`Microsoft Azure` 支持许多编程语言、工具和框架，包括 Microsoft 自家的，以及第三方软件和系统。

> [Azure OpenAI](https://azure.microsoft.com/products/ai-services/openai-service/) 是一项云服务，可帮助你基于 OpenAI、Meta 等提供的预构建和精选模型，快速开发生成式 AI 体验。

LangChain.js 支持通过 [OpenAI SDK](https://github.com/openai/openai-node) 中新的 Azure 集成来使用 [Azure OpenAI](https://azure.microsoft.com/products/ai-services/openai-service/)。

你可以在[这个页面](https://learn.microsoft.com/azure/ai-services/openai/overview)进一步了解 Azure OpenAI，以及它与 OpenAI API 的区别。如果你还没有 Azure 账号，可以[创建免费账号](https://azure.microsoft.com/free/)开始使用。

你需要先部署一个 Azure OpenAI 实例。你可以按照[这份指南](https://learn.microsoft.com/azure/ai-services/openai/how-to/create-resource?pivots=web-portal)，在 Azure Portal 中部署。

实例运行后，请确认你已经拿到实例名称和 key。你可以在 Azure Portal 中该实例的 "Keys and Endpoint" 区域找到 key。

如果你使用的是 Node.js，可以定义以下环境变量来使用该服务：

```bash
AZURE_OPENAI_API_INSTANCE_NAME=<YOUR_INSTANCE_NAME>
AZURE_OPENAI_API_DEPLOYMENT_NAME=<YOUR_DEPLOYMENT_NAME>
AZURE_OPENAI_API_EMBEDDINGS_DEPLOYMENT_NAME=<YOUR_EMBEDDINGS_DEPLOYMENT_NAME>
AZURE_OPENAI_API_KEY=<YOUR_KEY>
AZURE_OPENAI_API_VERSION="2024-02-01"
```

<Info>
**支持的 API 版本列表可在 [Azure OpenAI documentation](https://learn.microsoft.com/azure/ai-services/openai/reference) 中找到。**


</Info>

<Tip>
LangChain 包的通用安装说明，请参阅[这一节](/oss/langchain/install)。
</Tip>

```bash npm
npm install @langchain/openai @langchain/core
```
请参阅[用法示例](/oss/integrations/llms/azure)。

```typescript

const model = new AzureOpenAI({
  azureOpenAIApiKey: "<your_key>", // In Node.js defaults to process.env.AZURE_OPENAI_API_KEY
  azureOpenAIApiInstanceName: "<your_instance_name>", // In Node.js defaults to process.env.AZURE_OPENAI_API_INSTANCE_NAME
  azureOpenAIApiDeploymentName: "<your_deployment_name>", // In Node.js defaults to process.env.AZURE_OPENAI_API_DEPLOYMENT_NAME
  azureOpenAIApiVersion: "<api_version>", // In Node.js defaults to process.env.AZURE_OPENAI_API_VERSION
});
```

## 向量存储

### Azure cosmos DB for NoSQL

> [Azure Cosmos DB for NoSQL](https://learn.microsoft.com/azure/cosmos-db/nosql/) 支持对具备灵活 schema 的条目进行查询，并原生支持 JSON。它现在还提供向量索引和搜索。这个特性专为处理高维向量而设计，能够在任意规模下高效、准确地进行向量搜索。现在你可以将向量与数据一起直接存储在文档中。数据库中的每个文档除了传统的无 schema 数据之外，还可以包含高维向量，作为文档的其他属性。

```bash npm
npm install @langchain/azure-cosmosdb @langchain/core
```
请参阅[用法示例](/oss/integrations/vectorstores/azure_cosmosdb_nosql)。

```typescript
import { AzureCosmosDBNoSQLVectorStore } from "@langchain/azure-cosmosdb";
```
### Azure DocumentDB

> [Azure DocumentDB](https://learn.microsoft.com/azure/documentdb/)，前身为 Azure Cosmos DB for MongoDB vCore，可轻松创建完整原生支持 MongoDB 的数据库。你可以沿用既有的 MongoDB 经验，只需把应用指向连接字符串，就能继续使用喜欢的 MongoDB drivers、SDKs 和 tools。通过在 Azure DocumentDB 中使用 vector search，你可以把基于 AI 的应用与存储在 Azure DocumentDB 中的数据无缝集成起来。

```bash npm
npm install @langchain/azure-cosmosdb @langchain/core
```
请参阅[用法示例](/oss/integrations/vectorstores/azure_documentdb)。

```typescript
import { AzureDocumentDBVectorStore } from "@langchain/azure-cosmosdb";
```
## 语义缓存

### Azure cosmos DB NoSQL Semantic cache

> Azure Cosmos DB for NoSQL 集成支持 Semantic Cache 特性，使用户能够基于用户输入与先前缓存结果之间的语义相似度来获取缓存响应。它依赖 [AzureCosmosDBNoSQLVectorStore](/oss/integrations/vectorstores/azure_cosmosdb_nosql) 来存储缓存 prompts 的向量嵌入。这些 embeddings 支持基于相似度的搜索，使系统能够检索到相关的缓存结果。

```bash npm
npm install @langchain/azure-cosmosdb @langchain/core
```
请参阅[用法示例](/oss/integrations/llm_caching/azure_cosmosdb_nosql)。

```typescript
import { AzureCosmosDBNoSQLSemanticCache } from "@langchain/azure-cosmosdb";
```
