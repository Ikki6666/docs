[Sourcey](https://sourcey.com) 用于构建静态文档站点。

使用 `langchain-sourcey` 可以从已发布的 Sourcey 文档站点中进行检索。它会读取 `search-index.json`，在存在时使用 `llms-full.txt`，并返回规范页面 URL 以便引用。

## 安装与设置

安装 `langchain-sourcey`：

<CodeGroup>
```bash npm
npm install langchain-sourcey @langchain/core
```
```bash yarn
yarn add langchain-sourcey @langchain/core
```
```bash pnpm
pnpm add langchain-sourcey @langchain/core
```
</CodeGroup>

不需要 API key。

将 retriever 指向已发布的 Sourcey 文档构建根目录。它会读取 `search-index.json` 以获取候选页面，并在该文件存在时读取 `llms-full.txt` 以获取整页内容。

## Retriever

你可以在标准检索流水线中使用 [`SourceyRetriever`](/oss/integrations/retrievers/sourcey)。

```typescript
import { SourceyRetriever } from "langchain-sourcey";
```

请参阅[用法示例](/oss/integrations/retrievers/sourcey)或 [Sourcey guide](https://sourcey.com/docs/guides/guide-langchain-retriever)。
