>[Perplexity](https://www.perplexity.ai/pro) 是一种强大的互联网搜索方式，提供无限 Pro Search、升级版 AI 模型、无限文件上传、图像生成和 API credits。

## 安装与设置

为 LangChain JavaScript 安装 Perplexity 集成包：

<CodeGroup>
```bash npm
npm install @langchain/perplexity @langchain/core
```
```bash yarn
yarn add @langchain/perplexity @langchain/core
```
```bash pnpm
pnpm add @langchain/perplexity @langchain/core
```
</CodeGroup>

从 [Perplexity API key dashboard](https://www.perplexity.ai/account/api/keys) 获取你的 API key，并将其设置为 `PERPLEXITY_API_KEY` 环境变量。更多细节请参阅 [Perplexity getting started guide](https://docs.perplexity.ai/docs/getting-started)。

```bash
export PERPLEXITY_API_KEY="your-api-key"
```

## Chat model

请参阅[用法示例](/oss/integrations/chat/perplexity)。

```typescript
import { ChatPerplexity } from "@langchain/perplexity";
```

`ChatPerplexity` 还可以通过传入 `useResponsesApi: true`，或传入 `tools: [{ type: "web_search" }]`，它会自动启用，来调用 [Perplexity Agent API](https://docs.perplexity.ai/api-reference/agent-api)。详情和示例请参阅 chat 页面上的 [Agent API support](/oss/integrations/chat/perplexity#agent-api-support-useresponsesapi)。

## Retriever

你可以使用 [`PerplexitySearchRetriever`](/oss/integrations/retrievers/perplexity_search) 从 [Perplexity Search API](https://docs.perplexity.ai/docs/search/quickstart) 获取网页搜索结果，并将其作为标准检索流水线中的 `Document` 对象。

请参阅[用法示例](/oss/integrations/retrievers/perplexity_search)。

```typescript
import { PerplexitySearchRetriever } from "@langchain/perplexity";
```

## Tools

你可以把 Perplexity 作为 agent tool 使用，让你的 agent 可以访问 Perplexity Search API。

请参阅[用法示例](/oss/integrations/tools/perplexity_search)。

### PerplexitySearchResults

一个查询 Perplexity Search API 并返回 JSON 结果数组的工具，包含 title、URL、snippet、date 和 last updated。

```typescript
import { PerplexitySearchResults } from "@langchain/perplexity";
```

## 组件参考

| Class | Abstraction | Import path | Description |
|-------|-------------|-------------|-------------|
| `ChatPerplexity` | Chat model | `import { ChatPerplexity } from "@langchain/perplexity"` | 对 Perplexity API 的 chat model 封装，用于 grounded chat completions。 |
| `PerplexitySearchRetriever` | Retriever | `import { PerplexitySearchRetriever } from "@langchain/perplexity"` | 返回来自 Perplexity Search API 的 `Document` 对象的 retriever。 |
| `PerplexitySearchResults` | Tool | `import { PerplexitySearchResults } from "@langchain/perplexity"` | 为 agents 返回 JSON 数组格式的 Perplexity Search API 结果的工具。 |
