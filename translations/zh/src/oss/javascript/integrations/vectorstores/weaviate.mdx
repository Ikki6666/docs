[Weaviate](https://weaviate.io/) 是一个开源向量数据库，可同时存储对象和向量，因此可以把向量搜索与结构化过滤结合起来。LangChain 通过官方 TypeScript client `weaviate-client` 连接 Weaviate。

本指南快速介绍如何开始使用 Weaviate [vector stores](/oss/integrations/vectorstores)。关于 `WeaviateStore` 全部功能和配置的详细文档，请参阅 [API reference](https://reference.langchain.com/javascript/langchain-weaviate/WeaviateStore)。

## 设置

要使用 Weaviate vector stores，请先准备一个 Weaviate 实例，并安装 `@langchain/weaviate`、`@langchain/core` 和 `weaviate-client`。

本指南以 [OpenAI embeddings](/oss/integrations/embeddings/openai) 为例。你也可以改用[其他受支持的 embeddings models](/oss/integrations/embeddings)。

<CodeGroup>
```bash npm
npm install @langchain/weaviate @langchain/core weaviate-client @langchain/openai
```
```bash yarn
yarn add @langchain/weaviate @langchain/core weaviate-client @langchain/openai
```
```bash pnpm
pnpm add @langchain/weaviate @langchain/core weaviate-client @langchain/openai
```
</CodeGroup>

### 凭据

```typescript
process.env.WEAVIATE_URL = "YOUR_WEAVIATE_URL";
process.env.WEAVIATE_API_KEY = "YOUR_API_KEY";
```

如果你在本指南中使用 OpenAI embeddings，还需要设置：

```typescript
process.env.OPENAI_API_KEY = "YOUR_API_KEY";
```

## 实例化

### 连接 weaviate client

```typescript
import { WeaviateStore } from "@langchain/weaviate";
import { OpenAIEmbeddings } from "@langchain/openai";
import weaviate, {
  dataType,
  Filters,
  generativeParameters,
  vectorizer,
} from "weaviate-client";

const embeddings = new OpenAIEmbeddings({
  model: "text-embedding-3-small",
});

const weaviateClient = await weaviate.connectToWeaviateCloud(
  process.env.WEAVIATE_URL!,
  {
    authCredentials: new weaviate.ApiKey(process.env.WEAVIATE_API_KEY || ""),
    headers: {
      "X-OpenAI-Api-Key": process.env.OPENAI_API_KEY || "",
    },
  },
);
```

### 初始化 vectorStore

```typescript
let vectorStore = new WeaviateStore(embeddings, {
  client: weaviateClient,
  indexName: "Langchainjs_test",
});
```

你也可以通过 `schema` 属性启用 named vectors、vectorizers、reranker、generative-models 等能力。

## 管理 vector store

### 添加内容

**注意**：如果你想给已索引文档绑定 ids，这些 ids 必须是 UUID。

```typescript
import type { Document } from "@langchain/core/documents";

const documents = [
  { pageContent: "The powerhouse of the cell is the mitochondria", metadata: { source: "https://example.com" } },
  { pageContent: "Buildings are made out of brick", metadata: { source: "https://example.com" } },
];
const uuids = [crypto.randomUUID(), crypto.randomUUID()];

await vectorStore.addDocuments(documents, { ids: uuids });
```

### 删除内容

```typescript
await vectorStore.delete({ ids: [uuids[1]] });
```

## 查询 vector store

### 直接查询

```typescript
const collection = weaviateClient.collections.use("Langchainjs_test");
const filter = Filters.and(collection.filter.byProperty("source").equal("https://example.com"))
const similaritySearchResults = await vectorStore.similaritySearch("biology", 2, filter);
```

### 返回分数

```typescript
const similaritySearchWithScoreResults =
  await vectorStore.similaritySearchWithScore("biology", 2, filter);
```

### 混合搜索

```typescript
const results = await vectorStore.hybridSearch("biology",
  {
    limit: 1,
    alpha: 0.25,
    targetVector: ["title"],
  });
```

### RAG

```typescript
const results = await vectorStore.generate("hello world",
  {
    singlePrompt: {
      prompt: "Translate this into German: {title}",
    },
    config: generativeParameters.openAI({
      model: "gpt-3.5-turbo",
    }),
  },
  {
    limit: 2,
    targetVector: ["title"],
  }
);
```

### 转成 retriever 后查询

```typescript
const retriever = vectorStore.asRetriever({
  filter: filter,
  k: 2,
});
await retriever.invoke("biology");
```
