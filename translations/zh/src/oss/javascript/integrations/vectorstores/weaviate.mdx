[Weaviate](https://weaviate.io/) 是一个开源向量数据库，可同时存储对象和向量，因此可以把向量搜索与结构化过滤结合起来。LangChain 通过官方 TypeScript client `weaviate-client` 连接 Weaviate。

本指南快速介绍如何开始使用 Weaviate [vector stores](/oss/integrations/vectorstores)。关于 `WeaviateStore` 全部功能和配置的详细文档，请参阅 [API reference](https://reference.langchain.com/javascript/langchain-weaviate/WeaviateStore)。

## 设置

要使用 Weaviate vector stores，请先准备一个 Weaviate 实例，并安装 `@langchain/weaviate`、`@langchain/core` 和 `weaviate-client`，以连接到你的部署。

本指南以 [OpenAI embeddings](/oss/integrations/embeddings/openai) 为例。你也可以改用[其他受支持的 embeddings models](/oss/integrations/embeddings)。

<CodeGroup>
```bash npm
npm install @langchain/weaviate @langchain/core weaviate-client @langchain/openai
```
```bash yarn
yarn add @langchain/weaviate @langchain/core weaviate-client @langchain/openai
```
```bash pnpm
pnpm add @langchain/weaviate @langchain/core weaviate-client @langchain/openai
```
</CodeGroup>

你可以在本地或服务器上运行 Weaviate。更多信息请参阅 [Weaviate 文档](https://weaviate.io/developers/weaviate/installation)。

### 凭据

设置以下环境变量：

```typescript
// If running locally, include port e.g. "localhost:8080"
process.env.WEAVIATE_URL = "YOUR_WEAVIATE_URL";
// Optional, for cloud deployments
process.env.WEAVIATE_API_KEY = "YOUR_API_KEY";
```

如果你在本指南中使用 OpenAI embeddings，还需要设置 OpenAI key：

```typescript
process.env.OPENAI_API_KEY = "YOUR_API_KEY";
```

如果你希望自动追踪模型调用，还可以通过取消注释下面的内容来设置 [LangSmith](/langsmith/observability) API key：

```typescript
// process.env.LANGSMITH_TRACING="true"
// process.env.LANGSMITH_API_KEY="your-api-key"
```

## 实例化

### 连接 weaviate client

大多数情况下，你应该使用连接辅助函数之一来连接 Weaviate 实例：

- connectToWeaviateCloud
- connectToLocal
- connectToCustom

```typescript
import { WeaviateStore } from "@langchain/weaviate";
import { OpenAIEmbeddings } from "@langchain/openai";
import weaviate, {
  dataType,
  Filters,
  generativeParameters,
  vectorizer,
} from "weaviate-client";

const embeddings = new OpenAIEmbeddings({
  model: "text-embedding-3-small",
});

const weaviateClient = await weaviate.connectToWeaviateCloud(
  process.env.WEAVIATE_URL!,
  {
    authCredentials: new weaviate.ApiKey(process.env.WEAVIATE_API_KEY || ""),
    headers: {
      "X-OpenAI-Api-Key": process.env.OPENAI_API_KEY || "",
      "X-Cohere-Api-Key": process.env.COHERE_API_KEY || "",
    },
  },
);
```

### 初始化 vectorStore

要创建 collection，至少需要指定 collection 名称。如果不指定任何 properties，`auto-schema` 会自动创建它们。

```typescript
let vectorStore = new WeaviateStore(embeddings, {
  client: weaviateClient,
  indexName: "Langchainjs_test",
});
```

要使用 Weaviate 的 named vectors、vectorizers、reranker、generative-models 等能力，请在启用 vector store 时使用 `schema` 属性。创建 vector store 时，`schema` 中的 collection 名称和其他属性将优先。

```typescript
vectorStore = new WeaviateStore(embeddings, {
  client: weaviateClient,
  schema: {
    name: "Langchainjs_test",
    description: "A simple dataset",
    properties: [
      {
        name: "title",
        dataType: dataType.TEXT,
      },
      {
        name: "foo",
        dataType: dataType.TEXT,
      },
    ],
    vectorizers: [
      vectorizer.text2VecOpenAI({
        name: "title",
        sourceProperties: ["title"], // (Optional) Set the source property(ies)
        // vectorIndexConfig: configure.vectorIndex.hnsw()   // (Optional) Set the vector index configuration
      }),
    ],
    generative: weaviate.configure.generative.openAI(),
    reranker: weaviate.configure.reranker.cohere(),
  },
});
```

## 管理 vector store

### 向 vector store 添加条目

**注意**：如果你想给已索引文档绑定 ids，这些 ids 必须是 UUID。

```typescript
import type { Document } from "@langchain/core/documents";

const document1: Document = {
  pageContent: "The powerhouse of the cell is the mitochondria",
  metadata: { source: "https://example.com" }
};

const document2: Document = {
  pageContent: "Buildings are made out of brick",
  metadata: { source: "https://example.com" }
};

const document3: Document = {
  pageContent: "Mitochondria are made out of lipids",
  metadata: { source: "https://example.com" }
};

const document4: Document = {
  pageContent: "The 2024 Olympics are in Paris",
  metadata: { source: "https://example.com" }
}

const documents = [document1, document2, document3, document4];
const uuids = [crypto.randomUUID(), crypto.randomUUID(), crypto.randomUUID(), crypto.randomUUID()];

await vectorStore.addDocuments(documents, { ids: uuids });
```

```text
[
  '610f9b92-9bee-473f-a4db-8f2ca6e3442d',
  '995160fa-441e-41a0-b476-cf3785518a0d',
  '0cdbe6d4-0df8-4f99-9b67-184009fee9a2',
  '18a8211c-0649-467b-a7c5-50ebb4b9ca9d'
]
```

### 从 vector store 删除条目

你可以按 ID 删除，也可以传入 `filter` 参数：

```typescript
await vectorStore.delete({ ids: [uuids[3]] });
```

## 查询 vector store

创建 vector store 并添加相关文档后，你很可能希望在运行 chain 或 agent 时查询它。
在 weaviate 的 v3 中，client 通过 `collections` 与数据库中的对象交互，这是主要方式。`collection` 对象可以在整个代码库中复用。

### 直接查询

执行简单的相似性搜索如下。`Filter` 辅助类让带条件的 filter 更易使用。v3 client 简化了 `Filter` 的用法，使代码更简洁。

关于 Weaviate filter 语法的更多内容，请参阅[此页面](https://weaviate.io/developers/weaviate/api/graphql/filters)。

```typescript
const collection = weaviateClient.collections.use("Langchainjs_test");

const filter = Filters.and(collection.filter.byProperty("source").equal("https://example.com"))

const similaritySearchResults = await vectorStore.similaritySearch("biology", 2, filter);

for (const doc of similaritySearchResults) {
  console.log(`* ${doc.pageContent} [${JSON.stringify(doc.metadata, null)}]`);
}
```

```text
* The powerhouse of the cell is the mitochondria [{"source":"https://example.com"}]
* Mitochondria are made out of lipids [{"source":"https://example.com"}]
```

如果你想执行相似性搜索并获取相应的分数，可以运行：

```typescript
const similaritySearchWithScoreResults = await vectorStore.similaritySearchWithScore("biology", 2, filter)

for (const [doc, score] of similaritySearchWithScoreResults) {
  console.log(`* [SIM=${score.toFixed(3)}] ${doc.pageContent} [${JSON.stringify(doc.metadata)}]`);
}
```

```text
* [SIM=0.835] The powerhouse of the cell is the mitochondria [{"source":"https://example.com"}]
* [SIM=0.852] Mitochondria are made out of lipids [{"source":"https://example.com"}]
```

### 混合搜索

在 Weaviate 中，`Hybrid search` 会融合向量搜索和关键词（BM25F）搜索的两个结果集。要调整关键词和向量分量的相对权重，请在查询中设置 `alpha` 值。

完整混合搜索选项列表请查看 **[文档](https://weaviate.io/developers/weaviate/search/hybrid)**。

```typescript
const results = await vectorStore.hybridSearch("biology",
  {
    limit: 1,
    alpha: 0.25,
    targetVector: ["title"],
    rerank: {
      property: "title",
      query: "greeting",
    },
});
```

### 检索增强生成（RAG）

检索增强生成（RAG）将信息检索与生成式 AI 模型结合起来。

在 Weaviate 中，RAG 查询由两部分组成：搜索查询和给模型的 prompt。Weaviate 先执行搜索，然后将搜索结果和你的 prompt 一起传给生成式 AI 模型，再返回生成的响应。

- @param query 要搜索的查询。
- @param options 执行混合搜索的可用选项
- @param generate 生成时可用的选项。完整列表请参阅文档

```typescript
const results = await vectorStore.generate("hello world",
    {
        singlePrompt: {
            prompt: "Translate this into German: {title}",
        },
        config: generativeParameters.openAI({
            model: "gpt-5.4-mini",
        }),
    },
    {
        limit: 2,
        targetVector: ["title"],
    }
);
```

### 转换为 retriever 后查询

你也可以将 vector store 转换为 [retriever](/oss/deepagents/retrieval)，以便在 chain 中更方便地使用。

```typescript
const retriever = vectorStore.asRetriever({
  // Optional filter
  filter: filter,
  k: 2,
});
await retriever.invoke("biology");
```
