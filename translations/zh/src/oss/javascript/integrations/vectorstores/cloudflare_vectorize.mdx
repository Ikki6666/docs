如果你要把项目部署到 Cloudflare worker 中，可以将 [Cloudflare Vectorize](https://developers.cloudflare.com/vectorize/) 与 LangChain.js 一起使用。
这是一个强大且方便的选项，并且直接内建在 Cloudflare 中。

## 设置

<Tip>
**兼容性**

Cloudflare Vectorize 当前处于 open beta，且要求你的 Cloudflare 账户使用付费计划。
</Tip>

在[设置好项目](https://developers.cloudflare.com/vectorize/get-started/intro/#prerequisites)之后，运行下面的 Wrangler 命令创建一个 index：

```bash
$ npx wrangler vectorize create <index_name> --preset @cf/baai/bge-small-en-v1.5
```

你可以在[官方文档](https://developers.cloudflare.com/workers/wrangler/commands/#vectorize)中查看 `vectorize` 命令的完整选项列表。

然后，你需要更新 `wrangler.toml` 文件，加入一个 `[[vectorize]]` 条目：

```toml
[[vectorize]]
binding = "VECTORIZE_INDEX"
index_name = "<index_name>"
```

最后，你需要安装 LangChain 的 Cloudflare 集成包：

<Tip>
请参阅[这一节](/oss/langchain/install)，了解 LangChain 包的通用安装说明。
</Tip>

<CodeGroup>
```bash npm
npm install @langchain/cloudflare @langchain/core
```
```bash yarn
yarn add @langchain/cloudflare @langchain/core
```
```bash pnpm
pnpm add @langchain/cloudflare @langchain/core
```
</CodeGroup>

## 用法

下面是一个 worker 示例，它会根据访问路径向 vectorstore 添加文档、查询内容，或者清空内容。它还使用了 [Cloudflare Workers AI Embeddings](/oss/integrations/embeddings/cloudflare_ai)。

<Note>
如果你在本地运行，请务必用 `npx wrangler dev --remote` 启动 wrangler。
</Note>

```toml
name = "langchain-test"
main = "worker.ts"
compatibility_date = "2024-01-10"

[[vectorize]]
binding = "VECTORIZE_INDEX"
index_name = "langchain-test"

[ai]
binding = "AI"
```

```typescript
// @ts-nocheck

import type {
  VectorizeIndex,
  Fetcher,
  Request,
} from "@cloudflare/workers-types";

import {
  CloudflareVectorizeStore,
  CloudflareWorkersAIEmbeddings,
} from "@langchain/cloudflare";

export interface Env {
  VECTORIZE_INDEX: VectorizeIndex;
  AI: Fetcher;
}

export default {
  async fetch(request: Request, env: Env) {
    const { pathname } = new URL(request.url);
    const embeddings = new CloudflareWorkersAIEmbeddings({
      binding: env.AI,
      model: "@cf/baai/bge-small-en-v1.5",
    });
    const store = new CloudflareVectorizeStore(embeddings, {
      index: env.VECTORIZE_INDEX,
    });
    if (pathname === "/") {
      const results = await store.similaritySearch("hello", 5);
      return Response.json(results);
    } else if (pathname === "/load") {
      // Upsertion by id is supported
      await store.addDocuments(
        [
          {
            pageContent: "hello",
            metadata: {},
          },
          {
            pageContent: "world",
            metadata: {},
          },
          {
            pageContent: "hi",
            metadata: {},
          },
        ],
        { ids: ["id1", "id2", "id3"] }
      );

      return Response.json({ success: true });
    } else if (pathname === "/clear") {
      await store.delete({ ids: ["id1", "id2", "id3"] });
      return Response.json({ success: true });
    }

    return Response.json({ error: "Not Found" }, { status: 404 });
  },
};
```

你也可以传入 `filter` 参数，根据之前加载的 metadata 进行过滤。
所需格式请参阅[官方文档](https://developers.cloudflare.com/vectorize/learning/metadata-filtering/)。
