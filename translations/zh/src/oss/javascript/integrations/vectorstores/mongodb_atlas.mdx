## 设置

要使用 MongoDB Atlas vector stores，你需要先配置 MongoDB Atlas cluster，并安装 `@langchain/mongodb` 集成包。

### 初始 Cluster 配置

要创建 MongoDB Atlas cluster，请访问 [MongoDB Atlas 网站](https://www.mongodb.com/products/platform/atlas-database)，如果还没有账户请先注册。

在提示时创建并命名一个 cluster，然后在 `Database` 下找到它。选择 `Browse Collections`，创建一个空 collection，或基于提供的示例数据创建。

**注意**：用于 manual embedding 模式时，cluster 必须是 MongoDB 7.0 或更高版本。automated embedding 模式要求 [MongoDB 8.2 或更高版本](https://www.mongodb.com/docs/atlas/atlas-vector-search/crud-embeddings/create-embeddings-automatic/?interface=driver&language=nodejs)。

### 创建 Vector Search Index

配置好 cluster 后，请在 collection 上创建 vector search index。你可以通过 [Atlas](https://www.mongodb.com/docs/atlas/atlas-vector-search/tutorials/vector-search-quick-start/)、[Compass](https://www.mongodb.com/docs/compass/indexes/create-vector-search-index/) 或 [MongoDB Shell](https://www.mongodb.com/docs/atlas/atlas-vector-search/tutorials/vector-search-quick-start/?deployment-type=atlas&embedding=byo&interface=mongosh) 完成。索引定义取决于你使用哪种 embedding 模式。

**Manual embedding**（MongoDB 7.0+）：你在客户端生成文档的 embeddings，并将向量存入某个字段。使用以下定义，并调整 `numDimensions` 以匹配你的 embeddings 模型。

```json
{
  "name": "index_name",
  "type": "vectorSearch",
  "definition": {
    "fields": [
      {
        "numDimensions": 1536,
        "path": "embedding",
        "similarity": "euclidean",
        "type": "vector"
      }
    ]
  }
}
```

**Automated embedding**（MongoDB 8.2+）：MongoDB 使用 [Voyage AI 模型](https://www.mongodb.com/products/platform/ai-search-and-retrieval/models)在服务端生成 embeddings。使用 `autoEmbed` 字段类型并指定模型：

```json
{
  "name": "index_name",
  "type": "vectorSearch",
  "definition": {
    "fields": [
      {
        "type": "autoEmbed",
        "modality": "text",
        "path": "textContent",
        "model": "voyage-4"
      }
    ]
  }
}
```

默认情况下，vector store 从名为 `text` 的文本字段读取文本，并在 manual 模式下把向量写入名为 `embedding` 的字段。请设置 `textKey` 和 `embeddingKey` 以匹配你的索引。

```typescript
const vectorStore = new MongoDBAtlasVectorSearch(
  embeddings,                  // omit in auto embedding mode
  {
    collection,
    indexName: "index_name",
    textKey: "textContent",    // document field where raw text is stored
    embeddingKey: "embedding", // matches "path" (omit in auto embedding mode)
  }
);
```

接下来构建索引。

### Embeddings

在 **manual embedding 模式** 下，你需要提供 embeddings 模型并在客户端为文档生成 embeddings。本指南以 [OpenAI embeddings](/oss/integrations/embeddings/openai) 为例。你也可以使用[其他受支持的 embeddings models](/oss/integrations/embeddings)。

在 **automated embedding 模式** 下，MongoDB Atlas 会在服务端处理 embedding 生成，不需要客户端 embeddings 包。

### 凭据

完成上述操作后，请从 Mongo 仪表盘的 `Connect` 按钮获取连接信息并设置 `MONGODB_ATLAS_URI` 环境变量。你还需要 DB 名和 collection 名：

```typescript
process.env.MONGODB_ATLAS_URI = "your-atlas-URL";
process.env.MONGODB_ATLAS_COLLECTION_NAME = "your-atlas-collection-name";
process.env.MONGODB_ATLAS_DB_NAME = "your-atlas-db-name";
```

如果你使用 manual embedding 模式并搭配 OpenAI，还需要设置 OpenAI key：

```typescript
process.env.OPENAI_API_KEY = "YOUR_API_KEY";
```

在 automated embedding 模式下，不需要额外的 API key，MongoDB Atlas 会使用索引中配置的模型处理 embedding 生成。

如果你希望自动追踪模型调用，还可以通过取消注释下面的内容来设置 [LangSmith](/langsmith/observability) API key：

```typescript
// process.env.LANGSMITH_TRACING="true"
// process.env.LANGSMITH_API_KEY="your-api-key"
```

## 实例化

配置好 cluster 和 index 后，就可以初始化 vector store。根据你使用 manual 还是 automated embedding，构造函数接受两种形式。

<Tabs>
  <Tab title="Manual embedding">
    将 embeddings 实例作为第一个参数传入：

    ```typescript
    import { MongoDBAtlasVectorSearch } from "@langchain/mongodb";
    import { OpenAIEmbeddings } from "@langchain/openai";
    import { MongoClient } from "mongodb";

    const client = new MongoClient(process.env.MONGODB_ATLAS_URI!);
    const collection = client
      .db(process.env.MONGODB_ATLAS_DB_NAME)
      .collection(process.env.MONGODB_ATLAS_COLLECTION_NAME);

    const embeddings = new OpenAIEmbeddings({
      model: "text-embedding-3-small",
    });

    const vectorStore = new MongoDBAtlasVectorSearch(embeddings, {
      collection,
      indexName: "vector_index", // Defaults to "default"
      textKey: "text",           // Defaults to "text"
      embeddingKey: "embedding", // Defaults to "embedding"
    });
    ```
  </Tab>
  <Tab title="Automated embedding">
    只传入配置对象（不需要 embeddings 参数）。

    ```typescript
    import { MongoDBAtlasVectorSearch } from "@langchain/mongodb";
    import { MongoClient } from "mongodb";

    const client = new MongoClient(process.env.MONGODB_ATLAS_URI!);
    const collection = client
      .db(process.env.MONGODB_ATLAS_DB_NAME)
      .collection(process.env.MONGODB_ATLAS_COLLECTION_NAME);

    const vectorStore = new MongoDBAtlasVectorSearch({
      collection,
      indexName: "default", // Must match the index name in your Atlas cluster
    });
    ```
  </Tab>
</Tabs>

## 管理 vector store

### 向 vector store 添加条目

现在你可以向 vector store 添加文档了：

```typescript
import type { Document } from "@langchain/core/documents";

const document1: Document = {
  pageContent: "The powerhouse of the cell is the mitochondria",
  metadata: { source: "https://example.com" }
};

const document2: Document = {
  pageContent: "Buildings are made out of brick",
  metadata: { source: "https://example.com" }
};

const document3: Document = {
  pageContent: "Mitochondria are made out of lipids",
  metadata: { source: "https://example.com" }
};

const document4: Document = {
  pageContent: "The 2024 Olympics are in Paris",
  metadata: { source: "https://example.com" }
}

const documents = [document1, document2, document3, document4];

await vectorStore.addDocuments(documents, { ids: ["1", "2", "3", "4"] });
```

<Note>
添加文档后，需要等待一段时间它们才可被查询。在 automated embedding 模式下，这个延迟更长，因为 MongoDB 必须在插入后在服务端生成 embeddings。请等待 Atlas search index 报告文档已完成索引后再查询。
</Note>

添加与现有文档 `id` 相同的文档会更新现有文档。

### 从 vector store 删除条目

```typescript
await vectorStore.delete({ ids: ["4"] });
```

## 查询 vector store

创建 vector store 并添加相关文档后，你很可能希望在运行 chain 或 agent 时查询它。

### 直接查询

执行简单的相似性搜索如下：

```typescript
const similaritySearchResults = await vectorStore.similaritySearch("biology", 2);

for (const doc of similaritySearchResults) {
  console.log(`* ${doc.pageContent} [${JSON.stringify(doc.metadata, null)}]`);
}
```

```text
* The powerhouse of the cell is the mitochondria [{"_id":"1","source":"https://example.com"}]
* Mitochondria are made out of lipids [{"_id":"3","source":"https://example.com"}]
```

### 过滤

MongoDB Atlas 支持基于其他字段对结果进行预过滤。你需要在最初创建的索引中声明计划用于过滤的 metadata 字段。示例如下：

```json
{
  "fields": [
    {
      "numDimensions": 1024,
      "path": "embedding",
      "similarity": "euclidean",
      "type": "vector"
    },
    {
      "path": "source",
      "type": "filter"
    }
  ]
}
```

上面的 `fields` 中，第一项是向量索引，第二项是你要过滤的 metadata 属性。属性名称就是 `path` 键的值。因此，上述索引允许我们搜索名为 `source` 的 metadata 字段。

然后在代码中，你可以使用 [MQL Query Operators](https://www.mongodb.com/docs/manual/reference/mql/query-predicates/#alphabetical-list-of-operators) 进行过滤。

下面的示例演示了这一点：

```typescript
const filter = {
  preFilter: {
    source: {
      $eq: "https://example.com",
    },
  },
}

const filteredResults = await vectorStore.similaritySearch("biology", 2, filter);

for (const doc of filteredResults) {
  console.log(`* ${doc.pageContent} [${JSON.stringify(doc.metadata, null)}]`);
}
```

```text
* The powerhouse of the cell is the mitochondria [{"_id":"1","source":"https://example.com"}]
* Mitochondria are made out of lipids [{"_id":"3","source":"https://example.com"}]
```

### 返回分数

如果你想执行相似性搜索并获取相应的分数，可以运行：

```typescript
const similaritySearchWithScoreResults = await vectorStore.similaritySearchWithScore("biology", 2, filter)

for (const [doc, score] of similaritySearchWithScoreResults) {
  console.log(`* [SIM=${score.toFixed(3)}] ${doc.pageContent} [${JSON.stringify(doc.metadata)}]`);
}
```

```text
* [SIM=0.374] The powerhouse of the cell is the mitochondria [{"_id":"1","source":"https://example.com"}]
* [SIM=0.370] Mitochondria are made out of lipids [{"_id":"3","source":"https://example.com"}]
```

### 转换为 retriever 后查询

你也可以将 vector store 转换为 [retriever](/oss/deepagents/retrieval)，以便在 chain 中更方便地使用。

```typescript
const retriever = vectorStore.asRetriever({
  // Optional filter
  filter: filter,
  k: 2,
});
await retriever.invoke("biology");
```

```javascript
[
  Document {
    pageContent: 'The powerhouse of the cell is the mitochondria',
    metadata: { _id: '1', source: 'https://example.com' },
    id: undefined
  },
  Document {
    pageContent: 'Mitochondria are made out of lipids',
    metadata: { _id: '3', source: 'https://example.com' },
    id: undefined
  }
]
```
