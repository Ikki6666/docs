<Tip>
**兼容性**：仅支持 Node.js。
</Tip>

要在通用 PostgreSQL 数据库中启用向量搜索，LangChain.js 支持使用 [`pgvector`](https://github.com/pgvector/pgvector) Postgres 扩展。

本指南快速介绍如何开始使用 PGVector [vector stores](/oss/integrations/vectorstores)。关于 `PGVectorStore` 全部功能和配置的详细文档，请参阅 [API reference](https://reference.langchain.com/javascript/langchain-pgvector/PGVectorStore)。

## PGVectorStore vs PGVector

LangChain 有两个 Postgres vector store 集成：

| Feature | PGVector (Legacy) | PGVectorStore (Modern) |
|---|---|---|
| Package | `langchain-community` | `langchain-postgres` (Python) / `@langchain/pgvector` (JS) |
| Maintenance | 社区维护 | 官方 Partner Package |
| Connection | 简单 connection string | `PGEngine`，连接池更好 |
| Search Types | 标准向量搜索 | 混合搜索，向量 + BM25 |
| Async Support | 有限 | 完整原生 async |
| Schema | 固定表结构 | 可自定义列和 schema |

**推荐使用 `PGVectorStore`，即现代版，当你：**
- 正在开始新项目
- 需要混合搜索
- 希望通过连接池获得更好性能
- 正在构建 async 应用

**仅在以下情况下使用 `PGVector`，即旧版：**
- 正在维护已使用它的旧代码库
- 正在跟随尚未更新的旧教程

<Note>
对于所有新项目，建议使用 `langchain-postgres`，Python，或 `@langchain/pgvector`，JS，中的 `PGVectorStore`。
</Note>

## 设置

要使用 PGVector vector stores，请先准备一个启用了 [`pgvector`](https://github.com/pgvector/pgvector) 扩展的 Postgres 实例，然后安装 `@langchain/pgvector`、[`pg`](https://www.npmjs.com/package/pg) 和 `@langchain/core`。

本指南以 [OpenAI embeddings](/oss/integrations/embeddings/openai) 为例。你也可以改用[其他受支持的 embeddings models](/oss/integrations/embeddings)。

<CodeGroup>
```bash npm
npm install @langchain/pgvector @langchain/openai @langchain/core pg
```
```bash yarn
yarn add @langchain/pgvector @langchain/openai @langchain/core pg
```
```bash pnpm
pnpm add @langchain/pgvector @langchain/openai @langchain/core pg
```
</CodeGroup>

### 设置实例

一个本地 Docker 示例：

```yaml
# Run this command to start the database:
# docker compose up
services:
  db:
    hostname: 127.0.0.1
    image: pgvector/pgvector:pg16
    ports:
      - 5432:5432
    restart: always
    environment:
      - POSTGRES_DB=api
      - POSTGRES_USER=myuser
      - POSTGRES_PASSWORD=ChangeMe
```

### 凭据

如果你在本指南中使用 OpenAI embeddings，还需要设置：

```typescript
process.env.OPENAI_API_KEY = "YOUR_API_KEY";
```

## 实例化

调用 `.initialize()` 静态方法即可实例化 vector store。若 `tableName` 对应表不存在，它会自动创建。

<Warning>
**安全性**：不要把用户名之类的用户输入作为表名或列名。
**这可能导致 SQL 注入。**
</Warning>

```typescript
import { PGVectorStore } from "@langchain/pgvector";
import type { DistanceStrategy } from "@langchain/pgvector";
import { OpenAIEmbeddings } from "@langchain/openai";
import type { PoolConfig } from "pg";

const embeddings = new OpenAIEmbeddings({
  model: "text-embedding-3-small",
});

const config = {
  postgresConnectionOptions: {
    type: "postgres",
    host: "127.0.0.1",
    port: 5433,
    user: "myuser",
    password: "ChangeMe",
    database: "api",
  } as PoolConfig,
  tableName: "testlangchainjs",
  columns: {
    idColumnName: "id",
    vectorColumnName: "vector",
    contentColumnName: "content",
    metadataColumnName: "metadata",
  },
  distanceStrategy: "cosine" as DistanceStrategy,
};

const vectorStore = await PGVectorStore.initialize(embeddings, config);
```

## 管理 vector store

### 添加内容

```typescript
import type { Document } from "@langchain/core/documents";

const documents = [
  { pageContent: "The powerhouse of the cell is the mitochondria", metadata: { source: "https://example.com" } },
  { pageContent: "Buildings are made out of brick", metadata: { source: "https://example.com" } },
  { pageContent: "Mitochondria are made out of lipids", metadata: { source: "https://example.com" } },
  { pageContent: "The 2024 Olympics are in Paris", metadata: { source: "https://example.com" } },
];

const ids = [crypto.randomUUID(), crypto.randomUUID(), crypto.randomUUID(), crypto.randomUUID()];

await vectorStore.addDocuments(documents, { ids });
```

### 删除内容

```typescript
const id4 = ids[ids.length - 1];
await vectorStore.delete({ ids: [id4] });
```

## 查询 vector store

### 直接查询

```typescript
const filter = { source: "https://example.com" };
const similaritySearchResults = await vectorStore.similaritySearch("biology", 2, filter);
```

这个 filter 语法支持精确匹配，也支持：

#### `in` 操作符

```json
{
  "field": {
    "in": ["value1", "value2"]
  }
}
```

#### `notIn` 操作符

```json
{
  "field": {
    "notIn": ["value1", "value2"]
  }
}
```

#### `arrayContains` 操作符

```json
{
  "field": {
    "arrayContains": ["value1", "value2"]
  }
}
```

### 返回分数

```typescript
const similaritySearchWithScoreResults =
  await vectorStore.similaritySearchWithScore("biology", 2, filter);
```

### 转成 retriever 后查询

```typescript
const retriever = vectorStore.asRetriever({
  filter: filter,
  k: 2,
});
await retriever.invoke("biology");
```

## 高级：复用连接

你可以通过创建连接池来复用连接，然后直接通过构造函数创建新的 `PGVectorStore` 实例。

```typescript
import { OpenAIEmbeddings } from "@langchain/openai";
import { PGVectorStore } from "@langchain/pgvector";
import pg from "pg";

const reusablePool = new pg.Pool({
  host: "127.0.0.1",
  port: 5433,
  user: "myuser",
  password: "ChangeMe",
  database: "api",
});
```
