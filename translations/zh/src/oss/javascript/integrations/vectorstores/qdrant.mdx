[Qdrant](https://qdrant.tech/) 是一个向量相似度搜索引擎。它提供了一个适合生产环境的服务，以及便于存储、搜索和管理 points，带附加 payload 的向量，的 API。

本指南快速介绍如何开始使用 Qdrant [vector stores](/oss/integrations/vectorstores)。关于 `QdrantVectorStore` 全部功能和配置的详细文档，请参阅 [API reference](https://reference.langchain.com/javascript/langchain-qdrant/QdrantVectorStore)。

## 设置

要使用 Qdrant vector stores，请先准备一个 Qdrant 实例，并安装 `@langchain/qdrant` 和 `@langchain/core`。`@langchain/qdrant` 包已内置 Qdrant REST client，`@qdrant/js-client-rest`。

本指南以 [OpenAI embeddings](/oss/integrations/embeddings/openai) 为例。你也可以改用[其他受支持的 embeddings models](/oss/integrations/embeddings)。

<CodeGroup>
```bash npm
npm install @langchain/qdrant @langchain/core @langchain/openai
```
```bash yarn
yarn add @langchain/qdrant @langchain/core @langchain/openai
```
```bash pnpm
pnpm add @langchain/qdrant @langchain/core @langchain/openai
```
</CodeGroup>

按 [Qdrant setup instructions](https://qdrant.tech/documentation/quickstart/) 在本机通过 Docker 运行一个 Qdrant 实例，并记下 URL。

### 凭据

设置 `QDRANT_URL` 环境变量：

```typescript
process.env.QDRANT_URL = "your-qdrant-url"
```

如果你在本指南中使用 OpenAI embeddings，还需要设置：

```typescript
process.env.OPENAI_API_KEY = "YOUR_API_KEY";
```

## 实例化

```typescript
import { QdrantVectorStore } from "@langchain/qdrant";
import { OpenAIEmbeddings } from "@langchain/openai";

const embeddings = new OpenAIEmbeddings({
  model: "text-embedding-3-small",
});

const vectorStore = await QdrantVectorStore.fromExistingCollection(embeddings, {
  url: process.env.QDRANT_URL,
  collectionName: "langchainjs-testing",
});
```

## 管理 vector store

### 添加内容

```typescript
import type { Document } from "@langchain/core/documents";

const documents = [
  { pageContent: "The powerhouse of the cell is the mitochondria", metadata: { source: "https://example.com" } },
  { pageContent: "Buildings are made out of brick", metadata: { source: "https://example.com" } },
  { pageContent: "Mitochondria are made out of lipids", metadata: { source: "https://example.com" } },
  { pageContent: "The 2024 Olympics are in Paris", metadata: { source: "https://example.com" } },
];

await vectorStore.addDocuments(documents);
```

当前还不支持顶层 document ids 和删除操作。

## 查询 vector store

### 直接查询

```typescript
const filter = {
  "must": [
      { "key": "metadata.source", "match": { "value": "https://example.com" } },
  ]
};

const similaritySearchResults = await vectorStore.similaritySearch("biology", 2, filter);
```

更多关于 Qdrant filter 语法的说明，请参阅[这一页](https://qdrant.tech/documentation/concepts/filtering/)。注意，所有值都必须加上 `metadata.` 前缀。

### 返回分数

```typescript
const similaritySearchWithScoreResults =
  await vectorStore.similaritySearchWithScore("biology", 2, filter);
```

### 转成 retriever 后查询

```typescript
const retriever = vectorStore.asRetriever({
  filter: filter,
  k: 2,
});
await retriever.invoke("biology");
```
