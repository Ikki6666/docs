[Qdrant](https://qdrant.tech/) 是一个向量相似度搜索引擎。它提供了一个适合生产环境的服务，以及便于存储、搜索和管理 points（带附加 payload 的向量）的 API。

本指南快速介绍如何开始使用 Qdrant [vector stores](/oss/integrations/vectorstores)。关于 `QdrantVectorStore` 全部功能和配置的详细文档，请参阅 [API reference](https://reference.langchain.com/javascript/langchain-qdrant/QdrantVectorStore)。

## 设置

要使用 Qdrant vector stores，请先准备一个 Qdrant 实例，并安装 `@langchain/qdrant` 和 `@langchain/core`。`@langchain/qdrant` 包已内置 Qdrant REST client（`@qdrant/js-client-rest`）。

本指南以 [OpenAI embeddings](/oss/integrations/embeddings/openai) 为例。你也可以改用[其他受支持的 embeddings models](/oss/integrations/embeddings)。

<CodeGroup>
```bash npm
npm install @langchain/qdrant @langchain/core @langchain/openai
```
```bash yarn
yarn add @langchain/qdrant @langchain/core @langchain/openai
```
```bash pnpm
pnpm add @langchain/qdrant @langchain/core @langchain/openai
```
</CodeGroup>

安装所需依赖后，请按照 [Qdrant 设置说明](https://qdrant.tech/documentation/quickstart/) 在本机通过 Docker 运行一个 Qdrant 实例，并记下容器运行的 URL。

### 凭据

设置 `QDRANT_URL` 环境变量：

```typescript
// e.g. http://localhost:6333
process.env.QDRANT_URL = "your-qdrant-url"
```

如果你在本指南中使用 OpenAI embeddings，还需要设置 OpenAI key：

```typescript
process.env.OPENAI_API_KEY = "YOUR_API_KEY";
```

如果你希望自动追踪模型调用，还可以通过取消注释下面的内容来设置 [LangSmith](/langsmith/observability) API key：

```typescript
// process.env.LANGSMITH_TRACING="true"
// process.env.LANGSMITH_API_KEY="your-api-key"
```

## 实例化

```typescript
import { QdrantVectorStore } from "@langchain/qdrant";
import { OpenAIEmbeddings } from "@langchain/openai";

const embeddings = new OpenAIEmbeddings({
  model: "text-embedding-3-small",
});

const vectorStore = await QdrantVectorStore.fromExistingCollection(embeddings, {
  url: process.env.QDRANT_URL,
  collectionName: "langchainjs-testing",
});
```

## 管理 vector store

### 向 vector store 添加条目

```typescript
import type { Document } from "@langchain/core/documents";

const document1: Document = {
  pageContent: "The powerhouse of the cell is the mitochondria",
  metadata: { source: "https://example.com" }
};

const document2: Document = {
  pageContent: "Buildings are made out of brick",
  metadata: { source: "https://example.com" }
};

const document3: Document = {
  pageContent: "Mitochondria are made out of lipids",
  metadata: { source: "https://example.com" }
};

const document4: Document = {
  pageContent: "The 2024 Olympics are in Paris",
  metadata: { source: "https://example.com" }
}

const documents = [document1, document2, document3, document4];

await vectorStore.addDocuments(documents);
```

当前还不支持顶层 document ids 和删除操作。

## 查询 vector store

创建 vector store 并添加相关文档后，你很可能希望在运行 chain 或 agent 时查询它。

### 直接查询

执行简单的相似性搜索如下：

```typescript
const filter = {
  "must": [
      { "key": "metadata.source", "match": { "value": "https://example.com" } },
  ]
};

const similaritySearchResults = await vectorStore.similaritySearch("biology", 2, filter);

for (const doc of similaritySearchResults) {
  console.log(`* ${doc.pageContent} [${JSON.stringify(doc.metadata, null)}]`);
}
```

```text
* The powerhouse of the cell is the mitochondria [{"source":"https://example.com"}]
* Mitochondria are made out of lipids [{"source":"https://example.com"}]
```

更多关于 Qdrant filter 语法的说明，请参阅[这一页](https://qdrant.tech/documentation/concepts/filtering/)。注意，所有值都必须加上 `metadata.` 前缀。

如果你想执行相似性搜索并获取相应的分数，可以运行：

```typescript
const similaritySearchWithScoreResults = await vectorStore.similaritySearchWithScore("biology", 2, filter)

for (const [doc, score] of similaritySearchWithScoreResults) {
  console.log(`* [SIM=${score.toFixed(3)}] ${doc.pageContent} [${JSON.stringify(doc.metadata)}]`);
}
```

```text
* [SIM=0.165] The powerhouse of the cell is the mitochondria [{"source":"https://example.com"}]
* [SIM=0.148] Mitochondria are made out of lipids [{"source":"https://example.com"}]
```

### 转换为 retriever 后查询

你也可以将 vector store 转换为 [retriever](/oss/deepagents/retrieval)，以便在 chain 中更方便地使用。

```typescript
const retriever = vectorStore.asRetriever({
  // Optional filter
  filter: filter,
  k: 2,
});
await retriever.invoke("biology");
```

```javascript
[
  Document {
    pageContent: 'The powerhouse of the cell is the mitochondria',
    metadata: { source: 'https://example.com' },
    id: undefined
  },
  Document {
    pageContent: 'Mitochondria are made out of lipids',
    metadata: { source: 'https://example.com' },
    id: undefined
  }
]
```
