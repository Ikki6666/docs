[Pinecone](https://www.pinecone.io/) 是一个向量数据库，为全球一些优秀公司的 AI 系统提供支持。

本指南快速介绍如何开始使用 Pinecone [vector stores](/oss/integrations/vectorstores)。关于 `PineconeStore` 全部功能和配置的详细文档，请参阅 [API reference](https://reference.langchain.com/javascript/langchain-pinecone/PineconeStore)。

## 设置

要使用 Pinecone vector stores，请创建 Pinecone 账户、初始化一个 index，并安装 `@langchain/pinecone`、`@langchain/core` 和[官方 Pinecone SDK](https://www.npmjs.com/package/@pinecone-database/pinecone)，即 `@pinecone-database/pinecone` v5.x。

本指南以 [OpenAI embeddings](/oss/integrations/embeddings/openai) 为例。你也可以改用[其他受支持的 embeddings models](/oss/integrations/embeddings)。

<CodeGroup>
```bash npm
npm install @langchain/pinecone @langchain/openai @langchain/core @pinecone-database/pinecone@5
```
```bash yarn
yarn add @langchain/pinecone @langchain/openai @langchain/core @pinecone-database/pinecone@5
```
```bash pnpm
pnpm add @langchain/pinecone @langchain/openai @langchain/core @pinecone-database/pinecone@5
```
</CodeGroup>

### 凭据

注册 [Pinecone](https://www.pinecone.io/) 账户并创建一个 index。确保维度与所用 embeddings 一致。完成后设置：

```typescript
process.env.PINECONE_API_KEY = "your-pinecone-api-key";
process.env.PINECONE_INDEX = "your-pinecone-index";

// Optional
process.env.PINECONE_ENVIRONMENT = "your-pinecone-environment";
```

如果你在本指南中使用 OpenAI embeddings，还需要设置：

```typescript
process.env.OPENAI_API_KEY = "YOUR_API_KEY";
```

## 实例化

```typescript
import { PineconeStore } from "@langchain/pinecone";
import { OpenAIEmbeddings } from "@langchain/openai";
import { Pinecone as PineconeClient } from "@pinecone-database/pinecone";

const embeddings = new OpenAIEmbeddings({
  model: "text-embedding-3-small",
});

const pinecone = new PineconeClient();
const pineconeIndex = pinecone.Index(process.env.PINECONE_INDEX!);

const vectorStore = await PineconeStore.fromExistingIndex(embeddings, {
  pineconeIndex,
  maxConcurrency: 5,
});
```

## 管理 vector store

### 添加内容

```typescript
import type { Document } from "@langchain/core/documents";

const documents = [
  { pageContent: "The powerhouse of the cell is the mitochondria", metadata: { source: "https://example.com" } },
  { pageContent: "Buildings are made out of brick", metadata: { source: "https://example.com" } },
  { pageContent: "Mitochondria are made out of lipids", metadata: { source: "https://example.com" } },
  { pageContent: "The 2024 Olympics are in Paris", metadata: { source: "https://example.com" } },
];

await vectorStore.addDocuments(documents, { ids: ["1", "2", "3", "4"] });
```

**注意**：添加文档后，需要等待片刻，文档才会变得可查询。

### 删除内容

```typescript
await vectorStore.delete({ ids: ["4"] });
```

## 查询 vector store

### 直接查询

```typescript
const filter = { source: "https://example.com" };
const similaritySearchResults = await vectorStore.similaritySearch("biology", 2, filter);
```

### 返回分数

```typescript
const similaritySearchWithScoreResults =
  await vectorStore.similaritySearchWithScore("biology", 2, filter);
```

### 转成 retriever 后查询

```typescript
const retriever = vectorStore.asRetriever({
  filter: filter,
  k: 2,
});

await retriever.invoke("biology");
```
