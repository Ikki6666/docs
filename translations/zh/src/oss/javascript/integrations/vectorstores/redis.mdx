[Redis](https://redis.io/) 是一个快速的开源内存数据存储。作为 [Redis Stack](https://redis.io/docs/latest/operate/oss_and_stack/install/install-stack/) 的一部分，[RediSearch](https://redis.io/docs/latest/develop/interact/search-and-query/) 模块负责启用向量相似度语义搜索，以及其他多种搜索能力。

本指南快速介绍如何开始使用 Redis [vector stores](/oss/integrations/vectorstores)。关于 `RedisVectorStore` 全部功能和配置的详细文档，请参阅 [API reference](https://reference.langchain.com/javascript/langchain-redis/RedisVectorStore)。

## 设置

要使用 Redis vector stores，请先准备一个启用了 RediSearch 的 Redis Stack 实例，并安装 `@langchain/redis` 与 `@langchain/core`。如果你要把自己的 `createClient` 实例传给 `RedisVectorStore`，还需要安装 [`redis`](https://www.npmjs.com/package/redis) Node.js client。

本指南以 [OpenAI embeddings](/oss/integrations/embeddings/openai) 为例。你也可以改用[其他受支持的 embeddings models](/oss/integrations/embeddings)。

<CodeGroup>
```bash npm
npm install @langchain/redis @langchain/core redis @langchain/openai
```
```bash yarn
yarn add @langchain/redis @langchain/core redis @langchain/openai
```
```bash pnpm
pnpm add @langchain/redis @langchain/core redis @langchain/openai
```
</CodeGroup>

你可以按[这些说明](https://redis.io/docs/latest/operate/oss_and_stack/install/install-stack/docker/#redisredis-stack)在本地通过 Docker 启动 Redis。

### 凭据

设置 `REDIS_URL` 环境变量：

```typescript
process.env.REDIS_URL = "your-redis-url";
```

如果你在本指南中使用 OpenAI embeddings，还需要设置：

```typescript
process.env.OPENAI_API_KEY = "YOUR_API_KEY";
```

## 实例化

```typescript
import { RedisVectorStore } from "@langchain/redis";
import { OpenAIEmbeddings } from "@langchain/openai";
import { createClient } from "redis";

const embeddings = new OpenAIEmbeddings({
  model: "text-embedding-3-small",
});

const client = createClient({
  url: process.env.REDIS_URL ?? "redis://localhost:6379",
});
await client.connect();

const vectorStore = new RedisVectorStore(embeddings, {
  redisClient: client,
  indexName: "langchainjs-testing",
});
```

## 管理 vector store

### 添加内容

```typescript
import type { Document } from "@langchain/core/documents";

const documents = [
  { pageContent: "The powerhouse of the cell is the mitochondria", metadata: { type: "example" } },
  { pageContent: "Buildings are made out of brick", metadata: { type: "example" } },
  { pageContent: "Mitochondria are made out of lipids", metadata: { type: "example" } },
  { pageContent: "The 2024 Olympics are in Paris", metadata: { type: "example" } },
];

await vectorStore.addDocuments(documents);
```

当前还不支持顶层 document ids，但你可以通过直接提供 IDs 来删除文档。

## 查询 vector store

### 直接查询

```typescript
const similaritySearchResults = await vectorStore.similaritySearch("biology", 2);
```

当前过滤会查找任何 metadata key 中包含给定字符串的项。

### 返回分数

```typescript
const similaritySearchWithScoreResults =
  await vectorStore.similaritySearchWithScore("biology", 2);
```

### 转成 retriever 后查询

```typescript
const retriever = vectorStore.asRetriever({
  k: 2,
});
await retriever.invoke("biology");
```

## 删除文档

### 删除全部文档

```typescript
await vectorStore.delete({ deleteAll: true });
```

### 按 ID 删除指定文档

```typescript
await vectorStore.delete({ ids: ["doc1", "doc2", "doc3"] });
```

## 关闭连接

完成后请关闭 client 连接，避免资源占用：

```typescript
await client.disconnect();
```

## 高级功能

### 自定义 schema 与 metadata 过滤

Redis vector store 支持为 metadata 字段定义自定义 schema，以便实现更高效的过滤与搜索。

```typescript
import { RedisVectorStore } from "@langchain/redis";
import type { RedisVectorStoreConfig } from "@langchain/redis";
import { OpenAIEmbeddings } from "@langchain/openai";
import { SchemaFieldTypes } from "redis";
import { createClient } from "redis";

const embeddings = new OpenAIEmbeddings({
  model: "text-embedding-3-small",
});

const client = createClient({
  url: process.env.REDIS_URL ?? "redis://localhost:6379",
});
await client.connect();

const customSchema:RedisVectorStoreConfig["customSchema"] = {
  userId: {
    type: SchemaFieldTypes.TEXT,
    required: true,
    SORTABLE: true,
  },
};
```

自定义 schema 支持三类主要字段：

- **TEXT**：支持全文搜索
- **TAG**：适合精确匹配的分类字段
- **NUMERIC**：支持范围查询和排序的数值字段
