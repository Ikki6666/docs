[Cloud SQL](https://cloud.google.com/sql) 是一个完全托管的关系型数据库服务，提供高性能、无缝集成和出色的可扩展性，并支持 PostgreSQL 等数据库引擎。

本指南快速介绍如何使用 Cloud SQL for PostgreSQL 配合 `PostgresVectorStore` 类存储向量 embeddings。

## 概览

| :------------------ | :----------------------------------------- | :--------------------------------------------------------------------------------------------: | :------------: |

### 开始前

要使用这个包，你首先需要完成以下步骤：

1. [选择或创建一个 Cloud Platform project。](https://developers.google.com/workspace/guides/create-project)
2. [为你的 project 启用 billing。](https://cloud.google.com/billing/docs/how-to/modify-project#enable_billing_for_a_project)
3. [启用 Cloud SQL Admin API。](https://console.cloud.google.com/flows/enableapi?apiid=sqladmin.googleapis.com)
4. [设置 Authentication。](https://cloud.google.com/docs/authentication)
5. [创建一个 CloudSQL instance](https://cloud.google.com/sql/docs/postgres/connect-instance-auth-proxy#create-instance)
6. [创建一个 CloudSQL database](https://cloud.google.com/sql/docs/postgres/create-manage-databases)
7. [为数据库添加一个 user](https://cloud.google.com/sql/docs/postgres/create-manage-users)

### 身份验证

在本地使用 `gcloud auth login` 命令登录你的 Google Cloud 账户。

### 设置 Google cloud project

设置你的 Google Cloud project ID，以便在本地使用 Google Cloud 资源：

```bash
gcloud config set project YOUR-PROJECT-ID
```

如果你不知道 project ID，可以尝试以下方法：

* 运行 `gcloud config list`。
* 运行 `gcloud projects list`。
* 查看支持页面：[Locate the project ID](https://support.google.com/googleapi/answer/7014113)。

## 设置 PostgresVectorStore 实例

要使用 PostgresVectorStore 库，你需要先安装 `@langchain/google-cloud-sql-pg` 包，然后按照下面的步骤操作。

<CodeGroup>
```bash npm
npm install @langchain/google-cloud-sql-pg @langchain/core
```
```bash yarn
yarn add @langchain/google-cloud-sql-pg @langchain/core
```
```bash pnpm
pnpm add @langchain/google-cloud-sql-pg @langchain/core
```
</CodeGroup>

首先，你需要登录 Google Cloud 账户，并根据自己的 Google Cloud project 设置以下环境变量；这些变量会根据你希望如何配置 `PostgresEngine` 实例，`fromInstance`、`fromEngine`、`fromEngineArgs`，而有所不同：

```bash
PROJECT_ID="your-project-id"
REGION="your-project-region" // example: "us-central1"
INSTANCE_NAME="your-instance"
DB_NAME="your-database-name"
DB_USER="your-database-user"
PASSWORD="your-database-password"
```

### 设置实例

要实例化一个 `PostgresVectorStore`，你首先需要通过 `PostgresEngine` 创建数据库连接，然后初始化 vector store table，最后调用 `.initialize()` 方法来实例化 vector store。

```typescript
import {
  Column,
  PostgresEngine,
  PostgresEngineArgs,
  PostgresVectorStore,
  PostgresVectorStoreArgs,
  VectorStoreTableArgs,
} from "@langchain/google-cloud-sql-pg";
import { SyntheticEmbeddings } from "@langchain/core/utils/testing"; // This is used as an Embedding service
import * as dotenv from "dotenv";

dotenv.config();

const peArgs: PostgresEngineArgs = {
  user: process.env.DB_USER ?? "",
  password: process.env.PASSWORD ?? "",
};

// PostgresEngine instantiation
const engine: PostgresEngine = await PostgresEngine.fromInstance(
  process.env.PROJECT_ID ?? "",
  process.env.REGION ?? "",
  process.env.INSTANCE_NAME ?? "",
  process.env.DB_NAME ?? "",
  peArgs
);

const vectorStoreArgs: VectorStoreTableArgs = {
  metadataColumns: [new Column("page", "TEXT"), new Column("source", "TEXT")],
};

// Vector store table initialization
await engine.initVectorstoreTable("my_vector_store_table", 768, vectorStoreArgs);
const embeddingService = new SyntheticEmbeddings({ vectorSize: 768 });

const pvectorArgs: PostgresVectorStoreArgs = {
  metadataColumns: ["page", "source"],
};

// PostgresVectorStore instantiation
const vectorStore = await PostgresVectorStore.initialize(
  engine,
  embeddingService,
  "my_vector_store_table",
  pvectorArgs
);

```

## 管理 vector store

### 向 vector store 添加文档

要向 vector store 添加 Documents，你可以选择传入 ids，也可以不传：

```typescript
import type { Document } from "@langchain/core/documents";

const document1: Document = {
  pageContent: "The powerhouse of the cell is the mitochondria",
  metadata: { page: 0, source: "https://example.com" },
};

const document2: Document = {
  pageContent: "Buildings are made out of brick",
  metadata: { page: 1, source: "https://example.com" },
};

const document3: Document = {
  pageContent: "Mitochondria are made out of lipids",
  metadata: { page: 2, source: "https://example.com" },
};

const document4: Document = {
  pageContent: "The 2024 Olympics are in Paris",
  metadata: { page: 3, source: "https://example.com" },
};

const documents = [document1, document2, document3, document4];

const ids = [crypto.randomUUID(), crypto.randomUUID(), crypto.randomUUID(), crypto.randomUUID()];

await vectorStore.addDocuments(documents, { ids: ids });

```

### 从 vector store 删除文档

你可以通过传入要删除的 id 数组，从 vector store 中删除一个或多个 Documents：

```typescript
// deleting a document
const id1 = ids[0];
await vectorStore.delete({ ids: [id1] });

// deleting more than one document
await vectorStore.delete({ ids: ids });

```

## 搜索文档

当 vector store 创建完成并加入了相关文档后，你通常会希望在运行 chain 或 agent 时对它进行查询。

### 直接查询

执行简单的相似度搜索可以这样做：

```typescript
const filter = `"source" = "https://example.com"`;

const results = await vectorStore.similaritySearch("biology", 2, filter);

for (const doc of results) {
  console.log(`* ${doc.pageContent} [${JSON.stringify(doc.metadata, null)}]`);
}

```

如果你希望执行相似度搜索并同时获取对应分数，可以这样写：

```typescript
const filter = `"source" = "https://example.com"`;
const resultsWithScores = await vectorStore.similaritySearchWithScore(
  "biology",
  2,
  filter
);

for (const [doc, score] of resultsWithScores) {
  console.log(
    `* [SIM=${score.toFixed(3)}] ${doc.pageContent} [${JSON.stringify(doc.metadata)}]`
  );
}

```

### 使用 max marginal relevance search 查询

Maximal marginal relevance 会同时优化与查询的相似性以及所选文档之间的多样性。

```typescript
const options = {
  k: 4,
  filter: `"source" = 'https://example.com'`,
};

const results = await vectorStore.maxMarginalRelevanceSearch("biology", options);

for (const doc of results) {
  console.log(`* ${doc.pageContent} [${JSON.stringify(doc.metadata, null)}]`);
}

```
