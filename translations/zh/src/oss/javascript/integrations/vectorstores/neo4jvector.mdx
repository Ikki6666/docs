[Neo4j](https://neo4j.com/) 是一个开源图数据库，并集成支持向量相似度搜索。它支持 approximate nearest neighbor search、欧氏距离与余弦相似度，以及结合向量和关键词检索的混合搜索。

本指南帮助你开始使用 Neo4j [vector store](/oss/integrations/vectorstores)。关于 `Neo4jVectorStore` 全部功能和配置的详细文档，请参阅 [API reference](https://reference.langchain.com/javascript/langchain-neo4j/Neo4jVectorStore)。

## 设置

安装 `@langchain/neo4j`、`neo4j-driver`、`@langchain/core`，以及一个 embeddings provider。本指南使用 [OpenAI embeddings](/oss/integrations/embeddings/openai)：

<Tip>
请参阅[这一节](/oss/langchain/install)，了解 LangChain 包的通用安装说明。
</Tip>

<CodeGroup>
```bash npm
npm install @langchain/neo4j @langchain/core neo4j-driver @langchain/openai
```
```bash yarn
yarn add @langchain/neo4j @langchain/core neo4j-driver @langchain/openai
```
```bash pnpm
pnpm add @langchain/neo4j @langchain/core neo4j-driver @langchain/openai
```
</CodeGroup>

### 用 `docker-compose` 启动自托管 `Neo4j`

`Neo4j` 提供了预构建 Docker image，可用于快速启动自托管实例。创建如下 `docker-compose.yml`：

```yml docker-compose.yml
services:
  database:
    image: neo4j
    ports:
      - 7687:7687
      - 7474:7474
    environment:
      - NEO4J_AUTH=neo4j/pleaseletmein
```

然后在同一目录运行 `docker compose up`。

## 用法

```typescript
import { OpenAIEmbeddings } from "@langchain/openai";
import { Neo4jVectorStore } from "@langchain/neo4j";

const config = {
  url: "bolt://localhost:7687",
  username: "neo4j",
  password: "pleaseletmein",
  indexName: "vector",
  keywordIndexName: "keyword",
  searchType: "vector" as const,
  nodeLabel: "Chunk",
  textNodeProperty: "text",
  embeddingNodeProperty: "embedding",
};

const documents = [
  { pageContent: "what's this", metadata: { a: 2 } },
  { pageContent: "Cat drinks milk", metadata: { a: 1 } },
];

const neo4jVectorIndex = await Neo4jVectorStore.fromDocuments(
  documents,
  new OpenAIEmbeddings(),
  config
);

const results = await neo4jVectorIndex.similaritySearch("water", 1);
await neo4jVectorIndex.close();
```

### 使用 `retrievalQuery` 自定义返回结果

你可以通过 `retrievalQuery` 自定义 Neo4j 中搜索结果的返回结构，但不要省略必需列 `text`、`score` 和 `metadata`。

```typescript
const config = {
  url: "bolt://localhost:7687",
  username: "neo4j",
  password: "pleaseletmein",
  retrievalQuery: `
    RETURN node.text AS text, score, {a: node.a * 2} AS metadata
  `,
};
```

### 从已有 graph 实例化

```typescript
const config = {
  url: "bolt://localhost:7687",
  username: "neo4j",
  password: "pleaseletmein",
  indexName: "wikipedia",
  nodeLabel: "Wikipedia",
  textNodeProperties: ["title", "description"],
  embeddingNodeProperty: "embedding",
  searchType: "hybrid" as const,
};

const neo4jVectorIndex = await Neo4jVectorStore.fromExistingGraph(
  new OpenAIEmbeddings(),
  config
);
```

### Metadata 过滤

`similaritySearch` 的第三个参数支持 metadata filters，包括 `$eq`、`$ne`、`$lt`、`$lte`、`$gt`、`$gte`、`$in`、`$nin`、`$between`、`$like` 和 `$ilike` 等操作符。

```typescript
const filter = { a: { $eq: 1 } };
const results = await neo4jVectorIndex.similaritySearch("water", 1, { filter });
```

## 安全性

请确保数据库连接使用的 credentials 只授予必要权限。否则，调用代码在合适提示下可能执行删除、修改或读取敏感数据等操作。降低风险的最好方式之一，是为数据库创建只读用户或其他最小权限账户。
