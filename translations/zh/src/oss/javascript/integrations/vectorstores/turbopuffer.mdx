[turbopuffer](https://turbopuffer.com) 是一个快速、成本效率高的向量数据库，适用于搜索和检索。

本指南帮助你开始使用 turbopuffer [vector store](/oss/integrations/vectorstores)。关于 `TurbopufferVectorStore` 全部功能和配置的详细文档，请参阅 [API reference](https://reference.langchain.com/javascript/langchain-turbopuffer/TurbopufferVectorStore)。

## 设置

注册一个 [turbopuffer account](https://turbopuffer.com/join)，创建 API key，并安装 `@langchain/turbopuffer`、官方 `@turbopuffer/turbopuffer` client、`@langchain/core` 以及一个 embeddings provider。本指南使用 [OpenAI embeddings](/oss/integrations/embeddings/openai)。

<CodeGroup>
```bash npm
npm install @langchain/turbopuffer @turbopuffer/turbopuffer @langchain/core @langchain/openai
```
```bash yarn
yarn add @langchain/turbopuffer @turbopuffer/turbopuffer @langchain/core @langchain/openai
```
```bash pnpm
pnpm add @langchain/turbopuffer @turbopuffer/turbopuffer @langchain/core @langchain/openai
```
</CodeGroup>

### 凭据

```typescript
process.env.TURBOPUFFER_API_KEY = "your-api-key";
```

你也可以额外设置 [region](https://turbopuffer.com/docs/regions)，例如 `gcp-us-central1`。

## 实例化

```typescript
import { OpenAIEmbeddings } from "@langchain/openai";
import { TurbopufferVectorStore } from "@langchain/turbopuffer";
import { Turbopuffer } from "@turbopuffer/turbopuffer";

const embeddings = new OpenAIEmbeddings({
  model: "text-embedding-3-small",
});

const client = new Turbopuffer({
  apiKey: process.env.TURBOPUFFER_API_KEY,
  region: "gcp-us-central1",
});

const vectorStore = new TurbopufferVectorStore(embeddings, {
  namespace: client.namespace("my-namespace"),
});
```

## 管理 vector store

### 添加内容

当前仅支持字符串类型 metadata。

```typescript
const createdAt = new Date().getTime();

const ids = await vectorStore.addDocuments([
  {
    pageContent: "some content",
    metadata: { created_at: createdAt.toString() },
  },
  { pageContent: "hi", metadata: { created_at: (createdAt + 1).toString() } },
]);
```

### 删除内容

```typescript
await vectorStore.delete({ ids: [ids[ids.length - 1]] });
```

## 查询 vector store

### 直接查询

```typescript
const results = await vectorStore.similaritySearch("hello", 1);
```

使用 turbopuffer filter expressions 通过 metadata 过滤：

```typescript
const results2 = await vectorStore.similaritySearch("hello", 1, [
  "created_at",
  "Eq",
  (createdAt + 3).toString(),
]);
```

### 使用已有 IDs 执行 upsert

```typescript
await vectorStore.addDocuments(
  [{ pageContent: "changed", metadata: { created_at: createdAt.toString() } }],
  { ids }
);
```

### 删除 namespace 中全部向量

```typescript
await vectorStore.delete({ deleteAll: true });
```
