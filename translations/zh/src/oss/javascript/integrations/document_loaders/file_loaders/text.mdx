本文档简要介绍如何开始使用 `TextLoader` [文档加载器](/oss/integrations/document_loaders)。如需查看 `TextLoader` 的全部特性和配置详情，请参阅 [API reference](https://reference.langchain.com/javascript/langchain-core/document_loaders/base/BaseDocumentLoader)。

## 概览

### 集成信息

| Class | Package | Compatibility | Local | PY support |
| :--- | :--- | :---: | :---: |  :---: |
| [`TextLoader`](https://reference.langchain.com/javascript/langchain-core/document_loaders/base/BaseDocumentLoader) | [langchain](https://www.npmjs.com/package/langchain) | 仅 Node | ✅ | ❌ |

## 设置

要访问 `TextLoader` 文档加载器，需要安装 `langchain` 包。

### 安装

LangChain 的 TextLoader 集成位于 `langchain` 包中：

<CodeGroup>
```bash npm
npm install langchain
```
```bash yarn
yarn add langchain
```
```bash pnpm
pnpm add langchain
```
</CodeGroup>

## 实例化

现在可以实例化加载器对象并加载文档：

```typescript
import { TextLoader } from "@langchain/classic/document_loaders/fs/text"

const loader = new TextLoader("../../../../../../examples/src/document_loaders/example_data/example.txt")
```

## 加载

```typescript
const docs = await loader.load()
docs[0]
```

```javascript
Document {
  pageContent: 'Foo\nBar\nBaz\n\n',
  metadata: {
    source: '../../../../../../examples/src/document_loaders/example_data/example.txt'
  },
  id: undefined
}
```

```typescript
console.log(docs[0].metadata)
```

```javascript
{
  source: '../../../../../../examples/src/document_loaders/example_data/example.txt'
}
```
