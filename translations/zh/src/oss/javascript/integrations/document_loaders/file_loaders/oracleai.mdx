<Tip>
**兼容性**：仅适用于 Node.js。
</Tip>

Oracle Database 通过在单一系统中结合对非结构化内容的语义搜索与对业务数据的关系查询，支持以文档为中心的 AI 工作流。这让你可以更轻松地构建检索工作流，例如 RAG，而不必把数据和向量拆分到多个数据库中。

> **为什么要在数据库内处理文档？**
> 你可以将 Oracle Database 的能力，例如安全性、事务、可扩展性和高可用性，应用到同一条用于 AI 搜索和检索的内容加载、切分与存储流水线上。

如果你刚开始使用 Oracle Database，可以考虑体验免费的 [Oracle AI Database 26ai](https://www.oracle.com/database/free/#resources)，它提供了一个简便的入门方式。处理数据库时，通常建议避免对应用负载使用 `SYSTEM` 用户，而是创建一个仅具有最小所需权限的专用用户。关于用户管理的背景信息，请参阅官方 [Oracle Database Guide](https://docs.oracle.com/en/database/oracle/oracle-database/26/dbseg/configuring-privilege-and-role-authorization.html#GUID-16473474-7F47-4E40-A592-01836E7D911C)。


## 概览

### 集成信息

| Class | Package | Compatibility | Local | [PY support](https://python.langchain.com/docs/integrations/document_loaders/oracleai) |

| `OracleTextSplitter` | [`@oracle/langchain-oracledb`](https://www.npmjs.com/package/@oracle/langchain-oracledb) | 仅 Node | ✅ | ✅ |

### 加载文档

用户可以通过适当配置加载器参数，灵活地从 Oracle Database、文件系统或两者同时加载文档。有关这些参数的完整细节，请参阅 [Oracle AI Vector Search Guide](https://docs.oracle.com/en/database/oracle/oracle-database/23/arpls/dbms_vector_chain1.html#GUID-73397E89-92FB-48ED-94BB-1AD960C4EA1F)。

`OracleDocLoader` 的一个显著优势是它能够处理 150 多种不同的文件格式，因此不需要为不同文档类型准备多个加载器。完整支持格式列表请参阅 [Oracle Text Supported Document Formats](https://docs.oracle.com/en/database/oracle/oracle-database/23/ccref/oracle-text-supported-document-formats.html)。

## 设置

要使用 `OracleDocLoader`，请安装 `@oracle/langchain-oracledb` 辅助包以及 `@langchain/core`，并确保满足 Oracle Database 驱动的前置要求。有关 Oracle Database 驱动的完整信息，请参阅其 [guide](https://node-oracledb.readthedocs.io/en/latest/)。

### 凭据

为拥有源数据的 Oracle 用户设置环境变量，或者使用其他 secrets manager。

```bash
export ORACLE_USER=testuser
export ORACLE_PASSWORD=testuser
export ORACLE_DSN="localhost:1521/free"
```

### 安装

<CodeGroup>
```bash npm
npm install @oracle/langchain-oracledb @langchain/core
```
```bash yarn
yarn add @oracle/langchain-oracledb @langchain/core
```
```bash pnpm
pnpm add @oracle/langchain-oracledb @langchain/core
```
</CodeGroup>

## 实例化

```typescript
import oracledb from "oracledb";
import { OracleDocLoader } from "@oracle/langchain-oracledb";

const connection = await oracledb.getConnection({
  user: process.env.ORACLE_USER,
  password: process.env.ORACLE_PASSWORD,
  connectionString: process.env.ORACLE_DSN,
});

const loader = new OracleDocLoader(connection, {
  owner: "TESTUSER",
  tablename: "DEMO_TAB",
  colname: "DATA",
});

// Remember to close the connection (or pool) when your application shuts down.
// await connection.close();
```

## 从 Oracle Database 加载

```typescript
const docs = await loader.load();
console.log(`Loaded ${docs.length} documents`);
console.log(docs[0]?.pageContent.slice(0, 120));
```

## 从文件或目录加载

切换加载器参数即可摄取本地内容。`OracleDocLoader` 会自动处理 150 多种文件格式，完整列表请参阅 [Oracle Text supported formats](https://www.oracle.com/pls/topic/lookup?ctx=dblatest&id=GUID-2EC9C942-0989-4FEE-909A-3575349AC706)。

```typescript
const fileLoader = new OracleDocLoader(connection, {
  file: "/path/to/sample.pdf",
});

const directoryLoader = new OracleDocLoader(connection, {
  dir: "/path/to/documents",
});
```

## 切分文档

文档大小可能差异很大，从很小到非常大都有。用户通常更倾向于先将文档切分为较小片段，以便生成 embeddings。这个切分过程提供了大量自定义选项。有关这些参数的完整细节，请参阅 [Oracle AI Vector Search Guide](https://docs.oracle.com/en/database/oracle/oracle-database/23/arpls/dbms_vector_chain1.html#GUID-4E145629-7098-4C7C-804F-FC85D1F24240)。

```typescript
import { OracleTextSplitter } from "@oracle/langchain-oracledb";

const splitter = new OracleTextSplitter(connection, {
  split: "chars",
  max: 500,
  normalize: "all",
});

const chunks = await splitter.splitText(docs[0].pageContent);
console.log(`Generated ${chunks.length} chunks`);
```
