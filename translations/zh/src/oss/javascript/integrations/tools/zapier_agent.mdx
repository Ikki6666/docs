**Zapier Natural Language Actions** 让你可以通过自然语言 API 接口访问 Zapier 平台上的 5k+ apps 和 20k+ actions。

NLA 支持 Gmail、Salesforce、Trello、Slack、Asana、HubSpot、Google Sheets、Microsoft Teams 等应用，以及数千个其他 app：https://zapier.com/apps

Zapier NLA 会处理所有底层 API 认证，以及从自然语言到实际 API 调用、再到为 LLMs 简化输出的整个转换过程。核心思路是，你或你的用户会通过一个类似 oauth 的设置窗口暴露一组 actions，然后你就可以通过 REST API 对这些 actions 发起查询和执行。

NLA 支持使用 API Key 和 OAuth 来签署 NLA API 请求。

服务端，API Key：适合快速开始、测试，以及 LangChain 只会使用开发者自己 Zapier 账户中暴露 actions 的生产场景，也就是会使用开发者在 Zapier.com 上连接的账户。

面向用户，Oauth：适合终端用户可见的生产场景，此时 LangChain 需要访问终端用户在 Zapier.com 上暴露的 actions 和已连接账户。

你可以通过环境变量，`ZAPIER_NLA_OAUTH_ACCESS_TOKEN` 或 `ZAPIER_NLA_API_KEY`，附加 NLA 凭据，也可以参考 `ZapierNLAWrapper` API reference 中的 `params` 参数说明。

更多细节请参阅 [auth docs](https://docs.zapier.com/platform/build/auth)。

下面的示例演示如何把 Zapier 集成作为 Agent 使用：

<Tip>
请参阅[这一节](/oss/langchain/install)，了解 LangChain 包的通用安装说明。
</Tip>

```bash npm
npm install @langchain/openai @langchain/core
```
```typescript
import { OpenAI } from "@langchain/openai";
import { ZapierNLAWrapper } from "@langchain/classic/tools";
import {
  initializeAgentExecutorWithOptions,
  ZapierToolKit,
} from "@langchain/classic/agents";

const model = new OpenAI({ temperature: 0 });
const zapier = new ZapierNLAWrapper();
const toolkit = await ZapierToolKit.fromZapierNLAWrapper(zapier);

const executor = await initializeAgentExecutorWithOptions(
  toolkit.tools,
  model,
  {
    agentType: "zero-shot-react-description",
    verbose: true,
  }
);
console.log("Loaded agent.");

const input = `Summarize the last email I received regarding Silicon Valley Bank. Send the summary to the #test-zapier Slack channel.`;

console.log(`Executing with input "${input}"...`);

const result = await executor.invoke({ input });

console.log(`Got output ${result.output}`);
```
