## 设置

这个集成位于 `@langchain/tavily` 包中，你可以按如下方式安装：

<CodeGroup>
```bash npm
npm install @langchain/tavily @langchain/core
```
```bash yarn
yarn add @langchain/tavily @langchain/core
```
```bash pnpm
pnpm add @langchain/tavily @langchain/core
```
</CodeGroup>

### 凭据

[配置 Tavily API key](https://app.tavily.com)，并将其设置为名为 `TAVILY_API_KEY` 的环境变量。

```typescript
process.env.TAVILY_API_KEY = "YOUR_API_KEY"
```

你也可以配置 [LangSmith](https://smith.langchain.com) 以获得更好的可观测性，不过这不是必需的：

```typescript
process.env.LANGSMITH_TRACING="true"
process.env.LANGSMITH_API_KEY="your-api-key"
```

## 实例化

实例化时，这个 tool 接受多种参数：

- `maxResults`，optional，number：返回的最大搜索结果数。默认值为 `5`。
- `topic`，optional，string：搜索类别，可选 `"general"`、`"news"` 或 `"finance"`。默认值为 `"general"`。
- `includeAnswer`，optional，boolean：是否在结果中包含对原始 query 的回答。默认值为 `false`。
- `includeRawContent`，optional，boolean | `"markdown"` | `"text"`：是否包含每条搜索结果清洗并解析后的内容。默认值为 `false`。
- `includeImages`，optional，boolean：是否在响应中包含与 query 相关的图片列表。默认值为 `false`。
- `includeImageDescriptions`，optional，boolean：是否包含每张图片的描述文本。默认值为 `false`。
- `searchDepth`，optional，string：搜索深度，可选 `"basic"` 或 `"advanced"`。默认值为 `"basic"`。
- `timeRange`，optional，string：基于当前日期过滤结果的时间范围，可选 `"day"`、`"week"`、`"month"` 或 `"year"`。默认值为 `undefined`。
- `includeDomains`，optional，string[]：要特别包含的域名。默认值为 `[]`。
- `excludeDomains`，optional，string[]：要特别排除的域名。默认值为 `[]`。

关于可用参数的完整说明，请参阅 [Tavily Search API documentation](https://docs.tavily.com/documentation/api-reference/endpoint/search)。

```typescript
import { TavilySearch } from "@langchain/tavily";

const tool = new TavilySearch({
  maxResults: 5,
  topic: "general",
  // includeAnswer: false,
  // includeRawContent: false,
  // includeImages: false,
  // includeImageDescriptions: false,
  // searchDepth: "basic",
  // timeRange: "day",
  // includeDomains: [],
  // excludeDomains: [],
});
```

## 调用

### [使用 args 直接调用](/oss/langchain/tools)

调用时，Tavily search tool 接受以下参数：

- `query`，required：自然语言搜索 query。
- 以下参数也可以在调用时设置：`includeImages`、`searchDepth`、`timeRange`、`includeDomains`、`excludeDomains`。
- 出于可靠性和性能考虑，某些会影响响应体积的参数不能在调用时修改：`includeAnswer` 和 `includeRawContent`。这些限制用于避免意外的上下文窗口问题，并确保结果一致。

注意：这些可选参数也可以由 agents 动态设置。如果你在实例化时设置了某个参数，而调用时又传入了不同值，tool 会采用调用时传入的值。

```typescript
await tool.invoke({ query: "What happened at the last wimbledon" });
```

### [使用 ToolCall 调用](/oss/langchain/tools)

你也可以使用模型生成的 `ToolCall` 调用这个 tool，这种情况下会返回一个 @[`ToolMessage`]：

```typescript
// This is usually generated by a model, but we'll create a tool call directly for demo purposes.
const modelGeneratedToolCall = {
  args: { query: "euro 2024 host nation" },
  id: "1",
  name: tool.name,
  type: "tool_call",
};

const toolMsg = await tool.invoke(modelGeneratedToolCall);

// The content is a JSON string of results
console.log(toolMsg.content.slice(0, 400));
```

```json

```

## 在 agent 中使用

你可以通过把 search tool 传给 `createAgent`，直接在 LangChain agent 中使用它。agent 可以在 tool call 中动态设置 `includeDomains`、`searchDepth` 和 `timeRange` 等参数。

在下面这个示例中，当我们要求 agent 查找 “What nation hosted Euro 2024? Include only wikipedia sources.” 时，agent 会动态设置参数，并使用 `{ query: "Euro 2024 host nation", includeDomains: ["wikipedia.org"] }` 调用 Tavily search tool。

```typescript
// @lc-docs-hide-cell
import { ChatOpenAI } from "@langchain/openai";

const llm = new ChatOpenAI({
  model: "gpt-5.5",
  temperature: 0,
});
```

```typescript
import { TavilySearch } from "@langchain/tavily";
import { createAgent } from "langchain";

// Initialize Tavily Search Tool
const tavilySearchTool = new TavilySearch({
  maxResults: 5,
  topic: "general",
});

const agent = createAgent({
  model: llm,
  tools: [tavilySearchTool],
});

const userInput = "What nation hosted Euro 2024? Include only wikipedia sources.";

const stream = await agent.streamEvents(
  { messages: [["human", userInput]] },
  { version: "v3" },
);

for await (const snapshot of stream.values) {
  const lastMsg = snapshot.messages[snapshot.messages.length - 1];
  if (lastMsg.tool_calls?.length) {
    console.dir(lastMsg.tool_calls, { depth: null });
  } else if (lastMsg.content) {
    console.log(lastMsg.content);
  }
}
```
