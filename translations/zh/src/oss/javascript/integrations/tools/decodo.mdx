[@decodo/langchain-ts](https://www.npmjs.com/package/@decodo/langchain-ts) 包让开发者可以在 LangChain 应用中使用 Decodo 的 Web Scraper API。

Web Scraper API 提供以下能力：

- 轻松访问网页数据。简化从网站和在线来源中获取信息的过程。
- 地理灵活性。无视区域限制访问内容。
- 稳定抓取。使用高级技术规避检测和封锁。

## 特性

@decodo/langchain-ts 插件具备以下特性：

- **Web Scraping**: 抓取任意 URL 并返回 Markdown 内容
- **Google Search**: 搜索 Google 并返回结构化结果
- **Amazon Search**: 搜索 Amazon 并返回结构化商品数据
- **Geolocation selection**：适用于位置敏感内容
- **JavaScript rendering**：适用于需要真实浏览器渲染的目标
- **Markdown output**：为连接 LLM 提供更节省 token 的输出

## 安装

```bash
npm install @decodo/langchain-ts
```

## 快速开始

要在本项目中使用这些工具，你需要订阅 [Decodo Advanced Web Scraping API](https://help.decodo.com/docs/web-scraping-api-core-and-advanced-plans)。你可以在 [dashboard](https://dashboard.decodo.com/) 中申请免费试用。

## 示例

下面是一组针对每个工具的 agentic 示例。

### Universal

```typescript
import dotenv from "dotenv";
import { ChatOpenAI } from "@langchain/openai";
import { createAgent } from "@langchain/agents";
import { DecodoUniversalTool } from "@decodo/langchain-ts";

dotenv.config();

const main = async () => {
  const username = process.env.SCRAPER_API_USERNAME!;
  const password = process.env.SCRAPER_API_PASSWORD!;

  const decodoUniversalTool = new DecodoUniversalTool({ username, password });

  const model = new ChatOpenAI({
    model: "gpt-5.4-mini",
  });

  const agent = createAgent({
    llm: model,
    tools: [decodoUniversalTool],
  });

  const result = await agent.invoke({
    messages: [
      {
        role: "user",
        content:
          "scrape the wikipedia NBA 2025 season page and tell me who won in 2025?",
      },
    ],
  });

  console.log(result.messages[result.messages.length - 1].content);
};

if (require.main === module) {
  main();
}
```

更多示例请参阅 GitHub 上的 [@decodo/langchain-ts](https://github.com/Decodo/decodo-langchain-ts)。

## 配置

所有工具都接收一个 `DecodoConfig` 对象：

```typescript
type DecodoConfig = {
  username: string; // Your Web Advanced product username
  password: string; // Your Web Advanced product password
};
```
