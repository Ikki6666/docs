[Tavily](https://tavily.com/) 是专为 AI agents，LLMs，构建的搜索引擎，能够快速提供实时、准确且基于事实的结果。Tavily 提供 [Crawl](https://docs.tavily.com/documentation/api-reference/endpoint/crawl) endpoint，可从起始 URL 开始执行结构化的 Web 遍历，并内置内容提取和智能发现能力。

## 设置

这个集成位于 `@langchain/tavily` 包中，你可以按如下方式安装：

<CodeGroup>
```bash npm
npm install @langchain/tavily @langchain/core
```
```bash yarn
yarn add @langchain/tavily @langchain/core
```
```bash pnpm
pnpm add @langchain/tavily @langchain/core
```
</CodeGroup>

### 凭据

[配置 Tavily API key](https://app.tavily.com)，并将其设置为名为 `TAVILY_API_KEY` 的环境变量。

```typescript
process.env.TAVILY_API_KEY = "YOUR_API_KEY"
```

你也可以配置 [LangSmith](https://smith.langchain.com) 以获得更好的可观测性，不过这不是必需的：

```typescript
process.env.LANGSMITH_TRACING="true"
process.env.LANGSMITH_API_KEY="your-api-key"
```

## 实例化

实例化时，这个 tool 接受以下参数：

- `maxDepth`，optional，number：从起始 URL 开始的最大跳转层数。默认值为 `3`。
- `maxBreadth`，optional，number：每一层最多抓取的页面数。默认值为 `50`。
- `limit`，optional，number：最多抓取的页面总数。默认值为 `100`。
- `instructions`，optional，string：用于引导 crawler 的自然语言指令。
- `selectPaths`，optional，string[]：仅抓取 URL 中包含这些 path regex 的页面。
- `selectDomains`，optional，string[]：仅抓取这些 domain regex。
- `excludePaths`，optional，string[]：跳过 URL 中包含这些 path regex 的页面。
- `excludeDomains`，optional，string[]：跳过这些 domain regex 对应的 URL。
- `allowExternal`，optional，boolean：允许 crawler 跟随外部链接。
- `extractDepth`，optional，string：每个抓取页面的提取深度，可选 `"basic"` 或 `"advanced"`。默认值为 `"basic"`。
- `format`，optional，string：内容格式，可选 `"markdown"` 或 `"text"`。默认值为 `"markdown"`。
- `includeImages`，optional，boolean：是否包含每个页面上发现的图片。默认值为 `false`。

关于可用参数的完整说明，请参阅 [Tavily Crawl API documentation](https://docs.tavily.com/documentation/api-reference/endpoint/crawl)。

```typescript
import { TavilyCrawl } from "@langchain/tavily";

const tool = new TavilyCrawl({
  maxDepth: 3,
  maxBreadth: 50,
  // limit: 100,
  // extractDepth: "basic",
  // format: "markdown",
  // includeImages: false,
  // allowExternal: false,
});
```

## 调用

### [使用 args 直接调用](/oss/langchain/tools)

调用时，Tavily crawl tool 接受以下参数：

- `url`，required：开始抓取的基础 URL。
- 以下参数也可以在调用时设置：`instructions`、`selectPaths`、`selectDomains`、`excludePaths`、`excludeDomains`、`allowExternal`。

注意：这些可选参数也可以由 agents 动态设置。如果你在实例化时设置了某个参数，而调用时又传入了不同值，tool 会采用调用时传入的值。

```typescript
await tool.invoke({ url: "https://docs.tavily.com" });
```

### [使用 ToolCall 调用](/oss/langchain/tools)

你也可以使用模型生成的 `ToolCall` 调用这个 tool，这种情况下会返回一个 @[`ToolMessage`]：

```typescript
// This is usually generated by a model, but we'll create a tool call directly for demo purposes.
const modelGeneratedToolCall = {
  args: {
    url: "https://docs.tavily.com",
    instructions: "Find API reference pages",
  },
  id: "1",
  name: tool.name,
  type: "tool_call",
};

const toolMsg = await tool.invoke(modelGeneratedToolCall);

console.log(toolMsg.content.slice(0, 400));
```

## 在 agent 中使用

你可以通过把 crawl tool 传给 `createAgent`，直接在 LangChain agent 中使用它。agent 可以在 tool call 中动态设置 `url`、`instructions` 以及 path 或 domain 过滤条件。

```typescript
// @lc-docs-hide-cell
import { ChatOpenAI } from "@langchain/openai";

const llm = new ChatOpenAI({
  model: "gpt-5.5",
  temperature: 0,
});
```

```typescript
import { TavilyCrawl } from "@langchain/tavily";
import { createAgent } from "langchain";

const tavilyCrawlTool = new TavilyCrawl({
  maxDepth: 1,
  maxBreadth: 10,
  limit: 10,
});

const agent = createAgent({
  model: llm,
  tools: [tavilyCrawlTool],
});

const userInput = "Crawl https://docs.tavily.com and find the API reference for the search endpoint.";

const stream = await agent.streamEvents(
  { messages: [["human", userInput]] },
  { version: "v3" },
);

for await (const snapshot of stream.values) {
  const lastMsg = snapshot.messages[snapshot.messages.length - 1];
  if (lastMsg.tool_calls?.length) {
    console.dir(lastMsg.tool_calls, { depth: null });
  } else if (lastMsg.content) {
    console.log(lastMsg.content);
  }
}
```
