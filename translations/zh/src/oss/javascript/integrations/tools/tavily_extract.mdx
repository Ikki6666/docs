[Tavily](https://tavily.com/) 是专为 AI agents，LLMs，构建的搜索引擎，能够快速提供实时、准确且基于事实的结果。Tavily 提供 [Extract](https://docs.tavily.com/documentation/api-reference/endpoint/extract) endpoint，可用于提取一个或多个 URL 的清洗后、解析后的内容。

## 设置

这个集成位于 `@langchain/tavily` 包中，你可以按如下方式安装：

<CodeGroup>
```bash npm
npm install @langchain/tavily @langchain/core
```
```bash yarn
yarn add @langchain/tavily @langchain/core
```
```bash pnpm
pnpm add @langchain/tavily @langchain/core
```
</CodeGroup>

### 凭据

[配置 Tavily API key](https://app.tavily.com)，并将其设置为名为 `TAVILY_API_KEY` 的环境变量。

```typescript
process.env.TAVILY_API_KEY = "YOUR_API_KEY"
```

你也可以配置 [LangSmith](https://smith.langchain.com) 以获得更好的可观测性，不过这不是必需的：

```typescript
process.env.LANGSMITH_TRACING="true"
process.env.LANGSMITH_API_KEY="your-api-key"
```

## 实例化

实例化时，这个 tool 接受以下参数：

- `extractDepth`，optional，string：提取深度，可选 `"basic"` 或 `"advanced"`。默认值为 `"basic"`。
- `includeImages`，optional，boolean：是否在提取结果中包含图片。默认值为 `false`。
- `format`，optional，string：内容格式，可选 `"markdown"` 或 `"text"`。默认值为 `"markdown"`。
- `includeFavicon`，optional，boolean：是否包含每个结果的 favicon URL。默认值为 `false`。

关于可用参数的完整说明，请参阅 [Tavily Extract API documentation](https://docs.tavily.com/documentation/api-reference/endpoint/extract)。

```typescript
import { TavilyExtract } from "@langchain/tavily";

const tool = new TavilyExtract({
  extractDepth: "basic",
  includeImages: false,
});
```

## 调用

### [使用 args 直接调用](/oss/langchain/tools)

调用时，Tavily extract tool 接受以下参数：

- `urls`，required：要提取内容的 URL 列表。
- 以下参数也可以在调用时设置：`extractDepth`、`includeImages`。

注意：这些可选参数也可以由 agents 动态设置。如果你在实例化时设置了某个参数，而调用时又传入了不同值，tool 会采用调用时传入的值。

```typescript
await tool.invoke({ urls: ["https://en.wikipedia.org/wiki/Lionel_Messi"] });
```

```text
{
  results: [{
    url: 'https://en.wikipedia.org/wiki/Lionel_Messi',
    raw_content: 'Lionel Messi - Wikipedia\nJump to content\nMain menu\n... (truncated)',
    images: []
  }],
  failed_results: [],
  response_time: 0.02
}
```

### [使用 ToolCall 调用](/oss/langchain/tools)

你也可以使用模型生成的 `ToolCall` 调用这个 tool，这种情况下会返回一个 @[`ToolMessage`]：

```typescript
// This is usually generated by a model, but we'll create a tool call directly for demo purposes.
const modelGeneratedToolCall = {
  args: { urls: ["https://en.wikipedia.org/wiki/Lionel_Messi"] },
  id: "1",
  name: tool.name,
  type: "tool_call",
};

const toolMsg = await tool.invoke(modelGeneratedToolCall);

// The content is a JSON string of results
console.log(toolMsg.content.slice(0, 400));
```

```json
{"results": [{"url": "https://en.wikipedia.org/wiki/Lionel_Messi", "raw_content": "Lionel Messi - Wikipedia\nJump to content\nMain menu\nMain menu\nmove to sidebar hide\nNavigation\n\nMain page\nContents\nCurrent events\nRandom article\nAbout Wikipedia\nContact us\n\nContribute\n\nHelp\nLearn to edit\nCommunity portal\nRecent changes\nUpload file\nSpecial pages\n... (truncated)"}], "failed_results": [], "response_time": 0.02}
```

## 在 agent 中使用

你可以通过把 extract tool 传给 `createAgent`，直接在 LangChain agent 中使用它。agent 可以在 tool call 中动态设置 URL 列表以及 `extractDepth`、`includeImages` 之类的开关。

```typescript
// @lc-docs-hide-cell
import { ChatOpenAI } from "@langchain/openai";

const llm = new ChatOpenAI({
  model: "gpt-5.5",
  temperature: 0,
});
```

```typescript
import { TavilyExtract } from "@langchain/tavily";
import { createAgent } from "langchain";

const tavilyExtractTool = new TavilyExtract();

const agent = createAgent({
  model: llm,
  tools: [tavilyExtractTool],
});

const userInput = "Summarize https://en.wikipedia.org/wiki/Albert_Einstein and https://en.wikipedia.org/wiki/Theoretical_physics.";

const stream = await agent.streamEvents(
  { messages: [["human", userInput]] },
  { version: "v3" },
);

for await (const snapshot of stream.values) {
  const lastMsg = snapshot.messages[snapshot.messages.length - 1];
  if (lastMsg.tool_calls?.length) {
    console.dir(lastMsg.tool_calls, { depth: null });
  } else if (lastMsg.content) {
    console.log(lastMsg.content);
  }
}
```
