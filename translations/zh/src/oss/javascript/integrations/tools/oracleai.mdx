</Tip>

Oracle AI Database 支持按**语义**而不只是关键词来查询数据的 AI workload。它在同一个系统中结合了**对非结构化内容的语义搜索**和**对业务数据的关系型过滤**，因此你可以构建检索工作流，例如 RAG，而无需额外引入单独的向量数据库，也不会把数据拆散到多个平台上。

本指南演示如何使用 Oracle AI Vector Search LangChain 集成中的 `OracleSummary` 生成文档摘要。

> **为什么在这里做摘要？**
> 摘要是一种很实用的方式，可以把长文档压缩为便于检索的内容，例如预览、元数据或浓缩后的上下文，同时又让治理和运维保障尽量贴近数据本身。

如果你刚开始接触 Oracle Database，可以考虑体验 [free Oracle 26 AI](https://www.oracle.com/database/free/#resources)。关于用户管理背景知识，请参阅官方 [Oracle guide](https://docs.oracle.com/en/database/oracle/oracle-database/26/dbseg/configuring-privilege-and-role-authorization.html#GUID-16473474-7F47-4E40-A592-01836E7D911C)。

## 设置

要访问 OracleSummary，请安装 `@oracle/langchain-oracledb` 辅助包，连同 `@langchain/core`，并确保你的环境满足 [Oracle Database driver](https://node-oracledb.readthedocs.io/en/latest/) 的前置要求。

### 凭据

为拥有摘要配置的 Oracle 用户设置凭据，或使用 secrets manager：

```bash
export ORACLE_USER=testuser
export ORACLE_PASSWORD=testuser
export ORACLE_DSN="localhost:1521/free"
```

如果你计划调用 OCI Generative AI 或 Hugging Face 之类的第三方提供方，请先在 Oracle Database 中创建凭据，例如 `OCI_CRED`、`HF_CRED`，使用 [Oracle AI Vector Search guide](https://www.oracle.com/pls/topic/lookup?ctx=dblatest&id=GUID-EC9DDB58-6A15-4B36-BA66-ECBA20D2CE57) 中记录的 PL/SQL helpers。

### 安装

## 实例化 tool

```typescript
import oracledb from "oracledb";
import { OracleSummary } from "@oracle/langchain-oracledb";

const connection = await oracledb.getConnection({
  user: process.env.ORACLE_USER,
  password: process.env.ORACLE_PASSWORD,
  connectionString: process.env.ORACLE_DSN,
});

const summary = new OracleSummary(
  connection,
  {
    provider: "database",
    glevel: "S",
    numParagraphs: 1,
    language: "english",
  },
  process.env.HTTP_PROXY, // optional
);
```

第三个构造参数是可选的 proxy 字符串。只有在出站请求必须经过 HTTP proxy 时才需要提供，例如调用 Hugging Face endpoint 时。

## 使用数据库内模型生成摘要

直接在 Oracle Database 中运行 ONNX 摘要模型，让数据与事务型 workload 保持在同一主机上。

```typescript
const result = await summary.getSummary(
  "Oracle Database combines relational and vector workloads so you can build secure RAG pipelines.",
);

console.log(result); // => concise summary text
```

## 使用托管提供方

切换 `provider` 参数即可通过 [OCI Generative AI](https://docs.oracle.com/en-us/iaas/Content/generative-ai/home.htm) 或 Hugging Face 路由摘要请求。请提供你在 Oracle Database 中注册的凭据名称，以及在需要时传入 proxy 字符串。

```typescript
const ociSummary = new OracleSummary(
  connection,
  {
    provider: "ocigenai",
    credential_name: "OCI_CRED",
    url: "https://inference.generativeai.us-chicago-1.oci.oraclecloud.com/20231130/actions/summarizeText",
    model: "cohere.command",
  },
  process.env.HTTP_PROXY,
);

const hfSummary = new OracleSummary(connection, {
  provider: "huggingface",
  credential_name: "HF_CRED",
  url: "https://api-inference.huggingface.co/models/",
  model: "facebook/bart-large-cnn",
  wait_for_model: "true",
});
```

## 与 LangChain tools 串联

你可以把 `OracleSummary` 包装成自定义 LangChain tool 或 runnable，以便集成到 agent 的 tool calling 流程中。

```typescript
import { tool } from "@langchain/core/tools";
import { z } from "zod";

const summarizeTool = tool(
  async ({ text }: { text: string }) => summary.getSummary(text),
  {
    name: "oracle_summary",
    description: "Summarize Oracle-sourced documents.",
    schema: z.object({
      text: z.string().describe("Full text to summarize"),
    }),
  },
);

const toolSummary = await summarizeTool.invoke({ text });
```
