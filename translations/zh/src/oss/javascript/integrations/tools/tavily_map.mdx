[Tavily](https://tavily.com/) 是专为 AI agents，LLMs，构建的搜索引擎，能够快速提供实时、准确且基于事实的结果。Tavily 提供 [Map](https://docs.tavily.com/documentation/api-reference/endpoint/map) endpoint，可遍历网站并返回发现到的 URL 列表，而不会提取页面内容，因此很适合理解站点结构或在大型站点中定位特定页面。

## 设置

这个集成位于 `@langchain/tavily` 包中，你可以按如下方式安装：

<CodeGroup>
```bash npm
npm install @langchain/tavily @langchain/core
```
```bash yarn
yarn add @langchain/tavily @langchain/core
```
```bash pnpm
pnpm add @langchain/tavily @langchain/core
```
</CodeGroup>

### 凭据

[配置 Tavily API key](https://app.tavily.com)，并将其设置为名为 `TAVILY_API_KEY` 的环境变量。

```typescript
process.env.TAVILY_API_KEY = "YOUR_API_KEY"
```

你也可以配置 [LangSmith](https://smith.langchain.com) 以获得更好的可观测性，不过这不是必需的：

```typescript
process.env.LANGSMITH_TRACING="true"
process.env.LANGSMITH_API_KEY="your-api-key"
```

## 实例化

实例化时，这个 tool 接受以下参数：

- `maxDepth`，optional，number：从起始 URL 开始的最大跳转层数。默认值为 `3`。
- `maxBreadth`，optional，number：每一层返回的 URL 最大数量。默认值为 `50`。
- `limit`，optional，number：返回的 URL 总数上限。默认值为 `100`。
- `instructions`，optional，string：用于引导 map 遍历的自然语言指令。
- `selectPaths`，optional，string[]：仅包含 URL 中匹配这些 path regex 的页面。
- `selectDomains`，optional，string[]：仅包含匹配这些 domain regex 的 URL。
- `excludePaths`，optional，string[]：跳过 URL 中匹配这些 path regex 的页面。
- `excludeDomains`，optional，string[]：跳过匹配这些 domain regex 的 URL。
- `allowExternal`，optional，boolean：允许 map 跟随外部链接。

关于可用参数的完整说明，请参阅 [Tavily Map API documentation](https://docs.tavily.com/documentation/api-reference/endpoint/map)。

```typescript
import { TavilyMap } from "@langchain/tavily";

const tool = new TavilyMap({
  maxDepth: 3,
  maxBreadth: 50,
  // limit: 100,
  // allowExternal: false,
});
```

## 调用

### [使用 args 直接调用](/oss/langchain/tools)

调用时，Tavily map tool 接受以下参数：

- `url`，required：开始映射的基础 URL。
- 以下参数也可以在调用时设置：`instructions`、`selectPaths`、`selectDomains`、`excludePaths`、`excludeDomains`、`allowExternal`。

注意：这些可选参数也可以由 agents 动态设置。如果你在实例化时设置了某个参数，而调用时又传入了不同值，tool 会采用调用时传入的值。

```typescript
await tool.invoke({ url: "https://docs.tavily.com" });
```

```json
{
  "base_url": "https://docs.tavily.com",
  "results": [
    "https://docs.tavily.com/",
    "https://docs.tavily.com/changelog",
    "https://docs.tavily.com/welcome",
    "https://docs.tavily.com/documentation/mcp",
    "https://docs.tavily.com/documentation/about",
  ],
  "response_time": 0.07
}
```

### [使用 ToolCall 调用](/oss/langchain/tools)

你也可以使用模型生成的 `ToolCall` 调用这个 tool，这种情况下会返回一个 @[`ToolMessage`]：

```typescript
// This is usually generated by a model, but we'll create a tool call directly for demo purposes.
const modelGeneratedToolCall = {
  args: {
    url: "https://docs.tavily.com",
    instructions: "Find API reference pages",
  },
  id: "1",
  name: tool.name,
  type: "tool_call",
};

const toolMsg = await tool.invoke(modelGeneratedToolCall);

console.log(toolMsg.content.slice(0, 400));
```

## 在 agent 中使用

你可以通过把 map tool 传给 `createAgent`，直接在 LangChain agent 中使用它。agent 可以动态设置 `url`、`instructions` 以及 path 或 domain 过滤条件，以发现所需 URL。

```typescript
// @lc-docs-hide-cell
import { ChatOpenAI } from "@langchain/openai";

const llm = new ChatOpenAI({
  model: "gpt-5.5",
  temperature: 0,
});
```

```typescript
import { TavilyMap } from "@langchain/tavily";
import { createAgent } from "langchain";

const tavilyMapTool = new TavilyMap({
  maxDepth: 2,
  maxBreadth: 20,
  limit: 30,
});

const agent = createAgent({
  model: llm,
  tools: [tavilyMapTool],
});

const userInput = "Map https://docs.tavily.com and list URLs that look like API reference pages.";

const stream = await agent.streamEvents(
  { messages: [["human", userInput]] },
  { version: "v3" },
);

for await (const snapshot of stream.values) {
  const lastMsg = snapshot.messages[snapshot.messages.length - 1];
  if (lastMsg.tool_calls?.length) {
    console.dir(lastMsg.tool_calls, { depth: null });
  } else if (lastMsg.content) {
    console.log(lastMsg.content);
  }
}
```
