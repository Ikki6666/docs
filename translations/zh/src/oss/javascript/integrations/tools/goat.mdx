[GOAT](https://github.com/goat-sdk/goat) 是一个面向 AI agents 的金融工具包。

<Warning>
**这个工具存在于 LangChain 主[仓库](https://github.com/goat-sdk/goat/)之外。**

将钱包连接到外部提供方时请务必谨慎，并确认这些提供方值得信任。
</Warning>

## 概览

创建能够执行以下操作的 agents：

- 收发支付
- 购买实物与数字商品或服务
- 执行多种投资策略：
  - Earn yield
  - Bet on prediction markets
- 购买加密资产
- 将任意资产代币化
- 获取金融洞察

### 工作原理

GOAT 使用区块链、加密货币，例如稳定币，以及钱包作为基础设施，使 agents 能够成为经济参与者：

1. 为你的 agent 配置一个 [wallet](https://github.com/goat-sdk/goat/tree/main#chains-and-wallets)
2. 允许它在[任意地方](https://github.com/goat-sdk/goat/tree/main#chains-and-wallets)进行交易
3. 使用超过 [+200 tools](https://github.com/goat-sdk/goat/tree/main#tools)

请参阅 [what GOAT supports](https://github.com/goat-sdk/goat/tree/main#chains-and-wallets)。

**Lightweight and extendable**
与其他 toolkits 不同，GOAT 被设计为轻量且可扩展，它保持最小核心，只让你安装实际需要的工具。

如果在 200 多个集成中仍找不到你需要的内容，你也可以轻松：

- 创建自己的 plugin
- 集成新的 chain
- 集成新的 wallet
- 集成新的 agent framework

请参阅 [how to contribute](https://github.com/goat-sdk/goat/tree/main#-contributing)。

## 设置

1. 安装核心包和 langchain adapter：

```bash
npm i @goat-sdk/core @goat-sdk/adapter-langchain
```

2. 安装你想使用的钱包类型，例如 solana：

```bash
npm i @goat-sdk/wallet-evm @goat-sdk/wallet-viem
```

3. 安装你想在该链中使用的 plugins：

```bash
npm i @goat-sdk/plugin-erc20
```

## 实例化

现在可以实例化 toolkit：

```typescript
import { http } from "viem";
import { createWalletClient } from "viem";
import { privateKeyToAccount } from "viem/accounts";
import { baseSepolia } from "viem/chains";

import { getOnChainTools } from "@goat-sdk/adapter-langchain";
import { PEPE, USDC, erc20 } from "@goat-sdk/plugin-erc20";

import { sendETH } from "@goat-sdk/wallet-evm";
import { viem } from "@goat-sdk/wallet-viem";

import { ChatOpenAI } from "@langchain/openai";
import { createAgent } from "@langchain/classic";

// 1. Create a wallet client
const account = privateKeyToAccount(
  process.env.WALLET_PRIVATE_KEY as `0x${string}`
);

const walletClient = createWalletClient({
  account: account,
  transport: http(process.env.RPC_PROVIDER_URL),
  chain: baseSepolia,
});

// 2. Set up the tools
const tools = await getOnChainTools({
  wallet: viem(walletClient),
  plugins: [sendETH(), erc20({ tokens: [USDC, PEPE] })],
});

// 3. Create the agent
const model = new ChatOpenAI({
  model: "gpt-5.4-mini",
});

const agent = createAgent({ llm: model, tools: tools });
```
