Checkpointers 为 LangGraph 提供[persistence](/oss/langgraph/persistence)能力，让 agents 能够在多次交互之间保存并恢复状态。

如需为自定义存储后端实现自己的 checkpointer，请参阅[构建自定义 checkpointer](/oss/langgraph/checkpointers#build-a-custom-checkpointer)。
