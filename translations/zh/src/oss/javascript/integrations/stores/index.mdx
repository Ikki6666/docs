## 概览

LangChain 提供了一个按键存储和检索数据的 key-value store interface。LangChain 中的 key-value store interface 主要用于缓存 [embeddings](/oss/integrations/embeddings)。

## 接口

所有 [`BaseStores`](https://reference.langchain.com/javascript/langchain-core/stores/BaseStore) 都是**泛型**的，并支持如下接口，其中 `K` 表示 key 类型，`V` 表示 value 类型：

- `mget(keys: K[]): Promise<(V | undefined)[]>`：获取多个 key 的值，如果 key 不存在则返回 `undefined`
- `mset(keyValuePairs: [K, V][]): Promise<void>`：设置多个 key 的值
- `mdelete(keys: K[]): Promise<void>`：删除多个 key
- `yieldKeys(prefix?: string): AsyncGenerator<K | string>`：异步产出 store 中的全部 key，也可以按 prefix 过滤

接口的泛型特性让你可以为 keys 和 values 使用不同类型。例如，`BaseStore<string, BaseMessage>` 可以用字符串键存储消息，而 `BaseStore<string, number[]>` 则可以用字符串键存储数字数组。

<Note>
Base stores 设计成一次处理**多个**键值对，以提升效率。这样可以减少网络往返，并且可能让底层 store 支持更高效的批处理操作。
</Note>

你也可以通过扩展 @[`BaseStore`] 类来实现自己的 custom store。更多细节请参阅 [store interface documentation](https://reference.langchain.com/javascript/langchain-core/stores/BaseStore)。
