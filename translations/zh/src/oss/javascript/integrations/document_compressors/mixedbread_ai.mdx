## 概览

本指南将帮助你集成并使用 [Mixedbread AI](https://mixedbread.ai/) 的 reranking API。reranking API 可以根据给定查询对文档列表重新排序，从而提升搜索结果或任何排序列表的相关性。

## 安装

开始之前，请安装 `@langchain/mixedbread-ai` 包：

<Tip>
请参见[本节中的 LangChain 包通用安装说明](/oss/langchain/install)。
</Tip>

```bash
npm install @langchain/mixedbread-ai
```

## 认证

通过注册 [Mixedbread AI](https://mixedbread.ai/) 获取你的 API key。然后，你可以把 `MXBAI_API_KEY` 环境变量设置为该 API key，或者在构造类时通过 `apiKey` 选项直接传入。

## 使用 reranking

`MixedbreadAIReranker` 类提供了对 reranking API 的访问。使用方式如下：

1. **导入类**：首先，从包中导入 `MixedbreadAIReranker` 类。

```typescript
import { MixedbreadAIReranker } from "@langchain/mixedbread-ai";
```

2. **实例化类**：使用你的 API key 创建 `MixedbreadAIReranker` 实例。

```typescript
const reranker = new MixedbreadAIReranker({ apiKey: "your-api-key" });
```

3. **对文档做 rerank**：使用 `rerankDocuments` 方法根据查询对文档重新排序。

```typescript
const documents = [
  { pageContent: "To bake bread you need flour" },
  { pageContent: "To bake bread you need yeast" },
  { pageContent: "To eat bread you need nothing but good taste" },
];
const query = "What do you need to bake bread?";
const result = await reranker.compressDocuments(documents, query);
console.log(result);
```
