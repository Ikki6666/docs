## 设置

要访问 DeepSeek 模型，你需要创建 DeepSeek 账号、获取 API key，并安装 `@langchain/deepseek` 集成包。

你也可以通过 [Ollama](/oss/integrations/chat/ollama) 等提供方访问 DeepSeek API。

### 凭证

前往 [deepseek.com](https://deepseek.com/) 注册 DeepSeek 并生成 API key。完成后，设置 `DEEPSEEK_API_KEY` 环境变量：

```bash
export DEEPSEEK_API_KEY="your-api-key"
```

如果你希望自动追踪模型调用，也可以取消下面的注释并设置 [LangSmith](/langsmith/observability) API key：

```bash
# export LANGSMITH_TRACING="true"
# export LANGSMITH_API_KEY="your-api-key"
```

### 安装

LangChain 的 `ChatDeepSeek` 集成位于 `@langchain/deepseek` 包中：

<CodeGroup>
```bash npm
npm install @langchain/deepseek @langchain/core
```
```bash yarn
yarn add @langchain/deepseek @langchain/core
```
```bash pnpm
pnpm add @langchain/deepseek @langchain/core
```
</CodeGroup>

## 实例化

现在可以实例化模型对象并生成聊天补全：


```typescript
import { ChatDeepSeek } from "@langchain/deepseek";

const llm = new ChatDeepSeek({
  model: "deepseek-reasoner",
  temperature: 0,
  // other params...
})
```


```typescript
const aiMsg = await llm.invoke([
  [
    "system",
    "You are a helpful assistant that translates English to French. Translate the user sentence.",
  ],
  ["human", "I love programming."],
])
aiMsg
```
