## 设置

要访问 `ChatXAI` 模型，请创建 xAI 账号、[获取 API key](https://console.x.ai/)，并安装 `@langchain/xai` 集成包。

### 凭证

前往 [xAI 官网](https://x.ai) 注册并生成 API key。设置 `XAI_API_KEY` 环境变量：

```bash
export XAI_API_KEY="your-api-key"
```

如果你希望自动追踪模型调用，也可以取消下面的注释并设置 [LangSmith](/langsmith/observability) API key：

```bash
# export LANGSMITH_TRACING="true"
# export LANGSMITH_API_KEY="your-api-key"
```

### 安装

LangChain 的 `ChatXAI` 集成位于 `@langchain/xai` 包中：

<CodeGroup>
```bash npm
npm install @langchain/xai @langchain/core
```
```bash yarn
yarn add @langchain/xai @langchain/core
```
```bash pnpm
pnpm add @langchain/xai @langchain/core
```
</CodeGroup>

## 实例化

现在可以实例化模型对象并生成聊天补全：

```typescript
import { ChatXAI } from "@langchain/xai";

const llm = new ChatXAI({
    model: "grok-3-fast",
    temperature: 0,
    maxTokens: undefined,
    maxRetries: 2,
    // other params...
})
```

## 调用

```typescript
const aiMsg = await llm.invoke([
    [
      "system",
      "You are a helpful assistant that translates English to French. Translate the user sentence.",
    ],
    ["human", "I love programming."],
])
console.log(aiMsg)
```
