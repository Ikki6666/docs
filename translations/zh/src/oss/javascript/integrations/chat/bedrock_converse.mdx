[Amazon Bedrock Converse](https://docs.aws.amazon.com/bedrock/latest/APIReference/API_runtime_Converse.html) 是一项全托管服务，可通过 API 提供来自领先 AI 创业公司和 Amazon 的基础模型（FM）。你可以从丰富的模型中选择最适合自身用例的模型。它还为 Bedrock 模型提供统一的对话接口。

本文将帮助你开始使用 `ChatBedrockConverse` [chat models](/oss/langchain/models)。如需查看 `ChatBedrockConverse` 全部功能与配置的详细文档，请前往 [API reference](https://reference.langchain.com/javascript/langchain-aws/ChatBedrockConverse)。

## 设置

要访问 Bedrock 模型，你需要创建 AWS 账号、配置 Bedrock API 服务、获取 access key ID 和 secret key，并安装 `@langchain/aws` 集成包。

### 凭证

前往 [AWS docs](https://docs.aws.amazon.com/bedrock/latest/userguide/getting-started.html) 注册 AWS 并配置凭证。你还需要为账号开启模型访问权限，可按照[这些说明](https://docs.aws.amazon.com/bedrock/latest/userguide/model-access.html)操作。

在环境中设置你的 Bedrock 凭证：

```bash
export BEDROCK_AWS_REGION="us-east-1"
export BEDROCK_AWS_ACCESS_KEY_ID="your-access-key-id"
export BEDROCK_AWS_SECRET_ACCESS_KEY="your-secret-access-key"
```

或者，你也可以设置 `AWS_BEARER_TOKEN_BEDROCK` 来使用 API key 认证。详见 [AWS Bedrock API key docs](https://docs.aws.amazon.com/bedrock/latest/userguide/api-keys.html)。

如果你希望自动追踪模型调用，也可以取消下面的注释并设置 [LangSmith](/langsmith/observability) API key：

```bash
# export LANGSMITH_TRACING="true"
# export LANGSMITH_API_KEY="your-api-key"
```

### 安装

## 实例化

现在可以实例化模型对象并生成聊天补全。

AWS 有几种不同的认证方式。下面的示例依赖于环境变量中已设置的 access key、secret access key 和 region：

```typescript
import { ChatBedrockConverse } from "@langchain/aws";

const llm = new ChatBedrockConverse({
  model: "us.anthropic.claude-sonnet-4-6",
  region: process.env.BEDROCK_AWS_REGION,
  credentials: {
    accessKeyId: process.env.BEDROCK_AWS_ACCESS_KEY_ID!,
    secretAccessKey: process.env.BEDROCK_AWS_SECRET_ACCESS_KEY!,
  },
});
```
