## 设置

要访问 Perplexity 模型，你需要创建 Perplexity 账号、获取 API key，并安装 `@langchain/perplexity` 集成包。

### 凭证

前往 [Perplexity API key dashboard](https://www.perplexity.ai/account/api/keys) 注册并生成 API key。完成后，设置 `PERPLEXITY_API_KEY` 环境变量：

```bash
export PERPLEXITY_API_KEY="your-api-key"
```

如果你希望自动追踪模型调用，也可以取消下面的注释并设置 [LangSmith](/langsmith/observability) API key：

```bash
# export LANGSMITH_TRACING="true"
# export LANGSMITH_API_KEY="your-api-key"
```

### 安装

LangChain 的 Perplexity 集成位于 `@langchain/perplexity` 包中：

<CodeGroup>
```bash npm
npm install @langchain/perplexity @langchain/core
```
```bash yarn
yarn add @langchain/perplexity @langchain/core
```
```bash pnpm
pnpm add @langchain/perplexity @langchain/core
```
</CodeGroup>

## 实例化

现在可以实例化模型：

```typescript
import { ChatPerplexity } from "@langchain/perplexity";

const llm = new ChatPerplexity({
  model: "openai/gpt-5.5",
  temperature: 0,
  maxTokens: undefined,
  timeout: undefined,
  maxRetries: 2,
  // other params...
});
```

## Agent API 支持（`useResponsesApi`）

`ChatPerplexity` 也可以通过设置 `useResponsesApi`，把请求路由到 Perplexity 的 [Agent API](https://docs.perplexity.ai/docs/agent-api/quickstart)（Perplexity 风格的 Responses API）。这与 [`ChatOpenAI` 的 Responses 模式](https://reference.langchain.com/javascript/langchain-openai/)保持一致：一个类、两个 endpoint，由单个选项控制。

| Value | Endpoint | Notes |
| :--- | :--- | :--- |
| `undefined` (default) | Auto-detected | 当请求使用内置的 Perplexity 工具（`web_search`、`fetch_url`、`finance_search`、`people_search`）或包含仅 Responses 支持的字段（`previousResponseId`、`instructions`、`input`、`include`）时，会路由到 Agent API。否则路由到 Chat Completions。 |
| `true` | Agent API | 始终使用 `client.responses.create()`。 |
| `false` | Chat Completions | 始终使用 `client.chat.completions.create()`。 |

Agent API 让 `ChatPerplexity` 可以访问 Perplexity 的内置工具（实时网页搜索、URL 抓取、财经搜索和人物搜索）以及有状态 agent 字段（`previousResponseId`、`instructions`、`include`），这些在 Chat Completions 中不可用。现有的 `new ChatPerplexity({ model: "sonar" })` 调用方不会看到行为变化，对于纯文本请求，默认仍然走 Chat Completions。

```typescript
import { ChatPerplexity } from "@langchain/perplexity";

const chat = new ChatPerplexity({
  model: "openai/gpt-5.5",
  useResponsesApi: true,
});

const response = await chat.invoke("What did Apple announce at WWDC this week?");
console.log(response.content);
```

你也可以绑定内置工具，让自动检测来负责路由，无需额外选项：

```typescript
import { ChatPerplexity } from "@langchain/perplexity";

const chat = new ChatPerplexity({ model: "openai/gpt-5.5" });

const response = await chat.invoke(
  "Summarize the latest LangChain release notes.",
  { tools: [{ type: "web_search" }] },
);
console.log(response.content);
```

当请求通过 Agent API 路由时，响应对象会携带更丰富的元数据：

- `usage_metadata` 会从 Responses 形状的 `usage` 载荷中填充（`input_tokens`、`output_tokens`、`total_tokens`）。
- `response_metadata` 会携带传输层字段（`id`、`model`、`status`、`object`），以及 Perplexity 特有的搜索输出（如存在）：`citations`、`images`、`related_questions` 和 `search_results`。
- `additional_kwargs.responses_output` 持有原始 Agent API 输出项。
- 模型返回的工具调用会像 `ChatOpenAI` 一样出现在 `response.tool_calls` 上。

<Note>
    `_toResponsesPayload` 转换会直接把 `temperature`、`topP` 和 `toolChoice` 传给 Agent API。那些仅适用于 Chat Completions、且不是原生 Responses 字段的参数（例如 `topK`、`stop`、`metadata`）会通过 `extra_body` 转发。
</Note>

完整可用模型集合请参见 [Perplexity Agent API model list](https://docs.perplexity.ai/docs/agent-api/models)（例如 `openai/gpt-5.5`、`anthropic/claude-sonnet-4-6`、`google/gemini-3-1-pro`）。

## 相关集成

`@langchain/perplexity` 包还包含不使用聊天 API 的搜索组件：

- [`PerplexitySearchRetriever`](/oss/integrations/retrievers/perplexity_search)：从 Perplexity Search API 返回 `Document` 对象，用于 RAG 流水线

有关这三个组件的完整接入方式，请参见 [Perplexity provider overview](/oss/integrations/providers/perplexity)。
