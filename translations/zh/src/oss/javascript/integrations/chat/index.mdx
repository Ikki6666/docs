[Chat models](/oss/langchain/models) 是一种语言模型，它使用一系列 [messages](/oss/langchain/messages) 作为输入，并以消息作为输出 <Tooltip tip="较旧的模型不遵循聊天模型接口，而是使用“输入字符串、输出字符串”的接口。这类模型通常名称中不带前缀 'Chat'，或者以 'LLM' 作为后缀。">（而不是纯文本）</Tooltip>。

## 安装和使用

<Tip>
    请参见[本节中的 LangChain 包通用安装说明](/oss/langchain/install)。
</Tip>

<AccordionGroup>
    <Accordion title="OpenAI">
        安装：

        <CodeGroup>
            ```bash npm
            npm install @langchain/openai @langchain/core
            ```
            ```bash yarn
            yarn add @langchain/openai @langchain/core
            ```
            ```bash pnpm
            pnpm add @langchain/openai @langchain/core
            ```
        </CodeGroup>

        添加环境变量：

        ```bash
        OPENAI_API_KEY=your-api-key
        ```

        实例化模型：

        ```typescript
        import { ChatOpenAI } from "@langchain/openai";

        const model = new ChatOpenAI({ model: "gpt-5.4-mini" });
        ```
        ```javascript
        await model.invoke("Hello, world!")
        ```
    </Accordion>

## 路由器与代理

路由器和代理可让你通过单个 API 和一套凭据访问来自多个提供方的模型。它们可以简化计费，让你无需更换集成就能切换模型，并提供自动回退等特性。

| Provider | Integration | Description |
|-|-|-|
| [OpenRouter](https://openrouter.ai/) | [`ChatOpenRouter`](/oss/integrations/chat/openrouter) | 统一访问来自 OpenAI、Anthropic、Google、Meta 等提供方的模型 |

## Chat Completions API

某些模型提供方提供与 OpenAI（旧版）[Chat Completions API](https://platform.openai.com/docs/guides/completions)兼容的 endpoint。在这种情况下，你可以通过自定义 `base_url` 使用 [`ChatOpenAI`](/oss/integrations/chat/openai) 连接这些 endpoint。请注意，构建在 Chat Completions API 之上的特性可能无法被 `ChatOpenAI` 完整支持；遇到这种情况时，如果有提供方专用类，建议优先使用它。
