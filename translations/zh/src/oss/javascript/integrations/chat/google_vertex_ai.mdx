[Google Vertex](https://cloud.google.com/vertex-ai) 是一项服务，可暴露 Google Cloud 中提供的全部 foundation models，例如 `gemini-2.5-pro`、`gemini-2.5-flash` 等。
它还提供一些非 Google 模型，例如 [Anthropic 的 Claude](https://cloud.google.com/vertex-ai/generative-ai/docs/partner-models/use-claude)。

本文将帮助你开始使用 `ChatVertexAI` [chat models](/oss/langchain/models)。如需查看 `ChatVertexAI` 全部功能与配置的详细文档，请前往 [API reference](https://reference.langchain.com/javascript/langchain-google-vertexai/index/ChatVertexAI)。

<Note>

    新实现应使用 [ChatGoogle](/oss/integrations/chat/google)，
    现有实现也应考虑迁移。
</Note>

## 设置

LangChain.js 根据你是在 Node.js 环境还是 Web 环境中运行，支持两种不同的认证方式。
它还支持 Vertex AI Express Mode 所使用的认证方式，这两类包都可以使用。

要访问 `ChatVertexAI` 模型，你需要在 Google Cloud Platform（GCP）账号中配置 Google VertexAI、保存凭证文件，并安装 `@langchain/google-vertexai` 集成包。在 Node.js 中，这个包使用 [`@langchain/google-gauth`](https://github.com/langchain-ai/langchainjs/tree/main/libs/providers/langchain-google-gauth) 进行认证（无需单独安装）。

### 凭证

前往你的 [GCP account](https://console.cloud.google.com/) 生成凭证文件。完成后，设置 `GOOGLE_APPLICATION_CREDENTIALS` 环境变量：

```bash
export GOOGLE_APPLICATION_CREDENTIALS="path/to/your/credentials.json"
```

或者，在本地机器上运行 `gcloud auth application-default login`，使用 Application Default Credentials。

如果你运行在 Web 环境中，请安装 `@langchain/google-vertexai-web` 包（它使用 [`@langchain/google-webauth`](https://github.com/langchain-ai/langchainjs/tree/main/libs/providers/langchain-google-webauth) 做认证）。然后把 service account JSON 放入 `GOOGLE_WEB_CREDENTIALS`：

```bash
export GOOGLE_WEB_CREDENTIALS='{"type":"service_account","project_id":"YOUR_PROJECT-12345",...}'
```

`GOOGLE_VERTEX_AI_WEB_CREDENTIALS` 也受支持，但已被弃用。

如果你使用 Vertex AI Express Mode，可以安装 `@langchain/google-vertexai` 或 `@langchain/google-vertexai-web` 任一包。
然后前往 [Express Mode](https://console.cloud.google.com/vertex-ai/studio) API Key 页面，把你的 API Key 设置到 `GOOGLE_API_KEY` 环境变量中：

```bash
export GOOGLE_API_KEY="api_key_value"
```

如果你希望自动追踪模型调用，也可以取消下面的注释并设置 [LangSmith](/langsmith/observability) API key：

```bash
# export LANGSMITH_TRACING="true"
# export LANGSMITH_API_KEY="your-api-key"
```

## 实例化

现在可以实例化模型对象并生成聊天补全：

```typescript
import { ChatVertexAI } from "@langchain/google-vertexai"
// Uncomment the following line if you're running in a web environment:
// import { ChatVertexAI } from "@langchain/google-vertexai-web"

const llm = new ChatVertexAI({
    model: "gemini-2.5-flash",
    temperature: 0,
    maxRetries: 2,
    // For web, authOptions.credentials
    // authOptions: { ... }
    // other params...
})
```

## 调用

```typescript
const aiMsg = await llm.invoke([
    [
        "system",

    ],
    ["human", "I love programming."],
```

## 结合 Google 搜索检索进行工具调用

你可以在调用模型时使用 Google search 工具，以便用真实世界信息对内容生成进行 [ground](https://cloud.google.com/vertex-ai/generative-ai/docs/model-reference/grounding)，从而减少幻觉。

`gemini-2.0-flash-exp` 当前不支持 grounding。

你可以选择通过 Google Search 进行 grounding，也可以使用自定义 data store。下面分别给出两种示例：

### Google 搜索检索

使用 Google Search 的 grounding 示例：

```typescript
import { ChatVertexAI } from "@langchain/google-vertexai"

const searchRetrievalTool = {
  googleSearchRetrieval: {
    dynamicRetrievalConfig: {
      mode: "MODE_DYNAMIC", // Use Dynamic Retrieval
      dynamicThreshold: 0.7, // Default for Dynamic Retrieval threshold
    },
  },
};

const searchRetrievalModel = new ChatVertexAI({
  model: "gemini-2.5-pro",
  temperature: 0,
  maxRetries: 0,
}).bindTools([searchRetrievalTool]);

const searchRetrievalResult = await searchRetrievalModel.invoke("Who won the 2024 NBA Finals?");

console.log(searchRetrievalResult.content);
```

```text
The Boston Celtics won the 2024 NBA Finals, defeating the Dallas Mavericks 4-1 in the series to claim their 18th NBA championship. This victory marked their first title since 2008 and established them as the team with the most NBA championships, surpassing the Los Angeles Lakers' 17 titles.
```

### 使用 data store 的 Google 搜索检索

首先，设置你的 data store（下面是一个示例 data store 的 schema）：

|    ID   |     Date     |    Team 1   |   Score  |   Team 2   |
|:-------:|:------------:|:-----------:|:--------:|:----------:|
|  3001   |  2023-09-07  |  Argentina  |  1 - 0   |  Ecuador   |
|  3002   |  2023-09-12  |  Venezuela  |  1 - 0   |  Paraguay  |
|  3003   |  2023-09-12  |  Chile      |  0 - 0   |  Colombia  |
|  3004   |  2023-09-12  |  Peru       |  0 - 1   |  Brazil    |
|  3005   |  2024-10-15  |  Argentina  |  6 - 0   |  Bolivia   |

然后，在下面的示例中使用这个 data store：

（请注意，你需要把 `projectId` 和 `datastoreId` 替换成你自己的变量）

```typescript
import { ChatVertexAI } from "@langchain/google-vertexai";

const projectId = "YOUR_PROJECT_ID";
const datastoreId = "YOUR_DATASTORE_ID";

const searchRetrievalToolWithDataset = {
  retrieval: {
    vertexAiSearch: {
      datastore: `projects/${projectId}/locations/global/collections/default_collection/dataStores/${datastoreId}`,
    },
    disableAttribution: false,
  },
};

const searchRetrievalModelWithDataset = new ChatVertexAI({
  model: "gemini-2.5-pro",
  temperature: 0,
  maxRetries: 0,
}).bindTools([searchRetrievalToolWithDataset]);

const searchRetrievalModelResult = await searchRetrievalModelWithDataset.invoke(
  "What is the score of Argentina vs Bolivia football game?"
);

console.log(searchRetrievalModelResult.content);
```

```text
Argentina won against Bolivia with a score of 6-0 on October 15, 2024.
```

现在你应该可以得到基于所提供 data store 数据进行 grounding 的结果。

## 上下文缓存

Vertex AI 提供 context caching 功能，可通过在多个 API 请求之间存储和复用较长的消息内容块来优化成本。当你有较长的对话历史，或某些消息片段会在交互中频繁出现时，这一功能尤其有用。

要使用此功能，请先按照[这份官方指南](https://cloud.google.com/vertex-ai/generative-ai/docs/context-cache/context-cache-create)创建一个 context cache。

创建完成后，你可以像下面这样把 cache id 作为运行时参数传入：

```typescript
import { ChatVertexAI } from "@langchain/google-vertexai";

const modelWithCachedContent = new ChatVertexAI({
  model: "gemini-2.5-pro-002",
  location: "us-east5",
});

await modelWithCachedContent.invoke("What is in the content?", {
  cachedContent:
    "projects/PROJECT_NUMBER/locations/LOCATION/cachedContents/CACHE_ID",
});
```

你也可以直接把这个字段绑定到模型实例上：

```typescript
const modelWithBoundCachedContent = new ChatVertexAI({
  model: "gemini-2.5-pro-002",
  location: "us-east5",
}).bind({
  cachedContent:
    "projects/PROJECT_NUMBER/locations/LOCATION/cachedContents/CACHE_ID",
});

```

请注意，并非所有模型当前都支持上下文缓存。
