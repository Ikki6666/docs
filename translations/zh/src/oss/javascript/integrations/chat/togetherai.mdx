## 设置

要访问 `ChatTogetherAI` 模型，请创建 Together 账号、[获取 API key](https://api.together.xyz/)，并安装 `@langchain/together-ai` 集成包。

### 凭证

前往 [api.together.ai](https://api.together.ai/) 注册 Together AI 并生成 API key。设置 `TOGETHER_AI_API_KEY` 环境变量：

```bash
export TOGETHER_AI_API_KEY="your-api-key"
```

如果你希望自动追踪模型调用，也可以取消下面的注释并设置 [LangSmith](/langsmith/observability) API key：

```bash
# export LANGSMITH_TRACING="true"
# export LANGSMITH_API_KEY="your-api-key"
```

### 安装

LangChain 的 `ChatTogetherAI` 集成位于 `@langchain/together-ai` 包中：

<CodeGroup>
```bash npm
npm install @langchain/together-ai @langchain/core
```
```bash yarn
yarn add @langchain/together-ai @langchain/core
```
```bash pnpm
pnpm add @langchain/together-ai @langchain/core
```
</CodeGroup>

## 实例化

现在可以实例化模型对象并生成聊天补全：

```typescript
import { ChatTogetherAI } from "@langchain/together-ai";

const llm = new ChatTogetherAI({
    model: "meta-llama/Meta-Llama-3.1-70B-Instruct-Turbo",
    temperature: 0,
    // other params...
})
```

## 调用

```typescript
const aiMsg = await llm.invoke([
    [
        "system",
        "You are a helpful assistant that translates English to French. Translate the user sentence.",
    ],
    ["human", "I love programming."],
])
aiMsg
```
