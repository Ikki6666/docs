## 设置

要访问 Anthropic 模型，你需要注册并获取一个 [Anthropic API key](https://www.anthropic.com/)，并安装 `@langchain/anthropic` 集成包。

### 凭证

前往 [Anthropic 官网](https://www.anthropic.com/) 注册并生成 API key。完成后，设置 `ANTHROPIC_API_KEY` 环境变量：

```bash
export ANTHROPIC_API_KEY="your-api-key"
```

如果你希望自动追踪模型调用，也可以取消下面的注释并设置 [LangSmith](/langsmith/observability) API key：

```bash
# export LANGSMITH_TRACING="true"
# export LANGSMITH_API_KEY="your-api-key"
```

### 安装

LangChain 的 `ChatAnthropic` 集成位于 `@langchain/anthropic` 包中：

<CodeGroup>
```bash npm
npm install @langchain/anthropic @langchain/core
```
```bash yarn
yarn add @langchain/anthropic @langchain/core
```
```bash pnpm
pnpm add @langchain/anthropic @langchain/core
```
</CodeGroup>

## 实例化

现在可以实例化模型对象并生成聊天补全：

```typescript
import { ChatAnthropic } from "@langchain/anthropic"

const llm = new ChatAnthropic({
    model: "claude-haiku-4-5-20251001",
    temperature: 0,
    maxTokens: undefined,
    maxRetries: 2,
    // other params...
});
```

## 调用

```typescript
const aiMsg = await llm.invoke([
    [
        "system",
        "You are a helpful assistant that translates English to French. Translate the user sentence.",
    ],
    ["human", "I love programming."],
])
aiMsg
```

## 内容块

Anthropic 模型与多数其他模型的一个关键差异在于：单条 Anthropic @[`AIMessage`] 的内容既可能是单个字符串，也可能是**内容块列表**。例如，当 Anthropic 模型[调用工具](/oss/langchain/tools)时，工具调用会成为消息内容的一部分，同时也会暴露在标准化的 `AIMessage.tool_calls` 字段中。
