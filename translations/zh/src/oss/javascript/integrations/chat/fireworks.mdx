## 设置

要访问 `ChatFireworks` 模型，你需要创建 Fireworks 账号、获取 API key，并安装 `@langchain/fireworks` 集成包。

### 凭证

前往 [Fireworks 官网](https://fireworks.ai/login) 注册 Fireworks 并生成 API key。完成后，设置 `FIREWORKS_API_KEY` 环境变量：

```bash
export FIREWORKS_API_KEY="your-api-key"
```

如果你希望自动追踪模型调用，也可以取消下面的注释并设置 [LangSmith](/langsmith/observability) API key：

```bash
# export LANGSMITH_TRACING="true"
# export LANGSMITH_API_KEY="your-api-key"
```

### 安装

LangChain 的 `ChatFireworks` 集成位于 `@langchain/fireworks` 包中：

<CodeGroup>
```bash npm
npm install @langchain/fireworks @langchain/core
```
```bash yarn
yarn add @langchain/fireworks @langchain/core
```
```bash pnpm
pnpm add @langchain/fireworks @langchain/core
```
</CodeGroup>

## 实例化

现在可以实例化模型对象并生成聊天补全：

```typescript
import { ChatFireworks } from "@langchain/fireworks"

const llm = new ChatFireworks({
    model: "accounts/fireworks/models/llama-v3p1-70b-instruct",
    temperature: 0,
    maxTokens: undefined,
    timeout: undefined,
    maxRetries: 2,
    // other params...
})
```

## 调用

```typescript
const aiMsg = await llm.invoke([
    [
        "system",
        "You are a helpful assistant that translates English to French. Translate the user sentence.",
    ],
    ["human", "I love programming."],
])

```
