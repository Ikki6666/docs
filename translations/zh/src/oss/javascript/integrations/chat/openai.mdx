## 设置

要访问 OpenAI 模型，你需要创建 OpenAI 账号、获取 API key，并安装 `@langchain/openai` 集成包。

### 凭证

前往 [OpenAI Platform](https://platform.openai.com/docs/api-reference/authentication) 注册并生成 API key。完成后，请在环境中设置 `OPENAI_API_KEY` 环境变量：

```bash
export OPENAI_API_KEY="your-api-key"
```

如果你希望自动追踪模型调用，也可以取消下面的注释并设置 [LangSmith](/langsmith/observability) API key：

```bash
# export LANGSMITH_TRACING="true"
# export LANGSMITH_API_KEY="your-api-key"
```

### 安装

LangChain 的 `ChatOpenAI` 集成位于 `@langchain/openai` 包中：

<CodeGroup>
```bash npm
npm install @langchain/openai @langchain/core
```
```bash yarn
yarn add @langchain/openai @langchain/core
```
```bash pnpm
pnpm add @langchain/openai @langchain/core
```
</CodeGroup>

## 实例化

现在可以实例化模型对象并生成聊天补全：

```typescript
import { ChatOpenAI } from "@langchain/openai"

const llm = new ChatOpenAI({
    model: "gpt-5.5",
    temperature: 0,
    maxTokens: undefined,
    timeout: undefined,
    maxRetries: 2,
    // other params...
})
```

## 调用

```typescript
const aiMsg = await llm.invoke([
    [
        "system",
        "You are a helpful assistant that translates English to French. Translate the user sentence.",
    ],
    ["human", "I love programming."],
])
aiMsg
```

## 自定义 URL

如果你要连接代理、兼容 OpenAI 的第三方网关，或本地模拟服务，可以自定义 `baseURL` / `base_url`。

## 自定义请求头

你也可以通过客户端配置传入自定义请求头。

## 关闭流式 usage 元数据

OpenAI 兼容的某些 endpoint 不支持流式 token usage。如果遇到兼容性问题，可以关闭相应的 usage 聚合。

## 调用微调模型

`ChatOpenAI` 支持直接调用 OpenAI 的 fine-tuned 模型。

## 生成元数据

OpenAI 返回的 token 统计、finish reason 和其他 provider 特定字段会出现在 `response_metadata` 中，标准化后的 token 信息也会写入 `usage_metadata`。

## 自定义工具

OpenAI 支持原生工具调用。你可以定义自定义工具 schema，并把它们传给模型。

## `strict: true`

当你希望工具参数或结构化输出严格匹配给定 schema 时，可以使用 `strict: true`。

## 结构化输出

`ChatOpenAI` 支持通过 schema 约束模型返回结构化 JSON。

## Responses API

`ChatOpenAI` 也支持 OpenAI 的 Responses API，用于统一文本、工具、多模态与更丰富的响应控制能力。

### 内置工具

Responses API 可以与 OpenAI 的内置工具能力协同工作。

### 推理模型

对于 reasoning 类模型，你可以配置更适合推理场景的参数和请求选项。

## Prompt 缓存

OpenAI 支持一定形式的 prompt caching，用于降低长上下文请求的成本。
