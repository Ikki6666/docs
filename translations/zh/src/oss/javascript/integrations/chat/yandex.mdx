LangChain.js 支持调用 [YandexGPT](https://cloud.yandex.com/en/services/yandexgpt) 聊天模型。

## 设置

首先，你应该[创建一个 service account](https://cloud.yandex.com/en/docs/iam/operations/sa/create)，并赋予 `ai.languageModels.user` 角色。

接下来，你有两种认证方式：

- [IAM token](https://cloud.yandex.com/en/docs/iam/operations/iam-token/create-for-sa)。
  你可以在构造函数参数中通过 `iam_token` 指定 token，或者通过环境变量 `YC_IAM_TOKEN` 指定。
- [API key](https://cloud.yandex.com/en/docs/iam/operations/api-key/create)
  你可以在构造函数参数中通过 `api_key` 指定 key，或者通过环境变量 `YC_API_KEY` 指定。

## 用法

<Tip>
请参见[本节中的 LangChain 包通用安装说明](/oss/langchain/install)。
</Tip>

```bash npm
npm install @langchain/yandex @langchain/core
```

```typescript
import { ChatYandexGPT } from "@langchain/yandex/chat_models";
import { HumanMessage, SystemMessage } from "@langchain/core/messages";

const chat = new ChatYandexGPT();

const res = await chat.invoke([
  new SystemMessage(
    "You are a helpful assistant that translates English to French."
  ),
  new HumanMessage("I love programming."),
]);
console.log(res);

/*
AIMessage {
  lc_serializable: true,
  lc_kwargs: { content: "Je t'aime programmer.", additional_kwargs: {} },
  lc_namespace: [ 'langchain', 'schema' ],
  content: "Je t'aime programmer.",
  name: undefined,
  additional_kwargs: {}
}
 */
```
