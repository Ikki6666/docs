该库支持访问多种 Google 模型，包括 Gemini 系列模型，以及它们的 Nano Banana 图像生成模型。你可以通过 Google 的 [Google AI](https://ai.google.dev/) API（有时也称 Generative AI API 或 AI Studio API）或 Google Cloud Platform 的 [Vertex AI](https://cloud.google.com/vertex-ai) 服务来访问这些模型。

本文将帮助你开始使用 `ChatGoogle` [chat models](/oss/langchain/models)。
如需查看 `ChatGoogle` 全部功能与配置的详细文档，请前往 [API reference](https://reference.langchain.com/javascript/langchain-google/index/ChatGoogle)。

<Tip>
  `@langchain/google` 是所有新 Google Gemini 集成的推荐包。
  它取代了较旧的 [`@langchain/google-genai`](/oss/integrations/chat/google_generative_ai)
  和 [`@langchain/google-vertexai`](/oss/integrations/chat/google_vertex_ai) 包。
  迁移细节请参见 [legacy packages](/oss/integrations/providers/google#legacy-packages)。
</Tip>

## 设置

### 通过 AI Studio 的凭证（API Key）

如果你想通过 Google AI Studio（有时称 Generative AI API）使用模型，则需要一个 API key。你可以从 [Google AI Studio](https://aistudio.google.com/app/apikey) 获取。

拿到 API key 后，可以将其设置为环境变量：

```bash
export GOOGLE_API_KEY="your-api-key"
```

或者直接传给模型构造函数：

```typescript
import { ChatGoogle } from "@langchain/google";

const llm = new ChatGoogle({
  apiKey: "your-api-key",
  model: "gemini-2.5-flash",
});
```

### 通过 Vertex AI Express Mode 的凭证（API Key）

Vertex AI 也支持 [Express Mode](https://cloud.google.com/vertex-ai/docs/start/introduction-unified-platform#express-mode)，它允许你使用 API key 做认证。你可以从 [Google Cloud Console](https://console.cloud.google.com/vertex-ai/studio/api-key) 获取 Vertex AI API key。

拿到 API key 后，可以将其设置为环境变量：

```bash
export GOOGLE_API_KEY="your-api-key"
```

当使用 [Vertex AI Express Mode](https://docs.cloud.google.com/vertex-ai/generative-ai/docs/start/express-mode/overview) 时，还需要在实例化模型时把平台类型指定为 `gcp`。

```typescript
const llm = new ChatGoogle({
  model: "gemini-2.5-flash",
  platformType: "gcp",
  // apiKey: "...", // Optional if GOOGLE_API_KEY is set
});
```

### 通过 Vertex AI 的凭证（OAuth Application Default Credentials / ADC）

对于 Google Cloud 上的生产环境，推荐使用 [Application Default Credentials (ADC)](https://cloud.google.com/docs/authentication/provide-credentials-adc)。
Node.js 环境支持这种方式。

如果你运行在本地机器上，可以安装 [Google Cloud SDK](https://cloud.google.com/sdk)，然后执行：

```bash
gcloud auth application-default login
```

或者，也可以把 `GOOGLE_APPLICATION_CREDENTIALS` 环境变量设置为 service account key 文件路径：

```bash
export GOOGLE_APPLICATION_CREDENTIALS="/path/to/your/service-account-key.json"
```

### 通过 Vertex AI 的凭证（OAuth saved credentials）

如果你运行在 Web 环境中，或者想直接提供凭证，可以使用 `GOOGLE_CLOUD_CREDENTIALS` 环境变量。这里应该放 service account key 文件的**内容**，而不是路径。

```bash
export GOOGLE_CLOUD_CREDENTIALS='{"type":"service_account","project_id":"your-project-id",...}'
```

你也可以通过 `credentials` 参数在代码中直接提供这些凭证。

```typescript
const llm = new ChatGoogle({
  model: "gemini-2.5-flash",
  platformType: "gcp",
  credentials: {
    type: "service_account",
    project_id: "your-project-id",
    private_key_id: "your-private-key-id",
    private_key: "your-private-key",
    client_email: "your-service-account-email",
    client_id: "your-client-id",
    auth_uri: "https://accounts.google.com/o/oauth2/auth",
    token_uri: "https://oauth2.googleapis.com/token",
    auth_provider_x509_cert_url: "https://www.googleapis.com/oauth2/v1/certs",
    client_x509_cert_url: "your-cert-url",
  }
});
```

## 实例化

导入路径取决于你是在 Node.js 环境还是 Web/Edge 环境中运行。

<CodeGroup>
```typescript Node.js
import { ChatGoogle } from "@langchain/google/node";
```
```typescript Web/Edge
import { ChatGoogle } from "@langchain/google";
```
</CodeGroup>

模型会根据你的配置自动决定使用 Google AI API 还是 Vertex AI：
- 如果你提供 `apiKey`（或设置了 `GOOGLE_API_KEY`），默认使用 Google AI。
- 如果你提供 `credentials`（或在 Node 中设置 `GOOGLE_APPLICATION_CREDENTIALS` / `GOOGLE_CLOUD_CREDENTIALS`），默认使用 Vertex AI。

### Google AI（AI Studio）

```typescript
const llm = new ChatGoogle({
  model: "gemini-2.5-flash",
  maxRetries: 2,
  // apiKey: "...", // Optional if GOOGLE_API_KEY is set
});
```

### Vertex AI

```typescript
const llm = new ChatGoogle({
  model: "gemini-2.5-flash",
  // credentials: { ... }, // Optional if using ADC or GOOGLE_CLOUD_CREDENTIALS
});
```

### Vertex AI Express Mode

要通过 API key 使用 Vertex AI（Express Mode），你必须显式设置 `platformType`。

```typescript
const llm = new ChatGoogle({
  model: "gemini-2.5-flash",
  platformType: "gcp",
  // apiKey: "...", // Optional if GOOGLE_API_KEY is set
});
```

### 模型配置最佳实践

尽管 `ChatGoogle` 支持 `temperature`、`topP`、`topK` 等标准模型参数，但对于 Gemini 模型，最佳实践通常是保留这些参数的默认值。模型的调优往往围绕这些默认值展开。

如果你想控制模型的“随机性”或“创造性”，更推荐在提示词或 system prompt 中通过明确指令来实现（例如 “Be creative” 或 “Give a concise factual answer”），而不是直接调整 temperature。

## 调用

```typescript
import { HumanMessage, SystemMessage } from "@langchain/core/messages";

const aiMsg = await llm.invoke([
  new SystemMessage(
    "You are a helpful assistant that translates English to French. Translate the user sentence."
  ),
  new HumanMessage("I love programming."),
]);
```

```typescript
console.log(aiMsg.text);
```

## 响应元数据

### Token Usage

`ChatGoogle` 会把 token 使用情况暴露到标准的 `usage_metadata` 和 provider 特定的 `response_metadata` 中，便于你做成本和性能分析。

### Logprobs

Google Gemini 支持 logprobs，但与其他一些提供方相比，能力更受限。若你要依赖该特性，请同时参考对应模型与 provider 文档。

## 安全设置

Gemini 模型具有默认安全设置，这些设置可以被覆盖。如果模型经常返回安全拦截结果，可以调整 `safetySettings`。

## 结构化输出

`ChatGoogle` 支持结构化输出，可以把 schema 传给模型，以获得更稳定的 JSON 形状结果。

## 工具调用

### 标准工具

`ChatGoogle` 支持标准工具调用模式，你可以像在其他模型上一样绑定工具 schema，并让模型决定何时调用。

### 专用工具

Google 还提供一些更偏 provider 原生能力的工具，例如 grounding、代码执行、图像和媒体相关能力。这些工具的使用方式和普通工具类似，但通常会有模型支持范围或额外参数限制。

## 上下文缓存

Google 支持上下文缓存，用于在多次请求中复用大块稳定上下文，以降低延迟和成本。

## 多模态请求

### 图片

`ChatGoogle` 支持图片输入，可通过标准多模态消息格式传入。

### 音频

支持的模型还可以接受音频输入。

### 视频

支持的模型还可以接受视频输入。

## 推理 / Thinking

部分 Google 模型支持 reasoning / thinking 配置，用于控制模型在回答前进行更深入推理。

## 使用 Nano Banana 和 Nano Banana Pro 生成图片

`ChatGoogle` 支持 Google 的 Nano Banana 图像生成模型。具体模型 ID、输入模式和输出格式请参考英文源文档与 API reference。

## 语音生成（TTS）

支持的模型可以执行文本转语音（TTS）生成。

### 多说话人 TTS

某些 TTS 模式支持多说话人配置。
