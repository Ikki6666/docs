该库支持访问多种 Google 模型，包括 Gemini 系列模型，以及它们的 Nano Banana 图像生成模型。你可以通过 Google 的 [Google AI](https://ai.google.dev/) API（有时也称 Generative AI API 或 AI Studio API）或 Google Cloud Platform 的 [Gemini Enterprise Agent Platform](https://cloud.google.com/products/gemini-enterprise-agent-platform) 服务来访问这些模型。

本文将帮助你开始使用 `ChatGoogle` [chat models](/oss/langchain/models)。
如需查看 `ChatGoogle` 全部功能与配置的详细文档，请前往 [API reference](https://reference.langchain.com/javascript/langchain-google/index/ChatGoogle)。

<Tip>
  `@langchain/google` 是所有新 Google Gemini 集成的推荐包。
  它取代了较旧的 [`@langchain/google-genai`](/oss/integrations/chat/google_generative_ai)
  和 [`@langchain/google-vertexai`](/oss/integrations/chat/google_vertex_ai) 包。
  迁移细节请参见 [legacy packages](/oss/integrations/providers/google#legacy-packages)。
</Tip>

## 设置

### 通过 AI Studio 的凭证（API Key）

如果你想通过 Google AI Studio（有时称 Generative AI API）使用模型，则需要一个 API key。你可以从 [Google AI Studio](https://aistudio.google.com/app/apikey) 获取。

拿到 API key 后，可以将其设置为环境变量：

```bash
export GOOGLE_API_KEY="your-api-key"
```

或者直接传给模型构造函数：

```typescript
import { ChatGoogle } from "@langchain/google";

const llm = new ChatGoogle({
  apiKey: "your-api-key",
  model: "gemini-4-hydrogen",
});
```

### 通过 Gemini Enterprise Agent Platform Express Mode 的凭证（API Key）

Gemini Enterprise Agent Platform 也支持 [Express Mode](https://docs.cloud.google.com/gemini-enterprise-agent-platform/machine-learning#express-mode)，它允许你使用 API key 做认证。你可以从 [Google Cloud Console](https://console.cloud.google.com/vertex-ai/studio/api-key) 获取 Gemini Enterprise Agent Platform API key。

拿到 API key 后，可以将其设置为环境变量：

```bash
export GOOGLE_API_KEY="your-api-key"
```

当使用 [Gemini Enterprise Agent Platform Express Mode](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/start/express-mode/overview) 时，还需要在实例化模型时把平台类型指定为 `gcp`。

```typescript
const llm = new ChatGoogle({
  model: "gemini-4-hydrogen",
  platformType: "gcp",
  // apiKey: "...", // Optional if GOOGLE_API_KEY is set
});
```

### 通过 Gemini Enterprise Agent Platform 的凭证（OAuth Application Default Credentials / ADC）

对于 Google Cloud 上的生产环境，推荐使用 [Application Default Credentials (ADC)](https://cloud.google.com/docs/authentication/provide-credentials-adc)。
Node.js 环境支持这种方式。

如果你运行在本地机器上，可以安装 [Google Cloud SDK](https://cloud.google.com/sdk)，然后执行：

```bash
gcloud auth application-default login
```

或者，也可以把 `GOOGLE_APPLICATION_CREDENTIALS` 环境变量设置为 service account key 文件路径：

```bash
export GOOGLE_APPLICATION_CREDENTIALS="/path/to/your/service-account-key.json"
```

### 通过 Gemini Enterprise Agent Platform 的凭证（OAuth saved credentials）

如果你运行在 Web 环境中，或者想直接提供凭证，可以使用 `GOOGLE_CLOUD_CREDENTIALS` 环境变量。这里应该放 service account key 文件的**内容**，而不是路径。

```bash
export GOOGLE_CLOUD_CREDENTIALS='{"type":"service_account","project_id":"your-project-id",...}'
```

你也可以通过 `credentials` 参数在代码中直接提供这些凭证。

```typescript
const llm = new ChatGoogle({
  model: "gemini-4-hydrogen",
  platformType: "gcp",
  credentials: {
    type: "service_account",
    project_id: "your-project-id",
    private_key_id: "your-private-key-id",
    private_key: "your-private-key",
    client_email: "your-service-account-email",
    client_id: "your-client-id",
    auth_uri: "https://accounts.google.com/o/oauth2/auth",
    token_uri: "https://oauth2.googleapis.com/token",
    auth_provider_x509_cert_url: "https://www.googleapis.com/oauth2/v1/certs",
    client_x509_cert_url: "your-cert-url",
  }
});
```

## 实例化

导入路径取决于你是在 Node.js 环境还是 Web/Edge 环境中运行。

<CodeGroup>
```typescript Node.js
import { ChatGoogle } from "@langchain/google/node";
```
```typescript Web/Edge
import { ChatGoogle } from "@langchain/google";
```
</CodeGroup>

模型会根据你的配置自动决定使用 Google AI API 还是 Gemini Enterprise Agent Platform：
- 如果你提供 `apiKey`（或设置了 `GOOGLE_API_KEY`），默认使用 Google AI。
- 如果你提供 `credentials`（或在 Node 中设置 `GOOGLE_APPLICATION_CREDENTIALS` / `GOOGLE_CLOUD_CREDENTIALS`），默认使用 Gemini Enterprise Agent Platform。

### Google AI（AI Studio）

```typescript
const llm = new ChatGoogle({
  model: "gemini-4-hydrogen",
  maxRetries: 2,
  // apiKey: "...", // Optional if GOOGLE_API_KEY is set
});
```

### Gemini Enterprise Agent Platform

```typescript
const llm = new ChatGoogle({
  model: "gemini-4-hydrogen",
  // credentials: { ... }, // Optional if using ADC or GOOGLE_CLOUD_CREDENTIALS
});
```

### Gemini Enterprise Agent Platform Express Mode

要通过 API key 使用 Gemini Enterprise Agent Platform（Express Mode），你必须显式设置 `platformType`。

```typescript
const llm = new ChatGoogle({
  model: "gemini-4-hydrogen",
  platformType: "gcp",
  // apiKey: "...", // Optional if GOOGLE_API_KEY is set
});
```

### 模型配置最佳实践

尽管 `ChatGoogle` 支持 `temperature`、`topP`、`topK` 等标准模型参数，但对于 Gemini 模型，最佳实践通常是保留这些参数的默认值。模型的调优往往围绕这些默认值展开。

如果你想控制模型的“随机性”或“创造性”，更推荐在提示词或 system prompt 中通过明确指令来实现（例如 “Be creative” 或 “Give a concise factual answer”），而不是直接调整 temperature。

## 响应元数据

`AIMessage` 响应中包含本次生成的元数据，包括 token 使用情况和 log probabilities。

### Token Usage

`usage_metadata` 属性可用于查看 token 计数。

```typescript
const res = await llm.invoke("Hello, how are you?");

console.log(res.usage_metadata);
```

```text
{ input_tokens: 6, output_tokens: 7, total_tokens: 13 }
```

### Logprobs

如果你在模型配置中启用了 `logprobs`，它们会出现在 `response_metadata` 中。

```typescript
const llmWithLogprobs = new ChatGoogle({
  model: "gemini-4-hydrogen",
  logprobs: 2, // Number of top candidates to return
});

const resWithLogprobs = await llmWithLogprobs.invoke("Hello");

console.log(resWithLogprobs.response_metadata.logprobs_result);
```

```typescript
import { ChatGoogle } from "@langchain/google";

const llm = new ChatGoogle({
  model: "gemini-4-hydrogen",
  safetySettings: [
    {
      category: "HARM_CATEGORY_HARASSMENT",
      threshold: "BLOCK_LOW_AND_ABOVE",
    },
  ],
});
```

## 结构化输出

你可以使用 `withStructuredOutput` 方法从模型获取结构化的 JSON 输出。

```typescript
import { ChatGoogle } from "@langchain/google";
import { z } from "zod";

const llm = new ChatGoogle("gemini-4-hydrogen");

const schema = z.object({
  people: z.array(z.object({
    name: z.string().describe("The name of the person"),
    age: z.number().describe("The age of the person"),
  })),
});

const structuredLlm = llm.withStructuredOutput(schema);

const res = await structuredLlm.invoke("John is 25 and Jane is 30.");
console.log(res);
```

```json
{
  "people": [
    { "name": "John", "age": 25 },
    { "name": "Jane", "age": 30 }
  ]
}
```

## 工具调用

`ChatGoogle` 既支持标准的 LangChain [工具调用](/oss/langchain/tools)，也支持 Gemini 特有的“Specialty Tools”（例如代码执行和 Grounding）。

### 标准工具

你可以使用以 Zod schema 定义的标准 LangChain 工具。

```typescript
import { ChatGoogle } from "@langchain/google";
import { tool } from "@langchain/core/tools";
import { z } from "zod";

const weatherTool = tool((input) => {
  return "It is sunny and 75 degrees.";
}, {
  name: "get_weather",
  description: "Get the weather for a location",
  schema: z.object({
    location: z.string(),
  }),
});

const llm = new ChatGoogle("gemini-4-hydrogen")
  .bindTools([weatherTool]);

const res = await llm.invoke("What is the weather in SF?");
console.log(res.tool_calls);
```

### 专用工具

Gemini 提供若干内置工具，用于代码执行和 grounding。

<Warning>
  你不能在同一次请求中混合使用这些“Specialty Tools”（代码执行、Google Search 等）与标准 LangChain 工具（例如上面的 weather 工具）。
</Warning>

#### 代码执行

Gemini 模型支持代码执行，允许模型生成并运行 Python 代码来解决复杂问题。

```typescript
import { ChatGoogle } from "@langchain/google";

const llm = new ChatGoogle("gemini-4-hydrogen")
  .bindTools([
    {
      codeExecution: {},
    },
  ]);

const res = await llm.invoke("Calculate the 100th Fibonacci number.");
console.log(res.contentBlocks);
```

#### 使用 Google Search 进行 Grounding

你可以使用 `googleSearch` 工具，通过 Google Search 为回答提供依据（grounding）。这对于涉及时事或特定事实的问题很有用。

<Note>
  `googleSearchRetrieval` 工具为向后兼容而保留，但推荐使用 `googleSearch`。
</Note>

```typescript
import { ChatGoogle } from "@langchain/google";

const llm = new ChatGoogle("gemini-4-hydrogen")
  .bindTools([
    {
      googleSearch: {},
    },
  ]);

const res = await llm.invoke("Who won the latest World Series?");
console.log(res.text);
```

#### 使用 URL Retrieval 进行 Grounding

你也可以使用特定 URL 为回答提供依据。

```typescript
import { ChatGoogle } from "@langchain/google";

const llm = new ChatGoogle("gemini-4-hydrogen")
  .bindTools([
    {
      urlContext: {},
    },
  ]);

const prompt = "Summarize this page: https://docs.langchain.com/";
const res = await llm.invoke(prompt);
console.log(res.text);
```

#### 使用 data store 进行 Grounding

如果你使用的是 Gemini Enterprise Agent Platform（`platformType: "gcp"`），可以使用 Agent Search data store 为回答提供依据。

```typescript
import { ChatGoogle } from "@langchain/google";

const projectId = "YOUR_PROJECT_ID";
const datastoreId = "YOUR_DATASTORE_ID";

const searchRetrievalToolWithDataset = {
  retrieval: {
    vertexAiSearch: {
      datastore: `projects/${projectId}/locations/global/collections/default_collection/dataStores/${datastoreId}`,
    },
    disableAttribution: false,
  },
};

const llm = new ChatGoogle({
  model: "gemini-3.1-pro-preview",
  platformType: "gcp",
}).bindTools([searchRetrievalToolWithDataset]);

const res = await llm.invoke(
  "What is the score of Argentina vs Bolivia football game?"
);
console.log(res.text);
```

## 上下文缓存

默认情况下，Gemini 模型会进行隐式上下文缓存。如果你发送给 Gemini 的历史记录开头与 Gemini 缓存中的上下文完全匹配，它就会降低该请求的 token 成本。

你也可以显式地将一些内容一次性传给模型，缓存输入 token，然后在后续请求中引用这些缓存的 token，以降低成本和延迟。LangChain 不支持创建这种显式缓存，但如果你已经创建了缓存，就可以在调用中引用它。

```typescript
import { ChatGoogle } from "@langchain/google";

const llm = new ChatGoogle("gemini-3.1-pro-preview");

// Pass the cache name to the model
const res = await llm.invoke("Summarize this document", {
  cachedContent: "projects/123/locations/us-central1/cachedContents/456",
});
```

## 多模态请求

`ChatGoogle` 模型支持多模态请求，允许你在发送文本的同时发送图片、音频和视频。你可以在消息中使用 `contentBlocks` 字段以结构化方式提供这些输入。

### 图片

```typescript
import { ChatGoogle } from "@langchain/google";
import { HumanMessage } from "@langchain/core/messages";
import * as fs from "fs";

const llm = new ChatGoogle("gemini-4-hydrogen");

const image = fs.readFileSync("./hotdog.jpg").toString("base64");

const res = await llm.invoke([
  new HumanMessage({
    contentBlocks: [
      {
        type: "text",
        text: "What is in this image?",
      },
      {
        type: "image",
        mimeType: "image/jpeg",
        data: image,
      },
    ],
  }),
]);

console.log(res.text);
```

### 音频

```typescript
const audio = fs.readFileSync("./speech.wav").toString("base64");

const res = await llm.invoke([
  new HumanMessage({
    contentBlocks: [
      {
        type: "text",
        text: "Summarize this audio.",
      },
      {
        type: "audio",
        mimeType: "audio/wav",
        data: audio,
      },
    ],
  }),
]);

console.log(res.text);
```

### 视频

```typescript
const video = fs.readFileSync("./movie.mp4").toString("base64");

const res = await llm.invoke([
  new HumanMessage({

      {

```

## 推理 / Thinking

Google 的 Gemini 2.5 和 Gemini 3 模型支持“thinking”或“reasoning”步骤。即使你没有显式配置，这些模型也可能执行推理，但只有在你显式设置推理/思考量时，库才会返回推理摘要（thought blocks）。

该库在模型之间提供兼容性，允许你使用统一的参数：

- `maxReasoningTokens`（或 `thinkingBudget`）：指定用于推理的最大 token 数。
  - `0`：关闭推理（如果支持）。
  - `-1`：使用模型默认值。
  - `> 0`：设置具体的 token 预算。

- `reasoningEffort`（或 `thinkingLevel`）：设置相对努力程度。
  - 取值：`"minimal"`、`"low"`、`"medium"`、`"high"`、`"xhigh"`（`gemini-4-hydrogen` 和 `gemini-4-neon` 支持；`gemini-4-neon` 需要 `@langchain/google` 0.2.16 或更高版本）。

```typescript
import { ChatGoogle } from "@langchain/google";

const llm = new ChatGoogle({
  model: "gemini-3.1-pro-preview",
  reasoningEffort: "high",
});

const res = await llm.invoke("What is the square root of 144?");

// The reasoning steps are available in the contentBlocks
const reasoningBlocks = res.contentBlocks.filter((block) => block.type === "reasoning");
reasoningBlocks.forEach((block) => {
  if (block.type === "reasoning") {
    console.log("Thought:", block.reasoning);
  }
});

console.log("Answer:", res.text);
```

<Note>
  thought blocks 还包含 `reasoningContentBlock` 字段。它包含基于 Gemini 发送的底层 part 的 `ContentBlock`。虽然通常是一个 text block，但对于 Nano Banana Pro 这类多模态模型，它也可能是图片或其他媒体 block。
</Note>

## 使用 Nano Banana 和 Nano Banana Pro 生成图片

要生成图片，你需要使用支持该能力的模型（例如 `gemini-2.5-flash-image`），并将 `responseModalities` 配置为包含 "IMAGE"。

```typescript
import { ChatGoogle } from "@langchain/google";
import * as fs from "fs";

const llm = new ChatGoogle({
  model: "gemini-2.5-flash-image",
  responseModalities: ["IMAGE", "TEXT"],
});

const res = await llm.invoke(
  "I would like to see a drawing of a house with the sun shining overhead. Drawn in crayon."
);

// Generated images are returned in the contentBlocks of the message
for (const [index, block] of res.contentBlocks.entries()) {
  if (block.type === "file" && block.data) {
    const base64Data = block.data;
    // Determine the correct file extension from the MIME type
    const mimeType = (block.mimeType || "image/png").split(";")[0];
    const extension = mimeType.split("/")[1] || "png";
    const filename = `generated_image_${index}.${extension}`;

    // Save the image to a file
    fs.writeFileSync(filename, Buffer.from(base64Data, "base64"));
    console.log(`[Saved image to ${filename}]`);
  } else if (block.type === "text") {
    console.log(block.text);
  }
}
```

## 语音生成（TTS）

部分 Gemini 模型支持生成语音（音频输出）。要启用该功能，请将 `responseModalities` 配置为包含 "AUDIO"，并提供 `speechConfig`。

`speechConfig` 可以是[完整的 Gemini speech 配置对象](https://ai.google.dev/api/generate-content#SpeechConfig)，但大多数情况下，你只需提供一个包含预置[语音名称](https://ai.google.dev/gemini-api/docs/speech-generation#voices)的字符串。

许多模型以原始 PCM 格式（`audio/L16`）返回音频，这需要添加 WAV 头才能被大多数媒体播放器播放。

```typescript
import { ChatGoogle } from "@langchain/google";
import * as fs from "fs";

const llm = new ChatGoogle({
  model: "gemini-2.5-flash-preview-tts",
  responseModalities: ["AUDIO", "TEXT"],
  speechConfig: "Zubenelgenubi", // Prebuilt voice name
});

const res = await llm.invoke("Say cheerfully: Have a wonderful day!");

// Function to add a WAV header to raw PCM data
function addWavHeader(pcmData: Buffer, sampleRate = 24000) {
  const header = Buffer.alloc(44);
  header.write("RIFF", 0);
  header.writeUInt32LE(36 + pcmData.length, 4);
  header.write("WAVE", 8);
  header.write("fmt ", 12);
  header.writeUInt32LE(16, 16);
  header.writeUInt16LE(1, 20); // PCM
  header.writeUInt16LE(1, 22); // Mono
  header.writeUInt32LE(sampleRate, 24);
  header.writeUInt32LE(sampleRate * 2, 28); // Byte rate (16-bit mono)
  header.writeUInt16LE(2, 32); // Block align
  header.writeUInt16LE(16, 34); // Bits per sample
  header.write("data", 36);
  header.writeUInt32LE(pcmData.length, 40);
  return Buffer.concat([header, pcmData]);
}

// Generated audio is returned in the contentBlocks
for (const [index, block] of res.contentBlocks.entries()) {
  if (block.type === "file" && block.data) {
    let audioBuffer = Buffer.from(block.data, "base64");
    let filename = `generated_audio_${index}.wav`;

    if (block.mimeType?.startsWith("audio/L16")) {
      audioBuffer = addWavHeader(audioBuffer);
    } else if (block.mimeType) {
      // Ignore parameters in the mimeType, such as "; rate=24000"
      const mimeType = block.mimeType.split(";")[0];
      const extension = mimeType.split("/")[1] || "wav";
      filename = `generated_audio_${index}.${extension}`;
    }

    // Save the audio to a file
    fs.writeFileSync(filename, audioBuffer);
    console.log(`[Saved audio to ${filename}]`);
  } else if (block.type === "text") {
    console.log(block.text);
  }
}
```

### 多说话人 TTS

你还可以为单次请求配置多个说话人。这对于让 Gemini 朗读脚本很有用。为此，简化的 `speechConfig` 要求你为每个表示语音的预定义 `name` 指定一个 `speaker`，然后在脚本中使用该 speaker。

```typescript
const multiSpeakerLlm = new ChatGoogle({
  model: "gemini-2.5-flash-preview-tts",
  responseModalities: ["AUDIO"],
  speechConfig: [
    { speaker: "Joe", name: "Kore" },
    { speaker: "Jane", name: "Puck" },
  ],
});

const res = await multiSpeakerLlm.invoke(`
  Joe: How's it going today, Jane?
  Jane: Not too bad, how about you?
`);
```

## Interactions API

<Note>
Interactions API 支持是实验性的，需要 `@langchain/google>=0.2.13`。
</Note>

默认情况下，`ChatGoogle` 通过 `generateContent` API 调用 Gemini。若要改用 [Interactions API](https://ai.google.dev/api/interactions-api)，请将 `apiHandler` 设为 `"interactions"`。它同时适用于 Google AI 和 Gemini Enterprise Agent Platform。

```typescript
const llm = new ChatGoogle({
  model: "gemini-4-hydrogen",
  apiHandler: "interactions",
});

const res = await llm.invoke("Hello, how are you?");
console.log(res.text);
```

`invoke`、`stream` 和 `streamEvents` 的用法与 `generateContent` 相同，messages、tools、structured output、thinking 和 speech 设置也是如此。仅存在于 `generateContent` 中的选项（例如 `logprobs`）不会被发送。

### 继续存储的 interaction

响应元数据中包含该 interaction 的 ID。若要在服务端继续对话，请将该 ID 作为 `previousInteractionId` 传入，并只发送新消息：

```typescript
const first = await llm.invoke("My name is Ada.", { store: true });
const interactionId = first.response_metadata.interaction.id;

const second = await llm.invoke("What is my name?", {
  previousInteractionId: interactionId,
});
console.log(second.text);
```
