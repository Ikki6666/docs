## 设置

[Azure OpenAI](https://azure.microsoft.com/products/ai-services/openai-service/) 是一项云服务，可帮助你快速构建生成式 AI 体验，并使用来自 OpenAI、Meta 等提供方的多样化预构建与精选模型。

LangChain.js 通过 [OpenAI SDK](https://github.com/openai/openai-node) 中新的 Azure 集成来支持 [Azure OpenAI](https://azure.microsoft.com/products/ai-services/openai-service/)。

你可以在[此页面](https://learn.microsoft.com/azure/ai-services/openai/overview)进一步了解 Azure OpenAI 以及它与 OpenAI API 的区别。

### 凭证

如果你还没有 Azure 账号，可以[创建一个免费账号](https://azure.microsoft.com/free/)开始使用。

你还需要部署一个 Azure OpenAI 实例。可以参考[本指南](https://learn.microsoft.com/azure/ai-services/openai/how-to/create-resource?pivots=web-portal)，在 Azure Portal 中完成部署。

实例运行后，请确认你已拿到实例名称和 key。你可以在 Azure Portal 中实例的 "Keys and Endpoint" 部分找到 key。然后，如果你使用 Node.js，可以将凭证设置为环境变量：

```bash
AZURE_OPENAI_API_INSTANCE_NAME=<YOUR_INSTANCE_NAME>
AZURE_OPENAI_API_DEPLOYMENT_NAME=<YOUR_DEPLOYMENT_NAME>
AZURE_OPENAI_API_KEY=<YOUR_KEY>
AZURE_OPENAI_API_VERSION="2024-02-01"
```

如果你希望自动追踪模型调用，也可以取消下面的注释并设置 [LangSmith](/langsmith/observability) API key：

```bash
# export LANGSMITH_TRACING="true"
# export LANGSMITH_API_KEY="your-api-key"
```

## 实例化

现在可以实例化模型对象并生成聊天补全：

```typescript
import { AzureChatOpenAI } from "@langchain/openai"

const llm = new AzureChatOpenAI({
    model: "gpt-5.5",
    temperature: 0,
    maxTokens: undefined,
    maxRetries: 2,
    azureOpenAIApiKey: process.env.AZURE_OPENAI_API_KEY, // In Node.js defaults to process.env.AZURE_OPENAI_API_KEY
    azureOpenAIApiInstanceName: process.env.AZURE_OPENAI_API_INSTANCE_NAME, // In Node.js defaults to process.env.AZURE_OPENAI_API_INSTANCE_NAME
    azureOpenAIApiDeploymentName: process.env.AZURE_OPENAI_API_DEPLOYMENT_NAME, // In Node.js defaults to process.env.AZURE_OPENAI_API_DEPLOYMENT_NAME
    azureOpenAIApiVersion: process.env.AZURE_OPENAI_API_VERSION, // In Node.js defaults to process.env.AZURE_OPENAI_API_VERSION
})
```

## 使用 Azure Managed Identity

如果你使用的是 Azure Managed Identity，可以像这样配置凭证：

```typescript
import {
  DefaultAzureCredential,
  getBearerTokenProvider,
} from "@azure/identity";
import { AzureChatOpenAI } from "@langchain/openai";

const credentials = new DefaultAzureCredential();
const azureADTokenProvider = getBearerTokenProvider(
  credentials,
  "https://cognitiveservices.azure.com/.default"
);

const llmWithManagedIdentity = new AzureChatOpenAI({
  azureADTokenProvider,
  azureOpenAIApiInstanceName: "<your_instance_name>",
  azureOpenAIApiDeploymentName: "<your_deployment_name>",
  azureOpenAIApiVersion: "<api_version>",
});
```

## 使用不同的域名

如果你的实例托管在默认 `openai.azure.com` 之外的域名下，则需要改用 `AZURE_OPENAI_BASE_PATH` 环境变量。
例如，下面演示了如何连接到 `https://westeurope.api.microsoft.com/openai/deployments/{DEPLOYMENT_NAME}`：

```typescript
import { AzureChatOpenAI } from "@langchain/openai";

const llmWithDifferentDomain = new AzureChatOpenAI({
  temperature: 0.9,
  azureOpenAIApiKey: "<your_key>", // In Node.js defaults to process.env.AZURE_OPENAI_API_KEY
  azureOpenAIApiDeploymentName: "<your_deployment_name>", // In Node.js defaults to process.env.AZURE_OPENAI_API_DEPLOYMENT_NAME
  azureOpenAIApiVersion: "<api_version>", // In Node.js defaults to process.env.AZURE_OPENAI_API_VERSION
  azureOpenAIBasePath:
    "https://westeurope.api.microsoft.com/openai/deployments", // In Node.js defaults to process.env.AZURE_OPENAI_BASE_PATH
});

```

## 自定义请求头

你可以通过传入 `configuration` 字段来指定自定义请求头：

```typescript
import { AzureChatOpenAI } from "@langchain/openai";

const llmWithCustomHeaders = new AzureChatOpenAI({
  azureOpenAIApiKey: process.env.AZURE_OPENAI_API_KEY, // In Node.js defaults to process.env.AZURE_OPENAI_API_KEY
  azureOpenAIApiInstanceName: process.env.AZURE_OPENAI_API_INSTANCE_NAME, // In Node.js defaults to process.env.AZURE_OPENAI_API_INSTANCE_NAME
  azureOpenAIApiDeploymentName: process.env.AZURE_OPENAI_API_DEPLOYMENT_NAME, // In Node.js defaults to process.env.AZURE_OPENAI_API_DEPLOYMENT_NAME
  azureOpenAIApiVersion: process.env.AZURE_OPENAI_API_VERSION, // In Node.js defaults to process.env.AZURE_OPENAI_API_VERSION
  configuration: {
    defaultHeaders: {
      "x-custom-header": `SOME_VALUE`,
    },
  },
});

await llmWithCustomHeaders.invoke("Hi there!");
```

`configuration` 字段也接受官方 SDK 支持的其他 `ClientOptions` 参数。

**注意：** 特定的 `api-key` 请求头目前不能通过这种方式覆盖，仍然会传入 `azureOpenAIApiKey` 的值。

## 从 Azure OpenAI SDK 迁移

如果你仍在使用已弃用的 Azure OpenAI SDK 以及 `@langchain/azure-openai` 包，可以按以下步骤迁移到新的 Azure 集成：

1. 安装新的 `@langchain/openai` 包，并移除旧的 `@langchain/azure-openai` 包：

<CodeGroup>
```bash npm
npm install @langchain/openai
```
```bash yarn
yarn add @langchain/openai
```
```bash pnpm
pnpm add @langchain/openai
```
</CodeGroup>

```bash
npm uninstall @langchain/azure-openai
```

2. 更新导入语句，改为使用 `@langchain/openai` 包中的 @[`AzureChatOpenAI`]：

   ```typescript
   import { AzureChatOpenAI } from "@langchain/openai";
   ```

3. 更新代码，使用新的 @[`AzureChatOpenAI`] 类并传入所需参数：

   ```typescript
   const model = new AzureChatOpenAI({
     azureOpenAIApiKey: "<your_key>",
     azureOpenAIApiInstanceName: "<your_instance_name>",
     azureOpenAIApiDeploymentName: "<your_deployment_name>",
     azureOpenAIApiVersion: "<api_version>",
   });
   ```

   请注意，构造函数现在要求传入 `azureOpenAIApiInstanceName`，而不是 `azureOpenAIEndpoint`；同时新增了 `azureOpenAIApiVersion` 参数来指定 API 版本。

   - 如果你之前使用 Azure Managed Identity，现在需要改为向构造函数传入 `azureADTokenProvider`，详见 [Azure Managed Identity](#使用-azure-managed-identity) 小节。

   - 如果你之前使用环境变量，现在需要设置 `AZURE_OPENAI_API_INSTANCE_NAME`，而不是 `AZURE_OPENAI_API_ENDPOINT`；同时还要新增 `AZURE_OPENAI_API_VERSION` 用于指定 API 版本。
