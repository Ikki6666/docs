浏览适用于不同 providers 的 middleware，或为生态系统贡献你自己的 middleware。有关 middleware 工作方式的更多信息，请参阅 [middleware overview](/oss/langchain/middleware/overview)；有关如何在 Deep Agents 中使用 middleware，请参阅 [Deep Agents docs](/oss/deepagents/customization#middleware)。


## 分享你的 middleware

Middleware 支持 context engineering、harness customization 和 runtime safety controls。它是 LangChain 中一个很有用的扩展点，我们也很乐于展示社区构建出的成果：

## 社区集成

<Note>
这些 middleware 集成由社区维护。它们以开源方式贡献，不由 LangChain 管理或维护。
</Note>

| Middleware | Description | Source |
|-----------|-------------|--------|
| [langchain-task-steering](https://github.com/edvinhallvaxhiu/langchain-task-steering) | 面向有序任务流水线的隐式状态机 middleware，支持按任务划分的 tool scope、动态 prompt 注入，以及可组合的完成校验。 | [`edvinhallvaxhiu/langchain-task-steering`](https://github.com/edvinhallvaxhiu/langchain-task-steering) |
| [Nuggets Authority](https://nuggets.life) | 针对工具调用的执行前授权强制。在每次工具运行前验证一份带作用域的已签名委派，拒绝时直接 fail closed，并为每次决策发出可独立验证的加密证明。 | [`NuggetsLtd/langchain-nuggets`](https://github.com/NuggetsLtd/langchain-nuggets) |
