</Tip>

Oracle AI Database 支持这样的 AI 工作负载：你可以按**语义**而不是仅按关键词来查询数据。它把**对非结构化内容的语义搜索**与**对业务数据的关系过滤**结合在同一个系统里，因此你可以构建检索工作流，例如 RAG，而不需要额外引入单独的向量数据库，也不会把数据碎片化到多个平台。

本指南演示如何使用 `OracleEmbeddings` 为你的内容生成 embeddings。

> **为什么要在 Oracle 中，或者通过 Oracle 生成 embeddings？**
> 你可以让数据治理与运行保障，例如安全性、事务和可用性，紧贴你的 AI 工作流，同时还能选择最适合你环境的 embedding provider 模型。

## 设置

要使用 OracleEmbeddings，请安装 `@oracle/langchain-oracledb` 辅助包以及 `@langchain/core`，并确保你的系统满足 Oracle Database driver 的前置要求。

### 凭据

为拥有向量表和 ONNX 模型的 Oracle 用户导出凭据，或者从你的 secrets manager 中加载它们。

```bash
export ORACLE_USER=testuser
export ORACLE_PASSWORD=testuser
export ORACLE_DSN="localhost:1521/free"
```

如果你计划调用第三方 provider，例如 OCI Generative AI 或 Hugging Face，你必须先在 Oracle Database 内创建凭据。关于 PL/SQL 辅助过程，请参阅 [Oracle AI Vector Search guide](https://www.oracle.com/pls/topic/lookup?ctx=dblatest&id=GUID-C6439E94-4E86-4ECD-954E-4B73D53579DE)。

## 实例化 embeddings

```typescript
import oracledb from "oracledb";
import { OracleEmbeddings } from "@oracle/langchain-oracledb";

const connection = await oracledb.getConnection({
  user: process.env.ORACLE_USER,
  password: process.env.ORACLE_PASSWORD,
  connectionString: process.env.ORACLE_DSN,
});

const embeddings = new OracleEmbeddings(connection, {
  provider: "database",
  model: "DEMO_MODEL",
});

// Close the connection (or pool) when you are done to avoid leaking resources.
// await connection.close();
```

构造函数的第三个参数是一个可选的 `proxy` 字符串。当出站请求必须经过 HTTP 代理时，例如在私有网络中调用 Hugging Face，就可以使用它。

## 在 Oracle Database 中运行 ONNX 模型

Oracle Database 兼容多种 embedding providers，用户可以在数据库内置方案和第三方服务，例如 OCIGENAI 与 HuggingFace 之间进行选择。这个选择会决定生成和管理 embeddings 的方式。

***Important***：如果用户选择数据库内置方案，就必须先把 ONNX 模型上传到 Oracle Database。相反，如果选择第三方 provider 来生成 embeddings，就不需要把 ONNX 模型上传到 Oracle Database。

直接在 Oracle 中使用 ONNX 模型的一个显著优势是，它通过避免把数据传给外部服务来提升安全性与性能。此外，这种方式也绕开了网络或 REST API 调用通常带来的延迟。

下面的示例代码展示了如何将 ONNX 模型上传到 Oracle Database：

```typescript
import { OracleEmbeddings } from "@oracle/langchain-oracledb";

await OracleEmbeddings.loadOnnxModel(
  connection,
  "/path/to/model",
  "all-minilm-l12-v2.onnx",
  "DEMO_MODEL",
);

const dbEmbeddings = new OracleEmbeddings(connection, {
  provider: "database",
  model: "DEMO_MODEL",
});

const singleVector = await dbEmbeddings.embedQuery(
  "Summarize hybrid search patterns in Oracle Database.",
);
console.log(singleVector.length);
```

## 调用托管 embedding providers

切换 `provider` 即可把 embedding 请求路由到 OCI Generative AI 或 Hugging Face。提供你通过 Oracle 的 `DBMS_VECTOR_CHAIN` 辅助工具创建的 credential name，并在需要时提供代理。

```typescript
const ociEmbeddings = new OracleEmbeddings(connection, {
  provider: "ocigenai",
  credential_name: "OCI_CRED",
  url: "https://inference.generativeai.us-chicago-1.oci.oraclecloud.com/20231130/actions/embedText",
  model: "cohere.embed-english-light-v3.0",
}, process.env.HTTP_PROXY);

const hfEmbeddings = new OracleEmbeddings(connection, {
  provider: "huggingface",
  credential_name: "HF_CRED",
  url: "https://api-inference.huggingface.co/pipeline/feature-extraction/",
  model: "sentence-transformers/all-MiniLM-L6-v2",
});

// Clean up when finished:
// await connection.close();
```

## 为检索生成文档 embeddings

使用同一个 embeddings 实例，就可以为 Oracle Database 中的 vector stores 或混合检索准备内容。

```typescript
import { OracleDocLoader, OracleTextSplitter } from "@oracle/langchain-oracledb";

const loader = new OracleDocLoader(connection, {
  owner: "TESTUSER",
  tablename: "DEMO_TAB",
  colname: "DATA",
});

const docs = await loader.load();

const splitter = new OracleTextSplitter(connection, {
  split: "chars",
  max: 500,
  normalize: "all",
});

const chunks = await splitter.splitText(docs[0].pageContent);
const vectors = await embeddings.embedDocuments(chunks);

console.log(`Generated ${vectors.length} vectors`);
```
