---
title: "Minimax 集成"
description: "集成 Minimax embedding model 以在 LangChain JavaScript 中使用。"
---

`MinimaxEmbeddings` 类使用 Minimax API 为给定文本生成 embeddings。

# 设置

要使用 Minimax 模型，你需要一个 Minimax 账号、一个 API key，以及一个 Group ID。

# 用法

```typescript
import { MinimaxEmbeddings } from "@langchain/classic/embeddings/minimax";

export const run = async () => {
  /* Embed queries */
  const embeddings = new MinimaxEmbeddings();
  const res = await embeddings.embedQuery("Hello world");
  console.log(res);
  /* Embed documents */
  const documentRes = await embeddings.embedDocuments([
    "Hello world",
    "Bye bye",
  ]);
  console.log({ documentRes });
};
```
