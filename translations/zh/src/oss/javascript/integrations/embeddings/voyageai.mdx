## 设置

要访问 Voyage AI embedding models，需要创建 Voyage AI 账号、获取 API key，并安装 `@langchain/mongodb` 集成包。

### 凭据

前往 [voyageai.com](https://www.voyageai.com) 注册并生成 API key。完成后，设置 `VOYAGE_API_KEY` 环境变量：

```bash
export VOYAGE_API_KEY="your-api-key"
```

如果你还想为模型调用启用自动 tracing，也可以取消下面的注释来设置 [LangSmith](/langsmith/home) API key：

```bash
# export LANGSMITH_TRACING="true"
# export LANGSMITH_API_KEY="your-api-key"
```

### 安装

LangChain 的 VoyageEmbeddings 集成位于 `@langchain/mongodb` 包中：

<CodeGroup>
```bash npm
npm install @langchain/mongodb @langchain/core
```
```bash yarn
yarn add @langchain/mongodb @langchain/core
```
```bash pnpm
pnpm add @langchain/mongodb @langchain/core
```
</CodeGroup>

## 实例化

现在可以实例化模型对象并为文本生成 embeddings：

```typescript
import { VoyageEmbeddings } from "@langchain/mongodb";

const embeddings = new VoyageEmbeddings({
  apiKey: "YOUR-API-KEY", // In Node.js defaults to process.env.VOYAGE_API_KEY
  model: "voyage-4",
});
```

## 索引与检索

Embedding models 常用于检索增强生成（RAG）流程中，既用于索引数据，也用于后续检索。如需更详细的说明，请参阅 [**Learn** 标签页](/oss/learn/)下的 RAG 教程。

下面展示如何使用上面初始化好的 `embeddings` 对象进行数据索引和检索。在这个示例中，我们会使用演示用的 [`MemoryVectorStore`](/oss/integrations/vectorstores/memory) 对示例文档进行索引和检索。

```typescript
// Create a vector store with a sample text
import { MemoryVectorStore } from "@langchain/classic/vectorstores/memory";

const text = "LangChain is the framework for building context-aware reasoning applications";

const vectorstore = await MemoryVectorStore.fromDocuments(
  [{ pageContent: text, metadata: {} }],
  embeddings,
);

// Use the vector store as a retriever that returns a single document
const retriever = vectorstore.asRetriever(1);

// Retrieve the most similar text
const retrievedDocuments = await retriever.invoke("What is LangChain?");

retrievedDocuments[0].pageContent;
```

```text
LangChain is the framework for building context-aware reasoning applications
```

## 直接使用

在底层，vectorstore 和 retriever 的实现分别调用 `embeddings.embedDocument(...)` 与 `embeddings.embedQuery(...)`，来为 `fromDocuments` 中使用的文本以及 retriever 的 `invoke` 操作创建 embeddings。

你也可以直接调用这些方法，为自己的用例生成 embeddings。

### 为单条文本生成 embeddings

你可以使用 `embedQuery` 为搜索查询生成 embeddings。它会生成针对查询优化的向量表示：

```typescript
const singleVector = await embeddings.embedQuery(text);

console.log(singleVector.slice(0, 3));
```

### 为多条文本生成 embeddings

你可以使用 `embedDocuments` 为索引生成多个文本的 embeddings。此方法内部的实现可能与查询 embeddings 不同，但也可能相同：

```typescript
const text2 = "LangGraph is a library for building stateful, multi-actor applications with LLMs";

const vectors = await embeddings.embedDocuments([text, text2]);

console.log(vectors[0].slice(0, 3));
console.log(vectors[1].slice(0, 3));
```
