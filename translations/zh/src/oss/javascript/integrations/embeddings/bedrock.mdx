[Amazon Bedrock](https://aws.amazon.com/bedrock/) 是一项全托管服务，通过单一 API 提供来自 AI21 Labs、Anthropic、Cohere、Meta、Stability AI 和 Amazon 等领先 AI 公司的一系列高性能 foundation models（FMs），同时还提供构建生成式 AI 应用所需的广泛能力，包括安全、隐私和负责任的 AI。

本文将帮助你开始在 LangChain 中使用 Amazon Bedrock [embedding models](/oss/integrations/embeddings)。如需查看 `Bedrock` 的特性和配置选项详情，请参阅 [API reference](https://reference.langchain.com/javascript/langchain-aws/BedrockEmbeddings)。

## 设置

要访问 Bedrock embedding models，需要创建 AWS 账号、获取 API key，并安装 `@langchain/aws` 集成包。

前往 [AWS docs](https://docs.aws.amazon.com/bedrock/latest/userguide/getting-started.html) 注册 AWS 并设置凭据。你还需要为账号启用 model access，可以[按照这些说明](https://docs.aws.amazon.com/bedrock/latest/userguide/model-access.html)操作。

### 凭据

如果你还想为模型调用启用自动 tracing，也可以取消下面的注释来设置 [LangSmith](/langsmith/observability) API key：

```bash
# export LANGSMITH_TRACING="true"
# export LANGSMITH_API_KEY="your-api-key"
```

### 安装

LangChain 的 Bedrock 集成位于 `@langchain/aws` 包中：

<CodeGroup>
```bash npm
npm install @langchain/aws @langchain/core
```
```bash yarn
yarn add @langchain/aws @langchain/core
```
```bash pnpm
pnpm add @langchain/aws @langchain/core
```
</CodeGroup>

## 实例化

现在可以实例化模型对象并为文本生成 embeddings。

有几种不同的方式可以与 AWS 进行身份验证，下面的示例依赖于通过环境变量设置 access key、secret access key 和 region：

```typescript
import { BedrockEmbeddings } from "@langchain/aws";

const embeddings = new BedrockEmbeddings({
  region: process.env.BEDROCK_AWS_REGION!,
  credentials: {
    accessKeyId: process.env.BEDROCK_AWS_ACCESS_KEY_ID!,
    secretAccessKey: process.env.BEDROCK_AWS_SECRET_ACCESS_KEY!,
  },
  model: "amazon.titan-embed-text-v1",
});
```

## 索引与检索

Embedding models 常用于检索增强生成（RAG）流程中，既用于索引数据，也用于后续检索。如需更详细的说明，请参阅 [**Learn** 标签页](/oss/learn/)下的 RAG 教程。

下面展示如何使用上面初始化好的 `embeddings` 对象进行数据索引和检索。在这个示例中，我们会使用演示用的 [`MemoryVectorStore`](/oss/integrations/vectorstores/memory) 对示例文档进行索引和检索。

```typescript
// Create a vector store with a sample text
import { MemoryVectorStore } from "@langchain/classic/vectorstores/memory";

const text = "LangChain is the framework for building context-aware reasoning applications";

const vectorstore = await MemoryVectorStore.fromDocuments(
  [{ pageContent: text, metadata: {} }],
  embeddings,
);

// Use the vector store as a retriever that returns a single document
const retriever = vectorstore.asRetriever(1);

// Retrieve the most similar text
const retrievedDocuments = await retriever.invoke("What is LangChain?");

retrievedDocuments[0].pageContent;
```

```text
LangChain is the framework for building context-aware reasoning applications
```

## 直接使用

在底层，vectorstore 和 retriever 的实现分别调用 `embeddings.embedDocument(...)` 与 `embeddings.embedQuery(...)`，来为 `fromDocuments` 中使用的文本以及 retriever 的 `invoke` 操作创建 embeddings。

你也可以直接调用这些方法，为自己的用例生成 embeddings。

const vectors = await embeddings.embedDocuments([text, text2]);

console.log(vectors[0].slice(0, 100));
console.log(vectors[1].slice(0, 100));

## 配置 Bedrock runtime client

如果你想自定义 `credentials`、`region`、`retryPolicy` 等选项，可以传入你自己的 `BedrockRuntimeClient` 实例。

```typescript
import { BedrockRuntimeClient } from "@aws-sdk/client-bedrock-runtime";
import { BedrockEmbeddings } from "@langchain/aws";

const getCredentials = () => {
  // do something to get credentials
}

// @lc-ts-ignore
const client = new BedrockRuntimeClient({
  region: "us-east-1",
  credentials: getCredentials(),
});

const embeddingsWithCustomClient = new BedrockEmbeddings({
  client,
});
```
