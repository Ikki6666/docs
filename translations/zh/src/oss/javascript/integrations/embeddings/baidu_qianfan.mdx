---

`BaiduQianfanEmbeddings` 类使用 Baidu Qianfan API 为给定文本生成 embeddings。

## 设置

使用这个 embedding model 需要 API key。你可以在 https://cloud.baidu.com/doc/WENXINWORKSHOP/s/alj562vvu 注册后获取。

请将获取到的 API key 设置为名为 `BAIDU_API_KEY` 的环境变量，并将 secret key 设置为名为 `BAIDU_SECRET_KEY` 的环境变量。

然后，你需要安装 [`@langchain/baidu-qianfan`](https://www.npmjs.com/package/@langchain/baidu-qianfan) 包：

<Tip>
LangChain 包安装的一般说明，请参阅[这个部分](/oss/langchain/install)。
</Tip>

```bash npm
npm install @langchain/baidu-qianfan @langchain/core
```

## 用法

```typescript
import { BaiduQianfanEmbeddings } from "@langchain/baidu-qianfan";

const embeddings = new BaiduQianfanEmbeddings();
const res = await embeddings.embedQuery(
  "What would be a good company name a company that makes colorful socks?"
);
console.log({ res });
```
