[Azure OpenAI](https://azure.microsoft.com/products/ai-services/openai-service/) 是一项云服务，可帮助你快速使用来自 OpenAI、Meta 等提供方的多样化预构建和精选模型来开发生成式 AI 体验。

LangChain.js 通过 [OpenAI SDK](https://github.com/openai/openai-node) 中新的 Azure 集成支持与 [Azure OpenAI](https://azure.microsoft.com/products/ai-services/openai-service/) 进行集成。

你可以在[这个页面](https://learn.microsoft.com/azure/ai-services/openai/overview)了解更多关于 Azure OpenAI 以及它与 OpenAI API 的区别。如果你还没有 Azure 账号，可以[创建一个免费账号](https://azure.microsoft.com/free/)开始使用。

本文将帮助你开始在 LangChain 中使用 AzureOpenAIEmbeddings [embedding models](/oss/integrations/embeddings)。如需查看 `AzureOpenAIEmbeddings` 的特性和配置选项详情，请参阅 [API reference](https://reference.langchain.com/javascript/langchain-openai/AzureOpenAIEmbeddings)。


<Info>
**此前，LangChain.js 使用专用的 [Azure OpenAI SDK](https://github.com/Azure/azure-sdk-for-js/tree/main/sdk/openai/openai) 来支持 Azure OpenAI 集成。现在这个 SDK 已被弃用，推荐改用 OpenAI SDK 中新的 Azure 集成。这样可以在最新 OpenAI 模型和特性发布当天就访问到它们，并且可以在 OpenAI API 与 Azure OpenAI 之间无缝切换。**


如果你正在使用已弃用 SDK 下的 Azure OpenAI，请参阅[迁移指南](#migration-from-azure-openai-sdk)，更新到新的 API。

</Info>

## 设置

要访问 Azure OpenAI embedding models，需要创建 Azure 账号、获取 API key，并安装 `@langchain/openai` 集成包。

### 凭据

你需要先部署一个 Azure OpenAI 实例。可以按照[这份指南](https://learn.microsoft.com/azure/ai-services/openai/how-to/create-resource?pivots=web-portal)在 Azure Portal 中部署。

当实例运行起来后，请确保已经拿到实例名称和 key。你可以在 Azure Portal 的实例页面中，在 “Keys and Endpoint” 部分找到 key。

如果你使用的是 Node.js，可以定义以下环境变量来使用这项服务：

```bash
AZURE_OPENAI_API_INSTANCE_NAME=<YOUR_INSTANCE_NAME>
AZURE_OPENAI_API_EMBEDDINGS_DEPLOYMENT_NAME=<YOUR_EMBEDDINGS_DEPLOYMENT_NAME>
AZURE_OPENAI_API_KEY=<YOUR_KEY>
AZURE_OPENAI_API_VERSION="2024-02-01"
```

如果你还想为模型调用启用自动 tracing，也可以取消下面的注释来设置 [LangSmith](/langsmith/observability) API key：

```bash
# export LANGSMITH_TRACING="true"
# export LANGSMITH_API_KEY="your-api-key"
```

### 安装

LangChain 的 AzureOpenAIEmbeddings 集成位于 `@langchain/openai` 包中：

<CodeGroup>
```bash npm
npm install @langchain/openai @langchain/core
```
```bash yarn
yarn add @langchain/openai @langchain/core
```
```bash pnpm
pnpm add @langchain/openai @langchain/core
```
</CodeGroup>


<Info>
**支持的 API 版本列表可以在 [Azure OpenAI documentation](https://learn.microsoft.com/azure/ai-services/openai/reference) 中查看。**


</Info>

<Tip>
**如果没有定义 `AZURE_OPENAI_API_EMBEDDINGS_DEPLOYMENT_NAME`，它会回退到 `AZURE_OPENAI_API_DEPLOYMENT_NAME` 的值作为 deployment name。`AzureOpenAIEmbeddings` 构造函数中的 `azureOpenAIApiEmbeddingsDeploymentName` 参数也一样，如果未定义，则会回退到 `azureOpenAIApiDeploymentName` 的值。**


</Tip>

## 实例化

现在可以实例化模型对象并为文本生成 embeddings：

```typescript
import { AzureOpenAIEmbeddings } from "@langchain/openai";

const embeddings = new AzureOpenAIEmbeddings({
  azureOpenAIApiKey: "<your_key>", // In Node.js defaults to process.env.AZURE_OPENAI_API_KEY
  azureOpenAIApiInstanceName: "<your_instance_name>", // In Node.js defaults to process.env.AZURE_OPENAI_API_INSTANCE_NAME
  azureOpenAIApiEmbeddingsDeploymentName: "<your_embeddings_deployment_name>", // In Node.js defaults to process.env.AZURE_OPENAI_API_EMBEDDINGS_DEPLOYMENT_NAME
  azureOpenAIApiVersion: "<api_version>", // In Node.js defaults to process.env.AZURE_OPENAI_API_VERSION
  maxRetries: 1,
});
```

## 索引与检索

Embedding models 常用于检索增强生成（RAG）流程中，既用于索引数据，也用于后续检索。如需更详细的说明，请参阅 [**Learn** 标签页](/oss/learn/)下的 RAG 教程。

下面展示如何使用上面初始化好的 `embeddings` 对象进行数据索引和检索。在这个示例中，我们会使用演示用的 [`MemoryVectorStore`](/oss/integrations/vectorstores/memory) 对示例文档进行索引和检索。

```typescript
// Create a vector store with a sample text
import { MemoryVectorStore } from "@langchain/classic/vectorstores/memory";

const text = "LangChain is the framework for building context-aware reasoning applications";

const vectorstore = await MemoryVectorStore.fromDocuments(
  [{ pageContent: text, metadata: {} }],
  embeddings,
);

// Use the vector store as a retriever that returns a single document
const retriever = vectorstore.asRetriever(1);

// Retrieve the most similar text
const retrievedDocuments = await retriever.invoke("What is LangChain?");

retrievedDocuments[0].pageContent;
```

```text
LangChain is the framework for building context-aware reasoning applications
```

## 直接使用

在底层，vectorstore 和 retriever 的实现分别调用 `embeddings.embedDocument(...)` 与 `embeddings.embedQuery(...)`，来为 `fromDocuments` 中使用的文本以及 retriever 的 `invoke` 操作创建 embeddings。

你也可以直接调用这些方法，为自己的用例生成 embeddings。

## 使用 Azure Managed identity

如果你使用 Azure Managed Identity，可以像下面这样配置凭据：

```typescript
import {
  DefaultAzureCredential,
  getBearerTokenProvider,
} from "@azure/identity";
import { AzureOpenAIEmbeddings } from "@langchain/openai";

const credentials = new DefaultAzureCredential();
const azureADTokenProvider = getBearerTokenProvider(
  credentials,
  "https://cognitiveservices.azure.com/.default"
);

const modelWithManagedIdentity = new AzureOpenAIEmbeddings({
  azureADTokenProvider,
  azureOpenAIApiInstanceName: "<your_instance_name>",
  azureOpenAIApiEmbeddingsDeploymentName: "<your_embeddings_deployment_name>",
  azureOpenAIApiVersion: "<api_version>",
});

```

## 使用不同的域名

如果你的实例托管在默认 `openai.azure.com` 之外的域名下，则需要改用 `AZURE_OPENAI_BASE_PATH` 环境变量。
例如，如果要连接 `https://westeurope.api.microsoft.com/openai/deployments/{DEPLOYMENT_NAME}` 这个域名，可以这样写：

```typescript
import { AzureOpenAIEmbeddings } from "@langchain/openai";

const embeddingsDifferentDomain = new AzureOpenAIEmbeddings({
  azureOpenAIApiKey: "<your_key>", // In Node.js defaults to process.env.AZURE_OPENAI_API_KEY
  azureOpenAIApiEmbeddingsDeploymentName: "<your_embedding_deployment_name>", // In Node.js defaults to process.env.AZURE_OPENAI_API_EMBEDDINGS_DEPLOYMENT_NAME
  azureOpenAIApiVersion: "<api_version>", // In Node.js defaults to process.env.AZURE_OPENAI_API_VERSION
  azureOpenAIBasePath:
    "https://westeurope.api.microsoft.com/openai/deployments", // In Node.js defaults to process.env.AZURE_OPENAI_BASE_PATH
});

```

## 自定义请求头

你可以通过传入 `configuration` 字段来指定自定义请求头：

```typescript
import { AzureOpenAIEmbeddings } from "@langchain/openai";

const embeddingsWithCustomHeaders = new AzureOpenAIEmbeddings({
  azureOpenAIApiKey: "<your_key>",
  azureOpenAIApiInstanceName: "<your_instance_name>",
  azureOpenAIApiEmbeddingsDeploymentName: "<your_embeddings_deployment_name>",
  azureOpenAIApiVersion: "<api_version>",
  configuration: {
    defaultHeaders: {
      "x-custom-header": `SOME_VALUE`,
    },
  },
});
```

`configuration` 字段也接受官方 SDK 支持的其他 `ClientOptions` 参数。

**注意：** 特定的请求头 `api-key` 目前不能以这种方式覆盖，仍会透传 `azureOpenAIApiKey` 的值。

## 从 Azure OpenAI SDK 迁移

如果你正在使用已弃用的 Azure OpenAI SDK 配合 `@langchain/azure-openai` 包，可以按照以下步骤更新代码，迁移到新的 Azure 集成：

1. 安装新的 `@langchain/openai` 包，并移除之前的 `@langchain/azure-openai` 包：

   ```bash npm
   npm install @langchain/openai
   npm uninstall @langchain/azure-openai
   ```

2. 更新 import，改为使用 `@langchain/openai` 包中的 `AzureOpenAIEmbeddings` 类：

   ```typescript
   import { AzureOpenAIEmbeddings } from "@langchain/openai";
   ```

3. 更新代码，使用新的 `AzureOpenAIEmbeddings` 类并传入必需参数：

   ```typescript
   const model = new AzureOpenAIEmbeddings({
     azureOpenAIApiKey: "<your_key>",
     azureOpenAIApiInstanceName: "<your_instance_name>",
     azureOpenAIApiEmbeddingsDeploymentName:
       "<your_embeddings_deployment_name>",
     azureOpenAIApiVersion: "<api_version>",
   });
   ```

   注意，现在构造函数要求传入 `azureOpenAIApiInstanceName` 参数，而不是 `azureOpenAIEndpoint` 参数，同时增加了 `azureOpenAIApiVersion` 参数来指定 API 版本。

   - 如果你之前使用的是 Azure Managed Identity，现在需要在构造函数中使用 `azureADTokenProvider` 参数，而不是 `credentials`。详情请参阅 [Azure Managed Identity](#using-azure-managed-identity) 一节。

   - 如果你之前使用的是环境变量，现在需要设置 `AZURE_OPENAI_API_INSTANCE_NAME`，而不是 `AZURE_OPENAI_API_ENDPOINT`，并额外添加 `AZURE_OPENAI_API_VERSION` 环境变量来指定 API 版本。
