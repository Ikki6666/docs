## 设置

要访问 IBM WatsonxAI embeddings，需要创建 IBM watsonx.ai 账号、获取 API key 或其他类型的凭据，并安装 `@langchain/ibm` 集成包。

### 凭据

前往 [IBM Cloud](https://cloud.ibm.com/login) 注册 IBM watsonx.ai，并生成 API key，或者使用下面展示的其他身份验证方式。

#### IAM 身份验证

```bash
export WATSONX_AI_AUTH_TYPE=iam
export WATSONX_AI_APIKEY=<YOUR-APIKEY>
```

#### Bearer token 身份验证

```bash
export WATSONX_AI_AUTH_TYPE=bearertoken
export WATSONX_AI_BEARER_TOKEN=<YOUR-BEARER-TOKEN>
```

#### IBM watsonx.ai software 身份验证

```bash
export WATSONX_AI_AUTH_TYPE=cp4d
export WATSONX_AI_USERNAME=<YOUR_USERNAME>
export WATSONX_AI_PASSWORD=<YOUR_PASSWORD>
export WATSONX_AI_URL=<URL>
```

当这些值被放入环境变量，并且对象完成初始化后，身份验证将自动继续进行。

也可以在创建新实例时，将这些值作为参数传入来完成身份验证。

## IAM 身份验证

```typescript
import { WatsonxEmbeddings } from "@langchain/ibm";

const props = {
  version: "YYYY-MM-DD",
  serviceUrl: "<SERVICE_URL>",
  projectId: "<PROJECT_ID>",
  watsonxAIAuthType: "iam",
  watsonxAIApikey: "<YOUR-APIKEY>",
};
const instance = new WatsonxEmbeddings(props);
```

## Bearer token 身份验证

```typescript
import { WatsonxEmbeddings } from "@langchain/ibm";

const props = {
  version: "YYYY-MM-DD",
  serviceUrl: "<SERVICE_URL>",
  projectId: "<PROJECT_ID>",
  watsonxAIAuthType: "bearertoken",
  watsonxAIBearerToken: "<YOUR-BEARERTOKEN>",

```

### IBM watsonx.ai software 身份验证

```typescript
import { WatsonxEmbeddings } from "@langchain/ibm";

const props = {
  version: "YYYY-MM-DD",
  serviceUrl: "<SERVICE_URL>",
  projectId: "<PROJECT_ID>",
  watsonxAIAuthType: "cp4d",
  watsonxAIUsername: "<YOUR-USERNAME>",

```

如果你还想为模型调用启用自动 tracing，也可以取消下面的注释来设置 [LangSmith](/langsmith/observability) API key：

```bash

# export LANGSMITH_API_KEY="your-api-key"
```

## 实例化

现在可以实例化模型对象并为文本生成 embeddings：

```javascript
import { WatsonxEmbeddings } from "@langchain/ibm";

const embeddings = new WatsonxEmbeddings({
  version: "YYYY-MM-DD",
  serviceUrl: process.env.API_URL,
  projectId: "<PROJECT_ID>",
  spaceId: "<SPACE_ID>",
  model: "<MODEL_ID>",
});
```

注意：

- 你必须提供 `spaceId` 或 `projectId` 才能继续。
- 请根据已开通服务实例所在区域，使用正确的 `serviceUrl`。

### Model Gateway
```typescript
import { WatsonxEmbeddings } from "@langchain/ibm";

const instance = new WatsonxEmbeddings({
  version: "YYYY-MM-DD",
  serviceUrl: process.env.API_URL,
  model: "<ALIAS_MODEL_ID>",
  modelGateway: true,
});
```

## 索引与检索

Embedding models 常用于检索增强生成（RAG）流程中，既用于索引数据，也用于后续检索。如需更详细的说明，请参阅 [**Learn** 标签页](/oss/learn/)下的 RAG 教程。

下面展示如何使用上面初始化好的 `embeddings` 对象进行数据索引和检索。在这个示例中，我们会使用演示用的 [`MemoryVectorStore`](/oss/integrations/vectorstores/memory) 对示例文档进行索引和检索。

```javascript
// Create a vector store with a sample text
import { MemoryVectorStore } from "@langchain/classic/vectorstores/memory";

const text = "LangChain is the framework for building context-aware reasoning applications";

const vectorstore = await MemoryVectorStore.fromDocuments(
  [{ pageContent: text, metadata: {} }],
  embeddings,
);

// Use the vector store as a retriever that returns a single document
const retriever = vectorstore.asRetriever(1);

// Retrieve the most similar text
const retrievedDocuments = await retriever.invoke("What is LangChain?");

retrievedDocuments[0].pageContent;
```

```text
LangChain is the framework for building context-aware reasoning applications
```

## 直接使用

在底层，vectorstore 和 retriever 的实现分别调用 `embeddings.embedDocument(...)` 与 `embeddings.embedQuery(...)`，来为 `fromDocuments` 中使用的文本以及 retriever 的 `invoke` 操作创建 embeddings。

你也可以直接调用这些方法，为自己的用例生成 embeddings。

### 为单条文本生成 embeddings

你可以使用 `embedQuery` 为搜索查询生成 embeddings。它会生成针对查询优化的向量表示：

```javascript
    const singleVector = await embeddings.embedQuery(text);
    singleVector.slice(0, 10);
```

```text

   -0.015685871, -0.013543149,

    0.015286108, -0.023845721,
    -0.02454774,   0.07235078
]
```

### 为多条文本生成 embeddings

你可以使用 `embedDocuments` 为索引生成多个文本的 embeddings。此方法内部的实现可能与查询 embeddings 不同，但也可能相同：

```javascript
    const text2 = "LangGraph is a library for building stateful, multi-actor applications with LLMs";

    const vectors = await embeddings.embedDocuments([text, text2]);

    console.log(vectors[0].slice(0, 10));
    console.log(vectors[1].slice(0, 10));

```
