## 设置

要访问 OpenAIEmbeddings embedding models，需要创建 OpenAI 账号、获取 API key，并安装 `@langchain/openai` 集成包。

### 凭据

前往 [platform.openai.com](https://platform.openai.com) 注册 OpenAI 并生成 API key。完成后，设置 `OPENAI_API_KEY` 环境变量：

```bash
export OPENAI_API_KEY="your-api-key"
```

如果你还想为模型调用启用自动 tracing，也可以取消下面的注释来设置 [LangSmith](/langsmith/observability) API key：

```bash
# export LANGSMITH_TRACING="true"
# export LANGSMITH_API_KEY="your-api-key"
```

### 安装

LangChain 的 OpenAIEmbeddings 集成位于 `@langchain/openai` 包中：

<CodeGroup>
```bash npm
npm install @langchain/openai @langchain/core
```
```bash yarn
yarn add @langchain/openai @langchain/core
```
```bash pnpm
pnpm add @langchain/openai @langchain/core
```
</CodeGroup>

## 实例化

现在可以实例化 embeddings 模型：

```typescript
import { OpenAIEmbeddings } from "@langchain/openai";

const embeddings = new OpenAIEmbeddings({
  apiKey: "YOUR-API-KEY", // In Node.js defaults to process.env.OPENAI_API_KEY
  batchSize: 512, // Default value if omitted is 512. Max is 2048
  model: "text-embedding-3-large",
});
```

如果你属于某个组织，可以把 `process.env.OPENAI_ORGANIZATION` 设置为你的 OpenAI organization id，或者在初始化模型时通过 `organization` 参数传入。

## 索引与检索

Embedding models 常用于检索增强生成（RAG）流程中，既用于索引数据，也用于后续检索。如需更详细的说明，请参阅 [**Learn** 标签页](/oss/learn/)下的 RAG 教程。

下面展示如何使用上面初始化好的 `embeddings` 对象进行数据索引和检索。在这个示例中，我们会使用演示用的 [`MemoryVectorStore`](/oss/integrations/vectorstores/memory) 对示例文档进行索引和检索。

```typescript
// Create a vector store with a sample text
import { MemoryVectorStore } from "@langchain/classic/vectorstores/memory";

const text = "LangChain is the framework for building context-aware reasoning applications";

const vectorstore = await MemoryVectorStore.fromDocuments(
  [{ pageContent: text, metadata: {} }],
  embeddings,
);

// Use the vector store as a retriever that returns a single document
const retriever = vectorstore.asRetriever(1);

// Retrieve the most similar text
const retrievedDocuments = await retriever.invoke("What is LangChain?");

retrievedDocuments[0].pageContent;
```

```text
LangChain is the framework for building context-aware reasoning applications
```

## 直接使用

在底层，vectorstore 和 retriever 的实现分别调用 `embeddings.embedDocument(...)` 与 `embeddings.embedQuery(...)`，来为 `fromDocuments` 中使用的文本以及 retriever 的 `invoke` 操作创建 embeddings。

你也可以直接调用这些方法，为自己的用例生成 embeddings。

const vectors = await embeddings.embedDocuments([text, text2]);

console.log(vectors[0].slice(0, 100));
console.log(vectors[1].slice(0, 100));

## 指定维度

对于 `text-embedding-3` 这一类模型，你可以指定希望返回的 embeddings 维度。例如默认情况下，`text-embedding-3-large` 会返回 3072 维 embeddings：

```typescript
import { OpenAIEmbeddings } from "@langchain/openai";

const embeddingsDefaultDimensions = new OpenAIEmbeddings({
  model: "text-embedding-3-large",
});

const vectorsDefaultDimensions = await embeddingsDefaultDimensions.embedDocuments(["some text"]);
console.log(vectorsDefaultDimensions[0].length);
```

```text
3072
```

通过传入 `dimensions: 1024`，可以把 embeddings 的大小降到 1024：

```typescript
import { OpenAIEmbeddings } from "@langchain/openai";

const embeddings1024 = new OpenAIEmbeddings({
  model: "text-embedding-3-large",
  dimensions: 1024,
});

const vectors1024 = await embeddings1024.embedDocuments(["some text"]);
console.log(vectors1024[0].length);
```

```text
1024
```

## 自定义 URL

你可以通过传入 `configuration` 参数，自定义 SDK 请求发送到的 base URL，例如：

```typescript
import { OpenAIEmbeddings } from "@langchain/openai";

const model = new OpenAIEmbeddings({
  configuration: {
    baseURL: "https://your_custom_url.com",
  },
});
```

你也可以传入官方 SDK 接受的其他 `ClientOptions` 参数。

如果你使用的是 Azure OpenAI，请改看[专门页面](/oss/integrations/embeddings/azure_openai)。
