---
title: "Mixedbread AI 集成"
description: "集成 Mixedbread AI embedding model 以在 LangChain JavaScript 中使用。"
---

`MixedbreadAIEmbeddings` 类使用 [Mixedbread AI](https://mixedbread.ai/) API 生成文本 embeddings。本指南将带你完成 `MixedbreadAIEmbeddings` 类的设置和使用，帮助你高效地将其集成到项目中。

## 安装

使用下面的命令安装 `@langchain/mixedbread-ai` 包：

<Tip>
LangChain 包安装的一般说明，请参阅[这个部分](/oss/langchain/install)。
</Tip>

```bash npm
npm install @langchain/mixedbread-ai @langchain/core
```
## 初始化

首先，在 Mixedbread AI 网站上注册，并获取你的 [Mixedbread AI API key](https://mixedbread.ai/)。然后你就可以使用这个 key 来初始化 `MixedbreadAIEmbeddings` 类。

你可以直接把 API key 传给构造函数，或者将其设置为环境变量 `MXBAI_API_KEY`。

### 基础用法

下面演示如何创建一个 `MixedbreadAIEmbeddings` 实例：

```typescript
import { MixedbreadAIEmbeddings } from "@langchain/mixedbread-ai";

const embeddings = new MixedbreadAIEmbeddings({
  apiKey: "YOUR_API_KEY",
  // Optionally specify model
  // model: "mixedbread-ai/mxbai-embed-large-v1",
});
```
如果没有提供 `apiKey`，则会从 `MXBAI_API_KEY` 环境变量中读取。

## 生成 embeddings

### 为单条查询生成 embeddings

要为单条文本查询生成 embeddings，请使用 `embedQuery` 方法：

```typescript
const embedding = await embeddings.embedQuery(
  "Represent this sentence for searching relevant passages: Is baking fun?"
);
console.log(embedding);
```
### 为多个文档生成 embeddings

要为多个文档生成 embeddings，请使用 `embedDocuments` 方法。这个方法会根据 `batchSize` 参数自动处理 batching：

```typescript
const documents = ["Baking bread is fun", "I love baking"];

const embeddingsArray = await embeddings.embedDocuments(documents);
console.log(embeddingsArray);
```
## 自定义请求

你可以通过传入额外参数来自定义 SDK。

```typescript
const customEmbeddings = new MixedbreadAIEmbeddings({
  apiKey: "YOUR_API_KEY",
  baseUrl: "...",
  maxRetries: 6,
});
```
## 错误处理

如果没有提供 API key，并且在环境变量中也找不到，就会抛出错误：

```typescript
try {
  const embeddings = new MixedbreadAIEmbeddings();
} catch (error) {
  console.error(error);
}
```
