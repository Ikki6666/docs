## 概览

<Note>
本概览涵盖的是**基于文本的嵌入模型**。LangChain 目前不支持多模态嵌入。
</Note>

嵌入模型会将原始文本，例如一句话、一段文字或一条推文，转换为固定长度的数字向量，用来表示其**语义含义**。这些向量让机器能够基于含义而不是精确字面词汇来比较和搜索文本。

在实际使用中，这意味着表达相近思想的文本会被放置在向量空间中的相近位置。比如，嵌入不仅能匹配 *"machine learning"* 这个短语本身，还能找出那些使用不同措辞但讨论相关概念的文档。

### 工作原理

1. **向量化**：模型将每个输入字符串编码为高维向量。
2. **相似度评分**：使用数学度量比较这些向量，以衡量底层文本之间的相关程度。

### 相似度度量

比较嵌入时，常用以下几种度量方式：

* **余弦相似度**：衡量两个向量之间的夹角。
* **欧氏距离**：衡量两个点之间的直线距离。
* **点积**：衡量一个向量在另一个向量方向上的投影程度。

## 接口

LangChain 通过 @[Embeddings] 接口，为 OpenAI、Cohere、Hugging Face 等文本嵌入模型提供统一接口。

主要有两个方法：

* `embedDocuments(documents: string[]) → number[][]`：为一组文档生成嵌入。
* `embedQuery(text: string) → number[]`：为单个查询生成嵌入。

<Note>
该接口允许对查询和文档使用不同的嵌入策略，不过在大多数提供商中，这两者在实践里通常是相同的。
</Note>

## 安装并使用

<AccordionGroup>
<Accordion title="OpenAI">

安装依赖：

<CodeGroup>

```bash npm
npm install @langchain/openai @langchain/core
```
```bash yarn
yarn add @langchain/openai @langchain/core
```
```bash pnpm
pnpm add @langchain/openai @langchain/core
```
</CodeGroup>

添加环境变量：

```bash
OPENAI_API_KEY=your-api-key
```

实例化模型：

```typescript
import { OpenAIEmbeddings } from "@langchain/openai";

const embeddings = new OpenAIEmbeddings({
  model: "text-embedding-3-large"
});
```

## 缓存

嵌入可以被存储或临时缓存起来，以避免重复计算。

可以使用 `CacheBackedEmbeddings` 来缓存嵌入。这个包装器会将嵌入保存在键值存储中，其中原始文本会先被哈希，哈希值作为缓存中的键。

初始化 `CacheBackedEmbeddings` 的主要推荐方式是 `fromBytesStore`。它接受以下参数：

- **underlyingEmbeddings**：用于生成嵌入的底层 embedder。
- **documentEmbeddingStore**：任意 [`BaseStore`](/oss/integrations/stores/)，用于缓存文档嵌入。
- **options.namespace**：可选，默认值为 `""`。用于文档缓存的命名空间，有助于避免冲突，例如可设为嵌入模型名称。

<Important>
- 使用不同嵌入模型时，请始终设置 `namespace` 参数，以避免冲突。
- `CacheBackedEmbeddings` 默认不会缓存查询嵌入。如果需要启用，请指定 `query_embedding_store`。
</Important>

```typescript
import { CacheBackedEmbeddings } from "@langchain/classic/embeddings/cache_backed";
import { InMemoryStore } from "@langchain/core/stores";

const underlyingEmbeddings = new OpenAIEmbeddings();

const inMemoryStore = new InMemoryStore();

const cacheBackedEmbeddings = CacheBackedEmbeddings.fromBytesStore(
  underlyingEmbeddings,
  inMemoryStore,
  {
    namespace: underlyingEmbeddings.model,
  }
);

// Example: caching a query embedding
const tic = Date.now();
const queryEmbedding = cacheBackedEmbeddings.embedQuery("Hello, world!");
console.log(`First call took: ${Date.now() - tic}ms`);

// Example: caching a document embedding
const tic = Date.now();
const documentEmbedding = cacheBackedEmbeddings.embedDocuments(["Hello, world!"]);
console.log(`Cached creation time: ${Date.now() - tic}ms`);
```

在生产环境中，您通常会使用更可靠的持久化存储，例如数据库或云存储。可用方案请参阅[存储集成](/oss/integrations/stores/)。
