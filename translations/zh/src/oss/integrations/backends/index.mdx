浏览适用于 Deep Agents 的文件系统后端，或者为这个生态贡献你自己的后端。关于后端如何工作的更多信息，请参阅 [backends 文档](/oss/deepagents/backends)。

## 分享你的后端

自定义后端会把 Deep Agents 连接到数据库、对象存储和虚拟文件系统等存储系统。欢迎与你的社区共享：

## 社区集成

<Note>
这些后端集成由社区维护。它们以开源形式贡献，不由 LangChain 管理或维护。
</Note>

| Backend | Description | Source |
|---------|-------------|--------|
| [MongoDB VFS Adapter](https://github.com/mongodb-developer/MongoDB-LangChain-DeepAgents-VFS-Adapter) | 基于 MongoDB Atlas 的虚拟文件系统后端。可将智能体文件（包括 memories、artifacts 和对话历史）持久化到 MongoDB collection 中。 | [`mongodb-developer/MongoDB-LangChain-DeepAgents-VFS-Adapter`](https://github.com/mongodb-developer/MongoDB-LangChain-DeepAgents-VFS-Adapter) |

如果你也有想分享的后端，请[提交一个 PR](https://github.com/langchain-ai/docs) 将其添加到这里。
