浏览适用于 Deep Agents 的文件系统后端，或者为这个生态贡献你自己的后端。关于后端如何工作的更多信息，请参阅 [backends 文档](/oss/deepagents/backends)。

## 分享你的后端

自定义后端会把 Deep Agents 连接到数据库、对象存储和虚拟文件系统等存储系统。欢迎与你的社区共享：

<CardGroup cols={2}>
    <Card title="实现自定义后端" icon="database" href="/oss/deepagents/backends#custom-backends">
        按照自定义后端指南构建你自己的后端。
    </Card>
    <Card title="分享社区后端" icon="users" href="https://github.com/langchain-ai/docs">
        打开 docs 仓库的 PR，把你的后端加入下方表格。
    </Card>
</CardGroup>

## 所有后端

| Backend | Description | Package | Source |
|---------|-------------|---------|--------|
| [Azure Blob Backend](https://github.com/langchain-ai/langchain-azure/tree/main/libs/azure-storage) | Deep Agents `BackendProtocol` 的 Azure Blob Storage 实现。可将智能体工作区文件、memories 和 artifacts 持久化到 blob 容器中。 | `langchain-azure-storage` | [`langchain-ai/langchain-azure`](https://github.com/langchain-ai/langchain-azure/tree/main/libs/azure-storage) |
| [MongoDB VFS Adapter](https://github.com/langchain-ai/langchain-mongodb/tree/main/libs/langchain-mongodb-deepagents-vfs) | 基于 MongoDB Atlas 的虚拟文件系统后端。可将智能体文件（包括 memories、artifacts 和对话历史）持久化到 MongoDB collection 中。 | `langchain-mongodb-deepagents-vfs` | [`langchain-ai/langchain-mongodb`](https://github.com/langchain-ai/langchain-mongodb/tree/main/libs/langchain-mongodb-deepagents-vfs) |

如果你也有想分享的后端，请[提交一个 PR](https://github.com/langchain-ai/docs) 将其添加到这里。
