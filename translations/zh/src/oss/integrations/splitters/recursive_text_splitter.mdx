这个[文本分割器](/oss/integrations/splitters/)是通用文本场景下的推荐选项。它通过一个字符列表来参数化，并会按顺序尝试用这些字符分割文本，直到块足够小为止。默认列表是 `["\n\n", "\n", " ", ""]`。这意味着它会尽可能把段落放在一起，其次是句子，再其次是单词，因为这些通常是语义关联最强的文本单元。

1. 文本如何被分割：按字符列表分割。
2. 块大小如何衡量：按字符数衡量。

:::python
如果想直接获取字符串内容，请使用 `.split_text`。

如果想创建 LangChain @[Document] 对象（例如用于下游任务），请使用 `.create_documents`。

```python
from langchain_text_splitters import RecursiveCharacterTextSplitter

# Load example document
with open("state_of_the_union.txt") as f:
    state_of_the_union = f.read()

text_splitter = RecursiveCharacterTextSplitter(
    # Set a really small chunk size, just to show.
    chunk_size=100,
    chunk_overlap=20,
    length_function=len,
    is_separator_regex=False,
)
texts = text_splitter.create_documents([state_of_the_union])
print(texts[0])
print(texts[1])
```
```python
page_content='Madam Speaker, Madam Vice President, our First Lady and Second Gentleman. Members of Congress and'
page_content='of Congress and the Cabinet. Justices of the Supreme Court. My fellow Americans.'
```

```python
print(text_splitter.split_text(state_of_the_union)[:2])
```

```python
 'of Congress and the Cabinet. Justices of the Supreme Court. My fellow Americans.']
```

:::js
如果想直接获取字符串内容，请使用 `.splitText`。

如果想创建 LangChain @[Document] 对象（例如用于下游任务），请使用 `.createDocuments`。

```ts
import { RecursiveCharacterTextSplitter } from "@langchain/textsplitters";

const splitter = new RecursiveCharacterTextSplitter({ chunkSize: 100, chunkOverlap: 0 })
const texts = splitter.createDocuments([{ pageContent: "..." }])
```
```javascript
[
  { pageContent: "...", metadata: {} },
]
```
:::

下面解释上面为 `RecursiveCharacterTextSplitter` 设置的参数：

:::python
- `chunk_size`：块的最大大小，大小由 `length_function` 决定。
- `chunk_overlap`：块之间目标重叠长度。重叠块有助于减少上下文被切断时的信息损失。
- `length_function`：用于决定块大小的函数。
- `is_separator_regex`：分隔符列表（默认是 `["\n\n", "\n", " ", ""]`）是否按正则表达式解释。
:::

:::js
- `chunkSize`：块的最大大小，大小由 `lengthFunction` 决定。
- `chunkOverlap`：块之间目标重叠长度。重叠块有助于减少上下文被切断时的信息损失。

## 分割不带单词边界的语言文本

有些书写系统没有[单词边界](https://en.wikipedia.org/wiki/Category:Writing_systems_without_word_boundaries)，例如中文、日文和泰文。若使用默认分隔符列表 `["\n\n", "\n", " ", ""]` 来切分文本，可能会把单词拆到不同块里。为了尽量保持单词完整，你可以覆盖分隔符列表，加入额外的标点：

* 加入 ASCII 句号 "`.`"、[Unicode 全角](https://en.wikipedia.org/wiki/Halfwidth_and_Fullwidth_Forms_(Unicode_block))句号 "`．`"（常见于中文文本），以及[表意文字句号](https://en.wikipedia.org/wiki/CJK_Symbols_and_Punctuation) "`。`"（常见于日文和中文）
* 加入 [Zero-width space](https://en.wikipedia.org/wiki/Zero-width_space)，它常用于泰文、缅文、高棉文和日文。
* 加入 ASCII 逗号 "`,`"、Unicode 全角逗号 "`，`" 和 Unicode 顿号 "`、`"

:::python
```python
text_splitter = RecursiveCharacterTextSplitter(
    separators=[
        "\n\n",
        "\n",
        " ",
        ".",
        ",",
        "\u200b",  # Zero-width space
        "\uff0c",  # Fullwidth comma
        "\u3001",  # Ideographic comma
        "\uff0e",  # Fullwidth full stop
        "\u3002",  # Ideographic full stop
        "",
    ],
    # Existing args
)
```
:::

```ts
const splitter = new RecursiveCharacterTextSplitter({
  separators: [
    "\n\n",

    " ",

    "\uff0c",  // Fullwidth comma
    "\u3001",  // Ideographic comma
    "\uff0e",  // Fullwidth full stop
    "\u3002",  // Ideographic stop
    "",
  ],
});
```
