语言模型有 token 上限，因此不应超过这个限制。所以在你把[文本分割](/oss/integrations/splitters/)成多个块时，按 token 数量进行计数通常是个好主意。可用的 tokenizer 有很多种，而在统计文本 token 时，你应当使用与你的语言模型一致的 tokenizer。

:::python
## tiktoken

<Note>
**[tiktoken](https://github.com/openai/tiktoken) 是由 `OpenAI` 创建的高性能 `BPE` tokenizer。**
</Note>


我们可以使用 `tiktoken` 来估算 token 使用量。对于 OpenAI 模型，这通常会更准确。

1. 文本如何被分割：按传入的字符分割。
2. 块大小如何衡量：按 `tiktoken` tokenizer 计数。

@[CharacterTextSplitter]、@[RecursiveCharacterTextSplitter] 和 @[TokenTextSplitter] 都可以直接配合 `tiktoken` 使用。


```python
pip install --upgrade --quiet langchain-text-splitters tiktoken
```


```python
from langchain_text_splitters import CharacterTextSplitter

# This is a long document we can split up.
with open("state_of_the_union.txt") as f:
    state_of_the_union = f.read()
```

要先用 @[CharacterTextSplitter] 进行分割，再用 `tiktoken` 合并块，可以使用它的 `.from_tiktoken_encoder()` 方法。注意，这种方法产生的块在按 `tiktoken` tokenizer 衡量时，可能会大于设定的块大小。

`.from_tiktoken_encoder()` 方法可以接收 `encoding_name`（例如 `cl100k_base`）或 `model_name`（例如 `gpt-4`）。其他附加参数如 `chunk_size`、`chunk_overlap` 和 `separators` 都会用于实例化 `CharacterTextSplitter`：


```python
text_splitter = CharacterTextSplitter.from_tiktoken_encoder(
    encoding_name="cl100k_base", chunk_size=100, chunk_overlap=0
)
texts = text_splitter.split_text(state_of_the_union)
```


```python
print(texts[0])
```
```text
Madam Speaker, Madam Vice President, our First Lady and Second Gentleman. Members of Congress and the Cabinet. Justices of the Supreme Court. My fellow Americans.

Last year COVID-19 kept us apart. This year we are finally together again.

Tonight, we meet as Democrats Republicans and Independents. But most importantly as Americans.

With a duty to one another to the American people to the Constitution.
```
如果你想对块大小施加硬性限制，可以使用 `RecursiveCharacterTextSplitter.from_tiktoken_encoder`，它会在某个分块仍然过大时继续递归分割：


```python
from langchain_text_splitters import RecursiveCharacterTextSplitter

text_splitter = RecursiveCharacterTextSplitter.from_tiktoken_encoder(
    model_name="gpt-4",
    chunk_size=100,
    chunk_overlap=0,
)
```

你也可以使用 `TokenTextSplitter`，它直接与 `tiktoken` 配合工作，并能确保每个分块都小于设定的块大小。


```python
from langchain_text_splitters import TokenTextSplitter

text_splitter = TokenTextSplitter(chunk_size=10, chunk_overlap=0)

texts = text_splitter.split_text(state_of_the_union)
print(texts[0])
```
```text
Madam Speaker, Madam Vice President, our
```
有些书写语言（例如中文和日文）中的字符会编码成两个或更多 token。直接使用 `TokenTextSplitter` 可能会把一个字符对应的 token 切到两个块里，从而产生损坏的 Unicode 字符串。为确保分块后的字符串仍是合法 Unicode，请使用 `RecursiveCharacterTextSplitter.from_tiktoken_encoder` 或 `CharacterTextSplitter.from_tiktoken_encoder`。

我们可以通过 @[TokenTextSplitter] 使用 `tiktoken` 来估算 token 使用量。对于 OpenAI 模型，这通常会更准确。

1. 文本如何被分割：按传入的字符分割。
2. 块大小如何衡量：按 `tiktoken` tokenizer 计数。

```ts
import { TokenTextSplitter } from "@langchain/textsplitters";
import { readFileSync } from "fs";

// Example: read a long document
const stateOfTheUnion = readFileSync("state_of_the_union.txt", "utf8");
```

如果你想使用 @[TokenTextSplitter] 进行分割，再结合 `tiktoken` 合并块，可以在初始化 @[TokenTextSplitter] 时传入 `encodingName`（例如 `cl100k_base`）。注意，这种方法得到的分块在按 `tiktoken` tokenizer 衡量时，可能会大于设定的块大小。

```ts
import { TokenTextSplitter } from "@langchain/textsplitters";

// Example: use cl100k_base encoding
const splitter = new TokenTextSplitter({ encodingName: "cl100k_base", chunkSize: 10, chunkOverlap: 0 });

const texts = splitter.splitText(stateOfTheUnion);
console.log(texts[0]);
```

## SentenceTransformers

[`SentenceTransformersTokenTextSplitter`](https://reference.langchain.com/python/langchain-text-splitters/sentence_transformers/SentenceTransformersTokenTextSplitter) 是一个专为 sentence-transformer 模型设计的文本分割器。其默认行为是把文本切分为适合目标 sentence-transformer 模型 token 窗口大小的多个块。

如果你想按照 sentence-transformers tokenizer 的 token 计数来切分文本，可以实例化一个 `SentenceTransformersTokenTextSplitter`。你也可以选择性指定：

- `chunk_overlap`：token 级重叠的整数数量；
- `model_name`：sentence-transformer 模型名称，默认是 `"sentence-transformers/all-mpnet-base-v2"`；
- `tokens_per_chunk`：期望的每块 token 数。


```python
from langchain_text_splitters import SentenceTransformersTokenTextSplitter

splitter = SentenceTransformersTokenTextSplitter(chunk_overlap=0)
text = "Lorem "

count_start_and_stop_tokens = 2
text_token_count = splitter.count_tokens(text=text) - count_start_and_stop_tokens
print(text_token_count)
```
```text
2
```

```python
token_multiplier = splitter.maximum_tokens_per_chunk // text_token_count + 1

# `text_to_split` does not fit in a single chunk
text_to_split = text * token_multiplier

print(f"tokens in text to split: {splitter.count_tokens(text=text_to_split)}")
```
```text
tokens in text to split: 514
```

```python
text_chunks = splitter.split_text(text=text_to_split)

print(text_chunks[1])
```
```text
lorem
```

## KoNLPY

<Note>
[KoNLPy: Korean NLP in Python](https://konlpy.org/en/latest/) 是一个面向韩语自然语言处理（NLP）的 Python 包。
</Note>

Token 分割指的是把文本切成更小、更易管理的单元，这些单元称为 token。token 通常是单词、短语、符号或其他有意义的元素，是后续处理和分析的重要基础。在英语这类语言中，token 分割通常是按空格和标点来切分单词。而 token 分割是否有效，很大程度上取决于 tokenizer 对语言结构的理解，只有这样它才能产出有意义的 token。由于为英文设计的 tokenizer 无法理解其他语言（例如韩语）特有的语义结构，因此不能有效用于韩语处理。

### 使用 KoNLPY 的 kkma 分析器对韩文进行 token 分割
在韩语文本场景下，KoNLPY 内置了一个形态分析器 `Kkma`（Korean Knowledge Morpheme Analyzer）。`Kkma` 可以对韩语文本进行细致的形态分析，把句子拆成单词，再把单词拆成对应的语素，并标注每个 token 的词性。它还可以把一整段文本切分成独立句子，这对处理长文本特别有用。

### 使用注意事项
虽然 `Kkma` 以分析细致著称，但需要注意的是，这种精度可能会影响处理速度。因此，`Kkma` 更适合那些优先追求分析深度、而不是追求快速处理的应用场景。


```python
# pip install konlpy
```


```python
# This is a long Korean document that we want to split up into its component sentences.
with open("./your_korean_doc.txt") as f:
    korean_document = f.read()
```


```python
from langchain_text_splitters import KonlpyTextSplitter

text_splitter = KonlpyTextSplitter()
```


```python
texts = text_splitter.split_text(korean_document)
# The sentences are split with "\n\n" characters.
print(texts[0])
```

## Hugging Face tokenizer

[Hugging Face](https://huggingface.co/docs/tokenizers/index) 提供了许多 tokenizer。

我们使用 Hugging Face tokenizer 中的 [GPT2TokenizerFast](https://huggingface.co/Ransaka/gpt2-tokenizer-fast) 来按 token 计算文本长度。

1. 文本如何被分割：按传入的字符分割。
2. 块大小如何衡量：按 `Hugging Face` tokenizer 计算出的 token 数衡量。


```python
from transformers import GPT2TokenizerFast

tokenizer = GPT2TokenizerFast.from_pretrained("gpt2")
```


```python
# This is a long document we can split up.
with open("state_of_the_union.txt") as f:
    state_of_the_union = f.read()
from langchain_text_splitters import CharacterTextSplitter
```


```python
text_splitter = CharacterTextSplitter.from_huggingface_tokenizer(
    tokenizer, chunk_size=100, chunk_overlap=0
)
texts = text_splitter.split_text(state_of_the_union)
```


```python
print(texts[0])
```
