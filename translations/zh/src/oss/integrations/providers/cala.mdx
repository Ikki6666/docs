# Cala

>[Cala](https://cala.ai) 是一个面向 AI 智能体的已验证知识图谱。
>它返回的是结构化、带来源引用、可追踪的事实，而不是原始网页抓取结果。
>每个回答都包含引用、置信度分数和实体级溯源信息，
>因此非常适合需要可审计、抗幻觉检索能力的生产级智能体。

## 安装

```bash
pip install langchain-cala
```

可在 [console.cala.ai](https://console.cala.ai) 获取你的 API key。

## 配置

```python
import os
os.environ["CALA_API_KEY"] = "your-api-key"
```

或者直接传入 key：

```python
from langchain_cala import CalaRetriever

retriever = CalaRetriever(api_key="your-api-key")
```

## Retriever

`CalaRetriever` 实现了 LangChain 的 `BaseRetriever` 接口，并支持三种模式：

| Mode | Endpoint | Use when |
|------|----------|----------|
| `"search"` *(default)* | `POST /v1/knowledge/search` | 开放式自然语言问题，返回带引用的综合答案 |
| `"query"` | `POST /v1/knowledge/query` | 结构化点号查询，例如 `"OpenAI.founded.year"` |
| `"entities"` | `GET /v1/entities` | 在深入查询前按名称发现实体 |

### 基础搜索

```python
from langchain_cala import CalaRetriever

retriever = CalaRetriever(api_key="your-api-key")
docs = retriever.invoke("Which EU AI startups raised funding in 2024?")

for doc in docs:
    print(doc.page_content)
    print(doc.metadata)  # includes 'verified', 'source', 'explainability'
```

### 结构化查询

```python
retriever = CalaRetriever(api_key="your-api-key", mode="query")
docs = retriever.invoke("Mistral.founded.year")
```

### 实体发现

```python
retriever = CalaRetriever(api_key="your-api-key", mode="entities")
docs = retriever.invoke("Factorial HR")
```

### 在 RAG chain 中使用

```python
from langchain_cala import CalaRetriever
from langchain_core.output_parsers import StrOutputParser
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.runnables import RunnablePassthrough
from langchain_openai import ChatOpenAI

retriever = CalaRetriever(api_key="your-api-key")

prompt = ChatPromptTemplate.from_template(
    "Answer the question based only on the following context:\n\n{context}\n\nQuestion: {question}"
)

chain = (
    {"context": retriever, "question": RunnablePassthrough()}
    | prompt
    | ChatOpenAI()
    | StrOutputParser()
)

chain.invoke("Who are the key players in European AI infrastructure?")
```

## 关键参数

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `api_key` | `SecretStr` | `$CALA_API_KEY` | 你的 Cala API key |
| `mode` | `str` | `"search"` | 可选值为 `"search"`、`"query"`、`"entities"` |
| `k` | `int` | `5` | 返回文档的最大数量 |
| `timeout` | `int` | `30` | HTTP 请求超时时间，单位为秒 |

## 为什么使用 Cala

与 Web 搜索型 retriever 不同，Cala 返回的是**经过验证的实体数据**，并且具备完整的来源可追踪性。响应中的每个文档都包含 `verified` 元数据字段和引用链，因此适合需要满足欧盟 AI 法案第 13 条可解释性要求的高风险 AI 部署场景。
