[Amazon Bedrock AgentCore Code Interpreter](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/code-interpreter-tool.html) 是 [Deep Agents](https://github.com/langchain-ai/deepagents) 的一个沙箱后端，可在隔离的 MicroVM 环境中实现安全的代码执行。

## 安装

<CodeGroup>
```bash pip
pip install langchain-agentcore-codeinterpreter
```

```bash uv
uv add langchain-agentcore-codeinterpreter
```
</CodeGroup>

## 创建沙箱后端

有关用法、文件操作和生命周期细节，请参阅 [sandboxes guide](/oss/deepagents/sandboxes)。

```python
from bedrock_agentcore.tools.code_interpreter_client import CodeInterpreter
from langchain_agentcore_codeinterpreter import AgentCoreSandbox

interpreter = CodeInterpreter(region="us-west-2")
interpreter.start()

backend = AgentCoreSandbox(interpreter=interpreter)
result = backend.execute("echo hello")
print(result.output)

interpreter.stop()
```

## 与 Deep Agents 搭配使用

```python
from bedrock_agentcore.tools.code_interpreter_client import CodeInterpreter
from langchain_agentcore_codeinterpreter import AgentCoreSandbox
from langchain_anthropic import ChatAnthropic

from deepagents import create_deep_agent

interpreter = CodeInterpreter(region="us-west-2")
interpreter.start()

backend = AgentCoreSandbox(interpreter=interpreter)

agent = create_deep_agent(
    model=ChatAnthropic(model="claude-sonnet-4-20250514"),
    system_prompt="You are a coding assistant with sandbox access.",
    backend=backend,
)

try:
    result = agent.invoke(
        {"messages": [{"role": "user", "content": "Write and run a Python script"}]}
    )
finally:
    interpreter.stop()
```

## 清理

完成后请始终停止 interpreter，以释放资源。

另请参阅：[Sandboxes](/oss/deepagents/sandboxes)。
