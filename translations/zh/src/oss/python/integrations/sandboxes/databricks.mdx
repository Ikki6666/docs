[Databricks](https://www.databricks.com/) 沙箱是 Databricks 平台上的托管、隔离计算环境。`DatabricksSandbox` 通过 [`databricks-sdk`](https://pypi.org/project/databricks-sdk/) 在 Databricks 沙箱内运行 [Deep Agents](https://github.com/langchain-ai/deepagents) 的 shell 和文件系统工具。工作区设置和身份验证请参阅 [Databricks 文档](https://docs.databricks.com/)。

<Note>
`DatabricksSandbox` 后端需要 `databricks-langchain>=0.22.0`。
</Note>

## 安装

<CodeGroup>
```bash pip
pip install 'databricks-langchain[deepagents]>=0.22.0'
```

```bash uv
uv add 'databricks-langchain[deepagents]>=0.22.0'
```
</CodeGroup>

## 创建沙箱后端

`DatabricksSandbox` 绑定到一个已在运行的沙箱。使用 Databricks SDK 预置（或复用）一个沙箱，等待其达到 `RUNNING` 状态，然后将其包装为 [deepagents 后端](/oss/deepagents/backends)。沙箱生命周期（创建、启动、删除）保留在应用代码中，而不是 agent 中。

```python
import time

from databricks.sdk import WorkspaceClient
from databricks.sdk.service.sandbox import (
    ComputeSpec,
    Sandbox,
    SandboxSpec,
    SandboxState,
)
from google.protobuf.duration_pb2 import Duration

from databricks_langchain import DatabricksSandbox

client = WorkspaceClient()

sandbox_id = "my-agent-sandbox"
name = f"sandboxes/{sandbox_id}"

client.sandbox.create_sandbox(
    Sandbox(
        spec=SandboxSpec(
            compute=ComputeSpec(inactivity_timeout=Duration(seconds=900))
        )
    ),
    sandbox_id=sandbox_id,
)

# Wait until the sandbox is RUNNING before running commands.
while client.sandbox.get_sandbox(name).status.state != SandboxState.SANDBOX_STATE_RUNNING:
    time.sleep(3)

backend = DatabricksSandbox(client, name)

result = backend.execute("echo hello")
print(result.output)
```

## 与 Deep Agents 搭配使用

```python
from deepagents import create_deep_agent
from langchain_anthropic import ChatAnthropic

# `backend` from the previous step, bound to a RUNNING Databricks sandbox.
agent = create_deep_agent(
    model=ChatAnthropic(model="claude-sonnet-4-6"),
    system_prompt="You are a coding assistant with sandbox access.",
    backend=backend,
)

result = agent.invoke(
    {"messages": [{"role": "user", "content": "Write and run a Python script"}]}
)
```

你可以使用任何 LangChain 聊天模型，包括由 Databricks Model Serving 支持的 [`ChatDatabricks`](/oss/integrations/chat/databricks)。

## 清理

你需要自行管理沙箱生命周期。
沙箱在被删除前会持续消耗资源，因此完成后请删除沙箱。

```python
client.sandbox.delete_sandbox(name)
```

另请参阅：[沙箱](/oss/deepagents/sandboxes)。
