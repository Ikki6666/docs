[Daytona](https://daytona.io) 提供启动迅速、支持多语言的沙箱环境。有关注册、认证和平台细节，请参阅 [Daytona 文档](https://www.daytona.io/docs)。

## 安装

<CodeGroup>
```bash pip
pip install langchain-daytona
```

```bash uv
uv add langchain-daytona
```
</CodeGroup>

## 创建沙箱后端

在 Python 中，你先使用 provider SDK 创建沙箱，然后用 [deepagents backend](/oss/deepagents/backends) 对其进行包装。

```python
from daytona import Daytona

from langchain_daytona import DaytonaSandbox

sandbox = Daytona().create()
backend = DaytonaSandbox(sandbox=sandbox)

result = backend.execute("echo hello")
print(result.output)
```

## 与 Deep Agents 搭配使用

```python
from daytona import Daytona
from langchain_anthropic import ChatAnthropic

from deepagents import create_deep_agent
from langchain_daytona import DaytonaSandbox

sandbox = Daytona().create()
backend = DaytonaSandbox(sandbox=sandbox)

agent = create_deep_agent(
    model=ChatAnthropic(model="claude-sonnet-4-20250514"),
    system_prompt="You are a coding assistant with sandbox access.",
    backend=backend,
)

result = agent.invoke(
    {
        "messages": [
            {"role": "user", "content": "Create a hello world Python script and run it"}
        ]
    }
)
```

## 清理

你需要自行通过 Daytona SDK 管理沙箱生命周期。
完成后，请停止或销毁该沙箱。

另请参阅：[Sandboxes](/oss/deepagents/sandboxes)。
