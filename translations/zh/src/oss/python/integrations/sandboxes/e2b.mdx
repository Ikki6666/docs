[E2B](https://e2b.dev/) 提供云端沙箱，用于在隔离环境中运行 AI 生成的代码。有关注册、认证和平台细节，请参阅 [E2B docs](https://e2b.dev/docs)。

## 安装

<CodeGroup>

```bash pip
pip install langchain-e2b
```

```bash uv
uv add langchain-e2b
```

</CodeGroup>

## 认证

设置 E2B API key：

```bash
export E2B_API_KEY="..."
```

在创建 sandbox 时，可以通过 E2B SDK 配置 E2B 特有选项，例如模板或 sandbox 生命周期。

## 创建 sandbox

在 Python 中，你需要先使用 E2B SDK 创建 sandbox，然后再用 [deepagents backend](/oss/deepagents/backends) 对它进行封装。

```python
from e2b import Sandbox
from langchain_e2b import E2BSandbox

e2b_sandbox = Sandbox.create()
backend = E2BSandbox(sandbox=e2b_sandbox)

try:
    result = backend.execute("echo hello")
    print(result.output)
finally:
    e2b_sandbox.kill()
```

## 与 Deep Agents 一起使用

```python
from e2b import Sandbox
from deepagents import create_deep_agent
from langchain_anthropic import ChatAnthropic
from langchain_e2b import E2BSandbox

e2b_sandbox = Sandbox.create()
backend = E2BSandbox(sandbox=e2b_sandbox)

agent = create_deep_agent(
    model=ChatAnthropic(model="claude-sonnet-4-6"),
    system_prompt="You are a coding assistant with sandbox access.",
    backend=backend,
)

try:
    result = agent.invoke(
        {
            "messages": [
                {"role": "user", "content": "Create a hello world Python script and run it"}
            ]
        }
    )
finally:
    e2b_sandbox.kill()
```

## 与 Deep Agents Code 一起使用

`langchain-e2b` 还为 [Deep Agents Code](/oss/deepagents/code/remote-sandboxes) 提供了一个 E2B sandbox provider，因此 `dcode` 可以在 E2B sandbox 中执行 agent tool calls。把这个包安装进 `dcode` 环境、设置 API key，然后选择该 provider：

<Note>
    在 Deep Agents Code 中使用 E2B 需要 `dcode` 0.1.19 或更高版本，以及 `langchain-e2b` 0.0.4 或更高版本。
</Note>

```bash
dcode --install langchain-e2b --package
export E2B_API_KEY="..."
dcode --sandbox e2b
```

E2B sandboxes 默认使用 `/home/user` 作为工作目录。若要基于特定的 [E2B template](https://e2b.dev/docs/sandbox-template) 创建 sandbox，请设置 `E2B_TEMPLATE`；若要修改 sandbox 生命周期，请设置 `E2B_SANDBOX_TIMEOUT`（单位为秒）。每个变量也都接受带 `DEEPAGENTS_CODE_` 前缀的形式，例如 `DEEPAGENTS_CODE_E2B_API_KEY`，而且带前缀的形式优先生效。

Deep Agents Code 会为你管理 sandbox 生命周期，在启动时创建 sandbox，在退出时删除。

## 清理

使用完成后，一定要 kill E2B sandbox，避免持续占用资源。

另请参阅：[Sandboxes](/oss/deepagents/sandboxes)。
