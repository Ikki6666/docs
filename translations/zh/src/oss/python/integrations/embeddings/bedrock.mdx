>[Amazon Bedrock](https://aws.amazon.com/bedrock/) 是一项全托管服务，通过单一 API 提供来自 `AI21 Labs`、`Anthropic`、`Cohere`、`Meta`、`Stability AI` 和 `Amazon` 等领先 AI 公司的高性能 foundation models (`FMs`) 选择，同时还提供构建生成式 AI 应用所需的安全、隐私和负责任 AI 能力。使用 `Amazon Bedrock`，你可以轻松试验和评估最适合场景的顶级模型，基于私有数据使用 fine-tuning 与 `Retrieval Augmented Generation` (`RAG`) 等技术进行定制，并构建能调用企业系统和数据源来执行任务的 agents。由于 `Amazon Bedrock` 是无服务器服务，你无需管理任何基础设施，并且可以使用你已经熟悉的 AWS 服务，将生成式 AI 能力安全地集成并部署到应用中。

```python
pip install -qU  boto3
```

```python
from langchain_aws import BedrockEmbeddings

embeddings = BedrockEmbeddings(
    credentials_profile_name="bedrock-admin", region_name="us-east-1"
)
```

```python
embeddings.embed_query("This is a content of the document")
```

```python
embeddings.embed_documents(
    ["This is a content of the document", "This is another document"]
)
```

```python
# async embed query
await embeddings.aembed_query("This is a content of the document")
```

```python
# async embed documents
await embeddings.aembed_documents(
    ["This is a content of the document", "This is another document"]
)
```
