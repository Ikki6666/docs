>[Prediction Guard](https://predictionguard.com) 是一个安全、可扩展的 GenAI 平台，可保护敏感数据、预防常见 AI 故障，并运行在经济实惠的硬件上。

## 概览

### 集成详情

本集成演示如何在 LangChain 中使用 Prediction Guard embeddings 集成。该集成支持文本和图像，可分别使用，也可作为配对一起使用。

## 设置

要访问 Prediction Guard 模型，请 [contact Prediction Guard](https://predictionguard.com/get-started) 获取 API key 并开始使用。

### 凭据

获得 key 后，你可以使用下面的方式进行设置：

```python
import os

os.environ["PREDICTIONGUARD_API_KEY"] = "<Prediction Guard API Key"
```

### 安装

```python
pip install -qU langchain-predictionguard
```

## 实例化

首先，安装 Prediction Guard 和 LangChain 包。然后，设置所需环境变量并完成包导入。

```python
from langchain_predictionguard import PredictionGuardEmbeddings
```

```python
embeddings = PredictionGuardEmbeddings(model="bridgetower-large-itm-mlm-itc")
```

Prediction Guard embeddings 既支持文本也支持图像。这个集成将这些能力分散到多个函数中。

## 索引与检索

```python
# Create a vector store with a sample text
from langchain_core.vectorstores import InMemoryVectorStore

text = "LangChain is the framework for building context-aware reasoning applications."

vectorstore = InMemoryVectorStore.from_texts(
    [text],
    embedding=embeddings,
)

# Use the vectorstore as a retriever
retriever = vectorstore.as_retriever()

# Retrieve the most similar text
retrieved_documents = retriever.invoke("What is LangChain?")

# Show the retrieved document's content
retrieved_documents[0].page_content
```

```text
'LangChain is the framework for building context-aware reasoning applications.'
```

## 直接使用

vectorstore 和 retriever 的实现会调用 `embeddings.embed_documents(...)` 和 `embeddings.embed_query(...)`，为 `from_texts` 和检索 `invoke` 操作中使用的文本创建 embedding。

这些方法可以直接通过下面的命令调用。

### 嵌入单个文本

```python
# Embedding a single string
text = "This is an embedding example."
single_vector = embeddings.embed_query(text)

single_vector[:5]
```

```text
[0.01456777285784483,
 -0.08131945133209229,
 -0.013045587576925755,
 -0.09488929063081741,
 -0.003087474964559078]
```

### 嵌入多个文本

```python
# Embedding multiple strings
docs = [
    "This is an embedding example.",
    "This is another embedding example.",
]

two_vectors = embeddings.embed_documents(docs)

for vector in two_vectors:
    print(vector[:5])
```

```text
[0.01456777285784483, -0.08131945133209229, -0.013045587576925755, -0.09488929063081741, -0.003087474964559078]
[-0.0015021917643025517, -0.08883760124444962, -0.0025286630261689425, -0.1052245944738388, 0.014225339516997337]
```
