description: "使用 LangChain Python 与 Sentence Transformers embedding 模型集成。"
---

>[Sentence Transformers](https://sbert.net) 是目前最广泛使用的 Python 框架之一，适用于最先进的文本和图像 embedding。Hugging Face Hub 托管了成千上万个预训练的 [embedding](https://huggingface.co/models?library=sentence-transformers&pipeline_tag=feature-extraction) 和 [reranker](https://huggingface.co/models?pipeline_tag=text-ranking) 模型，这些模型可以在本地运行且无需 API key，并可通过 `HuggingFaceEmbeddings` 类访问。

## 设置

```shell
pip install -qU langchain-huggingface
```

`langchain-huggingface` 会拉取 `sentence-transformers` 作为依赖，而后者会进一步安装 `transformers` 和 `torch`。

## 基本用法

```python
from langchain_huggingface import HuggingFaceEmbeddings

embeddings = HuggingFaceEmbeddings(model_name="sentence-transformers/all-mpnet-base-v2")

query_embedding = embeddings.embed_query("What is a sentence embedding?")
doc_embeddings = embeddings.embed_documents(
    [
        "Sentence embeddings map text to dense vectors.",
        "LangChain provides a standard Embeddings interface.",
    ]
)
```

## 选择模型

从 [MTEB leaderboard](https://huggingface.co/spaces/mteb/leaderboard) 开始。下面是在不同取舍下的几个不错起点：

| Model | Size | Notes |
|---|---|---|
| `sentence-transformers/all-mpnet-base-v2` | 110M | 经典、小型、适合 CPU、无需 prompt |
| `BAAI/bge-m3` | 570M | 多语言；一次生成 dense、sparse 和 multi-vector embedding |
| `mixedbread-ai/mxbai-embed-large-v1` | 335M | 英文表现强，支持 Matryoshka truncation |
| `nomic-ai/modernbert-embed-base` | 149M | 8192-token 上下文，现代架构 |
| `lightonai/DenseOn` | 149M | 现代架构，体积下性能表现强 |
| `Qwen/Qwen3-Embedding-0.6B` | 595M | 多语言、指令感知、MTEB 表现靠前 |

更多取舍说明请参见 [Factors to weigh](/oss/integrations/embeddings#factors-to-weigh)。

## 归一化 embedding

使用 cosine similarity 训练的模型会受益于归一化后的输出向量。如果你的 vector store 使用 cosine similarity，请在源头进行归一化：

```python
embeddings = HuggingFaceEmbeddings(
    model_name="BAAI/bge-m3",
    encode_kwargs={"normalize_embeddings": True},
)
```

## 设备与吞吐量

Sentence Transformers 会自动选择可用的最佳设备（CUDA > MPS > CPU），因此在大多数情况下你无需显式设置 `device=`。在 GPU 上，可以增大 `batch_size` 以充分利用算力：

```python
embeddings = HuggingFaceEmbeddings(
    model_name="BAAI/bge-m3",
    encode_kwargs={"batch_size": 64, "normalize_embeddings": True},
)
```

如果你想固定到特定设备，可以传入 `model_kwargs={"device": "cpu"}`（或 `"cuda:1"` 等）。对于多 GPU 场景，可设置 `multi_process=True`。在 Intel CPU 上，可在安装 `optimum[ipex]` 后使用 `model_kwargs={"backend": "ipex"}`。

## Query 和 document prompts

某些模型（`intfloat/e5-*`、`Qwen/Qwen3-Embedding-*`、许多 `BAAI/bge-*`）在训练时会为 query 和 document 使用不同的 prompt。你可以通过 `encode_kwargs` 和 `query_encode_kwargs` 传入这些 prompt：

```python
embeddings = HuggingFaceEmbeddings(
    model_name="intfloat/e5-large-v2",
    encode_kwargs={"prompt": "passage: "},
    query_encode_kwargs={"prompt": "query: "},
)
```

在索引和查询时使用正确的 prompt 通常会显著提升检索质量。请查看 Hugging Face 上各模型的 model card 获取推荐的 prompt 字符串。

## 用于生产环境部署

如果你要大规模提供 Sentence Transformers 模型服务，请使用 [Text Embeddings Inference (TEI)](/oss/integrations/embeddings/text_embeddings_inference)，这是 Hugging Face 提供的专用推理服务器，支持 batching、GPU 以及 OpenAI-compatible APIs。你可以通过 `HuggingFaceEndpointEmbeddings` 连接 LangChain 到 TEI 部署：参见 [main Hugging Face embeddings guide](/oss/integrations/embeddings/huggingfacehub)。

## Reranking

同一生态中也提供 [cross-encoder reranker models](https://huggingface.co/models?pipeline_tag=text-ranking)。如果你想在 vector store 之上使用本地 reranker，请参见 [Cross Encoder Reranker guide](/oss/integrations/document_transformers/cross_encoder_reranker)。

## 故障排查

如果 `accelerate` 包缺失或导入失败：

```shell
pip install -qU accelerate
```
