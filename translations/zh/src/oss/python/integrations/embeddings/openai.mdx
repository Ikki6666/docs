## 设置

要访问 OpenAI embedding 模型，你需要创建 OpenAI 账号、获取 API key，并安装 `langchain-openai` 集成包。

### 凭据

前往 [platform.openai.com](https://platform.openai.com) 注册 OpenAI 并生成 API key。完成后，设置 `OPENAI_API_KEY` 环境变量：

```python
import getpass
import os

if not os.getenv("OPENAI_API_KEY"):
    os.environ["OPENAI_API_KEY"] = getpass.getpass("Enter your OpenAI API key: ")
```

如果你通过代理或 service emulator 路由请求，可以通过 env var 设置 base URL，而不是传入 `base_url`。解析顺序（先匹配到的生效）：

1. 显式的 `base_url`（或 `openai_api_base`）参数。
2. `OPENAI_API_BASE` - 由 LangChain 在初始化时读取。
3. `OPENAI_BASE_URL` - 由底层 `openai` SDK client 读取。

要启用模型调用的自动 tracing，请设置你的 [LangSmith](/langsmith/observability) API key：

```python
os.environ["LANGSMITH_TRACING"] = "true"
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
```

### 安装

LangChain OpenAI 集成位于 `langchain-openai` 包中：

```python
pip install -qU langchain-openai
```

## 实例化

现在我们可以实例化模型对象并生成 chat completions：

```python
from langchain_openai import OpenAIEmbeddings

embeddings = OpenAIEmbeddings(
    model="text-embedding-3-large",
    # With the `text-embedding-3` class
    # of models, you can specify the size
    # of the embeddings you want returned.
    # dimensions=1024
)
```

<Info>
    **Azure OpenAI v1 API 支持**

    从 `langchain-openai>=1.0.1` 开始，`OpenAIEmbeddings` 可以直接配合 Azure OpenAI endpoints 使用新的 [v1 API](https://learn.microsoft.com/en-us/azure/ai-foundry/openai/api-version-lifecycle?tabs=python#next-generation-api-1)，并支持 Microsoft Entra ID authentication。更多细节请参见下面的 [Using with Azure OpenAI](#using-with-azure-openai) 部分。
</Info>

## 索引与检索

Embedding 模型常用于检索增强生成（RAG）流程，既可以用于索引数据，也可以用于后续检索。更详细的说明请参见我们的 [RAG tutorials](/oss/deepagents/rag)。

下面展示如何使用上面初始化的 `embeddings` 对象进行索引和检索。在这个示例中，我们会在 `InMemoryVectorStore` 中索引和检索一个示例文档。

```python
# Create a vector store with a sample text
from langchain_core.vectorstores import InMemoryVectorStore

text = "LangChain is the framework for building context-aware reasoning applications"

vectorstore = InMemoryVectorStore.from_texts(
    [text],
    embedding=embeddings,
)

# Use the vectorstore as a retriever
retriever = vectorstore.as_retriever()

# Retrieve the most similar text
retrieved_documents = retriever.invoke("What is LangChain?")

# show the retrieved document's content
retrieved_documents[0].page_content
```

```text
'LangChain is the framework for building context-aware reasoning applications'
```

## 直接使用

在底层，vectorstore 和 retriever 的实现会调用 `embeddings.embed_documents(...)` 和 `embeddings.embed_query(...)`，分别为 `from_texts` 和检索 `invoke` 中使用的文本创建 embedding。

你可以直接调用这些方法来满足自己的使用场景。

### 嵌入单个文本

你可以使用 `embed_query` 嵌入单个文本或文档：

```python
single_vector = embeddings.embed_query(text)
print(str(single_vector)[:100])  # Show the first 100 characters of the vector
```

```text
[-0.019276829436421394, 0.0037708976306021214, -0.03294256329536438, 0.0037671267054975033, 0.008175
```

### 嵌入多个文本

你可以使用 `embed_documents` 嵌入多个文本：

```python
text2 = (
    "LangGraph is a library for building stateful, multi-actor applications with LLMs"
)
two_vectors = embeddings.embed_documents([text, text2])
for vector in two_vectors:
    print(str(vector)[:100])  # Show the first 100 characters of the vector
```

```text
[-0.019260549917817116, 0.0037612367887049913, -0.03291035071015358, 0.003757466096431017, 0.0082049
[-0.010181212797760963, 0.023419594392180443, -0.04215526953339577, -0.001532090245746076, -0.023573
```

## 使用 Azure OpenAI

<Info>
    **Azure OpenAI v1 API 支持**

    从 `langchain-openai>=1.0.1` 开始，`OpenAIEmbeddings` 可以直接配合 Azure OpenAI endpoints 使用新的 [v1 API](https://learn.microsoft.com/en-us/azure/ai-foundry/openai/api-version-lifecycle?tabs=python#next-generation-api-1)。这为在 OpenAI 或 Azure 上托管的 OpenAI embeddings 提供了统一使用方式。

    对于传统的 Azure-specific 实现，请继续使用 [`AzureOpenAIEmbeddings`](/oss/integrations/embeddings/azure_openai)。
</Info>

### 使用 API Key 的 Azure OpenAI v1 API

要将 `OpenAIEmbeddings` 与 Azure OpenAI 配合使用，请将 `base_url` 设置为你的 Azure endpoint，并附加 `/openai/v1/`：

```python
from langchain_openai import OpenAIEmbeddings

embeddings = OpenAIEmbeddings(
    model="text-embedding-3-large",  # Your Azure deployment name
    base_url="https://{your-resource-name}.openai.azure.com/openai/v1/",
    api_key="your-azure-api-key"
)

# Use as normal
vector = embeddings.embed_query("Hello world")
```

### 使用 Microsoft Entra ID 的 Azure OpenAI

v1 API 为 [Microsoft Entra ID](https://learn.microsoft.com/en-us/azure/ai-foundry/openai/how-to/managed-identity) authentication 提供原生支持，并自动刷新 token。将 token provider callable 传给 `api_key` 参数：

```python
from azure.identity import DefaultAzureCredential, get_bearer_token_provider
from langchain_openai import OpenAIEmbeddings

# Create a token provider that handles automatic refresh
token_provider = get_bearer_token_provider(
    DefaultAzureCredential(),
    "https://cognitiveservices.azure.com/.default"
)

embeddings = OpenAIEmbeddings(
    model="text-embedding-3-large",  # Your Azure deployment name
    base_url="https://{your-resource-name}.openai.azure.com/openai/v1/",
    api_key=token_provider  # Callable that handles token refresh
)

# Use as normal
vectors = embeddings.embed_documents(["Hello", "World"])
```

<Tip>
**安装要求**

要使用 Microsoft Entra ID authentication，请安装 Azure Identity 库：

```bash
pip install azure-identity
```

</Tip>

在使用 API key 的异步函数时，你也可以将 token provider callable 传给 `api_key` 参数。你必须从 `azure.identity.aio` 导入 `DefaultAzureCredential`：

:::python

```python
from azure.identity.aio import DefaultAzureCredential
from langchain_openai import OpenAIEmbeddings

credential = DefaultAzureCredential()

embeddings_async = OpenAIEmbeddings(
    model="text-embedding-3-large",
    api_key=credential
)

# Use async methods when using async callable
vectors = await embeddings_async.aembed_documents(["Hello", "World"])

```

:::

<Note>
    当使用异步 callable 作为 API key 时，你必须使用异步方法（`aembed_query`、`aembed_documents`）。同步方法会抛出错误。
</Note>
