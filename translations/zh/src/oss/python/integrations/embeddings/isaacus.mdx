本指南将带你了解如何开始使用 [Isaacus'](/oss/integrations/providers/isaacus) LangChain 集成来生成法律领域 embeddings。

## 1. 设置你的账户

前往 [Isaacus Platform](https://platform.isaacus.com/accounts/signup/) 创建一个新账户。

注册后，先[添加支付方式](https://platform.isaacus.com/billing/)以领取你的[免费额度](https://docs.isaacus.com/pricing/credits)。

添加支付方式后，[创建一个新的 API key](https://platform.isaacus.com/users/api-keys/)。

请务必妥善保管你的 API key。创建之后你将无法再次查看它。不过不用担心，你始终可以重新生成一个新的。

## 2. 安装 isaacus API client

账户准备好后，安装 [Isaacus LangChain](https://pypi.org/project/langchain-isaacus/) 集成包。

<CodeGroup>
```bash pip
pip install langchain-isaacus
```

```bash uv
uv add langchain-isaacus
```
</CodeGroup>

## 3. 为文档生成 embedding

安装好 API client 后，让我们为第一个法律查询和文档生成 embeddings。

首先，你需要**使用 API key 初始化 client**。你可以通过设置 `ISAACUS_API_KEY` 环境变量来完成，也可以像本示例一样直接传入。

我们将使用 [Kanon 2 Embedder](https://isaacus.com/blog/introducing-kanon-2-embedder)，这是截至 2025 年 10 月 20 日在 [Massive Legal Embedding Benchmark](https://isaacus.com/blog/introducing-mleb) 上全球最准确的法律 embedding 模型。

```python
from langchain_isaacus import IsaacusEmbeddings

# Create an Isaacus API client for Kanon 2 Embedder.
client = IsaacusEmbeddings(
    model="kanon-2-embedder",
    api_key="PASTE_YOUR_API_KEY_HERE",
    # dimensions=1792, # You may optionally wish to specify a lower dimension.
)
```
接下来，让我们获取一份要做 embedding 的法律文档。本例中，我们将使用 [GitHub's terms of service](https://github.com/terms)。

```python
import isaacus

tos = isaacus.Isaacus().get(path="https://examples.isaacus.com/github-tos.md", cast_to=str)
```

我们的目标是根据关于它的一个搜索查询，检索出 GitHub 的服务条款。

为此，我们首先使用 API client 的 `.embed_documents()` 方法为文档生成 embedding。使用这个方法意味着我们在为文档生成 embedding，而不是为搜索查询生成 embedding，这一点很重要，因为它能确保 embeddings 针对检索任务进行了优化，而不是用于分类或句子相似度之类的其他任务。

```python
document_embedding = client.embed_documents(texts=[tos])[0]
```

现在，让我们为两个搜索查询生成 embeddings，一个与文档明显相关，另一个则明显无关。这一次我们将使用 API client 的 `.embed_query()` 方法，它表明我们正在为搜索查询生成 embedding。

```python
relevant_query_embedding = client.embed_query(text="What are GitHub's billing policies?")
irrelevant_query_embedding = client.embed_query(text="What are Microsoft's billing policies?")
```

为了评估这些查询与文档之间的相关性，我们可以计算它们的 embeddings 与文档 embedding 之间的余弦相似度。

余弦相似度用于衡量两组数字之间的相似程度，更具体地说，是内积空间中两个向量夹角的余弦值。理论上，它的取值范围是 $$-1$$ 到 $$1$$，其中 $$1$$ 表示向量完全相同，$$0$$ 表示它们正交，也就是完全不相似，而 $$-1$$ 表示它们方向完全相反。不过在实际中，对于文本 embeddings，它通常落在 $$0$$ 到 $$1$$ 之间，因为它们通常是非负的。

Isaacus 的 embedders 经过优化，使其生成的 embeddings 的余弦相似度大致对应原始文本在语义上的相似程度。不过，与 Isaacus 的通用 classifiers 不同，Isaacus embedders 的得分并没有校准为概率含义，它们只能作为相对相似度来解释，因此最适合用于搜索结果排序。

为了方便起见，我们的 Python 示例使用 [`numpy`](https://numpy.org/) 的 `dot` 函数来计算 embeddings 的点积。由于我们的 embeddings 都经过 L2 归一化，这与计算它们的余弦相似度是等价的。如果你愿意，也可以使用其他库来计算 embeddings 的余弦相似度，例如通过 [`torch`](https://pytorch.org/) 的 `torch.nn.functional.cosine_similarity`，或者自己实现。

```python
import numpy as np

relevant_similarity = np.dot(relevant_query_embedding, document_embedding)
irrelevant_similarity = np.dot(irrelevant_query_embedding, document_embedding)

print(f"Similarity of relevant query to the document: {relevant_similarity * 100:.2f}")
print(f"Similarity of irrelevant query to the document: {irrelevant_similarity * 100:.2f}")
```

输出看起来应当类似这样：
```text
Similarity of relevant query to the document: 52.87
Similarity of irrelevant query to the document: 24.86
```

如你所见，相关查询与文档之间的相似度明显高于不相关查询，这说明我们的 embedder 已成功捕捉到了文本的语义含义。

就是这样！你已经成功通过 LangChain 中的 Isaacus API 为法律文档和查询生成了 embeddings。
