## 设置

首先，请按照 [these instructions](https://github.com/ollama/ollama?tab=readme-ov-file#ollama) 配置并运行本地 Ollama 实例：

* [下载](https://ollama.ai/download) 并在支持的平台上安装 Ollama（包括 Windows Subsystem for Linux aka WSL、macOS 和 Linux）
  * macOS 用户可以通过 Homebrew 安装：`brew install ollama`，然后使用 `brew services start ollama` 启动
* 使用 `ollama pull <name-of-model>` 获取可用的 LLM model
  * 可通过 [model library](https://ollama.ai/library) 查看可用模型列表
  * 例如：`ollama pull llama3`
* 这会下载默认标签版本的模型。通常默认值指向最新、参数规模最小的模型。

> 在 Mac 上，模型会下载到 `~/.ollama/models`
>
> 在 Linux（或 WSL）上，模型会存储在 `/usr/share/ollama/.ollama/models`

* 如需指定模型的具体版本，可以像这样：`ollama pull vicuna:13b-v1.5-16k-q4_0`（在该示例中可查看 [`Vicuna`](https://ollama.ai/library/vicuna/tags) 模型的各种 tags）
* 要查看所有已拉取的模型，请使用 `ollama list`
* 要直接从命令行与某个模型对话，请使用 `ollama run <name-of-model>`
* 查看 [Ollama documentation](https://github.com/ollama/ollama/tree/main/docs) 获取更多命令。你也可以在终端中运行 `ollama help` 来查看可用命令。

要启用模型调用的自动 tracing，请设置你的 [LangSmith](/langsmith/observability) API key：

```python
os.environ["LANGSMITH_TRACING"] = "true"
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
```

### 安装

LangChain Ollama 集成位于 `langchain-ollama` 包中：

```python
pip install -qU langchain-ollama
```

## 实例化

现在我们可以实例化模型对象并生成 embedding：

```python
from langchain_ollama import OllamaEmbeddings

embeddings = OllamaEmbeddings(
    model="llama3",
)
```

如果你的模型支持可配置输出维度（例如 `qwen3-embedding`），可以通过 `dimensions` 参数指定：

```python
from langchain_ollama import OllamaEmbeddings

embeddings = OllamaEmbeddings(
    model="qwen3-embedding:8b",
    dimensions=1024,
)
```

## 索引与检索

Embedding 模型常用于检索增强生成（RAG）流程，既可以用于索引数据，也可以用于后续检索。更详细的说明请参见我们的 [RAG tutorials](/oss/langchain/rag/)。

下面展示如何使用上面初始化的 `embeddings` 对象进行索引和检索。在这个示例中，我们会在 `InMemoryVectorStore` 中索引和检索一个示例文档。

```python
# Create a vector store with a sample text
from langchain_core.vectorstores import InMemoryVectorStore

text = "LangChain is the framework for building context-aware reasoning applications"

vectorstore = InMemoryVectorStore.from_texts(
    [text],
    embedding=embeddings,
)

# Use the vectorstore as a retriever
retriever = vectorstore.as_retriever()

# Retrieve the most similar text
retrieved_documents = retriever.invoke("What is LangChain?")

# Show the retrieved document's content
print(retrieved_documents[0].page_content)
```

```text
LangChain is the framework for building context-aware reasoning applications
```

## 直接使用

在底层，vectorstore 和 retriever 的实现会调用 `embeddings.embed_documents(...)` 和 `embeddings.embed_query(...)`，分别为 `from_texts` 和检索 `invoke` 中使用的文本创建 embedding。

你可以直接调用这些方法来满足自己的使用场景。

### 嵌入单个文本

你可以使用 `embed_query` 嵌入单个文本或文档：

```python
single_vector = embeddings.embed_query(text)
print(str(single_vector)[:100])  # Show the first 100 characters of the vector
```

```text
[-0.0039849705, 0.023019705, -0.001768838, -0.0058736936, 0.00040999008, 0.017861595, -0.011274585,
```

### 嵌入多个文本

你可以使用 `embed_documents` 嵌入多个文本：

```python
text2 = (
    "LangGraph is a library for building stateful, multi-actor applications with LLMs"
)
two_vectors = embeddings.embed_documents([text, text2])
for vector in two_vectors:
    print(str(vector)[:100])  # Show the first 100 characters of the vector
```

```text
[-0.0039849705, 0.023019705, -0.001768838, -0.0058736936, 0.00040999008, 0.017861595, -0.011274585,
[-0.0066985516, 0.009878328, 0.008019467, -0.009384944, -0.029560851, 0.025744654, 0.004872892, -0.0
```
