这将帮助你开始使用 Google Generative AI embedding 模型与 LangChain。关于 `GoogleGenerativeAIEmbeddings` 功能和配置选项的详细文档，请参见 [API reference](https://reference.langchain.com/python/langchain-google-genai/embeddings/GoogleGenerativeAIEmbeddings)。

## 概览

<Note>
    `gemini-embedding-2-preview` 通过 Google GenAI SDK 的 `embed_content()` API 原生支持文本、图片、视频、音频和 PDF 输入。不过，LangChain 的 `Embeddings` 接口（`embed_query` / `embed_documents`）当前只接受文本输入。LangChain 中对多模态 embedding 的支持计划在未来版本提供。对于今天的多模态场景，请直接使用 [Google GenAI SDK](https://ai.google.dev/gemini-api/docs)。
</Note>

### 集成详情

## 设置

要访问 Google Gemini embedding 模型，你需要创建 Google Cloud 项目、启用 Generative Language API、获取 API key，并安装 `langchain-google-genai` 集成包。

### 凭据

前往 [Google AI Studio](https://aistudio.google.com/apikey) 注册并生成 API key。更多细节请参见 [Gemini API keys documentation](https://ai.google.dev/gemini-api/docs/api-key)。完成后，设置 `GOOGLE_API_KEY` 环境变量：

```python
import getpass
import os

if not os.getenv("GOOGLE_API_KEY"):
    os.environ["GOOGLE_API_KEY"] = getpass.getpass("Enter your Google API key: ")
```

要启用模型调用的自动 tracing，请设置你的 [LangSmith](/langsmith/observability) API key：

```python
os.environ["LANGSMITH_TRACING"] = "true"
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
```

### 安装

LangChain Google Generative AI 集成位于 `langchain-google-genai` 包中：

```bash
pip install -qU langchain-google-genai
```

## 实例化

现在我们可以实例化模型对象并生成 embedding：

```python
from langchain_google_genai import GoogleGenerativeAIEmbeddings

embeddings = GoogleGenerativeAIEmbeddings(model="gemini-embedding-2-preview")
vector = embeddings.embed_query("hello, world!")
vector[:5]
```

```text
[-0.024917153641581535,
 0.012005362659692764,
 -0.003886754624545574,
 -0.05774897709488869,
 0.0020742062479257584]
```

### 降低维度

`gemini-embedding-2-preview` 通过 Matryoshka Representation Learning (MRL) 支持灵活的输出维度。你可以降低维度来优化存储和延迟：

```python
embeddings = GoogleGenerativeAIEmbeddings(
    model="gemini-embedding-2-preview",
    output_dimensionality=768,  # Suggested: 768, 1536, or 3072 (default)
)
vector = embeddings.embed_query("hello, world!")
len(vector)
```

```text
768
```

## 批处理

你也可以一次嵌入多个字符串，以提升处理速度：

```python
vectors = embeddings.embed_documents(
    [
        "Today is Monday",
        "Today is Tuesday",
        "Today is April Fools day",
    ]
)
len(vectors), len(vectors[0])
```

```text
(3, 768)
```

## 索引与检索

Embedding 模型常用于检索增强生成（RAG）流程，既可以用于索引数据，也可以用于后续检索。更详细的说明请参见我们的 [RAG tutorials](/oss/langchain/rag)。

下面展示如何使用上面初始化的 `embeddings` 对象进行索引和检索。在这个示例中，我们会在 `InMemoryVectorStore` 中索引和检索一个示例文档。

```python
# Create a vector store with a sample text
from langchain_core.vectorstores import InMemoryVectorStore

text = "LangChain is the framework for building context-aware reasoning applications"

vectorstore = InMemoryVectorStore.from_texts(
    [text],
    embedding=embeddings,
)

# Use the vectorstore as a retriever
retriever = vectorstore.as_retriever()

# Retrieve the most similar text
retrieved_documents = retriever.invoke("What is LangChain?")

# show the retrieved document's content
retrieved_documents[0].page_content
```

```text
'LangChain is the framework for building context-aware reasoning applications'
```

## Task type

`GoogleGenerativeAIEmbeddings` 可选支持 `task_type`，当前必须是以下之一：

- `SEMANTIC_SIMILARITY`: 用于生成优化后的 embedding，以评估文本相似度。
- `CLASSIFICATION`: 用于生成优化后的 embedding，以根据预设标签对文本进行分类。
- `CLUSTERING`: 用于生成优化后的 embedding，以根据相似性对文本聚类。
- `RETRIEVAL_DOCUMENT`、`RETRIEVAL_QUERY`、`QUESTION_ANSWERING` 和 `FACT_VERIFICATION`: 用于生成优化后的 embedding，适合文档搜索或信息检索。
- `CODE_RETRIEVAL_QUERY`: 用于根据自然语言查询检索代码块，例如对数组排序或反转链表。代码块的 embedding 使用 `RETRIEVAL_DOCUMENT` 计算。

默认情况下，我们在 `embed_documents` 方法中使用 `RETRIEVAL_DOCUMENT`，在 `embed_query` 方法中使用 `RETRIEVAL_QUERY`。如果你提供了 task type，我们会在所有方法中都使用它。

```bash
pip install -qU matplotlib scikit-learn
```

```python
from langchain_google_genai import GoogleGenerativeAIEmbeddings
from sklearn.metrics.pairwise import cosine_similarity

query_embeddings = GoogleGenerativeAIEmbeddings(
    model="gemini-embedding-2-preview", task_type="RETRIEVAL_QUERY"
)
doc_embeddings = GoogleGenerativeAIEmbeddings(
    model="gemini-embedding-2-preview", task_type="RETRIEVAL_DOCUMENT"
)

q_embed = query_embeddings.embed_query("What is the capital of France?")
d_embed = doc_embeddings.embed_documents(
    ["The capital of France is Paris.", "Philipp likes to eat pizza."]
)

for i, d in enumerate(d_embed):
    print(f"Document {i + 1}:")
    print(f"Cosine similarity with query: {cosine_similarity([q_embed], [d])[0][0]}")
    print("---")
```

```text
Document 1:
Cosine similarity with query: 0.7892893360164779
---
Document 2:
Cosine similarity with query: 0.5438283285204146
---
```

## Additional configuration

你可以向 `GoogleGenerativeAIEmbeddings` 传入以下参数来自定义 SDK 行为：

- `base_url`: API 客户端的自定义 base URL（例如自定义 endpoint）
- `output_dimensionality`: 降低返回 embedding 的维度（例如 `output_dimensionality=256`）
- `request_options`: 请求选项字典（例如 `{"timeout": 10}`）
- `additional_headers`: 要包含在 API 请求中的额外 HTTP headers
- `client_args`: 传递给底层 HTTP client 的额外参数
