>[Hugging Face 上的 BGE 模型](https://huggingface.co/BAAI)是一系列由[北京智源人工智能研究院（BAAI）](https://en.wikipedia.org/wiki/Beijing_Academy_of_Artificial_Intelligence)发布的开源 embedding 和 reranking 模型。BGE 是 2023 年和 2024 年领先的开源 embedding 系列之一，虽然 [MTEB 排行榜](https://huggingface.co/spaces/mteb/leaderboard)上的更新模型后来在原始检索分数上超过了它们，但 BGE，尤其是 `BAAI/bge-m3`，仍然是多语言检索中广泛使用、整体表现均衡的默认选择。

LangChain 提供了两种使用 BGE 模型的方式：

- 来自 `langchain-huggingface` 的 `HuggingFaceEmbeddings`，这是通用的 Sentence Transformers 类。它覆盖所有 BGE 变体，也是新项目的**推荐**选择。

## `BAAI/bge-m3` 及更新模型

```shell
pip install -qU langchain-huggingface
```

```python
from langchain_huggingface import HuggingFaceEmbeddings

embeddings = HuggingFaceEmbeddings(
    model_name="BAAI/bge-m3",
    encode_kwargs={"normalize_embeddings": True},
)
```

`BAAI/bge-m3` 在训练时没有使用 query prompt，因此不需要额外配置。模型作者建议将 `normalize_embeddings=True` 用于余弦相似度。

## `BAAI/bge-*-en-v1.5`（快捷路径）

```python
from langchain_huggingface import HuggingFaceEmbeddings

embeddings = HuggingFaceEmbeddings(
    model_name="BAAI/bge-large-en-v1.5",
    encode_kwargs={"normalize_embeddings": True},
    query_encode_kwargs={
        "prompt": "Represent this sentence for searching relevant passages: ",
        "normalize_embeddings": True,
    },
)
```

不同的 BGE 变体使用不同的 prompt，请查看 Hugging Face 上各模型卡片中的准确字符串。

## 选择 BGE 模型

| Model | Size | Notes |
|---|---|---|
| `BAAI/bge-small-en-v1.5` | 33M | 最小的英文模型，对 CPU 友好 |
| `BAAI/bge-large-en-v1.5` | 335M | 更强的英文模型，常用基线 |
| `BAAI/bge-m3` | 570M | 多语言，在一个模型中同时支持 dense、sparse 和 multi-vector |

关于 reranking，而不是 embedding，请参阅 [`BAAI/bge-reranker-v2-m3`](https://huggingface.co/BAAI/bge-reranker-v2-m3) 以及[Cross Encoder Reranker 指南](/oss/integrations/document_transformers/cross_encoder_reranker)。
