`langchain-nvidia-ai-endpoints` 包包含由 [NVIDIA AI Foundation Models](https://www.nvidia.com/en-us/ai-data-science/foundation-models/) 提供支持、并托管在 [NVIDIA API Catalog](https://build.nvidia.com/) 上的 chat models 和 embeddings 的 LangChain 集成。

NVIDIA AI Foundation models 是社区和 NVIDIA 共同构建的模型，经过优化，可在 NVIDIA 加速基础设施上提供最佳性能。你可以使用 API 查询 NVIDIA API Catalog 上可用的 live endpoints，以便从 DGX 托管的云计算环境快速获得结果；或者，你也可以使用 NVIDIA NIM 从 NVIDIA API catalog 下载模型，NVIDIA NIM 已包含在 NVIDIA AI Enterprise 许可中。将模型运行在本地环境的能力，使企业能够拥有自己的定制内容，并完全掌控其 IP 和 AI 应用。

NIM microservices 以容器镜像形式按单个模型 / 模型族进行打包，并通过 [NVIDIA NGC Catalog](https://catalog.ngc.nvidia.com/) 分发。其核心是作为容器运行的微服务，为在 AI Model 上执行推理提供交互式 API。

本示例介绍如何使用 LangChain 通过 `NVIDIAEmbeddings` 类与支持的 [NVIDIA Retrieval QA Embedding Model](https://build.nvidia.com/nvidia/embed-qa-4) 进行交互，用于 [retrieval-augmented generation](https://developer.nvidia.com/blog/build-enterprise-retrieval-augmented-generation-apps-with-nvidia-retrieval-qa-embedding-model/)。

关于通过此 API 访问 chat models 的更多信息，请参见 [ChatNVIDIA](/oss/integrations/chat/nvidia_ai_endpoints) 文档。

## 访问 NVIDIA API Catalog

要访问 NVIDIA API Catalog，请执行以下操作：

1. 在 [NVIDIA API Catalog](https://build.nvidia.com/) 创建一个免费账号并登录。
2. 点击你的 profile icon，然后点击 **API Keys**。此时会显示 **API Keys** 页面。
3. 点击 **Generate API Key**。会弹出 **Generate API Key** 窗口。
4. 点击 **Generate Key**。你会看到 **API Key Granted**，并且你的 key 会显示出来。
5. 将该 key 复制并保存为 `NVIDIA_API_KEY`。
6. 要验证你的 key，请使用下面的代码。

```python
import getpass
import os

if os.environ.get("NVIDIA_API_KEY", "").startswith("nvapi-"):
    print("Valid NVIDIA_API_KEY already in environment. Delete to reset")
else:
    nvapi_key = getpass.getpass("NVAPI Key (starts with nvapi-): ")
    assert nvapi_key.startswith(
        "nvapi-"
    ), f"{nvapi_key[:5]}... is not a valid key"
    os.environ["NVIDIA_API_KEY"] = nvapi_key
```

现在你就可以使用该 key 访问 NVIDIA API Catalog 上的 endpoints。

## 使用 API Catalog

初始化 embedding 模型时，你可以通过传入模型名称来选择模型，例如下面的 `NV-Embed-QA`，也可以什么都不传而使用默认模型。

```python
from langchain_nvidia_ai_endpoints import NVIDIAEmbeddings

embedder = NVIDIAEmbeddings(model="NV-Embed-QA")
```

该模型是一个微调过的 E5-large 模型，支持预期的 @[`Embeddings`] 方法，包括：

- `embed_query`: 为一个 query sample 生成 query embedding。
- `embed_documents`: 为你想要检索的一组 documents 生成 passage embeddings。
- `aembed_query`/`aembed_documents`: 上述方法的异步版本。

## 使用 NVIDIA NIM Microservices 自托管

当你准备部署 AI 应用时，可以使用 NVIDIA NIM 自托管模型。更多信息请参见 [NVIDIA NIM Microservices](https://www.nvidia.com/en-us/ai-data-science/products/nim-microservices/)。

下面的代码会连接到本地托管的 NIM Microservices。

```python
from langchain_nvidia_ai_endpoints import ChatNVIDIA, NVIDIAEmbeddings, NVIDIARerank

# connect to a chat NIM running at localhost:8000, specifying a model
llm = ChatNVIDIA(base_url="http://localhost:8000/v1", model="meta/llama3-8b-instruct")

# connect to an embedding NIM running at localhost:8080
embedder = NVIDIAEmbeddings(base_url="http://localhost:8080/v1")

# connect to a reranking NIM running at localhost:2016
ranker = NVIDIARerank(base_url="http://localhost:2016/v1")
```

## 截断

Embedding 模型通常有固定的上下文窗口，用于决定可被 embedding 的最大输入 token 数。这个限制可能是硬限制，也可能是模型最大输入 token 长度，或者是一个有效限制，超过后 embedding 的准确性会下降。

由于模型以 token 为单位运行，而应用通常处理的是文本，因此应用很难确保输入始终处在模型 token 限制之内。默认情况下，如果输入过大，会抛出异常。

为了解决这个问题，NVIDIA 的 NIM（API Catalog 或本地）提供了 `truncate` 参数，可以在输入过大时在服务器端进行截断。

`truncate` 参数有三种选项：

- "NONE": 默认选项。如果输入过大，会抛出异常。
- "START": 服务器从开头（左侧）截断输入，按需丢弃 tokens。
- "END": 服务器从结尾（右侧）截断输入，按需丢弃 tokens。

```python
long_text = "AI is amazing, amazing is " * 100
```

```python
strict_embedder = NVIDIAEmbeddings()
try:
    strict_embedder.embed_query(long_text)
except Exception as e:
    print("Error:", e)
```

```python
truncating_embedder = NVIDIAEmbeddings(truncate="END")
truncating_embedder.embed_query(long_text)[:5]
```
