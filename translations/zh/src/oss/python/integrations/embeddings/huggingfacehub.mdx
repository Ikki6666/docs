LangChain 支持三种使用 Hugging Face embedding 模型的方式：

- 通过 `HuggingFaceEmbeddings` 进行**本地推理**，下载模型并结合 [Sentence Transformers](https://sbert.net) 在进程内运行。
- 通过 `HuggingFaceEndpointEmbeddings` 使用 **Inference Providers 和专用 Inference Endpoints**，在 Hugging Face 上进行无服务器或专用托管推理。
- 通过 [Text Embeddings Inference (TEI)](/oss/integrations/embeddings/text_embeddings_inference) 实现**大规模自托管**，这是 Hugging Face 的生产级推理服务器，也由 `HuggingFaceEndpointEmbeddings` 指向。

这三种方式都使用同一个 `Embeddings` 接口，因此你可以先从本地开始，再平滑迁移到托管或自托管部署，而无需修改应用的其余部分。

## 设置

```shell
pip install -qU langchain-huggingface
```

## 本地 embeddings

通过 `sentence-transformers` 在本地生成 embeddings。首次运行时会下载模型权重。

```python
from langchain_huggingface import HuggingFaceEmbeddings

embeddings = HuggingFaceEmbeddings(
    model_name="sentence-transformers/all-mpnet-base-v2",
    encode_kwargs={"normalize_embeddings": True},
)

query_result = embeddings.embed_query("This is a test document.")
doc_result = embeddings.embed_documents(["This is a test document."])
```

关于模型选择、GPU 配置，以及 query/document prompts，请参阅专门的 [Sentence Transformers 指南](/oss/integrations/embeddings/sentence_transformers)。

## Hugging Face Inference Endpoints 和 Providers

如果你不想在本地下载模型，也可以通过 [Hugging Face Inference Providers](https://huggingface.co/docs/inference-providers) 或专用的 [Inference Endpoint](https://huggingface.co/inference-endpoints/dedicated) 访问 embedding 模型。两者都会在 Hugging Face 的可扩展无服务器基础设施上暴露开源 embedding 模型。

首先，从[你的 Hugging Face 设置](https://huggingface.co/settings/tokens)中获取 token：

```python
import os
from getpass import getpass

os.environ["HUGGINGFACEHUB_API_TOKEN"] = getpass()
```

然后使用 `HuggingFaceEndpointEmbeddings`：

```python
from langchain_huggingface import HuggingFaceEndpointEmbeddings

embeddings = HuggingFaceEndpointEmbeddings(
    model="sentence-transformers/all-mpnet-base-v2"
)

query_result = embeddings.embed_query("This is a test document.")
```

如果要通过特定的 Inference Provider（例如 `hf-inference`、`sambanova`、`together`）路由，请传入 `provider=`：

```python
embeddings = HuggingFaceEndpointEmbeddings(
    model="BAAI/bge-m3",
    provider="hf-inference",
)
```

完整的 provider 列表及其支持的模型见 [Inference Providers 文档](https://huggingface.co/docs/inference-providers)。

## 使用 Text Embeddings Inference 自托管

如果你想在自己的基础设施上以生产规模提供 Sentence Transformers 模型，请使用 [Text Embeddings Inference (TEI)](https://github.com/huggingface/text-embeddings-inference)。TEI 负责处理 batching、GPU 加速，并暴露 OpenAI-compatible API。完整流程请参阅 [TEI 集成指南](/oss/integrations/embeddings/text_embeddings_inference)。
