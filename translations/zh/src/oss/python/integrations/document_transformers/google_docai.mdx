Document AI 是 Google Cloud 提供的文档理解平台，可将文档中的非结构化数据转换为结构化数据，从而更易于理解、分析和使用。

了解更多：

- [Document AI overview](https://cloud.google.com/document-ai/docs/overview)
- [Document AI videos and labs](https://cloud.google.com/document-ai/docs/videos)
- [Try it!](https://cloud.google.com/document-ai/docs/drag-and-drop)

该模块包含一个基于 Google Cloud DocAI 的 `PDF` 解析器。

要使用这个解析器，你需要安装两个库：

```python
pip install -qU  langchain-google-community[docai]
```

首先，你需要设置一个 Google Cloud Storage (GCS) bucket，并按这里的说明创建自己的 Optical Character Recognition (OCR) processor：[cloud.google.com/document-ai/docs/create-processor](https://cloud.google.com/document-ai/docs/create-processor)

`GCS_OUTPUT_PATH` 应当是 GCS 上某个文件夹的路径（以 `gs://` 开头），`PROCESSOR_NAME` 应类似于 `projects/PROJECT_NUMBER/locations/LOCATION/processors/PROCESSOR_ID` 或 `projects/PROJECT_NUMBER/locations/LOCATION/processors/PROCESSOR_ID/processorVersions/PROCESSOR_VERSION_ID`。你可以通过编程方式获取，也可以从 Google Cloud Console 中 `Processor details` 标签页的 `Prediction endpoint` 部分复制。

```python
GCS_OUTPUT_PATH = "gs://BUCKET_NAME/FOLDER_PATH"
PROCESSOR_NAME = "projects/PROJECT_NUMBER/locations/LOCATION/processors/PROCESSOR_ID"
```

```python
from langchain_core.document_loaders.blob_loaders import Blob
from langchain_google_community import DocAIParser
```

现在，创建一个 `DocAIParser`。

```python
parser = DocAIParser(
    location="us", processor_name=PROCESSOR_NAME, gcs_output_path=GCS_OUTPUT_PATH
)
```

在这个示例中，你可以使用上传到公开 GCS bucket 中的 Alphabet 财报。

[2022Q1_alphabet_earnings_release.pdf](https://storage.googleapis.com/cloud-samples-data/gen-app-builder/search/alphabet-investor-pdfs/2022Q1_alphabet_earnings_release.pdf)

将文档传给 `lazy_parse()` 方法：

```python
blob = Blob(
    path="gs://cloud-samples-data/gen-app-builder/search/alphabet-investor-pdfs/2022Q1_alphabet_earnings_release.pdf"
)
```

我们会得到每页一个文档，总共 11 个：

```python
docs = list(parser.lazy_parse(blob))
print(len(docs))
```

```text
11
```

你也可以对 blob 执行端到端逐个解析。如果你有很多文档，更好的方式可能是把它们批量提交，甚至将解析过程与解析结果的处理过程分离。

```python
operations = parser.docai_parse([blob])
print([op.operation.name for op in operations])
```

```python
['projects/543079149601/locations/us/operations/16447136779727347991']
```

你可以检查这些操作是否已经完成：

```python
parser.is_running(operations)
```

```text
True
```

完成后，你可以解析结果：

```python
parser.is_running(operations)
```

```text
False
```

```python
results = parser.get_results(operations)
print(results[0])
```

```text
DocAIParsingResults(source_path='gs://vertex-pgt/examples/goog-exhibit-99-1-q1-2023-19.pdf', parsed_path='gs://vertex-pgt/test/run1/16447136779727347991/0')
```

现在就可以从解析结果中生成 Documents：

```python
docs = list(parser.parse_from_results(results))
```

```python
print(len(docs))
```

```text
11
```
