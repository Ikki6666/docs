>[Perplexity Search](https://docs.perplexity.ai/docs/search/quickstart) 是一个 web search API，会返回按排名排序并带来源归因的结果，专门为 LLM 和 agent 使用而设计。[Search API endpoint](https://docs.perplexity.ai/api-reference/search-post) 会返回驱动 Perplexity answer engine 的底层网页结果。

我们可以把它作为一个 [retriever](/oss/langchain/retrieval) 使用。下面会展示这个集成特有的功能。看完之后，你也可以继续查看[相关 use-case 页面](/oss/deepagents/rag)，了解如何把它作为更大 chain 的一部分来使用。

## 设置

### 安装

这个集成位于 `langchain-perplexity` 包中：

```python
pip install -qU langchain-perplexity
```

### 凭据

你需要一个 Perplexity API key 才能使用这个集成。可以在 [Perplexity API key dashboard](https://www.perplexity.ai/account/api/keys) 创建，然后把它设置为 `PPLX_API_KEY` 环境变量（这个集成也接受 `PERPLEXITY_API_KEY`）。

```python
import getpass
import os

if not os.environ.get("PPLX_API_KEY"):
    os.environ["PPLX_API_KEY"] = getpass.getpass("Perplexity API key:\n")
```

如果你想从单独的查询中获得自动 tracing，也可以取消下面的注释，设置 [LangSmith](/langsmith/observability) API key：

```python
# os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
# os.environ["LANGSMITH_TRACING"] = "true"
```

## 实例化

`PerplexitySearchRetriever` 支持以下构造参数：

- `k`：最大结果数（1–20）。默认值为 `10`。
- `max_tokens`：所有结果总共允许的最大 token 数。
- `max_tokens_per_page`：每个结果页面允许返回的最大 token 数。
- `country`：用于偏置结果的 ISO 国家代码，例如 `"US"`。
- `search_domain_filter`：要包含或排除的域名列表（最多 20 个）。在域名前加 `-` 表示排除它。参见 [domain filter docs](https://docs.perplexity.ai/docs/search/filters/domain-filter)。
- `search_recency_filter`：可选值为 `"day"`、`"week"`、`"month"`、`"year"`。参见 [date and time filter docs](https://docs.perplexity.ai/docs/search/filters/date-time-filters)。
- `search_after_date` / `search_before_date`：`MM/DD/YYYY` 格式的日期字符串。

```python
from langchain_perplexity import PerplexitySearchRetriever

retriever = PerplexitySearchRetriever(k=3)
```

## 使用

```python
query = "what year was breath of the wild released?"

retriever.invoke(query)
```

每个返回的 @[`Document`] 会把结果 `snippet` 放在 `page_content` 中，并在 `metadata` 中包含 `title`、`url`、`date` 和 `last_updated`。

### 带过滤条件的使用

你可以使用与 Perplexity Search API 相同的过滤条件来约束搜索：

```python
from langchain_perplexity import PerplexitySearchRetriever

retriever = PerplexitySearchRetriever(
    k=5,
    country="US",
    search_recency_filter="week",
    search_domain_filter=["nytimes.com", "reuters.com", "-pinterest.com"],
)

retriever.invoke("US Federal Reserve interest rate decisions")
```

```python
from langchain_perplexity import PerplexitySearchRetriever

# 将结果限制在特定日期范围内
retriever = PerplexitySearchRetriever(
    k=5,
    search_after_date="01/01/2025",
    search_before_date="06/30/2025",
)

retriever.invoke("US Federal Reserve interest rate decisions")
```

## 在 chain 中使用

我们可以很方便地把这个 retriever 组合进一个 chain，构建简单的 RAG pipeline。

```python
from langchain_core.output_parsers import StrOutputParser
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.runnables import RunnablePassthrough
from langchain_openai import ChatOpenAI

prompt = ChatPromptTemplate.from_template(
    """Answer the question based only on the context provided.

Context: {context}

Question: {question}"""
)

llm = ChatOpenAI(model="gpt-5.5")


def format_docs(docs):
    return "\n\n".join(doc.page_content for doc in docs)


chain = (
    {"context": retriever | format_docs, "question": RunnablePassthrough()}
    | prompt
    | llm
    | StrOutputParser()
)

chain.invoke("What were the major outcomes of the most recent Federal Reserve meeting?")
```
