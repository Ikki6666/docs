[Retriever](/oss/langchain/retrieval#building-blocks) 是一种接口，它会根据非结构化查询返回文档。
它比 vector store 更通用。
Retriever 不需要具备存储文档的能力，只需要能够返回（或检索）文档。
Retriever 可以从 vector store 创建，但也足够宽泛，可以覆盖其他来源。

Retriever 接收字符串查询作为输入，并返回一个由 @[`Document`] 对象组成的列表作为输出。

请注意，所有 [vector store](/oss/integrations/vectorstores) 都可以转换为 retriever。可用的 vector store 请参阅对应的[integration docs](/oss/integrations/vectorstores/)。本页列出的是通过继承 BaseRetriever 实现的自定义 retriever。

## 外部索引

下面这些 retriever 会搜索外部索引，例如基于互联网数据构建的索引。

| Retriever | Source | Package |
|-----------|---------|---------|
| [`ParallelSearchRetriever`](/oss/integrations/retrievers/parallel) | 通过 [Parallel Search API](https://docs.parallel.ai/search/search-quickstart) 进行互联网搜索 | [`langchain-parallel`](https://reference.langchain.com/python/langchain-parallel/retrievers/ParallelSearchRetriever) |
| [`PerplexitySearchRetriever`](/oss/integrations/retrievers/perplexity_search) | 通过 [Perplexity Search API](https://docs.perplexity.ai/docs/search/quickstart) 进行互联网搜索 | [`langchain-perplexity`](https://reference.langchain.com/python/langchain-perplexity/retrievers/PerplexitySearchRetriever) |
| [`YouRetriever`](https://you.com/docs/integrations/langchain) | 互联网搜索 | [`langchain-youdotcom`](https://pypi.org/project/langchain-youdotcom/) |
