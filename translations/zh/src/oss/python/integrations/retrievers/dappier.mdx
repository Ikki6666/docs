[Dappier](https://dappier.com) 可将任何 LLM 或你的 Agentic AI 连接到来自可信来源的实时、已清权、专有数据，让你的 AI 在任何主题上都更专业。其专用模型包括 Real-Time Web Search、News、Sports、Financial Stock Market Data、Crypto Data，以及来自高级出版商的独家内容。你可以在 [marketplace.dappier.com](https://marketplace.dappier.com) 的 marketplace 中探索各种数据模型。

[Dappier](https://dappier.com) 提供经过增强、可直接用于 prompt、并且在上下文上相关的数据字符串，已针对与 LangChain 的无缝集成进行优化。无论你是在构建 conversational AI、推荐引擎，还是智能搜索，Dappier 的 LLM-agnostic RAG models 都能让你的 AI 访问经过验证的最新数据，而无需自行构建和管理检索管道。

# DappierRetriever

本文将帮助你开始使用 Dappier [retriever](https://python.langchain.com/docs/concepts/retrievers/)。有关 `DappierRetriever` 所有功能和配置的详细文档，请参阅 [API reference](https://python.langchain.com/en/latest/retrievers/langchain_dappier.retrievers.Dappier.DappierRetriever.html)。

### 设置

安装 `langchain-dappier` 并设置环境变量 `DAPPIER_API_KEY`。

```bash
pip install -U langchain-dappier
export DAPPIER_API_KEY="your-api-key"
```

我们还需要设置 Dappier API 凭证，它可以在 [Dappier site](https://platform.dappier.com/profile/api-keys) 生成。

你可以在 [Dappier marketplace](https://platform.dappier.com/marketplace) 查看受支持的数据模型。

如果你想从单个查询中获得自动 tracing，也可以取消下面的注释来设置你的 [LangSmith](/langsmith/observability) API key：

```python
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

### 安装

这个 retriever 位于 `langchain-dappier` 包中：

```python
pip install -qU langchain-dappier
```

## 实例化

- data_model_id: str
    以 `dm_` 开头的数据模型 ID。
    可用的数据模型 ID 可在
    [Dappier marketplace](https://platform.dappier.com/marketplace) 查找。
- k: int
    要返回的文档数量。
- ref: Optional[str]
    显示 AI 推荐内容的站点域名。
- num_articles_ref: int
    指定 ref 域名下的最小文章数量。
    其余结果将来自 RAG model 中的其他站点。
- search_algorithm: Literal[
    "most_recent",
    "most_recent_semantic",
    "semantic",
    "trending"
]
    用于检索文章的搜索算法。
- api_key: Optional[str]
    用于与 Dappier APIs 交互的 API key。

```python
from langchain_dappier import DappierRetriever

retriever = DappierRetriever(data_model_id="dm_01jagy9nqaeer9hxx8z1sk1jx6")
```

## 用法

```python
query = "latest tech news"

retriever.invoke(query)
```
