---
title: "AgentMail"
description: "在 AgentMail inbox 上进行关键词检索。"
---

`AgentMailRetriever` 会在 [AgentMail](https://agentmail.to) inbox 中执行关键词搜索。它会通过 `AgentMailLoader` 加载最近的消息，在进程内使用大小写不敏感的子字符串匹配进行打分（subject 命中权重为 2 倍），并返回得分最高的 `k` 个 LangChain `Document`。如果需要语义搜索，建议把 `AgentMailLoader` 和你自己的 vector store 配合使用。

## 概览

| Class | Package |
|:------|:--------|
| `AgentMailRetriever` | [`langchain-agentmail`](https://pypi.org/project/langchain-agentmail/) |

## 设置

安装包：

```bash
pip install -qU langchain-agentmail
```

设置你的 AgentMail API key（可在 [agentmail.to](https://agentmail.to) 获取）：

```python
import getpass
import os

if not os.environ.get("AGENTMAIL_API_KEY"):
    os.environ["AGENTMAIL_API_KEY"] = getpass.getpass("AgentMail API key:\n")
```

## 实例化

```python
from langchain_agentmail import AgentMailRetriever

retriever = AgentMailRetriever(
    inbox_id="ib_abc123",
    k=5,              # 返回的文档数量
    labels=["inbox"], # 可选：按标签过滤消息
    scan_limit=50,    # 排序前扫描的消息数量
)
```

## 使用

```python
docs = retriever.invoke("invoice from acme")
for doc in docs:
    print(doc.metadata["subject"], "—", doc.metadata.get("from"))
```

这个 retriever 返回的 `Document` 结构与 `AgentMailLoader` 相同：`page_content` 里是完整的纯文本正文，另外还带有 inbox、message、thread 和 sender metadata。

## 何时改用 loader

`AgentMailRetriever` 适合“直接给我匹配 X 的最近消息”这种场景，不需要 embeddings，也不需要 vector store。如果你需要语义检索、按相关性排序，或者在数百万条消息里做过滤，请使用 `AgentMailLoader` 把消息物化成 `Document`，再交给真正的 vector store。相关流程请查看 [document loader 页面](/oss/integrations/document_loaders/agentmail)。
