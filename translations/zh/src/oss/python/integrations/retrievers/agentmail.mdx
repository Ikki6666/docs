---
title: "AgentMail"
description: "在 AgentMail 收件箱上执行关键词检索的 retriever。"
---

`AgentMailRetriever` 会在 [AgentMail](https://agentmail.to) 收件箱上执行关键词搜索。它通过 `AgentMailLoader` 加载最近的消息，在进程内用不区分大小写的子串匹配进行打分（主题命中权重为 2 倍），并将前 `k` 条结果作为 LangChain `Document` 返回。如果你需要语义搜索，请将 `AgentMailLoader` 与你自己的向量存储搭配使用。

## 概览

| Class | Package |
|:------|:--------|
| `AgentMailRetriever` | [`langchain-agentmail`](https://pypi.org/project/langchain-agentmail/) |

## 设置

安装包：

```bash
pip install -qU langchain-agentmail
```

设置你的 AgentMail API key，可在 [agentmail.to](https://agentmail.to) 获取：

```python
import getpass
import os

if not os.environ.get("AGENTMAIL_API_KEY"):
    os.environ["AGENTMAIL_API_KEY"] = getpass.getpass("AgentMail API key:\n")
```

## 实例化

```python
from langchain_agentmail import AgentMailRetriever

retriever = AgentMailRetriever(
    inbox_id="ib_abc123",
    k=5,              # number of documents to return
    labels=["inbox"], # optional — filter messages by label
    scan_limit=50,    # number of messages to scan before ranking
)
```

## 用法

```python
docs = retriever.invoke("invoice from acme")
for doc in docs:
    print(doc.metadata["subject"], "—", doc.metadata.get("from"))
```

retriever 返回的 `Document` 结构与 `AgentMailLoader` 相同，包括 `page_content` 中的完整纯文本正文，以及 inbox/message/thread/sender metadata。

## 何时改用 loader

`AgentMailRetriever` 是一种“直接给我最近匹配 X 的消息”的简便方式，不需要 embeddings，也不需要向量存储。如果你需要语义检索、按相关性排序，或者跨数百万条消息进行过滤，请使用 `AgentMailLoader` 物化 `Document`，再将它们送入真正的向量存储。该流程请参阅[文档加载器页面](/oss/integrations/document_loaders/agentmail)。
