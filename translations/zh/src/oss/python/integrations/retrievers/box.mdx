这会帮助你开始使用 Box [retriever](/oss/langchain/retrieval)。

# 概览

`BoxRetriever` 类可以帮助你把 Box 中的非结构化内容以 LangChain 的 @[`Document`] 格式取出来。你既可以基于全文搜索来查找文件，也可以使用 Box AI 针对文件执行 AI 查询，并返回包含结果的 @[`Document`]。这要求你提供一个包含 Box file id 的 `List[str]`，例如 `["12345","67890"]`。

<Info>
Box AI 需要 Enterprise Plus 许可证。
</Info>

没有文本表示的文件会被跳过。

### 集成详情

1: 自带数据源（也就是索引并搜索自定义文档语料）：

| Retriever | Self-host | Cloud offering | Package |
| :--- | :--- | :---: | :---: |
`BoxRetriever` | ❌ | ✅ | `langchain-box` |

## 设置

要使用 Box 包，你需要准备以下内容：

* 一个 Box 账户。如果你不是当前的 Box 客户，或者想在生产 Box 实例之外测试，可以使用 [free developer account](https://account.box.com/signup/n/developer#ty9l3)。
* [一个 Box app](https://developer.box.com/guides/getting-started/first-application/)。它需要在 [developer console](https://account.box.com/developers/console) 中配置；如果要使用 Box AI，还必须启用 `Manage AI` scope。在这里你也会选择认证方式。
* 这个 app 必须由[管理员启用](https://developer.box.com/guides/authorization/custom-app-approval/#manual-approval)。对于免费开发者账户，这个管理员就是注册该账户的人。

### 凭据

在这些示例中，我们会使用 [token authentication](https://developer.box.com/guides/authentication/tokens/developer-tokens)。这种方式可以配合任何[认证方式](https://developer.box.com/guides/authentication/)使用。你只需要用自己选择的方法拿到 token 即可。如果你想了解如何在 `langchain-box` 中使用其他认证类型，可以查看 [Box provider](/oss/integrations/providers/box) 文档。

```python
import getpass
import os

box_developer_token = getpass.getpass("Enter your Box Developer Token: ")
```

如果你想从单独的查询中获得自动 tracing，也可以取消下面的注释，设置 [LangSmith](/langsmith/observability) API key：

```python
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

### 安装

这个 retriever 位于 `langchain-box` 包中：

```python
pip install -qU langchain-box
```

## 实例化

现在我们可以实例化 retriever 了：

## 搜索

```python
from langchain_box import BoxRetriever

retriever = BoxRetriever(box_developer_token=box_developer_token)
```

如果你想做更细粒度的搜索，我们提供了一组配置项来帮助你缩小结果范围。它会结合 `langchain_box.utilities.SearchOptions`、`langchain_box.utilities.SearchTypeFilter` 和 `langchain_box.utilities.DocumentFiles` 这些枚举，来过滤诸如创建日期、要搜索文件的哪一部分，甚至将搜索范围限制到某个特定文件夹。

更多信息请查看 [API reference](https://python.langchain.com/v0.2/api_reference/box/utilities/langchain_box.utilities.box.SearchOptions.html)。

```python
from langchain_box.utilities import BoxSearchOptions, DocumentFiles, SearchTypeFilter

box_folder_id = "260931903795"

box_search_options = BoxSearchOptions(
    ancestor_folder_ids=[box_folder_id],
    search_type_filter=[SearchTypeFilter.FILE_CONTENT],
    created_date_range=["2023-01-01T00:00:00-07:00", "2024-08-01T00:00:00-07:00,"],
    k=200,
    size_range=[1, 1000000],
    updated_data_range=None,
)

retriever = BoxRetriever(
    box_developer_token=box_developer_token, box_search_options=box_search_options
)

retriever.invoke("AstroTech Solutions")
```

## Box AI

```python
from langchain_box import BoxRetriever

box_file_ids = ["1514555423624", "1514553902288"]

retriever = BoxRetriever(
    box_developer_token=box_developer_token, box_file_ids=box_file_ids
)
```

## 使用

```python
query = "What was the most expensive item purchased"

retriever.invoke(query)
```

```text
[Document(metadata={'source': 'Box AI', 'title': 'Box AI What was the most expensive item purchased'}, page_content='The most expensive item purchased is the **Gravitational Wave Detector Kit** from AstroTech Solutions, which costs **$800**.')]
```

## 引用

结合 Box AI 和 `BoxRetriever`，你既可以返回 prompt 的答案，也可以返回 Box 用于生成答案的 citations，或者两者都返回。不管你如何使用 Box AI，retriever 返回的都是 `List[Document]` 对象。我们通过两个 `bool` 参数 `answer` 和 `citations` 来提供这种灵活性。`answer` 默认是 `True`，`citations` 默认是 `False`，所以如果你只想要答案，可以两个都省略。如果你想两者都要，可以只设置 `citations=True`；如果你只想要 citations，则需要设置 `answer=False` 和 `citations=True`。

### 两者都返回

```python
retriever = BoxRetriever(
    box_developer_token=box_developer_token, box_file_ids=box_file_ids, citations=True
)

retriever.invoke(query)
```

```text
[Document(metadata={'source': 'Box AI', 'title': 'Box AI What was the most expensive item purchased'}, page_content='The most expensive item purchased is the **Gravitational Wave Detector Kit** from AstroTech Solutions, which costs **$800**.'),
 Document(metadata={'source': 'Box AI What was the most expensive item purchased', 'file_name': 'Invoice-A5555.txt', 'file_id': '1514555423624', 'file_type': 'file'}, page_content='Vendor: AstroTech Solutions\nInvoice Number: A5555\n\nLine Items:\n    - Gravitational Wave Detector Kit: $800\n    - Exoplanet Terrarium: $120\nTotal: $920')]
```

### 仅返回 citations

```python
retriever = BoxRetriever(
    box_developer_token=box_developer_token,
    box_file_ids=box_file_ids,
    answer=False,
    citations=True,
)

retriever.invoke(query)
```

```text
[Document(metadata={'source': 'Box AI What was the most expensive item purchased', 'file_name': 'Invoice-A5555.txt', 'file_id': '1514555423624', 'file_type': 'file'}, page_content='Vendor: AstroTech Solutions\nInvoice Number: A5555\n\nLine Items:\n    - Gravitational Wave Detector Kit: $800\n    - Exoplanet Terrarium: $120\nTotal: $920')]
```

## 作为 agent tool 使用

像其他 retriever 一样，BoxRetriever 也可以作为 tool 加入 LangGraph agent。

```python
pip install -U langsmith
```

```python
from langchain_classic import hub
from langchain.agents import AgentExecutor, create_openai_tools_agent
from langchain.tools.retriever import create_retriever_tool
```

```python
box_search_options = BoxSearchOptions(
    ancestor_folder_ids=[box_folder_id],
    search_type_filter=[SearchTypeFilter.FILE_CONTENT],
    created_date_range=["2023-01-01T00:00:00-07:00", "2024-08-01T00:00:00-07:00,"],
    k=200,
    size_range=[1, 1000000],
    updated_data_range=None,
)

retriever = BoxRetriever(
    box_developer_token=box_developer_token, box_search_options=box_search_options
)

box_search_tool = create_retriever_tool(
    retriever,
    "box_search_tool",
    "This tool is used to search Box and retrieve documents that match the search criteria",
)
tools = [box_search_tool]
```

```python
prompt = hub.pull("hwchase17/openai-tools-agent")
prompt.messages

llm = ChatOpenAI(temperature=0, openai_api_key=openai_key)

agent = create_openai_tools_agent(llm, tools, prompt)
agent_executor = AgentExecutor(agent=agent, tools=tools)
```

## 额外字段

所有 Box connector 都支持从 Box `FileFull` 对象中选取额外字段，并以自定义 LangChain metadata 的形式返回。每个对象都接受一个可选的 `List[str]` 参数 `extra_fields`，其内容是返回对象中的 json key，例如 `extra_fields=["shared_link"]`。

connector 会先把这个字段加入集成正常运行所需的字段列表，然后把结果一起加入到返回的 @[`Document`] 或 `Blob` 的 metadata 中，比如 `"metadata" : { "source" : "source, "shared_link" : "shared_link" }`。如果某个文件没有这个字段，则会返回空字符串，例如 `"shared_link" : ""`。
