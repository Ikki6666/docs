Galaxia 是一个 GraphRAG 方案，可以自动化完成文档处理、知识库（Graph Language Model）构建和检索：
[galaxia-rag](https://smabbler.gitbook.io/smabbler/api-rag/smabblers-api-rag)

要使用 Galaxia，首先需要在这里上传文本并创建 Graph Language Model：[smabbler-cloud](https://beta.cloud.smabbler.com)

模型构建并激活后，你就可以使用这个集成来检索所需内容。

模块仓库位于这里：[github](https://github.com/rrozanski-smabbler/galaxia-langchain)

### 集成详情

| Retriever | Self-host | Cloud offering | Package |
| :--- | :--- | :---: | :---: |
[Galaxia Retriever](https://github.com/rrozanski-smabbler/galaxia-langchain) | ❌ | ✅ | __langchain-galaxia-retriever__ |

## 设置

在开始检索之前，你需要先在这里创建 Graph Language Model：[smabbler-cloud](https://beta.cloud.smabbler.com)

并按照这 3 个简单步骤操作：[rag-instruction](https://smabbler.gitbook.io/smabbler/api-rag/build-rag-model-in-3-steps)

模型构建完之后，别忘了先激活它。

### 安装

这个 retriever 实现在如下包中：[pypi](https://pypi.org/project/langchain-galaxia-retriever/)

```python
pip install -qU langchain-galaxia-retriever
```

## 实例化

```python
from langchain_galaxia_retriever.retriever import GalaxiaRetriever

gr = GalaxiaRetriever(
    api_url="beta.api.smabbler.com",
    api_key="<key>",  # 可以在这里找到：https://beta.cloud.smabbler.com/user/account
    knowledge_base_id="<knowledge_base_id>",  # 可以在 https://beta.cloud.smabbler.com 的模型表中找到
    n_retries=10,
    wait_time=5,
)
```

## 使用

```python
result = gr.invoke("<test question>")
print(result)
```

## 在 chain 中使用

```python
# | output: false
# | echo: false

from langchain_openai import ChatOpenAI

llm = ChatOpenAI(model="gpt-3.5-turbo-0125", temperature=0)
```

```python
from langchain_core.output_parsers import StrOutputParser
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.runnables import RunnablePassthrough

prompt = ChatPromptTemplate.from_template(
    """Answer the question based only on the context provided.

Context: {context}

Question: {question}"""
)


def format_docs(docs):
    return "\n\n".join(doc.page_content for doc in docs)


chain = (
    {"context": gr | format_docs, "question": RunnablePassthrough()}
    | prompt
    | llm
    | StrOutputParser()
)
```

```python
chain.invoke("<test question>")
```
