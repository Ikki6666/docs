# CogneeRetriever

这会帮助你开始使用 Cognee [retriever](/oss/langchain/retrieval)。

### 集成详情

支持自带数据源（也就是索引并搜索自定义文档语料）：

| Retriever | Self-host | Cloud offering | Package |
| :--- | :--- | :---: | :---: |
`CogneeRetriever` | ✅ | ❌ | `langchain-cognee` |

## 设置

使用 cognee 默认设置时，你只需要 OpenAI API key。

如果你想从单独的查询中获得自动 tracing，也可以通过取消下面的注释来设置 [LangSmith](/langsmith/observability) API key：

```python
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

### 安装

这个 retriever 位于 `langchain-cognee` 包中：

```python
pip install -qU langchain-cognee
```

## 实例化

现在我们可以实例化 retriever 了：

```python
from langchain_cognee import CogneeRetriever

retriever = CogneeRetriever(
    llm_api_key="sk-",  # OpenAI API Key
    dataset_name="my_dataset",
    k=3,
)
```

## 使用

添加一些文档，处理它们，然后运行查询。Cognee 会为你的查询检索相关知识并生成最终答案。

```python
# 添加并处理文档的示例
from langchain_core.documents import Document

docs = [
    Document(page_content="Elon Musk is the CEO of SpaceX."),
    Document(page_content="SpaceX focuses on rockets and space travel."),
]

retriever.add_documents(docs)
retriever.process_data()

# 现在查询 retriever
query = "Tell me about Elon Musk"
results = retriever.invoke(query)

for idx, doc in enumerate(results, start=1):
    print(f"Doc {idx}: {doc.page_content}")
```
