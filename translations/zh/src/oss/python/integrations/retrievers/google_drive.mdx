这份 notebook 介绍如何从 `Google Drive` 检索文档。

## 前置条件

1. 创建一个 Google Cloud project，或者使用已有 project
1. 启用 [Google Drive API](https://console.cloud.google.com/flows/enableapi?apiid=drive.googleapis.com)
1. [为桌面应用授权凭据](https://developers.google.com/drive/api/quickstart/python#authorize_credentials_for_a_desktop_application)
1. `pip install -U google-api-python-client google-auth-httplib2 google-auth-oauthlib`

## 检索 Google docs

默认情况下，`GoogleDriveRetriever` 期望 `credentials.json` 文件位于 `~/.credentials/credentials.json`，但你也可以通过 `GOOGLE_ACCOUNT_FILE` 环境变量来修改。`token.json` 的位置会使用同一个目录（也可以用 `token_path` 参数指定）。注意，第一次使用 retriever 时会自动创建 `token.json`。

`GoogleDriveRetriever` 可以通过若干请求检索一组文件。

默认情况下，如果你使用 `folder_id`，这个文件夹里的所有文件都可以被检索成 `Document`。

你可以从 URL 中获取 folder 和 document 的 id：

* Folder: [drive.google.com/drive/u/0/folders/1yucgL9WGgWZdM1TOuKkeghlPizuzMYb5](https://drive.google.com/drive/u/0/folders/1yucgL9WGgWZdM1TOuKkeghlPizuzMYb5) -> folder id 是 `"1yucgL9WGgWZdM1TOuKkeghlPizuzMYb5"`
* Document: [docs.google.com/document/d/1bfaMQ18_i56204VaQDVeAFpqEijJTgvurupdEDiaUQw/edit](https://docs.google.com/document/d/1bfaMQ18_i56204VaQDVeAFpqEijJTgvurupdEDiaUQw/edit) -> document id 是 `"1bfaMQ18_i56204VaQDVeAFpqEijJTgvurupdEDiaUQw"`

特殊值 `root` 表示你的个人根目录。

```python
from langchain_googledrive.retrievers import GoogleDriveRetriever

folder_id = "root"
# folder_id='1yucgL9WGgWZdM1TOuKkeghlPizuzMYb5'

retriever = GoogleDriveRetriever(
    num_results=2,
)
```

默认情况下，所有以下 MIME type 的文件都可以被转换成 `Document`。

* `text/text`
* `text/plain`
* `text/html`
* `text/csv`
* `text/markdown`
* `image/png`
* `image/jpeg`
* `application/epub+zip`
* `application/pdf`
* `application/rtf`
* `application/vnd.google-apps.document` (GDoc)
* `application/vnd.google-apps.presentation` (GSlide)
* `application/vnd.google-apps.spreadsheet` (GSheet)
* `application/vnd.google.colaboratory` (Notebook colab)
* `application/vnd.openxmlformats-officedocument.presentationml.presentation` (PPTX)
* `application/vnd.openxmlformats-officedocument.wordprocessingml.document` (DOCX)

这些类型是可以更新或自定义的。请查看 `GoogleDriveRetriever` 的文档。

你可以自定义选择文件的条件。这里提供了一组预定义 filter：

| Template                                 | Description                                                           |
| --------------------------------------   | --------------------------------------------------------------------- |
| `gdrive-all-in-folder`                   | 从 `folder_id` 返回全部兼容文件                        |
| `gdrive-query`                           | 在所有 drives 中搜索 `query`                                          |
| `gdrive-by-name`                         | 搜索名称为 `query` 的文件                                         |
| `gdrive-query-in-folder`                 | 在 `folder_id` 中搜索 `query`（如果 `_recursive=true`，会包含子文件夹）  |
| `gdrive-mime-type`                       | 搜索特定 `mime_type`                                         |
| `gdrive-mime-type-in-folder`             | 在 `folder_id` 中搜索特定 `mime_type`                          |
| `gdrive-query-with-mime-type`            | 使用指定 `mime_type` 搜索 `query`                            |
| `gdrive-query-with-mime-type-and-folder` | 使用指定 `mime_type` 并在 `folder_id` 中搜索 `query`         |

```python
retriever = GoogleDriveRetriever(
    template="gdrive-query",  # 全局搜索
    num_results=2,  # 但只取 2 个文档
)
for doc in retriever.invoke("machine learning"):
    print("---")
    print(doc.page_content.strip()[:60] + "...")
```

你也可以使用自定义 `PromptTemplate` 来定制这个 query。

```python
from langchain_core.prompts import PromptTemplate

retriever = GoogleDriveRetriever(
    template=PromptTemplate(
        input_variables=["query"],
        # See https://developers.google.com/drive/api/guides/search-files
        template="(fullText contains '{query}') "
        "and mimeType='application/vnd.google-apps.document' "
        "and modifiedTime > '2000-01-01T00:00:00' "
        "and trashed=false",
    ),
    num_results=2,
    # See https://developers.google.com/drive/api/v3/reference/files/list
    includeItemsFromAllDrives=False,
    supportsAllDrives=False,
)
for doc in retriever.invoke("machine learning"):
    print(f"{doc.metadata['name']}:")
    print("---")
    print(doc.page_content.strip()[:60] + "...")
```

## 使用 Google drive 的 `description` metadata

每个 Google Drive 文件在 metadata 中都有一个 `description` 字段（可在 *details of a file* 中查看）。
使用 `snippets` 模式可以返回所选文件的 description。

```python
retriever = GoogleDriveRetriever(
    template="gdrive-mime-type-in-folder",
    folder_id=folder_id,
    mime_type="application/vnd.google-apps.document",  # 仅 Google Docs
    num_results=2,
    mode="snippets",
    includeItemsFromAllDrives=False,
    supportsAllDrives=False,
)
retriever.invoke("machine learning")
```
