# 概览

`EgnyteRetriever` 类可以帮助你通过混合搜索能力，从 Egnyte 中搜索并检索文档。它把语义搜索和关键词搜索结合起来。这个 retriever 完全符合 LangChain 标准，并且支持同步和异步操作。

### 集成详情

自带数据源（也就是索引并搜索自定义文档语料）：

| Retriever | Self-host | Cloud offering | Package |
| :--- | :--- | :---: | :---: |
[EgnyteRetriever](https://github.com/egnyte/egnyte-langchain-connector) | ❌ | ✅ | egnyte-langchain-connector |

## 设置

要使用 Egnyte 包，你需要以下内容：

* 一个 Egnyte 账户。如果你不是现有 Egnyte 客户，或者想在生产实例之外测试，可以使用 [free developer account](https://developers.egnyte.com/member/register)。
* 一个 Egnyte app。它在 [developer console](https://developers.egnyte.com/) 中配置，并且必须启用正确的 scopes。
* 这个 app 必须由管理员启用。对于免费开发者账户，这个管理员就是注册账户的人。

### 凭据

在这些示例里，我们会使用 Bearer token authentication 和 Egnyte user token。要生成 user token：

1. 在 [https://developers.egnyte.com/member/register](https://developers.egnyte.com/member/register) 注册开发者账户
2. 按照 [Public API Authentication guide](https://developers.egnyte.com/docs/read/Public_API_Authentication) 生成 user token
3. **Important**：生成 token 时使用 `Egnyte.ai` scope

```python
import getpass
import os

egnyte_user_token = getpass.getpass("Enter your Egnyte User Token: ")
domain = input("Enter your Egnyte domain (e.g., company.egnyte.com): ")
```

如果你想从单独的查询中获得自动 tracing，也可以把 [LangSmith](https://docs.smith.langchain.com/) API key 的设置取消注释：

```python
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

### 安装

这个 retriever 位于 `egnyte-langchain-connector` 包中：

```bash
pip install -qU egnyte-langchain-connector
```

## 实例化

现在我们可以实例化 retriever 了：

```python
from langchain_egnyte import EgnyteRetriever

retriever = EgnyteRetriever(domain=domain, k=100)
```

## 使用

### 基础搜索

```python
query = "machine learning policies"

documents = retriever.invoke(query, egnyte_user_token=egnyte_user_token)

for doc in documents:
    print(f"Title: {doc.metadata.get('title', 'N/A')}")
    print(f"Content: {doc.page_content[:200]}...")
    print("---")
```

### 使用选项进行高级搜索

如果你需要更细粒度的搜索，可以使用 `EgnyteSearchOptions` 按文件夹路径、日期范围等条件过滤结果：

```python
from langchain_egnyte import EgnyteRetriever, EgnyteSearchOptions

search_options = EgnyteSearchOptions(
    limit=50,
    folderPath="/policies",
    excludeFolderPaths=["/temp", "/archive"],
    createdAfter=1640995200000,  # Unix timestamp in milliseconds (Jan 1, 2022)
    createdBefore=1672531200000  # Unix timestamp in milliseconds (Jan 1, 2023)
)

retriever = EgnyteRetriever(
    domain=domain,
    k=50,
    search_options=search_options
)

documents = retriever.invoke(
    "compliance requirements",
    egnyte_user_token=egnyte_user_token
)
```

### 异步使用

这个 retriever 支持异步操作：

```python
import asyncio

async def search_async():
    documents = await retriever.ainvoke(
        "data privacy guidelines",
        egnyte_user_token=egnyte_user_token
    )
    return documents

# 运行异步搜索
documents = asyncio.run(search_async())
```

### 批量操作

你可以批量处理多个查询：

```python
queries = [
    "security policies",
    "employee handbook",
    "compliance guidelines"
]

# 同步 batch
results = retriever.batch(
    queries,
    config={"configurable": {"egnyte_user_token": egnyte_user_token}}
)

# 异步 batch
results = await retriever.abatch(
    queries,
    config={"configurable": {"egnyte_user_token": egnyte_user_token}}
)
```

## 作为 agent tool 使用

像其他 retriever 一样，EgnyteRetriever 也可以作为 tool 加入 LangGraph agent。

```python
from langchain import hub
from langchain.agents import AgentExecutor, create_openai_tools_agent
from langchain.tools.retriever import create_retriever_tool
from langchain_openai import ChatOpenAI

retriever = EgnyteRetriever(domain=domain, k=50)

egnyte_search_tool = create_retriever_tool(
    retriever,
    "egnyte_search_tool",
    "This tool searches Egnyte and retrieves documents that match the search criteria using hybrid search"
)

tools = [egnyte_search_tool]

prompt = hub.pull("hwchase17/openai-tools-agent")
llm = ChatOpenAI(temperature=0)

agent = create_openai_tools_agent(llm, tools, prompt)
agent_executor = AgentExecutor(agent=agent, tools=tools)

result = agent_executor.invoke({
    "input": "Find all documents related to data privacy policies"
})

print(result['output'])
```
