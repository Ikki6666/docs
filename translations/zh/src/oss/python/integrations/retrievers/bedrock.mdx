本指南将帮助你开始使用 AWS Knowledge Bases [retriever](/oss/langchain/retrieval/)。

[Knowledge Bases for Amazon Bedrock](https://aws.amazon.com/bedrock/knowledge-bases/) 是 Amazon Web Services (AWS) 提供的一项能力，可通过使用你的私有数据定制 FM 响应，从而快速构建 RAG 应用。

实现 `RAG` 通常需要组织执行若干繁琐步骤，将数据转换为 embeddings（vectors），把 embeddings 存储到专用向量数据库中，并构建到数据库的自定义集成以搜索和检索与用户查询相关的文本。这一过程可能既耗时又低效。

有了 `Knowledge Bases for Amazon Bedrock`，你只需把数据指向 `Amazon S3` 中的位置，`Knowledge Bases for Amazon Bedrock` 就会负责把数据摄取到向量数据库的整个工作流。如果你没有现成的向量数据库，Amazon Bedrock 会为你创建一个 Amazon OpenSearch Serverless vector store。进行检索时，可通过 LangChain - Amazon Bedrock 集成中的 Retrieve API，从 knowledge bases 中为用户查询检索相关结果。

## 设置

Knowledge Bases 可以通过 [AWS Console](https://aws.amazon.com/console/) 或 [AWS SDKs](https://aws.amazon.com/developer/tools/) 进行配置。我们需要 `knowledge_base_id` 来实例化 retriever。

如果你想从单个查询中获得自动 tracing，也可以取消下面的注释来设置你的 [LangSmith](/langsmith/observability) API key：

```python
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

### 安装

这个 retriever 位于 `langchain-aws` 包中：

```python
pip install -qU langchain-aws
```

## 实例化

现在可以实例化 retriever：

```python
from langchain_aws.retrievers import AmazonKnowledgeBasesRetriever

retriever = AmazonKnowledgeBasesRetriever(
    knowledge_base_id="PUIJP4EQUA",
    retrieval_config={"vectorSearchConfiguration": {"numberOfResults": 4}},
)
```

## 用法

```python
query = "What did the president say about Ketanji Brown?"

retriever.invoke(query)
```

## 在 chain 中使用

```python
from botocore.client import Config
from langchain_classic.chains import RetrievalQA
from langchain_aws import Bedrock

model_kwargs_claude = {"temperature": 0, "top_k": 10, "max_tokens_to_sample": 3000}

llm = Bedrock(model_id="anthropic.claude-v2", model_kwargs=model_kwargs_claude)

qa = RetrievalQA.from_chain_type(
    llm=llm, retriever=retriever, return_source_documents=True
)

qa(query)
```
