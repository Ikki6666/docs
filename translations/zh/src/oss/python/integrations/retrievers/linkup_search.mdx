> [Linkup](https://www.linkup.so/) 提供一个 API，可将 LLM 连接到 Web 和 Linkup Premium Partner 数据源。

本文将帮助你开始使用 LinkupSearchRetriever [retriever](/oss/langchain/retrieval/)。

### 集成详情

| Retriever | Source | Package |
| :--- | :--- | :---: |
| `LinkupSearchRetriever` | Web and partner sources | langchain-linkup |

## 设置

要使用 Linkup provider，你需要一个有效的 API key，可以通过[注册 Linkup](https://app.linkup.so/sign-up) 获取。之后可以将它设置为 `LINKUP_API_KEY` 环境变量。对于下面的 chain 示例，你还需要把 OpenAI API key 设置为 `OPENAI_API_KEY` 环境变量，也可以在这里一并设置：

```python
# import os
# os.environ["LINKUP_API_KEY"] = ""  # Fill with your API key
# os.environ["OPENAI_API_KEY"] = ""  # Fill with your API key
```

如果你想从单个查询中获得自动 tracing，也可以取消下面的注释来设置你的 [LangSmith](/langsmith/observability) API key：

```python
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

### 安装

这个 retriever 位于 `langchain-linkup` 包中：

```python
pip install -qU langchain-linkup
```

## 实例化

现在可以实例化 retriever：

```python
from langchain_linkup import LinkupSearchRetriever

retriever = LinkupSearchRetriever(
    depth="deep",  # "standard" or "deep"
    linkup_api_key=None,  # API key can be passed here or set as the LINKUP_API_KEY environment variable
)
```

## 用法

```python
query = "Who won the latest US presidential elections?"

retriever.invoke(query)
```
