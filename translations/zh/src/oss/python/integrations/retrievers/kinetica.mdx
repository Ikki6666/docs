[Kinetica](https://www.kinetica.com/) 是一个内置向量相似度搜索支持的数据库。

它支持：

- 精确和近似最近邻搜索
- L2 距离、内积和余弦距离

这份 notebook 展示如何使用基于 Kinetica 向量存储（`Kinetica`）的 retriever。

我们要使用 `OpenAIEmbeddings`，所以需要先拿到 OpenAI API Key。

```python
import getpass

if "OPENAI_API_KEY" not in os.environ:
    os.environ["OPENAI_API_KEY"] = getpass.getpass("OpenAI API Key:")

```

你必须在以下环境变量中设置数据库连接信息。如果你在使用虚拟环境，也可以把它们写进项目的 `.env` 文件：

* `KINETICA_URL`：数据库连接 URL（例如 `http://localhost:9191`）
* `KINETICA_USER`：数据库用户名
* `KINETICA_PASSWD`：安全密码

## 创建 Vectorstore

```python
from langchain_community.document_loaders import TextLoader
from langchain_text_splitters import CharacterTextSplitter

loader = TextLoader("./state_of_the_union.txt")
documents = loader.load()
text_splitter = CharacterTextSplitter(chunk_size=1000, chunk_overlap=0)
results = text_splitter.split_documents(documents)

# Kinetica 模块会尝试用 collection 的名称创建一张表。
# 所以请确保 collection 名称唯一，并且当前用户有权限创建表。

COLLECTION_NAME = "state_of_the_union_test"

vectorstore = KineticaVectorstore.from_documents(
    embedding=embeddings,
    documents=results,
    collection_name=COLLECTION_NAME,
    config=k_config,
    pre_delete_collection=True,
)
```

## 使用 retriever 搜索


```python
from langchain_core.vectorstores import VectorStoreRetriever

# 从 vector store 创建 retriever
retriever: VectorStoreRetriever = vectorstore.as_retriever(search_kwargs={"k": 2})

results = retriever.invoke("What did the president say about Ketanji Brown Jackson")

print(results[0].page_content)
```
