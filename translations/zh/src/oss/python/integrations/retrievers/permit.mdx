Permit 是一个访问控制平台，支持使用 RBAC、ABAC 和 ReBAC 等多种模型进行细粒度、实时的权限管理。它帮助组织在应用中实施动态策略，确保只有获得授权的用户才能访问特定资源。

### 集成详情

本笔记本演示如何将 [Permit.io](https://permit.io/) 权限集成到 LangChain retriever 中。

我们提供两个自定义 retriever：

- `PermitSelfQueryRetriever`：使用 self-query 方法解析用户的自然语言提示词，从 Permit 获取该用户有权限访问的资源 ID，并在向量存储搜索中自动应用该过滤条件。

- `PermitEnsembleRetriever`：通过 LangChain 的 EnsembleRetriever 组合多个底层 retriever（例如 BM25 + Vector），然后使用 Permit.io 对合并后的结果进行过滤。

## 实例化

### PermitSelfQueryRetriever

#### 基本说明

1. 从 Permit 获取允许访问的文档 ID。

2. 使用 LLM 解析查询并构建“结构化过滤器”，确保只考虑这些被授权 ID 对应的文档。

#### 基本用法

<LangchainCommunityUnmaintained />

```python
from langchain_openai import OpenAIEmbeddings
from langchain_community.vectorstores import FAISS
from langchain_permit.retrievers import PermitSelfQueryRetriever

# Step 1: Create / load some documents and build a vector store
docs = [...]
embeddings = OpenAIEmbeddings()
vectorstore = FAISS.from_documents(docs, embeddings)

# Step 2: Initialize the retriever
retriever = PermitSelfQueryRetriever(
    api_key="...",
    pdp_url="...",
    user={"key": "user-123"},
    resource_type="document",
    action="read",
    llm=...,                # Typically a ChatOpenAI or other LLM
    vectorstore=vectorstore,
    enable_limit=True,      # optional
)

# Step 3: Query
query = "Give me docs about cats"
results = retriever.get_relevant_documents(query)
for doc in results:
    print(doc.metadata.get("id"), doc.page_content)
```

### PermitEnsembleRetriever

#### 基本说明

1. 使用 LangChain 的 EnsembleRetriever 从多个子 retriever（例如基于向量的 retriever、BM25 等）中收集文档。
2. 检索到文档后，调用 Permit 的 `filter_objects`，移除用户无权查看的文档。

#### 基本用法

<LangchainCommunityUnmaintained />

```python
from langchain_community.retrievers import BM25Retriever
from langchain_core.documents import Document
from langchain_permit.retrievers import PermitEnsembleRetriever

# Suppose we have two child retrievers: bm25_retriever, vector_retriever
...
ensemble_retriever = PermitEnsembleRetriever(
    api_key="...",
    pdp_url="...",
    user="user_abc",
    action="read",
    resource_type="document",
    retrievers=[bm25_retriever, vector_retriever],
    weights=None
)

docs = ensemble_retriever.get_relevant_documents("Query about cats")
for doc in docs:
    print(doc.metadata.get("id"), doc.page_content)
```

### 总结

借助这些自定义 retriever，你可以将 Permit.io 的权限检查无缝集成进 LangChain 的检索工作流中。你既能保留应用现有的向量搜索逻辑，又能确保最终返回的始终是已授权文档。

如需了解更多有关 Permit 策略设置的细节，请参阅官方 Permit 文档。如果你还想把它们和其他工具（例如 JWT 校验或更完整的 RAG pipeline）组合使用，可以查看 examples 文件夹中的 `docs/tools.ipynb`。

```python
from langchain_permit import PermitRetriever

retriever = PermitRetriever(
    # ...
)
```

## 在 chain 中使用

与其他 retriever 一样，PermitRetriever 也可以通过 [chains](https://docs.permit.io/) 集成到 LLM 应用中。

我们需要一个 LLM 或 chat model：

<ChatModelTabs customVarName="llm" />

```python
# | output: false
# | echo: false

from langchain_openai import ChatOpenAI

llm = ChatOpenAI(model="gpt-3.5-turbo-0125", temperature=0)
```

```python
from langchain_core.output_parsers import StrOutputParser
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.runnables import RunnablePassthrough

prompt = ChatPromptTemplate.from_template(
    """Answer the question based only on the context provided.

Context: {context}

Question: {question}"""
)


def format_docs(docs):
    return "\n\n".join(doc.page_content for doc in docs)


chain = (
    {"context": retriever | format_docs, "question": RunnablePassthrough()}
    | prompt
    | llm
    | StrOutputParser()
)
```

```python
chain.invoke("...")
```
