本文将帮助你开始使用 Memgraph [toolkit](/oss/integrations/tools/memgraph)。

`MemgraphToolkit` 中的工具是为与 `Memgraph` 数据库交互而设计的。

## 设置

为能够执行下面的步骤，请确保你本地已有一个正在运行的 Memgraph 实例。关于如何运行 Memgraph 的更多细节，请参阅 [Memgraph docs](https://memgraph.com/docs/getting-started)

如果你想为单个工具的运行获取自动 tracing，也可以取消下面的注释来设置你的 [LangSmith](/langsmith/observability) API key：

```python
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

### 安装

这个 toolkit 位于 `langchain-memgraph` 包中：

```python
pip install -qU langchain-memgraph
```

## 实例化

现在可以实例化 toolkit：

```python
from langchain.chat_models import init_chat_model
from langchain_memgraph import MemgraphToolkit
from langchain_memgraph.graphs.memgraph import MemgraphLangChain

db = MemgraphLangChain(url=url, username=username, password=password)

model = init_chat_model("gpt-5.4-mini", model_provider="openai")

toolkit = MemgraphToolkit(
    db=db,  # Memgraph instance
    llm=model,  # LLM chat model for LLM operations
)
```

## 工具

查看可用工具：

```python
toolkit.get_tools()
```

## 调用

你可以通过传入参数单独调用工具。对于 `QueryMemgraphTool`，示例如下：

```python
from langchain_memgraph.tools import QueryMemgraphTool

# Rest of the code omitted for brevity

tool.invoke({QueryMemgraphTool({"query": "MATCH (n) RETURN n LIMIT 5"})})
```

## 在 agent 中使用

```python
from langchain.agents import create_agent


agent_executor = create_agent(model, tools)
```

```python
example_query = "MATCH (n) RETURN n LIMIT 1"

stream = agent_executor.stream_events(
    {"messages": [("user", example_query)]},
    version="v3",
)
for snapshot in stream.values:
    snapshot["messages"][-1].pretty_print()
```
