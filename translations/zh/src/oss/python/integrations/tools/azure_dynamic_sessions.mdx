Azure Container Apps dynamic sessions 提供了一种安全且可扩展的方式，用于在 Hyper-V 隔离沙箱中运行 Python 代码解释器。这使你的 agent 能够在安全环境中运行潜在不受信任的代码。代码解释器环境中包含许多常用 Python 包，例如 NumPy、pandas 和 scikit-learn。有关 session 工作方式的更多信息，请参阅 [Azure Container App docs](https://learn.microsoft.com/en-us/azure/container-apps/sessions-code-interpreter)。

## Setup

默认情况下，`SessionsPythonREPLTool` 工具使用 `DefaultAzureCredential` 与 Azure 进行认证。在本地，它会使用你的 Azure CLI 或 VS Code 凭证。安装 Azure CLI，并通过 `az login` 登录来完成认证。

要使用代码解释器，你还需要创建一个 session pool。可以按照 [session pool creation instructions](https://learn.microsoft.com/en-us/azure/container-apps/sessions-code-interpreter?tabs=azure-cli#create-a-session-pool-with-azure-cli) 进行创建。完成后，你将获得一个 pool management session endpoint，需要在下面进行设置：

```python
import getpass

POOL_MANAGEMENT_ENDPOINT = getpass.getpass()
```

## Use tool

实例化并使用工具：

```python
from langchain_azure_dynamic_sessions import SessionsPythonREPLTool

tool = SessionsPythonREPLTool(pool_management_endpoint=POOL_MANAGEMENT_ENDPOINT)
tool.invoke("6 * 7")
```

```text
'{\n  "result": 42,\n  "stdout": "",\n  "stderr": ""\n}'
```

调用该工具会返回一个 JSON 字符串，其中包含代码执行结果，以及任何 stdout 和 stderr 输出。若要获取原始字典结果，可使用 `execute()` 方法：

```python
tool.execute("6 * 7")
```

```text
{'$id': '2',
 'status': 'Success',
 'stdout': '',
 'stderr': '',
 'result': 42,
 'executionTimeInMilliseconds': 8}
```

## Upload data

如果你想基于特定数据执行计算，可以使用 `upload_file()` 功能将数据上传到 session。你既可以通过 `data: BinaryIO` 参数上传，也可以通过 `local_file_path: str` 参数上传（指向你系统上的本地文件）。数据会自动上传到 sessions 容器中的 `/mnt/data/` 目录。你可以通过 `upload_file()` 返回的上传元数据获取完整文件路径。

```python
import io
import json

data = {"important_data": [1, 10, -1541]}
binary_io = io.BytesIO(json.dumps(data).encode("ascii"))

upload_metadata = tool.upload_file(
    data=binary_io, remote_file_path="important_data.json"
)

code = f"""
import json

with open("{upload_metadata.full_path}") as f:
    data = json.load(f)

sum(data['important_data'])
"""
tool.execute(code)
```

```text
{'$id': '2',
 'status': 'Success',
 'stdout': '',
 'stderr': '',
 'result': -1530,
 'executionTimeInMilliseconds': 12}
```

## Handling image results

Dynamic sessions 的结果中可能包含以 base64 编码字符串表示的图像输出。在这种情况下，`result` 的值会是一个字典，包含 `"type"`（其值会是 `"image"`）、`"format"`（图像格式）和 `"base64_data"` 等键。

```python
code = """
import numpy as np
import matplotlib.pyplot as plt

# Generate values for x from -1 to 1
x = np.linspace(-1, 1, 400)

# Calculate the sine of each x value
y = np.sin(x)

# Create the plot
plt.plot(x, y)

# Add title and labels
plt.title('Plot of sin(x) from -1 to 1')
plt.xlabel('x')
plt.ylabel('sin(x)')

# Show the plot
plt.grid(True)
plt.show()
"""

result = tool.execute(code)
result["result"].keys()
```

```text
dict_keys(['type', 'format', 'base64_data'])
```

```python
result["result"]["type"], result["result"]["format"]
```

```text
('image', 'png')
```

我们可以解码图像数据并将其显示出来：

```python
import base64
import io

from IPython.display import display
from PIL import Image

base64_str = result["result"]["base64_data"]
img = Image.open(io.BytesIO(base64.decodebytes(bytes(base64_str, "utf-8"))))
display(img)
```

## Simple agent example

```python
from langchain_classic import hub
from langchain.agents import AgentExecutor, create_tool_calling_agent
from langchain_azure_dynamic_sessions import SessionsPythonREPLTool
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(model="gpt-5.5", temperature=0)
prompt = hub.pull("hwchase17/openai-functions-agent")
agent = create_tool_calling_agent(llm, [tool], prompt)

agent_executor = AgentExecutor(
    agent=agent, tools=[tool], verbose=True, handle_parsing_errors=True
)

response = agent_executor.invoke(
    {
        "input": "what's sin of pi . if it's negative generate a random number between 0 and 5. if it's positive between 5 and 10."
    }
)
```
