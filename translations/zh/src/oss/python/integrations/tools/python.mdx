有时，对于复杂计算，与其让 LLM 直接生成答案，不如让 LLM 生成用于计算答案的代码，再执行这段代码来得到结果。为了方便做到这一点，这里提供了一个简单的 Python REPL 用于执行命令。

这个接口只会返回被打印出来的内容，因此如果你希望用它来计算答案，请确保把结果通过 `print` 打印出来。

<Warning>
**Python REPL 可以在宿主机上执行任意代码，例如删除文件或发起网络请求。请谨慎使用。**

</Warning>

<LangchainExperimentalUnmaintained />

```python
from langchain.tools import tool
from langchain_experimental.utilities import PythonREPL
```

```python
python_repl = PythonREPL()
```

```python
python_repl.run("print(1+1)")
```

```text
Python REPL can execute arbitrary code. Use with caution.
```

```text
'2\n'
```

```python
# You can create the tool to pass to an agent
@tool
def python_repl_tool(code: str) -> str:
    """A Python shell.

    Use this to execute python commands.

    Input should be a valid python command.

    If you want to see the output of a value, you should print it out with `print(...)`.
    """
    return python_repl.run(code)
```
