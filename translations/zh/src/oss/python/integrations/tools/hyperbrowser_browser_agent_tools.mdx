[Hyperbrowser](https://hyperbrowser.ai) 是一个用于运行浏览器、运行 browser agents 以及扩展无头浏览器的基础平台。它让你能够大规模启动和管理浏览器会话，并为各种网页抓取需求提供易于使用的解决方案，例如抓取单页内容或爬取整个网站。

关键特性：

- Instant Scalability - 无需处理基础设施难题，即可在数秒内启动数百个浏览器会话
- Simple Integration - 可与 Puppeteer、Playwright 等常用工具无缝协作
- Powerful APIs - 易于使用的 API，可用于抓取/爬取任意网站，以及更多能力
- Bypass Anti-Bot Measures - 内建 stealth mode、广告拦截、自动 CAPTCHA 求解和轮换代理

本指南提供了一个快速概览，帮助你开始使用 Hyperbrowser 工具。

如需了解更多关于 Hyperbrowser 的信息，请访问 [Hyperbrowser website](https://hyperbrowser.ai)。如果你想查看文档，可以访问 [Hyperbrowser docs](https://docs.hyperbrowser.ai)。

## Browser agents

Hyperbrowser 提供了强大的 browser agent 工具，使 AI 模型能够以编程方式与浏览器交互。这些 browser agents 可以导航网站、填写表单、点击按钮、提取数据，并执行复杂的网页自动化任务。

Browser agents 特别适用于以下场景：

- 从复杂网站进行网页抓取与数据提取
- 自动化重复性的网页任务
- 与需要身份验证的 Web 应用交互
- 在多个网站上执行研究任务
- 测试 Web 应用

Hyperbrowser 提供三种 browser agent 工具：

- **Browser Use Tool**: 通用浏览器自动化工具
- **OpenAI CUA Tool**: 与 OpenAI Computer Use Agent 的集成
- **Claude Computer Use Tool**: 与 Anthropic Claude computer use 的集成

## 设置

要使用 Hyperbrowser 工具，你需要安装 `langchain-hyperbrowser` 集成包，创建 Hyperbrowser 账户，并获取 API key。

### 凭证

前往 [Hyperbrowser](https://app.hyperbrowser.ai/) 注册并生成 API key。完成后，请设置 `HYPERBROWSER_API_KEY` 环境变量：

```bash
export HYPERBROWSER_API_KEY=<your-api-key>
```

### 安装

安装 **langchain-hyperbrowser**。

```python
pip install -qU langchain-hyperbrowser
```

## 实例化

### Browser use tool

`HyperbrowserBrowserUseTool` 是一个使用 Browser-Use agent 执行网页自动化任务的工具。

```python
from langchain_hyperbrowser import HyperbrowserBrowserUseTool
tool = HyperbrowserBrowserUseTool()
```

### OpenAI CUA tool

`HyperbrowserOpenAICUATool` 是一个专用工具，通过 Hyperbrowser 利用 OpenAI 的 Computer Use Agent (CUA) 能力。

```python
from langchain_hyperbrowser import HyperbrowserOpenAICUATool
tool = HyperbrowserOpenAICUATool()
```

### Claude computer use tool

`HyperbrowserClaudeComputerUseTool` 是一个专用工具，通过 Hyperbrowser 利用 Claude 的 computer use 能力。

```python
from langchain_hyperbrowser import HyperbrowserClaudeComputerUseTool
tool = HyperbrowserClaudeComputerUseTool()
```

### 使用自定义 session options

所有工具都支持自定义 session options：

```python
result = tool.run(
    {
        "task": "Go to npmjs.com, and tell me when react package was last updated.",
        "session_options": {
            "session_options": {"use_proxy": True, "accept_cookies": True}
        },
    }
)
print(result)
```

```python
{'data': 'I have found that the react package was last published 11 hours ago. This is the most recently updated package I could find.', 'error': None}
```

### 异步用法

所有工具都支持异步使用：

```python
async def browse_website():
    tool = HyperbrowserBrowserUseTool()
    result = await tool.arun(
        {
            "task": "Go to npmjs.com, click the first visible package, and tell me when it was updated"
        }
    )
    return result


result = await browse_website()
```

## 在 agent 中使用

下面展示了如何在 agent 中使用任意一个 Hyperbrowser 工具：

```python
from langchain.prompts import ChatPromptTemplate, MessagesPlaceholder
from langchain_hyperbrowser import browser_use_tool
from langchain_openai import ChatOpenAI
from langchain.agents import create_agent


model = ChatOpenAI(temperature=0)

# You can use any of the three tools here
browser_use_tool = HyperbrowserBrowserUseTool()
agent = create_agent(model, [browser_use_tool])

user_input = "Go to npmjs.com, and tell me when react package was last updated."
stream = agent.stream_events({"messages": user_input}, version="v3")
for snapshot in stream.values:
    snapshot["messages"][-1].pretty_print()
```

## 配置选项

Claude Computer Use、OpenAI CUA 和 Browser Use 都支持以下参数：

- `task`: 要由 agent 执行的任务
- `max_steps`: agent 为完成任务允许采取的最大交互步数
- `session_options`: 浏览器会话配置
