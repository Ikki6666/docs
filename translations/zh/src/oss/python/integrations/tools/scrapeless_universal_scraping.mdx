**Scrapeless** 提供灵活且功能丰富的数据获取服务，支持广泛的参数定制和多格式导出。这些能力让 LangChain 能更有效地集成并利用外部数据。其核心功能模块包括：

**DeepSerp**

- **Google Search**: 支持对 Google SERP 各类结果进行全面提取。
  - 支持选择本地化的 Google 域名（例如 `google.com`、`google.ad`），以获取区域特定的搜索结果。
  - 支持分页，以获取第一页之后的结果。
  - 支持搜索结果过滤开关，用于控制是否排除重复或相似内容。
- **Google Trends**: 从 Google 获取关键词趋势数据，包括随时间变化的热度、区域兴趣和相关搜索。
  - 支持多关键词对比。
  - 支持多种数据类型：`interest_over_time`、`interest_by_region`、`related_queries` 和 `related_topics`。
  - 允许按特定 Google 属性（Web、YouTube、News、Shopping）进行过滤，以便做来源特定的趋势分析。

**Universal Scraping**

- 面向现代、重度依赖 JavaScript 的网站设计，可用于提取动态内容。
  - 支持全球 premium proxy，以绕过地理限制并提升稳定性。

**Crawler**

- **Crawl**: 递归爬取某个网站及其链接页面，以提取站点级内容。
  - 支持可配置的爬取深度与作用域 URL 目标控制。
- **Scrape**: 高精度提取单个网页内容。
  - 支持“仅主内容”提取，以排除广告、页脚和其他非核心元素。
  - 支持对多个独立 URL 进行批量抓取。

## 实例化

这里展示如何实例化 Scrapeless Universal Scraping Tool。该工具允许你使用带 JavaScript 渲染能力的 headless browser 抓取任意网站，并支持可定制的输出类型和按地区选择的代理支持。

该工具在实例化时接受以下参数：

- `url`（必填，str）：要抓取的网站 URL。
- `headless`（可选，bool）：是否使用 headless browser。默认值为 True。
- `js_render`（可选，bool）：是否启用 JavaScript 渲染。默认值为 True。
- `js_wait_until`（可选，str）：定义何时认为 JavaScript 渲染后的页面已准备完成。默认值为 `'domcontentloaded'`。可选值包括：
  - `load`: 等待页面完全加载。
  - `domcontentloaded`: 等待 DOM 完全加载。
  - `networkidle0`: 等待网络空闲。
  - `networkidle2`: 等待网络空闲 2 秒。
- `outputs`（可选，str）：要从页面提取的特定数据类型。可选值包括：
  - `phone_numbers`
  - `headings`
  - `images`
  - `audios`
  - `videos`
  - `links`
  - `menus`
  - `hashtags`
  - `emails`
  - `metadata`
  - `tables`
  - `favicon`
- `response_type`（可选，str）：定义响应格式。默认值为 `'html'`。可选值包括：
  - `html`: 返回页面原始 HTML。
  - `plaintext`: 返回纯文本内容。
  - `markdown`: 返回页面的 Markdown 版本。
  - `png`: 返回 PNG 截图。
  - `jpeg`: 返回 JPEG 截图。
- `response_image_full_page`（可选，bool）：在使用截图输出（png 或 jpeg）时，是否捕获并返回整页图像。默认值为 False。
- `selector`（可选，str）：一个特定的 CSS selector，用于把抓取范围限制在页面的某个区域内。默认值为 `None`。
- `proxy_country`（可选，str）：用于指定地区代理访问的两位国家代码（例如 `'us'`、`'gb'`、`'de'`、`'jp'`）。默认值为 `'ANY'`。

# Basic usage

print(result)

### 在 agent 中使用

```python
from langchain_openai import ChatOpenAI
from langchain_scrapeless import ScrapelessUniversalScrapingTool
from langchain.agents import create_agent


model = ChatOpenAI()

tool = ScrapelessUniversalScrapingTool()

# Use the tool with an agent
tools = [tool]
agent = create_agent(model, tools)

stream = agent.stream_events(
    {
        "messages": [
            (
                "human",
                "Use the scrapeless scraping tool to fetch https://www.scrapeless.com/en and extract the h1 tag.",
            )
        ]
    },
    version="v3",
)
for snapshot in stream.values:
    snapshot["messages"][-1].pretty_print()
```
