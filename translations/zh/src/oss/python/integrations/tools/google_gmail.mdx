这会帮助你开始使用 Gmail [toolkit](/oss/integrations/tools/google_gmail)。这个 toolkit 会与 Gmail API 交互，用于读取邮件、起草和发送邮件等。关于 `GmailToolkit` 全部特性和配置项的详细文档，请参阅 [API reference](https://reference.langchain.com/python/langchain-google-community/gmail/toolkit/GmailToolkit)。

## 设置

要使用这个 toolkit，你需要按 [Gmail API docs](https://developers.google.com/gmail/api/quickstart/python#authorize_credentials_for_a_desktop_application) 中说明的方式设置凭据。下载好 `credentials.json` 文件之后，就可以开始使用 Gmail API 了。

### 安装

这个 toolkit 位于 `langchain-google-community` 包中。我们需要安装它的 `gmail` extra：

```python
pip install -qU langchain-google-community\[gmail\]
```

如果你想为每个工具启用自动 tracing，请设置 [LangSmith](/langsmith/observability) API key：

```python
os.environ["LANGSMITH_TRACING"] = "true"
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
```

## 实例化

默认情况下，这个 toolkit 会读取本地的 `credentials.json` 文件。你也可以手动传入一个 `Credentials` 对象。

```python
from langchain_google_community import GmailToolkit

toolkit = GmailToolkit()
```

### 自定义认证方式

在底层，会通过以下方法创建一个 `googleapi` resource。你也可以手动构建这个 `googleapi` resource，以获得更细粒度的认证控制。

```python
from langchain_google_community.gmail.utils import (
    build_resource_service,
    get_gmail_credentials,
)

# Can review scopes here https://developers.google.com/gmail/api/auth/scopes
# For instance, readonly scope is 'https://www.googleapis.com/auth/gmail.readonly'
credentials = get_gmail_credentials(
    token_file="token.json",
    scopes=["https://mail.google.com/"],
    client_secrets_file="credentials.json",
)
api_resource = build_resource_service(credentials=credentials)
toolkit = GmailToolkit(api_resource=api_resource)
```

## 在 agent 中使用

下面演示如何把这个 toolkit 集成进一个 [agent](/oss/langchain/agents)。

我们需要一个 LLM 或 chat model：

<ChatModelTabs customVarName="llm" />

```python
# | output: false
# | echo: false

from langchain_openai import ChatOpenAI

llm = ChatOpenAI(model="gpt-5.4-mini", temperature=0)
```

```python
from langchain.agents import create_agent


agent_executor = create_agent(llm, tools)
```

```python
example_query = "Draft an email to fake@fake.com thanking them for coffee."

stream = agent_executor.stream_events(
    {"messages": [("user", example_query)]},
    version="v3",
)
for snapshot in stream.values:
    snapshot["messages"][-1].pretty_print()
```
