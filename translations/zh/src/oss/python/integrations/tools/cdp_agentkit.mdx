`CDP Agentkit` toolkit 包含一组工具，使 LLM agent 能与 [Coinbase Developer Platform](https://docs.cdp.coinbase.com/) 交互。该 toolkit 提供对 CDP SDK 的封装，让 agent 可以执行链上操作，例如转账、交易和智能合约交互。

## 概览

### 集成详情

| Class | Package | Serializable | JS support |  Version |
| :--- | :--- | :---: | :---: | :---: |
| `CdpToolkit` | `cdp-langchain` | ❌ | ❌ |  ![PyPI - Version](https://img.shields.io/pypi/v/cdp-langchain?style=flat-square&label=%20) |

### 工具特性

该 toolkit 提供以下工具：

1. **get_wallet_details** - 获取 MPC Wallet 的详细信息
2. **get_balance** - 获取特定资产余额
3. **request_faucet_funds** - 从 faucet 请求测试代币
4. **transfer** - 在地址之间转移资产
5. **trade** - 交易资产（仅 Mainnet）
6. **deploy_token** - 部署 ERC-20 代币合约
7. **mint_nft** - 从现有合约铸造 NFT
8. **deploy_nft** - 部署新的 NFT 合约
9. **register_basename** - 为钱包注册 basename

建议你自行添加工具，包括基于 CDP 和 web2 API 的工具，以创建更贴合需求的 agent。

## 设置

总体来说，我们会：

1. 安装 langchain 包
2. 设置 CDP API 凭证
3. 初始化 CDP wrapper 和 toolkit
4. 通过 `toolkit.get_tools()` 将工具传给 agent

要启用对单个工具的自动 tracing，请设置你的 [LangSmith](/langsmith/observability) API key：

```python
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

### 安装

该 toolkit 位于 `cdp-langchain` 包中：

```python
pip install -qU cdp-langchain
```

#### 设置环境变量

要使用此 toolkit，你必须先设置以下环境变量，以便访问 [CDP APIs](https://docs.cdp.coinbase.com/mpc-wallet/docs/quickstart) 来创建钱包并进行链上交互。你可以在 [CDP Portal](https://cdp.coinbase.com/) 免费注册并获取 API key：

```python
import getpass
import os

for env_var in [
    "CDP_API_KEY_NAME",
    "CDP_API_KEY_PRIVATE_KEY",
]:
    if not os.getenv(env_var):
        os.environ[env_var] = getpass.getpass(f"Enter your {env_var}: ")

# Optional: Set network (defaults to base-sepolia)
os.environ["NETWORK_ID"] = "base-sepolia"  # or "base-mainnet"
```

## 实例化

现在可以实例化 toolkit：

```python
from cdp_langchain.agent_toolkits import CdpToolkit
from cdp_langchain.utils import CdpAgentkitWrapper

# Initialize CDP wrapper
cdp = CdpAgentkitWrapper()

# Create toolkit from wrapper
toolkit = CdpToolkit.from_cdp_agentkit_wrapper(cdp)
```

## 工具

查看[可用工具](#工具特性)：

```python
tools = toolkit.get_tools()
for tool in tools:
    print(tool.name)
```

## 在 agent 中使用

我们需要一个 LLM 或聊天模型：

```python
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(model="gpt-5.4-mini")
```

使用这些工具初始化 agent：

```python
from langchain.agents import create_agent


tools = toolkit.get_tools()
agent_executor = create_agent(llm, tools)
```

用法示例：

```python
example_query = "Send 0.005 ETH to john2879.base.eth"

stream = agent_executor.stream_events(
    {"messages": [("user", example_query)]},
    version="v3",
)
for snapshot in stream.values:
    snapshot["messages"][-1].pretty_print()
```

预期输出：

```
Transferred 0.005 of eth to john2879.base.eth.
Transaction hash for the transfer: 0x78c7c2878659a0de216d0764fc87eff0d38b47f3315fa02ba493a83d8e782d1e
Transaction link for the transfer: https://sepolia.basescan.org/tx/0x78c7c2878659a0de216d0764fc87eff0d38b47f3315fa02ba493a83d8e782d1
```

## CDP toolkit 的特定特性

### 钱包管理

该 toolkit 会维护一个 MPC 钱包。你可以导出并导入钱包数据，以便在会话间持久化：

```python
# Export wallet data
wallet_data = cdp.export_wallet()

# Import wallet data
values = {"cdp_wallet_data": wallet_data}
cdp = CdpAgentkitWrapper(**values)
```

### 网络支持

该 toolkit 支持[多种网络](https://docs.cdp.coinbase.com/cdp-sdk/docs/networks)

### Gasless transactions

某些操作在 Base Mainnet 上支持 gasless transaction：

- USDC transfers
- EURC transfers
- cbBTC transfers
