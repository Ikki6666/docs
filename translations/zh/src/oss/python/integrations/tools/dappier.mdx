[Dappier](https://dappier.com) 可将任意 LLM 或你的 Agentic AI 连接到来自可信来源的实时、已清权、专有数据，使你的 AI 能在各种主题上成为专家。其专用模型包括实时网页搜索、新闻、体育、金融股市数据、加密数据，以及来自优质出版商的独家内容。你可以在 [marketplace.dappier.com](https://marketplace.dappier.com) 的 marketplace 中探索丰富的数据模型。

[Dappier](https://dappier.com) 提供经过增强、可直接用于提示、且具备上下文相关性的数据字符串，并针对与 LangChain 的无缝集成做了优化。无论你是在构建对话式 AI、推荐引擎还是智能搜索，Dappier 的 LLM-agnostic RAG 模型都能让你的 AI 访问经过验证、保持最新的数据，而无需自己构建和维护检索管道的复杂性。

# Dappier 工具

本页将帮助你开始使用 Dappier [tool](/oss/langchain/tools)。如需了解 `DappierRetriever` 的全部特性与配置细节，请参阅 [API reference](https://python.langchain.com/en/latest/tools/langchain_dappier.tools.Dappier.DappierRealTimeSearchTool.html)。

## 概览

DappierRealTimeSearchTool 和 DappierAIRecommendationTool 能为 AI 应用带来实时数据和 AI 驱动的洞察。前者可访问新闻、天气、旅行、金融市场等领域的最新信息；后者则借助 Dappier 预训练的 RAG 模型和自然语言 API，为应用注入来自新闻、金融、体育等多个领域的高质量、可信内容。

### 设置

该工具位于 `langchain-dappier` 包中。

```python
pip install -qU langchain-dappier
```

### 凭证

你还需要设置 Dappier API 凭证，可以在 [Dappier site.](https://platform.dappier.com/profile/api-keys) 生成。

```python
import getpass
import os

if not os.environ.get("DAPPIER_API_KEY"):
    os.environ["DAPPIER_API_KEY"] = getpass.getpass("Dappier API key:\n")
```

如果你希望为单次查询启用自动 tracing，也可以取消下面代码的注释，设置 [LangSmith](/langsmith/observability) API key：

```python
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

## DappierRealTimeSearchTool

访问实时 Google 搜索结果，包括最新新闻、天气、旅行和优惠信息，以及来自 polygon.io 的最新财经新闻、股价和交易数据，并通过 AI 洞察帮助你及时掌握动态。

### 实例化

- ai_model_id: str
    要用于查询的 AI model ID。AI model ID 总是以
    前缀 `"am_"` 开头。

    默认值为 `"am_01j06ytn18ejftedz6dyhz2b15"`。

    可用的 AI model ID 不止一个，可在以下地址查看：
    [marketplace.dappier.com/marketplace](https://marketplace.dappier.com/marketplace)

```python
from langchain_dappier import DappierRealTimeSearchTool

tool = DappierRealTimeSearchTool(
    # ai_model_id="...",     # overwrite default ai_model_id
    # name="...",            # overwrite default tool name
    # description="...",     # overwrite default tool description
    # args_schema=...,       # overwrite default args_schema: BaseModel
)
```

### 调用

#### [使用 args 直接调用](/oss/langchain/tools)

`DappierRealTimeSearchTool` 接收一个 `"query"` 参数，它应当是自然语言查询：

```python
tool.invoke({"query": "What happened at the last wimbledon"})
```


### [使用 ToolCall 调用](/oss/langchain/tools)

我们也可以使用模型生成的 ToolCall 调用该工具，这种情况下会返回一个 ToolMessage：

```python
# This is usually generated by a model, but we'll create a tool call directly for demo purposes.
model_generated_tool_call = {
    "args": {"query": "euro 2024 host nation"},
    "id": "1",
    "name": "dappier",
    "type": "tool_call",
}
tool_msg = tool.invoke(model_generated_tool_call)

# The content is a JSON string of results
print(tool_msg.content[:400])
```

### 链式调用

我们可以先把工具绑定到一个[支持工具调用的模型](/oss/langchain/tools/)，然后再调用它，从而在 chain 中使用该工具：

<ChatModelTabs customVarName="llm" />

```python
# | output: false
# | echo: false

# !pip install -qU langchain langchain-openai
from langchain.chat_models import init_chat_model

model = init_chat_model(model="gpt-5.5", model_provider="openai", temperature=0)
```

```python
import datetime

from langchain_core.prompts import ChatPromptTemplate
from langchain_core.runnables import RunnableConfig, chain

today = datetime.datetime.today().strftime("%D")
prompt = ChatPromptTemplate(
    [
        ("system", f"You are a helpful assistant. The date today is {today}."),
        ("human", "{user_input}"),
        ("placeholder", "{messages}"),
    ]
)

# specifying tool_choice will force the model to call this tool.
model_with_tools = model.bind_tools([tool])

model_chain = prompt | model_with_tools


@chain
def tool_chain(user_input: str, config: RunnableConfig):
    input_ = {"user_input": user_input}
    ai_msg = model_chain.invoke(input_, config=config)
    tool_msgs = tool.batch(ai_msg.tool_calls, config=config)
    return model_chain.invoke({**input_, "messages": [ai_msg, *tool_msgs]}, config=config)


tool_chain.invoke("who won the last womens singles wimbledon")
```

## DappierAIRecommendationTool

借助 Dappier 预训练的 RAG 模型和自然语言 API，为你的 AI 应用提供来自新闻、金融、体育、天气等多个垂直领域的高质量、及时内容。

### 实例化

- data_model_id: str
  要用于推荐的数据模型 ID。数据模型 ID 总是以前缀 `"dm_"` 开头。默认值为 `"dm_01j0pb465keqmatq9k83dthx34"`。
  你可以在 [Dappier marketplace](https://marketplace.dappier.com/marketplace) 查看多个可用的数据模型 ID。

- similarity_top_k: int
  基于相似度返回的顶部文档数量。默认值为 `"9"`。

- ref: Optional[str]
  AI 推荐内容应展示的网站域名。默认值为 `"None"`。

- num_articles_ref: int
  从指定参考域名 `("ref")` 返回的最少文章数量。其余文章将来自该 RAG 模型中的其他站点。默认值为 `"0"`。

- search_algorithm: Literal["most_recent", "semantic", "most_recent_semantic", "trending"]
  用于检索文章的搜索算法。默认值为 `"most_recent"`。

```python
from langchain_dappier import DappierAIRecommendationTool

tool = DappierAIRecommendationTool(
    data_model_id="dm_01j0pb465keqmatq9k83dthx34",
    similarity_top_k=3,
    ref="sportsnaut.com",
    num_articles_ref=2,
    search_algorithm="most_recent",
    # name="...",            # overwrite default tool name
    # description="...",     # overwrite default tool description
    # args_schema=...,       # overwrite default args_schema: BaseModel
)
```

```python
tool.invoke({"query": "latest sports news"})
```
