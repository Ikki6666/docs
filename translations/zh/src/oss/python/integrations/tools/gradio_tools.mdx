在 `Hugging Face Spaces` 上有成千上万的 `Gradio` 应用。这个库让你的 LLM 可以直接调用它们 🦾

更具体地说，`gradio-tools` 是一个 Python 库，可以把 `Gradio` 应用转换成工具，让基于大语言模型（LLM）的 agent 能够利用这些工具完成任务。比如，一个 LLM 可以用某个 `Gradio` 工具转录它在网上找到的语音录音，然后再帮你总结内容。或者，它也可以使用另一个 `Gradio` 工具对你 Google Drive 里的文档执行 OCR，然后回答相关问题。

如果你想使用的 space 不在预构建工具列表中，那么创建自己的工具也非常简单。关于具体做法，请参阅 gradio-tools 文档中的对应章节。欢迎一切贡献。

```python
pip install -qU  gradio_tools
```

## 在 agent 中使用

```python
from gradio_tools.tools import (
    ImageCaptioningTool,
    StableDiffusionPromptGeneratorTool,
    StableDiffusionTool,
    TextToVideoTool,
)
from langchain.agents import create_agent
from langchain.memory import ConversationBufferMemory
from langchain_openai import OpenAI

llm = OpenAI(temperature=0)
memory = ConversationBufferMemory(memory_key="chat_history")
tools = [
    StableDiffusionTool().langchain,
    ImageCaptioningTool().langchain,
    StableDiffusionPromptGeneratorTool().langchain,
    TextToVideoTool().langchain,
]

agent = create_agent(
    model=llm,
    tools=tools,
    memory=memory,
    verbose=True,
)

output = agent.invoke(
    {
        "input": (
            "Please create a photo of a dog riding a skateboard "
            "but improve my prompt prior to using an image generator."
            "Please caption the generated image and create a video for it using the improved prompt."
        )
    }
)
```
