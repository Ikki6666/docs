[Bright Data](https://brightdata.com/) 提供了强大的 Web Unlocker API，可以帮助你访问那些可能受到反爬机制、地域限制或其他访问限制保护的网站，因此它对需要稳定网页内容提取能力的 AI agents 特别有用。

## 设置

该集成位于 `langchain-brightdata` 包中。

```python
pip install langchain-brightdata
```

要使用这个工具，你需要一个 Bright Data API key。可以把它设置成环境变量：

```python
import os

os.environ["BRIGHT_DATA_API_KEY"] = "your-api-key"
```

或者在初始化工具时直接传入：

```python
from langchain_brightdata import BrightDataUnlocker

unlocker_tool = BrightDataUnlocker(bright_data_api_key="your-api-key")
```

## 实例化

下面演示如何实例化 `BrightDataUnlocker` 工具。这个工具可以借助 Bright Data 的 Web Unlocker 服务，帮助你访问那些可能受到反爬机制、地域限制或其他访问限制保护的网站。

该工具在实例化时支持多个参数：

- `bright_data_api_key`（必填，str）：用于认证的 Bright Data API key。
- `format`（可选，Literal["raw"]）：响应内容格式。默认是 `"raw"`。
- `country`（可选，str）：用于地域访问的两位国家代码，例如 `"us"`、`"gb"`、`"de"`、`"jp"`。当你需要模拟从某个国家访问网站时，可以设置这个值。默认是 None。
- `zone`（可选，str）：请求使用的 Bright Data zone。`"unlocker"` zone 针对那些可能会阻止普通请求的网站进行了优化。默认是 `"unlocker"`。
- `data_format`（可选，Literal["html", "markdown", "screenshot"]）：返回内容的输出格式，可选项包括：
  - `"html"`：返回标准 HTML 内容（默认）
  - `"markdown"`：返回转换成 markdown 的内容
  - `"screenshot"`：返回渲染页面的 PNG 截图

## 调用

### 基本用法

```python
from langchain_brightdata import BrightDataUnlocker

# Initialize the tool
unlocker_tool = BrightDataUnlocker(
    bright_data_api_key="your-api-key"  # Optional if set in environment variables
)

# Access a webpage
result = unlocker_tool.invoke("https://example.com")

print(result)
```

### 带参数的高级用法

```python
from langchain_brightdata import BrightDataUnlocker

unlocker_tool = BrightDataUnlocker(
    bright_data_api_key="your-api-key",
)

# Access a webpage with specific parameters
result = unlocker_tool.invoke(
    {
        "url": "https://example.com/region-restricted-content",
        "country": "gb",  # Access as if from Great Britain
        "data_format": "html",  # Get content in markdown format
        "zone": "unlocker",  # Use the unlocker zone
    }
)

print(result)
```

## 自定义选项

BrightDataUnlocker 工具支持以下自定义参数：

|Parameter|Type|Description|
|:--|:--|:--|
|`url`|str|要访问的 URL|
|`format`|str|响应内容格式（默认：`"raw"`）|
|`country`|str|用于地域访问的两位国家代码，例如 `"us"`、`"gb"`|
|`zone`|str|要使用的 Bright Data zone（默认：`"unlocker"`）|
|`data_format`|str|输出格式：None（HTML）、`"markdown"` 或 `"screenshot"`|

## 数据格式选项

`data_format` 参数允许你指定返回内容的形式：

- `None` 或 `"html"`（默认）：返回页面的标准 HTML 内容
- `"markdown"`：返回转换成 markdown 的内容，适合直接喂给 LLM
- `"screenshot"`：返回渲染页面的 PNG 截图，适合做视觉分析

## 在 agent 中使用

```python
from langchain_brightdata import BrightDataUnlocker
from langchain_google_genai import ChatGoogleGenerativeAI
from langchain.agents import create_agent


# Initialize the LLM
llm = ChatGoogleGenerativeAI(model="gemini-2.5-flash", google_api_key="your-api-key")

# Initialize the tool
bright_data_tool = BrightDataUnlocker(bright_data_api_key="your-api-key")

# Create the agent
agent = create_agent(llm, [bright_data_tool])

# Input URLs or prompt
user_input = "Get the content from https://example.com/region-restricted-page - access it from GB"

# Stream the agent's output step by step
stream = agent.stream_events({"messages": user_input}, version="v3")
for snapshot in stream.values:
    snapshot["messages"][-1].pretty_print()
```
