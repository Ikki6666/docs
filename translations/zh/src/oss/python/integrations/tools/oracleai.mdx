Oracle AI Database 支持这样的 AI 工作负载：按**语义**而不只是按关键词来查询数据。它把**对非结构化内容的语义搜索**与**对业务数据的关系型过滤**整合在一个系统中，因此你可以构建检索工作流，例如 RAG，而不需要额外引入一个向量数据库，也不会把数据切碎到多个平台中。

本指南演示如何使用 Oracle AI Vector Search LangChain 集成中的 `OracleSummary` 来生成文档摘要。

> **为什么要在这里做摘要？**
> 摘要是一种很实用的方式，可以把长文档压缩成更适合检索的内容，例如预览、metadata 或浓缩后的上下文，同时又能让治理和运维保障贴近数据本身。

如果你刚开始接触 Oracle Database，可以先了解一下 [free Oracle 26 AI](https://www.oracle.com/database/free/#resources)。如需端到端的配置演练，请参阅 [Oracle AI Vector Search demo notebook](https://github.com/langchain-ai/langchain/blob/v0.3/cookbook/oracleai_demo.ipynb)。关于用户管理的背景信息，请参阅官方 [Oracle guide](https://docs.oracle.com/en/database/oracle/oracle-database/19/admqs/administering-user-accounts-and-security.html#GUID-36B21D72-1BBB-46C9-A0C9-F0D2A8591B8D)。

### 前置条件

安装 `langchain-oracledb`。`python-oracledb` driver 会作为依赖自动安装。

<CodeGroup>
```bash pip
pip install -qU langchain-oracledb
```

</CodeGroup>

### 连接到 Oracle Database

下面的示例代码演示如何连接到 Oracle Database。默认情况下，python-oracledb 会以 “Thin” 模式运行，直接连接到 Oracle Database，这种模式不需要 Oracle Client libraries。不过，当 python-oracledb 使用这些库时，还会提供一些额外功能。此时 python-oracledb 被称为运行在 “Thick” 模式下。两种模式都全面支持 Python Database API v2.0 Specification。关于每种模式支持的功能，请参阅这份[指南](https://python-oracledb.readthedocs.io/en/latest/user_guide/appendix_a.html#featuresummary)。如果你无法使用 thin-mode，可以考虑切换到 thick-mode。

```python
import oracledb

# Please update with your username, password, hostname, port and service_name
username = "<username>"
password = "<password>"
dsn = "<hostname>:<port>/<service_name>"

connection = oracledb.connect(user=username, password=password, dsn=dsn)
print("Connection successful!")
```

### 生成摘要

Oracle AI Vector Search LangChain 库提供了一组用于文档摘要的 API。它支持多种摘要提供方，例如 Database、OCIGENAI、HuggingFace 等，因此用户可以根据需要选择最适合的 provider。要使用这些能力，用户必须按照要求配置摘要参数。关于这些参数的详细信息，请参阅 [Oracle AI Vector Search Guide book](https://docs.oracle.com/en/database/oracle/oracle-database/23/arpls/dbms_vector_chain1.html#GUID-EC9DDB58-6A15-4B36-BA66-ECBA20D2CE57)。

***注意：*** 如果用户想使用 Oracle 自家默认 provider `database` 之外的第三方摘要生成 provider，可能需要设置 proxy。如果你没有 proxy，在实例化 `OracleSummary` 时请移除 `proxy` 参数。

```python
# proxy to be used when we instantiate summary and embedder object
proxy = "<proxy>"
```

下面的示例代码演示如何生成摘要：

```python
from langchain_oracledb.utilities.oracleai import OracleSummary
from langchain_core.documents import Document

"""
# using 'ocigenai' provider
summary_params = {
    "provider": "ocigenai",
    "credential_name": "OCI_CRED",
    "url": "https://inference.generativeai.us-chicago-1.oci.oraclecloud.com/20231130/actions/summarizeText",
    "model": "cohere.command",
}

# using 'huggingface' provider
summary_params = {
    "provider": "huggingface",
    "credential_name": "HF_CRED",
    "url": "https://api-inference.huggingface.co/models/",
    "model": "facebook/bart-large-cnn",
    "wait_for_model": "true"
}
"""

# using 'database' provider
summary_params = {
    "provider": "database",
    "glevel": "S",
    "numParagraphs": 1,
    "language": "english",
}

# get the summary instance
# Remove proxy if not required
summ = OracleSummary(conn=conn, params=summary_params, proxy=proxy)
summary = summ.get_summary(
    "In the heart of the forest, "
    + "a lone fox ventured out at dusk, seeking a lost treasure. "
    + "With each step, memories flooded back, guiding its path. "
    + "As the moon rose high, illuminating the night, the fox unearthed "
    + "not gold, but a forgotten friendship, worth more than any riches."
)

print(f"Summary generated by OracleSummary: {summary}")
```
