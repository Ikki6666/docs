title: Nimble Extract
---

>[Nimble's Extract API](https://docs.nimbleway.com/nimble-sdk/extract-api) 通过无头浏览器访问特定 URL，并提取渲染后的内容。与用于发现内容的搜索 API 不同，Extract 工具专门处理已知 URL，非常适合那些需要抓取并处理特定网页的 agent 工作流，包括分页、筛选器以及客户端渲染之后的内容。

**关键特性：**

- **URL 提取**：并行提取 1 到 20 个 URL 的渲染内容
- **动态渲染**：支持 JavaScript、懒加载和客户端渲染
- **多种格式**：plain_text（默认）、markdown 或 simplified_html
- **可配置等待时间**：控制页面加载行为，适配加载较慢的内容
- **浏览器驱动**：可选择 vx6、vx8 或 vx10，以满足不同渲染需求
- **生产可用**：原生 async 支持、自动重试和连接池

## 在 agent 中使用

你可以把 Nimble extract 工具与 agent 配合使用，使其具备 URL 内容提取能力。下面是一个使用 LangGraph 的完整示例：

```python
import os
import getpass

from langchain_nimble import NimbleExtractTool
from langchain.agents import create_agent
from langchain.chat_models import init_chat_model

if not os.environ.get("OPENAI_API_KEY"):
    os.environ["OPENAI_API_KEY"] = getpass.getpass("OpenAI API key:\n")
if not os.environ.get("NIMBLE_API_KEY"):
    os.environ["NIMBLE_API_KEY"] = getpass.getpass("Nimble API key:\n")

# Initialize Nimble Extract Tool
extract_tool = NimbleExtractTool(
    parsing_type="markdown"
)

# Create agent with the tool
model = init_chat_model(model="gpt-4o", model_provider="openai", temperature=0)
agent = create_agent(model, [extract_tool])

# Ask the agent to extract and analyze content from LangChain documentation
user_input = "Extract and summarize the key concepts from these LangChain docs: https://python.langchain.com/docs/concepts/retrievers/, https://python.langchain.com/docs/concepts/tools/"

stream = agent.stream_events({"messages": user_input}, version="v3")
for snapshot in stream.values:
    snapshot["messages"][-1].pretty_print()
```

## 高级配置

该工具支持广泛的 URL 提取配置：

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `links` | list[str] | None | 要提取的 URL（1 到 20 个），由 agent 在运行时提供 |
| `parsing_type` | str | "plain_text" | 输出格式："plain_text"、"markdown" 或 "simplified_html" |
| `driver` | str | "vx6" | 浏览器驱动版本："vx6"（快速）、"vx8"（平衡）或 "vx10"（全面） |
| `wait` | int | None | 页面加载等待时间（毫秒，0 到 60000） |
| `render` | bool | True | 启用 JavaScript 渲染 |
| `locale` | str | "en" | 页面 locale 偏好，例如 `"en-US"` |
| `country` | str | "US" | 本地化内容的国家代码，例如 `"US"` |
| `api_key` | str | env var | Nimble API key，默认读取 `NIMBLE_API_KEY` 环境变量 |

## 最佳实践

### Driver 选择

- **vx6**（默认）：适合标准网站的快速提取
- **vx8**：适合中等复杂度网站的平衡性能
- **vx10**：适合 JavaScript 很重的 SPA 和复杂动态内容的完整渲染

### 何时使用等待时间

- **不等待**（`wait=None`）：适合大多数首次渲染较快的现代网站
- **短等待**（`wait=1000-2000`）：适合有懒加载或动态内容的网站
- **更长等待**（`wait=5000+`）：适合加载缓慢的页面或需要完整渲染时间的复杂 SPA

### URL 管理

- **批量提取**：每次调用提供 1 到 20 个 URL 进行并行提取
- **错误处理**：失败的 URL 会在 agent 的错误处理逻辑中被报告
- **内容校验**：agent 在处理前应校验提取出的内容

### 性能优化

- **选择合适格式**：速度优先用 **plain_text**，结构优先用 **markdown**，样式细节优先用 **HTML**
- **调优等待时间**：仅在必要时使用等待时间，以平衡速度与可靠性
- **批量处理同域 URL**：并行提取同一域名下的多个 URL 以提升效率
- **使用 async**：当需要并发提取大量 URL 时，调用 `ainvoke()`
