>[Parallel](https://platform.parallel.ai/) 是一个为 LLM 和 AI 应用构建的实时网页搜索与内容提取平台。

`ParallelExtractTool` 调用 Parallel 的 [Extract API](https://docs.parallel.ai/extract/extract-quickstart)，从网页中返回干净、采用 markdown 格式的内容，并可通过 `search_objective` 提供聚焦式摘录。你可以将它与 [ParallelSearchTool](/oss/integrations/tools/parallel_search) 搭配，构建一个 search → extract 流水线。

<CodeGroup>

    uv add langchain-parallel

### 凭证

前往 [Parallel](https://platform.parallel.ai) 注册并生成 API key。然后在环境中设置 `PARALLEL_API_KEY`：

```python
import getpass
import os

if not os.environ.get("PARALLEL_API_KEY"):
    os.environ["PARALLEL_API_KEY"] = getpass.getpass("Parallel API key:\n")
```

## 实例化

```python
from langchain_parallel import ParallelExtractTool

tool = ParallelExtractTool()

# Or pass an explicit key, override the base URL, or cap per-URL `full_content` size:
# tool = ParallelExtractTool(
#     api_key="your-api-key",
#     base_url="https://api.parallel.ai",
#     max_chars_per_extract=5000,
# )
```

## 调用

### 使用 args 直接调用

```python
result = tool.invoke(
    {"urls": ["https://en.wikipedia.org/wiki/Artificial_intelligence"]}
)

print(result[0]["title"])
print(result[0]["url"])
print(result[0]["content"][:200], "...")
```

单次调用中使用多个 URL：

```python
result = tool.invoke(
    {
        "urls": [
            "https://en.wikipedia.org/wiki/Machine_learning",
            "https://en.wikipedia.org/wiki/Deep_learning",
            "https://en.wikipedia.org/wiki/Natural_language_processing",
        ]
    }
)

for item in result:
    print(item["title"], "—", item["url"])
```

### 使用 ToolCall 调用

使用模型生成的 `ToolCall` 调用时，会返回一个 `ToolMessage`：

```python
model_generated_tool_call = {
    "args": {
        "urls": [
            "https://en.wikipedia.org/wiki/Climate_change",
            "https://en.wikipedia.org/wiki/Renewable_energy",
        ]
    },
    "id": "call_123",
    "name": tool.name,  # "parallel_extract"
    "type": "tool_call",
}

result = tool.invoke(model_generated_tool_call)
```

### 异步用法

```python
async def extract_async():
    return await tool.ainvoke(
        {
            "urls": [
                "https://en.wikipedia.org/wiki/Python_(programming_language)",
                "https://en.wikipedia.org/wiki/JavaScript",
            ]
        }
    )

result = await extract_async()
```

### 聚焦摘录

可以通过 `search_objective`（或 `search_queries`）驱动摘录选择。将 `full_content=False` 时，会跳过完整 markdown 正文，只返回匹配摘录：

```python
result = tool.invoke(
    {
        "urls": ["https://en.wikipedia.org/wiki/Artificial_intelligence"],
        "search_objective": "What are the main applications and ethical concerns of AI?",
        "excerpts": {"max_chars_per_result": 2000},
        "full_content": False,
    }
)
```

### 获取策略与完整内容大小控制

可以分别控制缓存、超时，以及每个 URL 的 `full_content` 大小上限：

```python
result = tool.invoke(
    {
        "urls": ["https://en.wikipedia.org/wiki/Quantum_computing"],
        "fetch_policy": {
            "max_age_seconds": 86400,
            "timeout_seconds": 60,
            "disable_cache_fallback": False,
        },
        "full_content": {"max_chars_per_result": 5000},
    }
)
```

<Note>
    **`full_content` 优先级。** 调用时显式传入的 `FullContentSettings`（或 dict）始终优先于工具级别的 `max_chars_per_extract`。后者只会在你把 `full_content=True` 作为普通布尔值传入时生效。
</Note>

### 针对单个 URL 的错误处理

提取失败的 URL 会以带有 `error_type` 字段的条目返回，因此默认行为是允许部分成功：

```python
result = tool.invoke(
    {
        "urls": [
            "https://en.wikipedia.org/wiki/Artificial_intelligence",
            "https://this-domain-does-not-exist-12345.com/",
        ]
    }
)

for item in result:
    if "error_type" in item:
        print("failed:", item["url"], "—", item["content"])
    else:
        print("ok:", item["url"], f"({len(item['content'])} chars)")
```

### 参数

#### 必填

- `urls`: 要提取的 URL 列表。

#### 可选

- `search_objective`: 用于驱动摘录选择的自然语言描述。
- `search_queries`: 与 `search_objective` 一起使用，或替代它使用的关键词字符串列表。
- `excerpts`: 每条结果的摘录设置。可传入 `ExcerptSettings(max_chars_per_result=…)`（或 dict）来控制单条结果的摘录长度；省略时使用 API 默认值。
- `full_content`: `True` 表示返回完整 markdown 内容（大小由工具级别 `max_chars_per_extract` 决定），`False` 表示跳过完整内容，或使用 `FullContentSettings(max_chars_per_result=…)` 进行细粒度控制。
- `fetch_policy`: 缓存控制，例如 `{"max_age_seconds": 86400, "timeout_seconds": 60}`。
- `max_chars_total`: 所有 URL 合并输出长度的上限。
- `client_model` / `session_id`: 会透传给 Parallel，用于下游归因。

## 链式调用

把工具绑定到任意支持工具调用的聊天模型，再使用 [`create_agent`](/oss/langchain/agents) 驱动 agent：

```python
from langchain.agents import create_agent
from langchain.chat_models import init_chat_model

llm = init_chat_model(model="claude-opus-4-8")
agent = create_agent(model=llm, tools=[tool])

agent.invoke({"messages": [("human", "Summarize https://en.wikipedia.org/wiki/Quantum_computing")]})
```

### Search → extract

把 `ParallelSearchTool` 和 `ParallelExtractTool` 一起交给同一个 agent。模型会先用 search 查找 URL，再用 extract 深入它选中的内容。

```python
from langchain_parallel import ParallelSearchTool

search = ParallelSearchTool()
extract = ParallelExtractTool()
agent = create_agent(model=llm, tools=[search, extract])

agent.invoke({
    "messages": [
        ("human", "Find a recent peer-reviewed paper on net-energy-gain fusion and summarize it."),
    ]
})
```

```python
[
    {
        "url": "https://example.com/article",
        "title": "Article Title",
        "content": "# Article Title\n\nMain content formatted as markdown...",
        "publish_date": "2026-01-15",
        "excerpts": ["...", "..."],  # if excerpts/search_objective requested
    },
    # Failed extractions:
    {
        "url": "https://failed-site.com",
        "title": None,
        "content": "Error: 404 Not Found",
        "error_type": "http_error",
    },
]
```
