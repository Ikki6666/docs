> [Google Calendar](https://workspace.google.com/intl/en-419/products/calendar/) 是 Google Workspace 的产品之一，允许用户组织自己的日程和事件。它是一个基于云的日历，允许用户创建、编辑和删除事件，也支持与他人共享日历。

## 概览

本笔记本将帮助你开始使用 Google Calendar Toolkit。该 toolkit 通过 Google Calendar API 与日历交互，并执行多种操作。你可以：

- 创建事件。
- 搜索事件。
- 更新事件。
- 在不同日历之间移动事件。
- 删除事件。
- 列出事件。

## 设置

要使用该 toolkit，你需要：

1. 拥有一个可访问 Google Calendar 的 Google 账户。
2. 按照 [Google Calendar API docs](https://developers.google.com/calendar/api/quickstart/python#authorize_credentials_for_a_desktop_application) 中的说明设置凭证。下载好 `credentials.json` 文件后，就可以开始使用 Google Calendar API。

要启用对单个工具的自动 tracing，请设置你的 [LangSmith](/langsmith/observability) API key：

```python
os.environ["LANGSMITH_TRACING"] = "true"
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
```

### 安装

该 toolkit 位于 [langchain-google](https://github.com/langchain-ai/langchain-google) 仓库中的 `langchain-google-community` 包内。我们需要使用 `calendar` extra：

```python
pip install -qU langchain-google-community\[calendar\]
```

## 实例化

默认情况下，该 toolkit 会读取本地的 `credentials.json` 文件。你也可以手动提供一个 `Credentials` 对象。

```python
from langchain_google_community import CalendarToolkit

toolkit = CalendarToolkit()
```

### 自定义认证

在底层，会通过以下方法创建一个 `googleapi` resource。为了获得更精细的认证控制，你也可以手动构建 `googleapi` resource。

```python
from langchain_google_community import CalendarToolkit
from langchain_google_community.calendar.utils import (
    build_resource_service,
    get_google_credentials,
)

# Can review scopes here: https://developers.google.com/calendar/api/auth
# For instance, readonly scope is https://www.googleapis.com/auth/calendar.readonly
credentials = get_google_credentials(
    token_file="token.json",
    scopes=["https://www.googleapis.com/auth/calendar"],
    client_secrets_file="credentials.json",
)

api_resource = build_resource_service(credentials=credentials)
toolkit = CalendarToolkit(api_resource=api_resource)
```

## 调用

### [使用 args 直接调用](/oss/langchain/tools#create-tools)

你可以通过字典形式传入所需参数，直接调用工具。下面示例展示了如何使用 `CalendarCreateEvent` 工具创建新事件。

```python
from langchain_google_community.calendar.create_event import CalendarCreateEvent

tool = CalendarCreateEvent()
tool.invoke(
    {
        "summary": "Calculus exam",
        "start_datetime": "2025-07-11 11:00:00",
        "end_datetime": "2025-07-11 13:00:00",
        "timezone": "America/Mexico_City",
        "location": "UAM Cuajimalpa",
        "description": "Event created from the LangChain toolkit",
        "reminders": [{"method": "popup", "minutes": 60}],
        "conference_data": True,
        "color_id": "5",
    }
)
```

```text

```

## 在 agent 中使用

下面展示如何把该 toolkit 集成到 [agent](/oss/langchain/agents) 中。

我们需要一个 LLM 或聊天模型：

<ChatModelTabs customVarName="llm" />

```python
# | output: false
# | echo: false

from langchain_openai import ChatOpenAI

llm = ChatOpenAI(model="gpt-5.4-mini", temperature=0)
```

```python
from langchain.agents import create_agent


agent_executor = create_agent(llm, tools)
```

```python
example_query = "Create a green event for this afternoon to go for a 30-minute run."

stream = agent_executor.stream_events(
    {"messages": [("user", example_query)]},
    version="v3",
)
for snapshot in stream.values:
    snapshot["messages"][-1].pretty_print()
```
