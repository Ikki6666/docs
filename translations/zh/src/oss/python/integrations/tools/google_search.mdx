本 notebook 介绍如何使用 google search 组件。

首先，你需要设置正确的 API key 和环境变量。要完成配置，请在 Google Cloud 凭证控制台（[console.cloud.google.com/apis/credentials](https://console.cloud.google.com/apis/credentials)）中创建 `GOOGLE_API_KEY`，并通过 Programmable Search Engine（[programmablesearchengine.google.com/controlpanel/create](https://programmablesearchengine.google.com/controlpanel/create)）创建 `GOOGLE_CSE_ID`。接下来，建议按照[程序化 Google Search 的说明](https://stackoverflow.com/questions/37083058/programmatically-searching-google-in-python-using-custom-search)进行配置。

然后我们需要设置一些环境变量。

```python
pip install -qU  langchain-google-community
```

```python
import os

os.environ["GOOGLE_CSE_ID"] = ""
os.environ["GOOGLE_API_KEY"] = ""
```

```python
from langchain.tools import tool
from langchain_google_community import GoogleSearchAPIWrapper

search = GoogleSearchAPIWrapper()


@tool
def google_search(query: str) -> str:
    """Search Google for recent results."""
    return search.run(query)
```

```python
google_search.invoke("Obama's first name?")
```

## 结果数量

你可以使用 `k` 参数设置结果数量。

```python
search = GoogleSearchAPIWrapper(k=1)


@tool
def im_feeling_lucky(query: str) -> str:
    """Search Google and return the first result."""
    return search.run(query)
```

```python
im_feeling_lucky.invoke("python")
```

'The official home of the Python Programming Language.'

## Metadata 结果

通过 GoogleSearch 运行查询，并返回 snippet、title 和 link metadata。

- Snippet: 结果的描述。
- Title: 结果的标题。
- Link: 结果的链接。

```python
search = GoogleSearchAPIWrapper()


@tool
def google_search_snippets(query: str) -> str:
    """Search Google for recent results."""
    return search.results(query, 5)
```
