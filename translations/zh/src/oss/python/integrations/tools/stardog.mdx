>[Stardog](https://www.stardog.com) 是一个企业知识图谱平台，帮助组织统一、查询和分析其数据。  
> 该集成包提供了用于与 Stardog Voicebox 交互的 LangChain tools 和 runnables。Stardog Voicebox 是一个自然语言问答 agent，可以从你的企业数据中提供无幻觉的洞察。

## 概览

Stardog LangChain 集成包为使用 Stardog Voicebox 提供了以下工具：
- `VoiceboxAskTool`：提问并获取自然语言回答
- `VoiceboxGenerateQueryTool`：从自然语言生成 SPARQL 查询
- `VoiceboxSettingsTool`：获取 Voicebox 应用配置

所有工具都同时支持同步和异步执行模式，因此适合多种应用架构。

完整细节请参阅 [GitHub repository](https://github.com/stardog-union/stardog-langchain)。

## 设置

### 安装

```bash
pip install langchain-stardog
```

### 前置条件

- 一个 [Stardog Cloud](https://cloud.stardog.com) 账户
- 一个已配置好数据的 Voicebox 应用
- 一个 Voicebox API token

### 获取 API token

1. 登录 [Stardog Cloud](https://cloud.stardog.com)。
2. 点击个人头像并选择 **Manage API Keys**。
3. 创建一个新应用并生成一个 secret。
4. 复制 API token，并妥善保管。
5. 更多细节请参阅 Stardog Voicebox API access。

### 凭据

把 API token 设置为环境变量：

```python
import getpass
import os

if not os.environ.get("SD_VOICEBOX_API_TOKEN"):
    os.environ["SD_VOICEBOX_API_TOKEN"] = getpass.getpass("Enter your Voicebox API token: ")
```

可选环境变量：

```python
os.environ["SD_VOICEBOX_CLIENT_ID"] = "my-app"  # Client identifier (default: VBX-LANGCHAIN)
os.environ["SD_CLOUD_ENDPOINT"] = "https://cloud.stardog.com/api"  # Custom endpoint (optional)
```

## 实例化与示例

### VoiceboxAskTool

对与你的 API token 所配置知识图谱相关的内容提出自然语言问题，并获得无幻觉回答。

```python
from langchain_stardog.voicebox import VoiceboxAskTool

# Tools automatically load credentials from environment variables
ask_tool = VoiceboxAskTool()

# Ask a question
result = ask_tool.invoke({"question": "What are all flights from San Francisco to New York?"})
print(result)
# Returns: Natural language answer
```

### VoiceboxSettingsTool

获取 Voicebox 应用配置和元数据。

```python
from langchain_stardog.voicebox import VoiceboxSettingsTool

settings_tool = VoiceboxSettingsTool()

# Get application settings
settings = settings_tool.invoke({})
print(settings)
# Returns: Configuration details like data sources, schema info, and capabilities
```

### VoiceboxGenerateQueryTool

根据自然语言问题生成 SPARQL 查询，但不执行它们。

```python
from langchain_stardog.voicebox import VoiceboxGenerateQueryTool

query_tool = VoiceboxGenerateQueryTool()

# Generate a SPARQL query
query = query_tool.invoke({"question": "Which flights are delayed by more than 30 minutes?"})
print(query)
# Returns: Generated SPARQL query without executing it
```

不同用法和 runnables 的更多示例，请参阅 [Examples](https://github.com/stardog-union/stardog-langchain?tab=readme-ov-file#examples) 一节。

## 类参考

更多细节请参阅 [Class Reference](https://github.com/stardog-union/stardog-langchain?tab=readme-ov-file#class-reference)

**Available classes:**

- `VoiceboxAskTool`：提问并获取回答
- `VoiceboxSettingsTool`：获取应用配置
- `VoiceboxGenerateQueryTool`：生成 SPARQL 查询
- `VoiceboxAskRunnable`：用于自然语言提问的 Runnable
- `VoiceboxSettingsRunnable`：配置获取 Runnable
- `VoiceboxGenerateQueryRunnable`：查询生成 Runnable
- `VoiceboxClient`：Voicebox API 的核心 client
