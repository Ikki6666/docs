只需两行代码，就能让你的 AI agent 具备浏览网站、搜索 Google 和 Amazon 的能力。

`langchain-scraperapi` 包基于 [ScraperAPI](https://www.scraperapi.com/) 服务，提供三个开箱即用的 LangChain 工具：

| Tool class | Use it to |
|------------|------------------|
| `ScraperAPITool` | 抓取任意网页的 HTML/text/markdown |
| `ScraperAPIGoogleSearchTool` | 获取结构化的 Google Search SERP 数据 |
| `ScraperAPIAmazonSearchTool` | 获取结构化的 Amazon 商品搜索数据 |

## 概览

| :--- | :---: | :---: | :---: |

## 设置

安装 `langchain-scraperapi` 包：

```python
pip install -qU langchain-scraperapi
```

### 凭证

在 [ScraperAPI](https://www.scraperapi.com/) 创建账户并获取 API key：

```python
import os

if not os.environ.get("SCRAPERAPI_API_KEY"):
    os.environ["SCRAPERAPI_API_KEY"] = "your-api-key"
```

## 实例化

```python
from langchain_scraperapi.tools import ScraperAPITool

tool = ScraperAPITool()
```

## 调用

### 使用 args 直接调用

```python
output = tool.invoke(
    {
        "url": "https://langchain.com",
        "output_format": "markdown",
        "render": True,
    }
)
print(output)
```

## 特性

### 1. `ScraperAPITool` — 浏览任意网站

调用原始 ScraperAPI endpoint，并获取 HTML、渲染后的 DOM、文本或 markdown。

**调用参数：**

* **`url`** **(required)** – 目标页面 URL
* **可选（与 ScraperAPI query params 对应）：**
  * `output_format`: `"text"` | `"markdown"`（默认返回原始 HTML）
  * `country_code`: 例如 `"us"`、`"de"`
  * `device_type`: `"desktop"` | `"mobile"`
  * `premium`: `bool` – 使用 premium proxies
  * `render`: `bool` – 返回 HTML 前先执行 JS
  * `keep_headers`: `bool` – 包含响应 headers

如需查看完整修饰参数集合，请参阅 [ScraperAPI request-customisation docs](https://docs.scraperapi.com/python/making-requests/customizing-requests)。

```python
from langchain_scraperapi.tools import ScraperAPITool

tool = ScraperAPITool()

html_text = tool.invoke(
    {
        "url": "https://langchain.com",
        "output_format": "markdown",
        "render": True,
    }
)
print(html_text[:300], "…")
```

### 2. `ScraperAPIGoogleSearchTool` — 结构化 Google 搜索

通过 `/structured/google/search` 获取结构化 SERP 数据。

**调用参数：**

* **`query`** **(required)** – 自然语言搜索字符串
* **可选：** `country_code`, `tld`, `uule`, `hl`, `gl`, `ie`, `oe`, `start`, `num`
* `output_format`: `"json"`（默认）或 `"csv"`

```python
from langchain_scraperapi.tools import ScraperAPIGoogleSearchTool

google_search = ScraperAPIGoogleSearchTool()

results = google_search.invoke(
    {
        "query": "what is langchain",
        "num": 20,
        "output_format": "json",
    }
)
print(results)
```

### 3. `ScraperAPIAmazonSearchTool` — 结构化 Amazon 搜索

通过 `/structured/amazon/search` 获取结构化商品结果。

**调用参数：**

* **`query`** **(required)** – 商品搜索词
* **可选：** `country_code`, `tld`, `page`
* `output_format`: `"json"`（默认）或 `"csv"`

```python
from langchain_scraperapi.tools import ScraperAPIAmazonSearchTool

amazon_search = ScraperAPIAmazonSearchTool()

products = amazon_search.invoke(
    {
        "query": "noise cancelling headphones",
        "tld": "co.uk",
        "page": 2,
    }
)
print(products)
```

## 在 agent 中使用

下面是一个在 AI agent 中使用这些工具的示例。`ScraperAPITool` 让 AI 具备浏览任意网站、总结文章，以及通过点击链接在页面间导航的能力。

```python
pip install -qU langchain-openai langchain
```

```python
import os

from langchain.agents import create_agent
from langchain_openai import ChatOpenAI
from langchain_scraperapi.tools import ScraperAPITool


os.environ["SCRAPERAPI_API_KEY"] = "your-api-key"
os.environ["OPENAI_API_KEY"] = "your-api-key"

tools = [ScraperAPITool(output_format="markdown")]
model = ChatOpenAI(model="gpt-5.5", temperature=0)

agent = create_agent(
    model=model,
    tools=tools,
    system_prompt="You are a helpful assistant that can browse websites for users. When asked to browse a website or a link, do so with the ScraperAPITool, then provide information based on the website based on the user's needs.",
)

response = agent.invoke(
    {"messages": [{"role": "user", "content": "can you browse hacker news and summarize the first website"}]}
)
print(response["messages"][-1].content)
```
