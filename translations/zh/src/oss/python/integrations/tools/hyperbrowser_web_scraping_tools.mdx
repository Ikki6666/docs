[Hyperbrowser](https://hyperbrowser.ai) 是一个用于运行和扩展无头浏览器的平台。它可以帮助你大规模启动和管理浏览器会话，并为各种网页抓取需求提供易用方案，例如抓取单个页面或爬取整个网站。

主要特性：

- 即时扩展能力，几秒内即可启动数百个浏览器会话，无需处理基础设施问题
- 简单集成，可与 Puppeteer 和 Playwright 等常用工具无缝协作
- 强大的 API，易于抓取或爬取任意网站，并支持更多场景
- 绕过反机器人措施，内置隐身模式、广告拦截、自动 CAPTCHA 求解和轮换代理

本指南简要介绍如何开始使用 Hyperbrowser 网页工具。

如需更多信息，请访问 [Hyperbrowser 网站](https://hyperbrowser.ai)。如果想查看文档，请访问 [Hyperbrowser docs](https://docs.hyperbrowser.ai)。

## 关键能力

### Scrape

Hyperbrowser 提供强大的抓取能力，可从任意网页提取数据。抓取工具可以把网页内容转换为 markdown 或 HTML 等结构化格式，便于后续处理和分析。

### Crawl

爬取功能可以自动遍历网站中的多个页面。你可以设置页面数量限制等参数，控制爬虫探索网站的范围，并收集其访问页面中的数据。

### Extract

Hyperbrowser 的提取能力使用 AI 按照你定义的 schema 从网页中提取特定信息。这让你可以把非结构化网页内容转换为符合精确需求的结构化数据。

## 设置

要访问 Hyperbrowser 网页工具，需要安装 `langchain-hyperbrowser` 集成包，并创建 Hyperbrowser 账户获取 API 密钥。

### 凭证

前往 [Hyperbrowser](https://app.hyperbrowser.ai/) 注册并生成 API 密钥。完成后，设置 `HYPERBROWSER_API_KEY` 环境变量：

```bash
export HYPERBROWSER_API_KEY=<your-api-key>
```

### 安装

安装 **langchain-hyperbrowser**。

```python
pip install -qU langchain-hyperbrowser
```

## 实例化

### Crawl tool

`HyperbrowserCrawlTool` 是一个强大的工具，可以从给定 URL 开始爬取整个网站。它支持可配置的页面数量限制和抓取选项。

```python
from langchain_hyperbrowser import HyperbrowserCrawlTool
tool = HyperbrowserCrawlTool()
```

### Scrape tool

`HyperbrowserScrapeTool` 可以抓取网页内容。它支持 markdown 和 HTML 两种输出格式，以及元数据提取。

```python
from langchain_hyperbrowser import HyperbrowserScrapeTool
tool = HyperbrowserScrapeTool()
```

### Extract tool

`HyperbrowserExtractTool` 是一个强大的工具，它使用 AI 从网页中提取结构化数据。它可以根据预定义 schema 提取信息。

```python
from langchain_hyperbrowser import HyperbrowserExtractTool
tool = HyperbrowserExtractTool()
```

### 异步用法

所有工具都支持异步使用：

```python
from typing import List

from langchain_hyperbrowser import (
    HyperbrowserCrawlTool,
    HyperbrowserExtractTool,
    HyperbrowserScrapeTool,
)
from pydantic import BaseModel


class ExtractionSchema(BaseModel):
    popular_library_name: List[str]


async def web_operations():
    # Crawl
    crawl_tool = HyperbrowserCrawlTool()
    crawl_result = await crawl_tool.arun(
        {
            "url": "https://example.com",
            "max_pages": 5,
            "scrape_options": {"formats": ["markdown"]},
        }
    )

    # Scrape
    scrape_tool = HyperbrowserScrapeTool()
    scrape_result = await scrape_tool.arun(
        {"url": "https://example.com", "scrape_options": {"formats": ["markdown"]}}
    )

    # Extract
    extract_tool = HyperbrowserExtractTool()
    extract_result = await extract_tool.arun(
        {
            "url": "https://npmjs.com",
            "schema": ExtractionSchema,
        }
    )

    return crawl_result, scrape_result, extract_result


results = await web_operations()
print(results)
```

## 在 agent 中使用

下面展示如何在 agent 中使用任意一个网页工具：

```python
from langchain_hyperbrowser import HyperbrowserCrawlTool
from langchain_openai import ChatOpenAI
from langchain.agents import create_agent


# 初始化 crawl 工具
crawl_tool = HyperbrowserCrawlTool()

# 创建带 crawl 工具的 agent
model = ChatOpenAI(temperature=0)

agent = create_agent(model, [crawl_tool])
user_input = "Crawl https://example.com and get content from up to 5 pages"
stream = agent.stream_events({"messages": user_input}, version="v3")
for snapshot in stream.values:
    snapshot["messages"][-1].pretty_print()
```

## 配置选项

### 通用选项

所有工具都支持以下基础配置项：

- `url`：要处理的 URL
- `session_options`：浏览器会话配置
  - `use_proxy`：是否使用代理
  - `solve_captchas`：是否自动求解 CAPTCHA
  - `accept_cookies`：是否接受 cookies

### 各工具专属选项

#### Crawl tool

- `max_pages`：要爬取的最大页面数
- `scrape_options`：抓取每个页面时的选项
  - `formats`：输出格式列表（markdown、html）

#### Scrape tool

- `scrape_options`：抓取页面时的选项
  - `formats`：输出格式列表（markdown、html）

#### Extract tool

- `schema`：定义提取结构的 Pydantic model
- `extraction_prompt`：用于提取的自然语言提示
