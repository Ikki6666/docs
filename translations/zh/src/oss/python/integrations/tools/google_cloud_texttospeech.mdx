>[Google Cloud Text-to-Speech](https://cloud.google.com/text-to-speech) 让开发者能够使用 100+ 种声音合成自然语音，这些声音覆盖多种语言和变体。它结合了 DeepMind 在 WaveNet 上的突破性研究与 Google 强大的神经网络，以尽可能提供最高保真度的语音输出。
>
>它支持多种语言，包括英语、德语、波兰语、西班牙语、意大利语、法语、葡萄牙语和印地语。

本 notebook 展示如何与 `Google Cloud Text-to-Speech API` 交互，从而实现语音合成能力。

首先，你需要设置一个 Google Cloud project。可以参考 [Google Cloud Text-to-Speech setup instructions](https://cloud.google.com/text-to-speech/docs/before-you-begin)。
