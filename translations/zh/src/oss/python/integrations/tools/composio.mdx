[Composio](https://composio.dev) 是一个集成平台，可通过统一 API 访问 GitHub、Slack、Notion 等常用应用中的 500 多种工具。它使 AI agent 能够与外部服务交互，并处理认证、权限以及事件驱动工作流。

## 概览

### 集成详情

### 工具特性

- **访问 500+ 工具**：为 GitHub、Slack、Gmail、Jira、Notion 等提供预构建集成
- **认证管理**：处理 OAuth 流程、API 密钥和认证状态
- **事件驱动工作流**：基于外部事件触发 agent，如新的 Slack 消息、GitHub issue 等
- **细粒度权限控制**：按用户控制工具访问和数据暴露
- **自定义工具支持**：添加私有 API 和内部工具

## 实例化

使用 LangChain provider 初始化 Composio，并从特定 toolkit 中获取工具。每个 toolkit 表示一个服务，例如 GitHub、Slack，其中包含多个工具，也就是你可以执行的操作。

```python Initialize Composio icon="robot"
from composio import Composio
from composio_langchain import LangchainProvider

# 使用 LangChain provider 初始化 Composio
composio = Composio(provider=LangchainProvider())

# 从特定 toolkit 获取工具
# 你可以指定一个或多个 toolkit
tools = composio.tools.get(
    user_id="default",
    toolkits=["GITHUB"]
)

print(f"Loaded {len(tools)} tools from GitHub toolkit")
```

## 调用

### 从多个 toolkit 获取工具

你可以一次性加载多个服务的工具：

```python
# 从多个 toolkit 获取工具
tools = composio.tools.get(
    user_id="default",
    toolkits=["GITHUB", "SLACK", "GMAIL"]
)
```

### 获取特定工具

除了整个 toolkit 之外，你也可以按名称加载特定工具：

```python
# 按名称获取特定工具
tools = composio.tools.get(
    user_id="default",
    tools=["GITHUB_CREATE_ISSUE", "SLACK_SEND_MESSAGE"]
)
```

### 用户专属工具

Composio 支持多用户场景，并带有按用户区分的认证能力：

```python
# 为特定用户获取工具
# 该用户必须先完成账户认证
tools = composio.tools.get(
    user_id="user_123",
    toolkits=["GITHUB"]
)
```

```python Agent with Composio tools icon="robot"
from composio import Composio
from composio_langchain import LangchainProvider
from langchain import hub
from langchain.agents import AgentExecutor, create_openai_functions_agent

# 拉取提示模板
prompt = hub.pull("hwchase17/openai-functions-agent")

# 初始化 Composio
composio = Composio(provider=LangchainProvider())

# 获取 GitHub 工具
tools = composio.tools.get(user_id="default", toolkits=["GITHUB"])

# 定义任务
task = "Star a repo composiohq/composio on GitHub"

# 创建 agent
agent = create_openai_functions_agent(llm, tools, prompt)
agent_executor = AgentExecutor(agent=agent, tools=tools, verbose=True)

# 通过 agent_executor 执行
agent_executor.invoke({"input": task})
```

### 事件驱动工作流

Composio 支持基于外部事件触发 agent。当连接的应用中发生事件时，例如新的 GitHub commit 或 Slack 消息，trigger 会自动把结构化负载发送到你的应用。

#### 创建 trigger

先为你想监控的事件创建一个 trigger：

```python
from composio import Composio

composio = Composio(api_key="your_api_key")
user_id = "user_123"

# 查看该 trigger 需要哪些配置
trigger_type = composio.triggers.get_type("GITHUB_COMMIT_EVENT")
print(trigger_type.config)

# 使用必需配置创建 trigger
trigger = composio.triggers.create(
    slug="GITHUB_COMMIT_EVENT",
    user_id=user_id,
    trigger_config={
        "owner": "composiohq",
        "repo": "composio"
    }
)

print(f"Trigger created: {trigger.trigger_id}")
```

#### 订阅 trigger（开发环境）

在本地开发和原型阶段，你可以直接订阅 trigger：

```python
from composio import Composio

composio = Composio(api_key="your_api_key")

# 订阅 trigger 事件
subscription = composio.triggers.subscribe()

# 定义事件处理器
@subscription.handle(trigger_id="your_trigger_id")
def handle_github_commit(data):
    print(f"New commit detected: {data}")
    # 使用你的 agent 处理该事件
    # ... invoke your agent with the task

# Note: For production, use webhooks instead
```

#### Webhooks（生产环境）

在生产环境中，请在 [Composio dashboard](https://platform.composio.dev/settings/events) 中配置 webhook：

```python
from fastapi import FastAPI, Request
import json

app = FastAPI()

@app.post("/webhook")
async def webhook_handler(request: Request):
    # 获取 webhook payload
    payload = await request.json()

    print("Received trigger event:")
    print(json.dumps(payload, indent=2))

    # 使用你的 agent 处理该事件
    if payload.get("triggerSlug") == "GITHUB_COMMIT_EVENT":
        commit_data = payload.get("payload")
        # ... invoke your agent with commit_data

    return {"status": "success"}
```

更多细节请参阅 [Composio Triggers documentation](https://docs.composio.dev/docs/using-triggers)

## 认证设置

在使用需要认证的工具之前，用户需要先连接他们的账户：

```python
from composio import Composio

composio = Composio()

# 获取用户的认证 URL
auth_connection = composio.integrations.create(
    user_id="user_123",
    integration="github"
)

print(f"Authenticate at: {auth_connection.redirect_url}")

# 完成认证后，用户的已连接账户就会可用
# 工具会使用他们自己的凭证
```

## 多用户场景

对于多用户应用：

```python
# 每个用户都认证自己的账户
tools_user_1 = composio.tools.get(user_id="user_1", toolkits=["GITHUB"])
tools_user_2 = composio.tools.get(user_id="user_2", toolkits=["GITHUB"])

# 工具会分别使用对应用户的凭证
# User 1 的 agent 会操作 User 1 的 GitHub 账户
agent_1 = create_agent(llm, tools_user_1)

# User 2 的 agent 会操作 User 2 的 GitHub 账户
agent_2 = create_agent(llm, tools_user_2)
```

## 高级特性

### 自定义工具

Composio 允许你创建自定义工具，并与内置工具一起使用。支持两种类型：

#### 独立工具

不需要认证的简单工具：

```python
from pydantic import BaseModel, Field
from composio import Composio

composio = Composio()

class AddTwoNumbersInput(BaseModel):
    a: int = Field(description="The first number to add")
    b: int = Field(description="The second number to add")

# 函数名会被用作 tool slug
@composio.tools.custom_tool
def add_two_numbers(request: AddTwoNumbersInput) -> int:
    """Add two numbers."""
    return request.a + request.b

# 与 agent 一起使用
tools = composio.tools.get(user_id="default", toolkits=["GITHUB"])
tools.append(add_two_numbers)
```

#### 基于 toolkit 的工具

需要认证并且可以使用 toolkit 凭证的工具：

```python
from composio.types import ExecuteRequestFn

class GetIssueInfoInput(BaseModel):
    issue_number: int = Field(
        ..., description="The number of the issue to get information about"
    )

@composio.tools.custom_tool(toolkit="github")
def get_issue_info(
    request: GetIssueInfoInput,
    execute_request: ExecuteRequestFn,
    auth_credentials: dict,
) -> dict:
    """Get information about a GitHub issue."""
    response = execute_request(
        endpoint=f"/repos/composiohq/composio/issues/{request.issue_number}",
        method="GET",
        parameters=[
            {
                "name": "Accept",
                "value": "application/vnd.github.v3+json",
                "type": "header",
            },
            {
                "name": "Authorization",
                "value": f"Bearer {auth_credentials['access_token']}",
                "type": "header",
            },
        ],
    )
    return {"data": response.data}
```

执行自定义工具：

```python
response = composio.tools.execute(
    user_id="default",
    slug="get_issue_info",  # Use function name as slug
    arguments={"issue_number": 1},
)
```

更多细节请参阅 [Composio Custom Tools documentation](https://docs.composio.dev/docs/custom-tools)

### 细粒度权限

控制工具可以执行哪些操作：

```python
# 获取带特定权限的工具
tools = composio.tools.get(
    user_id="default",
    toolkits=["GITHUB"],
    # 限制为只读操作
    permissions=["read"]
)
```
