[Stagehand](https://docs.stagehand.dev/v4/first-steps/introduction) 是来自 [Browserbase](/oss/integrations/providers/browserbase) 的面向浏览器 agent 的开源 SDK。`StagehandMiddleware` 将其 `run`、`snapshot` 和 `screenshot` 工具添加到 LangChain 或 Deep Agents agent 中。将配置好的 Stagehand 客户端传给该 middleware：无需 MCP server、自定义工具定义或浏览器系统提示词。

有关用例、浏览器作用域和沙箱测试设置，请参阅[浏览器使用](/oss/deepagents/browser-use)。

<Note>
该 middleware 在 [langchain-browserbase#1](https://github.com/langchain-ai/langchain-browserbase/pull/1) 中提出，尚未发布到 PyPI。本页使用该源码修订版本。它要求 Python 3.11 或更高版本、LangChain 1.4.7 或更高版本，以及 Stagehand 4.3.0 或更高版本。
</Note>

## 工具

| 工具 | 说明 |
|------|-------------|
| `run` | 对当前活动页面执行操作。可以传入 `code`（使用 Playwright 风格 `page`、`context` 和 `browser` 对象的 JavaScript），或传入 `actions`（一批基于 snapshot ID 的 `click`、`hover`、`fill`、`type`、`press` 和 `select` 操作）。 |
| `snapshot` | 捕获活动页面的可访问性树，并分配 `run` 操作用于引用的方括号 ID。每次调用都会替换之前的 ID。 |
| `screenshot` | 返回模型可见的 PNG 或 JPEG 图像。接受可选的 `fullPage`、`type` 和 `quality` 参数。仅在 JPEG 时使用 `quality`。 |

`run` 的两种输入形式如下：

<CodeGroup>
```json JavaScript
{ "code": "await page.goto('https://example.com'); return await page.title();" }
```

```json Snapshot actions
{ "actions": [{ "op": "click", "id": "1-42" }] }
```
</CodeGroup>

请使用最新 `snapshot` 响应中的 ID，而不是示例中的 `1-42`。在导航后或 ID 失效时重新截取 snapshot。

## 设置

从源码安装 middleware，以及 Deep Agents 和一个模型集成：

```bash
pip install "langchain-stagehand @ git+https://github.com/langchain-ai/langchain-browserbase.git@40d1ae1d5e0543fe1e49b13d0887df40acf1c4c8" deepagents langchain-openai
```

设置模型提供商凭据和你的 [Browserbase API key](https://www.browserbase.com)：

```bash
export OPENAI_API_KEY="your-openai-api-key"
export BROWSERBASE_API_KEY="your-browserbase-api-key"
```

## 与 deep agent 一起使用

创建一个 Browserbase 浏览器，附加 Stagehand 客户端，并将 middleware 传给 @[`create_deep_agent`]：

```python
import asyncio
import os

from deepagents import create_deep_agent
from langchain_stagehand import StagehandMiddleware
from stagehand import Stagehand, browserbase


async def main():
    browser = await browserbase.launch(api_key=os.environ["BROWSERBASE_API_KEY"])
    try:
        stagehand = await Stagehand.create(browser=browser)
        agent = create_deep_agent(
            model="openai:gpt-5.5-2026-04-23",
            middleware=[StagehandMiddleware(stagehand=stagehand)],
        )
        result = await agent.ainvoke({
            "messages": [{
                "role": "user",
                "content": "Open news.ycombinator.com, read the top three stories, and summarize each one.",
            }]
        })
        print(result["messages"][-1].content_blocks)
    finally:
        await browser.close()


asyncio.run(main())
```

使用 `ainvoke` 或 `astream`：浏览器工具是异步的。Middleware 会在工具描述中包含浏览器使用指引，并保持你的系统提示词不变。这些工具使用 Stagehand 的 Playwright 风格外观，不需要单独的 Stagehand 模型。

### 与 LangChain 一起使用

保留相同的浏览器设置，并将 `create_deep_agent` 替换为 @[`create_agent`]：

```python
from langchain.agents import create_agent

agent = create_agent(
    model="openai:gpt-5.5-2026-04-23",
    middleware=[StagehandMiddleware(stagehand=stagehand)],
)
```

## 选择浏览器

你的应用直接配置浏览器和 Stagehand 客户端，而不是通过 MCP server 环境变量。

- **Browserbase**：如上例所示使用 `browserbase.launch(api_key=...)`。浏览器在远程运行，因此无法访问你机器上或沙箱中的 `localhost`。
- **本地 Chrome**：使用 `local_browser.launch(headless=True)` 在无可见窗口的情况下运行。Chrome 与应用共享 `localhost`，并且需要安装 Google Chrome 或 Chromium 浏览器。

要使用本地 Chrome，请将浏览器启动和客户端设置替换为：

```python
from stagehand import Stagehand, local_browser

browser = await local_browser.launch(headless=True)
stagehand = await Stagehand.create(browser=browser)
middleware = StagehandMiddleware(stagehand=stagehand)
```

保留相同的应用级 `try`/`finally` 清理逻辑。所有 Stagehand 客户端设置仍可通过 `Stagehand.create(...)` 使用。

要在使用 LangSmith 沙箱后端时让 Chrome 与应用一同运行，请参阅[在 LangSmith 沙箱中测试带 Chrome 的应用](/oss/deepagents/browser-use#test-an-app-with-chrome-in-a-langsmith-sandbox)。

## 管理浏览器生命周期

你的应用拥有客户端和浏览器。Middleware 会在多次运行之间复用传入的客户端，不会关闭或重新创建它。保持浏览器打开以保留标签页和登录状态，完成后调用 `await browser.close()`。如果浏览器断开连接，请提供新的已配置客户端。

你需要选择是在一个 thread 内复用登录状态，还是在一个已认证用户的多个对话之间复用。Middleware 不实现作用域选择、会话存储或浏览器 checkpoint。请为并发 agent 提供独立的客户端和浏览器。有关权衡和用户隔离要求，请参阅[选择浏览器作用域](/oss/deepagents/browser-use#choose-a-browser-scope)。

`screenshot` 工具会直接将图像返回给模型。`run` 代码通过 `path` 保存的截图会写入当前工作目录，而不是 Deep Agents 后端。目前尚不支持将产物保存到后端。

## 在执行操作前要求批准

`snapshot` 和 `screenshot` 只读取页面。`run` 会导航、点击、输入并提交表单。要在每次 `run` 调用执行前进行审查，请保留上面的浏览器设置，并为 agent 添加 `interrupt_on` 和 checkpointer：

```python
from langgraph.checkpoint.memory import InMemorySaver

agent = create_deep_agent(
    model="openai:gpt-5.5-2026-04-23",
    middleware=[StagehandMiddleware(stagehand=stagehand)],
    interrupt_on={"run": True},
    checkpointer=InMemorySaver(),
)
config = {"configurable": {"thread_id": "browser-1"}}
```

将 `config` 传给 `ainvoke`，并在审查和恢复 interrupt 期间保持浏览器打开。每次 interrupt 都会列出待处理的 `run` 参数。有关批准和恢复循环，请参阅[人在回路中](/oss/deepagents/human-in-the-loop)。

## 安全

`run` 在 Stagehand 浏览器扩展内执行模型编写的 JavaScript。该代码可以使用会话已登录的任何账户，并访问浏览器能访问的任何站点。请将 Browserbase 用作不受信任任务的隔离边界。Playwright 风格的 API 不是通用安全沙箱。请参阅 Stagehand 的[安全边界](https://docs.stagehand.dev/v4/integrations/agent-frameworks/overview#security-boundary)。

将页面内容视为不受信任的输入。将凭据保留在应用环境中，而不是提示词或浏览器工具输入中。不要在不相关的用户之间共享个人浏览器会话。
