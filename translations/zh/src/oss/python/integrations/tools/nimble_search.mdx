>[Nimble's Search API](https://docs.nimbleway.com/nimble-sdk/search-api) 通过无头浏览器访问实时 Web 来提供搜索能力，而不是查询预构建索引。该工具可处理 JavaScript 渲染、动态内容和复杂导航流程，因此适合那些需要获取当前 Web 数据的 agent 工作流，包括分页、筛选器和客户端渲染之后的内容。

## Overview

### Integration details

| Class | Package | Serializable | JS support |  Package latest |
| :--- | :--- | :---: | :---: | :---: |
| [`NimbleSearchTool`](https://github.com/Nimbleway/langchain-nimble) | [`langchain-nimble`](https://pypi.org/project/langchain-nimble/) | ❌ | ❌ | ![PyPI - Version](https://img.shields.io/pypi/v/langchain-nimble?style=flat-square&label=%20) |

### Tool features

| Returns artifact | Native async | Return data | Pricing |
| :---: | :---: | :---: | :---: |
| ❌ | ✅ | title, URL, content (markdown/plain_text/HTML), metadata | [提供免费试用](https://www.nimbleway.com/) |

**关键特性：**

- **Fast mode 与 Deep mode**：**Deep mode**（默认）用于完整内容提取并支持 JavaScript 渲染，**Fast mode** 用于快速返回仅含 SERP 的结果
- **AI 生成摘要**：可选地在原始搜索结果旁生成简明答案
- **域名与日期过滤**：按特定域名或日期范围过滤，获得更精确的结果
- **按主题路由**：针对 general、news 或 location 查询进行优化路由
- **灵活输出格式**：plain_text、markdown（默认）或 simplified_html
- **生产可用**：原生 async 支持、自动重试和连接池

### Credentials

你需要 Nimble API key 才能使用该工具。前往 [Nimble](https://www.nimbleway.com/) 注册，获取 API key 并使用其免费试用。

```python
import getpass
import os

if not os.environ.get("NIMBLE_API_KEY"):
    os.environ["NIMBLE_API_KEY"] = getpass.getpass("Nimble API key:\n")
```

## Instantiation

现在可以实例化该工具：

```python
from langchain_nimble import NimbleSearchTool

# Basic usage - uses environment variable for API key
tool = NimbleSearchTool()
```

## Use within an agent

你可以将 Nimble search 工具与 agent 结合使用，让 agent 具备动态 Web 搜索能力。下面是一个使用 LangGraph 的完整示例：

```python
import os
import getpass

from langchain_nimble import NimbleSearchTool
from langchain.agents import create_agent
from langchain.chat_models import init_chat_model

if not os.environ.get("OPENAI_API_KEY"):
    os.environ["OPENAI_API_KEY"] = getpass.getpass("OpenAI API key:\n")
if not os.environ.get("NIMBLE_API_KEY"):
    os.environ["NIMBLE_API_KEY"] = getpass.getpass("Nimble API key:\n")

# Initialize Nimble Search Tool with deep search for comprehensive results
nimble_tool = NimbleSearchTool(
    k=5,
    deep_search=True,
    parsing_type="markdown"
)

# Create agent with the tool
model = init_chat_model(model="gpt-4o", model_provider="openai", temperature=0)
agent = create_agent(model, [nimble_tool])

# Ask the agent a question that requires web search
user_input = "What are the latest developments in quantum computing? Include only sources from academic institutions and reputable tech publications."

stream = agent.stream_events({"messages": user_input}, version="v3")
for snapshot in stream.values:
    snapshot["messages"][-1].pretty_print()
```

## Advanced configuration

该工具支持针对不同场景的广泛配置：

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `num_results` | int | 10 | 返回结果最大数量（1 到 20） |
| `deep_search` | bool | True | **Deep mode**（默认）用于完整内容提取，**Fast mode**（False）仅返回 SERP 结果 |
| `topic` | str | "general" | 针对特定内容类型优化搜索："general"、"news"` 或 `"location"` |
| `include_answer` | bool | False | 在搜索结果旁生成 AI 驱动的摘要答案 |
| `include_domains` | list[str] | None | 白名单域名，例如 `["wikipedia.org", ".edu"]` |
| `exclude_domains` | list[str] | None | 黑名单域名，用于过滤结果 |
| `start_date` | str | None | 过滤某个日期之后的结果（YYYY-MM-DD 或 YYYY） |
| `end_date` | str | None | 过滤某个日期之前的结果（YYYY-MM-DD 或 YYYY） |
| `parsing_type` | str | "markdown" | 输出格式："plain_text"`、`"markdown"` 或 `"simplified_html"` |
| `locale` | str | "en" | 搜索 locale，例如 `"en-US"` |
| `country` | str | "US" | 本地化结果的国家代码，例如 `"US"` |
| `api_key` | str | env var | Nimble API key，默认读取 `NIMBLE_API_KEY` 环境变量 |

## Best Practices

### Fast mode vs Deep mode

- **Deep mode**（`deep_search=True`，默认）：
  - 从网页中提取完整内容
  - 适合详细分析、RAG 应用和综合研究
  - 可处理 JavaScript 渲染与动态内容

- **Fast mode**（`deep_search=False`）：
  - 快速返回仅含标题和摘要的 SERP 结果
  - 适合对速度要求高的大批量查询
  - 单次查询成本更低

### 何时使用 include_answer

- 当你希望在原始搜索结果之外，同时得到一份简明的 AI 生成摘要时，可启用 `include_answer=True`
- 适合快速获得结论，而无需自行处理全部原始内容

### Filtering tips

- **域名过滤**：当你需要学术研究结果或可信来源时，使用 `include_domains`。使用 `exclude_domains` 可过滤不需要的内容类型
- **日期过滤**：把 `start_date` 与 `end_date` 组合使用，适合时间敏感查询或最新新闻
- **主题路由**：使用 `topic` 参数优化 general Web 内容、新闻文章或基于地理位置的信息搜索

### Performance optimization

- **选择正确模式**：速度优先时使用 **Fast mode**（`deep_search=False`）；需要完整内容提取时使用 **Deep mode**（默认）
- 当并发运行多个搜索时，使用 async 操作（`ainvoke`）
- 把 `num_results` 调整到实际所需的最小值，以减少响应时间
- 使用域名过滤聚焦高质量来源，减少噪声
