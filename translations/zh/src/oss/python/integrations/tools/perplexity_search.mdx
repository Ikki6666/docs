[Perplexity Search](https://docs.perplexity.ai/docs/search/quickstart) 是一个 Web 搜索 API，会返回带排序、带来源标注的结果，专为 LLM 和 agents 设计。它驱动了 [perplexity.ai](https://www.perplexity.ai/) 的 answer engine，并通过专用的 [Search API endpoint](https://docs.perplexity.ai/api-reference/search-post) 提供服务。

本页介绍如何把 Perplexity Search API 作为 LangChain tool 使用。

## 设置

### 安装

安装 LangChain Perplexity 集成包：

```python
pip install -qU langchain-perplexity

# and some deps for this notebook
pip install -qU langchain langchain-openai
```

### 凭据

要使用该集成，你需要一个 Perplexity API key。可以在 [Perplexity API key dashboard](https://www.perplexity.ai/account/api/keys) 中创建。

```python
import getpass
import os

if not os.environ.get("PPLX_API_KEY"):
    os.environ["PPLX_API_KEY"] = getpass.getpass("Perplexity API key:\n")
```

如果你更喜欢 `PERPLEXITY_API_KEY` 这个名字，集成也支持它。

## 使用 PerplexitySearchResults 工具

`PerplexitySearchResults` 是一个可以与 LangChain agents 配合使用的工具，用于执行 Perplexity 搜索。调用它时，会返回一个 JSON 数组，其中每个搜索结果都包含 `title`、`url`、`snippet`、`date` 和 `last_updated` 字段。

```python
from langchain_perplexity import PerplexitySearchResults

# Initialize the PerplexitySearchResults tool
search_tool = PerplexitySearchResults(max_results=5)

# Perform a search query
search_results = search_tool.invoke("When was the last time the New York Knicks won the NBA Championship?")

print("Search Results:", search_results)
```

### PerplexitySearchResults 的高级特性

这个工具支持以下构造参数和调用时参数：

- `max_results`：返回结果数量。
- `country`：用于偏置结果的 ISO 国家代码，例如 `"US"`。
- `search_domain_filter`：要包含或排除的域名列表（最多 20 个）。若某个域名前面加 `-`，表示排除它。详见 [domain filter docs](https://docs.perplexity.ai/docs/search/filters/domain-filter)。
- `search_recency_filter`：可以是 `"day"`、`"week"`、`"month"` 或 `"year"`。详见 [date and time filter docs](https://docs.perplexity.ai/docs/search/filters/date-time-filters)。
- `search_after_date` / `search_before_date`：`MM/DD/YYYY` 格式的日期字符串。

```python
from langchain_perplexity import PerplexitySearchResults

# Restrict results to a recent timeframe and a specific set of domains
search_tool = PerplexitySearchResults(
    max_results=10,
    country="US",
    search_recency_filter="week",
    search_domain_filter=["nytimes.com", "reuters.com", "-pinterest.com"],
)

results = search_tool.invoke("Latest AI research papers")
print(results)
```

```python
from langchain_perplexity import PerplexitySearchResults

# Restrict results to a specific date range
search_tool = PerplexitySearchResults(
    max_results=5,
    search_after_date="01/01/2025",
    search_before_date="06/30/2025",
)

results = search_tool.invoke("US Federal Reserve interest rate decisions")
print(results)
```

## 在 Agent 中使用

我们可以把 `PerplexitySearchResults` 工具与 LangGraph agent 搭配使用。这样 agent 就能够动态搜索 Web，并获得有来源支撑的信息。

首先，设置语言模型。你需要提供自己的 OpenAI API key：

```python
import getpass

if not os.environ.get("OPENAI_API_KEY"):
    os.environ["OPENAI_API_KEY"] = getpass.getpass("OpenAI API key:\n")
```

```python
from langchain.agents import create_agent
from langchain.chat_models import init_chat_model
from langchain_perplexity import PerplexitySearchResults


# Initialize the language model
model = init_chat_model(model="gpt-5.5", temperature=0)

# Initialize the Perplexity search tool
perplexity_search = PerplexitySearchResults(
    max_results=5,
    search_recency_filter="month",
)

# Create the agent
agent = create_agent(model, [perplexity_search])

# Run the agent
user_input = "What are the latest developments in quantum computing?"

stream = agent.stream_events(
    {"messages": [{"role": "user", "content": user_input}]},
    version="v3",
)
for snapshot in stream.values:
    snapshot["messages"][-1].pretty_print()
```
