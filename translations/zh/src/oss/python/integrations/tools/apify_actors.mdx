>[Apify Actors](https://docs.apify.com/platform/actors) 是云端程序，适用于广泛的网页抓取、爬取和数据提取任务。这些 Actor 能自动从 Web 采集数据，帮助用户高效地提取、处理和存储信息。Actor 可用于抓取电商网站的商品详情、监控价格变化，或收集搜索引擎结果等任务。它们还可以与 [Apify Datasets](https://docs.apify.com/platform/storage/dataset) 无缝集成，使采集到的结构化数据能够以 JSON、CSV 或 Excel 等格式存储、管理和导出，以便后续分析或使用。

## 概览

本笔记本将带你了解如何在 LangChain 中使用 [Apify Actors](https://docs.apify.com/platform/actors) 来自动化网页抓取和数据提取。`langchain-apify` 包将 Apify 的云端工具集成到 LangChain agent 中，使 AI 应用能够高效地采集和处理数据。

## 设置

该集成位于 [langchain-apify](https://pypi.org/project/langchain-apify/) 包中。你可以使用 pip 安装：

```python
pip install langchain-apify
```

### 前置条件

- **Apify account**：注册免费的 [Apify account](https://console.apify.com/sign-up)。
- **Apify API token**：请在 [Apify documentation](https://docs.apify.com/platform/integrations/api) 中了解如何获取 API token。

```python
import os

os.environ["APIFY_TOKEN"] = "your-apify-token"
os.environ["OPENAI_API_KEY"] = "your-openai-api-key"
```

### 定价

Apify 采用按使用付费的定价方式，并提供免费层。
价格因 Actor 而异，有些 Actor 是免费的，你只需支付平台使用费，而另一些则按结果数或事件数计费。

## 实例化

这里我们实例化 `ApifyActorsTool`，以便调用 [RAG Web Browser](https://apify.com/apify/rag-web-browser) 这个 Apify Actor。该 Actor 为 AI 和 LLM 应用提供网页浏览能力，类似 ChatGPT 中的网页浏览功能。你也可以用同样的方式使用 [Apify Store](https://apify.com/store) 中的任意 Actor。

```python
from langchain_apify import ApifyActorsTool

tool = ApifyActorsTool("apify/rag-web-browser")
```

## 调用

`ApifyActorsTool` 接收一个参数，即 `run_input`，它是一个字典，会作为运行输入传递给 Actor。运行输入 schema 文档可以在 Actor 详情页的 input 部分找到。参见 [RAG Web Browser input schema](https://apify.com/apify/rag-web-browser/input-schema)。

```python
tool.invoke({"run_input": {"query": "what is apify?", "maxResults": 2}})
```

## 链式调用

你可以将创建好的工具传给一个 [agent](https://python.langchain.com/docs/tutorials/agents/)。当要求搜索信息时，agent 会调用 Apify Actor 执行 Web 搜索，然后取回搜索结果。

```python
pip install langgraph langchain-openai
```

```python
from langchain.messages import ToolMessage
from langchain_openai import ChatOpenAI
from langchain.agents import create_agent


model = ChatOpenAI(model="gpt-5-mini")
tools = [tool]
graph = create_agent(model, tools=tools)
```

```python
inputs = {"messages": [("user", "search for what is Apify")]}
stream = graph.stream_events(inputs, version="v3")
for snapshot in stream.values:
    message = snapshot["messages"][-1]
    # skip tool messages
    if isinstance(message, ToolMessage):
        continue
    message.pretty_print()
```

## 其他 Actor 示例

Apify Store 中有数千个预构建 Actor。下面是一些其他常见 Actor 的示例：

### Instagram Scraper

```python
from langchain_apify import ApifyActorsTool

instagram_tool = ApifyActorsTool("apify/instagram-scraper")

# Scrape Instagram posts
result = instagram_tool.invoke({
    "run_input": {
        "directUrls": ["https://www.instagram.com/humansofny/"],
        "resultsLimit": 10
    }
})
```

### Google Search Results Scraper

```python
google_search_tool = ApifyActorsTool("apify/google-search-scraper")

# Scrape Google Search results
result = google_search_tool.invoke({
    "run_input": {
        "queries": "langchain python tutorial",
        "maxPagesPerQuery": 1
    }
})
```

浏览 [Apify Store](https://apify.com/store) 以发现更多适合你场景的 Actor。

## 何时使用 Apify

当你需要以下能力时，Apify 很适合：

- **访问成千上万个预构建 Actor**，覆盖各类平台（社交媒体、电商、搜索引擎等）
- **自定义网页抓取和自动化流程**，而不仅仅是简单搜索
- **无需自建基础设施的抓取能力**，由无服务器平台负责扩缩容和维护
- **灵活的 Actor 生态**，可运行 Apify Store 中的任意 Actor

## 使用 Apify MCP Server

不确定该用哪个 Actor，或者不清楚它需要哪些参数？
[Apify MCP (Model Context Protocol) server](https://mcp.apify.com) 可以帮助你发现可用 Actor、查看其输入 schema，并通过 Model Context Protocol 了解参数要求。

要在 LangChain 中使用 Apify MCP server：

```python
import os
from langchain_mcp_adapters.client import MultiServerMCPClient
from langchain.agents import create_agent

client = MultiServerMCPClient({
    "apify": {
        "transport": "http",
        "url": "https://mcp.apify.com",
        "headers": {
            "Authorization": f"Bearer {os.environ['APIFY_TOKEN']}",
        },
    }
})

tools = await client.get_tools()
agent = create_agent("gpt-5-mini", tools)
```

有关更多信息，请参阅 [LangChain MCP documentation](/oss/langchain/mcp) 和 [Apify MCP server](https://mcp.apify.com)。
