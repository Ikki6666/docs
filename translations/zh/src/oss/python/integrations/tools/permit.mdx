Permit 是一个访问控制平台，支持通过 RBAC、ABAC 和 ReBAC 等多种模型进行细粒度、实时权限管理。它让组织能够在应用中实施动态策略，确保只有授权用户才能访问特定资源。

## 概览

这个包提供了两个 LangChain 工具，用于基于 Permit 执行 JWT 校验和权限检查：

* LangchainJWTValidationTool: 针对 JWKS endpoint 校验 JWT token

* LangchainPermissionsCheckTool: 使用 Permit 检查用户权限

## 设置

设置以下环境变量：

```bash
PERMIT_API_KEY=your_permit_api_key
JWKS_URL=your_jwks_endpoint_url
PERMIT_PDP_URL=your_permit_pdp_url  # Usually http://localhost:7766 for local development or your real deployment
```

确保你的 PDP（Policy Decision Point）正在 `PERMIT_PDP_URL` 上运行。
有关策略设置以及如何启动 PDP 容器的详细信息，请参阅 [Permit docs](https://docs.permit.io/concepts/pdp/overview/)。

### 凭证


## 实例化

### JWT validation tool

JWT Validation tool 会针对 JWKS（JSON Web Key Set）endpoint 校验 JWT token。

```python
from langchain_permit.tools import LangchainJWTValidationTool

# Initialize the tool
jwt_validator = LangchainJWTValidationTool(
    jwks_url=#your url endpoint
)
```

### 配置选项

你可以通过以下任一方式初始化该工具：

* 一个 JWKS URL
* 直接传入 JWKS JSON 数据
* 环境变量（JWKS_URL）

```python
# Using direct JWKS JSON
jwt_validator = LangchainJWTValidationTool(
    jwks_json={
        "keys": [
            {
                "kid": "key-id",
                "kty": "RSA",
                ...
            }
        ]
    }
)
```

### Permissions check tool

Permissions Check tool 与 Permit.io 集成，用于根据资源验证用户权限。

```python
from permit import Permit
from langchain_permit.tools import LangchainPermissionsCheckTool

# Initialize Permit client
permit_client = Permit(
    token="your_permit_api_key",
    pdp=# Your PDP URL
)

# Initialize the tool
permissions_checker = LangchainPermissionsCheckTool(
    permit=permit_client
)
```

本文档展示了这两个工具的关键特性与使用模式。

## 调用

### [使用 args 直接调用](https://docs.permit.io/)

### JWT validation tool

```python
# Validate a token
async def validate_token():
    claims = await jwt_validator._arun(
        "..."  # Your JWT token
    )
    print("Validated Claims:", claims)
```

### Permissions check tool

```python
# Check permissions
async def check_user_permission():
    result = await permissions_checker._arun(
        user={
            "key": "user-123",
            "firstName": "John"
        },
        action="read",
        resource={
            "type": "Document",
            "tenant": "default"
        }
    )
    print("Permission granted:", result)
```

#### 输入格式

permissions checker 支持多种输入格式：

1. 将简单字符串作为 user 传入（会转换为用户 key）：

```python
result = await permissions_checker._arun(
    user="user-123",
    action="read",
    resource="Document"
)
```

2. 传入完整的用户对象：

```python
result = await permissions_checker._arun(
    user={
        "key": "user-123",
        "firstName": "John",
        "lastName": "Doe",
        "email": "john@example.com",
        "attributes": {"department": "IT"}
    },
    action="read",
    resource={
        "type": "Document",
        "key": "doc-123",
        "tenant": "techcorp",
        "attributes": {"confidentiality": "high"}
    }
)
```

### 额外 demo 脚本

如需完整可运行的示例，请查看这个 [repository](https://github.com/permitio/langchain-permit) 中的 `/langchain_permit/examples/demo_scripts` 目录。你会看到：
