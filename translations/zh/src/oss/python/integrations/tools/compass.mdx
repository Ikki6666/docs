与多种 DeFi 协议交互，且不托管资产。工具返回的是*未签名交易*。该 toolkit 构建在一个通用 DeFi API 之上，也就是 [Compass API](https://api.compasslabs.ai/)，使 agent 能够执行以下金融操作：

- 在 Uniswap 和 Aerodrome 上**交换代币**
- 使用 Aave 上的协议进行**借贷**
- 在 Aerodrome 和 Uniswap 上**提供流动性**
- 在钱包之间**转移资金**
- 查询余额、投资组合，并**监控仓位**

## 概览

### 集成详情

| Class                    | Package             | Serializable | JS support |                                         Version                                         |
|:-------------------------|:--------------------| :---: | :---: |:----------------------------------------------------------------------------------------------:|
| `LangchainCompassToolkit`  | `langchain-compass` | ❌ | ❌ | ![PyPI - Version](https://img.shields.io/pypi/v/langchain-compass?style=flat-square&label=%20) |

### 工具特性

下面列出该 toolkit 提供的一部分工具，具体内容可能每天变化：

- `aave_supply`: 向 Aave 存入资产以赚取利息。
- `aave_borrow`: 使用抵押品从 Aave 借入资产。
- `uniswap_swap_sell_exactly`: 在 Uniswap 上交换指定数量的某种代币。
- `generic_portfolio_get`: 获取钱包的美元投资组合和代币余额。
- `generic_transfer_erc20`: 在地址之间转移 ERC20 代币。

## 设置

这里我们会：

1. 安装 langchain 包
2. 导入并实例化 toolkit
3. 通过 `toolkit.get_tools()` 将工具传给 agent

### 安装

该 toolkit 位于 `langchain-compass` 包中：

```python
pip install -qU langchain-compass
```

#### 环境设置

要运行这些示例，请确保 LangChain 可以访问 LLM 服务。例如，如果你使用 GPT-4o，可以创建一个包含以下内容的 `.env` 文件：

```plaintext
# .env file
OPENAI_API_KEY=<your_openai_api_key_here>
```

### 实例化

现在可以实例化 toolkit：

```python
from langchain_compass.toolkits import LangchainCompassToolkit

toolkit = LangchainCompassToolkit(compass_api_key=None)
```

### 工具

查看[可用工具](#工具特性)：

```python
tools = toolkit.get_tools()
for tool in tools:
    print(tool.name)
```


## 调用

以编程方式调用单个工具：

```python
tool_name = "generic_ens_get"
tool = next(tool for tool in tools if tool.name == tool_name)
tool.invoke({"ens_name": "vitalik.eth", "chain": "ethereum:mainnet"})
```

## 在 agent 中使用

我们需要一个 LLM 或聊天模型：

```python
from dotenv import load_dotenv
from langchain_openai import ChatOpenAI

load_dotenv()

llm = ChatOpenAI(model="gpt-5.5")
```

使用这些工具初始化 agent：

```python
from langchain.agents import create_agent


tools = toolkit.get_tools()
agent_executor = create_agent(llm, tools)
```

用法示例：

```python
example_query = "please set an allowance on Uniswap of 10 WETH for vitalic.eth."  # spelt wrong intentionally

stream = agent_executor.stream_events(
    {"messages": [("user", example_query)]},
    version="v3",
)
for snapshot in stream.values:
    snapshot["messages"][-1].pretty_print()
```
