[Tavily's Search API](https://tavily.com) 是一个专为 AI agents（LLMs）构建的搜索引擎，可快速提供实时、准确且真实的结果。

## 设置

该集成位于 `langchain-tavily` 包中。

```python
pip install -qU langchain-tavily
```

### 凭证

我们还需要设置 Tavily API key。你可以访问 [this site](https://app.tavily.com/sign-in) 创建账户并获取 API key。

```python
import getpass
import os

if not os.environ.get("TAVILY_API_KEY"):
    os.environ["TAVILY_API_KEY"] = getpass.getpass("Tavily API key:\n")
```

## 实例化

这里展示如何实例化 Tavily search 工具。该工具在实例化时接受多种参数：

- max_results（可选，int）：返回的最大搜索结果数。默认值为 5。
- topic（可选，str）：搜索分类。可选 `"general"`、`"news"` 或 `"finance"`。默认值为 `"general"`。
- include_answer（可选，bool）：是否在结果中包含对原始查询的回答。默认值为 False。
- include_raw_content（可选，bool）：是否包含每条搜索结果清洗并解析后的 HTML。默认值为 False。
- include_images（可选，bool）：是否在响应中包含与查询相关的图片列表。默认值为 False。
- include_image_descriptions（可选，bool）：是否为每张图片包含描述文本。默认值为 False。
- search_depth（可选，str）：搜索深度，可选 `"basic"` 或 `"advanced"`。默认值为 `"basic"`。
- time_range（可选，str）：从当前日期向前过滤结果的时间范围，可选 `"day"`、`"week"`、`"month"` 或 `"year"`。默认值为 None。
- include_domains（可选，List[str]）：需要特别包含的域名列表。默认值为 None。
- exclude_domains（可选，List[str]）：需要特别排除的域名列表。默认值为 None。

如需全面了解可用参数，请参阅 [Tavily Search API documentation](https://docs.tavily.com/documentation/api-reference/endpoint/search)

```python
from langchain_tavily import TavilySearch

tool = TavilySearch(
    max_results=5,
    topic="general",
    # include_answer=False,
    # include_raw_content=False,
    # include_images=False,
    # include_image_descriptions=False,
    # search_depth="basic",
    # time_range="day",
    # include_domains=None,
    # exclude_domains=None
)
```

## 调用

### [使用 args 直接调用](/oss/langchain/tools)

Tavily search 工具在调用时接受以下参数：

- `query`（必填）：自然语言搜索查询
- 以下参数也可以在调用时设置：`include_images`、`search_depth`、`time_range`、`include_domains`、`exclude_domains`
- 出于可靠性和性能考虑，一些会影响响应大小的参数不能在调用时修改：`include_answer` 和 `include_raw_content`。这些限制可避免意外的上下文窗口问题，并保证结果一致性。

NOTE: 这些可选参数可以由 agent 动态设置。如果你在实例化时设置了某个参数，又在调用时传入不同值，工具会采用调用时传入的值。

```python
tool.invoke({"query": "What happened at the last wimbledon"})
```

### [使用 ToolCall 调用](/oss/langchain/tools)

我们也可以使用模型生成的 ToolCall 调用该工具，这种情况下会返回一个 ToolMessage：

```python
# This is usually generated by a model, but we'll create a tool call directly for demo purposes.
model_generated_tool_call = {
    "args": {"query": "euro 2024 host nation"},
    "id": "1",
    "name": "tavily",
    "type": "tool_call",
}
tool_msg = tool.invoke(model_generated_tool_call)

# The content is a JSON string of results
print(tool_msg.content[:400])
```

```python
from langchain_tavily import TavilySearch
from langchain.agents import create_agent


# Initialize Tavily Search Tool
tavily_search_tool = TavilySearch(
    max_results=5,
    topic="general",
)

agent = create_agent(model, [tavily_search_tool])

user_input = "What nation hosted the Euro 2024? Include only wikipedia sources."

stream = agent.stream_events({"messages": user_input}, version="v3")
for snapshot in stream.values:
    snapshot["messages"][-1].pretty_print()
```
