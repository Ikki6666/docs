>[Lemon Agent](https://github.com/felixbrock/lemon-agent) 可以帮助你在几分钟内构建强大的 AI 助手，并通过在 `Airtable`、`Hubspot`、`Discord`、`Notion`、`Slack` 和 `GitHub` 等工具中执行准确可靠的读写操作来自动化工作流。

完整文档见[这里](https://github.com/felixbrock/lemonai-py-client)。

如今大多数 connector 都只关注只读操作，这限制了 LLM 的潜力。另一方面，agent 由于上下文或指令缺失，有时又会产生幻觉。

使用 `Lemon AI`，你可以让 agent 访问定义良好的 API，以可靠地执行读写操作。此外，`Lemon AI` functions 还可以帮助你进一步降低幻觉风险，因为你可以静态定义工作流，让模型在不确定时依赖这些工作流。

## 快速开始

下面的快速开始示例演示如何将 Lemon AI 与 Agents 结合使用，以自动化那些需要与内部工具交互的工作流。

### 1. 安装 Lemon AI

需要 Python 3.8.1 及以上版本。

要在 Python 项目中使用 Lemon AI，请运行 `pip install lemonai`。

这会安装对应的 Lemon AI client，之后你就可以在脚本中导入它。

该工具会使用 `langchain` 和 `loguru` 这两个 Python 包。如果安装 Lemon AI 时出现错误，请先安装这两个包，再安装 Lemon AI 包。

### 2. 启动服务器

你的 agent 与 Lemon AI 提供的全部工具之间的交互，都由 [Lemon AI Server](https://github.com/felixbrock/lemonai-server) 处理。要使用 Lemon AI，你需要在本地机器上运行这个服务器，这样 Lemon AI Python client 才能连接上它。

### 3. 在 LangChain 中使用 Lemon AI

Lemon AI 会自动通过找到正确的相关工具组合来完成任务，或者改用 Lemon AI Functions。下面的示例演示如何从 Hackernews 获取一个用户，并把它写入 Airtable 表：

#### （可选）定义你的 Lemon AI functions

与 [OpenAI functions](https://openai.com/blog/function-calling-and-other-api-updates) 类似，Lemon AI 也支持将工作流定义为可复用函数。对于那些尤其需要尽可能接近确定性行为的场景，这些函数会非常有用。特定工作流可以在单独的 `lemonai.json` 中定义：

```json
[
  {
    "name": "Hackernews Airtable User Workflow",
    "description": "retrieves user data from Hackernews and appends it to a table in Airtable",
    "tools": ["hackernews-get-user", "airtable-append-data"]
  }
]
```

你的模型将可以访问这些函数，并且在解决任务时会优先选择它们，而不是自己挑选工具。你需要做的只是把函数名称写进 prompt，让 agent 知道应该使用哪个函数。

#### 在 LangChain 项目中引入 Lemon AI

```python
import os

from langchain_openai import OpenAI
from lemonai import execute_workflow
```

#### 加载 API keys 和访问令牌

要使用需要认证的工具，你必须把相应的访问凭据以 `"{tool name}_{authentication string}"` 的格式存进环境变量中。其中 authentication string 对于 API keys 来说，可以是 `["API_KEY", "SECRET_KEY", "SUBSCRIPTION_KEY", "ACCESS_KEY"]` 中的一个；对于认证令牌来说，可以是 `["ACCESS_TOKEN", "SECRET_TOKEN"]`。例如：`"OPENAI_API_KEY"`、`"BING_SUBSCRIPTION_KEY"`、`"AIRTABLE_ACCESS_TOKEN"`。

```python
""" Load all relevant API Keys and Access Tokens into your environment variables """
os.environ["OPENAI_API_KEY"] = "*INSERT OPENAI API KEY HERE*"
os.environ["AIRTABLE_ACCESS_TOKEN"] = "*INSERT AIRTABLE TOKEN HERE*"
```

```python
hackernews_username = "*INSERT HACKERNEWS USERNAME HERE*"
airtable_base_id = "*INSERT BASE ID HERE*"
airtable_table_id = "*INSERT TABLE ID HERE*"

""" Define your instruction to be given to your LLM """
prompt = f"""Read information from Hackernews for user {hackernews_username} and then write the results to
Airtable (baseId: {airtable_base_id}, tableId: {airtable_table_id}). Only write the fields "username", "karma"
and "created_at_i". Please make sure that Airtable does NOT automatically convert the field types.
"""

"""
Use the Lemon AI execute_workflow wrapper
to run your LangChain agent in combination with Lemon AI
"""
model = OpenAI(temperature=0)

execute_workflow(llm=model, prompt_string=prompt)
```

### 4. 提高 agent 决策过程的透明度

如果你想了解 agent 是如何与 Lemon AI 工具交互来完成任务的，那么 Lemon AI 会把所有决策、所用工具和执行操作写入本地 `lemonai.log` 文件。每次你的 LLM agent 与 Lemon AI 工具栈交互时，都会生成一条对应的日志记录。

```log
2023-06-26T11:50:27.708785+0100 - b5f91c59-8487-45c2-800a-156eac0c7dae - hackernews-get-user
2023-06-26T11:50:39.624035+0100 - b5f91c59-8487-45c2-800a-156eac0c7dae - airtable-append-data
2023-06-26T11:58:32.925228+0100 - 5efe603c-9898-4143-b99a-55b50007ed9d - hackernews-get-user
2023-06-26T11:58:43.988788+0100 - 5efe603c-9898-4143-b99a-55b50007ed9d - airtable-append-data
```

借助 [Lemon AI Analytics](https://github.com/felixbrock/lemon-agent/blob/main/apps/analytics/README.md)，你可以更容易地理解工具被使用的频率和顺序。这样你就能识别 agent 决策能力中的薄弱点，并通过定义 Lemon AI functions，让系统向更确定性的行为演进。
