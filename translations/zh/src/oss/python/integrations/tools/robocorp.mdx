本笔记本介绍如何开始使用 [Robocorp Action Server](https://github.com/robocorp/robocorp) action toolkit 与 LangChain。

Robocorp 是为 AI agents、assistants 和 copilots 扩展自定义 actions 能力的最简单方式。

## 安装

首先，请查看 [Robocorp Quickstart](https://github.com/robocorp/robocorp#quickstart)，了解如何设置 `Action Server` 并创建你的 Actions。

在 LangChain 应用中，安装 `langchain-robocorp` 包：

```python
# Install package
pip install -qU langchain-robocorp
```

当你按照上面的 quickstart 创建新的 `Action Server` 时：

它会创建一个目录，其中包含多个文件，包括 `action.py`。

我们可以像 [Robocorp actions documentation](https://github.com/robocorp/robocorp/tree/master/actions#describe-your-action) 里展示的那样，把 Python 函数添加为 actions。

下面给 `action.py` 加一个简单的示例函数。

```python
@action
def get_weather_forecast(city: str, days: int, scale: str = "celsius") -> str:
    """
    Returns weather conditions forecast for a given city.

    Args:
        city (str): Target city to get the weather conditions for
        days: How many day forecast to return
        scale (str): Temperature scale to use, should be one of "celsius" or "fahrenheit"

    Returns:
        str: The requested weather conditions forecast
    """
    return "75F and sunny :)"
```

然后启动服务器：

```bash
action-server start
```

你会看到：

```
Found new action: get_weather_forecast

```

可以通过访问运行在 `http://localhost:8080` 的服务器，并使用 UI 来本地测试这个函数。

## 环境设置

你也可以按需设置以下环境变量：

- `LANGSMITH_TRACING=true`：启用 LangSmith 日志追踪，这样也可以把追踪结果绑定到对应的 Action Server action run 日志上。详情请参阅 [LangSmith documentation](/langsmith/observability-quickstart)。

## 用法

上面我们已经启动了本地 action server，它运行在 `http://localhost:8080`。

```python
from langchain.agents import AgentExecutor, OpenAIFunctionsAgent
from langchain.messages import SystemMessage
from langchain_openai import ChatOpenAI
from langchain_robocorp import ActionServerToolkit

# Initialize LLM chat model
llm = ChatOpenAI(model="gpt-4", temperature=0)

# Initialize Action Server Toolkit
toolkit = ActionServerToolkit(url="http://localhost:8080", report_trace=True)
tools = toolkit.get_tools()

# Initialize Agent
system_message = SystemMessage(content="You are a helpful assistant")
prompt = OpenAIFunctionsAgent.create_prompt(system_message)
agent = OpenAIFunctionsAgent(llm=llm, prompt=prompt, tools=tools)

executor = AgentExecutor(agent=agent, tools=tools, verbose=True)

executor.invoke("What is the current weather today in San Francisco in fahrenheit?")
```

```text
> Entering new AgentExecutor chain...

Invoking: `robocorp_action_server_get_weather_forecast` with `{'city': 'San Francisco', 'days': 1, 'scale': 'fahrenheit'}`


"75F and sunny :)"The current weather today in San Francisco is 75F and sunny.

> Finished chain.
```

```text
{'input': 'What is the current weather today in San Francisco in fahrenheit?',
 'output': 'The current weather today in San Francisco is 75F and sunny.'}
```

### 单输入工具

默认情况下，`toolkit.get_tools()` 会把 actions 作为 Structured Tools 返回。

如果你想让它返回单输入工具，可以传入一个 Chat model，用于处理输入。

```python
# Initialize single input Action Server Toolkit
toolkit = ActionServerToolkit(url="http://localhost:8080")
tools = toolkit.get_tools(llm=llm)
```
