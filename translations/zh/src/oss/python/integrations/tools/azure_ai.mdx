本页介绍来自 `langchain_azure_ai.tools` 的 Microsoft Foundry project tools。另请参阅作为 [Microsoft Foundry Tools（原 Azure AI Services）](/oss/integrations/tools/azure_ai_services) 一部分提供的工具。

当你希望 agent 调用 Microsoft Foundry project 提供的工具能力时，请使用这些工具。

## 概览

| Tool | Description |
|------------|-------------|
| [`AzureOpenAIModelImageGenTool`](#azureopenaimodelimagegentool) | 通过兼容 OpenAI 的 `/images/generations` 端点生成图像。 |
| [`AzureOpenAITranscriptionsTool`](#azureopenaitranscriptionstool) | 通过兼容 OpenAI 的 `/audio/transcriptions` 端点将音频转写为文本。 |
| [`CodeInterpreterTool`](#codeinterpretertool) | 在沙箱容器中于服务端运行 Python 代码。 |
| [`WebSearchTool`](#websearchtool) | 搜索互联网中的当前信息和来源。 |
| [`FileSearchTool`](#filesearchtool) | 在向量存储中搜索相关文档内容。 |
| [`ImageGenerationTool`](#imagegenerationtool) | 使用 GPT 图像模型生成或编辑图片。 |
| [`McpTool`](#mcptool) | 访问外部 Model Context Protocol (MCP) 服务器。 |
| [`AzureAIProjectToolbox`](#azureaiprojecttoolbox) | 从 Azure AI Foundry Toolbox 加载工具，并通过 Model Context Protocol (MCP) 使用它们。 |

## 设置

安装依赖，创建这些工具所使用的资源，并提供凭证。

### 安装

安装集成包：

<CodeGroup>
    ```bash pip
    pip install -U "langchain-azure-ai[tools]"
    ```
    ```bash uv
    uv add "langchain-azure-ai[tools]"
    ```
</CodeGroup>

### 凭证

通过 `credential` 参数传入 `DefaultAzureCredential()` 或 API key 字符串，`AzureAIProjectToolbox` 除外，它不支持 key。

```python Initialize credential icon="shield-lock"
from azure.identity import DefaultAzureCredential

credential = DefaultAzureCredential()
```

使用 Microsoft Entra ID 时，你需要在模型部署所在资源上拥有 `Azure AI User` 角色。

### 配置端点

这些工具支持两种端点风格：

- 通过 `project_endpoint` 或 `AZURE_AI_PROJECT_ENDPOINT`（或 `FOUNDRY_PROJECT_ENDPOINT`）指定 Azure AI Foundry project endpoint。
- 通过 `endpoint` 或 `OPENAI_BASE_URL` 指定直接的 OpenAI-compatible endpoint，例如 `https://<resource>.services.ai.azure.com/openai/v1`。

如果两者都可用，优先使用 `project_endpoint`，因为它会自动解析 Foundry 工作流背后的服务端点。

```bash Configure endpoint icon="key"
    export AZURE_AI_PROJECT_ENDPOINT="https://<resource>.services.ai.azure.com/api/projects/<project>"
```

```python
from azure.identity import DefaultAzureCredential
from langchain_azure_ai.tools import AzureOpenAIModelImageGenTool

tool = AzureOpenAIModelImageGenTool(
    endpoint="https://<resource>.services.ai.azure.com/openai/v1",
    credential=DefaultAzureCredential(),
    model="my-gpt-image-1-deployment",
)

result = tool.invoke(
    {
        "prompt": "A futuristic cityscape at sunset with flying cars",
        "n": 1,
        "size": "1024x1024",
    }
)
print(result)
```

## 工具

### AzureOpenAIModelImageGenTool

`AzureOpenAIModelImageGenTool`（来自 `langchain_azure_ai.tools`）使用 Microsoft Foundry Models 或 Azure OpenAI 暴露的 OpenAI-compatible 图像生成端点来生成图片。你可以使用包括 `gpt-image-1.5` 或 `MAI-Image-2` 在内的模型。

当你希望在 agent 流程中显式调用图像生成工具时，请使用该工具。该工具会调用 OpenAI client 的 `images.generate` API，并在配置了 `output_directory` 时返回 base64 PNG 输出或保存后的文件路径。

你必须先部署图像生成模型，再通过 `model` 传入部署名称。

<Accordion title="Configuration options">
    <ParamField body="project_endpoint" type="str">
        部署图像模型的 Foundry project。使用该参数时必须使用 Microsoft Entra ID。
    </ParamField>

    <ParamField body="endpoint" type="str">
        存在 `/images/generations` 路由的 OpenAI-compatible endpoint。
    </ParamField>

    <ParamField body="credential" type="str | TokenCredential">
        要使用的凭证，可以是 key，也可以是 token credential。
    </ParamField>

    <ParamField body="prompt" type="str">
        描述待生成图像的文本提示。
    </ParamField>

    <ParamField body="n" type="int" default="1">
        要生成的图片数量。
    </ParamField>

    <ParamField body="size" type="str | None" default="1024x1024">
        输出图像尺寸，例如 `1024x1024`、`1024x1792` 或 `1792x1024`，是否支持取决于模型。
    </ParamField>

    <ParamField body="quality" type="str | None">
        传给图像生成模型的可选质量参数，例如 `hd`，是否支持取决于模型。
    </ParamField>

    <ParamField body="style" type="str | None">
        可选风格参数，例如 `vivid` 或 `natural`，是否支持取决于模型。
    </ParamField>

    <ParamField body="model" type="str">
        必填，要使用的图像生成模型部署名称。请先在 Microsoft Foundry 中创建该部署。可使用任意 OpenAI-compatible 模型，例如 MAI-Image-2。
    </ParamField>

    <ParamField body="output_directory" type="str | None">
        如果设置，生成的图片会保存为 PNG 文件，工具返回保存后的文件路径；如果省略，工具返回 base64 PNG 数据。
    </ParamField>
</Accordion>

### AzureOpenAITranscriptionsTool

`AzureOpenAITranscriptionsTool`（来自 `langchain_azure_ai.tools`）使用 Microsoft Foundry Models 或 Azure OpenAI 暴露的 OpenAI-compatible 语音转文本端点（例如 Whisper）将音频转写为文本。

当你希望在 agent 流程中将音频文件或远程音频 URL 转换为文本时，请使用该工具。该工具会自动处理本地文件和远程 URL，并支持多种音频格式，包括 MP3、MP4、MPEG、MPGA、M4A、OGG、FLAC、WAV。

你必须先部署语音转文本模型，再通过 `model` 传入部署名称。

```python
from azure.identity import DefaultAzureCredential
from langchain_azure_ai.tools import AzureOpenAITranscriptionsTool

tool = AzureOpenAITranscriptionsTool(
    endpoint="https://<resource>.services.ai.azure.com/openai/v1",
    credential=DefaultAzureCredential(),
    model="my-whisper-deployment",
)

result = tool.invoke(
    {
        "audio_path": "/path/to/audio.wav",
        "language": "en",
    }
)
print(result)
```

<Accordion title="Configuration options">
    <ParamField body="project_endpoint" type="str">
        部署语音转文本模型的 Foundry project。使用该参数时必须使用 Microsoft Entra ID。
    </ParamField>

    <ParamField body="endpoint" type="str">
        存在 `/audio/transcriptions` 路由的 OpenAI-compatible endpoint。
    </ParamField>

    <ParamField body="credential" type="str | TokenCredential">
        要使用的凭证，可以是 key，也可以是 token credential。
    </ParamField>

    <ParamField body="audio_path" type="str">
        本地音频文件路径，或指向音频文件的 URL。
    </ParamField>

    <ParamField body="language" type="str | None">
        可选语言代码，采用 ISO-639-1 格式，例如 `"en"`、`"es"`、`"fr"`。如果未指定，模型会自动检测语言。
    </ParamField>

    <ParamField body="model" type="str">
        必填，要使用的语音转文本模型部署名称。请先在 Microsoft Foundry 中创建该部署。
    </ParamField>
</Accordion>

### CodeInterpreterTool

`CodeInterpreterTool` 允许模型在沙箱容器中编写并执行 Python 代码，并将结果纳入响应中。这适合数据分析、数学计算、可视化和通用问题求解场景。

<Warning>
    `langchain_azure_ai.tools.builtin` 命名空间中的工具必须与部署在 Microsoft Foundry project 中的 OpenAI 模型一起使用。它们会在模型推理请求内部解析，无法用于运行在 Azure AI Foundry 之外的模型。
</Warning>

```python
from langchain_azure_ai.tools.builtin import CodeInterpreterTool

tool = CodeInterpreterTool(
    memory_limit="4g",
)

model_with_code = model.bind_tools([tool])
response = model_with_code.invoke("Plot a sine wave using Python and explain it")
print(response)
```

<Accordion title="Configuration options">
    <ParamField body="file_ids" type="list[str] | None">
        可选，要在容器中提供给代码处理的上传文件 ID 列表。
    </ParamField>

    <ParamField body="memory_limit" type="str | None">
        容器的内存限制。可接受的值为 `"1g"`、`"4g"`、`"16g"` 和 `"64g"`。
    </ParamField>

    <ParamField body="network_policy" type="dict | None">
        可选，容器的网络访问策略。
    </ParamField>
</Accordion>

### WebSearchTool

`WebSearchTool` 允许模型搜索互联网中与其查询相关的当前信息和来源。这适合提供最新信息、研究、事实核查，以及访问实时数据。

<Warning>
    `langchain_azure_ai.tools.builtin` 命名空间中的工具必须与部署在 Microsoft Foundry project 中的 OpenAI 模型一起使用。它们会在模型推理请求内部解析，无法用于运行在 Azure AI Foundry 之外的模型。
</Warning>

```python
from langchain_azure_ai.tools.builtin import WebSearchTool

tool = WebSearchTool(
    search_context_size="high",
)

model_with_search = model.bind_tools([tool])
response = model_with_search.invoke(
    "What are the latest developments in quantum computing?"
)
print(response)
```

<Accordion title="Configuration options">
    <ParamField body="search_context_size" type="'low' | 'medium' | 'high' | None">
        对搜索结果可使用上下文窗口空间的高层级建议。默认值为 `"medium"`。
    </ParamField>

    <ParamField body="user_location" type="dict | None">
        用户的大致位置。可包含可选键：`city`、`country`（ISO-3166 两位国家代码）、`region`、`timezone`（IANA）以及 `type="approximate"`。
    </ParamField>

    <ParamField body="filters" type="dict | None">
        搜索过滤器。可包含可选的 `allowed_domains` 列表，以限制结果来源域名。
    </ParamField>
</Accordion>

### FileSearchTool

`FileSearchTool` 从已上传的向量存储中搜索相关内容。这适合从大型文档集合、知识库以及已建立索引的自定义数据源中检索信息。

<Warning>
    `langchain_azure_ai.tools.builtin` 命名空间中的工具必须与部署在 Microsoft Foundry project 中的 OpenAI 模型一起使用。它们会在模型推理请求内部解析，无法用于运行在 Azure AI Foundry 之外的模型。
</Warning>

```python
from langchain_azure_ai.tools.builtin import FileSearchTool

tool = FileSearchTool(
    vector_store_ids=["vs_abc123", "vs_def456"],
    max_num_results=5,
)

model_with_search = model.bind_tools([tool])
response = model_with_search.invoke(
    "Find information about company policies on remote work"
)
print(response)
```

<Accordion title="Configuration options">
    <ParamField body="vector_store_ids" type="list[str]" required>
        要搜索的向量存储 ID。必须至少提供一个 ID。
    </ParamField>

    <ParamField body="max_num_results" type="int | None">
        返回结果的最大数量（1-50）。默认值为合理数量。
    </ParamField>

    <ParamField body="filters" type="dict | None">
        可选元数据过滤器，用于使用比较或复合过滤规则缩小结果范围。
    </ParamField>

    <ParamField body="ranking_options" type="dict | None">
        排名选项。可包含可选键 `ranker` 和 `score_threshold`，以控制结果排序。
    </ParamField>
</Accordion>

### ImageGenerationTool

`ImageGenerationTool` 允许模型使用 GPT 图像模型生成或编辑图片。这适合创建视觉内容、编辑图片，以及根据文本描述生成图像。该工具必须与部署在 Microsoft Foundry project 中的 OpenAI 模型一起使用。如果你使用的是其他模型，请改用 [`AzureOpenAIModelImageGenTool`](#azureopenaimodelimagegentool)。

<Warning>
    `langchain_azure_ai.tools.builtin` 命名空间中的工具必须与部署在 Microsoft Foundry project 中的 OpenAI 模型一起使用。它们会在模型推理请求内部解析，无法用于运行在 Azure AI Foundry 之外的模型。
</Warning>

```python
from langchain_azure_ai.tools.builtin import ImageGenerationTool

tool = ImageGenerationTool(
    quality="high",
    size="1024x1024",
    model_deployment="my-gpt-image-1-deployment",
)

model_with_images = model.bind_tools([tool])
response = model_with_images.invoke(
    "Generate an image of a futuristic city with flying cars"
)
print(response)
```

<Accordion title="Configuration options">
    <ParamField body="model_deployment" type="str | None">
        Azure AI Foundry 中图像生成模型的部署名称。设置后，工具会自动注入 `x-ms-oai-image-generation-deployment` HTTP 请求头。
    </ParamField>

    <ParamField body="model" type="'gpt-image-1' | 'gpt-image-1-mini' | 'gpt-image-1.5' | None">
        要使用的图像生成模型。
    </ParamField>

    <ParamField body="action" type="'generate' | 'edit' | 'auto' | None">
        是生成新图片还是编辑现有图片。默认值为 `"auto"`。
    </ParamField>

    <ParamField body="quality" type="'low' | 'medium' | 'high' | 'auto' | None">
        图像质量。默认值为 `"auto"`。
    </ParamField>

    <ParamField body="size" type="'1024x1024' | '1024x1536' | '1536x1024' | 'auto' | None">
        图像尺寸。默认值为 `"auto"`。
    </ParamField>

    <ParamField body="output_format" type="'png' | 'webp' | 'jpeg' | None">
        输出格式。默认值为 `"png"`。
    </ParamField>

    <ParamField body="background" type="'transparent' | 'opaque' | 'auto' | None">
        图像生成时的背景类型。
    </ParamField>

    <ParamField body="input_fidelity" type="str | None">
        输出结果与输入图像在风格和面部特征上的接近程度，可为 `"high"` 或 `"low"`。
    </ParamField>

    <ParamField body="input_image_mask" type="dict | None">
        用于图像修补操作的 mask。
    </ParamField>

    <ParamField body="moderation" type="'auto' | 'low' | None">
        审核等级。默认值为 `"auto"`。
    </ParamField>

    <ParamField body="output_compression" type="int | None">
        压缩等级（0-100，默认 100）。
    </ParamField>

    <ParamField body="partial_images" type="int | None">
        要流式返回的 partial image 数量（0-3）。
    </ParamField>
</Accordion>

### McpTool

`McpTool` 让模型能够访问外部 Model Context Protocol (MCP) 服务器。这样模型就可以在单轮对话内调用远程 MCP 服务器暴露的工具，从而与自定义服务和外部系统集成。

<Warning>
    `langchain_azure_ai.tools.builtin` 命名空间中的工具必须与部署在 Microsoft Foundry project 中的 OpenAI 模型一起使用。它们会在模型推理请求内部解析，无法用于运行在 Azure AI Foundry 之外的模型。
</Warning>

```python
from langchain_azure_ai.tools.builtin import McpTool

tool = McpTool(
    server_label="my_mcp_server",
    server_url="https://my-mcp-server.example.com",
    allowed_tools=["tool_1", "tool_2"],
)

model_with_mcp = model.bind_tools([tool])
response = model_with_mcp.invoke(
    "Use the MCP server to retrieve user profile information"
)
print(response)
```

<Accordion title="Configuration options">
    <ParamField body="server_label" type="str" required>
        此 MCP 服务器的标签，用于在工具调用中标识它。
    </ParamField>

    <ParamField body="server_url" type="str | None">
        MCP 服务器的 URL。必须提供 `server_url` 或 `connector_id` 之一。
    </ParamField>

    <ParamField body="connector_id" type="str | None">
        内建服务连接器的标识符，例如 `"connector_gmail"`。必须提供 `server_url` 或 `connector_id` 之一。
    </ParamField>

    <ParamField body="allowed_tools" type="list[str] | dict | None">
        允许模型在该服务器上调用的工具名列表，或工具过滤字典。
    </ParamField>

    <ParamField body="headers" type="dict[str, str] | None">
        每次向 MCP 服务器发送请求时附带的可选 HTTP headers，例如用于认证。
    </ParamField>

    <ParamField body="require_approval" type="'always' | 'never' | dict | None">
        工具调用在执行前是否需要人工批准。
    </ParamField>

    <ParamField body="server_description" type="str | None">
        提供给模型的 MCP 服务器可选描述。
    </ParamField>

    <ParamField body="authorization" type="str | None">
        MCP 服务器的 OAuth access token。
    </ParamField>
</Accordion>

### AzureAIProjectToolbox

`AzureAIProjectToolbox`（来自 `langchain_azure_ai.tools`）会从 Azure AI Foundry Toolbox 加载工具，并通过 Model Context Protocol (MCP) 将其提供出来。

Azure AI Foundry Toolbox 是一个托管的多 MCP 服务器，会将多个已配置工具聚合到同一个 MCP endpoint 之后。当你希望在 agent 中动态加载并使用 Azure AI Foundry project 中的一组工具时，可以使用它。

该 toolbox 会自动处理：

- Azure Identity Bearer-token 认证
- 优雅的 OAuth consent 错误处理，即返回包含 consent URL 的回退工具，而不是直接抛错
- 对输出不完整 JSON schema 的 MCP 服务器自动执行 tool schema 清洗

请先在 Microsoft Foundry project 中创建 toolbox。相关文档见 [Toolbox in Foundry](https://learn.microsoft.com/azure/foundry/agents/how-to/tools/toolbox)。

<Accordion title="Configuration parameters">
    <ParamField body="project_endpoint" type="str">
        Azure AI Foundry project endpoint，例如 `https://<resource>.services.ai.azure.com/api/projects/<project>`。如果未显式传入，会回退到 `AZURE_AI_PROJECT_ENDPOINT` 或 `FOUNDRY_PROJECT_ENDPOINT` 环境变量。
    </ParamField>

    <ParamField body="toolbox_name" type="str">
        在 Azure AI Foundry 中配置的 toolbox 名称。该参数必填。
    </ParamField>

    <ParamField body="api_version" type="str" default="v1">
        追加到 MCP URL 末尾的 Toolbox API version。
    </ParamField>

    <ParamField body="credential" type="str | TokenCredential">
        用于 Bearer-token 认证的 Azure credential。可以是字符串（静态 Bearer token）或任意 `TokenCredential`，例如 `DefaultAzureCredential`。默认值为 `DefaultAzureCredential()`。
    </ParamField>

    <ParamField body="extra_headers" type="dict[str, str]">
        附加到 MCP 请求中的额外 HTTP headers。除非你已显式提供，否则会自动加入默认值的 `Foundry-Features` header。
    </ParamField>
</Accordion>

#### 基本用法

```python
from azure.identity import DefaultAzureCredential
from langchain_azure_ai.tools import AzureAIProjectToolbox
from langchain.agents import create_agent
from langchain.chat_models import init_chat_model
from langchain.messages import HumanMessage

async def main():
    toolbox = AzureAIProjectToolbox(
        project_endpoint="https://<resource>.services.ai.azure.com/api/projects/<project>",
        toolbox_name="my-toolbox",
    )
    tools = await toolbox.get_tools()

    model = init_chat_model("azure_ai:gpt-5-mini", credential=DefaultAzureCredential())
    agent = create_agent(
        model=model,
        tools=tools,
    )

    result = await agent.ainvoke({
        "messages": [HumanMessage("What can you do with the available tools?")]
    })
    return result
```

也可以改用环境变量：

```bash
export AZURE_AI_PROJECT_ENDPOINT="https://<resource>.services.ai.azure.com/api/projects/<project>"
```

然后不带参数实例化，或者只传 `toolbox_name`：

```python
from langchain_azure_ai.tools import AzureAIProjectToolbox

toolbox = AzureAIProjectToolbox(toolbox_name="my-toolbox")
tools = await toolbox.get_tools()
```

#### 使用异步上下文管理器

支持 `async with`，以便更方便地使用：

```python
async with AzureAIProjectToolbox(toolbox_name="my-toolbox") as toolbox:
    tools = await toolbox.get_tools()
```

#### 与 agent 集成

`get_tools()` 方法返回一组 `BaseTool` 实例，可直接用于任何 LangChain agent 模式：

```python Agent with AzureAIProjectToolbox icon="robot"
from azure.identity import DefaultAzureCredential
from langchain_azure_ai.tools import AzureAIProjectToolbox
from langchain.agents import create_agent
from langchain.chat_models import init_chat_model

async def main():
    credential = DefaultAzureCredential()
    toolbox = AzureAIProjectToolbox(
        toolbox_name="my-toolbox",
        credential=credential,
    )

    tools = await toolbox.get_tools()

    model = init_chat_model("azure_ai:gpt-5-mini", credential=credential)
    agent = create_agent(
        model=model,
        tools=tools,
        system_prompt=(
            "You are a helpful assistant with access to a set of tools from "
            "Azure AI Foundry. Use them to help the user with their requests."
        ),
    )

    return agent
```
