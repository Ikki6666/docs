[AgentQL](https://www.agentql.com/) 工具可以使用 [AgentQL query](https://docs.agentql.com/agentql-query) 或自然语言提示，对任意网页执行网页交互和结构化数据提取。AgentQL 可跨多种语言和网页使用，并且不易因页面随时间变化而失效。

## 概览

AgentQL 提供以下三个工具：

- **`ExtractWebDataTool`** 使用 [AgentQL query](https://docs.agentql.com/agentql-query/query-intro) 或自然语言数据描述，根据给定 URL 从网页中提取 JSON 结构化数据。

以下两个工具也会打包进 `AgentQLBrowserToolkit`，并且必须与 `Playwright` 浏览器或通过 Chrome DevTools Protocol (CDP) 连接的远程浏览器实例一起使用：

- **`ExtractWebDataBrowserTool`** 使用 [AgentQL query](https://docs.agentql.com/agentql-query/query-intro) 或自然语言描述，从浏览器当前活动网页中提取 JSON 结构化数据。

- **`GetWebElementBrowserTool`** 使用自然语言描述定位浏览器当前活动网页中的某个网页元素，并返回其 CSS selector，以便后续交互。

## 实例化

### `ExtractWebDataTool`

你可以使用以下参数实例化 `ExtractWebDataTool`：

- `api_key`: 你在 [dev.agentql.com](https://dev.agentql.com) 获取的 AgentQL API key。**`Optional`。**
- `timeout`: 请求超时前等待的秒数。如果数据提取超时，可以增大该值。**默认值为 `900`。**
- `is_stealth_mode_enabled`: 是否启用实验性的反爬规避策略。该特性并不保证在所有网站、所有时间都有效。启用后数据提取可能耗时更长。**默认值为 `False`。**
- `wait_for`: 在提取数据前等待页面加载的秒数。**默认值为 `0`。**
- `is_scroll_to_bottom_enabled`: 是否在提取数据前滚动到页面底部。**默认值为 `False`。**
- `mode`: `"standard"` 使用更深入的数据分析，`"fast"` 则以部分分析深度换取速度，适合大多数用例。[可在此指南中了解模式详情。](https://docs.agentql.com/accuracy/standard-mode) **默认值为 `"fast"`。**
- `is_screenshot_enabled`: 是否在提取数据前截图。截图会以 Base64 字符串形式返回在 `metadata` 中。**默认值为 `False`。**

`ExtractWebDataTool` 基于 AgentQL 的 REST API 实现。你可以在 [API Reference docs](https://docs.agentql.com/rest-api/api-reference) 中查看这些参数的更多细节。

```python
from langchain_agentql.tools import ExtractWebDataTool

extract_web_data_tool = ExtractWebDataTool()
```

### `ExtractWebDataBrowserTool`

要实例化 **ExtractWebDataBrowserTool**，你需要将该工具连接到一个浏览器实例。

你可以设置以下参数：

- `timeout`: 请求超时前等待的秒数。如果数据提取超时，可以增大该值。**默认值为 `900`。**
- `wait_for_network_idle`: 是否在执行前等待网络进入完全空闲状态。**默认值为 `True`。**
- `include_hidden`: 是否将页面中视觉上隐藏的元素纳入考虑。**默认值为 `True`。**
- `mode`: `"standard"` 使用更深入的数据分析，`"fast"` 则以部分分析深度换取速度，适合大多数用例。[可在此指南中了解模式详情。](https://docs.agentql.com/accuracy/standard-mode) **默认值为 `"fast"`。**

`ExtractWebDataBrowserTool` 基于 AgentQL SDK 实现。你可以在 AgentQL 的 [API References](https://docs.agentql.com/python-sdk/api-references/agentql-page#querydata) 中查看参数和函数的更多细节。

```python
from langchain_agentql.tools import ExtractWebDataBrowserTool
from langchain_agentql.utils import create_async_playwright_browser

async_browser = await create_async_playwright_browser()

extract_web_data_browser_tool = ExtractWebDataBrowserTool(async_browser=async_browser)
```

## 调用

### `ExtractWebDataTool`

该工具底层使用 AgentQL 的 REST API，并将公开可访问网页的 URL 发送到 AgentQL 的端点。这不适用于私有页面或需要登录会话的页面。这类场景请改用 `ExtractWebDataBrowserTool`。

- `url`: 你要从中提取数据的网页 URL。
- `query`: 要执行的 AgentQL query。如果你想提取精确结构化的数据，请使用 AgentQL query。可在文档中了解 [如何编写 AgentQL query](https://docs.agentql.com/agentql-query)，也可以在 [AgentQL Playground](https://dev.agentql.com/playground) 中进行测试。
- `prompt`: 用自然语言描述你希望从页面提取的数据。AgentQL 会根据提示推断数据结构。如果你希望以自由形式语言定义要提取的数据，而不是事先定义固定结构，可以使用 `prompt`。

**Note:** 你必须定义 `query` 或 `prompt` 其中之一，才能使用 AgentQL。

```python
# You can invoke the tool with either a query or a prompt
```

## 链式调用

你可以先将 AgentQL 工具绑定到一个[支持工具调用的模型](/oss/langchain/tools/)，然后再调用它，从而在 chain 中使用 AgentQL 工具：

### 实例化 LLM

```python
import os

os.environ["OPENAI_API_KEY"] = "YOUR_OPENAI_API_KEY"
```

```python
from langchain.chat_models import init_chat_model

model = init_chat_model(model="gpt-5.5", model_provider="openai")
```

### 执行工具链

```python
from langchain_core.prompts import ChatPromptTemplate
from langchain_core.runnables import RunnableConfig, chain

prompt = ChatPromptTemplate(
    [
        ("system", "You are a helpful assistant in extracting data from website."),
        ("human", "{user_input}"),
        ("placeholder", "{messages}"),
    ]
)

# specifying tool_choice will force the model to call this tool.
model_with_tools = model.bind_tools(
    [extract_web_data_tool], tool_choice="extract_web_data_with_rest_api"
)

model_chain = prompt | model_with_tools


@chain
def tool_chain(user_input: str, config: RunnableConfig):
    input_ = {"user_input": user_input}
    ai_msg = model_chain.invoke(input_, config=config)
    tool_msgs = extract_web_data_tool.batch(ai_msg.tool_calls, config=config)
    return {"messages": tool_msgs}


tool_chain.invoke(
    "Extract data from https://www.agentql.com/blog using the following agentql query: { posts[] { title url date author } }"
)
```

### 实例化 toolkit

```python
from langchain_agentql.utils import create_async_playwright_browser

async_agent_browser = await create_async_playwright_browser()
```

```python
from langchain_agentql import AgentQLBrowserToolkit

agentql_toolkit = AgentQLBrowserToolkit(async_browser=async_agent_browser)
agentql_toolkit.get_tools()
```
