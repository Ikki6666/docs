**Scrapeless** 提供灵活且功能丰富的数据采集服务，支持广泛的参数自定义和多格式导出能力。这些能力使 LangChain 能更有效地集成和利用外部数据。其核心功能模块包括：

**DeepSerp**

- **Google Search**：支持跨所有结果类型全面提取 Google SERP 数据。
  - 支持选择本地化 Google 域名，例如 `google.com`、`google.ad`，以获取特定区域的搜索结果。
  - 支持分页，便于获取第一页之后的结果。
  - 支持搜索结果过滤开关，用于控制是否排除重复或相似内容。
- **Google Trends**：从 Google 获取关键词趋势数据，包括随时间变化的热度、地区兴趣和相关搜索。
  - 支持多关键词对比。
  - 支持多种数据类型：`interest_over_time`、`interest_by_region`、`related_queries` 和 `related_topics`。
  - 允许按特定 Google 属性筛选，例如 Web、YouTube、News、Shopping，以做面向来源的趋势分析。

**Universal Scraping**

- 面向现代、重度依赖 JavaScript 的网站，支持动态内容提取。
  - 支持全球高级代理，用于绕过地理限制并提升稳定性。

**Crawler**

- **Crawl**：递归爬取网站及其链接页面，提取全站内容。
  - 支持可配置的爬取深度和限定 URL 范围。
- **Scrape**：高精度提取单个网页内容。
  - 支持仅提取“主体内容”，排除广告、页脚和其他非核心元素。
  - 支持对多个独立 URL 进行批量抓取。

## 实例化

### ScrapelessDeepSerpGoogleSearchTool

这里展示如何实例化 `ScrapelessDeepSerpGoogleSearchTool`。这个通用信息搜索引擎允许你检索各类数据信息。

- 检索任意数据信息。
- 处理解释型查询，例如 `"why"`、`"how"`。
- 支持比较分析类请求。

该工具接受以下参数：

- `q`：(str) 搜索查询字符串。支持 `inurl:`、`site:`、`intitle:`、`as_eq` 等高级 Google 语法。
- `hl`：(str) 结果内容的语言代码，例如 `en`、`es`、`fr`。默认值为 `'en'`。
- `gl`：(str) 用于面向特定地理区域结果的国家代码，例如 `us`、`uk`、`de`。默认值为 `'us'`。
- `google_domain`：(str) 要使用的 Google 域名，例如 `'google.com'`、`'google.co.jp'`。默认值为 `'google.com'`。
- `start`：(int) 结果偏移量，用于分页，表示跳过前多少条结果。例如：
  - `0`（默认）：第一页结果
  - `10`：第二页
  - `20`：第三页
- `num`：(int) 返回结果的最大数量。例如：
  - `10`（默认）：返回 10 条结果
  - `40`：返回 40 条结果
  - `100`：返回 100 条结果
- `ludocid`：(str) 要抓取的 Google My Business 列表 ID（CID），也称 Google Place ID。
- `kgmid`：(str) 要抓取的 Google Knowledge Graph 列表 ID（KGMID），也称 Google Knowledge Graph ID。带 `kgmid` 参数的搜索会返回原始加密搜索参数对应的结果。某些搜索中，`kgmid` 可能覆盖除 `start` 和 `num` 之外的其他参数。
- `ibp`：(str) 负责渲染某些元素的布局和展开。例如 `gwp;0,7` 可用于在带 `ludocid` 的搜索中展开知识图谱。
- `cr`：(str) 定义要限制搜索的一个或多个国家。格式为 `country{two-letter country code}`，多个国家用 `|` 分隔。例如：
  - `countryFR|countryDE` 表示仅搜索法国和德国页面。
- `lr`：(str) 定义要限制搜索的一个或多个语言。格式为 `lang_{two-letter language code}`，多个语言用 `|` 分隔。例如：
  - `lang_fr|lang_de` 表示仅搜索法语和德语页面。
- `tbs`：(str) 定义普通查询字段无法表达的高级搜索参数。包括：
  - `patents`
  - `dates`
  - `news`
  - `videos`
  - `images`
  - `apps`
  - `text` contents
- `safe`：(str) 成人内容过滤级别。可选值：
  - `active`：模糊显式内容
  - `off`：不过滤
- `nfpr`：(str) 当原始查询拼写错误时，是否排除自动纠正结果。可选值：
  - `1`：排除这些结果
  - `0`（默认）：包含这些结果
  - 注意：如果没有其他结果可返回，这并不一定能阻止 Google 返回自动纠正结果。
- `filter`：(str) 控制 `'Similar Results'` 和 `'Omitted Results'` 过滤器是否开启。可选值：
  - `1`（默认）：启用过滤器
  - `0`：禁用过滤器
- `tbm`：(str) 定义要执行的搜索类型。可选值：
  - `none`：普通 Google Search
  - `isch`：Google Images
  - `lcl`：Google Local
  - `vid`：Google Videos
  - `nws`：Google News
  - `shop`：Google Shopping
  - `pts`：Google Patents
  - `jobs`：Google Jobs

### ScrapelessDeepSerpGoogleTrendsTool

这里展示如何实例化 `ScrapelessDeepSerpGoogleTrendsTool`。这个工具允许你通过 Scrapeless API，以细粒度控制 locale、category 和结果类型的方式查询 Google Trends 的实时或历史趋势数据。

该工具接受以下参数：

- `q`（必填，str）：定义你要搜索的查询词。可以填写任何你在 Google Trends 常规搜索中会使用的内容。每次搜索最多支持 **5** 个查询词。（这一限制只适用于 `interest_over_time` 和 `compared_breakdown_by_region` 数据类型。）其他数据类型每次搜索只接受 **1 个查询词**。
- `data_type`（可选，str）：要获取的数据类型。默认值为 `'interest_over_time'`。可选项包括：
  - `autocomplete`
  - `interest_over_time`
  - `compared_breakdown_by_region`
  - `interest_by_subregion`
  - `related_queries`
  - `related_topics`
- `date`（可选，str）：定义要获取的数据时间范围。默认值为 `'today 1-m'`。支持的格式包括：
  - 相对时间：`'now 1-H'`、`'now 7-d'`、`'today 12-m'`、`'today 5-y'`、`'all'`
  - 自定义日期范围：`'2023-01-01 2023-12-31'`
  - 带小时：`'2023-07-01T10 2023-07-03T22'`
- `hl`（可选，str）：搜索中使用的语言代码。默认值为 `'en'`。例如：
  - `'es'`（Spanish）
  - `'fr'`（French）
- `tz`（可选，str）：时区偏移量。默认值为 `'420'`（PST）。
- `geo`（可选，str）：定义搜索地理来源的两位国家代码。例如：
  - `'US'`（United States）
  - `'GB'`（United Kingdom）
  - `'JP'`（Japan）
  - 留空或设为 `None` 表示全球搜索。
- `cat`（可选，`CategoryEnum`）：用于缩小搜索上下文的类别 ID。默认值为 `'all_categories'`（0）。例如：
  - `'0'` – All categories
  - 以及 `'3'` – News、`'29'` – Sports 等

#### 在 agent 中使用

```python
# Use the tool with an agent
tools = [tool]
agent = create_agent(model, tools)

stream = agent.stream_events(
    {"messages": [("human", "I want to know the iPhone keyword trends")]},
    version="v3",
)
for snapshot in stream.values:
    snapshot["messages"][-1].pretty_print()
```
