>[`Amazon AWS Lambda`](https://aws.amazon.com/pm/lambda/) 是由 `Amazon Web Services` (`AWS`) 提供的无服务器计算服务。它帮助开发者在无需预置或管理服务器的情况下构建和运行应用与服务。这种无服务器架构使你可以专注于编写和部署代码，而 AWS 会自动负责扩缩容、打补丁以及管理运行应用所需的基础设施。

本 notebook 介绍如何使用 `AWS Lambda` Tool。

将 `AWS Lambda` 加入 Agent 可用工具列表后，就可以赋予 Agent 调用你在 AWS 云上运行代码的能力，以满足你需要的各种用途。

当 Agent 使用 `AWS Lambda` tool 时，它会提供一个字符串类型参数，这个参数随后会通过 `event` 参数传入 Lambda 函数。

首先，需要安装 `boto3` Python 包。

```python
pip install -qU boto3 > /dev/null
```

为了让 agent 能使用这个工具，你必须为它提供与 Lambda 函数逻辑功能相匹配的名称和描述。

你还必须提供函数名。

注意，由于这个工具本质上只是对 boto3 库的封装，因此你需要运行 `aws configure` 才能真正使用它。更多细节参见 [AWS CLI documentation](https://docs.aws.amazon.com/cli/index.html)

```python
from langchain.agents import create_agent, load_tools
from langchain_openai import OpenAI

llm = OpenAI(temperature=0)

tools = load_tools(
    ["awslambda"],
    awslambda_tool_name="email-sender",
    awslambda_tool_description="sends an email with the specified content to test@testing123.com",
    function_name="testFunction1",
)

agent = create_agent(
    model=llm,
    tools=tools,
)

agent.invoke("Send an email to test@testing123.com saying hello world.")
```
