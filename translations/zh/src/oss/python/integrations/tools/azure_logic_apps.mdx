本页介绍来自 `langchain_azure_ai.tools` 的 Azure Logic Apps 集成。

Azure Logic Apps 是一个云服务，可帮助你自动化工作流和业务流程。你可以使用 `AzureLogicAppTool` 从 LangChain agent 中调用预先配置好的 Logic App 工作流，从而实现自动化、通知、数据同步以及多步骤流程编排。

## Overview

`AzureLogicAppTool` 允许 agent 通过向已命名的 trigger 发送 JSON payload 来触发 Azure Logic Apps 工作流。这对于自动化发送邮件、处理数据、调用 API，或与其他 Azure 及第三方服务集成等任务非常有用。

常见使用场景：

1. **Email notifications** - 通过 Logic App 发送告警和通知
2. **Data synchronization** - 在系统之间同步数据
3. **Order processing** - 触发订单履行工作流
4. **API integrations** - 通过 Logic Apps 调用外部 API
5. **Approval workflows** - 启动审批流程
6. **Data transformation** - 处理并转换数据
7. **Multi-step automation** - 编排复杂业务流程

## Setup

安装集成包并配置 Azure 凭证。

### Installation

安装带有 `tools` extra 的包：

<CodeGroup>
    ```bash pip
    pip install -U "langchain-azure-ai[tools]"
    ```
    ```bash uv
    uv add "langchain-azure-ai[tools]"
    ```
</CodeGroup>

该 extra 会安装所需的 `azure-mgmt-logic` 依赖。

### Prerequisites

在使用该工具前，你需要：

1. 一个 Azure subscription
2. 一个至少包含一个 HTTP request trigger 的 Azure Logic App
3. subscription ID、resource group name、Logic App name 和 trigger name

### Credentials

该工具默认使用 `DefaultAzureCredential()`，支持多种认证方式，包括环境变量、托管身份和交互式登录。

```python Initialize credential icon="shield-lock"
from azure.identity import DefaultAzureCredential

credential = DefaultAzureCredential()
```

你也可以显式传入特定凭证：

```python
from azure.identity import ManagedIdentityCredential

credential = ManagedIdentityCredential()
```

## Basic usage

### 实例化工具

```python Initialize tool icon="arrows-shuffle"
from langchain_azure_ai.tools import AzureLogicAppTool

tool = AzureLogicAppTool(
    subscription_id="<your-subscription-id>",
    resource_group="<your-resource-group>",
    logic_app_name="<your-logic-app-name>",
    trigger_name="<your-trigger-name>",
)
```

### 调用工具

```python
import json

# Simple text input
result = tool.invoke("Send an email notification")
print(result)

# JSON payload input
payload = {
    "email": "user@example.com",
    "subject": "Test Email",
    "message": "This is a test message from a Logic App trigger."
}
result = tool.invoke(json.dumps(payload))
print(result)
```

## Use with an agent

把该工具传给 @[`create_agent`]。

```python Agent with Logic Apps icon="robot"
from azure.identity import DefaultAzureCredential
from langchain.agents import create_agent
from langchain.chat_models import init_chat_model
from langchain_azure_ai.tools import AzureLogicAppTool

credential = DefaultAzureCredential()
tool = AzureLogicAppTool(
    subscription_id="<your-subscription-id>",
    resource_group="<your-resource-group>",
    logic_app_name="notification-workflow",
    trigger_name="manual_trigger",
    credential=credential,
)

agent = create_agent(
    model=init_chat_model("azure_ai:gpt-4.1", credential=credential),
    tools=[tool],
    system_prompt=(
        "You are a workflow automation assistant. Use the Logic Apps tool to trigger "
        "workflows for sending notifications, processing data, or integrating with "
        "other services when users request automation tasks."
    ),
)
```

## Configuration

### Parameters

<Accordion title="Configuration options">
    <ParamField body="subscription_id" type="str" required>
        托管 Logic Apps 的 Azure subscription ID。
    </ParamField>

    <ParamField body="resource_group" type="str" required>
        部署 Logic App 的 Azure Resource Group 名称。
    </ParamField>

    <ParamField body="logic_app_name" type="str" required>
        要调用的 Logic App 工作流名称。
    </ParamField>

    <ParamField body="trigger_name" type="str" required>
        要调用的 Logic App trigger 名称。对于基于 HTTP request 的 trigger，通常是 `manual_trigger` 或 `http_request`。
    </ParamField>

    <ParamField body="credential" type="TokenCredential | None" default="None">
        可选的 Azure 认证凭证。若为 `None`，则使用 `DefaultAzureCredential()`。可以是任何 Azure SDK credential，例如 `ManagedIdentityCredential`、`ClientSecretCredential` 等。
    </ParamField>

    <ParamField body="name" type="str" default="azure_logic_app_tool">
        工具名称。你可以为不同 Logic App 或不同使用场景自定义该名称。
    </ParamField>

    <ParamField body="description" type="str">
        工具用途说明。可自定义该描述，以帮助 agent 理解何时应使用这个特定 Logic App。
    </ParamField>
</Accordion>

## Input format

该工具接受以下两种输入格式：

1. **Plain text** - 自动转换为带有 `input` 键的 JSON
2. **JSON string** - 解析后原样发送给 Logic App trigger

### Examples

```python
# Plain text input
tool.invoke("Process this order")
# Sent as: {"input": "Process this order"}

# JSON payload
import json
payload = {
    "orderId": "12345",
    "customerEmail": "customer@example.com",
    "items": ["item1", "item2"]
}
tool.invoke(json.dumps(payload))
```

## Response format

该工具返回一个 JSON 响应，表明成功或失败：

```json
{
  "result": "Successfully invoked <logic-app-name>."
}
```

如果报错，则返回：

```json
{
  "error": "Error invoking <logic-app-name> (HTTP_STATUS): ERROR_DETAILS"
}
```
