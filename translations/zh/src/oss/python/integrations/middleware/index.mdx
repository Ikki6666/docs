浏览不同提供方可用的 middleware，或为生态贡献你自己的实现。要了解 middleware 的工作方式，请参阅[middleware 概览](/oss/langchain/middleware/overview)；要了解如何在 Deep Agents 中使用 middleware，请参阅 [Deep Agents 文档](/oss/deepagents/customization#middleware)。

## 分享你的 middleware

Middleware 支持上下文工程、harness 自定义和运行时安全控制。它是 LangChain 中一个很有用的扩展点，也欢迎你把社区构建的成果分享出来：

<CardGroup cols={2}>
    <Card title="添加官方集成" icon="package" href="/oss/contributing/implement-langchain#middleware">
        按照贡献指南构建并发布一个 middleware 包。
    </Card>
    <Card title="分享社区 middleware" icon="users" href="https://github.com/langchain-ai/docs">
        向 docs 仓库提交 PR，把你的 middleware 添加到下方表格中。
    </Card>
</CardGroup>

## 官方集成

| Provider | Middleware available | Source |
|------------|-------------|--------|
| [Anthropic](/oss/integrations/middleware/anthropic) | Prompt caching、bash tool、text editor、memory 和 file search | [`langchain-ai/langchain`](https://github.com/langchain-ai/langchain/tree/master/libs/partners/anthropic) |
| [AWS](/oss/integrations/middleware/aws) | Prompt caching | [`langchain-ai/langchain-aws`](https://github.com/langchain-ai/langchain-aws/tree/main/libs/aws) |
| [Microsoft Foundry](/oss/integrations/middleware/azure_ai) | Text moderation、image moderation、prompt shield、protected material 和 groundedness | [`langchain-ai/langchain-azure`](https://github.com/langchain-ai/langchain-azure/tree/main/libs/azure-ai) |
| [OpenAI](/oss/integrations/middleware/openai) | Content moderation | [`langchain-ai/langchain`](https://github.com/langchain-ai/langchain/tree/master/libs/partners/openai) |

## 社区集成

<Note>
这些 middleware 集成由社区维护。它们以开源方式贡献，不由 LangChain 管理或维护。
</Note>

| Middleware | Description | Source |
|-----------|-------------|--------|
| [Cisco AI Defense](https://github.com/cisco-ai-defense/ai-defense-langchain-middleware) | 运行时安全检查 | [`cisco-ai-defense/ai-defense-langchain-middleware`](https://github.com/cisco-ai-defense/ai-defense-langchain-middleware) |
| [compact-middleware](https://github.com/emanueleielo/compact-middleware) | 将 Claude Code 的 compaction engine 作为 LangChain middleware 使用。为长时运行的智能体提供多层级上下文压缩。 | [`emanueleielo/compact-middleware`](https://github.com/emanueleielo/compact-middleware) |
| [langchain-collapse](https://github.com/johanity/langchain-collapse) | 预防式上下文管理。在 tool-call 组填满上下文窗口之前，先折叠连续的 tool-call 组。 | [`johanity/langchain-collapse`](https://github.com/johanity/langchain-collapse) |
| [langchain-task-steering](https://github.com/edvinhallvaxhiu/langchain-task-steering) | 面向有序任务流水线的隐式状态机 middleware，支持按任务限定工具作用域、动态注入提示词，以及可组合的完成校验。 | [`edvinhallvaxhiu/langchain-task-steering`](https://github.com/edvinhallvaxhiu/langchain-task-steering) |
| [advisor-middleware](https://github.com/emanueleielo/advisor-middleware) | 将 Claude Code 的 advisor 模式作为 LangChain middleware 使用。它将一个快速执行模型与一个强大的 advisor 模型配对，后者只在关键决策时介入。 | [`emanueleielo/advisor-middleware`](https://github.com/emanueleielo/advisor-middleware) |
| [langchain-router](https://github.com/johanity/langchain-router) | 基于阶段的模型路由。将执行轮次路由到快速模型，同时保留主模型负责规划和恢复。 | [`johanity/langchain-router`](https://github.com/johanity/langchain-router) |
| [CopilotKit](/oss/langchain/frontend/integrations/copilotkit) | 面向 [Deep Agents](/oss/deepagents/overview)、`create_agent` 图、AG-UI，以及 React 和运行时客户端的 CopilotKit `CopilotKitMiddleware` 与 FastAPI bridge。 | [`CopilotKit/CopilotKit`](https://github.com/CopilotKit/CopilotKit) |
| [eager-tools](https://github.com/cloudthinker-ai/eager-tools) | 通过在每个流式代码块关闭后立刻分派对应工具调用，减少智能体端到端延迟，让工具执行与 LLM 生成并行进行。 | [`cloudthinker-ai/eager-tools`](https://github.com/cloudthinker-ai/eager-tools) |
| [NoPII](https://github.com/Enigma-Vault/NoPII/tree/main/integrations/langchain-nopii-middleware) | 运行时 PII 标记化。在请求到达 LLM 之前检测外发提示中的个人数据，用确定性的 vault token 进行替换，并在响应中恢复原始值。 | [`Enigma-Vault/NoPII`](https://github.com/Enigma-Vault/NoPII/tree/main/integrations/langchain-nopii-middleware) |
| [langgraph-state-machine](https://github.com/mahmoud661/langgraph-state-machine) | 面向 LangGraph React 智能体的分段式流程控制。它将对话划分为离散阶段，并支持限定作用域的工具、提示词、自动切换、分支流程，以及可选的分阶段 LLM 覆盖。 | [`mahmoud661/langgraph-state-machine`](https://github.com/mahmoud661/langgraph-state-machine) |
| [text2sql-framework](https://github.com/Text2SqlAgent/text2sql-framework) | 用递归式工具使用替代 RAG，智能体通过一个 `execute_sql` 工具自行探索、编写、测试并修正 SQL。 | [`Text2SqlAgent/text2sql-framework`](https://github.com/Text2SqlAgent/text2sql-framework) |
