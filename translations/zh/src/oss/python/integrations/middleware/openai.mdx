## 内容审核

使用 OpenAI 的 moderation endpoint 审核 agent 流量，包括用户输入、模型输出和工具结果，以检测并处理不安全内容。内容审核适用于以下场景：

- 需要内容安全和合规的应用
- 过滤有害、仇恨或不适当内容
- 需要安全护栏的面向客户的 agent
- 满足平台审核要求

<Info>
    了解更多关于 [OpenAI 的 moderation models](https://platform.openai.com/docs/guides/moderation) 和分类的信息。
</Info>

**API reference:** @[`OpenAIModerationMiddleware`]

```python
from langchain_openai import ChatOpenAI
from langchain_openai.middleware import OpenAIModerationMiddleware
from langchain.agents import create_agent

agent = create_agent(
    model=ChatOpenAI(model="gpt-5.5"),
    tools=[search_tool, database_tool],
    middleware=[
        OpenAIModerationMiddleware(
            model="omni-moderation-latest",
            check_input=True,
            check_output=True,
            exit_behavior="end",
        ),
    ],
)
```

<Accordion title="配置选项">

<ParamField body="model" type="ModerationModel" default="omni-moderation-latest">
    要使用的 OpenAI moderation 模型。可选值：`'omni-moderation-latest'`、`'omni-moderation-2024-09-26'`、`'text-moderation-latest'`、`'text-moderation-stable'`
</ParamField>

<ParamField body="check_input" type="bool" default="True">
    是否在调用模型之前检查用户输入消息
</ParamField>

<ParamField body="check_output" type="bool" default="True">
    是否在调用模型之后检查模型输出消息
</ParamField>

<ParamField body="check_tool_results" type="bool" default="False">
    是否在调用模型之前检查工具结果消息
</ParamField>

<ParamField body="exit_behavior" type="string" default="end">
    当内容被标记时如何处理。可选值：

    - `'end'` - 立即结束 agent 执行，并返回违规消息
    - `'error'` - 抛出 `OpenAIModerationError` 异常
    - `'replace'` - 用违规消息替换被标记内容，然后继续执行
</ParamField>

<ParamField body="violation_message" type="str | None">
    违规消息的自定义模板。支持以下模板变量：

    - `{categories}` - 被标记分类的逗号分隔列表
    - `{category_scores}` - 分类分数的 JSON 字符串
    - `{original_content}` - 原始被标记内容

    默认值：`"I'm sorry, but I can't comply with that request. It was flagged for {categories}."`
</ParamField>

<ParamField body="client" type="OpenAI | None">
    可选的预配置 OpenAI client，用于复用。如果不提供，就会创建一个新的 client。
</ParamField>

<ParamField body="async_client" type="AsyncOpenAI | None">
    可选的预配置 AsyncOpenAI client，用于复用。如果不提供，就会创建一个新的异步 client。
</ParamField>

</Accordion>

<Accordion title="完整示例">

这个 middleware 会在不同阶段调用 OpenAI 的 moderation endpoint 来检查内容：

**审核阶段：**
- `check_input` - 模型调用前的用户消息
- `check_output` - 模型调用后的 AI 消息
- `check_tool_results` - 模型调用前的工具输出

**退出行为：**
- `'end'`（默认）- 停止执行，并返回违规消息
- `'error'` - 抛出异常，由应用处理
- `'replace'` - 替换被标记内容并继续执行

```python
from langchain_openai import ChatOpenAI
from langchain_openai.middleware import OpenAIModerationMiddleware
from langchain.agents import create_agent


# 基础审核
agent = create_agent(
    model=ChatOpenAI(model="gpt-5.5"),
    tools=[search_tool, customer_data_tool],
    middleware=[
        OpenAIModerationMiddleware(
            model="omni-moderation-latest",
            check_input=True,
            check_output=True,
        ),
    ],
)

# 更严格的审核，带自定义消息
agent_strict = create_agent(
    model=ChatOpenAI(model="gpt-5.5"),
    tools=[search_tool, customer_data_tool],
    middleware=[
        OpenAIModerationMiddleware(
            model="omni-moderation-latest",
            check_input=True,
            check_output=True,
            check_tool_results=True,
            exit_behavior="error",
            violation_message=(
                "Content policy violation detected: {categories}. "
                "Please rephrase your request."
            ),
        ),
    ],
)

# 带替换行为的审核
agent_replace = create_agent(
    model=ChatOpenAI(model="gpt-5.5"),
    tools=[search_tool],
    middleware=[
        OpenAIModerationMiddleware(
            check_input=True,
            exit_behavior="replace",
            violation_message="[Content removed due to safety policies]",
        ),
    ],
)
```
</Accordion>
