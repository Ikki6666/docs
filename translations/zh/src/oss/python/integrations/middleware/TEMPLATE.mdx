## 与 agent 一起使用

按顺序把 middleware 传给 @[`create_agent`] 或 @[`create_deep_agent`]。你可以把 provider middleware 和 [built-in middleware](/oss/langchain/middleware/built-in) 组合使用。

```python Agent with middleware icon="robot"
from langchain.agents import create_agent

agent = create_agent(
    model="claude-sonnet-4-6",
    tools=[...],
    middleware=[middleware],
)

agent.invoke({"messages": [{"role": "user", "content": "INSERT QUERY"}]})
```

<Tip>
    Middleware 会在 [agent loop](/oss/langchain/middleware/overview#the-agent-loop) 中运行。如需自定义行为，请参阅 [custom middleware](/oss/langchain/middleware/custom)。
</Tip>
