专门为 Anthropic 的 Claude 模型设计的 middleware。更多信息请参阅 [middleware](/oss/langchain/middleware/overview)。

| Middleware | Description |
|------------|-------------|
| [Prompt caching](#prompt-caching) | 通过缓存重复的 prompt 前缀来降低成本 |
| [Bash tool](#bash-tool) | 结合本地命令执行，运行 Claude 原生 bash 工具 |
| [Text editor](#text-editor) | 为文件编辑提供 Claude 的 text editor 工具 |
| [Memory](#memory) | 为持久化 agent memory 提供 Claude 的 memory 工具 |
| [File search](#file-search) | 为基于 state 的文件系统提供搜索工具 |

## Middleware vs tools

`langchain-anthropic` 提供了两种使用 Claude 原生工具的方法：

- **Middleware**（本页）：可直接用于生产的实现，内置执行、状态管理和安全策略
- **Tools**（通过 [`bind_tools`](/oss/integrations/chat/anthropic#built-in-tools)）：更底层的构建块，由你自己提供执行逻辑

### 何时用哪一种

| Use case | Recommended | Why |
|----------|-------------|-----|
| 带 bash 的生产 agent | Middleware | 持久会话、Docker 隔离、输出脱敏 |
| 基于 state 的文件编辑 | Middleware | 内置 LangGraph 状态持久化 |
| 基于文件系统的文件编辑 | Middleware | 带路径校验地写入磁盘 |
| 自定义执行逻辑 | Tools | 完整控制执行行为 |
| 快速原型 | Tools | 更简单，自带回调即可 |
| 通过 @[`bind_tools`][ChatAnthropic.bind_tools] 的非 agent 用法 | Tools | Middleware 需要 @[`create_agent`] |

### 功能对比

| Feature | Middleware | Tools |
|---------|:----------:|:-----:|
| Works with @[`create_agent`] | ✅ | ✅ |
| Works with @[`bind_tools`][ChatAnthropic.bind_tools] | ❌ | ✅ |
| Built-in state management | ✅ | ❌ |
| Custom execute callback | ❌ | ✅ |

<Accordion title="Example: Middleware vs tools comparison">

**Using middleware**（开箱即用）：

```python
from langchain_anthropic import ChatAnthropic
from langchain_anthropic.middleware import ClaudeBashToolMiddleware
from langchain.agents import create_agent
from langchain.agents.middleware import DockerExecutionPolicy

# Production-ready with Docker isolation, session management, etc.
agent = create_agent(
    model=ChatAnthropic(model="claude-sonnet-4-6"),
    middleware=[
        ClaudeBashToolMiddleware(
            workspace_root="/workspace",
            execution_policy=DockerExecutionPolicy(image="python:3.11"),
            startup_commands=["pip install pandas"],
        ),
    ],
)
```

**Using tools**（自行提供执行逻辑）：

```python
import subprocess

from anthropic.types.beta import BetaToolBash20250124Param
from langchain_anthropic import ChatAnthropic
from langchain.agents import create_agent
from langchain.tools import tool

tool_spec = BetaToolBash20250124Param(
    name="bash",
    type="bash_20250124",
    strict=True,
)

@tool(extras={"provider_tool_definition": tool_spec})
def bash(*, command: str, restart: bool = False, **kw):
    """Execute a bash command."""
    if restart:
        return "Bash session restarted"
    try:
        result = subprocess.run(
            command,
            shell=True,
            capture_output=True,
            text=True,
            timeout=30,
        )
        return result.stdout + result.stderr
    except Exception as e:
        return f"Error: {e}"


agent = create_agent(
    model=ChatAnthropic(model="claude-sonnet-4-6"),
    tools=[bash],
)

result = agent.invoke(
    {"messages": [{"role": "user", "content": "List files in this directory"}]}
)
print(result["messages"][-1].content)
```

</Accordion>

## Prompt caching

通过在 Anthropic 服务器上缓存静态或重复的 prompt 内容，例如 system prompt、tool definitions 和 conversation history，来降低成本和延迟。这个 middleware 实现了一种 **conversational caching strategy**，会直接标记稳定的 agent 内容，例如 system prompt 和 tool definitions，并通过 `model_settings` 传递 `cache_control`。聊天模型和 provider 随后会处理消息尾部和 provider 特定的缓存行为，从而让会话历史能够在后续 API 调用中被缓存和复用。

Prompt caching 适用于以下场景：

- 应用具有较长且静态的 system prompt，并且请求之间不会变化
- agent 带有大量在多次调用中保持不变的工具定义
- 会话中早期的消息历史会在多个轮次中被复用
- 高流量部署，需要重点降低 API 成本和延迟

<Tip>
    对于更简单的场景，也可以在调用时直接传入 `cache_control`，使用 [automatic caching](/oss/integrations/chat/anthropic#automatic-caching)，而不借助 middleware。需要显式控制 system prompts 和 tool definitions 的 cache breakpoints 时，推荐使用 middleware。
</Tip>

<Info>
    更多信息请参阅 [Anthropic prompt caching](https://platform.claude.com/docs/en/build-with-claude/prompt-caching#cache-limitations) 的策略与限制。
</Info>

**API reference:** @[`AnthropicPromptCachingMiddleware`]

```python
from langchain_anthropic import ChatAnthropic
from langchain_anthropic.middleware import AnthropicPromptCachingMiddleware
from langchain.agents import create_agent

agent = create_agent(
    model=ChatAnthropic(model="claude-sonnet-4-6"),
    system_prompt="<Your long system prompt here>",
    middleware=[AnthropicPromptCachingMiddleware(ttl="5m")], # [!code highlight]
)
```

<Accordion title="Configuration options">

<ParamField body="type" type="string" default="ephemeral">
    缓存类型。目前只支持 `'ephemeral'`。
</ParamField>

<ParamField body="ttl" type="string" default="5m">
    缓存内容的生存时间。有效值为 `'5m'` 或 `'1h'`
</ParamField>

<ParamField body="min_messages_to_cache" type="number" default="0">
    开始缓存前所需的最少消息数
</ParamField>

<ParamField body="unsupported_model_behavior" type="string" default="warn">
    使用非 Anthropic 模型时的行为。可选值：`'ignore'`、`'warn'` 或 `'raise'`
</ParamField>

</Accordion>

<Accordion title="Full example">

middleware 会缓存每次请求中直到最新消息为止的内容。在 TTL 窗口内，也就是 5 分钟或 1 小时内，后续请求会从缓存中取回之前已出现的内容，而不是重新处理，从而显著降低成本和延迟。

**How it works:**
1. First request: System prompt, tools, and the user message *"Hi, my name is Bob"* are sent to the API and cached
2. Second request: The cached content (system prompt, tools, and first message) is retrieved from cache. Only the new message *"What's my name?"* needs to be processed, plus the model's response from the first request
3. This pattern continues for each turn, with each request reusing the cached conversation history

<Note>
    Prompt caching 会通过缓存 token 降低 API 成本，但**不会**提供会话记忆。若要在多次调用之间持久化会话历史，请使用像 `MemorySaver` 这样的 [checkpointer](https://langchain-ai.github.io/langgraph/concepts/persistence/#checkpointer-libraries)。
</Note>

```python
from langchain_anthropic import ChatAnthropic
from langchain_anthropic.middleware import AnthropicPromptCachingMiddleware
from langchain.agents import create_agent
from langchain.messages import HumanMessage
from langchain_core.runnables import RunnableConfig
from langgraph.checkpoint.memory import MemorySaver


LONG_PROMPT = """
Please be a helpful assistant.

<Lots more context ...>
"""

agent = create_agent(
    model=ChatAnthropic(model="claude-sonnet-4-6"),
    system_prompt=LONG_PROMPT,
    middleware=[AnthropicPromptCachingMiddleware(ttl="5m")], # [!code highlight]
    checkpointer=MemorySaver(),  # Persists conversation history
)

config: RunnableConfig = {"configurable": {"thread_id": "user-123"}}
agent.invoke({"messages": [HumanMessage("Hi, my name is Bob")]}, config=config)
result = agent.invoke({"messages": [HumanMessage("What's my name?")]}, config=config)
print(result["messages"][-1].content)
```

```text
Your name is Bob! You told me that when you introduced yourself at the start of our conversation.
```

</Accordion>

## Bash tool

执行 Claude 原生的 `bash_20250124` 工具，并在本地执行命令。

这个 bash tool middleware 适用于：

- 将 Claude 的内置 bash 工具和本地执行结合使用
- 使用 Claude 优化过的 bash 工具接口
- 需要持久 shell 会话的 Anthropic 模型 agent

<Info>
    这个 middleware 封装了 `ShellToolMiddleware`，并将其暴露为 Claude 的原生 bash 工具。
</Info>

**API reference:** @[`ClaudeBashToolMiddleware`]

```python
from langchain_anthropic import ChatAnthropic
from langchain_anthropic.middleware import ClaudeBashToolMiddleware
from langchain.agents import create_agent

agent = create_agent(
    model=ChatAnthropic(model="claude-sonnet-4-6"),
    tools=[],
    middleware=[
        ClaudeBashToolMiddleware(
            workspace_root="/workspace",
        ),
    ],
)
```

<Accordion title="Configuration options">

`ClaudeBashToolMiddleware` 接受 @[`ShellToolMiddleware`] 的全部参数，包括：

<ParamField body="workspace_root" type="str | Path | None">
    Shell 会话的基础目录
</ParamField>

<ParamField body="startup_commands" type="tuple[str, ...] | list[str] | str | None">
    会话启动时要运行的命令
</ParamField>

<ParamField body="execution_policy" type="BaseExecutionPolicy | None">
    执行策略，即 `HostExecutionPolicy`、`DockerExecutionPolicy` 或 `CodexSandboxExecutionPolicy`
</ParamField>

<ParamField body="redaction_rules" type="tuple[RedactionRule, ...] | list[RedactionRule] | None">
    用于清洗命令输出的规则
</ParamField>

完整配置细节请参阅 [Shell tool](/oss/langchain/middleware/built-in#shell-tool)。

</Accordion>

<Accordion title="Full example">

```python
import tempfile

from langchain_anthropic import ChatAnthropic
from langchain_anthropic.middleware import ClaudeBashToolMiddleware
from langchain.agents import create_agent
from langchain.agents.middleware import DockerExecutionPolicy

workspace = tempfile.mkdtemp(prefix="agent-workspace-")

agent = create_agent(
    model=ChatAnthropic(model="claude-sonnet-4-6"),
    tools=[],
    middleware=[
        ClaudeBashToolMiddleware(
            workspace_root=workspace,
            startup_commands=["echo 'Session initialized'"],
            execution_policy=DockerExecutionPolicy(
                image="python:3.11-slim",
            ),
        ),
    ],
)

result = agent.invoke(
    {"messages": [{"role": "user", "content": "What version of Python is installed?"}]}
)
print(result["messages"][-1].content)
```

```text
Python 3.11.14 is installed.
```

</Accordion>

## Text editor

提供 Claude 的 text editor 工具 `text_editor_20250728`，用于文件创建和编辑。

这个 text editor middleware 适用于：

- 基于文件的 agent 工作流
- 代码编辑和重构任务
- 多文件项目工作
- 需要持久文件存储的 agent

<Note>
    提供两种变体：**State-based**（文件保存在 LangGraph state 中）和 **Filesystem-based**（文件写入磁盘）。
</Note>

**API references:**
- @[`StateClaudeTextEditorMiddleware`]
- @[`FilesystemClaudeTextEditorMiddleware`]

```python State-based text editor
from langchain_anthropic import ChatAnthropic
from langchain_anthropic.middleware import StateClaudeTextEditorMiddleware
from langchain.agents import create_agent

agent = create_agent(
    model=ChatAnthropic(model="claude-sonnet-4-6"),
    tools=[],
    middleware=[StateClaudeTextEditorMiddleware()],
)
```

```python Filesystem-based text editor
from langchain_anthropic import ChatAnthropic
from langchain_anthropic.middleware import FilesystemClaudeTextEditorMiddleware
from langchain.agents import create_agent

agent = create_agent(
    model=ChatAnthropic(model="claude-sonnet-4-6"),
    tools=[],
    middleware=[
        FilesystemClaudeTextEditorMiddleware(
            root_path="/workspace",
        ),
    ],
)
```

Claude 的 text editor 工具支持以下命令：

- `view` - 查看文件内容或列出目录
- `create` - 创建新文件
- `str_replace` - 替换文件中的字符串
- `insert` - 在指定行号插入文本
- `delete` - 删除文件
- `rename` - 重命名或移动文件

<Accordion title="Configuration options">

**@[`StateClaudeTextEditorMiddleware`]（state-based）**

<ParamField body="allowed_path_prefixes" type="Sequence[str] | None">
    可选的允许路径前缀列表。若设置，只允许以这些前缀开头的路径。
</ParamField>

**@[`FilesystemClaudeTextEditorMiddleware`]（filesystem-based）**

<ParamField body="root_path" type="str" required>
    文件操作的根目录
</ParamField>

<ParamField body="allowed_prefixes" type="list[str] | None">
    可选的允许虚拟路径前缀列表，默认值为 `["/"]`
</ParamField>

<ParamField body="max_file_size_mb" type="int" default="10">
    文件最大大小，单位 MB
</ParamField>

</Accordion>

## Memory

提供 Claude 的 memory 工具 `memory_20250818`，用于在多轮对话之间保持持久化 agent memory。

这个 memory middleware 适用于：

- 长时间运行的 agent 对话
- 在中断之后继续保持上下文
- 任务进度跟踪
- 持久化 agent 状态管理

<Info>
    Claude 的 memory 工具使用 `/memories` 目录，并会自动注入 system prompt，鼓励 agent 检查并更新 memory。
</Info>

**API reference:** @[`StateClaudeMemoryMiddleware`], @[`FilesystemClaudeMemoryMiddleware`]

```python State-based memory
from langchain_anthropic import ChatAnthropic
from langchain_anthropic.middleware import StateClaudeMemoryMiddleware
from langchain.agents import create_agent

agent = create_agent(
    model=ChatAnthropic(model="claude-sonnet-4-6"),
    tools=[],
    middleware=[StateClaudeMemoryMiddleware()],
)
```

```python Filesystem-based memory
from langchain_anthropic import ChatAnthropic
from langchain_anthropic.middleware import FilesystemClaudeMemoryMiddleware
from langchain.agents import create_agent

agent_fs = create_agent(
    model=ChatAnthropic(model="claude-sonnet-4-6"),
    tools=[],
    middleware=[
        FilesystemClaudeMemoryMiddleware(
            root_path="/workspace",
        ),
    ],
)
```

<Accordion title="Configuration options">

**@[`StateClaudeMemoryMiddleware`]（state-based）**

<ParamField body="allowed_path_prefixes" type="Sequence[str] | None">

</ParamField>

<ParamField body="system_prompt" type="str">
    要注入的 system prompt。默认使用 Anthropic 推荐的 memory prompt，鼓励 agent 检查并更新 memory。
</ParamField>

**@[`FilesystemClaudeMemoryMiddleware`]（filesystem-based）**

<ParamField body="root_path" type="str" required>
    文件操作根目录
</ParamField>

<ParamField body="allowed_prefixes" type="list[str] | None">
    可选的允许虚拟路径前缀列表。默认值为 `["/memories"]`。
</ParamField>

<ParamField body="max_file_size_mb" type="int" default="10">
    文件最大大小，单位 MB
</ParamField>

<ParamField body="system_prompt" type="str">
    要注入的 system prompt
</ParamField>

## File search

为存储在 LangGraph state 中的文件提供 Glob 和 Grep 搜索工具。File search middleware 适用于：

- 在基于 state 的虚拟文件系统中搜索
- 与 text editor 和 memory 工具协同工作
- 按模式查找文件
- 使用正则做内容搜索

**API reference:** @[`StateFileSearchMiddleware`]

```python
from langchain_anthropic import ChatAnthropic
from langchain_anthropic.middleware import (
    StateClaudeTextEditorMiddleware,
    StateFileSearchMiddleware,
)
from langchain.agents import create_agent

agent = create_agent(
    model=ChatAnthropic(model="claude-sonnet-4-6"),
    tools=[],
    middleware=[
        StateClaudeTextEditorMiddleware(),
        StateFileSearchMiddleware(),
    ],
)
```

<Accordion title="Configuration options">

<ParamField body="state_key" type="str" default="text_editor_files">
    包含待搜索文件的 state key。对于 text editor 文件使用 `"text_editor_files"`，对于 memory 文件使用 `"memory_files"`。
</ParamField>

</Accordion>
