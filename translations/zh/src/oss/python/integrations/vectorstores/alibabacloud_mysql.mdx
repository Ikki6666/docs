>[Alibaba Cloud MySQL](https://www.alibabacloud.com/product/apsaradb-for-rds-mysql) 是一项全托管关系型数据库服务，提供高可用性、可扩展性和安全性。

>Alibaba Cloud MySQL 为企业级向量数据处理提供深度集成。它原生支持最多 16,383 维向量数据的存储与计算，集成了主流向量运算能力，并采用高度优化的 Hierarchical Navigable Small World（HNSW）算法，以高效执行近似最近邻搜索，同时支持在全维度向量列上创建索引。

本指南简要介绍如何开始使用 `AlibabaCloudMySQL` [vector store](/oss/integrations/vectorstores#overview)。有关全部功能、参数与配置的完整说明，请参阅 [langchain-alibabacloud-mysql](https://github.com/wangkuahai/langchain-alibabacloud-mysql)。

## 设置

要使用 alibabacloud-mysql 向量存储，你需要先 [create an Alibaba Cloud RDS for MySQL instance](https://www.alibabacloud.com/help/en/rds/apsaradb-rds-for-mysql/step-1-create-an-apsaradb-rds-for-mysql-instance-and-configure-databases)，且次版本号为 8.0.36 或更高，同时 [open the vector feature](https://www.alibabacloud.com/help/en/rds/apsaradb-rds-for-mysql/vector-storage-1#:~:text=restarting%20the%20instance.-,Enable%20and%20use%20the%20feature,-Note)，[make it accessible](https://www.alibabacloud.com/help/en/rds/apsaradb-rds-for-mysql/step-2-connect-to-an-apsaradb-rds-for-mysql-instance)，并安装 `langchain-alibabacloud-mysql` 集成包。

### 凭证

连接到 Alibaba Cloud RDS MySQL 实例时，需要设置以下环境变量：

- `ALIBABACLOUD_MYSQL_HOST`：RDS MySQL 主机地址
- `ALIBABACLOUD_MYSQL_PORT`：MySQL 端口，默认 `3306`
- `ALIBABACLOUD_MYSQL_USER`：MySQL 用户名
- `ALIBABACLOUD_MYSQL_PASSWORD`：MySQL 密码
- `ALIBABACLOUD_MYSQL_DATABASE`：数据库名称

### 安装

LangChain 的 alibabacloud-mysql 集成位于 `langchain-alibabacloud-mysql` 包中：

<CodeGroup>
    ```python pip
    pip install -U langchain-alibabacloud-mysql
    ```
    ```python uv
    uv add langchain-alibabacloud-mysql
    ```
</CodeGroup>

## 实例化

现在我们可以使用你的 RDS MySQL 连接信息来实例化这个向量存储：

<LangchainCommunityUnmaintained />

```python Initialize vector store icon="database"
import os
from langchain_alibabacloud_mysql import AlibabaCloudMySQL
from langchain_community.embeddings import DashScopeEmbeddings

embeddings = DashScopeEmbeddings(
    model="text-embedding-v4",
    dashscope_api_key=os.environ.get("DASHSCOPE_API_KEY"),
)

vector_store = AlibabaCloudMySQL(
    host=os.environ.get("ALIBABACLOUD_MYSQL_HOST", "localhost"),
    port=int(os.environ.get("ALIBABACLOUD_MYSQL_PORT", "3306")),
    user=os.environ.get("ALIBABACLOUD_MYSQL_USER", "root"),
    password=os.environ.get("ALIBABACLOUD_MYSQL_PASSWORD", ""),
    database=os.environ.get("ALIBABACLOUD_MYSQL_DATABASE", "test"),
    embedding=embeddings,
    table_name="langchain_vectors",
    distance_strategy="cosine",
    hnsw_m=6,
)
```

<Note>
实例化向量存储时，需要提供一个 embedding 模型。你可以使用 DashScope embeddings（推荐用于 Alibaba Cloud），也可以使用 LangChain 中接入的其他 embedding 模型，例如 OpenAI。
如果你选择使用 dashscope 模型，可以 [get your API key from Model Studio](https://modelstudio.console.aliyun.com/?tab=dashboard#/api-key)，并在代码中进行设置。
</Note>

## 管理向量存储

### 添加条目

```python Add documents icon="folder-plus"
from langchain_core.documents import Document

document_1 = Document(page_content="Alibaba", metadata={"source": "https://example.com"})
document_2 = Document(page_content="Cloud", metadata={"source": "https://example.com"})
document_3 = Document(page_content="RDS for MySQL", metadata={"source": "https://example.com"})
documents = [document_1, document_2, document_3]

vector_store.add_documents(documents=documents, ids=["1", "2", "3"])
```

### 更新条目

```python Update document by ID icon="pencil"
updated_document = Document(
    page_content="Alibaba Cloud", metadata={"source": "https://another-example.com"}
)

vector_store.update_documents(document_id="1", document=updated_document)
```

### 删除条目

```python Delete documents by IDs icon="trash"
vector_store.delete(ids=["3"])
```

## 查询向量存储

创建好向量存储并写入文档后，通常你会在 chain 或 agent 运行时对其进行查询。

### 直接查询

执行简单相似度搜索：

```python Similarity search icon="folders"
results = vector_store.similarity_search(
    query="mysql", k=1, filter={"source": "https://example.com"}
)
for doc in results:
    print(f"* {doc.page_content} [{doc.metadata}]")
```

如果你希望在相似度搜索时同时获得分数，可以这样做：

```python Similarity search with scores icon="star-half"
results = vector_store.similarity_search_with_score(
    query="mysql", k=1, filter={"source": "https://example.com"}
)
for doc, score in results:
    print(f"* [SIM={score:3f}] {doc.page_content} [{doc.metadata}]")
```

### 转成 retriever

你也可以把 vector store 转成 retriever，以便在 chain 中更方便地使用。

```python Create retriever icon="robot"
retriever = vector_store.as_retriever(search_type="mmr", search_kwargs={"k": 1})
retriever.invoke("alibaba")
```

| **IDs in add Documents** | ✅ |

### 元数据过滤

你可以用字典风格的过滤器，按元数据过滤搜索结果：

```python Filter by metadata icon="filter"
results = vector_store.similarity_search(
    query="technology",
    k=5,
    filter={"category": "tech", "year": {"$gte": 2023}}
)
```

支持的过滤操作符：

- `$eq`：等于
- `$ne`：不等于
- `$gt`：大于
- `$gte`：大于等于
- `$lt`：小于
- `$lte`：小于等于
- `$in`：在列表中
- `$nin`：不在列表中
- `$like`：LIKE 模式匹配

### 最大边际相关性（MMR）搜索

MMR 搜索通过平衡相关性与多样性，返回更丰富的结果：

```python MMR search icon="chart-bar"
results = vector_store.max_marginal_relevance_search(
    query="artificial intelligence",
    k=4,
    fetch_k=20,
    lambda_mult=0.5,
)
```

### 批量操作

高效地一次性添加多个文档：

```python Batch add documents icon="folder-plus"
texts = ["Document 1", "Document 2", "Document 3"]
metadatas = [
    {"source": "doc1.pdf"},
    {"source": "doc2.pdf"},
    {"source": "doc3.pdf"},
]
ids = vector_store.add_texts(texts, metadatas=metadatas)
```

### 按 ID 获取文档

```python Get by IDs icon="tags"
documents = vector_store.get_by_ids(["id1", "id2", "id3"])
for doc in documents:
    print(f"{doc.page_content} - {doc.metadata}")
```

### 计数与清空

获取向量总数，或清空所有数据：

```python Count and clear icon="server"
count = vector_store.count()
print(f"Total vectors: {count}")

vector_store.clear()
```
