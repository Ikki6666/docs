>Teradata Vector Store 专为在企业数据平台中高效存储、索引和检索高维向量嵌入而设计。

本指南将带你快速上手 TeradataVectorStore，用于语义搜索和 RAG 应用。无论你是第一次接触 Teradata，还是想为现有数据工作流引入 AI 能力，本指南都会带你完成需要了解的核心内容。

**TeradataVectorStore 的特别之处是什么？**
- 构建于企业级的 Teradata Vantage 平台之上。
- 与现有数据仓库无缝集成。
- 支持多种向量搜索算法，适用于不同用例。
- 可从原型扩展到生产级工作负载。

## 设置

在开始之前，需要安装必要的软件包。TeradataVectorStore 属于 `langchain-teradata` 软件包的一部分，该包还包含其他面向 LangChain 的 Teradata 集成。

**第一次接触 Teradata？** 可参考：
- [Teradata VantageCloud Lake](https://www.teradata.com/platform/vantagecloud)
- 通过 [VantageCloud Lake](https://docs.teradata.com/r/Lake-Getting-Started-with-VantageCloud-Lake/) 快速开始

### 安装


    ```python pip
    pip install langchain-teradata
    ```

### 凭证

**连接到 Teradata：** `create_context()` 函数会建立与 Teradata Vantage 系统的连接。这样 teradataml（以及基于它的 TeradataVectorStore）就知道该连接哪个数据库并如何认证。

**你需要准备：**
- **hostname**：你的 Teradata 系统地址
- **username/password**：数据库凭证
- **base_url**：Teradata 系统的 API endpoint
- **pat_token**：用于 API 认证的 Personal Access Token
- **pem_file**：用于安全连接的 SSL 证书文件

**更多信息** 请参阅 [Teradata Vector Store User Guide](https://docs.teradata.com/r/Enterprise_IntelliFlex_VMware/Teradata-Vector-Store-User-Guide/Setting-up-Vector-Store/Required-Privileges)，获取详细设置说明。

**关于 teradataml 的信息** 请参阅 [TeradataML User Guide](https://docs.teradata.com/r/Enterprise_IntelliFlex_VMware/Teradata-Package-for-Python-User-Guide/Introduction-to-Teradata-Package-for-Python)

```python
import os
from getpass import getpass
from teradataml import create_context

os.environ['TD_HOST'] = getpass(prompt='hostname: ')
os.environ['TD_USERNAME'] = getpass(prompt='username: ')
os.environ['TD_PASSWORD'] = getpass(prompt='password: ')
os.environ['TD_BASE_URL'] = getpass(prompt='base_url: ')
os.environ['TD_PAT_TOKEN'] = getpass(prompt='pat_token: ')
os.environ['TD_PEM_FILE'] = getpass(prompt='pem_file: ')
create_context()
```

## 实例化

**初始化 embeddings**

**TeradataVectorStore 支持三类 embedding 对象：**
1. **字符串标识符**，例如 `"amazon.titan-embed-text-v1"`
2. **TeradataAI objects**
3. **LangChain embedding objects**，也就是兼容 LangChain 的嵌入模型对象

```python
# Initialize embeddings
from langchain_aws import BedrockEmbeddings
embeddings = BedrockEmbeddings(model_id="amazon.titan-embed-text-v1", region_name="us-west-2")
```

**创建你的第一个向量存储**

下面先准备一些示例 `Document`，然后创建一个向量存储。`from_documents()` 是最直接的入门方式之一，只需传入文档，剩下的由 TeradataVectorStore 自动处理。

**底层会发生什么：**
- 文档会被转换为 Teradataml Dataframe，并传入向量存储
- 会为每个 `Document` 对象生成并存储嵌入
- 系统会自动创建索引，以便执行高效的相似度搜索和聊天操作

```python
from langchain_teradata import TeradataVectorStore
from langchain_core.documents import Document
# Sample documents about different topics
docs = [
    Document(page_content="Teradata provides scalable data analytics solutions for enterprises."),
    Document(page_content="Machine learning models require high-quality training data to perform well."),
    Document(page_content="Vector databases enable semantic search capabilities beyond keyword matching."),
    Document(page_content="LangChain simplifies building applications with large language models."),
    Document(page_content="Data warehousing has evolved to support real-time analytics and AI workloads.")
]

# Create the vector store
vs = TeradataVectorStore.from_documents(
    name="my_knowledge_base",
    documents=docs,
    embedding=embeddings
)

print("Vector store created successfully!")
```

创建完向量存储后，最好先验证一下是否一切都已正确设置。TeradataVectorStore 提供了便捷方法来监控操作状态，并帮助你了解底层发生了什么。

**为什么要检查状态？**
- **Operation tracking**：查看向量存储当前处于哪个阶段
- **Troubleshooting**：快速定位设置过程中是否出现异常
- **Progress monitoring**：对于大数据集，可跟踪嵌入生成进度
- **Validation**：确认向量存储已经可以接收查询

```python
# Check the status of the store.
vs.status()
```

如果你想知道向量存储里到底有哪些内容，`get_details()` 方法会返回一个完整概览，可以把它理解成向量存储的“仪表盘”。

**你会看到：**
- **Object inventory**：已添加的表或文档数量
- **Search parameters**：当前算法设置，例如 HNSW、K-means 等
- **Configuration details**：嵌入维度、距离度量、索引配置等
- **Performance settings**：Top-k、相似度阈值和其他查询参数

```python
vs.get_details()
```

## 管理向量存储

### 向向量存储中添加条目

TeradataVectorStore 的一大优势是扩展知识库非常方便。随着业务增长，你可以不断加入新文档，而无需推倒重建。

**现实场景中的例子：**
- 随着产品文档产出，持续将其加入知识库。
- 纳入最新的研究论文或行业报告。
- 整合客户反馈和支持文档。
- 用最新的政策或流程变更内容进行更新。

**Enterprise advantage：** 所有能力都运行在 Teradata 上，因此你可以很方便地把现有表、数据仓库或实时数据流中的内容加入进来，而不需要复杂的数据搬运。

```python
# Add more documents
additional_docs = [
    Document(page_content="Retrieval-augmented generation combines the power of search with language models."),
    Document(page_content="Teradata's vector capabilities support both structured and unstructured data analysis.")
]

vs.add_documents(documents=additional_docs)
print("Added more knowledge to the vector store!")
```

```python
# Check the status of the new store.
vs.status()
```

## 查询向量存储

在创建好向量存储并添加相关文档后，你通常会希望在链或 agent 运行过程中对其进行查询。

### 直接查询

现在来在向量存储中搜索信息。与传统关键词搜索不同，向量搜索理解的是问题背后的含义。比如你问“AI applications”，它可能返回关于“machine learning models”的结果，因为它知道这些概念在语义上相关。

**相似度搜索的工作方式：**
- 你的问题会被转换成一个向量嵌入，就像文档一样
- TeradataVectorStore 会计算问题与已存文档之间的相似度分数
- 返回最相关的结果，并按相似度排序

```python
# Ask a question
question = "What are vector databases?"
results = vs.similarity_search(question=question, return_type = "json")

print("Found relevant information:")
for result in results.similar_objects:
    print(f" {result}")
```

### 转换为检索器进行查询

你也可以把向量存储转换为检索器，以便在 chain 中更方便地使用。

```python
# Create a retriever for your RAG pipeline
retriever = vs.as_retriever(search_type="similarity")

# Test the retriever
retrieved_docs = retriever.invoke("Tell me about Teradata's capabilities")

print("Retrieved documents for RAG:")
for doc in retrieved_docs:
    print(f"- {doc.page_content}")
```

## 用于检索增强生成

`ask()` 将向量搜索与语言模型生成能力结合起来。它返回的不只是原始文档片段，而是更连贯、带上下文的答案。

**两步流程：**
1. **Retrieval**：从向量存储中找出最相关的文档
2. **Generation**：用这些文档作为上下文生成自然语言回答

**为什么这很强大：** 你的 AI 回答会建立在真实数据之上，降低幻觉风险并提高准确性。它有点像一个真正读过公司文档的智能助手。

```python
# Get a comprehensive answer
response = vs.ask(question="What are the benefits of using vector databases?")
print("AI Response:")
print(response)
```

Retrieval-Augmented Generation（RAG）是现代 AI 助手和聊天机器人背后的核心技术之一。TeradataVectorStore 与 LangChain 无缝集成，使构建 RAG 应用变得直接。

**好的 RAG 应用包含什么：**
- **Relevant retrieval**：向量存储能找对信息
- **Contextual generation**：语言模型能有效利用这些信息
- **Source transparency**：用户能知道答案来自哪里


**它与 TeradataVectorStore 的结合方式：**
- 你可以把向量存储作为 retriever，先取回最相关的文档，再把这些文档传给 LangChain 工作流中的 RAG chain。
- 这样既能保留构建自定义 pipeline 的灵活性，也能充分利用 Teradata 强大的向量搜索能力。

下面构建一个完整的 RAG pipeline，把 TeradataVectorStore retriever 与语言模型组合起来，演示 RAG 的完整能力：先从向量存储中检索相关信息，再基于这些信息生成答案。

**这个 pipeline 中发生了什么：**

- Retrieval：向量存储找出与问题最相关的文档
- Context preparation：这些文档被组装成语言模型上下文
- Generation：语言模型基于你的真实数据生成回答
- Output parsing：得到可直接用于应用的干净输出


**现实应用场景：**

- Customer support：基于产品文档自动回答问题
- Research assistance：查询组织内部知识库
- Compliance：确保回答建立在公司批准的信息之上

```python
from langchain_core.runnables import RunnablePassthrough
from langchain_core.prompts import PromptTemplate
from langchain_core.output_parsers import StrOutputParser
from langchain.chat_models import init_chat_model

#Example: Simple RAG chain
# Initialize the chat model
llm = init_chat_model("anthropic.claude-3-5-sonnet-20240620-v1:0",
                      model_provider="bedrock_converse",
                      region_name="<ENTER REGION>",
                      aws_access_key_id = "<ENTER AWS ACCESS KEY>" ,
                      aws_secret_access_key = "<ENTER AWS SECRET KEY>"
                      )


# Create a prompt template for the LLM to format its response using retrieved context
prompt = PromptTemplate.from_template(
    "Use the following context to answer the question.\nContext:\n{context}\n\nQuestion: {question}\nAnswer:"
)

# Build the RAG chain: retrieve context, format prompt, generate answer, and parse output
rag_chain = (
    {
        "context": retriever,
        "question": RunnablePassthrough()
    }
    | prompt
    | llm
    | StrOutputParser()
)

# Invoke the RAG chain with a sample question and print the response
response = rag_chain.invoke("Benefits of Vector Store")
print(response)
```

## 处理不同数据类型

TeradataVectorStore 在处理不同类型数据源时尤其灵活。根据你的起点不同，可以选择最适合的方法。

**如何选择起点：**
- **已有 PDF 文档？** 使用 `from_documents()` 搭配文件路径。
- **正在处理数据库表？** 使用 `from_datasets()` 搭配 DataFrame。
- **已经有 embeddings？** 使用 `from_embeddings()` 直接导入。

### 从 PDF 文件创建
```python
# File-based vector store from PDFs
pdf_vs = TeradataVectorStore.from_documents(
    name="pdf_knowledge",
    documents="path/to/your/document.pdf",  # or list of PDF paths
    embedding=embeddings
)
```

### 从数据库表创建
```python
# Content-based from existing tables
from teradataml import DataFrame
table_data = DataFrame('your_table_name')

table_vs = TeradataVectorStore.from_datasets(
    name="table_knowledge",
    data=table_data,
    data_columns=["text_column"],
    embedding=embeddings
)
```

### 从预先计算好的 embeddings 创建
```python
# If you already have embeddings
embedding_vs = TeradataVectorStore.from_embeddings(
    name="embedding_store",
    data=your_embedding_data,
    data_columns="embedding_column"
)
```

***Note*** <br />
处理表（以及嵌入表）时，`data_columns` 参数是必填项。它用于明确告诉 TeradataVectorStore 哪些列包含要转换成嵌入的文本内容。

例如，如果你的表里有 `id`、`title`、`description` 和 `category` 这些列，那么可设置 `data_columns=["description"]` 只嵌入描述列，或者设置 `data_columns=["title", "description"]` 把两个字段一起作为内容。

下面是一个小示例：使用 `teradatagenai` 加载样例表，并基于它创建 content based store。这里我们把 `"rev_text"` 列作为 `data_columns`，它会被用来生成嵌入。

```python
from teradatagenai import load_data

# Load sample data into Teradata
load_data("byom", "amazon_reviews_25")

# Create a vector store from the Teradata table
td_vs = TeradataVectorStore.from_datasets(
    name="table_store_amazon",
    data="amazon_reviews_25",
    data_columns="rev_text",
    embedding=embeddings)
```

```python
# Check the status of the new store
td_vs.status()
```
