>[Gel](https://www.geldata.com/) 是一个开源 PostgreSQL 数据层，针对从快速开发到生产落地的全流程进行了优化。它提供高级、强类型、类图结构的数据模型，可组合的分层查询语言，完整 SQL 支持，以及 migrations、Auth 和 AI 模块。

本页介绍如何使用 `Gel` 作为 LangChain 向量存储的后端实现。

相关代码位于集成包 [langchain-gel](https://github.com/geldata/langchain-gel) 中。

## 设置

首先安装相关依赖：

```python
! pip install -qU gel langchain-gel
```

## 初始化

要将 Gel 用作你的 `VectorStore` 后端，需要先准备一个可用的 Gel 实例。
好消息是，这不一定需要 Docker 容器或复杂配置，除非你希望这样做。

如需设置本地实例，请运行：

```python
! gel project init --non-interactive
```

如果你使用的是 [Gel Cloud](https://cloud.geldata.com/) ，请在命令中再加一个参数：

```bash
gel project init --server-instance <org-name>/<instance-name>
```

如需查看运行 Gel 的完整方式，请参阅参考文档中的 [Running Gel](https://docs.geldata.com/reference/running)。

### 设置 schema

[Gel schema](https://docs.geldata.com/reference/datamodel) 是对应用数据模型的显式高级描述。
除了让你精确定义数据的组织方式，它还驱动了 Gel 的许多强大能力，例如 links、access policies、functions、triggers、constraints 和 indexes。

LangChain 的 @[`VectorStore`] 期望 schema 采用如下结构：

```python
schema_content = """
using extension pgvector;

module default {
    scalar type EmbeddingVector extending ext::pgvector::vector<1536>;

    type Record {
        required collection: str;
        text: str;
        embedding: EmbeddingVector;
        external_id: str {
            constraint exclusive;
        };
        metadata: json;

        index ext::pgvector::hnsw_cosine(m := 16, ef_construction := 128)
            on (.embedding)
    }
}
""".strip()

with open("dbschema/default.gel", "w") as f:
    f.write(schema_content)
```

要把 schema 变更应用到数据库中，请通过 Gel 的 [migration 机制](https://docs.geldata.com/reference/datamodel/migrations)运行迁移：

```python
! gel migration create --non-interactive
! gel migrate
```

从这一步开始，`GelVectorStore` 就可以作为 LangChain 中其他向量存储的直接替代方案来使用。

## 管理向量存储

### 向向量存储添加条目

注意，按 ID 添加文档时，如果已有相同 ID 的文档，会被覆盖。

```python

docs = [
    Document(
        page_content="there are cats in the pond",
        metadata={"id": "1", "location": "pond", "topic": "animals"},
    ),
    Document(
        page_content="ducks are also found in the pond",
        metadata={"id": "2", "location": "pond", "topic": "animals"},
    ),
    Document(
        page_content="fresh apples are available at the market",
        metadata={"id": "3", "location": "market", "topic": "food"},
    ),
    Document(
        page_content="the market also sells fresh oranges",
        metadata={"id": "4", "location": "market", "topic": "food"},
    ),
    Document(
        page_content="the new art exhibit is fascinating",
        metadata={"id": "5", "location": "museum", "topic": "art"},
    ),
    Document(
        page_content="a sculpture exhibit is also at the museum",
        metadata={"id": "6", "location": "museum", "topic": "art"},
    ),
    Document(
        page_content="a new coffee shop opened on Main Street",
        metadata={"id": "7", "location": "Main Street", "topic": "food"},
    ),
    Document(
        page_content="the book club meets at the library",
        metadata={"id": "8", "location": "library", "topic": "reading"},
    ),
    Document(
        page_content="the library hosts a weekly story time for kids",
        metadata={"id": "9", "location": "library", "topic": "reading"},

vector_store.add_documents(docs, ids=[doc.metadata["id"] for doc in docs])
```

### 从向量存储删除条目

```python
vector_store.delete(ids=["3"])
```

## 查询向量存储

创建好向量存储并写入相关文档后，通常会在 chain 或 agent 运行期间对其进行查询。

### 过滤支持

该向量存储支持一组可应用于文档 metadata 字段的过滤器。

| Operator | 含义/类别 |
|----------|-----------|
| \$eq | 相等（==） |
| \$ne | 不相等（!=） |
| \$lt | 小于 (&lt;) |
| \$lte | 小于等于 (&lt;=) |
| \$gt | 大于 (>) |
| \$gte | 大于等于 (>=) |
| \$in | 特殊处理（in） |
| \$nin | 特殊处理（not in） |
| \$between | 特殊处理（between） |
| \$like | 文本（like） |
| \$ilike | 文本（不区分大小写 like） |
| \$and | 逻辑（and） |
| \$or | 逻辑（or） |

### 直接查询

你可以像下面这样执行一个简单的相似度搜索：

```python
results = vector_store.similarity_search(
    "kitty", k=10, filter={"id": {"$in": ["1", "5", "2", "9"]}}
)
for doc in results:
    print(f"* {doc.page_content} [{doc.metadata}]")
```

如果你传入的是一个包含多个字段、但没有显式操作符的字典，顶层会被解释为逻辑 **AND** 过滤：

```python
vector_store.similarity_search(
    "ducks",
    k=10,
    filter={
        "id": {"$in": ["1", "5", "2", "9"]},
        "location": {"$in": ["pond", "market"]},
    },
)
```

```python
vector_store.similarity_search(
    "ducks",
    k=10,
    filter={
        "$and": [
            {"id": {"$in": ["1", "5", "2", "9"]}},
            {"location": {"$in": ["pond", "market"]}},
        ]
    },
)
```

如果你希望执行相似度搜索并同时返回对应分数，可以运行：

```python
results = vector_store.similarity_search_with_score(query="cats", k=1)
for doc, score in results:
    print(f"* [SIM={score:3f}] {doc.page_content} [{doc.metadata}]")
```

### 转换为 retriever 后查询

你也可以把向量存储转换成 retriever，以便在 chain 中更方便地使用。

```python
retriever = vector_store.as_retriever(search_kwargs={"k": 1})
retriever.invoke("kitty")
```
