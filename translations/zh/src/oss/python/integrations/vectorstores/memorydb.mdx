## 什么是 Amazon MemoryDB？

MemoryDB 与 Redis OSS 兼容。Redis OSS 是一种流行的开源数据存储，因此你可以使用现有的 Redis OSS 数据结构、API 和命令快速构建应用。MemoryDB 将所有数据保存在内存中，从而实现微秒级读取、个位数毫秒级写入延迟以及高吞吐量。MemoryDB 还通过 Multi-AZ 事务日志在多个可用区（AZ）之间持久存储数据，以支持快速故障转移、数据库恢复和节点重启。

## MemoryDB 的向量搜索

MemoryDB 的向量搜索扩展了 MemoryDB 的功能，并可与现有的 MemoryDB 功能配合使用。不使用向量搜索的应用不会受到影响。向量搜索在所有支持 MemoryDB 的区域中均可用。你可以使用现有的 MemoryDB 数据或 Redis OSS API 来构建机器学习和生成式 AI 用例，例如检索增强生成、异常检测、文档检索和实时推荐。

* 对 Redis hashes 和 `JSON` 中的多个字段建立索引
* 向量相似度搜索（支持 `HNSW`（ANN）或 `FLAT`（KNN））
* 向量范围搜索（例如查找查询向量半径范围内的所有向量）
* 无性能损失的增量索引

## 设置

### 安装 Redis Python 客户端

`Redis-py` 是一个 Python 客户端，可用于连接 MemoryDB。

```python
pip install -qU  redis langchain-aws
```

```python
from langchain_aws.embeddings import BedrockEmbeddings

embeddings = BedrockEmbeddings()
```

### MemoryDB 连接

有效的 Redis URL schema 包括：

1. `redis://`  - 连接到未加密的 Redis 集群
2. `rediss://` - 连接到启用了 TLS 加密的 Redis 集群

有关更多连接参数的信息，请参阅 [redis-py documentation](https://redis-py.readthedocs.io/en/stable/connections.html)。

### 创建 MemoryDB 向量存储

可以通过以下方式初始化 `InMemoryVectorStore` 实例：
* `InMemoryVectorStore.__init__` - 直接初始化
* `InMemoryVectorStore.from_documents` - 从 `LangChain.docstore.Document` 对象列表初始化
* `InMemoryVectorStore.from_texts` - 从文本列表初始化，可选附带元数据
* `InMemoryVectorStore.from_existing_index` - 从已有的 MemoryDB 索引初始化

```python
from langchain_aws.vectorstores.inmemorydb import InMemoryVectorStore

vds = InMemoryVectorStore.from_texts(
    embeddings,
    redis_url="rediss://cluster_endpoint:6379/ssl=True ssl_cert_reqs=none",
)
```

```python

```

```text
'users'
```

## 查询

`InMemoryVectorStore` 提供多种查询方式，可覆盖不同使用场景：

* `similarity_search`：查找与给定向量最相似的向量
* `similarity_search_with_score`：查找最相似的向量并返回向量距离
* `similarity_search_limit_score`：查找最相似的向量，并通过 `score_threshold` 限制返回结果
* `similarity_search_with_relevance_scores`：查找最相似的向量并返回相似度
* `max_marginal_relevance_search`：在查找最相似向量的同时优化结果多样性

```python
results = vds.similarity_search("foo")
print(results[0].page_content)
```

```text
foo
```

```python
# with scores (distances)
results = vds.similarity_search_with_score("foo", k=5)
for result in results:
    print(f"Content: {result[0].page_content} --- Score: {result[1]}")
```

```text
Content: foo --- Score: 0.0
Content: foo --- Score: 0.0
Content: foo --- Score: 0.0
Content: bar --- Score: 0.1566
Content: bar --- Score: 0.1566
```

```python
# limit the vector distance that can be returned
results = vds.similarity_search_with_score("foo", k=5, distance_threshold=0.1)
for result in results:
    print(f"Content: {result[0].page_content} --- Score: {result[1]}")
```

```text
Content: foo --- Score: 0.0
Content: foo --- Score: 0.0
Content: foo --- Score: 0.0
```

```python
# with scores
results = vds.similarity_search_with_relevance_scores("foo", k=5)
```


## 将 MemoryDB 用作检索器

下面展示如何使用不同方式将该向量存储作为检索器。

可以使用三种不同的检索方法，默认方式是语义相似度检索。

```python
query = "foo"
results = vds.similarity_search_with_score(query, k=3, return_metadata=True)

for result in results:
    print("Content:", result[0].page_content, " --- Score: ", result[1])
```

```text
Content: foo  --- Score:  0.0
Content: foo  --- Score:  0.0
Content: foo  --- Score:  0.0
```

```python
retriever = vds.as_retriever(search_type="similarity", search_kwargs={"k": 4})
```

```python
docs = retriever.invoke(query)
docs
```
