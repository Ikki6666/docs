# Moorcheh

[Moorcheh](https://www.moorcheh.ai/) 是一个极速语义搜索引擎和向量存储。它不使用 L2 或 Cosine 这类简单距离度量，而是通过 Maximally Informative Binarization (MIB) 和 Information-Theoretic Score (ITS) 来检索更准确的文档分块。

下面的教程将演示如何结合 Moorcheh 与 LangChain 上传并存储文本文档和向量嵌入，以及如何为你的查询检索相关分块。

## 设置

首先，安装所需软件包：

```bash
pip install langchain-moorcheh
```

## 初始化

开始使用 Moorcheh：

1. 在 [Moorcheh Console](https://console.moorcheh.ai/) 注册或登录。
2. 前往 `"API Keys"` 标签页并生成 API key。
3. 将该 key 保存为名为 `MOORCHEH_API_KEY` 的环境变量，下面会用到。
4. 若要创建一个用于存储数据的 namespace：
   - 在 Console 中打开 `"Namespaces"` 标签页并点击 `"Create namespace"`；或
   - 在下一节中使用向量存储代码以编程方式初始化。
5. 使用你的 API key 创建 namespace、上传文档并检索答案。

有关 Moorcheh SDK 函数的更多信息，请参阅其 [GitHub repository](https://github.com/moorcheh-ai/moorcheh-python-sdk)。

导入以下软件包：

## 代码设置

在环境变量中设置你的 Moorcheh API Key：

```python
MOORCHEH_API_KEY = os.environ['MOORCHEH_API_KEY']
```

设置 namespace 名称、类型，并创建向量存储：

```python
namespace = "your_namespace_name"
namespace_type = "text" # or vector
store = MoorchehVectorStore(
            api_key=MOORCHEH_API_KEY,
            namespace=namespace,
            namespace_type=namespace_type
        )
```

## 查询引擎

当你创建好 namespace 并把文档上传进去后，就可以直接通过向量存储对文档发起查询。设置好查询内容和你希望回答查询的 LLM。关于支持的 LLM，请参阅我们的 [GitHub page](https://github.com/moorcheh-ai/moorcheh-python-sdk)。

```python
query = "Give me a brief summary of the provided documents"
answer = store.generative_answer(query, ai_model = "anthropic.claude-sonnet-4-6")
print(answer)
```
