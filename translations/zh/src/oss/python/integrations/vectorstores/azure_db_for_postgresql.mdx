[Azure Database for PostgreSQL - Flexible Server](https://learn.microsoft.com/en-us/azure/postgresql/flexible-server/service-overview) 是一个基于开源 Postgres 数据库引擎的关系型数据库服务。它是一种完全托管的数据库即服务，能够以可预测的性能、安全性、高可用性和动态伸缩能力来支撑关键任务工作负载。

本指南展示了如何利用这个集成的[向量数据库](https://learn.microsoft.com/en-us/azure/postgresql/flexible-server/how-to-use-pgvector)，在集合中存储文档、创建索引，并使用 Cosine Distance、L2（欧几里得距离）和 IP（内积）等近似最近邻算法执行向量搜索查询，以定位与查询向量接近的文档。

## 向量支持

Azure Database for PostgreSQL - Flexible Server 使你能够在 PostgreSQL 中高效存储和查询数百万个向量嵌入，并将 AI 用例从 POC 扩展到生产环境：

* 提供熟悉的 SQL 接口，用于查询向量嵌入和关系型数据。
* 使用 [DiskANN 索引算法](https://aka.ms/pg-diskann-docs)，为 1 亿以上向量提供更快、更精确的 `pgvector` 相似度搜索。
* 将关系型元数据、向量嵌入和时序数据整合到单一数据库中，从而简化运维。
* 利用强大的 PostgreSQL 生态与 Azure Cloud，提供包括复制和高可用在内的企业级能力。

## 认证

Azure Database for PostgreSQL - Flexible Server 同时支持基于密码的认证，以及 [Microsoft Entra](https://learn.microsoft.com/en-us/azure/postgresql/flexible-server/concepts-azure-ad-authentication)（原 Azure Active Directory）认证。

Entra 认证允许你使用 Entra 身份对 PostgreSQL 服务器进行认证。这样就不需要为数据库用户单独管理用户名和密码，同时还能复用你为其他 Azure 服务使用的相同安全机制。

本指南已配置为可使用任一认证方式。你可以在笔记本后续部分决定是否启用 Entra 认证。

## 设置

Azure Database for PostgreSQL 基于开源 Postgres。该集成使用专门的 [`langchain-azure-postgresql`](https://pypi.org/project/langchain-azure-postgresql/) 包，它提供包括 DiskANN 索引和 Microsoft Entra 认证在内的优化支持。

先安装 partner packages：

```python
pip install -qU langchain-azure-postgresql langchain-openai azure-identity
```

### 启用 pgvector

请参考 Azure Database for PostgreSQL 的 [启用说明](https://learn.microsoft.com/en-us/azure/postgresql/flexible-server/how-to-use-pgvector)。

### 设置凭证

你需要 Azure Database for PostgreSQL 的[连接信息](https://learn.microsoft.com/en-us/azure/postgresql/flexible-server/quickstart-create-server-portal#get-the-connection-information)，并将其添加为环境变量，才能运行本笔记本。

如果你想使用 Microsoft Entra 认证，请将 `USE_ENTRA_AUTH` 标志设为 `True`。如果使用 Entra 认证，只需提供主机和数据库名；如果使用密码认证，还需要设置用户名和密码。

```python
import getpass
import os

USE_ENTRA_AUTH = True

# Supply the connection details for the database
os.environ["DBHOST"] = "REPLACE_WITH_SERVER_NAME"
os.environ["DBNAME"] = "REPLACE_WITH_DATABASE_NAME"
os.environ["SSLMODE"] = "require"

if not USE_ENTRA_AUTH:
    # If using a username and password, supply them here
    os.environ["DBUSER"] = "REPLACE_WITH_USERNAME"
    os.environ["DBPASSWORD"] = getpass.getpass("Database Password:")
```

### 设置 `AzureOpenAIEmbeddings`

```python
os.environ["AZURE_OPENAI_ENDPOINT"] = "REPLACE_WITH_AZURE_OPENAI_ENDPOINT"
os.environ["AZURE_OPENAI_API_KEY"] = getpass.getpass("Azure OpenAI API Key:")
```

```python
AZURE_OPENAI_ENDPOINT = os.environ["AZURE_OPENAI_ENDPOINT"]
AZURE_OPENAI_API_KEY = os.environ["AZURE_OPENAI_API_KEY"]

from langchain_openai import AzureOpenAIEmbeddings

embeddings = AzureOpenAIEmbeddings(
    model="text-embedding-3-small",
    api_key=AZURE_OPENAI_API_KEY,
    azure_endpoint=AZURE_OPENAI_ENDPOINT,
    azure_deployment="text-embedding-3-small",
)
```

## 初始化

### 使用 Microsoft Entra 认证

下面的部分演示了如何将 LangChain 配置为使用 Microsoft Entra 认证。LangChain Azure Postgres 包中的 `AzurePGConnectionPool` 类会通过 `azure.identity` 库中的 `DefaultAzureCredential` 为 Azure Database for PostgreSQL 服务获取 token。

然后可以将该连接传入 `AzurePGVectorStore` LangChain 向量存储的 `connection` 参数。

#### 登录 Azure

要登录 Azure，请确保已安装 [Azure CLI](https://learn.microsoft.com/en-us/cli/azure/install-azure-cli)。你需要在终端中运行以下命令：

```bash
az login
```

完成登录后，下面的代码就能够获取 token。

```python
from langchain_azure_postgresql.common import (
    BasicAuth,
    AzurePGConnectionPool,
    ConnectionInfo,
)
from langchain_azure_postgresql.langchain import AzurePGVectorStore

entra_connection_pool = AzurePGConnectionPool(
    azure_conn_info=ConnectionInfo(
        host=os.environ["DBHOST"], dbname=os.environ["DBNAME"]
    )
)
```

### 密码认证

如果你不使用 Microsoft Entra 认证，可以通过 `BasicAuth` 类来使用用户名和密码：

```python
basic_auth_connection_pool = AzurePGConnectionPool(
    azure_conn_info=ConnectionInfo(
        host=os.environ["DBHOST"],
        dbname=os.environ["DBNAME"],
        credentials=BasicAuth(
            username=os.environ["DBUSER"],
            password=os.environ["DBPASSWORD"],
        ),
    )
)
```

### 创建向量存储

```python
from langchain_core.documents import Document
from langchain_azure_postgresql.langchain import AzurePGVectorStore

table_name = "my_docs"

# The connection is either using Entra ID or Basic Auth
connection = entra_connection_pool if USE_ENTRA_AUTH else basic_auth_connection_pool

vector_store = AzurePGVectorStore(
    embedding=embeddings,
    table_name=table_name,
    connection=connection,
)
```

```text
Metadata columns are specified as a string, defaulting to 'jsonb' type.
Embedding type is not specified, defaulting to 'vector'.
Embedding dimension is not specified, defaulting to 1536.
Embedding index is not specified, defaulting to 'DiskANN' with 'vector_cosine_ops' opclass.
```

## 配置向量存储参数

初始化 `AzurePGVectorStore` 时，你可以覆盖元数据类型、嵌入维度、索引类型等默认参数。这使你能够根据具体用例和数据来定制向量存储。

**关键配置项：**

- `metadata_column_type`：元数据列的类型（默认：`'jsonb'`）。可设为 `'jsonb'`、`'text'` 等。
- `embedding_column_type`：嵌入列的类型（默认：`'vector'`）。
- `embedding_dimension`：嵌入向量的维度（默认：`1536`）。
- `embedding_index_type`：向量搜索的索引类型（默认：`'DiskANN'`）。其他选项可能包括 `'ivfflat'`、`'hnsw'` 等。
- `embedding_index_opclass`：索引使用的 operator class（默认：`'vector_cosine_ops'`）。

**示例：**

```python
vector_store = AzurePGVectorStore(
    embedding=embeddings,
    table_name=table_name,
    connection=connection,
    metadata_column_type="jsonb",           # or "text"
    embedding_column_type="vector",
    embedding_dimension=768,                # set to match your model's output
    embedding_index_type="DiskANN",         # or "ivfflat", "hnsw", etc.
    embedding_index_opclass="vector_cosine_ops",  # or "vector_l2_ops", etc.
)
```

## 初始化 DiskANN 向量索引，以获得更高效的向量搜索

[DiskANN](https://aka.ms/pg-diskann-blog) 是一种可扩展的近似最近邻搜索算法，可在任意规模下实现高效向量搜索。它具备高召回率、高每秒查询数和低查询延迟，即便面对十亿级数据集也是如此。这些特性使其成为处理大规模数据的强大工具。

```python
vector_store.create_index()
```

```text
True
```

## 查询向量存储

创建向量存储并添加相关文档后，你就可以在 chain 或 agent 中查询该向量存储。

### 过滤

该向量存储支持通过 [LangChain Azure PostgreSQL](https://pypi.org/project/langchain-azure-postgresql/) 包中的 `FilterCondition`、`OrFilter` 和 `AndFilter`，对文档元数据字段应用一组过滤器：

| Operator | Meaning/Category                |
| -------- | ------------------------------- |
| `=`      | Equality                    |
| `!=`      | Inequality                  |
| `<`      | Less than                    |
| `<=`     | Less than or equal          |
| `>`      | Greater than                 |
| `>=`     | Greater than or equal      |
| `in`      | Special cased (in)              |
| `not in`     | Special cased (not in)          |
| `is null`     | Special cased (is null)          |
| `is not null`     | Special cased (is not null)          |
| `between` | Special cased (between)         |
| `not between` | Special cased (not between)         |
| `like`    | Text (like)                     |
| `ilike`   | Text (case-insensitive like)    |
| `AND`     | Logical (and)                   |
| `OR`      | Logical (or)                    |

### 直接查询

执行简单的相似度搜索可以像下面这样：

```python
from langchain_azure_postgresql import FilterCondition, AndFilter

results = vector_store.similarity_search(
    "kitty",
    k=10,
    filter=FilterCondition(
        column="(metadata->>'doc_id')::int",
        operator="in",
        value=[1, 5, 2, 9],
    ),
)

for doc in results:
    print("* " + doc.page_content + " [" + str(doc.metadata) + "]")
```

```text
* there are cats in the pond [{'topic': 'animals', 'doc_id': 1, 'location': 'pond'}]
* ducks are also found in the pond [{'topic': 'animals', 'doc_id': 2, 'location': 'pond'}]
* the new art exhibit is fascinating [{'topic': 'art', 'doc_id': 5, 'location': 'museum'}]
* the library hosts a weekly story time for kids [{'topic': 'reading', 'doc_id': 9, 'location': 'library'}]
```

如果你想使用逻辑 `AND` 过滤器，可以参考下面的示例：

```python
results = vector_store.similarity_search(
    "ducks",
    k=10,
    filter=AndFilter(
        AND=[
            FilterCondition(
                column="(metadata->>'doc_id')::int",
                operator="in",
                value=[1, 5, 2, 9],
            ),
            FilterCondition(
                column="metadata->>'location'",
                operator="in",
                value=["pond", "market"],
            ),
        ]
    ),
)

for doc in results:
    print("* " + doc.page_content + " [" + str(doc.metadata) + "]")
```

```text
* ducks are also found in the pond [{'topic': 'animals', 'doc_id': 2, 'location': 'pond'}]
* there are cats in the pond [{'topic': 'animals', 'doc_id': 1, 'location': 'pond'}]
```

如果你想执行相似度搜索并同时获得对应分数，可以运行：

```python
results = vector_store.similarity_search_with_score(query="cats", k=1)
for doc, score in results:
    print(f"* [SIM={score:3f}] {doc.page_content} [{doc.metadata}]")
```

```text
* [SIM=0.528167] there are cats in the pond [{'topic': 'animals', 'doc_id': 1, 'location': 'pond'}]
```

### 转换为 retriever 后查询

你也可以把向量存储转换为 retriever，以便更方便地在 chain 中使用。

```python
retriever = vector_store.as_retriever(search_kwargs={"k": 1})
retriever.invoke("kitty")
```

```text
[Document(id='00e2cfe6-6e58-4733-9ebf-a708fd16488a', metadata={'topic': 'animals', 'doc_id': 1, 'location': 'pond'}, page_content='there are cats in the pond')]
```

如果你想在向量存储上使用最大边际相关性搜索，可以这样做：

```python
results = vector_store.max_marginal_relevance_search(
    "query about cats",
    k=10,
    lambda_mult=0.5,
    filter=FilterCondition(
        column="(metadata->>'doc_id')::int",
        operator="in",
        value=[1, 2, 5, 9],
    ),
)

for doc in results:
    print("* " + doc.page_content + " [" + str(doc.metadata) + "]")
```

```text
* there are cats in the pond [{'topic': 'animals', 'doc_id': 1, 'location': 'pond'}]
* the new art exhibit is fascinating [{'topic': 'art', 'doc_id': 5, 'location': 'museum'}]
* the library hosts a weekly story time for kids [{'topic': 'reading', 'doc_id': 9, 'location': 'library'}]

```
