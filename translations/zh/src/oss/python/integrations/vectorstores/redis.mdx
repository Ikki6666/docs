>[Redis](https://redis.io/docs/latest/) 是一个内存数据平台，提供向量搜索、全文搜索和语义缓存能力，专为实时 AI 应用设计。

本笔记介绍如何使用与 `RedisVectorStore` 相关的功能。

## 设置

要使用 `RedisVectorStore`，首先需要安装 partner package，以及本笔记中会用到的其他软件包。

```bash
pip install -qU langchain-redis langchain-openai
```

你需要一个启用了 Redis Search 功能的 Redis 实例。我们建议使用 Redis 8.4+。你可以用 Docker 在本地启动一个：

```bash
docker run -d --name redis -p 6379:6379 redis:8.4
```

或者使用 [Redis Cloud](https://redis.io/cloud/) 来获取托管部署。

（可选）下载 [RedisInsight](https://redis.io/insight/)，这是一个基于浏览器的 GUI，可用于查看你的数据和索引。

```bash
docker run -d --name redisinsight -p 5540:5540 redis/redisinsight:latest
```

### 凭证

通过设置下列环境变量来配置 Redis 连接：

```bash
export REDIS_URL="redis://localhost:6379"
```

如果 Redis 启用了认证：

```bash
export REDIS_URL="redis://username:password@localhost:6379"
```

如果使用 Redis Cloud，请使用数据库控制台提供的连接字符串：

```bash
export REDIS_URL="redis://default:<password>@<host>:<port>"
```

该软件包还支持 SSL/TLS（`rediss://`）和高可用 Redis Sentinel 部署（`redis+sentinel://`）。完整连接选项请参阅 [langchain-redis README](https://github.com/langchain-ai/langchain-redis/blob/main/libs/redis/README.md#redis-connection-options)。

设置你的 OpenAI API key：

```bash
export OPENAI_API_KEY="your-api-key-here"
```

<Tip>
[`langchain-redis`](https://github.com/langchain-ai/langchain-redis/blob/main/libs/redis/README.md) 软件包还提供 `RedisChatMessageHistory` 用于会话记忆，以及 `RedisSemanticCache` 用于 LLM 响应缓存，它们都可以与向量存储共用同一个 Redis 实例。
</Tip>

## 初始化

```python
import os
from langchain_openai import OpenAIEmbeddings

embeddings = OpenAIEmbeddings(model="text-embedding-3-small")
```

```python
from langchain_redis import RedisConfig, RedisVectorStore

config = RedisConfig(
    index_name="my_vectors",
    redis_url=os.getenv("REDIS_URL", "redis://localhost:6379"),
    distance_metric="COSINE",  # Options: COSINE, L2, IP
    metadata_schema=[
        {"name": "baz", "type": "tag"},
        {"name": "foo", "type": "tag"},
    ]
)

vector_store = RedisVectorStore(embeddings=embeddings, config=config)
```

<Note>
`metadata_schema` 参数用于告诉 Redis 哪些元数据字段需要建立索引。未列出的字段无法用于过滤。对于分类字符串值，请使用 `"tag"`；对于数值，请使用 `"numeric"`。
</Note>

## 管理向量存储

### 向向量存储中添加条目

```python
texts = ["foo", "bar"]
metadatas = [{"baz": "bar"}, {"foo": "baz"}]
vector_store.add_texts(texts, metadatas=metadatas)
```

你也可以使用自定义 key 添加文本：

```python
custom_keys = ["doc1", "doc2"]
vector_store.add_texts(texts, metadatas=metadatas, keys=custom_keys)
```

或者配合 LangChain `Document` 对象使用 `add_documents`：

```python
from langchain_core.documents import Document

document_1 = Document(page_content="foo", metadata={"baz": "bar"})
document_2 = Document(page_content="bar", metadata={"foo": "baz"})
document_3 = Document(page_content="to be deleted")

documents = [document_1, document_2, document_3]
ids = ["1", "2", "3"]
vector_store.add_documents(documents=documents, ids=ids)
```

### 从向量存储中删除条目

```python
vector_store.delete(ids=["3"])
```

## 查询向量存储

在创建好向量存储并添加相关文档后，你通常会希望在链或 agent 运行过程中对其进行查询。

### 直接查询

可以像下面这样执行简单的相似度搜索：

```python
query = "foo"
docs = vector_store.similarity_search(query, k=2)
for doc in docs:
    print(f"* {doc.page_content} [{doc.metadata}]")
```

#### 带分数的相似度搜索

```python
docs_and_scores = vector_store.similarity_search_with_score(query, k=2)
for doc, score in docs_and_scores:
    print(f"* [SIM={score:.3f}] {doc.page_content} [{doc.metadata}]")
```

#### 带过滤的相似度搜索

```python
from redisvl.query.filter import Tag

results = vector_store.similarity_search(
    query="foo",
    k=1,
    filter=Tag("baz") == "bar"
)
for doc in results:
    print(f"* {doc.page_content} [{doc.metadata}]")
```

#### 最大边际相关性搜索

```python
docs = vector_store.max_marginal_relevance_search(query, k=2, fetch_k=10)
for doc in docs:
    print(f"* {doc.page_content} [{doc.metadata}]")
```

#### 其他搜索方法

本笔记没有列出所有搜索方法，如需完整列表，请查阅 @[`API reference`][RedisVectorStore]。

<Tip>
Redis 支持将向量相似度搜索与全文搜索结合的 hybrid search。关于 `similarity_search` 的参数，包括 `return_all` 和 `distance_threshold`，请参阅 @[`API reference`][RedisVectorStore]。
</Tip>

### 转换为检索器进行查询

你也可以把向量存储转换为检索器，以便在 chain 中更方便地使用。

```python
retriever = vector_store.as_retriever(
    search_type="mmr",
    search_kwargs={"k": 1, "fetch_k": 2, "lambda_mult": 0.5},
)
retriever.invoke("your query here")
```
