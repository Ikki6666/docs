> [SingleStore](https://singlestore.com/) 是一个同时支持事务型和分析型负载的分布式 SQL 数据库。你既可以在 [cloud](https://www.singlestore.com/cloud/) 上运行它，也可以在本地部署。

SingleStore 支持向量存储和相似度搜索，并且与 SQL 共存。它内置了 [dot_product](https://docs.singlestore.com/managed-service/en/reference/sql-reference/vector-functions/dot_product.html) 和 [euclidean_distance](https://docs.singlestore.com/managed-service/en/reference/sql-reference/vector-functions/euclidean_distance.html) 等向量函数。关于表设计、索引和查询模式，请参阅 SingleStore 文档中的 [working with vector data](https://docs.singlestore.com/managed-service/en/developer-resources/functional-extensions/working-with-vector-data.html)。

你还可以将向量搜索与 [full-text indexing based on Lucene](https://docs.singlestore.com/cloud/developer-resources/functional-extensions/working-with-full-text-search/) 结合，并按文档元数据过滤。根据你的工作负载，可以先按文本过滤、先按向量过滤，或组合评分，例如加权求和。

请按下面的章节把 SingleStore 接入 LangChain。

| Class | Package | JS support |
| :--- | :--- |  :---: |
| `SingleStoreVectorStore` | `langchain_singlestore` | ✅ |

## 设置

要访问 SingleStore vector store，需要先安装 `langchain-singlestore` 集成包。
pip install -qU "langchain-singlestore"

## 初始化

要初始化 `SingleStoreVectorStore`，你需要一个 @[`Embeddings`] 对象以及 SingleStore 数据库的连接参数。

### 必需参数

- **embedding** (`Embeddings`)：文本嵌入模型。

### 可选参数

- **distance_strategy** (`DistanceStrategy`)：用于计算向量距离的策略。默认为 `DOT_PRODUCT`。可选值：
  - `DOT_PRODUCT`：计算两个向量的标量积。
  - `EUCLIDEAN_DISTANCE`：计算欧几里得距离。

- **table_name** (`str`)：表名，默认 `embeddings`。
- **content_field** (`str`)：存储内容的字段名，默认 `content`。
- **metadata_field** (`str`)：存储元数据的字段名，默认 `metadata`。
- **vector_field** (`str`)：存储向量的字段名，默认 `vector`。
- **id_field** (`str`)：存储 ID 的字段名，默认 `id`。

- **use_vector_index** (`bool`)：启用向量索引（需要 SingleStore 8.5+），默认 `False`。
- **vector_index_name** (`str`)：向量索引名称。如果 `use_vector_index` 为 `False` 则忽略。
- **vector_index_options** (`dict`)：向量索引选项。如果 `use_vector_index` 为 `False` 则忽略。
- **vector_size** (`int`)：向量大小。如果 `use_vector_index` 为 `True` 则必填。

- **use_full_text_search** (`bool`)：启用内容的全文索引，默认 `False`。

### 连接池参数

- **pool_size** (`int`)：连接池中的活跃连接数，默认 `5`。
- **max_overflow** (`int`)：超出 `pool_size` 的最大连接数，默认 `10`。
- **timeout** (`float`)：连接超时时间（秒），默认 `30`。

### 数据库连接参数

- **host** (`str`)：数据库主机名、IP 或 URL。
- **user** (`str`)：数据库用户名。
- **password** (`str`)：数据库密码。
- **port** (`int`)：数据库端口，默认 `3306`。
- **database** (`str`)：数据库名称。

### 其他选项

- **pure_python** (`bool`)：启用 pure Python 模式。
- **local_infile** (`bool`)：允许本地文件上传。
- **charset** (`str`)：字符串值使用的字符集。
- **ssl_key**、**ssl_cert**、**ssl_ca** (`str`)：SSL 文件路径。
- **ssl_disabled** (`bool`)：禁用 SSL。
- **ssl_verify_cert** (`bool`)：校验证书。
- **ssl_verify_identity** (`bool`)：校验服务端身份。
- **autocommit** (`bool`)：启用自动提交。
- **results_type** (`str`)：查询结果结构，例如 `tuples` 或 `dicts`。

```python
import os

from langchain_singlestore.vectorstores import SingleStoreVectorStore

os.environ["SINGLESTOREDB_URL"] = "root:pass@localhost:3306/db"

vector_store = SingleStoreVectorStore(embeddings=embeddings)
```

### 更新向量存储中的条目

要更新向量存储中的现有文档，可使用如下代码：

```python
updated_document = Document(
    page_content="qux", metadata={"source": "https://another-example.com"}
)

vector_store.update_documents(document_id="1", document=updated_document)
```

### 从向量存储中删除条目

要从向量存储中删除文档，可使用如下代码：

```python
vector_store.delete(ids=["3"])
```

## 查询向量存储

在创建好向量存储并添加相关文档后，你通常会希望在链或 agent 运行过程中对其进行查询。

### 直接查询

可以像下面这样执行简单的相似度搜索：

```python
results = vector_store.similarity_search(query="trees in the snow", k=1)
for doc in results:
    print(f"* {doc.page_content} [{doc.metadata}]")
```

### 元数据过滤

SingleStoreDB 通过允许用户按元数据字段进行预过滤，增强并细化搜索结果。这使开发者和数据分析师能够更精确地控制查询，只聚焦于相关数据子集。

SingleStoreVectorStore 同时支持简单和高级元数据过滤，并提供强大的查询操作符。

#### 简单元数据过滤

使用简单的字典风格语法进行精确匹配，同时兼容旧用法：

```python
# Filter by a single field
query = "trees branches"
docs = vector_store.similarity_search(
    query, filter={"category": "snow"}
)

# Filter by multiple fields (implicit AND)
docs = vector_store.similarity_search(
    query="landmarks",
    filter={"country": "France", "category": "museum"}
)
```

#### 高级元数据过滤

对于复杂查询，可以使用带操作符的高级过滤，例如 `$eq`、`$gt`、`$in`、`$and`、`$or` 等：

**比较操作符：**

```python
# Greater than, less than, and other comparisons
results = vector_store.similarity_search(
    query="old structures",
    k=10,
    filter={"year_built": {"$lt": 1900}}  # Built before 1900
)

# Other operators: $eq, $ne, $gt, $gte, $lte
results = vector_store.similarity_search(
    query="landmarks",
    filter={"year_built": {"$gte": 1800, "$lte": 1950}}
)
```

**集合操作符：**

```python
# Check if value is in a list
results = vector_store.similarity_search(
    query="landmarks",
    k=10,
    filter={"country": {"$in": ["France", "UK"]}}
)

# Not in ($nin)
results = vector_store.similarity_search(
    query="museums",
    filter={"country": {"$nin": ["USA", "Canada"]}}
)
```

**存在性检查：**

```python
# Check if a field exists
results = vector_store.similarity_search(
    query="heritage sites",
    k=10,
    filter={"heritage_status": {"$exists": True}}
)
```

**逻辑操作符：**

```python
# Combine multiple conditions with $and
results = vector_store.similarity_search(
    query="european landmarks",
    k=10,
    filter={
        "$and": [
            {"category": "landmark"},
            {"year_built": {"$gte": 1800}},
            {"country": {"$in": ["France", "UK"]}}
        ]
    }
)

# Use $or for alternative conditions
results = vector_store.similarity_search(
    query="cultural sites",
    filter={
        "$or": [
            {"category": "museum"},
            {"category": "landmark"}
        ]
    }
)

# Complex nested queries
results = vector_store.similarity_search(
    query="cultural sites",
    k=10,
    filter={
        "$or": [
            {
                "$and": [
                    {"category": "museum"},
                    {"country": "France"}
                ]
            },
            {
                "$and": [
                    {"category": "landmark"},
                    {"year_built": {"$lt": 1900}}
                ]
            }
        ]
    }
)
```

### 向量索引

如果使用 SingleStore DB 8.5 或更高版本，可以借助 [ANN vector indexes](https://docs.singlestore.com/cloud/reference/sql-reference/vector-functions/vector-indexing/) 提升搜索效率。在创建向量存储对象时设置 `use_vector_index=True` 即可启用该功能。如果你的向量维度与默认 OpenAI 嵌入维度 1536 不同，请记得通过 `vector_size` 参数显式指定。

### 搜索策略

SingleStoreDB 提供多种搜索策略，以满足不同使用场景和用户偏好。默认的 `VECTOR_ONLY` 策略直接使用 `dot_product` 或 `euclidean_distance` 等向量操作来计算向量相似度；`TEXT_ONLY` 使用基于 Lucene 的全文搜索，特别适合文本检索场景。若想平衡两者，可以使用 `FILTER_BY_TEXT`，先根据文本相似度收窄范围，再执行向量比较；`FILTER_BY_VECTOR` 则相反，先按向量相似度过滤，再依据文本相似度选出最优结果。值得注意的是，`FILTER_BY_TEXT` 和 `FILTER_BY_VECTOR` 都要求启用全文索引。除此之外，`WEIGHTED_SUM` 是一种更高级的策略，它通过加权组合文本和向量相似度来计算最终得分，不过它仅支持 `dot_product` 距离计算，并同样要求启用全文索引。这些灵活策略让用户可以根据具体需求调优搜索过程，从而实现更高效、更精准的数据检索与分析。像 `FILTER_BY_TEXT`、`FILTER_BY_VECTOR` 和 `WEIGHTED_SUM` 这样的混合策略，把向量搜索和文本搜索自然结合起来，能帮助你更充分地发挥 SingleStoreDB 的能力。

```python
from langchain_singlestore.vectorstores import DistanceStrategy

docsearch = SingleStoreVectorStore.from_documents(
    docs,
    embeddings,
    distance_strategy=DistanceStrategy.DOT_PRODUCT,  # Use dot product for similarity search
    use_vector_index=True,  # Use vector index for faster search
    use_full_text_search=True,  # Use full text index
)

vectorResults = docsearch.similarity_search(
    "rainstorm in parched desert, rain",
    k=1,
    search_strategy=SingleStoreVectorStore.SearchStrategy.VECTOR_ONLY,
    filter={"category": "rain"},
)
print(vectorResults[0].page_content)

textResults = docsearch.similarity_search(
    "rainstorm in parched desert, rain",
    k=1,
    search_strategy=SingleStoreVectorStore.SearchStrategy.TEXT_ONLY,
)
print(textResults[0].page_content)

filteredByTextResults = docsearch.similarity_search(
    "rainstorm in parched desert, rain",
    k=1,
    search_strategy=SingleStoreVectorStore.SearchStrategy.FILTER_BY_TEXT,
    filter_threshold=0.1,
)
print(filteredByTextResults[0].page_content)

filteredByVectorResults = docsearch.similarity_search(
    "rainstorm in parched desert, rain",
    k=1,
    search_strategy=SingleStoreVectorStore.SearchStrategy.FILTER_BY_VECTOR,
    filter_threshold=0.1,
)
print(filteredByVectorResults[0].page_content)

weightedSumResults = docsearch.similarity_search(
    "rainstorm in parched desert, rain",
    k=1,
    search_strategy=SingleStoreVectorStore.SearchStrategy.WEIGHTED_SUM,
    text_weight=0.2,
    vector_weight=0.8,
)
print(weightedSumResults[0].page_content)
```

### 转换为检索器进行查询

你也可以把向量存储转换为检索器，以便在 chain 中更方便地使用。

```python
retriever = vector_store.as_retriever(search_kwargs={"k": 1})
retriever.invoke("trees in the snow")
```

## 多模态示例：结合 CLIP 与 OpenClip embeddings

在多模态数据分析领域，把图像和文本等不同信息类型结合起来越来越重要。[CLIP](https://openai.com/research/clip) 是一个非常强大的工具，它能够把图像和文本嵌入到同一个语义空间中，从而支持跨模态相似度搜索。

举个例子，如果我们想高效分析多模态数据，就可以利用 OpenClip 多模态嵌入，它建立在 CLIP 框架之上。借助 OpenClip，我们可以同时嵌入文本描述和对应图像，从而完成更全面的分析和检索任务。无论是根据文本查询寻找视觉上相近的图像，还是找出与特定图像内容相关的文本片段，OpenClip 都可以帮助用户以较高的效率和准确度发掘多模态数据中的信息。

```python
import os

from langchain_experimental.open_clip import OpenCLIPEmbeddings
from langchain_singlestore.vectorstores import SingleStoreVectorStore

os.environ["SINGLESTOREDB_URL"] = "root:pass@localhost:3306/db"

TEST_IMAGES_DIR = "../../modules/images"

docsearch = SingleStoreVectorStore(OpenCLIPEmbeddings())

image_uris = sorted(
    [
        os.path.join(TEST_IMAGES_DIR, image_name)
        for image_name in os.listdir(TEST_IMAGES_DIR)
        if image_name.endswith(".jpg")
    ]
)

# Add images
docsearch.add_images(uris=image_uris)
```
