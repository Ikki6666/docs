>Azure SQL 提供了专用的 [Vector data type](https:\learn.microsoft.com\sql\t-sql\data-types\vector-data-type?view=azuresqldb-current&viewFallbackFrom=sql-server-ver16&tabs=csharp-sample)，可以直接在关系型数据库中简化向量 embedding 的创建、存储和查询。这让你不再需要单独部署向量数据库及相关集成，在降低整体复杂度的同时，也增强了解决方案的安全性。

Azure SQL 是一项强大的数据库服务，兼具可扩展性、安全性和高可用性，拥有现代数据库方案的所有优势。它借助成熟的查询优化器和企业级特性，让你可以在传统 SQL 查询旁边执行向量相似度搜索，从而增强数据分析与决策能力。

更多信息请参阅 [Intelligent applications with Azure SQL Database](https://learn.microsoft.com/azure/azure-sql/database/ai-artificial-intelligence-intelligent-applications?view=azuresql)

本笔记本介绍如何利用这个内置的 SQL [vector database](https://devblogs.microsoft.com/azure-sql/exciting-announcement-public-preview-of-native-vector-support-in-azure-sql-database/)，使用 Cosine（余弦距离）、L2（欧氏距离）和 IP（内积）来存储文档并执行向量搜索，从而找到与查询向量接近的文档。

### 过滤支持

该向量存储支持一组可应用于文档 metadata 字段的过滤器。这个能力可以帮助开发者和数据分析人员更细粒度地控制查询条件，从而让搜索结果更准确地对齐实际需求。通过基于特定 metadata 属性加过滤器，用户可以缩小搜索范围，只聚焦在最相关的数据子集上。

```python
# hybrid search -> filter for cases where id not equal to 1.
hybrid_simsearch_result = vector_store.similarity_search(
    "Good reviews", k=3, filter={"id": {"$ne": 1}}
)
print(hybrid_simsearch_result)
```

## 从 Azure Blob Storage 加载文档

下面的示例展示了如何从 Azure Blob Storage 容器中加载文件，切分成块后再写入 SQL 向量存储。
[Azure Blog Storage](https://learn.microsoft.com/en-us/azure/storage/blobs/storage-blobs-introduction) 是微软面向云的对象存储方案，适合保存海量非结构化数据。

```python
pip install azure-storage-blob
```

```python
from langchain.document_loaders import AzureBlobStorageFileLoader
from langchain.text_splitter import RecursiveCharacterTextSplitter
from langchain_core.documents import Document

# Define your connection string and blob details
conn_str = "DefaultEndpointsProtocol=https;AccountName=<YourBlobName>;AccountKey=<YourAccountKey>==;EndpointSuffix=core.windows.net"
container_name = "<YourContainerName"
blob_name = "01 Harry Potter and the Sorcerers Stone.txt"

# Create an instance of AzureBlobStorageFileLoader
loader = AzureBlobStorageFileLoader(
    conn_str=conn_str, container=container_name, blob_name=blob_name
)

# Load the document from Azure Blob Storage
documents = loader.load()

# Split the document into smaller chunks if necessary
text_splitter = RecursiveCharacterTextSplitter(chunk_size=1000, chunk_overlap=100)
split_documents = text_splitter.split_documents(documents)

# Print the number of split documents
print(f"Number of split documents: {len(split_documents)}")
```

```text
Number of split documents: 528
```

## 用于检索增强生成

#### Use case 1: 基于故事书的问答系统

问答功能允许用户就故事、角色和事件提出具体问题，并得到简洁但上下文充分的答案。这不仅能提升他们对作品的理解，也能让他们更有沉浸感。

## 转换为 retriever 后查询

LangChain Vector store 可以方便地构建复杂的问答系统。它能基于用户查询高效做相似度搜索，找出最相关的 10 个文档。**retriever** 由 **vector_store** 创建，问答链则通过 **create_stuff_documents_chain** 构建。系统再借助 **ChatPromptTemplate** 生成结构化、上下文充分的提示词。很多问答应用还需要把答案的来源展示给用户。LangChain 内置的 **create_retrieval_chain** 会自动把检索到的 source documents 放到输出里的 `"context"` 键下。

更多术语说明请参阅 [LangChain RAG tutorials and terminologies](/oss/langchain/rag)。

```python
from typing import List, Tuple

import pandas as pd
from langchain_classic.chains import create_retrieval_chain
from langchain_classic.chains.combine_documents import create_stuff_documents_chain
from langchain_core.prompts import ChatPromptTemplate


# Define the function to perform the RAG chain invocation
def get_answer_and_sources(user_query: str):
    # Perform similarity search with scores
    docs_with_score: List[Tuple[Document, float]] = (
        vector_store.similarity_search_with_score(
            user_query,
            k=10,
        )
    )

    # Extract the context from the top results
    context = "\n".join([doc.page_content for doc, score in docs_with_score])

    # Define the system prompt
    system_prompt = (
        "You are an assistant for question-answering tasks based on the story in the book. "
        "Use the following pieces of retrieved context to answer the question. "
        "If you don't know the answer, say that you don't know, but also suggest that the user can use the fan fiction function to generate fun stories. "
        "Use 5 sentences maximum and keep the answer concise by also providing some background context of 1-2 sentences."
        "\n\n"
        "{context}"
    )

    # Create the prompt template
    prompt = ChatPromptTemplate.from_messages(
        [
            ("system", system_prompt),
            ("human", "{input}"),
        ]
    )

    # Create the retriever and chains
    retriever = vector_store.as_retriever()
    question_answer_chain = create_stuff_documents_chain(llm, prompt)
    rag_chain = create_retrieval_chain(retriever, question_answer_chain)

    # Define the input
    input_data = {"input": user_query}

    # Invoke the RAG chain
    response = rag_chain.invoke(input_data)

    # Print the answer
    print("Answer:", response["answer"])

    # Prepare the data for the table
    data = {
        "Doc ID": [
            doc.metadata.get("source", "N/A").split("/")[-1]
            for doc in response["context"]
        ],
        "Content": [
            doc.page_content[:50] + "..."
            if len(doc.page_content) > 100
            else doc.page_content
            for doc in response["context"]
        ],
    }

    # Create a DataFrame
    df = pd.DataFrame(data)

    # Print the table
    print("\nSources:")
    print(df.to_markdown(index=False))
```

```python
# Define the user query
user_query = "How did Harry feel when he first learnt that he was a Wizard?"

# Call the function to get the answer and sources
get_answer_and_sources(user_query)
```
