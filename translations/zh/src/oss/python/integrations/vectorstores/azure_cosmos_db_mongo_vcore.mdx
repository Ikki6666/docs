本 notebook 展示如何利用这个集成的 [vector database](https://learn.microsoft.com/en-us/azure/cosmos-db/vector-database)，将文档存入 collection、创建索引，并通过向量搜索查询，使用 COS（余弦距离）、L2（欧氏距离）和 IP（内积）等近似最近邻算法，找到与查询向量接近的文档。

Azure Cosmos DB 是驱动 OpenAI ChatGPT 服务的数据库。它提供个位数毫秒响应时间、自动且即时的扩展能力，以及任意规模下的速度保障。

[Azure Cosmos DB for MongoDB vCore](https://learn.microsoft.com/en-us/azure/cosmos-db/mongodb/vcore/) 为开发者提供了一个全托管、兼容 MongoDB 的数据库服务，可用于构建现代应用。你可以继续沿用自己的 MongoDB 经验，并通过 MongoDB drivers、SDK 和工具连接到这个 API for MongoDB vCore 账户。

文档加载并创建索引后，你也可以直接实例化向量存储，并对索引执行查询：

```python
vectorstore = AzureCosmosDBMongoVCoreVectorSearch.from_connection_string(
    CONNECTION_STRING, NAMESPACE, openai_embeddings, index_name=INDEX_NAME
)

query = "What did the president say about Ketanji Brown Jackson"
docs = vectorstore.similarity_search(query)

print(docs[0].page_content)
```

## 过滤向量搜索（预览）

Azure Cosmos DB for MongoDB 支持使用 `$lt`、`$lte`、`$eq`、`$neq`、`$gte`、`$gt`、`$in`、`$nin` 和 `$regex` 做预过滤。要使用这个功能，请在 Azure Subscription 的 "Preview Features" 标签中启用 `"filtering vector search"`。更多信息请参阅 [filtered vector search preview features](https://learn.microsoft.com/azure/cosmos-db/mongodb/vcore/vector-search#filtered-vector-search-preview)。

```python
vectorstore.create_filter_index(
    property_to_filter="metadata.source", index_name="filter_index"
)
```
