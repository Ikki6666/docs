本笔记本介绍如何开始使用 `Chroma` 向量存储。

>[Chroma](https://docs.trychroma.com/getting-started) 是一个以开发者生产力和使用体验为核心的、AI 原生开源向量数据库。Chroma 基于 Apache 2.0 协议发布。你可以在[此页面](https://docs.trychroma.com/reference/py-collection)查看 `Chroma` 的完整文档，并在[此页面](https://reference.langchain.com/python/langchain-chroma/vectorstores/Chroma)查看 LangChain 集成的 API reference。

<Info>
**Chroma Cloud**

Chroma Cloud 提供无服务器的向量和全文搜索能力。它速度快、成本低、可扩展，并且几乎无痛上手。创建一个 DB，并用 5 美元免费额度在 30 秒内开始体验。

[开始使用 Chroma Cloud](https://trychroma.com/signup)
</Info>

## 设置

要访问 `Chroma` 向量存储，你需要安装 `langchain-chroma` 集成包。

```python
pip install -qU "langchain-chroma>=0.1.2"
```

### 凭证

你可以在完全不提供凭证的情况下使用 `Chroma` 向量存储，只安装上面的包就够了。

如果你是 [Chroma Cloud](https://trychroma.com/signup) 用户，请设置 `CHROMA_TENANT`、`CHROMA_DATABASE` 和 `CHROMA_API_KEY` 环境变量。

安装 `chromadb` 包后，你也可以使用 Chroma CLI 来帮你设置这些值。首先通过 CLI [登录](https://docs.trychroma.com/docs/cli/login)，然后使用 [`connect` 命令](https://docs.trychroma.com/docs/cli/db)：

```bash
chroma db connect [db_name] --env-file
```

如果你想获得更完善的模型调用自动 tracing，请设置 [LangSmith](/langsmith/observability) API key 并启用 tracing：

```python
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

## 初始化

### 基础初始化

下面的示例展示了如何先为 Chroma 设置 embedding function，再配置本地持久化以存储向量数据。

<EmbeddingTabs/>

```python
# | output: false
# | echo: false
from langchain_openai import OpenAIEmbeddings

embeddings = OpenAIEmbeddings(model="text-embedding-3-large")
```

#### 本地运行（内存模式）

你只需用 collection name 和 embeddings provider 实例化一个 `Chroma` 对象，就可以让 Chroma 服务器在内存中运行：

```python
from langchain_chroma import Chroma

vector_store = Chroma(
    collection_name="example_collection",
    embedding_function=embeddings,
)
```

如果你不需要数据持久化，这是在使用 LangChain 构建 AI 应用时进行实验的一个很好的选择。

#### 本地运行（带数据持久化）

你可以提供 `persist_directory` 参数，在程序多次运行之间保留数据：

```python
from langchain_chroma import Chroma

vector_store = Chroma(
    collection_name="example_collection",
    embedding_function=embeddings,
    persist_directory="./chroma_langchain_db",
)
```

#### 连接到 Chroma Server

如果你在本地运行了 Chroma server，或者你已经自行[部署](https://docs.trychroma.com/guides/deploy/client-server-mode)了一个实例，可以通过提供 `host` 参数来连接它。

例如，你可以用 `chroma run` 在本地启动一个 Chroma server，然后通过 `host='localhost'` 连接它：

```python
from langchain_chroma import Chroma

vector_store = Chroma(
    collection_name="example_collection",
    embedding_function=embeddings,
    host="localhost",
)
```

对于其他部署方式，你可以使用 `port`、`ssl` 和 `headers` 参数自定义连接。

#### Chroma Cloud

Chroma Cloud 用户也可以结合 LangChain 进行开发。请为你的 `Chroma` 实例提供 Chroma Cloud API key、tenant 和 DB name：

```python
from langchain_chroma import Chroma

vector_store = Chroma(
    collection_name="example_collection",
    embedding_function=embeddings,
    chroma_cloud_api_key=os.getenv("CHROMA_API_KEY"),
    tenant=os.getenv("CHROMA_TENANT"),
    database=os.getenv("CHROMA_DATABASE"),
)
```

### 从 client 初始化

你也可以通过一个 `Chroma` client 来初始化，这在你想更方便地访问底层数据库时尤其有用。

#### 本地运行（内存模式）

```python
import chromadb

client = chromadb.Client()
```

#### 本地运行（带数据持久化）

```python
import chromadb

client = chromadb.PersistentClient(path="./chroma_langchain_db")
```

#### 连接到 Chroma Server

例如，如果你在本地运行 Chroma server（使用 `chroma run`）：

```python
import chromadb

client = chromadb.HttpClient(host="localhost", port=8000, ssl=False)
```

#### Chroma Cloud

设置好 `CHROMA_API_KEY`、`CHROMA_TENANT` 和 `CHROMA_DATABASE` 之后，你可以直接实例化：

```python
import chromadb

client = chromadb.CloudClient()
```

#### 访问你的 Chroma DB

```python
collection = client.get_or_create_collection("collection_name")
collection.add(ids=["1", "2", "3"], documents=["a", "b", "c"])
```

#### 创建一个 Chroma vectorstore

```python
vector_store_from_client = Chroma(
    client=client,
    collection_name="collection_name",
    embedding_function=embeddings,
)
```

## 管理向量存储

创建好向量存储后，你可以通过添加和删除不同条目来与其交互。

### 向向量存储添加条目

你可以使用 `add_documents` 函数向向量存储中添加条目。

```python
from uuid import uuid4

from langchain_core.documents import Document

document_1 = Document(
    page_content="I had chocolate chip pancakes and scrambled eggs for breakfast this morning.",
    metadata={"source": "tweet"},
    id=1,
)

document_2 = Document(
    page_content="The weather forecast for tomorrow is cloudy and overcast, with a high of 62 degrees.",
    metadata={"source": "news"},
    id=2,
)

document_3 = Document(
    page_content="Building an exciting new project with LangChain - come check it out!",
    metadata={"source": "tweet"},
    id=3,
)

document_4 = Document(
    page_content="Robbers broke into the city bank and stole $1 million in cash.",
    metadata={"source": "news"},
    id=4,
)

document_5 = Document(
    page_content="Wow! That was an amazing movie. I can't wait to see it again.",
    metadata={"source": "tweet"},
    id=5,
)

document_6 = Document(
    page_content="Is the new iPhone worth the price? Read this review to find out.",
    metadata={"source": "website"},
    id=6,
)

document_7 = Document(
    page_content="The top 10 soccer players in the world right now.",
    metadata={"source": "website"},
    id=7,
)

document_8 = Document(
    page_content="LangGraph is the best framework for building stateful, agentic applications!",
    metadata={"source": "tweet"},
    id=8,
)

document_9 = Document(
    page_content="The stock market is down 500 points today due to fears of a recession.",
    metadata={"source": "news"},
    id=9,
)

document_10 = Document(
    page_content="I have a bad feeling I am going to get deleted :(",
    metadata={"source": "tweet"},
    id=10,
)

documents = [
    document_1,
    document_2,
    document_3,
    document_4,
    document_5,
    document_6,
    document_7,
    document_8,
    document_9,
    document_10,
]
uuids = [str(uuid4()) for _ in range(len(documents))]

vector_store.add_documents(documents=documents, ids=uuids)
```

### 更新向量存储中的条目

现在我们已经向向量存储中添加了文档，可以使用 `update_documents` 函数更新已有文档。

```python
updated_document_1 = Document(
    page_content="I had chocolate chip pancakes and fried eggs for breakfast this morning.",
    metadata={"source": "tweet"},
    id=1,
)

updated_document_2 = Document(
    page_content="The weather forecast for tomorrow is sunny and warm, with a high of 82 degrees.",
    metadata={"source": "news"},
    id=2,
)

vector_store.update_document(document_id=uuids[0], document=updated_document_1)
# You can also update multiple documents at once
vector_store.update_documents(
    ids=uuids[:2], documents=[updated_document_1, updated_document_2]
)
```

### 从向量存储中删除条目

你也可以像下面这样删除条目：

```python
vector_store.delete(ids=uuids[-1])
```

## 查询向量存储

创建向量存储并添加相关文档后，你通常会希望在 chain 或 agent 运行过程中查询它。

### 直接查询

#### 相似度搜索

执行简单的相似度搜索可以像下面这样：

```python
results = vector_store.similarity_search(
    "LangChain provides abstractions to make working with LLMs easy",
    k=2,
    filter={"source": "tweet"},
)
for res in results:
    print(f"* {res.page_content} [{res.metadata}]")
```

#### 带分数的相似度搜索

如果你想执行相似度搜索并获得相应分数，可以运行：

```python
results = vector_store.similarity_search_with_score(
    "Will it be hot tomorrow?", k=1, filter={"source": "news"}
)
for res, score in results:
    print(f"* [SIM={score:3f}] {res.page_content} [{res.metadata}]")
```

#### 按向量搜索

你也可以按向量执行搜索：

```python
results = vector_store.similarity_search_by_vector(
    embedding=embeddings.embed_query("I love green eggs and ham!"), k=1
)
for doc in results:
    print(f"* {doc.page_content} [{doc.metadata}]")
```

#### 其他搜索方法

还有多种本文未覆盖的搜索方法，例如 MMR 搜索。有关 `Chroma` 可用全部搜索能力，请查看 @[API reference][ChromaVectorStore]。

### 转换为 retriever 后查询

你也可以将向量存储转换为 retriever，以便在 chain 中更方便地使用。关于不同搜索类型以及可传入的 kwargs 的更多信息，请参阅 [Chroma API reference](https://reference.langchain.com/python/langchain-chroma/vectorstores/Chroma#langchain_chroma.vectorstores.Chroma.as_retriever)。

```python
retriever = vector_store.as_retriever(
    search_type="mmr", search_kwargs={"k": 1, "fetch_k": 5}
)
retriever.invoke("Stealing from the bank is a crime", filter={"source": "news"})
```
