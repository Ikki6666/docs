[AgentQL](https://www.agentql.com/) 可使用 [AgentQL 查询](https://docs.agentql.com/agentql-query)或自然语言提示词，从任意网页进行网页交互和结构化数据提取。AgentQL 可跨多种语言和网页使用，并且不会随着时间推移或网页变化而失效。

## 安装和设置

安装集成包：

<CodeGroup>
```bash pip
pip install langchain-agentql
```

```bash uv
uv add langchain-agentql
```
</CodeGroup>

## API 密钥

从我们的 [Dev Portal](https://dev.agentql.com/) 获取 API 密钥，并将其添加到环境变量中：
```
export AGENTQL_API_KEY="your-api-key-here"
```

## DocumentLoader

AgentQL 的 document loader 可使用 AgentQL 查询从任意网页提取结构化数据。

```python
from langchain_agentql.document_loaders import AgentQLLoader
```

请参阅我们的 [document loader 文档和用法示例](/oss/integrations/document_loaders/agentql)。

## 工具和工具包

AgentQL 工具可使用 AgentQL 查询或自然语言提示词，从任意网页进行网页交互和结构化数据提取。

```python
from langchain_agentql.tools import ExtractWebDataTool, ExtractWebDataBrowserTool, GetWebElementBrowserTool
from langchain_agentql import AgentQLBrowserToolkit
```

请参阅我们的[工具文档和用法示例](/oss/integrations/tools/agentql)。
