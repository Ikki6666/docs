>[Alibaba Group Holding Limited (Wikipedia)](https://en.wikipedia.org/wiki/Alibaba_Group)，即 `Alibaba`
>（中文：阿里巴巴），是一家中国跨国科技公司，专注于电子商务、零售、
>互联网和技术领域。
>
> [Alibaba Cloud (Wikipedia)](https://en.wikipedia.org/wiki/Alibaba_Cloud)，也称作 `Aliyun`
>（中文：阿里云；拼音：Ālǐyún；字面义为 “Ali Cloud”），是一家云计算公司，也是
> `Alibaba Group` 的子公司。`Alibaba Cloud` 为在线业务以及
> Alibaba 自身的电商生态提供云计算服务。
