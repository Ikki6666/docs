[Jenkins](https://www.jenkins.io/) 是一个开源自动化平台，可帮助软件团队简化开发工作流。它在 DevOps 社区中被广泛采用，用于通过 CI/CD 流水线自动完成应用的构建、测试和部署。


## 安装与设置

<CodeGroup>
```bash pip
pip install langchain-jenkins
```

```bash uv
uv add langchain-jenkins
```
</CodeGroup>

## Tools

可用工具的详细信息请参阅 [Jenkins tools documentation](/oss/integrations/tools/jenkins)。
