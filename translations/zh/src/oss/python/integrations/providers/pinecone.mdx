## 向量存储

这里提供了一个围绕 Pinecone indexes 的 wrapper，可让您将其用作 vectorstore，
无论是进行语义搜索还是示例选择。

```python
from langchain_pinecone import PineconeVectorStore
```

有关 Pinecone vectorstore 的更详细说明，请参阅[这个 notebook](/oss/integrations/vectorstores/pinecone)。

### Sparse vector store

LangChain 的 `PineconeSparseVectorStore` 支持使用 Pinecone 的 sparse English 模型进行稀疏检索。它会将文本映射为稀疏向量，并支持添加文档与相似度搜索。

```python
from langchain_pinecone import PineconeSparseVectorStore

# Initialize sparse vector store
vector_store = PineconeSparseVectorStore(
    index=my_index,
    embedding_model="pinecone-sparse-english-v0"
)
# Add documents
vector_store.add_documents(documents)
# Query
results = vector_store.similarity_search("your query", k=3)
```

有关更详细的说明，请参阅 [Pinecone Sparse Vector Store notebook](/oss/integrations/vectorstores/pinecone_sparse)。

### Sparse embedding

LangChain 的 `PineconeSparseEmbeddings` 使用 Pinecone 的 `pinecone-sparse-english-v0` 模型提供稀疏 embedding 生成功能。

```python
from langchain_pinecone.embeddings import PineconeSparseEmbeddings

# Initialize sparse embeddings
sparse_embeddings = PineconeSparseEmbeddings(
    model="pinecone-sparse-english-v0"
)
# Embed a single query (returns SparseValues)
query_embedding = sparse_embeddings.embed_query("sample text")

# Embed multiple documents (returns list of SparseValues)
docs = ["Document 1 content", "Document 2 content"]
doc_embeddings = sparse_embeddings.embed_documents(docs)
```

更多详细用法请参阅 [Pinecone Sparse Embeddings notebook](/oss/integrations/vectorstores/pinecone_sparse)。
