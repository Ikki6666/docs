>[Milvus](https://milvus.io/docs/overview.md) 是一个用于存储、索引和管理海量 embedding 向量的数据库，这些向量通常由深度神经网络和其他机器学习（ML）模型生成。


## 安装与设置

安装 Python SDK：

<CodeGroup>
```bash pip
pip install langchain-milvus
```

```bash uv
uv add langchain-milvus
```
</CodeGroup>

## Vector store

参阅[使用示例](/oss/integrations/vectorstores/milvus)。

导入这个 vectorstore：
```python
from langchain_milvus import Milvus
```
