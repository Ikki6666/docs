>[MongoDB](https://www.mongodb.com/) 是一个面向文档的 NoSQL 数据库，支持带有动态 schema 的类 JSON 文档。你可以将其作为自管理的部署来运行，也可以使用 [MongoDB Atlas](https://www.mongodb.com/docs/atlas/)（MongoDB 完全托管的云数据库）来运行。

安装 `langchain-mongodb` 即可同时支持自管理和 Atlas 两类集成。你可以将 MongoDB 运行在自己的基础设施上，也可以使用 Atlas 获得完全托管的云体验。文档数据模型以灵活的 schema 存储类 JSON 文档，能够适应你的应用需求。

## 安装与设置

安装 Python 包：

<CodeGroup>
```bash pip
pip install langchain-mongodb
```

```bash uv
uv add langchain-mongodb
```
</CodeGroup>

### 获取你的 MongoDB 连接字符串

在与 LangChain 集成之前，你需要一个正在运行的 MongoDB 部署以及一个连接字符串。请根据你的环境选择合适的方式。

#### MongoDB Atlas

MongoDB Atlas 是 MongoDB 完全托管的云数据库，可在 AWS、Azure 和 GCP 上使用。它是生产部署的推荐选项，也是向量搜索、全文搜索和混合搜索等 Atlas 专属 LangChain 集成所必需的。

1. [注册一个免费的 Atlas 账户](https://www.mongodb.com/cloud/atlas/register) 并部署一个集群。
2. 在 Atlas UI 中，导航到你的集群并选择 Connect 来获取连接字符串。

示例连接字符串：

```python
MONGODB_ATLAS_URI = "mongodb+srv://<username>:<password>@<cluster-url>/"
```

#### 自管理 MongoDB

MongoDB 可以作为自管理部署，用于本地机房、私有云或本地开发环境。MongoDB 提供两种自管理版本：

- **Community Edition**：免费且开源。适合本地开发和较小规模的部署。[下载 Community Edition](https://www.mongodb.com/try/download/community)。
- **Enterprise Advanced**：面向生产环境的本地部署，提供高级安全和管理功能。[下载 Enterprise Advanced](https://www.mongodb.com/try/download/enterprise)。

要确定适合你部署类型的连接字符串格式，请参见 [MongoDB 连接字符串文档](https://www.mongodb.com/docs/manual/reference/connection-string/)。

示例本地连接字符串：

```python
MONGODB_URI = "mongodb://localhost:27017/"
```

## 可用集成

### 模型缓存

`MongoDBCache` 将 LLM 响应存储在 MongoDB 中，无需搜索索引或 Atlas 部署。它同时适用于自管理和 Atlas 部署。

```python
from langchain_mongodb.cache import MongoDBCache
```

### MongoDB Atlas 集成

以下集成需要 MongoDB Atlas。你可以使用 MongoDB Atlas 与 LangChain 进行向量搜索、检索和语义缓存：

- **向量存储**：`MongoDBAtlasVectorSearch` 将嵌入存储在 MongoDB 中，支持语义搜索、过滤搜索和混合搜索（通过 BM25 实现向量 + 全文）。
- **检索器**：`MongoDBAtlasFullTextSearchRetriever` 和 `MongoDBAtlasHybridSearchRetriever` 支持全文检索以及向量 + 关键词的组合检索工作流。
- **语义缓存**：`MongoDBAtlasSemanticCache` 基于语义相似度检索已缓存的 LLM 响应，由 Atlas Vector Search 提供支持。

有关导入方式和用法示例，请参见 [MongoDB Atlas 集成](/oss/integrations/providers/mongodb_atlas) 页面。

有关向量存储设置、索引创建、语义搜索等的详细说明，请参见 [MongoDB Atlas 向量存储](/oss/integrations/vectorstores/mongodb_atlas) 指南。
