>[MongoDB](https://www.mongodb.com/) 是一个面向文档的 NoSQL
> 数据库，支持带有动态 schema 的类 JSON 文档。

**注意：**
- 其他 `MongoDB` 集成请参阅 [MongoDB Atlas page](/oss/integrations/providers/mongodb_atlas)。

## 安装与设置

安装 Python 包：

<CodeGroup>
```bash pip
pip install langchain-mongodb
```

```bash uv
uv add langchain-mongodb
```
</CodeGroup>
