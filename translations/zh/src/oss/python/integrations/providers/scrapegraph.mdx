>[ScrapeGraph AI](https://scrapegraphai.com) 是一项提供 AI 驱动网页抓取能力的服务。
>它提供用于提取结构化数据、将网页转换为 markdown 以及
>使用自然语言提示处理本地 HTML 内容的工具。

## 安装与设置

安装所需包：

<CodeGroup>
```bash pip
pip install langchain-scrapegraph
```

```bash uv
uv add langchain-scrapegraph
```
</CodeGroup>

设置你的 API key：

```bash
export SGAI_API_KEY="your-scrapegraph-api-key"
```

## Tools

参见[使用示例](/oss/integrations/tools/scrapegraph)。

共有四个可用工具：

```python
from langchain_scrapegraph.tools import (
    SmartScraperTool,    # Extract structured data from websites
    SmartCrawlerTool,    # Extract data from multiple pages with crawling
    MarkdownifyTool,     # Convert webpages to markdown
    AgenticScraperTool,  # Extract specifying steps
    GetCreditsTool,      # Check remaining API credits
)
```

每个工具都有特定用途：

- `SmartScraperTool`: 给定 URL、提示词和可选输出 schema，从网站提取结构化数据
- `SmartCrawlerTool`: 通过高级爬取选项从多个页面提取数据，例如深度控制、页面限制和域名限制
- `MarkdownifyTool`: 将任意网页转换为干净的 markdown 格式
- `AgenticScraperTool`: 按指定步骤执行提取
- `GetCreditsTool`: 检查你剩余的 ScrapeGraph AI credits
