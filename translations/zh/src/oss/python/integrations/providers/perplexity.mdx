>[Perplexity](https://www.perplexity.ai/pro) 是搜索互联网的最强方式之一，提供无限 Pro Search、升级版 AI 模型、无限文件上传、图像生成和 API 积分。
>
> 您可以查看[可用模型列表](https://docs.perplexity.ai/docs/model-cards)。

## 安装和设置

安装 Perplexity x LangChain 集成包：

<CodeGroup>
```bash pip
pip install langchain-perplexity
```

```bash uv
uv add langchain-perplexity
```
</CodeGroup>

从 [Perplexity API key dashboard](https://www.perplexity.ai/account/api/keys) 获取您的 API key，并将其设置为 `PERPLEXITY_API_KEY`（或 `PPLX_API_KEY`）环境变量。更多细节请参阅 [Perplexity getting started guide](https://docs.perplexity.ai/docs/getting-started)。

## 聊天模型

请参阅各种 [Perplexity 用法示例](/oss/integrations/chat/perplexity)。

```python
from langchain_perplexity import ChatPerplexity
```

`ChatPerplexity` 也可以通过传入 `use_responses_api=True`（或者传入 `tools=[{"type": "web_search"}]`，其会自动启用）来对接 [Perplexity Agent API](https://docs.perplexity.ai/api-reference/agent-api)。详情和示例请参阅聊天页面中的 [Agent API support](/oss/integrations/chat/perplexity#agent-api-support-use_responses_api)。

## Retriever

您可以在标准检索流水线中使用 [`PerplexitySearchRetriever`](/oss/integrations/retrievers/perplexity_search)，以 @[`Document`] 对象形式从 [Perplexity Search API](https://docs.perplexity.ai/docs/search/quickstart) 获取网页搜索结果。

请参阅[用法示例](/oss/integrations/retrievers/perplexity_search)。

```python
from langchain_perplexity import PerplexitySearchRetriever
```

## 工具

您可以将 Perplexity 用作 agent 工具，让 agent 能访问 Perplexity Search API。

请参阅[用法示例](/oss/integrations/tools/perplexity_search)。

### PerplexitySearchResults

这是一个查询 Perplexity Search API 并返回 JSON 结果数组（title、URL、snippet、date、last updated）的工具。

```python
from langchain_perplexity import PerplexitySearchResults
```

## Embedding 模型

您可以使用 [`PerplexityEmbeddings`](/oss/integrations/embeddings/perplexity) 通过 [Perplexity Embeddings API](https://docs.perplexity.ai/api-reference/embeddings-post) 生成 embeddings。

请参阅[用法示例](/oss/integrations/embeddings/perplexity)。

```python
from langchain_perplexity import PerplexityEmbeddings
```

## Deep Agents Code

在 [Deep Agents Code](/oss/deepagents/code/providers) 中，将 Perplexity 作为一等 provider 使用。

安装带 Perplexity extra 的 Deep Agents Code：

<CodeGroup>
```bash uv
uv tool install 'deepagents-code[perplexity]'
```
</CodeGroup>

然后设置 `PERPLEXITY_API_KEY`，并在交互式 `/model` 切换器或您的配置中，使用带 `perplexity:` 前缀的 Perplexity 模型（例如 `perplexity:sonar-pro`）。

## 组件参考

| Class | Abstraction | Import path | Description |
|-------|-------------|-------------|-------------|
| `ChatPerplexity` | Chat model | `from langchain_perplexity import ChatPerplexity` | 对 Perplexity API 的聊天模型封装，用于 grounded chat completions。 |
| `PerplexitySearchRetriever` | Retriever | `from langchain_perplexity import PerplexitySearchRetriever` | 从 Perplexity Search API 返回 `Document` 对象的检索器。 |
| `PerplexitySearchResults` | Tool | `from langchain_perplexity import PerplexitySearchResults` | 为 agents 返回 JSON 数组形式 Perplexity Search API 结果的工具。 |
| `PerplexityEmbeddings` | Embeddings | `from langchain_perplexity import PerplexityEmbeddings` | 对 Perplexity Embeddings API 的 embedding 模型封装。 |
