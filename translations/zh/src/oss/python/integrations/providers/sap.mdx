>[SAP SE(Wikipedia)](https://www.sap.com/about/company.html) 是一家德国跨国软件公司。它开发用于管理业务运营和客户关系的企业软件，也是全球领先的 `enterprise resource planning (ERP)` 软件供应商。

## 安装与设置

你需要安装 `langchain-hana` Python 包。

<CodeGroup>
```bash pip
pip install langchain-hana
```

```bash uv
uv add langchain-hana
```
</CodeGroup>

## Vectorstore

>[SAP HANA Cloud Vector Engine](https://help.sap.com/docs/hana-cloud-database/sap-hana-cloud-sap-hana-database-vector-engine-guide/sap-hana-cloud-sap-hana-database-vector-engine-guide) 是一个完全集成在 `SAP HANA Cloud` 数据库中的 vector store。

参见[使用示例](/oss/integrations/vectorstores/sap_hanavector)。

```python
from langchain_hana import HanaDB
```

## Self Query Retriever
>[SAP HANA Cloud Vector Engine](https://help.sap.com/docs/hana-cloud-database/sap-hana-cloud-sap-hana-database-vector-engine-guide/sap-hana-cloud-sap-hana-database-vector-engine-guide)
> 还通过 `HanaTranslator` 类提供了 Self Query Retriever 实现。

参见[使用示例](/oss/integrations/retrievers/self_query/hanavector_self_query)。

```python
from langchain_hana import HanaTranslator
```

## Graph
>[SAP HANA Cloud Knowledge Graph Engine](https://help.sap.com/docs/hana-cloud-database/sap-hana-cloud-sap-hana-database-knowledge-graph-guide/sap-hana-cloud-sap-hana-database-knowledge-graph-engine-guide)
> 提供了通过 `HanaRdfGraph` 类使用知识图谱的支持。

参见[使用示例](/oss/integrations/graphs/sap_hana_rdf_graph)。

```python
from langchain_hana import HanaRdfGraph
```

## Chains
还提供了一个 `SparqlQAChain`，可与 `HanaRdfGraph` 配合使用，以处理 SPARQL-QA 任务。

参见[使用示例](/oss/integrations/chains/sap_hana_sparql_qa_chain)。

```python
from langchain_hana import HanaSparqlQAChain
```

## Agents
`HanaSparqlQAAgent` 可以基于 `HanaRdfGraph` 迭代生成并执行 SPARQL 查询，包括本体检索和自我纠错。

参见[使用示例](/oss/integrations/agents/sap_hana_sparql_qa_agent)。

```python
from langchain_hana import HanaSparqlQAAgent
```
