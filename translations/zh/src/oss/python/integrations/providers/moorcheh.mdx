# Moorcheh

>[Moorcheh](https://www.moorcheh.ai/) 是一个极速语义搜索引擎和向量存储。Moorcheh 不使用 L2 或 Cosine 这类简单距离度量，而是采用 Maximally Informative Binarization（MIB）和 Information-Theoretic Score（ITS）来检索准确的文档片段。

本页介绍如何在 LangChain 中使用 Moorcheh 来实现向量存储、语义搜索和生成式 AI 响应。

## 安装和设置

安装 Python 集成包：

```bash
pip install langchain-moorcheh
```

从 [Moorcheh Console](https://console.moorcheh.ai/) 获取 Moorcheh API key，并将其设置为环境变量：

```bash
export MOORCHEH_API_KEY="your-api-key-here"
```

## 向量存储

Moorcheh 提供了一个 vector store wrapper，可让您高效地存储、搜索和检索文档 embeddings。

请参阅[详细用法示例](/oss/integrations/vectorstores/moorcheh)。

```python
from langchain_moorcheh import MoorchehVectorStore

# Initialize the vector store
store = MoorchehVectorStore(
    api_key="your-api-key",
    namespace="your_namespace",
    namespace_type="text"  # or "vector"
)

# Add documents
from langchain_core.documents import Document
documents = [
    Document(page_content="Your document content here", metadata={"source": "example"})
]
store.add_documents(documents=documents)
```

## 生成式 AI

Moorcheh 支持使用多种 LLM 模型（包括 Claude 3）生成 AI 响应，让您能够基于存储的文档获取 AI 生成答案。

```python
# Get an AI-generated answer based on your documents
query = "What are the main topics covered in the documents?"
answer = store.generative_answer(
    query,
    ai_model="anthropic.claude-sonnet-4-6"
)
print(answer)
```

## 核心特性

- **Document Management**：使用唯一 ID 添加和删除文档
- **Semantic Search**：使用自然语言查询查找相关文档
- **Generative AI**：使用多种 LLM 模型获取 AI 生成答案
- **Namespace Organization**：将数据组织到不同命名空间中
- **Metadata Support**：存储和检索带有自定义元数据的文档

更多详细示例和高级用法，请参阅 [Moorcheh vectorstore integration](/oss/integrations/vectorstores/moorcheh)。
