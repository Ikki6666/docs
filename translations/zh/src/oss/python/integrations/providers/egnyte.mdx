[Egnyte](https://www.egnyte.com) 是一个基于云的内容协作和文件共享平台，使组织能够安全地存储、共享和治理其文件。Egnyte 将云内容管理能力与高级安全性、合规性以及 AI 驱动的搜索功能结合在一起。

此包为 Egnyte 的混合搜索 API 提供了 LangChain 集成。该 API 结合语义搜索和关键词搜索，帮助您从 Egnyte 实例中查找和检索文档。

# egnyte-langchain-connector

此包包含与 Egnyte 的 LangChain 集成。有关 Egnyte 的更多信息，请查看 [Egnyte developer documentation](https://developers.egnyte.com/)。

## 前置条件

要与 Egnyte 集成，您需要：

* 一个 Egnyte 账户 — 如果您当前不是 Egnyte 客户，或者想在生产实例之外进行测试，可以使用一个[免费开发者账户](https://developers.egnyte.com/member/register)。
* 一个 Egnyte 应用 — 该应用需在 [developer console](https://developers.egnyte.com/) 中配置，并启用适当的 scopes。
* 该应用必须由管理员启用。

## 认证

`egnyte-langchain-connector` 包使用 Egnyte 用户令牌的 Bearer token 认证方式。

### 生成用户令牌

要生成用于认证的 Egnyte 用户令牌：

1. **注册开发者账户**
   - 访问 [https://developers.egnyte.com/member/register](https://developers.egnyte.com/member/register)
   - 创建您的免费开发者账户

2. **生成用户令牌**
   - 使用您的 API 密钥，按照 [Public API Authentication guide](https://developers.egnyte.com/docs/read/Public_API_Authentication) 生成用户令牌
   - **重要**：生成令牌时请使用 `Egnyte.ai` scope，以确保能够正确访问 AI 驱动的搜索功能

### 使用令牌

您可以将令牌直接传给 retriever：

```python
import getpass

egnyte_user_token = getpass.getpass("Enter your Egnyte User Token: ")
domain = "company.egnyte.com"  # Your Egnyte domain (without https://)
```

或者使用环境变量：

```python
import os
from dotenv import load_dotenv

load_dotenv()

egnyte_user_token = os.getenv("EGNYTE_USER_TOKEN")
domain = os.getenv("EGNYTE_DOMAIN")
```

## Utilities

### EgnyteSearchOptions

配置高级搜索参数：

```python
from langchain_egnyte import EgnyteSearchOptions

search_options = EgnyteSearchOptions(
    limit=50,
    folderPath="/policies",
    excludeFolderPaths=["/temp", "/archive"],
    createdAfter=1640995200000,  # Unix timestamp in milliseconds
    createdBefore=1672531200000
)
```
