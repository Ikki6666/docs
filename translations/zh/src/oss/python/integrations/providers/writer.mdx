与 WRITER 相关的全部功能


>本页介绍如何在 LangChain 中使用 [WRITER](https://writer.com/) 生态。更多信息参见 Writer [docs](https://dev.writer.com/home/introduction)。
>[Palmyra](https://writer.com/blog/palmyra/) 是由 `WRITER` 开发的大语言模型（LLM）。
>
>[Writer API](https://dev.writer.com/api-guides/introduction) 由一组功能和定价各不相同的 Palmyra 子模型提供支持。

## 安装与设置

使用以下命令安装集成包
<CodeGroup>
```bash pip
pip install langchain-writer
```

```bash uv
uv add langchain-writer
```
</CodeGroup>

获取 WRITER API key，并将其设置为环境变量 `WRITER_API_KEY`

## Chat model

```python
from langchain_writer import ChatWriter
```
参见[详情](/oss/integrations/chat/writer)。


## PDF parser

```python
from langchain_writer.pdf_parser import PDFParser
```

**迁移路径**：计划为 chat completions 引入一个预构建的 PDF parsing tool，以提供类似功能。这个工具的工作方式会与其他预构建工具类似。一旦该替代方案可用，就会提供更多细节。
</Warning>
