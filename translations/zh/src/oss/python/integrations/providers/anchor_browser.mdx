[Anchor](https://anchorbrowser.io?utm=langchain) 是一个面向 AI 智能体浏览器自动化的平台，用于解决那些缺少 API 或 API 覆盖有限的 Web 应用自动化工作流问题。它简化了基于浏览器自动化的创建、部署和管理，将复杂的网页交互转化为简单的 API 端点。

`langchain-anchorbrowser` 提供 3 个主要工具：
- `AnchorContentTool` - 用于提取 Markdown 或 HTML 格式的网页内容。
- `AnchorScreenshotTool` - 用于网页截图。
- `AnchorWebTaskTools` - 用于执行网页任务。

## 快速开始

### 安装

安装该包：

<CodeGroup>
```bash pip
pip install langchain-anchorbrowser
```

```bash uv
uv add langchain-anchorbrowser
```
</CodeGroup>

### 用法

导入并使用您需要的工具。Anchor Browser 可用工具的完整列表，请参阅 [Anchor Browser 工具页面](/oss/integrations/tools/anchor_browser)中的 **Tool Features** 表。

```python
from langchain_anchorbrowser import AnchorContentTool

# Get Markdown Content for https://www.anchorbrowser.io
AnchorContentTool().invoke(
    {"url": "https://www.anchorbrowser.io", "format": "markdown"}
)
```
