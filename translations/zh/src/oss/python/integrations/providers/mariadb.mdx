本页介绍如何在 LangChain 中使用 [MariaDB](https://github.com/mariadb/) 生态系统。
内容分为两部分：安装与设置，以及对特定 PGVector wrappers 的引用。

## 安装

- 安装 c/c connector

在 Debian、Ubuntu 上
```bash
sudo apt install libmariadb3 libmariadb-dev
```

在 CentOS、RHEL、Rocky Linux 上
```bash
sudo yum install MariaDB-shared MariaDB-devel
```

- 使用 `pip install mariadb` 安装 Python connector 包

## 设置

1. 第一步是安装 MariaDB 11.7.1 或更高版本。

    使用 docker image 是最容易开始的方式。

## Wrappers

### VectorStore

这里提供了一个围绕 MariaDB 向量数据库的 wrapper，使您可以将其作为 vectorstore 使用，无论是用于语义搜索还是示例选择。

导入该 vectorstore：
```python
from langchain_mariadb import MariaDBStore
```
