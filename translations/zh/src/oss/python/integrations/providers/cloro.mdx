本页介绍如何在 LangChain 中使用 [cloro](https://cloro.dev/) 的监控 API。

## 安装与设置
- 使用 `pip install -U langchain-cloro` 安装依赖
- 从 [cloro dashboard](https://dashboard.cloro.dev/) 获取 cloro API key，并将其设置为环境变量（`CLORO_API_KEY`）

## Tools

cloro 提供了一组工具，用于抓取 AI 平台并提取结构化数据。要使用这些工具：

```python
from langchain_cloro import CloroGoogleSearch, CloroChatGPT, CloroGemini, CloroPerplexity, CloroGrok, CloroCopilot
```
