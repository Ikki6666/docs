>[MLflow](https://mlflow.org/) 是一个灵活的开源平台，用于管理机器学习和生成式 AI 生命周期中的工作流与工件。它与许多流行的 AI 和 ML 库内置集成，但也可以与任何库、算法或部署工具一起使用。

MLflow 的 [LangChain integration](https://mlflow.org/docs/latest/llms/langchain/autologging.html) 提供以下能力：

- **[Tracing](https://mlflow.org/docs/latest/llms/langchain/autologging.html)**：只需一行代码（`mlflow.langchain.autolog()`）即可可视化 LangChain 组件中的数据流
- **[Experiment Tracking](https://mlflow.org/docs/latest/llms/langchain/index.html#experiment-tracking)**：记录 LangChain 运行中的工件、代码和指标
- **[Model Management](https://mlflow.org/docs/latest/model-registry.html)**：结合依赖追踪对 LangChain 应用进行版本管理和部署
- **[Evaluation](https://mlflow.org/docs/latest/llms/langchain/index.html#mlflow-evaluate)**：衡量 LangChain 应用的表现

**注意**：MLflow tracing 适用于 MLflow 2.14.0 及以上版本。

本简短指南聚焦于 MLflow 针对 LangChain 和 LangGraph 应用的 tracing 能力。您将看到如何用一行代码启用 tracing，并查看应用的执行流程。有关 MLflow 其他能力以及更多教程，请参阅 [MLflow documentation for LangChain](https://mlflow.org/docs/latest/llms/langchain/index.html)。如果您刚接触 MLflow，请查看 [Getting Started with MLflow](https://mlflow.org/docs/latest/getting-started/index.html) 指南。

## 设置

要开始使用面向 LangChain 的 MLflow tracing，请安装 MLflow Python 包。我们也会使用 `langchain-openai` 包。

```python
pip install mlflow langchain-openai langgraph -qU
```

接下来，设置 MLflow tracking URI 和 OpenAI API key。

```python
import os

# Set MLflow tracking URI if you have MLflow Tracking Server running
os.environ["MLFLOW_TRACKING_URI"] = ""
os.environ["OPENAI_API_KEY"] = ""
```

## MLflow tracing

MLflow 的 tracing 能力可帮助您可视化 LangChain 应用的执行流程。启用方式如下。

```python
import mlflow

# Optional: Set an experiment to organize your traces
mlflow.set_experiment("LangChain MLflow Integration")

# Enable tracing
mlflow.langchain.autolog()
```

## 示例：追踪 LangChain 应用

下面是一个展示 MLflow tracing 与 LangChain 配合使用的完整示例：

```python
import mlflow
from langchain_core.output_parsers import StrOutputParser
from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI

# Enable MLflow tracing
mlflow.langchain.autolog()

# Create a simple chain
llm = ChatOpenAI(model_name="gpt-5.5")

prompt = ChatPromptTemplate.from_messages(
    [
        (
            "system",
            "You are a helpful assistant that translates {input_language} to {output_language}.",
        ),
        ("human", "{input}"),
    ]
)

chain = prompt | llm | StrOutputParser()

# Run the chain
result = chain.invoke(
    {
        "input_language": "English",
        "output_language": "German",
        "input": "I love programming.",
    }
)
```

要查看 trace，请在终端中运行 `mlflow ui`，然后在 MLflow UI 中导航到 Traces 标签页。

## 示例：追踪 LangGraph 应用

MLflow 也支持追踪 LangGraph 应用：

```python
import mlflow
from langchain.tools import tool
from langchain.agents import create_agent


# Enable MLflow tracing
mlflow.langchain.autolog()


# Define a tool
@tool
def count_words(text: str) -> str:
    """Counts the number of words in a text."""
    word_count = len(text.split())
    return f"This text contains {word_count} words."


# Create a LangGraph agent
llm = ChatOpenAI(model="gpt-5.5")
tools = [count_words]
graph = create_agent(llm, tools)

# Run the agent
result = graph.invoke(
    {"messages": [{"role": "user", "content": "Write me a 71-word story about a cat."}]}
)
```

要查看 trace，请在终端中运行 `mlflow ui`，然后在 MLflow UI 中导航到 Traces 标签页。
