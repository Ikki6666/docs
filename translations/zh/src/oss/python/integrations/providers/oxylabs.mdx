[Oxylabs](https://oxylabs.io/) 是领先的 web intelligence collection 平台，以高标准的业务、伦理和合规实践为驱动，帮助全球企业释放数据洞察。

[langchain-oxylabs](https://pypi.org/project/langchain-oxylabs/) 实现了一组工具，使 LLM 能够与 Oxylabs Web Scraper API 交互。


## 安装与设置

<CodeGroup>
```bash pip
pip install langchain-oxylabs
```

```bash uv
uv add langchain-oxylabs
```
</CodeGroup>

## Tools

可用工具的详细信息请参阅 [Oxylabs tools documentation](/oss/integrations/tools/oxylabs/)。
