本页介绍 LangChain 与 [Parallel](https://platform.parallel.ai/) 的全部集成。

## 安装和设置

`Parallel` 集成位于其独立的 [partner package](https://pypi.org/project/langchain-parallel/) 中：

<CodeGroup>
    ```bash pip
    pip install -U langchain-parallel
    ```
    ```bash uv
    uv add langchain-parallel
    ```
</CodeGroup>

将 `PARALLEL_API_KEY` 环境变量设置为您的 Parallel API key。可在 [platform.parallel.ai](https://platform.parallel.ai) 注册获取。
