[AgentPhone](https://agentphone.to) 是一个面向 AI agent 的电话通信平台，通过简单 API 提供消息、语音通话、电话号码管理和联系人管理能力。

## 安装与设置

<CodeGroup>
```bash pip
pip install langchain-agentphone
```

```bash uv
uv add langchain-agentphone
```
</CodeGroup>

从 [agentphone.to](https://agentphone.to) 获取你的 API key，并将其设置为环境变量：

```bash
export AGENTPHONE_API_KEY="your-api-key"
```

## Tools

有关可用工具的详细信息，包括消息、语音通话、电话号码管理等，请参阅 [AgentPhone Toolkit](/oss/integrations/tools/agentphone) 指南。
