[Shale Protocol](https://shaleprotocol.com) 为开源 LLM 提供可直接用于生产环境的推理 API。它是即插即用的 API，托管在高度可扩展的 GPU 云基础设施上。

其免费层支持每个 key 每天最多 1K 次请求，目标是消除任何人开始使用 LLM 构建生成式 AI 应用的门槛。

借助 Shale Protocol，开发者和研究人员可以零成本创建应用并探索开源 LLM 的能力。

本页介绍如何将 Shale-Serve API 与 LangChain 集成。

截至 2023 年 6 月，该 API 默认支持 Vicuna-13B。未来版本还将支持更多 LLM，例如 Falcon-40B。

## 使用方法

### 1. 在 https://shaleprotocol.com 找到其 Discord 链接。通过 Discord 中的 “Shale bot” 生成 API key。不需要信用卡，也没有免费试用期限制。这是永久免费的层级，每个 API key 每天限制 1K 次请求

### 2. 将 https://shale.live/v1 用作 OpenAI API 的直接替代地址

例如：

```python
from langchain_openai import OpenAI
from langchain_core.prompts import PromptTemplate
from langchain_core.output_parsers import StrOutputParser

import os
os.environ['OPENAI_API_BASE'] = "https://shale.live/v1"
os.environ['OPENAI_API_KEY'] = "ENTER YOUR API KEY"

llm = OpenAI()

template = """Question: {question}

# Answer: Let's think step by step."""

prompt = PromptTemplate.from_template(template)


llm_chain = prompt | llm | StrOutputParser()

question = "What NFL team won the Super Bowl in the year Justin Beiber was born?"

llm_chain.invoke(question)

```
