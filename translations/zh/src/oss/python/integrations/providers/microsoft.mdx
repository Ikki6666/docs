浏览 [Microsoft Azure](https://portal.azure.com) 以及其他 [Microsoft](https://www.microsoft.com) 产品常见的 LangChain Python 集成。关于包选择、共享 Azure 设置、memory、vector store 和托管 agents，请参阅 [Azure AI 集成](/oss/integrations/providers/azure_ai)。

<Tip>
    **推荐：Microsoft Foundry**

    对于以 [Microsoft Foundry](https://learn.microsoft.com/en-us/azure/foundry/) 为中心的新 LangChain 或 LangGraph 应用，请从 [`langchain-azure-ai`](/oss/integrations/providers/azure_ai) 开始。它提供 Foundry 项目 endpoint、Azure 凭据集成、Agent Service、hosting、工具、Content Safety、检索和 Azure 可观测性。

    如需直接访问 [Azure OpenAI v1 API](https://learn.microsoft.com/en-us/azure/ai-foundry/openai/api-version-lifecycle?tabs=python)、运行会在 OpenAI 与 Azure 之间切换的代码、使用传统 Azure OpenAI API 版本或 completion LLM，或者希望依赖面更小，请使用 `langchain-openai` 包。

</Tip>

<Note>
    **Claude on Azure**

    Microsoft Foundry 也提供对全部 [Anthropic Claude models](https://learn.microsoft.com/en-us/azure/foundry/foundry-models/how-to/use-foundry-models-claude) 的访问，包括 Opus、Sonnet 和 Haiku。Claude 模型通过 Anthropic 原生专用 endpoint 提供，而不是 Azure OpenAI v1 API。对于 Foundry project endpoint 和 Microsoft Entra ID，优先使用 `langchain-azure-ai` 中的 `AzureAIAnthropicChatModel`。你也可以使用 `langchain-anthropic` 中指向 Foundry Anthropic endpoint 的 [`ChatAnthropic`](/oss/integrations/chat/anthropic)。

</Note>
