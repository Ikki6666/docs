>[Unstructured.IO](https://www.unstructured.io/) 提供的 `unstructured` 包可以从 PDF、Word 文档等原始源文档中提取干净文本。
本页介绍如何在 LangChain 中使用 [`unstructured`](https://github.com/Unstructured-IO/unstructured) 生态。

## 安装与设置

如果你使用的是在本地运行的 loader，可按以下步骤安装并运行 `unstructured` 及其依赖。

- 若希望安装占用最小，并使用开源 `unstructured` 包中没有的功能，请安装 Python SDK `pip install unstructured-client`，再配合 `pip install langchain-unstructured` 使用 `UnstructuredLoader`，并通过 Unstructured API 进行远程 partition。
  这个 loader 位于 LangChain partner 仓库，而不是 `langchain-community` 仓库中，并且你需要提供 `api_key`。你可以在 [Unstructured API key page](https://unstructured.io/api-key/) 上生成免费 key。
    - Unstructured 关于该 sdk 的文档见：
      https://docs.unstructured.io/api-reference/api-services/sdk

- 如果希望全部在本地运行，请安装开源 Python 包 `pip install unstructured`，再安装 `pip install langchain-community`，并使用上文提到的同一个 `UnstructuredLoader`。
    - 你可以通过 extras 安装特定文档类型的依赖，例如 `pip install "unstructured[docx]"`。更多 extras 信息参见[完整安装文档](https://docs.unstructured.io/open-source/installation/full-installation)。
    - 若要安装所有文档类型的依赖，请使用 `pip install "unstructured[all-docs]"``。
- 如果你的系统中还没有以下系统依赖，请安装，例如在 Mac 上可使用 `brew install`。
  具体是否都需要，取决于你要解析的文档类型。
    - `libmagic-dev`（文件类型检测）
    - `poppler-utils`（图像和 PDF）
    - `tesseract-ocr`（图像和 PDF）
    - `qpdf`（PDF）
    - `libreoffice`（MS Office 文档）
    - `pandoc`（EPUB）
- 在本地运行时，Unstructured 还建议按照这份[指南](https://docs.unstructured.io/open-source/installation/docker-installation)使用 Docker，以确保所有系统依赖都已正确安装。

Unstructured API 需要 API key 才能发起请求。
你可以[申请一个 API key](https://unstructured.io/api-key-hosted) 并立即开始使用。
可以先阅读 [Unstructured API README](https://github.com/Unstructured-IO/unstructured-api) 了解如何发起 API 调用。
也欢迎在其 [community slack](https://join.slack.com/t/unstructuredw-kbe4326/shared_invite/zt-1x7cgo0pg-PTptXWylzPQF9xZolzCnwQ) 中反馈使用体验。
同时也可关注后续在质量和性能上的持续改进。
如果你希望自托管 Unstructured API 或在本地运行它，可参见 [Docker self-hosting instructions](https://github.com/Unstructured-IO/unstructured-api#dizzy-instructions-for-using-the-docker-image)。
