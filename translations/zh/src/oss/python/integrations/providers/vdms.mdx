> [VDMS](https://github.com/IntelLabs/vdms/blob/master/README.md) 是一种存储解决方案，能够高效访问大规模“视觉”数据。它旨在通过基于图中存储的视觉元数据搜索相关视觉数据来实现云规模能力，并支持对视觉数据进行更适合机器处理的增强，从而提升访问速度。

## 安装与设置

### 安装客户端

<CodeGroup>
```bash pip
pip install langchain-vdms
```

```bash uv
uv add langchain-vdms
```
</CodeGroup>

### 安装数据库

你可以通过两种方式开始使用 VDMS：


1. 通过 docker 在本地机器上安装 VDMS
    ```bash
        docker run -d -p 55555:55555 intellabs/vdms:latest
    ```

2. 直接在本地机器上安装 VDMS。参见[安装说明](https://github.com/IntelLabs/vdms/blob/master/INSTALL.md)。

## VectorStore

导入该 vectorstore：

```python
from langchain_vdms import VDMS
from langchain_vdms.vectorstores import VDMS
```
导入 VDMS Client 连接器：

```python
from langchain_vdms.vectorstores import VDMS_Client
```

若要查看更详细的 VDMS 封装器使用说明，参见 [VDMS](/oss/integrations/vectorstores/vdms)。
