[Salesforce](https://www.salesforce.com/) 是一家基于云的软件公司，提供客户关系管理（CRM）解决方案，以及围绕销售、客户服务、营销自动化和分析的一整套企业应用。

[langchain-salesforce](https://pypi.org/project/langchain-salesforce/) 实现了一组工具，使 LLM 能够与 Salesforce 数据交互。


## 安装与设置

<CodeGroup>
```bash pip
pip install langchain-salesforce
```

```bash uv
uv add langchain-salesforce
```
</CodeGroup>

## Tools

可用工具的详细信息请参阅 [Salesforce tools documentation](/oss/integrations/tools/salesforce/)。
