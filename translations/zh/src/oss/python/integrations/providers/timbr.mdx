>什么是 `Timbr`？

>- Timbr 是一个`语义 SQL 知识图谱平台`，专注于通过本体驱动的语义层连接数据。
>- Timbr 允许你使用更贴近业务的语言表示和查询数据，因此非常适合处理复杂的数据关系和业务逻辑。
>- Timbr 提供 `natural language to SQL` 能力，使你能够用自然英语查询轻松与数据交互。
>- 借助 Timbr，你可以实现高性能的`语义数据查询`，适用于生产级分析和商业智能场景。

>访问[官方网站](https://docs.timbr.ai/doc/docs/getting-started/intro-timbr/)即可开始使用 Timbr。

## 安装与设置

- 使用 `pip install langchain-timbr` 安装 Python SDK

### 可选：安装时包含指定 LLM provider

从以下选项中选择其一：openai、anthropic、google、azure_openai、snowflake、databricks、vertex_ai（或 `'all'`）

```bash
pip install 'langchain-timbr[<your selected providers, separated by comma without spaces>]'
```

## Semantic SQL queries

Timbr 提供了围绕其语义层的 wrapper，可根据自然语言输入生成 SQL 语句，并从知识图谱中检索相关信息。

```python
from langchain_timbr import create_timbr_sql_agent, ExecuteTimbrQueryChain, GenerateTimbrSqlChain
```
