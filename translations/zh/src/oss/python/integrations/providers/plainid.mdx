title: "PlainID 集成"

---

[PlainID](https://www.plainid.com/) 提供基于策略的授权（PBAC）和集中式策略执行。该集成允许您在 LLM 链的不同阶段，为 LangChain 应用强制实施细粒度访问控制。

借助 `langchain-plainid`，您可以：
- **过滤 RAG 数据：** 根据用户权限动态过滤从向量存储中检索出的文档，确保他们只能看到有权访问的数据。
- **授权 prompts：** 根据查询的*类别*，控制某个用户或租户是否被允许*调用*某个链或工具。
- **匿名化数据：** 根据在 PlainID 中定义的策略，检测并匿名化（掩码或加密）响应中的 PII 或其他敏感实体。

## 安装

首先，安装 partner package：

<CodeGroup>
```bash pip
pip install langchain_plainid
```
</CodeGroup>

## 设置

接下来，您需要使用来自 PlainID tenant 的凭证来配置 provider。您需要 Client ID、Client Secret 和 Base URL。

您可以将它们设置为环境变量：

<CodeGroup>
```bash Environment Variables
export PLAINID_CLIENT_ID="your-client-id"
export PLAINID_CLIENT_SECRET="your-client-secret"
export PLAINID_BASE_URL="[https://platform-product.us1.plainid.io](https://platform-product.us1.plainid.io)"
```
</CodeGroup>

如果在实例化时未显式提供凭证，所有组件都会自动使用这些环境变量。

## 用法

该包提供三个主要组件来强制执行授权。

### RAG 数据过滤

`PlainIDRetriever` 会包装您现有的向量存储 retriever。它会根据用户身份从 PlainID 获取授权过滤器，并将其应用到向量存储查询中。这样可以在文档被传递给 LLM 作为上下文之前就将其过滤掉。

该示例假设您已经配置好了 `PlainIDPermissionsProvider`（例如通过环境变量），并设置了 `PlainIDRetrieverFilterProvider`。

### Prompt 授权

`PlainIDCategorizer` 可以放在链的起始位置，用于授权用户的*意图*。它会对输入 prompt 进行分类（例如 “HR”、“Finance”、“Contract”），并向 PlainID 检查用户是否有权询问该类别。如果未获授权，它会抛出 `ValueError`。

### PII 匿名化

`PlainIDAnonymizer` 可以放在链的末尾，用于检查 LLM 的响应。它使用 `presidio` 检测 PII 实体（如 “PERSON”、“PHONE_NUMBER”），然后咨询 PlainID，以决定是否根据已定义策略对其执行 `MASK` 或 `ENCRYPT`。

有关更多详细信息和完整示例，请参阅 [langchain_plainid PyPI page](https://pypi.org/project/langchain_plainid/)。
