> [any-llm](https://github.com/mozilla-ai/any-llm) 是一个统一接口，可用于调用 OpenAI、Anthropic、Google、本地模型（通过 Ollama/LocalAI）以及[更多提供方](https://mozilla-ai.github.io/any-llm/providers/)。你只需要改一个字符串，就能在不同 provider 之间切换。

## 安装与设置

<CodeGroup>
```bash pip
pip install langchain-anyllm
```

```bash uv
uv add langchain-anyllm
```
</CodeGroup>

你需要为所选 provider 准备对应的 API key。API key 可以通过 `api_key` 参数传入，也可以设置为环境变量（例如 `OPENAI_API_KEY`、`ANTHROPIC_API_KEY`）。不同 provider 的要求请参阅 [any-llm documentation](https://mozilla-ai.github.io/any-llm/providers/)。

## Chat models

```python
from langchain_anyllm import ChatAnyLLM
```
