本页介绍所有与 [Google Gemini](https://ai.google.dev/gemini-api/docs)、[Google Cloud](https://cloud.google.com/) 以及其他 Google 产品相关的 LangChain 集成，例如 Google Maps、YouTube 和[更多产品](#other-google-products)。

<Note>
    **统一 SDK 与包整合**

    从 `langchain-google-genai` 4.0.0 开始，这个包使用整合后的 [`google-genai`](https://googleapis.github.io/python-genai/) SDK，并且现在同时支持 **Gemini Developer API** 和 **Vertex AI** 两种后端。

    `langchain-google-vertexai` 包仍然会继续支持 Vertex AI 平台专属特性，例如 Model Garden、Vector Search、评估服务等。

    阅读[完整公告和迁移指南](https://github.com/langchain-ai/langchain-google/discussions/1422)了解详情。
</Note>

不确定该用哪个包？

<AccordionGroup>
    <Accordion title="Google Generative AI (Gemini API & Vertex AI)">
        通过 **[Gemini Developer API](https://ai.google.dev/)** 或 **[Vertex AI](https://cloud.google.com/vertex-ai)** 访问 Google Gemini 模型。后端会根据你的配置自动选择。

        - **Gemini Developer API**：基于 API key 的快速配置，适合个人开发者和快速原型
        - **Vertex AI**：具备与 Google Cloud 集成的企业级能力，需要 GCP project

        对于 chat models、LLMs 和 embeddings，请使用 `langchain-google-genai` 包。

        [查看集成。](#google-generative-ai)
    </Accordion>
    <Accordion title="Google Cloud (Vertex AI Platform Services)">
        访问 Gemini 模型之外的 Vertex AI 平台能力，例如 Model Garden 中的 Llama、Mistral、Anthropic，评估服务，以及专用视觉模型。

        对于平台能力请使用 `langchain-google-vertexai`，而对于其他云服务如数据库和存储，则使用相应的专用包，例如 `langchain-google-community`、`langchain-google-cloud-sql-pg`。

        [查看集成。](#google-cloud)
    </Accordion>
</AccordionGroup>

更多差异说明，参见 Google 关于[从 Gemini API 迁移到 Vertex AI](https://ai.google.dev/gemini-api/docs/migrate-to-cloud) 的指南。
