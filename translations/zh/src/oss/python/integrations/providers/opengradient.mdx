[OpenGradient](https://www.opengradient.ai/) 是一个去中心化 AI 计算网络，可提供全球可访问、无需许可且可验证的机器学习模型推理。

OpenGradient 的 langchain 包当前提供了一个 toolkit，让开发者能够为 OpenGradient 网络上的模型构建自定义机器学习推理工具。此前，这是一件很有挑战的事情，因为大型模型参数会污染上下文窗口，例如，你可以想象一下，不得不给 agent 提供一个 200x200 的浮点数组！

该 toolkit 通过将所有数据处理逻辑封装在工具定义内部，解决了这个问题。这种方式既能保持 agent 的上下文窗口整洁，又能让开发者完全自由地为其机器学习模型实现自定义数据处理与实时数据检索。

## 安装和设置

请确保您拥有一个 OpenGradient API key 以访问 OpenGradient 网络。如果已经有 API key，只需设置环境变量：

```python
!export OPENGRADIENT_PRIVATE_KEY="your-api-key"
```

如果您需要设置一个新的 API key，请下载 opengradient SDK，并按照说明初始化新配置。

```python
!pip install opengradient
!opengradient config init
```

设置好 API key 后，安装 `langchain-opengradient` 包。

```python
pip install -U langchain-opengradient
```

## OpenGradient toolkit

OpenGradientToolkit 使开发者能够基于部署在 OpenGradient 去中心化网络上的 [ML models](https://hub.opengradient.ai/models) 和 [workflows](https://docs.opengradient.ai/developers/sdk/ml_workflows.html) 创建专用工具。该集成让 LangChain agents 能访问强大的机器学习能力，同时保持高效的上下文使用。

### 核心优势

* 🔄 实时数据集成 - 在工具内部处理实时数据流

* 🎯 动态处理 - 可根据特定 agent 输入自适应的自定义数据流水线

* 🧠 上下文高效 - 在不淹没上下文窗口的前提下处理复杂机器学习操作

* 🔌 无缝部署 - 轻松集成已部署在 OpenGradient 网络上的模型

* 🔧 完全可定制 - 通过 [OpenGradient SDK](https://docs.opengradient.ai/developers/sdk/model_management.html) 创建并部署您自己的专用模型，再基于它们构建自定义工具

* 🔐 可验证推理 - 所有推理都运行在去中心化的 OpenGradient 网络上，允许用户选择 ZKML 和 TEE 等多种安全机制，以实现无信任、可验证的模型执行
