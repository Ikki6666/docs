>[Qdrant](https://qdrant.tech/documentation/)（读作：quadrant）是一个向量相似度搜索引擎。
> 它提供生产就绪的服务，并带有便捷 API，用于存储、搜索和管理
> points，即带附加 payload 的向量。`Qdrant` 特别适合扩展过滤支持。

## 安装和设置

安装 Python partner package：

<CodeGroup>
```bash pip
pip install langchain-qdrant
```

```bash uv
uv add langchain-qdrant
```
</CodeGroup>

## Embedding 模型

### FastEmbedSparse

```python
from langchain_qdrant import FastEmbedSparse
```

### SparseEmbeddings

```python
from langchain_qdrant import SparseEmbeddings
```

## 向量存储

这里提供了一个围绕 `Qdrant` indexes 的 wrapper，可让您将其用作 vectorstore，
无论是进行语义搜索还是示例选择。

导入该 vectorstore：
```python
from langchain_qdrant import QdrantVectorStore
```

有关 Qdrant wrapper 的更详细说明，请参阅[这个 notebook](/oss/integrations/vectorstores/qdrant)。
