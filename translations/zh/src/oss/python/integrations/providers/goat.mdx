[GOAT](https://github.com/goat-sdk/goat) 是面向 AI 智能体的金融工具包。

您可以创建能够执行以下操作的智能体：

- 发送和接收付款
- 购买实体和数字商品及服务
- 执行多种投资策略：
  - 获取收益
  - 在预测市场中下注
- 购买加密资产
- 将任意资产代币化
- 获取金融洞察

### 工作原理

GOAT 利用区块链、加密货币（例如稳定币）和钱包作为基础设施，使智能体能够成为经济行为主体：

1. 为您的智能体提供一个[钱包](https://github.com/goat-sdk/goat/tree/main#chains-and-wallets)
2. 允许它在[任意地方](https://github.com/goat-sdk/goat/tree/main#chains-and-wallets)进行交易
3. 使用超过 [+200 个工具](https://github.com/goat-sdk/goat/tree/main#tools)

请参阅 [GOAT 支持的全部内容](https://github.com/goat-sdk/goat/tree/main#chains-and-wallets)。

**轻量且可扩展**

与其他工具包不同，GOAT 通过保持核心最小化，并让您只安装所需工具，来实现轻量和可扩展。

如果您在我们超过 200 个集成中找不到所需内容，您也可以轻松：

- 创建自己的插件
- 集成新的链
- 集成新的钱包
- 集成新的智能体框架

请参阅[如何贡献](https://github.com/goat-sdk/goat/tree/main#-contributing)。
