本页介绍如何在 LangChain 中运行 Replicate 上的模型。

## 安装与设置
- 创建一个 [Replicate](https://replicate.com) 账户。获取你的 API key，并将其设置为环境变量 `REPLICATE_API_TOKEN`
- 安装 [Replicate python client](https://github.com/replicate/replicate-python)，命令为 `pip install replicate`

## 调用模型

在 [Replicate explore page](https://replicate.com/explore) 上找到一个模型，然后按如下格式粘贴模型名称和版本：`owner-name/model-name:version`

例如，对于这个 [dolly model](https://replicate.com/replicate/dolly-v2-12b)，点击 API 标签页。模型名称和版本会是：`"replicate/dolly-v2-12b:ef0e1aefc61f8e096ebe4db6b2bacc297daf2ef6899f0f7e001ec445893500e5"`

只要求传入 `model` 参数，不过也可以通过 `input={model_param: value, ...}` 的格式传入其他模型参数。


例如，如果你运行的是 stable diffusion，并且想修改图像尺寸：

```
Replicate(model="stability-ai/stable-diffusion:db21e45d3f7023abc2a46ee38a23973f6dce16bb082a930b0c49861f96d1e5bf", input={'image_dimensions': '512x512'})
```

*请注意，只会返回模型的第一个输出。*
接下来，你可以这样初始化模型：

```python
llm = Replicate(model="replicate/dolly-v2-12b:ef0e1aefc61f8e096ebe4db6b2bacc297daf2ef6899f0f7e001ec445893500e5")
```

然后运行它：

```python
prompt = """
Answer the following yes/no question by reasoning step by step.
Can a dog drive a car?
"""
llm(prompt)
```

你可以用这种语法调用任意 Replicate 模型，而不仅限于 LLM。例如，你可以调用 [Stable Diffusion](https://replicate.com/stability-ai/stable-diffusion)：

```python
text2image = Replicate(model="stability-ai/stable-diffusion:db21e45d3f7023abc2a46ee38a23973f6dce16bb082a930b0c49861f96d1e5bf", input={'image_dimensions':'512x512'})

image_output = text2image("A cat riding a motorcycle by Picasso")
```
