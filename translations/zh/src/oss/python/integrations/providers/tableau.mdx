[Tableau](https://www.tableau.com/) 是一个分析平台，让任何人都能查看并理解数据。


## 安装与设置

<CodeGroup>
```bash pip
pip install langchain-tableau
```

```bash uv
uv add langchain-tableau
```
</CodeGroup>

## Tools

可用工具请参阅 [Tableau tools documentation](/oss/integrations/tools/tableau)。
