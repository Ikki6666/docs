[SurrealDB](https://surrealdb.com) 是一个为 AI 系统构建的统一多模型数据库。它把结构化与非结构化数据（包括向量搜索、图遍历、关系查询、全文搜索、文档存储和时序数据）整合进一个符合 ACID 的引擎中，既可从 3MB 的边缘二进制部署扩展到云中的 PB 级集群。通过消除对多个专用存储系统的需求，SurrealDB 能简化架构、降低延迟，并为 AI 工作负载提供一致性。

**Why SurrealDB Matters for GenAI Systems**
- **一个引擎同时负责存储和记忆：** 在一个系统中结合持久化存储与适合 agent 的快速记忆，为 agent 提供所需全部数据，并消除跨多个系统同步的需求。
- **面向 agent 的单跳记忆：** 在一次查询中完成向量搜索、图遍历、语义连接和事务写入，让 LLM agent 无需拼接关系库、图库和向量库，就能快速获得一致的记忆访问能力。
- **原地推理和实时更新：** SurrealDB 让 agent 能在数据旁边运行推理，并接收毫秒级新鲜更新，这对实时推理和协作至关重要。
- **可版本化、可持久化的上下文：** SurrealDB 支持时间旅行查询和版本化记录，让 agent 可以审计或“回放”过去状态，从而实现一致且可解释的推理。
- **即插即用的 agent memory：** 将 AI memory 作为原生概念暴露出来，使得把 SurrealDB 作为 AI 框架的即插即用后端变得更容易。

## 安装与设置

<CodeGroup>
```bash pip

```

```bash uv
uv add langchain-surrealdb
```
