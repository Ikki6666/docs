>[Upstage](https://upstage.ai) 是一家领先的人工智能公司，专注于提供达到超越人类水平表现的 LLM 组件。
>
>**Solar Pro** 是一个面向企业级场景的 LLM，针对单 GPU 部署进行了优化，在遵循指令以及处理 HTML、Markdown 等结构化格式方面表现出色。它支持英语、韩语和日语，具有顶尖的多语言性能，并在金融、医疗和法律领域具备专业能力。

>除了 Solar，Upstage 还提供用于真实世界 RAG（retrieval-augmented generation）的功能，例如 **Document Parse** 和 **Groundedness Check**。

### Upstage LangChain 集成

| API | Description | Import | Example usage |
| --- | --- | --- | --- |
| Chat | 使用 Solar Chat 构建 assistants | `from langchain_upstage import ChatUpstage` | [Go](/oss/integrations/chat/upstage) |
| Text Embedding | 将字符串嵌入为向量 | `from langchain_upstage import UpstageEmbeddings` | [Go](/oss/integrations/embeddings/upstage) |
| Groundedness Check | 验证 assistant 响应的 groundedness | `from langchain_upstage import UpstageGroundednessCheck` | [Go](/oss/integrations/tools/upstage_groundedness_check) |
| Document Parse | 将包含表格和图像的文档序列化 | `from langchain_upstage import UpstageDocumentParseLoader` | [Go](/oss/integrations/document_loaders/upstage) |

更多模型和功能细节参见 [documentations](https://console.upstage.ai/docs/getting-started/overview)。

## 安装与设置

安装 `langchain-upstage` 包：

```bash
pip install -qU langchain-core langchain-upstage
```

获取 [API Keys](https://console.upstage.ai)，并设置环境变量 `UPSTAGE_API_KEY`。

```python
import os

os.environ["UPSTAGE_API_KEY"] = "YOUR_API_KEY"
```

## Chat models

### Solar LLM

参见[使用示例](/oss/integrations/chat/upstage)。

```python
from langchain_upstage import ChatUpstage

chat = ChatUpstage()
response = chat.invoke("Hello, how are you?")
print(response)
```

## Embedding models

参见[使用示例](/oss/integrations/embeddings/upstage)。

```python
from langchain_upstage import UpstageEmbeddings

embeddings = UpstageEmbeddings(model="solar-embedding-1-large")
doc_result = embeddings.embed_documents(
    ["Sung is a professor.", "This is another document"]
)
print(doc_result)

query_result = embeddings.embed_query("What does Sung do?")
print(query_result)
```

## Document loader

### Document parse

参见[使用示例](/oss/integrations/document_loaders/upstage)。

```python
from langchain_upstage import UpstageDocumentParseLoader

file_path = "/PATH/TO/YOUR/FILE.pdf"
layzer = UpstageDocumentParseLoader(file_path, split="page")

# For improved memory efficiency, consider using the lazy_load method to load documents page by page.
docs = layzer.load()  # or layzer.lazy_load()

for doc in docs[:3]:
    print(doc)
```

## Tools

### Groundedness check

参见[使用示例](/oss/integrations/tools/upstage_groundedness_check)。

```python
from langchain_upstage import UpstageGroundednessCheck

groundedness_check = UpstageGroundednessCheck()

request_input = {
    "context": "Mauna Kea is an inactive volcano on the island of Hawaii. Its peak is 4,207.3 m above sea level, making it the highest point in Hawaii and second-highest peak of an island on Earth.",
    "answer": "Mauna Kea is 5,207.3 meters tall.",
}
response = groundedness_check.invoke(request_input)
print(response)
```
