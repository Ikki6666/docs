>[LambdaDB](https://lambdadb.ai/) 是一个面向 RAG 和 agents 的无服务器 AI 数据库。在灵活的文档模型上统一全文搜索、多向量搜索和混合搜索。它能够即时处理无限持久化内存和海量并发，并将成本降至十分之一。

## 安装和设置

安装 Python SDK：

<CodeGroup>
    ```bash pip
    pip install langchain-lambdadb
    ```

    ```bash uv
    uv add langchain-lambdadb
    ```
</CodeGroup>

您还需要一个 LambdaDB 账户，并具备：
- Project URL
- Project API key

可在 [lambdadb.ai](https://lambdadb.ai) 获取凭证。

## 向量存储

这里提供了一个围绕 `LambdaDB` collections 的 wrapper，使您可以将其用作向量存储，以支持语义搜索、RAG 和其他 AI 应用。

导入该 vectorstore：
```python
from langchain_lambdadb import LambdaDBVectorStore
```

### 快速开始

```python
from langchain_lambdadb import LambdaDBVectorStore
from langchain_openai import OpenAIEmbeddings
from lambdadb import LambdaDB
import os

# Initialize client
client = LambdaDB(
    server_url=os.environ["LAMBDADB_SERVER_URL"],
    project_api_key=os.environ["LAMBDADB_API_KEY"]
)

# Create vector store with existing collection
vector_store = LambdaDBVectorStore(
    client=client,
    collection_name="my_collection",  # Must exist beforehand
    embedding=OpenAIEmbeddings()
)
```

有关 LambdaDB wrapper 的更详细说明，请参阅[完整文档](/oss/integrations/vectorstores/lambdadb)。
