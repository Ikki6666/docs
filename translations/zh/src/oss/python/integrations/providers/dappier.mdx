[Dappier](https://dappier.com) 可将任意 LLM 或您的 Agentic AI 连接到来自可信来源的实时、权利已清算、专有数据，让您的 AI 在任何主题上都成为专家。我们的专用模型包括实时网页搜索、新闻、体育、金融股票市场数据、加密货币数据，以及来自优质出版商的独家内容。您可以在 [marketplace.dappier.com](https://marketplace.dappier.com) 的市场中探索丰富的数据模型。

[Dappier](https://dappier.com) 提供经过增强、可直接用于提示词、并且与上下文相关的数据字符串，已针对与 LangChain 的无缝集成进行优化。无论您是在构建对话式 AI、推荐引擎，还是智能搜索，Dappier 与 LLM 无关的 RAG 模型都能确保您的 AI 获取经过验证的最新数据，而无需自行构建和管理检索流水线。

## 安装和设置

安装 `langchain-dappier` 并设置环境变量 `DAPPIER_API_KEY`。

<CodeGroup>
```bash pip
pip install -U langchain-dappier
export DAPPIER_API_KEY="your-api-key"
```

```bash uv
uv add langchain-dappier
export DAPPIER_API_KEY="your-api-key"
```
</CodeGroup>

您还需要设置 Dappier API 凭证，可在 [Dappier site.](https://platform.dappier.com/profile/api-keys) 生成。

您可以前往 [Dappier marketplace.](https://platform.dappier.com/marketplace) 查看支持的数据模型。
