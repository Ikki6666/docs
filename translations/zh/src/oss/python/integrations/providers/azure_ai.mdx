本页介绍 LangChain 与 [Microsoft Azure](https://azure.microsoft.com/) 及其相关项目的全部集成。

Azure AI、Dynamic Sessions、SQL Server 的集成包维护在 [langchain-azure](https://github.com/langchain-ai/langchain-azure) 仓库中。

## 聊天模型

我们建议开发者从 `langchain-azure-ai` 开始，以访问 [Azure AI Foundry](https://learn.microsoft.com/en-us/azure/ai-studio/how-to/model-catalog-overview) 中所有可用模型。

### Azure AI chat completions

使用 `AzureAIOpenAIApiChatModel` 类可访问 Azure OpenAI、DeepSeek R1、Cohere、Phi 和 Mistral 等模型。

<CodeGroup>
```bash pip
pip install -U langchain-azure-ai
```

```bash uv
uv add langchain-azure-ai
```
</CodeGroup>

配置您的 endpoint。您可以结合 `DefaultAzureCredential` 使用 project endpoint，也可以直接设置 API key。

```bash
export AZURE_AI_PROJECT_ENDPOINT=your-project-endpoint
```

```python
from langchain_azure_ai.chat_models import AzureAIOpenAIApiChatModel
from azure.identity import DefaultAzureCredential

llm = AzureAIOpenAIApiChatModel(
    model="gpt-5.5",
    credential=DefaultAzureCredential(),
)

llm.invoke('Tell me a joke and include some emojis')
```

## 向量存储

### Azure CosmosDB NoSQL vector search

> [Azure CosmosDB NoSQL](https://azure.microsoft.com/en-us/products/cosmos-db/) 是一个全托管、
> 全球分布式、无服务器文档数据库，面向现代应用。它以灵活的
> JSON 文档形式存储数据，并使用类 SQL 查询语言。由此带来高性能、低延迟和自动、
> 弹性扩展能力。它还为生成式 AI 和 RAG 等 AI 工作负载提供集成式向量搜索能力。
> 这使您可以在同一个数据库中，将向量嵌入与业务数据一起存储、索引和查询。
> 您可以将向量相似度搜索与传统基于关键词的搜索相结合，以获得相关结果，并从多种索引方法中选择最佳性能方案。
> 这种统一方式可简化应用架构并确保数据一致性。

要使用此 vector store，我们需要安装 `langchain-azure-cosmosdb` 和 `azure-cosmos` 包。

<CodeGroup>
    ```bash pip
    pip install -qU langchain-azure-cosmosdb azure-cosmos
    ```

    ```bash uv
    uv add langchain-azure-cosmosdb azure-cosmos
    ```
</CodeGroup>

```python
from langchain_azure_cosmosdb import AzureCosmosDBNoSqlVectorSearch

vector_search = AzureCosmosDBNoSqlVectorSearch.from_documents(
    documents=docs,
    embedding=openai_embeddings,
    cosmos_client=cosmos_client,
    database_name=database_name,
    container_name=container_name,
    vector_embedding_policy=vector_embedding_policy,
    full_text_policy=full_text_policy,
    indexing_policy=indexing_policy,
    cosmos_container_properties=cosmos_container_properties,
    cosmos_database_properties={},
    full_text_search_enabled=True,
)
```

请参阅[用法示例](/oss/integrations/vectorstores/azure_cosmos_db_no_sql)。

### Azure CosmosDB mongo vCore vector search

> [Azure CosmosDB Mongo vCore](https://learn.microsoft.com/en-us/azure/cosmos-db/mongodb/vcore/) 架构
> 让您可以轻松创建具备完整原生 MongoDB 支持的数据库。您可以沿用 MongoDB 经验，
> 继续使用自己偏好的 MongoDB drivers、SDKs 和工具，只需将应用指向
> API for MongoDB（vCore）cluster 的连接字符串。

要使用此 vector store，我们需要安装 `pymongo` 包。

<CodeGroup>
    ```bash pip
    pip install -qU pymongo
    ```

    ```bash uv
    uv add pymongo
    ```
</CodeGroup>

```python
from langchain_azure_ai.vectorstores.azure_cosmos_db_mongo_vcore import (
    AzureCosmosDBMongoVCoreVectorSearch,
)

vectorstore = AzureCosmosDBMongoVCoreVectorSearch.from_documents(
    docs,
    openai_embeddings,
    collection=collection,
    index_name=INDEX_NAME,
)
```

请参阅[用法示例](/oss/integrations/vectorstores/azure_cosmos_db_mongo_vcore)。
