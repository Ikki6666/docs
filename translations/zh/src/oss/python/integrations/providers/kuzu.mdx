> [Kùzu](https://kuzudb.com/) 是一个可嵌入、可扩展且速度极快的图数据库。
> 它采用宽松的 MIT 许可证发布，您可以在 [GitHub](https://github.com/kuzudb/kuzu) 查看其源码。

> Kùzu 的主要特点：
>- 性能与可扩展性：为图实现了现代化、最先进的 join 算法。
>- 易用性：由于没有服务器（嵌入式架构），非常容易安装和上手。
>- 互操作性：可以方便地从外部列式格式、CSV、JSON 以及关系型数据库中扫描和复制数据。
>- 结构化属性图模型：实现了带额外结构的属性图模型。
>- Cypher 支持：可使用声明式查询语言 Cypher 便捷地查询图。

> 访问他们的 [documentation](https://docs.kuzudb.com/) 开始使用 Kùzu。

## 安装和设置

按如下方式安装 Python SDK：

<CodeGroup>
```bash pip
pip install -U langchain-kuzu
```

```bash uv
uv add langchain-kuzu
```
</CodeGroup>
