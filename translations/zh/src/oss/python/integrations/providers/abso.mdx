[Abso](https://abso.ai/#router) 是一个开源 LLM proxy，会根据提示词复杂度在快模型和慢模型之间自动路由请求。它使用多种启发式方法来选择合适的模型，速度很快且延迟很低。

## 安装与设置

```bash
pip install langchain-abso
```
