[Bodo DataFrames](https://github.com/bodo-ai/Bodo) 是一个高性能 DataFrame 库，用于大规模 Python 数据处理，并且是 Pandas 的可直接替代方案。只需将：

```python
import pandas as pd
```

替换为：

```python
import bodo.pandas as pd
```

即可自动扩展并加速 Pandas 工作负载。
由于 Bodo DataFrames 与 Pandas 兼容，因此它非常适合作为 LLM 代码生成的目标，既易于验证，又高效，并且能够突破 Pandas 的常见限制实现扩展。

我们的集成包提供了一个工具包，可让智能体借助 Bodo DataFrames 以更高的效率和可扩展性对大型数据集进行提问。

在底层，Bodo DataFrames 使用惰性求值来优化一系列 Pandas 操作，通过算子流式传输数据以支持处理超出内存大小的数据集，并利用基于 MPI 的高性能计算技术来实现高效并行执行，能够轻松从笔记本电脑扩展到大型集群。

## 安装和设置

```bash pip
pip install -U langchain_bodo
```

## 工具包

[langchain-bodo 包](https://pypi.org/project/langchain-bodo/)提供了用于创建智能体的功能，这些智能体可以使用 Bodo DataFrames 回答有关大型数据集的问题。
有关更详细的用法示例，请参阅 [Bodo DataFrames 工具页面](/oss/integrations/tools/bodo)。

**注意：此功能底层使用 `Python` 智能体，它会执行 LLM 生成的 Python 代码。如果 LLM 生成的 Python 代码具有危害性，可能会带来风险。请谨慎使用。**

```python
from langchain_bodo import create_bodo_dataframes_agent
```

### 用法示例

在运行下面的代码之前，请复制 [titanic dataset](https://raw.githubusercontent.com/pandas-dev/pandas/main/doc/data/titanic.csv) 并将其保存为本地文件 `titanic.csv`。

```python
import bodo.pandas as pd
from langchain_openai import OpenAI

df = pd.read_csv("titanic.csv")
agent = create_bodo_dataframes_agent(
    OpenAI(temperature=0), df, verbose=True, allow_dangerous_code=True
)
```

```python
agent.invoke("how many rows are there?")
```
