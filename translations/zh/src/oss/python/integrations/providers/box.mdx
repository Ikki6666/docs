# langchain-box

该包包含了 LangChain 与 Box 的集成。有关
Box 的更多信息，参见其[开发者文档](https://developer.box.com)。

## 前置要求

要与 Box 集成，你需要准备以下内容：

* 一个 Box 实例。如果你还不是 Box 客户，可以注册一个
[免费的开发者账号](https://account.box.com/signup/n/developer#ty9l3)。
* 一个 Box app。关于如何创建，参见
[create an app](https://developer.box.com/guides/getting-started/first-application/)
* 你的 app 需要在 Box 实例中获得批准，这由管理员完成。
如果你使用的是免费开发者账号，那么你自己就是管理员。
[Authorize your app](https://developer.box.com/guides/authorization/custom-app-approval/#manual-approval)

## Authentication

`box-langchain` 包在认证方式上提供了一定灵活性。
最基础的认证方式是使用 developer token。你可以在
[Box developer console](https://account.box.com/developers/console)
的配置页面找到它。该 token 有意设置为短时有效，仅 1 小时，
用于开发用途。通过这个 token，你可以将其加入环境变量
`BOX_DEVELOPER_TOKEN`，也可以直接传给 loader，或者使用
`BoxAuth` 认证辅助类。

下面的章节会介绍如何直接传给 loader。

### BoxAuth helper class

`BoxAuth` 支持以下认证方式：

* Token，可以是 developer token，也可以是通过 Box SDK 生成的任意 token
* JWT with a service account
* JWT with a specified user
* CCG with a service account
* CCG with a specified user

<Note>
**如果使用 JWT 认证，你需要在生成公钥/私钥对后，从 Box developer console 下载配置文件。**

请将此文件放在应用目录结构中的某个位置。使用 `BoxAuth` helper class 时，你需要传入该文件路径。
</Note>

有关更多信息，请了解如何
[set up a Box application](https://developer.box.com/guides/getting-started/first-application/)，并查看
[Box authentication guide](https://developer.box.com/guides/authentication/select/)
了解不同认证方式的更多内容。

示例：

**Token**

```python
from langchain_box.document_loaders import BoxLoader
from langchain_box.utilities import BoxAuth, BoxAuthType

auth = BoxAuth(
    auth_type=BoxAuthType.TOKEN,
    box_developer_token=box_developer_token
)

loader = BoxLoader(
    box_auth=auth,
    ...
)
```

**JWT with a service account**

```python
from langchain_box.document_loaders import BoxLoader
from langchain_box.utilities import BoxAuth, BoxAuthType

auth = BoxAuth(
    auth_type=BoxAuthType.JWT,
    box_jwt_path=box_jwt_path
)

loader = BoxLoader(
    box_auth=auth,
    ...
```

**JWT with a specified user**

```python
from langchain_box.document_loaders import BoxLoader
from langchain_box.utilities import BoxAuth, BoxAuthType

auth = BoxAuth(
    auth_type=BoxAuthType.JWT,
    box_jwt_path=box_jwt_path,
    box_user_id=box_user_id
)

loader = BoxLoader(
    box_auth=auth,
    ...
```

**CCG with a service account**

```python
from langchain_box.document_loaders import BoxLoader
from langchain_box.utilities import BoxAuth, BoxAuthType

auth = BoxAuth(
    auth_type=BoxAuthType.CCG,
    box_client_id=box_client_id,
    box_client_secret=box_client_secret,
    box_enterprise_id=box_enterprise_id
)

loader = BoxLoader(
    box_auth=auth,
    ...
```

**CCG with a specified user**

```python
from langchain_box.document_loaders import BoxLoader
from langchain_box.utilities import BoxAuth, BoxAuthType

auth = BoxAuth(
    auth_type=BoxAuthType.CCG,
    box_client_id=box_client_id,
    box_client_secret=box_client_secret,
    box_user_id=box_user_id
)

loader = BoxLoader(
    box_auth=auth,
    ...
```

如果你希望在 `authorization_code` 流程中使用 OAuth2，请使用已获取 token 对应的 `BoxAuthType.TOKEN`。
