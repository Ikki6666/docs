>[Chroma](https://docs.trychroma.com/getting-started) 是一个用于构建 embedding 驱动 AI 应用的数据库。

## 安装与设置

<CodeGroup>
```bash pip
pip install langchain-chroma
```

```bash uv
uv add langchain-chroma
```
</CodeGroup>


## VectorStore

存在一个围绕 Chroma 向量数据库的 wrapper，使你能够把它当作 vectorstore 来使用，无论是用于语义搜索还是示例选择。

```python
from langchain_chroma import Chroma
```

如需更详细的 Chroma wrapper 使用说明，请参阅[这个 notebook](/oss/integrations/vectorstores/chroma)。
