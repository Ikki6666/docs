> Smabbler 的图驱动平台通过把数据转换为结构化知识基础来提升 AI 开发效率。

## Galaxia

> Galaxia Knowledge Base 是一个面向 RAG 的集成式知识库和检索机制。与标准方案不同，它基于使用符号 NLP 和知识表示方案构建的 Knowledge Graph。输入文本会被分析并转换为包含文本、语言和语义信息的图。这种丰富结构使检索能够基于语义信息，而不是向量相似度或距离。

要使用 Galaxia 实现 RAG，首先需要将文件上传到 [Galaxia](https://beta.cloud.smabbler.com/home)，在其中进行分析，然后构建模型（知识图谱）。当模型构建完成后，你就可以使用 `GalaxiaRetriever` 连接 API 并开始检索。

更多信息：[docs](https://smabbler.gitbook.io/smabbler)

## 安装
<CodeGroup>
```bash pip
pip install langchain-galaxia-retriever
```

```bash uv
uv add langchain-galaxia-retriever
```
</CodeGroup>

## 用法

```python
from langchain_galaxia_retriever.retriever import GalaxiaRetriever

gr = GalaxiaRetriever(
    api_url="beta.api.smabbler.com",
    api_key="<key>",
    knowledge_base_id="<knowledge_base_id>",
    n_retries=10,
    wait_time=5,
)

result = gr.invoke('<test question>')
print(result)
```
