越来越多客户正在使用 [SambaNova](https://sambanova.ai/) 快速部署最先进的 AI 能力，以获得竞争优势。面向企业规模打造的 AI 平台，是下一代 AI 计算的技术底座。它所提供的基础模型，能够释放沉淀在数据中的宝贵业务洞察。

专为 AI 设计的 SambaNova RDU 构建于革命性的数据流架构之上。由于这种设计消除了 GPU 工作方式中固有的、对内存的重复调用，RDU 在这些工作负载上相比 GPU 效率更高。这种内建效率也是 RDU 能够在更小占用下实现更高性能的原因之一。

在这套架构之上，还开发了一些平台，使企业和开发者能够充分利用 RDU 处理器和开源模型。


## 安装与设置

安装集成包：

<CodeGroup>
```bash
pip install langchain-sambanova
```

```bash uv
uv add langchain-sambanova
```
</CodeGroup>


## API Key
将你的 API key 设置为环境变量：

如果你是 SambaCloud 用户，请申请一个 [API key](http://cloud.sambanova.ai/apis?utm_source=langchain&utm_medium=external&utm_campaign=cloud_signup)，并将其设置为环境变量：

```bash
export SAMBANOVA_API_KEY="your-sambacloud-api-key-here"
```

如果你是 SambaStack 用户，则需要将 base URL 和 API key 设置为环境变量：

```bash
export SAMBANOVA_API_BASE="your-sambastack-envirronment-base-url-here"
export SAMBANOVA_API_KEY="your-sambastack-api-key-here"
```
