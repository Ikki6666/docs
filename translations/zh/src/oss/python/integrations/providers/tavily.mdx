[Tavily](https://tavily.com) 是一个专为 AI agents 设计的搜索引擎，提供 search、extract、crawl 和 map API，使开发者能够将应用连接到实时在线信息。Tavily 的核心使命是从可信来源提供事实准确、可靠的信息，从而提升 AI 生成内容和推理的准确性与可靠性。

`langchain-tavily` 包将 Tavily 的 Search、Extract、Crawl 和 Map 端点暴露为 LangChain tools。

## 安装与设置

为 LangChain Python 安装 Tavily 集成包：

<CodeGroup>
```bash pip
pip install langchain-tavily
```

```bash uv
uv add langchain-tavily
```
</CodeGroup>

[设置一个 Tavily API key](https://app.tavily.com)，并将其设置为名为 `TAVILY_API_KEY` 的环境变量：

```bash
export TAVILY_API_KEY="your-api-key"
```

## Tools

### TavilySearch

一个搜索工具，可返回来自 Tavily Search API 的实时、适用于 LLM 的结果。

参见[使用示例](/oss/integrations/tools/tavily_search)。

```python
from langchain_tavily import TavilySearch
```

### TavilyExtract

一个工具，可返回一个或多个 URL 的清洗后、已解析内容。

参见[使用示例](/oss/integrations/tools/tavily_extract)。

```python
from langchain_tavily import TavilyExtract
```

### TavilyCrawl

一个工具，可从基础 URL 开始执行结构化网页遍历，并支持可选的自然语言指令以及路径或域名过滤。

参见[使用示例](/oss/integrations/tools/tavily_crawl)。

```python
from langchain_tavily import TavilyCrawl
```

### TavilyMap

一个工具，用于发现网站的 URL 结构，而不提取页面内容。

参见[使用示例](/oss/integrations/tools/tavily_map)。

```python
from langchain_tavily import TavilyMap
```
