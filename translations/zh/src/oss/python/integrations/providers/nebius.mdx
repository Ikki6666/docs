与 Nebius Token Factory 相关的全部功能。

>[Nebius Token Factory](https://tokenfactory.nebius.com/) 提供对各种用例所需的先进大语言模型和 embedding 模型的 API 访问能力。

## 安装和设置

Nebius 集成可以通过 pip 安装：

<CodeGroup>
```bash pip
pip install langchain-nebius
```

```bash uv
uv add langchain-nebius
```
</CodeGroup>

要使用 Nebius Token Factory，您需要一个 API key，可从 [Nebius Token Factory](https://tokenfactory.nebius.com/) 获取。API key 可以作为初始化参数 `api_key` 传入，也可以设置为环境变量 `NEBIUS_API_KEY`。

```python
import os
os.environ["NEBIUS_API_KEY"] = "YOUR-NEBIUS-API-KEY"
```

### 可用模型

完整支持模型列表可在 [Nebius Token Factory Models Page](https://tokenfactory.nebius.com/models) 查看。

## 聊天模型

### ChatNebius

`ChatNebius` 类允许您与 Nebius Token Factory 的聊天模型交互。

请参阅[用法示例](/oss/integrations/chat/nebius)。

```python
from langchain_nebius import ChatNebius

# Initialize the chat model
chat = ChatNebius(
    model="moonshotai/Kimi-K2.5",  # Choose from available models
    temperature=0.6,
    top_p=0.95
)
```

## Embedding 模型

### NebiusEmbeddings

`NebiusEmbeddings` 类允许您使用 Nebius Token Factory 的 embedding 模型生成向量嵌入。

请参阅[用法示例](/oss/integrations/embeddings/nebius)。

```python
from langchain_nebius import NebiusEmbeddings

# Initialize embeddings
embeddings = NebiusEmbeddings(
    model="Qwen/Qwen3-Embedding-8B"  # Default embedding model
)
```

## 检索器

### NebiusRetriever

`NebiusRetriever` 使用来自 Nebius Token Factory 的 embeddings 来实现高效的相似度搜索。它利用高质量 embedding 模型对文档执行语义搜索。

请参阅[用法示例](/oss/integrations/retrievers/nebius)。

```python
from langchain_core.documents import Document
from langchain_nebius import NebiusEmbeddings, NebiusRetriever

# Create sample documents
docs = [
    Document(page_content="Paris is the capital of France"),
    Document(page_content="Berlin is the capital of Germany"),
]

# Initialize embeddings
embeddings = NebiusEmbeddings()

# Create retriever
retriever = NebiusRetriever(
    embeddings=embeddings,
    docs=docs,
    k=2  # Number of documents to return
)
```

## 工具

### NebiusRetrievalTool

`NebiusRetrievalTool` 允许您基于 `NebiusRetriever` 为 agents 创建一个工具。

```python
from langchain_nebius import NebiusEmbeddings, NebiusRetriever, NebiusRetrievalTool
from langchain_core.documents import Document

# Create sample documents
docs = [
    Document(page_content="Paris is the capital of France and has the Eiffel Tower"),
    Document(page_content="Berlin is the capital of Germany and has the Brandenburg Gate"),
]

# Create embeddings and retriever
embeddings = NebiusEmbeddings()
retriever = NebiusRetriever(embeddings=embeddings, docs=docs)

# Create retrieval tool
tool = NebiusRetrievalTool(
    retriever=retriever,
    name="nebius_search",
    description="Search for information about European capitals"
)
```
