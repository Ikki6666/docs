[Bright Data](https://brightdata.com) 是一个网页数据平台，提供网页抓取、SERP 采集以及访问地理限制内容的工具。

Bright Data 允许开发者从网站提取结构化数据、执行搜索引擎查询，以及访问原本可能被屏蔽或受地理限制的内容。该平台旨在帮助解决常见的网页抓取难题，包括反爬系统、CAPTCHA 和 IP 封锁。

## 安装和设置

<CodeGroup>
```bash pip
pip install langchain-brightdata
```

```bash uv
uv add langchain-brightdata
```

</CodeGroup>

您需要设置 Bright Data API 密钥：

在 [Bright Data](https://brightdata.com/?utm_source=tech-partner&utm_medium=link&utm_campaign=langchain&hs_signup=1) 注册，并从账户设置中获取 API 密钥。在下面的示例中，将 `"your-api-key"` 替换为您的真实 API 密钥：

```python
import os
os.environ["BRIGHT_DATA_API_KEY"] = "your-api-key"
```

或者，您也可以在初始化工具时直接传入：

```python
from langchain_brightdata import BrightDataSERP

tool = BrightDataSERP(bright_data_api_key="your-api-key")
```

## 工具

Bright Data 集成提供多个工具：

- [BrightDataSERP](/oss/integrations/tools/brightdata_serp) - 支持地理定位和自定义 zone 的搜索引擎结果采集
- [BrightDataUnlocker](/oss/integrations/tools/brightdata_unlocker) - 访问可能受地理限制或机器人防护保护的任意公开网站
- [BrightDataWebScraperAPI](/oss/integrations/tools/brightdata-webscraperapi) - 从 44 个热门域名中提取结构化数据，包括 Amazon、LinkedIn、Instagram、TikTok 等
