[Zotero](https://www.zotero.org/) 是一个开源的参考文献管理系统，用于管理书目数据及相关研究资料。你可以通过 [API](https://www.zotero.org/support/dev/web_api/v3/start) 连接到个人资料库，也可以连接到共享的群组资料库。这个 retriever 实现使用 [PyZotero](https://github.com/urschrei/pyzotero) 来访问资料库。

## 安装

```bash
pip install pyzotero
```

## Retriever

参阅[使用示例](/oss/integrations/retrievers/zotero)。

```python
from langchain_zotero_retriever.retrievers import ZoteroRetriever
```
