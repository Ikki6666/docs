> [FMP-Data](https://pypi.org/project/fmp-data/) 是一个 Python 包，
> 用于连接 Financial Data Prep API，让你更容易访问生产级数据。


## 安装与设置

访问[这个页面](https://site.financialmodelingprep.com/pricing-plans?couponCode=mehdi)，
获取 `FMP Data` API key，并将其设置为环境变量（`FMP_API_KEY`）。

然后安装 [langchain-fmp-data](https://pypi.org/project/langchain-fmp-data/)。

## Tools

参阅[示例](https://github.com/MehdiZare/langchain-fmp-data/tree/main/docs)。

```python
from langchain_fmp_data import FMPDataTool, FMPDataToolkit
```
