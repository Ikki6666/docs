[Nia](https://trynia.ai) 是一个搜索和索引 API，可持续从文档、研究论文、数据集、代码库等来源提供上下文，因此 agent 不会依赖过时数据。它可扩展、成本低 5 倍，并且可靠。

## 安装与设置

<CodeGroup>
```bash pip
pip install langchain-nia
```

```bash uv
uv add langchain-nia
```
</CodeGroup>

设置你的 API key：

```bash
export NIA_API_KEY="nk_..."
```

## Tools

`langchain-nia` 包提供了 20 个工具，并组织成一个可配置的 toolkit。

关于完整细节、使用示例以及全部可用工具列表，请参阅 [Nia Toolkit integration guide](/oss/integrations/tools/nia)。

```python
from langchain_nia import NiaToolkit

toolkit = NiaToolkit()
tools = toolkit.get_tools()  # 20 tools
```
