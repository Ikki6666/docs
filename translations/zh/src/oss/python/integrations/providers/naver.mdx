与 `Naver` 相关的全部功能，包括 HyperCLOVA X 模型，特别是可通过 `Naver Cloud` [CLOVA Studio](https://clovastudio.ncloud.com/) 访问的模型。

> [Naver](https://navercorp.com/) 是一家全球技术公司，拥有前沿技术和多元化业务组合，涵盖搜索、电商、金融科技、内容、云和 AI。

> [Naver Cloud](https://www.navercloudcorp.com/lang/en/) 是 Naver 的云计算部门，也是领先的云服务提供商之一，通过其 [Naver Cloud Platform (NCP)](https://www.ncloud.com/) 为企业提供全面的云服务套件。

更详细说明请参阅 [NCP User Guide](https://guide.ncloud-docs.com/docs/clovastudio-overview)（也提供韩文版本）。

## 安装和设置

- 通过[申请](https://api.ncloud-docs.com/docs/ai-naver-clovastudio-summary#API%ED%82%A4)获取 CLOVA Studio API Key，并将其设置为环境变量（`CLOVASTUDIO_API_KEY`）。

Naver 集成位于两个包中：

- `langchain-naver`：Naver 的专用集成包。
- `langchain-naver-community`：社区维护包，并非由 Naver 或 LangChain 官方维护。

<CodeGroup>
```bash pip
pip install -U langchain-naver
# pip install -U langchain-naver-community // Install to use Naver Search tool.
```

```bash uv
uv add langchain-naver
# uv add langchain-naver-community // Install to use Naver Search tool.
```
</CodeGroup>

> **（注意）** 通过 `langchain-community` 这一组[第三方集成](https://python.langchain.com/docs/concepts/architecture/#langchain-community)使用 Naver 的方式已过时。
> - **请改用 `langchain-naver`，因为新特性只会通过该包实现**。
> - 如果您正在使用 `langchain-community`（过时方案），并且拿到的是旧版 API Key（不是以 `nv-*` 开头），则应将其设置为 `NCP_CLOVASTUDIO_API_KEY`，并且可能还需要通过[创建应用](https://guide.ncloud-docs.com/docs/en/clovastudio-playground01#create-test-app)来获取额外的 API Gateway API Key，并将其设置为 `NCP_APIGW_API_KEY`。

## 工具

### Naver search

Naver Search 集成允许您的 LangChain 应用从 Naver 搜索引擎中检索信息。这对于韩语查询以及获取韩国相关主题的最新信息尤其有用。

要使用 Naver Search 工具，您需要：

1. 登录 [Naver Developers portal](https://developers.naver.com/main/)
2. 创建一个新应用并启用 Search API
3. 从 “Application List” 部分获取您的 **NAVER_CLIENT_ID** 和 **NAVER_CLIENT_SECRET**
4. 在应用中将它们设置为环境变量

```python
from langchain_naver_community.tool import NaverSearchResults
from langchain_naver_community.utils import NaverSearchAPIWrapper

# Set up the search wrapper
search = NaverSearchAPIWrapper()

# Create a tool
tool = NaverSearchResults(api_wrapper=search)
```

更多细节请参阅[用法示例](/oss/integrations/tools/naver_search)。

### 专用搜索工具

该包还提供针对不同内容类型的专用搜索工具：

```python
from langchain_naver_community.tool import NaverNewsSearch  # For news articles
from langchain_naver_community.tool import NaverBlogSearch  # For blog posts
from langchain_naver_community.tool import NaverImageSearch  # For images
```

这些工具都可以在 LangChain agents 中使用，以提供更有针对性的搜索能力。
