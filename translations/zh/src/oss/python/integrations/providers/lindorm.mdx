Lindorm 是阿里云推出的云原生多模数据库，支持宽表、时序、文本、对象、流和空间数据等多种数据类型的统一接入与一体化处理。它兼容 SQL、HBase/Cassandra/S3、TSDB、HDFS、Solr 和 Kafka 等多种标准接口，并可无缝集成第三方生态工具。因此，它适用于日志、监控、计费、广告、社交、出行和风控等场景。Lindorm 也是支持阿里巴巴核心业务的数据库之一。

要使用 Lindorm 的 AI 和向量能力，您需要[开通服务](https://help.aliyun.com/document_detail/174640.html?spm=a2c4g.11186623.help-menu-172543.d_0_1_0.4c6367558DN8Uq)，并安装 `langchain-lindorm-integration` 包。

```python
!pip install -U langchain-lindorm-integration
```

## Embeddings

要使用部署在 Lindorm AI Service 中的 embedding model，请导入 `LindormAIEmbeddings`。

```python
from langchain_lindorm_integration import LindormAIEmbeddings
```

## Rerank

Lindorm AI Service 也支持 reranking。

```python
from langchain_lindorm_integration.reranker import LindormAIRerank
```

## 向量存储

Lindorm 也支持向量存储。

```python
from langchain_lindorm_integration import LindormVectorStore
```

## ByteStore

使用 Lindorm 的 ByteStore

```python
from langchain_lindorm_integration import LindormByteStore
```
