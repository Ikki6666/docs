# Supadata

本页介绍如何在 LangChain 中使用 [Supadata](https://supadata.ai) 生态。它允许你从 YouTube、TikTok 和其他平台加载数据。

## 安装与设置

要使用 Supadata，你需要安装独立的集成包。

```bash
pip install supadata-langchain
```

## Document Loader

Supadata 集成允许你将多个视频平台中的内容作为 LangChain documents 加载。它支持获取字幕和元数据。

```python
import os
from supadata_langchain import SupadataLoader

os.environ["SUPADATA_API_KEY"] = "YOUR_API_KEY"

loader = SupadataLoader()

# Fetch Transcript
docs = loader.load(
    {
        "url": "[https://www.youtube.com/watch?v=dQw4w9WgXcQ](https://www.youtube.com/watch?v=dQw4w9WgXcQ)",
        "operation": "transcript",
        "lang": "en",
        "text": True,
        "mode": "auto",
    }
)

print(docs[0].page_content)
print(docs[0].metadata)
```

### Metadata

你也可以获取视频的结构化元数据。

```python
# Fetch Metadata
docs = loader.load(
    {
        "url": "https://www.youtube.com/watch?v=dQw4w9WgXcQ",
        "operation": "metadata",
    }
)

print(docs[0].page_content)
```
