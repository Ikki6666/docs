[Scrapeless](https://scrapeless.com) 提供灵活且功能丰富的数据采集服务，支持广泛的参数定制和多格式导出。

## 安装与设置

<CodeGroup>
```bash pip
pip install langchain-scrapeless
```

```bash uv
uv add langchain-scrapeless
```
</CodeGroup>

你需要先设置 Scrapeless API key：

```python
import os
os.environ["SCRAPELESS_API_KEY"] = "your-api-key"
```

## Tools

Scrapeless 集成提供以下工具：

- [ScrapelessDeepSerpGoogleSearchTool](/oss/integrations/tools/scrapeless_scraping_api) - 支持对 Google SERP 各类结果执行全面数据提取。
- [ScrapelessDeepSerpGoogleTrendsTool](/oss/integrations/tools/scrapeless_scraping_api) - 获取来自 Google 的关键词趋势数据，包括时间热度、地区兴趣和相关搜索。
- [ScrapelessUniversalScrapingTool](/oss/integrations/tools/scrapeless_universal_scraping) - 访问并提取通常会拦截机器人访问的 JS 渲染网站数据。
- [ScrapelessCrawlerCrawlTool](/oss/integrations/tools/scrapeless_crawl) - 爬取一个网站及其关联页面，以提取完整数据。
- [ScrapelessCrawlerScrapeTool](/oss/integrations/tools/scrapeless_crawl) - 从单个网页中提取信息。
