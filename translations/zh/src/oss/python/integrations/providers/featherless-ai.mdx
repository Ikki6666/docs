[Featherless AI](https://featherless.ai/) 是一个无服务器 AI 推理平台，提供对 4300+ 开源模型的访问。我们的目标是让所有 AI 模型都可以通过无服务器方式进行推理。我们通过 API 提供推理能力，并持续扩展 open-weight 模型库。

# 安装与设置
`pip install langchain-featherless-ai`
1. 在 [Featherless](https://featherless.ai/register) 注册账号
2. 订阅套餐，并在 [API Keys](https://featherless.ai/account/api-keys) 获取你的 API key
3. 把你的 API key 设置为环境变量（`FEATHERLESSAI_API_KEY`）

# 模型目录
访问我们的模型目录，查看所有模型的概览：https://featherless.ai/models
