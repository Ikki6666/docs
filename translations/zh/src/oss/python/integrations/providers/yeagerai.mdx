本页介绍如何使用 [Yeager.ai](https://yeager.ai) 生成 LangChain tools 和 agents。

## 什么是 yeager.ai？
Yeager.ai 是一个旨在简化 AI agents 和 tools 创建流程的生态系统。

它提供 yAgents，这是一款无代码 LangChain Agent Builder，能够让用户轻松构建、测试和部署 AI 解决方案。借助 LangChain 框架，yAgents 可以无缝集成多种语言模型和资源，因此适用于在各种应用场景中工作的开发者、研究人员和 AI 爱好者。

## yAgents
这是一个低代码生成式 agent，旨在帮助你轻松构建、原型设计和部署 LangChain tools。

### 如何使用？
<CodeGroup>
```bash pip
pip install yeagerai-agent
yeagerai-agent
```

```bash uv
uv add yeagerai-agent
yeagerai-agent
```
</CodeGroup>
前往 http://127.0.0.1:7860

这会安装所需依赖，并在你的系统上设置 yAgents。首次运行后，yAgents 会创建一个 `.env` 文件，你可以在其中填写 OpenAI API key。你也可以直接在 Gradio 界面的 “Settings” 标签页中完成同样的设置。

`OPENAI_API_KEY=<your_openai_api_key_here>`

推荐使用 GPT-4。不过，如果将问题拆解得足够充分，该工具也可以配合 GPT-3 使用。

### 使用 yAgents 创建并执行工具
yAgents 让创建和执行 AI 驱动的工具变得简单。下面是简要流程：
1. 创建工具：向 yAgents 提供一条自然语言提示词来创建工具。该提示词应清楚描述工具的用途和功能。例如：
`create a tool that returns the n-th prime number`

2. 将工具加载到工具包中：要把某个工具加载到 yAgents 中，只需向 yAgents 发出相应命令即可。例如：
`load the tool that you just created it into your toolkit`

3. 执行工具：要运行某个工具或 agent，只需向 yAgents 提供包含工具名称和所需参数的命令。例如：
`generate the 50th prime number`

你可以[观看演示视频](https://www.youtube.com/watch?v=KA5hCM3RaWE)了解其工作方式。

当你逐渐熟悉 yAgents 后，可以创建更高级的 tools 和 agents，以自动化工作并提升生产力。

更多信息参见 [yAgents' GitHub](https://github.com/yeagerai/yeagerai-agent) 或其 [docs](https://yeagerai.gitbook.io/docs/general/welcome-to-yeager.ai)。
