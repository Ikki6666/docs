> [Vectorize](https://vectorize.io/) 可帮助你更快、更轻松地构建 AI 应用。
> 它能够自动完成数据提取，使用 RAG 评估找到最佳向量化策略，
> 并让你快速为非结构化数据部署实时 RAG pipeline。
> 你的向量搜索索引会保持最新状态，并且它能够与你现有的向量数据库集成，
> 因此你可以继续完全掌控自己的数据。
> Vectorize 负责繁重工作，让你专注于构建稳健的 AI 解决方案，而不必被数据管理拖住。

# 安装与设置

安装以下 Python 包：

<CodeGroup>
```bash pip
pip install langchain-vectorize
```

```bash uv
uv add langchain-vectorize
```
</CodeGroup>

[注册一个免费的 Vectorize 账户](https://platform.vectorize.io/)。
在 [Access Token](https://docs.vectorize.io/rag-pipelines/retrieval-endpoint#access-tokens) 部分生成访问令牌。
收集你的 organization ID。从浏览器 URL 中提取 `/organization/` 后面的 UUID。

设置以下变量：
```python
VECTORIZE_ORG_ID="your-organization-id"
VECTORIZE_API_TOKEN="your-api-token"
```

## Retriever

```python
from langchain_vectorize import VectorizeRetriever

retriever = VectorizeRetriever(
    api_token=VECTORIZE_API_TOKEN,
    organization=VECTORIZE_ORG_ID,
    pipeline_id="...",
)
retriever.invoke("query")
```

更多信息参见[示例 notebook](/oss/integrations/retrievers/vectorize)。
