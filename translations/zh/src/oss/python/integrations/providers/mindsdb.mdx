title: "Mindsdb 集成"
description: "使用 LangChain Python 集成 Mindsdb。"
---

MindsDB 是一个基于企业数据定制 AI 的平台。借助 MindsDB 及其近 200 个到[data sources](https://docs.mindsdb.com/integrations/data-overview) 和 [AI/ML frameworks](https://docs.mindsdb.com/integrations/ai-overview) 的集成，任何开发者都可以更快、更安全地使用企业数据为自己的用途定制 AI。

通过 MindsDB，你可以把任意数据源连接到任意 AI/ML 模型，以实现并自动化 AI 驱动的应用。你可以实时部署、提供服务并微调模型，同时利用来自数据库、vector store 或应用的数据，而且这些都可以通过开发者已经熟悉的通用工具完成。

MindsDB 与 LangChain 集成后，用户可以：


- 在 MindsDB 中部署通过 LangChain 可用的模型，并让这些模型能够被大量数据源访问。
- 使用实时且动态的数据，在 MindsDB 中微调通过 LangChain 可用的模型。
- 结合 LangChain 和 MindsDB 自动化 AI 工作流。

请参阅[我们的文档](https://docs.mindsdb.com/integrations/ai-engines/langchain)，进一步了解 MindsDB 与 LangChain 的集成方式并查看示例。
