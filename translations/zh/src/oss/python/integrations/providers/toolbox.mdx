LangChain 中的 [MCP Toolbox](https://googleapis.github.io/genai-toolbox/getting-started/introduction/) 允许你为 agent 配备一组工具。当 agent 收到查询时，它可以智能选择并使用 MCP Toolbox 提供的最合适工具来完成请求。

## 这是什么？

MCP Toolbox 本质上是一个工具容器。你可以把它看作 agent 的多功能工具设备，它可以容纳你创建的任意工具。随后，agent 会根据用户输入决定使用哪一个具体工具。

当你的 agent 需要执行多种任务，并且这些任务依赖不同能力时，这种方式尤其有用。

## 安装

开始前，你需要安装必要的包：

<CodeGroup>
```bash pip
pip install toolbox-langchain
```

```bash uv
uv add toolbox-langchain
```
</CodeGroup>
