> [Hyperbrowser](https://hyperbrowser.ai) 是一个用于运行和扩展无头浏览器的平台。它让您可以大规模启动和管理浏览器会话，并为各种网页抓取需求提供易用方案，例如抓取单个页面或爬取整个站点。
>
> 主要特性：
>
> - 即时扩展性 - 数秒内启动数百个浏览器会话，无需处理基础设施难题
> - 简单集成 - 可与 Puppeteer、Playwright 等常用工具无缝协作
> - 强大 API - 提供易于使用的 API 来抓取/爬取任意站点，及更多能力
> - 绕过反机器人措施 - 内置 stealth mode、广告拦截、自动 CAPTCHA 求解和轮换代理

有关 Hyperbrowser 的更多信息，请访问 [Hyperbrowser website](https://hyperbrowser.ai)。如果您想查看文档，也可以访问 [Hyperbrowser docs](https://docs.hyperbrowser.ai)。

## 安装和设置

要开始使用 `langchain-hyperbrowser`，可以通过 pip 安装该包：

<CodeGroup>
```bash pip
pip install langchain-hyperbrowser
```

```bash uv
uv add langchain-hyperbrowser
```
</CodeGroup>

您还应通过设置以下环境变量来配置凭证：

`HYPERBROWSER_API_KEY=<your-api-key>`

请务必从 https://app.hyperbrowser.ai/ 获取您的 API Key。

## 可用工具

Hyperbrowser 提供两大类工具，特别适用于：
- 从复杂网站抓取网页和提取数据
- 自动化重复性的网页任务
- 与需要身份验证的 Web 应用交互
- 在多个网站之间开展研究
- 测试 Web 应用

### Browser Agent 工具

Hyperbrowser 提供多种 Browser Agents 工具。目前支持：
 - Claude Computer Use
 - OpenAI CUA
 - Browser Use

您可以在 [Hyperbrowser browser agent tools guide](/oss/integrations/tools/hyperbrowser_browser_agent_tools) 中查看更多细节。

#### Browser use 工具

一个通用的浏览器自动化工具，可通过自然语言指令处理各种网页任务。

```python
from langchain_hyperbrowser import HyperbrowserBrowserUseTool

tool = HyperbrowserBrowserUseTool()
result = tool.run({
    "task": "Go to npmjs.com, find the React package, and tell me when it was last updated"
})
print(result)
```

#### OpenAI CUA 工具

利用 OpenAI 的 Computer Use Agent 能力进行高级网页交互和信息收集。

```python
from langchain_hyperbrowser import HyperbrowserOpenAICUATool

tool = HyperbrowserOpenAICUATool()
result = tool.run({
    "task": "Go to Hacker News and summarize the top 5 posts right now"
})
print(result)
```

#### Claude computer use 工具

使用 Anthropic 的 Claude 执行更复杂的网页浏览和信息处理任务。

```python
from langchain_hyperbrowser import HyperbrowserClaudeComputerUseTool

tool = HyperbrowserClaudeComputerUseTool()
result = tool.run({
    "task": "Go to GitHub's trending repositories page, and list the top 3 posts there right now"
})
print(result)
```

### Web scraping 工具

下面简要介绍 Hyperbrowser 提供的 Web Scraping Tools。更多细节请参阅 [Hyperbrowser web scraping tools guide](/oss/integrations/tools/hyperbrowser_web_scraping_tools)。

#### Scrape 工具

Scrape Tool 允许您以 markdown、HTML 或 link 格式从单个网页提取内容。

```python
from langchain_hyperbrowser import HyperbrowserScrapeTool

tool = HyperbrowserScrapeTool()
result = tool.run({
    "url": "https://example.com",
    "scrape_options": {"formats": ["markdown"]}
})
print(result)
```

#### Crawl 工具

Crawl Tool 支持从给定 URL 开始遍历整个网站，并可配置页面数量上限。

```python
from langchain_hyperbrowser import HyperbrowserCrawlTool

tool = HyperbrowserCrawlTool()
result = tool.run({
    "url": "https://example.com",
    "max_pages": 2,
    "scrape_options": {"formats": ["markdown"]}
})
print(result)
```

#### Extract 工具

Extract Tool 使用 AI 根据预定义 schema 从网页中提取结构化数据，非常适合数据抽取任务。

```python
from langchain_hyperbrowser import HyperbrowserExtractTool
from pydantic import BaseModel

class SimpleExtractionModel(BaseModel):
    title: str

tool = HyperbrowserExtractTool()
result = tool.run({
    "url": "https://example.com",
    "schema": SimpleExtractionModel
})
print(result)
```

## Document loader

`langchain-hyperbrowser` 中的 `HyperbrowserLoader` 类可以方便地从任意单页或多页加载内容，也可以爬取整个站点。
内容可以加载为 markdown 或 html。

```python
from langchain_hyperbrowser import HyperbrowserLoader

loader = HyperbrowserLoader(urls="https://example.com")
docs = loader.load()

print(docs[0])
```

### 高级用法

您可以指定 loader 要执行的操作。默认操作是 `scrape`。对于 `scrape`，您可以提供单个 URL 或 URL 列表进行抓取。对于 `crawl`，您只能提供单个 URL。`crawl` 操作会爬取所提供页面及其子页面，并为每个页面返回一个文档。

```python
loader = HyperbrowserLoader(
  urls="https://hyperbrowser.ai", api_key="YOUR_API_KEY", operation="crawl"
)
```

还可以通过 `params` 参数为 loader 提供可选参数。有关支持参数的更多信息，请访问 https://docs.hyperbrowser.ai/reference/sdks/python/scrape#start-scrape-job-and-wait 或 https://docs.hyperbrowser.ai/reference/sdks/python/crawl#start-crawl-job-and-wait 。

```python
loader = HyperbrowserLoader(
  urls="https://example.com",
  api_key="YOUR_API_KEY",
  operation="scrape",
  params={"scrape_options": {"include_tags": ["h1", "h2", "p"]}}
)
```
