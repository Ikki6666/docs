>[Robocorp](https://robocorp.com/) 可帮助你构建和运行 Python workers，这些 workers 能够在任意位置、任意规模下无缝运行。


## 安装与设置

你需要安装 `langchain-robocorp` Python 包：

<CodeGroup>
```bash pip
pip install langchain-robocorp
```

```bash uv
uv add langchain-robocorp
```
</CodeGroup>

你需要有一个正在运行的 `Action Server` 实例，以便从你的 agent 应用与其通信。
参见 [Robocorp Quickstart](https://github.com/robocorp/robocorp#quickstart)，了解如何设置 Action Server 并创建你的 Actions。

你可以使用 Action Server 的 `new` 命令快速初始化一个新项目。

```bash
action-server new
cd ./your-project-name
action-server start
```
