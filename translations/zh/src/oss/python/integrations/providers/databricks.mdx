> [Databricks](https://www.databricks.com/) 提供一个数据与 AI 平台（通常称为 Databricks Lakehouse），用于分析、机器学习和生成式 AI 工作负载。

Databricks 通过多种方式拥抱 LangChain 生态系统：

1. 🚀 **Model Serving** - 通过高可用、低延迟的推理端点，在 [Databricks Model Serving](https://www.databricks.com/product/model-serving) 上访问最先进的 LLM，例如 DBRX、Llama3、Mixtral，或者您微调后的模型。LangChain 提供了 LLM（`Databricks`）、聊天模型（`ChatDatabricks`）和嵌入（`DatabricksEmbeddings`）实现，可简化将托管在 Databricks Model Serving 上的模型与 LangChain 应用集成的流程。
2. 📃 **Vector Search** - [Databricks Vector Search](https://www.databricks.com/product/machine-learning/vector-search) 是一个无服务器向量数据库，与 Databricks 平台无缝集成。使用 `DatabricksVectorSearch` 类，可将 LangChain 连接到您 Databricks 账户中的向量搜索索引。
3. 📊 **MLflow** - [MLflow](https://mlflow.org/) 是一个用于管理完整 ML 生命周期的开源平台，包括实验管理、评估、追踪、部署等。[MLflow 的 LangChain 集成](/oss/integrations/providers/mlflow_tracking) 简化了现代复合型 ML 系统的开发和运维流程。
4. 🌐 **SQL Database** - [Databricks SQL](https://www.databricks.com/product/databricks-sql) 已与 LangChain 中的 `SQLDatabase` 集成，让您能够访问具备自动优化和卓越性能的数据仓库。
5. 💡 **Open Models** - Databricks 开源了诸如 [DBRX](https://www.databricks.com/blog/introducing-dbrx-new-state-art-open-llm) 之类的模型，这些模型可通过 [Hugging Face Hub](https://huggingface.co/databricks/dbrx-instruct) 获取。这些模型可以借助 LangChain 对 `transformers` 库的集成直接使用。

Installation
------------

第一方 Databricks 集成现已通过 `databricks-langchain` partner package 提供。

<CodeGroup>
```bash pip
pip install databricks-langchain
```

```bash uv
uv add databricks-langchain
```
</CodeGroup>

旧版 `langchain-databricks` partner package 仍然可用，但很快会被弃用。

Chat Model
----------

`ChatDatabricks` 是一个聊天模型类，用于访问托管在 Databricks 上的聊天端点，包括 Llama3、Mixtral 和 DBRX 等先进模型，以及您自己微调后的模型。

```
from databricks_langchain import ChatDatabricks

chat_model = ChatDatabricks(endpoint="databricks-meta-llama-3-70b-instruct")
```

有关如何在 LangChain 应用中使用它的更多指导，请参阅[用法示例](/oss/integrations/chat/databricks)。

Embeddings
----------

`DatabricksEmbeddings` 是一个嵌入类，用于访问托管在 Databricks 上的文本嵌入端点，包括 BGE 等先进模型，以及您自己微调后的模型。

```
from databricks_langchain import DatabricksEmbeddings

embeddings = DatabricksEmbeddings(endpoint="databricks-bge-large-en")
```

有关如何在 LangChain 应用中使用它的更多指导，请参阅[用法示例](/oss/integrations/embeddings/databricks)。

Vector Search
-------------

Databricks Vector Search 是一个无服务器相似度搜索引擎，允许您将数据的向量表示（包括元数据）存储在向量数据库中。借助 Vector Search，您可以从由 [Unity Catalog](https://www.databricks.com/product/unity-catalog) 管理的 [Delta](https://docs.databricks.com/en/introduction/delta-comparison.html) 表中创建自动更新的向量搜索索引，并通过简单的 API 查询返回最相似的向量。

```
from databricks_langchain import DatabricksVectorSearch

dvs = DatabricksVectorSearch(
    endpoint="<YOUT_ENDPOINT_NAME>",
    index_name="<YOUR_INDEX_NAME>",
    index,
    text_column="text",
    embedding=embeddings,
    columns=["source"]
)
docs = dvs.similarity_search("What is vector search?)
```

有关如何设置向量索引并将其与 LangChain 集成，请参阅[用法示例](/oss/integrations/vectorstores/databricks_vector_search)。

MLflow Integration
------------------

在 LangChain 集成场景下，MLflow 提供以下能力：

- **Experiment Tracking**：跟踪并存储您的 LangChain 实验中的模型、工件和追踪。
- **Dependency Management**：自动记录依赖库，确保开发、预发布和生产环境之间的一致性。
- **Model Evaluation**：提供原生能力来评估 LangChain 应用。
- **Tracing**：以可视化方式追踪 LangChain 应用中的数据流。

请参阅 [MLflow LangChain Integration](/oss/integrations/providers/mlflow_tracking)，了解通过丰富代码示例和指南将 MLflow 与 LangChain 结合使用的完整能力。

SQLDatabase
-----------

要连接 Databricks SQL 或查询结构化数据，请参阅 [Databricks structured retriever tool documentation](https://docs.databricks.com/en/generative-ai/agent-framework/structured-retrieval-tools.html#table-query-tool)。若要使用上面创建的 SQL UDF 创建智能体，请参阅 [Databricks UC Integration](https://docs.unitycatalog.io/ai/integrations/langchain/)。

Open Models
-----------

如果要直接集成托管在 HuggingFace 上的 Databricks 开源模型，可以使用 LangChain 的 [HuggingFace Integration](/oss/integrations/providers/huggingface)。

```
from langchain_huggingface import HuggingFaceEndpoint

llm = HuggingFaceEndpoint(
    repo_id="databricks/dbrx-instruct",
    task="text-generation",
    max_new_tokens=512,
    do_sample=False,
    repetition_penalty=1.03,
)
llm.invoke("What is DBRX model?")
```
