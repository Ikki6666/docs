[RunPod](https://www.runpod.io/) 提供 GPU 云基础设施，其中包括适合部署和扩展 AI 模型的 Serverless endpoints。

本指南介绍如何使用 `langchain-runpod` 集成包，将 LangChain 应用连接到托管在 [RunPod Serverless](https://www.runpod.io/serverless-gpu) 上的模型。

该集成为标准语言模型（LLMs）和 Chat Models 都提供了接口。

## 安装

安装专用 partner 包：

```python
pip install -qU langchain-runpod
```

## 设置

### 1. 在 RunPod 上部署 endpoint

- 打开你的 [RunPod Serverless Console](https://www.runpod.io/console/serverless/user/endpoints)。
- 创建一个 `"New Endpoint"`，选择合适的 GPU 和模板，例如 vLLM、TGI、text-generation-webui，并确保其与你的模型及预期输入输出格式兼容，参见组件指南或该包的 [README](https://github.com/runpod/langchain-runpod)。
- 配置设置并完成部署。
- **务必在部署后复制 Endpoint ID**。

### 2. 设置 API 凭据

该集成需要你的 RunPod API Key 和 Endpoint ID。将它们设置为环境变量，以便安全访问：

```python
import getpass
import os

os.environ["RUNPOD_API_KEY"] = getpass.getpass("Enter your RunPod API Key: ")
os.environ["RUNPOD_ENDPOINT_ID"] = input("Enter your RunPod Endpoint ID: ")
```

*（可选）* 如果 LLM 和 Chat models 使用不同的 endpoints，你可能还需要设置 `RUNPOD_CHAT_ENDPOINT_ID`，或者在初始化时直接传入该 ID。

## Components

该包提供两个主要组件：

### 1. LLM

用于与标准文本补全模型交互。

详细用法参见 [RunPod LLM Integration Guide](/oss/integrations/llms/runpod)

```python
from langchain_runpod import RunPod

# Example initialization (uses environment variables)
llm = RunPod(model_kwargs={"max_new_tokens": 100})  # Add generation params here

# Example Invocation
try:
    response = llm.invoke("Write a short poem about the cloud.")
    print(response)
except Exception as e:
    print(
        f"Error invoking LLM: {e}. Ensure endpoint ID and API key are correct and endpoint is active."
    )
```

### 2. Chat model

用于与对话模型交互。

详细用法和特性支持参见 [RunPod Chat Model Integration Guide](/oss/integrations/chat/runpod)。

```python
from langchain.messages import HumanMessage
from langchain_runpod import ChatRunPod

# Example initialization (uses environment variables)
chat = ChatRunPod(model_kwargs={"temperature": 0.8})  # Add generation params here

# Example Invocation
try:
    response = chat.invoke(
        [HumanMessage(content="Explain RunPod Serverless in one sentence.")]
    )
    print(response.content)
except Exception as e:
    print(
        f"Error invoking Chat Model: {e}. Ensure endpoint ID and API key are correct and endpoint is active."
    )
```
