## Authentication

<Note>
    初始化 [ChatOCIGenAI](#chatocigenai) 的成本较高。为了获得最佳性能，建议将此 client 视为单例，并在整个应用中复用同一个实例。
</Note>

OCI 服务支持四种认证方式。所有方式都遵循[标准 OCI SDK 认证](https://docs.oracle.com/en-us/iaas/Content/API/Concepts/sdk_authentication_methods.htm)。

### API Key（默认）

使用 `~/.oci/config` 中的凭据：

```python
from langchain_oci import ChatOCIGenAI

llm = ChatOCIGenAI(
    model_id="meta.llama-3.3-70b-instruct",
    service_endpoint="https://inference.generativeai.us-chicago-1.oci.oraclecloud.com",
    compartment_id="ocid1.compartment.oc1..xxx",
    auth_type="API_KEY",        # Default
    auth_profile="DEFAULT",      # Profile name in ~/.oci/config
)
```

### Security Token

适用于基于会话的认证：

```bash
oci session authenticate --profile-name MY_PROFILE
```

```python
llm = ChatOCIGenAI(
    model_id="meta.llama-3.3-70b-instruct",
    service_endpoint="https://inference.generativeai.us-chicago-1.oci.oraclecloud.com",
    compartment_id="ocid1.compartment.oc1..your-compartment-id",
    auth_type="SECURITY_TOKEN",
    auth_profile="MY_PROFILE",
)
```

### Instance Principal

适用于运行在 OCI 计算实例上的应用：

```python
llm = ChatOCIGenAI(
    model_id="meta.llama-3.3-70b-instruct",
    service_endpoint="https://inference.generativeai.us-chicago-1.oci.oraclecloud.com",
    compartment_id="ocid1.compartment.oc1..your-compartment-id",
    auth_type="INSTANCE_PRINCIPAL",
)
```

### Resource Principal

适用于 OCI Functions 和其他资源：

```python
llm = ChatOCIGenAI(
    model_id="meta.llama-3.3-70b-instruct",
    service_endpoint="https://inference.generativeai.us-chicago-1.oci.oraclecloud.com",
    compartment_id="ocid1.compartment.oc1..your-compartment-id",
    auth_type="RESOURCE_PRINCIPAL",
)
```

## OCI Generative AI

> Oracle Cloud Infrastructure (OCI) [Generative AI](https://docs.oracle.com/en-us/iaas/Content/generative-ai/home.htm) 是一项全托管服务，通过单一 API 提供一组最先进、可定制的大语言模型（LLMs），覆盖广泛的使用场景。
> 使用 OCI Generative AI 服务，你可以访问可直接使用的预训练模型，或者基于自己的数据，在专用 AI 集群上创建并托管自定义微调模型。

### Chat Models

#### ChatOCIGenAI

面向 OCI Generative AI 服务的主聊天模型，完整支持 LangChain 特性。

参见[使用示例](/oss/integrations/chat/oci_generative_ai)。

```python
from langchain_oci import ChatOCIGenAI

llm = ChatOCIGenAI(
    model_id="meta.llama-3.3-70b-instruct",
    service_endpoint="https://inference.generativeai.us-chicago-1.oci.oraclecloud.com",
    compartment_id="ocid1.compartment.oc1..xxx",
)
```

**支持特性：**
- ✅ Tool calling，包括 Llama 4+ 的并行工具调用
- ✅ Structured output，支持 Pydantic、JSON mode
- ✅ Vision 和 multimodal，13+ 模型支持图像输入
- ✅ Streaming，同步和异步都支持
- ✅ Async operations，例如 `ainvoke`、`astream`、`abatch`
- ✅ PDF、视频、音频处理，适用于 Gemini 模型

#### ChatOCIOpenAI

为 OCI 商业 OpenAI 模型提供 OpenAI Responses API 兼容接口。

```python
from langchain_oci import ChatOCIOpenAI

llm = ChatOCIOpenAI(
    model="openai.gpt-5.5",
    service_endpoint="https://inference.generativeai.us-chicago-1.oci.oraclecloud.com",
    compartment_id="ocid1.compartment.oc1..your-compartment-id",
)
```

**特性：**
- OpenAI 兼容接口
- 支持 conversation store，用于持久化 memory
- 可访问 GPT-4、GPT-5、o1、o3 模型，具体取决于可用性

### Embedding Models

#### OCIGenAIEmbeddings

文本和图像 embedding 模型。

参见[使用示例](/oss/integrations/embeddings/oci_generative_ai)。

```python
from langchain_oci import OCIGenAIEmbeddings

# Text embeddings
embeddings = OCIGenAIEmbeddings(
    model_id="cohere.embed-english-v3.0",
    service_endpoint="https://inference.generativeai.us-chicago-1.oci.oraclecloud.com",
    compartment_id="ocid1.compartment.oc1..xxx",
)

# Image embeddings (with multimodal models)
vector = embeddings.embed_image("./architecture_diagram.png")
```

**可用模型：**
- `cohere.embed-english-v3.0`，1024 维
- `cohere.embed-multilingual-v3.0`，1024 维
- `cohere.embed-v4.0`，文本和图像双模态，支持 256 到 1536 维

### Vision 与 Multimodal

支持 13+ 个具备视觉能力的模型，涵盖 Meta Llama、Google Gemini、xAI Grok 和 Cohere：

```python
from langchain.messages import HumanMessage
from langchain_oci import ChatOCIGenAI, load_image

llm = ChatOCIGenAI(
    model_id="meta.llama-3.2-90b-vision-instruct",
    service_endpoint="https://inference.generativeai.us-chicago-1.oci.oraclecloud.com",
    compartment_id="ocid1.compartment.oc1..xxx",
)

message = HumanMessage(content=[
    {"type": "text", "text": "Identify all microservices, data flows, and external dependencies."},
    load_image("./architecture_diagram.png"),
])
response = llm.invoke([message])
```

**Gemini Multimodal**，支持 PDF、视频、音频：

```python
import base64
from langchain.messages import HumanMessage
from langchain_oci import ChatOCIGenAI

llm = ChatOCIGenAI(
    model_id="google.gemini-2.5-flash",
    service_endpoint="https://inference.generativeai.us-chicago-1.oci.oraclecloud.com",
    compartment_id="ocid1.compartment.oc1..your-compartment-id",
)

# PDF processing - Extract structured data from contracts
with open("vendor_contract.pdf", "rb") as f:
    pdf_data = base64.b64encode(f.read()).decode()

message = HumanMessage(content=[
    {"type": "text", "text": "Extract: parties, effective date, payment terms. Return as JSON."},
    {"type": "document_url", "document_url": {"url": f"data:application/pdf;base64,{pdf_data}"}}
])
response = llm.invoke([message])
```

### AI Agents

使用 OCI 模型创建基于 LangGraph 的 ReAct agents：

```python
from langchain.tools import tool
from langchain_oci import create_oci_agent

@tool
def query_infrastructure(resource_type: str, region: str) -> dict:
    """Query OCI infrastructure status and health metrics.

    Args:
        resource_type: Type of resource (compute, database, network)
        region: OCI region to query
    """
    # Example: Call OCI monitoring API
    return {
        "status": "healthy",
        "active_instances": 12,
        "cpu_utilization": "45%",
        "alerts": []
    }

agent = create_oci_agent(
    model_id="meta.llama-4-scout-17b-16e-instruct",
    tools=[query_infrastructure],
    compartment_id="ocid1.compartment.oc1..xxx",
    service_endpoint="https://inference.generativeai.us-chicago-1.oci.oraclecloud.com",
    system_prompt="You are an infrastructure monitoring assistant.",
)

from langchain.messages import HumanMessage
result = agent.invoke({
    "messages": [HumanMessage(content="Check compute resource health in us-ashburn-1")]
})
```

### Provider Coverage

| Provider | Example Models | Key Features |
|----------|----------------|--------------|
| **Meta** | Llama 3.2、3.3、4（Scout、Maverick） | Vision、并行工具调用 |
| **Google** | Gemini 2.0/2.5 Flash、Flash Lite、Pro | PDF、视频、音频处理 |
| **xAI** | Grok 3、4（Fast、Mini） | Vision、推理模式 |
| **Cohere** | Command R+、Command A | 面向 RAG 的优化、V2 vision |
| **OpenAI** | GPT-5.5、GPT-5、o1、o3 | 推理能力，通过 ChatOCIOpenAI 使用 |

> **Note:** 模型可用性会因区域而异。当前模型目录请参见 [OCI Generative AI documentation](https://docs.oracle.com/en-us/iaas/Content/generative-ai/pretrained-models.htm)。

## OCI Data Science Model Deployments

> [OCI Data Science](https://docs.oracle.com/en-us/iaas/data-science/using/home.htm) 是一个全托管、无服务器的平台，面向数据科学团队。你可以使用 [OCI Data Science Model Deployment Service](https://docs.oracle.com/en-us/iaas/data-science/using/model-dep-about.htm) 将自定义模型部署为 endpoints。

### ChatOCIModelDeployment

面向 OCI Data Science Model Deployments 的聊天模型。

参见 [ChatOCIModelDeployment integration guide](/oss/integrations/chat/oci_data_science)。

```python
from langchain_oci import ChatOCIModelDeployment

llm = ChatOCIModelDeployment(
    endpoint="https://modeldeployment.us-ashburn-1.oci.customer-oci.com/ocid1.datasciencemodeldeployment.oc1.iad.xxx/predict",
    model="odsc-llm",
)
```

### ChatOCIModelDeploymentVLLM

面向基于 vLLM 的部署做了优化，并支持 streaming：

```python
from langchain_oci import ChatOCIModelDeploymentVLLM

llm = ChatOCIModelDeploymentVLLM(
    endpoint="https://modeldeployment.us-ashburn-1.oci.customer-oci.com/ocid1.datasciencemodeldeployment.oc1.iad.xxx/predict",
    model="meta-llama/Llama-2-7b-chat-hf",
    streaming=True,
)
```

### ChatOCIModelDeploymentTGI

适用于 Text Generation Inference (TGI) 部署：

```python
from langchain_oci import ChatOCIModelDeploymentTGI

llm = ChatOCIModelDeploymentTGI(
    endpoint="https://modeldeployment.us-ashburn-1.oci.customer-oci.com/ocid1.datasciencemodeldeployment.oc1.iad.xxx/predict",
)
```
