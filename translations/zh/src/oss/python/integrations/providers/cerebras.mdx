在 Cerebras，我们打造了全球最大、最快的 AI 处理器 Wafer-Scale Engine-3（WSE-3）。由 WSE-3 驱动的 Cerebras CS-3 系统代表了一类全新的 AI 超级计算机，以无与伦比的性能和可扩展性为生成式 AI 训练和推理树立了标准。

使用 Cerebras 作为推理提供方时，你可以：
- 为 AI 推理工作负载获得前所未有的速度
- 以高吞吐进行商业化构建
- 借助我们无缝的集群技术，轻松扩展 AI 工作负载

我们的 CS-3 系统可以快速、轻松地组建成集群，构建全球规模最大的 AI 超级计算机，从而让部署和运行最大模型变得简单。领先企业、研究机构和政府已经在使用 Cerebras 解决方案来开发专有模型，并训练流行的开源模型。

想体验 Cerebras 的强大能力？欢迎访问我们的[官网](https://cerebras.ai)获取更多资源，并了解如何通过 Cerebras Cloud 或本地部署方式访问我们的技术。

如需了解 Cerebras Cloud 的更多信息，请访问 [cloud.cerebras.ai](https://cloud.cerebras.ai/)。API reference 位于 [inference-docs.cerebras.ai](https://inference-docs.cerebras.ai/)。

## 安装与设置
安装集成包：

<CodeGroup>
```bash pip
pip install langchain-cerebras
```

```bash uv
uv add langchain-cerebras
```
</CodeGroup>

## API Key
从 [cloud.cerebras.ai](https://cloud.cerebras.ai/) 获取 API Key，并将其添加到环境变量中：
```
export CEREBRAS_API_KEY="your-api-key-here"
```
