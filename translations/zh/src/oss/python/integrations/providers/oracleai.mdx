Oracle AI Database 专为 AI 工作负载而构建，在这里您是按**语义**而不仅仅是关键词来查询数据。它将**对非结构化内容的语义搜索**与**对业务数据的关系过滤**结合到一个系统中，因此您可以在不引入额外向量数据库、也不将数据分散到多个平台的前提下，构建 AI 检索工作流（例如 RAG）。

### 重要意义

- **一个系统同时处理 AI 与业务数据：** 向量与业务数据共存。
- **更少碎片化：** 相比独立的向量存储，所需组件更少。
- **数据库级保障：** 可将安全性、事务、扩展性和可用性应用到同一套 AI 工作负载中。

## 前置条件

安装 `langchain-oracledb`。`python-oracledb` 驱动会作为依赖自动安装。

<CodeGroup>
```bash pip
pip install -qU langchain-oracledb
```
```bash uv
uv add langchain-oracledb
```
</CodeGroup>
