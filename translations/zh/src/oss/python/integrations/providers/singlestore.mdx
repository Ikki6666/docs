[SingleStore](https://singlestore.com/) 是一个高性能分布式 SQL 数据库，专为在[云端](https://www.singlestore.com/cloud/)和本地环境中都表现出色而设计。它提供丰富的功能、无缝的部署选项以及卓越的性能。

这个集成提供了以下组件，用于发挥 SingleStore 的能力：

- **`SingleStoreLoader`**：直接从 SingleStore 数据库表中加载文档。
- **`SingleStoreSemanticCache`**：把 SingleStore 用作语义缓存，以高效存储和检索 embedding。
- **`SingleStoreChatMessageHistory`**：在 SingleStore 中存储和检索聊天消息历史。
- **`SingleStoreVectorStore`**：存储文档 embedding，并执行快速的向量搜索和全文搜索。

这些组件支持高效的文档存储、embedding 管理和高级搜索能力，把全文搜索与向量搜索结合起来，以实现快速且准确的查询。

```python
from langchain_singlestore import (
    SingleStoreChatMessageHistory,
    SingleStoreLoader,
    SingleStoreSemanticCache,
    SingleStoreVectorStore,
)
```
