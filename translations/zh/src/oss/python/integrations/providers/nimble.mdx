[Nimble](https://www.nimbleway.com/) 通过一个搜索 API 提供实时网页数据访问，该 API 会直接浏览实时网页，而不是依赖预构建索引。不同于传统搜索 API，Nimble 使用无头浏览器实时导航网站，能够处理 JavaScript 渲染、动态内容、分页以及复杂的多步骤导航流程。

**关键技术能力：**

- **实时网页浏览**：访问当前网页内容，而不是缓存索引
- **JavaScript 渲染**：处理现代 SPA、懒加载和客户端渲染
- **灵活模式**：快速模式适合 SERP 数据，深度模式适合完整内容提取
- **AI 摘要**：在原始搜索结果之外，可选提供由 LLM 生成的答案
- **生产就绪**：支持异步、具备完善错误处理，并为大规模使用而设计

更多信息请访问 [nimbleway.com](https://www.nimbleway.com/)，或查看[官方 Nimble 文档](https://docs.nimbleway.com/)。

## 安装和设置

Nimble 集成位于它自己的 partner package 中。您可以使用以下命令安装：

<CodeGroup>
```bash pip
pip install -U langchain-nimble
```
```bash uv
uv add langchain-nimble
```
</CodeGroup>

要使用该包，您需要将 `NIMBLE_API_KEY` 环境变量设置为自己的 Nimble API key。您可以通过在 [Nimble](https://www.nimbleway.com/) 注册获取 API key。
