[Browserbase](https://www.browserbase.com) 为 agent 运行云端浏览器，并提供[会话录制](https://docs.browserbase.com/platform/browser/observability/observability)和用于调试的[实时视图](https://docs.browserbase.com/platform/browser/observability/session-live-view)。同一个 API key 可用于 [Search](https://docs.browserbase.com/platform/search/overview) 和 [Fetch](https://docs.browserbase.com/platform/fetch/overview)，它们无需启动浏览器会话即可查找和读取页面。

本页介绍如何在 [Deep Agents](/oss/deepagents/overview) 中使用 Browserbase：由 Stagehand 驱动的云端浏览器，以及作为 agent 工具的 Search 和 Fetch。

## 安装与设置

从 [Browserbase](https://www.browserbase.com) 获取 API key，并将其设置为环境变量：

```bash
export BROWSERBASE_API_KEY="your-browserbase-api-key"
```

安装 [Browserbase Python SDK](https://github.com/browserbase/sdk-python)：

<CodeGroup>
```bash pip
pip install "browserbase>=1.21.0"
```

```bash uv
uv add "browserbase>=1.21.0"
```
</CodeGroup>

## Deep Agents

[Deep agent](/oss/deepagents/overview)可以通过两种方式使用 Browserbase：通过 Stagehand 工具驱动的云端浏览器，以及用于无需浏览器的页面的 Search 和 Fetch 工具。有关何时应为 agent 提供浏览器，请参阅[浏览器使用](/oss/deepagents/browser-use)。

### 使用 Stagehand 的浏览器工具

[Stagehand 集成](/oss/integrations/tools/stagehand)通过原生 Python middleware 添加 `run`、`snapshot` 和 `screenshot`。将配置好的 Stagehand 客户端传给 `StagehandMiddleware`，然后将其加入 agent 的 `middleware` 列表。无需 MCP server 或自定义浏览器系统提示词。

你的应用拥有该浏览器，可以在多次运行之间保持其打开，以复用标签页和登录状态。有关安装、完整 agent 和清理，请参阅[与 deep agent 一起使用](/oss/integrations/tools/stagehand#use-with-a-deep-agent)。有关会话隔离，请参阅[选择浏览器作用域](/oss/deepagents/browser-use#choose-a-browser-scope)。

### 搜索和抓取工具

将 Search 和 Fetch 暴露为 agent 工具。这些 API 无需启动浏览器会话即可查找和读取页面。Fetch 不执行 JavaScript。

在运行此示例前，安装 agent 软件包并设置模型提供商的凭据：

<CodeGroup>
```bash pip
pip install "browserbase>=1.21.0" deepagents langchain-openai
```

```bash uv
uv add "browserbase>=1.21.0" deepagents langchain-openai
```
</CodeGroup>

```bash
export OPENAI_API_KEY="your-openai-api-key"
```

该示例使用 OpenAI 的 [GPT-5.5 快照](https://developers.openai.com/api/docs/models/gpt-5.5)。省略 `search.web` 上的 `provider`，以使用项目的默认搜索提供商：

```python
import os

from browserbase import Browserbase
from deepagents import create_deep_agent
from langchain.tools import tool

bb = Browserbase(api_key=os.environ["BROWSERBASE_API_KEY"])


@tool
def web_search(query: str) -> str:
    """Search the web and return result titles and URLs."""
    response = bb.search.web(query=query, num_results=5)
    return "\n".join(f"{result.title}: {result.url}" for result in response.results)


@tool
def fetch_page(url: str) -> str:
    """Fetch a page as markdown without opening a browser."""
    return bb.fetch_api.create(url=url, format="markdown").content


agent = create_deep_agent(
    model="openai:gpt-5.5-2026-04-23",
    tools=[web_search, fetch_page],
    system_prompt="Search to find pages, then fetch the pages you need to read.",
)
```

有关结合 Search、Fetch 和 Stagehand 的完整示例，请参阅 Browserbase 的 [Deep Agents 指南](https://docs.browserbase.com/integrations/langchain/deepagents)。
