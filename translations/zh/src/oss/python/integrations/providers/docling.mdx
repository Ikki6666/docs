> [Docling](https://github.com/DS4SD/docling) 可将 PDF、DOCX、PPTX、HTML 及其他格式解析为丰富且统一的表示形式，包括文档布局、表格等，使其能够直接用于 RAG 等生成式 AI 工作流。
>
> 此集成通过 `DoclingLoader` document loader 提供 Docling 的能力。

## 安装和设置

只需从您的包管理器安装 `langchain-docling`，例如使用 pip：

<CodeGroup>
```bash pip
pip install langchain-docling
```

```bash uv
uv add langchain-docling
```
</CodeGroup>

## Document loader

`langchain-docling` 中的 `DoclingLoader` 类可将 Docling 无缝集成到 LangChain 中，使您能够：
- 轻松且高效地在 LLM 应用中使用多种文档类型，并且
- 利用 Docling 丰富的表示形式实现更高级、以文档为原生对象的 grounding。

基本用法如下：

```python
from langchain_docling import DoclingLoader

FILE_PATH = ["https://arxiv.org/pdf/2408.09869"]  # Docling Technical Report

loader = DoclingLoader(file_path=FILE_PATH)

docs = loader.load()
```

完整端到端用法请参阅[此示例](/oss/integrations/document_loaders/docling)。
