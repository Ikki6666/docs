>[Airbyte](https://github.com/airbytehq/airbyte) 是一个面向 ELT 流水线的数据集成平台，可将来自 API、数据库和文件的数据接入仓库与湖仓。它拥有最大的 ELT connector 目录之一，覆盖数据仓库和数据库。

## 安装与设置

<CodeGroup>
```bash pip
pip install -U langchain-airbyte
```

```bash uv
uv add langchain-airbyte
```
</CodeGroup>

<Note>
**当前 `langchain-airbyte` 库不支持 Pydantic v2。**

请降级到 Pydantic v1 才能使用该包。

这个包当前还要求 Python 3.10+。

</Note>

这个集成包不要求设置任何全局环境变量，但某些具体集成（例如 `source-github`）可能需要传入凭证。
