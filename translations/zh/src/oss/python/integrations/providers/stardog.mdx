[Stardog](https://www.stardog.com) 是一个企业级知识图谱平台，帮助组织统一、查询和分析数据。

为 agent 提供以下工具能力：

- 用自然语言提问，并从企业知识图谱数据库中获得无幻觉的答案
- 从自然语言生成 SPARQL 查询
- 使用语义推理来查询和分析结构化数据
- 通过对话式界面访问企业数据

### 工作原理
Stardog 提供知识图谱基础设施，把数据集成与自然语言处理结合起来：

1. 让你的 agent 访问企业知识图谱
2. 通过 Voicebox 使用自然语言查询数据
3. 获得由你的数据支撑的准确、可溯源答案
