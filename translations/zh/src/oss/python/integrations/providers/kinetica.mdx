[Kinetica](https://www.kinetica.com/) 是一个专为在时序和空间数据上实现分析与生成式 AI 而构建的实时数据库。

## 聊天模型

Kinetica 的 LLM wrapper 使用 [Kinetica SqlAssist
LLM](https://docs.kinetica.com/7.2/sql-gpt/concepts/) 将自然语言转换为 SQL，从而简化数据检索过程。

用法请参阅 [Kinetica Language To SQL Chat Model](/oss/integrations/chat/kinetica)。

```python
from langchain_kinetica import ChatKinetica
```

## 向量存储

Kinetca 的 vectorstore wrapper 利用 Kinetica 对[向量相似性搜索](https://docs.kinetica.com/7.2/vector_search/)的原生支持。

用法请参阅 [Kinetica Vectorstore API](/oss/integrations/vectorstores/kinetica)。

```python
from langchain_kinetica import KineticaVectorstore
```

## Document loader

Kinetica Document loader 可用于从 [Kinetica](https://www.kinetica.com/) 数据库中加载 LangChain [Documents](https://reference.langchain.com/python/langchain-core/documents/base/Document)。

用法请参阅 [Kinetica Document Loader](/oss/integrations/document_loaders/kinetica)。

```python
from langchain_kinetica import KineticaLoader
```

## 检索器

Kinetica Retriever 可以根据非结构化查询返回文档。

用法请参阅 [Kinetica VectorStore based Retriever](/oss/integrations/retrievers/kinetica)。
