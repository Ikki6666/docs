[Ampersend](https://ampersend.ai) 让 LangChain agent 能够为远程 AI agent 服务付款并使用这些服务。

为 agent 提供以下工具能力：

- 自动为远程 agent 服务付款
- 与远程 A2A agent 交互

### 工作原理

Ampersend 通过 x402 协议提供透明的支付处理：

1. 将你的 agent 连接到带有支出控制的钱包
2. 通过 A2A 协议调用远程 agent
3. 在需要时自动处理付款
