> [Flyte](https://github.com/flyteorg/flyte) 是一个开源编排器，可帮助构建生产级的数据与机器学习流水线。
> 它以 Kubernetes 作为底层平台，专为可扩展性和可复现性而设计。

本 notebook 的目的是展示如何将 `FlyteCallback` 集成到您的 Flyte task 中，以便高效监控和跟踪 LangChain 实验。

## 安装和设置

- 运行命令 `pip install flytekit` 安装 Flytekit 库。
- 运行命令 `pip install flytekitplugins-envd` 安装 Flytekit-Envd 插件。
- 运行命令 `pip install langchain` 安装 LangChain。
- 在您的系统上安装 [Docker](https://docs.docker.com/engine/install/)。

## Flyte tasks

Flyte 的一个 [task](https://docs.flyte.org/en/latest/user_guide/basics/tasks.html) 是 Flyte 的基础构建块。
要执行 LangChain 实验，您需要编写 Flyte tasks 来定义其中涉及的具体步骤和操作。

注意：[getting started guide](https://docs.flyte.org/projects/cookbook/en/latest/index.html) 提供了关于如何在本地安装 Flyte 并运行初始 Flyte pipeline 的详细分步说明。

首先，导入支持 LangChain 实验所需的依赖项。

```python
import os

from flytekit import ImageSpec, task
from langchain.agents import create_agent, load_tools
from langchain.callbacks import FlyteCallbackHandler
from langchain_classic.chains import LLMChain
from langchain_openai import ChatOpenAI
from langchain_core.prompts import PromptTemplate
from langchain.messages import HumanMessage
```

设置使用 OpenAI API 和 Serp API 所需的环境变量：

```python
# Set OpenAI API key
os.environ["OPENAI_API_KEY"] = "<your_openai_api_key>"

# Set Serp API key
os.environ["SERPAPI_API_KEY"] = "<your_serp_api_key>"
```

将 `<your_openai_api_key>` 和 `<your_serp_api_key>` 替换为您分别从 OpenAI 和 Serp API 获取的 API 密钥。

为了保证流水线的可复现性，Flyte tasks 会被容器化。
每个 Flyte task 都必须关联一个镜像，该镜像既可以在整个 Flyte [workflow](https://docs.flyte.org/en/latest/user_guide/basics/workflows.html) 中共享，也可以为每个 task 单独提供。

为了简化为每个 Flyte task 提供所需依赖项的过程，您可以初始化一个 [`ImageSpec`](https://docs.flyte.org/en/latest/user_guide/customizing_dependencies/imagespec.html) 对象。
这种方式会自动触发 Docker 构建，免去了用户手动创建 Docker 镜像的需求。

```python
custom_image = ImageSpec(
    name="langchain-flyte",
    packages=[
        "langchain",
        "openai",
        "spacy",
        "https://github.com/explosion/spacy-models/releases/download/en_core_web_sm-3.5.0/en_core_web_sm-3.5.0.tar.gz",
        "textstat",
        "google-search-results",
    ],
    registry="<your-registry>",
)
```

您可以灵活地将 Docker 镜像推送到任意选择的 registry。
[Docker Hub](https://hub.docker.com/) 或 [GitHub Container Registry (GHCR)](https://docs.github.com/en/packages/working-with-a-github-packages-registry/working-with-the-container-registry) 是一个方便的起点。

选定 registry 后，您就可以继续创建将 LangChain 指标记录到 Flyte Deck 的 Flyte tasks。

以下示例展示了与 OpenAI LLM、chains 和带工具的 agent 相关的 tasks：

### LLM

```python
@task(disable_deck=False, container_image=custom_image)
def langchain_llm() -> str:
    llm = ChatOpenAI(
        model_name="gpt-3.5-turbo",
        temperature=0.2,
        callbacks=[FlyteCallbackHandler()],
    )
    return llm.invoke([HumanMessage(content="Tell me a joke")]).content
```

### Chain

```python
@task(disable_deck=False, container_image=custom_image)
def langchain_chain() -> list[dict[str, str]]:
    template = """You are a playwright. Given the title of play, it is your job to write a synopsis for that title.
Title: {title}
Playwright: This is a synopsis for the above play:"""
    llm = ChatOpenAI(
        model_name="gpt-3.5-turbo",
        temperature=0,
        callbacks=[FlyteCallbackHandler()],
    )
    prompt_template = PromptTemplate(input_variables=["title"], template=template)
    synopsis_chain = LLMChain(
        llm=llm, prompt=prompt_template, callbacks=[FlyteCallbackHandler()]
    )
    test_prompts = [
        {
            "title": "documentary about good video games that push the boundary of game design"
        },
    ]
    return synopsis_chain.apply(test_prompts)
```

### Agent

```python
@task(disable_deck=False, container_image=custom_image)
def langchain_agent() -> str:
    llm = ChatOpenAI(
        model_name="gpt-3.5-turbo",
        temperature=0,
        callbacks=[FlyteCallbackHandler()],
    )

    tools = load_tools(
        ["serpapi", "llm-math"],
        llm=llm,
        callbacks=[FlyteCallbackHandler()],
    )

    agent = create_agent(
        model=llm,
        tools=tools,
        callbacks=[FlyteCallbackHandler()],
        verbose=True,
    )

    return agent.invoke(
        "Who is Leonardo DiCaprio's girlfriend? Could you calculate her current age and raise it to the power of 0.43?"
    )
```

这些 tasks 可作为在 Flyte 中运行 LangChain 实验的起点。

## 在 Kubernetes 上执行 flyte tasks

要在已配置的 Flyte 后端上执行 Flyte tasks，请使用以下命令：

```bash
pyflyte run --image <your-image> langchain_flyte.py langchain_llm
```

此命令会在 Flyte 后端上启动 `langchain_llm` task 的执行。您也可以用类似方式触发其余两个 task。
