> [LiteLLM](https://github.com/BerriAI/litellm) 是一个库，它通过单一统一接口简化了对 Anthropic、Azure、Huggingface、Replicate 以及许多其他 LLM 提供方的调用。

## 安装和设置

<CodeGroup>
```bash pip
pip install langchain-litellm
```

```bash uv
uv add langchain-litellm
```
</CodeGroup>

## 聊天模型

```python
from langchain_litellm import ChatLiteLLM
```
```python
from langchain_litellm import ChatLiteLLMRouter
```

完整用法请参阅 [LiteLLM chat guide](/oss/integrations/chat/litellm)，其中包括流式输出、tool calling、structured output 和 Vertex AI Grounding。

## Embeddings

```python
from langchain_litellm import LiteLLMEmbeddings
```

```python
from langchain_litellm import LiteLLMEmbeddingsRouter
```

`LiteLLMEmbeddings` 通过单一一致的接口支持 100 多个 provider 的文本嵌入。所有配置都显式传入，不需要环境变量。

```python
from langchain_litellm import LiteLLMEmbeddings

embeddings = LiteLLMEmbeddings(
    model="openai/text-embedding-3-small",
    api_key="sk-...",
)

vectors = embeddings.embed_documents(["hello", "world"])
query_vector = embeddings.embed_query("hello")
```

通过修改 `model` 即可切换 provider，接口保持不变：

```python
# Cohere
embeddings = LiteLLMEmbeddings(
    model="cohere/embed-english-v3.0",
    api_key="...",
    document_input_type="search_document",
    query_input_type="search_query",
)

# Azure OpenAI
embeddings = LiteLLMEmbeddings(
    model="azure/my-embedding-deployment",
    api_key="...",
    api_base="https://my-resource.openai.azure.com",
    api_version="2024-02-01",
)

# Bedrock
embeddings = LiteLLMEmbeddings(
    model="bedrock/amazon.titan-embed-text-v1",
)
```

如果要在同一模型的多个部署之间进行负载均衡，请使用 `LiteLLMEmbeddingsRouter`：

```python
from litellm import Router
from langchain_litellm import LiteLLMEmbeddingsRouter

router = Router(model_list=[
    {
        "model_name": "text-embedding-3-small",
        "litellm_params": {
            "model": "openai/text-embedding-3-small",
            "api_key": "sk-key1",
        },
    },
    {
        "model_name": "text-embedding-3-small",
        "litellm_params": {
            "model": "openai/text-embedding-3-small",
            "api_key": "sk-key2",
        },
    },
])

embeddings = LiteLLMEmbeddingsRouter(router=router)
```

## Document loaders

```python
from langchain_litellm import LiteLLMOCRLoader
```

`LiteLLMOCRLoader` 通过 LiteLLM proxy 的 OCR endpoint（例如 Azure Document Intelligence）加载文档。该 proxy 会处理所有 provider 特定的认证和配置。

```python
from langchain_litellm import LiteLLMOCRLoader

loader = LiteLLMOCRLoader(
    proxy_base_url="http://localhost:4000",
    api_key="my-bearer-token",
    url_path="https://example.com/document.pdf",
    model="azure-document",
    mode="page",  # "page" = one Document per page; "single" = concatenate all pages
)
documents = loader.load()
```

也支持异步加载：

```python
documents = await loader.aload()
```

## API reference

有关所有类和配置的详细文档，请参阅 @[langchain-litellm] API reference。

| Class | Description |
| :--- | :--- |
| @[ChatLiteLLM] | LiteLLM 的 LangChain 聊天模型包装器 |
| @[ChatLiteLLMRouter] | 基于 Router 的聊天模型，用于负载均衡和回退 |
| @[LiteLLMEmbeddings] | 通过单一一致接口在 100 多个 provider 上执行文本嵌入 |
| @[LiteLLMEmbeddingsRouter] | 基于 Router 的 embeddings，用于跨部署负载均衡 |
| @[LiteLLMOCRLoader] | 通过 LiteLLM proxy 的 OCR endpoint 加载文档 |
