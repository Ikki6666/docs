> 来自 [UnDatasIO](https://undatas.io) 的 `undatasio` 包可以从 PDF 等原始源文档中提取干净文本。
> 本页介绍如何在 LangChain 中使用 `undatasio` 生态。

## 安装与设置

- 安装 Python SDK：  
  `pip install undatasio`  
  同时安装  
  `pip install langchain-undatasio`  
  以便使用 `UnDatasIOLoader` 并通过 UnDatasIO API 进行远程解析。  
  你需要一个 API key，可以在 [undatas.io](https://undatas.io) 免费生成。

- 不需要本地系统依赖，所有处理都在云端运行。

## Data loaders

`UnDatasIO` 的主要用法是通过 **document loader**。

### UnDatasIOLoader

有关单文件解析和惰性加载，请参阅[使用示例](/oss/integrations/document_loaders/undatasio)。

```python
from langchain_undatasio import UnDatasIOLoader
```
