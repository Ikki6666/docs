Tensorlake 是 AI Data Cloud，能够可靠地将非结构化来源中的数据转换为适用于 AI Applications 的可摄取格式。

`langchain-tensorlake` 包在 [Tensorlake](https://tensorlake.ai) 与 [LangChain](https://langchain.com) 之间提供了无缝集成，
让你能够构建具备增强解析能力的复杂文档处理 agents，例如签名检测。

## Tensorlake 功能概览

Tensorlake 为你提供以下工具：
- Extract：基于 schema 的结构化数据提取，用于从文档中提取特定字段。
- Parse：将文档转换为 markdown，用于构建 RAG 或 Knowledge Graph 系统。
- Orchestrate：为 Documents、Text、Audio、Video 等内容构建可编程工作流，以支持大规模摄取和增强。

更多信息参见 [docs.tensorlake.ai](https://docs.tensorlake.ai/introduction)

## 快速开始

### 1. 设置环境

你应当通过设置以下环境变量来配置 Tensorlake 和 OpenAI 的凭据：
```
export TENSORLAKE_API_KEY="your-tensorlake-api-key"
export OPENAI_API_KEY = "your-openai-api-key"
```

你可以在 [Tensorlake Cloud Console](https://cloud.tensorlake.ai/) 获取 Tensorlake API key。新用户可获得 100 个免费积分。

### 2. 导入所需包

```python
from langchain_tensorlake import document_markdown_tool
from langchain.agents import create_agent
import asyncio
import os
```

### 3. 构建一个签名检测 Agent

```python
async def main(question):
    # Create the agent with the Tensorlake tool
    agent = create_agent(
            model="gpt-5.4-mini",
            tools=[document_markdown_tool],
            prompt=(
                """
                I have a document that needs to be parsed. \n\nPlease parse this document and answer the question about it.
                """
            ),
            name="real-estate-agent",
        )

    # Run the agent
    result = await agent.ainvoke({"messages": [{"role": "user", "content": question}]})

    # Print the result
    print(result["messages"][-1].content)
```

*注意：* 强烈建议使用 `openai` 作为 agent 模型，以确保 agent 能设置正确的解析参数

### 4. 示例用法

```python
# Define the path to the document to be parsed
path = "path/to/your/document.pdf"

# Define the question to be asked and create the agent
question = f"What contextual information can you extract about the signatures in my document found at {path}?"

if __name__ == "__main__":
    asyncio.run(main(question))
```
