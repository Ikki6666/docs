[Netmind AI](https://www.netmind.ai/) 致力于让 AI 构建更快、更智能、成本更低。借助其全球 GPU 网络，你可以完成训练、微调、推理和扩展，这是一套一体化 AI 引擎。

本示例介绍如何使用 LangChain 与 Netmind AI 模型交互。

## 安装与设置

```bash
pip install langchain-netmind
```

获取 Netmind API key，并将其设置为环境变量（`NETMIND_API_KEY`）。
访问 [www.netmind.ai/](https://www.netmind.ai/) 注册 Netmind 账号并生成 API key。
