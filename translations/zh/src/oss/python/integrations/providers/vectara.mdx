[Vectara](https://vectara.com/) 是一个值得信赖的 AI Assistant 与 Agent 平台，重点面向企业级关键任务应用的可用性。
Vectara 的无服务器 RAG-as-a-service 通过一个易于使用的 API 提供 RAG 所需的全部组件，包括：

1. 从文件中提取文本的能力，例如 PDF、PPT、DOCX 等
2. 基于机器学习的 chunking，具备业界领先的性能
3. [Boomerang](https://vectara.com/how-boomerang-takes-retrieval-augmented-generation-to-the-next-level-via-grounded-generation/) embeddings 模型
4. 自带内部向量数据库，用于存储文本块和 embedding 向量
5. 一个查询服务，可自动将查询编码为 embedding，并检索最相关的文本片段，同时支持 [Hybrid Search](https://docs.vectara.com/docs/api-reference/search-apis/lexical-matching) 以及多种 reranking 选项，例如 [multi-lingual relevance reranker](https://www.vectara.com/blog/deep-dive-into-vectara-multilingual-reranker-v1-state-of-the-art-reranker-across-100-languages)、[MMR](https://vectara.com/get-diverse-results-and-comprehensive-summaries-with-vectaras-mmr-reranker/)、[UDF reranker](https://www.vectara.com/blog/rag-with-user-defined-functions-based-reranking)
6. 一个用于生成[生成式摘要](https://docs.vectara.com/docs/learn/grounded-generation/grounded-generation-overview)的 LLM，基于检索到的文档（上下文），并包含引用

# 开始使用

要开始使用，请执行以下步骤：

1. 如果你还没有账号，请先[注册](https://www.vectara.com/integrations/langchain)，获取免费的 Vectara 试用。
2. 在你的账号中可以创建一个或多个 corpora。每个 corpus 表示一个区域，用于存储从输入文档摄取后的文本数据。要创建 corpus，请点击 **"Create Corpus"** 按钮，然后为其提供名称和描述。你也可以选择定义过滤属性并启用一些高级选项。点击已创建的 corpus 后，可以在顶部看到其名称和 corpus ID。
3. 接下来需要创建用于访问该 corpus 的 API keys。点击 corpus 视图中的 **"Access Control"** 标签页，然后点击 **"Create API Key"** 按钮。为 key 命名，并选择是只允许 query，还是允许 query+index。点击 `"Create"` 后，该 API key 就会生效。请妥善保管该 key。

要在 LangChain 中使用 Vectara，你需要这两个值：`corpus_key` 和 `api_key`。
你可以通过两种方式向 LangChain 提供 `VECTARA_API_KEY`：

1. 在环境中设置这个变量：`VECTARA_API_KEY`

   例如，可以这样使用 os.environ 和 getpass 设置：

```python
import os
import getpass

os.environ["VECTARA_API_KEY"] = getpass.getpass("Vectara API Key:")
```

2. 在 `Vectara` vectorstore 构造函数中传入：

```python
vectara = Vectara(
    vectara_api_key=vectara_api_key
)
```

本 notebook 假设它们已经在环境中提供。

```python
import os

os.environ["VECTARA_API_KEY"] = "<VECTARA_API_KEY>"
os.environ["VECTARA_CORPUS_KEY"] = "VECTARA_CORPUS_KEY"

from langchain_vectara import Vectara
from langchain_vectara.vectorstores import (
    ChainReranker,
    CorpusConfig,
    CustomerSpecificReranker,
    File,
    GenerationConfig,
    MmrReranker,
    SearchConfig,
    VectaraQueryConfig,
)

vectara = Vectara(vectara_api_key=os.getenv("VECTARA_API_KEY"))
```

首先将 state-of-the-union 文本加载到 Vectara 中。

请注意，这里使用的是 `add_files` 接口，它不需要任何本地处理或 chunking。Vectara 会接收文件内容，并完成所有必要的预处理、chunking 和 embedding，然后写入其知识存储。

这里使用的是 `.txt` 文件，但同样适用于许多其他[文件类型](https://docs.vectara.com/docs/api-reference/indexing-apis/file-upload/file-upload-filetypes)。

```python
corpus_key = os.getenv("VECTARA_CORPUS_KEY")
file_obj = File(
    file_path="../document_loaders/example_data/state_of_the_union.txt",
    metadata={"source": "text_file"},
)
vectara.add_files([file_obj], corpus_key)
```

## Vectara RAG（retrieval augmented generation）

现在创建一个 `VectaraQueryConfig` 对象，用于控制检索和摘要选项：
- 启用摘要，并指定希望 LLM 选取前 7 个最匹配的 chunks，并使用英文回答

基于该配置，使用 `as_rag` 方法创建一个封装完整 Vectara RAG 流水线的 LangChain `Runnable` 对象：

```python
generation_config = GenerationConfig(
    max_used_search_results=7,
    response_language="eng",
    generation_preset_name="vectara-summary-ext-24-05-med-omni",
    enable_factual_consistency_score=True,
)
search_config = SearchConfig(
    corpora=[CorpusConfig(corpus_key=corpus_key)],
    limit=25,
    reranker=ChainReranker(
        rerankers=[
            CustomerSpecificReranker(reranker_id="rnk_272725719", limit=100),
            MmrReranker(diversity_bias=0.2, limit=100),
        ]
    ),
)

config = VectaraQueryConfig(
    search=search_config,
    generation=generation_config,
)

query_str = "what did Biden say?"

rag = vectara.as_rag(config)
rag.invoke(query_str)["answer"]
```

```text
"President Biden discussed several key issues in his recent statements. He emphasized the importance of keeping schools open and noted that with a high vaccination rate and reduced hospitalizations, most Americans can safely return to normal activities without masks [1]. He addressed the need to hold social media platforms accountable for their impact on children and called for stronger privacy protections and mental health services [2]. Biden also announced measures against Russia, including preventing its central bank from defending the Ruble and targeting Russian oligarchs' assets, as part of efforts to weaken Russia's economy and military [3]. Additionally, he highlighted the importance of protecting women's rights, specifically the right to choose as affirmed in Roe v. Wade [5]. Lastly, he advocated for funding the police with necessary resources and training to ensure community safety [6]."
```

也可以这样使用流式接口：

```python
output = {}
curr_key = None
for chunk in rag.stream(query_str):
    for key in chunk:
        if key not in output:
            output[key] = chunk[key]
        else:
            output[key] += chunk[key]
        if key == "answer":
            print(chunk[key], end="", flush=True)
        curr_key = key
```

He highlighted the importance of keeping schools open and noted that with a high vaccination rate and reduced hospitalizations, most Americans can safely return to normal activities without masks [1]. ## Vectara chat

在大多数使用 LangChain 创建 chatbot 的场景中，通常需要集成一个专门的 `memory` 组件，用于维护聊天会话历史，再利用这段历史确保 chatbot 能感知上下文。

而使用 Vectara Chat 时，这一切都会由 Vectara 在后端自动完成。

```python
generation_config = GenerationConfig(
    max_used_search_results=7,
    response_language="eng",
    generation_preset_name="vectara-summary-ext-24-05-med-omni",
    enable_factual_consistency_score=True,
)
search_config = SearchConfig(
    corpora=[CorpusConfig(corpus_key=corpus_key, limit=25)],
    reranker=MmrReranker(diversity_bias=0.2),
)

config = VectaraQueryConfig(
    search=search_config,
    generation=generation_config,
)


bot = vectara.as_chat(config)

bot.invoke("What did the president say about Ketanji Brown Jackson?")["answer"]
```

```text
'The president stated that nominating someone to serve on the United States Supreme Court is one of the most serious constitutional responsibilities he has. He nominated Circuit Court of Appeals Judge Ketanji Brown Jackson, describing her as one of the nation’s top legal minds who will continue Justice Breyer’s legacy of excellence [1].'
```

## Vectara 作为自查询检索器

Vectara 提供 Intelligent Query Rewriting 选项，它能够通过自然语言查询自动生成元数据过滤表达式，从而提升搜索精度。该能力会分析用户查询、提取相关元数据过滤条件，并重写查询，使其更聚焦于核心信息需求。
