本页介绍如何在 LangChain 中使用 Teradata Vector Store。
内容分为两部分：安装与设置，以及对特定 Teradata wrapper 的说明。

## 安装
- 使用 `pip install langchain-teradata` 安装 Python 包

## 设置
第一步是创建到 Teradata Vantage 系统的连接。

    你需要准备 Teradata 凭证，包括 hostname、username、password，以及在云部署场景下可选的 API token。更详细的设置说明请参阅 [Teradata Vector Store User Guide](https://docs.teradata.com/r/Enterprise_IntelliFlex_VMware/Teradata-Vector-Store-User-Guide/Introduction-to-the-Enterprise-Vector-Store-User-Guide)
以及 [Getting started with Vantage Cloud Lake](https://docs.teradata.com/r/Lake-Getting-Started-with-VantageCloud-Lake/)

## Wrappers

### VectorStore

Teradata Vector database 提供了一个 wrapper，使你能够把它当作 vectorstore 来使用，无论是相似度搜索还是 RAG pipeline。

导入这个 vectorstore：
```python
from langchain_teradata import TeradataVectorStore
```
