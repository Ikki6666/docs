> [Pipeshift](https://pipeshift.com) 是一个面向开源 LLM 的微调与推理平台。

- 您带来自己的数据集，微调多个 LLM，只需一键即可开始推理，并观察它们扩展到数百万级。

## 安装和设置

- 安装 Pipeshift 集成包。

  ```bash
  pip install langchain-pipeshift
  ```

- 在 [Pipeshift](https://pipeshift.com) 注册以获取您的 Pipeshift API key。

### 认证

您可以通过以下任一方式使用 Pipeshift API key 进行认证：

1. 将 API key 添加到环境变量 `PIPESHIFT_API_KEY` 中。

    ```python
    os.environ["PIPESHIFT_API_KEY"] = "<your_api_key>"
    ```

2. 通过 `api_key` 传给 pipeshift LLM 模块或 chat 模块

    ```python
    llm = Pipeshift(api_key="<your_api_key>", model="meta-llama/Meta-Llama-3.1-8B-Instruct", max_tokens=512)

                        OR

    chat = ChatPipeshift(api_key="<your_api_key>", model="meta-llama/Meta-Llama-3.1-8B-Instruct", max_tokens=512)
    ```
