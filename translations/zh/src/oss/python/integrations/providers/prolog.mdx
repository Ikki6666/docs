SWI-Prolog 提供了一个完整且免费的 Prolog 环境。

## 安装与设置

安装好 SWI-Prolog 之后，使用 pip 安装 lanchain-prolog：

<CodeGroup>
```bash pip
pip install langchain-prolog
```

```bash uv
uv add langchain-prolog
```
</CodeGroup>

## Tools

`PrologTool` 类允许生成使用 Prolog 规则来产生答案的 langchain tools。

```python
from langchain_prolog import PrologConfig, PrologTool
```

参阅[使用示例](/oss/integrations/tools/prolog_tool)。

同一份指南中也包含 `PrologRunnable` 的使用示例，它允许生成使用 Prolog 规则来产生答案的 LangChain runnable。
