>[Apify](https://apify.com) 是一个用于网页抓取和数据提取的云平台，提供由一千多个现成应用组成的[生态系统](https://apify.com/store)，这些应用称为 *Actors*，可用于各种抓取、爬取和提取场景。

## 概述

Apify 提供对数千个预构建工具（Actors）的访问能力，可用于网页抓取、数据提取和自动化。
该平台负责底层基础设施管理，因此您可以专注于数据提取逻辑。

## 何时使用 Apify

- **访问数千个预构建 Actor**，覆盖多种平台（社交媒体、电商、搜索引擎等）
- **自定义网页抓取和自动化工作流**，不仅限于简单搜索
- **灵活的 Actor 生态系统**，可运行 Apify Store 中的任意 Actor

此集成使您能够在 `Apify` 平台上运行 Actors，并将其结果加载到 LangChain 中，将来自网页的数据和文档输入到向量索引中，例如从文档站点、博客或知识库生成回答。

## 安装和设置

- 使用以下命令安装适用于 Python 的 LangChain Apify 包：

<CodeGroup>
```bash pip
pip install langchain-apify
```

```bash uv
uv add langchain-apify
```
</CodeGroup>

- 获取您的 [Apify API token](https://console.apify.com/account/integrations)，并将其设置为环境变量（`APIFY_TOKEN`），或在构造函数中通过 `apify_api_token` 传入。

## 工具

您可以使用 `ApifyActorsTool` 在智能体中调用 Apify Actors。

```python
from langchain_apify import ApifyActorsTool
```

请参阅[该 notebook](/oss/integrations/tools/apify_actors)中的示例用法，以及 [Apify LangGraph agent Actor template](https://apify.com/templates/python-langgraph) 中工具调用智能体的完整示例。

有关如何使用该工具的更多信息，请访问 [Apify 集成文档](https://docs.apify.com/platform/integrations/langgraph)。

## Wrapper

您可以使用 `ApifyWrapper` 在 Apify 平台上运行 Actors。

```python
from langchain_apify import ApifyWrapper
```

有关如何使用该 wrapper 的更多信息，请参阅 [Apify 集成文档](https://docs.apify.com/platform/integrations/langchain)。

## 用例

- **网页抓取**：从网站、社交媒体、电商站点提取数据
- **搜索引擎结果**：抓取 Google、Bing 和其他搜索引擎
- **数据采集**：为分析和机器学习流水线收集结构化数据
- **内容聚合**：为 RAG 应用从多个来源收集内容

## 定价

Apify 采用按使用量计费或按事件计费，并提供免费层。具体价格因 Actor 而异：

- 某些 Actor 免费使用（您只需为平台计算单元付费）
- 其他 Actor 会按结果或事件收费
- **按事件计费（PPE）**：许多 Actor 支持 [PPE 定价](https://docs.apify.com/platform/actors/publishing/monetize/pay-per-event)，当您希望在智能体部署中获得可预测的按用量计费成本时，这会很有帮助
- 详情请参阅 [Apify pricing](https://apify.com/pricing)

此集成的源代码可在 [LangChain Apify repository](https://github.com/apify/langchain-apify) 中找到。

## MCP Server

不确定该使用哪个 Actor，或者不清楚它需要哪些参数？
Apify 提供了一个 [MCP (Model Context Protocol) server](https://mcp.apify.com)，可帮助您发现可用的 Actor、探索其输入模式，并了解参数要求。

通过 HTTP 连接到 Apify MCP server 时，请在请求头中包含您的 Apify token：

```text
Authorization: Bearer <APIFY_TOKEN>
```
