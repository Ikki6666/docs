与 VoyageAI 相关的所有功能。

>[VoyageAI](https://www.voyageai.com/) Voyage AI 会为您的领域和公司构建定制化嵌入模型，以获得更好的检索质量。

## 安装和设置

安装集成包：
<CodeGroup>
```bash pip
pip install langchain-voyageai
```

```bash uv
uv add langchain-voyageai
```
</CodeGroup>

获取 VoyageAI API 密钥，并将其设置为环境变量（`VOYAGE_API_KEY`）。

## 文本嵌入模型

请参阅[用法示例](/oss/integrations/embeddings/voyageai)。

```python
from langchain_voyageai import VoyageAIEmbeddings
```

## 重排序

请参阅[用法示例](/oss/integrations/document_transformers/voyageai-reranker)。

```python
from langchain_voyageai import VoyageAIRerank
```
