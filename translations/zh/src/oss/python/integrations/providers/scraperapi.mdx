[ScraperAPI](https://www.scraperapi.com/) 通过其网页抓取 API，让你能够从任意公开网站采集数据，而无需担心代理、浏览器或 CAPTCHA 处理。[langchain-scraperapi](https://github.com/scraperapi/langchain-scraperapi) 对这项服务进行了封装，使 AI agent 能更方便地浏览网页并抓取数据。

## 安装与设置

<CodeGroup>
```bash pip
pip install langchain-scraperapi
```

```bash uv
uv add langchain-scraperapi
```
</CodeGroup>

从 [ScraperAPI](https://www.scraperapi.com/) 获取 API key，并将其设置为环境变量：

```python
import os

os.environ["SCRAPERAPI_API_KEY"] = "your-api-key"
```

## Tools

这个包提供了 3 个工具，分别用于抓取任意网站、获取结构化的 Google 搜索结果，以及获取结构化的 Amazon 搜索结果。

每个工具的详细文档如下：
- [ScraperAPITool](/oss/integrations/tools/scraperapi) - 浏览并抓取任意网站
- ScraperAPIGoogleSearchTool - 获取结构化的 Google Search SERP 数据
- ScraperAPIAmazonSearchTool - 获取结构化的 Amazon 商品搜索数据

如需更详细的说明，请参阅[官方仓库](https://github.com/scraperapi/langchain-scraperapi)。
