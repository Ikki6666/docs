[AgentMail](https://agentmail.to) 是一个为 AI agent 打造的 inbox-as-an-API 平台，提供邮箱开通、发送、回复、草稿和入站 webhook 等能力，全部都可通过单一 HTTP API 访问。`langchain-agentmail` 包把 AgentMail SDK 封装为 LangChain tools，并提供了针对收件箱的 document loader 和 retriever。

## 安装与设置

<CodeGroup>
```bash pip
pip install langchain-agentmail
```

```bash uv
uv add langchain-agentmail
```
</CodeGroup>

从 [agentmail.to](https://agentmail.to) 获取你的 API key，并将其设置为环境变量：

```bash
export AGENTMAIL_API_KEY="your-api-key"
```
