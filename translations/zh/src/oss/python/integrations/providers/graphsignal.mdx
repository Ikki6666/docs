本页介绍如何使用 [Graphsignal](https://app.graphsignal.com) 对 LangChain 进行追踪和监控。Graphsignal 能为您的应用提供完整可见性。它提供按 chains 和 tools 拆分的延迟分析、带完整上下文的异常、数据监控、计算/GPU 利用率、OpenAI 成本分析等能力。

## 安装和设置

- 使用 `pip install graphsignal` 安装 Python 库
- 创建一个免费的 [Graphsignal account](https://graphsignal.com)
- 获取 API key，并将其设置为环境变量（`GRAPHSIGNAL_API_KEY`）

## 追踪与监控

Graphsignal 会自动为 chains 注入埋点并开始追踪和监控。随后，追踪和指标会显示在您的 [Graphsignal dashboards](https://app.graphsignal.com) 中。

通过提供 deployment name 来初始化 tracer：

```python
import graphsignal

graphsignal.configure(deployment='my-langchain-app-prod')
```

如果还想追踪任意函数或代码，可以使用装饰器或上下文管理器：

```python
@graphsignal.trace_function
def handle_request():
    chain.run("some initial text")
```

```python
with graphsignal.start_trace('my-chain'):
    chain.run("some initial text")
```

另外，您还可以启用 profiling，为每条 trace 记录函数级统计信息。

```python
with graphsignal.start_trace(
        'my-chain', options=graphsignal.TraceOptions(enable_profiling=True)):
    chain.run("some initial text")
```

完整设置说明请参阅 [Quick Start](https://graphsignal.com/docs/guides/quick-start/) 指南。
