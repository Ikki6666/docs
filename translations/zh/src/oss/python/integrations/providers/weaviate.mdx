>[Weaviate](https://weaviate.io/) 是一个开源向量数据库。它允许你存储数据对象和来自你常用 ML 模型的向量嵌入，并能无缝扩展到数十亿个数据对象。


什么是 `Weaviate`？
- Weaviate 是一种开源的向量搜索引擎数据库。
- Weaviate 允许你以类似类属性的方式存储 JSON 文档，同时为这些文档附加机器学习向量，以便在向量空间中表示它们。
- Weaviate 可以独立使用，也就是自带向量，或者结合多种模块来为你完成向量化并扩展核心能力。
- Weaviate 提供 GraphQL API，便于你访问数据。
- Weaviate 致力于帮助你将向量搜索投入生产环境，并实现毫秒级查询，查看其[开源基准测试](https://weaviate.io/developers/weaviate/current/benchmarks/)可了解 Weaviate 是否适合你的使用场景。
- 通过[基础入门指南](https://weaviate.io/developers/weaviate/current/core-knowledge/basics.html)，你可以在五分钟内了解 Weaviate。

**Weaviate 详解：**

`Weaviate` 是一个低延迟向量搜索引擎，开箱即用地支持不同媒体类型，如文本、图像等。它提供语义搜索、问答提取、分类、可定制模型（PyTorch/TensorFlow/Keras）等能力。Weaviate 使用 Go 从零构建，同时存储对象和向量，因此能够将向量搜索与结构化过滤以及云原生数据库的容错能力结合起来。所有这些能力都可以通过 GraphQL、REST 以及多种客户端编程语言访问。

## 安装与设置

安装 Python SDK：

<CodeGroup>
```bash pip
pip install langchain-weaviate
```

```bash uv
uv add langchain-weaviate
```
</CodeGroup>


## Vector store

这里提供了一个围绕 `Weaviate` 索引的封装器，允许你将其用作 vectorstore，
无论是用于语义搜索还是示例选择。

导入该 vectorstore：
```python
from langchain_weaviate import WeaviateVectorStore
```

若要查看更详细的 Weaviate 封装器使用说明，参见[此 notebook](/oss/integrations/vectorstores/weaviate)。
