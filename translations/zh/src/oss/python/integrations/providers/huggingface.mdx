## 聊天模型

### ChatHuggingFace

您可以使用 `Hugging Face` 的 LLM 类，或者直接使用 `ChatHuggingFace` 类。

请参阅[用法示例](/oss/integrations/chat/huggingface)。

```python
from langchain_huggingface import ChatHuggingFace
```

## LLM

### HuggingFaceEndpoint

您可以使用 `HuggingFaceEndpoint` 类，通过无服务器 [Inference Providers](https://huggingface.co/docs/inference-providers) 或专用 [Inference Endpoints](https://huggingface.co/inference-endpoints/dedicated) 运行开源模型。

请参阅[用法示例](/oss/integrations/llms/huggingface_endpoint)。

```python
from langchain_huggingface import HuggingFaceEndpoint
```

### HuggingFacePipeline

您可以使用 `HuggingFacePipeline` 类在本地运行开源模型。

请参阅[用法示例](/oss/integrations/llms/huggingface_pipelines)。

```python
from langchain_huggingface import HuggingFacePipeline
```

## 嵌入模型

### HuggingFaceEmbeddings

您可以使用 `HuggingFaceEmbeddings` 类在本地运行开源嵌入模型。

请参阅[用法示例](/oss/integrations/embeddings/huggingfacehub)。

```python
from langchain_huggingface import HuggingFaceEmbeddings
```

### HuggingFaceEndpointEmbeddings

您可以使用 `HuggingFaceEndpointEmbeddings` 类，通过专用 [Inference Endpoint](https://huggingface.co/inference-endpoints/dedicated) 运行开源嵌入模型。

请参阅[用法示例](/oss/integrations/embeddings/huggingfacehub)。

```python
from langchain_huggingface import HuggingFaceEndpointEmbeddings
```

### Text Embeddings Inference (TEI)

对于 Sentence Transformers 模型的自托管生产服务，Hugging Face 发布了 [Text Embeddings Inference](https://github.com/huggingface/text-embeddings-inference)，这是一个支持批处理和 GPU 的专用推理服务器。您可以通过 `HuggingFaceEndpointEmbeddings` 将 LangChain 指向一个 TEI 部署，或者查看专门的 [TEI integration guide](/oss/integrations/embeddings/text_embeddings_inference)。

### BGE embedding models

>[Hugging Face 上的 BGE models](https://huggingface.co/BAAI) 是来自 [北京智源人工智能研究院（BAAI）](https://en.wikipedia.org/wiki/Beijing_Academy_of_Artificial_Intelligence) 的一个强大开源嵌入模型家族。

BGE 模型属于 Sentence Transformers 模型，因此请搭配 `HuggingFaceEmbeddings` 并使用 `encode_kwargs={"normalize_embeddings": True}`。请参阅[用法示例](/oss/integrations/embeddings/bge_huggingface)。
