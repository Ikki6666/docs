>什么是 `FalkorDB`？

>- FalkorDB 是一个专注于图数据库技术的`开源数据库管理系统`。
>- FalkorDB 允许你用节点和边来表示和存储数据，因此非常适合处理连接型数据和关系。
>- FalkorDB 支持 OpenCypher 查询语言，并带有专有扩展，便于你与图数据交互并执行查询。
>- 借助 FalkorDB，你可以实现高性能的`图遍历和查询`，适用于生产级系统。

>访问[官方网站](https://docs.falkordb.com/)即可开始使用 FalkorDB。

## 安装与设置

- 使用 `pip install falkordb langchain-falkordb` 安装 Python SDK

## VectorStore

FalkorDB 的向量索引用作 vectorstore，
可用于语义搜索或示例选择。

```python
from langchain_falkordb.vectorstore import FalkorDBVector
```
