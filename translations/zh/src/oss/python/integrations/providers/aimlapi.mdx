>[AI/ML API](https://aimlapi.com/app/?utm_source=langchain&utm_medium=github&utm_campaign=integration) 通过单一 API 提供对 300 多个托管基础模型（DeepSeek、Gemini、GPT 等）的访问，并具备企业级可用性和吞吐能力。

## 安装和设置

- 安装 AI/ML API 集成包。

  ```bash
  pip install langchain-aimlapi
  ```

- 在 [aimlapi.com](https://aimlapi.com/app/?utm_source=langchain&utm_medium=github&utm_campaign=integration) 创建账户并生成 API 密钥。
- 通过设置 `AIMLAPI_API_KEY` 环境变量进行认证。

```python
import os

os.environ["AIMLAPI_API_KEY"] = "aimlapi_..."
```
