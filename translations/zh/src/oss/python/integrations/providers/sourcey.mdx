[Sourcey](https://sourcey.com) 用于构建静态文档站点。

使用 `langchain-sourcey` 可以从已发布的 Sourcey 文档站点中检索内容。它会读取 `search-index.json`，在存在时使用 `llms-full.txt`，并返回规范页面 URL 以供引用。

## 安装和设置

安装 `langchain-sourcey`：

<CodeGroup>
```bash pip
pip install -qU langchain-sourcey
```

```bash uv
uv add langchain-sourcey
```
</CodeGroup>

不需要 API 密钥。

将检索器指向已发布的 Sourcey 文档构建根目录。它会读取 `search-index.json` 以获取候选页面，并在该文件存在时读取 `llms-full.txt` 以获取完整页面内容。

## 检索器

您可以在标准检索流程中使用 [`SourceyRetriever`](/oss/integrations/retrievers/sourcey)。

```python
from langchain_sourcey import SourceyRetriever
```

请参阅[用法示例](/oss/integrations/retrievers/sourcey)或 [Sourcey 指南](https://sourcey.com/docs/guides/guide-langchain-retriever)。
