> [Snowflake](https://www.snowflake.com/) 是一个基于云的数据仓库平台，
> 让你能够存储并查询海量数据。

本页介绍如何在 `LangChain` 中使用 `Snowflake` 生态。

## Embedding models

Snowflake 在 [Hugging Face](https://huggingface.co/Snowflake/snowflake-arctic-embed-m-v1.5) 上免费提供其开源权重的 `arctic` embedding model 系列。最新模型 snowflake-arctic-embed-m-v1.5 具备 [matryoshka embedding](https://arxiv.org/abs/2205.13147) 特性，从而支持高效的向量截断。
你可以通过
[HuggingFaceEmbeddings](/oss/integrations/embeddings/huggingfacehub) connector 使用这些模型：

<CodeGroup>
```bash pip
pip install sentence-transformers
```

```bash uv
uv add sentence-transformers
```
</CodeGroup>

```python
from langchain_huggingface import HuggingFaceEmbeddings

model = HuggingFaceEmbeddings(model_name="snowflake/arctic-embed-m-v1.5")
```
