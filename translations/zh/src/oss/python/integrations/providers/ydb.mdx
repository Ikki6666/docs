这里汇总了与 YDB 相关的全部功能。

> [YDB](https://ydb.tech/) 是一个多功能的开源分布式 SQL 数据库，兼具高可用性、可扩展性、强一致性和 ACID 事务能力。
> 它能够同时承载事务型（OLTP）、分析型（OLAP）和流式工作负载。

## 安装与设置

<CodeGroup>
```bash pip
pip install langchain-ydb
```

```bash uv
uv add langchain-ydb
```
</CodeGroup>

## Vector store

导入 YDB vector store：

```python
from langchain_ydb.vectorstores import YDB
```

如需更详细的 YDB vector store 使用说明，请参阅[这个 notebook](/oss/integrations/vectorstores/ydb)。
