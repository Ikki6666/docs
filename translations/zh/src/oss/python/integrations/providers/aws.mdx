## Chat models

### Bedrock chat

>[Amazon Bedrock](https://aws.amazon.com/bedrock/) 是一项全托管服务，通过单一 API 提供来自 `AI21 Labs`、`Anthropic`、`Cohere`、`Meta`、`Stability AI` 和 `Amazon` 等领先 AI 公司的高性能 foundation models (`FMs`) 选择，同时还提供构建生成式 AI 应用所需的安全、隐私和负责任 AI 能力。使用 `Amazon Bedrock`，你可以轻松试验和评估最适合场景的顶级模型，基于私有数据使用 fine-tuning 与 `Retrieval Augmented Generation` (`RAG`) 等技术进行定制，并构建能调用企业系统和数据源来执行任务的 agents。由于 `Amazon Bedrock` 是无服务器服务，你无需管理任何基础设施，并且可以使用你已经熟悉的 AWS 服务，将生成式 AI 能力安全地集成并部署到应用中。

参见[使用示例](/oss/integrations/chat/bedrock)。

```python
from langchain_aws import ChatBedrock
```

### Bedrock converse
AWS Bedrock 维护了一个 [Converse API](https://docs.aws.amazon.com/bedrock/latest/APIReference/API_runtime_Converse.html)，为 Bedrock 模型提供统一的对话接口。这个 API 目前还不支持自定义模型。支持的所有模型可见[这里](https://docs.aws.amazon.com/bedrock/latest/userguide/conversation-inference.html)。

<Info>
    **对于不需要使用自定义模型的用户，推荐使用 Converse API。它可通过 [ChatBedrockConverse](https://reference.langchain.com/python/langchain-aws/chat_models/bedrock_converse/ChatBedrockConverse) 访问。**
</Info>

参见[使用示例](/oss/integrations/chat/bedrock)。

```python
from langchain_aws import ChatBedrockConverse
```

### Amazon DocumentDB vector search

>[Amazon DocumentDB (with MongoDB Compatibility)](https://docs.aws.amazon.com/documentdb/) 让你可以轻松地在云中搭建、运行和扩展兼容 MongoDB 的数据库。借助 Amazon DocumentDB，你可以运行相同的应用代码，并使用与 MongoDB 相同的驱动和工具。Amazon DocumentDB 的向量搜索将基于 JSON 的文档数据库的灵活性与丰富查询能力，与向量搜索能力结合起来。

### Amazon MemoryDB

[Amazon MemoryDB](https://aws.amazon.com/memorydb/) 是一个具备持久性的内存数据库服务，可提供极快性能。MemoryDB 兼容 Redis OSS，这是一种流行的开源数据存储，因此你可以快速使用相同的 Redis OSS API 和命令来构建应用。

`InMemoryVectorStore` 类提供了一个可连接 Amazon MemoryDB 的 vectorstore。

```python
from langchain_aws.vectorstores.inmemorydb import InMemoryVectorStore

vds = InMemoryVectorStore.from_documents(
            chunks,
            embeddings,
            redis_url="rediss://cluster_endpoint:6379/ssl=True ssl_cert_reqs=none",
            vector_schema=vector_schema,
            index_name=INDEX_NAME,
        )
```
参见[使用示例](/oss/integrations/vectorstores/memorydb)。

## Memory

### Amazon Bedrock AgentCore Memory

>[Amazon Bedrock AgentCore Memory](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/memory.html) 为 LangGraph agents 提供托管式持久化，使对话历史和状态可在多次会话之间保存，并具备自动扩展与高可用能力。

<CodeGroup>
    ```bash pip
    pip install langgraph-checkpoint-aws
    ```

    ```bash uv
    uv add langgraph-checkpoint-aws
    ```
</CodeGroup>

```python
from langgraph_checkpoint_aws import AgentCoreMemorySaver

# Create checkpointer
checkpointer = AgentCoreMemorySaver(
    memory_id="your-memory-id",
    region_name="us-west-2"
)

# Use with LangGraph
graph = workflow.compile(checkpointer=checkpointer)

# Invoke with thread_id and actor_id for conversation persistence
config = {
    "configurable": {
        "thread_id": "user-123",
        "actor_id": "my-agent"  # Required for AgentCore
    }
}
result = graph.invoke({"messages": []}, config)
```

核心特性：
- 托管式基础设施，无需自行搭建数据库
- 自动扩展与高可用性
- 通过 `actor_id` 隔离实现多 agent 支持
- 静态与传输中的数据加密

### Amazon Bedrock AgentCore Memory Store

>[Amazon Bedrock AgentCore Memory Store](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/memory.html) 为 LangGraph agents 提供具备语义搜索能力的长期记忆，用于跨会话存储和检索用户偏好、事实和提取出的记忆。

```python
from langgraph_checkpoint_aws import AgentCoreMemoryStore

# Initialize store for long-term memories
store = AgentCoreMemoryStore(memory_id="your-memory-id", region_name="us-west-2")

# Use in a pre-model hook to save and retrieve memories
def pre_model_hook(state, config, *, store):
    actor_id = config["configurable"]["actor_id"]
    thread_id = config["configurable"]["thread_id"]
    namespace = (actor_id, thread_id)

    # Save a message
    store.put(namespace, str(uuid.uuid4()), {"message": msg})

    # Search for relevant memories
    results = store.search(("preferences", actor_id), query="user preferences", limit=5)
    return {"model_input_messages": state["messages"]}
```

## Runtime

### Amazon Bedrock AgentCore Runtime

>[Amazon Bedrock AgentCore Runtime](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/agents-tools-runtime.html) 为 LangGraph agents 提供托管式无服务器执行环境，内置可观测性、自动扩展能力，并可无缝集成其他 AgentCore 服务。

<CodeGroup>
    ```bash pip
    pip install bedrock-agentcore
    ```

    ```bash uv
    uv add bedrock-agentcore
    ```
</CodeGroup>

```python
from bedrock_agentcore.runtime import BedrockAgentCoreApp

app = BedrockAgentCoreApp()

@app.entrypoint
def agent_invocation(payload, context):
    result = graph.invoke({"messages": [{"role": "user", "content": payload["prompt"]}]})
    return {"result": result["messages"][-1].content}

app.run()
```

使用 AgentCore CLI 进行部署：

```bash
# Configure your agent
agentcore configure

# Deploy to AgentCore Runtime
agentcore launch -e your_agent.py
```
