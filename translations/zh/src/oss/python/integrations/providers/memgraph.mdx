>Memgraph 是一个高性能、基于内存的图数据库，针对实时查询和分析进行了优化。
>访问[官网](https://memgraph.com/)即可开始使用 Memgraph。

## 安装和设置

- 使用 `pip install langchain-memgraph` 安装 Python SDK

## MemgraphQAChain

这里提供了一个围绕 Memgraph 数据库的 wrapper，可根据用户输入生成 Cypher 语句，并使用这些语句从数据库中检索相关信息。

```python
from langchain_memgraph.chains.graph_qa import MemgraphQAChain
from langchain_memgraph.graphs.memgraph import MemgraphLangChain
```

请参阅[用法示例](/oss/integrations/graphs/memgraph)。

## 从非结构化数据构建知识图谱

您可以使用该集成从非结构化数据中构建知识图谱。

<LangchainExperimentalUnmaintained />

```python
from langchain_memgraph.graphs.memgraph import MemgraphLangChain
from langchain_experimental.graph_transformers import LLMGraphTransformer
```

请参阅[用法示例](/oss/integrations/graphs/memgraph)。

## Memgraph 工具和工具包

Memgraph 还提供了一个 toolkit，使您能够与 Memgraph 数据库交互。
请参阅[用法示例](/oss/integrations/tools/memgraph)。

```python
from langchain_memgraph import MemgraphToolkit
```
