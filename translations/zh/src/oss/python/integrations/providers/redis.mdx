>[Redis（Remote Dictionary Server）](https://en.wikipedia.org/wiki/Redis) 是一个开源内存存储系统，
>可用作分布式内存键值数据库、缓存和消息代理，并可选支持持久化。
>由于全部数据都保存在内存中，加上其设计特点，`Redis` 能提供低延迟读写，
>因此特别适合需要缓存的使用场景。Redis 是最流行的 NoSQL 数据库，
>也是整体上最受欢迎的数据库之一。

本页介绍如何在 LangChain 中使用 [Redis](https://redis.com) 生态。
它分为两部分：安装与设置，以及对各个 Redis 封装器的引用。

## 安装与设置

安装 Python SDK 和 LangChain Redis 集成：

<CodeGroup>
```bash pip
pip install redis langchain-redis
```

```bash uv
uv add redis langchain-redis
```
</CodeGroup>

要在本地运行 Redis，可以使用 Docker：

```bash
docker run --name langchain-redis -d -p 6379:6379 redis redis-server --save 60 1 --loglevel warning
```

停止容器：

```bash
docker stop langchain-redis
```

再次启动容器：

```bash
docker start langchain-redis
```

### 连接

你需要一个 redis URL 连接字符串来连接数据库，既支持独立部署的 Redis 服务器，
也支持带复制和 Redis Sentinels 的高可用部署。

#### Redis 单机连接 URL
对于独立部署的 `Redis` 服务器，可以使用官方 redis 连接 URL 格式，具体见 Python redis 模块
`from_url()` 方法的说明 [Redis.from_url](https://redis-py.readthedocs.io/en/stable/connections.html#redis.Redis.from_url)

示例：`redis_url = "redis://:secret-pass@localhost:6379/0"`

#### Redis sentinel 连接 URL

对于 [Redis sentinel setups](https://redis.io/docs/management/sentinel/)，连接 scheme 为 `"redis+sentinel"`。
这是对官方 IANA 注册协议 scheme 的一种非官方扩展，因为目前还没有专门面向 Sentinels 的连接 URL。

示例：`redis_url = "redis+sentinel://:secret-pass@sentinel-host:26379/mymaster/0"`

格式为 `redis+sentinel://$USERNAME:$PASSWORD@$HOST_OR_IP:$PORT/$SERVICE_NAME/$DB_NUMBER`
如果未显式设置，则默认值是 `"service-name = mymaster"` 和 `"db-number = 0"`。
其中 service-name 是在 Sentinel 中配置的 redis 服务器监控组名称。

当前 URL 格式只支持一个 sentinel host，不能提供主机列表，
并且 Redis 服务器与 sentinel 必须使用相同的密码，如果启用了密码的话。

#### Redis cluster 连接 URL

目前 Redis cluster 不支持所有需要 `"redis_url"` 参数的方法。
要使用 Redis Cluster，唯一方式是使用接受预先配置好的 Redis client 的 LangChain 类，例如 `RedisCache`，
见下方示例。

## Cache

Cache 封装器允许将 [Redis](https://redis.io) 用作远程、低延迟、内存型缓存，以缓存 LLM prompts 和 responses。

### Standard cache
标准缓存是 Redis 在生产环境中的经典用法，适用于全球范围内的[开源](https://redis.io)和[企业版](https://redis.com)用户。

```python
from langchain_redis import RedisCache
```

将该缓存与 LLM 配合使用：
```python
from langchain.globals import set_llm_cache
import redis

redis_client = redis.Redis.from_url(...)
set_llm_cache(RedisCache(redis_client))
```

### Semantic cache
语义缓存允许用户根据当前输入与历史缓存结果之间的语义相似度来命中缓存。
其底层同时将 Redis 用作缓存和 vectorstore。

```python
from langchain_redis import RedisSemanticCache
```

将该缓存与 LLM 配合使用：
```python
from langchain.globals import set_llm_cache
import redis

# use any embedding provider...
from tests.integration_tests.vectorstores.fake_embeddings import FakeEmbeddings

redis_url = "redis://localhost:6379"

set_llm_cache(RedisSemanticCache(
    embedding=FakeEmbeddings(),
    redis_url=redis_url
))
```

## Vector store

Redis 内置了 vector store 集成，支持低延迟检索、元数据过滤、MMR，以及混合全文和向量搜索。

```python
from langchain_redis import RedisVectorStore
```

详细说明参见 [Redis vector store integration guide](/oss/integrations/vectorstores/redis)。

## Retriever

Redis vector store retriever 封装器对 vectorstore 类进行了泛化，用于执行
低延迟文档检索。要创建 retriever，只需在基础 vectorstore 类上
调用 `.as_retriever()`。
