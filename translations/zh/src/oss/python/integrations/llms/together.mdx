**你当前所在的页面记录的是如何将 Together AI 模型作为文本补全模型使用。许多流行的 Together AI 模型其实是[聊天补全模型](/oss/langchain/models)。**

你可能想找的是[这个页面](/oss/integrations/chat/together/)。
</Warning>

[Together AI](https://www.together.ai/) 提供 API，让你只需几行代码就能查询 [50+ 个领先的开源模型](https://docs.together.ai/docs/inference-models)。

本示例介绍如何使用 LangChain 与 Together AI 模型交互。

## 安装

```python
pip install -U langchain-together
```

## 环境

要使用 Together AI，你需要一个 API key，可在这里找到：[api.together.ai/settings/api-keys](https://api.together.ai/settings/api-keys)。你可以通过初始化参数 `together_api_key` 传入，或将其设置为环境变量 `TOGETHER_API_KEY`。

## 示例

```python
# Querying chat models with Together AI

from langchain_together import ChatTogether

# choose from our 50+ models here: https://docs.together.ai/docs/inference-models
chat = ChatTogether(
    # together_api_key="YOUR_API_KEY",
    model="meta-llama/Llama-3-70b-chat-hf",
)

# stream the response back from the model
stream = chat.stream_events("Tell me fun things to do in NYC", version="v3")
for token in stream.text:
    print(token, end="", flush=True)

# if you don't want to do streaming, you can use the invoke method
# chat.invoke("Tell me fun things to do in NYC")
```

```python
# Querying code and language models with Together AI

from langchain_together import Together

llm = Together(
    model="codellama/CodeLlama-70b-Python-hf",
    # together_api_key="..."
)

print(llm.invoke("def bubble_sort(): "))
```
