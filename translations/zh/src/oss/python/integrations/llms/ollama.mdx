## 安装

```python

pip install -U langchain-ollama
```

## 配置

首先，按照 [这些说明](https://github.com/ollama/ollama?tab=readme-ov-file#ollama) 配置并运行本地 Ollama 实例：

* [下载](https://ollama.ai/download) 并在受支持的平台上安装 Ollama（包括 Windows Subsystem for Linux aka WSL、macOS 和 Linux）
  * macOS 用户可以通过 Homebrew 安装：`brew install ollama`，然后用 `brew services start ollama` 启动
* 使用 `ollama pull <name-of-model>` 获取可用的 LLM 模型
  * 你可以通过 [model library](https://ollama.ai/library) 查看可用模型列表
  * 例如：`ollama pull llama3`
* 这会下载模型默认标记的版本。通常默认值会指向最新、参数规模最小的模型。

> 在 Mac 上，模型会下载到 `~/.ollama/models`
>
> 在 Linux（或 WSL）上，模型会存储在 `/usr/share/ollama/.ollama/models`

* 使用 `ollama pull vicuna:13b-v1.5-16k-q4_0` 这类写法指定你关注模型的精确版本（此例可查看 [Vicuna](https://ollama.ai/library/vicuna/tags) 模型的各类标签）
* 查看所有已拉取模型：`ollama list`
* 直接在命令行与模型聊天：`ollama run <name-of-model>`
* 查看 [Ollama documentation](https://github.com/ollama/ollama/tree/main/docs) 获取更多命令。你也可以在终端运行 `ollama help` 查看可用命令。

## 使用

```python
from langchain_core.prompts import ChatPromptTemplate
from langchain_ollama.llms import OllamaLLM

template = """Question: {question}

Answer: Let's think step by step."""

prompt = ChatPromptTemplate.from_template(template)

model = OllamaLLM(model="llama3.1")

chain = prompt | model

chain.invoke({"question": "What is LangChain?"})
```

```python
import base64
from io import BytesIO

from IPython.display import HTML, display
from PIL import Image


def convert_to_base64(pil_image):
    """
    将 PIL 图像转换为 Base64 编码字符串

    :param pil_image: PIL image
    :return: 调整尺寸后的 Base64 字符串
    """

    buffered = BytesIO()
    pil_image.save(buffered, format="JPEG")  # 如有需要，你可以更改格式
    img_str = base64.b64encode(buffered.getvalue()).decode("utf-8")
    return img_str


def plt_img_base64(img_base64):
    """
    显示 Base64 编码字符串作为图片

    :param img_base64:  Base64 字符串
    """
    # 使用 base64 字符串创建 HTML img 标签
    image_html = f'<img src="data:image/jpeg;base64,{img_base64}" />'
    # 通过渲染 HTML 显示图片
    display(HTML(image_html))


file_path = "../../../static/img/ollama_example_img.jpg"
pil_image = Image.open(file_path)
image_b64 = convert_to_base64(pil_image)
plt_img_base64(image_b64)
```
