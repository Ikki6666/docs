本页介绍如何在 LangChain 中使用 [Azure OpenAI](https://aka.ms/azure-openai)。

Azure OpenAI API 与 OpenAI 的 API 兼容。`openai` Python 包可以让你同时方便地使用 OpenAI 和 Azure OpenAI。除了下面说明的差异之外，你可以像调用 OpenAI 一样调用 Azure OpenAI。

## API 配置

你可以使用环境变量来配置 `openai` 包以使用 Azure OpenAI。下面是 `bash` 的示例：

```bash
# 你要使用的 API 版本：如果使用发布版本，请设为 `2023-12-01-preview`。
export OPENAI_API_VERSION=2023-12-01-preview
# Azure OpenAI 资源的基础 URL。你可以在 Azure 门户中的 Azure OpenAI 资源里找到它。
export AZURE_OPENAI_ENDPOINT=https://your-resource-name.openai.azure.com
# Azure OpenAI 资源的 API key。你可以在 Azure 门户中的 Azure OpenAI 资源里找到它。
export AZURE_OPENAI_API_KEY=<your Azure OpenAI API key>
```

或者，你也可以直接在运行中的 Python 环境里配置 API：

```python
import os
os.environ["OPENAI_API_VERSION"] = "2023-12-01-preview"
```

## Azure Active Directory 认证

你可以通过两种方式对 Azure OpenAI 进行认证：

- API Key
- Azure Active Directory (AAD)

使用 API key 是最简单的入门方式。你可以在 Azure 门户中的 Azure OpenAI 资源下找到你的 API key。

不过，如果你的安全要求比较复杂，你可能会想使用 Azure Active Directory。关于如何在 Azure OpenAI 中使用 AAD 的更多信息，请参见 [managed identity 文档](https://learn.microsoft.com/en-us/azure/ai-services/openai/how-to/managed-identity)。

如果你在本地开发，需要安装 Azure CLI 并完成登录。你可以在 [Azure CLI 安装指南](https://docs.microsoft.com/en-us/cli/azure/install-azure-cli) 中安装 Azure CLI，然后运行 `az login` 登录。

为你的 Azure OpenAI 资源添加一个作用域限定到该资源的 Azure role assignment `Cognitive Services OpenAI User`。这样你就可以从 AAD 获取 token 并用于 Azure OpenAI。这个角色可以分配给用户、组、service principal 或 managed identity。关于 Azure OpenAI RBAC 角色的更多信息，请参见 [role-based access control 文档](https://learn.microsoft.com/en-us/azure/ai-services/openai/how-to/role-based-access-control)。

要在 Python 中使用 LangChain 的 AAD，请安装 `azure-identity` 包。然后将 `OPENAI_API_TYPE` 设置为 `azure_ad`。接着，使用 `DefaultAzureCredential` 类通过 `get_token` 获取 AAD token，如下所示。最后，把 `OPENAI_API_KEY` 环境变量设置为该 token 值。

```python
import os
from azure.identity import DefaultAzureCredential

# 获取 Azure Credential
credential = DefaultAzureCredential()

# 将 API type 设置为 `azure_ad`
os.environ["OPENAI_API_TYPE"] = "azure_ad"
# 将 API_KEY 设置为从 Azure credential 获取到的 token
os.environ["OPENAI_API_KEY"] = credential.get_token("https://cognitiveservices.azure.com/.default").token
```

`DefaultAzureCredential` 类是开始使用 AAD 认证的简单方式。如果需要，你也可以自定义 credential chain。下面的示例中，我们先尝试 Managed Identity，再回退到 Azure CLI。这在你运行代码于 Azure 环境，但又想在本地开发时非常有用。

```python
from azure.identity import ChainedTokenCredential, ManagedIdentityCredential, AzureCliCredential

credential = ChainedTokenCredential(
    ManagedIdentityCredential(),
    AzureCliCredential()
)
```

## 部署

使用 Azure OpenAI 时，你需要为常见的 GPT-3 和 Codex 模型配置自己的 deployment。调用 API 时，你需要指定想要使用的 deployment。

_**注意**：这些文档面向 Azure 文本补全模型。像 GPT-4 这样的模型是聊天模型，它们的接口略有不同，可以通过 @[`AzureChatOpenAI`] 类访问。关于 Azure chat 的文档，请参见 [Azure Chat OpenAI 文档](/oss/integrations/chat/azure_chat_openai)。_

假设你的 deployment 名称是 `gpt-35-turbo-instruct-prod`。在 `openai` Python API 中，你可以使用 `engine` 参数指定这个 deployment。例如：

```python
import openai

client = openai.AzureOpenAI(
    api_version="2023-12-01-preview",
)

response = client.completions.create(
    model="gpt-35-turbo-instruct-prod",
    prompt="Test prompt"
)
```

import os

```python
# 导入 Azure OpenAI
from langchain_openai import AzureOpenAI
```

```python
# 创建 Azure OpenAI 实例
# 将 deployment 名称替换成你自己的
llm = AzureOpenAI(
    deployment_name="gpt-35-turbo-instruct-0914",
)
```

```python
# 运行 LLM
llm.invoke("Tell me a joke")
```
