开始使用 RunPod LLM。

## 概览

本指南介绍如何使用 LangChain `RunPod` LLM 类与托管在 [RunPod Serverless](https://www.runpod.io/serverless-gpu) 上的文本生成模型交互。

## 配置

1. **安装包：**

   ```bash
   pip install -qU langchain-runpod
   ```

2. **部署一个 LLM Endpoint：** 按照 [RunPod Provider Guide](/oss/integrations/providers/runpod#setup) 中的设置步骤，在 RunPod Serverless 上部署一个兼容的文本生成 endpoint，并获取它的 Endpoint ID。
3. **设置环境变量：** 确保 `RUNPOD_API_KEY` 和 `RUNPOD_ENDPOINT_ID` 已设置。

```python
import getpass
import os

# 确保环境变量已设置（或者直接传给 RunPod）
if "RUNPOD_API_KEY" not in os.environ:
    os.environ["RUNPOD_API_KEY"] = getpass.getpass("Enter your RunPod API Key: ")
if "RUNPOD_ENDPOINT_ID" not in os.environ:
    os.environ["RUNPOD_ENDPOINT_ID"] = input("Enter your RunPod Endpoint ID: ")
```

## 实例化

初始化 `RunPod` 类。你可以通过 `model_kwargs` 传入模型特定参数，并配置 polling 行为。

```python
from langchain_runpod import RunPod

llm = RunPod(
    # 如果没有在环境变量中设置，可以在这里传入 runpod_endpoint_id
    model_kwargs={
        "max_new_tokens": 256,
        "temperature": 0.6,
        "top_k": 50,
        # 添加你的 endpoint handler 支持的其他参数
    },
    # 可选：调整 polling
    # poll_interval=0.3,
    # max_polling_attempts=100
)
```

## 调用

使用标准 LangChain `.invoke()` 和 `.ainvoke()` 方法调用模型。`stream()` 和 `astream()` 也支持流式输出（通过轮询 RunPod `/stream` endpoint 模拟实现）。

```python
prompt = "Write a tagline for an ice cream shop on the moon."

# 同步调用
try:
    response = llm.invoke(prompt)
    print("--- Sync Invoke Response ---")
    print(response)
except Exception as e:
    print(
        f"Error invoking LLM: {e}. Ensure endpoint ID/API key are correct and endpoint is active/compatible."
    )
```

```python
# 流式（同步，通过轮询 /stream 模拟）
print("\n--- Sync Stream Response ---")
try:
    stream = llm.stream_events(prompt, version="v3")
    for token in stream.text:
        print(token, end="", flush=True)
    print()  # 换行
except Exception as e:
    print(
        f"\nError streaming LLM: {e}. Ensure endpoint handler supports streaming output format."
    )
```

### 异步使用

```python
# 异步调用
try:
    async_response = await llm.ainvoke(prompt)
    print("--- Async Invoke Response ---")
    print(async_response)
except Exception as e:
    print(f"Error invoking LLM asynchronously: {e}.")
```

```python
# 异步流式
print("\n--- Async Stream Response ---")
try:
    stream = await llm.astream_events(prompt, version="v3")
    async for token in stream.text:
        print(token, end="", flush=True)
    print()  # 换行
except Exception as e:
    print(
        f"\nError streaming LLM asynchronously: {e}. Ensure endpoint handler supports streaming output format."
    )
```

## 链式调用

该 LLM 可以与 LangChain Expression Language (LCEL) chain 无缝集成。

```python
from langchain_core.output_parsers import StrOutputParser
from langchain_core.prompts import PromptTemplate

# 假设 'llm' 变量已在 'Instantiation' 单元中初始化
prompt_template = PromptTemplate.from_template("Tell me a joke about {topic}")
parser = StrOutputParser()

chain = prompt_template | llm | parser

try:
    chain_response = chain.invoke({"topic": "bears"})
    print("--- Chain Response ---")
    print(chain_response)
except Exception as e:
    print(f"Error running chain: {e}")

# 异步 chain
try:
    async_chain_response = await chain.ainvoke({"topic": "robots"})
    print("--- Async Chain Response ---")
    print(async_chain_response)
except Exception as e:
    print(f"Error running async chain: {e}")
```

## Endpoint 注意事项

- **输入：** endpoint handler 应该在 `{"input": {"prompt": "...", ...}}` 中接收 prompt 字符串。
- **输出：** handler 应该在最终状态响应的 `"output"` key 中返回生成文本（例如 `{"output": "Generated text..."}` 或 `{"output": {"text": "..."}}`）。
- **流式：** 对于通过 `/stream` endpoint 模拟的流式输出，handler 必须在状态响应中填充 `"stream"` key，并包含一个 chunk 字典列表，例如 `[{"output": "token1"}, {"output": "token2"}]`。
