## 概览

`langchain-nvidia-ai-endpoints` 包包含用于基于 NVIDIA NIM inference microservice 构建应用的 LangChain 集成。这些模型经过 NVIDIA 优化，可在 NVIDIA accelerated infrastructure 上提供最佳性能，并作为 NIM 部署。NIM 是一种易于使用的预构建容器，可以通过单个命令在 NVIDIA accelerated infrastructure 上任意部署。

NVIDIA 托管的 NIM 部署可以在 [NVIDIA API catalog](https://build.nvidia.com/) 上测试。测试完成后，可以使用 NVIDIA AI Enterprise 许可证从 NVIDIA 的 API catalog 导出 NIM，并在本地或云端运行，让企业拥有并完全控制自己的 IP 和 AI 应用。

NIM 以容器镜像的形式按模型分别打包，并通过 NVIDIA NGC Catalog 以 NGC container images 的方式分发。NIM 的核心是为在 AI 模型上执行推理提供简单、一致且熟悉的 API。

本示例介绍如何使用 LangChain 与通过 `NVIDIA` 类支持的模型交互。

关于通过这个 API 访问 llm 模型的更多信息，请查看 [NVIDIA](https://python.langchain.com/docs/integrations/llms/nvidia_ai_endpoints/) 文档。

## 配置

**开始前：**

1. 在 [NVIDIA](https://build.nvidia.com/) 创建一个免费账号，该平台托管 NVIDIA AI Foundation models。

2. 点击你选择的模型。

3. 在 `Input` 下选择 `Python` 选项卡，然后点击 `Get API Key`。接着点击 `Generate Key`。

4. 复制并保存生成的 key，命名为 `NVIDIA_API_KEY`。完成后，你就可以访问这些 endpoints。

### 凭据

```python
import getpass
import os

if not os.getenv("NVIDIA_API_KEY"):
    # 注意：API key 应以 "nvapi-" 开头
    os.environ["NVIDIA_API_KEY"] = getpass.getpass("Enter your NVIDIA API key: ")
```

## 流式、批量和异步

这些模型原生支持流式输出，而且和所有 LangChain LLM 一样，它们也提供 batch 方法来处理并发请求，并提供用于 invoke、stream 和 batch 的 async 方法。下面是一些示例。

```python
stream = llm.stream_events(prompt, version="v3")
for token in stream.text:
    print(token, end="", flush=True)
```

```python
llm.batch([prompt])
```

```python
await llm.ainvoke(prompt)
```

```python
stream = await llm.astream_events(prompt, version="v3")
async for token in stream.text:
    print(token, end="", flush=True)
```

```python
await llm.abatch([prompt])
```

```python
async for chunk in llm.astream_log(prompt):
    print(chunk)
```

```python
response = llm.invoke(
    "X_train, y_train, X_test, y_test = train_test_split(X, y, test_size=0.1) #Train a logistic regression model, predict the labels on the test set and compute the accuracy score"
)
print(response)
```
