>[`WatsonxLLM`](https://ibm.github.io/watsonx-ai-python-sdk/fm_extensions.html#langchain) 是 IBM [watsonx.ai](https://www.ibm.com/products/watsonx-ai) foundation models 的封装器。

本示例展示如何使用 `LangChain` 与 `watsonx.ai` 模型通信。

## 配置

要访问 IBM watsonx.ai 模型，你需要创建一个 IBM watsonx.ai 账号、获取 API key，并安装 `langchain-ibm` 集成包。

### 凭据

下面的代码单元定义了与 watsonx Foundation Model 推理配合使用所需的凭据。

**操作：** 提供 IBM Cloud 用户 API key。详情请参见 [Managing user API keys](https://cloud.ibm.com/docs/account?topic=account-userapikey&interface=ui)。

```python
import os
from getpass import getpass

watsonx_api_key = getpass()
os.environ["WATSONX_APIKEY"] = watsonx_api_key
```

此外，你还可以将其他 secret 作为环境变量传入。

```python
import os

os.environ["WATSONX_URL"] = "your service instance url"
os.environ["WATSONX_TOKEN"] = "your token for accessing the CLOUD or CPD cluster"
os.environ["WATSONX_PASSWORD"] = "your password for accessing the CPD cluster"
os.environ["WATSONX_USERNAME"] = "your username for accessing the CPD cluster"
os.environ["WATSONX_INSTANCE_ID"] = "your instance_id for accessing the CPD cluster"
```

## 实例化

你可能需要针对不同模型或任务调整模型 `parameters`。详细信息请参见 [documentation](https://ibm.github.io/watsonx-ai-python-sdk/fm_model.html#metanames.GenTextParamsMetaNames)。

```python
parameters = {
    "decoding_method": "sample",
    "max_new_tokens": 100,
    "min_new_tokens": 1,
    "temperature": 0.5,
    "top_k": 50,
    "top_p": 1,
}
```

使用前面设置好的参数初始化 `WatsonxLLM` 类。

**注意**：

- 如果你想为 API 调用提供上下文，必须添加 `project_id` 或 `space_id`。更多信息请参见 [documentation](https://www.ibm.com/docs/en/watsonx-as-a-service?topic=projects)。
- 根据你所提供的服务实例所在区域，请使用 [Watsonx Python SDK cloud setup guide](https://ibm.github.io/watsonx-ai-python-sdk/setup_cloud.html#authentication) 中描述的 URL 之一。

在这个示例中，我们使用 `project_id` 和 Dallas URL。

你需要指定用于推理的 `model_id`。所有可用模型请见 [documentation](https://ibm.github.io/watsonx-ai-python-sdk/fm_model.html#TextModels)。

```python
from langchain_ibm import WatsonxLLM

watsonx_llm = WatsonxLLM(
    model_id="ibm/granite-13b-instruct-v2",
    url="https://us-south.ml.cloud.ibm.com",
    project_id="PASTE YOUR PROJECT_ID HERE",
    params=parameters,
)
```

另外，你也可以使用 Cloud Pak for Data 凭据。更多信息请参见 [documentation](https://ibm.github.io/watsonx-ai-python-sdk/setup_cpd.html)。

```python
watsonx_llm = WatsonxLLM(
    model_id="ibm/granite-13b-instruct-v2",
    url="PASTE YOUR URL HERE",
    username="PASTE YOUR USERNAME HERE",
    password="PASTE YOUR PASSWORD HERE",
    instance_id="openshift",
    version="4.8",
    project_id="PASTE YOUR PROJECT_ID HERE",
    params=parameters,
)
```

除了 `model_id`，你也可以传入之前调优模型的 `deployment_id`。整个模型调优流程请参见 [Working with TuneExperiment and PromptTuner](https://ibm.github.io/watsonx-ai-python-sdk/pt_tune_experiment_run.html)。

```python
watsonx_llm = WatsonxLLM(
    deployment_id="PASTE YOUR DEPLOYMENT_ID HERE",
    url="https://us-south.ml.cloud.ibm.com",
    project_id="PASTE YOUR PROJECT_ID HERE",
    params=parameters,
)
```

对于某些需求，你还可以将 IBM 的 [`APIClient`](https://ibm.github.io/watsonx-ai-python-sdk/base.html#apiclient) 对象传入 `WatsonxLLM` 类。

```python
from ibm_watsonx_ai import APIClient

api_client = APIClient(...)

watsonx_llm = WatsonxLLM(
    model_id="ibm/granite-13b-instruct-v2",
    watsonx_client=api_client,
)
```

你也可以将 IBM 的 [`ModelInference`](https://ibm.github.io/watsonx-ai-python-sdk/fm_model_inference.html) 对象传入 `WatsonxLLM` 类。

```python
from ibm_watsonx_ai.foundation_models import ModelInference

model = ModelInference(...)

watsonx_llm = WatsonxLLM(watsonx_model=model)
```

## 调用

要获取 completions，你可以直接使用字符串 prompt 调用模型。

```python
# 调用单个 prompt

watsonx_llm.invoke("Who is man's best friend?")
```

```text
"Man's best friend is his dog. Dogs are man's best friend because they are always there for you, they never judge you, and they love you unconditionally. Dogs are also great companions and can help reduce stress levels. "
```

```python
# 调用多个 prompt

watsonx_llm.generate(
    [
        "The fastest dog in the world?",
        "Describe your chosen dog breed",
    ]
)
```

## 流式输出模型结果

你可以流式输出模型结果。

```python
stream = watsonx_llm.stream_events(
    "Describe your favorite breed of dog and why it is your favorite.",
    version="v3",
)
for token in stream.text:
    print(token, end="")
```

```text
My favorite breed of dog is a Labrador Retriever. They are my favorite breed because they are my favorite color, yellow. They are also very smart and easy to train.
```

## 链式调用

创建 `PromptTemplate` 对象，用于生成随机问题。

```python
from langchain_core.prompts import PromptTemplate

template = "Generate a random question about {topic}: Question: "

prompt = PromptTemplate.from_template(template)
```

提供一个主题并运行 chain。

```python
llm_chain = prompt | watsonx_llm

topic = "dog"

llm_chain.invoke(topic)
```

```text
'What is the origin of the name "Pomeranian"?'
```
