>[Amazon Bedrock](https://aws.amazon.com/bedrock/) 是一项全托管服务，它通过单一 API 提供来自 `AI21 Labs`、`Anthropic`、`Cohere`、`Meta`、`Stability AI` 和 `Amazon` 等领先 AI 公司的一系列高性能基础模型（FMs），以及构建生成式 AI 应用所需的一整套安全、隐私和负责任 AI 能力。使用 `Amazon Bedrock`，你可以轻松地针对自己的用例试验和评估顶级基础模型，使用微调和 `Retrieval Augmented Generation`（`RAG`）等技术结合你的数据对模型进行私有化定制，并构建可借助企业系统和数据源执行任务的 agents。由于 `Amazon Bedrock` 是无服务器的，你无需管理任何基础设施，还可以借助你已经熟悉的 AWS 服务，将生成式 AI 能力安全地集成并部署到应用中。

```python
pip install -qU langchain-aws
```

```python
from langchain_aws import BedrockLLM

llm = BedrockLLM(
    credentials_profile_name="bedrock-admin", model_id="amazon.titan-text-express-v1"
)
```

### 自定义模型

```python
custom_llm = BedrockLLM(
    credentials_profile_name="bedrock-admin",
    provider="cohere",
    model_id="<Custom model ARN>",  # ARN like 'arn:aws:bedrock:...' obtained via provisioning the custom model
    model_kwargs={"temperature": 1},
    streaming=True,
)

custom_llm.invoke(input="What is the recipe of mayonnaise?")
```

## Amazon Bedrock 的 Guardrails

[Guardrails for Amazon Bedrock](https://aws.amazon.com/bedrock/guardrails/) 会根据特定用例策略评估用户输入和模型响应，并在底层模型之外额外提供一层防护。Guardrails 可应用于多种模型，包括 Anthropic Claude、Meta Llama 2、Cohere Command、AI21 Labs Jurassic、Amazon Titan Text，以及微调模型。
本节将设置一个带有特定 guardrails 的 Bedrock 语言模型，其中包含 tracing 能力。

```python
from typing import Any

from langchain_core.callbacks import AsyncCallbackHandler


class BedrockAsyncCallbackHandler(AsyncCallbackHandler):
    # Async callback handler that can be used to handle callbacks from langchain.

    async def on_llm_error(self, error: BaseException, **kwargs: Any) -> Any:
        reason = kwargs.get("reason")
        if reason == "GUARDRAIL_INTERVENED":
            print(f"Guardrails: {kwargs}")


# Guardrails for Amazon Bedrock with trace
llm = BedrockLLM(
    credentials_profile_name="bedrock-admin",
    model_id="<Model_ID>",
    model_kwargs={},
    guardrails={"id": "<Guardrail_ID>", "version": "<Version>", "trace": True},
    callbacks=[BedrockAsyncCallbackHandler()],
)
```
