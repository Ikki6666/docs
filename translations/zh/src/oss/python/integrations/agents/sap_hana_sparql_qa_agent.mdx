## 设置与安装

要使用该功能，请安装 `langchain-hana` 包：

```python
pip install langchain_hana
```

`HanaSparqlQAAgent` 是一种基于 agent 的方法，用于对存储在 SAP HANA Cloud 中的 RDF 数据进行问答。与基于 chain 的方法不同，该 agent 可以：

1. **动态检索本体（ontology）**，使用一个专用工具
2. **迭代地生成并执行 SPARQL 查询**
3. **自我纠错**，当查询失败或返回意外结果时
4. **逐步推理**复杂问题

## 初始化

你需要：

- 一个为 agent 提供推理能力的 **LLM**
- 一个 **`HanaRdfGraph`**（包含连接、`graph_uri` 和本体）

按照此处的步骤 [HanaRdfGraph](/oss/integrations/graphs/sap_hana_rdf_graph) 了解更多关于创建 `HanaRdfGraph` 实例的内容。

导入 `HanaSparqlQAAgent`

```python
from langchain_hana import HanaSparqlQAAgent
agent = HanaSparqlQAAgent.create_agent(graph=graph, model=llm)
```

## Agent 概览

该 agent 迭代地使用工具来：
1. 首先检索本体，以理解数据结构
2. 基于 schema 生成合适的 SPARQL 查询
3. 执行查询并解读结果
4. 构造自然语言回答

### 默认配置

- **Tools**：
  - `retrieve_ontology` - 从 graph 中以 Turtle 格式检索 RDF 本体/schema
  - `execute_sparql` - 对 HANA RDF graph 执行 SPARQL 查询
- **System Prompt**：提供了一个默认的 system prompt，其中包含 SPARQL 生成与工具使用说明。
- **Middleware**：默认添加 `ModelRetryMiddleware(max_retries=3)` 和 `ToolRetryMiddleWare(max_retries=2)`，以防止无限循环

### 自定义你的 Agent

你可以通过向 `create_agent` 提供额外参数来自定义 agent 的行为：

```python
agent = HanaSparqlQAAgent.create_agent(
    graph=graph,  # Required: HanaRdfGraph instance
    model=llm,  # Required: LLM to power the agent
    system_prompt=your_custom_prompt,  # Custom system prompt (str or SystemMessage)
    tools=[your_custom_tools],  # Additional tools to include
    middleware=[your_custom_middlewares],  # Additional middleware to include
    include_default_tools=True,  # include default tools (default: True)
    include_default_middleware=True,  # include default middleware (default: True)
)
```

## 示例：对 "Movies" 知识图谱进行问答

**前提条件**：
你必须拥有一个启用了 **triple store** 功能的 SAP HANA Cloud 实例。
详细说明请参阅：[Enable Triple Store](https://help.sap.com/docs/hana-cloud-database/sap-hana-cloud-sap-hana-database-knowledge-graph-guide/enable-triple-store/)<br />
加载 `kgdocu_movies` 示例数据。请参见 [Knowledge Graph Example](https://help.sap.com/docs/hana-cloud-database/sap-hana-cloud-sap-hana-database-knowledge-graph-guide/knowledge-graph-example)。

下面的示例：

1. 实例化指向 movies 数据 graph 的 `HanaRdfGraph`
2. 创建一个由 LLM 驱动的 `HanaSparqlQAAgent`
3. 提出自然语言问题，并让 agent 自行推理得出答案

该示例演示了 agent 如何动态检索本体、生成 SPARQL 查询，并返回人类可读的回答。

```python
import os

from dotenv import load_dotenv
from hdbcli import dbapi

# Load environment variables if needed
load_dotenv()

# Establish connection to SAP HANA Cloud
connection = dbapi.connect(
    address=os.environ.get("HANA_DB_ADDRESS"),
    port=os.environ.get("HANA_DB_PORT"),
    user=os.environ.get("HANA_DB_USER"),
    password=os.environ.get("HANA_DB_PASSWORD")
)
```

然后，设置知识图谱实例

```python
from gen_ai_hub.proxy.langchain.openai import ChatOpenAI
from langchain_hana import HanaRdfGraph, HanaSparqlQAChain

# from langchain_openai import ChatOpenAI  # or your chosen LLM
```

```python
# Set up the Knowledge Graph
graph_uri = "kgdocu_movies"

graph = HanaRdfGraph(
    connection=connection,
    graph_uri=graph_uri,
    auto_extract_ontology=True
)
```

```python
# a basic graph schema is extracted from the data graph. This schema will guide the LLM to generate a proper SPARQL query.
schema_graph = graph.get_schema
print(schema_graph.serialize(format="turtle"))
```

```python

llm = ChatOpenAI(proxy_model_name="gpt-4o", temperature=0)
```

然后，创建 SPARQL QA Agent。

```python
# Create a SPARQL QA Agent
agent = HanaSparqlQAAgent.create_agent(
    graph=graph,
    model=llm,
)
```

```python
# Example queries:
# question = "Which movies are in the data?"
# question = "In which movies did Keanu Reeves and Carrie-Anne Moss play together"
# question = "which movie genres are in the data?"
# question = "which are the two most assigned movie genres?"
# question = "where were the actors of 'Blade Runner' born?"
# question = "which actors acted together in a movie and were born in the same city?"
question = "which actors acted in Blade Runner?"

for event in agent.stream(
    {"messages": [{"role": "user", "content": question}]},
    stream_mode="values",
):
    event["messages"][-1].pretty_print()
```

### 底层发生了什么？

1. **本体检索**
   Agent 首先使用 `retrieve_ontology` 工具以 Turtle 格式获取 RDF schema。这让 agent 了解可用的类、属性和关系。

2. **SPARQL 生成**
   基于本体和用户的问题，agent 会推理要查询哪些实体和属性，然后生成一个有效的 `SELECT` 查询。

3. **查询执行**
   Agent 调用 `execute_sparql` 工具，对 HANA RDF graph 运行生成的查询。如果查询失败或返回意外结果，agent 可以自我纠错并重试。

4. **答案构造**
   Agent 解读查询结果，并严格基于检索到的数据构造一个简洁、人类可读的回答。
