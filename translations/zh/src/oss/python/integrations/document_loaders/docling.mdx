[Docling](https://github.com/DS4SD/docling) 可以将 PDF、DOCX、PPTX、HTML 等格式解析为丰富而统一的表示形式，包括文档布局、表格等，使其能够直接用于 RAG 等生成式 AI 工作流。

这个集成通过 `DoclingLoader` 文档加载器提供 Docling 的能力。

## 概览

### 集成详情

| Class | Package | Local | Serializable | JS support|
| :--- | :--- | :---: | :---: |  :---: |
| langchain_docling.loader | langchain-docling | ✅ | ❌ | ❌ |

### Loader 特性

| Source | Document Lazy Loading | Native Async Support
| :---: | :---: | :---: |
| `DoclingLoader` | ✅ | ❌ |

这里展示的 `DoclingLoader` 组件可以让你：

- 轻松、快速地在 LLM 应用中使用多种文档类型。
- 利用 Docling 的丰富格式实现更高级、以文档为中心的 grounding。

`DoclingLoader` 支持两种不同的导出模式：

- `ExportType.DOC_CHUNKS`（默认）：如果你希望将每个输入文档进行切块，并在下游把每个块作为单独的 LangChain Document。
- `ExportType.MARKDOWN`：如果你希望将每个输入文档作为单独的 LangChain Document。

示例允许你通过参数 `EXPORT_TYPE` 探索这两种模式，随后会根据设定值构建对应的示例 pipeline。

## 设置

```python
pip install -qU langchain-docling
```

> 为了获得最佳转换速度，请尽可能使用 GPU 加速。例如在 Colab 中运行时，请使用启用了 GPU 的 runtime。

## 初始化

基础初始化如下：

```python
from langchain_docling.loader import DoclingLoader

FILE_PATH = "https://arxiv.org/pdf/2408.09869"

loader = DoclingLoader(file_path=FILE_PATH)
```

对于高级用法，`DoclingLoader` 支持以下参数：

- `file_path`：来源，可以是单个字符串（URL 或本地文件）或其可迭代对象
- `converter`（可选）：要使用的特定 Docling converter 实例
- `convert_kwargs`（可选）：转换执行时使用的特定 kwargs
- `export_type`（可选）：导出模式，`ExportType.DOC_CHUNKS`（默认）或 `ExportType.MARKDOWN`
- `md_export_kwargs`（可选）：Markdown 模式下使用的特定 Markdown 导出 kwargs
- `chunker`（可选）：要使用的特定 Docling chunker 实例（用于 doc-chunk 模式）
- `meta_extractor`（可选）：要使用的特定 metadata extractor

## 惰性加载

文档也可以按惰性方式加载：

```python
doc_iter = loader.lazy_load()
for doc in doc_iter:
    pass  # you can operate on `doc` here
```

## 端到端示例

```python
import os

# https://github.com/huggingface/transformers/issues/5486:
os.environ["TOKENIZERS_PARALLELISM"] = "false"
```

> - 下面的示例 pipeline 使用 HuggingFace 的 Inference API；如需更高的 LLM 配额，可以通过环境变量 `HF_TOKEN` 提供 token。
> - 这个 pipeline 的依赖可以按如下方式安装（`--no-warn-conflicts` 主要是为 Colab 预装的 Python 环境准备的；如果你希望更严格一些，可以自行去掉）：

```python
pip install -q --progress-bar off --no-warn-conflicts langchain-core langchain-huggingface langchain-milvus langchain python-dotenv
```

定义 pipeline 参数：

```python
from pathlib import Path
from tempfile import mkdtemp

from dotenv import load_dotenv
from langchain_core.prompts import PromptTemplate
from langchain_docling.loader import ExportType


def _get_env_from_colab_or_os(key):
    try:
        from google.colab import userdata

        try:
            return userdata.get(key)
        except userdata.SecretNotFoundError:
            pass
    except ImportError:
        pass
    return os.getenv(key)


load_dotenv()

HF_TOKEN = _get_env_from_colab_or_os("HF_TOKEN")
FILE_PATH = ["https://arxiv.org/pdf/2408.09869"]  # Docling Technical Report
EMBED_MODEL_ID = "sentence-transformers/all-MiniLM-L6-v2"
GEN_MODEL_ID = "mistralai/Mixtral-8x7B-Instruct-v0.1"
EXPORT_TYPE = ExportType.DOC_CHUNKS
QUESTION = "Which are the main AI models in Docling?"
PROMPT = PromptTemplate.from_template(
    "Context information is below.\n---------------------\n{context}\n---------------------\nGiven the context information and not prior knowledge, answer the query.\nQuery: {input}\nAnswer:\n",
)
TOP_K = 3
MILVUS_URI = str(Path(mkdtemp()) / "docling.db")
```

现在可以实例化加载器并加载文档：

```python
from docling.chunking import HybridChunker
from langchain_docling import DoclingLoader

loader = DoclingLoader(
    file_path=FILE_PATH,
    export_type=EXPORT_TYPE,
    chunker=HybridChunker(tokenizer=EMBED_MODEL_ID),
)

docs = loader.load()
```

确定切分结果：

```python
if EXPORT_TYPE == ExportType.DOC_CHUNKS:
    splits = docs
elif EXPORT_TYPE == ExportType.MARKDOWN:
    from langchain_text_splitters import MarkdownHeaderTextSplitter

    splitter = MarkdownHeaderTextSplitter(
        headers_to_split_on=[
            ("#", "Header_1"),
            ("##", "Header_2"),
            ("###", "Header_3"),
        ],
    )
    splits = [split for doc in docs for split in splitter.split_text(doc.page_content)]
else:
    raise ValueError(f"Unexpected export type: {EXPORT_TYPE}")
```

### 导入向量库

```python
import json
from pathlib import Path
from tempfile import mkdtemp

from langchain_huggingface.embeddings import HuggingFaceEmbeddings
from langchain_milvus import Milvus

embedding = HuggingFaceEmbeddings(model_name=EMBED_MODEL_ID)

milvus_uri = str(Path(mkdtemp()) / "docling.db")  # or set as needed
vectorstore = Milvus.from_documents(
    documents=splits,
    embedding=embedding,
    collection_name="docling_demo",
    connection_args={"uri": milvus_uri},
    index_params={"index_type": "FLAT"},
    drop_old=True,
)
```

### RAG

```python
from langchain_classic.chains import create_retrieval_chain
from langchain_classic.chains.combine_documents import create_stuff_documents_chain
from langchain_huggingface import HuggingFaceEndpoint

retriever = vectorstore.as_retriever(search_kwargs={"k": TOP_K})
llm = HuggingFaceEndpoint(
    repo_id=GEN_MODEL_ID,
    huggingfacehub_api_token=HF_TOKEN,
    task="text-generation",
)
```

```python
def clip_text(text, threshold=100):
    return f"{text[:threshold]}..." if len(text) > threshold else text
```

```python
question_answer_chain = create_stuff_documents_chain(llm, PROMPT)
rag_chain = create_retrieval_chain(retriever, question_answer_chain)
resp_dict = rag_chain.invoke({"input": QUESTION})

clipped_answer = clip_text(resp_dict["answer"], threshold=350)
print(f"Question:\n{resp_dict['input']}\n\nAnswer:\n{clipped_answer}")
for i, doc in enumerate(resp_dict["context"]):
    print()
    print(f"Source {i + 1}:")
    print(f"  text: {json.dumps(clip_text(doc.page_content, threshold=350))}")
    for key in doc.metadata:
        if key != "pk":
            val = doc.metadata.get(key)
            clipped_val = clip_text(val) if isinstance(val, str) else val
            print(f"  {key}: {clipped_val}")
```
