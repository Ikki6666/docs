## 基础用法

### 保存文档

使用 `SpannerDocumentSaver.add_documents(<documents>)` 保存 langchain documents。初始化 `SpannerDocumentSaver` 类时，需要提供 3 项信息：

1. `instance_id` - 要从中加载数据的 Spanner 实例。
1. `database_id` - 要从中加载数据的 Spanner 数据库。
1. `table_name` - Spanner 数据库中用于存储 langchain documents 的表名。

```python
from langchain_core.documents import Document
from langchain_google_spanner import SpannerDocumentSaver

test_docs = [
    Document(
        page_content="Apple Granny Smith 150 0.99 1",
        metadata={"fruit_id": 1},
    ),
    Document(
        page_content="Banana Cavendish 200 0.59 0",
        metadata={"fruit_id": 2},
    ),
    Document(
        page_content="Orange Navel 80 1.29 1",
        metadata={"fruit_id": 3},
    ),
]

saver = SpannerDocumentSaver(
    instance_id=INSTANCE_ID,
    database_id=DATABASE_ID,
    table_name=TABLE_NAME,
)
saver.add_documents(test_docs)
```

### 从 spanner 查询文档

如需了解如何连接 Spanner 表的更多细节，请参阅 [Python SDK documentation](https://cloud.google.com/python/docs/reference/spanner/latest)。

#### 从表中加载文档

使用 `SpannerLoader.load()` 或 `SpannerLoader.lazy_load()` 加载 langchain documents。`lazy_load` 返回一个 generator，只有在迭代时才会查询数据库。初始化 `SpannerLoader` 类时，需要提供：

1. `instance_id` - 要从中加载数据的 Spanner 实例。
1. `database_id` - 要从中加载数据的 Spanner 数据库。
1. `query` - 数据库方言对应的查询语句。

```python
from langchain_google_spanner import SpannerLoader

query = f"SELECT * from {TABLE_NAME}"
loader = SpannerLoader(
    instance_id=INSTANCE_ID,
    database_id=DATABASE_ID,
    query=query,
)

for doc in loader.lazy_load():
    print(doc)
    break
```

### 删除文档

使用 `SpannerDocumentSaver.delete(<documents>)` 从表中删除一组 langchain documents。

```python
docs = loader.load()
print("Documents before delete:", docs)

doc = test_docs[0]
saver.delete([doc])
print("Documents after delete:", loader.load())
```

## 高级用法

### 自定义 client

默认创建的 client 是默认 client。如果你想显式传入 `credentials` 和 `project`，可以向构造函数传入自定义 client。

```python
from google.cloud import spanner
from google.oauth2 import service_account

creds = service_account.Credentials.from_service_account_file("/path/to/key.json")
custom_client = spanner.Client(project="my-project", credentials=creds)
loader = SpannerLoader(
    INSTANCE_ID,
    DATABASE_ID,
    query,
    client=custom_client,
)
```

### 自定义 document page content 和 metadata

loader 会返回一个 Documents 列表，其 page content 来源于指定的数据列，其余所有数据列都会加入 metadata。每一行对应一个 document。

#### 自定义 page content 格式

`SpannerLoader` 默认假设存在一个名为 `page_content` 的列。你可以按如下方式修改这一默认值：

```python
custom_content_loader = SpannerLoader(
    INSTANCE_ID, DATABASE_ID, query, content_columns=["custom_content"]
)
```

如果指定了多个列，page content 的字符串格式默认会是 `text`（空格分隔的字符串拼接）。你也可以指定其他格式，包括 `text`、`JSON`、`YAML`、`CSV`。

#### 自定义 metadata 格式

`SpannerLoader` 默认假设存在一个名为 `langchain_metadata` 的 metadata 列，用于存储 JSON 数据。这个 metadata 列会作为基础字典。默认情况下，所有其他列数据都会被加入其中，并且可能覆盖原始值。你可以按如下方式修改这些默认行为：

```python
custom_metadata_loader = SpannerLoader(
    INSTANCE_ID, DATABASE_ID, query, metadata_columns=["column1", "column2"]
)
```

#### 自定义 JSON metadata 列名

默认情况下，loader 会使用 `langchain_metadata` 作为基础字典。你也可以改为选择另一个 JSON 列，作为 Document metadata 的基础字典。

```python
custom_metadata_json_loader = SpannerLoader(
    INSTANCE_ID, DATABASE_ID, query, metadata_json_column="another-json-column"
)
```

### 自定义 staleness

默认的 [staleness](https://cloud.google.com/python/docs/reference/spanner/latest/snapshot-usage#beginning-a-snapshot) 是 15 秒。你可以通过指定更弱的边界来自定义它，例如指定所有读取都以某个时间戳为准，或者以过去某个时间长度为准。

```python
import datetime

timestamp = datetime.datetime.utcnow()
custom_timestamp_loader = SpannerLoader(
    INSTANCE_ID,
    DATABASE_ID,
    query,
    staleness=timestamp,
)
```

```python
duration = 20.0
custom_duration_loader = SpannerLoader(
    INSTANCE_ID,
    DATABASE_ID,
    query,
    staleness=duration,
)
```

### 打开 data boost

默认情况下，loader 不会使用 [data boost](https://cloud.google.com/spanner/docs/databoost/databoost-overview)，因为它会带来额外成本，并且需要额外 IAM 权限。不过，用户也可以选择启用它。

```python
custom_databoost_loader = SpannerLoader(
    INSTANCE_ID,
    DATABASE_ID,
    query,
    databoost=True,
)
```

### 自定义 client

默认创建的 client 是默认 client。如果你想显式传入 `credentials` 和 `project`，可以向构造函数传入自定义 client。

```python
from google.cloud import spanner

custom_client = spanner.Client(project="my-project", credentials=creds)
saver = SpannerDocumentSaver(
    INSTANCE_ID,
    DATABASE_ID,
    TABLE_NAME,
    client=custom_client,
)
```

### 为 SpannerDocumentSaver 自定义初始化

SpannerDocumentSaver 支持自定义初始化。这样可以让用户指定 Document 该如何保存到表中。

content_column：作为 Document page content 的列名。默认值为 `page_content`。

metadata_columns：如果 Document metadata 中存在这些 key，则这些 metadata 会保存到对应列中。

metadata_json_column：特殊 JSON 列的列名。默认值为 `langchain_metadata`。

```python
custom_saver = SpannerDocumentSaver(
    INSTANCE_ID,
    DATABASE_ID,
    TABLE_NAME,
    content_column="my-content",
    metadata_columns=["foo"],
    metadata_json_column="my-special-json-column",
)
```

### 为 spanner 初始化自定义 schema

SpannerDocumentSaver 提供 `init_document_table` 方法，用于创建带自定义 schema 的新表来存储 docs。

```python
from langchain_google_spanner import Column

new_table_name = "my_new_table"

SpannerDocumentSaver.init_document_table(
    INSTANCE_ID,
    DATABASE_ID,
    new_table_name,
    content_column="my-page-content",
    metadata_columns=[
        Column("category", "STRING(36)", True),
        Column("price", "FLOAT64", False),
    ],
)
```
