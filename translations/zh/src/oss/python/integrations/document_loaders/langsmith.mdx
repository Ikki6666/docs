## 设置

要使用 LangSmith document loader，你需要安装 `langchain-core`，创建一个 [LangSmith](https://langsmith.com) 账户并获取 API key。

### 凭证

在 [langsmith.com](https://langsmith.com) 注册并生成 API key。完成后，设置 `LANGSMITH_API_KEY` 环境变量：

```python
import getpass
import os

if not os.environ.get("LANGSMITH_API_KEY"):
    os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
```

如果你还想启用自动化、最佳体验的 tracing，也可以开启 LangSmith tracing：

```python
os.environ["LANGSMITH_TRACING"] = "true"
```

### 安装

安装 `langchain-core`：

```python
pip install -qU langchain-core
```

### 克隆示例数据集

在这个示例中，我们会克隆并加载一个公开的 LangSmith 数据集。克隆操作会在你个人的 LangSmith 账户中创建该数据集的副本。你只能加载自己拥有个人副本的数据集。

```python
from langsmith import Client as LangSmithClient

ls_client = LangSmithClient()

dataset_name = "LangSmith Few Shot Datasets Notebook"
dataset_public_url = (
    "https://smith.langchain.com/public/55658626-124a-4223-af45-07fb774a6212/d"
)

ls_client.clone_public_dataset(dataset_public_url)
```

## 初始化

现在可以实例化 document loader 并加载文档：

```python
from langchain_core.document_loaders import LangSmithLoader

loader = LangSmithLoader(
    dataset_name=dataset_name,
    content_key="question",
    limit=50,
    # format_content=...,
    # ...
)
```
