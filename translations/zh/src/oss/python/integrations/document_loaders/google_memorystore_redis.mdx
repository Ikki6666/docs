可在 [GitHub](https://github.com/googleapis/langchain-google-memorystore-redis-python/) 上了解此包的更多信息。

## 基础用法

### 保存文档

使用 `MemorystoreDocumentSaver.add_documents(<documents>)` 保存 langchain documents。初始化 `MemorystoreDocumentSaver` 类时，需要提供 2 项信息：

1. `client` - 一个 `redis.Redis` client 对象。
1. `key_prefix` - 用于在 Redis 中存储 Documents 的 key 前缀。

Documents 会存储到带有 `key_prefix` 指定前缀的随机生成 key 中。你也可以在 `add_documents` 方法中指定 `ids`，从而指定 key 的后缀。

```python
import redis
from langchain_core.documents import Document
from langchain_google_memorystore_redis import MemorystoreDocumentSaver

test_docs = [
    Document(
        page_content="Apple Granny Smith 150 0.99 1",
        metadata={"fruit_id": 1},
    ),
    Document(
        page_content="Banana Cavendish 200 0.59 0",
        metadata={"fruit_id": 2},
    ),
    Document(
        page_content="Orange Navel 80 1.29 1",
        metadata={"fruit_id": 3},
    ),
]
doc_ids = [f"{i}" for i in range(len(test_docs))]

redis_client = redis.from_url(ENDPOINT)
saver = MemorystoreDocumentSaver(
    client=redis_client,
    key_prefix=KEY_PREFIX,
    content_field="page_content",
)
saver.add_documents(test_docs, ids=doc_ids)
```

### 加载文档

初始化一个 loader，用于加载 Memorystore for Redis instance 中带有特定前缀的所有文档。

使用 `MemorystoreDocumentLoader.load()` 或 `MemorystoreDocumentLoader.lazy_load()` 加载 langchain documents。`lazy_load` 返回一个 generator，只有在迭代时才会查询数据库。初始化 `MemorystoreDocumentLoader` 类时，需要提供：

1. `client` - 一个 `redis.Redis` client 对象。
1. `key_prefix` - 用于在 Redis 中存储 Documents 的 key 前缀。

```python
import redis
from langchain_google_memorystore_redis import MemorystoreDocumentLoader

redis_client = redis.from_url(ENDPOINT)
loader = MemorystoreDocumentLoader(
    client=redis_client,
    key_prefix=KEY_PREFIX,
    content_fields=set(["page_content"]),
)
for doc in loader.lazy_load():
    print("Loaded documents:", doc)
```

### 删除文档

使用 `MemorystoreDocumentSaver.delete()` 删除 Memorystore for Redis instance 中具有指定前缀的所有 key。如果你知道 key 后缀，也可以显式指定。

```python
docs = loader.load()
print("Documents before delete:", docs)

saver.delete(ids=[0])
print("Documents after delete:", loader.load())

saver.delete()
print("Documents after delete all:", loader.load())
```

## 高级用法

### 自定义 document page content 和 metadata

当你使用多个 content field 初始化 loader 时，加载出的 Documents 的 `page_content` 会包含一个 JSON 编码字符串，其顶层字段与 `content_fields` 中指定的字段一致。

如果指定了 `metadata_fields`，那么加载出的 Documents 的 `metadata` 只会包含这些顶层字段。如果 metadata 字段的某些值本身是 JSON 编码字符串，则会先解码，再写入 metadata。

```python
loader = MemorystoreDocumentLoader(
    client=redis_client,
    key_prefix=KEY_PREFIX,
    content_fields=set(["content_field_1", "content_field_2"]),
    metadata_fields=set(["title", "author"]),
)
```
