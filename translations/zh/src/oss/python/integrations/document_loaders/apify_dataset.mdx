> [Apify Dataset](https://docs.apify.com/platform/storage/dataset) 是一种可扩展、仅追加写入、按顺序访问的存储，专门用于保存结构化网页抓取结果，例如商品列表或 Google SERP，然后可将其导出为 JSON、CSV 或 Excel 等多种格式。Dataset 主要用于保存 [Apify Actors](https://apify.com/store) 的结果，这些 Actor 是用于多种网页抓取、爬取和数据提取场景的无服务器云程序。

这个 notebook 演示如何将 Apify dataset 加载到 LangChain 中。

## 前置条件

你需要在 Apify 平台上已经有一个现成的 dataset。本示例展示如何加载由 [Website Content Crawler](https://apify.com/apify/website-content-crawler) 生成的 dataset。

```python
pip install -qU langchain langchain-apify langchain-openai
```

首先，将 `ApifyDatasetLoader` 导入到你的代码中：

```python
from langchain_apify import ApifyDatasetLoader
from langchain_core.documents import Document
```

找到你的 [Apify API token](https://console.apify.com/account/integrations) 和 [OpenAI API key](https://platform.openai.com/account/api-keys)，并将它们初始化到环境变量中：

```python
import os

os.environ["APIFY_TOKEN"] = "your-apify-token"
os.environ["OPENAI_API_KEY"] = "your-openai-api-key"
```

## 定价

Apify Actors 的计费方式取决于你运行的 Actor。
许多 Actor 支持 [Pay-Per-Event (PPE) pricing](https://docs.apify.com/platform/actors/publishing/monetize/pay-per-event)，即你为 Actor 作者定义的显式事件付费（例如按 dataset item 计费）。对于需要清晰、按操作计费的 agent workload，这种方式会比较合适。

## 将 dataset item 映射为文档

接下来，定义一个函数，将 Apify dataset 的记录字段映射为 LangChain @[`Document`] 格式。

例如，如果你的 dataset item 结构如下：

```json
{
    "url": "https://apify.com",
    "text": "Apify is the best web scraping and automation platform."
}
```

下面代码中的映射函数会将其转换成 LangChain @[`Document`] 格式，以便后续和任意 LLM 一起使用（例如做问答）。

```python
loader = ApifyDatasetLoader(
    dataset_id="your-dataset-id",
    dataset_mapping_function=lambda dataset_item: Document(
        page_content=dataset_item["text"], metadata={"source": dataset_item["url"]}
    ),
)
```

```python
data = loader.load()
```

## 一个问答示例

在这个示例中，我们使用 dataset 中的数据来回答一个问题。

```python
from langchain.indexes import VectorstoreIndexCreator
from langchain_apify import ApifyWrapper
from langchain_core.documents import Document
from langchain_core.vectorstores import InMemoryVectorStore
from langchain_openai import ChatOpenAI
from langchain_openai.embeddings import OpenAIEmbeddings
```

```python
loader = ApifyDatasetLoader(
    dataset_id="your-dataset-id",
    dataset_mapping_function=lambda item: Document(
        page_content=item["text"] or "", metadata={"source": item["url"]}
    ),
)
```

```python
index = VectorstoreIndexCreator(
    vectorstore_cls=InMemoryVectorStore, embedding=OpenAIEmbeddings()
).from_loaders([loader])
```

```python
llm = ChatOpenAI(model="gpt-5-mini")
```

```python
query = "What is Apify?"
result = index.query_with_sources(query, llm=llm)
```

```python
print(result["answer"])
print(result["sources"])
```

```text
 Apify is a platform for developing, running, and sharing serverless cloud programs. It enables users to create web scraping and automation tools and publish them on the Apify platform.

https://docs.apify.com/platform/actors, https://docs.apify.com/platform/actors/running/actors-in-store, https://docs.apify.com/platform/security, https://docs.apify.com/platform/actors/examples
```

## 使用 Apify MCP server

不确定该用哪个 Actor，或者不知道它需要哪些参数？[Apify MCP (Model Context Protocol) server](https://mcp.apify.com) 可以帮助你发现可用 Actor、查看它们的输入 schema，并理解参数要求。

通过 HTTP 连接 Apify MCP server 时，请在请求头中包含你的 Apify token：

```text
Authorization: Bearer <APIFY_TOKEN>
```

更多信息请参见 [LangChain MCP documentation](/oss/langchain/mcp)。
