Document loader 提供了一个**标准接口**，用于把不同来源的数据（例如 Slack、Notion 或 Google Drive）读取到 LangChain 的 @[Document] 格式中。
这样无论数据来自哪里，都可以用一致的方式处理。

所有 document loader 都实现了 @[`BaseLoader`] 接口。

<Warning>
社区 document loader 由用户贡献，且未经验证。LangChain 不会审核或背书这些集成，请自行承担使用风险。
</Warning>

## 接口

每个 document loader 都可以定义自己的参数，但它们共享一套通用 API：

* `load()`：一次性加载全部文档。
* `lazy_load()`：惰性流式加载文档，适合大型数据集。

```python
from langchain_docling.loader import DoclingLoader

FILE_PATH = "https://arxiv.org/pdf/2408.09869"

loader = DoclingLoader(file_path=FILE_PATH)

# Load all documents
documents = loader.load()

# For large datasets, lazily load documents
for document in loader.lazy_load():
    print(document)
```
