本指南简要介绍如何开始使用 WRITER `PDFParser` [document loader](/oss/integrations/document_loaders/)。

WRITER 的 [PDF Parser](https://dev.writer.com/api-guides/api-reference/tool-api/pdf-parser#parse-pdf) 可以将 PDF 文档转换为文本或 Markdown 等其他格式。当你需要提取并处理 PDF 文件中的文本内容，以便后续分析或集成到工作流中时，这非常有用。在 `langchain-writer` 中，我们提供了将 WRITER 的 PDF Parser 作为 LangChain document parser 的用法。

<Warning>
**Deprecation notice**：parse PDF 工具已弃用，并将在 **December 22, 2025** 被移除。

**Migration path**：我们计划为 chat completions 引入一个预构建的 PDF parsing 工具，以提供类似功能。该工具的工作方式将类似于其他预构建工具。待其可用时，我们会提供更多详细信息。
</Warning>

## 设置

`PDFParser` 位于 `langchain-writer` 包中：

```python
pip install --quiet -U langchain-writer
```

### 凭证

注册 [WRITER AI Studio](https://app.writer.com/aistudio/signup?utm_campaign=devrel) 以生成 API key，你也可以参考这个 [Quickstart](https://dev.writer.com/api-guides/quickstart)。然后，设置 `WRITER_API_KEY` 环境变量：

```python
import getpass
import os

if not os.getenv("WRITER_API_KEY"):
    os.environ["WRITER_API_KEY"] = getpass.getpass("Enter your WRITER API key: ")
```

为获得最佳可观测性，设置 [LangSmith](https://smith.langchain.com) 也会很有帮助，但不是必需的。如果你想这样做，可以设置 `LANGSMITH_TRACING` 和 `LANGSMITH_API_KEY` 环境变量：

```python
os.environ["LANGSMITH_TRACING"] = "true"
# os.environ["LANGSMITH_API_KEY"] = getpass.getpass()
```

### 实例化

接下来，使用期望的输出格式来实例化一个 WRITER PDF Parser：

```python
from langchain_writer.pdf_parser import PDFParser

parser = PDFParser(format="markdown")
```

## 用法

PDF Parser 有两种使用方式，同步或异步。无论哪种方式，PDF Parser 都会返回一个 @[`Document`] 对象列表，其中每个对象都包含 PDF 文件某一页的解析内容。

### 同步用法

要同步调用 PDF Parser，请向 `parse` 方法传入一个引用你要解析的 PDF 文件的 `Blob` 对象：

```python
from langchain_core.documents.base import Blob

file = Blob.from_path("../example_data/layout-parser-paper.pdf")

parsed_pages = parser.parse(blob=file)
parsed_pages
```

### 异步用法

要异步调用 PDF Parser，请向 `aparse` 方法传入一个引用你要解析的 PDF 文件的 `Blob` 对象：

```python
parsed_pages_async = await parser.aparse(blob=file)
parsed_pages_async
```
