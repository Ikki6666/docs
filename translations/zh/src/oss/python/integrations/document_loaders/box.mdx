`langchain-box` 包提供了两种从 Box 为文件建立索引的方法：`BoxLoader` 和 `BoxBlobLoader`。`BoxLoader` 允许你摄取在 Box 中具有文本表示形式的文件文本内容。`BoxBlobLoader` 则允许你下载任意文档或图像文件的 blob，并交给你选择的 blob parser 进行处理。

本文介绍如何开始使用这两者。

## 概览

`BoxLoader` 类可以帮助你将 Box 中的非结构化内容转换为 LangChain 的 @[`Document`] 格式。你可以传入包含 Box 文件 ID 的 `List[str]`，或者传入表示 Box 文件夹 ID 的 `str`。

`BoxBlobLoader` 类可以帮助你将 Box 中的非结构化内容转换为 LangChain 的 `Blob` 格式。你可以传入包含 Box 文件 ID 的 `List[str]`、表示 Box 文件夹 ID 的 `str`、搜索查询，或 `BoxMetadataQuery`。

如果你是通过文件夹 ID 获取文件，也可以设置一个 `Bool`，让加载器递归获取该文件夹下的所有子文件夹。

<Info>
一个 Box 实例可能包含 PB 级文件，而一个文件夹也可能包含数百万个文件。选择要建立索引的文件夹时请谨慎。并且建议永远不要递归获取文件夹 0 下的所有文件。文件夹 ID 0 是你的根目录。
</Info>

`BoxLoader` 会跳过没有文本表示形式的文件，而 `BoxBlobLoader` 会为所有文档和图像文件返回 blob。

## 设置

要使用 Box 包，你需要准备以下内容：

* 一个 Box 账户。如果你当前不是 Box 客户，或者想在生产环境之外测试，可以使用 [free developer account](https://account.box.com/signup/n/developer#ty9l3)。
* [一个 Box app](https://developer.box.com/guides/getting-started/first-application/)。它需要在 [developer console](https://account.box.com/developers/console) 中配置；如果要使用 Box AI，则必须启用 `Manage AI` scope。你也需要在此选择认证方式。
* 该应用必须由 [administrator 启用](https://developer.box.com/guides/authorization/custom-app-approval/#manual-approval)。对于免费开发者账户，这通常就是创建该账户的人。

在这些示例中，我们会使用 [token authentication](https://developer.box.com/guides/authentication/tokens/developer-tokens)。它可以配合任意 [authentication method](https://developer.box.com/guides/authentication/) 使用，你只需要用对应方式拿到 token。如果你想了解如何在 `langchain-box` 中使用其他认证类型，请参阅 [Box provider](/oss/integrations/providers/box) 文档。

## 初始化

### 加载文件

如果你想加载文件，必须在实例化时提供文件 ID 的 `List`。

这需要 1 项信息：

* **box_file_ids** (`List[str]`) - Box 文件 ID 列表。

#### BoxLoader

```python
from langchain_box.document_loaders import BoxLoader

box_file_ids = ["1514555423624", "1514553902288"]

loader = BoxLoader(
    box_developer_token=box_developer_token,
    box_file_ids=box_file_ids,
    character_limit=10000,  # Optional. Defaults to no limit
)
```

#### BoxBlobLoader

```python
from langchain_box.blob_loaders import BoxBlobLoader

box_file_ids = ["1514555423624", "1514553902288"]

loader = BoxBlobLoader(
    box_developer_token=box_developer_token, box_file_ids=box_file_ids
)
```

### 从文件夹加载

如果你想从文件夹加载文件，必须在实例化时提供一个包含 Box 文件夹 ID 的 `str`。

这需要 1 项信息：

* **box_folder_id** (`str`) - 包含 Box 文件夹 ID 的字符串。

#### BoxLoader

```python
from langchain_box.document_loaders import BoxLoader

box_folder_id = "260932470532"

loader = BoxLoader(
    box_folder_id=box_folder_id,
    recursive=False,  # Optional. return entire tree, defaults to False
    character_limit=10000,  # Optional. Defaults to no limit
)
```

#### BoxBlobLoader

```python
from langchain_box.blob_loaders import BoxBlobLoader

box_folder_id = "260932470532"

loader = BoxBlobLoader(
    box_folder_id=box_folder_id,
    recursive=False,  # Optional. return entire tree, defaults to False
)
```

### 使用 BoxBlobLoader 搜索文件

如果你需要搜索文件，`BoxBlobLoader` 提供了两种方法。首先，你可以执行全文搜索，并用可选的搜索选项进一步缩小范围。

这需要 1 项信息：

* **query** (`str`) - 要执行的搜索查询字符串。

你也可以提供一个 `BoxSearchOptions` 对象来缩小搜索范围：

* **box_search_options** (`BoxSearchOptions`)

#### BoxBlobLoader 搜索

```python
from langchain_box.blob_loaders import BoxBlobLoader
from langchain_box.utilities import BoxSearchOptions, DocumentFiles, SearchTypeFilter

box_folder_id = "260932470532"

box_search_options = BoxSearchOptions(
    ancestor_folder_ids=[box_folder_id],
    search_type_filter=[SearchTypeFilter.FILE_CONTENT],
    created_date_range=["2023-01-01T00:00:00-07:00", "2024-08-01T00:00:00-07:00,"],
    file_extensions=[DocumentFiles.DOCX, DocumentFiles.PDF],
    k=200,
    size_range=[1, 1000000],
    updated_data_range=None,
)

loader = BoxBlobLoader(
    box_developer_token=box_developer_token,
    query="Victor",
    box_search_options=box_search_options,
)
```

你还可以基于 Box Metadata 搜索内容。如果你的 Box 实例使用了 Metadata，你可以搜索附加了特定 Metadata Template 且满足某些条件的文档，例如返回上季度创建、总金额大于或等于 500 美元的所有发票。

这需要 1 项信息：

* **query** (`str`) - 要执行的搜索查询字符串。

你也可以提供一个 `BoxSearchOptions` 对象来缩小搜索范围：

* **box_search_options** (`BoxSearchOptions`)

#### BoxBlobLoader metadata query

```python
from langchain_box.blob_loaders import BoxBlobLoader
from langchain_box.utilities import BoxMetadataQuery

query = BoxMetadataQuery(
    template_key="enterprise_1234.myTemplate",
    query="total >= :value",
    query_params={"value": 100},
    ancestor_folder_id="260932470532",
)

loader = BoxBlobLoader(box_metadata_query=query)
```

#### 仅适用于 BoxLoader

```python
page = []
for doc in loader.lazy_load():
    page.append(doc)
    if len(page) >= 10:
        # do some paged operation, e.g.
        # index.upsert(page)

        page = []
```

## 额外字段

所有 Box connector 都支持从 Box `FileFull` 对象中选择额外字段，并将其作为自定义 LangChain metadata 返回。每个对象都接受一个可选的 `List[str]` 参数 `extra_fields`，其中包含返回对象的 JSON key，例如 `extra_fields=["shared_link"]`。

connector 会将该字段加入集成正常运行所需的字段列表中，然后把结果加入返回的 @[`Document`] 或 `Blob` 的 metadata，例如 `"metadata" : { "source" : "source, "shared_link" : "shared_link" }`。如果某个文件没有该字段，则会返回空字符串，例如 `"shared_link" : ""`。
