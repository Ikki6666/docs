[AgentQL](https://www.agentql.com/) 的文档加载器可以通过 [AgentQL query](https://docs.agentql.com/agentql-query)，从任意网页中提取结构化数据。AgentQL 可跨多种语言和网页使用，并且随着时间推移和页面变化也不容易失效。

## 概览

`AgentQLLoader` 需要以下两个参数：

- `url`：你想提取数据的网页 URL。
- `query`：要执行的 AgentQL 查询。你可以在文档中了解[如何编写 AgentQL query](https://docs.agentql.com/agentql-query)，或在 [AgentQL Playground](https://dev.agentql.com/playground) 中实际测试。

以下参数是可选的：

- `api_key`：你的 AgentQL API key，来源于 [dev.agentql.com](https://dev.agentql.com)。**`Optional`。**
- `timeout`：请求超时前等待的秒数。**默认值为 `900`。**
- `is_stealth_mode_enabled`：是否启用实验性的反机器人规避策略。此功能未必在所有网站、所有时间都可用。启用后，数据提取可能需要更长时间。**默认值为 `False`。**
- `wait_for`：页面加载完成后，提取数据前等待的秒数。**默认值为 `0`。**
- `is_scroll_to_bottom_enabled`：提取数据前是否滚动到页面底部。**默认值为 `False`。**
- `mode`：`"standard"` 使用更深入的数据分析，而 `"fast"` 会以牺牲部分分析深度换取速度，对大多数场景已足够。[在这份指南中了解更多模式说明。](https://docs.agentql.com/accuracy/standard-mode) **默认值为 `"fast"`。**
- `is_screenshot_enabled`：提取数据前是否截屏。截图会以 Base64 字符串形式返回在 `metadata` 中。**默认值为 `False`。**

AgentQLLoader 基于 AgentQL 的 [REST API](https://docs.agentql.com/rest-api/api-reference) 实现。

## 设置

要使用 AgentQL Document Loader，你需要配置 `AGENTQL_API_KEY` 环境变量，或者使用 `api_key` 参数。你可以从我们的 [Dev Portal](https://dev.agentql.com) 获取 API key。

### 安装

安装 **langchain-agentql**。

```python
pip install -qU langchain-agentql
```

### 设置凭证

```python
import os

os.environ["AGENTQL_API_KEY"] = "YOUR_AGENTQL_API_KEY"
```

## 初始化

接下来实例化模型对象：

```python
from langchain_agentql.document_loaders import AgentQLLoader

loader = AgentQLLoader(
    url="https://www.agentql.com/blog",
    query="""
    {
        posts[] {
            title
            url
            date
            author
        }
    }
    """,
    is_scroll_to_bottom_enabled=True,
)
```

## 惰性加载

`AgentQLLoader` 当前一次只会加载一个 @[`Document`]。因此，`load()` 和 `lazy_load()` 的行为是一样的：

```python
pages = [doc for doc in loader.lazy_load()]
pages
```
