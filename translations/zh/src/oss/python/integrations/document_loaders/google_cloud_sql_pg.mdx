## 基础用法

### 设置 Cloud SQL 数据库变量

在 [Cloud SQL Instances page](https://console.cloud.google.com/sql/instances) 中找到数据库参数值。

```python
# @title Set Your Values Here { display-mode: "form" }
REGION = "us-central1"  # @param {type: "string"}
INSTANCE = "my-primary"  # @param {type: "string"}
DATABASE = "my-database"  # @param {type: "string"}
TABLE_NAME = "vector_store"  # @param {type: "string"}
```

### Cloud SQL engine

将 PostgreSQL 用作文档加载器时，前提之一是准备一个 `PostgresEngine` 对象。`PostgresEngine` 会为你的 Cloud SQL for PostgreSQL 数据库配置连接池，从而让应用能够成功建立连接，并遵循行业最佳实践。

使用 `PostgresEngine.from_instance()` 创建 `PostgresEngine` 时，只需要提供以下 4 项信息：

1. `project_id`：Cloud SQL instance 所在 Google Cloud Project 的 Project ID。
1. `region`：Cloud SQL instance 所在区域。
1. `instance`：Cloud SQL instance 名称。
1. `database`：要连接到的 Cloud SQL instance 中的数据库名称。

默认情况下，会使用 [IAM database authentication](https://cloud.google.com/sql/docs/postgres/iam-authentication) 作为数据库认证方式。该库会使用来自环境中 [Application Default Credentials (ADC)](https://cloud.google.com/docs/authentication/application-default-credentials) 对应的 IAM principal。

你也可以选择使用用户名和密码的 [built-in database authentication](https://cloud.google.com/sql/docs/postgres/users) 访问 Cloud SQL 数据库。只需向 `PostgresEngine.from_instance()` 额外传入可选的 `user` 和 `password` 参数：

* `user`：用于内置数据库认证和登录的数据库用户
* `password`：用于内置数据库认证和登录的数据库密码

**注意：** 本教程演示的是 async 接口。所有 async 方法都提供对应的 sync 方法。

```python
from langchain_google_cloud_sql_pg import PostgresEngine

engine = await PostgresEngine.afrom_instance(
    project_id=PROJECT_ID,
    region=REGION,
    instance=INSTANCE,
    database=DATABASE,
)
```

### 创建 PostgresLoader

```python
from langchain_google_cloud_sql_pg import PostgresLoader

# Creating a basic PostgreSQL object
loader = await PostgresLoader.create(engine, table_name=TABLE_NAME)
```

### 通过默认表加载文档

该加载器会从表中返回一个 Documents 列表，其中第一列用作 `page_content`，其余列全部作为 metadata。默认表的第一列是 `page_content`，第二列是 `metadata`（JSON）。每一行都会变成一个 document。请注意，如果你希望文档拥有 id，需要自行加入。

```python
from langchain_google_cloud_sql_pg import PostgresLoader

# Creating a basic PostgresLoader object
loader = await PostgresLoader.create(engine, table_name=TABLE_NAME)

docs = await loader.aload()
print(docs)
```

### 通过自定义表或 metadata、自定义 page content 列加载文档

```python
loader = await PostgresLoader.create(
    engine,
    table_name=TABLE_NAME,
    content_columns=["product_name"],  # Optional
    metadata_columns=["id"],  # Optional
)
docs = await loader.aload()
print(docs)
```

### 设置 page content 格式

该加载器会返回一个 Documents 列表，每行对应一个 document，并以指定字符串格式构造 page content，例如 text（空格拼接）、JSON、YAML、CSV 等。JSON 和 YAML 格式会包含表头，而 text 和 CSV 不会包含字段名。

```python
loader = await PostgresLoader.create(
    engine,
    table_name="products",
    content_columns=["product_name", "description"],
    format="YAML",
)
docs = await loader.aload()
print(docs)
```
