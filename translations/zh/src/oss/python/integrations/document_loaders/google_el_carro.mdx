> Google [El Carro Oracle Operator](https://github.com/GoogleCloudPlatform/elcarro-oracle-operator)
提供了一种方式，可在 Kubernetes 中运行 Oracle 数据库，并借助这一可移植、开源、社区驱动、无厂商锁定的容器编排系统进行管理。El Carro
提供了强大的声明式 API，可用于全面且一致的
配置与部署，以及实时运维和
监控。
你可以借助 El Carro LangChain 集成扩展 Oracle 数据库能力，
构建 AI 驱动的体验。

本指南介绍如何使用 El Carro LangChain 集成，通过
`ElCarroLoader` 和 `ElCarroDocumentSaver`
来[保存、加载和删除 langchain documents](/oss/integrations/document_loaders)。该集成适用于任意 Oracle 数据库，无论其运行位置在哪里。

可在 [GitHub](https://github.com/googleapis/langchain-google-el-carro-python/) 上了解此包的更多信息。

## 基础用法

### 设置 Oracle 数据库连接

请填写以下变量，提供你的 Oracle 数据库连接信息。

```python
# @title Set Your Values Here { display-mode: "form" }
HOST = "127.0.0.1"  # @param {type: "string"}
PORT = 3307  # @param {type: "integer"}
DATABASE = "my-database"  # @param {type: "string"}
TABLE_NAME = "message_store"  # @param {type: "string"}
USER = "my-user"  # @param {type: "string"}
PASSWORD = input("Please provide a password to be used for the database user: ")
```

如果你使用的是 El Carro，可以在
El Carro Kubernetes instance 的 status 中找到 hostname 和 port。
请使用你为 PDB 创建的用户密码。

输出示例：

```
kubectl get -w instances.oracle.db.anthosapis.com -n db
NAME   DB ENGINE   VERSION   EDITION      ENDPOINT      URL                DB NAMES   BACKUP ID   READYSTATUS   READYREASON        DBREADYSTATUS   DBREADYREASON

mydb   Oracle      18c       Express      mydb-svc.db   34.71.69.25:6021   ['pdbname']            TRUE          CreateComplete     True            CreateComplete
```

### ElCarroEngine 连接池

`ElCarroEngine` 会为你的 Oracle 数据库配置连接池，从而让应用能够成功建立连接，并遵循行业最佳实践。

```python
from langchain_google_el_carro import ElCarroEngine

elcarro_engine = ElCarroEngine.from_instance(
    db_host=HOST,
    db_port=PORT,
    db_name=DATABASE,
    db_user=USER,
    db_password=PASSWORD,
)
```

### 初始化表

通过 `elcarro_engine.init_document_table(<table_name>)`
初始化一个默认 schema 的表。表列如下：

- page_content（type: text）
- langchain_metadata（type: JSON）

```python
elcarro_engine.drop_document_table(TABLE_NAME)
elcarro_engine.init_document_table(
    table_name=TABLE_NAME,
)
```

### 保存文档

使用 `ElCarroDocumentSaver.add_documents(<documents>)`
保存 langchain documents。
初始化 `ElCarroDocumentSaver` 类时，需要提供 2 项信息：

1. `elcarro_engine` - 一个 `ElCarroEngine` engine 实例。
2. `table_name` - Oracle 数据库中用于存储
   langchain documents 的表名。

```python
from langchain_core.documents import Document
from langchain_google_el_carro import ElCarroDocumentSaver

doc = Document(
    page_content="Banana",
    metadata={"type": "fruit", "weight": 100, "organic": 1},
)

saver = ElCarroDocumentSaver(
    elcarro_engine=elcarro_engine,
    table_name=TABLE_NAME,
)
saver.add_documents([doc])
```

### 加载文档

使用 `ElCarroLoader.load()`
或 `ElCarroLoader.lazy_load()`
加载 langchain documents。
`lazy_load` 返回一个 generator，只有在迭代时才会查询数据库。
初始化 `ElCarroLoader` 类时，需要提供：

1. `elcarro_engine` - 一个 `ElCarroEngine` engine 实例。
2. `table_name` - Oracle 数据库中用于存储
   langchain documents 的表名。

```python
from langchain_google_el_carro import ElCarroLoader

loader = ElCarroLoader(elcarro_engine=elcarro_engine, table_name=TABLE_NAME)
docs = loader.lazy_load()
for doc in docs:
    print("Loaded documents:", doc)
```

### 通过查询加载文档

除了从表中加载文档，
你也可以选择从 SQL 查询生成的视图中加载文档。例如：

```python
from langchain_google_el_carro import ElCarroLoader

loader = ElCarroLoader(
    elcarro_engine=elcarro_engine,
    query=f"SELECT * FROM {TABLE_NAME} WHERE json_value(langchain_metadata, '$.organic') = '1'",
)
onedoc = loader.load()
print(onedoc)
```

由 SQL 查询生成的视图，其 schema 可能不同于默认表。
在这种情况下，ElCarroLoader 的行为与从非默认 schema 表加载时相同。请参阅
[Load documents with customized document page content & metadata](#load-documents-with-customized-document-page-content-and-metadata)
一节。

### 删除文档

使用 `ElCarroDocumentSaver.delete(<documents>)`
从 Oracle 表中删除一组 langchain documents。

对于默认 schema（`page_content`, `langchain_metadata`）的表，
删除条件如下：

当列表中存在某个 `document`，并满足以下条件时，对应 `row` 会被删除：

- `document.page_content` 等于 `row[page_content]`
- `document.metadata` 等于 `row[langchain_metadata]`

```python
docs = loader.load()
print("Documents before delete:", docs)
saver.delete(onedoc)
print("Documents after delete:", loader.load())
```

## 高级用法

### 使用自定义的 document page content 和 metadata 加载文档

首先准备一个非默认 schema 的示例表，并写入一些任意数据。

```python
import sqlalchemy

create_table_query = f"""CREATE TABLE {TABLE_NAME} (
    fruit_id NUMBER GENERATED BY DEFAULT AS IDENTITY (START WITH 1),
    fruit_name VARCHAR2(100) NOT NULL,
    variety VARCHAR2(50),
    quantity_in_stock NUMBER(10) NOT NULL,
    price_per_unit NUMBER(6,2) NOT NULL,
    organic NUMBER(3) NOT NULL
)"""
elcarro_engine.drop_document_table(TABLE_NAME)

with elcarro_engine.connect() as conn:
    conn.execute(sqlalchemy.text(create_table_query))
    conn.commit()
    conn.execute(
        sqlalchemy.text(
            f"""
            INSERT INTO {TABLE_NAME} (fruit_name, variety, quantity_in_stock, price_per_unit, organic)
            VALUES ('Apple', 'Granny Smith', 150, 0.99, 1)
            """
        )
    )
    conn.execute(
        sqlalchemy.text(
            f"""
            INSERT INTO {TABLE_NAME} (fruit_name, variety, quantity_in_stock, price_per_unit, organic)
            VALUES ('Banana', 'Cavendish', 200, 0.59, 0)
            """
        )
    )
    conn.execute(
        sqlalchemy.text(
            f"""
            INSERT INTO {TABLE_NAME} (fruit_name, variety, quantity_in_stock, price_per_unit, organic)
            VALUES ('Orange', 'Navel', 80, 1.29, 1)
            """
        )
    )
    conn.commit()
```

如果仍然使用 `ElCarroLoader` 的默认参数
从这个示例表加载 langchain documents，那么加载出的文档
会把表的第一列作为 `page_content`，而 `metadata`
则由其余所有列组成键值对。

```python
loader = ElCarroLoader(
    elcarro_engine=elcarro_engine,
    table_name=TABLE_NAME,
)
loaded_docs = loader.load()
print(f"Loaded Documents: [{loaded_docs}]")
```

你可以在初始化
`ElCarroLoader` 时，通过设置 `content_columns` 和 `metadata_columns`
指定要加载的内容和 metadata。

1. `content_columns`：要写入
   document `page_content` 的列。
2. `metadata_columns`：要写入
   document `metadata` 的列。

例如在这里，`content_columns` 中各列的值会被拼接成
一个以空格分隔的字符串，作为加载出的文档 `page_content`，
而 `metadata` 中只会包含 `metadata_columns`
指定的列对应键值对。

```python
loader = ElCarroLoader(
    elcarro_engine=elcarro_engine,
    table_name=TABLE_NAME,
    content_columns=[
        "variety",
        "quantity_in_stock",
        "price_per_unit",
        "organic",
    ],
    metadata_columns=["fruit_id", "fruit_name"],
)
loaded_docs = loader.load()
print(f"Loaded Documents: [{loaded_docs}]")
```

### 使用自定义 page content 和 metadata 保存文档

要将 langchain document 保存到带有自定义 metadata 字段的表中，
首先需要通过 `ElCarroEngine.init_document_table()` 创建这样一个表，并
指定所需的 `metadata_columns` 列表。在这个示例中，创建出的表将包含以下列：

- content（type: text）：用于存储水果描述。
- type（type VARCHAR2(200)）：用于存储水果类型。
- weight（type INT）：用于存储水果重量。
- extra_json_metadata（type: JSON）：用于存储其他
  水果 metadata。

你可以使用以下参数
配合 `elcarro_engine.init_document_table()` 创建该表：

1. `table_name`：Oracle 数据库中用于存储
   langchain documents 的表名。
2. `metadata_columns`：一个 `sqlalchemy.Column` 列表，用于表示
   所需的 metadata 列。
3. `content_column`：用于存储 langchain
   document `page_content` 的列名。默认值：`"page_content", "VARCHAR2(4000)"`
4. `metadata_json_column`：用于存储额外
   JSON `metadata` 的列名。
   默认值：`"langchain_metadata", "VARCHAR2(4000)"`。

```python
elcarro_engine.drop_document_table(TABLE_NAME)
elcarro_engine.init_document_table(
    table_name=TABLE_NAME,
    metadata_columns=[
        sqlalchemy.Column("type", sqlalchemy.dialects.oracle.VARCHAR2(200)),
        sqlalchemy.Column("weight", sqlalchemy.INT),
    ],
    content_column="content",
    metadata_json_column="extra_json_metadata",
)
```

使用 `ElCarroDocumentSaver.add_documents(<documents>)` 保存文档。正如这个示例所示：

- `document.page_content` 会写入 `content` 列。
- `document.metadata.type` 会写入 `type` 列。
- `document.metadata.weight` 会写入 `weight` 列。
- `document.metadata.organic` 会以 JSON 格式写入 `extra_json_metadata` 列。

```python
doc = Document(
    page_content="Banana",
    metadata={"type": "fruit", "weight": 100, "organic": 1},
)

print(f"Original Document: [{doc}]")

saver = ElCarroDocumentSaver(
    elcarro_engine=elcarro_engine,
    table_name=TABLE_NAME,
    content_column="content",
    metadata_json_column="extra_json_metadata",
)
saver.add_documents([doc])

loader = ElCarroLoader(
    elcarro_engine=elcarro_engine,
    table_name=TABLE_NAME,
    content_columns=["content"],
    metadata_columns=[
        "type",
        "weight",
    ],
    metadata_json_column="extra_json_metadata",
)

loaded_docs = loader.load()
print(f"Loaded Document: [{loaded_docs[0]}]")
```

### 使用自定义 page content 和 metadata 删除文档

我们也可以通过 `ElCarroDocumentSaver.delete(<documents>)`
从带有自定义 metadata 列的表中删除文档。删除条件如下：

当列表中存在某个 `document`，并满足以下条件时，对应 `row` 会被删除：

- `document.page_content` 等于 `row[page_content]`
- 对于 `document.metadata` 中的每个 metadata 字段 `k`
  - `document.metadata[k]` 等于 `row[k]`，或 `document.metadata[k]`
      等于 `row[langchain_metadata][k]`
- `row` 中不存在额外 metadata 字段，
  而这些字段不在 `document.metadata` 中。

```python
loader = ElCarroLoader(elcarro_engine=elcarro_engine, table_name=TABLE_NAME)
saver.delete(loader.load())
print(f"Documents left: {len(loader.load())}")
```
