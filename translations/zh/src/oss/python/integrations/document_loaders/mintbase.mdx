本文档旨在提供一种方式，用于测试 LangChain 针对 Near Blockchain 的 Document Loader 功能。

当前该 Loader 支持：

* 将 NFT Smart Contracts（NEP-171 和 NEP-177）中的 NFT 作为 Document 加载
* Near Mainnnet、Near Testnet（默认是 mainnet）
* Mintbase 的 Graph API

如果社区认为这个 loader 有价值，它还可以继续扩展。具体来说：

* 可以添加额外的 API（例如，与交易相关的 API）

这个 Document Loader 需要：

* 一个免费的 [Mintbase API Key](https://docs.mintbase.xyz/dev/mintbase-graph/)

输出格式如下：

* pageContent= 单个 NFT
* metadata=\{'source': 'nft.yearofchef.near', 'blockchain': 'mainnet', 'tokenId': '1846'\}

## 将 NFT 加载到文档加载器中

```python
# get MINTBASE_API_KEY from https://docs.mintbase.xyz/dev/mintbase-graph/

mintbaseApiKey = "..."
```

### 选项 1：Ethereum mainnet（默认 BlockchainType）

```python
from MintbaseLoader import MintbaseDocumentLoader

contractAddress = "nft.yearofchef.near"  # Year of chef contract address


blockchainLoader = MintbaseDocumentLoader(
    contract_address=contractAddress, blockchain_type="mainnet", api_key="omni-site"
)

nfts = blockchainLoader.load()

print(nfts[:1])

for doc in blockchainLoader.lazy_load():
    print()
    print(type(doc))
    print(doc)
```
