[Browserbase](https://browserbase.com) 是一个开发者平台，用于可靠地运行、管理和监控无头浏览器。

用以下能力增强 AI 数据检索：

- [Serverless Infrastructure](https://docs.browserbase.com/under-the-hood) 提供可靠的浏览器，用于从复杂 UI 中提取数据
- [Stealth Mode](https://docs.browserbase.com/features/stealth-mode) 提供内置指纹伪装策略和自动验证码求解
- [Session Debugger](https://docs.browserbase.com/features/sessions) 用于通过网络时间线和日志检查 Browser Session
- [Live Debug](https://docs.browserbase.com/guides/session-debug-connection/browser-remote-control) 用于快速调试自动化流程

## 安装和设置

- 从 [browserbase.com](https://browserbase.com) 获取 API key 和 Project ID，并将它们设置为环境变量（`BROWSERBASE_API_KEY`、`BROWSERBASE_PROJECT_ID`）。
- 安装 [Browserbase SDK](https://github.com/browserbase/python-sdk)：

```bash
pip install browserbase
```

## 加载文档

使用 `BrowserbaseLoader` 将网页加载到 LangChain 中。省略参数时，加载器会从环境中读取 `BROWSERBASE_API_KEY` 和 `BROWSERBASE_PROJECT_ID`。将 `text_content=True` 设置为仅返回文本内容，而不是完整 HTML。

<LangchainCommunityUnmaintained />

```python
from langchain_community.document_loaders import BrowserbaseLoader

loader = BrowserbaseLoader(
    urls=["https://example.com"],
    text_content=False,
)

docs = loader.load()
print(docs[0].page_content[:61])
```

### 加载器选项

- `urls` 必填。要抓取的 URL 列表。
- `text_content` 仅检索文本内容。默认值为 `False`。
- `api_key` Browserbase API key。默认值为 `BROWSERBASE_API_KEY` 环境变量。
- `project_id` Browserbase Project ID。默认值为 `BROWSERBASE_PROJECT_ID` 环境变量。
- `session_id` 可选。提供现有 Session ID。
- `proxy` 可选。启用或禁用代理。
