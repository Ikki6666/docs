>[Outline](https://www.getoutline.com/) 是一个开源协作知识库平台，专为团队信息共享而设计。

本文档展示如何从你的 Outline collections 中获取 langchain Documents。

## 概览

[Outline Document Loader](https://github.com/10Pines/langchain-outline) 可用于将 Outline collections 加载为 LangChain Documents，以便集成到 Retrieval-Augmented Generation (RAG) 工作流中。

本示例演示了：

* 设置一个 Document Loader，从 Outline 实例中加载所有文档。

### 设置

开始之前，请确保你已经设置以下环境变量：

* OUTLINE_API_KEY：用于对你的 Outline 实例进行身份验证的 API key（[www.getoutline.com/developers#section/Authentication](https://www.getoutline.com/developers#section/Authentication)）。
* OUTLINE_INSTANCE_URL：你的 Outline 实例 URL，包含协议。

```python
import os

os.environ["OUTLINE_API_KEY"] = "ol_api_xyz123"
os.environ["OUTLINE_INSTANCE_URL"] = "https://app.getoutline.com"
```

## 初始化

要初始化 OutlineLoader，你需要以下参数：

* outline_base_url：你的 outline 实例 URL，或者从环境变量中读取。
* outline_api_key：用于对 Outline 实例进行身份验证的 API key，或者从环境变量中读取。
* outline_collection_id_list：要检索的 collection id 列表。如果为 None，则检索全部。
* page_size：由于 Outline API 使用分页结果，你可以配置每次 API 请求要检索多少条结果（文档）。如果未指定，则使用默认值。

## 实例化

```python
# Option 1: Using environment variables (ensure they are set)
from langchain_outline.document_loaders.outline import OutlineLoader

loader = OutlineLoader()

# Option 2: Passing parameters directly
loader = OutlineLoader(
    outline_base_url="YOUR_OUTLINE_URL", outline_api_key="YOUR_API_KEY"
)
```

## 加载

加载并返回 Outline 实例中所有可用文档：

```python
loader.load()
```

## 惰性加载

`lazy_load` 方法允许你迭代式地从 Outline collection 中加载文档，在每条文档被获取时逐个产出：

```python
loader.lazy_load()
```
