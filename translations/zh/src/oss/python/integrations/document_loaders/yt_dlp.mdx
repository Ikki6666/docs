基于 `yt-dlp` 库的 Youtube 加载器。

这个包为 Youtube 实现了一个[文档加载器](/oss/integrations/document_loaders/)。与 `langchain-community` 中依赖 `pytube` 的 [YoutubeLoader](https://reference.langchain.com/python/langchain-community/document_loaders/youtube/YoutubeLoader) 不同，`YoutubeLoaderDL` 可以获取 YouTube metadata。`langchain-yt-dlp` 基于稳健的 `yt-dlp` 库，提供了一个更可靠、功能更丰富的 YouTube 文档加载器。

## 概览

### 集成详情

| Class | Package | Local | Serializable | JS Support |
| :--- | :--- | :---: | :---: | :---: |
| `YoutubeLoader` | langchain-yt-dlp | ✅ | ✅ | ❌ |

## 设置

### 安装

```bash
pip install langchain-yt-dlp
```

### 初始化

```python
from langchain_yt_dlp.youtube_loader import YoutubeLoaderDL

# Basic transcript loading
loader = YoutubeLoaderDL.from_youtube_url(
    "https://www.youtube.com/watch?v=dQw4w9WgXcQ", add_video_info=True
)
```

### 加载

```python
documents = loader.load()
```

```python
documents[0].metadata
```
