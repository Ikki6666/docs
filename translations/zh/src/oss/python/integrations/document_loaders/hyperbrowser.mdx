[Hyperbrowser](https://hyperbrowser.ai) 是一个用于运行和扩展无头浏览器的平台。它可以让你大规模启动和管理浏览器会话，并为各种网页抓取需求提供易于使用的方案，例如抓取单个页面或爬取整个站点。

主要特性：

- 即时扩展性：几秒内即可启动数百个浏览器会话，无需为基础设施头疼
- 简单集成：可与 Puppeteer、Playwright 等常用工具无缝配合
- 强大 API：提供易用 API，可抓取或爬取任意站点，以及更多能力
- 绕过反爬措施：内置 stealth mode、广告拦截、自动 CAPTCHA 求解和 rotating proxies

本指南快速介绍如何开始使用 `HyperbrowserLoader` [document loader](https://python.langchain.com/docs/concepts/#document-loaders)。

如需了解 Hyperbrowser 的更多信息，请访问 [Hyperbrowser website](https://hyperbrowser.ai)。如果你想查看文档，可以访问 [Hyperbrowser docs](https://docs.hyperbrowser.ai)。

## 设置

要使用 Hyperbrowser document loader，你需要安装 `langchain-hyperbrowser` 集成包，创建 Hyperbrowser 账户并获取 API key。

### 凭证

前往 [Hyperbrowser](https://app.hyperbrowser.ai/) 注册并生成 API key。完成后，设置 `HYPERBROWSER_API_KEY` 环境变量：

### 安装

安装 **langchain-hyperbrowser**。

```python
pip install -qU langchain-hyperbrowser
```

## 初始化

现在可以实例化模型对象并加载文档：

```python
from langchain_hyperbrowser import HyperbrowserLoader

loader = HyperbrowserLoader(
    urls="https://example.com",
    api_key="YOUR_API_KEY",
)
```

```python
    page.append(doc)

```

## 高级用法

你可以指定 loader 要执行的操作。默认操作是 `scrape`。对于 `scrape`，你可以提供单个 URL 或 URL 列表。对于 `crawl`，你只能提供单个 URL。`crawl` 会爬取传入页面及其子页面，并为每个页面返回一个 document。

```python
loader = HyperbrowserLoader(
    urls="https://hyperbrowser.ai", api_key="YOUR_API_KEY", operation="crawl"
)
```

你也可以通过 `params` 参数为 loader 传入可选参数。有关支持参数的更多信息，请访问 [docs.hyperbrowser.ai/reference/sdks/python/scrape#start-scrape-job-and-wait](https://docs.hyperbrowser.ai/reference/sdks/python/scrape#start-scrape-job-and-wait) 或 [docs.hyperbrowser.ai/reference/sdks/python/crawl#start-crawl-job-and-wait](https://docs.hyperbrowser.ai/reference/sdks/python/crawl#start-crawl-job-and-wait)。

```python
loader = HyperbrowserLoader(
    urls="https://example.com",
    api_key="YOUR_API_KEY",
    operation="scrape",
    params={"scrape_options": {"include_tags": ["h1", "h2", "p"]}},
)
```
