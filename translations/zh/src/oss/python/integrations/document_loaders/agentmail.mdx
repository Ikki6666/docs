---
title: "AgentMail"
description: "将 AgentMail 收件箱中的消息加载为 LangChain Documents。"
---

`AgentMailLoader` 会把来自 [AgentMail](https://agentmail.to) 收件箱的消息流式读取为 LangChain `Document`，每条消息对应一个文档，纯文本正文放在 `page_content` 中，发送者 / 主题 / labels / thread / attachment metadata 放在 `metadata` 中。它适合用于把收件箱索引到向量存储中，以便对邮件做 RAG。

## 概览

| Class | Package |
|:------|:--------|
| `AgentMailLoader` | [`langchain-agentmail`](https://pypi.org/project/langchain-agentmail/) |

## 设置

安装包：

```bash
pip install -qU langchain-agentmail
```

设置你的 AgentMail API key，可在 [agentmail.to](https://agentmail.to) 获取：

```python
import getpass
import os

if not os.environ.get("AGENTMAIL_API_KEY"):
    os.environ["AGENTMAIL_API_KEY"] = getpass.getpass("AgentMail API key:\n")
```

## 实例化

```python
from langchain_agentmail import AgentMailLoader

loader = AgentMailLoader(
    inbox_id="ib_abc123",
    labels=["inbox"],  # optional — filter messages by label
    limit=100,         # optional — cap the number of messages loaded
)
```

## 加载

```python
docs = loader.load()
print(docs[0].page_content[:200])
print(docs[0].metadata)
```

每个 `Document` 都包含以下 metadata 键（如果存在）：

- `inbox_id`, `message_id`, `thread_id`
- `from`, `to`, `cc`, `subject`, `labels`, `timestamp`
- `has_attachments`, `attachments`：一个 `{attachment_id, filename, content_type, size}` 列表

要下载附件字节流，请将这个 loader 与 toolkit 中的 `AgentMailGetAttachmentTool` 搭配使用，它会返回一个预签名下载 URL。

## 惰性加载

对于较大的收件箱，你可以逐条流式读取文档，而不是一次性物化完整列表：

```python
for doc in loader.lazy_load():
    print(doc.metadata["subject"])
```

## 索引到向量存储

```python
from langchain_core.vectorstores import InMemoryVectorStore
from langchain_openai import OpenAIEmbeddings

docs = AgentMailLoader(inbox_id="ib_abc123", limit=200).load()

store = InMemoryVectorStore.from_documents(docs, OpenAIEmbeddings())
retriever = store.as_retriever(search_kwargs={"k": 5})

retriever.invoke("Q3 invoice from acme")
```
