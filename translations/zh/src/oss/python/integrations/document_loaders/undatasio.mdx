本 notebook 快速介绍如何开始使用 __UnDatasIO document loader__。UnDatasIO 可以高效加载并解析多种文档格式，包括 PDF、PNG、JPG、JPEG 和 JFIF，并提供 document lazy loading 与原生 async 支持，所有能力都通过 UnDatasIO 的安全云 API 提供。这些能力使得处理后的数据能够直接用于 RAG 等生成式 AI 工作流。

如需了解全部特性与配置，请参阅官方 API reference。

## 概览

| :---: | :---: | :---: |

## 设置

### 凭证

UnDatasIO 需要 API token。
请前往 [undatas.io](https://undatas.io) 生成一个免费 token，并在下面的单元格中设置：

```python
import getpass
import os

if "UNDATASIO_TOKEN" not in os.environ:
    os.environ["UNDATASIO_TOKEN"] = getpass.getpass(
        "Enter your UnDatasIO API token: "
    )
```

### 安装

#### 常规安装

### 初始化

__UnDatasIOLoader__ 支持通过 UnDatasIO 云 API 进行单文件上传与解析。

```python
from langchain_undatasio import UnDatasIOLoader

loader = UnDatasIOLoader(
    token=os.environ["UNDATASIO_TOKEN"],
    file_path="demo.pdf"
)
```

### 加载

docs = loader.load()

### 惰性加载

__UnDatasIOLoader__ 支持惰性加载，可用于节省内存的迭代处理。

```python
pages = []
for doc in loader.lazy_load():
    pages.append(doc)

pages[0]
```
