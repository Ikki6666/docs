[PaddleOCR](https://www.paddleocr.com) 是由百度开发的强大且轻量的 OCR 工具包，可将图像和 PDF 与 LLM 连接起来。它支持 100 多种语言，并可将文档内容转换为结构化、适合 AI 使用的数据。

这个集成通过 `PaddleOCRVLLoader` document loader 提供 PaddleOCR 的大模型文档解析能力。

## 概览

### 集成详情

| Class | Package | Local | Serializable | JS support|
| :--- | :--- | :---: | :---: |  :---: |
| `PaddleOCRVLLoader` | `langchain-paddleocr` | ✅ | ❌ | ❌ |

### Loader 特性

| Source | Document Lazy Loading | Native Async Support
| :---: | :---: | :---: |
| `PaddleOCRVLLoader` | ✅ | ❌ |

`PaddleOCRVLLoader` 可以让你：

- 使用百度 PaddleOCR-VL 系列模型（例如 PaddleOCR-VL、PaddleOCR-VL-1.5）从 PDF 和图像文件中提取文本与版面信息
- 处理本地文件或远程 URL 中的文档

## 前置要求

要使用 PaddleOCR-VL loader，你需要：

1. **API Access**：可以访问 PaddleOCR-VL API endpoint
2. **Authentication**：用于 API 的 access token（可直接传入，或通过 `PADDLEOCR_ACCESS_TOKEN` 环境变量提供）

API URL 和 access token 都可以在 [PaddleOCR official website](https://www.paddleocr.com) 上获取。只需点击 **API** 按钮，并从那里提供的 API 调用示例中复制 URL 和 token。

## 设置

```python
pip install langchain-paddleocr
```

## 初始化

基础初始化需要 API endpoint URL 和文件路径：

```python
from langchain_paddleocr import PaddleOCRVLLoader
from pydantic import SecretStr

loader = PaddleOCRVLLoader(
    file_path="path/to/document.pdf",
    api_url="your-api-endpoint",
    access_token=SecretStr("your-access-token")  # Optional if using environment variable
)
```

如果通过环境变量进行认证：

```bash
export PADDLEOCR_ACCESS_TOKEN="your-access-token"
```

随后可以在不传 `access_token` 参数的情况下初始化：

```python
loader = PaddleOCRVLLoader(
    file_path="path/to/document.pdf",
    api_url="your-api-endpoint"
)
```

## 基础用法

### 加载文档

```python
# Load a single document
loader = PaddleOCRVLLoader(
    file_path="https://arxiv.org/pdf/2408.09869",
    api_url="your-api-endpoint"
)
docs = loader.load()

# Inspect the results
for doc in docs[:2]:
    print(f"Content: {doc.page_content[:200]}...")
    print(f"Source: {doc.metadata['source']}")
    print("---")
```

### 处理多种文件类型

loader 会根据扩展名自动识别文件类型：

```python
# Mixed file types - auto-detected
files = [
    "document.pdf",      # PDF file
    "image.jpg",         # Image file
    "https://example.com/report.pdf"  # Remote PDF
]

loader = PaddleOCRVLLoader(file_path=files, api_url="your-api-endpoint")
```

支持的图像格式：`.jpg`、`.jpeg`、`.png`、`.bmp`、`.tiff`、`.tif`、`.webp`
支持的文档格式：`.pdf`

## 高级特性

### 访问原始 API 响应

loader 会将完整的 API 响应包含在 document metadata 中：

```python
docs = loader.load()
first_doc = docs[0]

# Access raw API response for advanced processing
raw_response = first_doc.metadata["paddleocr_vl_raw_response"]
print(f"Layout results: {len(raw_response['result']['layoutParsingResults'])}")
```

### 错误处理

loader 提供了详细错误信息，便于排查问题：

```python
try:
    docs = loader.load()
except ValueError as e:
    print(f"Processing failed: {e}")
    # Common issues: invalid API endpoint, authentication errors, unsupported file types
```

## 最佳实践

### 错误处理

- **Network Timeouts**：为大文档设置合适的 `timeout` 参数
- **Authentication**：使用环境变量安全管理 token
- **File Validation**：在处理前验证文件是否可访问

## 故障排查

### 常见问题

1. **Authentication Errors**：确认已设置 `PADDLEOCR_ACCESS_TOKEN`，或已提供 `access_token`
2. **File Type Errors**：确认文件扩展名和可访问性是否正确
3. **API Connection Issues**：检查 endpoint URL 和网络连通性

### 调试模式

如需详细调试，可查看原始 API 响应：

```python
docs = loader.load()
if docs:
    raw_response = docs[0].metadata.get("paddleocr_vl_raw_response")
    print("API Response structure:", raw_response.keys())
```
