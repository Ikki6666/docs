本 notebook 介绍如何使用 Unstructured [document loader](/oss/integrations/document_loaders) 加载多种类型的文件。`Unstructured` 当前支持加载文本文件、PowerPoint、HTML、PDF、图片等。

请参阅 [Unstructured](/oss/integrations/providers/unstructured)，了解更多关于在本地配置 Unstructured 的说明，包括所需系统依赖的安装方式。

## 设置

### 凭证

默认情况下，`langchain-unstructured` 安装的是一个更轻量的版本，它要求将 partitioning 逻辑卸载到 Unstructured API，因此需要 API key。如果你使用本地安装，则不需要 API key。要获取 API key，请前往 [this site](https://unstructured.io) 生成一个 API key，然后在下面的单元格中设置：

```python
import getpass
import os

if "UNSTRUCTURED_API_KEY" not in os.environ:
    os.environ["UNSTRUCTURED_API_KEY"] = getpass.getpass(
        "Enter your Unstructured API key: "
    )
```

### 安装

#### 常规安装

运行本 notebook 剩余部分需要以下包。

```python
# Install package, compatible with API partitioning
pip install -qU langchain-unstructured unstructured-client unstructured "unstructured[pdf]" python-magic
```

#### 本地安装

如果你希望在本地运行 partitioning 逻辑，则需要安装一组系统依赖，具体请参阅 [Unstructured documentation here](https://docs.unstructured.io/open-source/installation/full-installation)。

例如，在 Mac 上可以这样安装所需依赖：

```bash
# base dependencies
brew install libmagic poppler tesseract

# If parsing xml / html documents:
brew install libxml2 libxslt
```

本地运行还需要安装以下 `pip` 依赖：

```bash
pip install "langchain-unstructured[local]"
```

## 初始化

`UnstructuredLoader` 支持从多种不同文件类型加载内容。若要完整了解 `unstructured` 包，请参阅其 [documentation](https://docs.unstructured.io/open-source/introduction/overview)/。在本示例中，我们展示了如何同时加载文本文件和 PDF 文件。

```python
from langchain_unstructured import UnstructuredLoader

file_paths = [
    "./example_data/layout-parser-paper.pdf",
    "./example_data/state_of_the_union.txt",
]


loader = UnstructuredLoader(file_paths)
```

## 后处理

如果你需要在提取完成后，对 `unstructured` elements 做后处理，可以在实例化 `UnstructuredLoader` 时，通过 `post_processors` kwarg 传入一个 `str` -> `str` 函数列表。这个机制同样适用于其他 Unstructured loaders。下面是一个示例。

```python
from langchain_unstructured import UnstructuredLoader
from unstructured.cleaners.core import clean_extra_whitespace

loader = UnstructuredLoader(
    "./example_data/layout-parser-paper.pdf",
    post_processors=[clean_extra_whitespace],
)

docs = loader.load()
```

## Unstructured API

如果你希望用更小的安装体积快速开始，并获得最新的 partitioning 能力，可以执行 `pip install
unstructured-client` 和 `pip install langchain-unstructured`。有关
`UnstructuredLoader` 的更多信息，请参阅
[Unstructured provider page](https://python.langchain.com/v0.1/docs/integrations/document_loaders/unstructured_file/)。

当你传入 `api_key` 并设置 `partition_via_api=True` 时，
loader 会使用托管的 Unstructured serverless API 来处理文档。
你可以 [生成一个免费 Unstructured API key](https://unstructured.io/api-key/)。

如果你想自托管 Unstructured API 或在本地运行它，
可以参阅 [Docker image instructions for self-hosting the Unstructured API](https://github.com/Unstructured-IO/unstructured-api#dizzy-instructions-for-using-the-docker-image)。

```python
from langchain_unstructured import UnstructuredLoader

loader = UnstructuredLoader(
    file_path="example_data/fake.docx",
    api_key=os.getenv("UNSTRUCTURED_API_KEY"),
    partition_via_api=True,
)

docs = loader.load()
docs[0]
```

### Unstructured SDK client

通过 Unstructured API 进行 partitioning 依赖于 [Unstructured SDK
Client](https://docs.unstructured.io/api-reference/api-services/accessing-unstructured-api)。

如果你希望自定义 client，则需要向 `UnstructuredLoader` 传入一个 `UnstructuredClient` 实例。下面的示例展示了如何自定义 client，例如使用你自己的 `requests.Session()`、传入替代的 `server_url`，以及自定义 `RetryConfig` 对象。若要进一步了解 client 可以如何自定义，或者 sdk client 接受哪些附加参数，请参阅 [Unstructured Python SDK](https://docs.unstructured.io/api-reference/api-services/sdk-python) 文档，以及 [API Parameters](https://docs.unstructured.io/api-reference/api-services/api-parameters) 文档中的 client 部分。请注意，所有 API Parameters 都应该传给 `UnstructuredLoader`。

<div class="alert alert-block alert-warning"><b>Warning:</b> The example below may not use the latest version of the UnstructuredClient and there could be breaking changes in future releases. For the latest examples, refer to the <a href="https://docs.unstructured.io/api-reference/api-services/sdk-python">Unstructured Python SDK</a> docs.</div>

```python
import requests
from langchain_unstructured import UnstructuredLoader
from unstructured_client import UnstructuredClient
from unstructured_client.utils import BackoffStrategy, RetryConfig

client = UnstructuredClient(
        api_key_auth=os.getenv(
        "UNSTRUCTURED_API_KEY"
    ),  # Note: the client API param is "api_key_auth" instead of "api_key"
        client=requests.Session(),  # Define your own requests session
        server_url="https://api.unstructuredapp.io/general/v0/general",  # Define your own api url
        retry_config=RetryConfig(
                strategy="backoff",
                retry_connection_errors=True,
                backoff=BackoffStrategy(
                        initial_interval=500,
                        max_interval=60000,
                        exponent=1.5,
                        max_elapsed_time=900000,
        ),
    ),  # Define your own retry config
)

loader = UnstructuredLoader(
    "./example_data/layout-parser-paper.pdf",
        partition_via_api=True,
        client=client,
        split_pdf_page=True,
        split_pdf_page_range=[1, 10],
)

docs = loader.load()

print(docs[0].metadata["filename"], ": ", docs[0].page_content[:100])
```

## Chunking

`UnstructuredLoader` 不支持像旧版
`UnstructuredFileLoader` 那样通过 `mode` 参数来对文本进行分组。它支持的是 “chunking”。Unstructured 中的 chunking 与你可能熟悉的其他 chunking 机制不同，后者通常基于纯文本特征来形成 chunks，例如 `"\n\n"` 或 `"\n"` 这样的字符序列，用于指示段落边界或列表项边界。而在 Unstructured 中，所有文档会先基于对具体文档格式的理解，被切分成语义单元（document elements），只有当单个 element 超过目标最大 chunk 大小时，才会退回到文本切分。总体来说，chunking 会尽可能将相邻 elements 组合成尽可能大的 chunks，但又不超过最大 chunk 大小。chunking 产生的是由 CompositeElement、Table 或 TableChunk 元素组成的序列。每一个 “chunk” 都是这三种类型之一的实例。

更多 chunking 选项细节可参阅这个 [page](https://docs.unstructured.io/open-source/core-functionality/chunking)。如果你想复现 `mode="single"` 的行为，可以设置
`chunking_strategy="basic"`、`max_characters=<some-really-big-number>` 和 `include_orig_elements=False`。

```python
from langchain_unstructured import UnstructuredLoader

loader = UnstructuredLoader(
    "./example_data/layout-parser-paper.pdf",
    chunking_strategy="basic",
    max_characters=1000000,
    include_orig_elements=False,
)

docs = loader.load()

print("Number of LangChain documents:", len(docs))
print("Length of text in the document:", len(docs[0].page_content))
```

```text
Number of LangChain documents: 1
Length of text in the document: 42772
```

## 加载网页

当在本地运行时，`UnstructuredLoader` 接受 `web_url` kwarg，并会将其传给底层 Unstructured [partition](https://docs.unstructured.io/open-source/core-functionality/partitioning) 的 `url` 参数。这样就可以解析远程托管的文档，例如 HTML 网页。

用法示例：

```python
from langchain_unstructured import UnstructuredLoader

loader = UnstructuredLoader(web_url="https://www.example.com")
docs = loader.load()

for doc in docs:
    print(f"{doc}\n")
```
