可在 [GitHub](https://github.com/googleapis/langchain-google-datastore-python/) 上了解此包的更多信息。

## 基础用法

### 保存文档

使用 `DatastoreSaver.upsert_documents(<documents>)` 保存 langchain documents。默认情况下，它会尝试从 Document metadata 中的 `key` 提取 entity key。

```python
from langchain_core.documents import Document
from langchain_google_datastore import DatastoreSaver

saver = DatastoreSaver()

data = [Document(page_content="Hello, World!")]
saver.upsert_documents(data)
```

#### 保存不带 key 的文档

如果指定了 `kind`，文档会使用自动生成的 id 存储。

```python
saver = DatastoreSaver("MyKind")

saver.upsert_documents(data)
```

### 通过 kind 加载文档

使用 `DatastoreLoader.load()` 或 `DatastoreLoader.lazy_load()` 加载 langchain documents。`lazy_load` 返回一个 generator，只有在迭代时才会查询数据库。初始化 `DatastoreLoader` 类时，需要提供：

1. `source` - 要加载文档的数据源。它可以是 Query 实例，或要读取的 Datastore kind 名称。

```python
from langchain_google_datastore import DatastoreLoader

loader = DatastoreLoader("MyKind")
data = loader.load()
```

### 通过 query 加载文档

除了从 kind 加载文档，你也可以选择从 query 加载文档。例如：

```python
from google.cloud import datastore

client = datastore.Client(database="non-default-db", namespace="custom_namespace")
query_load = client.query(kind="MyKind")
query_load.add_filter("region", "=", "west_coast")

loader_document = DatastoreLoader(query_load)

data = loader_document.load()
```

### 删除文档

使用 `DatastoreSaver.delete_documents(<documents>)` 从 Datastore 中删除一组 langchain documents。

```python
saver = DatastoreSaver()

saver.delete_documents(data)

keys_to_delete = [
    ["Kind1", "identifier"],
    ["Kind2", 123],
    ["Kind3", "identifier", "NestedKind", 456],
]
# The Documents will be ignored and only the document ids will be used.
saver.delete_documents(data, keys_to_delete)
```

## 高级用法

### 使用自定义的 document page content 和 metadata 加载文档

`page_content_properties` 和 `metadata_properties` 参数用于指定哪些 Entity 属性会被写入 LangChain Document 的 `page_content` 与 `metadata`。

```python
loader = DatastoreLoader(
    source="MyKind",
    page_content_fields=["data_field"],
    metadata_fields=["metadata_field"],
)

data = loader.load()
```

### 自定义 page content 格式

当 `page_content` 只包含一个字段时，输出信息会直接是该字段的值。否则，`page_content` 会以 JSON 格式表示。

### 自定义连接与认证

```python
from google.auth import compute_engine
from google.cloud.firestore import Client

client = Client(database="non-default-db", creds=compute_engine.Credentials())
loader = DatastoreLoader(
    source="foo",
    client=client,
)
```
