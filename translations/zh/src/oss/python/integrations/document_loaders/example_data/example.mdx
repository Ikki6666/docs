# 示例 Markdown 文档

## 简介

欢迎阅读这份示例 Markdown 文档。Markdown 是一种轻量级标记语言，用于格式化文本。它被广泛用于文档、readme 文件等场景。

## 功能

### 标题

Markdown 支持多个层级的标题：

- **标题 1**: `# Header 1`
- **标题 2**: `## Header 2`
- **标题 3**: `### Header 3`

### 列表

#### 无序列表

- Item 1
- Item 2
  - Subitem 2.1
  - Subitem 2.2

#### 有序列表

1. First item
2. Second item
3. Third item
