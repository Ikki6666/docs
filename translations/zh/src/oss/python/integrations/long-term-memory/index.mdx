title: "存储集成"
sidebarTitle: 存储
description: "为 LangGraph 长期记忆集成存储后端。"
---

Store 在 LangGraph 中支持[长期记忆](/oss/langgraph/stores)，让 agent 能够跨线程持久化和检索信息。

要为自定义存储后端实现自己的 store，请参见[构建自定义 store](/oss/langgraph/stores#build-a-custom-store)。
