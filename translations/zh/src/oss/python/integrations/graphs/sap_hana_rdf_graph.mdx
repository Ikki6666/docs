[SAP HANA Cloud Knowledge Graph](https://help.sap.com/docs/hana-cloud-database/sap-hana-cloud-sap-hana-database-knowledge-graph-guide/sap-hana-cloud-sap-hana-database-knowledge-graph-engine-guide) 是 `SAP HANA Cloud` 数据库中完整集成的知识图谱解决方案。

## 配置与安装

你必须拥有一个启用了 **triple store** 功能的 SAP HANA Cloud 实例。
详细步骤请参见：[Enable Triple Store](https://help.sap.com/docs/hana-cloud-database/sap-hana-cloud-sap-hana-database-knowledge-graph-guide/enable-triple-store/)

要在 LangChain 中使用 SAP HANA Knowledge Graph Engine，请安装 `langchain-hana` 包：

```python
pip install langchain_hana
```

首先，创建到 SAP HANA Cloud 实例的连接。

```python
import os

from dotenv import load_dotenv
from hdbcli import dbapi

# 如有需要，加载环境变量
load_dotenv()

# 建立到 SAP HANA Cloud 的连接
connection = dbapi.connect(
    address=os.environ.get("HANA_DB_ADDRESS"),
    port=os.environ.get("HANA_DB_PORT"),
    user=os.environ.get("HANA_DB_USER"),
    password=os.environ.get("HANA_DB_PASSWORD")
)
```

然后导入 `HanaRdfGraph` 类。

```python
from langchain_hana import HanaRdfGraph
```

## 创建 `HanaRdfGraph` 实例

构造函数需要：

* **`connection`**：一个有效的 `hdbcli.dbapi.connect(...)` 连接实例
* **`graph_uri`**：RDF 数据所在的命名图，或 `"DEFAULT"`
* **以下任选其一**：
  1. **`ontology_query`**：用于提取 schema 三元组的 SPARQL CONSTRUCT 查询
  2. **`ontology_uri`**：一个托管的 ontology graph URI
  3. **`ontology_local_file`** + **`ontology_local_file_format`**：本地 Turtle/RDF 文件
  4. **`auto_extract_ontology=True`**（不建议用于生产环境，见说明）

`graph_uri` 与 Ontology 的关系

* **`graph_uri`**：
  SAP HANA Cloud 实例中包含实例数据的命名图（有时会有 100k+ triples）。
  如果传入 `None`、`""` 或 `"DEFAULT"`，则使用默认图。
* **Ontology**：一个精简的 schema（通常大约 50-100 triples），用于描述 classes、properties、domains、ranges、labels、comments 和 subclass 关系。Ontology 会指导 SPARQL 生成和结果解释。

### 创建使用 **DEFAULT** 图的实例

关于 DEFAULT 图的更多信息，请参见 [DEFAULT Graph and Named Graphs](https://help.sap.com/docs/hana-cloud-database/sap-hana-cloud-sap-hana-database-knowledge-graph-guide/default-graph-and-named-graphs)。

```python

graph = HanaRdfGraph(
    connection=connection,
    auto_extract_ontology=True,
)
```

### 创建带有远程 `ontology_uri` 的实例

直接从托管 graph URI 加载 schema。

```python
graph = HanaRdfGraph(
    connection=connection,
    ontology_uri="<your_ontology_graph_uri>",
)
```

### 创建带有自定义 `ontology_query` 的实例

使用自定义 `CONSTRUCT` 查询，有选择地提取 schema triples。

```python
ontology_query = """
    PREFIX owl: <http://www.w3.org/2002/07/owl#>
    PREFIX rdf: <http://www.w3.org/1999/02/22-rdf-syntax-ns#>
    PREFIX rdfs: <http://www.w3.org/2000/01/rdf-schema#>
    PREFIX xsd: <http://www.w3.org/2001/XMLSchema#>
    CONSTRUCT {?cls rdf:type owl:Class . ?cls rdfs:label ?clsLabel . ?rel rdf:type ?propertyType . ?rel rdfs:label ?relLabel . ?rel rdfs:domain ?domain . ?rel rdfs:range ?range .}
    FROM <kgdocu_movies>
    WHERE { # 获取 properties
        {SELECT DISTINCT ?domain ?rel ?relLabel ?propertyType ?range
        WHERE {
            ?subj ?rel ?obj .
            ?subj a ?domain .
            OPTIONAL{?obj a ?rangeClass .}
            FILTER(?rel != rdf:type)
            BIND(IF(isIRI(?obj) = true, owl:ObjectProperty, owl:DatatypeProperty) AS ?propertyType)
            BIND(COALESCE(?rangeClass, DATATYPE(?obj)) AS ?range)
            BIND(STR(?rel) AS ?uriStr)       # 将 URI 转成字符串
            BIND(REPLACE(?uriStr, "^.*[/#]", "") AS ?relLabel)
        }}
        UNION { # 获取 classes
            SELECT DISTINCT ?cls ?clsLabel
            WHERE {
                ?instance a/rdfs:subClassOf* ?cls .
                FILTER (isIRI(?cls)) .
                BIND(STR(?cls) AS ?uriStr)       # 将 URI 转成字符串
                BIND(REPLACE(?uriStr, "^.*[/#]", "") AS ?clsLabel)
            }
        }
    }
"""

# 如有需要，也可以传入 graph_uri 参数
graph = HanaRdfGraph(
    connection=connection,
    ontology_query=ontology_query,
)
```

### 创建使用本地 RDF 文件的实例

(`ontology_local_file` + `ontology_local_file_format`)：从本地 RDF ontology 文件加载 schema。

支持的 RDF 格式包括 `Turtle`、`RDF/XML`、`JSON-LD`、`N-Triples`、`Notation-3`、`Trig`、`Trix` 和 `N-Quads`。

```python
graph = HanaRdfGraph(
    connection=connection,
    ontology_local_file="<your_ontology_file_path>", # 例如 "ontology.ttl"
    ontology_local_file_format="<your_ontology_file_format>",  # 例如 "Turtle"、"RDF/XML"、"JSON-LD"、"N-Triples"、"Notation-3"、"Trig"、"Trix"、"N-Quads"
)
```

### 自动提取 ontology

(`auto_extract_ontology=True`)：直接从实例数据中推断 schema 信息。

```python
graph = HanaRdfGraph(
    connection=connection,
    graph_uri="<your_graph_uri>",
    auto_extract_ontology=True,
)
```

> **注意**：自动提取**不**建议用于生产环境，因为它通常会遗漏一些重要 triples，例如 `rdfs:label`、`rdfs:comment` 和 `rdfs:subClassOf`。

## 执行 SPARQL 查询

你可以使用 `query()` 方法在数据图上执行任意 SPARQL 查询（`SELECT`、`ASK`、`CONSTRUCT` 等）。

这个函数有以下参数：

* **query**：SPARQL 查询字符串。
* **content_type**：输出格式（默认是 CSV）。

请使用以下字符串来表示对应格式：

* CSV: `"sparql-results+xml"`
* JSON: `"sparql-results+json"`
* XML: `"sparql-results+csv"`
* TSV: `"sparql-results+tsv"`

> **注意**：CONSTRUCT 和 ASK 查询分别返回 `turtle` 和 `boolean` 格式。

下面我们向 `Puppets` 图中插入一些数据。

```python
cursor = connection.cursor()
try:
    result = cursor.callproc(
        "SYS.SPARQL_EXECUTE", (
        """
        INSERT DATA {
        GRAPH <Puppets> {
            <P1> a <Puppet>; <name> "Ernie"; <show> "Sesame Street".
            <P2> a <Puppet>; <name> "Bert"; <show> "Sesame Street" .
            }
        }
        """, "", "?", "?"
        )
    )
    response = result[2]
except dbapi.Error as db_error:
    raise RuntimeError(
        f'The database query failed: '
        f'{db_error.errortext.split("; Server Connection")[0]}'
    )
finally:
    cursor.close()
```

然后，我们为 `Puppets` 图创建一个 graph 实例。

```python
puppets_graph = HanaRdfGraph(
    connection=connection,
    graph_uri="Puppets",
    auto_extract_ontology=True,
)
```

下面的查询会列出 `Puppets` 图中的所有三元组。

```python
query = """
SELECT ?s ?p ?o
WHERE {
    GRAPH <Puppets> {
        ?s ?p ?o .
    }
}
ORDER BY ?s
"""

result = puppets_graph.query(query)
print(result)
```

```output
s,p,o
P1,name,Ernie
P1,show,Sesame Street
P1,http://www.w3.org/1999/02/22-rdf-syntax-ns#type,Puppet
P2,name,Bert
P2,show,Sesame Street
P2,http://www.w3.org/1999/02/22-rdf-syntax-ns#type,Puppet
```
