## 概览

`InMemoryByteStore` 是 `ByteStore` 的一种非持久化实现，它将所有内容都存储在 Python 字典中。它适用于演示场景，以及那些不需要在 Python 进程生命周期之外保留数据的情况。

### 安装

LangChain `InMemoryByteStore` 集成位于 `langchain-core` 包中：

```python
pip install -qU langchain-core
```

## 实例化

现在你可以实例化 byte store：

```python
from langchain_core.stores import InMemoryByteStore

kv_store = InMemoryByteStore()
```

## 用法

你可以使用 `mset` 方法按下面的方式在键下设置数据：

```python
kv_store.mset(
    [
        ["key1", b"value1"],
        ["key2", b"value2"],
    ]
)

kv_store.mget(
    [
        "key1",
        "key2",
    ]
)
```

```text
[b'value1', b'value2']
```

你也可以使用 `mdelete` 方法删除数据：

```python
kv_store.mdelete(
    [
        "key1",
        "key2",
    ]
)

kv_store.mget(
    [
        "key1",
        "key2",
    ]
)
```

```text
[None, None]
```
