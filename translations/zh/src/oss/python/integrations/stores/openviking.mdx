`OpenVikingStore` 是 LangGraph [`BaseStore`](https://reference.langchain.com/python/langgraph.store/base/BaseStore) 的一种实现，底层由 OpenViking 提供支持。在 OpenViking HTTP 部署中，可以用它实现跨线程的[长期记忆](/oss/langgraph/stores)。

## 概览

OpenViking 是面向 AI agent 的上下文数据库。`langchain-openviking` 包包含 `OpenVikingStore` 类，可将 LangGraph 值存储为持久的 OpenViking 内容记录，并为基于查询的 `search` 调用建立索引。

<Note>
本页中的示例需要 `langchain-openviking>=0.2.0`。
</Note>

## 设置

要使用 `OpenVikingStore`，你需要一个 OpenViking HTTP 部署和一个 API key。

### 安装

请使用 Python 3.10 或更高版本。通过 `langgraph` extra 安装该集成：

```bash
pip install -qU "langchain-openviking[langgraph]>=0.2.0"
```

### 凭据

设置 OpenViking URL 和 API key：

```python
from getpass import getpass

OPENVIKING_URL = getpass("OpenViking URL: ")
OPENVIKING_API_KEY = getpass("OpenViking API key: ")
```

## 实例化

使用 OpenViking HTTP 连接设置实例化 `OpenVikingStore`：

```python
from langchain_openviking import OpenVikingStore

store = OpenVikingStore(
    url=OPENVIKING_URL,
    api_key=OPENVIKING_API_KEY,
    auth_mode="api_key",
)
```

`root_uri` 默认为 `viking://~/memories/langgraph_store`。请使用支持 `viking://~` 主页别名的 OpenViking 服务器，该别名会解析为已认证用户的空间。若要定位特定用户，请将显式的 `viking://user/<uid>/...` URI 作为 `root_uri` 传入。

## 用法

使用 `put` 在命名空间和 key 下写入可 JSON 序列化的映射：

```python
store.put(
    ("users", "ada"),
    "preferences",
    {"color": "azure"},
)
```

使用 `get` 获取已存储的条目：

```python
item = store.get(("users", "ada"), "preferences")
print(item.value)
```

在给定命名空间前缀时使用 `search`。传入 `query` 进行语义搜索：

```python
results = store.search(("users",), query="azure", limit=3)
```

若要跳过对某个值的语义索引，请向 `put` 传入 `index=False` 或 `index=[]`。该值仍可通过 `get` 获取：

```python
store.put(
    ("users", "ada"),
    "preferences",
    {"color": "azure"},
    index=[],
)
```

使用 `delete` 删除 key：

```python
store.delete(("users", "ada"), "preferences")
```

使用完 store 后，请关闭其连接：

```python
store.close()
```

在异步代码中，请使用 `await store.aclose()`。该 store 也支持 `with` 和 `async with` 以自动清理。如果你通过 `client=` 提供了 client，请自行关闭该 client。
