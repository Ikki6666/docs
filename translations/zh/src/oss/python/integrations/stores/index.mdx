## 概览

LangChain 提供了一个键值存储接口，用于按 key 存储和检索数据。LangChain 中的键值存储接口主要用于缓存 [embeddings](/oss/integrations/embeddings)。

## 接口

所有 [`BaseStores`](https://reference.langchain.com/python/langchain-core/stores/BaseStore) 都支持以下接口：

- `mget(key: Sequence[str]) -> List[Optional[bytes]]`：获取多个 key 的内容，如果 key 不存在则返回 `None`
- `mset(key_value_pairs: Sequence[Tuple[str, bytes]]) -> None`：设置多个 key 的内容
- `mdelete(key: Sequence[str]) -> None`：删除多个 key
- `yield_keys(prefix: Optional[str] = None) -> Iterator[str]`：产出 store 中的所有 key，也可以按前缀过滤

<Note>
Base store 的设计是为了能够一次处理**多个**键值对，从而提升效率。这可以减少网络往返次数，也可能让底层 store 执行更高效的批量操作。
</Note>
