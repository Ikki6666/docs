## 概览

`ElasticsearchEmbeddingsCache` 是一个 `ByteStore` 实现，它利用你的 Elasticsearch 实例来高效存储和检索 embeddings。

## 设置

要创建 `ElasticsearchEmbeddingsCache` byte store，你需要一个 Elasticsearch 集群。你可以[在本地搭建](https://www.elastic.co/downloads/elasticsearch)，或者创建一个 [Elastic account](https://www.elastic.co/elasticsearch)。

### 安装

LangChain `ElasticsearchEmbeddingsCache` 集成位于 `langchain-elasticsearch` 包中：

```python
pip install -qU langchain-elasticsearch
```

## 实例化

现在可以实例化 byte store 了：

```python
from langchain_elasticsearch import ElasticsearchEmbeddingsCache

# Example config for a locally running Elasticsearch instance
kv_store = ElasticsearchEmbeddingsCache(
    es_url="https://localhost:9200",
    index_name="llm-chat-cache",
    metadata={"project": "my_chatgpt_project"},
    namespace="my_chatgpt_project",
    es_user="elastic",
    es_password="<GENERATED PASSWORD>",
    es_params={
        "ca_certs": "~/http_ca.crt",
    },
)
```

## 用法

你可以像下面这样使用 `mset` 方法按 key 写入数据：

```python
kv_store.mset(
    [
        ["key1", b"value1"],
        ["key2", b"value2"],
    ]
)

kv_store.mget(
    [
        "key1",
        "key2",
    ]
)
```

```text
[b'value1', b'value2']
```

你也可以使用 `mdelete` 方法删除数据：

```python
kv_store.mdelete(
    [
        "key1",
        "key2",
    ]
)

kv_store.mget(
    [
        "key1",
        "key2",
    ]
)
```

```text
[None, None]
```

## 作为 embeddings cache 使用

与其他 `ByteStores` 一样，你可以把 `ElasticsearchEmbeddingsCache` 实例用于 RAG 的[文档摄取阶段持久化缓存](/oss/integrations/embeddings#caching)。

不过，默认情况下缓存的向量并不能直接被搜索。开发者可以自定义 Elasticsearch 文档的构建方式，为其增加可索引的向量字段。

可以通过继承并重写方法来实现：

```python
from typing import Any, Dict, List


class SearchableElasticsearchStore(ElasticsearchEmbeddingsCache):
    @property
    def mapping(self) -> Dict[str, Any]:
        mapping = super().mapping
        mapping["mappings"]["properties"]["vector"] = {
            "type": "dense_vector",
            "dims": 1536,
            "index": True,
            "similarity": "dot_product",
        }
        return mapping

    def build_document(self, llm_input: str, vector: List[float]) -> Dict[str, Any]:
        body = super().build_document(llm_input, vector)
        body["vector"] = vector
        return body
```

在重写 mapping 和文档构建逻辑时，请只做增量修改，并保持基础 mapping 不变。
