## 概览

`LocalFileStore` 是 `ByteStore` 的一种持久化实现，会把所有内容存储在你指定的文件夹中。如果你只在单机上使用，并且可以接受文件被添加或删除，这会很有用。

### 安装

这个 `LocalFileStore` 集成位于 `langchain` 包中：

```python
pip install -qU langchain-classic
```

## 实例化

现在我们可以实例化 byte store 了：

```python
from pathlib import Path

from langchain_classic.storage import LocalFileStore

root_path = Path.cwd() / "data"  # 也可以使用字符串路径

kv_store = LocalFileStore(root_path)
```

## 使用

你可以像下面这样用 `mset` 方法按 key 写入数据：

```python
kv_store.mset(
    [
        ["key1", b"value1"],
        ["key2", b"value2"],
    ]
)

kv_store.mget(
    [
        "key1",
        "key2",
    ]
)
```

```text
[b'value1', b'value2']
```

你可以在 `data` 文件夹里看到创建出来的文件：

```python
!ls {root_path}
```

```text
key1 key2
```

你也可以使用 `mdelete` 方法删除数据：

```python
kv_store.mdelete(
    [
        "key1",
        "key2",
    ]
)

kv_store.mget(
    [
        "key1",
        "key2",
    ]
)
```

```text
[None, None]
```
