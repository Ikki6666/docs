## 设置与安装

要使用此功能，请安装 `langchain-hana` 包：

```python
pip install langchain_hana
```

然后，创建到 SAP HANA Cloud 实例的连接。

```python
import os

from dotenv import load_dotenv
from hdbcli import dbapi

# 如果需要则加载环境变量
load_dotenv()

# 建立到 SAP HANA Cloud 的连接
connection = dbapi.connect(
    address=os.environ.get("HANA_DB_ADDRESS"),
    port=os.environ.get("HANA_DB_PORT"),
    user=os.environ.get("HANA_DB_USER"),
    password=os.environ.get("HANA_DB_PASSWORD")
)
```

`HanaSparqlQAChain` 将以下能力串联在一起：

1. **感知 schema 的 SPARQL 生成**
2. **针对 SAP HANA 执行查询**
3. **自然语言答案格式化**

## 初始化

需要准备：

* 一个用于生成和解释查询的 **LLM**
* 一个 **`HanaRdfGraph`**，其中包含连接、`graph_uri` 和 ontology

按照这里的步骤了解如何创建 `HanaRdfGraph` 实例：[HanaRdfGraph](/oss/integrations/graphs/sap_hana_rdf_graph)。

导入 `HanaSparqlQAChain`

```python
from langchain_hana import HanaSparqlQAChain
```

```python
qa_chain = HanaSparqlQAChain.from_llm(
    llm=llm, graph=graph, allow_dangerous_requests=True, verbose=True
)
```

## 流水线概览

1. **SPARQL 生成**
   * 使用 `SPARQL_GENERATION_SELECT_PROMPT`
   * 输入：
     * `schema`（来自 `graph.get_schema` 的 Turtle）
     * `prompt`（用户问题）
2. **查询后处理**
   * 从 llm 输出中提取 SPARQL 代码
   * 如果缺失，则注入 `FROM <graph_uri>`
   * 确保声明了必需的通用前缀（`rdf:`、`rdfs:`、`owl:`、`xsd:`）
3. **执行**
   * 调用 `graph.query(generated_sparql)`
4. **答案生成**
   * 使用 `SPARQL_QA_PROMPT`
   * 输入：
     * `context`（原始查询结果）
     * `prompt`（原始问题）

## 提示模板

### “SPARQL Generation” 提示

`sparql_generation_prompt` 用于引导 LLM 根据用户问题和提供的 schema 生成 SPARQL 查询。

### 回答提示

`qa_prompt` 指导 LLM 仅基于数据库结果生成自然语言答案。

默认提示可在这里查看：[`prompts.py`](https://github.com/SAP/langchain-integration-for-sap-hana-cloud/blob/main/langchain_hana/chains/graph_qa/prompts.py)

## 自定义提示

可以在初始化时覆盖默认值：

```python
qa_chain = HanaSparqlQAChain.from_llm(
    llm=llm,
    graph=graph,
    allow_dangerous_requests=True,
    verbose=True,
    sparql_generation_prompt=YOUR_SPARQL_PROMPT,
    qa_prompt=YOUR_QA_PROMPT
)
```

> - `sparql_generation_prompt` 必须包含输入变量：`["schema", "prompt"]`
> - `qa_prompt` 必须包含输入变量：`["context", "prompt"]`

## 示例：在 “Movies” 知识图谱上进行问答

**前置条件**：
必须拥有启用了 **triple store** 功能的 SAP HANA Cloud 实例。
详细说明参见：[Enable Triple Store](https://help.sap.com/docs/hana-cloud-database/sap-hana-cloud-sap-hana-database-knowledge-graph-guide/enable-triple-store/)<br />
加载 `kgdocu_movies` 示例数据。参见 [Knowledge Graph Example](https://help.sap.com/docs/hana-cloud-database/sap-hana-cloud-sap-hana-database-knowledge-graph-guide/knowledge-graph-example)。

1. 实例化一个指向 “movies” 数据图的 `HanaRdfGraph`

这演示了 LLM 如何在底层生成 SPARQL、在 SAP HANA 上执行查询，并返回可读的答案。

## 底层发生了什么？

1. **SPARQL 生成**
   链会使用你以 Turtle 格式提供的 ontology（`graph.get_schema`）和用户问题，通过 `SPARQL_GENERATION_SELECT_PROMPT` 调用 LLM。随后 LLM 会生成一个适合你的 schema 的有效 `SELECT` 查询。
2. **预处理与执行**
   * **提取与清理**：从 LLM 的响应中提取原始 SPARQL 文本。
   * **注入图上下文**：如果缺少 `FROM <graph_uri>`，则将其添加进去，并确保声明了通用前缀（`rdf:`、`rdfs:`、`owl:`、`xsd:`）。
   * **在 HANA 上运行**：通过 `HanaRdfGraph.query()` 在你的命名图上执行最终查询。
3. **答案生成**
   返回的 CSV（或 Turtle）结果会再次输入 LLM，这次使用 `SPARQL_QA_PROMPT`。LLM 会严格基于检索到的数据生成简洁、可读的答案，而不会产生幻觉。
