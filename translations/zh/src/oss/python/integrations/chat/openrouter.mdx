## 设置

要通过 OpenRouter 访问模型，你需要创建一个 [OpenRouter account](https://openrouter.ai/)、获取 API key，并安装 `langchain-openrouter` 集成包。

### 安装

LangChain 的 OpenRouter 集成位于 `langchain-openrouter` 包中：

<CodeGroup>
    ```bash pip
    pip install -U langchain-openrouter
    ```
    ```bash uv
    uv add langchain-openrouter
    ```
</CodeGroup>

### 凭证

前往 [OpenRouter keys page](https://openrouter.ai/settings/keys) 注册并生成 API key。完成后，设置 `OPENROUTER_API_KEY` 环境变量：

```python
import getpass
import os

if not os.getenv("OPENROUTER_API_KEY"):
    os.environ["OPENROUTER_API_KEY"] = getpass.getpass("Enter your OpenRouter API key: ")
```

要启用模型调用的自动 tracing，请设置 [LangSmith](/langsmith/observability) API key：

```python
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

## 实例化

现在可以实例化模型对象并生成聊天补全：

```python
from langchain_openrouter import ChatOpenRouter

model = ChatOpenRouter(
    model="anthropic/claude-sonnet-4.5",
    temperature=0,
    max_tokens=1024,
    max_retries=2,
    # other params...
)
```

```python
stream = model.stream_events("Write a short poem about the sea.", version="v3")
for token in stream.text:
```

```python
stream = await model.astream_events("Write a short poem about the sea.", version="v3")
```

## Tool calling

OpenRouter 使用 OpenAI-compatible tool calling 格式。你可以描述工具及其参数，让模型返回一个 JSON 对象，其中包含要调用的工具及其输入。

### 绑定工具

借助 `ChatOpenRouter.bind_tools`，你可以将 Pydantic 类、dict schema、LangChain 工具，或者函数本身传给模型作为工具。在底层，它们会被转换成 OpenAI tool schema，并在每次模型调用时一同传入。

```python
from pydantic import BaseModel, Field


class GetWeather(BaseModel):
    """Get the current weather in a given location"""

    location: str = Field(description="The city and state, e.g. San Francisco, CA")


model_with_tools = model.bind_tools([GetWeather])
```

```python
ai_msg = model_with_tools.invoke(
    "what is the weather like in San Francisco",
)
ai_msg
```

```text
AIMessage(content='', response_metadata={'finish_reason': 'tool_calls'}, tool_calls=[{'name': 'GetWeather', 'args': {'location': 'San Francisco, CA'}, 'id': 'call_abc123', 'type': 'tool_call'}], usage_metadata={'input_tokens': 68, 'output_tokens': 17, 'total_tokens': 85})
```

### 工具调用

`AIMessage` 带有一个 `tool_calls` 属性。它以标准化格式提供工具调用，因此与具体模型提供方无关。

```python
ai_msg.tool_calls
```

```text
[{'name': 'GetWeather',
  'args': {'location': 'San Francisco, CA'},
  'id': 'call_abc123',
  'type': 'tool_call'}]
```

### 严格模式

向 `bind_tools` 传入 `strict=True` 可以保证模型输出严格匹配工具定义中的 JSON Schema：

```python
model_with_tools = model.bind_tools([GetWeather], strict=True)
```

关于绑定工具和工具调用输出的更多内容，请参见 [tool calling](/oss/langchain/tools) 文档。

## 结构化输出

`ChatOpenRouter` 通过 [`with_structured_output`](/oss/langchain/models#structured-output) 方法支持结构化输出。可用的两种方法是 `function_calling`（默认）和 `json_schema`。

<Accordion title="Individual model calls">

使用 `with_structured_output` 生成结构化模型响应。指定 `method="json_schema"` 可使用基于 JSON Schema 的结构化输出，否则默认使用 function calling。

```python
from langchain_openrouter import ChatOpenRouter
from pydantic import BaseModel, Field

model = ChatOpenRouter(model="openai/gpt-5.5")

class Movie(BaseModel):
    """A movie with details."""
    title: str = Field(description="The title of the movie")
    year: int = Field(description="The year the movie was released")
    director: str = Field(description="The director of the movie")
    rating: float = Field(description="The movie's rating out of 10")

structured_model = model.with_structured_output(Movie, method="json_schema")  # [!code highlight]
response = structured_model.invoke("Provide details about the movie Inception")
response
```

```python
Movie(title='Inception', year=2010, director='Christopher Nolan', rating=8.8)
```

</Accordion>

<Accordion title="Agent response format">

通过 [`ProviderStrategy`](/oss/langchain/structured-output) 指定 `response_format`，在生成 agent 最终响应时启用结构化输出。

```python
from langchain.agents import create_agent
from langchain.agents.structured_output import ProviderStrategy
from pydantic import BaseModel

class Weather(BaseModel):
    temperature: float
    condition: str

def weather_tool(location: str) -> str:
    """Get the weather at a location."""
    return "Sunny and 75 degrees F."

agent = create_agent(
    model="openrouter:openai/gpt-5.5",
    tools=[weather_tool],
    response_format=ProviderStrategy(Weather),  # [!code highlight]
)

result = agent.invoke({
    "messages": [{"role": "user", "content": "What's the weather in SF?"}]
})

result["structured_response"]
```

```python
Weather(temperature=75.0, condition='Sunny')
```

</Accordion>

你可以对 `function_calling` 和 `json_schema` 方法传入 `strict=True`，以强制严格遵守 schema。`json_mode` 不支持 `strict` 参数。

```python
structured_model = model.with_structured_output(Movie, method="json_schema", strict=True)
```

## 推理输出

对于支持推理的模型（例如 `anthropic/claude-sonnet-4.5`、`deepseek/deepseek-r1`），你可以通过 `reasoning` 参数启用 reasoning token。详情请参见 [OpenRouter reasoning docs](https://openrouter.ai/docs/guides/best-practices/reasoning-tokens)：

```python
model = ChatOpenRouter(
    model="anthropic/claude-sonnet-4.5",
    max_tokens=16384,
    reasoning={"effort": "high", "summary": "auto"},
)

ai_msg = model.invoke("What is the square root of 529?")

# Access reasoning content via content_blocks
for block in ai_msg.content_blocks:
    if block["type"] == "reasoning":
        print(block["reasoning"])
```

关于 content blocks 的更多信息，请参见 [standard content blocks](/oss/langchain/messages#standard-content-blocks) 指南。

`reasoning` 字典支持两个键：

- `effort`：控制推理 token 预算。可选值：`"xhigh"`、`"high"`、`"medium"`、`"low"`、`"minimal"`、`"none"`。
- `summary`：控制返回的推理摘要详细程度。可选值：`"auto"`、`"concise"`、`"detailed"`。

推理 token 使用量会包含在 `usage_metadata` 中：

```python
print(ai_msg.usage_metadata)
# {'input_tokens': ..., 'output_tokens': ..., 'total_tokens': ...,
#  'output_token_details': {'reasoning': ...}}
```

<Note>
    effort 到预算的映射依赖具体模型。例如 Google Gemini 会把 effort 映射为内部的 `thinkingLevel`，而不是精确 token 预算。详情请参见 [OpenRouter reasoning docs](https://openrouter.ai/docs/guides/best-practices/reasoning-tokens)。
</Note>

## 多模态输入

OpenRouter 对支持的模型提供 [multimodal inputs](/oss/langchain/messages#multimodal)。具体支持哪些模态取决于你选择的模型，请查看 [OpenRouter models page](https://openrouter.ai/models)。

### 支持的输入方式

| Method | Image | Audio | Video | PDF |
|--------|:-----:|:-----:|:-----:|:---:|
| HTTP/HTTPS URLs | ✅ | ❌ | ✅ | ✅ |
| Base64 inline data | ✅ | ✅ | ✅ | ✅ |

<Note>
    并非所有模型都支持全部模态。请查看 [OpenRouter models page](https://openrouter.ai/models) 获取模型级支持详情。


    ```python Base64 encoded
    import httpx
    from langchain_openrouter import ChatOpenRouter
    from langchain.messages import HumanMessage
    ```

## Token usage 元数据

调用完成后，token 使用信息可在响应的 `usage_metadata` 属性中获得：

```python
ai_msg = model.invoke("Tell me a joke.")
ai_msg.usage_metadata
```

```text
{'input_tokens': 12,
 'output_tokens': 25,
 'total_tokens': 37}
```

当底层提供方在响应中包含更详细的 token 分解信息时，这些字段也会自动暴露出来。如果提供方没有上报，或者值为零，则这些字段会被省略。

### 推理 token

`output_token_details.reasoning` 表示模型在内部 chain-of-thought 推理中使用的 token 数量。使用推理模型（例如 `deepseek/deepseek-r1`、`openai/o3`）或显式启用推理时会出现该字段：

```python
from langchain_openrouter import ChatOpenRouter

model = ChatOpenRouter(
    model="anthropic/claude-sonnet-4.5",
    reasoning={"effort": "high"},
)

ai_msg = model.invoke("What is the square root of 529?")
ai_msg.usage_metadata
```

```text
{'input_tokens': 39,
 'output_tokens': 98,
 'total_tokens': 137,
 'output_token_details': {'reasoning': 62}}
```

### 缓存输入 token

`input_token_details.cache_read` 表示从提供方 prompt cache 中读取的输入 token 数量，而 `input_token_details.cache_creation` 表示首次调用时写入缓存的 token 数量。

Prompt caching 需要你在消息内容块中显式设置 `cache_control` 断点。对你希望被缓存的内容块传入 `{"cache_control": {"type": "ephemeral"}}`：

```python
from langchain_openrouter import ChatOpenRouter

model = ChatOpenRouter(model="anthropic/claude-sonnet-4.5")

long_system = "You are a helpful assistant. " * 200
messages = [
    ("system", [{"type": "text", "text": long_system, "cache_control": {"type": "ephemeral"}}]),
    ("human", "Say hi."),
]

# First call writes to cache
ai_msg = model.invoke(messages)
ai_msg.usage_metadata
```

```text
{'input_tokens': 1210,
 'output_tokens': 12,
 'total_tokens': 1222,
 'input_token_details': {'cache_creation': 1201}}
```

```python
# Second call reads from cache
ai_msg = model.invoke(messages)
ai_msg.usage_metadata
```

```text
{'input_tokens': 1210,
 'output_tokens': 12,
 'total_tokens': 1222,
 'input_token_details': {'cache_read': 1201}}
```

<Note>
    如果消息内容块上没有 `cache_control`，提供方就不会缓存该 prompt，这些字段也不会出现。
</Note>

在流式输出中，可以从完整输出对象上访问 token usage：

```python
stream = model.stream_events("Tell me a joke.", version="v3")
full = stream.output
full.usage_metadata
```

```text
{'input_tokens': 12,
 'output_tokens': 25,
 'total_tokens': 37}
```

## Provider routing

OpenRouter 上的许多模型由多个提供方共同提供。`openrouter_provider` 参数让你能够控制由哪些提供方处理请求，以及如何选择它们。

### 排序与过滤提供方

使用 `order` 设置首选提供方顺序。OpenRouter 会按顺序尝试各提供方，并在某个提供方不可用时回退到下一个：

```python
model = ChatOpenRouter(
    model="anthropic/claude-sonnet-4.5",
    openrouter_provider={
        "order": ["Anthropic", "Google"],
        "allow_fallbacks": True,  # default; fall back beyond the order list if needed
    },
)
```

如果你只想限制在特定提供方内使用，请使用 `only`。如果你想排除某些提供方，请使用 `ignore`：

```python
# Only use these providers (no fallback to others)
model = ChatOpenRouter(
    model="openai/gpt-4o",
    openrouter_provider={"only": ["OpenAI", "Azure"]},
)

# Use any provider except DeepInfra
model = ChatOpenRouter(
    model="meta-llama/llama-4-maverick",
    openrouter_provider={"ignore": ["DeepInfra"]},
)
```

### 按成本、速度或延迟排序

默认情况下，OpenRouter 会在多个提供方之间做负载均衡，并倾向于更低成本。你可以使用 `sort` 改变优先级：

```python
# Prefer the fastest providers (highest tokens/second)
model = ChatOpenRouter(
    model="openai/gpt-4o",
    openrouter_provider={"sort": "throughput"},
)

# Prefer the lowest-latency providers
model = ChatOpenRouter(
    model="openai/gpt-4o",
    openrouter_provider={"sort": "latency"},
)
```

### 数据收集策略

如果你的场景要求提供方不得存储或训练使用你的数据，可将 `data_collection` 设为 `"deny"`：

```python
model = ChatOpenRouter(
    model="anthropic/claude-sonnet-4.5",
    openrouter_provider={"data_collection": "deny"},
)
```

### 按量化方式过滤

对于开源权重模型，你可以限制只路由到某些精度级别：

```python
model = ChatOpenRouter(
    model="meta-llama/llama-4-maverick",
    openrouter_provider={"quantizations": ["fp16", "bf16"]},
)
```

### route 参数

`route` 参数控制高层路由行为：

- `"fallback"`：启用提供方之间的自动故障转移（默认行为）
- `"sort"`：按 `openrouter_provider` 中配置的排序策略进行路由

```python
model = ChatOpenRouter(
    model="anthropic/claude-sonnet-4.5",
    route="fallback",
)
```

### 组合使用选项

你可以把多个提供方选项组合起来使用：

```python
model = ChatOpenRouter(
    model="openai/gpt-4o",
    openrouter_provider={
        "order": ["OpenAI", "Azure"],
        "allow_fallbacks": False,       # strict—only use providers in order
        "require_parameters": True,     # skip providers that don't support all params
        "data_collection": "deny",
    },
)
```

完整选项列表请参见 [OpenRouter provider routing docs](https://openrouter.ai/docs/guides/routing/provider-selection)。

## Observability 与 tracing

OpenRouter 可以将请求数据广播到配置好的 observability destination。`ChatOpenRouter` 暴露了两个相关参数：`session_id` 用于把相关请求归组到同一个逻辑工作流中，`trace` 用于附加每次请求的 trace 元数据。详情请参见 [OpenRouter broadcast docs](https://openrouter.ai/docs/guides/features/broadcast/overview)。

### 通过 `session_id` 对请求分组

传入 `session_id`，可以把多个请求关联到同一个工作流中（例如一个对话、一次 agent 运行、一次批处理任务、一次 CI 运行等）。最大长度为 256 个字符。

```python
model = ChatOpenRouter(
    model="anthropic/claude-sonnet-4.5",
    session_id="workflow-abc-123",   # or OPENROUTER_SESSION_ID env var
)
```

如果没有显式传入 `session_id`，则在实例化时会读取 `OPENROUTER_SESSION_ID` 环境变量，这样整个进程中的请求都可以统一打上标记，而无需在应用代码中层层传递。

你也可以在每次调用时覆盖这个值：

```python
model.invoke("Summarize the doc", session_id="workflow-abc-123-step-1")
```

### 通过 `trace` 添加 trace 元数据

传入 `trace`，可为每次请求附加元数据，OpenRouter 会将其转发到 broadcast destination。已识别的键包括 `trace_id`、`trace_name`、`span_name`、`generation_name` 和 `parent_span_id`；其余附加键会作为自定义元数据原样传递。

```python
model = ChatOpenRouter(
    model="anthropic/claude-sonnet-4.5",
    trace={
        "trace_id": "trace-789",
        "span_name": "summarize",
    },
)
```

`session_id` 和 `trace` 是相互独立的：`session_id` 用于在 OpenRouter 侧将请求归组为一个逻辑工作流，而 `trace` 用于给单个请求打标注。
