## 设置

要访问 Contextual 模型，需要创建 Contextual AI 账号、获取 API key，并安装 `langchain-contextual` 集成包。

### 凭证

前往 [app.contextual.ai](https://app.contextual.ai) 注册 Contextual，并生成 API key。完成后，设置 `CONTEXTUAL_AI_API_KEY` 环境变量：

```python
import getpass
import os

if not os.getenv("CONTEXTUAL_AI_API_KEY"):
    os.environ["CONTEXTUAL_AI_API_KEY"] = getpass.getpass(
        "Enter your Contextual API key: "
    )
```

如果希望为模型调用启用自动 tracing，也可以取消下方注释并设置 [LangSmith](/langsmith/observability) API key：

```python
os.environ["LANGSMITH_TRACING"] = "true"
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
```

### 安装

LangChain 的 Contextual 集成位于 `langchain-contextual` 包中：

```python
pip install -qU langchain-contextual
```

## 实例化

现在可以实例化模型对象并生成聊天补全。

聊天客户端还支持以下额外设置：

| Parameter | Type | Description | Default |
|-----------|------|-------------|---------|
| temperature | Optional[float] | 采样温度，会影响响应的随机性。请注意，较高的 temperature 值会降低 groundedness。 | 0 |
| top_p | Optional[float] | nucleus sampling 参数，是 temperature 的另一种替代方式，也会影响响应的随机性。请注意，较高的 top_p 值会降低 groundedness。 | 0.9 |
| max_new_tokens | Optional[int] | 模型在响应中最多可生成的 token 数量。最小为 1，最大为 2048。 | 1024 |

```python
from langchain_contextual import ChatContextual

llm = ChatContextual(
    model="v1",  # defaults to `v1`
    api_key="",
    temperature=0,  # defaults to 0
    top_p=0.9,  # defaults to 0.9
    max_new_tokens=1024,  # defaults to 1024
)
```

## 调用

在调用 `ChatContextual.invoke` 方法时，Contextual Grounded Language Model 支持传入额外 `kwargs`。

这些额外输入包括：

| Parameter | Type | Description |
|-----------|------|-------------|
| knowledge | list[str] | 必填：grounded language model 在生成响应时可使用的知识源字符串列表。 |
| system_prompt | Optional[str] | 可选：模型在生成响应时应遵循的指令。请注意，我们不保证模型会严格遵循这些指令。 |
| avoid_commentary | Optional[bool] | 可选，默认值为 `False`：用于指示模型是否应避免在响应中提供额外 commentary。Commentary 具有对话性质，不包含可验证声明，因此并不是严格 grounded 在可用上下文中的。不过，commentary 有时会提供额外上下文，提高响应的帮助性。 |

```python
# include a system prompt (optional)
system_prompt = "You are a helpful assistant that uses all of the provided knowledge to answer the user's query to the best of your ability."

# provide your own knowledge from your knowledge-base here in an array of string
knowledge = [
    "There are 2 types of dogs in the world: good dogs and best dogs.",
    "There are 2 types of cats in the world: good cats and best cats.",
]

# create your message
messages = [
    ("human", "What type of cats are there in the world and what are the types?"),
]

# invoke the GLM by providing the knowledge strings, optional system prompt
# if you want to turn off the GLM's commentary, pass True to the `avoid_commentary` argument
ai_msg = llm.invoke(
    messages, knowledge=knowledge, system_prompt=system_prompt, avoid_commentary=True
)

print(ai_msg.content)
```

## 链式组合

我们可以把 Contextual Model 与 output parser 组合起来。

```python
from langchain_core.output_parsers import StrOutputParser

chain = llm | StrOutputParser

chain.invoke(
    messages, knowledge=knowledge, systemp_prompt=system_prompt, avoid_commentary=True
)
```
