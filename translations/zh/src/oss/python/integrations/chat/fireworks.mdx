## 设置

要访问 Fireworks 模型，需要创建 Fireworks 账号、获取 API key，并安装 `langchain-fireworks` 集成包。

### 凭证

前往 [fireworks.ai](https://app.fireworks.ai/login) 注册 Fireworks 并生成 API key。完成后，设置 `FIREWORKS_API_KEY` 环境变量：

```python
import getpass
import os

if "FIREWORKS_API_KEY" not in os.environ:
    os.environ["FIREWORKS_API_KEY"] = getpass.getpass("Enter your Fireworks API key: ")
```

要为模型调用启用自动 tracing，请设置你的 [LangSmith](/langsmith/observability) API key：

```python
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

### 安装

LangChain 的 Fireworks 集成位于 `langchain-fireworks` 包中：

```bash
pip install -qU langchain-fireworks
```

## 实例化

现在可以实例化模型对象并生成聊天补全：

```python
from langchain_fireworks import ChatFireworks

llm = ChatFireworks(
    model="accounts/fireworks/models/kimi-k2-instruct-0905",
    temperature=0,
    max_tokens=None,
    timeout=None,
    max_retries=2,
    # other params...
)
```

## 推理力度

部分由 Fireworks 托管的模型支持标准的 [`reasoning_effort`](/oss/langchain/models#reasoning) 参数，该参数用于控制模型执行的推理量。`ChatFireworks` 会将其原样转发为 `reasoning_effort` 请求字段。支持的值因模型而异。你可以在构造模型时设置它，也可以在每次调用时设置：

```python
from langchain_fireworks import ChatFireworks

model = ChatFireworks(model="accounts/fireworks/models/deepseek-v4-pro")
response = model.invoke(
    "Analyze the trade-offs between microservices and monolithic architectures",
    reasoning_effort="high",
)
```

<Note>
    作为标准参数使用的 `reasoning_effort` 需要 `langchain-fireworks>=1.5.2`。
</Note>

请查看模型的 [profile](/oss/langchain/models#model-profiles)，了解它支持哪些力度层级：

```python
model.profile["reasoning_effort_levels"]  # e.g. ['low', 'medium', 'high']
```
