[Ollama](https://ollama.com/) 允许你在本地运行开源大语言模型（LLM），例如 `gpt-oss`。

Ollama 会把模型权重、配置和数据打包成一个由 Modelfile 定义的单一包，并优化包括 GPU 使用在内的安装和配置细节。

完整支持模型与模型变体列表请参见 [Ollama model library](https://ollama.com/search)。

<Tip>
    **API Reference**

    如需查看全部功能和配置选项的详细文档，请前往 @[`ChatOllama`] API reference。
</Tip>

## 设置

首先，请按照[这些说明](https://github.com/ollama/ollama?tab=readme-ov-file#ollama)设置并运行本地 Ollama 实例：

* [Download](https://ollama.ai/download) 并在受支持的平台上安装 Ollama（包括 Windows Subsystem for Linux 即 WSL、macOS 和 Linux）
  * macOS 用户可以通过 Homebrew 安装：`brew install ollama`，并通过 `brew services start ollama` 启动
* 通过 `ollama pull <name-of-model>` 拉取可用的 LLM 模型
  * 可在 [model library](https://ollama.ai/library) 中查看可用模型列表
  * 例如：`ollama pull gpt-oss:20b`
* 这会下载模型的默认 tag 版本。通常默认值指向最新、参数规模最小的版本。

> 在 Mac 上，模型会下载到 `~/.ollama/models`
>
> 在 Linux（或 WSL）上，模型会存储在 `/usr/share/ollama/.ollama/models`

* 也可以像 `ollama pull gpt-oss:20b` 这样指定精确版本（这里示例中可查看 [`Vicuna`](https://ollama.ai/library/vicuna/tags) 模型的不同 tag）
* 使用 `ollama list` 查看已拉取的所有模型
* 使用 `ollama run <name-of-model>` 直接在命令行中和模型对话
* 更多命令请参见 [Ollama documentation](https://github.com/ollama/ollama/blob/main/docs/README.md)。你也可以在终端运行 `ollama help` 查看可用命令。

要启用模型调用的自动 tracing，请设置 [LangSmith](/langsmith/observability) API key：

```python
os.environ["LANGSMITH_TRACING"] = "true"
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
```

### 安装

LangChain 的 Ollama 集成位于 `langchain-ollama` 包中：

```python
pip install -qU langchain-ollama
```

## Tool calling

[Ollama tool calling](https://ollama.com/blog/tool-support) 使用 OpenAI-compatible web server 规范，你可以像 [LangChain tools 文档](/oss/langchain/tools/) 中描述的那样，使用默认的 `BaseChatModel.bind_tools()` 方法。

请确保选择支持 [tool calling](https://ollama.com/search?&c=tools) 的 ollama 模型。

我们可以对[经过工具使用微调](https://ollama.com/search?&c=tools)的 LLM 使用 [tool calling](/oss/langchain/tools/)，例如 `gpt-oss`：

```
ollama pull gpt-oss:20b
```

关于自定义工具的更多细节，请参见 [Customize tool properties](/oss/langchain/tools#customize-tool-properties)。下面展示如何在普通 python 函数上使用 @[`@tool`] 装饰器来创建工具。

```python
from typing import List

from langchain.messages import AIMessage
from langchain.tools import tool
from langchain_ollama import ChatOllama


@tool
def validate_user(user_id: int, addresses: List[str]) -> bool:
    """Validate user using historical addresses.

    Args:
        user_id (int): the user ID.
        addresses (List[str]): Previous addresses as a list of strings.
    """
    return True


llm = ChatOllama(
    model="gpt-oss:20b",
    validate_model_on_init=True,
    temperature=0,
).bind_tools([validate_user])

result = llm.invoke(
    "Could you validate user 123? They previously lived at "
    "123 Fake St in Boston MA and 234 Pretend Boulevard in "
    "Houston TX."
)

if isinstance(result, AIMessage) and result.tool_calls:
    print(result.tool_calls)
```

```text
[{'name': 'validate_user', 'args': {'addresses': ['123 Fake St, Boston, MA', '234 Pretend Boulevard, Houston, TX'], 'user_id': '123'}, 'id': 'aef33a32-a34b-4b37-b054-e0d85584772f', 'type': 'tool_call'}]
```

```python
import base64
from io import BytesIO

from IPython.display import HTML, display
from PIL import Image


def convert_to_base64(pil_image):
    """
    Convert PIL images to Base64 encoded strings

    :param pil_image: PIL image
    :return: Re-sized Base64 string
    """

    buffered = BytesIO()
    pil_image.save(buffered, format="JPEG")  # You can change the format if needed
    img_str = base64.b64encode(buffered.getvalue()).decode("utf-8")
    return img_str


def plt_img_base64(img_base64):
    """
    Display base64 encoded string as image

    :param img_base64:  Base64 string
    """
    # Create an HTML img tag with the base64 string as the source
    image_html = f'<img src="data:image/jpeg;base64,{img_base64}" />'
    # Display the image by rendering the HTML
    display(HTML(image_html))


file_path = "../../../static/img/ollama_example_img.jpg"

image_b64 = convert_to_base64(pil_image)
plt_img_base64(image_b64)
```

```python
from langchain.messages import HumanMessage
from langchain_ollama import ChatOllama

llm = ChatOllama(model="bakllava", temperature=0)


def prompt_func(data):
    text = data["text"]
    image = data["image"]

    image_part = {
        "type": "image_url",
        "image_url": f"data:image/jpeg;base64,{image}",
    }

    content_parts = []

    text_part = {"type": "text", "text": text}

    content_parts.append(image_part)
    content_parts.append(text_part)

    return [HumanMessage(content=content_parts)]


from langchain_core.output_parsers import StrOutputParser

chain = prompt_func | llm | StrOutputParser()

query_chain = chain.invoke(
    {"text": "What is the Dollar-based gross retention rate?", "image": image_b64}
)

print(query_chain)
```

```text
90%
```

## Log probabilities

`ChatOllama` 通过 `logprobs` 和 `top_logprobs` 参数支持 token 级 log probabilities。log probabilities 用来表示每一步生成时各 token 的可能性大小。

### 基本用法

```python
from langchain_ollama import ChatOllama

llm = ChatOllama(model="llama3.1", logprobs=True)

response = llm.invoke("What color is the sky?")
logprobs = response.response_metadata["logprobs"]
for entry in logprobs[:5]:
    print(f"Token: {entry['token']!r:>15}  logprob: {entry['logprob']:.4f}")
```

```text
Token:           'The'  logprob: -0.1094
Token:       ' answer'  logprob: -1.7309
Token:             ','  logprob: -1.5854
Token:           ' of'  logprob: -0.4066
Token:       ' course'  logprob: -0.0000
```

### 每个 token 的 Top-K 候选

使用 `top_logprobs` 可以返回每个位置上最可能的候选 token：

```python
llm = ChatOllama(model="llama3.1", logprobs=True, top_logprobs=3)

response = llm.invoke("The capital of France is")
logprobs = response.response_metadata["logprobs"]
for entry in logprobs[:3]:
    print(f"Chosen: {entry['token']!r}")
    if entry.get("top_logprobs"):
        for alt in entry["top_logprobs"]:
            print(f"    {alt['token']!r:>12}  logprob: {alt['logprob']:.4f}")
```

```text
Chosen: 'Paris'
         'Paris'  logprob: -0.5567
           'The'  logprob: -0.9152
            '**'  logprob: -4.0410
Chosen: '.'
             '.'  logprob: -0.3831
    '<|eot_id|>'  logprob: -1.5511
             '!'  logprob: -2.3379
```

## 推理模型与自定义消息角色

某些模型（例如 IBM 的 [Granite 3.2](https://ollama.com/library/granite3.2)）支持通过自定义消息角色启用 thinking 过程。

要访问 Granite 3.2 的 thinking 功能，请传入一个角色为 `"control"`、内容为 `"thinking"` 的消息。由于 `"control"` 不是标准消息角色，我们可以使用 [ChatMessage](https://reference.langchain.com/python/langchain-core/messages/chat/ChatMessage) 对象来实现：

```python
from langchain.messages import HumanMessage
from langchain_core.messages import ChatMessage
from langchain_ollama import ChatOllama

llm = ChatOllama(model="granite3.2:8b")

messages = [
    ChatMessage(role="control", content="thinking"),
    HumanMessage("What is 3^3?"),
]

response = llm.invoke(messages)
print(response.content)
```

```text
Here is my thought process:
The user is asking for the value of 3 raised to the power of 3, which is a basic exponentiation operation.

Here is my response:

3^3 (read as "3 to the power of 3") equals 27.

This calculation is performed by multiplying 3 by itself three times: 3*3*3 = 27.
```

注意，该模型除了最终回答之外，也会暴露它的思考过程。
