## 设置

要访问 Groq 模型，需要创建 Groq 账号、获取 API key，并安装 `langchain-groq` 集成包。

### 凭证

前往 [Groq console](https://console.groq.com/login?utm_source=langchain&utm_content=chat_page) 注册 Groq 并生成 API key。完成后，设置 `GROQ_API_KEY` 环境变量：

```python
import getpass
import os

if "GROQ_API_KEY" not in os.environ:
    os.environ["GROQ_API_KEY"] = getpass.getpass("Enter your Groq API key: ")
```

要启用模型调用的自动 tracing，请设置 [LangSmith](/langsmith/observability) API key：

```python
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

### 安装

LangChain 的 Groq 集成位于 `langchain-groq` 包中：

```python
pip install -qU langchain-groq
```

```python
    temperature=0,
    max_tokens=None,

    timeout=None,

    # other params...
)
```

## 视觉能力

Groq 支持部分模型的视觉能力，允许你将图片与文本提示一起发送。

<Note>
**支持视觉的模型**

- `meta-llama/llama-4-scout-17b-16e-instruct`
- `meta-llama/llama-4-maverick-17b-128e-instruct`

最新的支持视觉模型列表请参见 [Groq documentation](https://console.groq.com/docs/vision)。
</Note>

```python
from langchain_groq import ChatGroq
from langchain.messages import HumanMessage

llm = ChatGroq(model="meta-llama/llama-4-scout-17b-16e-instruct")

message = HumanMessage(
    content=[
        {"type": "text", "text": "Describe this image in detail."},
        {
            "type": "image_url",
            "image_url": {"url": "https://example.com/image.jpg"},
        },
    ]
)

response = llm.invoke([message])
print(response.content)
```

<Tip>
**图片 URL 要求**

Groq 会直接从 URL 拉取图片。请确保你的图片 URL：
- 可公开访问（不需要认证）
- 直接返回图片（无重定向）
- 每次请求的最大图片大小为 20MB
</Tip>
