[Kinetica](https://www.kinetica.com/) 是一个数据库，原生集成了对 text-to-SQL 生成的支持。

本 notebook 演示如何使用 Kinetica 将自然语言转换为 SQL，从而简化数据检索流程。这个 demo 主要用于展示文本生成工作流，而不是展示 LLM 本身的能力上限。

## 概览

在 Kinetica 的 LLM 工作流中，你需要先在数据库里创建一个 LLM context，它会提供推理所需的信息，包括表、注释、规则和样例。调用 `ChatKinetica.load_messages_from_context()` 时，会从数据库中取回这些 context 信息，并用来创建聊天提示。

聊天提示由一个 @[`SystemMessage`] 以及若干 `HumanMessage`/`AIMessage` 样例对组成，这些样例是问题与 SQL 的配对。你可以继续向这个列表追加样例对，但它并不是为典型的自然语言对话场景设计的。

当你基于这个聊天提示创建链并执行后，Kinetica LLM 会根据输入生成 SQL。你也可以选择使用 `KineticaSqlOutputParser` 来执行 SQL，并将结果作为 dataframe 返回。

目前支持两种用于 SQL 生成的 LLM：

1. **Kinetica SQL-GPT**: 该 LLM 基于 OpenAI ChatGPT API。
2. **Kinetica SqlAssist**: 该 LLM 专门为与 Kinetica 数据库集成而设计，并且可以在安全的客户本地环境中运行。

本 demo 将使用 **SqlAssist**。更多信息请参见 [Kinetica Documentation site](https://docs.kinetica.com/7.1/sql-gpt/concepts/)。

你必须在以下环境变量中设置数据库连接信息。如果你使用虚拟环境，也可以把它们配置在项目的 `.env` 文件中：

* `KINETICA_PASSWD`: 安全密码。

### 创建一些伪造的用户档案

我们将使用 `faker` 包创建一个包含 100 条伪造档案的 dataframe。

```python
from collections.abc import Generator

import pandas as pd
from faker import Faker

Faker.seed(5467)
faker = Faker(locale="en-US")


def profile_gen(count: int) -> Generator:
    for p_id in range(count):
        rec = dict(id=p_id, **faker.simple_profile())
        rec["birthdate"] = pd.Timestamp(rec["birthdate"])
        yield rec


load_df = pd.DataFrame.from_records(data=profile_gen(100), index="id")
print(load_df.head())
```

### 创建 LLM context

你可以通过 Kinetica Workbench UI 创建 LLM Context，也可以使用 `CREATE OR REPLACE CONTEXT` 语法手动创建。

这里我们通过 SQL 语法，并引用刚才创建的表，来创建一个 context。


```python
from gpudb import GPUdbSamplesClause, GPUdbSqlContext, GPUdbTableClause

table_ctx = GPUdbTableClause(table=table_name, comment="Contains user profiles.")

samples_ctx = GPUdbSamplesClause(
    samples=[
        (
            "How many users born after 1970 are there?",
            f"""
            select count(1) as num_users
                from {table_name}
                where birthdate > '1970-01-01';
            """,
        )
    ]
)

context_sql = GPUdbSqlContext(
    name=kinetica_ctx, tables=[table_ctx], samples=samples_ctx
).build_sql()

print(context_sql)
count_affected = kinetica_llm.kdbc.execute(context_sql)
count_affected
```

## 使用 LangChain 进行推理

下面的示例将基于之前创建的表和 LLM context 创建一个链。这个链会生成 SQL，并将结果数据作为 dataframe 返回。

### 从 kinetica DB 加载聊天提示

`load_messages_from_context()` 函数会从数据库中取回 context，并把它转换成一个聊天消息列表，我们再用这些消息来创建 `ChatPromptTemplate`。

```python
from langchain_core.prompts import ChatPromptTemplate

# load the context from the database
ctx_messages = kinetica_llm.load_messages_from_context(kinetica_ctx)

# Add the input prompt. This is where input question will be substituted.
ctx_messages.append(("human", "{input}"))

# Create the prompt template.
prompt_template = ChatPromptTemplate.from_messages(ctx_messages)
print(prompt_template.pretty_repr())
```

```text
COMMENT ON TABLE demo.user_profiles IS 'Contains user profiles.';

================================== Ai Message ==================================

select count(1) as num_users
    from demo.user_profiles
    where birthdate > '1970-01-01';

================================ Human Message =================================

{input}
```

### 创建链

该链的最后一个组件是 `KineticaSqlOutputParser`，它会执行 SQL 并返回 dataframe。这一步是可选的，如果去掉它，就只会返回 SQL。


```python
from langchain_kinetica import (
    KineticaSqlOutputParser,
    KineticaSqlResponse,
)

chain = prompt_template | kinetica_llm | KineticaSqlOutputParser(kdbc=kinetica_llm.kdbc)
```

### 生成 SQL

我们创建的链会接收一个问题作为输入，并返回一个 `KineticaSqlResponse`，其中包含生成出的 SQL 和数据。这个问题必须与用于构建提示的 LLM context 相关。


```python
# Here you must ask a question relevant to the LLM context provided in the
# prompt template.
response: KineticaSqlResponse = chain.invoke(
    {"input": "What users were born after 1990?"}
)

print(f"SQL: {response.sql}")
print(response.dataframe.head())
```
