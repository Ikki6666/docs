### 凭证

注册 [WRITER AI Studio](https://app.writer.com/aistudio/signup?utm_campaign=devrel)，并按照这份 [Quickstart](https://dev.writer.com/api-guides/quickstart) 获取 API key。然后，设置 `WRITER_API_KEY` 环境变量：

```python
import getpass
import os

if not os.getenv("WRITER_API_KEY"):
    os.environ["WRITER_API_KEY"] = getpass.getpass("Enter your WRITER API key: ")
```

如果你想为模型调用启用自动 tracing，也可以取消注释下面的代码来设置 [LangSmith](/langsmith/observability) API key：

```python
os.environ["LANGSMITH_TRACING"] = "true"
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
```

### 安装

`ChatWriter` 可通过 `langchain-writer` 包获取，安装方式如下：

```python
pip install -qU langchain-writer
```

### 实例化

现在我们可以实例化模型对象，以生成聊天补全：

```python
from langchain_writer import ChatWriter

llm = ChatWriter(
    model="palmyra-x5",
    temperature=0,
    max_tokens=None,
    timeout=None,
    max_retries=2,
)
```

## 用法

要使用该模型，请传入一个消息列表并调用 `invoke` 方法：

```python
messages = [
    (
        "system",
        "You are a helpful assistant that translates English to French. Translate the user sentence.",
    ),
    ("human", "I love programming."),
]
ai_msg = llm.invoke(messages)
ai_msg
```

然后，你可以访问消息内容：

```python
print(ai_msg.content)
```

## 流式输出

你也可以流式获取响应。首先创建一个 stream：

```python
messages = [
    (
        "system",
        "You are a helpful assistant that translates English to French. Translate the user sentence.",
    ),
    ("human", "I love programming. Sing a song about it"),
]
stream = llm.stream_events(messages, version="v3")
stream
```

然后遍历 stream 获取各个 chunk：

```python
for token in stream.text:
    print(token, end="", flush=True)
```

## Tool calling

像 Palmyra X5 这样的 WRITER 模型支持 [tool calling](https://dev.writer.com/api-guides/tool-calling)。你可以描述工具及其参数，模型会返回一个 JSON 对象，其中包含要调用的工具以及该工具的输入。

### 绑定工具

通过 `ChatWriter.bind_tools`，你可以很方便地把 Pydantic 类、字典 schema、LangChain 工具，甚至函数本身，作为工具传给模型。在底层，它们会被转换为如下形式的工具 schema：

```
{
    "name": "...",
    "description": "...",
    "parameters": {...}  # JSONSchema
}
```

这些 schema 会在每次模型调用时一同传入。

例如，如果要使用一个获取指定位置天气的工具，可以定义一个 Pydantic 类并将其传给 `ChatWriter.bind_tools`：

```python
from pydantic import BaseModel, Field


class GetWeather(BaseModel):
    """Get the current weather in a given location"""

    location: str = Field(description="The city and state, e.g. San Francisco, CA")


llm.bind_tools([GetWeather])
```

然后，你可以携带这个工具调用模型：

```python
ai_msg = llm.invoke(
    "what is the weather like in New York City",
)
ai_msg
```

最后，你可以访问工具调用结果，并继续执行自己的函数：

```python
print(ai_msg.tool_calls)
```

### 关于工具绑定的说明

`ChatWriter.bind_tools()` 方法不会创建一个带有已绑定工具的新实例，而是把接收到的 `tools` 和 `tool_choice` 存储在初始类实例的属性中，以便在使用 `ChatWriter` 调用 Palmyra LLM 时把它们作为参数传递。这种设计可以支持不同的工具类型，例如 `function` 和 `graph`。`Graph` 是 WRITER Palmyra 远程调用工具之一。更多信息请访问我们的 [docs](https://dev.writer.com/api-guides/knowledge-graph#knowledge-graph)。

如需了解 LangChain 中工具使用的更多信息，请参见 [LangChain tool calling documentation](https://python.langchain.com/docs/concepts/tool_calling/)。

## 批处理

你也可以批量发送请求，并设置 `max_concurrency`：

```python
ai_batch = llm.batch(
    [
        "How to cook pancakes?",
        "How to compose poem?",
        "How to run faster?",
    ],
    config={"max_concurrency": 3},
)
ai_batch
```

然后遍历批处理结果：

```python
for batch in ai_batch:
    print(batch.content)
    print("-" * 100)
```

## 异步用法

以上所有功能（调用、流式输出、批处理、工具调用）也都支持异步使用。

## Prompt templates

[Prompt templates](https://python.langchain.com/docs/concepts/prompt_templates/) 可以帮助你把用户输入和参数转换成语言模型的指令。你可以像下面这样把 `ChatWriter` 与 prompt template 一起使用：

```python
from langchain_core.prompts import ChatPromptTemplate

prompt = ChatPromptTemplate(
    [
        (
            "system",
            "You are a helpful assistant that translates {input_language} to {output_language}.",
        ),
        ("human", "{input}"),
    ]
)

chain = prompt | llm
chain.invoke(
    {
        "input_language": "English",
        "output_language": "German",
        "input": "I love programming.",
    }
)
```
