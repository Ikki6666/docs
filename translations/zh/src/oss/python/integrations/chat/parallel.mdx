[Parallel Responses API](https://docs.parallel.ai/responses-api/responses-quickstart) 使用实时网页研究来回答问题，并返回带引用的答案。

<Warning>
    Parallel 的 Chat API 已弃用。请将使用 `ChatParallel` 或 `ChatParallelWeb` 的集成替换为 Responses API。
</Warning>

## 迁移到 Responses

使用 OpenAI Python SDK 调用 `https://api.parallel.ai/v1/responses`。将现有的 Chat Completions 客户端或 `ChatParallel` 实例指向新的模型名称并不足够。Responses 使用不同的端点和请求结构。

安装 SDK：

```bash
pip install -U openai
```

将 `PARALLEL_API_KEY` 设置为你的 [Parallel API key](https://platform.parallel.ai/)，然后创建 response：

```python
import os

from openai import OpenAI

client = OpenAI(
    api_key=os.environ["PARALLEL_API_KEY"],
    base_url="https://api.parallel.ai/v1",
    timeout=120.0,
)

response = client.responses.create(
    model="parallel",
    input="Who is the current CEO of the largest cloud provider by revenue?",
    reasoning={"effort": "low"},
)

print(response.output_text)
```

使用 `model="parallel"`，并通过 `reasoning.effort` 选择研究层级：`low`、`medium`、`high` 或 `auto`。默认 effort 为 `medium`。effort 越高，执行的研究越多；`high` 请求最多可能需要一分钟。

Responses API 使用 `input` 作为请求字段。请通过 SDK 的 `response.output_text` 访问器读取答案。不要复用 Chat API 的模型名称，也不要假设其响应元数据具有相同的结构。

## 在 LangChain 中使用 Parallel

对于 agent 工具调用，请将 [Parallel 搜索工具](/oss/integrations/tools/parallel_search) 和 [提取工具](/oss/integrations/tools/parallel_extract) 与支持工具调用的模型配合使用。这些集成使用独立的 Search 和 Extract API。

如需使用由 Responses 支持的研究工具，请参阅 Parallel 的 [研究子代理指南](https://docs.parallel.ai/responses-api/responses-quickstart#use-it-as-a-research-subagent)。
