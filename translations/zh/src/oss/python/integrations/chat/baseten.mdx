## 设置

要访问 Baseten 模型，需要创建 Baseten 账号、获取 API key，并安装 `langchain-baseten` 集成包。

前往 [the Baseten website](https://app.baseten.co) 创建账号并生成 API key。完成后，设置 `BASETEN_API_KEY` 环境变量：

### 凭证

```python Set API key icon="key"
import getpass
import os

if "BASETEN_API_KEY" not in os.environ:
    os.environ["BASETEN_API_KEY"] = getpass.getpass("Enter your Baseten API key: ")
```

要为模型调用启用自动 <Tooltip tip="Log each step of a model's execution to debug and improve it">tracing</Tooltip>，请设置 [LangSmith](/langsmith/observability) API key：

```python Enable tracing icon="flask"
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

### 安装

LangChain Baseten 集成位于 `langchain-baseten` 包中：

<CodeGroup>
    ```python pip
    pip install -U langchain-baseten
    ```
    ```python uv
    uv add langchain-baseten
    ```
</CodeGroup>

## 实例化

Baseten 提供两种方式来访问聊天模型：

1. **Model APIs**：用于访问最新、最流行的开源模型。
2. **Dedicated URLs**：使用具备专用资源的特定模型部署。

这两种方式都支持，并且会自动规范化 endpoint。


```python Initialize with model slug icon="robot"
from langchain_baseten import ChatBaseten

# Option 1: Use Model APIs with model slug
model = ChatBaseten(
    model="moonshotai/Kimi-K2-Instruct-0905",  # Choose from available model slugs: https://docs.baseten.co/development/model-apis/overview#supported-models
    api_key="your-api-key",  # Or set BASETEN_API_KEY env var
)
```

```python Initialize with model URL icon="link"
from langchain_baseten import ChatBaseten

# Option 2: Use dedicated deployments with model url
model = ChatBaseten(
    model_url="https://model-<id>.api.baseten.co/environments/production/predict",
    api_key="your-api-key",  # Or set BASETEN_API_KEY env var
)
```

## 调用

```python Basic invocation icon="player-play"
# Use the chat model
response = model.invoke("Hello, how are you?")
print(response.content)
```

```text
Hello! I'm doing well, thank you for asking! How about you?
```

你也可以使用 message object 构建更复杂的对话：

<CodeGroup>
    ```python Dictionary format icon="book"
    messages = [
        {"role": "system", "content": "You are a poetry expert"},
        {"role": "user", "content": "Write a haiku about spring"},
    ]
    response = model.invoke(messages)
    print(response)
    ```
</CodeGroup>
