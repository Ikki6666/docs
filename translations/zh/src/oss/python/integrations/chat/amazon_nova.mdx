本指南简要介绍如何开始使用 Amazon Nova [chat models](/oss/langchain/models)。Amazon Nova 模型兼容 OpenAI，可通过将 OpenAI SDK 指向 Nova 端点来访问，因此可以无缝接入 LangChain 的标准接口。Amazon Nova API 提供免费层，但带有速率限制。

如果需要更高吞吐量和企业级特性的生产部署，考虑通过 [Amazon Bedrock](/oss/integrations/chat/bedrock) 使用 Amazon Nova 模型。

可以在 [Amazon Nova documentation](https://nova.amazon.com/dev/documentation) 中查看 Amazon Nova 模型、功能和 API 详情。

<Tip>
    **API Reference**

    如需查看 @[`ChatAmazonNova`] 的全部功能和配置选项，请前往 @[`ChatAmazonNova`] API reference。

    如需了解 Amazon Nova 模型的详细信息和能力，请参见 [Amazon Nova documentation](https://nova.amazon.com/dev/documentation)。
</Tip>

## 设置

要访问 Amazon Nova 模型，需要[获取 API 凭证](https://nova.amazon.com/dev)，并安装 @[`langchain-amazon-nova`] 集成包。

### 安装

<CodeGroup>
    ```bash pip
    pip install -U langchain-amazon-nova
    ```
    ```bash uv
    uv add langchain-amazon-nova
    ```
</CodeGroup>

### 凭证

将 Nova API 凭证设置为环境变量：

```python
import getpass
import os

if "NOVA_API_KEY" not in os.environ:
    os.environ["NOVA_API_KEY"] = getpass.getpass("Enter your Nova API key: ")

if "NOVA_BASE_URL" not in os.environ:
    os.environ["NOVA_BASE_URL"] = getpass.getpass("Enter your Nova base URL: ")
```

要启用模型调用的自动 tracing，请设置 [LangSmith](/langsmith/observability) API 密钥：

```python
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

## 实例化

现在可以实例化模型对象并生成聊天补全：

```python
from langchain_amazon_nova import ChatAmazonNova

model = ChatAmazonNova(
    model="nova-2-lite-v1",
    temperature=0.7,
    max_tokens=2048,
    timeout=None,
    max_retries=2,
    # other params...
)
```

<Info>
    如需查看支持参数及其说明的完整列表，请参见 [Amazon Nova documentation](https://nova.amazon.com/dev/documentation)。
</Info>

## 调用

```python
messages = [
    (
        "system",
        "You are a helpful assistant that translates English to French. Translate the user sentence.",
    ),
    ("user", "I love programming."),
]
ai_msg = model.invoke(messages)
ai_msg
```

```text
AIMessage(content="J'adore la programmation.", response_metadata={'model': 'nova-2-lite-v1', 'finish_reason': 'stop'}, id='run-12345678-1234-1234-1234-123456789abc', usage_metadata={'input_tokens': 29, 'output_tokens': 8, 'total_tokens': 37})
```

```python
print(ai_msg.content)
```

```text
J'adore la programmation.
```

## 内容块

Amazon Nova 消息可以包含单个字符串，也可以包含内容块列表。可以通过 `content_blocks` 属性访问标准化后的内容块：

```python
ai_msg.content_blocks
```

使用 `content_blocks` 会以与其他模型提供方一致的标准格式渲染内容。更多信息参见 [content blocks](/oss/langchain/messages#standard-content-blocks)。

## 流式输出

Amazon Nova 支持 token 级流式输出，可用于实时生成响应：

```python
stream = model.stream_events(messages, version="v3")
for token in stream.text:
    print(token, end="", flush=True)
```

```text
J'adore la programmation.
```

### 异步流式输出

对于异步应用，可使用 `astream_events`：

```python
import asyncio

async def main():
    stream = await model.astream_events(messages, version="v3")
    async for token in stream.text:
        print(token, end="", flush=True)

asyncio.run(main())
```

## 工具调用

Amazon Nova 在兼容模型上支持工具调用，也就是 function calling。可以通过 LangChain 的模型配置文件判断某个模型是否支持工具调用。

<Info>
    关于 Nova 工具调用的实现方式和可用参数，请参见 [tool calling documentation](https://nova.amazon.com/dev/documentation)。
</Info>

### 基础工具用法

可以使用 Pydantic 模型或 LangChain 的 @[`@tool`] 将工具绑定到模型：

```python
from pydantic import BaseModel, Field

class GetWeather(BaseModel):
    """Get the weather for a location."""

    location: str = Field(description="City name")

model_with_tools = model.bind_tools([GetWeather])
response = model_with_tools.invoke("What's the weather in Paris?")
print(response.tool_calls)
```

```text
[{'name': 'GetWeather', 'args': {'location': 'Paris'}, 'id': 'call_abc123', 'type': 'tool_call'}]
```

也可以通过 `tool_calls` 属性，以标准格式专门访问工具调用：

```python
response.tool_calls
```

```text
[{'name': 'GetWeather',
  'args': {'location': 'Paris'},
  'id': 'call_abc123',
  'type': 'tool_call'}]
```

### 使用 LangChain 工具

也可以使用标准 LangChain 工具：

```python
from langchain.tools import tool

@tool
def get_weather(location: str) -> str:
    """Get the weather for a location."""
    return f"Weather in {location}: Sunny, 72°F"

model_with_tools = model.bind_tools([get_weather])
response = model_with_tools.invoke("What's the weather in San Francisco?")
```

### 控制工具选择

Amazon Nova 支持通过 `tool_choice` 参数控制模型何时使用工具：

```python
# 由模型决定是否调用工具（默认）
model_auto = model.bind_tools([get_weather], tool_choice="auto")

# 模型必须调用工具
model_required = model.bind_tools([get_weather], tool_choice="required")

# 模型不能调用工具
model_none = model.bind_tools([get_weather], tool_choice="none")
```

<Warning>
    **Nova 的 tool_choice 取值**

    Amazon Nova 支持的 `tool_choice` 取值为 `"auto"`、`"required"` 和 `"none"`。与其他一些提供方不同，Nova 不支持 `tool_choice="any"`，也不支持将具体工具名作为 choice 值。
</Warning>

`tool_choice="required"`` 选项特别适合确保模型始终使用工具，例如结构化输出场景。


## 系统工具

Amazon Nova 提供内置系统工具，可通过集成功能增强模型能力。启用方式是在模型初始化时传入这些工具，或者在调用时作为参数传入。

### 可用的系统工具

Amazon Nova 支持以下内置工具：

#### Web grounding (nova_grounding)

grounding 工具允许模型搜索网络，并用来自外部来源的实时信息为响应提供依据。

```python
from langchain_amazon_nova import ChatAmazonNova

model_with_grounding = ChatAmazonNova(
    model="nova-2-lite-v1",
    system_tools=["nova_grounding"],
)

response = model_with_grounding.invoke("What are the latest developments in AI?")
```

grounding 工具会自动搜索相关信息，并在响应中包含引用。

#### Code interpreter (nova_code_interpreter)

code interpreter 工具允许模型在沙箱环境中编写并执行 Python 代码，适用于数学计算、数据分析和代码生成任务。

```python
from langchain_amazon_nova import ChatAmazonNova

model_with_code = ChatAmazonNova(
    model="nova-2-lite-v1",
    system_tools=["nova_code_interpreter"],
)

response = model_with_code.invoke("Calculate the fibonacci sequence up to the 10th number")
```

code interpreter 会安全执行代码，并返回代码及其输出。

### 组合系统工具

可以同时启用多个系统工具：

```python
from langchain_amazon_nova import ChatAmazonNova

model_with_tools = ChatAmazonNova(
    model="nova-2-lite-v1",
    system_tools=["nova_grounding", "nova_code_interpreter"],
)

response = model_with_tools.invoke(
    "Search for the current price of Bitcoin and calculate its 7-day moving average"
)
```

模型会根据查询自动判断需要使用哪个或哪些工具。

### 将系统工具作为调用参数

也可以在调用时指定系统工具，而不是在初始化期间指定：

```python
from langchain_amazon_nova import ChatAmazonNova

model = ChatAmazonNova(model="nova-2-lite-v1")

# 仅为这次调用启用 grounding
response = model.invoke(
    "What's the weather today?",
    system_tools=["nova_grounding"]
)
```

当你希望同一个模型实例针对不同查询使用不同系统工具时，这种方式很有用。

<Info>
    **工具输出与引用**

    使用系统工具时，模型响应会包含：
    - 主文本响应
    - 引用或参考来源（适用于 grounding 工具）
    - 代码执行结果（适用于 code interpreter）

    这些输出会包含在消息的 `response_metadata` 中，可用于展示来源或调试。
</Info>

如需系统工具、参数和能力的完整详情，请参见 [Amazon Nova documentation](https://nova.amazon.com/dev/documentation)。

## 结构化输出

Amazon Nova 支持通过 `with_structured_output()` 方法生成结构化输出，可以结合 Pydantic 模型或 JSON schema 获取结构化格式的 LLM 响应。

### 使用 Pydantic 的基础示例

可以使用 Pydantic 模型约束 LLM 响应，使其匹配指定结构：

```python
from pydantic import BaseModel, Field
from langchain_amazon_nova import ChatAmazonNova

class Person(BaseModel):
    """Information about a person."""
    name: str = Field(description="The person's name")
    age: int = Field(description="The person's age")

model = ChatAmazonNova(model="nova-pro-v1")
structured_model = model.with_structured_output(Person)

result = structured_model.invoke("John is 30 years old")
print(result)
```

```output
Person(name='John', age=30)
```

### JSON schema 支持

也可以直接提供 JSON schema：

```python
json_schema = {
    "type": "object",
    "properties": {
        "name": {"type": "string"},
        "age": {"type": "integer"}
    },
    "required": ["name", "age"]
}

structured_model = model.with_structured_output(json_schema)
result = structured_model.invoke("Sarah is 28 years old")
print(result)
```

```output
{'name': 'Sarah', 'age': 28}
```

### 流式结构化输出

结构化输出可以与流式输出一起工作，完整响应到达后会返回解析后的对象：

```python
from pydantic import BaseModel, Field

class Person(BaseModel):
    """Information about a person."""
    name: str = Field(description="The person's name")
    age: int = Field(description="The person's age")

structured_model = model.with_structured_output(Person)

for chunk in structured_model.stream("Michael is 35 years old"):
    print(chunk)
```

```output
Person(name='Michael', age=35)
```

### 访问原始消息

`include_raw` 参数允许同时访问解析后的输出和原始 AIMessage：

```python
structured_model = model.with_structured_output(Person, include_raw=True)
result = structured_model.invoke("John is 30 years old")

print(f"Parsed: {result['parsed']}")
print(f"Raw message: {result['raw']}")
```

```output
Parsed: Person(name='John', age=30)
Raw message: AIMessage(content='', additional_kwargs={'tool_calls': [...]}, ...)
```

这在调试、访问元数据，或者处理解析可能失败的边界情况时很有用。

### 嵌套和复杂 schema

可以使用嵌套的 Pydantic 模型来表达复杂数据结构：

```python
from pydantic import BaseModel, Field
from typing import List

class Address(BaseModel):
    """A physical address."""
    street: str
    city: str
    country: str

class Person(BaseModel):
    """Information about a person."""
    name: str
    age: int
    addresses: List[Address] = Field(description="List of addresses")

structured_model = model.with_structured_output(Person)
result = structured_model.invoke(
    "John is 30 years old. He lives at 123 Main St in Seattle, USA "
    "and has a vacation home at 456 Beach Rd in Miami, USA."
)
print(result)
```

<Info>
    **实现细节**

    结构化输出底层使用 Nova 的工具调用能力，并结合 `tool_choice='required'` 来确保结构化响应的一致性。schema 会被转换为工具定义，而工具调用响应会被解析回请求的格式。
</Info>

## 异步操作

对于需要高吞吐量的生产应用，请使用原生异步操作：

```python
import asyncio

async def main():
    messages = [
        ("system", "You are a helpful assistant."),
        ("human", "What is the capital of France?"),
    ]
    response = await model.ainvoke(messages)
    print(response.content)

asyncio.run(main())
```

```text
The capital of France is Paris.
```

## 链式组合

Amazon Nova 模型可以与 LangChain 的 LCEL（LangChain Expression Language）无缝协作，用于构建链：

```python
from langchain_core.output_parsers import StrOutputParser
from langchain_core.prompts import ChatPromptTemplate

prompt = ChatPromptTemplate.from_messages([
    ("system", "You are a helpful assistant that translates {input_language} to {output_language}."),
    ("human", "{text}"),
])

chain = prompt | model | StrOutputParser()

result = chain.invoke({
    "input_language": "English",
    "output_language": "Spanish",
    "text": "Hello, how are you?"
})
print(result)
```

```text
Hola, ¿cómo estás?
```

## 错误处理

模型内置了重试逻辑，并支持可配置参数：

```python
model = ChatAmazonNova(
    model="nova-2-lite-v1",
    max_retries=3,  # Number of retries on failure
    timeout=60.0,   # Request timeout in seconds
)
```

如需对重试进行更细粒度的控制，请使用 `with_retry` 方法：

```python
model_with_custom_retry = model.with_retry(
    stop_after_attempt=5,
    wait_exponential_jitter=True,
)
```

## 故障排查

### 连接问题

如果遇到连接错误，请确认环境变量已正确设置：

```python
import os
print(f"API Key set: {'NOVA_API_KEY' in os.environ}")
print(f"Base URL: {os.environ.get('NOVA_BASE_URL', 'Not set')}")
```

关于身份验证和连接问题，请参见 [Amazon Nova documentation](https://nova.amazon.com/dev/documentation)。

### 压缩错误

<Note>
    @[`ChatAmazonNova`] 客户端会自动禁用压缩，以避免潜在的解压问题。
</Note>

如果需要自定义 HTTP 客户端行为，可以访问底层 OpenAI 客户端：

```python
# 客户端已自动配置为不使用压缩
model = ChatAmazonNova(model="nova-2-lite-v1")
# model.client is the configured OpenAI client
```

### 工具调用校验错误

如果在绑定工具时收到校验错误，请确认该模型支持工具调用。
