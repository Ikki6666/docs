[Xinference](https://github.com/xorbitsai/inference) 是一个功能强大且用途广泛的库，用于部署 LLM、语音识别模型和多模态模型，哪怕是在你的笔记本电脑上也可以运行。它支持多种与 GGML 兼容的模型，例如 chatglm、baichuan、whisper、vicuna、orca 等等。

## 设置

通过 PyPI 安装 `Xinference`：

```python
pip install -qU  "xinference[all]"
```

### 在本地或分布式集群中部署 xinference

对于本地部署，运行 `xinference`。

要在集群中部署 Xinference，先使用 `xinference-supervisor` 启动一个 Xinference supervisor。你也可以使用 `-p` 选项指定端口，使用 `-H` 指定 host。默认端口为 8080，默认 host 为 0.0.0.0。

然后，在每台要运行 worker 的服务器上使用 `xinference-worker` 启动 Xinference worker。

更多信息请参阅 [Xinference](https://github.com/xorbitsai/inference) 的 README 文件。

### Wrapper

要在 LangChain 中使用 Xinference，你首先需要启动一个模型。你可以使用命令行界面（CLI）来完成：

```python
%xinference launch -n vicuna-v1.3 -f ggmlv3 -q q4_0
```

```text
Model uid: 7167b2b0-2a04-11ee-83f0-d29396a3f064
```

## 安装

LangChain Xinference 集成位于 `langchain-xinference` 包中：

```python
pip install -qU langchain-xinference
```

如果要使用结构化输出，请确保你使用的是最新版本的 Xinference。

## 实例化

现在我们可以实例化模型对象并生成聊天补全：

```python
from langchain_xinference.chat_models import ChatXinference

llm = ChatXinference(
    server_url="your_server_url", model_uid="7167b2b0-2a04-11ee-83f0-d29396a3f064"
)

llm.invoke(
    "Q: where can we visit in the capital of France?",
    config={"max_tokens": 1024},
)
```

## 调用

```python
from langchain.messages import HumanMessage, SystemMessage
from langchain_xinference.chat_models import ChatXinference

llm = ChatXinference(
    server_url="your_server_url", model_uid="7167b2b0-2a04-11ee-83f0-d29396a3f064"
)

system_message = "You are a helpful assistant that translates English to French. Translate the user sentence."
human_message = "I love programming."

llm.invoke([HumanMessage(content=human_message), SystemMessage(content=system_message)])
```
