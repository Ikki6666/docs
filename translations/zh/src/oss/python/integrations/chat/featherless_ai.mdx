## 设置

要访问 Featherless AI 模型，需要创建 Featherless AI 账号、获取 API key，并安装 `langchain-featherless-ai` 集成包。

### 凭证

前往 [featherless.ai/](https://featherless.ai/) 注册 FeatherlessAI 并生成 API key。完成后，设置 `FEATHERLESSAI_API_KEY` 环境变量：

```python
import getpass
import os

if not os.getenv("FEATHERLESSAI_API_KEY"):
    os.environ["FEATHERLESSAI_API_KEY"] = getpass.getpass(
        "Enter your FeatherlessAI API key: "
    )
```

如果希望为模型调用启用自动 tracing，也可以取消下方注释并设置 [LangSmith](/langsmith/observability) API key：

```python
os.environ["LANGSMITH_TRACING"] = "true"
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
```

### 安装

LangChain 的 FeatherlessAi 集成位于 `langchain-featherless-ai` 包中：

```python
pip install -qU langchain-featherless-ai
```

## 实例化

现在可以实例化模型对象并生成聊天补全：

```python
from langchain_featherless_ai import ChatFeatherlessAi

llm = ChatFeatherlessAi(
    model="featherless-ai/Qwerky-72B",
    temperature=0.9,
    max_tokens=None,
    timeout=None,
)
```
