## 设置

要访问 VertexAI 模型，需要创建 Google Cloud Platform 账号、配置凭证，并安装 `langchain-google-vertexai` 集成包。

### 凭证

要使用该集成，必须满足以下任一条件：

- 已为你的环境配置好凭证（gcloud、workload identity 等）
- 将服务账号 JSON 文件路径保存到 `GOOGLE_APPLICATION_CREDENTIALS` 环境变量中

该代码库使用 `google.auth` 库。它会先查找上面提到的 application credentials 变量，然后再查找系统级认证。

如需了解更多信息，请参见 `google.auth` 的 [API reference](https://googleapis.dev/python/google-auth/latest/reference/google.auth.html#module-google.auth)。

要启用模型调用的自动 tracing，请设置 [LangSmith](/langsmith/observability) API key：

```python
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

### 安装

LangChain 的 VertexAI 集成位于 `langchain-google-vertexai` 包中：

```python
pip install -qU langchain-google-vertexai
```

## 实例化

现在可以实例化模型对象并生成聊天补全：

```python
from langchain_google_vertexai import ChatVertexAI

llm = ChatVertexAI(
    model="gemini-2.5-flash",
    temperature=0,
    max_tokens=None,
    max_retries=6,
    stop=None,
    # other params...
)
```

## 内置工具

Gemini 支持一系列在服务端执行的工具。

### Google 搜索

<Info>
    **Requires `langchain-google-vertexai>=2.0.11`**
</Info>

Gemini 可以执行 Google 搜索，并利用结果来[支撑其响应](https://ai.google.dev/gemini-api/docs/grounding)：

```python
from langchain_google_vertexai import ChatVertexAI

llm = ChatVertexAI(model="gemini-2.5-flash").bind_tools([{"google_search": {}}])

response = llm.invoke("What is today's news?")
```

### 代码执行

<Info>
    **Requires `langchain-google-vertexai>=2.0.25`**
</Info>

Gemini 可以[生成并执行 Python 代码](https://ai.google.dev/gemini-api/docs/code-execution)：

```python
from langchain_google_vertexai import ChatVertexAI

llm = ChatVertexAI(model="gemini-2.5-flash").bind_tools([{"code_execution": {}}])

response = llm.invoke("What is 3^3?")
```
