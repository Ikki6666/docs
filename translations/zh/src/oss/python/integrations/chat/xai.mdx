## 设置

要访问 xAI 模型，你需要创建一个 xAI 账户、获取 API key，并安装 `langchain-xai` 集成包。

### 凭证

前往[此页面](https://console.x.ai/)注册 xAI 并生成 API key。完成后，设置 `XAI_API_KEY` 环境变量：

```python
import getpass
import os

if "XAI_API_KEY" not in os.environ:
    os.environ["XAI_API_KEY"] = getpass.getpass("Enter your xAI API key: ")
```

要为模型调用启用自动 tracing，请设置你的 [LangSmith](/langsmith/observability) API key：

```python
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

### 安装

LangChain xAI 集成位于 `langchain-xai` 包中：

```python
pip install -qU langchain-xai
```

## 实例化

现在我们可以实例化模型对象并生成聊天补全：

```python
from langchain_xai import ChatXAI

llm = ChatXAI(
    model="grok-beta",
    temperature=0,
    max_tokens=None,
    timeout=None,
    max_retries=2,
    # other params...
)
```

```python
messages = [
```

## Tool calling

ChatXAI 提供 [tool calling](https://docs.x.ai/docs#capabilities) API（这里 “tool calling” 和 “function calling” 两个术语可互换），你可以描述工具及其参数，并让模型返回一个 JSON 对象，其中包含要调用的工具以及该工具的输入。tool calling 对构建可使用工具的 chain 和 agent 非常有用，也常用于获取更结构化的模型输出。

### ChatXAI.bind_tools()

通过 `ChatXAI.bind_tools`，我们可以轻松地把 Pydantic 类、dict schema、LangChain 工具，甚至函数本身，作为工具传给模型。在底层，它们会被转换为 OpenAI 风格的工具 schema，形式如下：

```
{
    "name": "...",
    "description": "...",
    "parameters": {...}  # JSONSchema
}
```

并在每次模型调用时一同传入。

```python
from pydantic import BaseModel, Field


class GetWeather(BaseModel):
    """Get the current weather in a given location"""

    location: str = Field(description="The city and state, e.g. San Francisco, CA")


llm_with_tools = llm.bind_tools([GetWeather])
```

```python
ai_msg = llm_with_tools.invoke(
    "what is the weather like in San Francisco",
)
ai_msg
```


## Live search

xAI 支持 [Live Search](https://docs.x.ai/docs/guides/live-search) 功能，可让 Grok 通过网页搜索结果来为答案提供依据：

```python
from langchain_xai import ChatXAI

llm = ChatXAI(
    model="grok-3-latest",
    search_parameters={
        "mode": "auto",
        # Example optional parameters below:
        "max_search_results": 3,
        "from_date": "2025-05-26",
        "to_date": "2025-05-27",
    },
)

llm.invoke("Provide me a digest of world news in the last 24 hours.")
```

如需查看完整的网页搜索选项，请参见 [xAI docs](https://docs.x.ai/docs/guides/live-search)。
