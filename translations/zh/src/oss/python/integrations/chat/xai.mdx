## 设置

要访问 xAI 模型，你需要创建一个 xAI 账户、获取 API key，并安装 `langchain-xai` 集成包。

### 凭证

前往[此页面](https://console.x.ai/)注册 xAI 并生成 API key。完成后，设置 `XAI_API_KEY` 环境变量：

```python
import getpass
import os

if "XAI_API_KEY" not in os.environ:
    os.environ["XAI_API_KEY"] = getpass.getpass("Enter your xAI API key: ")
```

要为模型调用启用自动 tracing，请设置你的 [LangSmith](/langsmith/observability) API key：

```python
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

### 安装

LangChain xAI 集成位于 `langchain-xai` 包中：

```python
pip install -qU langchain-xai
```

## 实例化

现在我们可以实例化模型对象并生成聊天补全：

```python
from langchain_xai import ChatXAI

llm = ChatXAI(
    model="grok-beta",
    temperature=0,
    max_tokens=None,
    timeout=None,
    max_retries=2,
    # other params...
)
```

```python
messages = [
```

## Tool calling

ChatXAI 提供 [tool calling](https://docs.x.ai/docs#capabilities) API（这里 “tool calling” 和 “function calling” 两个术语可互换），你可以描述工具及其参数，并让模型返回一个 JSON 对象，其中包含要调用的工具以及该工具的输入。tool calling 对构建可使用工具的 chain 和 agent 非常有用，也常用于获取更结构化的模型输出。

### ChatXAI.bind_tools()

通过 `ChatXAI.bind_tools`，我们可以轻松地把 Pydantic 类、dict schema、LangChain 工具，甚至函数本身，作为工具传给模型。在底层，它们会被转换为 OpenAI 风格的工具 schema，形式如下：

```
{
    "name": "...",
    "description": "...",
    "parameters": {...}  # JSONSchema
}
```

并在每次模型调用时一同传入。

```python
from pydantic import BaseModel, Field


class GetWeather(BaseModel):
    """Get the current weather in a given location"""

    location: str = Field(description="The city and state, e.g. San Francisco, CA")


llm_with_tools = llm.bind_tools([GetWeather])
```

```python
ai_msg = llm_with_tools.invoke(
    "what is the weather like in San Francisco",
)
ai_msg
```


## 网页搜索

xAI 之前的 Live Search 配置使用 `search_parameters` 构造函数参数，该参数现已弃用。若要使用当前的网页搜索结果来为 Grok 的响应提供依据，请改为绑定 xAI 内置的 `web_search` 工具：

```python
from langchain_xai import ChatXAI

llm = ChatXAI(model="grok-4", temperature=0).bind_tools([{"type": "web_search"}])

response = llm.invoke("Provide me a digest of world news in the last 24 hours.")
response.content
```

如需了解当前可用的内置工具（包括 Web Search 和 X Search），请参阅 [xAI 的工具文档](https://docs.x.ai/developers/tools/overview)。

## 推理力度

[部分 xAI 模型](https://docs.x.ai/docs/models#model-pricing)支持标准的 [`reasoning_effort`](/oss/langchain/models#reasoning) 参数，该参数用于控制模型执行的推理量。你可以在构造模型时设置它，也可以在每次调用时设置：

```python
from langchain_xai import ChatXAI

model = ChatXAI(model="grok-4.3")
response = model.invoke(
    "Analyze the trade-offs between microservices and monolithic architectures",
    reasoning_effort="high",
)
```

<Note>
    作为标准参数使用的 `reasoning_effort` 需要 `langchain-xai>=1.3.0`。`ChatXAI` 会将其嵌套在 `extra_body.reasoning_effort` 下发送。
</Note>

请查看模型的 [profile](/oss/langchain/models#model-profiles)，了解它支持哪些力度层级：

```python
model.profile["reasoning_effort_levels"]  # e.g. ['low', 'medium', 'high']
```
