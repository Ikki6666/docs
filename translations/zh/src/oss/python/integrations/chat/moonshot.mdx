## 设置

要访问 Moonshot 模型，你需要 Moonshot 账号、API key，以及 `langchain-moonshot` 集成包。

### 凭证

前往 [Moonshot console](https://platform.moonshot.ai/console/api-keys) 创建 API key。完成后，设置 `MOONSHOT_API_KEY` 环境变量。

```python
import getpass
import os

if not os.getenv("MOONSHOT_API_KEY"):
    os.environ["MOONSHOT_API_KEY"] = getpass.getpass("Enter your Moonshot API key: ")
```

默认情况下，该包使用 Moonshot 的国际 endpoint（`https://api.moonshot.ai/v1`）。如果要改用中国区 endpoint，请设置：

```python
import os

os.environ["MOONSHOT_API_BASE"] = "https://api.moonshot.cn/v1"
```

要启用模型调用的自动 tracing，请设置 [LangSmith](/langsmith/observability) API key：

```python
import getpass
import os

os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

## 实例化

现在可以实例化模型对象并生成响应：

```python
from langchain_moonshot import ChatMoonshot

llm = ChatMoonshot(
    model="kimi-k2.5",
    thinking=False,
    temperature=0.6,
    max_retries=2,
    # prompt_cache_key="docs-example-cache",
    # safety_identifier="docs-example-user",
    # max_completion_tokens=1024,
)
```

<Note>
    对于 `kimi-k2.5`，如果设置了 `temperature`，那么在 `thinking=True` 时它必须为 `1.0`，在 `thinking=False` 时必须为 `0.6`。如果省略 `thinking`（或将其设为 `None`），校验时会视为启用了 thinking。若要使用 `temperature=0.6`，请显式设置 `thinking=False`。
</Note>

## 调用

```python
messages = [
    ("system", "You are a concise bilingual assistant."),
    ("human", "Summarize why Moonshot reasoning models are useful in two bullet points."),
]

ai_msg = llm.invoke(messages)

print(ai_msg.text)
print(ai_msg.usage_metadata)
```


## 推理输出

`ChatMoonshot` 会在非流式和流式响应中都保留 Moonshot 的 `reasoning_content` 字段。

```python
reasoning_llm = ChatMoonshot(
    model="kimi-k2.5",
    thinking=True,
    temperature=1.0,
)

ai_msg = reasoning_llm.invoke(
    "Explain in two bullet points why reasoning models are useful."
)

print(ai_msg.text)
print(ai_msg.additional_kwargs.get("reasoning_content"))
```

## 流式输出

要在流式输出时恢复 usage metadata，请设置 `stream_usage=True`：

```python
streaming_llm = ChatMoonshot(
    model="kimi-k2.5",
    thinking=True,
    temperature=1.0,
    stream_usage=True,
)

stream = streaming_llm.stream_events(
    "Explain streaming output in two short bullet points.", version="v3"
)
for token in stream.text:
    print(token, end="", flush=True)
for reasoning_token in stream.reasoning:
    print(f"\n[reasoning] {reasoning_token}", end="", flush=True)
print()
print(stream.output.usage_metadata)
```

## Tool calling

Moonshot 通过 `bind_tools` 支持 LangChain tool calling：

```python
from langchain.messages import ToolMessage
from langchain.tools import tool


@tool
def add(a: int, b: int) -> int:
    """Add two integers."""
    return a + b


@tool
def multiply(a: int, b: int) -> int:
    """Multiply two integers."""
    return a * b


llm_with_tools = ChatMoonshot(
    model="kimi-k2.5",
    thinking=False,
    temperature=0.6,
).bind_tools([add, multiply])

messages = [
    ("system", "Use the provided math tools before answering."),
    ("human", "Add 17 and 25, multiply 12 by 13, then summarize the results."),
]

response = llm_with_tools.invoke(messages)
print(response.tool_calls)

if response.tool_calls:
    tools_map = {"add": add, "multiply": multiply}
    tool_results = []
    for tool_call in response.tool_calls:
        result = tools_map[tool_call["name"]].invoke(tool_call["args"])
        tool_results.append(
            ToolMessage(content=str(result), tool_call_id=tool_call["id"])
        )

    final_response = llm_with_tools.invoke([*messages, response, *tool_results])
    print(final_response.text)
```

<Note>
    对于启用 `thinking=True` 的 `kimi-k2.5`，`tool_choice` 必须是 `"auto"` 或 `"none"`。不支持强制指定工具（例如直接指定函数名）。
</Note>

## 结构化输出

Moonshot 通过 LangChain 的 `with_structured_output(...)` 支持结构化输出。Moonshot 在这个包中不提供独立的 `json_schema` steering 路径，因此 `method="json_schema"` 会被有意降级为 `function_calling`。

```python
from pydantic import BaseModel, Field


class WeatherAnswer(BaseModel):
    city: str = Field(description="City name")
    summary: str = Field(description="One-sentence weather summary")


structured_llm = ChatMoonshot(
    model="kimi-k2.5",
    thinking=False,
    temperature=0.6,
).with_structured_output(WeatherAnswer)

result = structured_llm.invoke("Summarize today's weather in Shanghai.")
print(result)
```

## 多模态输入

支持视觉的 Moonshot 模型接受 OpenAI 风格的 `image_url` content block：

```python
from langchain.messages import HumanMessage

vision_llm = ChatMoonshot(
    model="moonshot-v1-32k-vision-preview",
)

message = HumanMessage(
    content=[
        {"type": "text", "text": "Describe the image and mention one concrete detail."},
        {
            "type": "image_url",
            "image_url": {"url": "data:image/png;base64,<your-base64-image>"},
        },
    ]
)

response = vision_llm.invoke([message])
print(response.text)
```

## Moonshot 专属说明

- `ChatMoonshot` 是一个独立的 LangChain 集成包，用于接入 Moonshot AI 聊天模型，底层基于 `langchain-openai`。
- 该包暴露的 Moonshot 专属请求控制项包括 `thinking`、`prompt_cache_key`、`safety_identifier` 和 `max_completion_tokens`。
- 相比通用的 OpenAI-compatible chat model，`kimi-k2.5` 的参数校验更严格。
- 对于 `kimi-k2.5`，`top_p` 必须保持为 `0.95`，`n` 必须保持为 `1`，并且 `presence_penalty` 与 `frequency_penalty` 都必须保持为 `0.0`。
- 当 `thinking=True` 时，`kimi-k2.5` 不支持 Moonshot 内置的 `$web_search`。
