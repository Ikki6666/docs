## 设置

要访问 Perplexity 模型，你需要创建一个 Perplexity 账户、获取 API key，并安装 `langchain-perplexity` 集成包。

### 凭证

前往[此页面](https://www.perplexity.ai/)注册 Perplexity 并生成 API key。完成后，设置 `PPLX_API_KEY` 环境变量：

```python
import getpass
import os

if "PPLX_API_KEY" not in os.environ:
    os.environ["PPLX_API_KEY"] = getpass.getpass("Enter your Perplexity API key: ")
```

要为模型调用启用自动 tracing，请设置你的 [LangSmith](/langsmith/observability) API key：

```python
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

```python
from langchain_core.prompts import ChatPromptTemplate
from langchain_perplexity import ChatPerplexity
```

下面的代码假设你的 `PPLX_API_KEY` 已经设置在环境变量中。如果你希望手动指定 API key，并同时选择不同模型，可以使用下面的代码：

```python
chat = ChatPerplexity(temperature=0, pplx_api_key="YOUR_API_KEY", model="sonar")
```

你可以查看 [Perplexity 可用模型列表](https://docs.perplexity.ai/docs/model-cards)。为了便于复现，我们也可以在这个 notebook 中把 API key 作为输入动态设置。

```python
chat = ChatPerplexity(temperature=0, model="sonar")
```

```python
system = "You are a helpful assistant."
human = "{input}"
prompt = ChatPromptTemplate.from_messages([("system", system), ("human", human)])

chain = prompt | chat
response = chain.invoke({"input": "Why is the Higgs Boson important?"})
response.content
```

## Agent API 支持（`use_responses_api`）

`ChatPerplexity` 也可以通过设置 `use_responses_api`，把请求路由到 Perplexity 的 [Agent API](https://docs.perplexity.ai/docs/agent-api/quickstart)（即带有 Perplexity 风格的 Responses API）。它的使用心智模型与 [`ChatOpenAI.use_responses_api`](https://reference.langchain.com/python/langchain-openai/chat_models/ChatOpenAI) 相同：一个类、两个 endpoint，由单个开关控制。

| Value | Endpoint | Notes |
| :--- | :--- | :--- |
| `None`（默认） | 自动检测 | 当请求使用内置的 Perplexity 工具（`web_search`、`fetch_url`、`finance_search`、`people_search`），或包含仅 Responses 支持的字段（`previous_response_id`、`instructions`、`input`、`include`）时，会路由到 Agent API。否则会路由到 Chat Completions。 |
| `True` | Agent API | 始终使用 `client.responses.create()`。 |
| `False` | Chat Completions | 始终使用 `client.chat.completions.create()`。 |

Agent API 让 `ChatPerplexity` 能访问 Perplexity 的内置工具（实时网页搜索、URL 抓取、金融搜索、人物搜索）以及有状态的 agent 字段（`previous_response_id`、`instructions`、`include`），这些能力在 Chat Completions 中不可用。已有的 `ChatPerplexity(model="sonar")` 调用者不会看到行为变化，纯文本请求默认仍然走 Chat Completions。

```python
from langchain_perplexity import ChatPerplexity

chat = ChatPerplexity(
    model="openai/gpt-5.5",
    use_responses_api=True,
)
response = chat.invoke("What did Apple announce at WWDC this week?")
response.content
```

你也可以传入内置工具，让自动检测自行完成路由，无需显式设置这个开关：

```python
chat = ChatPerplexity(model="openai/gpt-5.5")

response = chat.invoke(
    "Summarize the latest LangChain release notes.",
    tools=[{"type": "web_search"}],
)
response.content
```

当通过 Agent API 路由时，响应对象会带有更丰富的元数据：

- `usage_metadata` 会根据 Responses 形态的 `usage` 载荷填充（`input_tokens`、`output_tokens`、`total_tokens`）。
- `response_metadata` 会带上协议层字段：`id`、`model`、`status` 和 `object`。
- `additional_kwargs` 会在存在时暴露 Perplexity 特有输出：`citations`、`images`、`related_questions`、`search_results`、`videos` 和 `reasoning_steps`。
- 模型返回的工具调用会像 `ChatOpenAI` 一样出现在 `response.tool_calls` 中。

<Warning>
    Agent API 不接受仅适用于 Chat Completions 的采样和控制参数。当 `ChatPerplexity` 通过 Agent API 路由时（无论是显式指定还是自动检测），以下字段都会从发出的 payload 中移除，并记录 `WARNING` 日志：`temperature`、`top_p`、`top_k`、`stop` 和 `metadata`。类默认的 `temperature` 会被静默忽略，因为 `_default_params` 会在每次调用时注入它，但如果是用户显式传入 `temperature`，仍然会给出警告。

    `tool_choice` 不会被静默移除，而是在通过 Agent API 路由时直接抛出 `ValueError`，因为下游 agent 循环无法从缺失的强制工具选择中恢复。
</Warning>

查看 [Perplexity Agent API model list](https://docs.perplexity.ai/docs/agent-api/models)，了解此 endpoint 提供的完整模型列表，例如 `openai/gpt-5.5`、`anthropic/claude-sonnet-4-6`、`google/gemini-3-1-pro`。

## 通过 `ChatPerplexity` 使用 Perplexity 专有参数

你也可以通过 `ChatPerplexity` 使用 Perplexity 专有参数。例如，`search_domain_filter`、`return_images`、`return_related_questions` 或 `search_recency_filter` 等参数，可以像下面这样通过 `extra_body` 传入：

```python
chat = ChatPerplexity(temperature=0.7, model="sonar")
response = chat.invoke(
    "Tell me a joke about cats", extra_body={"search_recency_filter": "week"}
)
response.content
```

```text
"Sure, here's a cat joke for you:\n\nWhy are cats bad storytellers?\n\nBecause they only have one tale. (Pun alert!)\n\nSource: OneLineFun.com [4]"
```

### 访问搜索结果元数据

Perplexity 通常会提供它参考过的网页列表（`search_results`）。
你不需要传入任何特殊参数，这个列表会直接放在
`response.additional_kwargs["search_results"]` 中。

```python
chat = ChatPerplexity(temperature=0, model="sonar")

response = chat.invoke(
    "What is the tallest mountain in South America?",
)

# Main answer
print(response.content)

# First two supporting search results
response.additional_kwargs["search_results"][:2]
```

```text
The tallest mountain in South America is Aconcagua. It has a summit elevation of approximately 6,961 meters (22,838 feet), making it not only the highest peak in South America but also the highest mountain in the Americas, the Western Hemisphere, and the Southern Hemisphere[1]\[2]\[4].

Aconcagua is located in the Principal Cordillera of the Andes mountain range, in Mendoza Province, Argentina, near the border with Chile[1]\[2]\[4]. It is of volcanic origin but is not an active volcano[4]. The mountain is part of Aconcagua Provincial Park and features several glaciers, including the large Ventisquero Horcones Inferior glacier[1].

In summary, Aconcagua stands as the tallest mountain in South America at about 6,961 meters (22,838 feet) in height.
```

## `ChatPerplexity` 也支持流式输出

```python
chat = ChatPerplexity(temperature=0.7, model="sonar")

stream = chat.stream_events("Give me a list of famous tourist attractions in Pakistan", version="v3")
for token in stream.text:
    print(token, end="", flush=True)
```

## `ChatPerplexity` 为 tier 3+ 用户支持结构化输出

```python
from pydantic import BaseModel


class AnswerFormat(BaseModel):
    first_name: str
    last_name: str
    year_of_birth: int
    num_seasons_in_nba: int


chat = ChatPerplexity(temperature=0.7, model="sonar-pro")
structured_chat = chat.with_structured_output(AnswerFormat)
response = structured_chat.invoke(
    "Tell me about Michael Jordan. Return your answer "
    "as JSON with keys first_name (str), last_name (str), "
    "year_of_birth (int), and num_seasons_in_nba (int)."
)
response
```

```text
AnswerFormat(first_name='Michael', last_name='Jordan', year_of_birth=1963, num_seasons_in_nba=15)
```
