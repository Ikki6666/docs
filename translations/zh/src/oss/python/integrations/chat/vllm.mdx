vLLM 可以部署为一个模拟 OpenAI API 协议的服务器。这使得 vLLM 能作为使用 OpenAI API 的应用的直接替代方案。这个服务器可以用与 OpenAI API 相同的格式进行查询。

## 概览

本文将帮助你开始使用 vLLM [chat models](/oss/langchain/models)，它依赖 `langchain-openai` 包。有关 @[`ChatOpenAI`] 所有功能和配置的详细文档，请参阅 [API reference](https://reference.langchain.com/python/langchain-openai/chat_models/base/ChatOpenAI)。

### 模型特性

特定模型的功能，例如 tool calling、对多模态输入的支持、对 token-level streaming 的支持等，将取决于实际托管的模型。

## 设置

参阅 [vLLM documentation](https://docs.vllm.ai/en/latest/)。

要通过 LangChain 访问 vLLM 模型，你需要安装 `langchain-openai` 集成包。

### 凭证

认证方式将取决于具体的推理服务器配置。

要为模型调用启用自动 tracing，请设置你的 [LangSmith](/langsmith/observability) API key：

```python
os.environ["LANGSMITH_TRACING"] = "true"
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
```

### 安装

LangChain vLLM 集成可通过 `langchain-openai` 包访问：

```python
pip install -qU langchain-openai
```

## 实例化

现在可以实例化模型对象并生成聊天补全：

```python
from langchain.messages import HumanMessage, SystemMessage
from langchain_openai import ChatOpenAI
```

```python
inference_server_url = "http://localhost:8000/v1"

llm = ChatOpenAI(
    model="mosaicml/mpt-7b",
    api_key="your api key goes here",
    base_url=inference_server_url,
    max_tokens=5,
    temperature=0,
)
```

## 调用

```python
messages = [
    SystemMessage(
        content="You are a helpful assistant that translates English to Italian."
    ),
    HumanMessage(
        content="Translate the following sentence from English to Italian: I love programming."
    ),
]
llm.invoke(messages)
```

```text
AIMessage(content=' Io amo programmare', additional_kwargs={}, example=False)
```
