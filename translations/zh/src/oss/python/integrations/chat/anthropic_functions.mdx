<Warning>
**Anthropic API 现已正式支持 tool-calling，因此不再需要这个变通方案。请使用 [ChatAnthropic](/oss/integrations/chat/anthropic) 并搭配 `langchain-anthropic>=0.1.15`。**

</Warning>

本文档展示如何使用一个围绕 Anthropic 的实验性包装器，为其提供 tool calling 和 structured output 能力。它遵循 [Anthropic 的 tool use 指南](https://platform.claude.com/docs/en/agents-and-tools/tool-use/overview)。

这个包装器来自 `langchain-anthropic` 包，还需要可选依赖 `defusedxml` 来解析 llm 的 XML 输出。

注意，这是一个 beta 功能，后续会被 Anthropic 的正式 tool calling 实现所替代，但它在当前仍适合用于测试和实验。

```python
pip install -qU langchain-anthropic defusedxml
from langchain_anthropic.experimental import ChatAnthropicTools
```

## 绑定工具

`ChatAnthropicTools` 提供 `bind_tools` 方法，你可以将 Pydantic 模型或 BaseTools 传递给 llm。

```python
from pydantic import BaseModel


class Person(BaseModel):
    name: str
    age: int


model = ChatAnthropicTools(model="claude-3-opus-20240229").bind_tools(tools=[Person])
model.invoke("I am a 27 year old named Erick")
```

```text
AIMessage(content='', additional_kwargs={'tool_calls': [{'function': {'name': 'Person', 'arguments': '{"name": "Erick", "age": "27"}'}, 'type': 'function'}]})
```

## 结构化输出

`ChatAnthropicTools` 还实现了 [`with_structured_output` 规范](/oss/langchain/structured-output)，可用于提取值。注意：与显式提供 tool calling 的模型相比，这种方式可能没有那么稳定。

```python
chain = ChatAnthropicTools(model="claude-3-opus-20240229").with_structured_output(
    Person
)
chain.invoke("I am a 27 year old named Erick")
```

```text
Person(name='Erick', age=27)
```
