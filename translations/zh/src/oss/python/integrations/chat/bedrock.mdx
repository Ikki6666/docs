本文将帮助你开始使用 AWS Bedrock [chat models](/oss/langchain/models)。Amazon Bedrock 是一项全托管服务，通过单一 API 提供来自 AI21 Labs、Anthropic、Cohere、Meta、Stability AI 和 Amazon 等领先 AI 公司的高性能基础模型（FMs），同时还具备构建生成式 AI 应用所需的一整套能力，包括安全、隐私和负责任 AI。借助 Amazon Bedrock，你可以轻松试验和评估适合自身用例的顶级基础模型，使用微调和 Retrieval Augmented Generation（RAG）等技术结合你的数据进行私有化定制，并构建可利用企业系统和数据源执行任务的 agents。由于 Amazon Bedrock 是无服务器的，因此无需管理底层基础设施，并且可以借助你已经熟悉的 AWS 服务，将生成式 AI 能力安全地集成并部署到应用中。

AWS Bedrock 提供了 [Converse API](https://docs.aws.amazon.com/bedrock/latest/APIReference/API_runtime_Converse.html)，为 Bedrock 模型提供统一的对话接口。该 API 目前尚不支持自定义模型。你可以在[这里查看全部受支持模型列表](https://docs.aws.amazon.com/bedrock/latest/userguide/conversation-inference.html)。

<Info>
**如果你不需要使用自定义模型，我们推荐使用 Converse API。可以通过 [`ChatBedrockConverse`](https://reference.langchain.com/python/langchain-aws/chat_models/bedrock_converse/ChatBedrockConverse) 访问。**

</Info>

<Info>
**Bedrock 上的 Anthropic 模型**

对于 Anthropic 模型，你可以使用 `ChatAnthropicBedrock`。它扩展自 `ChatAnthropic`，在 AWS Bedrock 上运行时提供相同 API。详情请参见下方的 [ChatAnthropicBedrock](#chatanthropicbedrock) 小节。
</Info>

如需查看全部 Bedrock 功能和配置的详细文档，请前往 [API reference](https://reference.langchain.com/python/langchain-aws/chat_models/bedrock_converse/ChatBedrockConverse)。

## 设置

要访问 Bedrock 模型，需要创建 AWS 账号、配置 Bedrock API 服务、获取 access key ID 和 secret key，并安装 `langchain-aws` 集成包。

### 凭证

前往 [AWS docs](https://docs.aws.amazon.com/bedrock/latest/userguide/setting-up.html) 注册 AWS 并配置凭证。

另外，`ChatBedrockConverse` 默认也会从以下环境变量中读取凭证：

```python
# os.environ["AWS_ACCESS_KEY_ID"] = "..."
# os.environ["AWS_SECRET_ACCESS_KEY"] = "..."

# Not required unless using temporary credentials.
# os.environ["AWS_SESSION_TOKEN"] = "..."
```

你还需要为账号开启模型访问权限，具体可按照[这些说明](https://docs.aws.amazon.com/bedrock/latest/userguide/model-access.html)操作。

要启用模型调用的自动 tracing，请设置 [LangSmith](/langsmith/observability) API key：

```python
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

### 安装

LangChain 的 Bedrock 集成位于 `langchain-aws` 包中：

```python
pip install -qU langchain-aws
```

## 实例化

现在可以实例化模型对象并生成聊天补全：

```python
from langchain_aws import ChatBedrockConverse

llm = ChatBedrockConverse(
    model_id="anthropic.claude-3-5-sonnet-20240620-v1:0",
    # region_name=...,
    # aws_access_key_id=...,
    # aws_secret_access_key=...,
    # aws_session_token=...,
    # temperature=...,
    # max_tokens=...,
    # other params...
)
```

### 流式工具调用和结构化输出

当你在 Anthropic 模型上使用 [tool calling](/oss/langchain/tools) 或 [structured output](/oss/langchain/structured-output) 时，工具调用参数默认会以部分 JSON chunk 的形式流式输出。

如果想降低延迟并获得更均匀的 chunk 分布，可以启用 Anthropic 的 fine-grained tool streaming beta：

```python
from langchain_aws import ChatBedrockConverse

llm = ChatBedrockConverse(
    model_id="us.anthropic.claude-sonnet-4-5-20250514-v1:0",
    additional_model_request_fields={
        "anthropic_beta": ["fine-grained-tool-streaming-2025-05-14"]
    }
)
```

<Note>
    Fine-grained tool streaming 支持 Claude 4.5+ 模型。更多细节请参见 [Claude documentation](https://platform.claude.com/docs/en/agents-and-tools/tool-use/fine-grained-tool-streaming)。
</Note>

<Warning>
使用 fine-grained tool streaming 时，你可能会收到无效或不完整的 JSON 输入。请在代码中考虑这些边界情况。
</Warning>

## Prompt 缓存

Bedrock 支持对提示中的元素进行 [caching](https://docs.aws.amazon.com/bedrock/latest/userguide/prompt-caching.html)，包括消息和工具。这样你可以复用大文档、说明、[few-shot documents](/langsmith/create-few-shot-evaluators) 以及其他数据，以降低延迟和成本。

<Note>
    **并非所有模型都支持 prompt caching。请参见 [Bedrock prompt caching supported models](https://docs.aws.amazon.com/bedrock/latest/userguide/prompt-caching.html#prompt-caching-models)。**
</Note>

<Note>
    对于 LangChain agent，请使用 [`BedrockPromptCachingMiddleware`](/oss/integrations/middleware/aws#prompt-caching)，让 LangChain 自动优化稳定的 system prompt 和 tool 内容。对于直接模型调用，请根据模型和 API，使用手动 `cachePoint` block 或调用级 `cache_control`。
</Note>

要为提示中的元素启用缓存，请在其对应的内容块上标记 `cachePoint` 键。示例如下：

```python
import requests
from langchain_aws import ChatBedrockConverse

llm = ChatBedrockConverse(model="us.anthropic.claude-sonnet-4-6")

# Pull LangChain readme
get_response = requests.get(
    "https://raw.githubusercontent.com/langchain-ai/langchain/b476fdb54aa6e6f5f0b24a68c2f4a94e43b369f9/README.md"
)
readme = get_response.text

messages = [
    {
        "role": "user",
        "content": [
            {
                "type": "text",
                "text": "What's LangChain, according to its README?",
            },
            {
                "type": "text",
                "text": f"{readme}",
            },
            {
                "cachePoint": {"type": "default"},
            },
        ],
    },
]

response_1 = llm.invoke(messages)
response_2 = llm.invoke(messages)

usage_1 = response_1.usage_metadata["input_token_details"]
usage_2 = response_2.usage_metadata["input_token_details"]

print(f"First invocation:\n{usage_1}")
print(f"\nSecond:\n{usage_2}")
```

```python
First invocation:
{'cache_creation': 1528, 'cache_read': 0}

Second:
{'cache_creation': 0, 'cache_read': 1528}
```

## 引用

如果在输入文档上启用了引用，就可以生成 citations。文档既可以使用 Bedrock 的[原生格式](https://docs.aws.amazon.com/bedrock/latest/APIReference/API_runtime_DocumentBlock.html)，也可以使用 LangChain 的[标准类型](/oss/langchain/messages#multimodal)：

<CodeGroup>
```python Bedrock format
from langchain_aws import ChatBedrockConverse

llm = ChatBedrockConverse(model="us.anthropic.claude-sonnet-4-20250514-v1:0")

pdf_path = "path/to/your/file.pdf"

with open(pdf_path, "rb") as f:
    pdf_bytes = f.read()

document = {
    "document": {
        "format": "pdf",
        "source": {"bytes": pdf_bytes},
        "name": "my-pdf",
        "citations": {"enabled": True},  # [!code highlight]
    },
}

response = llm.invoke(
    [
        {
            "role": "user",
            "content": [
                {"type": "text", "text": "Describe this document."},
                document,
            ]
        },
    ]
)
response.content_blocks
```

```python LangChain standard format
import base64
from langchain_aws import ChatBedrockConverse

llm = ChatBedrockConverse(model="us.anthropic.claude-sonnet-4-20250514-v1:0")

pdf_path = "path/to/your/file.pdf"

with open(pdf_path, "rb") as f:
    pdf_base64 = base64.b64encode(f.read()).decode("utf-8")

document = {
    "type": "file",
    "mime_type": "application/pdf",
    "base64": pdf_base64,
    "name": "my-pdf",  # Converse requires a filename
    "citations": {"enabled": True},  # [!code highlight]
}

response = llm.invoke(
    [
        {
            "role": "user",
            "content": [
                {"type": "text", "text": "Describe this document."},
                document,
            ]
        },
    ]
)
response.content_blocks
```
</CodeGroup>

## ChatAnthropicBedrock

如果你使用 AWS Bedrock，并且特别关注 Anthropic 模型，`langchain-aws` 提供了 `ChatAnthropicBedrock`。该类扩展自 `ChatAnthropic`，在 AWS Bedrock 基础设施上运行时提供相同接口。它底层使用的是 Anthropic SDK 的 [Bedrock clients](https://platform.claude.com/docs/en/build-with-claude/claude-on-amazon-bedrock)。

### 安装

安装带有 `anthropic` extra 的 `langchain-aws`，以获取所需依赖：

<CodeGroup>
```bash pip
pip install --upgrade "langchain-aws[anthropic]"
```
```bash uv
uv add "langchain-aws[anthropic]"
```
</CodeGroup>

### 用法

`ChatAnthropicBedrock` 支持与 `ChatAnthropic` 相同的功能和参数。你可以用 AWS 特有参数来初始化它：

```python
from langchain_aws import ChatAnthropicBedrock

model = ChatAnthropicBedrock(
    model="us.anthropic.claude-haiku-4-5-20251001-v1:0",
    region_name="us-west-2",
    aws_access_key_id="...",
    aws_secret_access_key="...",
    aws_session_token="...",
)
```

AWS 凭证也可以从环境变量中读取，或由 boto3 自动发现：

```python
# Set environment variables
# os.environ["AWS_ACCESS_KEY_ID"] = "..."
# os.environ["AWS_SECRET_ACCESS_KEY"] = "..."
# os.environ["AWS_REGION"] = "..."

from langchain_aws import ChatAnthropicBedrock

model = ChatAnthropicBedrock(model="us.anthropic.claude-haiku-4-5-20251001-v1:0")
```

关于可用参数和功能的详细文档，请参见 [`ChatAnthropic` integration page](/oss/integrations/chat/anthropic)。
