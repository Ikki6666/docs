本页帮助你开始使用 `AzureAIOpenAIApiChatModel` [chat models](/oss/langchain/models)。

`AzureAIOpenAIApiChatModel` 类使用 Azure AI Foundry 中提供的 OpenAI 兼容 API。AI Foundry 提供多种聊天模型，包括 AzureOpenAI、Cohere、Llama、Phi-3/4、DeepSeek-R1 等。你可以在 [Azure docs](https://learn.microsoft.com/azure/ai-studio/how-to/model-catalog-overview) 中查看它们的最新模型、成本、上下文窗口和支持的输入类型。

## 设置

要访问 `AzureAIOpenAIApiChatModel` 模型，需要创建一个 [Azure account](https://azure.microsoft.com/pricing/purchase-options/azure-account)、获取 API key，并安装 `langchain-azure-ai` 集成包。

### 凭证

前往 [Azure docs](https://learn.microsoft.com/en-us/azure/ai-studio/how-to/develop/sdk-overview?tabs=sync&pivots=programming-language-python) 查看如何创建部署并生成 API key。模型部署完成后，可以在 AI Foundry 中点击 “get endpoint” 按钮，这会显示你的 endpoint 和 API key。完成后，设置以下环境变量：

```python
import getpass
import os

if not os.getenv("AZURE_AI_PROJECT_ENDPOINT"):
    os.environ["AZURE_AI_PROJECT_ENDPOINT"] = getpass.getpass(
        "Enter your Azure AI project endpoint: "
    )
```

如果希望为模型调用启用自动 tracing，也可以取消下方注释并设置 [LangSmith](/langsmith/observability) API key：

```python
os.environ["LANGSMITH_TRACING"] = "true"
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
```

### 安装

LangChain 的 `AzureAIOpenAIApiChatModel` 集成位于 `langchain-azure-ai` 包中：

```python
pip install -qU langchain-azure-ai
```

## 实例化

现在可以实例化模型对象并生成聊天补全：

```python
from langchain_azure_ai.chat_models import AzureAIOpenAIApiChatModel
from azure.identity import DefaultAzureCredential

llm = AzureAIOpenAIApiChatModel(
    model="gpt-4o",
    credential=DefaultAzureCredential(),
    temperature=0,
    max_tokens=None,
    max_retries=2,
)
```

messages = [
