<Info>
    **Azure OpenAI 与 OpenAI 的区别**

    Azure OpenAI 指的是托管在 [Microsoft Azure platform](https://azure.microsoft.com/en-us/products/ai-services/openai-service) 上的 OpenAI 模型。托管在 Azure 上的模型提供额外的企业级特性，包括通过 Entra ID 的无密钥身份验证。
</Info>

<Info>
    **配合 v1 API 使用 `ChatOpenAI`（推荐）**

    Azure OpenAI 的 [v1 API](https://learn.microsoft.com/en-us/azure/ai-foundry/openai/api-version-lifecycle?tabs=python) 已于 2025 年 8 月 Generally Available，可以直接将 [`ChatOpenAI`](/oss/integrations/chat/openai/#using-with-azure-openai) 与 Azure endpoint 一起使用。这不再需要老式的 `api-version` 参数，并且原生支持 Microsoft Entra ID 身份验证和自动 token 刷新。

    我们仍然支持 @[`AzureChatOpenAI`]，它现在与 @[`ChatOpenAI`] 共用相同的底层实现，而后者直接与 OpenAI 服务交互。

    本页作为一个 quickstart，用于帮助你在 LangChain 中认证并连接 Azure OpenAI Chat Models。
</Info>

<Tip>
    **API Reference**

    如需查看全部功能和配置选项的详细文档，请前往 @[`AzureChatOpenAI`] API reference。关于可用功能的更多细节，请参见 [`ChatOpenAI` docs](/oss/integrations/chat/openai/)。
</Tip>

## 设置

要访问 Azure OpenAI 模型，需要[创建 Azure 账号](https://account.azure.com/signup)、创建 Azure OpenAI 模型部署、获取部署名称和 endpoint，并安装 `langchain-openai` 集成包。

### 安装

<CodeGroup>
    ```bash pip
    pip install -U langchain-openai
    ```
    ```bash uv
    uv add langchain-openai
    ```
</CodeGroup>

## 凭证

@[`ChatOpenAI`] 和 @[`AzureChatOpenAI`] 都支持通过 **Microsoft Entra ID**（推荐）或 **API key** 来认证 Azure OpenAI。

### Microsoft Entra ID

[Microsoft Entra ID](https://learn.microsoft.com/en-us/azure/ai-foundry/openai/how-to/managed-identity) 提供无密钥身份验证和自动 token 刷新。安装 `azure-identity` 包并创建 token provider，该 provider 可同时用于 `ChatOpenAI` 和 `AzureChatOpenAI`：

```bash
pip install azure-identity
```

```python
from azure.identity import DefaultAzureCredential, get_bearer_token_provider

token_provider = get_bearer_token_provider(
    DefaultAzureCredential(),
    "https://cognitiveservices.azure.com/.default",
)
```

### API key

前往 [Azure docs](https://learn.microsoft.com/en-us/azure/ai-services/openai/chatgpt-quickstart?tabs=command-line%2Cpython-new&pivots=programming-language-python) 创建部署并生成 API key。设置 `AZURE_OPENAI_API_KEY` 和 `AZURE_OPENAI_ENDPOINT` 环境变量：

```python
import getpass
import os

if "AZURE_OPENAI_API_KEY" not in os.environ:
    os.environ["AZURE_OPENAI_API_KEY"] = getpass.getpass(
        "Enter your AzureOpenAI API key: "
    )
os.environ["AZURE_OPENAI_ENDPOINT"] = "https://YOUR-RESOURCE-NAME.openai.azure.com/"
```

要启用模型调用的自动 tracing，请设置 [LangSmith](/langsmith/observability) API key：

```python
os.environ["LANGSMITH_API_KEY"] = getpass.getpass("Enter your LangSmith API key: ")
os.environ["LANGSMITH_TRACING"] = "true"
```

## 实例化

### 配合 v1 API 使用 ChatOpenAI

将 `base_url` 设置为你的 Azure endpoint，并在后面追加 `/openai/v1/`。使用 v1 API 时，可以通过一个统一接口调用部署在 [Microsoft Foundry](https://learn.microsoft.com/en-us/azure/ai-foundry/) 中的任意模型，包括 OpenAI、Llama、DeepSeek、Mistral 和 Phi，只需将 `model` 指向你的 deployment name。

<Tabs>
    <Tab title="Entra ID (recommended)">
        将 token provider 传给 `api_key`：

        ```python
        from langchain_openai import ChatOpenAI

        llm = ChatOpenAI(
            model="gpt-5.4-mini",  # your Azure deployment name
            base_url="https://YOUR-RESOURCE-NAME.openai.azure.com/openai/v1/",
            api_key=token_provider,  # callable that handles token refresh
        )
        ```
    </Tab>
    <Tab title="API key">
        ```python
        from langchain_openai import ChatOpenAI

        llm = ChatOpenAI(
            model="gpt-5.4-mini",  # your Azure deployment name
            base_url="https://YOUR-RESOURCE-NAME.openai.azure.com/openai/v1/",
            api_key="your-azure-api-key",
        )
        ```
    </Tab>
</Tabs>

### AzureChatOpenAI

在需要 `api_version` 的传统 Azure OpenAI API 版本下，使用 @[`AzureChatOpenAI`]。

<Tabs>
    <Tab title="Entra ID (recommended)">
        将 token provider 传给 `azure_ad_token_provider`：

        ```python
        from langchain_openai import AzureChatOpenAI

        llm = AzureChatOpenAI(
            azure_deployment="gpt-5.4-mini",  # or your deployment
            api_version="2025-04-01-preview",  # or your api version
            azure_ad_token_provider=token_provider,
        )
        ```
    </Tab>
    <Tab title="API key">
        从环境变量中读取 `AZURE_OPENAI_API_KEY` 和 `AZURE_OPENAI_ENDPOINT`：

        ```python
        from langchain_openai import AzureChatOpenAI

        llm = AzureChatOpenAI(
            azure_deployment="gpt-5.4-mini",  # or your deployment
            api_version="2025-04-01-preview",  # or your api version
            temperature=0,
            max_tokens=None,
            timeout=None,
            max_retries=2,
            # other params...
        )
        ```
    </Tab>
</Tabs>

## 调用

```python
messages = [
    (
        "system",
        "You are a helpful assistant that translates English to French. Translate the user sentence.",
    ),
    ("human", "I love programming."),
]
ai_msg = llm.invoke(messages)
print(ai_msg.text)
```

```text
J'adore la programmation.
```

## 工具调用

可以使用 Pydantic class、dict schema、LangChain tool 或普通函数将工具绑定到模型：

```python
from langchain_openai import ChatOpenAI
from pydantic import BaseModel, Field


class GetWeather(BaseModel):
    """Get the current weather in a given location"""

    location: str = Field(description="The city and state, e.g. San Francisco, CA")


llm = ChatOpenAI(
    model="gpt-5.4-mini",
    base_url="https://YOUR-RESOURCE-NAME.openai.azure.com/openai/v1/",
    api_key="your-azure-api-key",
)

llm_with_tools = llm.bind_tools([GetWeather])

ai_msg = llm_with_tools.invoke("What is the weather like in San Francisco?")
ai_msg.tool_calls
```

```text
[{'name': 'GetWeather',
  'args': {'location': 'San Francisco, CA'},
  'id': 'call_jUqhd8wzAIzInTJl72Rla8ht',
  'type': 'tool_call'}]
```

关于工具绑定和工具调用输出的更多信息，请参见 [tool calling](/oss/langchain/tools) 文档。

## 构建 agent

使用 @[`create_agent`] 结合 Azure OpenAI 和工具来构建 agent：

```python
from langchain.agents import create_agent
from langchain_openai import ChatOpenAI

llm = ChatOpenAI(
    model="gpt-5.4-mini",
    base_url="https://YOUR-RESOURCE-NAME.openai.azure.com/openai/v1/",
    api_key="your-azure-api-key",
)


def get_weather(city: str) -> str:
    """Get weather for a given city."""
    return f"It's always sunny in {city}!"


agent = create_agent(
    model=llm,
    tools=[get_weather],
    system_prompt="You are a helpful assistant",
)

# Stream agent responses
stream = agent.stream_events(
    {"messages": [{"role": "user", "content": "What is the weather in SF?"}]},
    version="v3",
)
for snapshot in stream.values:
    print(snapshot["messages"][-1].text)
```
