ModelScope（[Home](https://www.modelscope.cn/) | [GitHub](https://github.com/modelscope/modelscope)）建立在 “Model-as-a-Service” (MaaS) 理念之上。它致力于汇聚 AI 社区中最先进的机器学习模型，并简化在真实应用中利用 AI 模型的过程。该仓库中开源的核心 ModelScope library 提供了接口和实现，使开发者可以执行模型推理、训练和评估。

本文将帮助你开始使用 ModelScope Chat Endpoint。

## 设置

要访问 ModelScope chat endpoint，你需要创建一个 ModelScope 账户、获取 SDK token，并安装 `langchain-modelscope-integration` 集成包。

### 凭证

前往 [ModelScope](https://modelscope.cn/) 注册，并生成一个 [SDK token](https://modelscope.cn/my/myaccesstoken)。完成后，设置 `MODELSCOPE_SDK_TOKEN` 环境变量：

```python
import getpass
import os

if not os.getenv("MODELSCOPE_SDK_TOKEN"):
    os.environ["MODELSCOPE_SDK_TOKEN"] = getpass.getpass(
        "Enter your ModelScope SDK token: "
    )
```

### 安装

LangChain ModelScope 集成位于 `langchain-modelscope-integration` 包中：

```python
pip install -qU langchain-modelscope-integration
```

## 实例化

现在可以实例化模型对象并生成聊天补全：

```python
from langchain_modelscope import ModelScopeChatEndpoint

llm = ModelScopeChatEndpoint(
    model="Qwen/Qwen2.5-Coder-32B-Instruct",
    temperature=0,
    max_tokens=1024,
    timeout=60,
    max_retries=2,
    # other params...
)
```

## 调用

messages = [
