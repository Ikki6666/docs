`ChatQwQ` 将 Qwen 思考模型接入 LangChain 的[聊天模型接口](/oss/langchain/models)。`langchain-qwq` 包还提供了 [`ChatQwen`](/oss/integrations/chat/qwen)，可通过构造函数参数控制思考行为。

<Warning>
阿里云已于 2026 年 10 月 10 日在北京和新加坡区域下线 `qwq-plus`。请参见[模型下线通知](https://www.alibabacloud.com/en/notice/model_studionotice_on_the_decommissioning_of_certain_historical_mainline_models_731)。

`ChatQwQ` 仍默认使用 `qwq-plus`。请按下文所示显式设置 `model` 并启用思考功能。包名和导入路径保持不变。
</Warning>

## 设置

请使用可访问所选模型的阿里云百炼（Model Studio）账号。示例要求 Python 3.10 或更高版本。

### 凭证

在 [Alibaba's API Key page](https://account.alibabacloud.com/login/login.htm?oauth_callback=https%3A%2F%2Fbailian.console.alibabacloud.com%2F%3FapiKey%3D1&lang=en#/api-key) 生成 API key，然后设置 `DASHSCOPE_API_KEY`：

```python
import getpass
import os

if not os.getenv("DASHSCOPE_API_KEY"):
    os.environ["DASHSCOPE_API_KEY"] = getpass.getpass("Enter your DashScope API key: ")
```

默认 base URL 为 `https://dashscope-intl.aliyuncs.com/compatible-mode/v1`。如需使用所在区域的端点，请设置 `DASHSCOPE_API_BASE` 或传入 `base_url`。API key 和模型必须在该端点可用。

### 安装

安装 `langchain-qwq` 包：

```bash
pip install -qU "langchain-qwq>=0.4.0"
```

## 实例化

选择一个受支持的 Qwen 模型，并通过 `extra_body` 启用思考功能：

```python
from langchain_qwq import ChatQwQ

llm = ChatQwQ(
    model="qwen-plus-2025-12-01",
    extra_body={"enable_thinking": True},
    max_tokens=3_000,
    timeout=None,
    max_retries=2,
)
```

也可以使用 `ChatQwen` 及其 `enable_thinking` 参数：

```python
from langchain_qwq import ChatQwen

qwen = ChatQwen(model="qwen-plus-2025-12-01", enable_thinking=True)
response = qwen.invoke("What is 17 multiplied by 19?")
print(response.content_blocks)
```

受支持的模型和思考控制选项，请参见阿里云的[思考模式文档](https://www.alibabacloud.com/help/en/model-studio/deep-thinking)。

## 调用

以下示例使用 `ChatQwQ` 的 `llm` 实例：

```python
messages = [
    (
        "system",
        "You are a helpful assistant that translates English to French. "
        "Translate the user sentence.",
    ),
    ("human", "I love programming."),
]
ai_msg = llm.invoke(messages)
print(ai_msg.content_blocks)
```

当 provider 返回推理内容时，`additional_kwargs` 中也会包含其 `reasoning_content` 字段：

```python
print(ai_msg.additional_kwargs.get("reasoning_content", ""))
```

`content_blocks` 提供 LangChain 对文本和推理内容的规范化视图。访问该属性无需设置 `output_version="v1"`，本集成也不支持该设置。

## 流式响应

流式输出会在模型生成响应时返回消息块：

```python
for chunk in llm.stream("What is 17 multiplied by 19?"):
    print(chunk.content_blocks)
```

如需异步调用，请使用 `ainvoke`：

```python
import asyncio

from langchain_qwq import ChatQwQ


async def main() -> None:
    model = ChatQwQ(
        model="qwen-plus-2025-12-01",
        extra_body={"enable_thinking": True},
    )
    response = await model.ainvoke("What is 17 multiplied by 19?")
    print(response.content_blocks)


asyncio.run(main())
```

在已有事件循环的 notebook 中，请使用 `await main()`，而不是 `asyncio.run(main())`。

## Tool calling

Tool calling 允许模型请求调用某个函数并提供参数。`bind_tools` 只把工具定义发送给模型，并不会执行这些工具。

### 配合 `bind_tools` 使用

```python
from langchain.tools import tool
from langchain_qwq import ChatQwQ


@tool
def multiply(first_int: int, second_int: int) -> int:
    """Multiply two integers together."""
    return first_int * second_int


llm = ChatQwQ(
    model="qwen-plus-2025-12-01",
    extra_body={"enable_thinking": True},
)
llm_with_tools = llm.bind_tools([multiply])
msg = llm_with_tools.invoke("Use multiply to calculate 5 times forty two.")
print(msg.tool_calls)
```

<Note>
完整的工具参数缓冲需要 `langchain-qwq>=0.4.0`。
</Note>

`ChatQwQ` 会缓冲工具参数，直到 provider 完成生成或正常结束流。它会保留合法的 JSON，并且只在拼接出完整参数后才尝试修复格式错误的 JSON。文本和推理内容仍会立即流式返回。发生错误或流被取消时，不会发出未完成的工具调用。该行为适用于同步和异步流，包括回调。

## 结构化输出

`ChatQwQ` 通过 function calling 返回结构化结果。解析后的结果由 Pydantic schema 进行校验：

```python
from langchain_qwq import ChatQwQ
from pydantic import BaseModel


class Person(BaseModel):
    name: str
    age: int


model = ChatQwQ(
    model="qwen-plus-2025-12-01",
    extra_body={"enable_thinking": True},
)
structured = model.with_structured_output(Person, method="function_calling")
person = structured.invoke("Extract the person: Alice is 30 years old.")
print(person)
```

向 `ChatQwQ` 传入 `method="json_mode"` 或 `method="json_schema"` 同样会选择 function calling。这两个值不会在此 wrapper 上启用原生 JSON mode。

## 视觉支持

本指南中的文本模型不接受图片或视频输入。如需处理视觉任务，请通过 `ChatQwen` 选择兼容的模型和端点。发送[多模态消息](/oss/langchain/messages#multimodal)前，请先确认 provider 支持的输入格式。
