title: LangGraph v1 的新特性
sidebarTitle: LangGraph v1
---

**LangGraph v1 是一个以稳定性为重点的 agent runtime 版本。** 它保持核心图 API 和执行模型不变，同时改进了类型安全、文档和开发体验。

它被设计为与 [LangChain v1](/oss/releases/langchain-v1) 协同工作。后者的 `create_agent` 正是构建在 LangGraph 之上，因此你可以先从高层接口开始，在需要时再下探到更细粒度的控制。

<CardGroup cols={1}>
    <Card title="稳定的核心 API" icon="sitemap">
        图原语（state、nodes、edges）以及执行/runtime 模型保持不变，因此升级过程更直接。
    </Card>
    <Card title="默认具备可靠性" icon="database">
        带 checkpointing、persistence、streaming 和 human-in-the-loop 的持久执行仍然是一等能力。
    </Card>
    <Card title="与 LangChain v1 无缝协作" icon="link">
        LangChain 的 `create_agent` 运行在 LangGraph 之上。使用 LangChain 可以快速起步，而使用 LangGraph 则可实现自定义编排。
    </Card>
</CardGroup>

升级命令：

<CodeGroup>
```bash pip
pip install -U langgraph
```
```bash uv
uv add langgraph
```
</CodeGroup>

## `create_react_agent` 的弃用

LangGraph 的 @[`create_react_agent`] prebuilt 已被弃用，推荐改用 LangChain 的 @[`create_agent`]。后者接口更简洁，并通过 middleware 引入了更强的定制潜力。

* 关于新的 @[`create_agent`] API，请参阅 [LangChain v1 release notes](/oss/releases/langchain-v1#create_agent)。
* 关于如何从 @[`create_react_agent`] 迁移到 @[`create_agent`]，请参阅 [LangChain v1 migration guide](/oss/migrate/langchain-v1#migrate-to-create_agent)。
