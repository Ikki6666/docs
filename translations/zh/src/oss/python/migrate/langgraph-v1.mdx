<CodeGroup>

```bash uv
uv add langgraph langchain-core
```
</CodeGroup>

## 变更摘要

LangGraph v1 整体上与旧版本保持较强的向后兼容性。最主要的变化是：@[`create_react_agent`] 被弃用，推荐改用 LangChain 新提供的 @[`create_agent`] 函数。

## 弃用项

下表列出了 LangGraph v1 中所有已弃用的项目：

| Deprecated item | Alternative |
|----------------|-------------|
| `create_react_agent` | @[`langchain.agents.create_agent`][create_agent] |
| `AgentState` | @[`langchain.agents.AgentState`][AgentState] |
| `AgentStatePydantic` | `langchain.agents.AgentState`（不再支持 pydantic state） |
| `AgentStateWithStructuredResponse` | `langchain.agents.AgentState` |
| `AgentStateWithStructuredResponsePydantic` | `langchain.agents.AgentState`（不再支持 pydantic state） |
| `HumanInterruptConfig` | `langchain.agents.middleware.human_in_the_loop.InterruptOnConfig` |
| `ActionRequest` | `langchain.agents.middleware.human_in_the_loop.InterruptOnConfig` |
| `HumanInterrupt` | `langchain.agents.middleware.human_in_the_loop.HITLRequest` |
| `ValidationNode` | 输入校验由 @[`create_agent`] 自动在工具层处理 |
| `MessageGraph` | 使用带有 `messages` 键的 @[`StateGraph`]，和 @[`create_agent`] 提供的结构一致 |

## `create_react_agent` → `create_agent`

LangGraph v1 弃用了预构建的 @[`create_react_agent`]。请改用基于 LangGraph 运行、并且带有灵活 middleware 系统的 LangChain @[`create_agent`]。

更多细节请参阅 LangChain v1 文档：

- [Release notes](/oss/releases/langchain-v1#create_agent)
- [Migration guide](/oss/migrate/langchain-v1#migrate-to-create_agent)

<CodeGroup>
```python v1 (new)
from langchain.agents import create_agent

agent = create_agent(  # [!code highlight]
    model,
    tools,
    system_prompt="You are a helpful assistant.",
)
```
```python v0 (old)
from langgraph.prebuilt import create_react_agent

agent = create_react_agent(  # [!code highlight]
    model,
    tools,
    prompt="You are a helpful assistant.",  # [!code highlight]
)
```
</CodeGroup>

## Breaking changes

### 不再支持 Python 3.9

所有 LangChain 包现在都要求使用 **Python 3.10 或更高版本**。Python 3.9 已于 2025 年 10 月到达 [end of life](https://devguide.python.org/versions/)。
