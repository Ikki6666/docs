在 Deep Agents Code 中，自定义 agent 主要有两种方式：

- **[Memory](#memory)**：`AGENTS.md` 文件和自动保存的 memories，会跨 session 持久化。Memory 适合保存通用编码风格、偏好和已学到的约定。

- **[Skills](#skills)**：可复用、按需加载的能力，agent 只会在相关时发现并读取它们。Skills 适合任务专用上下文，例如工作流、最佳实践和参考文档。

在实践中，skills 和 memory 其实位于同一条连续谱上。关于何时使用哪一种，请参见 [Skills, memory, and tools](/oss/deepagents/skills#skills-memory-and-tools)。

使用 `/remember` 可以显式提示 agent 从当前对话中更新它的 memory 和 skills。

<Tip>
    如果你是用 SDK 构建自定义 agent，请参见 [Memory](/oss/deepagents/memory) 了解程序化 memory backend。
</Tip>

## Memory

### 自动 memory

当你使用 agent 时，它会自动把信息存到 `~/.deepagents/<agent_name>/memories/` 中，格式是 markdown 文件，采用 memory-first 协议：

1. **Research**：在开始任务前搜索 memory，寻找相关上下文
2. **Response**：在执行过程中不确定时检查 memory
3. **Learning**：自动保存新信息供未来 session 使用

agent 会按主题组织 memories，并使用描述性的文件名：

```
~/.deepagents/backend-dev/memories/
├── api-conventions.md
├── database-schema.md
└── deployment-process.md
```

当你教 agent 某些约定时：

```bash
dcode --agent backend-dev
> Our API uses snake_case and includes created_at/updated_at timestamps
```

它会在未来的 session 中记住：

```bash
> Create a /users endpoint
# 不再提示，自动应用这些约定
```

### AGENTS.md 文件

[`AGENTS.md` 文件](https://agents.md/) 会提供会话开始时始终加载的持久上下文：

- **Global**：`~/.deepagents/<agent_name>/AGENTS.md` - 每次 session 都会加载。
- **Project**：项目根目录中的 `.deepagents/AGENTS.md` - 当 Deep Agents Code 在该项目内运行时会加载。

这两个文件都会在启动时追加到 system prompt 中。

### Memory 如何工作

当 agent 回答项目相关问题，或者你引用过去的工作或模式时，它也可能读取自己的 memory 文件。

agent 会根据你给它的行为说明、对其工作的反馈，或者需要记住的指令来更新 `AGENTS.md`。
如果它识别出你的交互中的模式或偏好，也会更新自己的 memory。

如果你想在额外的 memory 文件中添加更结构化的项目知识，可以把它们放到 `.deepagents/` 下，并在 `AGENTS.md` 文件中引用它们。
你必须在 `AGENTS.md` 文件中引用额外文件，这样 agent 才会知道它们。
这些额外文件不会在启动时读取，但 agent 需要时可以引用和更新它们。

### 何时使用 global vs. project AGENTS.md

使用全局 `AGENTS.md`（`~/.deepagents/<agent_name>/AGENTS.md`）来存放：

- 你的个性、风格和通用编码偏好
- 通用的语气和沟通风格
- 适用于任何地方的通用编码偏好（格式化、type hints 等）
- 适用于所有地方的工具使用模式
- 不依赖具体项目的工作流和方法论

使用项目 `AGENTS.md`（项目根目录中的 `.deepagents/AGENTS.md`）来存放：

- 项目特有的上下文和约定
- 项目架构和设计模式
- 这个 codebase 特有的编码约定
- 测试策略和部署流程
- 团队指南和项目结构

## Skills

Skills 把领域知识，例如工作流、最佳实践、脚本和参考文档，打包成可复用目录，agent 只会在相关时发现并读取。
deep agent skills 遵循 [Agent Skills 规范](https://agentskills.io/)。关于 skills 的工作方式以及如何编写高质量 skills，请参见 [Skills](/oss/deepagents/skills)。

在启动时，Deep Agents Code 会读取每个 `SKILL.md` 文件 frontmatter 里的 name 和 description。当任务与某个 skill 的描述匹配时，agent 会读取该 skill 文件并遵循其指令。Discovery 会在 `/reload` 时重新运行。

### 添加 skill

<Steps>
    <Step title="创建 skill">

        ```bash
        # 用户 skill（存放在 ~/.deepagents/<agent_name>/skills/）
        dcode skills create test-skill

        # 项目 skill（存放在 .deepagents/skills/）
        dcode skills create test-skill --project
        ```

        这会生成：

        ```plaintext
        skills/
        └── test-skill
            └── SKILL.md
        ```

    </Step>
    <Step title="编辑 SKILL.md">
        打开生成的 `SKILL.md`，把你的指令写进去。
    </Step>
    <Step title="添加可选资源">
        你也可以给 `test-skill` 文件夹增加脚本或其他资源。更多信息请参见 [Usage](/oss/deepagents/skills#add-supporting-resources)。
    </Step>
</Steps>

你也可以直接把已有 skill 复制到 agent 文件夹里：

```bash
mkdir -p ~/.deepagents/<agent_name>/skills
cp -r examples/skills/web-research ~/.deepagents/<agent_name>/skills/
```

### 安装社区 skills

你可以使用 Vercel 的 [Skills CLI](https://github.com/vercel-labs/skills) 等工具安装社区 [Agent Skills](https://agentskills.io/)，并把它们提供给你的 deep agents：

```bash
# 全局安装一个 skill
npx skills add vercel-labs/agent-skills --skill web-design-guidelines -a deepagents -g -y

# 列出已安装 skills
npx skills ls -a deepagents -g
```

全局安装（`-g`）会把 skills 符号链接到 `~/.deepagents/agent/skills/` - 也就是默认 agent 的用户级 skills 目录。项目级安装（省略 `-g`）会把 skills 放到当前目录下的 `.deepagents/skills/`，这样无论 agent 名称是什么，任何在该项目中运行的 agent 都能使用它们。

<Note>
    全局安装只会目标到默认的 `agent` 目录。如果你使用自定义名称的 agent，请使用项目级安装，或者手动把 skill 符号链接到 `~/.deepagents/{your-agent}/skills/`。
</Note>

### Skill discovery

Skills 会在启动时从以下目录加载：

```text
~/.deepagents/<agent_name>/skills/
~/.agents/skills/
.deepagents/skills/
.agents/skills/
~/.claude/skills/          (experimental)
.claude/skills/            (experimental)
```

当存在同名 skill 时，后加载优先级更高的目录会覆盖之前的目录（见 [App data](/oss/deepagents/code/data-locations#skills)）。

对于项目专属 skills（位于 `.deepagents/skills/` 或 `.agents/skills/` 下），项目根目录通过包含 `.git` 文件夹来识别。

### 在会话中调用 skill

在交互式会话中，可以直接使用 `/skill:<name>` slash command 来运行某个 skill：

```text
/skill:code-review
/skill:code-review review the auth module
```

该 skill 的 `SKILL.md` 指令会和你提供的任何参数一起注入到 prompt 中。

### 启动时使用 skill

`--skill` flag 会在启动时立即调用某个 skill，无论是交互式（TUI）还是非交互式（headless）模式：

```bash
# 打开 TUI 并立即运行 skill
dcode --skill code-review

# 通过 -m 给 skill 传入请求
dcode --skill code-review -m 'review the auth module'

# 把内容 pipe 给 skill
cat diff.txt | dcode --skill code-review

# pipe 内容并添加请求
cat diff.txt | dcode --skill code-review -m 'focus on security'

# 无头方式运行 skill
dcode --skill code-review -n 'review this patch'

# 安静模式（stdout 只输出 agent 结果）
dcode --skill code-review -n 'review this patch' -q
```

<Note>
    `--skill` 搭配 `--quiet` 或 `--no-stream` 时需要 `-n`（非交互模式）。
</Note>

### 列出 skills

```bash
# 列出所有用户 skills
dcode skills list

# 列出项目 skills
dcode skills list --project

# 查看某个 skill 的详细信息
dcode skills info test-skill
dcode skills info test-skill --project
```
