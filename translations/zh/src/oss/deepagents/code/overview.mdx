Deep Agents Code (`dcode`) 是一个基于 [Deep Agents SDK](/oss/deepagents/quickstart) 构建的开源编码 agent。
它可以与任何大型语言模型协作，并支持切换 provider 或 model。
持久化 memory 会把上下文带到不同对话中，可自定义的 skills 会塑造行为，而审批控制会在代码执行前做把关。

## 开始使用

运行以下命令安装 Deep Agents Code 并启动一个交互式 session：

```bash
curl -LsSf https://langch.in/dcode | bash
dcode
```

参见 [快速开始](/oss/deepagents/code/quickstart)，了解如何添加 provider 凭据、运行你的第一个任务以及学习交互模式。
