Deep Agents Code 把数据存放在两个目录层级中：

- **`~/.deepagents/`** - Deep Agents 专用数据（agent memory、skills、sessions）
- **`~/.agents/`** - 工具无关数据（可在不同 AI CLI 工具之间共享的 skills）

## 目录结构

```text
~/.deepagents/
├── .state/                  # 每台机器的 Deep Agents Code 状态（自动管理）
│   ├── sessions.db          #   用于 conversation checkpoints 的 SQLite 数据库
│   ├── history.jsonl        #   命令输入历史
│   ├── chatgpt-auth.json    #   openai_codex provider 的 ChatGPT OAuth token
│   ├── ...                  #   其他标记和凭据
└── {agent}/                 # 每个 agent 一个目录（默认值："agent"）
    ├── AGENTS.md            # 用户对 agent 指令的自定义内容
    ├── skills/              # 用户级 skills
    │   └── {skill-name}/
    │       └── SKILL.md
    └── agents/              # 自定义 subagent 定义
        └── {subagent-name}/
            └── AGENTS.md

~/.agents/                   # 工具无关别名（跨 AI CLI 共享）
└── skills/                  # 任何兼容工具都可用的 skills
    └── {skill-name}/
        └── SKILL.md

{project}/                   # 项目级（git repo root）
├── AGENTS.md                # 项目指令（根目录）
└── .deepagents/
   ├── AGENTS.md             # 项目指令（首选位置）
   ├── skills/               # 项目专属 skills
   │   └── {skill-name}/
   │       └── SKILL.md
   └── agents/               # 项目专属 subagents
       └── {subagent-name}/
           └── AGENTS.md
└── .agents/                 # 工具无关的项目 skills
    └── skills/
        └── {skill-name}/
            └── SKILL.md
```

## 放在哪里

| 数据 | 位置 | 读/写 | 说明 |
|------|----------|------------|-------|
| **Sessions** | `~/.deepagents/.state/sessions.db` | R/W | SQLite checkpoint 数据库 |
| **Input history** | `~/.deepagents/.state/history.jsonl` | R/W | JSON-lines，支持上下箭头回看 |
| **ChatGPT OAuth token** | `~/.deepagents/.state/chatgpt-auth.json` | R/W | 支持 [`openai_codex`](/oss/deepagents/code/providers) provider；在你使用 ChatGPT 登录时创建，并自动刷新。只有你的用户账户可读。 |
| **Base instructions** | Package `default_agent_prompt.md` | R | 不可变，随 Deep Agents Code 升级更新 |
| **User customizations** | `~/.deepagents/{agent}/AGENTS.md` | R/W | 追加到 base instructions |
| **Project instructions** | `.deepagents/AGENTS.md` 或 `AGENTS.md` | R | 如果两者都存在则都会加载 |
| **User skills** | `~/.deepagents/{agent}/skills/` | R/W | agent 专属 skills |
| **Shared skills** | `~/.agents/skills/` | R | 工具无关、跨 CLI |
| **Project skills** | `.deepagents/skills/` 或 `.agents/skills/` | R | 项目作用域 |
| **Custom subagents** | `~/.deepagents/{agent}/agents/` | R/W | 用户定义的 subagents |
| **Project subagents** | `.deepagents/agents/` | R | 项目定义的 subagents |

## 优先级规则

当同一个内容存在于多个位置时，**更高优先级会完全覆盖低优先级**（不会合并）。

### Skills

优先级顺序（从低到高）：

1. `~/.deepagents/{agent}/skills/` - User Deep Agents Code
2. `~/.agents/skills/` - User tool-agnostic
3. `.deepagents/skills/` - Project Deep Agents Code
4. `.agents/skills/` - Project tool-agnostic *(最高)*

当 skill 被加载时，Deep Agents Code 会校验解析后的文件路径是否仍然位于这些目录之一中。解析到这些 skill roots 之外的符号链接会被拒绝。要允许额外目录中的符号链接目标，请参见 [`[skills].extra_allowed_dirs`](/oss/deepagents/code/configuration#skill-directory-allowlist)。

### Subagents

优先级顺序（从低到高）：

1. `~/.deepagents/{agent}/agents/` - User-level
2. `.deepagents/agents/` - Project-level *(最高)*

每个 subagent 都是一个带 YAML frontmatter（`name`、`description`、可选 `model`）的 `AGENTS.md` 文件，以及作为 system prompt 的 markdown 正文。完整格式参考见 [在 Deep Agents Code 中使用 subagents](/oss/deepagents/code/subagents)。

### 指令

所有指令来源都会 **合并**（而不是覆盖）：

1. Package base prompt *(始终加载)*
2. `~/.deepagents/{agent}/AGENTS.md` *(追加)*
3. `.deepagents/AGENTS.md` *(追加)*
4. 项目根目录的 `AGENTS.md` *(追加)*

## `.deepagents` 与 `.agents`

| 目录 | 用途 | 何时使用 |
|-----------|---------|-------------|
| `.deepagents/` | Deep Agents Code 专用 | 使用 Deep Agents Code 专属特性所需的 skills 和 config |
| `.agents/` | 工具无关 | 想在不同 AI coding assistant 之间共享的 skills |

<Tip>
使用 `.agents/skills/` 存放能在任何 AI coding assistant 中使用的 skills。
使用 `.deepagents/skills/` 存放依赖 Deep Agents 特定工具或约定的 skills。
</Tip>

## 清理

| 需求 | 操作 |
|------|--------|
| 重置全部数据 | `rm -rf ~/.deepagents` |
| 只清除 sessions | `rm ~/.deepagents/.state/sessions.db*` |
| 清除输入历史 | `rm ~/.deepagents/.state/history.jsonl` |
| 清除已存储 API keys | `rm ~/.deepagents/.state/auth.json` |
| 清除 MCP OAuth tokens | `rm -rf ~/.deepagents/.state/mcp-tokens` |
| 清除 MCP project trust | `rm ~/.deepagents/.state/mcp_trust.json` |
| 重新运行首次启动引导 | `rm ~/.deepagents/.state/onboarding_complete` |
| 重置 agent 指令 | `dcode agents reset --agent {name}` |
| 删除 skill | `rm -rf ~/.deepagents/{agent}/skills/{skill-name}` |

<Warning>
    删除 `~/.deepagents/.state/sessions.db` 会移除所有对话历史和 checkpoints。

    除非你有 `sessions.db` 的备份，否则这无法撤销。
</Warning>
