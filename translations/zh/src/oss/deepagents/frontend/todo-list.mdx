当 agent 执行多步计划时，交互不一定是聊天。有时，最适合展示进度的方式是一个会实时更新的 **待办列表**。Deep Agents 的待办列表模式会直接从 agent 的状态中读取 `todos` 数组，并在 agent 执行计划时，按当前状态渲染每一项。这是建立在同一个 `useStream` hook 上的进度面板，你也可以把它用于聊天界面。它说明 agent 状态不仅能驱动消息气泡，也能驱动任何 UI。

## 工作原理

Deep Agents 内置一个 **`todos` 状态**，用于在 agent 执行计划时跟踪任务进度。执行过程中，agent 会把每个 todo 的状态从 `"pending"` 更新为 `"in_progress"`，再更新为 `"completed"`。@[`useStream`] hook 会通过 `stream.values.todos` 暴露这些状态，UI 会随之响应式更新。

流程如下：

1. 用户提交请求
2. Agent 创建计划，并把 `todos` 填入自身状态
3. Agent 开始执行，每个 todo 依次从 `pending` 变为 `in_progress`，再变为 `completed`
4. `stream.values.todos` 会随着 agent 进度实时更新
5. 你的 UI 重新渲染待办列表，显示最新状态

## 配置 `useStream`

不需要特殊配置。把 @[`useStream`] 指向你的 agent，并从 `stream.values` 中读取 `todos`。

<UseStreamTypeInference />

<CodeGroup>
```tsx React
import { useStream } from "@langchain/react";

const AGENT_URL = "http://localhost:2024";

export function TodoAgent() {
  const stream = useStream<typeof myAgent>({
    apiUrl: AGENT_URL,
    assistantId: "deep_agent_todo_list",
  });

  const todos = stream.values?.todos ?? [];

  return (
    <div>
      <TodoList todos={todos} />
      {stream.messages.map((msg) => (
        <Message key={msg.id} message={msg} />
      ))}
    </div>
  );
}
```

## 构建 TodoList 组件

待办列表会用状态图标、颜色编码和视觉样式来呈现每一项，反映当前状态：

```tsx
function TodoList({ todos }: { todos: Todo[] }) {
  const completed = todos.filter((t) => t.status === "completed").length;
  const percentage = todos.length
    ? Math.round((completed / todos.length) * 100)
    : 0;

  return (
    <div className="rounded-lg border bg-white p-4 shadow-sm">
      <div className="mb-4 flex items-center justify-between">
        <h2 className="text-lg font-semibold">Agent 进度</h2>
        <span className="text-sm text-gray-500">
          {completed}/{todos.length} 个任务
        </span>
      </div>

      <ProgressBar percentage={percentage} />

      <ul className="mt-4 space-y-2">
        {todos.map((todo, i) => (
          <TodoItem key={i} todo={todo} />
        ))}
      </ul>
    </div>
  );
}
```

## 进度条

可视化进度条能让用户一眼看出整体完成度：

```tsx
function ProgressBar({ percentage }: { percentage: number }) {
```

## 单个待办项

每个条目都会带有状态图标、颜色区分和完成任务的删除线样式：

```tsx
function TodoItem({ todo }: { todo: Todo }) {
  const config = {
    pending: {
      icon: "○",
      textClass: "text-gray-600",
      bgClass: "bg-gray-50",
      iconClass: "text-gray-400",
    },
    in_progress: {
      icon: "◉",
      textClass: "text-amber-800",
      bgClass: "bg-amber-50 border-amber-200",
      iconClass: "text-amber-500 animate-pulse",
    },
    completed: {
      icon: "✓",
      textClass: "text-green-800 line-through",
      bgClass: "bg-green-50 border-green-200",
      iconClass: "text-green-500",
    },
  };

  const style = config[todo.status];

  return (
    <li
      className={`flex items-start gap-3 rounded-md border px-3 py-2 ${style.bgClass}`}
    >
      <span className={`mt-0.5 text-lg leading-none ${style.iconClass}`}>
        {style.icon}
      </span>
      <span className={`text-sm ${style.textClass}`}>{todo.content}</span>
    </li>
  );
}
```

`in_progress` 图标会使用 `animate-pulse` 来突出当前正在执行的任务。

## 计算进度

直接从 todos 数组派生进度指标：

```ts
const todos = stream.values?.todos ?? [];

const completed = todos.filter((t) => t.status === "completed").length;
const inProgress = todos.filter((t) => t.status === "in_progress").length;
const pending = todos.filter((t) => t.status === "pending").length;
const percentage = todos.length
  ? Math.round((completed / todos.length) * 100)
  : 0;
```

这些值会在 agent 修改状态时响应式更新，从而让进度条和计数器始终保持同步。

## 与聊天消息结合

待办列表可以和常规聊天界面一起使用。一个实用的布局是把待办列表作为固定的侧边栏或顶部面板，聊天消息放在下面：

```tsx
function TodoAgentLayout() {
  const stream = useStream<typeof myAgent>({
    apiUrl: AGENT_URL,
    assistantId: "deep_agent_todo_list",
  });

  const todos = stream.values?.todos ?? [];

  return (
    <div className="flex h-screen flex-col">
      {todos.length > 0 && (
        <div className="border-b bg-gray-50 p-4">
          <TodoList todos={todos} />
        </div>
      )}

      <main className="flex-1 overflow-y-auto p-6">
        <div className="mx-auto max-w-2xl space-y-4">
          {stream.messages.map((msg) => (
            <Message key={msg.id} message={msg} />
          ))}
        </div>
      </main>

      <ChatInput
        onSubmit={(text) =>
          stream.submit({ messages: [{ type: "human", content: text }] })
        }
        isLoading={stream.isLoading}
      />
    </div>
  );
}
```

<Tip>
只有在 `todos.length > 0` 时才显示待办列表。在 agent 创建计划之前，没有内容可以展示。显示一个空组件只会浪费空间。
</Tip>

## 使用场景

待办列表模式适用于任何会执行结构化计划的 agent：

- **项目规划**：agent 将项目拆成任务，并按顺序推进
- **研究工作流**：每个研究问题都会变成一个待办项，由 agent 逐个调查并完成
- **数据处理**：摄取、验证、转换、导出等步骤各自拥有独立待办项
- **入职流程**：agent 逐步完成配置步骤，并勾选每一项
- **报告生成**：报告的各个部分会变成待办项，例如收集数据、分析趋势、撰写摘要、格式化输出

## 处理空状态和加载状态

在 agent 创建计划之前，先处理初始状态：

```tsx
function TodoList({ todos, isLoading }: { todos: Todo[]; isLoading: boolean }) {
  if (todos.length === 0 && !isLoading) {
    return null;
  }

  if (todos.length === 0 && isLoading) {
    return (
      <div className="rounded-lg border bg-white p-4 shadow-sm">
        <div className="flex items-center gap-2 text-sm text-gray-500">
          <span className="animate-spin">⟳</span>
          Agent 正在创建计划...
        </div>
      </div>
    );
  }

  return (
    <div className="rounded-lg border bg-white p-4 shadow-sm">
      {/* ... 完整的待办列表渲染 */}
    </div>
  );
}
```

## 最佳实践

- **显著展示待办列表**。它是基于计划的 agent 的主要进度指示器。不要把它放到折叠区之外。
- **为状态切换添加动画**。平滑过渡能让 agent 看起来更有响应。可以在背景色、删除线和透明度上使用 CSS 过渡。
- **只高亮一个 `in_progress` 条目**。Agent 通常一次只处理一个任务。如果多个条目都显示为 `in_progress`，界面会显得杂乱。可以考虑只让第一个条目闪烁。
- **折叠或弱化已完成项**。列表越长，已完成项就越不重要。降低它们的视觉权重，让用户更关注当前仍在进行的内容。
- **显示进度百分比**。像“67% 完成”这样的单个数字，即使在远处也能立即理解。
- **保持待办列表同步**。由于 `stream.values` 会响应式更新，待办列表会自动保持最新。不要再额外添加手动轮询或刷新逻辑。
