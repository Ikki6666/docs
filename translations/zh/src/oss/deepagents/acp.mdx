[Agent Client Protocol (ACP)](https://agentclientprotocol.com/get-started/introduction) 统一了编码代理与代码编辑器或 IDE 之间的通信方式。
借助 ACP，你可以让自定义 Deep Agents 与任何兼容 ACP 的客户端配合使用，从而让代码编辑器提供项目上下文并接收丰富的更新。

<Note>
    ACP 专为 agent 与编辑器的集成而设计。如果你想让你的 agent 调用外部服务器托管的工具，请参见 [Model Context Protocol (MCP)](/oss/langchain/mcp/)。
</Note>

## 快速开始

安装 ACP 集成包：

:::python
<CodeGroup>
```bash pip
pip install deepagents-acp
```

```bash uv
uv add deepagents-acp
```
</CodeGroup>
:::

:::js
<CodeGroup>
```bash npm
npm install deepagents-acp
```

```bash yarn
yarn add deepagents-acp
```

```bash pnpm
pnpm add deepagents-acp
```
</CodeGroup>
:::

然后通过 ACP 公开一个 deep agent。

这会以 stdio 模式启动一个 ACP server（它从 stdin 读取请求，并将响应写入 stdout）。实际使用中，你通常会把它作为 ACP client（例如你的编辑器）启动的命令运行，然后由客户端通过 stdio 与 server 通信。

:::python

<AcpQuickstartPy />

:::

:::js

```ts icon="server"
import { startServer } from "deepagents-acp";

await startServer({
  agents: {
    name: "coding-assistant",
    description: "AI coding assistant with filesystem access",
  },
  workspaceRoot: process.cwd(),
});
```

你也可以不写任何代码，直接使用 CLI：

```bash
npx deepagents-acp
```

## 客户端

Deep Agents 可以在任何能运行 ACP agent server 的地方使用。常见的 ACP client 包括：

- [Zed](https://zed.dev/docs/ai/external-agents)
- [JetBrains IDEs](https://www.jetbrains.com/help/ai-assistant/acp.html)
- Visual Studio Code（通过 [vscode-acp](https://github.com/formulahendry/vscode-acp)）
- Neovim（通过兼容 ACP 的插件）

### Zed

:::python

`deepagents` 仓库包含一个 [示例 ACP 入口点](https://github.com/langchain-ai/deepagents/blob/main/libs/acp/run_demo_agent.sh)，你可以将它注册到 [Zed](https://zed.dev/docs/ai/external-agents)：

1. 克隆 `deepagents` 仓库并安装依赖：

```bash
git clone https://github.com/langchain-ai/deepagents.git
cd deepagents/libs/acp
uv sync --all-groups
chmod +x run_demo_agent.sh
```

2. 为示例 agent 配置凭据：

```bash
cp .env.example .env
```

然后在 `.env` 中设置 `ANTHROPIC_API_KEY`。

3. 在 Zed 的 `settings.json` 中配置你的 ACP agent server 命令：

```json
{
  "agent_servers": {
    "DeepAgents": {
      "type": "custom",
      "command": "/your/absolute/path/to/deepagents/libs/acp/run_demo_agent.sh"
    }
  }
}
```

4. 打开 Zed 的 Agents 面板并启动一个 Deep Agents 线程。

:::

:::js

通过把你的 deep agent 添加到 Zed 设置中来注册它（Linux 上是 `~/.config/zed/settings.json`，macOS 上是 `~/Library/Application Support/Zed/settings.json`）：

**简单配置（无需代码）：**

```json
{
  "agent": {
    "profiles": {
      "deepagents": {
        "name": "DeepAgents",
        "command": "npx",
        "args": ["deepagents-acp"],
        "env": {
          "ANTHROPIC_API_KEY": "sk-ant-..."
        }
      }
    }
  }
}
```

**使用 CLI 选项：**

```json
{
  "agent": {
    "profiles": {
      "deepagents": {
        "name": "DeepAgents",
        "command": "npx",
        "args": [
          "deepagents-acp",
          "--name", "my-assistant",
          "--skills", "./skills",
          "--debug"
        ],
        "env": {
          "ANTHROPIC_API_KEY": "sk-ant-..."
        }
      }
    }
  }
}
```

**自定义 server 脚本：**

如果你想要更多控制，可以创建一个 TypeScript server 脚本：

```ts
// server.ts
import { startServer } from "deepagents-acp";

await startServer({
  agents: {
    name: "my-agent",
    description: "My custom coding agent",
    skills: ["./skills/"],
  },
});
```

然后让 Zed 指向它：

```json
{
  "agent": {
    "profiles": {
      "my-agent": {
        "name": "My Agent",
        "command": "npx",
        "args": ["tsx", "./server.ts"]
      }
    }
  }
}
```

打开 Zed 的 Agents 面板并启动一个 Deep Agents 线程。

## CLI reference

CLI 是启动 ACP server 最快的方式。它不需要任何代码，直接运行 `npx deepagents-acp`，然后把编辑器连上即可。

```bash
npx deepagents-acp [options]
```

| Option | Short | Description |
| ------ | ----- | ----------- |
| `--name <name>` | `-n` | agent 名称，默认值为 `"deepagents"` |
| `--description <desc>` | `-d` | agent 描述 |
| `--model <model>` | `-m` | LLM 模型，默认值为 `"claude-sonnet-4-5-20250929"` |
| `--workspace <path>` | `-w` | 工作区根目录，默认值为当前目录 |
| `--skills <paths>` | `-s` | 逗号分隔的 skill 路径 |
| `--memory <paths>` |  | 逗号分隔的 AGENTS.md 路径 |
| `--debug` |  | 启用 stderr 调试日志 |
| `--help` | `-h` | 显示帮助信息 |
| `--version` | `-v` | 显示版本 |

### 环境变量

| Variable | Description |
| -------- | ----------- |
| `ANTHROPIC_API_KEY` | Anthropic/Claude 模型的 API key，必需 |
| `OPENAI_API_KEY` | OpenAI 模型的 API key |
| `DEBUG` | 设为 `"true"` 以启用调试日志 |
| `WORKSPACE_ROOT` | `--workspace` 参数的替代方式 |

:::

## Programmatic API

### `startServer`

这是一个便捷函数，可以在一次调用中完成 server 创建与启动：

```ts icon="server"
import { startServer } from "deepagents-acp";

await startServer({
  agents: {
    name: "coding-assistant",
    description: "AI coding assistant with filesystem access",
  },
  workspaceRoot: process.cwd(),
});
```

### `DeepAgentsServer`

如果你需要更完整的控制能力，可以直接使用 `DeepAgentsServer` 类：

<AcpDeepAgentsServerJs />

#### Server options

| Option | Type | Default | Description |
| ------ | ---- | ------- | ----------- |
| `agents` | `DeepAgentConfig \| DeepAgentConfig[]` | required | agent 配置 |
| `serverName` | `string` | `"deepagents-acp"` | ACP 的 server 名称 |
| `serverVersion` | `string` | `"0.0.1"` | server 版本 |
| `workspaceRoot` | `string` | `process.cwd()` | 工作区根目录 |
| `debug` | `boolean` | `false` | 启用调试日志 |

#### Agent configuration

| Option | Type | Description |
| ------ | ---- | ----------- |
| `name` | `string` | 唯一的 agent 名称，必需 |
| `description` | `string` | agent 描述 |
| `model` | `string` | LLM 模型，默认值为 `"claude-sonnet-4-5-20250929"` |
| `tools` | `StructuredTool[]` | 自定义 LangChain tools |
| `systemPrompt` | `string` | 自定义 system prompt |
| `middleware` | `AgentMiddleware[]` | 追加到[默认栈](/oss/deepagents/customization#default-stack-main-agent)后的自定义 middleware |
| `backend` | `AnyBackendProtocol` | 文件系统 backend |
| `skills` | `string[]` | skill 源路径 |
| `memory` | `string[]` | memory 源路径（AGENTS.md） |
| `interruptOn` | `Record<string, boolean \| InterruptOnConfig>` | 需要用户审批的 tools（HITL） |
| `commands` | `Array<{ name, description, input? }>` | 自定义 slash commands |
