## 自定义工具

可以直接把任意可调用对象传给 `tools=`，例如普通函数、带 `@tool` 装饰器的 LangChain 函数，或者 tool dict。
Deep Agents 会根据函数签名和 docstring 推断工具 schema，所以大多数情况下你不需要单独定义 schema。

## MCP 工具

<Note>
  Deep Agents 完全支持 [Model Context Protocol (MCP)](/oss/langchain/mcp)，这是连接 agent 与外部服务的开放标准。你可以从任意 MCP server 加载工具，然后直接传给 `create_deep_agent`。
</Note>

MCP 是一种开放协议，可让 agent 通过标准接口连接到不断增长的 server 生态：数据库、API、文件系统、浏览器等等。与其为每个服务编写自定义集成代码，不如把 Deep Agents 指向一个 MCP server，它就能获得该 server 暴露的全部工具。

:::python
安装 `langchain-mcp-adapters` 以连接 MCP server：

```bash
pip install langchain-mcp-adapters
```

## 内置 harness 工具

除了你提供的工具之外，每个 Deep Agent 还自带一组来自 harness 的内置工具：

:::python

| 工具 | 说明 |
| ---- | ---- |
| `ls` | 列出目录中的文件。 |
| `read_file` | 读取文件内容，支持分页和多模态内容。 |
| `write_file` | 创建新文件，或覆盖已有文件。 |
| `edit_file` | 在文件中执行精确字符串替换。 |
| `delete` | 删除文件，或递归删除目录及其内容。`delete` 工具要求 `deepagents>=0.7`。 |
| `glob` | 查找匹配 glob 模式的文件。 |
| `grep` | 搜索文件内容。 |
| `execute` | 运行 shell 命令（仅 sandbox backend 可用）。 |
| `task` | 派生 subagent 来处理委派任务。 |
| `write_todos` | 管理结构化 todo list |

:::

:::js

## 多模态工具输出

当所选模型支持多模态工具结果时，自定义工具可以返回纯文本，或者返回[标准内容块](/oss/langchain/messages#standard-content-blocks)（文本、图像、音频、视频和文件）。内置的 `read_file` 工具也会为支持的非文本文件类型返回多模态 block。

只返回文本结果时，返回字符串；如果是文本加媒体，或交错的多模态输出，则返回一个有序的内容块列表。有关示例和上下文压缩注意事项，请参见 [Multimodal](/oss/deepagents/multimodal) 和 [Tool return values](/oss/langchain/tools#return-multimodal-content)。
