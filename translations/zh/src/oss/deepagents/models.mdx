Deep Agents 可以与任何支持 [tool calling](/oss/langchain/models#tool-calling) 的 [LangChain chat model](/oss/langchain/models) 一起工作。

## 支持的模型

请使用 `provider:model` 格式指定模型，例如 `google_genai:gemini-3.5-flash`、`openai:gpt-5.4` 或 `anthropic:claude-sonnet-4-6`。provider 前缀会选择对应的 LangChain integration，冒号后的内容会作为 model identifier 传给该 provider。有效的 provider 字符串请参见 @[`init_chat_model`] 的 `model_provider` 参数。关于 provider 专属配置，请参见 [chat model integrations](/oss/integrations/chat)。

model identifier 必须符合 provider 期望的格式。有些 provider 使用像 `gpt-5.5` 这样的简单名称；另一些则使用带命名空间的 ID 或 deployment path，例如 `zai-org/GLM-5.2`，因此完整的 Deep Agents 字符串会是 `baseten:zai-org/GLM-5.2`。请查看 provider 的 model catalog 或 integration docs 获取当前标识符。

### 推荐模型

这些模型在 [Deep Agents eval suite](https://github.com/langchain-ai/deepagents/tree/main/libs/evals#readme) 上表现不错。该套件会测试基础 agent 操作。通过这些 eval 是必要条件，但并不足以保证它们在更长、更复杂的任务上表现出色。

## 配置模型参数

:::python
向 @[`create_deep_agent`] 传入 `provider:model` 格式的 model string，或者传入已配置好的 model instance 以获得完全控制。底层上，model string 会通过 @[`init_chat_model`] 解析。
:::

:::js
向 @[`createDeepAgent`] 传入 `provider:model` 格式的 model string，或者传入已配置好的 model instance 以获得完全控制。底层上，model string 会通过 @[`init_chat_model`] 解析。
:::

要配置模型特定参数，可以使用 @[`init_chat_model`]，或者直接实例化 provider model class：

:::python
<CodeGroup>
    ```python init_chat_model
    from langchain.chat_models import init_chat_model
    from deepagents import create_deep_agent

    model = init_chat_model(
        model="google_genai:gemini-3.5-flash",
        thinking_level="medium",  # [!code highlight]
    )
    agent = create_deep_agent(model=model)
    ```

    ```python Provider package
    from langchain_google_genai import ChatGoogleGenerativeAI
    from deepagents import create_deep_agent

    model = ChatGoogleGenerativeAI(
        model="gemini-3.1-pro-preview",
        thinking_level="medium",  # [!code highlight]
    )
    agent = create_deep_agent(model=model)
    ```
</CodeGroup>
:::

:::js
<CodeGroup>
    ```typescript initChatModel
    import { initChatModel } from "langchain/chat_models/universal";
    import { createDeepAgent } from "deepagents";

    const model = await initChatModel("google_genai:gemini-3.5-flash", {
        reasoningEffort: "medium",  // [!code highlight]
    });
    const agent = createDeepAgent({ model });
    ```

    ```typescript Provider package
    import { ChatGoogle } from "@langchain/google";
    import { createDeepAgent } from "deepagents";

    const model = new ChatGoogle({
        model: "gemini-3.1-pro-preview",
        reasoningEffort: "medium",  // [!code highlight]
    });
    const agent = createDeepAgent({ model });
    ```
</CodeGroup>
:::

### Provider 配置

[`ProviderProfile`](/oss/deepagents/profiles#provider-profiles) 会把初始化参数打包起来，这些参数会在你创建 deep agent 时传入 `provider:model` string 时生效。如果你通过 @[`init_chat_model`] 传入一个预配置 model，则不会应用它。

你可以在两个层级注册，而且两者可以同时存在：

- **Provider level** — 像 `"openai"` 这样的裸 provider key 会应用到 `openai` provider 下的每一个模型。
- **Model level** — 像 `"openai:gpt-5.5"` 这样的 `provider:model` key 只会应用到那个特定模型，并会叠加在任何匹配的 provider-level profile 之上。

```python
from deepagents import ProviderProfile, register_provider_profile

# Provider-wide default: every openai model gets temperature=0.
register_provider_profile(
    "openai",
    ProviderProfile(init_kwargs={"temperature": 0}),
)

# Model-level override: gpt-5.5 additionally gets a specific reasoning effort.
# Inherits temperature=0 from the provider-level profile above.
register_provider_profile(
    "openai:gpt-5.5",
    ProviderProfile(init_kwargs={"reasoning_effort": "medium"}),
)
```

完整字段列表、合并语义和 plugin 打包方式请参见 [Profiles](/oss/deepagents/profiles)。

<Tip>
    如果你想控制模型构建完成后 *agent* 的行为，请使用 [harness profile](/oss/deepagents/profiles#harness-profiles)。
</Tip>

## 运行时选择模型

如果你的应用允许用户选择模型（例如在 UI 里使用下拉菜单），可以通过 [middleware](/oss/langchain/middleware) 在运行时切换模型，而不必重建 agent。

:::python

把用户选择的模型通过 [runtime context](/oss/langchain/models#dynamic-model-selection) 传入，然后使用 `wrap_model_call` middleware，并借助 @[`@wrap_model_call`] 装饰器在每次调用时覆盖 model：

```python
from dataclasses import dataclass
from langchain.chat_models import init_chat_model
from langchain.agents.middleware import wrap_model_call, ModelRequest, ModelResponse
from deepagents import create_deep_agent
from typing import Callable


@dataclass
class Context:
    model: str

@wrap_model_call
def configurable_model(
    request: ModelRequest,
    handler: Callable[[ModelRequest], ModelResponse],
) -> ModelResponse:
    model_name = request.runtime.context.model
    model = init_chat_model(model_name)
    return handler(request.override(model=model))

agent = create_deep_agent(
    model="google_genai:gemini-3.5-flash",
    middleware=[configurable_model],
    context_schema=Context,
)

# Invoke with the user's model selection
result = agent.invoke(
    {"messages": [{"role": "user", "content": "Hello!"}]},
    context=Context(model="openai:gpt-5.5"),
)
```
:::

:::js
```typescript
import { initChatModel, createMiddleware } from "langchain";
import { createDeepAgent } from "deepagents";
import * as z from "zod";

const contextSchema = z.object({
  model: z.string(),
});

const configurableModel = createMiddleware({
  name: "ConfigurableModel",
  wrapModelCall: async (request, handler) => {
    const modelName = request.runtime.context.model;
    const model = await initChatModel(modelName);
    return handler({ ...request, model });
  },
});

const agent = await createDeepAgent({
  model: "google_genai:gemini-3.5-flash",
  middleware: [configurableModel],
  contextSchema,
});

// 使用用户选择的模型进行调用
const result = await agent.invoke(
  { messages: [{ role: "user", content: "Hello!" }] },
  { context: { model: "openai:gpt-5.5" } },
);
```
:::

</Tip>
