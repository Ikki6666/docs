## 概览

本指南介绍如何使用 [Deep Agents](/oss/deepagents) 构建一个内容写作 agent。这个 agent 会加载品牌语气和 skills，把研究委派给 subagent，起草博客或社交媒体内容，并生成配套图像。

你构建的 agent 会：

1. 从品牌 instructions 和 skill 文件夹加载语气与工作流规则
1. 使用 `web_search` 把网页研究委派给专门的 subagent
1. 按照已加载的 skill 起草博客或社交媒体内容
1. 使用 Gemini 生成封面或社交图像，并把文件保存到项目目录下

完整可运行的 SDK 项目请参见 [content-builder-agent](https://github.com/langchain-ai/deepagents/tree/main/examples/content-builder-agent) 示例。

### 关键概念

本教程涵盖：

- 品牌 instructions（Managed Deep Agents 上的 [instructions](/langsmith/managed-deep-agents-instructions)，或 SDK 上的 [memory](/oss/deepagents/memory) 文件）：用于始终生效的语气和研究规则
- [Skills](/oss/deepagents/skills)：用于博客和社交媒体 playbook
- [Subagents](/oss/deepagents/subagents)：用于写作前的研究
- SDK 路径上的 [Filesystem backends](/oss/deepagents/backends)：用于文件读写
- 自定义 [tools](/oss/langchain/tools)：用于搜索和图像生成

## 前置条件

需要这些 API key：

- Anthropic（Claude）或其他 chat model provider
- Google（Gemini）：使用 `gemini-2.5-flash-image` 生成图像
- [Tavily](https://www.tavily.com/)：用于网页搜索（免费套餐）
- [LangSmith](https://smith.langchain.com)：用于 tracing（SDK 路径可选；Managed Deep Agents 必需）

:::python
Python 3.11 or later.
:::

:::js
Node.js 18 or later.
:::

## 选择一种方式

先从 [Managed Deep Agents](/langsmith/managed-deep-agents-overview) 开始，无需管理基础设施即可运行生产 agent。如果你希望在使用同一套 Deep Agents harness 的同时获得最大灵活性，可以改用 Deep Agents SDK：自己托管 agent，或运行自定义的 [LangSmith Deployment](/langsmith/deployment)。
