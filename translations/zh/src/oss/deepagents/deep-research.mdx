## 概览

本指南介绍如何使用 [Deep Agents](/oss/deepagents) 构建一个多步骤网页研究 agent。这个 agent 会把研究问题拆解为聚焦的任务，委派给专门的 subagent，并把研究结果综合成一份完整报告。

你构建的 agent 会：

1. 使用可选启用的 todo list middleware 规划研究
1. Delegate focused research tasks to sub-agents with isolated context
1. Assess search results and plan next steps as you gather information
1. Synthesize findings with proper citations into a final report

派生出的 subagent 使用 Tavily 执行网页搜索，并抓取完整网页内容用于分析。

### 关键概念

本教程涵盖：

- 用于并行且上下文隔离研究的 [Subagents](/oss/deepagents/subagents)
- 用于网页搜索的自定义 [tools](/oss/langchain/tools)
- 使用可选启用的 [planning tool](/oss/deepagents/overview#task-planning) 进行多步骤规划

## 前置条件

需要这些 API key：

- Anthropic (Claude) or Google (Gemini)
- [Tavily](https://www.tavily.com/)：用于网页搜索（可选；免费套餐足够）
- [LangSmith](https://smith.langchain.com)：用于 tracing（使用 SDK 时可选；Managed Deep Agents 必需）

## 选择一种方式

本指南介绍如何使用 [Managed Deep Agents](/langsmith/managed-deep-agents-overview) 和 Deep Agents SDK 构建这个 agent。Managed Deep Agents 让你无需管理基础设施即可部署 agent。Deep Agents SDK 在使用同一套 Deep Agents harness 的同时提供最大灵活性：你可以自己托管 agent，或运行自定义的 [LangSmith Deployment](/langsmith/deployment)。

### 运行 agent

<Steps>
<Step title="本地运行">

安装依赖并启动 agent：

:::python
```bash
uv sync
uv run mda dev
```
:::

:::js
<CodeGroup>
```bash npm
npm install
npx mda dev
```

```bash pnpm
pnpm install
pnpm exec mda dev
```

```bash bun
bun install
bunx mda dev
```
</CodeGroup>
:::

`mda dev` 会从 `.env` 加载 API keys，启动本地 Agent Server，并在 LangSmith Studio 中打开 agent。

在 Studio 中发送一个研究问题，例如：

```txt wrap
Compare the main approaches to context engineering for AI agents in 2025.
```

你应该会看到 orchestrator 使用 `write_todos` 进行规划、委派给 research sub-agent，并撰写报告。更多信息请参见[使用 LangSmith Studio 进行本地开发](/langsmith/managed-deep-agents-local-development)。
