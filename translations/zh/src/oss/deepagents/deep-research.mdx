## 概览

本指南演示如何使用 [Deep Agents](/oss/deepagents) 从零构建一个多步骤网页研究 agent。这个 agent 会把研究问题拆成聚焦的任务，把它们委派给专门的 subagent，并把结果综合成一份完整报告。

你构建的 agent 会：

1. Plan research using a todo list
1. Delegate focused research tasks to sub-agents with isolated context
1. Assess search results and plan next steps as you gather information
1. Synthesize findings with proper citations into a final report

被派生出来的 subagent 会使用 Tavily 执行网页搜索，并抓取完整网页内容用于分析。

### 关键概念

本教程涵盖：

- 用于并行且上下文隔离研究的 [Subagents](/oss/deepagents/subagents)
- 用于网页搜索的自定义 [tools](/oss/langchain/tools)
- 使用 [built-in planning tool](/oss/deepagents/overview#task-planning) 进行多步骤规划

## 前置条件

需要这些 API key：

- Anthropic (Claude) or Google (Gemini)
- [Tavily](https://www.tavily.com/) for web search (optional - free tier sufficient)
- [LangSmith](https://smith.langchain.com) for tracing (optional)

## 下一步

既然你已经构建了这个 agent，可以通过修改 agent 文件中的 prompt 常量来自定义工作流、委派策略或研究者行为。
你也可以调整委派限制，让它支持更多并行 subagent 或更多轮委派。

For more information on the concepts in this tutorial, check out the following resources:

- [Subagents](/oss/deepagents/subagents)：了解如何为 subagent 配置不同的 tools 和 prompts
- [Customization](/oss/deepagents/customization)：自定义模型、tools、system prompt 和规划行为
- [LangSmith](/langsmith/observability)：为研究运行添加 tracing，并调试多步骤行为
- [Deep Research Course](https://academy.langchain.com/courses/deep-research-with-langgraph)：LangGraph deep research 的完整课程
