<Tip>
对于新应用程序，我们推荐[事件流](/oss/deepagents/event-streaming)——Deep Agents v0.6 中引入的类型化投影 API。事件流为每个投影提供单独的迭代器（子代理、消息、工具调用、值），因此您可以独立使用它们，而不是在“stream_mode”块上分支。
</Tip>
Deep Agents 构建在 LangGraph 的流基础设施之上，为子代理流提供一流的支持。当深度代理将工作委托给子代理时，您可以独立地传输来自每个子代理的更新 - 实时跟踪进度、LLM 令牌和工具调用。

深度代理流可以实现什么：

* <Icon icon="diagram-subtask" size={16} /> [**流子代理进度**](#subagent-progress) — 跟踪每个子代理并行运行时的执行情况。
* <Icon icon="square-binary" size={16} /> [**流式传输 LLM 令牌**](#llm-tokens) — 从主代理和每个子代理流式传输令牌。
* <Icon icon="screwdriver-wrench" size={16} /> [**流工具调用**](#tool-calls) - 查看子代理执行中的工具调用和结果。
* <Icon icon="table" size={16} /> [**流自定义更新**](#custom-updates) — 从内部子代理节点发出用户定义的信号。

## 命名空间

启用“子图”时，每个流事件都包含一个**命名空间**，用于标识哪个代理生成了它。命名空间是代表代理层次结构的节点名称和任务 ID 的路径。

|命名空间 |来源 |
| ---------| ------ |
| `()`（空）|主代理|
| `("工具：abc123",)` |由主代理的“任务”工具调用“abc123”生成的子代理 |
| `（“工具：abc123”，“model_request：def456”）` |子代理内的模型请求节点 |

## v2 流媒体格式
<Note>
需要 LangGraph >= 1.1。
</Note>
本页上的所有示例都使用 v2 流格式 (`version="v2"`)，这是推荐的方法。每个块都是一个带有“type”、“ns”和“data”键的“StreamPart”字典——无论流模式、模式数量或子图设置如何，形状都相同。

v2 格式消除了嵌套元组解包，从而可以直接处理深度代理中的子图流。比较两种格式：
<CodeGroup>
```python v2 (recommended)
# Unified format — no nested tuple unpacking
for chunk in agent.stream(
    {"messages": [{"role": "user", "content": "Research quantum computing"}]},
    stream_mode=["updates", "messages", "custom"],
    subgraphs=True,
    version="v2",
):
    print(chunk["type"])  # "updates", "messages", or "custom"
    print(chunk["ns"])    # () for main agent, ("tools:<id>",) for subagent
    print(chunk["data"])  # payload
```
```python v1 (legacy)
# Must handle (namespace, (mode, data)) nested tuples
for namespace, chunk in agent.stream(
    {"messages": [{"role": "user", "content": "Research quantum computing"}]},
    stream_mode=["updates", "messages", "custom"],
    subgraphs=True,
):
    mode, data = chunk[0], chunk[1]
    print(mode)       # "updates", "messages", or "custom"
    print(namespace)  # () for main agent, ("tools:<id>",) for subagent
    print(data)       # payload
```
</CodeGroup>
有关 v2 格式的更多详细信息，包括类型缩小和 Pydantic/dataclass 强制，请参阅 [LangGraph 流文档](/oss/langgraph/streaming#stream-output-format-v2)。
:::
