本指南会带你创建第一个 deep agent，涵盖规划、文件系统工具和子 agent 能力。你将构建一个可以做研究并撰写报告的 research agent。

<Tip>
    **在使用 AI 编码助手？**

    - 安装 [LangChain Docs MCP server](/use-these-docs)，让你的 agent 可以访问最新的 LangChain 文档和示例。
    - 安装 [LangChain Skills](https://github.com/langchain-ai/langchain-skills)，提升 agent 在 LangChain 生态任务上的表现。
</Tip>

## 前提条件

开始之前，请确保你拥有一个模型 provider 的 API key（例如 Gemini、Anthropic、OpenAI）。

<Note>
    Deep Agents 需要支持 [tool calling](/oss/langchain/models#tool-calling) 的模型。有关如何配置模型，请参见 [customization](/oss/deepagents/customization#model)。
</Note>

## 它是如何工作的？

你的 deep agent 会自动：

1. **规划方法**，使用内置的 [`write_todos`](/oss/deepagents/overview#task-planning) 工具拆解研究任务。
1. **开展研究**，调用 `internet_search` 工具收集信息。
1. **管理上下文**，使用文件系统工具（[`write_file`](/oss/deepagents/overview#virtual-filesystem-access)、[`read_file`](/oss/deepagents/overview#virtual-filesystem-access)）卸载大型搜索结果。
1. **按需派生子 agent**，把复杂子任务委派给专用子 agent。
1. **汇总报告**，把发现整理成连贯的回答。

## 流式输出

Deep Agents 内置 [streaming](/oss/langchain/event-streaming)，可通过 LangGraph 接收 agent 执行过程中的实时更新。
这让你可以逐步观察输出，并审查和调试 agent 与子 agent 的工作，例如工具调用、工具结果和 LLM 响应。

## 下一步

既然你已经构建了第一个 deep agent：

- **自定义你的 agent**：了解 [customization options](/oss/deepagents/customization)，包括自定义 system prompt、工具和子 agent。
- **添加长期 memory**：在多轮对话中启用 [persistent memory](/oss/deepagents/memory)。
- **部署到生产环境**：使用 [Managed Deep Agents](/langsmith/managed-deep-agents-overview) 在 LangSmith 中创建、运行和运维 deep agent。
- **测试和评估**：使用 [LangSmith evaluation](/langsmith/evaluation-quickstart) 对数据集运行自动化测试，并衡量 agent 的表现。
