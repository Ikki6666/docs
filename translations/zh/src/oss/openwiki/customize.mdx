通过忽略规则、wiki brief、agent 指令指针和遥测来自定义 OpenWiki。

## 忽略路径

在仓库根目录创建 `.openwikiignore`，将私有、生成或无关的路径排除在文档运行之外。语法和行为请参见 [Code mode](/oss/openwiki/code-mode#ignore-paths)。

## Wiki 指令

OpenWiki 在运行期间会读取以下文件。你可以自己编辑它们，或在聊天中让 OpenWiki 修订 brief（例如 `openwiki "Update openwiki/INSTRUCTIONS.md to focus on the public API"`）。

| 模式 | 路径 | 用途 |
| --- | --- | --- |
| Code | `openwiki/INSTRUCTIONS.md` | 面向仓库文档范围和优先级的共享、用户编写的 brief |
| Personal | `~/.openwiki/INSTRUCTIONS.md` | 全局个人 wiki 指令 |

正常的 `--init` 和 `--update` 运行不会重写这些文件。

## Agent 指令文件

在每次 code 运行时，OpenWiki 会在仓库根目录维护 `AGENTS.md` 和 `CLAUDE.md`：

- 如果文件不存在则创建它
- 如果文件已存在，只重写 `<!-- OPENWIKI:START -->` … `<!-- OPENWIKI:END -->` block
- 其余内容保持原样

该 block 会指示 coding agent 在需要仓库上下文时查阅生成的 wiki。

## 本地配置目录

Code 和 personal 两种模式默认都将机器本地 state 存储在 `~/.openwiki/` 下：

| 路径 | 模式 | 用途 |
| --- | --- | --- |
| `~/.openwiki/.env` | 两者 | Provider 配置、API key 和 connector OAuth token |
| `~/.openwiki/openwiki.sqlite` | 两者 | 会话 checkpoint 数据库 |
| `~/.openwiki/install-id` | 两者 | 用于匿名遥测的随机安装 ID |
| `~/.openwiki/wiki/` | Personal | Personal 模式的 wiki 输出 |
| `~/.openwiki/INSTRUCTIONS.md` | Personal | 个人 wiki brief |
| `~/.openwiki/onboarding.json` | Personal | 个人 onboarding 偏好和 connector schedule |
| `~/.openwiki/connectors/` | 主要为 personal | Connector 原始数据和配置。Personal 来源使用该路径；code 模式的 LangSmith 摄取也可以在这里缓存原始数据 |

Code 模式的仓库产物（例如生成的 wiki、`openwiki/.claims/` 下的 Claims、`openwiki/INSTRUCTIONS.md` 和 `openwiki/.last-update.json`）位于项目中，而不是 `~/.openwiki/` 下。更多细节请参见 [Code mode](/oss/openwiki/code-mode) 和 [Personal mode](/oss/openwiki/personal-mode)。


### 覆盖 state 目录

在启动 OpenWiki 之前设置 `OPENWIKI_CONFIG_DIR` 可以使用其他可写目录，例如挂载的容器卷：

```bash
OPENWIKI_CONFIG_DIR=/data/openwiki openwiki personal --init
```

该覆盖会选择一个独立的 state 目录。OpenWiki 不会移动或删除已有的 `~/.openwiki` 目录。要保留任何你想保留的 state，请自己复制它，并将该变量指向一个专用目录，因为 OpenWiki 会将其权限限制为当前用户。

## 遥测

OpenWiki 默认收集匿名的、聚合的使用数据，以便项目了解工具的使用方式并加以改进。

在单个 `openwiki_run` 事件上**收集**的内容，以存储在 `~/.openwiki/install-id` 中的随机安装 ID 为键：

- 每次记录的运行：命令（`init` / `update`）和结果（`success` / `failure` / `no-op`），失败时附带粗粒度的错误类别（绝不会是错误消息本身）。交互式聊天、`auth` 和 `ingest` 不会被记录
- 在设置时（仅 init）：brain 模式（`code` / `personal`）、模型 provider 和已配置的 connector 名称（绝不会是它们的内容）

**绝不收集：** 文件内容、仓库数据或名称、凭据、prompts、模型输出、connector payload、错误消息、文件路径、URL、model ID、运行时长、IP 地址或个人信息。GeoIP 丰富已禁用。

按计划和 CI 运行会在共享的 CI 标识符下单独标记，不会被计为不同的安装。

### 退出遥测

```bash
export OPENWIKI_TELEMETRY_DISABLED=1
# or
export DO_NOT_TRACK=1
```

要永久禁用遥测收集，请将 `OPENWIKI_TELEMETRY_DISABLED=1` 添加到 `~/.openwiki/.env`。在 CI 中，在工作流环境中设置它。

要检查一次运行会确切发送什么，请为任意运行添加 `--telemetry-file=<path>`。
