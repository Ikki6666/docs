OpenWiki 以单个 `openwiki` 二进制发布，用于交互式聊天和一次性文档运行。安装和首次使用请参见 [Quickstart](/oss/openwiki/quickstart)。

## 核心命令

```bash
# Interactive chat in code mode (current repository)
openwiki
openwiki "Please generate documentation for this repository"

# Personal mode
openwiki personal
openwiki personal --init
openwiki personal --update

# Explicit code mode
openwiki code --init
openwiki code --update
openwiki code --update --print

# Defaults to code mode and specify a language
openwiki --init
openwiki --update
openwiki --init --language ko

# One-shot print mode
openwiki -p "Summarize what you can do"

# Explore the wiki locally or export a static visualizer
openwiki visualize
openwiki visualize openwiki --port 4400 --no-open
openwiki visualize openwiki --export docs/openwiki-visualizer

# Coding-agent integrations
openwiki integrations list
openwiki integrations install codex
openwiki integrations install claude
openwiki integrations install opencode
openwiki integrations install cursor
openwiki integrations uninstall codex

# Help
openwiki --help
```

### 常用 flag

| Flag | 说明 |
| --- | --- |
| `--init` | 生成初始文档。默认为 code 模式。重新运行会从头重新生成仓库 wiki，同时保留 `openwiki/INSTRUCTIONS.md`。在 TTY 中不使用 `--print` 时，会流式输出 agent 输出并在成功后自动退出。`--init` 和 `--update` 不能组合。 |
| `--update` | 更新已有文档。默认为 code 模式。在 TTY 中不使用 `--print` 时，会流式输出 agent 输出并在成功后自动退出。`--init` 和 `--update` 不能组合。 |
| `-l`、`--language <locale>` | 以给定的 BCP-47 locale 生成 wiki 文档，例如 `ko`、`zh-CN` 或 `pt-BR`。无法识别的值会被拒绝。 |
| `--mode <personal\|code>` | 选择个人 brain 或仓库文档。 |
| `-p`、`--print` | 运行一次，打印最终的 assistant 输出，然后退出。提供一条消息或命令。不使用 `--print` 的交互式聊天会保持打开以便后续追问。 |
| `--modelId` / `--model-id` | 为本次运行选择模型 ID。 |
| `--telemetry-file=<path>` | 同时将本次运行的遥测 payload 写入本地 JSON 文件。 |
| `-h`、`--help` | 打印用法。 |

## Visualize

你可以将生成的 wiki 可视化为交互式节点图和实时 Markdown 阅读器，或导出静态站点用于托管：

```bash
openwiki visualize
openwiki visualize openwiki --port 4400 --no-open
openwiki visualize openwiki --export docs/openwiki-visualizer
openwiki visualize ~/.openwiki/wiki
```

详情请参见 [Visualize your wiki](/oss/openwiki/visualize)。

## Coding-agent 集成

将 OpenWiki 安装到宿主 coding agent 中，由宿主的模型和仓库工具驱动生成，而 OpenWiki 负责持久化的页面 job 生命周期：

```bash
openwiki integrations list [--project [path]]
openwiki integrations install <codex|claude|opencode|cursor> [--force] [--project [path]]
openwiki integrations uninstall <codex|claude|opencode|cursor> [--project [path]]
```

详情请参见 [Coding-agent integrations](/oss/openwiki/integrations)。

## Auth 与 connector

```bash
# List supported auth providers and status
openwiki auth

# Browser OAuth; save tokens to ~/.openwiki/.env and create connector config when possible
openwiki auth gmail
openwiki auth notion
openwiki auth slack
openwiki auth x

# Regenerate connector config from saved auth env vars
openwiki auth configure <provider> [--force]

# List live MCP tools for MCP-backed providers
openwiki auth tools <provider>

# Run source-specific connector ingestion
openwiki ingest <source|source-instance|all>

# HTTPS tunnel for Slack OAuth; saves OPENWIKI_HTTPS_OAUTH_REDIRECT_URI
openwiki ngrok start [url] [--port <port>]
```

## Cron（macOS）

管理 [personal mode](/oss/openwiki/personal-mode) 来源的可选 connector schedule。在 macOS 上，OpenWiki 可以将 schedule 安装为用户 LaunchAgents，按周期刷新某个来源（例如 Gmail 或 web search）。使用这些命令列出、暂停、恢复或删除它们：

```bash
openwiki cron list
openwiki cron pause <source|all>
openwiki cron resume <source|all>
openwiki cron delete <source|all>
```

`cron delete` 会移除已保存的 schedule 并卸载其 LaunchAgent。它不会移除认证、connector 配置、原始数据或 wiki 内容。

## 斜杠命令（交互式）

在交互式聊天模式中，可以使用以下命令：

- `/api-key`：更新当前 provider 的 API key（掩码输入）
- `/langsmith-key`：更新或清除 LangSmith tracing 凭据（掩码输入）
- `/provider` 和 `/model`：更改会话的 provider 或模型（持久化到 `~/.openwiki/.env`）
- `/effort`：为受支持的 OpenAI GPT-5.6 和 NVIDIA NIM 模型设置 reasoning effort，或使用 `/effort default` 恢复 provider 默认值
- `/init` 和 `/update`：从会话中启动 init 或 update
- `/exit`：退出应用
