为了浏览 OpenWiki 的 Markdown wiki，`openwiki visualize` 会在你的浏览器中提供一张本地交互式节点图，旁边是实时的 Markdown 阅读器。你还可以将相同的图和阅读器导出为静态目录用于托管。

## 打开 visualizer

在一个已经有 `openwiki/` 目录的仓库中：

```bash
openwiki visualize
```

这会在 `127.0.0.1:4321` 上提供 `./openwiki`，并打开你的浏览器到该图。server 运行期间对 wiki 文件的编辑会被自动读取。图面板可以调整大小并折叠，位于 Markdown 阅读器旁边。

## 选项

```bash
openwiki visualize openwiki --port 4400 --no-open
```

| 参数 / flag | 说明 |
| --- | --- |
| `[path]` | 要提供的 wiki 目录。默认为 `./openwiki` |
| `--port <port>` | 偏好的端口。默认为 `4321`。如果端口已被占用则递增 |
| `--no-open` | 不自动打开浏览器 |
| `--export <dir>` | 写入一个静态 visualizer 目录，而不是启动本地 server。不能与 `--port` 或 `--no-open` 组合 |

要浏览个人 wiki：

```bash
openwiki visualize ~/.openwiki/wiki
```

Visualizer 显示：

- wiki concepts 及其之间 Markdown 链接的交互式节点图
- 所选页面的并排实时 Markdown 阅读器

该图不显示 `INSTRUCTIONS.md` 和其他脚手架文件。

## 导出静态站点

要将 visualizer 与生成的文档一起发布，请导出一个静态目录而不是启动 server：

```bash
openwiki visualize <PATH> --export docs/openwiki-visualizer
```

导出内容包括 `index.html`、`client.js`、`client-lib.js`、`styles.css` 和 `graph.json`。它的 client 会读取同目录下的 graph 文件，不使用实时重载，因此该目录可以由 GitHub Pages、MkDocs 或任何其他静态主机托管。

<Note>
    该页面从公共 CDN 加载它的图、Markdown 和 diagram 库，因此本地和静态 viewer 都需要互联网连接。
</Note>
