:::python
<Warning>
**不要向 LangChain 或 Deep Agents 仓库提交集成 PR。**

新的集成应当作为**独立的 PyPI 包**发布在你自己的 GitHub 组织或账号下（例如 `langchain-yourservice`），而不是向 [`langchain-ai/langchain`](https://github.com/langchain-ai/langchain) 仓库提交 PR。

现在你的包已经实现并通过测试，你可以将它发布出去，并补充文档，让社区能够发现它。

## 发布你的包

<Info>
    本指南假设你已经实现了你的包，并为它编写了测试。如果还没有，请参阅[实现指南](/oss/contributing/implement-langchain)和[测试指南](/oss/contributing/standard-tests-langchain)。
</Info>

在本指南中，我们会使用 PyPI 作为包注册表。如果你更希望发布到其他注册表，也完全可以，只是具体步骤会有所不同。

### 配置凭证

首先，请确认你已经拥有一个 PyPI 账号：

<AccordionGroup>
    <Accordion title="如何创建 PyPI Token" icon="key">
        <Steps>
            <Step title="创建账号">
                前往 [PyPI 网站](https://pypi.org/) 并创建一个账号
            </Step>

            <Step title="验证邮箱">
                点击 PyPI 发送给你的邮件中的链接，完成邮箱验证
            </Step>

            <Step title="启用 2FA">
                打开你的账号设置，点击 "Generate Recovery Codes" 启用 2FA。要生成 API token，**必须**先启用 2FA
            </Step>

            <Step title="生成 token">
                打开账号设置，并[生成一个新的 API token](https://pypi.org/manage/account/token/)
            </Step>
        </Steps>
    </Accordion>
</AccordionGroup>

## 添加文档

如果你想在本站的[integrations 标签页](/oss/integrations/providers/overview)下为你的包添加文档，你需要创建对应的文档页面，并在 [LangChain docs repository](https://github.com/langchain-ai/docs) 中提交一个 PR。

### 编写文档

根据你构建的集成类型不同，你需要创建的文档页面类型也不同。LangChain 为不同类型的集成提供了模板，帮助你快速开始。

<CardGroup>
    <Card title="Chat models" icon="message" href="https://github.com/langchain-ai/docs/blob/main/src/oss/python/integrations/chat/TEMPLATE.mdx" arrow/>
    <Card title="Tools/toolkits" icon="tool" href="https://github.com/langchain-ai/docs/blob/main/src/oss/python/integrations/tools/TEMPLATE.mdx" arrow/>
    <Card title="Middleware" icon="plug" href="https://github.com/langchain-ai/docs/blob/main/src/oss/python/integrations/middleware/TEMPLATE.mdx" arrow/>
    <Card title="Vector stores" icon="database" href="https://github.com/langchain-ai/docs/blob/main/src/oss/python/integrations/vectorstores/TEMPLATE.mdx" arrow/>
</CardGroup>

<Tip>
    如果你想参考现有文档，可以查看[集成列表](/oss/integrations/providers/overview)，然后找到和你类似的集成。

    如果你想查看某个文档页面的原始 markdown，可以点击页面右上角 "Copy page" 旁边的下拉按钮，然后选择 "View as Markdown"。
</Tip>

### 向 docs 仓库提交 PR

请 fork [LangChain docs repository](https://github.com/langchain-ai/docs)（不是主 `langchain` 仓库）到你的个人 GitHub 账号下，并将其克隆到本地。为你的集成创建一个新分支。复制模板后，用你喜欢的 markdown 编辑器进行修改。编写文档时，请务必参考并遵循[文档指南](/oss/contributing/documentation)。

<Info>
    这个 PR **只用于文档**。你的集成包本身应位于你自己的 GitHub 组织或账号下的独立仓库中，并作为独立包发布到 PyPI。
</Info>

<Warning>
    在以下情况下，我们可能会拒绝 PR 或要求修改：
    - CI 检查失败
    - 存在严重语法错误或拼写错误
    - [Mintlify components](/oss/contributing/documentation#mintlify-components) 使用不正确
    - 页面缺少 [frontmatter](/oss/contributing/documentation#page-structure)
    - 缺少[本地化](/oss/contributing/documentation#localization)（在适用情况下）
    - [代码示例](/oss/contributing/documentation#in-code-documentation) 无法运行或存在错误
    - 不符合[质量标准](/oss/contributing/documentation#quality-standards)
</Warning>

由于我们需要处理大量 PR，请保持耐心。我们会尽快审核你的 PR，并给出反馈或完成合并。**不要反复 @ 维护者催促你的 PR。**

<Note>
    如果你的 PR 包含 AI 生成内容，你必须遵循我们的[LLM 可接受使用方式](/oss/contributing/overview#acceptable-uses-of-llms)政策。
</Note>
