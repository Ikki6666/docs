**集成是 LangChain 的核心组成部分。**

LangChain 为多种关键组件提供标准接口（语言模型、向量存储等），这些组件在构建 LLM 应用时至关重要。实现新的集成可以帮助扩展 LangChain 生态，也能让你的服务被数百万开发者发现。

<Warning>
    任何 `langchain-ai` 仓库都**不接受新的集成 PR**。所有新集成都必须作为独立包发布到 PyPI（例如 `langchain-yourprovider`）。你唯一应该向 `langchain-ai` 仓库提交的 PR，是为你已经发布的包添加文档。
</Warning>

## 为什么要实现 LangChain 集成？

<Card title="可发现性" icon="search">
    LangChain 是最常用的 LLM 应用构建框架，每月下载量超过 2 亿次。
</Card>

<Card title="互操作性" icon="refresh">
    LangChain 组件暴露的是标准接口，开发者可以轻松在不同组件之间互换。如果你实现了一个 LangChain 集成，任何使用其他组件的开发者都可以很容易地切换到你的组件。
</Card>

<Card title="最佳实践" icon="star">
    通过标准接口，LangChain 组件鼓励并支持流式处理、异步等最佳实践，从而提升开发者体验和应用性能。
</Card>

## 可集成的组件

虽然任何组件都可以集成到 LangChain 中，但我们尤其鼓励以下几类集成：

**优先集成这些 ✅**：

- [**Chat Models**](/oss/integrations/chat)：使用最活跃的组件类型
- [**Tools/Toolkits**](/oss/integrations/tools)：赋予智能体能力
- [**Retrievers**](/oss/integrations/retrievers)：RAG 应用的核心
- [**Embedding Models**](/oss/integrations/embeddings)：向量操作的基础
- [**Vector Stores**](/oss/integrations/vectorstores)：语义搜索的关键组成
- [**Middleware**](/oss/integrations/middleware)：通过钩子扩展智能体行为
- [**Sandboxes**](/oss/deepagents/sandboxes)：让 Deep Agents 安全运行代码

**不建议集成这些 ❌**：

- **LLMs（文本补全模型）**：已被 [Chat Models](/oss/integrations/chat) 取代
- [**Document Loaders**](/oss/integrations/document_loaders)：维护成本高
- [**Key-Value Stores**](/oss/integrations/stores)：使用场景有限
- **Document Transformers**：用例较小众
- **Model Caches**：更偏基础设施问题
- **Graphs**：抽象较复杂
- **Message Histories**：存储抽象
- **Callbacks**：系统级组件
- **Chat Loaders**：需求有限
- **Adapters**：边界场景工具

## 如何贡献一个集成

<Steps>
    <Step title="实现你的包">
        <Card title="如何实现 LangChain 集成" icon="link" href="/oss/contributing/implement-langchain" arrow />
    </Step>

    <Step title="通过标准测试">
        如果适用，请为你的集成实现对 LangChain [标准测试](/oss/contributing/standard-tests-langchain)套件的支持，并成功运行它们。
    </Step>

    <Step title="发布集成">
        <Card title="如何发布一个集成" icon="upload" href="/oss/contributing/publish-langchain" arrow />
    </Step>

    <Step title="添加文档">
        提交 PR，将你的集成文档加入官方 LangChain 文档站点。

        <Accordion title="集成文档指南" icon="book">
            一个集成只有在文档完善时才真正有用。为了确保用户拥有一致的使用体验，所有新集成都必须提供文档。我们为每种集成类型都提供了标准起始模板，你可以复制后再修改。

            在一个新的 LangChain [docs repo](https://github.com/langchain-ai/docs) PR 中，使用合适的模板文件，在 `src/oss/python/integrations/<component_type>/integration_name.mdx` 对应目录下创建一个新文件：

            - [Chat models](https://github.com/langchain-ai/docs/blob/main/src/oss/python/integrations/chat/TEMPLATE.mdx)
            - [Tools and toolkits](https://github.com/langchain-ai/docs/blob/main/src/oss/python/integrations/tools/TEMPLATE.mdx)
            - [Middleware](https://github.com/langchain-ai/docs/blob/main/src/oss/python/integrations/middleware/TEMPLATE.mdx)
            - Retrievers - 即将推出
            - Text splitters - 即将推出
            - Embedding models - 即将推出
            - [Vector stores](https://github.com/langchain-ai/docs/blob/main/src/oss/python/integrations/vectorstores/TEMPLATE.mdx)
            - Document loaders - 即将推出
            - Key-value stores - 即将推出
        </Accordion>
    </Step>

    <Step title="联合营销" icon="speakerphone">
        （可选）与 LangChain 团队联系，开展联合[营销推广](/oss/contributing/comarketing)。
    </Step>
</Steps>
