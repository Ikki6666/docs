LangSmith 可以通过 PydanticAI 内置的 OpenTelemetry instrumentation 捕获其生成的 traces。本指南介绍如何自动捕获 PydanticAI agents 的 traces，并把它们发送到 LangSmith 进行监控和分析。

## 安装

安装所需依赖：

<CodeGroup>

```bash pip
pip install langsmith pydantic-ai opentelemetry-exporter-otlp
```

```bash uv
uv add langsmith pydantic-ai opentelemetry-exporter-otlp
```

</CodeGroup>

<Info>
为了获得最佳 OpenTelemetry 支持，需要 LangSmith Python SDK 版本 `langsmith>=0.4.26`。
</Info>

## 设置

### 1. 配置环境变量

设置你的 [API keys](/langsmith/create-account-api-key) 和 project 名称：

```bash
export LANGSMITH_API_KEY=<your_langsmith_api_key>
export LANGSMITH_PROJECT=<your_project_name>
export OPENAI_API_KEY=<your_openai_api_key>
```

### 2. 配置 OpenTelemetry integration

在 PydanticAI 应用中，配置 LangSmith 的 OpenTelemetry integration：

```python
from langsmith.integrations.otel import configure
from pydantic_ai import Agent

# Configure LangSmith tracing
configure(project_name="pydantic-ai-demo")

# Instrument all PydanticAI agents
Agent.instrument_all()
```

<Note>
你不需要设置任何 OpenTelemetry 环境变量，也不需要手动配置 exporters，`configure()` 会自动处理这些事情。
</Note>

### 3. 创建并运行 PydanticAI agent

完成配置后，PydanticAI agents 会自动把 traces 发送到 LangSmith：

```python
from langsmith.integrations.otel import configure
from pydantic_ai import Agent

# Configure LangSmith tracing
configure(project_name="pydantic-ai-demo")

# Instrument all PydanticAI agents
Agent.instrument_all()

# Create and run an agent
agent = Agent('openai:gpt-5.5')
result = agent.run_sync('What is the capital of France?')
print(result.output)
#> Paris
```

## 高级用法

### 自定义 metadata 和 tags

你可以使用 OpenTelemetry span attributes，把自定义 metadata 添加到 traces 中：

```python
from opentelemetry import trace
from pydantic_ai import Agent
from langsmith.integrations.otel import configure

configure(project_name="pydantic-ai-metadata")
Agent.instrument_all()

tracer = trace.get_tracer(__name__)

agent = Agent('openai:gpt-5.5')

with tracer.start_as_current_span("pydantic_ai_workflow") as span:
    span.set_attribute("langsmith.metadata.user_id", "user_123")
    span.set_attribute("langsmith.metadata.workflow_type", "question_answering")
    span.set_attribute("langsmith.span.tags", "pydantic-ai,production")

    result = agent.run_sync('Explain quantum computing in simple terms')
    print(result.output)
```
