本页介绍如何设置和管理你的 LangSmith[_组织_](/langsmith/administration-overview#organizations)与[_工作区_](/langsmith/administration-overview#workspaces)：

- [设置组织](#set-up-an-organization)：创建并管理用于团队协作的组织，包括用户管理和角色分配。
- [设置工作区](#set-up-a-workspace)：设置并配置工作区，以组织 LangSmith 资源、管理工作区成员，并为团队协作配置相关设置。
- [设置应用](#set-up-applications)：在工作区内设置应用，以进一步组织 LangSmith 资源，并利用 ABAC 权限控制。

<Check>
在阅读本设置页面前，你可能会先参考 [LangSmith 资源层级概览](/langsmith/administration-overview)。
</Check>

## 设置组织

<Note>
如果你想以编程方式管理组织和工作区，请参阅[使用 API 管理组织](/langsmith/manage-organization-by-api)。
</Note>

### 创建组织

当你第一次登录 [UI](https://smith.langchain.com) 时，LangSmith 会自动为你创建一个个人组织。如果你想与其他人协作，可以新建一个独立组织，并邀请团队成员加入。

1. 点击左下角的个人资料图标，打开 **Organizations** 抽屉。
1. 选择菜单顶部的组织资料下拉框。
1. 点击 **+ Create organization**。

共享组织在开始使用前需要绑定信用卡。你需要先[设置计费](/langsmith/billing#set-up-billing-for-your-account)。

### 管理和切换工作区

一旦你订阅了允许每个组织内有多个用户的[方案](/langsmith/pricing-plans)，就可以设置[工作区](/langsmith/administration-overview#workspaces)，以便更高效地协作，并在不同用户组之间隔离 LangSmith 资源。要在工作区之间切换并访问各个工作区中的资源（trace 项目、annotation queues 等），请在 [LangSmith UI](https://smith.langchain.com) 左下角的选择器中选中目标工作区。

### 管理用户

在 [Settings 页面](https://smith.langchain.com/settings) 的 **Members and roles** 标签页中管理共享组织中的成员资格。你可以在这里：

- 邀请新用户加入组织，并选择其工作区成员资格，以及工作区角色（如果启用了 [RBAC](/langsmith/rbac)）。
- 编辑用户的组织角色。
- 将用户移出组织。

[企业版方案](/langsmith/pricing-plans)中的组织可以在 **Roles** 标签页中设置自定义工作区角色。更多细节请参阅[访问控制设置指南](/langsmith/user-management)。

#### 组织角色

组织级角色用于决定对组织设置的访问权限。所选角色也会影响工作区成员资格：

- **Organization Admin** 拥有管理所有组织配置、用户、计费和工作区的完整权限。任何 Organization Admin 都自动拥有该组织内所有工作区的 `Admin` 权限。
- **Organization User** 可以读取组织信息，但不能在组织级执行写操作。你仍然可以像往常一样把 Organization User 添加到部分工作区，并分配工作区角色（如果启用了 [RBAC](/langsmith/rbac)），这些角色决定其在工作区级别的权限。

<Info>
[Organization User](/langsmith/rbac#organization-user) 和 [Organization Viewer](/langsmith/rbac#organization-viewer) 角色仅在[Plus 和 Enterprise 方案](https://langchain.com/pricing)的组织中可用。在 Developer 组织（单工作区）中，所有用户默认都会被分配为 [Organization Admin](/langsmith/rbac#organization-admin)。不支持自定义组织级角色。
</Info>

若想查看每个角色对应的完整权限列表，请参阅[组织管理概览](/langsmith/administration-overview#organization-roles)页面。

## 设置工作区

当你第一次登录时，LangSmith 会在你的个人组织中为你创建一个默认[工作区](/langsmith/administration-overview#workspaces)。你可以用工作区把不同团队或业务单元的资源隔离开来，从而建立清晰的信任边界。在每个工作区内部，[基于角色的访问控制（RBAC）](/langsmith/rbac)负责管理权限和访问级别，确保用户只能访问其角色所需的资源和设置。大多数 LangSmith 活动都发生在工作区上下文中，每个工作区都有自己的设置和访问控制。

关于如何为团队选择合适的工作区组织模型（每个团队一个工作区、一个工作区包含多个团队、或一个团队使用多个工作区），请参阅 [Workload isolation](/langsmith/workload-isolation)。

### 创建工作区

要创建新工作区，请在共享组织中进入 [**Settings** 页面](https://smith.langchain.com/settings) 的 **Workspaces** 标签页，然后点击 **Add Workspace**。

创建完成后，你可以在 **Settings** 页面中选中该工作区，管理其成员和其他配置。

<Note>
不同方案对每个组织可使用的工作区数量有不同限制。更多信息请参阅[定价页面](https://www.langchain.com/pricing-langsmith)。
</Note>

### 管理用户

<Info>
只有 [workspace admins](/langsmith/rbac#workspace-admin) 可以管理工作区成员资格，并且如果启用了 RBAC，也只有他们可以更改用户的工作区角色。
</Info>

对于已经属于某个组织的用户，工作区管理员可以在 [**Workspaces settings** 页面](https://smith.langchain.com/settings/workspaces) 的 **Workspace members** 标签页中，把他们添加到工作区。用户在被邀请加入组织时，也可以被直接加入一个或多个工作区。

### 配置工作区设置

工作区配置位于 [**Workspaces settings** 页面](https://smith.langchain.com/settings/workspaces) 的对应标签页中。先选择要配置的工作区，再进入对应的配置子标签页。
可配置项包括：

- **Workspace members**
- **API keys**
- **Secrets**
- **Feedback config**
- **Models**
- **Rules**
- **Shared URLs**

### 删除工作区

<Warning>
删除工作区会永久删除该工作区及其所有关联数据。此操作无法撤销。
</Warning>

你可以通过 [LangSmith UI](https://smith.langchain.com) 或 [API](/langsmith/smith-api/workspaces/delete-workspace) 删除工作区。你必须是 [workspace admin](/langsmith/rbac#workspace-admin) 才能执行该操作。

在 LangSmith UI 中：

1. 进入 **Settings**。
1. 选择你要删除的工作区。
1. 点击界面右上角的删除图标 <Icon icon="trash" iconType="solid"/>。

## 设置应用

你可以在工作区内创建应用，以进一步组织 tracing projects、datasets 等资源。一个工作区可以包含零个或多个应用。

你可以在 LangSmith UI 首页选择 **All applications**，查看某个工作区中的全部资源。你也可以在 **Settings** 页面的 **Resource Tags** 中，把资源添加到 `Application` 标签下，从而将资源关联到多个应用。
