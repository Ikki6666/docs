---
title: 如何在一个 evaluator 中返回多个分数
sidebarTitle: 在一个 evaluator 中返回多个分数
---

有时，让自定义 evaluator 或 summary evaluator 返回多个指标会很有用。例如，如果多个指标由同一个 LLM judge 生成，就可以通过一次 LLM 调用生成多个指标，从而节省时间和成本，而不必发起多次 LLM 调用。

如果要在 Python SDK 中返回多个分数，只需返回一个由字典或对象组成的列表，格式如下：

```python
[
    # 'key' is the metric name
    # 'score' is the value of a numerical metric
    {"key": string, "score": number},
    # 'value' is the value of a categorical metric
    {"key": string, "value": string},
    ... # You may log as many as you wish
]
```

如果要在 JS/TS SDK 中实现这一点，请返回一个带有 `results` 键的对象，其值为上述格式的列表：

```typescript
{results: [{ key: string, score: number }, ...]};
```

这些字典都可以包含任意数量或任意组合的[反馈字段](/langsmith/feedback-data-format)；更多信息请参阅对应文档。

示例：

- Python：需要 `langsmith>=0.2.0`
- TypeScript：`langsmith@0.1.32` 及更高版本支持多个分数

<CodeGroup>

```python Python
def multiple_scores(outputs: dict, reference_outputs: dict) -> list[dict]:
    # Replace with real evaluation logic.
    precision = 0.8
    recall = 0.9
    f1 = 0.85
    return [
        {"key": "precision", "score": precision},
        {"key": "recall", "score": recall},
        {"key": "f1", "score": f1},
    ]
```

```typescript TypeScript
import type { Run, Example } from "langsmith/schemas";

function multipleScores(rootRun: Run, example: Example) {
  // Your evaluation logic here
  return {
      results: [
          { key: "precision", score: 0.8 },
          { key: "recall", score: 0.9 },
          { key: "f1", score: 0.85 },
      ],
  };
}
```

</CodeGroup>

生成的实验结果中，每一行都会显示这些分数。
