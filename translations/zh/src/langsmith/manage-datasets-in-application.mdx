[_Datasets_](/langsmith/evaluation-concepts#datasets) 让你能够基于一致的数据，随着时间推移反复执行评估。数据集由 [_examples_](/langsmith/evaluation-concepts#examples) 组成，用于保存输入、输出，以及可选的参考输出。

本页概述了如何在 [UI](https://smith.langchain.com) 中[创建](#create-a-dataset-and-add-examples)和[管理](#manage-a-dataset)数据集。

## 创建数据集并添加 examples

下面各节介绍了在 LangSmith 中创建数据集并添加 examples 的不同方式。你可以根据自己的工作流，手动整理 examples、从 tracing 自动捕获、导入文件，甚至生成合成数据：

- [从 tracing 项目手动添加](#manually-from-a-tracing-project)
- [从 tracing 项目自动添加](#automatically-from-a-tracing-project)
- [从 annotation queue 中的 examples 添加](#from-examples-in-an-annotation-queue)
- [从 Playground 添加](#from-the-playground)
- [从 CSV 或 JSONL 文件导入数据集](#import-a-dataset-from-a-csv-or-jsonl-file)
- [从数据集页面创建新的数据集](#create-a-new-dataset-from-the-datasets-%26-experiments-page)
- [通过 Datasets UI 添加由 LLM 生成的合成 examples](#add-synthetic-examples-created-by-an-llm)

### 从 tracing 项目手动添加

构建数据集的一种常见模式，是将应用中的关键 traces 转换成数据集 examples。此方法要求你已经[配置了向 LangSmith 发送 tracing](/langsmith/observability-concepts)。

<Check>
构建数据集的一个技巧是筛选那些最有价值的 traces，例如带有较差用户反馈标签的 traces，并将它们加入数据集。关于如何过滤 traces，可参见 [Filter traces](/langsmith/filter-traces-in-application) 指南。
</Check>

从 tracing 项目手动向数据集添加数据有两种方式。先进入 **Tracing Projects**，然后选择一个项目。

1. 在 runs 表中多选 runs。在 **Runs** 标签页中多选若干 runs。页面底部会出现操作区，点击 <Icon icon="database" /> **Add to Dataset**。
1. 在 **Runs** 标签页中，从表格里选择一个 run。在单个 run 的详情页右上角，选择 **Add to** -> **Dataset**。

    当你从 run 详情页选择一个数据集时，会弹出一个模态框，告诉你是否应用了某些 [transformations](/langsmith/dataset-transformations)，或 schema 校验是否失败。

    之后你可以选择先编辑该 run，再把它加入数据集。

### 从 tracing 项目自动添加

你可以使用 [run rules](/langsmith/rules)，根据特定条件将 traces 自动添加到数据集中。例如，可以把所有带有特定[标签](/langsmith/observability-concepts#tags)的 traces，或所有[反馈分数较低](/langsmith/observability-concepts#feedback)的 traces 自动加入数据集。

### 从 annotation queue 中的 examples 添加

<Check>
如果你依赖领域专家来构建高质量数据集，可以使用 [annotation queues](/langsmith/annotation-queues) 为审阅者提供更流畅的工作界面。人工审阅者可以在将 trace 加入数据集之前，选择性修改其中的 inputs、outputs 和 reference outputs。
</Check>

你可以为 annotation queue 配置默认数据集，不过也可以通过屏幕底部的数据集切换器，将 runs 添加到任意数据集。选中正确的数据集后，点击 **Add to Dataset**，或直接使用快捷键 `D` 即可加入。

你在 annotation queue 中对 run 做出的所有修改，都会一并带到数据集中，并且该 run 关联的所有 metadata 也会被复制过去。

<Tip>
你也可以使用 [automation rules](/langsmith/rules) 建立规则，把满足特定条件的 runs 自动加入 annotation queue。
</Tip>

### 从 Playground 添加

在 [**Playground**](/langsmith/prompt-engineering-concepts#playground) 页面中：

1. 选择 **Set up Evaluation**。
1. 如果你想创建新的数据集，点击 **+New**；如果想复用已有数据集，则直接选择一个。

    <Note>
    Playground 不支持为带有嵌套键的数据集进行内联创建。若要添加或编辑带嵌套键的 examples，必须到[数据集页面](/langsmith/manage-datasets-in-application#create-a-new-dataset-from-the-datasets-%26-experiments-page)中进行编辑。
    </Note>

1. 编辑 examples：

    - 使用 **+Row** 向数据集中添加新 example。
    - 通过表格右侧的 **⋮** 下拉菜单删除某个 example。
    - 如果你创建的是一个无 reference 的数据集，可以使用列上的 **x** 按钮移除 **Reference Output** 列。注意，这个操作不可逆。

### 从 CSV 或 JSONL 文件导入数据集

在 **Datasets & Experiments** 页面中，点击 **+New Dataset**，然后通过 **Import** 从 CSV 或 JSONL 文件导入已有数据集。

### 从 datasets & experiments 页面创建新数据集

1. 通过左侧菜单进入 **Datasets & Experiments** 页面。
1. 点击 **+ New Dataset**。
1. 在 **New Dataset** 页面中，选择 **Create from scratch** 标签页。
1. 为数据集填写名称和描述。
1. （可选）创建一个[数据集 schema](#create-a-dataset-schema)，用于验证数据集。
1. 点击 **Create**，创建一个空数据集。
1. 如需内联添加 examples，请在该数据集页面进入 **Examples** 标签页，然后点击 **+ Example**。
1. 用 JSON 定义 examples，然后点击 **Submit**。关于数据集 split 的更多细节，请参见 [Create and manage dataset splits](#create-and-manage-dataset-splits)。

### 添加由 LLM 生成的合成 examples

如果你的数据集已经有现有 examples，并且定义了一个 [schema](#create-a-dataset-schema)，那么点击 **+ Example** 时会出现一个 <Icon icon="sparkles"/> **Add AI-Generated Examples** 选项。它会使用 LLM 生成[合成](/langsmith/evaluation-concepts#building-datasets) examples。

在 **Generate examples** 中，执行以下步骤：

1. 点击面板右上角的 **API Key**，将你的 OpenAI API key 设置为 [workspace secret](/langsmith/administration-overview#workspaces)。如果工作区中已经设置过 OpenAI API key，则可跳过此步骤。
1. 选择 <Tooltip tip="A few sample input–output pairs that guide the model on how to perform a task.">few-shot examples</Tooltip>：切换 **Automatic** 或 **Manual** reference examples。你可以手动从数据集中选择这些 examples，也可以使用自动选择功能。
1. 输入你希望生成的合成 example 数量。
1. 点击 **Generate**。

## 管理数据集

### 创建数据集 schema

LangSmith 数据集可以存储任意 JSON 对象。我们建议（但不强制）你为数据集定义一个 schema，以确保其符合某个特定 JSON schema。数据集 schema 使用标准 [JSON schema](https://json-schema.org/) 定义，同时支持一些额外的[预构建类型](/langsmith/dataset-json-types)，让常见原语类型（如消息和工具）的建模更方便。

在 schema 的某些字段中，你会看到 `+ Transformations` 选项。Transformation 是一种预处理步骤，如果启用，它会在你把 example 加入数据集时自动更新该 example。例如，`convert to OpenAI messages` transformation 会把类似 LangChain message 这样的消息对象转换为 OpenAI message 格式。

完整 transformation 列表请参见 [Dataset transformations reference](/langsmith/dataset-transformations)。

<Note>
如果你计划从 LangChain [ChatModels](/oss/langchain/models) 或通过 [LangSmith OpenAI wrapper](/langsmith/annotate-code) 调用 OpenAI，将生产 traces 收集到数据集中，我们提供了一个预构建的 Chat Model schema。它会将 messages 和 tools 转换为行业标准的 OpenAI 格式，以便后续可以和任意模型配合测试。你也可以根据自己的用例自定义模板设置。

更多信息请参见 [dataset transformations reference](/langsmith/dataset-transformations)。
</Note>

### 创建和管理数据集 split

关于何时以及为什么使用 split，请参见 [Dataset organization](/langsmith/evaluation-concepts#dataset-organization)。

在 UI 中创建和管理 split 的方法如下：

1. 在数据集中选中若干 examples。
1. 点击 **Add to Split**。
1. 在弹出的菜单中，你可以为选中的 examples 选择或取消选择 split，也可以创建新的 split。

![Add to Split](/langsmith/images/add-to-split2.png)

### 编辑 example metadata

为 example 添加 metadata 的方式如下：

1. 点击某个 example，然后在弹出层右上角点击 **Edit**。
1. 在该页面中，你可以更新或删除现有 metadata，或者添加新的 metadata。

你可以用它来保存 examples 的附加信息，例如标签或版本信息。之后在分析实验结果时，可以用这些字段进行[分组](/langsmith/analyze-an-experiment#group-results-by-metadata)；或者在 SDK 中调用 `list_examples` 时，按它们进行[过滤](/langsmith/manage-datasets-programmatically#list-examples-by-metadata)。

### 过滤 examples

你可以按 split、metadata key/value 或全文搜索来过滤 examples。这些过滤选项位于 examples 表格左上角：

- **按 split 过滤**：选择 split > 再选择要过滤的 split。
- **按 metadata 过滤**：Filters > 在下拉菜单中选择 **Metadata** > 选择要过滤的 metadata key 和 value。
- **全文搜索**：Filters > 选择 **Full Text** > 输入你的搜索条件。

你可以同时添加多个过滤条件，只有满足全部条件的 examples 才会显示在表格中。
