本页介绍了在 LangSmith 中处理[_实验_](/langsmith/evaluation-concepts#experiment)时的一些核心任务：

- **[分析单个实验](#analyze-a-single-experiment)**：查看并解读实验结果，自定义列、筛选数据，以及比较 runs。
- **[在 Experiments 标签页中设置基线](#set-a-baseline-in-the-experiments-tab-view)**：为你希望超越的数据集设置一个基线。
- **[在 Experiments 标签页中按模型、提示词和工具筛选与分组](#filter-and-group-by-models-prompts-and-tools-in-the-experiments-tab-view)**：使用 **Models**、**Prompts** 和 **Tools** 列，在 **Experiments** 标签页中筛选和分组实验。
- **[将实验结果下载为 CSV](#download-experiment-results-as-a-csv)**：导出实验数据，用于外部分析和共享。
- **[重命名实验](#rename-an-experiment)**：在 Playground 和实验视图中更新实验名称。

## 分析单个实验

运行实验后，你可以使用 LangSmith 的实验视图分析结果，并提炼出关于实验表现的洞察。

### 打开实验视图

要打开实验视图：

1. 在 **Dataset & Experiments** 页面中选择相关的[_数据集_](/langsmith/evaluation-concepts#datasets)，这会打开 **Experiments** 标签页视图。
2. 点击你想查看的实验所在行。

![Open experiment view](/langsmith/images/select-experiment.png)

### 查看实验结果

#### 自定义列

默认情况下，实验视图会显示数据集中每个[示例](/langsmith/evaluation-concepts#examples)的输入、输出和参考输出，以及来自评估的反馈分数和实验指标，例如成本、token 数、延迟与状态。

你可以点击视图右上角的 **Columns** 图标来自定义列，从而更轻松地解读实验结果：

- **将 inputs、outputs 和 reference outputs 中的字段拆分**为单独的列。如果你的 inputs、outputs 或 reference outputs 很长，但又希望突出重要字段，这会特别有帮助。
- **隐藏并重排列**，创建更聚焦的分析视图。
- **控制反馈分数的小数精度**。默认情况下，LangSmith 会以 2 位小数显示数值型反馈分数，但你可以将其自定义为最多 6 位小数。
- **设置 Heat Map 阈值**，为实验中的数值型反馈分数设定高、中、低阈值，这会影响分数标签何时显示为红色或绿色：

![Column heatmap configuration](/langsmith/images/column-heat-map.png)

<Tip>
你可以为整个数据集设置默认配置，也可以仅为自己临时保存设置。
</Tip>

#### 排序和筛选

如果要按某个反馈分数对行排序，请点击列表头中的 **Sort by** 图标。

![Sort column](/langsmith/images/column-sort.png)

如果要筛选行，请点击列表头中的 <Icon icon="dots-vertical"/> 图标，并配置筛选条件。

![Filter column](/langsmith/images/column-filter.png)

#### 表格视图

在实验视图右上角选择以下三种表格视图图标之一：

- **Compact**：将每个 run 显示为单独一行，便于快速比较分数。
- **Full**：显示每个 run 的完整输出。
- **Diff**：显示每个 run 的输出与参考输出之间的文本差异。

![Diff view](/langsmith/images/diff-mode.png)

#### 查看 traces

点击实验视图中的任意一行，即可打开详情面板，其中会显示该 run 的 trace，以及反馈、输入、输出和属性。

![View trace](/langsmith/images/view-trace.png)

如果要查看完整的 tracing project，请点击实验视图右上角的 **View Project** 图标。

#### 查看 evaluator runs

将鼠标悬停在 evaluator 分数上时，你可以查看该 evaluator run 的更多细节。对于 [LLM-as-a-judge evaluators](/langsmith/llm-as-judge)，点击 **Source** 链接可查看所使用的 prompt，点击 **Evaluator trace** 可在新的浏览器标签页中打开该 trace。对于带有[重复运行](/langsmith/repetition)的实验，点击聚合后的平均分，可查看所有单次 runs 的链接。

![View evaluator runs](/langsmith/images/evaluator-run.png)

#### 跟踪实验进度

对于从 Playground 或通过 SDK 运行的实验，实验标题中的进度条会实时跟踪完成情况。同样的进度也会显示在实验表格的 **Progress** 列中。进度同时反映 run 和 evaluation 的状态。将鼠标悬停在进度条上，可以查看已完成的 runs 数和已评估的 runs 数。

<Note>
通过 SDK 运行的实验若要支持进度跟踪，需要满足：

- Python: `langsmith>=0.8.16`
- TypeScript: `langsmith>=0.7.8`
</Note>

### 按 metadata 对结果分组

你可以为示例添加 metadata，用于分类和组织。例如，如果你在问答数据集上评估事实准确性，metadata 中可以包含每个问题所属的主题领域。你既可以[通过 UI](/langsmith/manage-datasets-in-application#edit-example-metadata)添加 metadata，也可以[通过 SDK](/langsmith/manage-datasets-programmatically#update-single-example)添加。

如果要按 metadata 分析结果，请使用实验视图右上角的 **Group by** 图标，并选择想要的 metadata key。这样会显示每个 metadata 分组的平均反馈分数、延迟、总 token 数和成本。

<Info>
只有在 2025 年 2 月 20 日之后创建的实验，才能直接按 example metadata 分组。更早之前的实验仍然可以按 metadata 分组，但前提是这些 metadata 存在于实验 traces 本身。
</Info>

### 重复运行

如果你的实验启用了[_重复运行_](/langsmith/repetition)，点击任意一行即可打开详情面板。**Repetition Summary** 会显示指标表、所有反馈分数，并允许你切换查看不同输出，或查看各个单独重复运行及其 traces。

![Repetitions](/langsmith/images/repetitions.png)

### 与另一个实验比较

在实验视图右上角，你可以选择另一个实验进行比较。这会打开比较视图，你可以在其中查看两个实验之间的差异。要了解更多，请参阅[如何比较实验结果](/langsmith/compare-experiment-results)。

## 在 Experiments 标签页中设置基线

虽然你可能会运行几十次测试，但通常会有一个你希望超越的特定基准。设置一个_基线_，可以让结果锚定在这个参考点上，帮助你在密集的实验列表中识别改进或回归。

通过指定基线，你可以：

- 突出参考对象：明确标记当前表现最好的 run，让它在你持续迭代时始终显示在 **Experiments** 标签页顶部。
- 立即查看差异：自动查看所有实验相对于基线的性能变化，这意味着你不一定需要手动逐个并排比较。
- 加快评估：快速判断新的迭代是否达到或超过当前的性能标准。

  src="/langsmith/images/baseline-experiment-view-light.png"
  alt="The Experiments tab view with an experiment marked as the baseline at the top of the table. Scores show against the baseline on the rows of other experiments."
/>

<img
  className="hidden dark:block"
  src="/langsmith/images/baseline-experiment-view-dark.png"
  alt="The Experiments tab view with an experiment marked as the baseline at the top of the table. Scores show against the baseline on the rows of other experiments."
/>

要为某个数据集设置基线：

1. 在 [LangSmith UI](https://smith.langchain.com) 中，前往左侧菜单里的 **Datasets & Experiments**。
1. 从表格中选择你要处理的数据集。
1. 在 **Experiments** 标签页视图中，将鼠标悬停在某个实验行上，使行右侧显示 **Set baseline** 按钮。点击后即可将该实验设为基线。

你的基线实验会固定在表格顶部，并在名称旁边显示 **Baseline** 标签。一旦某个实验被设置为基线，表格中每一列都会显示其他实验相对于该基线的分数。选择多个实验进行比较时，基线实验也会作为默认的源实验。

## 在 Experiments 标签页中按模型、提示词和工具筛选与分组

实验表格中包含 **Models**、**Prompts** 和 **Tools** 列，用来显示每个实验使用了哪些模型、提示词和工具，让你可以一眼看出 runs 之间发生了哪些变化。

当你从 Playground 运行实验时，这些列会自动填充。通过 SDK 运行实验时，请向 `evaluate()` 传入带有 `models`、`prompts` 和 `tools` keys 的 `metadata` 对象：

```python
results = client.evaluate(
    target,
    data="my-dataset",
    evaluators=[...],
    metadata={
        "models": "openai:gpt-5.4-mini",
        "prompts": ["my-org/my-prompt:abc12345"],
        "tools": [{"name": "web_search", "description": "Search the web for information"}],
    },
)
```

关于使用 metadata 的示例，请参阅[如何评估 LLM application](/langsmith/evaluate-llm-application#run-the-evaluation)。

只有当数据集中至少有一个实验设置了这些字段时，这些列才会出现。一旦填充完成，你可以点击这些列中的任意值，对实验进行筛选或分组。

## 将实验结果下载为 CSV

LangSmith 支持将实验结果下载为 CSV 文件，以便在外部进行分析和共享。点击实验视图右上角的 **Download as CSV** 图标即可。

<Note>
实验结果下载上限为 5,000 行。
</Note>

## 重命名实验

<Note>
在同一个 workspace 内，实验名称必须唯一。
</Note>

你可以在 LangSmith UI 的以下位置重命名实验：

- **Experiment view**：使用实验名称旁边的铅笔图标来重命名实验。

  ![Edit name in experiment view](/langsmith/images/rename-in-experiment-view.png)

- **Playground**：系统会自动分配一个默认名称，格式为 `pg::prompt-name::model::uuid`（例如 `pg::gpt-5.4-mini::897ee630`）。你可以在运行后，直接在 Playground 表格头部编辑实验名称。

  ![Edit name in playground](/langsmith/images/rename-in-playground.png)
