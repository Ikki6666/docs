[_Evaluations_](/langsmith/evaluation-concepts) 是一种定量衡量 LLM 应用表现的方式。LLM 的行为本身具有不确定性，即使只是对 prompts、models 或 inputs 做了很小的改动，也可能显著影响结果。Evaluations 提供了一种结构化方法，用来识别失败、比较版本，并构建更可靠的 AI 应用。

要在 LangSmith 中运行一次评估，需要三个关键组成部分：

- [_Dataset_](/langsmith/evaluation-concepts#datasets)：一组测试输入，以及（可选的）期望输出。
- [_Target function_](/langsmith/define-target-function)：你想测试的那部分应用逻辑，可能是一条新的 prompt 对应的单次 LLM 调用，也可能是一个模块，或者整个 workflow。
- [_Evaluators_](/langsmith/evaluation-concepts#evaluators)：用于给 target function 输出打分的函数。

这个 quickstart 会带你运行一个入门评估，用于检查 LLM 响应的正确性。你可以选择通过 LangSmith SDK 或 UI 来完成。

## 前置条件

开始之前，请确保你已经准备好：

- **一个 LangSmith account**：在 [smith.langchain.com](https://smith.langchain.com) 注册或登录。
- **一个 LangSmith API key**：按照[创建 API key](/langsmith/create-account-api-key)指南操作。
- **一个 OpenAI API key**：在 [OpenAI dashboard](https://platform.openai.com/account/api-keys) 中生成。

## 2. 创建一个 prompt

[Playground](/langsmith/prompt-engineering-concepts#playground) 可以让你在不同 prompts、不同 models 或不同模型配置上运行评估。

1. 在 [LangSmith UI](https://smith.langchain.com) 中，点击侧边栏的 **Playground**。
1. 在 **Prompts** 面板中，把 **system** prompt 改成：

    ```
    Answer the following question accurately:
    ```

    **Human** message 保持不变：`{question}`。

## 3. 创建一个 dataset

1. 点击 **Set up Evaluation**，页面底部会打开一个 **New Experiment** 表格。
1. 在 **Select or create a new dataset** 下拉框中，点击 **+ New** 按钮创建新 dataset。

1. 向 dataset 中添加以下 examples：

    | Inputs                                                   | Reference Outputs                                 |
    | -------------------------------------------------------- | ------------------------------------------------- |
    | question: Which country is Mount Kilimanjaro located in? | output: Mount Kilimanjaro is located in Tanzania. |
    | question: What is Earth's lowest point?                  | output: Earth's lowest point is The Dead Sea.     |

1. 点击 **Save**，并输入一个名称来保存你新建的 dataset。

## 4. 添加 evaluator

1. 点击 **+ Evaluator**，在 **Prebuilt Evaluator** 选项中选择 **Correctness**。
1. 在 **Correctness** 面板中点击 **Save**。

## 5. 运行评估

1. 点击右上角的 <Icon icon="player-play" /> **Start** 运行评估。系统会创建一个 [_experiment_](/langsmith/evaluation-concepts#experiment)，并在 **New Experiment** 表格中显示一个预览。点击 experiment 名称可以查看完整结果。

## 1. 安装依赖

在终端中，先为项目创建一个目录，然后在环境中安装依赖：

<CodeGroup>

mkdir ls-evaluation-quickstart && cd ls-evaluation-quickstart
python -m venv .venv && source .venv/bin/activate

```

```

## 2. 设置环境变量

设置以下环境变量：

- `LANGSMITH_TRACING`
- `LANGSMITH_API_KEY`
- `OPENAI_API_KEY`（或者你的 LLM provider 的 API key）
- （可选）`LANGSMITH_WORKSPACE_ID`：如果你的 LangSmith API key 关联了多个 [workspaces](/langsmith/administration-overview#workspaces)，就设置这个变量来显式指定要使用哪个 workspace。

``` bash
export LANGSMITH_TRACING=true
export LANGSMITH_API_KEY="<your-langsmith-api-key>"
export OPENAI_API_KEY="<your-openai-api-key>"
export LANGSMITH_WORKSPACE_ID="<your-workspace-id>"
```
<Note>
如果你使用 Anthropic，请用 [Anthropic wrapper](/langsmith/trace-anthropic) 为调用加 tracing。对于其他 providers，请使用 [traceable wrapper](/langsmith/annotate-code#use-%40traceable-%2F-traceable)。
</Note>

## 3. 创建 dataset

1. 创建一个文件，并添加以下代码。它会：

    - 导入 `Client`，用于连接 LangSmith。
    - 创建一个 dataset。
    - 定义示例 [_inputs_ 和 _outputs_](/langsmith/evaluation-concepts#examples)。
    - 把这些输入输出对与该 dataset 关联起来，这样后面就可以在 LangSmith 中用于评估。

    <CodeGroup>

    ```python Python
    # dataset.py
    from langsmith import Client

    def main():
        client = Client()

        # Programmatically create a dataset in LangSmith
        dataset = client.create_dataset(
            dataset_name="Sample dataset",
            description="A sample dataset in LangSmith."
        )

        # Create examples
        examples = [
            {
                "inputs": {"question": "Which country is Mount Kilimanjaro located in?"},
                "outputs": {"answer": "Mount Kilimanjaro is located in Tanzania."},
            },
            {
                "inputs": {"question": "What is Earth's lowest point?"},
                "outputs": {"answer": "Earth's lowest point is The Dead Sea."},
            },
        ]

        # Add examples to the dataset
        client.create_examples(dataset_id=dataset.id, examples=examples)
        print("Created dataset:", dataset.name)

    if __name__ == "__main__":
        main()

    ```

    ```typescript TypeScript
    // dataset.ts
    import { Client } from "langsmith";

    async function main() {
    const client = new Client();

    const dataset = await client.createDataset(
        "Sample dataset",
        { description: "A sample dataset in LangSmith." }
    );

    // Define examples
    const inputs = [
        { question: "Which country is Mount Kilimanjaro located in?" },
        { question: "What is Earth's lowest point?" },
    ];
    const outputs = [
        { answer: "Mount Kilimanjaro is located in Tanzania." },
        { answer: "Earth's lowest point is The Dead Sea." },
    ];

    await client.createExamples({
        datasetId: dataset.id,
        inputs,
        outputs,
    });

    console.log("Created dataset:", dataset.name);
    }

    if (require.main === module) {
    main().catch((e) => {
        console.error(e);
        process.exit(1);
    });
    }
    ```

    </CodeGroup>

1. 在终端中运行这个 `dataset` 文件，创建后续评估要使用的 dataset：

    <CodeGroup>
    ```bash Python
    python dataset.py
    ```
    ```bash TypeScript
    npx ts-node dataset.ts
    ```

    </CodeGroup>

## 4. 创建 target function

定义一个 [target function](/langsmith/define-target-function)，把你真正想评估的内容放进去。本指南中，我们会定义一个 target function，其中只包含一次用来回答问题的 LLM 调用。

在一个 `eval` 文件中添加以下内容：

<CodeGroup>

```python Python
# eval.py
from langsmith import Client, wrappers
from openai import OpenAI

# Wrap the OpenAI client for LangSmith tracing
openai_client = wrappers.wrap_openai(OpenAI())

# Define the application logic you want to evaluate inside a target function
# The SDK will automatically send the inputs from the dataset to your target function
def target(inputs: dict) -> dict:
    response = openai_client.chat.completions.create(
        model="gpt-5-mini",
        messages=[
            {"role": "system", "content": "Answer the following question accurately"},
            {"role": "user", "content": inputs["question"]},
        ],
    )
    return {"answer": response.choices[0].message.content.strip()}
```

```typescript TypeScript
// eval.ts
import { evaluate } from "langsmith/evaluation";
import { wrapOpenAI } from "langsmith/wrappers/openai";
import OpenAI from "openai";

const openaiClient = wrapOpenAI(new OpenAI());

async function target(inputs: Record<string, any>): Promise<Record<string, any>> {
  const question = String(inputs.question ?? "");
  const resp = await openaiClient.chat.completions.create({
    model: "gpt-5-mini",
    messages: [
      { role: "system", content: "Answer the following question accurately" },
      { role: "user", content: question },
    ],
  });
  return { answer: resp.choices[0].message.content?.trim() ?? "" };
}
```

</CodeGroup>


## 5. 定义 evaluator

在这一步里，你是在告诉 LangSmith：应该如何给你的应用答案打分。

从 [`openevals`](https://github.com/langchain-ai/openevals) 导入一个预构建评估 prompt（`CORRECTNESS_PROMPT`），再导入一个 helper，把它包装成 [_LLM-as-judge evaluator_](/langsmith/evaluation-concepts#llm-as-judge)。这个 evaluator 会对应用输出打分。

<Info>
`CORRECTNESS_PROMPT` 本质上只是一个 f-string，其中包含 `"inputs"`、`"outputs"` 和 `"reference_outputs"` 这几个变量。更多信息请参阅 [customizing OpenEvals prompts](https://github.com/langchain-ai/openevals#customizing-prompts)。
</Info>

这个 evaluator 会比较：

- `inputs`：传入 target function 的内容，例如问题文本。
- `outputs`：target function 返回的结果，例如模型回答。
- `reference_outputs`：你在[第 3 步](#3-create-a-dataset)中为每个 dataset example 添加的 ground truth answers。

把下面高亮代码加入你的 `eval` 文件中：

<CodeGroup>

```python Python highlight={3,4,21-31}
from langsmith import Client, wrappers
from openai import OpenAI
from openevals.llm import create_llm_as_judge
from openevals.prompts import CORRECTNESS_PROMPT

# Wrap the OpenAI client for LangSmith tracing
openai_client = wrappers.wrap_openai(OpenAI())

# Define the application logic you want to evaluate inside a target function
# The SDK will automatically send the inputs from the dataset to your target function
def target(inputs: dict) -> dict:
    response = openai_client.chat.completions.create(
        model="gpt-5-mini",
        messages=[
            {"role": "system", "content": "Answer the following question accurately"},
            {"role": "user", "content": inputs["question"]},
        ],
    )
    return {"answer": response.choices[0].message.content.strip()}

def correctness_evaluator(inputs: dict, outputs: dict, reference_outputs: dict):
    evaluator = create_llm_as_judge(
        prompt=CORRECTNESS_PROMPT,
        model="openai:o3-mini",
        feedback_key="correctness",
    )
    return evaluator(
        inputs=inputs,
        outputs=outputs,
        reference_outputs=reference_outputs
    )
```

```typescript TypeScript highlight={4,20-37}
import { evaluate } from "langsmith/evaluation";
import { wrapOpenAI } from "langsmith/wrappers/openai";
import OpenAI from "openai";
import { createLLMAsJudge, CORRECTNESS_PROMPT } from "openevals";

const openaiClient = wrapOpenAI(new OpenAI());

async function target(inputs: Record<string, any>): Promise<Record<string, any>> {
  const question = String(inputs.question ?? "");
  const resp = await openaiClient.chat.completions.create({
    model: "gpt-5-mini",
    messages: [
      { role: "system", content: "Answer the following question accurately" },
      { role: "user", content: question },
    ],
  });
  return { answer: resp.choices[0].message.content?.trim() ?? "" };
}

const judge = createLLMAsJudge({
  prompt: CORRECTNESS_PROMPT,
  model: "openai:o3-mini",
  feedbackKey: "correctness",
});

async function correctnessEvaluator(run: {
  inputs: Record<string, any>;
  outputs: Record<string, any>;
  referenceOutputs?: Record<string, any>;
}) {
  return judge({
    inputs: run.inputs,
    outputs: run.outputs,
    // OpenEvals expects snake_case here:
    reference_outputs: run.referenceOutputs,
  });
}
```

</CodeGroup>

## 6. 运行并查看结果

要运行这次评估 experiment，你需要调用 `evaluate(...)`。它会：

- 从你在[第 3 步](#3-create-a-dataset)创建的 dataset 中拉取 examples。
- 将每个 example 的 inputs 发送给你在[第 4 步](#4-add-an-evaluator)中定义的 target function。
- 收集输出，也就是模型生成的答案。
- 将这些输出连同 `reference_outputs` 一起传给你在[第 5 步](#5-define-an-evaluator)定义的 evaluator。
- 把所有结果记录到 LangSmith 中，形成一个 experiment，以便你在 UI 中查看。

1. 将下方高亮代码加入你的 `eval` 文件中：

    <CodeGroup>

    ```python Python highlight={33-49}
    from langsmith import Client, wrappers
    from openai import OpenAI
    from openevals.llm import create_llm_as_judge
    from openevals.prompts import CORRECTNESS_PROMPT

    # Wrap the OpenAI client for LangSmith tracing
    openai_client = wrappers.wrap_openai(OpenAI())

    # Define the application logic you want to evaluate inside a target function
    # The SDK will automatically send the inputs from the dataset to your target function
    def target(inputs: dict) -> dict:
        response = openai_client.chat.completions.create(
            model="gpt-5-mini",
            messages=[
                {"role": "system", "content": "Answer the following question accurately"},
                {"role": "user", "content": inputs["question"]},
            ],
        )
        return {"answer": response.choices[0].message.content.strip()}

    def correctness_evaluator(inputs: dict, outputs: dict, reference_outputs: dict):
        evaluator = create_llm_as_judge(
            prompt=CORRECTNESS_PROMPT,
            model="openai:o3-mini",
            feedback_key="correctness",
        )
        return evaluator(
            inputs=inputs,
            outputs=outputs,
            reference_outputs=reference_outputs
        )

    # After running the evaluation, a link will be provided to view the results in langsmith
    def main():
        client = Client()
        experiment_results = client.evaluate(
            target,
            data="Sample dataset",
            evaluators=[
                correctness_evaluator,
                # can add multiple evaluators here
            ],
            experiment_prefix="first-eval-in-langsmith",
            max_concurrency=2,
        )
        print(experiment_results)

    if __name__ == "__main__":
        main()
    ```

    ```typescript TypeScript highlight={39-57}

    import { wrapOpenAI } from "langsmith/wrappers/openai";   // helper to wrap OpenAI client
    import OpenAI from "openai";                              // model provider
    import { createLLMAsJudge, CORRECTNESS_PROMPT } from "openevals"; // evaluator tools

    const openaiClient = wrapOpenAI(new OpenAI());

    async function target(inputs: Record<string, any>): Promise<Record<string, any>> {
    const question = String(inputs.question ?? "");
    const resp = await openaiClient.chat.completions.create({
        model: "gpt-5-mini",
        messages: [
        { role: "system", content: "Answer the following question accurately" },
        { role: "user", content: question },
        ],
    });
    return { answer: resp.choices[0].message.content?.trim() ?? "" };
    }

    const judge = createLLMAsJudge({
    prompt: CORRECTNESS_PROMPT,
    model: "openai:o3-mini",
    feedbackKey: "correctness",
    });

    async function correctnessEvaluator(run: {
    inputs: Record<string, any>;
    outputs: Record<string, any>;
    referenceOutputs?: Record<string, any>;
    }) {
    return judge({
        inputs: run.inputs,
        outputs: run.outputs,
        // OpenEvals expects snake_case here:
        reference_outputs: run.referenceOutputs,
    });
    }

    async function main() {
    const datasetName = process.env.DATASET_NAME ?? "Sample dataset";

    const results = await evaluate(target, {
        data: datasetName,
        evaluators: [correctnessEvaluator],
        experimentPrefix: "first-eval-in-langsmith",
        maxConcurrency: 2,
    });

    console.log(results);
    }

    if (require.main === module) {
    main().catch((e) => {
        console.error(e);
        process.exit(1);
    });
    }
    ```

    </CodeGroup>
