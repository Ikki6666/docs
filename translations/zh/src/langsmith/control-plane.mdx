_control plane_ 是 LangSmith 中负责管理 deployments 的部分。它包括 control plane UI，用户可以在其中创建和更新 [Agent Servers](/langsmith/agent-server)，还包括支持该 UI 并提供编程访问能力的 control plane APIs。

当通过 control plane 发起更新时，这些更新会存储在 control plane state 中。[data plane](/langsmith/data-plane) 的 “listener” 会通过调用 control plane APIs 轮询这些更新。control plane 永远不会直接连接到 data plane。

## Control plane UI

在 control plane UI 中，可以：

* 查看待处理 deployment 列表。
* 查看单个 deployment 的详情。
* 创建新的 deployment。
* 更新 deployment。
* 更新 deployment 的环境变量。
* 查看 deployment 的构建日志和服务日志。
* 查看 CPU 和内存使用情况等 deployment 指标。
* 删除 deployment。

Control plane UI 内嵌在 [LangSmith](https://docs.smith.langchain.com) 中。

## Control plane API

本节介绍 control plane API 的数据模型。该 API 用于创建、更新和删除 deployments。更多细节请参阅 [control plane API reference](/langsmith/api-ref-control-plane)。

### Integrations

Integration 是对 `git` 仓库提供商（例如 GitHub）的抽象。它包含连接并从某个 `git` 仓库部署所需的全部元数据。

### Deployments

Deployment 是 Agent Server 的一个实例。单个 deployment 可以包含多个 revisions。

### Revisions

Revision 是 deployment 的一次迭代。创建新的 deployment 时，会自动创建一个初始 revision。若要部署代码变更或更新 deployment 的 secrets，就必须创建新的 revision。

### Listeners

Listener 是一个["listener" application](/langsmith/data-plane#listener-application)实例。Listener 包含该应用的元数据（例如版本），以及它可部署到的计算基础设施元数据（例如 Kubernetes namespaces）。

## Control plane 功能

本节介绍 control plane 的各项功能。对于 Cloud 部署类型或自托管资源自定义等平台特定行为，请参阅 [Cloud platform features](/langsmith/cloud-platform-features) 或[部署到自托管环境](/langsmith/deploy-to-self-hosted-overview)。

### 异步部署

Deployments 和 revisions 的基础设施是以异步方式创建和部署的。提交后不会立刻部署。目前 deployment 可能需要几分钟时间。

* 创建新 deployment 时，会为该 deployment 新建一个数据库。数据库创建是一次性步骤，因此会导致该 deployment 的初始 revision 部署时间更长。
* 为已有 deployment 创建后续 revision 时，不再需要创建数据库。与初始 revision 相比，后续 revision 的部署速度会快很多。
* 每个 revision 的部署流程都包含一个构建步骤，这一步可能需要几分钟。

control plane 与 [data plane](/langsmith/data-plane) 的 "listener" application 协同工作，以实现异步部署。

### 监控

当 deployment 就绪后，control plane 会对其进行监控，并记录多种指标，例如：

* deployment 的 CPU 和内存使用情况。
* 容器重启次数。
* 副本数（会随着[自动扩缩容](/langsmith/data-plane#autoscaling)而增加）。
* [PostgreSQL](/langsmith/data-plane#postgresql) 的 CPU、内存使用量和磁盘使用量。
* [Agent Server queue](/langsmith/agent-server#task-queue) 的待处理和活跃 run 数量。
* [Agent Server API](/langsmith/agent-server) 的成功响应数、错误响应数和延迟。

这些指标会以图表形式显示在 Control Plane UI 中。

### LangSmith 集成

每个 deployment 都会自动创建一个 [LangSmith](/langsmith/observability) tracing project。该 tracing project 与 deployment 同名。创建 deployment 时，无需显式指定 `LANGCHAIN_TRACING` 和 `LANGSMITH_API_KEY`/`LANGCHAIN_API_KEY` 环境变量；它们会由 control plane 自动设置。

删除 deployment 时，traces 和 tracing project 不会被删除。
