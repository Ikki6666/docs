借助 prompt canvas，你可以在 LLM 的帮助下轻松编辑 prompt。这让你能更快地迭代长 prompt，也更容易对 prompt 的整体风格或语气做出统一修改。点击 prompt 中任意消息上方的发光魔杖图标，即可进入 prompt canvas：

![Prompt canvas open](/langsmith/images/prompt-canvas-open.gif)

## Chat sidebar

你可以使用 chat sidebar 就 prompt 提问，或者用自然语言向 LLM 下达指令，让它改写你的 prompt。

![Prompt canvas rewrite](/langsmith/images/prompt-canvas-rewrite.gif)

<Note>
你也可以直接编辑 prompt，不**一定**要使用 LLM。如果你已经知道自己想改什么，只是想直接动手修改，这会很有用。
</Note>

## Quick actions

你可以通过 quick actions，一键修改 prompt 的阅读难度或长度：

![Prompt canvas quick actions](/langsmith/images/prompt-canvas-quick-actions.gif)

## Custom quick actions

你还可以保存自己的自定义 quick actions，以便在 LangSmith 中处理的所有 prompts 上复用：

![Prompt canvas custom quick action](/langsmith/images/prompt-canvas-custom-quick-action.gif)

## Diffing

你还可以通过选择 canvas 右上角的 diff slider，查看 prompt 每个版本之间的具体差异：

![Prompt canvas diff](/langsmith/images/prompt-canvas-diff.gif)

## Saving and using prompts

最后，你可以点击右下角的 "Use this Version" 按钮，保存你在 canvas 中创建的 prompt：

![Prompt canvas save](/langsmith/images/prompt-canvas-save.gif)
