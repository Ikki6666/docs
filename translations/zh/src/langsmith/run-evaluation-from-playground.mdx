LangSmith 允许你直接在 UI 中运行评估。[**Playground**](/langsmith/prompt-engineering-concepts#playground) 可以让你在一组输入上测试 prompt 或模型配置，观察它在不同上下文或场景下的得分表现，而无需编写任何代码。

在运行评估前，你需要先有一个[现有 dataset](/langsmith/evaluation-concepts#datasets)。了解如何[通过 UI 创建 dataset](/langsmith/manage-datasets-in-application#create-a-dataset-and-add-examples)。

如果你想改为从 Studio 运行评估，请参阅[在 Studio 中基于 dataset 运行 experiments](/langsmith/observability-studio#run-experiments-over-a-dataset)。如果你更倾向于在代码中运行 experiments，请参阅[使用 SDK 运行评估](/langsmith/evaluate-llm-application)。

<Callout type="info" icon="feather">
**[Chat](/langsmith/chat)** 已在 Playground 中提供，可帮助你在运行评估前优化 prompts。

## Create an experiment in the Playground

1. 在侧边栏中点击 **Playground**。
2. 通过选择一个现有已保存 prompt，或创建新 prompt，来**添加 prompt**。
3. 从 **Test over dataset** 下拉菜单中**选择一个 dataset**。

   * 请注意，dataset input 中的键必须与 prompt 的输入变量一致。例如，在上方视频中，所选 dataset 的输入键为 `"blog"`，它与 prompt 的输入变量正确匹配。
   * Playground 最多允许 15 个输入变量。

4. 点击 **Start** 或按 CMD+Enter，**启动 experiment**。这样会让 prompt 在 dataset 中的所有 examples 上运行，并在 dataset 详情页中为该 experiment 创建一个条目。建议你在启动 experiment 前先将 prompt 提交到 prompt hub，以便后续回顾实验时更容易引用。
5. 点击 **View full experiment**，**查看完整结果**。这会带你进入 experiment 详情页，在那里你可以查看实验结果。

在 experiment 运行期间，experiments 表中的 **Progress** 列以及 experiment 视图中的进度条会实时跟踪完成情况，包括已有多少个 runs 已完成并被评估。更多信息请参阅 [Track experiment progress](/langsmith/analyze-an-experiment#track-experiment-progress)。

## Add evaluation scores to the experiment

通过添加 evaluators，你可以基于特定标准对 experiment 进行评估。使用 Playground 中的 **+Evaluator** 按钮，可以添加 LLM-as-a-judge 或自定义代码 evaluators。

如需了解如何通过 UI 添加 evaluators，请参阅[如何定义 LLM-as-a-judge evaluator](/langsmith/llm-as-judge)。
