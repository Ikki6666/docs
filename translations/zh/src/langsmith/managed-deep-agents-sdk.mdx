你可以通过 Python、TypeScript 和 React 来构建、运行并流式处理 Managed Deep Agents。SDK 对 `/v1/deepagents` API 进行了封装，用于创建 agents、管理 threads、流式运行、注册 MCP servers，以及构建 React UI。

关于概念介绍，请参见 [Managed Deep Agents overview](/langsmith/managed-deep-agents-overview)。如果你想按端到端方式上手，请参见 [quickstart](/langsmith/managed-deep-agents-quickstart)。

<Note>
这些 SDK 包当前处于 **public [beta](/langsmith/release-stages)**。方法签名和 payload 字段在 beta 期间仍可能变化。

Managed Deep Agents 当前处于 **private beta**，仅在美国区域的 [LangSmith Cloud](/langsmith/cloud) 中可用。你可以[加入候补名单](https://www.langchain.com/langsmith-managed-deep-agents-waitlist)来申请访问权限。
</Note>

## 安装

<CodeGroup>

```bash Python
uv add managed-deepagents

# or with pip
pip install managed-deepagents
```

```bash TypeScript
npm install @langchain/managed-deepagents
```

```bash React
npm install @langchain/managed-deepagents @langchain/react
```

</CodeGroup>

要求如下：

- `managed-deepagents` 需要 Python 3.10 或更高版本。
- `@langchain/managed-deepagents` 需要 Node.js 22 或更高版本。
- 你具备 Managed Deep Agents 的 [private beta 访问权限](https://www.langchain.com/langsmith-managed-deep-agents-waitlist)。
- 你拥有一个可访问 private beta 工作区的 [LangSmith API key](/langsmith/create-account-api-key)。

## 配置客户端

设置 API key：

```bash
export LANGSMITH_API_KEY="<LANGSMITH_API_KEY>"
```

这两个 SDK 默认连接到 `https://api.smith.langchain.com/v1/deepagents`。如果你要使用兼容 endpoint，可以设置 `LANGSMITH_ENDPOINT`，或者直接传入 API URL：

<CodeGroup>

```python Python
from managed_deepagents import Client

client = Client(
    api_key="<LANGSMITH_API_KEY>",
    api_url="https://api.smith.langchain.com/v1/deepagents",
)
```

```ts TypeScript
import { Client } from "@langchain/managed-deepagents";

const client = new Client({
  apiKey: process.env.LANGSMITH_API_KEY,
  apiUrl: "https://api.smith.langchain.com/v1/deepagents",
});
```

</CodeGroup>

`Client()` 和 `new Client()` 都会从环境中读取 `LANGSMITH_API_KEY` 和 `LANGSMITH_ENDPOINT`，因此本页后续示例都直接使用无参客户端构造方式。

## 创建 agent

创建 agent 的请求可以使用与 [Managed Deep Agents CLI](/langsmith/managed-deep-agents-cli) 相同的顶层 `model` 和 `backend` 字段。`model` 应以 `{provider}:{model_id}` 形式传入。支持的 provider 与模型请参见 [supported providers and models](/oss/langchain/models#supported-providers-and-models)。

<CodeGroup>

```python Python
from managed_deepagents import Client

with Client() as client:
    agent = client.agents.create(
        name="research-assistant",
        description="Research assistant that can search the web and summarize sources.",
        model="openai:gpt-5.5",
        backend={"type": "state"},
        instructions=(
            "You are a careful research assistant. Search for sources, "
            "keep notes, and return concise answers with citations."
        ),
    )

agent_id = agent["id"]
print(f"Agent ID: {agent_id}")
```

```ts TypeScript
import { Client } from "@langchain/managed-deepagents";

const client = new Client();

const agent = await client.agents.create({
  name: "research-assistant",
  description: "Research assistant that can search the web and summarize sources.",
  model: "openai:gpt-5.5",
  backend: { type: "state" },
  instructions:
    "You are a careful research assistant. Search for sources, keep notes, and return concise answers with citations.",
});

const agentId = agent.id;
console.log(`Agent ID: ${agentId}`);
```

</CodeGroup>

Python 方法返回的是类 dict 响应，因此使用 `agent["id"]`。TypeScript 方法返回的是类型化对象，因此使用 `agent.id`。

## 运行与流式输出

在运行 agent 前，先创建一个 thread。[Threads](/langsmith/use-threads#understand-threads) 会保存会话和执行状态，因此你可以之后恢复运行，或对运行过程进行检查。这里使用的是前面创建 agent 时返回的 `id`。

<CodeGroup>

```python Python
from managed_deepagents import Client

agent_id = "<agent_id>"

with Client() as client:
    thread = client.threads.create(
        agent_id=agent_id,
        options={
            "test_run": False,
            "skip_memory_write_protection": False,
        },
    )

    for event in client.threads.stream(
        thread["id"],
        agent_id=agent_id,
        messages=[
            {
                "role": "user",
                "content": "Research recent approaches to agent memory and summarize the main trade-offs.",
            }
        ],
        stream_mode=["values", "updates", "messages-tuple"],
        stream_subgraphs=True,
    ):
        print(event.event, event.data)
```

```ts TypeScript
import { Client } from "@langchain/managed-deepagents";

const agentId = "<agent_id>";
const client = new Client();

const thread = await client.threads.create({
  agent_id: agentId,
  options: {
    test_run: false,
    skip_memory_write_protection: false,
  },
});

const langGraphClient = client.getLangGraphClient({ agentId });
const stream = langGraphClient.runs.stream(thread.id, agentId, {
  input: {
    messages: [
      {
        role: "user",
        content:
          "Research recent approaches to agent memory and summarize the main trade-offs.",
      },
    ],
  },
  streamMode: ["values", "updates", "messages-tuple"],
  streamSubgraphs: true,
});

for await (const event of stream) {
  console.log(event.event, event.data);
}
```

</CodeGroup>

`options` 对象是可选的，这两个字段默认都为 `false`。将 `test_run` 设为 `true`，即可把该 thread 标记为测试运行，并将其从用量和分析中排除。默认情况下，`skip_memory_write_protection` 会让运行时在 agent 写入长期记忆前触发一次 human-in-the-loop interrupt，以便你批准或拒绝该写入。若将它设为 `true`，则记忆写入会立即执行，适用于无人工参与批准的 headless 运行场景。

在 Python 中，直接使用 `client.threads.stream(...)` 流式获取事件；在 TypeScript 中，先通过 `client.getLangGraphClient(...)` 获取 LangGraph client，再通过 `runs.stream(...)` 进行流式调用，并将消息列表放在 `input` 字段下。每个事件都包含 `event` 类型和 `data` payload。你实际收到的事件类型取决于 `stream_mode`。关于 stream mode 和事件类型，请参见 [Stream a run from a thread](/langsmith/managed-deep-agents-invoke#stream-a-run-from-a-thread)。

## 使用 React `useStream`

TypeScript SDK 提供了适用于 `@langchain/react` 的 LangGraph client adapter。使用 `getLangGraphClient()` 后，`useStream` 就可以自动管理 thread 生命周期、run 提交和状态更新，而 Managed Deep Agents SDK 则会提供正确的路由、认证头和 payload 结构。

<Warning>
不要把 LangSmith API key 下发到浏览器。`new Client()` 会从环境变量读取 `LANGSMITH_API_KEY`，因此不要把它暴露到客户端 bundle 中。在生产环境 React 应用里，请通过自定义 `fetch` 将请求转发到你的后端。
</Warning>

```tsx
import { Client } from "@langchain/managed-deepagents";
import { useStream } from "@langchain/react";

const agentId = "<agent_id>";

const managedDeepAgents = new Client();

const client = managedDeepAgents.getLangGraphClient({ agentId });

export function ManagedDeepAgentStream() {
  const stream = useStream({
    client,
    assistantId: agentId
  });

  return (
    <section>
      <button
        type="button"
        disabled={stream.isLoading}
        onClick={() => {
          void stream.submit({
            messages: [
              { role: "user", content: "Write a short status update." },
            ],
          });
        }}
      >
        Run agent
      </button>

      {stream.messages.map((message, index) => (
        <p key={message.id ?? index}>{String(message.content)}</p>
      ))}

      <p>State keys: {Object.keys(stream.values).join(", ")}</p>
    </section>
  );
}
```

## 资源

SDK 客户端暴露了以下资源组：

| Resource | Python | TypeScript |
| --- | --- | --- |
| Agents | `client.agents` | `client.agents` |
| Threads and runs | `client.threads` | `client.threads` |
| MCP servers | `client.mcp_servers` | `client.mcpServers` |
| Auth sessions | `client.auth_sessions` | `client.authSessions` |

Python 方法使用 `snake_case`，例如 `create_and_run` 和 `resolve_interrupt`。TypeScript 方法使用 `camelCase`，例如 `createAndRun` 和 `resolveInterrupt`。

SDK 还可以注册 MCP servers、完成 auth session，并通过 Python 中的 `client.mcp_servers.list_tools(...)` 或 TypeScript 中的 `client.mcpServers.listTools(...)` 发现已注册 server 的工具 schema。然后你可以把选中的工具条目传给 `client.agents.create(...)` 或 `client.agents.update(...)`。

## 处理错误

请求失败时会抛出带类型的错误对象，其中包含 HTTP 状态码，以及 API 返回时附带的错误 code 和 detail。

<CodeGroup>

```python Python
from managed_deepagents import Client, ManagedDeepAgentsAPIError

with Client() as client:
    try:
        client.agents.get("missing-agent")
    except ManagedDeepAgentsAPIError as error:
        # `code` and `detail` can be empty, for example on a 403 permission error.
        # The raw message is on `error.body`.
        print(error.status_code, error.code, error.detail, error.body)
```

```ts TypeScript
import { Client, ManagedDeepAgentsAPIError } from "@langchain/managed-deepagents";

const client = new Client();

try {
  await client.agents.get("missing-agent");
} catch (error) {
  if (error instanceof ManagedDeepAgentsAPIError) {
    // `code` and `detail` can be undefined, for example on a 403 permission error.
    // The raw message is on `error.body`.
    console.log(error.status, error.code, error.detail, error.body);
  }
}
```

</CodeGroup>

当请求因为权限缺失而被拒绝时，响应通常是 `403`，其中 `code` 和 `detail` 为空，而拒绝原因则会以纯文本形式返回。这种情况下，请从两个 SDK 的 `error.body` 中读取原始信息，例如 `missing permission mcp-servers:create`。

关于各 endpoint 层级的请求与响应 schema，请参见 [Managed Deep Agents API reference](/langsmith/managed-deep-agents-api-overview)。
