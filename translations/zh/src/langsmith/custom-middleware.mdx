---
title: 如何添加自定义 middleware
sidebarTitle: 添加自定义 middleware
---
当把 agents 部署到 LangSmith 时，你可以给服务添加自定义 middleware，用于处理请求指标日志、注入或检查 headers，以及执行安全策略，而无需修改核心服务逻辑。这与[添加自定义 routes](/langsmith/custom-routes)的方式完全相同。你只需要提供自己的 [`Starlette`](https://www.starlette.io/applications/) app（包括 [`FastAPI`](https://fastapi.tiangolo.com/)、[`FastHTML`](https://fastht.ml/) 以及其他兼容应用）。

添加 middleware 后，你就可以在整个 deployment 范围内全局拦截和修改请求与响应，无论这些请求打到的是自定义 endpoints，还是内置的 LangSmith APIs。

下面是一个使用 FastAPI 的示例。

<Note>
"仅 Python"
目前只支持在使用 `langgraph-api>=0.0.26` 的 Python 部署中添加自定义 middleware。
</Note>

## 创建 app

从一个**已有的** LangSmith 应用开始，把下面的 middleware 代码加入 `webapp.py` 文件中。如果你是从零开始，也可以通过 CLI 从模板创建一个新应用。

```bash
langgraph new --template=new-langgraph-project-python my_new_project
```

准备好 LangGraph 项目后，加入以下 app 代码：

```python {highlight={5}}
# ./src/agent/webapp.py
from fastapi import FastAPI, Request
from starlette.middleware.base import BaseHTTPMiddleware

app = FastAPI()

class CustomHeaderMiddleware(BaseHTTPMiddleware):
    async def dispatch(self, request: Request, call_next):
        response = await call_next(request)
        response.headers['X-Custom-Header'] = 'Hello from middleware!'
        return response

# Add the middleware to the app
app.add_middleware(CustomHeaderMiddleware)
```

## 配置 `langgraph.json`

将以下内容添加到 `langgraph.json` 配置文件中。请确保路径指向上面创建的 `webapp.py` 文件。

```json
{
  "dependencies": ["."],
  "graphs": {
    "agent": "./src/agent/graph.py:graph"
  },
  "env": ".env",
  "http": {
    "app": "./src/agent/webapp.py:app"
  }
  // Other configuration options like auth, store, etc.
}
```

### 自定义 middleware 顺序

默认情况下，自定义 middleware 会在认证逻辑之前运行。如果你希望它在认证**之后**运行，请在 `http` 配置中把 `middleware_order` 设置为 `auth_first`。（该自定义能力从 API server v0.4.35 起可用。）

```json
{
  "dependencies": ["."],
  "graphs": {
    "agent": "./src/agent/graph.py:graph"
  },
  "env": ".env",
  "http": {
    "app": "./src/agent/webapp.py:app",
    "middleware_order": "auth_first"
  },
  "auth": {
    "path": "./auth.py:my_auth"
  }
}
```

## 启动服务

先在本地测试服务：

```bash
langgraph dev --no-browser
```

现在，打到服务的任何请求，其响应中都会包含自定义 header `X-Custom-Header`。

## 部署

你可以保持原样将这个 app 部署到 cloud，或部署到自己的自托管平台。

## 下一步

既然已经给 deployment 添加了自定义 middleware，也可以用类似方法继续添加[自定义 routes](/langsmith/custom-routes)，或者定义[自定义 lifespan 事件](/langsmith/custom-lifespan)，以进一步定制服务行为。
