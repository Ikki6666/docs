创建一个 agent 项目，在 [LangSmith Studio](/langsmith/studio) 中本地测试，然后使用 [`mda` CLI](/langsmith/managed-deep-agents-cli) 将其部署到托管 LangSmith 基础设施。项目文件夹包含你的 agent 的 model、instructions 和 tools。Managed Deep Agents 提供 [Deep Agents harness](/oss/deepagents/overview) 和托管运行时。

## 创建并部署 agent

<Steps>
  <Step title="安装包" id="install-the-package">

安装 `managed-deepagents`。该包内置了 `mda` CLI。

:::python
```bash
uv tool install managed-deepagents
```
:::

:::js
```bash
npm install managed-deepagents
```
:::

  </Step>

  <Step title="创建项目" id="create-a-project">

创建一个项目并打开其目录：

```bash
mda init research-assistant
cd research-assistant
```

你在本 quickstart 中编辑的文件有：

:::python
- **`agent.py`**：定义并导出 agent。参见 [Agent definition](/langsmith/managed-deep-agents-agent-definition)。
:::

:::js
- **`agent.ts`**：定义并导出 agent。参见 [Agent definition](/langsmith/managed-deep-agents-agent-definition)。
:::

- **[`instructions.md`](/langsmith/managed-deep-agents-instructions)**：包含描述 agent 应如何表现的 prompt。
- **`.env`**：存储本地开发和部署所需的 API keys。不要提交此文件。

关于所有生成的文件，请参见 [Project structure](/langsmith/managed-deep-agents-project-structure)。

  </Step>

  <Step title="添加 API keys" id="add-api-keys">

将你的 LangSmith API key 和 model provider API key 添加到 `.env`：

```text .env
LANGSMITH_API_KEY=<LANGSMITH_API_KEY>
OPENAI_API_KEY=<OPENAI_API_KEY>
```

此示例使用 [OpenAI chat model](/oss/integrations/chat/openai)。如果你选择其他 model provider，请改为添加该 provider 所需的 API key。`mda deploy` 使用 LangSmith API key 部署 agent，并将 provider key 添加到 deployment。

  </Step>

  <Step title="配置 agent" id="configure-the-agent">

:::python
打开 `agent.py` 并设置 agent 名称和 model：

```python agent.py
from managed_deepagents import define_deep_agent

agent = define_deep_agent(
    name="research-assistant",
    model="openai:gpt-5.5",
)
```
:::

:::js
打开 `agent.ts` 并设置 agent 名称和 model：

```ts agent.ts
import { defineDeepAgent } from "managed-deepagents";

export const agent = defineDeepAgent({
  name: "research-assistant",
  model: "openai:gpt-5.5",
});
```
:::

Model 负责 agent 的语言理解和推理。Agent 名称也是默认的 deployment 名称。关于 model 概念和 provider 选项，请参见 [Models](/oss/langchain/models)。

  </Step>

  <Step title="编辑 instructions" id="edit-the-instructions">

打开 `instructions.md`，描述 agent 应如何表现：

```markdown instructions.md
# Research assistant

You are a careful research assistant. Use internet search to find sources,
keep notes, and return concise answers with citations.
```

部署时，Managed Deep Agents 会将这些 instructions 同步到 [LangSmith Context Hub](/langsmith/use-the-context-hub)，你可以在那里更新它们而无需重新部署 agent。

  </Step>

  <Step title="添加互联网搜索 tool" id="add-an-internet-search-tool">

Tool 是 agent 可以调用的函数，用于检索数据或执行操作。选择你的 model provider 的服务端搜索，或使用 Tavily 创建一个[自定义 LangChain tool](/oss/langchain/tools)。

<Tabs>
  <Tab title="Provider search（推荐）">

OpenAI 提供了一个内置的 web search tool，它在服务端运行，因此不需要额外的包或 API key。直接将其添加到 agent：

:::python
```python agent.py
from managed_deepagents import define_deep_agent

agent = define_deep_agent(
    name="research-assistant",
    model="openai:gpt-5.5",
    tools=[{"type": "web_search"}],
)
```
:::

:::js
```ts agent.ts
import { defineDeepAgent } from "managed-deepagents";

export const agent = defineDeepAgent({
  name: "research-assistant",
  model: "openai:gpt-5.5",
  tools: [{ type: "web_search_preview" }],
});
```
:::

  </Tab>
  <Tab title="Tavily（任意 provider）">

将 [Tavily API key](https://app.tavily.com) 添加到 `.env`：

```text .env
TAVILY_API_KEY=<TAVILY_API_KEY>
```

安装 Tavily 客户端：

:::python
```bash
uv add tavily-python
```
:::

:::js
```bash
npm install @langchain/tavily
```
:::

创建一个自定义 `internet_search` tool：

:::python
```python tools/search.py
import os
from typing import Literal

from langchain.tools import tool
from tavily import TavilyClient


tavily_client = TavilyClient(api_key=os.environ["TAVILY_API_KEY"])


@tool
def internet_search(
    query: str,
    max_results: int = 5,
    topic: Literal["general", "news", "finance"] = "general",
) -> dict:
    """Search the internet for relevant sources."""
    return tavily_client.search(
        query,
        max_results=max_results,
        topic=topic,
    )
```
:::

:::js
```ts tools/search.ts
import { TavilySearch } from "@langchain/tavily";
import { tool } from "langchain";
import { z } from "zod";

export const internetSearch = tool(
  async ({ query, maxResults = 5, topic = "general" }) => {
    const tavilySearch = new TavilySearch({
      maxResults,
      tavilyApiKey: process.env.TAVILY_API_KEY,
      topic,
    });
    return tavilySearch._call({ query });
  },
  {
    name: "internet_search",
    description: "Search the internet for relevant sources.",
    schema: z.object({
      query: z.string().describe("The search query."),
      maxResults: z.number().optional().default(5),
      topic: z.enum(["general", "news", "finance"]).optional().default("general"),
    }),
  },
);
```
:::

导入该 tool 并将其添加到 agent：

:::python
```python agent.py
from managed_deepagents import define_deep_agent

from tools.search import internet_search

agent = define_deep_agent(
    name="research-assistant",
    model="openai:gpt-5.5",
    tools=[internet_search],
)
```
:::

:::js
```ts agent.ts
import { defineDeepAgent } from "managed-deepagents";

import { internetSearch } from "./tools/search";

export const agent = defineDeepAgent({
  name: "research-assistant",
  model: "openai:gpt-5.5",
  tools: [internetSearch],
});
```
:::

  </Tab>
</Tabs>

更多信息请参见 [Custom tools](/langsmith/managed-deep-agents-tools)。

  </Step>

  <Step title="本地运行" id="run-locally">

安装项目依赖并启动 agent：

:::python
```bash
uv sync
mda dev .
```
:::

:::js
```bash
npm install
mda dev .
```
:::

`mda dev` 会从 `.env` 加载 API keys，启动本地 Agent Server，并在 LangSmith Studio 中打开 agent。在 Studio 中发送消息以检查模型响应和工具调用。更多信息请参见[使用 LangSmith Studio 进行本地开发](/langsmith/managed-deep-agents-local-development)。

  </Step>

  <Step title="部署 agent" id="deploy-the-agent">

部署项目：

```bash
mda deploy .
```

Managed Deep Agents 会打包项目，并将其作为托管 deployment 在 [LangSmith Agent Server](/langsmith/agent-server) 上运行。部署完成后，CLI 会打印 deployment dashboard URL。打开它以查看和测试已部署的 agent。

关于部署选项和 secrets 处理，请参见 [Deploy a Managed Deep Agent](/langsmith/managed-deep-agents-deploy)。要在 agent 运行后检查其执行情况，请使用 [LangSmith observability](/langsmith/observability-quickstart)。

  </Step>
</Steps>
