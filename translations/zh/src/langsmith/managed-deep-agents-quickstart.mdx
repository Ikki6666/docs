LangChain 托管了 [Managed Deep Agents](/langsmith/managed-deep-agents-overview)，因此你无需搭建基础设施，就可以创建一个 agent 并流式获取它的响应。本快速开始将演示如何通过 CLI 或 SDK 创建 agent，然后用 Python SDK、TypeScript SDK 或 React `useStream` 来运行它。

关于完整的部署工作流和所有 backend 选项，请参见 [Deploy an agent](/langsmith/managed-deep-agents-deploy)。关于包配置和 API 细节，请参见 [Managed Deep Agents SDKs](/langsmith/managed-deep-agents-sdk)。

<Note>
Managed Deep Agents 当前处于 **private beta**，仅在美国区域的 [LangSmith Cloud](/langsmith/cloud) 中可用。你可以[加入候补名单](https://www.langchain.com/langsmith-managed-deep-agents-waitlist)来申请访问权限。
</Note>

## 前置条件

开始前，请确保你具备以下条件：

- Managed Deep Agents 的 [private beta 访问权限](https://www.langchain.com/langsmith-managed-deep-agents-waitlist)。
- 一个可访问 private beta 工作区的 [LangSmith API key](/langsmith/create-account-api-key)。
- 一个客户端。Python SDK（`managed-deepagents`）或 TypeScript SDK（`@langchain/managed-deepagents`）可以覆盖完整 quickstart。`deepagents-cli>=0.2.2` 可以创建 agent，但不能运行它，因此真正运行 agent 仍需要 SDK。

## 创建并运行 agent

<Steps>
  <Step title="安装客户端" id="install-a-client">

根据你的运行时选择客户端：

<CodeGroup>

```bash CLI
uv tool install "deepagents-cli>=0.2.2"

# Or with pip:
pip install -U "deepagents-cli>=0.2.2"
```

```bash Python
uv add managed-deepagents

# Or with pip:
pip install managed-deepagents
```

```bash TypeScript
npm install @langchain/managed-deepagents

# For React streaming:
npm install @langchain/react
```

</CodeGroup>

若要升级现有 CLI 安装，请运行 `uv tool upgrade deepagents-cli`（如果你是通过 pip 安装的，则使用 `pip install -U "deepagents-cli"`）。

  </Step>

  <Step title="设置 API key">

为具备 private beta 访问权限的工作区设置 LangSmith API key：

```bash
export LANGSMITH_API_KEY="<LANGSMITH_API_KEY>"
```

<Note>
如果某次请求返回 401 或 403，请确认该 API key 对应的是具备 private beta 权限的工作区。
</Note>

  </Step>

  <Step title="创建 agent">

创建一个 Managed Deep Agent，并保存返回的 `agent_id`，后续运行步骤会用到它。

<CodeGroup>

```bash CLI
deepagents init research-assistant
cd research-assistant

# Edit AGENTS.md to define the agent behavior, then deploy.
deepagents deploy
```

```python Python
from managed_deepagents import Client

with Client() as client:
    agent = client.agents.create(
        name="research-assistant",
        description="Research assistant that can search the web and summarize sources.",
        model="openai:gpt-5.5",
        backend={"type": "state"},
        instructions=(
            "You are a careful research assistant. Search for sources, "
            "keep notes, and return concise answers with citations."
        ),
    )

agent_id = agent["id"]
print(f"Agent ID: {agent_id}")
```

```ts TypeScript
import { Client } from "@langchain/managed-deepagents";

const client = new Client({
  apiKey: process.env.LANGSMITH_API_KEY,
});

const agent = await client.agents.create({
  name: "research-assistant",
  description: "Research assistant that can search the web and summarize sources.",
  model: "openai:gpt-5.5",
  backend: { type: "state" },
  instructions:
    "You are a careful research assistant. Search for sources, keep notes, and return concise answers with citations.",
});

const agentId = agent.id;
console.log(`Agent ID: ${agentId}`);
```

</CodeGroup>

CLI 在部署前会创建 `agent.json`、`AGENTS.md`、`.gitignore`、一个空的 `tools.json`、一个示例 skill 和一个示例 subagent。SDK 示例则会直接创建托管 agent。

这里的示例使用 `state` backend，因此 agent 可以在不需要 sandbox 特殊配置的情况下直接运行。当 agent 需要使用 [LangSmith sandbox](/langsmith/sandboxes) 来执行代码、操作文件系统或处理长任务时，再切换到 `sandbox` backend。关于可选项，请参见 [Choose a backend](/langsmith/managed-deep-agents-deploy#choose-a-backend)。

如果 agent 会调用 MCP tools，请在创建或部署 agent 之前先完成[连接工具](/langsmith/managed-deep-agents-mcp)。

  </Step>

  <Step title="运行 agent">

从 agent 中流式获取响应：

<CodeGroup>

```python Python
from managed_deepagents import Client

agent_id = "<agent_id>"

with Client() as client:
    thread = client.threads.create(
        agent_id=agent_id,
        options={
            "test_run": False,
            "skip_memory_write_protection": False,
        },
    )

    for event in client.threads.stream(
        thread["id"],
        agent_id=agent_id,
        messages=[
            {
                "role": "user",
                "content": "Research recent approaches to agent memory and summarize the main trade-offs.",
            }
        ],
        stream_mode=["values", "updates", "messages-tuple"],
        stream_subgraphs=True,
    ):
        print(event.event, event.data)
```

```ts TypeScript
import { Client } from "@langchain/managed-deepagents";

const agentId = "<agent_id>";
const client = new Client({
  apiKey: process.env.LANGSMITH_API_KEY,
});

const thread = await client.threads.create({
  agent_id: agentId,
  options: {
    test_run: false,
    skip_memory_write_protection: false,
  },
});

const langGraphClient = client.getLangGraphClient({ agentId });
const stream = langGraphClient.runs.stream(thread.id, agentId, {
  input: {
    messages: [
      {
        role: "user",
        content:
          "Research recent approaches to agent memory and summarize the main trade-offs.",
      },
    ],
  },
  streamMode: ["values", "updates", "messages-tuple"],
  streamSubgraphs: true,
});

for await (const event of stream) {
  console.log(event.event, event.data);
}
```

```tsx useStream
import { Client } from "@langchain/managed-deepagents";
import { useStream } from "@langchain/react";

const agentId = "<agent_id>";

const managedDeepAgents = new Client({
  // In browser apps, prefer passing a custom fetch that calls your backend.
  apiKey: process.env.LANGSMITH_API_KEY,
});

const client = managedDeepAgents.getLangGraphClient({ agentId });

export function ManagedDeepAgentStream() {
  const stream = useStream({
    client,
    assistantId: agentId
  });

  return (
    <section>
      <button
        type="button"
        disabled={stream.isLoading}
        onClick={() => {
          void stream.submit({
            messages: [
              {
                role: "user",
                content:
                  "Research recent approaches to agent memory and summarize the main trade-offs.",
              },
            ],
          });
        }}
      >
        Run agent
      </button>

      {stream.messages.map((message, index) => (
        <p key={message.id ?? index}>{String(message.content)}</p>
      ))}
    </section>
  );
}
```

</CodeGroup>

Python 流会产出来自 run 的 Server-Sent Events。TypeScript SDK 和 React `useStream` 示例使用的是 LangGraph 的 stream 投影，分别面向 messages、values 和 output state。

  </Step>
</Steps>

<Note>
如果 `deepagents init`、`deploy`、`agents` 或 `mcp-servers` 缺失或行为异常，请用 `deepagents --version` 确认已安装版本是 `0.2.2` 或更高。旧版 `deepagents` 可能会在你的 `PATH` 中遮蔽当前版本。
</Note>
