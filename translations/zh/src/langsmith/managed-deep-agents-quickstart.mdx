创建并部署你的第一个 Managed Deep Agent：搭建项目脚手架、配置 model 和 instructions、添加搜索、在 [LangSmith Studio](/langsmith/studio) 中测试，并使用 [`mda` CLI](/langsmith/managed-deep-agents-cli) 部署。Managed Deep Agents 提供 [Deep Agents harness](/oss/deepagents/overview) 和托管运行时。

完成本 quickstart 后，[tutorial](/langsmith/managed-deep-agents-tutorial) 会在同一项目上添加持久 memory 和每日调度。

## 添加 `managed-deep-agents` skill

[`managed-deep-agents` skill](https://github.com/langchain-ai/langchain-skills/blob/main/config/skills/managed-deep-agents/SKILL.md) 会引导 coding agent 使用 `mda` CLI 构建、测试和部署 Managed Deep Agent。要将其添加到当前项目，请运行：

```bash
npx skills add langchain-ai/langchain-skills --skill managed-deep-agents --yes
```

## 创建并部署 agent

<Steps>
  <Step title="设置项目" id="set-up-the-project">

安装 `managed-deepagents`，创建一个项目，并打开其目录：

:::python
```bash
uv tool install managed-deepagents
mda init research-assistant
cd research-assistant
```
:::

:::js
```bash
npm install managed-deepagents
mda init research-assistant
cd research-assistant
```
:::

现在你已经拥有 agent 的全部脚手架。

  </Step>

  <Step title="添加你的 keys" id="add-keys">

将你的 model provider API key 添加到 `.env`：

```text .env
OPENAI_API_KEY=<OPENAI_API_KEY>
# ANTHROPIC_API_KEY=<ANTHROPIC_API_KEY>
# GOOGLE_API_KEY=<GOOGLE_API_KEY>
```

本 quickstart 默认使用 OpenAI。如果你在下一步中选择 Google 或 Anthropic，请改为设置该 provider 的 API key。`mda deploy` 会将 provider key 添加到 deployment。你也可以使用任何[其他 chat provider](/oss/integrations/chat/)。

<Warning>
不要将 `.env` 文件提交到版本控制。它包含 secrets。
</Warning>

  </Step>

  <Step title="设置 LangSmith" id="set-up-langsmith">

Managed Deep Agents 运行在 LangSmith 上。你的 LangSmith API key 用于通过 `mda dev` 认证本地开发、通过 `mda deploy` 部署 agent，并在 [LangSmith Studio](/langsmith/studio) 中打开 agent，以便你与它对话并检查 traces。

如果你还没有账号，请[注册 LangSmith](https://smith.langchain.com)。

要创建 LangSmith API key，请打开 [Settings](https://smith.langchain.com/settings)，进入 **API Keys**，然后点击 **Create API Key**。更多详情请参见[创建账号和 API key](/langsmith/create-account-api-key)。

将你的 LangSmith API key 添加到 `.env`：

```text .env
LANGSMITH_API_KEY=<LANGSMITH_API_KEY>
```

  </Step>
  <Step title="编辑 instructions" id="edit-the-instructions">

打开 `instructions.md`，描述 agent 应如何表现：

```markdown instructions.md
# Research assistant

You are a careful research assistant. Use internet search to find sources,
keep notes, and return concise answers with citations.
```

部署时，Managed Deep Agents 会将这些 instructions 同步到 [LangSmith Context Hub](/langsmith/use-the-context-hub)，你可以在那里更新它们而无需重新部署 agent。

  </Step>

<Accordion title="使用其他 provider？">

你可以改用 Tavily 搜索 tool。
将 [Tavily API key](https://app.tavily.com) 添加到 `.env`：

```text .env
TAVILY_API_KEY=<TAVILY_API_KEY>
```

安装 Tavily 客户端：

:::python
```bash
uv add tavily-python
```
:::

:::js
```bash
npm install @langchain/tavily
```
:::

创建一个自定义 `internet_search` tool：

:::python
```python tools/search.py
import os
from typing import Literal

from langchain.tools import tool
from tavily import TavilyClient


tavily_client = TavilyClient(api_key=os.environ["TAVILY_API_KEY"])


@tool
def internet_search(
    query: str,
    max_results: int = 5,
    topic: Literal["general", "news", "finance"] = "general",
) -> dict:
    """Search the internet for relevant sources."""
    return tavily_client.search(
        query,
        max_results=max_results,
        topic=topic,
    )
```
:::

:::js
```ts tools/search.ts
import { TavilySearch } from "@langchain/tavily";
import { tool } from "langchain";
import { z } from "zod";

export const internetSearch = tool(
  async ({ query, maxResults = 5, topic = "general" }) => {
    const tavilySearch = new TavilySearch({
      maxResults,
      tavilyApiKey: process.env.TAVILY_API_KEY,
      topic,
    });
    return tavilySearch._call({ query });
  },
  {
    name: "internet_search",
    description: "Search the internet for relevant sources.",
    schema: z.object({
      query: z.string().describe("The search query."),
      maxResults: z.number().optional().default(5),
      topic: z.enum(["general", "news", "finance"]).optional().default("general"),
    }),
  },
);
```
:::

导入该 tool 并将其添加到 agent：

:::python
```python agent.py
from managed_deepagents import define_deep_agent

from tools.search import internet_search

agent = define_deep_agent(
    name="research-assistant",
    model="openai:gpt-5.5",
    tools=[internet_search],
)
```
:::

:::js
```ts agent.ts
import { defineDeepAgent } from "managed-deepagents";

import { internetSearch } from "./tools/search";

export const agent = defineDeepAgent({
  name: "research-assistant",
  model: "openai:gpt-5.5",
  tools: [internetSearch],
});
```
:::

关于更多已编写的 tools，请参见 [Custom tools](/langsmith/managed-deep-agents-tools)。

</Accordion>

  </Step>

  <Step title="本地运行" id="run-locally">

安装项目依赖并启动 agent：

:::python
```bash
uv sync
mda dev .
```
:::

:::js
```bash
npm install
mda dev .
```
:::

`mda dev` 会从 `.env` 加载 API keys，启动本地 Agent Server，并在 LangSmith Studio 中打开 agent。

在 Studio 中发送：

```txt wrap
What were the main announcements from the latest LangChain release?
```

你应该会看到 agent 调用 web search tool，然后返回一个引用来源的简明答案。如果 trace 中始终没有出现搜索，请确认 provider tool dict 与你在 `agent.py` 或 `agent.ts` 中设置的 model 匹配。

更多信息请参见[使用 LangSmith Studio 进行本地开发](/langsmith/managed-deep-agents-local-development)。
  </Step>

  <Step title="部署 agent" id="deploy-the-agent">

通过运行以下命令部署项目：

```bash
mda deploy .
```

Managed Deep Agents 会打包项目，并将其作为托管 deployment 在 [LangSmith Agent Server](/langsmith/agent-server) 上运行。部署完成后，CLI 会打印 deployment dashboard URL。

打开该 URL。你应该会看到 deployment 处于 ready 状态。发送与上一步相同的研究问题，确认托管 agent 返回了带有搜索 tool 调用的答案。关于部署选项和 secrets 处理，请参见 [Deploy a Managed Deep Agent](/langsmith/managed-deep-agents-deploy)。要在 agent 运行后检查其执行情况，请使用 [LangSmith observability](/langsmith/observability-quickstart)。

  </Step>
</Steps>
