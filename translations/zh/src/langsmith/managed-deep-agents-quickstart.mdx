无需自行搭建基础设施即可部署托管 Deep Agent。本 quickstart 会带你完成一个代码优先项目的脚手架初始化、本地运行、编辑托管 system prompt，并使用 `mda` 部署。如果你想按步骤构建一个更完整的 agent，请继续阅读 [tutorial](/langsmith/managed-deep-agents-tutorial)。

完整 deploy 工作流与全部 CLI flags 请参见 [Deploy an agent](/langsmith/managed-deep-agents-deploy) 和 [CLI reference](/langsmith/managed-deep-agents-cli)。

## 创建并部署 agent

<Steps>
  <Step title="安装包" id="install-the-package">

为你打算使用的语言安装 `managed-deepagents`。两个包都内置了 `mda` CLI。

<CodeGroup>

```bash pip
pip install --pre managed-deepagents
```

```bash npm
npm install -g managed-deepagents@dev
```

</CodeGroup>

对于 Python，`pip` 会同时安装 `mda` CLI。完成项目脚手架后，请在项目目录中运行 `uv sync`，安装生成的 `pyproject.toml` 中声明的依赖。

  </Step>

  <Step title="创建项目" id="create-a-project">

创建一个 Managed Deep Agents 项目：

```bash
mda init research-assistant
cd research-assistant
```

CLI 会根据当前目录中的 `pyproject.toml` 或 `package.json` 推断语言。如果无法推断，它会提示你选择 Python 或 TypeScript。

脚手架会创建：

| 文件 | 作用 |
| --- | --- |
| `agent.py` 或 `agent.ts` | 由 `mda` 编译的命名 `agent` 定义。 |
| `instructions.md` | 托管 system prompt，本地开发时嵌入，deploy 时同步到 Context Hub。 |
| `pyproject.toml` 或 `package.json` | 包含 `managed-deepagents` 的最小项目清单。 |
| `README.md` | 本地项目说明与 deploy 命令。 |
| `.env` | Deploy 鉴权和运行时 secrets。不要提交真实 secrets。 |
| `.gitignore` | 忽略 `.env`、`.env.*`、`.mda/` 和依赖缓存。 |

完整项目布局请参见 [CLI project file reference](/langsmith/managed-deep-agents-cli#project-file-reference)。

  </Step>

  <Step title="在 `.env` 中添加 API keys" id="add-api-keys">

打开生成的 `.env` 文件，填入 LangSmith API key 和你计划使用模型所需的 provider key：

```text .env
LANGSMITH_API_KEY=<LANGSMITH_API_KEY>
OPENAI_API_KEY=<OPENAI_API_KEY>
```

`LANGSMITH_API_KEY` 用于 `mda deploy` 鉴权。Provider keys、MCP tokens、database URLs 以及其他非保留 `.env` 值，会在 deploy 时作为 secrets 发送到托管 deployment。`.env` 文件本身不会被打包上传。

CLI 默认面向美国区域的 LangSmith Cloud。若要使用 organization-scoped key，请在 `.env` 中设置 `LANGSMITH_TENANT_ID`，或在 `mda deploy` 时传入 `--tenant-id`。

<Note>
如果请求返回 401 或 403，请确认该 key 所属 workspace 已获得 beta 访问权限。
</Note>

  </Step>

  <Step title="编辑 agent" id="edit-the-agent">

打开生成的 `agent.py` 或 `agent.ts`，在代码中配置 model、tools、middleware 和 interrupts。

<CodeGroup>

```python agent.py
from managed_deepagents import define_deep_agent

agent = define_deep_agent(
    model="openai:gpt-5.5",
)
```

```ts agent.ts
import { defineDeepAgent } from "managed-deepagents";

export const agent = defineDeepAgent({
  model: "openai:gpt-5.5",
});
```

</CodeGroup>

<ManagedDeepAgentsRuntimeOwnership />

生成的示例默认使用 OpenAI。如果你使用其他 provider，请修改 model 标识符，并在 `.env`、shell 环境变量或 LangSmith workspace secrets 中配置该 provider 所需的 API key。

  </Step>

  <Step title="编辑 instructions" id="edit-the-instructions">

打开 `instructions.md`，将生成的 prompt 替换为你需要的行为描述：

```markdown instructions.md
# Research assistant

You are a careful research assistant. Search for sources, keep notes, and return
concise answers with citations.
```

`mda dev` 会把这个文件嵌入生成的本地入口模块。`mda deploy` 会把它同步到 Context Hub，部署后的运行时会从那里读取。

  </Step>

  <Step title="本地运行" id="run-locally">

先安装生成项目的依赖，然后启动本地 LangGraph dev server：

<CodeGroup>

```bash uv
uv sync
mda dev .
```

```bash npm
npm install
mda dev .
```

</CodeGroup>

对于 TypeScript 项目，`mda dev` 会运行 `npx --yes @langchain/langgraph-cli dev`。对于 Python 项目，它会使用 `uv` 自动解析并运行本地 LangGraph dev server。你无需自行安装 `langgraph-cli[inmem]`。

`mda dev` 会从编译后的本地构建目录加载项目 `.env` 文件，使 model provider keys 和 connector tokens 在本地开发期间可用。

  </Step>

  <Step title="部署 agent" id="deploy-the-agent">

部署本地项目：

```bash
mda deploy .
```

成功后，CLI 会打印 LangSmith deployment dashboard URL：

```text
Deployment live
Deployment dashboard
https://smith.langchain.com/o/<tenant-id>/host/deployments/<deployment-id>
Deployed 'research-assistant' to LangSmith.
```

在 LangSmith 中打开打印出的 URL，查看 build 状态、revisions 和 traces。

  </Step>
</Steps>
