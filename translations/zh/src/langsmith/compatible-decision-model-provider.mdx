Compatible endpoint 是一个保存下来的 [model configuration](/langsmith/model-configurations)，用于将 decision model evaluator 的请求发送到你选择的服务器。借助 compatible endpoint，你可以通过其他 provider（例如 OpenRouter）调用 decision model，或调用你自己托管的 decision model。LangSmith 支持两种类型：

- **OpenAI-Decisions-compatible endpoint**：调用任何实现了 [OpenAI Decisions API](https://developers.openai.com/api/docs/guides/decisions) 的服务器，并使用该服务器提供的任意 model 名称。
- **TypeSafe-compatible endpoint**：调用任何实现了 [TypeSafe System One API](https://docs.typesafe.ai) 的服务器。

Compatible endpoints 可用于 [decision model evaluators](/langsmith/decision-model-evaluator)。要直接从 OpenAI 使用 `gpt-6-luna`，或直接从 TypeSafe 使用 Jev，你不需要 compatible endpoint。对于实现 OpenAI API 的 chat model，请参阅[连接 OpenAI 兼容的 model provider/proxy](/langsmith/custom-openai-compliant-model)。

## 配置

Compatible endpoint 有三个设置：

- **Model**：服务器期望的 model ID。
- **API Key Name**：存储服务器 API key 的 workspace secret 的名称。
- **Base URL**：服务器 API 的根路径。请参阅 [Base URL 格式](#base-url-格式)。

默认值取决于 endpoint 的类型：

| Setting | OpenAI-Decisions-compatible endpoint | TypeSafe-compatible endpoint |
|---------|--------------------------------------|------------------------------|
| Model | `gpt-6-luna` | `jev-latest` |
| API Key Name | `OPENAI_API_KEY` | `TYPESAFE_API_KEY` |

## 在 evaluator 中使用 endpoint

只有在将 endpoint 保存为 model configuration 之后，evaluator 才能使用 compatible endpoint。

在 evaluator 中使用 compatible endpoint：

1. 将服务器的 API key 添加为 workspace secret。进入 **Settings > Integrations > Provider secrets**，点击 **+ Secret**，然后选择 **Custom** 以输入你自己的 secret 名称。要使用默认名称，请改为选择 **OpenAI** 或 **TypeSafe**。
1. 在 evaluator 中，在 **Prompt & Model** 下打开 **Model Configuration**。
1. 对于 **Provider**，选择 **OpenAI Decisions Compatible Endpoint** 或 **TypeSafe Compatible Endpoint**。两者都显示在 **Other** 下。
1. 输入 **Model**、**API Key Name** 和 **Base URL**。
1. 点击 **Save as preset** 并为该配置命名。
1. 选择已保存的配置作为 evaluator 的 model。

当 evaluator 运行时，它会使用你填写在 **API Key Name** 中的 secret 所存储的 API key 调用该 endpoint。接下来，按照[如何定义 decision model evaluator](/langsmith/decision-model-evaluator) 中所述，添加问题并保存 evaluator。

## Base URL 格式

**Base URL** 应指向服务器 API 的根路径。LangSmith 追加的路径取决于 endpoint 的类型。

### OpenAI-Decisions-compatible endpoints

LangSmith 会向 Base URL 追加 `/v1/decisions`，因此不要包含它。

| Provider | Model | Example Base URL |
|----------|-------|------------------|
| [OpenAI](https://developers.openai.com/api/docs/guides/decisions) | `gpt-6-luna` | `https://api.openai.com` |
| Self-hosted（远程） | 你的 model ID | `https://decisions.example.com` |

### TypeSafe-compatible endpoints

LangSmith 会向 Base URL 追加 `/v1/systemone`，因此不要包含它。要完全按输入的 URL 调用（包括其路径），请清除 **Append /v1/systemone**。

| Provider | Model | Example Base URL |
|----------|-------|------------------|
| [TypeSafe](https://docs.typesafe.ai) | `jev-latest` | `https://api.typesafe.ai` |
| [OpenRouter](https://openrouter.ai) | `~typesafe/jev-latest` | `https://openrouter.ai/api` |
| Self-hosted（远程） | 你的 model ID | `https://my-model-server.example.com` |
