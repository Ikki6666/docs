**Context Hub** 为团队提供带版本控制、具备环境感知能力的管理方式，用于管理生产环境中 agents 使用的指令和工具。_context_ 是在 LangSmith 中管理的一个带版本的 agent 指令和工具包，可以是一个 skill，也可以是一个完整 agent。

使用本指南可以创建第一个 context、查看它的文件和历史记录，并将其发布到某个环境，以便 agents 拉取使用。

## 1. 打开 Context Hub

<Note>
如果在左侧导航中看不到 **Context**，请先确认工作区已启用 Context Hub，并且拥有所需权限。
</Note>

在 [LangSmith UI](https://smith.langchain.com) 中，选择左侧导航中的 **Context**。Context Hub 会列出工作区中的每一个 agent 和 skill。

![The Context Hub home view listing existing Agent and Skill contexts with their commit metadata.](/langsmith/images/context-hub-home.png)

## 2. 创建 context

1. 点击 Context Hub 左上角的 **+ Create**。
1. 选择 context 类型：
    - **Agent:** 完整的 agent 包，包含 `AGENTS.md` 文件和工具。
    - **Skill:** agents 可复用的能力，包含 `SKILL.md` 文件。

    <img src="/langsmith/images/context-hub-create-context.png" alt="The Create dropdown showing the Agent and Skill context type options." width="360" />

1. 填写名称和描述。对于 skill，描述为必填项。此时也可以输入初始文件内容（skill 使用 `SKILL.md`，agent 使用 `AGENTS.md`），或者在创建后再添加。点击 **Create Agent** 或 **Create Skill**。LangSmith 会创建该仓库并打开编辑界面。

## 3. 查看 context

在 Context Hub 中点击某个 agent 或 skill 即可查看。

![An Agent context with an AGENTS.md file open, showing the environments panel, commit history, and file tree.](/langsmith/images/context-hub-agent-view.png)

中间面板显示当前 commit 的文件树，右侧面板预览所选文件。点击中间面板中的文件即可打开，然后在右侧面板中编辑并保存，从而创建新的 commit。

每次保存的更改都会在左侧的 **Commit History** 面板中生成一个新的 **commit**，因此可以浏览、比较和回退历史版本，而不会丢失已有工作。

## 4. 标记并发布 commit

当某个 commit 已经可以交付时，将其发布到某个环境，下游 agents 就可以拉取使用它。

<Note>
Context Hub 当前支持两个可用于发布的环境标签：`staging` 和 `production`。
</Note>

1. 选中目标 commit 后，点击右上角的 **Promote**。
1. 选择目标环境：
    - **Promote to Production:** 生产环境 agents 会拉取的 commit。
    - **Promote to Staging:** 用于验证的预生产环境。

    <img src="/langsmith/images/context-hub-promote.png" alt="The Promote dropdown with options to promote a commit to Production or Staging." width="300" />

1. 环境标签（例如 `Production 7ca95573`）会移动到被发布的 commit 上。可以使用 **Promote** 旁边的 **Tag** 按钮，为任意 commit 添加便于识别的人类可读标签。

按环境标签解析 context 的 agent 运行时（例如 `:production`）现在会拉取这个已发布的 commit。
