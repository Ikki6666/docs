## 公开分享 trace

<Warning>
**公开分享 trace 后，任何拥有链接的人都可以访问它。请确保其中不包含敏感信息。**

如果你的[自托管](/langsmith/self-hosted) LangSmith 部署位于 VPC 内，那么公开链接仅对在该 VPC 内完成认证的成员可访问。为了进一步提升安全性，建议将实例配置为仅对具备网络访问权限的用户可达的私有 URL。
</Warning>

要公开分享 trace：

1. 在 [UI](https://smith.langchain.com) 中打开任意 trace。
1. 点击 Details 视图顶部更多 <Icon icon="dots-vertical" /> 菜单中的 **Share** 按钮。
1. 在弹出的对话框中复制公开链接。

共享后的 trace 对任何拥有该链接的人都可访问，即使对方没有 LangSmith 账号。他们可以查看该 trace，但不能编辑。

如果要取消共享 trace，可以使用以下任一方法：

1. 打开已共享的 trace，点击 Details 视图顶部工具栏中的 **Public**，然后在对话框中点击 **Unshare**。
1. 进入 **Settings** → **Shared URLs**，查看所选工作区中所有已公开共享的 traces。在想取消共享的 trace 旁点击 **Unshare**。

## 查看服务日志

<Note>
查看 trace 的服务日志仅适用于 [Cloud SaaS](/langsmith/cloud) 和[完整自托管](/langsmith/self-hosted)部署方式。
</Note>

当查看由 LangSmith 中某个 run 生成的 trace 时，可以直接在 Details 视图中访问对应的服务日志。

在 Details 视图中，使用右上角、位于 **Run in Studio** 按钮旁边的 **See Logs** 按钮。

点击该按钮后，会跳转到 LangSmith 中与该 deployment 对应的服务日志视图。

服务日志视图会显示以下两类日志：

- **Agent Server 自身的运行日志**：内部服务操作、API 调用和系统事件
- **用户应用日志**：你在 graph 中写出的日志：
  - Python：使用 `logging` 或 `structlog` 库。
  - JavaScript：使用从 `@langchain/langgraph-sdk/logging` 重新导出的 Winston logger：

    ```javascript
    import { getLogger } from "@langchain/langgraph-sdk/logging";

    const logger = getLogger();
    logger.info("Your log message");
    ```

从 Details 视图跳转过去时，**Filters** 输入框会自动预填你刚查看的 trace 的 Trace ID，因此可以快速筛选，只查看与该次 trace 执行相关的日志。

## 删除 trace

如果需要在过期日期之前从 LangSmith 中移除 traces，可以删除整个项目，或者删除特定 traces。

### 删除整个项目

- 在 [LangSmith UI](https://smith.langchain.com) 中，在项目的溢出菜单中选择 **Delete**。
- 使用 [`delete_tracer_sessions`](/langsmith/smith-api/tracer-sessions/delete-tracer-session) API endpoint。
- 在 LangSmith SDK 中使用 `delete_project()`（[Python](https://reference.langchain.com/python/langsmith/observability/sdk/)）或 `deleteProject()`（[JS/TS](https://reference.langchain.com/javascript/modules/langsmith.html)）。

### 删除特定 traces：

使用 [`delete_runs`](/langsmith/smith-api/run/delete-runs) API endpoint，可按 trace IDs 或 metadata 键值对删除 runs。请求体支持：

- `session_id`：将删除范围限定到某个特定项目。
- `trace_ids`：要删除的 trace ID 列表。
- `metadata`：删除所有匹配给定 metadata 键值对的 runs。

关于完整的 API 用法，包括代码示例、每次请求 1000 条 trace 的限制、删除时间线和 metadata 匹配行为，请参阅[出于合规目的的数据清除](/langsmith/data-purging-compliance#trace-deletes)。
