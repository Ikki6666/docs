本指南展示如何使用 LangSmith SDK 对一个 agent 运行评估。

<Info>
[Evaluations](/langsmith/evaluation-concepts#evaluation-lifecycle) | [Evaluators](/langsmith/evaluation-concepts#evaluators) | [Datasets](/langsmith/evaluation-concepts#datasets)
</Info>

本指南将介绍如何使用 LangSmith SDK 中的 [evaluate()](https://docs.smith.langchain.com/reference/python/evaluation/langsmith.evaluation._runner.evaluate) 方法来评估应用。

<Check>
对于 Python 中较大的评估任务，我们建议使用 [aevaluate()](https://docs.smith.langchain.com/reference/python/evaluation/langsmith.evaluation._arunner.aevaluate)，也就是 [evaluate()](https://docs.smith.langchain.com/reference/python/evaluation/langsmith.evaluation._runner.evaluate) 的异步版本。不过，建议你先读完本指南，因为两者接口完全一致，然后再阅读关于[异步运行评估](/langsmith/evaluation-async)的 how-to guide。

在 JS/TS 中，`evaluate()` 本身已经是异步的，因此不需要额外的方法。

另外，在运行较大任务时，正确配置 `max_concurrency` / `maxConcurrency` 也很重要。它会通过在多个线程间拆分 dataset，从而并行执行评估。
</Check>

## 定义一个应用

首先我们需要一个待评估的应用。这里我们创建一个简单的 toxicity classifier 作为示例。

<CodeGroup>

```python Python
from langsmith import traceable, wrappers
from openai import OpenAI

# Optionally wrap the OpenAI client to trace all model calls.
oai_client = wrappers.wrap_openai(OpenAI())

# Optionally add the 'traceable' decorator to trace the inputs/outputs of this function.
@traceable
def toxicity_classifier(inputs: dict) -> dict:
    instructions = (
      "Please review the user query below and determine if it contains any form of toxic behavior, "
      "such as insults, threats, or highly negative comments. Respond with 'Toxic' if it does "
      "and 'Not toxic' if it doesn't."
    )
    messages = [
        {"role": "system", "content": instructions},
        {"role": "user", "content": inputs["text"]},
    ]
    result = oai_client.chat.completions.create(
        messages=messages, model="gpt-5.4-mini", temperature=0
    )
    return {"class": result.choices[0].message.content}
```

```typescript TypeScript
import { OpenAI } from "openai";
import { wrapOpenAI } from "langsmith/wrappers";
import { traceable } from "langsmith/traceable";

// Optionally wrap the OpenAI client to trace all model calls.
const oaiClient = wrapOpenAI(new OpenAI());

// Optionally add the 'traceable' wrapper to trace the inputs/outputs of this function.
const toxicityClassifier = traceable(
  async (text: string) => {
    const result = await oaiClient.chat.completions.create({
      messages: [
        {
           role: "system",
          content: "Please review the user query below and determine if it contains any form of toxic behavior, such as insults, threats, or highly negative comments. Respond with 'Toxic' if it does, and 'Not toxic' if it doesn't.",
        },
        { role: "user", content: text },
      ],
      model: "gpt-5.4-mini",
      temperature: 0,
    });

    return result.choices[0].message.content;
  },
  { name: "toxicityClassifier" }
);
```

</CodeGroup>

这里我们可选地启用了 tracing，用来记录 pipeline 每一步的输入输出。如果你想进一步了解如何给代码加 tracing 标注，请参阅[自定义埋点](/langsmith/annotate-code)。

## 创建或选择一个 dataset

我们需要一个 [Dataset](/langsmith/evaluation-concepts#datasets) 来评估应用。这个 dataset 会包含带标签的[examples](/langsmith/evaluation-concepts#examples)，其中既有 toxic 文本，也有 non-toxic 文本。


需要 `langsmith>=0.3.13`

<CodeGroup>

```python Python
from langsmith import Client
ls_client = Client()

examples = [
  {
    "inputs": {"text": "Shut up, idiot"},
    "outputs": {"label": "Toxic"},
  },
  {
    "inputs": {"text": "You're a wonderful person"},
    "outputs": {"label": "Not toxic"},
  },
  {
    "inputs": {"text": "This is the worst thing ever"},
    "outputs": {"label": "Toxic"},
  },
  {
    "inputs": {"text": "I had a great day today"},
    "outputs": {"label": "Not toxic"},
  },
  {
    "inputs": {"text": "Nobody likes you"},
    "outputs": {"label": "Toxic"},
  },
  {
    "inputs": {"text": "This is unacceptable. I want to speak to the manager."},
    "outputs": {"label": "Not toxic"},
  },
]

dataset = ls_client.create_dataset(dataset_name="Toxic Queries")
ls_client.create_examples(
  dataset_id=dataset.id,
  examples=examples,
)
```

```typescript TypeScript
import { Client } from "langsmith";

const langsmith = new Client();

// create a dataset
const labeledTexts = [
  ["Shut up, idiot", "Toxic"],
  ["You're a wonderful person", "Not toxic"],
  ["This is the worst thing ever", "Toxic"],
  ["I had a great day today", "Not toxic"],
  ["Nobody likes you", "Toxic"],
  ["This is unacceptable. I want to speak to the manager.", "Not toxic"],
];

const [inputs, outputs] = labeledTexts.reduce<
  [Array<{ input: string }>, Array<{ outputs: string }>]
>(
  ([inputs, outputs], item) => [
    [...inputs, { input: item[0] }],
    [...outputs, { outputs: item[1] }],
  ],
  [[], []]
);

const datasetName = "Toxic Queries";
const toxicDataset = await langsmith.createDataset(datasetName);
await langsmith.createExamples({ inputs, outputs, datasetId: toxicDataset.id });
```

</CodeGroup>

关于 dataset 的更多细节，请参阅 [Manage datasets](/langsmith/manage-datasets)。

## 定义 evaluator

定义 evaluator 主要有两种方式。

### 在本地代码中定义

<Check>
你也可以看看 LangChain 的开源评估包 [openevals](https://github.com/langchain-ai/openevals)，里面提供了许多常见场景的预构建 evaluators。
</Check>

[Evaluators](/langsmith/evaluation-concepts#evaluators) 是给应用输出打分的函数。它们会接收 example inputs、实际 outputs，以及在存在时的 reference outputs。由于这个任务已经有标签，因此 evaluator 可以直接判断实际输出是否匹配 reference outputs。

- Python：需要 `langsmith>=0.3.13`
- TypeScript：需要 `langsmith>=0.2.9`

<CodeGroup>

```python Python
def correct(inputs: dict, outputs: dict, reference_outputs: dict) -> bool:
    return outputs["class"] == reference_outputs["label"]
```

```typescript TypeScript
import type { EvaluationResult } from "langsmith/evaluation";

function correct({
  outputs,
  referenceOutputs,
}: {
  outputs: Record<string, any>;
  referenceOutputs?: Record<string, any>;
}): EvaluationResult {
  const score = outputs.output === referenceOutputs?.outputs;
  return { key: "correct", score };
}
```

</CodeGroup>

### 在 LangSmith UI 中定义

你也可以直接在 [LangSmith UI](https://smith.langchain.com) 里定义 evaluator。你可以在 **Evaluators** 标签页中[创建 evaluators](/langsmith/llm-as-judge)。这些 evaluators 还可以[自动绑定到 dataset，在每次新 experiment 触发时自动运行](/langsmith/bind-evaluator-to-dataset)。


## 运行评估

我们会使用 [evaluate()](https://docs.smith.langchain.com/reference/python/evaluation/langsmith.evaluation._runner.evaluate) / [aevaluate()](https://docs.smith.langchain.com/reference/python/evaluation/langsmith.evaluation._arunner.aevaluate) 来运行评估。

关键参数包括：

* 一个 target function，它接收输入字典并返回输出字典。每个 [Example](/langsmith/example-data-format) 的 `example.inputs` 字段都会传给这个 target function。本例中，`toxicity_classifier` 本来就是按照 example inputs 结构编写的，因此可以直接使用。
* `data`：要评估的 LangSmith dataset 的名称或 UUID，也可以直接传入 example 迭代器。
* `evaluators`：一个 evaluator 列表，用于给函数输出打分；另外，在 [Langsmith UI](https://smith.langchain.com) 中绑定到 dataset 的 evaluators 也会自动触发。
* `metadata`：一个可选对象，会附加到 experiment 上。传入 `models`、`prompts` 和 `tools` keys，可以自动填充 experiment table view 对应的列。

Python：需要 `langsmith>=0.3.13`

<CodeGroup>

```python Python
# optional metadata, used to populate model/prompt/tool columns in UI
EXPERIMENT_METADATA = {
    "models": [
        "openai:gpt-5.4-mini",
        {
            "id": ["langchain", "chat_models", "openai", "ChatOpenAI"],
            "lc": 1,
            "type": "constructor",
            "kwargs": {"model_name": "gpt-5.5", "temperature": 0.2},
        },
    ],
    "prompts": ["my-org/my-eval-prompt:abc12345"],
    "tools": [
        {
            "name": "web_search",
            "description": "Search the web for information",
            "parameters": {
                "type": "object",
                "properties": {"query": {"type": "string"}},
                "required": ["query"],
            },
        },
    ],
}

# Can equivalently use the 'evaluate' function directly:
# from langsmith import evaluate; evaluate(...)
results = ls_client.evaluate(
    toxicity_classifier,
    data=dataset.name,
    evaluators=[correct],
    experiment_prefix="gpt-5.4-mini, baseline",  # optional, experiment name prefix
    description="Testing the baseline system.",  # optional, experiment description
    max_concurrency=4,  # optional, add concurrency
    metadata=EXPERIMENT_METADATA,  # optional, used to populate model/prompt/tool columns in UI
)
```

```typescript TypeScript

  data: datasetName,
  evaluators: [correct],
  experimentPrefix: "gpt-5.4-mini, baseline",  // optional, experiment name prefix

  metadata: EXPERIMENT_METADATA,  // optional, used to populate model/prompt/tool columns in UI
});
```

## 给 experiment 添加 metadata

Metadata 是一组附加在 experiment 上的 key-value pairs，用于在 experiments table 中分组和过滤 experiments。你既可以在运行 experiment 时通过 `metadata` 参数传入（见[运行评估](#run-the-evaluation)），也可以事后直接在 LangSmith UI 中补充。

要打开 **Edit Experiment** 面板，把鼠标悬停到 experiments table 中某一行 experiment 上，然后点击该行右侧出现的 **Edit** 铅笔图标。

<img
  className="block dark:hidden"

  alt="Experiments table with the edit pencil icon visible on a hovered row."
/>
<img
  className="hidden dark:block"

  alt="Experiments table with the edit pencil icon visible on a hovered row."
/>

**Edit Experiment** 面板允许你更新 experiment name 和 description，并管理 metadata key-value pairs。点击 **+ Add Metadata** 就能新增一组 key-value，然后点击右上角 **Submit** 保存修改。

<img
  className="block dark:hidden"
  src="/langsmith/images/edit-experiment-panel-light.png"
  alt="Edit Experiment panel showing metadata key-value pairs and the Add Metadata button."
/>
<img
  className="hidden dark:block"
  src="/langsmith/images/edit-experiment-panel-dark.png"
  alt="Edit Experiment panel showing metadata key-value pairs and the Add Metadata button."
/>

一旦 experiments 打上了 metadata，你就可以使用 experiments table 顶部的 **Group by** 控件，按任意 metadata 字段对 experiments 分组。表格上方的汇总图表也会按组更新，展示每组配置的平均反馈分数、延迟和 token 用量。这样你就可以非常直观地比较不同 prompt 版本、不同模型，或其他改动在同一 dataset 上的表现差异。

保留字 `models`、`prompts` 和 `tools` 会自动填充 experiments table 中对应的专用列。点击这些列里的值，可以直接按它们过滤或分组。完整说明请参阅[按 models、prompts 和 tools 过滤与分组](/langsmith/analyze-an-experiment#filter-and-group-by-models-prompts-and-tools-in-the-experiments-tab-view)。
