_自定义视图_ 会用你向 [LangSmith Chat](/langsmith/chat) 描述的一种展示方式，替换 [annotation queue](/langsmith/annotation-queues) 中间窗格中默认的 trace 视图。可以用它只向审核者展示评分所需的内容，例如不带 tool calls 的对话 transcript 或问答卡片。

自定义视图仅用于展示。它不能调用 LangSmith API 或网络，也不会更改条目列表、rubric 或审核者提交的 feedback。自定义视图是工作区资源，因此一个视图可以服务多个 queue。

自定义视图取代[自定义输出渲染](/langsmith/custom-output-rendering)，后者将被弃用。一个 queue 只能使用其中一种，不能同时使用两者。

<Note>
自定义视图在 LangSmith Cloud 上默认开启。在自托管 LangSmith 上，自定义视图需要 v0.18 或更高版本，并[启用 Chat](/langsmith/self-host-insights-chat)。
</Note>

## 要求

- 创建、编辑、重命名或移除某个 queue 的自定义视图，需要在该 queue 上拥有 `annotation-queues:update` 权限。
- 从工作区删除视图还需要 `annotation-queues:delete` 权限。
- 自定义视图仅适用于 [single-run annotation queues](/langsmith/annotation-queues#single-run-annotation-queues)，不适用于 pairwise queues。

## 创建自定义视图

要为某个 queue 创建自定义视图：

1. 打开该 annotation queue。
1. 在条目顶部打开 **Custom view** 开关。如果该 queue 还没有视图，窗格会显示 **No custom view configured for this annotation queue**。
1. 点击 **New custom view**。Chat 会打开并询问 **What should reviewers see?**
1. 描述你想要的视图，或选择一个建议，例如 **Show it as a chat conversation**、**Summarize as a Q&A card** 或 **Hide tool calls and system messages**。
1. 查看实时预览，它会渲染当前 queue 条目。继续在 Chat 中描述要做的更改，直到视图符合预期。
1. 点击 **Save**，在 **Name your custom view** 对话框中输入名称，然后点击 **Save view**。

在点击 **Save** 之前不会保存任何内容。要放弃草稿，请点击 **Cancel**。

一个视图会渲染 queue 中的每个条目。当一个 queue 同时包含 runs 和 threads 时，请让 Chat 处理这两种条目类型。

## 在多个 queue 之间复用视图

要附加工作区中已有的视图，请执行以下任一操作：

- 在空的自定义视图窗格中，点击 **Use an existing view** 并选择该视图。
- 在 queue 的设置中，于 **Custom View** 下从 **Select a custom view** 选择器中选择该视图。

当该 queue 开启[自定义输出渲染](/langsmith/custom-output-rendering#for-annotation-queues)时，设置中的选择器会被禁用。关闭自定义输出渲染后才能使用自定义视图。

## 编辑或管理视图

开启 **Custom view** 开关后，点击条目顶部的 **Edit** 打开视图菜单：

- **Edit current view**：带着已保存的视图重新打开 Chat，并描述要做的更改。
- **Rename view**：更改名称。新名称会显示在使用该视图的每个 queue 上。
- **New custom view**：为这个 queue 构建另一个视图。
- **Remove custom view**：从该 queue 分离视图。视图仍保留在工作区中，供其他 queue 使用。
- **Delete view**：从工作区删除该视图。这会将其从所有使用它的 queue 中移除，且无法撤销。

当你保存对其他 queue 也在使用的视图所做的编辑时，LangSmith 会询问如何应用这些更改：

- **Update for all queues**：在所有使用该共享视图的地方应用更改。
- **Save as new view**：保存一份仅由该 queue 使用的副本。

## 在默认视图和自定义视图之间切换

条目顶部的 **Custom view** 开关用于在默认 trace 视图和 queue 的自定义视图之间切换。当 queue 有自定义视图时，审核者会从该视图开始。LangSmith 会按 queue 记住每位审核者的选择。
