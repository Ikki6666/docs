sidebarTitle: 追踪 generator functions

在大多数 LLM 应用中，你都会希望通过流式输出尽量缩短用户看到第一个 token 的时间。

LangSmith 的 tracing 功能原生支持通过 `generator` functions 处理流式输出。下面是一个示例。

<CodeGroup>

```python Python
from langsmith import traceable
@traceable
def my_generator():
  for chunk in ["Hello", "World", "!"]:
      yield chunk
# Stream to the user
for output in my_generator():
  print(output)
# It also works with async functions
import asyncio
@traceable
async def my_async_generator():
  for chunk in ["Hello", "World", "!"]:
      yield chunk
# Stream to the user
async def main():
  async for output in my_async_generator():
      print(output)
asyncio.run(main())
```

```typescript TypeScript
import { traceable } from "langsmith/traceable";
const myGenerator = traceable(function* () {
  for (const chunk of ["Hello", "World", "!"]) {
      yield chunk;
  }
});
for (const output of myGenerator()) {
  console.log(output);
}
```

</CodeGroup>

## 聚合结果[ ](#aggregate-results "Direct link to aggregate results")

默认情况下，被追踪函数的 `outputs` 会在 LangSmith 中被聚合成一个单独的数组。如果你想自定义存储方式（例如把输出拼接成一个字符串），可以使用 `aggregate` 选项（Python 中为 `reduce_fn`）。这在聚合流式 LLM 输出时尤其有用。

<Note>
聚合输出**只会**影响在 tracing 中展示出来的输出形态。它**不会**改变函数实际返回的值。
</Note>

<CodeGroup>

```python Python
from langsmith import traceable
def concatenate_strings(outputs: list):
  return "".join(outputs)
@traceable(reduce_fn=concatenate_strings)
def my_generator():
  for chunk in ["Hello", "World", "!"]:
      yield chunk
# Stream to the user
for output in my_generator():
  print(output)
# It also works with async functions
import asyncio
@traceable(reduce_fn=concatenate_strings)
async def my_async_generator():
  for chunk in ["Hello", "World", "!"]:
      yield chunk
# Stream to the user
async def main():
  async for output in my_async_generator():
      print(output)
asyncio.run(main())
```

```typescript TypeScript
import { traceable } from "langsmith/traceable";
const concatenateStrings = (outputs: string[]) => outputs.join("");
const myGenerator = traceable(function* () {
  for (const chunk of ["Hello", "World", "!"]) {
      yield chunk;
  }
}, { aggregator: concatenateStrings });
for (const output of await myGenerator()) {
  console.log(output);
}
```

</CodeGroup>
