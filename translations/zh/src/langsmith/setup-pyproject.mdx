应用必须通过[配置文件](/langsmith/cli#configuration-file)进行配置，才能部署到 LangSmith，或用于自托管。本文介绍使用 `pyproject.toml` 定义包依赖并为部署完成应用设置的基本步骤。

本示例基于[这个仓库](https://github.com/langchain-ai/langgraph-example-pyproject)，它使用 LangGraph 框架。

最终的仓库结构大致如下：

```bash
my-app/
├── my_agent # 所有项目代码都位于此目录下
│   ├── utils # 你的 graph 所需的工具函数
│   │   ├── __init__.py
│   │   ├── tools.py # 你的 graph 使用的 tools
│   │   ├── nodes.py # node 函数
│   │   └── state.py # state 定义
│   ├── __init__.py
│   └── agent.py # 构建 graph 的代码
├── .env # 环境变量
├── langgraph.json  # LangGraph 的配置文件
└── pyproject.toml # 项目依赖
```

</Tip>

你也可以使用以下方式进行设置：

- `requirements.txt`：若使用它进行依赖管理，请参阅[这篇操作指南](/langsmith/setup-app-requirements-txt)，了解如何在 LangSmith 中使用 `requirements.txt`。
- monorepo：若要部署位于 monorepo 内的 graph，请参考[这个仓库](https://github.com/langchain-ai/langgraph-example-monorepo)中的示例做法。

在每一步之后，都会提供一个示例目录结构，演示代码可以如何组织。

依赖可以选择写入以下任一文件中：`pyproject.toml`、`setup.py` 或 `requirements.txt`。如果这些文件都没有创建，也可以稍后在[配置文件](#创建配置文件)中指定依赖。

## 定义 graphs

实现你的 graphs。Graph 可以定义在单个文件中，也可以拆分到多个文件中。请记下应用中要包含的每个 @[CompiledStateGraph] 的变量名。稍后创建[配置文件](/langsmith/cli#configuration-file)时会用到这些变量名。

示例 `agent.py` 文件，展示了如何导入你在其他模块中定义的内容，这些模块的具体代码此处未展示，请参阅[这个仓库](https://github.com/langchain-ai/langgraph-example-pyproject)查看实现：

```python
# my_agent/agent.py
from typing import Literal
from typing_extensions import TypedDict

from langgraph.graph import StateGraph, END, START
from my_agent.utils.nodes import call_model, should_continue, tool_node # import nodes
from my_agent.utils.state import AgentState # import state

# Define the runtime context
class GraphContext(TypedDict):
    model_name: Literal["anthropic", "openai"]

workflow = StateGraph(AgentState, context_schema=GraphContext)
workflow.add_node("agent", call_model)
workflow.add_node("action", tool_node)
workflow.add_edge(START, "agent")
workflow.add_conditional_edges(
    "agent",
    should_continue,
    {
        "continue": "action",
        "end": END,
    },
)
workflow.add_edge("action", "agent")

graph = workflow.compile()
```

│   │   ├── __init__.py

## 创建配置文件

创建一个名为 `langgraph.json` 的[配置文件](/langsmith/cli#configuration-file)。如需了解配置文件 JSON 对象中每个键的详细说明，请参阅[配置文件参考](/langsmith/cli#configuration-file)。

示例 `langgraph.json` 文件：

```json
{
  "dependencies": ["."],
  "graphs": {
    "agent": "./my_agent/agent.py:graph"
  },
  "env": ".env"
}
```

请注意，`CompiledGraph` 的变量名会出现在顶层 `graphs` 键中各子键值的末尾，也就是 `:<variable_name>` 这一部分。

<Warning>
    **配置文件位置**
    配置文件必须放在一个与包含已编译 graph 及其相关依赖的 Python 文件同级或更高层级的目录中。
</Warning>

示例目录结构：

```bash
my-app/
├── my_agent # 所有项目代码都位于此目录下
│   ├── utils # 你的 graph 所需的工具函数
│   │   ├── __init__.py
│   │   ├── tools.py # 你的 graph 使用的 tools
│   │   ├── nodes.py # node 函数
│   │   └── state.py # state 定义
│   ├── __init__.py
│   └── agent.py # 构建 graph 的代码
├── .env # 环境变量
├── langgraph.json  # LangGraph 的配置文件
└── pyproject.toml # 项目依赖
```
