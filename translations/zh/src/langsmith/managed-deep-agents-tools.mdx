Managed Deep Agents 支持标准 Deep Agents 的 `tools` 配置面。你可以在项目中定义 LangChain tools，把它们导入 `agent.py` 或 `agent.ts`，然后传给 `define_deep_agent` 或 `defineDeepAgent`。

</Note>

## 自编写 tools 与 connector tools

Managed Deep Agents 可以使用两类 tools：

| Tool 来源 | 配置位置 | 运行时行为 |
| --- | --- | --- |
| 自编写 tools | `agent.py` 或 `agent.ts` 从项目源代码导入 | Managed Deep Agents 会把源代码复制到编译后的 build，并把这些 tools 传给 Deep Agents。 |
| MCP connector tools | `connectors/mcp.py` 或 `connectors/mcp.ts` | Managed Deep Agents 会在运行时加载远程 MCP tools，并把它们追加到自编写 tools 后面。 |

自编写 tools 适合业务逻辑、私有 API、数据库访问，以及其他属于 agent 项目的代码。当工具能力由远程 MCP server 暴露时，请使用 [MCP connectors](/langsmith/managed-deep-agents-connectors/mcp)。

关于 LangChain tool 定义的更多信息，请参见 [Tools](/oss/langchain/tools)。

## 添加 tool 模块

将自定义 tool 代码放在项目的 `tools/` 目录下，并从 agent 入口中导入。完整项目布局请参见 [CLI project file reference](/langsmith/managed-deep-agents-cli#project-file-reference)。

<CodeGroup>

```python tools/customer.py
from langchain.tools import tool


@tool(parse_docstring=True)
def lookup_customer(customer_id: str) -> str:
    """Look up a customer record by ID.

    Args:
        customer_id: Customer ID from the CRM.
    """
    return f"Customer {customer_id} is on the enterprise plan."
```

```ts tools/customer.ts
import { tool } from "langchain";
import { z } from "zod";

export const lookupCustomer = tool(
  async ({ customerId }) => `Customer ${customerId} is on the enterprise plan.`,
  {
    name: "lookup_customer",
    description: "Look up a customer record by ID.",
    schema: z.object({
      customerId: z.string().describe("Customer ID from the CRM."),
    }),
  },
);
```

</CodeGroup>

## 将 tools 挂到 agent 上

把这些 tools 导入项目根目录下的 agent 入口，并放进 `tools` 列表中。

<CodeGroup>

```python agent.py
from managed_deepagents import define_deep_agent

from tools.customer import lookup_customer

agent = define_deep_agent(
    model="openai:gpt-5.5",
    tools=[lookup_customer],
)
```

```ts agent.ts
import { defineDeepAgent } from "managed-deepagents";

import { lookupCustomer } from "./tools/customer";

export const agent = defineDeepAgent({
  model: "openai:gpt-5.5",
  tools: [lookupCustomer],
});
```

</CodeGroup>

`mda dev` 和 `mda deploy` 会把项目文件复制到编译后的 build 中，因此 imports 行为应与普通本地 Python 或 TypeScript 项目一致。

<Tip>
请使用清晰且唯一的 tool 名称。MCP connector tools 会在自编写 tools 之后追加，connector 名称默认会作为前缀，避免命名冲突。
</Tip>

## 使用 secrets 和 context

Tools 可以通过环境变量读取 deployment secrets。本地开发时，把值写入 `.env`，供 `mda dev` 加载；部署时，`mda deploy` 会把非保留 `.env` 值转发为托管 deployment secrets。

当项目声明了 [identity](/langsmith/managed-deep-agents-identity) 时，tools 和 middleware 会收到一个包含已认证调用方信息的冻结 `runtime.identity` envelope。对于 actor 或 tenant ids，应优先使用它，而不是由客户端提供的可配置 keys。

对于 request metadata 或 feature flags 等其他按 run 变化的值，请使用标准 LangChain 工具运行时 context 模式。请参见 [how to access context from within your tools](/oss/langchain/tools#access-context)。
