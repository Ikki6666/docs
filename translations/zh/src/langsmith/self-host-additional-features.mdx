[自托管 LangSmith](/langsmith/self-hosted) 在基础安装之外还支持可选功能。请先完成 [Kubernetes 安装](/langsmith/kubernetes)。它已经包含可观测性和评估，以及 [Insights 和 Chat](/langsmith/self-host-insights-chat)。然后只遵循你的使用场景所需的指南。

## 选择附加功能

每个功能都有自己的配置指南。只遵循你所需功能的指南。当一个功能依赖另一个功能时，请先配置被依赖的功能。

- **[Sandboxes](/langsmith/enable-self-hosted-sandboxes)**：运行隔离的代码工作负载。其指南涵盖支持 KVM 的节点、JuiceFS 存储以及可选的 service URL。
- **[Engine](/langsmith/engine-self-hosted)**：诊断反复出现的问题并提出修复建议。Engine 需要 Sandboxes、带有 Engine entitlement 的 license、一个模型配置，以及 Helm chart 0.16.0 或更高版本。[隔离网络安装](/langsmith/engine-self-hosted#air-gapped-installations)和你自己的模型 providers 需要 Helm chart 0.17.0 或更高版本。
- **[Fleet](/langsmith/enable-self-hosted-fleet)**：创建和管理无代码 agents。其指南涵盖 Fleet 服务以及可选的 tools 和 triggers。
- **[LLM Gateway](/langsmith/llm-gateway-self-hosted)**：路由模型调用并应用策略。它需要 Helm chart 0.17.1 或更高版本。其指南涵盖服务连通性、provider 配置以及你的第一次 gateway 调用。
- **[LangSmith Deployment](/langsmith/deploy-self-hosted-full-platform)**：通过 LangSmith UI 部署和管理 Agent Servers。其指南涵盖 KEDA、ingress、控制平面和数据平面。
