---
title: 导入导出数据
description: 将 LangSmith 批量导出的 Parquet 数据导入到 BigQuery、Snowflake、Redshift、Clickhouse 或 DuckDB。
---

大多数分析系统都普遍支持从 S3 和 Parquet 格式导入数据。下面提供相关文档链接：

## BigQuery

如需将数据导入 BigQuery，请参阅 [Loading Data from Parquet](https://cloud.google.com/bigquery/docs/loading-data-cloud-storage-parquet) 以及
[Hive Partitioned loads](https://cloud.google.com/bigquery/docs/hive-partitioned-loads-gcs)。

## Snowflake

你可以按照 [Load from Cloud Document](https://docs.snowflake.com/en/user-guide/tutorials/load-from-cloud-tutorial) 将来自 S3 的数据加载到 Snowflake。

## RedShift

你可以按照 [AWS COPY command documentation](https://docs.aws.amazon.com/redshift/latest/dg/r_COPY.html)，从 S3 或 Parquet 中将数据 COPY 到 Amazon Redshift。

## Clickhouse

你可以在 Clickhouse 中直接查询 S3 / Parquet 格式的数据。例如，如果使用 GCS，可以像下面这样查询：

```sql
SELECT count(distinct id) FROM s3('https://storage.googleapis.com/<bucket>/<prefix>/export_id=<export_id>/**',
 'access_key_id', 'access_secret', 'Parquet')
```

更多信息请参阅 [Clickhouse S3 Integration Documentation](https://clickhouse.com/docs/en/engines/table-engines/integrations/s3)。

## DuckDB

你可以使用 DuckDB 在内存中通过 SQL 查询来自 S3 的数据。请参阅 [S3 import Documentation](https://duckdb.org/docs/guides/network_cloud_storage/s3_import.html)。
