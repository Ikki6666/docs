本指南介绍如何在 LangSmith 中跟踪和记录 [Google Gemini](https://ai.google.dev/gemini-api/docs) 模型。你将使用最新版 [`google-genai` SDK](https://googleapis.github.io/python-genai/)，Python，或 [`@google/genai` SDK](https://googleapis.github.io/js-genai/release_docs/index.html)，JavaScript，为 Gemini 调用添加跟踪，对 Gemini client 做 tracing 包装，并尝试一些示例，包括基础提示词、metadata 标记和多轮对话。

<Note>
LangSmith 的 Gemini wrappers 目前处于 **[beta](/langsmith/release-stages)** 阶段。API 在后续版本中可能会发生变化。
</Note>

## 安装

使用你喜欢的包管理器安装所需依赖：

<CodeGroup>

```bash pip
pip install langsmith google-genai
```

```bash npm
npm install langsmith@latest @google/genai
```

</CodeGroup>

## 设置

设置你的 [API keys](/langsmith/create-account-api-key) 和 project 名称：

```bash
export LANGSMITH_API_KEY=<your_langsmith_api_key>
export LANGSMITH_PROJECT=<your_project_name>
export LANGSMITH_TRACING=true
export GOOGLE_API_KEY=<your_google_api_key>
```

如需创建 Google API key，请参阅 [Google AI Studio](https://aistudio.google.com/apikey)。

## 配置 tracing

如需跟踪 Gemini API 调用，请使用 LangSmith 的 @[`wrap_gemini`][wrap_gemini]，Python，或 @[`wrapGemini`][wrapGemini]，JavaScript，包装函数。该 wrapper 会拦截对 Gemini client 的调用，并自动将它们作为 traces 记录到 LangSmith 中。它会在保留原始 client 全部功能的同时，增加 observability：

<CodeGroup>

```python Python
from google import genai
from langsmith import wrappers

def main():
    # genai.Client() reads GOOGLE_API_KEY / GEMINI_API_KEY from the environment
    gemini_client = genai.Client()

    # Wrap the Gemini client to enable LangSmith tracing
    client = wrappers.wrap_gemini(
        gemini_client,
        tracing_extra={
            "tags": ["gemini", "python"],
            "metadata": {
                "integration": "google-genai",
            },
        },
    )

    # Make a traced Gemini call
    response = client.models.generate_content(
        model="gemini-2.5-flash",
        contents="Explain quantum computing in simple terms.",
    )

    print(response.text)


if __name__ == "__main__":
    main()
```

```javascript JavaScript
import { GoogleGenAI } from "@google/genai";
import { wrapGemini } from "langsmith/wrappers/gemini";

const GEMINI_API_KEY = process.env.GEMINI_API_KEY;

// Initialize the Gemini client
const geminiClient = new GoogleGenAI({ apiKey: GEMINI_API_KEY });

// Wrap the client to enable LangSmith tracing
// Configuration is applied to ALL calls made with this wrapped client
const client = wrapGemini(geminiClient, {
  tags: ["gemini", "javascript"],
  metadata: {
    integration: "google-genai",
  },
});

// Make a traced call - tracing happens automatically
const response = await client.models.generateContent({
  model: "gemini-2.5-flash",
  contents: "Explain quantum computing in simple terms.",
});

console.log(response.text);
```

</CodeGroup>

<Tabs>
<Tab title="Python" icon="brand-python">

调用 `wrap_gemini()` 时，可通过传入 @[`tracing_extra`][wrap_gemini] 自定义 tracing。这个参数会应用到随后使用该 wrapped client 发起的所有请求，因此你可以为 traces 附加 tags 和 metadata，方便在 [LangSmith UI](https://smith.langchain.com) 中进行筛选和组织。`tracing_extra` 参数支持：

- `tags`：用于给 traces 分类的字符串列表，例如 `["production", "gemini"]`。
- `metadata`：用于补充上下文的键值对字典，例如 `{"team": "ml-research", "integration": "google-genai"}`。
- `client`：可选的自定义 LangSmith client 实例。

这些设置会一致地应用到 wrapped client 产生的所有 traces 上，因此你可以添加在整个应用中保持不变的环境级 tags 或团队 metadata。

</Tab>
<Tab title="JavaScript" icon="brand-javascript">

你可以通过向 @[`wrapGemini`][wrapGemini] 传入配置选项来自定义 tracing。这些选项会应用到随后使用该 wrapped client 发起的所有请求，因此你可以为 traces 附加 tags 和 metadata，方便在 [LangSmith UI](https://smith.langchain.com) 中进行筛选和组织。配置支持：

- `tags`：用于给 traces 分类的字符串数组，例如 `["production", "gemini"]`。
- `metadata`：用于补充上下文的键值对象，例如 `{ team: "ml-research", integration: "google-genai" }`。
- `client`：可选的自定义 LangSmith client 实例。

这些设置会一致地应用到 wrapped client 产生的所有 traces 上，因此你可以添加在整个应用中保持不变的环境级 tags 或团队 metadata。

## 在 LangSmith 中查看 traces

运行应用后，你可以在 [LangSmith UI](https://smith.langchain.com) 中查看包含以下内容的 traces：

- **Model requests**：发送给 Gemini 模型的完整提示词
- **Model responses**：生成文本和结构化输出
- **Function calls**：使用 function calling 时的工具调用及其结果
- **Chat sessions**：多轮对话上下文
- **Performance metrics**：延迟和 token 用量信息
