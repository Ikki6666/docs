本 quickstart 介绍如何使用 [`langgraph deploy`](/langsmith/cli#deploy) 命令将应用部署到 LangSmith Cloud（AWS 和 GCP）。只要你的应用通过 [`langgraph.json`](/langsmith/application-structure#configuration-file-concepts) 导出了 graph，无论你使用什么框架编写 agent，部署方式都相同。

<Tip>
如果你需要包含基于 GitHub 的部署方式和全部配置选项的完整 Cloud 部署指南，请参阅 [Cloud deployment setup guide](/langsmith/deploy-to-cloud)。
</Tip>

<Note>
`langgraph deploy` 命令目前处于 **[beta](/langsmith/release-stages)**。
</Note>

## 前置条件

开始前，请确认你已具备：

- 一个 [LangSmith 账户](https://smith.langchain.com)，且套餐为 [Plus 或以上](https://www.langchain.com/pricing)，并拥有 [API key](/langsmith/create-account-api-key)。
- 已安装并启动 [Docker](https://docs.docker.com/get-docker/)，可通过 `docker ps` 验证。
- 如果你使用 Apple Silicon（M1/M2/M3），还需要安装 [Docker Buildx](https://docs.docker.com/build/install-buildx/) 以交叉编译到 `linux/amd64`。
- [LangGraph CLI](/langsmith/cli)：

  ```shell
  uv tool install langgraph-cli
  ```

## 1. 创建可部署应用

`langgraph deploy` 可以部署任何在 `langgraph.json` 中导出 graph 的项目。请选择与你的 agent 编写方式对应的路径：

<Tabs>
    <Tab title="LangGraph template">
    使用 [`new-langgraph-project-python` 模板](https://github.com/langchain-ai/new-langgraph-project)创建一个新应用：

    ```shell
    langgraph new path/to/your/app --template new-langgraph-project-python
    cd path/to/your/app
    ```

    <Tip>
    如果你不带 `--template` 运行 `langgraph new`，会看到一个可交互的模板选择菜单。
    </Tip>
    </Tab>
    <Tab title="Bring your own framework">
    使用 Claude Agent SDK、Strands、CrewAI、AutoGen 或 Google ADK 编写的 agents，只要在 `langgraph.json` 中导出了 graph，也可以通过同一个 CLI 部署。完整示例请参阅[部署其他框架](/langsmith/deploy-other-frameworks)。当你的项目已经导出 graph 后，再回到这里继续剩余步骤。
    </Tab>
</Tabs>

## 2. 设置 API key

在项目根目录的 `.env` 文件中添加 LangSmith API key：

```shell
LANGSMITH_API_KEY=lsv2_...
```

`langgraph deploy` 会自动读取它。你也可以直接以内联方式传入：

```shell
LANGSMITH_API_KEY=lsv2_... langgraph deploy
```

## 3. 部署

你可以直接通过 CLI 部署，也可以通过 UI 部署。

<Tabs>
    <Tab title="Deploy from CLI">
    在项目目录中运行部署命令：

    ```shell
    langgraph deploy
    ```

    默认情况下，这会创建一个名为项目目录名的 `dev` deployment。你可以用 `--name` 或 `--deployment-type prod` 覆盖默认值。

    <Tip>
    当你修改代码后，如果想更新已有 deployment，只需再次运行 `langgraph deploy`。它会根据名称找到已有 deployment 并原地更新。
    </Tip>

    你还可以使用 `langgraph deploy list` 查看所有 deployments，使用 `langgraph deploy logs` 实时查看运行日志，或使用 `langgraph deploy delete <ID>` 删除某个 deployment。详见 [CLI reference](/langsmith/cli#deploy)。
    </Tab>
    <Tab title="Deploy from Studio">
    通过 Studio 部署：

    1. 启动[本地开发 server](/langsmith/local-dev-testing#langgraph-dev)。这会自动打开 [Studio](/langsmith/studio)，它是一个交互式 agent IDE。

    ```shell
    langgraph dev
    ```
    2. 点击 `deploy` 按钮。
    ![Deploy from Studio](/langsmith/images/deploy-from-studio.gif)
    </Tab>
</Tabs>

## 4. 在 Studio 中测试

[Studio](/langsmith/studio) 是直接连接到 deployment 的交互式 agent IDE。你可以在其中发送消息、查看每个节点的中间状态、在运行过程中编辑 state，并从任意历史 checkpoint 重新回放，而无需写代码。

当 deployment 准备就绪后：

1. 打开 [LangSmith](https://smith.langchain.com)，在左侧边栏选择 **Deployments**。
1. 选择你的 deployment 查看详情。
1. 点击右上角的 **Studio**，打开 [Studio](/langsmith/studio)。

## 5. 测试 API

从 deployment 详情页复制 **API URL**，然后用它调用你的应用：

<Tabs>
    <Tab title="Python SDK (Async)">
    1. 安装 LangGraph Python SDK：
        ```shell
        pip install langgraph-sdk
        ```
    2. 向 assistant 发送消息（无状态 run）：
        ```python
        from langgraph_sdk import get_client

        client = get_client(url="your-deployment-url", api_key="your-langsmith-api-key")

        async for chunk in client.runs.stream(
            None,  # Threadless run
            "agent", # assistant 名称，在 langgraph.json 中定义
            input={
                "messages": [{
                    "role": "human",
                    "content": "Say hello.",
                }],
            },
            stream_mode="updates",
        ):
            print(f"Receiving new event of type: {chunk.event}...")
            print(chunk.data)
            print("\n\n")
        ```
    </Tab>
    <Tab title="Python SDK (Sync)">
    1. 安装 LangGraph Python SDK：
        ```shell
        pip install langgraph-sdk
        ```
    2. 向 assistant 发送消息（无状态 run）：
        ```python
        from langgraph_sdk import get_sync_client

        client = get_sync_client(url="your-deployment-url", api_key="your-langsmith-api-key")

        for chunk in client.runs.stream(
            None,  # Threadless run
            "agent", # assistant 名称，在 langgraph.json 中定义
            input={
                "messages": [{
                    "role": "human",
                    "content": "Say hello.",
                }],
            },
            stream_mode="updates",
        ):
            print(f"Receiving new event of type: {chunk.event}...")
            print(chunk.data)
            print("\n\n")
        ```
    </Tab>
    <Tab title="JavaScript SDK">
    1. 安装 LangGraph JS SDK：
        ```shell
        npm install @langchain/langgraph-sdk
        ```
    2. 向 assistant 发送消息（无状态 run）：
        ```js
        const { Client } = await import("@langchain/langgraph-sdk");

        const client = new Client({ apiUrl: "your-deployment-url", apiKey: "your-langsmith-api-key" });

        const streamResponse = client.runs.stream(
            null, // Threadless run
            "agent", // Assistant ID
            {
                input: {
                    "messages": [
                        { "role": "user", "content": "Say hello."}
                    ]
                },
                streamMode: "messages",
            }
        );

        for await (const chunk of streamResponse) {
            console.log(`Receiving new event of type: ${chunk.event}...`);
            console.log(JSON.stringify(chunk.data));
            console.log("\n\n");
        }
        ```
    </Tab>
    <Tab title="Rest API">
    ```bash
    curl -s --request POST \
        --url <DEPLOYMENT_URL>/runs/stream \
        --header 'Content-Type: application/json' \
        --header "X-Api-Key: <LANGSMITH API KEY>" \
        --data "{
            \"assistant_id\": \"agent\",
            \"input\": {
                \"messages\": [
                    {
                        \"role\": \"human\",
                        \"content\": \"Say hello.\"
                    }
                ]
            },
            \"stream_mode\": \"updates\"
        }"
    ```
    </Tab>
</Tabs>
