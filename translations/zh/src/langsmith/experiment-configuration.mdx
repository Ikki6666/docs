LangSmith 为实验提供了若干配置选项：

- [重复次数](#repetitions)
- [并发](#concurrency)
- [缓存](#caching)

### Repetitions

_Repetitions_ 会多次运行同一个实验，以考虑 LLM 输出的波动性。由于 LLM 输出具有非确定性，多次重复可以提供更准确的性能估计。

你可以通过向 `evaluate` / `aevaluate` 传入 `num_repetitions` 参数来配置重复次数（[Python](https://reference.langchain.com/python/langsmith/evaluation/_runner/evaluate)，[TypeScript](https://reference.langchain.com/javascript/langsmith/evaluation/EvaluateOptions#member-numRepetitions-9)）。每次重复都会重新运行目标函数和所有 evaluators。

更多信息请参阅[重复次数 how-to 指南](/langsmith/repetition)。

### Concurrency

_Concurrency_ 用于控制实验期间同时运行多少个 examples。你可以通过传入 `max_concurrency` 参数来配置。该参数在这两个函数中的语义不同：

#### `evaluate`

`max_concurrency` 参数指定运行目标函数和 evaluators 时可使用的最大并发线程数。

#### `aevaluate`

`max_concurrency` 参数使用 semaphore 限制并发任务数。`aevaluate` 会为每个 example 创建一个 task，每个 task 运行该 example 的目标函数和所有 evaluators。`max_concurrency` 指定可同时处理的最大 example 数量。

### Caching

_Caching_ 会将 API 调用结果存储到磁盘，以加快未来实验的速度。请将 `LANGSMITH_TEST_CACHE` 环境变量设置为一个具有写权限的有效文件夹路径。之后，任何发起相同 API 调用的实验都会复用缓存结果，而不是重新发起请求。
