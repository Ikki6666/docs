在你迭代 LLM application 的过程中（例如更换模型或 prompt），你可能希望比较不同[_实验_](/langsmith/evaluation-concepts#experiment)的结果。

LangSmith 提供了比较视图，帮助你识别不同实验之间的关键差异、回归和改进。

## 打开比较视图

1. 若要进入实验比较视图，请前往 **Datasets & Experiments** 页面。
1. 选择一个数据集，这会打开 **Experiments** 标签页。
1. 选择两个或更多实验，然后点击 **Compare**。

### Filters

点击 <Icon icon="filter-2"/> 图标，可对比较视图应用过滤条件，从而缩小到特定 examples。常见过滤包括：

- 包含特定 `input` / `output` 的 examples。
- 状态为 `success` 或 `error` 的 runs。
- `latency` 超过 x 秒的 runs。
- 特定的 `metadata`、`tag` 或 `feedback`。

除了对整体实验视图应用过滤外，你也可以对单独的列应用过滤。点击任意列顶部的 <Icon icon="dots-vertical"/> 图标，即可查看该列数据支持的过滤条件。

### Columns

点击 <Icon icon="columns-3"/> 图标，可在比较视图中显示或隐藏单独的 feedback keys 或 metrics。

### 表格视图

在比较视图右上角可选择三种表格视图图标之一：

- **Compact**：展示每个 example 的实验结果预览。
- **Full**：显示每个 run 的完整输入、输出和参考输出文本。如果输出太长而无法在表格中完整显示，可点击 **Expand** 查看全部内容。
- **Diff**：显示每个 run 在实验输出之间的文本差异。该模式一次仅支持 2 个实验。更多细节请参阅[并排查看差异](#view-side-by-side-diffs)。

### 显示类型

内置提供三种实验视图，覆盖了多种显示类型：**Default**、**YAML**、**JSON**。

## 查看回归与改进

在比较视图中，红色高亮表示某个 run 相对于源实验在任意 feedback key 上发生了*回归*，绿色高亮表示发生了*改进*。在每个 feedback 列顶部，你可以看到有多少 runs 比源实验更好或更差。

点击每列顶部的回归或改进按钮，即可只显示在该实验中发生回归或改进的 runs。

## 并排查看差异

比较两个实验时，在 JSON 和 YAML 显示样式下，你可以开启 experiment diff mode 来比较实验输出。Diff mode 会高亮输出之间的修改，对于结构化输出的比较尤其有用。

## 更新源实验与指标

如果你想跟踪各实验间的回归情况，可以：

1. 在比较视图顶部，将鼠标悬停在某个实验图标上，并从下拉菜单中选择 **Set as source experiment**。你也可以通过这个下拉菜单添加或移除实验。默认情况下，第一个被选中的实验会作为源实验。

    <img
        className="block dark:hidden"

    <img

1. 在 **Feedback** 列中，你可以为每个 feedback key 配置“更高分是否更好”。这个偏好会被保存。默认情况下，系统认为更高分意味着更好。

## 展开详情面板

点击任意一行，即可打开该 example 在多个被比较实验之间的详情面板。

使用面板右上角的切换按钮，在两种模式间切换：

- **Details**：显示 feedback keys 和 scores、该 example 的指标汇总，以及每个实验的输入、输出、参考输出和属性。

    <img
        className="block dark:hidden"

    <img

- **Traces**：并排显示每个实验的 traces。

    <img

## 使用实验 metadata 作为图表标签

你可以基于[实验 metadata](/langsmith/filter-experiments-ui#background-add-metadata-to-your-experiments)配置图表的 x 轴标签。

在比较视图右上角的 **Charts** 下拉菜单中选择某个 metadata key，即可更改 x 轴标签。
