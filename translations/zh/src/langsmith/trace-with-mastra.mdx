[Mastra](https://mastra.ai/docs) 是一个用于构建 AI 驱动应用和智能体的 TypeScript 框架。借助 Mastra 的 [LangSmith exporter](https://mastra.ai/docs/observability/ai-tracing/exporters/langsmith)，你可以将 Mastra 智能体和工作流中的 traces 发送到 LangSmith，用于调试、评估和可观测性分析。

本指南介绍如何使用 Mastra 的 AI tracing system 将 Mastra 与 LangSmith 集成。

## 安装

安装 Mastra 和 LangSmith exporter：

```bash
npm install @mastra/core @mastra/langsmith @mastra/observability @mastra/libsql
```

## 设置

1. 设置你的 LangSmith API key，以及可选的 LangSmith project 名称：

    ```bash
    export LANGSMITH_API_KEY=<your_langsmith_api_key>
    export LANGCHAIN_PROJECT=<your_project_name> # optional
    ```

    <Tip>
    如果没有设置 [`LANGCHAIN_PROJECT`](/langsmith/log-traces-to-project)，traces 会发送到默认 project。
    </Tip>


1. 如果你计划使用 OpenAI 模型，还需要确保运行时可用的 OpenAI API key 已设置：

    ```bash
    export OPENAI_API_KEY=<your_openai_api_key>
    ```

1. 在你的项目目录中，创建以下项目结构和文件：

    ```
    src/
        mastra.ts
        agent.ts
        index.ts
    ```

## 使用 LangSmith exporter 配置 Mastra

Mastra tracing 直接在 `Mastra` 构造函数上进行配置。将以下内容加入 `mastra.ts` 文件：

```ts
import { Mastra } from "@mastra/core";
import { LibSQLStore } from "@mastra/libsql";
import { LangSmithExporter } from "@mastra/langsmith";

import { echoAgent } from "./agent";

export const mastra = new Mastra({
  agents: { echoAgent },

  storage: new LibSQLStore({
    url: "file:./mastra.db",
  }),

  observability: {
    configs: {
      langsmith: {
        serviceName: "mastra-langsmith-demo",
        exporters: [
          new LangSmithExporter({
            apiKey: process.env.LANGSMITH_API_KEY,
          }),
        ],
      },
    },
  },

  // Disable deprecated telemetry system
  telemetry: {
    enabled: false,
  },
});
```

- [Tracing 需要 storage](https://mastra.ai/docs/observability/ai-tracing/overview#basic-config)，即使 traces 是导出到外部系统也是如此。
- LangSmith exporter 会从环境变量中读取凭证。
- 这里禁用了[已弃用的 telemetry system](https://mastra.ai/docs/observability/overview#otel-tracing-deprecated)，以避免产生警告。
- 当 Mastra 运行在 Mastra server 之外时，不需要单独的 instrumentation 文件。
如需更多细节，请参阅 [Mastra docs](https://mastra.ai/docs/observability/ai-tracing/overview)。

### 定义一个智能体

为了兼容性，请使用[基于字符串的模型标识符](https://mastra.ai/models#basic-usage)。将以下代码加入 `agent.ts` 文件：

```ts
import { Agent } from "@mastra/core/agent";

export const echoAgent = new Agent({
  name: "echoAgent",
  instructions: "You are a helpful assistant.",
  model: "openai/gpt-4o-mini",
});
```

Mastra 会自动使用你配置好的 API keys 路由模型调用，并为每次调用采集 traces。

### 运行智能体

1. 将以下内容加入 `index.ts` 文件：

    ```ts
    import { mastra } from "./mastra";

    async function main() {
    const agent = mastra.getAgent("echoAgent");
    const result = await agent.generate("Say hello and explain what Mastra is.");
    console.log(result.text);
    }

    main();
    ```

1. 运行你的应用：

    ```bash
    npx ts-node src/index.ts
    ```

## 在 LangSmith 中查看 traces

运行智能体后：

1. 打开 [LangSmith UI](https://smith.langchain.com)。
1. 选择你的 project，例如 `LANGCHAIN_PROJECT` 的值。
1. 找到对应于 `echoAgent.generate` 的 trace。

你将能够检查：

- 模型输入和输出
- 智能体执行步骤
- 耗时和错误信息
