如果你在构建对话式 agent，或者任何多轮交互应用，LangSmith 会自动把你的 [runs](/langsmith/run-data-format) 归入 [_threads_](/langsmith/observability-concepts#threads)。查询 threads 可以帮助你回放完整对话、审计 agent 在不同会话中的行为、基于对话长度和延迟构建分析，以及为[微调](/langsmith/smithtune)和评估等下游流程提供输入。

SDK 提供了两种处理 threads 的方法：

| 方法 | 使用场景 |
|--------|-------------|
| `client.threads.query()` ([Python](https://reference.langchain.com/python/langsmith/resources/threads/threads/AsyncThreadsResource/query), [TypeScript](https://reference.langchain.com/javascript/langsmith/client/Langsmith/Threads/query)) | 你想浏览项目中的 threads |
| `client.threads.list_traces()` / `client.threads.listTraces()` ([Python](https://reference.langchain.com/python/langsmith/resources/threads/threads/AsyncThreadsResource/list_traces), [TypeScript](https://reference.langchain.com/javascript/langsmith/client/Langsmith/Threads/listTraces)) | 你已经知道 thread ID，并且需要读取其中的 traces |

两个方法都需要 project ID。如果你只有项目名称，请先用 `aread_project()` / `readProject()` 查出 ID，下面的示例就是这样做的。在 Python 中，这两个方法都是异步的。

<Note>
要查询某个 agent、某个 experiment 或 evaluators 的 threads，请[查找其 project ID](/langsmith/resolve-an-agent)，并将其作为 project ID 传入。
</Note>

<Note>
这些方法取代了已弃用的 `list_threads` / `listThreads` 和 `read_thread` / `readThread`。LangSmith Cloud 将于 2027 年 1 月 31 日移除它们，自托管 LangSmith 将在 v0.19 中移除它们。新方法要求 `langsmith>=0.10.15`（Python）或 `langsmith>=0.8.9`（TypeScript），在自托管 LangSmith 上还要求 v0.16 或更高版本。完整的变更列表请参阅[迁移指南](/langsmith/smithdb-sdk-migration-threads)。
</Note>

## Threads 的工作原理

你创建的每个 run 都可以在其 metadata 中携带一个 `thread_id`。LangSmith 会基于这个字段把 runs 归组为 threads。后端会先在 `metadata` 中查找 `thread_id`，找不到时再回退到 `session_id`。

<Note>
建议使用 **UUID v7** 作为 thread ID。UUIDv7 内嵌时间戳，能够保留 threads 的正确时间顺序。LangSmith SDK 导出了一个 `uuid7` helper（Python v0.4.43+，JS v0.3.80+）：

- **Python**: `from langsmith import uuid7`
- **JS/TS**: `import { uuid7 } from 'langsmith'`
</Note>

如果你在使用 [tracing integration](/langsmith/integrations)，请在 run metadata 中传入 `thread_id`：

<CodeGroup>

```python Python
from langsmith import traceable, uuid7

THREAD_ID = str(uuid7())

@traceable(metadata={"thread_id": THREAD_ID})
def my_agent(user_message: str) -> str:
    ...
```

```typescript TypeScript
import { traceable } from "langsmith/traceable";
import { uuid7 } from "langsmith";

const THREAD_ID = uuid7();

const myAgent = traceable(
  async (userMessage: string) => {
    // ...
  },
  { metadata: { thread_id: THREAD_ID } }
);
```

</CodeGroup>

## 列出项目中的 threads

`threads.query` 返回项目中的 threads，每个 thread 一行，并带有其聚合数据。结果通过 cursor 分页；SDK 会替你逐页遍历。

<CodeGroup>

```python Python
import asyncio

from langsmith import Client


async def main():
    client = Client()
    project = await client.aread_project(project_name="my-project")

    async for thread in client.threads.query(project_id=str(project.id)):
        print(thread.thread_id)
        print(f"  {thread.count} traces")
        print(f"  last active: {thread.max_start_time}")


asyncio.run(main())
```

```typescript TypeScript
import { Client } from "langsmith";

const client = new Client();
const project = await client.readProject({ projectName: "my-project" });

for await (const thread of client.threads.query({ project_id: project.id })) {
  console.log(thread.thread_id);
  console.log(`  ${thread.count} traces`);
  console.log(`  last active: ${thread.max_start_time}`);
}
```

</CodeGroup>

```text Output
conv-abc123
  3 traces
  last active: 2026-02-25T10:05:42+00:00
conv-def456
  1 traces
  last active: 2026-02-25T09:30:00+00:00
```

### 参数

| 参数 | 类型 | 默认值 | 说明 |
|-----------|------|---------|-------------|
| `project_id` | `string` | — | **必填。** 项目 ID。 |
| `min_start_time` | `datetime` / ISO `string` | 1 天前 | 只包含 traces 在此时间之后启动的 threads。如需看到更早的 threads，请扩大这个时间窗口。 |
| `max_start_time` | `datetime` / ISO `string` | 当前时间 | 只包含 traces 在此时间之前启动的 threads。 |
| `filter` | `string` | — | 针对每个 thread 的 root runs 求值的过滤表达式，语法见 [LangSmith trace query syntax](/langsmith/trace-query-syntax)。 |
| `page_size` | `int` | — | 每页的 thread 数量。 |
| `cursor` | `string` | — | 手动分页时用于获取下一页的 cursor。 |

### 返回值

`Thread` 对象的异步迭代器。最常用的字段如下：

| 字段 | 类型 | 说明 |
|-------|------|-------------|
| `thread_id` | `string` | thread 标识符。 |
| `count` | `int` | 此 thread 中的 trace 数量。 |
| `min_start_time` | `datetime`（Python）/ `string`（TypeScript） | 最早一条 trace 的时间戳。 |
| `max_start_time` | `datetime`（Python）/ `string`（TypeScript） | 最近一条 trace 的时间戳。 |
| `first_trace_id`, `last_trace_id` | `string` | 查询窗口内该 thread 的第一条和最后一条 trace。 |
| `first_inputs`, `last_outputs` | `string` | 首个输入和最后一个输出的截断预览。 |
| `last_error`, `num_errored_turns` | `string`, `int` | 最后一条错误消息，以及出错的 trace 数量。 |
| `total_tokens`, `total_cost` | `int`, `number` | 整个 thread 的 token 和成本总计。 |
| `latency_p50`, `latency_p99` | `number` | 该 thread 各条 traces 的延迟百分位数。 |
| `feedback_stats` | `object` | 该 thread 的 feedback 聚合结果。 |

`Thread` 对象不包含其 runs。要获取 runs，请用 `thread_id` 调用 `threads.list_traces`。

## 读取单个 thread 的 traces

当你已经知道 `thread_id` 时，请使用 `threads.list_traces` / `threads.listTraces`。它会按 `start_time` 升序返回该 thread 的 traces（root runs）。

<CodeGroup>

```python Python
import asyncio

from langsmith import Client


async def main():
    client = Client()
    project = await client.aread_project(project_name="my-project")

    async for trace in client.threads.list_traces(
        "conv-abc123",
        project_id=str(project.id),
        selects=["TRACE_ID", "NAME", "START_TIME"],
    ):
        print(trace.trace_id, trace.name, trace.start_time)


asyncio.run(main())
```

```typescript TypeScript
import { Client } from "langsmith";

const client = new Client();
const project = await client.readProject({ projectName: "my-project" });

for await (const trace of client.threads.listTraces("conv-abc123", {
  project_id: project.id,
  selects: ["TRACE_ID", "NAME", "START_TIME"],
})) {
  console.log(trace.trace_id, trace.name, trace.start_time);
}
```

</CodeGroup>

每个条目都是轻量的 `ThreadTrace`，而不是完整的 run。只有 `selects` 中列出的字段会被填充；不传 `selects` 时只会得到 `trace_id`。要获取某条 trace 的 child runs（工具调用、子链），请使用 [`traces.list_runs`](/langsmith/smithdb-sdk-migration-traces)。

### 参数

| 参数 | 类型 | 默认值 | 说明 |
|-----------|------|---------|-------------|
| `thread_id` | `string` | — | **必填。** 要读取的 thread，作为第一个位置参数传入。 |
| `project_id` | `string` | — | **必填。** 项目 ID。 |
| `selects` | `string[]` | `["TRACE_ID"]` | 要返回的字段。如果你还需要 `TRACE_ID` 与其他字段一起返回，请一并列出。例如 `NAME`、`START_TIME`、`END_TIME`、`LATENCY`、`INPUTS`、`OUTPUTS`、`INPUTS_PREVIEW`、`OUTPUTS_PREVIEW`、`ERROR`、`TOTAL_TOKENS`、`TOTAL_COST`。 |
| `filter` | `string` | — | 针对每条 trace 的 root run 求值的过滤表达式。 |
| `page_size` | `int` | — | 每页的 trace 数量。 |
| `cursor` | `string` | — | 手动分页时用于获取下一页的 cursor。 |

### 返回值

`ThreadTrace` 对象的异步迭代器，按 `start_time` 升序排列。

## 示例

下面的代码片段延续上文的示例：在 Python 中，请在同一个 `async def main()` 内运行它们，此时 `client` 和 `project` 已经设置好。

### 按 run 属性过滤 threads

传入过滤表达式，可以使用 [LangSmith trace query syntax](/langsmith/trace-query-syntax) 缩小结果范围。例如，只返回至少包含一个失败 run 的 threads：

<CodeGroup>

```python Python
async for thread in client.threads.query(
    project_id=str(project.id),
    filter='eq(status, "error")',
):
    print(thread.thread_id, thread.last_error)
```

```typescript TypeScript
for await (const thread of client.threads.query({
  project_id: project.id,
  filter: 'eq(status, "error")',
})) {
  console.log(thread.thread_id, thread.last_error);
}
```

</CodeGroup>

### 查询超过 24 小时之前的数据

默认情况下，`threads.query` 只会展示最近一天内有 traces 的 threads。你可以传入 `min_start_time` 来扩大时间窗口：

<CodeGroup>

```python Python
from datetime import datetime, timedelta, timezone

async for thread in client.threads.query(
    project_id=str(project.id),
    min_start_time=datetime.now(timezone.utc) - timedelta(days=2),
):
    print(thread.thread_id)
```

```typescript TypeScript
for await (const thread of client.threads.query({
  project_id: project.id,
  min_start_time: new Date(Date.now() - 2 * 24 * 60 * 60 * 1000).toISOString(),
})) {
  console.log(thread.thread_id);
}
```

</CodeGroup>

### 重建一段对话

`threads.list_traces` 按从旧到新的顺序返回 traces，因此你可以逐轮回放一段对话。选择 `INPUTS` 和 `OUTPUTS` 可以获取完整的 payload：

<CodeGroup>

```python Python
async for trace in client.threads.list_traces(
    "conv-abc123",
    project_id=str(project.id),
    selects=["INPUTS", "OUTPUTS"],
):
    user_msg = (trace.inputs or {}).get("messages", [{}])[-1].get("content", "")
    assistant_msg = (trace.outputs or {}).get("content", "")
    print(f"User:      {user_msg}")
    print(f"Assistant: {assistant_msg}")
    print()
```

```typescript TypeScript
for await (const trace of client.threads.listTraces("conv-abc123", {
  project_id: project.id,
  selects: ["INPUTS", "OUTPUTS"],
})) {
  const inputs = trace.inputs as { messages?: Array<Record<string, string>> } | undefined;
  const outputs = trace.outputs as Record<string, string> | undefined;
  const messages = inputs?.messages ?? [];
  const userMsg = messages.at(-1)?.content ?? "";
  const assistantMsg = outputs?.content ?? "";
  console.log(`User:      ${userMsg}`);
  console.log(`Assistant: ${assistantMsg}`);
}
```

</CodeGroup>
