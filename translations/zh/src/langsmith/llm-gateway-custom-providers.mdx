---

<Note>
**Private beta:** LLM Gateway 当前处于私有 [beta](/langsmith/release-stages) 阶段。你可以加入[候补名单](https://www.langchain.com/langsmith-llm-gateway-waitlist)来申请访问权限。
</Note>

除了[内置 providers](/langsmith/llm-gateway#supported-providers)之外，LLM Gateway 还可以把请求代理到**任意 OpenAI-compatible endpoint**，例如通过推理服务器（如 vLLM、Ollama 等）提供的自托管开源模型。

## 工作方式

自定义 provider 由一个 **OpenAI Compatible Endpoint** [模型配置](/langsmith/model-configurations) 定义。你需要在 [LangSmith UI](https://smith.langchain.com) 的 **Settings → Model configurations** 下保存该配置。Gateway 会使用该配置中的以下选项：

- 一个 **base URL**：gateway 将请求转发到的上游 endpoint。
- 一个 **model name**：会被注入到每次请求中，因此调用方无需再显式指定。
- 一个 **API key**：作为[工作区 secret](/langsmith/llm-gateway-admin-setup#2-add-provider-secrets)保存，永远不会由客户端直接发送。

然后你可以通过 `https://gateway.smith.langchain.com/providers/{configName}` 这条路由，按名称访问该已保存配置。当请求到达时，gateway 会查找配置、解析 secret，并把调用代理到配置中指定的上游 URL。

<Note>
`{configName}` 指的是你工作区中[模型配置](/langsmith/model-configurations)的配置名称。如果名称中包含 URL 不安全字符（例如 `/` 或空格），请在路径中对它做 URL 编码。例如，一个名为 `meta-llama/Llama-3.1-8B-Instruct` 的配置，会变成 `https://gateway.smith.langchain.com/providers/meta-llama%2FLlama-3.1-8B-Instruct/v1/chat/completions`。
</Note>

## 1. 创建自定义 provider 配置

1. 在 **Settings → Integrations → Provider Secrets** 下，把上游 endpoint 的 API key 添加为工作区 secret。请使用一个有描述性的名称，例如 `MY_PROVIDER_API_KEY`。
1. 前往 **Settings → Model configurations**，并以 **OpenAI Compatible Endpoint** 作为 provider 创建一个配置。
1. 将 **Base URL** 设置为你的上游 endpoint，例如 `https://my-inference-server.example.com/v1`，并把 **Model Name** 设置为该 endpoint 所期望的模型标识符。
1. 将 **API Key Name** 设置为你刚创建的 secret。
1. 用一个**名称**保存该配置。之后你会在 gateway 路由中使用这个名称。

<Note>
每个配置都会固定到单个模型，因为 gateway 会使用配置中的值覆盖请求体里的 `model` 字段。若要通过同一个 endpoint 提供多个模型，请为每个模型分别创建一个配置，每个配置都拥有自己的名称和 `/providers/{configName}` 路由。
</Note>

## 2. 发起调用

按名称调用已保存配置。路由格式为 `https://gateway.smith.langchain.com/providers/{configName}`，其中 `{configName}` 就是你在 **Settings → Model configurations** 中保存的配置名称（下面示例中的 `my-custom-endpoint`）。

```bash
curl https://gateway.smith.langchain.com/providers/my-custom-endpoint/v1/chat/completions \
    -H "Authorization: Bearer $LANGSMITH_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{"messages":[{"role":"user","content":"ping"}]}'
```

Gateway 会用已保存配置中的模型名覆盖请求体里的 `model` 字段，因此你从客户端传入的该值会被忽略。

## 支持的 endpoints

自定义 providers 采用与内置 OpenAI provider 相同的 allowlist：`POST /v1/chat/completions`（包括 streaming）、`POST /v1/responses`，以及 `GET /v1/models` 列表端点。任何其他路径都会返回 `501 Not Implemented`。
