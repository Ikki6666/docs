[GCP Terraform modules](https://github.com/langchain-ai/terraform/tree/main/modules/gcp) 公开的每个输入变量的完整参考。首次填写 `terraform.tfvars` 或调整现有部署时可以使用本页。

变量分为两类：

- **非敏感**（region、规格、feature 开关）：在 `infra/terraform.tfvars` 中设置。
- **敏感**（license key、密码、加密 key）：通过 `infra/scripts/setup-env.sh` 载入，该脚本将它们写入 Google Secret Manager，并导出供 Terraform 和 Helm 步骤使用。

端到端安装请参阅[部署指南](/langsmith/self-host-terraform-gcp-deploy)。module 之间如何协同，请参阅[架构参考](/langsmith/self-host-terraform-gcp-architecture)。

## Core

| 变量 | 默认值 | 必填 | 描述 |
|---|---|---|---|
| `project_id` | — | 是 | 创建资源所在的 GCP project ID。 |
| `region` | `us-west2` | 否 | regional 资源使用的 GCP region。 |
| `zone` | `us-west2-a` | 否 | zonal 资源使用的 GCP zone。 |
| `environment` | `prod` | 否 | 应用到 label 的环境名称：`dev`、`staging` 或 `prod`。 |
| `name_prefix` | `ls` | 否 | 所有资源名称的前缀。1 到 11 个字符，以小写字母开头；只能包含小写字母、数字和连字符。 |
| `unique_suffix` | `true` | 否 | 在资源名称后追加随机后缀。多租户项目推荐使用。 |
| `owner` | `platform-team` | 否 | 应用到所有资源的 owner label。 |
| `cost_center` | `""` | 否 | 用于计费归因的 cost center label。 |
| `labels` | `{}` | 否 | 应用到所有资源的额外 label。 |

## 网络

| 变量 | 默认值 | 必填 | 描述 |
|---|---|---|---|
| `subnet_cidr` | `10.0.0.0/20` | 否 | GKE subnet 的 CIDR。不得与现有范围重叠。 |
| `pods_cidr` | `10.4.0.0/14` | 否 | GKE pods 的 CIDR。不得与 subnet 或 services 范围重叠。 |
| `services_cidr` | `10.8.0.0/20` | 否 | GKE services 的 CIDR。不得与 subnet 或 pods 范围重叠。 |
| `gke_master_authorized_cidrs` | `[]` | 否 | 允许访问 GKE control plane endpoint 的外部 CIDR。留空时 control plane 保持公网可达，Terraform 管理的 Helm 和 `kubectl` 步骤可以从任何 apply 主机运行。生产环境应填入 operator 和 CI 的出口 CIDR。 |

## GKE

| 变量 | 默认值 | 必填 | 描述 |
|---|---|---|---|
| `gke_use_autopilot` | `false` | 否 | 使用 GKE Autopilot 模式。Autopilot 始终使用 Dataplane V2。 |
| `gke_node_count` | `2` | 否 | 每个 zone 的初始节点数（仅 Standard 模式）。 |
| `gke_min_nodes` | `2` | 否 | 自动扩缩容时每个 zone 的最小节点数。 |
| `gke_max_nodes` | `10` | 否 | 自动扩缩容时每个 zone 的最大节点数。 |
| `gke_machine_type` | `e2-standard-4` | 否 | GKE 节点机型（例如 `e2-standard-4`、`n2-standard-8`）。 |
| `gke_disk_size` | `100` | 否 | 节点磁盘大小（GB）。 |
| `gke_release_channel` | `REGULAR` | 否 | GKE release channel：`RAPID`、`REGULAR` 或 `STABLE`。 |
| `gke_deletion_protection` | `true` | 否 | 为 GKE 集群启用删除保护。 |
| `gke_network_policy_provider` | `DATA_PLANE_V2` | 否 | 网络策略提供方：`CALICO`（旧版）或 `DATA_PLANE_V2`（基于 Cilium，推荐）。 |

## PostgreSQL（Cloud SQL）

| 变量 | 默认值 | 必填 | 描述 |
|---|---|---|---|
| `postgres_source` | `external` | 否 | `external`（带私有 IP 的 Cloud SQL）或 `in-cluster`（通过 Helm 部署）。 |
| `postgres_version` | `POSTGRES_15` | 否 | Cloud SQL PostgreSQL 版本。 |
| `postgres_tier` | `db-custom-2-8192` | 否 | Cloud SQL 机器层级（例如 `db-f1-micro`、`db-custom-2-8192`）。 |
| `postgres_disk_size` | `50` | 否 | Cloud SQL 磁盘大小（GB）。 |
| `postgres_high_availability` | `true` | 否 | 启用 Cloud SQL HA（regional 备用实例）。 |
| `postgres_deletion_protection` | `true` | 否 | 为 Cloud SQL 启用删除保护。 |
| `postgres_database_flags` | 见描述 | 否 | 在 Cloud SQL 实例上设置的 database flags。默认为 `max_connections = 500`，外加 checkpoint 和连接日志 flags。 |
| `postgres_ssl_mode` | `ENCRYPTED_ONLY` | 否 | Cloud SQL SSL 强制策略。`ENCRYPTED_ONLY` 要求每个连接都使用 TLS。`ALLOW_UNENCRYPTED_AND_ENCRYPTED` 接受明文。`TRUSTED_CLIENT_CERTIFICATE_REQUIRED` 还要求客户端证书。 |
| `postgres_password` | `""` | external 时 | Cloud SQL 密码。通过 `TF_VAR_postgres_password` 设置，或由 `setup-env.sh` 存入 Secret Manager。 |

## Ingress 与 TLS

| 变量 | 默认值 | 必填 | 描述 |
|---|---|---|---|
| `install_ingress` | `true` | 否 | 通过 Terraform 安装 ingress controller。Gateway 仅支持 HTTPS，因此 `tls_certificate_source` 必须是 `letsencrypt` 或 `existing`。 |
| `ingress_type` | `envoy` | 否 | Ingress 类型：`envoy`（已实现），或 `istio` / `other`（预留）。 |
| `tls_certificate_source` | `none` | 否 | `none`、`letsencrypt`（通过 cert-manager 自动签发）或 `existing`（提供自己的证书）。 |
| `install_cert_manager` | `false` | 否 | 安装 cert-manager 以使用 Let's Encrypt 证书。 |
| `letsencrypt_email` | `""` | 使用 `letsencrypt` 时 | 接收 Let's Encrypt 通知的 email。 |
| `tls_certificate_crt` | `""` | 使用 `existing` 时 | TLS 证书（PEM）。使用 `file()` 加载。 |
| `tls_certificate_key` | `""` | 使用 `existing` 时 | TLS 私钥（PEM）。使用 `file()` 加载。 |
| `tls_secret_name` | `langsmith-tls` | 否 | Kubernetes 中 TLS secret 的名称。 |

## 规格与 feature 开关

Terraform `app` 层和 Helm 部署脚本会读取这些开关，以启用对应的 chart 组件并预配各功能专属的数据库。部署脚本读取 `sizing_profile` 来选择 Helm 规格 overlay。

| 变量 | 默认值 | 必填 | 描述 |
|---|---|---|---|
| `sizing_profile` | `default` | 否 | Helm 规格：`production`（约 20 用户、约 100 traces/秒）、`production-large`（约 50 用户、约 1000 traces/秒）、`dev`（单副本）、`minimum`（成本占位下限，不适用于生产）或 `default`（chart 默认值）。 |
| `enable_deployments` | `false` | 否 | 启用 LangSmith Deployment（listener、operator、host-backend）。需要 license 中的 Deployments entitlement。 |
| `enable_agent_builder` | `false` | 否 | 启用 Agent Builder。需要 `enable_deployments = true` 和 Agent Builder entitlement。 |
| `enable_insights` | `false` | 否 | 启用 Insights（基于 ClickHouse 的分析）。需要 Insights entitlement。 |
| `enable_polly` | `false` | 否 | 启用 Polly（AI 评估与监控）。需要 `enable_deployments = true` 和 Polly entitlement。 |
| `enable_fleet` | `false` | 否 | 启用 Fleet 独立部署（chart v0.15+）。不要求 `enable_deployments`。从 `enable_agent_builder` 迁移时复用 `langsmith_agent_builder_encryption_key`。 |
| `enable_standalone_polly` | `false` | 否 | 启用 Polly 独立部署（chart v0.15+）。不要求 `enable_deployments`。复用 `langsmith_polly_encryption_key`。 |
| `enable_standalone_insights` | `false` | 否 | 启用 Insights 独立部署（chart v0.15+）。不要求 `enable_deployments`。复用 `langsmith_insights_encryption_key`。 |
| `enable_usage_telemetry` | `false` | 否 | 启用扩展使用量 telemetry 上报（`PHONE_HOME_USAGE_REPORTING_ENABLED`）。 |

## 敏感值（使用 `setup-env.sh` 设置）

运行 source 载入 `infra/scripts/setup-env.sh` 会将这些值写入 Google Secret Manager，并导出到当前 shell 供 Terraform 和 Helm 步骤使用。绝不要在 `terraform.tfvars` 中内联设置这些值。

| 变量 | 描述 |
|---|---|
| `langsmith_license_key` | LangSmith 企业版 license key。 |
| `langsmith_admin_password` | 初始组织 admin 密码。 |
| `langsmith_api_key_salt` | 用于哈希 API key 的 salt。首次部署后必须保持稳定。 |
| `langsmith_jwt_secret` | 用于 Basic Auth 会话的 JWT secret。必须保持稳定。 |
| `langsmith_deployments_encryption_key` | LangSmith Deployment 的 Fernet key。绝不能更改。 |
| `langsmith_agent_builder_encryption_key` | Agent Builder 的 Fernet key。绝不能更改。 |
| `langsmith_insights_encryption_key` | Insights 的 Fernet key。绝不能更改。 |
| `langsmith_polly_encryption_key` | Polly 的 Fernet key。绝不能更改。 |
