当你无法以编程方式评估系统时，使用 LLM-as-a-judge evaluators 会非常有帮助。不过，它们的效果取决于自身质量，以及它们与人工评审反馈的对齐程度。LangSmith 提供了借助 few-shot examples 来提升 LLM-as-a-judge evaluator 与人工偏好对齐能力的方式。

人工修正会以 few-shot examples 的形式自动插入到 evaluator prompt 中。Few-shot examples 是一种受 [few-shot prompting](https://www.promptingguide.ai/techniques/fewshot) 启发的技术，它通过少量高质量示例来引导模型输出。

本指南将介绍如何把 few-shot examples 作为 LLM-as-a-judge evaluator 的一部分进行设置，并将其应用到反馈分数修正中。

## How few-shot examples work

* Few-shot examples 会通过 `{{Few-shot examples}}` 变量添加到 evaluator prompt 中。
* 创建带 few-shot examples 的 evaluator 时，会自动为你创建一个 dataset。一旦你开始做修正，这个 dataset 会被自动填充为 few-shot examples。
* 在运行时，这些 examples 会被插入到 evaluator 中，作为其输出的指导。这会帮助 evaluator 更好地与人工偏好对齐。

## Configure your evaluator

<Note>
Few-shot examples 目前不支持使用 prompt hub 的 LLM-as-a-judge evaluators，并且只兼容使用 mustache formatting 的 prompts。

Few-shot examples 只支持 run-level evaluators，不支持 thread-level。在 [**Configure Evaluator** panel](/langsmith/evaluators#edit-an-evaluator) 中请打开 **Runs** 开关。
</Note>

在启用 few-shot examples 之前，请先设置好你的 LLM-as-a-judge evaluator。如果你还没有设置，请先按照 [LLM-as-a-judge evaluator guide](/langsmith/llm-as-judge) 中的步骤完成。

### 1. Configure variable mapping

每个 few-shot example 都会按照配置中指定的 variable mapping 进行格式化。Few-shot examples 的 variable mapping 应当包含与你主 prompt 相同的变量，另外再加上 `few_shot_explanation` 和一个 `score` 变量，该变量名应与 feedback key 保持一致。

例如，如果你的主 prompt 变量有 `question` 和 `response`，而 evaluator 输出的是 `correctness` 分数，那么 few-shot prompt 就应包含 `question`、`response`、`few_shot_explanation` 和 `correctness` 这些变量。

### 2. Specify the number of few-shot examples to use

你还可以指定要使用的 few-shot examples 数量。默认值为 5。如果 examples 很长，你可能希望把这个数调低以节省 tokens；而如果 examples 通常较短，你可以把它设得更高，以给 evaluator 更多可学习的示例。如果 dataset 中的 examples 数量超过这个值，我们会为你随机选择。

## Make corrections

<Info>
[Audit evaluator scores](/langsmith/audit-evaluator-scores)
</Info>

当你开始记录 traces 或运行 experiments 后，你很可能会不同意 evaluator 给出的某些分数。当你[对这些分数进行修正](/langsmith/audit-evaluator-scores)时，你会开始在 corrections dataset 中看到已填充的 examples。进行修正时，请务必附带 explanations，这些 explanations 会在 evaluator prompt 中填充到 `few_shot_explanation` 变量的位置。

Few-shot examples 的输入将取自你的 chain/dataset 的 inputs、outputs，以及 reference（若这是一个 offline evaluator）中的相关字段。输出则会是修正后的 evaluator score，以及你在修正时填写的 explanations。你可以根据需要继续编辑它们。下面是 corrections dataset 中一个 few-shot example 的示例：

![Few-shot example](/langsmith/images/few-shot-example.png)

请注意，修正结果可能需要一两分钟才会填充进你的 few-shot dataset。一旦填充完成，evaluator 后续运行时就会把它们包含进 prompt 中。

## View your corrections dataset

若要查看你的 corrections dataset：

* **Online evaluators**：选择你的 run rule，然后点击 **Edit Rule**
* **Offline evaluators**：选择你的 evaluator，然后点击 **Edit Evaluator**

![Edit Evaluator](/langsmith/images/edit-evaluator.png)

进入 **Improve evaluator accuracy using few-shot examples** 部分中链接到的 corrections dataset。你可以在这个 dataset 中查看并更新你的 few-shot examples。

![View few-shot dataset](/langsmith/images/view-few-shot-ds.png)
