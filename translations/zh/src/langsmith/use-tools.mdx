Tool 让语言模型能够与外部系统交互，并执行超出纯文本生成范围的动作。在 Playground 中，你可以使用两类 tool：

1. [**Built-in tools**](#built-in-tools)：由模型提供商，例如 OpenAI 和 Anthropic，预先配置好的现成工具。需要常见能力，例如 web search 或 code interpretation 时，适合使用 built-in tool。
2. [**Custom tools**](#create-a-custom-tool)：由你自己定义的函数，用于执行特定任务。当你需要与自己的系统集成，或实现专门功能时，它们会很有用。当你在 Playground 中定义 custom tool 后，你还可以验证模型是否能正确识别这些工具，并以正确参数调用它们。

LangSmith 会自动把你创建的 tool 保存到一个 workspace 级别的 [tool registry](#manage-tools-with-the-registry) 中，从而让这些 tool 可以在不同 prompt 和 session 间复用。

## Built-in tools

Playground 原生支持来自 OpenAI 和 Anthropic 的多种 tool。如果你要使用的 tool 没有在 Playground 中明确列出，你仍然可以通过手动指定其 `type` 以及所需参数来添加它。

### OpenAI tools

- **Web search**：[Search the web for real-time information](https://platform.openai.com/docs/guides/tools-web-search?api-mode=responses)。
- **Image generation**：[Generate images based on a text prompt](https://platform.openai.com/docs/guides/tools-image-generation)。
- **MCP**：[Gives the model access to tools hosted on a remote MCP server](https://platform.openai.com/docs/guides/tools-remote-mcp)。
- [View all OpenAI tools](https://platform.openai.com/docs/guides/tools?api-mode=responses)。

### Anthropic tools

- **Web search**：[Search the web for up-to-date information](https://platform.claude.com/docs/en/agents-and-tools/tool-use/web-search-tool)。
- [View all Anthropic tools](https://platform.claude.com/docs/en/agents-and-tools/tool-use/overview)。

## Add and use tools

Playground 支持通过一次点击，快速把 [tool](#add-a-tool) 添加到任意 prompt 中。你可以从 OpenAI、Anthropic 等模型提供商提供的 built-in tool 中选择，也可以定义适配自己需求的 [custom tool](#create-a-custom-tool)。一旦你创建了 custom tool，它会自动加入 workspace 级别的 [tool registry](#manage-tools-with-the-registry)，你可以在不同 prompt 中启用、禁用或编辑它，而无需重复创建。

### Add a tool

要把 tool 添加到 prompt 中，请点击 prompt editor 底部的 **+ Tool** 按钮。

### Use a built-in tool

1. 在 tool 区域中，选择你想使用的 built-in tool。你只能看到与当前所选 provider 和 model 兼容的 tool。
2. 当模型调用该 tool 时，Playground 会显示返回结果。

    ![Web search tool](/langsmith/images/web-search-tool.gif)

### Create a custom tool

要创建 custom tool，你需要提供：

- **Name**：tool 的描述性名称。
- **Description**：清楚说明该 tool 的作用。
- **Arguments**：该 tool 所要求的输入。

![Custom tool](/langsmith/images/custom-tool.gif)

在 Playground 中运行 custom tool 时，模型会返回一个 JSON object，其中包含 tool name 和 tool call。

![Tool call](/langsmith/images/tool-call.png)

### Manage tools with the registry

Playground 内置了一个以 [workspace](/langsmith/administration-overview#workspaces) 为作用域的 **tool registry**，可在不同 prompt 和 session 之间持久化保存 custom tool 和 built-in tool。无论你是创建 custom tool，还是添加 built-in tool，它都会自动保存到 workspace registry 中，并在任意 prompt 中可复用。你可以按 prompt 级别启用或禁用 tool，以控制每个 prompt 中哪些 tool 处于活动状态；当你编辑某个共享 tool 时，也可以选择更新 registry 中的版本，或另存为一个新的 tool。

点击 Playground 中的 **+ Tool** 按钮，打开 **Manage tools**。你可以：

- 在 **Available Tools** 标签页中选择并查看已有 tool。
- 使用 **Enabled** 开关为单个 tool 打开或关闭启用状态。
- 点击列表中的 tool 来编辑它。
- 使用 **Manage tools** 底部的 **Delete** 删除 tool。

## Tool choice settings

某些模型允许你控制调用哪些 tool。配置方式如下：

1. 在 prompt editor 下方选择 **+ Tool**。
1. 进入 **Tool Choice Setting** 标签页。
1. 选择你的 tool choice。

如需了解可用的 tool choice 选项，请查看你所用 provider 的文档。例如，[OpenAI's documentation on tool choice](https://platform.openai.com/docs/guides/function-calling/function-calling-behavior?api-mode=responses#tool-choice)。
