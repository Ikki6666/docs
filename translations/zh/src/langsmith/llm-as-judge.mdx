title: 如何定义 LLM-as-a-judge evaluator
sidebarTitle: LLM-as-a-judge

LLM 应用往往很难评估，因为它们通常生成的是对话文本，而这类输出往往不存在唯一正确答案。

本指南展示如何使用 [LangSmith UI](https://smith.langchain.com) 为[离线评估](/langsmith/evaluation-concepts#offline-evaluations)定义一个 [LLM-as-a-judge evaluator](/langsmith/evaluation-concepts#llm-as-judge)。

<Note>
如果想对生产 traces 实时运行评估，请参阅[设置在线评估](/langsmith/online-evaluations-llm-as-judge)。
</Note>

<Tip>
如果 dataset 示例是通过[在 annotation queue 中编写 assertions](/langsmith/assertions)构建出来的，那么 LLM-as-a-judge evaluator 可以读取 `example.outputs["assertions"]`，并根据你的应用输出为每一条 assertion 打分。
</Tip>

## 第 1 步：创建 evaluator

1. 在 [LangSmith UI](https://smith.langchain.com) 中，从 [Evaluators](/langsmith/evaluators) 页面点击 **+ Evaluator**，或者在 dataset 或 tracing project 内的 **Evaluators** 标签页中点击。
1. 在 **Add Evaluator** 面板中，在 **Create from scratch** 下选择 **LLM-as-a-Judge Evaluator**。也可以选择 **Create from a template**，先从现成 evaluator 开始，再进行编辑。

### Evaluator 模板

在设置评估时，evaluator 模板是一个很有用的起点。在 **Add Evaluator** 面板中选择 **Create from a template**，即可浏览按 Security、Safety、Quality 等类别组织的模板。

你可以在以下场景配置 LLM-as-a-Judge evaluator：

- 从 [Evaluators](/langsmith/evaluators) 页面
- 作为 dataset 的一部分，用于[自动在实验上运行评估](/langsmith/bind-evaluator-to-dataset)
- 在运行[在线评估](/langsmith/online-evaluations-llm-as-judge)时

### 自定义你的 LLM-as-a-judge evaluator

可以为 LLM-as-a-judge evaluator 的 prompt 添加更具体的说明，并配置要将输入、输出、参考输出中的哪些部分传给 evaluator。

## 第 2 步：配置 evaluator

### Prompt

创建一个新 prompt，或从 [prompt hub](/langsmith/prompt-engineering-quickstart) 中选择已有 prompt。

* **Create your own prompt**：直接内联创建一个自定义 prompt。

* **Pull a prompt from the prompt hub**：使用 **Select a prompt** 下拉框从已有 prompt 中选择。你不能直接在 prompt 编辑器中修改这些 prompts，但可以查看 prompt 及其使用的 schema。若要修改，请先在 Playground 中编辑 prompt 并提交版本，然后在 evaluator 中重新拉取新版本。

### Model

从提供的选项中选择所需模型。

### 映射变量

使用变量映射来指定从 run 或 example 中将哪些变量传入 evaluator prompt。为了帮助完成变量映射，界面会提供一个示例（或 run）供参考。点击 prompt 中的变量，并使用下拉框将其映射到输入、输出或参考输出中的相应部分。

如果使用 mustache 格式（默认），可以通过双花括号 `{{prompt_var}}` 添加 prompt 变量；如果使用 f-string 格式，则用单花括号 `{prompt_var}`。

你也可以根据需要删除变量。例如，如果正在评估简洁性这类指标，通常不需要参考输出，那么就可以移除该变量。

### 预览

Prompt 预览会展示，在使用右侧显示的参考 run 和 dataset example 进行填充后，最终格式化后的 prompt 长什么样。

### 用 few-shot examples 改进 evaluator

为了让 LLM-as-a-judge evaluator 更贴近人类偏好，LangSmith 允许你为 evaluator 分数收集[人工修正](/langsmith/create-few-shot-evaluators#make-corrections)。启用该选项后，这些修正会被自动插入到 prompt 中，作为 few-shot examples。

了解[如何设置 few-shot examples 并进行修正](/langsmith/create-few-shot-evaluators)。

### Feedback 配置

Feedback 配置就是 LLM-as-a-judge evaluator 用来打分的评分标准。可以把它看作 evaluator 依据的 rubric。分数会以[feedback](/langsmith/observability-concepts#feedback)的形式附加到 run 或 example 上。为 evaluator 定义 feedback 时：

1. **命名 feedback key**：这是查看评估结果时显示的名称。名称应在各个实验中保持唯一。

2. **添加描述**：描述该 feedback 表示什么。

3. **选择 feedback 类型**：

   * **Boolean**：True/false 类型反馈。
   * **Categorical**：从预定义类别中选择。
   * **Continuous**：在指定范围内的数值评分。

在底层实现中，feedback 配置会以[结构化输出](/oss/langchain/structured-output)的形式加入到 LLM-as-a-judge prompt 中。如果使用的是来自 hub 的现有 prompt，那么在将它配置为 evaluator 之前，必须先为该 prompt 添加 output schema。Output schema 中的每个顶层 key 都会被当作一条独立 feedback。

## 第 3 步：保存 evaluator

当你完成配置后，保存变更即可。
