此 Helm 仓库包含一些查询，用于生成 LangSmith UI 当前无法直接支持的输出，例如在单个查询中获取多个组织的 trace 计数。

此命令接收一个包含内嵌用户名和密码的 postgres 连接字符串，可以通过 secrets manager 调用传入，然后执行输入文件中的查询。在下面的示例中，我们使用的是 `support_queries/postgres` 目录中的 `pg_get_trace_counts_daily.sql` 输入文件。

## 前提条件

确保你已准备好以下工具和信息。

1. kubectl

   * [https://kubernetes.io/docs/tasks/tools/](https://kubernetes.io/docs/tasks/tools/)

2. PostgreSQL client

   * [https://www.postgresql.org/download/](https://www.postgresql.org/download/)

3. PostgreSQL 数据库连接信息：

   * Host
   * Port
   * Username
     * 如果使用 bundled 版本，这里是 `postgres`
   * Password
     * 如果使用 bundled 版本，这里是 `postgres`
   * Database name
     * 如果使用 bundled 版本，这里是 `postgres`

4. 从你将运行迁移脚本的机器到 PostgreSQL 数据库的连通性。

   * 如果你使用 bundled 版本，可能需要把 postgresql service 端口转发到本地机器。
   * 运行 `kubectl port-forward svc/langsmith-postgres 5432:5432`，将 postgresql service 端口转发到本地机器。

5. 用于运行支持查询的脚本

   * 下载 [PostgreSQL support query script](https://github.com/langchain-ai/helm/blob/main/charts/langsmith/scripts/run_support_query_pg.sh)

## 运行查询脚本

运行以下命令来执行所需查询：

```bash
sh run_support_query_pg.sh <postgres_url> --input path/to/query.sql
```

例如，如果你使用带端口转发的 bundled 版本，命令可能如下所示：

```bash
sh run_support_query_pg.sh "postgres://postgres:postgres@localhost:5432/postgres" --input support_queries/pg_get_trace_counts_daily.sql
```

该命令会输出按 workspace ID 和 organization ID 统计的每日 trace 数量。如需将结果导出到文件，请添加 `--output path/to/file.csv` 标志。

## 导出使用数据

所有导出方式都会生成相同的数据：LangSmith trace 计数、LangSmith Deployments 节点使用量，以及跨所有 workspace 和 organization 的 Fleet run 计数。

<Note>
UI 和 API 导出都要求同时满足以下条件：

- 具备 `organization:manage` 权限。
- 调用者的邮箱必须列在 `USAGE_EXPORT_ADMIN_EMAILS` 中，或者 `ORG_ADMINS_INSTALLATION_USAGE_EXPORT_ENABLED` 必须设置为 `true`。

```env
USAGE_EXPORT_ADMIN_EMAILS='["admin@example.com", "admin2@example.com"]'
ORG_ADMINS_INSTALLATION_USAGE_EXPORT_ENABLED=true
```
</Note>

### 从 UI 导出（推荐）

1. 进入 **Settings** > **Usage and billing** > **Usage export**。
2. 点击 **Export usage data**。
3. 将下载一个包含全部使用数据的 ZIP 文件。

### 通过 API 导出

如果你希望以编程方式导出使用数据，可以直接调用导出 API 端点。

```bash
curl -OJ \
  -H "X-API-Key: <your_api_key>" \
  https://<langsmith_url>/api/v1/orgs/current/usage/backfill-export
```

### 通过 SQL 脚本导出

你也可以直接对 PostgreSQL 数据库运行 SQL 脚本来导出使用数据。这要求你具备数据库访问凭证，应用层权限在这里不适用。

要导出 trace 使用数据，需要 Helm chart 版本 0.11.4 或更高：

```bash
sh run_support_query_pg.sh <postgres_url> \
  --input support_queries/postgres/pg_usage_traces_full_export.sql \
  --output ls_export.csv
```

要导出节点使用数据，需要 Helm chart 版本 0.11.4 或更高：

```bash
sh run_support_query_pg.sh <postgres_url> \
  --input support_queries/postgres/pg_usage_nodes_full_export.sql \
  --output lgp_export.csv
```

要导出 Fleet run 计数，需要 Helm chart 版本 0.13.25 或更高：

```bash
sh run_support_query_pg.sh <postgres_url> \
  --input support_queries/postgres/pg_usage_agent_builder_full_export.sql \
  --output ab_export.csv
```

要导出 usage snapshots，例如 workspace、project、dataset、prompt 和 active user 的每日实体计数：

```bash
sh run_support_query_pg.sh <postgres_url> \
  --input support_queries/postgres/pg_usage_snapshots_full_export.sql \
  --output usage_snapshots_export.csv
```
