LangSmith Engine 是 LangSmith 面向 agent engineering 的 Agent。它基于你的生产 traces 工作，用于发现反复出现的问题、诊断其根因，并在开发生命周期的各个阶段推动修复落地。

每个问题都会经历一个闭环：trace 中检测到重复出现的问题，系统诊断其根因，提出修复方案，并随着匹配同一模式的新 traces 到达而跟踪该问题；如果问题在关闭后再次出现，Engine 会自动重新打开它。

## Engine across the lifecycle

针对每个问题，Engine 会展示相关 traces，提出修复方案，通过附加匹配同一失败模式的新 traces 来保持问题的最新状态，并基于生产 trace 输入创建 ground truth dataset examples，供离线评估使用。

## How Engine runs

Engine 按照为平衡成本和性能而调整的动态调度来扫描每个已连接的 tracing project。它会按严重程度对问题进行聚类和优先级排序，并以 LangChain Standard Units（LSUs）计费。

LangSmith Cloud 使用由 LangChain 托管的 inference。Self-hosted 部署可以使用 LangSmith Intelligence 或自己的模型 provider。关于安装和模型 provider 选项，请参阅 [Engine on self-hosted](/langsmith/engine-self-hosted)；关于数据处理和访问控制，请参阅 [Engine security](/langsmith/engine-security)。

关于设置、成本和问题处理流程，请参阅 [Find and fix your agent's issues](/langsmith/engine)。在 LangSmith Cloud 上，[Red Teaming](/langsmith/engine#beta-proactively-detect-issues-with-red-teaming) 还可以在故障到达生产环境之前，使用合成请求测试 deployment。
