LangSmith Engine 是 LangSmith 面向 agent engineering 的 Agent。它基于你的生产 traces 工作，用于发现反复出现的问题、诊断其根因，并在开发生命周期的各个阶段推动修复落地。

每个问题都会经历一个闭环：trace 中检测到重复出现的问题，系统诊断其根因，提出修复方案，并随着匹配同一模式的新 traces 到达而跟踪该问题；如果问题在关闭后再次出现，Engine 会自动重新打开它。

## Engine across the lifecycle

针对每个问题，Engine 会展示相关 traces，提出修复方案，通过附加匹配同一失败模式的新 traces 来保持问题的最新状态，并基于生产 trace 输入创建 ground truth dataset examples，供离线评估使用。

## How Engine runs

Engine 按照为平衡成本和性能而调整的动态调度来扫描每个已连接的 tracing project，并按严重程度对问题进行聚类和优先级排序。它使用由 LangChain 托管的 inference，并以 LangChain Compute Units（LCUs）计费。关于设置、成本和完整的问题处理流程，请参阅 [Find and fix your agent's issues](/langsmith/engine)。关于 Engine 如何处理你的数据、它的 GitHub 和模型 subprocessor 控制方式，以及合规状况，请参阅 [Engine security](/langsmith/engine-security)。关于 Engine 在 self-hosted 部署中如何运行，请参阅 [Engine on self-hosted](/langsmith/engine-self-hosted)。
