---
title: 如何自定义 Dockerfile
sidebarTitle: 自定义 Dockerfile
---
用户可以在继承父级 LangGraph 镜像之后，向 Dockerfile 添加一组额外的行。要实现这一点，只需要修改你的 `langgraph.json` 文件，把你希望执行的命令传入 `dockerfile_lines` 键。例如，如果你想在 graph 中使用 `Pillow`，则需要添加以下依赖：

```json
{
    "dependencies": ["."],
    "graphs": {
        "openai_agent": "./openai_agent.py:agent",
    },
    "env": "./.env",
    "dockerfile_lines": [
        "RUN apt-get update && apt-get install -y libjpeg-dev zlib1g-dev libpng-dev",
        "RUN pip install Pillow"
    ]
}
```

如果你要处理 `jpeg` 或 `png` 图像格式，这些配置会安装使用 Pillow 所需的系统包。
