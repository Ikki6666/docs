本教程将演示如何基于用户反馈来优化一个分类器。分类器非常适合做优化，因为它通常很容易收集期望输出，因此也很容易基于用户反馈构建 few-shot 示例。本例中我们就会这么做。

## 目标

在这个示例里，我们会构建一个 bot，根据 GitHub issue 的标题对 issue 进行分类。它接收一个标题，并将其归类到若干类别之一。随后，我们会开始收集用户反馈，并利用这些反馈来调整分类器的表现。

## 开始

首先，我们把所有 traces 都发送到一个指定 project 中。可以通过设置环境变量来实现：

```python
import os
os.environ["LANGSMITH_PROJECT"] = "classifier"
```

接着创建初始应用。这里会是一个非常简单的函数，只接收 GitHub issue title，并尝试给它打上标签。

```python
import openai
from langsmith import traceable, Client
import uuid

client = openai.Client()

available_topics = [
    "bug",
    "improvement",
    "new_feature",
    "documentation",
    "integration",
]

prompt_template = """Classify the type of the issue as one of {topics}.
Issue: {text}"""

@traceable(
    run_type="chain",
    name="Classifier",
)
def topic_classifier(
    topic: str):
    return client.chat.completions.create(
        model="gpt-5.4-mini",
        temperature=0,
        messages=[
            {
                "role": "user",
                "content": prompt_template.format(
                    topics=','.join(available_topics),
                    text=topic,
                )
            }
        ],
    ).choices[0].message.content
```

然后就可以开始与它交互了。在交互时，我们会预先生成 LangSmith run id，并把它传进函数。这样做是为了后续能把反馈附加到这个 run 上。

下面是调用应用的方式：

```python
from langsmith import uuid7

run_id = uuid7()
topic_classifier(
    "fix bug in LCEL",
    langsmith_extra={"run_id": run_id})
```

下面是如何在调用之后附加反馈。我们可以用两种形式收集反馈。

首先是“正向”反馈，也就是模型答对了的例子：

```python
ls_client = Client()
run_id = uuid7()
topic_classifier(
    "fix bug in LCEL",
    langsmith_extra={"run_id": run_id})
ls_client.create_feedback(
    run_id,
    key="user-score",
    score=1.0,
)
```

接下来，我们也可以收集对应“纠正结果”的反馈。比如这个示例中，模型会把它分类为 bug，但我实际上希望它被归到 documentation。

```python
ls_client = Client()
run_id = uuid7()
topic_classifier(
    "fix bug in documentation",
    langsmith_extra={"run_id": run_id})
ls_client.create_feedback(
    run_id,
    key="correction",
    correction="documentation")
```

## 设置 automations

现在我们可以设置 automations，把带有某种反馈形式的示例移动到 dataset 中。这里会设置两个 automation，一个处理正向反馈，一个处理负向反馈。

第一个 automation 会把所有带正向反馈的 runs 自动加入某个 dataset。背后的逻辑是，任何得到正向反馈的 run 都可以在后续迭代中作为优秀示例复用。我们先创建一个名为 `classifier-github-issues` 的 dataset 来保存这些数据。

![Optimization Negative](/langsmith/images/class-optimization-neg.png)

第二个 automation 会把带有 correction 的 runs，通过 webhook 加入 dataset。创建这个 webhook 时，我们会选择 “Use Corrections” 选项。这样在根据 run 创建 dataset 时，系统不会把 run 的原始输出当成该 datapoint 的 gold-truth output，而是会使用 correction。

![Optimization Positive](/langsmith/images/class-optimization-pos.png)

## 更新应用

接下来可以更新代码，让它拉取我们正在往里写入 runs 的 dataset。拉取后，我们把示例整理成一个字符串，再把这个字符串拼进 prompt 中。

```python
### NEW CODE ###
# Initialize the LangSmith Client so we can use to get the dataset
ls_client = Client()

# Create a function that will take in a list of examples and format them into a string
def create_example_string(examples):
    final_strings = []
    for e in examples:
        final_strings.append(f"Input: {e.inputs['topic']}\n> {e.outputs['output']}")
    return "\n\n".join(final_strings)
### NEW CODE ###

client = openai.Client()

available_topics = [
    "bug",
    "improvement",
    "new_feature",
    "documentation",
    "integration",
]

prompt_template = """Classify the type of the issue as one of {topics}.

Here are some examples:
{examples}

Begin!
Issue: {text}
>"""

@traceable(
    run_type="chain",
    name="Classifier",
)
def topic_classifier(
    topic: str):
    # We can now pull down the examples from the dataset
    # We do this inside the function so it always get the most up-to-date examples,
    # But this can be done outside and cached for speed if desired
    examples = list(ls_client.list_examples(dataset_name="classifier-github-issues"))  # <- New Code
    example_string = create_example_string(examples)
    return client.chat.completions.create(
        model="gpt-5.4-mini",
        temperature=0,
        messages=[
            {
                "role": "user",
                "content": prompt_template.format(
                    topics=','.join(available_topics),
                    text=topic,
                    examples=example_string,
                )
            }
        ],
    ).choices[0].message.content
```

如果现在再用和之前相似的输入运行应用，就会看到它已经正确学会了：任何和 docs 相关的内容，即使本质上是 bug，也应该被归类为 `documentation`。

```python
ls_client = Client()
run_id = uuid7()
topic_classifier(
    "address bug in documentation",
    langsmith_extra={"run_id": run_id})
```

## 基于示例做语义搜索

另一个可选优化是，只使用语义上最相近的示例。当你的示例逐渐积累变多时，这会很有帮助。

为此，我们可以先定义一个函数，用来找出最相似的 `k` 个示例：

```python
import numpy as np

def find_similar(examples, topic, k=5):
    inputs = [e.inputs['topic'] for e in examples] + [topic]
    vectors = client.embeddings.create(input=inputs, model="text-embedding-3-small")
    vectors = [e.embedding for e in vectors.data]
    vectors = np.array(vectors)
    args = np.argsort(-vectors.dot(vectors[-1])[:-1])[:5]
    examples = [examples[i] for i in args]
    return examples
```

然后在应用中使用它：

```python
ls_client = Client()

def create_example_string(examples):
    final_strings = []
    for e in examples:
        final_strings.append(f"Input: {e.inputs['topic']}\n> {e.outputs['output']}")
    return "\n\n".join(final_strings)

client = openai.Client()

available_topics = [
    "bug",
    "improvement",
    "new_feature",
    "documentation",
    "integration",
]

prompt_template = """Classify the type of the issue as one of {topics}.

Here are some examples:
{examples}

Begin!
Issue: {text}
>"""

@traceable(
    run_type="chain",
    name="Classifier",
)
def topic_classifier(
    topic: str):
    examples = list(ls_client.list_examples(dataset_name="classifier-github-issues"))
    examples = find_similar(examples, topic)
    example_string = create_example_string(examples)
    return client.chat.completions.create(
        model="gpt-5.4-mini",
        temperature=0,
        messages=[
            {
                "role": "user",
                "content": prompt_template.format(
                    topics=','.join(available_topics),
                    text=topic,
                    examples=example_string,
                )
            }
        ],
    ).choices[0].message.content
```
