自托管 LangSmith Deployment 会在你自行运维的基础设施中运行 [Agent Server](/langsmith/agent-server)、control plane、data plane 以及配套数据库。

LangChain 提供容器镜像、Helm charts 和许可证；Kubernetes 集群（或 Docker 主机）、PostgreSQL、Redis，以及适配你环境的网络和可观测性工具由你提供。若你有数据驻留、监管约束、自定义网络或隔离网络要求，自托管是最合适的部署方式。

<Callout icon="clipboard-check" color="#4F46E5" iconType="regular">
自托管部署需要 [Enterprise plan](https://www.langchain.com/pricing) 以及该套餐附带的 LangSmith license key。安装说明请参阅[自托管 LangSmith](/langsmith/self-hosted)。
</Callout>

## 拓扑

LangSmith 支持三种自托管拓扑，它们在部署复杂度和 control-plane 功能之间做了不同取舍。[平台功能](/langsmith/self-hosted-platform-features)、[Agent Server metrics](/langsmith/self-hosted-agent-server-metrics) 和[诊断](/langsmith/diagnostics-self-hosted)的参考页面适用于这三种拓扑。

<CardGroup cols={2}>

<Card title="完整自托管平台" icon="buildings" href="/langsmith/deploy-with-control-plane">
完整的 LangSmith 平台，包括 [control plane](/langsmith/control-plane) UI 与 API、[data plane](/langsmith/data-plane) listener、可观测性、评估，以及 agent 部署管理。适合希望在自有网络中获得完整 LangSmith 产品体验的团队。
</Card>

<Card title="Hybrid" icon="cloud-network" href="/langsmith/hybrid">
由 LangChain 托管 control plane，而 data plane（Agent Servers 和数据库）运行在你的基础设施中。适合希望使用托管部署工作流，但又需要让 agent 工作负载和客户数据留在 VPC 内的场景。
</Card>

<Card title="独立服务器" icon="server" href="/langsmith/deploy-standalone-server">
最轻量的选项，仅包含 Agent Server 容器（API + queue workers）以及你自己的 PostgreSQL 和 Redis。没有 control plane，也没有托管 UI。适合将运行时嵌入现有基础设施，或在隔离网络中运行。
</Card>

<Card title="平台功能" icon="list-check" href="/langsmith/self-hosted-platform-features">
自托管专属平台行为的参考文档，包括自定义 Postgres 和 Redis、listeners，以及资源自定义。
</Card>

<Card title="Agent Server 指标" icon="chart-line" href="/langsmith/self-hosted-agent-server-metrics">
Agent Server 的 Prometheus 和 Datadog 导出，包括 Deployment UI 指标和内部指标。
</Card>

<Card title="诊断" icon="stethoscope" href="/langsmith/diagnostics-self-hosted">
收集日志、检查状态，并排查自托管安装问题。
</Card>

</CardGroup>

## 谁负责什么

自托管将基础设施运维的责任从 LangChain 转移到你的团队，这带来了更高的灵活性，以及对配置和运行方式的完全控制：

|                                              | **Who manages it** | **Where it runs**           |
|----------------------------------------------|--------------------|-----------------------------|
| LangSmith 平台（UI、APIs、datastores）       | You                | Your infrastructure         |
| Agent Server 运行时                          | You                | Your infrastructure         |
| PostgreSQL 和 Redis                          | You                | Your infrastructure         |
| 应用的 CI/CD                                 | You                | Your CI environment         |
| 升级、扩缩容和备份                           | You                | Your infrastructure         |

作为交换，你可以接入自己的 [Postgres](/langsmith/self-hosted-platform-features#custom-postgresql) 和 [Redis](/langsmith/self-hosted-platform-features#custom-redis)，按工作负载调整 [CPU 和内存](/langsmith/self-hosted-platform-features#resource-customization)，并在现有网络和可观测性体系中运行。对应的云托管模式请参阅[部署到 Cloud](/langsmith/deploy-to-cloud-overview)。
