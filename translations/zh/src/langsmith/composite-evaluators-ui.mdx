_Composite evaluators_ 是将多个 evaluator 分数组合成单个 [score](/langsmith/evaluation-concepts#evaluator-outputs) 的一种方式。当你想评估应用的多个方面，并把结果汇总成一个单独结果时，这会非常有用。

本指南会向你展示如何使用 [LangSmith UI](https://smith.langchain.com) 定义一个 [composite evaluator](/langsmith/evaluation-concepts#llm-as-judge)。

<Note>
若要使用 SDK 以编程方式创建 composite evaluators，请参阅 [How to create a composite evaluator (SDK)](/langsmith/composite-evaluators-sdk)。
</Note>

## Create a composite evaluator

你可以在 [tracing project](/langsmith/observability-concepts#projects) 上创建 composite evaluators（用于 [online evaluations](/langsmith/evaluation-concepts#online-evaluations)），也可以在 [dataset](/langsmith/evaluation-concepts#datasets) 上创建（用于 [offline evaluations](/langsmith/evaluation-concepts#offline-evaluations)）。借助 UI 中的 composite evaluators，你可以计算多个 evaluator 分数的加权平均值或加权总和，并可自定义权重。

### 1. Navigate to the tracing project or dataset

要开始配置 composite evaluator，请进入 **Tracing Projects** 或 **Dataset & Experiments** 标签页，并选择一个 project 或 dataset。
- 在 tracing project 中：**+ New** > **Evaluator** > **Composite score**
- 在 dataset 中：**+ Evaluator** > **Composite score**

### 2. Configure the composite evaluator

1. 为 evaluator 命名。
2. 选择聚合方式，**Average** 或 **Sum**。
    - **Average**：∑(weight*score) / ∑(weight)。
    - **Sum**：∑(weight*score)。
3. 添加你希望纳入 composite score 的 feedback keys。
4. 为 feedback keys 添加权重。默认情况下，每个 feedback key 的权重相等。你可以调整权重，以提升或降低某些 feedback key 在最终得分中的重要性。
5. 点击 **Create** 保存 evaluator。

<Tip> 如果你需要调整 composite scores 的权重，可以在 evaluator 创建后再更新。更新后，所有已配置该 evaluator 的 runs 对应结果都会同步刷新。 </Tip>

### 3. View composite evaluator results
Composite scores 会以 **feedback** 的形式附加到 run 上，方式与单个 evaluator 产生的 feedback 类似。具体查看方式取决于评估运行的位置：

**在 tracing project 中**：
- Composite scores 会显示为 runs 上的 feedback。
- 你可以[筛选 runs](/langsmith/filter-traces-in-application)，找出带有 composite score 的 runs，或者 composite score 满足特定阈值的 runs。
- 你可以[创建 chart](/langsmith/dashboards#custom-dashboards) 来可视化 composite score 随时间变化的趋势。

**在 dataset 中**：
- 你可以在 experiments 标签页中查看 composite scores。你也可以根据 runs 的平均 composite score 来筛选和排序 experiments。
- 点击进入某个 experiment，即可查看每个 run 的 composite score。

<Note> 如果组成 composite 的任意一个 evaluator 没有配置在该 run 上，那么该 run 不会计算 composite score。 </Note>
