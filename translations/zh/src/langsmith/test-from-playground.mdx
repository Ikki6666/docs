---

[Playground](/langsmith/prompt-engineering-concepts#playground) 提供了一个用于迭代和测试 prompts 与 model configurations 的界面。基于一系列输入测试某个 prompt 或 model configuration，无需编写任何代码，即可查看它在不同上下文或场景下的评分表现。

在 Playground 中，你可以：

* 更改正在使用的模型。
* 更改正在使用的 prompt 模板。
* 更改 output schema。
* 更改可用的 tools。
* 输入要通过 prompt 模板运行的输入变量。
* 将 prompt 通过模型运行并观察输出。

要基于 dataset 测试某个 prompt 或 model configuration 并对结果评分，请[从 Playground 运行评估](/langsmith/run-evaluation-from-playground)。

<Callout type="info" icon="feather">
使用 Playground 中的 [Chat](/langsmith/chat)，借助 AI 辅助优化 prompts、生成 tools 并创建 output schemas。
</Callout>
