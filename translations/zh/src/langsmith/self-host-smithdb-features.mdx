一些 LangSmith 功能只从 [SmithDB](/langsmith/self-host-smithdb) 读取 trace 数据。在仍在查询 ClickHouse 的自托管安装上，这些功能会被隐藏、禁用，或回退到旧版体验。使用本页面了解将查询迁移到 SmithDB 后你能获得什么，以及尚未迁移时哪些功能仍然可用。

<Note>
ClickHouse 支持在 LangSmith v0.19 结束。关于升级时机，请参见[自托管 changelog](/langsmith/self-hosted-changelog)。
</Note>

## 检查查询是否使用 SmithDB

当 LangSmith [查询 SmithDB](/langsmith/self-host-smithdb-install#step-6-switch-queries-to-smithdb) 时，本页面上的功能才会开启。仅启用[双路径摄取](/langsmith/self-host-smithdb-install#step-4-enable-dual-ingestion)并不会启用它们。要检查当前设置，请读取 `sdb_query_enabled` 实例 flag：

```bash
curl -s https://LANGSMITH_HOST/api/v1/info | jq '.instance_flags | {sdb_ingestion_enabled, sdb_query_enabled}'
```

SmithDB 是必要条件，但不总是充分条件。功能还可能取决于你的 LangSmith 版本，而且一些功能在到达 LangSmith Cloud 之后才会推广到自托管安装。每个功能自己的页面会说明其版本和区域可用性。

## 需要 SmithDB 的功能

其中几行介绍的是某个功能的新版本，该功能在没有 SmithDB 时也有可用版本。最后一列列出了在查询 ClickHouse 的安装上你仍然可以使用的内容。

| 功能 | 哪些部分需要 SmithDB | 没有 SmithDB 时可用的内容 |
| --- | --- | --- |
| [过滤器查询语法](/langsmith/filter-traces#query-syntax) | 过滤器搜索栏和 `field:value` 查询语法，支持 thread、root run、single run 和 any run scopes。 | 使用旧版 function 风格过滤器进行过滤。 |
| [自定义 dashboard 图表编辑器](/langsmith/dashboards#custom-dashboards) | 当前的图表编辑器，支持模板、比例、每序列过滤器、分组、breakdown 和图表下钻。 | 使用[旧版自定义 dashboard](/langsmith/dashboards#custom-dashboards-legacy) 创建自定义 dashboard 和 chart，以及预置 dashboard。 |
| [Trajectory 视图](/langsmith/view-traces#trajectory-view) | 跨 turns、模型调用、工具和 subagent 的去重对话。还为 thread 的 Markdown 导出以及 experiment run 详情中解析后的消息提供支持。 | 单个 run 的 trace 检查和消息渲染。 |
| [Trajectory evaluator](/langsmith/online-evaluations-multi-turn#evaluate-trajectories) | 使用 `trajectory` 变量为完整 agent 路径打分的 online evaluator，包括子模型调用和工具调用。 | 读取 root-run 消息的 run evaluator 和 thread evaluator。 |
| [Annotation queue 中的 thread](/langsmith/annotation-queues#assign-runs-and-threads-to-a-single-run-queue) | 从 thread 视图将 thread 添加到 annotation queue，以及审核会显示其 trajectory 的 thread 条目。 | Run 级别的 annotation queue。 |
| [数据集中的 thread](/langsmith/manage-datasets-in-application#manually-from-a-tracing-project) | 将选定的 thread（包括来自 annotation queue 的 thread 条目）作为对话 example 添加到 dataset。 | 向 dataset 添加 run。 |
| [Thread 自动化规则](/langsmith/rules#set-the-item-type-to-runs-or-threads) | 创建将 thread 添加到 annotation queue 或 dataset，或发送 [webhook](/langsmith/webhooks#read-a-thread-rule-payload) 的 thread 规则。对历史数据回填 thread 规则。 | Run 自动化规则。 |
| 公开 thread 分享 | 通过公开链接分享整个 thread。 | 通过公开链接分享单个 trace。 |
| 大型 trace 操作 | 面向大型 trace 的分页 trace 树、将整个 trace 下载为 JSON，以及从 trace 详情页删除整个 trace。 | 查看 trace、下载单个 run，以及已有的删除流程。 |
| [LLM Gateway 用量](/langsmith/llm-gateway-monitoring) | **Usage** 仪表板：支出汇总、图表、breakdown、过滤器和下钻。 | Gateway 路由和[策略](/langsmith/llm-gateway-spend-policies)。 |
| Agent trace 量 | Agent 概览卡片上的 trace 计数 sparkline，以及 agent 概览上的 trace 量图表。 | Agent 部署、管理和其他 agent 统计。 |
| [Bulk export 中的 feedback](/langsmith/data-export#limit-exported-fields) | 导出包含 feedback key 和评论的 `feedbacks` 字段。 | 其他所有字段的 bulk export。 |

Tracing、thread 列表、datasets 和 experiments 在两种 datastore 上都可用。
