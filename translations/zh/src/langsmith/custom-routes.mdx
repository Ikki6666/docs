---
title: 如何添加自定义 routes
sidebarTitle: 添加自定义 routes
---
当你把 agents 部署到 LangSmith Deployment 时，服务端会自动暴露用于创建 runs 和 threads、与长期 memory store 交互、管理 configurable assistants 等核心功能的 routes（[查看全部默认 API endpoints](/langsmith/server-api-ref)）。

你可以通过提供自己的 app object，并在 `langgraph.json` 中传入其路径来添加自定义 routes（例如 Python 中的 [`Starlette`](https://www.starlette.io/applications/) app，或 TypeScript 中的 [`Hono`](https://hono.dev/) app）。

定义一个自定义 app object 后，你就可以添加任何你需要的 routes，因此从新增一个 `/login` endpoint，到部署一个完整的 full-stack web-app，都可以放进同一个 Agent Server 中完成。

下面分别给出 Python 和 TypeScript 示例。

## 创建 app

从一个**已有的** LangSmith application 开始，在你的 app 文件中加入以下自定义 route 代码。如果你是从零开始，也可以用 CLI 基于模板创建一个新 app。

<Tabs>
    <Tab title="Python">
    ```bash
    langgraph new --template=new-langgraph-project-python my_new_project
    ```

    拿到 LangGraph project 之后，加入如下 app 代码：

    ```python {highlight={4}}
    # ./src/agent/webapp.py
    from fastapi import FastAPI

    app = FastAPI()


    @app.get("/hello")
    def read_root():
        return {"Hello": "World"}
    ```
    </Tab>
    <Tab title="TypeScript">
    ```bash
    yarn create langgraph
    npm install hono
    ```

    拿到 LangGraph project 之后，加入如下 app 代码：

    ```typescript
    // ./src/custom-routes.ts
    import { Hono } from "hono";

    export const app = new Hono()
      .get("/custom/hello", (c) => {
        return c.json({ hello: "world" });
      })
      .post("/custom/webhook", async (c) => {
        const body = await c.req.json();
        return c.json({ received: true, payload: body });
      });
    ```

    `hono` package 必须存在于你的项目依赖中。
    </Tab>
</Tabs>

## 配置 `langgraph.json`

把以下内容添加到你的 `langgraph.json` 配置文件中。请确保路径指向你在[上一节](#create-app)中创建的 app 实例。

<Tabs>
    <Tab title="Python">
    ```json
    {
      "dependencies": ["."],
      "graphs": {
        "agent": "./src/agent/graph.py:graph"
      },
      "env": ".env",
      "http": {
        "app": "./src/agent/webapp.py:app"
      }
      // Other configuration options like auth, store, etc.
    }
    ```
    </Tab>
    <Tab title="TypeScript">
    ```json
    {
      "node_version": "20",
      "dependencies": ["."],
      "graphs": { "agent": "./src/agent.ts:graph" },
      "http": { "app": "./src/custom-routes.ts:app" },
      "env": ".env"
    }
    ```
    </Tab>
</Tabs>

## 启动服务端

在本地测试服务端：

<Tabs>
    <Tab title="Python">
    ```bash
    langgraph dev --no-browser
    ```
    </Tab>
    <Tab title="TypeScript">
    ```bash
    npx @langchain/langgraph-cli@latest dev --no-browser
    ```
    </Tab>
</Tabs>

如果你在浏览器中访问 `localhost:2024/hello`（`2024` 是默认开发端口），应该能看到 `/hello` endpoint 返回 JSON 响应。对于 TypeScript 示例，请访问 `localhost:2024/custom/hello`。

TypeScript 的 `http.app` 配置同时适用于本地 `langgraph dev` 开发，以及 Docker 中的 `langgraph up`。

<Note>
**覆盖默认 endpoints**
你在 app 中创建的 routes 会优先于系统默认 routes，这意味着你可以覆盖并重新定义任意默认 endpoint 的行为。
</Note>

## 部署

你可以将这个 app 原样部署到 LangSmith，或部署到你自己的 self-hosted 平台。

## 后续步骤

既然你已经给 deployment 添加了自定义 route，你就可以用同样的方式继续定制服务端行为，例如定义[自定义 middleware](/langsmith/custom-middleware)和[自定义 lifespan events](/langsmith/custom-lifespan)。
