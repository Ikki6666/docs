Agent Server 支持两种应用层静态加密方案。除非你需要按租户划分密钥或使用外部密钥管理系统，否则请使用内置 AES 加密。

## 选择加密方案

<CardGroup cols={2}>
  <Card title="内置 AES 加密" icon="shield-lock" href="/langsmith/aes-encryption">
    适合大多数部署。配置一个 AES key，即可对 checkpoint 数据和选定的 JSON 字段进行加密。支持惰性密钥轮换。
  </Card>
  <Card title="自定义加密" icon="settings-code" href="/langsmith/custom-encryption">
    仅在内置 AES 无法满足需求时使用。通过自定义 handler，支持按租户划分密钥和外部密钥管理系统。
  </Card>
</CardGroup>

如果你需要以下能力，请选择[内置 AES 加密](/langsmith/aes-encryption)：

- 整个部署只使用一个加密密钥
- 密钥轮换
- 选择性加密 JSON 字段

只有在需要以下能力时，才选择[自定义加密](/langsmith/custom-encryption)：

- 不同租户使用不同的加密密钥
- 外部密钥管理系统
- 自定义加密逻辑或审计行为
