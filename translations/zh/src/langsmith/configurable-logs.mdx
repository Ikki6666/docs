---
title: 在服务器日志中包含 HTTP headers
sidebarTitle: Logging Headers
---

默认情况下，[Agent Server](/langsmith/agent-server) 出于隐私原因不会在服务器日志中记录 HTTP headers。不过，记录 request ID 和 correlation ID 能帮助你调试问题，并在分布式系统中追踪请求。你可以通过修改 [`langgraph.json`](/langsmith/application-structure#configuration-file) 文件中的 `logging_headers` 部分，为所有 API 调用选择性开启 header 记录。

```json
{
  "$schema": "https://langgra.ph/schema.json",
  "http": {
    "logging_headers": {
      "includes": ["request-id", "x-purchase-id", "*-trace-*"],
      "excludes": ["authorization", "x-api-key", "x-organization-id", "x-user-id"]
    }
  }
}
```

`includes` 和 `excludes` 列表接受精确的 header 名称，或使用 `*` 作为通配符、匹配任意长度字符的 glob 模式（大小写不敏感）。出于安全考虑，不支持其他模式类型。

请注意，排除规则优先于包含规则。例如，如果你包含 `*-id`，但排除了 `x-user-id`，那么 `x-user-id` header 仍不会被记录。
