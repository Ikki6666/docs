Playground 允许你使用自己的自定义模型。你可以通过 [LangServe](https://github.com/langchain-ai/langserve) 暴露模型 API，这是一个用于托管 LangChain 应用的开源库。Playground 会在后台与你的模型服务交互，以生成响应。

## Deploy a custom model server

为了方便你开始，我们提供了一个可供参考的[示例模型服务](https://github.com/langchain-ai/langsmith-model-server)。强烈建议你把这个示例模型服务作为起点。

根据你的模型是 instruct-style 还是 chat-style，你需要分别实现 `custom_model.py` 或 `custom_chat_model.py`。

## Adding configurable fields

通常，为模型配置不同参数会很有帮助，例如 temperature、model_name、max_tokens 等。

若要让你的模型能在 Playground 中配置，你需要为模型服务添加 configurable fields。这样就可以在 Playground 中修改模型参数。

你可以通过在 `config.py` 文件中实现 `with_configurable_fields` 函数来添加 configurable fields。示例如下：

```python
def with_configurable_fields(self) -> Runnable:
    """Expose fields you want to be configurable in the Playground. We will automatically expose these to the
    Playground. If you don't want to expose any fields, you can remove this method."""
    return self.configurable_fields(n=ConfigurableField(
        id="n",
        name="Num Characters",
        description="Number of characters to return from the input prompt.",
    ))
```

## Use the model in the Playground

部署好模型服务后，你就可以在 Playground 中使用它。进入 Playground，并根据模型类型选择 `ChatCustomModel` 或 `CustomModel` provider，分别对应 chat-style model 和 instruct-style model。

输入 `URL` 后，Playground 会自动检测可用的 endpoints 和 configurable fields。随后你就可以使用期望的参数调用模型。

![ChatCustomModel in Playground](/langsmith/images/playground-custom-model.png)

如果一切设置正确，你应当能在 Playground 中看到模型响应，以及你在 `with_configurable_fields` 中指定的 configurable fields。

更多信息请参阅[如何存储模型配置以便后续复用](/langsmith/managing-model-configurations)。
