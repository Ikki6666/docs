title: 决策模型
description: 通过 LangSmith LLM Gateway，使用 System One API 或 OpenAI Decisions API 调用 SemIf、TypeSafe 和 OpenAI 决策模型。
---

决策模型会对文本进行分类或打分，返回结构化的答案而不是生成的 chat 消息。通过 [LLM Gateway](/langsmith/llm-gateway) 使用以下两种 API 之一来调用它们：

| 模型 | API | Endpoint | 凭证 |
|-------|-----|----------|-------------|
| [SemIf](#semif) | System One | `/v1/systemone` | 仅需 LangSmith API key |
| [TypeSafe (Jev)](#typesafe-jev) | System One | `/v1/systemone` | `TYPESAFE_API_KEY` provider secret |
| [OpenAI 决策模型](#use-the-openai-decisions-api) | OpenAI Decisions | `/openai/v1/decisions` | `OPENAI_API_KEY` provider secret |

## Quickstart

这个示例调用 [SemIf](#semif)，它不需要 provider secret。

<Note>
SemIf 对处于 Free、Developer 和 Plus plan 的 US 组织启用。
</Note>

设置你的 [LangSmith API key](/langsmith/create-account-api-key)：

```bash
export LANGSMITH_API_KEY="<your-api-key>"
```

然后运行一个请求：

<Tabs>
<Tab title="Python">

安装 TypeSafe SDK：

```bash
pip install typesafe-sdk
```

```python
import os

from typesafe_sdk import Noul, TypeSafeClient

client = TypeSafeClient(
    api_key=os.environ["LANGSMITH_API_KEY"],
    base_url="https://gateway.smith.langchain.com",
)

response = client.system_one(
    state="Hello!",
    model="semif-qwen3.5-4b",
    questions={
        "is_helpful": Noul(
            instructions="Does this explain what an LLM gateway does?"
        ),
    },
)
```

## 使用 System One API

SemIf 和 TypeSafe (Jev) 都使用 System One API。`model` 字段决定由哪一个处理请求。

把要评估的文本传入 `state`，把 1 到 32 个命名问题传入 `questions`。System One 支持三种问题类型：

- **`noul`**：返回答案为真的概率。
- **`choice`**：把 state 分类到提供的选项之一。
- **`score`**：按 rubric 对 state 打分。

响应包含以问题名称为键的 `answers`，而不是 chat 消息。不支持流式。

### SemIf

LangSmith 在 gateway 上托管了 SemIf（`semif-qwen3.5-4b`），一个开源决策模型。你可以在 gateway 主页的托管模型中选择 SemIf 来获取请求示例。区域 base URL 请参见[区域 gateway](/langsmith/llm-gateway-direct-model-access#use-a-regional-gateway)。

SemIf 调用不消耗 Gateway Credits。Gateway [访问](/langsmith/llm-gateway-model-access-policies)、[速率限制](/langsmith/llm-gateway-rate-limit-policies)和[预算策略](/langsmith/llm-gateway-spend-policies)仍然适用。

### TypeSafe (Jev)

TypeSafe 决策模型通过 BYOK（自带 key）使用。把 `TYPESAFE_API_KEY` 配置为工作区 [provider secret](/langsmith/llm-gateway-admin-setup#1-add-provider-secrets)。设置和安装 LangChain 集成请参见 [TypeSafe setup](/oss/integrations/providers/typesafe)。

把 `LANGSMITH_API_KEY` 设置为你工作区范围的 LangSmith API key。`typesafe/` 前缀会把请求路由到你的 TypeSafe provider secret，而不是托管模型。调用 gateway 时，不要把 TypeSafe API key 传给 SDK 的 `api_key` 或 `apiKey`。SDK 请使用不带 `/v1` 的 gateway base URL：

## 使用 OpenAI Decisions API

OpenAI Decisions API 有自己的请求和响应格式，独立于 System One。gateway 通过 [direct model access](/langsmith/llm-gateway-direct-model-access) 支持它，因此需要工作区 provider secret `OPENAI_API_KEY`。

使用你工作区范围的 LangSmith API key，把请求发送到 `POST /openai/v1/decisions`。把 `model` 设置为不带 `openai/` 前缀的原生 OpenAI 模型名称：

```bash
curl https://gateway.smith.langchain.com/openai/v1/decisions \
    -H "Authorization: Bearer $LANGSMITH_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{
      "model": "gpt-6-luna",
      "input": "The package arrived with a broken screen.",
      "questions": [
        {
          "type": "predicate",
          "name": "damaged",
          "instructions": "Does the customer report a damaged item?"
        }
      ]
    }'
```

gateway 会保留原生的请求和响应格式：

```json
{
  "model": "gpt-6-luna",
  "answers": [
    {
      "type": "predicate",
      "name": "damaged",
      "probability": 1.0
    }
  ],
  "usage": {
    "input_tokens": 164,
    "input_tokens_details": {
      "cached_tokens": 0,
      "cache_write_tokens": 0
    },
    "output_tokens": 0,
    "output_tokens_details": {
      "reasoning_tokens": 0
    },
    "total_tokens": 164
  }
}
```

Gateway [访问](/langsmith/llm-gateway-model-access-policies)、[速率限制](/langsmith/llm-gateway-rate-limit-policies)和[预算策略](/langsmith/llm-gateway-spend-policies)适用于 Decisions 请求，token 用量也计入支出上限。gateway 会把每个请求追踪到 LangSmith，以请求作为输入，以答案和 token 用量作为输出。
