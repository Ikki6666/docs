LangSmith 建议你为 dataset schema 的输入和输出设置 schema，以确保数据一致性，并保证 examples 的格式适合下游处理，例如运行 evals。

为了更好地支持 LLM 工作流，LangSmith 支持几种预定义的预构建类型。这些 schema 由 LangSmith API 公开托管，并可通过 [JSON Schema references](https://json-schema.org/understanding-json-schema/structuring#dollarref) 在你的 dataset schema 中定义。可用 schema 如下表所示。

| Type    | JSON Schema Reference Link                                                                                                       | Usage                                                                                                                     |
| ------- | -------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| Message | [https://api.smith.langchain.com/public/schemas/v1/message.json](https://api.smith.langchain.com/public/schemas/v1/message.json) | 表示发送给 chat model 的消息，遵循 OpenAI 标准格式。 |
| Tool    | [https://api.smith.langchain.com/public/schemas/v1/tooldef.json](https://api.smith.langchain.com/public/schemas/v1/tooldef.json) | 表示 chat model 可用于 function calling 的工具定义，采用受 OpenAI JSON Schema 启发的函数格式。 |

LangSmith 允许你定义一系列 transformations，从 traces 中收集上述预构建类型并将其加入 dataset。关于可用 transformations 的更多信息，请参阅我们的[参考文档](/langsmith/dataset-transformations)。
