**Gateway Credits** 让你可以通过标准 LLM Gateway API 调用 LangChain 托管的模型，无需设置 provider account 或 key。只需使用你的 [LangSmith API key](/langsmith/create-account-api-key) 进行认证，不需要 [provider secret](/langsmith/llm-gateway-admin-setup#1-add-provider-secrets)。

gateway 会根据每个请求的 model ID 进行路由。像 `moonshotai/kimi-k3` 这样的托管模型 slug 使用 Gateway Credits。以已配置的 bring-your-own-key provider 开头的 model ID，例如 `anthropic/claude-opus-5`，则改用该 provider 的 secret。

<Card title="Base URL" icon="link">
把任何受支持的 client 指向标准 gateway API：

```text
https://gateway.smith.langchain.com/v1
```

使用你的 LangSmith API key 作为 bearer token 进行认证。

区域 base URL 请参见[区域 gateway](/langsmith/llm-gateway-how-it-works#use-a-regional-gateway)。
</Card>

## 可用模型

在请求体中按 ID 选择一个托管模型。模型 ID 不区分大小写。

| Model ID | 描述 |
| --- | --- |
| `moonshotai/kimi-k2.6` | Moonshot AI 的 Kimi K2.6，一个强大的通用模型，由 Fireworks Inference 提供支持。 |
| `moonshotai/kimi-k3` | Moonshot AI 的 Kimi K3，由 Fireworks Inference 提供支持。 |

使用标准 model-list endpoint 列出你的工作区可用的所有模型，包括已配置的 bring-your-own-key providers 和托管模型：

```bash
curl https://gateway.smith.langchain.com/v1/models \
    -H "Authorization: Bearer $LANGSMITH_API_KEY"
```

请按返回的原样使用 model ID，在 prompt 请求的 `model` 字段中传入。

## 前提条件

在使用 Gateway Credits 之前：

- 你的组织处于付费 plan（[Developer、Plus、Startup 或 Premier](/langsmith/pricing-plans)）。
- 你有一个工作区范围的 [LangSmith API key](/langsmith/create-account-api-key)，关联到具有 `gateway:invoke` 和 `workspaces:read` [权限](/langsmith/organization-workspace-operations)的角色。如果不确定，请参见 [Admin setup](/langsmith/llm-gateway-admin-setup)。

## 发起调用

把 OpenAI 兼容的 client 指向 `https://gateway.smith.langchain.com/v1`，使用你的 LangSmith API key 进行认证，并把 `model` 设置为托管模型 ID。

<CodeGroup>

```bash cURL
curl https://gateway.smith.langchain.com/v1/chat/completions \
    -H "Authorization: Bearer $LANGSMITH_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{"model":"moonshotai/kimi-k3","messages":[{"role":"user","content":"ping"}]}'
```

```python OpenAI SDK
import os

from openai import OpenAI

client = OpenAI(
    base_url="https://gateway.smith.langchain.com/v1",
    api_key=os.environ["LANGSMITH_API_KEY"],
)
response = client.chat.completions.create(
    model="moonshotai/kimi-k3",
    messages=[{"role": "user", "content": "ping"}],
)
print(response.choices[0].message.content)
```

```python LangChain
import os

from langchain.chat_models import init_chat_model

model = init_chat_model(
    model="moonshotai/kimi-k3",
    model_provider="openai",
    base_url="https://gateway.smith.langchain.com/v1",
    api_key=os.environ["LANGSMITH_API_KEY"],
)
print(model.invoke("ping").content)
```

</CodeGroup>

## 支持的 endpoint

由 Credits 付费的 chat 模型使用与 bring-your-own-key 模型相同的标准 API 格式：

| 方法和路径 | 行为 |
| --- | --- |
| `POST /v1/chat/completions` | OpenAI Chat Completions，包括流式。 |
| `POST /v1/messages` | Anthropic Messages，包括流式。 |
| `POST /v1/responses` | OpenAI Responses。 |
| `GET /v1/models` | 列出工作区可用的模型。 |

请求示例和转换行为请参见 [API 格式](/langsmith/llm-gateway-api-formats)。

## 定价

Gateway Credits 在除 Enterprise 之外的所有付费 plan 上可用。Plan 详情和当前费率请参见[定价页面](https://www.langchain.com/pricing)。Gateway Credits 以 **LangChain Standard Units (LSUs)** 计价，价格为 **每 LSU 1 美元**；每次调用会根据 token 用量消耗 LSUs。

标准 gateway [spend policies](/langsmith/llm-gateway-spend-policies) 同样适用于托管模型流量，因此你配置的任何组织、工作区、API key 或用户上限也会约束 Gateway Credits 用量。你可以用与 bring-your-own-key providers 相同的工具来控制 Gateway Credits 消耗。例如，把某个特定 API key 的所有 provider 消耗上限设为每月 200 美元，或者设置一个包含托管模型调用的全工作区日限额。

## Tracing

与所有 gateway 流量一样，托管模型调用会被追踪到 LangSmith。关于 traces 落在哪里以及如何控制访问，请参见 [Traces、Engine 与访问控制](/langsmith/llm-gateway-access)。
