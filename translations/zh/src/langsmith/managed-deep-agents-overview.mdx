Managed Deep Agents 让你把 agent 定义为一个文件夹，并在托管的 LangSmith 基础设施上运行它。你提供业务逻辑，Managed Deep Agents 提供 agent harness 和生产基础设施。

## 定义你的 agent

一个 agent 最初是一个项目文件夹，其中包含定义其行为的业务逻辑：

- **[Instructions](/langsmith/managed-deep-agents-instructions)**：定义 agent 做什么以及如何表现的 prompt。
- **[Tools](/langsmith/managed-deep-agents-tools)**：agent 可以调用的函数，用于与其他系统交互或执行操作。
- **[MCP connectors](/langsmith/managed-deep-agents-mcp-connectors)**：为 agent 提供工具的远程 MCP 服务器。
- **[Skills](/langsmith/managed-deep-agents-skills)**：可复用的、特定于任务的指令和资源。

你可以根据需要添加其他能力。完整的文件夹布局请参见 [Project structure](/langsmith/managed-deep-agents-project-structure)。

## 在托管 harness 上运行

Managed Deep Agents 结合了三层：

- **你的业务逻辑**：项目文件夹中的 instructions、tools 和 skills。
- **Agent harness**：经过实战检验的 [Deep Agents harness](/oss/deepagents/overview)，负责运行 agent 并连接其业务逻辑。
- **托管基础设施**：LangSmith 基础设施，为生产环境和多用户应用大规模运行 agent。

这种分离让你可以专注于 agent 应该做什么，而不必构建和运行它所需的系统。

## 托管基础设施

这套预设的基础设施由若干部分组成：

- **Runtime**：[LangSmith Agent Server](/langsmith/agent-server) 以持久、容错的方式运行 agent。
- **Sandboxes**：[LangSmith Sandboxes](/langsmith/sandboxes) 让 agent 可以在隔离环境中编写和执行不可信代码。
- **Evals**：Managed Deep Agents 使用 [Harbor tasks](/langsmith/managed-deep-agents-evals) 来测试 agent 行为。
- **Channels**：[channels 抽象](/langsmith/managed-deep-agents-channels)将 agent 连接到其用户所在的工作平台。
- **Memory**：[托管 memory](/langsmith/managed-deep-agents-memory) 让 agent 可以跨交互记住信息。
- **Context 管理**：[LangSmith Context Hub](/langsmith/use-the-context-hub) 管理 agent 的 instructions 和 skills。你可以在 LangSmith UI 中更新它们，而无需重新部署 agent。

要创建并部署 agent，请遵循 [Managed Deep Agents quickstart](/langsmith/managed-deep-agents-quickstart)。
