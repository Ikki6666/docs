Managed Deep Agents evals 是 [Harbor](https://www.harborframework.com/docs/tasks) 任务。使用一个带有 [`eval-engineering` skill](https://github.com/langchain-ai/langchain-skills/blob/main/config/skills/eval-engineering/SKILL.md) 的 coding agent 来检查项目、起草供你审阅的 Task Spec，并在 `evals/` 下编写完整的任务。

Managed Deep Agents 会初始化 Harbor workspace。Harbor 在隔离环境中让托管 agent 运行每个任务，并记录结果。

<ManagedDeepAgentsPublicBetaNote />

## 前提条件

在评估之前，请确保你拥有：

- 用 `mda init` 创建的 Managed Deep Agents 项目，或一个带有 agent 入口文件的现有项目。
- [`uv`](https://docs.astral.sh/uv/)，用于运行固定版本的 Harbor 和插件。
- [Docker](https://docs.docker.com/get-docker/)，Harbor 用它构建任务环境。
- 一个 coding agent。支持 Agent Skills 的 agent 可以直接安装 `eval-engineering`。其他 agent 请在会话中提供 skill 指令。

## 添加 `eval-engineering` skill

[`eval-engineering` skill](https://github.com/langchain-ai/langchain-skills/blob/main/config/skills/eval-engineering/SKILL.md) 引导 coding agent 完成 agent 发现、提出 Task Spec 和构建经过审阅的 Harbor 任务。要将它添加到当前项目，请运行：

:::python
```bash
uvx --from npx-skills skills add langchain-ai/langchain-skills --skill eval-engineering --yes
```
:::

:::js
```bash
npx skills add langchain-ai/langchain-skills --skill eval-engineering --yes
```
:::

你可以使用任何 coding agent。

<Tip>
要使用 [Deep Agents Code](/oss/deepagents/code/overview)（`dcode`），请用以下命令安装：

```bash
curl -LsSf https://langch.in/dcode | bash
```

关于 provider 设置和交互式使用，请参见 [Deep Agents Code quickstart](/oss/deepagents/code/quickstart)。
</Tip>

## 使用 coding agent 开发 evals

<Steps>
  <Step title="初始化 eval workspace" id="initialize-the-eval-workspace">

从项目根目录运行：

:::python
```bash
uv run mda evals init -i
```
:::

:::js
<CodeGroup>
    ```bash npm
    npx mda evals init -i
    ```

    ```bash pnpm
    pnpm exec mda evals init -i
    ```

    ```bash bun
    bunx mda evals init -i
    ```
</CodeGroup>
:::

交互式交接会列出检测到的 coding agents，包括 Deep Agents Code、Claude Code、Codex 和 Cursor。选择一个 agent 会在项目目录中启动该 agent 并运行 eval-engineering prompt。你也可以把 prompt 复制给其他 agent，或者退出后稍后再来。

初始化会创建：

```text
my-agent/
├── evals/
│   └── harbor-job.json
└── .mda/
    └── evals/
        ├── runtime.json
        └── harbor-adapter/
```

`evals/harbor-job.json` 归你所有。Managed Deep Agents 只在它缺失时写入，因此后续的编辑会被保留。`.mda/evals/` 下的文件是生成的。

  </Step>

  <Step title="启动 coding-agent 会话" id="start-the-coding-agent-session">

交接流程会要求所选的 coding agent 安装 `eval-engineering` skill 并将其用于本项目。如果你已经添加了该 skill，请在那个会话中继续。

让 coding agent 遵循该 skill 的审阅流程，并使用 Managed Deep Agents 的任务布局：

<Prompt
    description="Develop Harbor evals with the eval-engineering skill"
    icon="flask"
    actions={["copy"]}
>
Use the eval-engineering skill to develop Harbor evals for this Managed
Deep Agent. Inspect the project and existing evals first. Draft the Task
Spec and wait for my review before implementing the approved task directly
under {'evals/<task>/'}.
</Prompt>

与 coding agent 一起审阅 Task Spec、任务 instruction、environment、verifier 和可复用的项目知识。你批准设计后，coding agent 会编写可运行的任务。

  </Step>

  <Step title="审阅 Harbor 任务" id="review-the-harbor-task">

`evals/` 下每个直接子目录，只要包含一个 instruction 和测试，就是一个 Harbor 任务：

```text
evals/
├── harbor-job.json
└── <task>/
    ├── Task.md
    ├── instruction.md
    ├── task.toml
    ├── environment/
    │   └── Dockerfile
    └── tests/
        ├── test.sh
        └── <verifier>
```

`Task.md` 是经人工审阅的 spec。`instruction.md` 告诉 agent 要做什么。Harbor 构建任务环境，运行托管 agent，然后运行 `tests/test.sh`。Verifier 将数字 reward 写入 `/logs/verifier/reward.txt`，或将数字指标写入 `/logs/verifier/reward.json`。

完整的任务格式请参见 [Harbor task documentation](https://www.harborframework.com/docs/tasks)。

  </Step>

  <Step title="运行 evals" id="run-the-evals">

Coding-agent 交接包含一个针对项目和当前 shell 配置好的命令。从项目根目录运行该命令。

在 macOS 或 Linux 上，它具有以下形式：

```bash
HARBOR_LANGSMITH_DATASET=mda-my-agent-evals \
PYTHONPATH=.mda/evals/harbor-adapter \
uv run --env-file .env --python 3.12 --with 'harbor[langsmith]==0.21.0' harbor run \
  --config evals/harbor-job.json --yes \
  --plugin mda_harbor.job_plugin:MDAJobPlugin \
  --plugin mda_harbor.langsmith_plugin:LangSmithPlugin
```

把 `my-agent` 替换为项目目录名。生成的命令会填入名称，并在 Windows 上使用 PowerShell 语法。

编辑 agent 之后重新运行该命令，会应用项目中的更改。

  </Step>

  <Step title="检查结果" id="inspect-the-results">

打开 Harbor 结果：

```bash
uv run --python 3.12 --with 'harbor[langsmith]==0.21.0' \
  harbor view .mda/evals/jobs
```

与你的 coding agent 一起审阅失败的 trials。当 eval 没有度量预期的行为时，更新任务或 verifier。当 eval 暴露产品缺陷时，更新托管 agent，然后再次运行同一条 Harbor 命令。

  </Step>
</Steps>

## 编辑 Harbor job

编辑 `evals/harbor-job.json` 来更改 datasets、attempts、并发、environment 设置或 agent 环境变量。再次运行 `mda evals init` 时，Managed Deep Agents 会保留该文件。

## 在 LangSmith 中记录 runs

当 `LANGSMITH_API_KEY` 可用时，LangSmith 插件会将 Harbor runs 记录到 `HARBOR_LANGSMITH_DATASET` 指定的 dataset 中。
