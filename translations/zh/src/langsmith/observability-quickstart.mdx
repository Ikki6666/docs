LangSmith 通过捕获 [_traces_](/langsmith/observability-concepts#traces) 为你的 agent 提供端到端可观测性。trace 会完整记录一次请求执行过程中发生的每一步，从传入的输入到最终返回的输出。

在这个 quickstart 中，你将为一个 AI assistant 加入 tracing，并在 LangSmith 中查看结果。

traces 属于 workspace 中的[某个 agent 及其某个 environment](/langsmith/agents)。本 quickstart 会先在 LangSmith 中创建 agent，然后配置你的代码，把 traces 发送到它的标识符和环境。兼容性说明涵盖了旧版工作区和自托管 LangSmith。

<Tip>
如果你使用 [LangChain](https://docs.langchain.com/oss/python/langchain/overview) 或 [LangGraph](https://docs.langchain.com/oss/python/langgraph/overview) 构建应用，只需一个环境变量即可启用 LangSmith tracing。请参见 [trace with LangChain](/langsmith/trace-with-langchain) 或 [trace with LangGraph](/langsmith/trace-with-langgraph)。
</Tip>

## 前置条件

开始前，请确保你具备：

- **一个 LangSmith 账号**：前往 [smith.langchain.com](https://smith.langchain.com) 注册或登录。
- **一个 LangSmith API key**：按照 [Create an API key](/langsmith/create-account-api-key) 指南获取。
- **一个模型 provider API key**：可在 [OpenAI dashboard](https://platform.openai.com/account/api-keys)、[Claude Console](https://platform.claude.com/settings/keys) 或 [Google AI Studio](https://aistudio.google.com/apikey)（用于 Gemini）中生成。

在每一步的标签页中选择所用的 provider。Anthropic 和 Gemini 示例仅提供 Python 和 TypeScript 版本，因为 LangSmith Java SDK 只封装了 OpenAI client。

## 2. 构建应用

下面这个应用使用了两个 LangSmith 工具来加入 tracing：

- **Provider wrapper**：包装 [OpenAI](/langsmith/trace-openai)、[Anthropic](/langsmith/trace-anthropic) 或 [Gemini](/langsmith/trace-with-google-gemini) client，使每一次 LLM 调用都能自动记录为嵌套 span。Gemini wrapper 目前处于 [beta](/langsmith/release-stages) 阶段。
- **Traceable wrapper**：包装一个函数，使它的输入、输出以及所有嵌套 span 都作为一条完整 trace 记录到 LangSmith 中。Python 中使用 `@traceable`，TypeScript 和 Kotlin 中使用 `traceable`，Java 中使用 `Tracing.traceFunction`。

`assistant` 函数会调用一个工具函数 `get_context` 来检索相关上下文，然后再把该上下文传给模型。对这两个函数都使用 traceable wrapper，可以将整个流水线记录为一条完整 trace，其中工具调用和 LLM 调用会作为嵌套 span 出现。

创建一个名为 `app.py`、`index.ts`、`App.java` 或 `App.kt` 的文件，并写入以下代码：

<Tabs>
<Tab title="OpenAI">

<CodeGroup>

```python Python
from openai import OpenAI
from langsmith.wrappers import wrap_openai
from langsmith import traceable

client = wrap_openai(OpenAI())  # log every OpenAI call automatically

@traceable(run_type="tool")  # trace this as a tool span
def get_context(question: str) -> str:
    # In a real app, this would query a knowledge base or vector store
    return "LangSmith traces are stored for 14 days on the Developer plan."

@traceable  # capture the full pipeline as a single trace
def assistant(question: str) -> str:
    context = get_context(question)
    response = client.chat.completions.create(
        model="gpt-6-luna",
        messages=[
            {
                "role": "system",
                "content": f"Answer using the context below.\n\nContext: {context}",
            },
            {"role": "user", "content": question},
        ],
    )
    return response.choices[0].message.content

if __name__ == "__main__":
    print(assistant("How long are LangSmith traces stored?"))
```

```typescript TypeScript
import OpenAI from "openai";
import { wrapOpenAI } from "langsmith/wrappers";
import { traceable } from "langsmith/traceable";

const client = wrapOpenAI(new OpenAI()); // log every OpenAI call automatically

const getContext = traceable(
    async function getContext(question: string): Promise<string> { // trace this as a tool span
        // In a real app, this would query a knowledge base or vector store
        return "LangSmith traces are stored for 14 days on the Developer plan.";
    },
    { run_type: "tool" }
);

const assistant = traceable(async function assistant(question: string) { // capture the full pipeline as a single trace
    const context = await getContext(question);
    const response = await client.chat.completions.create({
        model: "gpt-6-luna",
        messages: [
            {
                role: "system",
                content: `Answer using the context below.\n\nContext: ${context}`,
            },
            { role: "user", content: question },
        ],
    });
    return response.choices[0]?.message?.content ?? null;
});

(async () => {
    console.log(await assistant("How long are LangSmith traces stored?"));
})();
```

from langsmith.wrappers import wrap_gemini
from langsmith import traceable

client = wrap_gemini(genai.Client())  # log every Gemini call automatically

## 4. 查看 trace

在 [LangSmith UI](https://smith.langchain.com) 中，选择你的 agent，进入 **Tracing**，然后选择在设置阶段配置的 environment。在 project-based 工作区中，打开由 `LANGSMITH_PROJECT` 指定的项目。更多信息请参见 [Navigate agents](/langsmith/navigate-agents)。

点击 `assistant` 那一行即可打开 trace。**Trajectory** 标签页会显示模型收到的对话内容。切换到 **Details** 标签页，则可以看到完整 run tree，包括 `assistant` 函数，以及其中嵌套的 `get_context` 工具调用和模型调用。

最外层 span 会捕获 `assistant` 函数的输入与输出。嵌套的 **get_context** span（TypeScript 中为 **getContext**）会记录工具调用，而模型 span（**ChatOpenAI**、**ChatAnthropic** 或 **ChatGoogleGenerativeAI**）会记录实际发给模型的 prompt 以及模型返回的响应。

<Tip>
你也可以通过 [LangSmith CLI](/langsmith/langsmith-cli) 在终端中查看 traces。
</Tip>
