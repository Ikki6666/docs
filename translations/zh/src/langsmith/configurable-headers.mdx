---
title: 使用 HTTP headers 做运行时配置
sidebarTitle: 可配置 headers
---
LangGraph 支持通过运行时配置动态修改 agent 的行为和权限。在使用 [LangSmith Deployment](/langsmith/deployment-quickstart) 时，可以在请求体中的 `config` 或特定请求头中传入这些配置。这样就能基于用户身份或其他请求上下文进行调整。

出于隐私考虑，可以通过 [`langgraph.json`](/langsmith/application-structure#configuration-file) 文件中的 `http.configurable_headers` 部分，控制哪些 headers 会传递到运行时配置中。

下面展示了如何自定义包含和排除的 headers：

```json
{
  "http": {
    "configurable_headers": {
      "includes": ["x-user-id", "x-organization-id", "my-prefix-*"],
      "excludes": ["authorization", "x-api-key"]
    }
  }
}
```

`includes` 和 `excludes` 列表既支持精确 header 名称，也支持使用 `*` 匹配任意数量字符的模式。为了安全起见，不支持其他正则表达式模式。

## 在 graph 中使用

可以在任意节点中通过 `config` 参数访问这些被包含的 headers。

```python
def my_node(state, config):
  organization_id = config["configurable"].get("x-organization-id")
  ...
```

也可以从 context 中获取它们（这在工具中，或其他嵌套函数内部很有用）。

```python
from langgraph.config import get_config

def search_everything(query: str):
  organization_id = get_config()["configurable"].get("x-organization-id")
  ...
```

甚至还可以用它来动态编译 graph。

```python
# my_graph.py.
import contextlib

@contextlib.asynccontextmanager
async def generate_agent(config):
  organization_id = config["configurable"].get("x-organization-id")
  if organization_id == "org1":
    graph = ...
    yield graph
  else:
    graph = ...
    yield graph

```

```json
{
  "graphs": {"agent": "my_grph.py:generate_agent"}
}
```

### 退出 configurable headers

如果想完全退出 configurable headers，可以在 `s` 列表中直接设置一个通配符模式：

```json
{
  "http": {
    "configurable_headers": {
      "excludes": ["*"]
    }
  }
}
```

这样会阻止所有 headers 被加入 run 的配置中。

请注意，排除规则优先于包含规则。
