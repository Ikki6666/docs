<Note>
**Private beta:** LLM Gateway 当前处于私有 [beta](/langsmith/release-stages) 阶段。我们在持续迭代过程中，API 和功能都可能发生变化。你可以加入[候补名单](https://www.langchain.com/langsmith-llm-gateway-waitlist)来申请访问权限。
</Note>

LLM Gateway 是位于你的 agents（或任意 LLM client）与它们所调用的 LLM providers 之间的一层代理。与其让每个 client 在本地保存 provider API key，不如把密钥统一存放在 LangSmith 中，作为 Provider Secrets。客户端则使用 [LangSmith API key](/langsmith/create-account-api-key) 进行认证。

当一个请求通过 gateway 时，它会：

1. 使用调用者的 LangSmith API key 进行认证。
1. 从你的工作区 Provider Secrets 中解析出真实的 provider API key。
1. 评估治理策略（支出限制、PII 脱敏、secrets 脱敏）。
1. 把请求代理到上游 provider。
1. 将这次调用追踪到 LangSmith。

每一次经 gateway 代理的调用，都会在 LangSmith 中显示为一条 [trace](/langsmith/observability-concepts#traces)。当某条策略被触发时，该事件还会流入 [LangSmith Engine](/langsmith/engine) 进行分诊，你可以在同一产品里从被拦截请求一路跳转到触发它的 trace，再跳转到修复点。

## 功能可用性

| 能力 | 说明 |
| --- | --- |
| **Spend limits** | 可在[组织](/langsmith/administration-overview#organizations)、[工作区](/langsmith/administration-overview#workspaces)、[API key](/langsmith/administration-overview#api-keys)或用户级别强制硬性拦截。当达到上限时，调用方会收到带有可执行错误信息的 402 响应。 |
| **Spend visibility** | 提供按工作区、用户和 API key 实时汇总的成本可视化。按模型粒度的可视化可通过 Custom Charts 实现。 |
| **PII redaction** | 在请求到达模型前，检测并脱敏姓名、地点、国籍、宗教、政治立场和年龄。 |
| **Secrets redaction** | 在请求到达模型前，检测并脱敏美国电话号码、美国社会安全号、API keys、tokens 和凭证。覆盖 AWS、GitHub、GitLab、OpenAI、Anthropic、GCP、Azure、Slack、Datadog、PyPI、npm、私钥以及 LangSmith tokens。 |
| **LangSmith Engine integration** | 策略违规会作为问题呈现在 LangSmith Engine 中。你可以从违规事件直接点击进入对应 trace。 |
| **Audit logging** | 对 gateway 配置的管理操作以及 gateway 调用都会被记录。 |
| **Tracing** | 每次经过 gateway 代理的调用，都会出现在与你其他 agent traces 相同的 LangSmith 工作区中。通过 gateway 路由不会打碎你的 observability。 |

## 支持的 providers

| Provider | Gateway path | Secret name |
| --- | --- | --- |
| Anthropic | `/anthropic` | `ANTHROPIC_API_KEY` |
| AWS Bedrock | `/bedrock` | `AWS_BEARER_TOKEN_BEDROCK` |
| Baseten | `/baseten` | `BASETEN_API_KEY` |
| Fireworks | `/fireworks` | `FIREWORKS_API_KEY` |
| Google Gemini | `/gemini` | `GOOGLE_API_KEY` |
| Google Vertex AI | `/vertex` | `VERTEX_SERVICE_ACCOUNT_JSON` |
| OpenAI | `/openai` | `OPENAI_API_KEY` |

## 已知限制

- **Claude Desktop:** 不支持 marketplace plugins。Chat 标签页不可见，但 Cowork 可用。
- **Codex Desktop:** 不支持 marketplace plugins。
- **Cursor:** 尚不支持 IDE 集成。
- **ChatGPT Desktop / Gemini Desktop:** 无法配置。
