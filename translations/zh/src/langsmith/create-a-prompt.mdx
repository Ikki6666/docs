## 组织你的 prompt

Playground 左侧面板是 prompt 的可编辑视图。

一个 prompt 由多条 messages 组成，每条 message 都有一个 _role_，包括：

- **System**：相当于“说明手册”。用于定义 AI 的 persona、语气和基本规则（例如 “You are a helpful assistant that explains things like the weather”）。
- **Human**：相当于“用户”。表示向 AI 提问或下达指令的人。
- **AI**：相当于“assistant”。这是模型的响应。在 playground 中，你可以用它来提供 “few-shot” 示例，向 AI 精确展示你希望它如何回应。
- **Tool / Function**：这些 roles 表示来自外部工具（如计算器或搜索引擎）的输出。它们有助于你测试 AI 在接收到特定数据后应如何表现。
- **Chat**：通用用途的 role，通常用于导入日志或对话历史，因为那类数据可能还没有被赋予明确标签。
- **Messages List**：一个动态占位符。它允许你添加一个变量，其中包含整个历史消息列表，方便管理较长的对话历史。

### 模板格式

默认的[模板格式](/langsmith/prompt-template-format)是 f-string，但你也可以点击 prompt 输入框下方的下拉菜单，将 prompt 模板格式切换为 mustache。

### 添加模板变量

当你在 prompt 中加入变量时，prompts 会变得尤其有用。你可以通过变量为 prompt 注入动态内容。添加模板变量有两种方式：

- 在 prompt 中加入 `{variable_name}`（f-string 使用一层花括号，mustache 使用两层花括号）。

添加变量后，Playground 右侧面板会出现一个 **Input** 输入框，用来为该 prompt 变量填写示例输入。填入这些值即可测试 prompt。

</Callout>

### Structured output

为 prompt 添加输出 schema 后，你就能以结构化格式获得输出。更多内容请参阅[structured output](/langsmith/prompt-engineering-concepts#structured-output)。

### Tools

你也可以点击 prompt 编辑器底部的 **+ Tool** 按钮来添加 tool。关于如何使用 tools，请参阅[使用 tools](/langsmith/use-tools)。

<Callout type="info" icon="feather">
你可以在 Playground 中使用 **[Chat](/langsmith/chat)** 借助 AI 辅助来生成 tools、创建输出 schema，以及优化 prompts。
</Callout>

## 运行 prompt

若要运行 prompt，请在 Playground 右侧面板顶部点击 <Icon icon="player-play"/> **Start**。

## 保存 prompt

若要保存 prompt，请点击 **Save** 按钮并为它命名。

你在 playground settings 中选择的模型和配置也会随 prompt 一起保存。当你重新打开这个 prompt 时，模型与配置会自动从保存的版本中加载。

<Check>
第一次创建 public prompt 时，系统会要求你设置一个 LangChain Hub handle。你所有公开的 prompts 都会关联到这个 handle。在共享 workspace 中，这个 handle 会为整个 workspace 统一设置。
</Check>

## 查看 prompts

创建 prompt 后，你可以在左侧边栏的 **Prompts** 下查看 prompt 表格。

## 添加 metadata

若要为 prompt 添加 metadata，请点击页面右上角的 <Icon icon="dots-vertical"/> **More** 图标，然后在下拉菜单中点击 <Icon icon="pencil"/> **Update metadata**。这会带你进入一个页面，你可以为 prompt 添加额外信息，例如 description 和 README。
