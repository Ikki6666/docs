许多 LLM 应用会把从向量数据库、知识图谱或其他索引中检索文档，作为检索增强生成（RAG）pipeline 的一部分。LangSmith 为 retriever 步骤提供了专门的渲染方式，这让你更容易检查被检索出的文档，并诊断检索问题。

<Note>
这些步骤是**可选的**。如果你跳过它们，retriever 数据仍然会被记录，但 LangSmith 不会使用 retriever 专属格式来渲染它。
</Note>

若要启用 retriever 专属渲染，请完成以下两步。

## 将 `run_type` 设为 retriever

在 @[traceable] 装饰器（Python）或 `traceable` wrapper（TypeScript）中传入 [`run_type="retriever"`](/langsmith/run-data-format#run-types)。这会告诉 LangSmith 把该步骤视为一个 retrieval run，并在 [LangSmith UI](https://smith.langchain.com) 中采用 retriever 专属渲染：

```python
from langsmith import traceable

@traceable(run_type="retriever")
def retrieve_docs(query):
    ...
```

如果你使用的是 [RunTree API](/langsmith/annotate-code#use-the-runtree-api) 而不是 `traceable`，那么在创建 `RunTree` 对象时传入 `run_type="retriever"` 即可。

## 以期望格式返回 documents

从你的 retriever 函数中返回一个字典列表（Python）或对象列表（TypeScript）。列表中的每一项都表示一个被检索到的文档，并且必须包含以下字段：

| Field | Type | Description |
|---|---|---|
| `page_content` | string | 被检索文档的正文文本。 |
| `type` | string | 必须始终为 `"Document"`。 |
| `metadata` | object | 关于该文档的键值对 metadata，例如 source URL、chunk ID 或 score。这些 metadata 会和文档一起显示在 trace 中。 |

下面的示例展示了一个满足以上两个要求的完整 retriever 实现：

<CodeGroup>

```python Python wrap
from langsmith import traceable

def _convert_docs(results):
    return [
        {
            "page_content": r,
            "type": "Document",
            "metadata": {"foo": "bar"}
        }
        for r in results
    ]

@traceable(run_type="retriever")
def retrieve_docs(query):
    # Returning hardcoded placeholder documents.
    # In production, replace with a real vector database or document index.
    contents = ["Document contents 1", "Document contents 2", "Document contents 3"]
    return _convert_docs(contents)

retrieve_docs("User query")
```

```typescript TypeScript wrap
import { traceable } from "langsmith/traceable";

interface Document {
    page_content: string;
    type: string;
    metadata: { foo: string };
}

function convertDocs(results: string[]): Document[] {
    return results.map((r) => ({
        page_content: r,
        type: "Document",
        metadata: { foo: "bar" }
    }));
}

const retrieveDocs = traceable((query: string): Document[] => {
    // Returning hardcoded placeholder documents.
    // In production, replace with a real vector database or document index.
    const contents = ["Document contents 1", "Document contents 2", "Document contents 3"];
    return convertDocs(contents);
}, {
    name: "retrieveDocs",
    run_type: "retriever"
});

await retrieveDocs("User query");
```

</CodeGroup>

在 LangSmith UI 中，你会看到每个被检索文档的内容以及对应 metadata。
