LangSmith REST API 提供了以编程方式访问 LangSmith 平台功能的能力，包括 tracing、datasets、experiments、annotations 等。

请在侧边栏中的 **LangSmith REST API** 部分浏览完整 API 参考。

## Authentication

在每个请求中传递 `X-Api-Key` header。其值应为有效的 [LangSmith API key](/langsmith/create-account-api-key)。

```shell
curl --request GET \
  --url https://api.smith.langchain.com/api/v1/workspaces \
  --header 'X-Api-Key: LANGSMITH_API_KEY'
```
