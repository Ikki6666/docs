[Playground](/langsmith/prompt-engineering-concepts#playground) 允许你控制 prompt 的各种设置。**Prompt Settings** 窗口包含：

- [模型配置](#model-configurations)
- [工具设置](#tool-settings)
- [Prompt 格式](#prompt-formatting)

要访问 **Prompt Settings**：

1. 在左侧边栏中进入 **Playground**。
1. 在 **Prompts** 标题下，点击模型名称旁边的齿轮 <Icon icon="settings" iconType="solid" /> 图标，即可打开 **Prompt Settings** 窗口。

## 模型配置

[模型配置](/langsmith/model-configurations)定义了 prompt 运行时所使用的参数。配置会在整个工作区中共享，因此你在这里保存的任意配置，都能在其他 LangSmith 功能中使用，并且管理员也能在 **Settings** > **Model configurations** 中看到。关于各项具体设置的细节，请参阅你的模型提供商文档（例如 [Anthropic](https://platform.claude.com/docs/en/api/messages) 或 [OpenAI](https://platform.openai.com/docs/api-reference/responses/create)）。

### 创建已保存配置

1. 在 **Model Configurations** 标签页中，按需调整模型配置，也可以先选择一个[已保存配置进行编辑](#edit-configurations)。
1. 点击顶部栏中的 **Save As** 按钮。
1. 输入配置名称和可选描述，并确认保存。
1. 配置保存后，你所在组织的任何[工作区](/langsmith/administration-overview#workspaces)成员都可以访问它。所有已保存配置都会出现在 **Model Configuration** 下拉框中。
1. 创建已保存配置后，还可以将其设为默认值，这样新建的任何 prompt 都会自动使用该配置。要设为默认值，请在下拉框中点击模型名称旁边的 **Set as default** <Icon icon="pinned" iconType="solid" /> 图标。

<Note>
只有当配置先被保存为 preset 后，OAuth client credential 字段才会出现在此弹层中。如果要为一次性配置附加 OAuth，请先将其保存为 preset（参阅[OAuth client credentials](/langsmith/model-configurations#oauth-client-credentials)）。
</Note>

### 编辑配置

1. 若要重命名已保存配置或更新其描述，直接选择配置名称或描述并进行修改。
1. 按需更新当前配置的参数，然后点击顶部的 **Save** 按钮。

### 删除配置

1. 选择想删除的配置。
1. 点击垃圾桶 <Icon icon="trash" iconType="solid" /> 图标删除它。

### Extra parameters

**Extra Parameters** 字段允许你传入 LangSmith 界面尚未直接支持的额外模型参数。它在两种情况下尤其有用：

1. 当模型提供商发布了新参数，而这些参数还没有集成进 LangSmith 界面时，你可以用 JSON 格式指定这些参数，并立刻开始使用。例如：

    ```json
    {
        "reasoning_effort": "medium"
    }
    ```

1. 当你在 Playground 中排查与参数相关的错误时，例如：

    ```
    TypeError: AsyncCompletions.create() got an unexpected keyword argument 'max_concurrency'
    ```

    如果你收到关于多余参数的错误（这种情况在使用 [LangChain JS](/oss/langchain/overview) 做 run tracing 时更常见），就可以利用这个字段去除多余参数。

## 工具设置

[_Tools_](/langsmith/prompt-engineering-concepts#tools)让你的 LLM 能够执行网页搜索、信息查询等任务。在 **Tools Settings** 标签页中，你可以管理 LLM 使用和访问 prompt 中定义的工具的方式，包括：

- **Parallel Tool Calls**：在合适时并行调用多个工具。这样模型就可以同时从不同来源收集信息。（取决于模型是否支持并行执行。）
- **Tool Choice**：选择模型可访问的工具。更多信息请参阅[在 prompt 中使用 tools](/langsmith/use-tools)。

<Callout icon="tool" color="#A855F7" iconType="regular">
如果你想管理工作区中可用的工具，包括跨 prompts 启用、禁用和编辑工具，请参阅[使用 registry 管理 tools](/langsmith/use-tools#manage-tools-with-the-registry)。
</Callout>

## Prompt 格式

**Prompt Format** 标签页允许你指定：

- **Prompt type**。关于 chat prompt 和 completion prompt 的细节，请参阅[Prompt engineering](/langsmith/prompt-engineering-concepts#prompt-types)概念页。
- **Template format**。关于 prompt 模板和变量使用的细节，请参阅[F-string vs. mustache](/langsmith/prompt-engineering-concepts#f-string-vs-mustache)。
