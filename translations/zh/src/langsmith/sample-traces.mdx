---
title: 为 traces 设置采样率
sidebarTitle: 为 traces 设置采样率
---

在处理高吞吐应用时，可能并不希望将每一条 trace 都记录到 LangSmith。采样率允许控制记录的 trace 百分比，帮助在可观测性需求与成本之间取得平衡。

本指南介绍如何使用 `LANGSMITH_TRACING_SAMPLING_RATE` 环境变量设置全局采样率，以及如何为每个 `Client` 实例设置不同的采样率，从而更细粒度地控制哪些操作会被追踪。

<Tip>
如果要基于运行时条件（例如数据敏感性、租户或功能开关）为特定请求启用或禁用 tracing，请参阅[条件追踪](/langsmith/conditional-tracing)。
</Tip>

## 设置全局采样率

<Note>
本节适用于使用 [LangSmith SDK](/langsmith/reference) 或 [LangChain](/oss/langchain/overview) 的用户，不适用于直接通过 LangSmith API 记录数据的用户。
</Note>

默认情况下，所有 trace 都会记录到 LangSmith。若要降低记录到 LangSmith 的 trace 数量，请将 `LANGSMITH_TRACING_SAMPLING_RATE` 环境变量设置为 `0`（不记录任何 trace）到 `1`（记录全部 trace）之间的任意浮点数。例如，设置以下环境变量会记录 75% 的 traces。

```bash
export LANGSMITH_TRACING_SAMPLING_RATE=0.75
```

这适用于 `traceable` 装饰器和 `RunTree` 对象。

## 为每个客户端设置不同的采样率

还可以为特定 `Client` 实例设置采样率，并配合使用 [`tracing_context`](/langsmith/annotate-code#use-the-trace-context-manager-python-only) 上下文管理器：

```python
from langsmith import Client, tracing_context

# Create clients with different sampling rates
client_1 = Client(tracing_sampling_rate=0.5)  # 50% sampling
client_2 = Client(tracing_sampling_rate=0.25)  # 25% sampling
client_no_trace = Client(tracing_sampling_rate=0.0)  # No tracing

# Use different sampling rates for different operations
with tracing_context(client=client_1):
    # Your code here - will be traced with 50% sampling rate
    agent_1.invoke(...)

with tracing_context(client=client_2):
    # Your code here - will be traced with 25% sampling rate
    agent_1.invoke(...)

with tracing_context(client=client_no_trace):
    # Your code here - will not be traced
    agent_1.invoke(...)
```

这样可以在操作级别控制采样率。

## 采样还是条件追踪

采样提供的是**概率性**的 trace 量控制，而[条件追踪](/langsmith/conditional-tracing)提供的是基于业务逻辑的**确定性**控制。

如果想在保留应用行为统计代表性的同时降低整体 trace 量，请使用**采样**。

当需要针对特定请求保证追踪行为时，请使用[条件追踪](/langsmith/conditional-tracing)，例如：

- 为零保留策略的客户端禁用 tracing。
- 根据租户将 traces 路由到不同项目。
- 处理绝不能被追踪的敏感数据。

可以将这两种方式结合使用，以更细粒度地控制可观测性策略。
