自托管 LangSmith 部署支持一定程度的 UI 自定义。

## 设置自定义 logo

对于自托管部署，你可以将 LangSmith logo 替换为你自己的。该 logo 会显示在导航侧边栏和错误屏幕上，位于 LangSmith 字标旁边。

在 Helm values 中设置 `config.customLogo`：

```yaml Helm
config:
  customLogo:
    enabled: true
    logoUrl: "https://example.com/logo.svg"
```

`logoUrl` 接受 PNG、JPG 或 SVG。不接受 Data URI。

### 为浅色和深色模式使用不同的 logo

```yaml Helm
config:
  customLogo:
    enabled: true
    lightModeLogoUrl: "https://example.com/logo-dark-text.svg"
    darkModeLogoUrl: "https://example.com/logo-white-text.svg"
```

每个名称对应 logo 显示时的配色方案。当你只设置一个值时，LangSmith 会在两种方案中都使用它。要求 Helm chart 版本 0.17.0-rc.38 或更高版本。

### 从文件提供 logo

每个 logo 值也接受根相对路径，例如 `/logos/acme.svg`。当浏览器无法访问外部主机时，请使用路径。LangSmith 会从自己的 origin 请求该路径，因此文件必须存在于 frontend 容器中。

挂载 logo 文件的步骤如下：

1. 将镜像存储在 ConfigMap 中。文件名会成为 URL 的最后一段：

   ```bash
   kubectl create configmap langsmith-custom-logo \
     --from-file=acme.svg=./your-logo.svg \
     -n <your-namespace>
   ```

2. 将 ConfigMap 挂载到 frontend pod 中，并将 `logoUrl` 指向该路径：

   ```yaml Helm
   config:
     customLogo:
       enabled: true
       logoUrl: "/logos/acme.svg"

   frontend:
     deployment:
       volumes:
         - name: custom-logo
           configMap:
             name: langsmith-custom-logo
       volumeMounts:
         - name: custom-logo
           mountPath: /usr/share/nginx/html/build/logos
           readOnly: true
   ```

3. 升级 release，然后确认文件已被提供：

   ```bash
   curl -sI https://<your-langsmith-host>/logos/acme.svg
   ```

   `content-type` 为 `image/svg+xml` 表示 logo 已就位。文件缺失时会返回 HTTP 200 和应用的 HTML 而不是 404，因此请检查 content type 而不是状态码。

<Note>
当你的 values 已经设置了 `frontend.deployment.volumes` 或 `frontend.deployment.volumeMounts` 时，请向这些列表追加内容。替换它们会移除其他设置所依赖的挂载。
</Note>

当你通过 base path 提供 LangSmith 时，请将其包含在值中：`/<base-path>/logos/acme.svg`。完整的 Helm values 列表请参见 [Environment variables](/langsmith/self-host-environment-variables)。

## 设置自定义错误支持信息

默认情况下，LangSmith 中的错误消息会引导用户前往 [Support Portal](https://support.langchain.com)。你可以将其替换为你自己的支持联系方式。

设置后，UI 中所有错误与支持相关消息都会显示你的自定义文本，而不是默认的 LangChain 支持邮箱。

<Note>
自定义消息只会以**纯文本**形式渲染。HTML tags 不会被解析，而是会按字面文本显示。
</Note>

```yaml Helm
config:
  customErrorSupportMessage: "For help, contact your internal IT team at helpdesk@example.com"
```

如果要恢复默认行为，请移除该设置，或将其设为空字符串。
