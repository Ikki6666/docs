本指南将带你了解如何使用你的自托管 LangSmith 实例。

<Info>
本指南假设你已经部署好了一个自托管 LangSmith 实例。如果尚未部署，请参阅 [kubernetes deployment guide](/langsmith/kubernetes)。
</Info>

### Configuring the application you want to use with LangSmith

LangSmith 使用一套统一 API 与 hub 和 LangSmith backend 交互。

1. 部署实例后，你可以通过 `http(s)://<host>` 访问 LangSmith UI。
2. LangSmith API 可通过 `http(s)://<host>/api/v1` 访问。
3. LangSmith Control Plane 可通过 `http(s)://<host>/api-host` 访问。

若要使用你实例的 API，需要在应用中设置以下环境变量：

```bash
LANGSMITH_ENDPOINT=http://<host>/api/v1
LANGSMITH_API_KEY=foo # Set to a legitimate API key if using OAuth
```

你也可以直接在 LangSmith SDK client 中配置这些变量：

```python
import langsmith
langsmith_client = langsmith.Client(
    api_key='<api_key>',
    api_url='http(s)://<host>/api/v1',
)
```

设置完成后，你应当就可以运行代码，并在自托管实例中看到结果。我们建议你先走一遍 [*quickstart guide*](https://docs.smith.langchain.com/#quick-start)，快速了解 LangSmith 的使用方式。

### Self-Signed certificates

如果你的自托管 LangSmith 实例使用的是 self-signed certificates，这可能会带来问题，因为 Python 自带一套受信任证书，而其中可能不包含你的自签名证书。要解决这个问题，你可能需要使用类似 `truststore` 这样的工具，将系统证书加载到 Python 环境中。

你可以按如下方式操作：

1. `pip install truststore`（或根据你所使用的包管理器采用类似方式安装）

然后使用以下代码加载系统证书：

```python
import truststore
truststore.inject_into_ssl()
# The rest of your code
import langsmith
langsmith_client = langsmith.Client(
    api_key='<api_key>',
    api_url='http(s)://<host>/api/v1',
)
```
