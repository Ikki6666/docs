---
title: 如何在实验中重试失败的 runs（仅限 Python）
sidebarTitle: 失败实验 runs 的重试（Python）
---


当你在大型 [datasets](/langsmith/evaluation-concepts#datasets) 上运行[评估](/langsmith/evaluation-concepts#evaluation-lifecycle)时，可能会因为速率限制、网络问题或其他瞬时错误，导致只有少量 examples 失败。与其重新运行整个评估，不如只识别并重试 [experiment](/langsmith/evaluation-concepts#experiment) 中失败的 examples。

本指南展示了一种把重试逻辑构建进评估工作流的方法，只重试失败的 examples。你可以使用 `error_handling='ignore'` 参数跳过记录出错的 runs，然后自动识别不成功的 examples，并在 Python 中重新运行它们。


## Step 1. Run the initial evaluation
运行初始评估，并忽略错误，以避免将出错的 runs 记录下来：

```python
from langsmith import Client

client = Client()

# Run initial evaluation, ignoring errors
# error_handling='ignore' prevents errored runs from being logged
results = await client.aevaluate(
    target,
    data="dataset",
    evaluators=[your_evaluators],
    error_handling='ignore'
)
```

## Step 2. Retry on failed examples and log to same experiment

先获取所有未成功的 examples：
```python
# Identify unsuccessful examples
runs = client.list_runs(project_name=results.experiment_name)
successful_example_ids = [r.reference_example_id for r in runs]
unsuccessful_examples = (e for e in client.list_examples(dataset_name="dataset") if e.id not in successful_example_ids)
```

然后，只重新运行失败的 examples，并把它们记录到同一个 experiment 中：
```python
# Retry only the failed examples, log
results_retry = await client.aevaluate(
    target,
    unsuccessful_examples,
    evaluators=[your_evaluators],
    experiment=results.experiment_name,
    error_handling='ignore'
)
```
