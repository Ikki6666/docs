本指南介绍如何为 LangSmith API 文档自定义 OpenAPI 安全模式。完善的安全模式文档可以帮助 API 使用者理解如何向你的 API 进行身份验证，甚至还能启用自动化客户端生成。关于 LangGraph 身份验证系统的更多细节，请参阅[身份验证与访问控制概念指南](/langsmith/auth)。

<Note>
**实现与文档**
本指南只涵盖如何在 OpenAPI 中记录你的安全要求。要实现实际的身份验证逻辑，请参阅[如何添加自定义身份验证](/langsmith/custom-auth)。
</Note>

本指南适用于所有 LangSmith 部署，包括 Cloud 和 self-hosted。不适用于你在未使用 LangSmith 的情况下使用 LangGraph 开源库。

## 默认模式

默认安全模式会随部署类型变化：

<Tabs>
    <Tab title="LangSmith">
    </Tab>
</Tabs>

默认情况下，LangSmith 要求在 `x-api-key` 请求头中提供 LangSmith API key：

```yaml
components:
  securitySchemes:
    apiKeyAuth:
      type: apiKey
      in: header
      name: x-api-key
security:
  - apiKeyAuth: []
```

当你使用 LangGraph SDK 之一时，这些信息也可以从环境变量中推断出来。

<Tabs>
    <Tab title="Self-hosted">
    </Tab>
</Tabs>

默认情况下，self-hosted 部署没有安全模式。这意味着它只能部署在受保护的网络中，或者需要你自行加上身份验证。如果要添加自定义身份验证，请参阅[如何添加自定义身份验证](/langsmith/custom-auth)。

## 自定义安全模式

如果要自定义 OpenAPI 文档中的安全模式，请在 `langgraph.json` 的 `auth` 配置中添加一个 `openapi` 字段。请记住，这只会更新 API 文档，你仍然必须像[如何添加自定义身份验证](/langsmith/custom-auth)中演示的那样实现对应的身份验证逻辑。

还需要注意，LangSmith 本身不提供身份验证端点。你需要在客户端应用中处理用户身份验证，并把得到的凭证传递给 LangGraph API。

<Tabs>
    <Tab title="OAuth2 with Bearer Token">
    ```json
    {
      "auth": {
        "path": "./auth.py:my_auth",  // Implement auth logic here
        "openapi": {
          "securitySchemes": {
            "OAuth2": {
              "type": "oauth2",
              "flows": {
                "implicit": {
                  "authorizationUrl": "https://your-auth-server.com/oauth/authorize",
                  "scopes": {
                    "me": "Read information about the current user",
                    "threads": "Access to create and manage threads"
                  }
                }
              }
            }
          },
          "security": [
            {"OAuth2": ["me", "threads"]}
          ]
        }
      }
    }
    ```
    </Tab>
    <Tab title="API Key">
    ```json
    {
      "auth": {
        "path": "./auth.py:my_auth",  // Implement auth logic here
        "openapi": {
          "securitySchemes": {
            "apiKeyAuth": {
              "type": "apiKey",
              "in": "header",
              "name": "X-API-Key"
            }
          },
          "security": [
            {"apiKeyAuth": []}
          ]
        }
      }
    }
    ```
    </Tab>
</Tabs>

## 测试

更新配置后：

1. 部署你的应用
2. 访问 `/docs`，查看更新后的 OpenAPI 文档
3. 使用你的身份验证服务器签发的凭证来尝试调用接口，请确保你已经先实现了身份验证逻辑
