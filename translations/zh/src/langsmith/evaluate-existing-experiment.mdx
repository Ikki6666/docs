---
title: "如何为现有实验添加 evaluators（仅限 Python）"
sidebarTitle: 评估现有实验（Python）
---

对现有实验进行评估目前仅支持 Python SDK。

在运行实验后，你可能希望**在不重新运行应用的前提下添加新的评估指标**。当你新增了 evaluators，或想对现有结果应用不同的评分标准时，这会非常有用。你无需再次对所有 examples 重新执行目标函数，而是可以直接对现有实验 traces 进行评估。

要为现有实验添加 evaluators，请将实验名称或 ID 传给 `evaluate()` / `aevaluate()`，而不是传入目标函数。Evaluators 会基于原始实验中已缓存的 traces 运行，并访问其中记录的 inputs、outputs 以及任何中间步骤。

## Example


```python
from langsmith import evaluate

def always_half(inputs: dict, outputs: dict) -> float:
    return 0.5

experiment_name = "my-experiment:abc"  # Replace with an actual experiment name or ID

evaluate(experiment_name, evaluators=[always_half])
```
