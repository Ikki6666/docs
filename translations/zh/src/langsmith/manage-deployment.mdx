管理 Cloud deployment 的 repository、branch 和自动更新设置。你还可以在不再需要时删除一个 deployment。

## 配置 deployment 设置

要配置 deployment 设置：

1. 在 **Deployments** 视图中，选择一个 deployment。
1. 在右上角，选择齿轮图标（**Deployment Settings**）。
1. （可选）要从另一个 GitHub repository 构建，选择 **Change repository** 并选择该 repository。详情请参阅 [Change the repository](#change-the-repository)。
1. 根据需要更新 **Git Branch**。
1. 启用或禁用 **Automatically update deployment on push to branch**。

Branch 和 tag 的创建或删除事件不会触发 revisions。只有对已有 branch 的推送才会触发更新。

当多个推送在短时间内相继发生时，LangSmith 会将这些更新排队。当前 build 完成后，LangSmith 会构建最新的 commit，并跳过其他排队的 commits。

### 更改 repository

在重命名 repository、将其转移到另一个 GitHub 账户，或将你的 agent 移到另一个 repository 之后，可以更改 repository。LangSmith 会检查 `hosted-langserve` GitHub app 是否可以访问该 repository，以及该 repository 的 Git branch 上是否包含该 deployment 的配置文件。保存不会创建 revision；下一个 revision 会从新 repository 构建。

如果你已将 repository 转移到另一个 GitHub 账户，请先[给该 app 访问权限](/langsmith/deploy-to-cloud#manage-github-repository-access)。

要通过 API 更改 repository，请在 `PATCH /v2/deployments/{deployment_id}` 请求中发送 `source_config.repo_url`。更多信息请参阅 [Control plane API reference](/langsmith/api-ref-control-plane)。

## 删除 deployment

<Tabs>
  <Tab title="LangSmith UI">
    要删除一个 deployment：

    1. 在 [LangSmith UI](https://smith.langchain.com) 中，选择 **Deployments**。
    1. 选择该 deployment 的菜单图标，然后选择 **Delete**。
    1. 在确认模态框中，选择 **Delete**。
  </Tab>
  <Tab title="LangGraph CLI">
    要查找 deployment ID，请运行：

    ```shell
    langgraph deploy list
    ```

    按 ID 删除该 deployment：

    ```shell
    langgraph deploy delete <DEPLOYMENT_ID>
    ```

    要跳过确认提示，请传入 `--force`：

    ```shell
    langgraph deploy delete --force <DEPLOYMENT_ID>
    ```
  </Tab>
</Tabs>

<Note>
删除是异步的。该 deployment 会立即从 **Deployments** 视图中消失，但 LangSmith 会分阶段移除其基础设施和 metadata。在删除完成之前，该 deployment 名称可能保持不可用。
</Note>
