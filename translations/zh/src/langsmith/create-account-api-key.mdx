要开始使用 LangSmith，你需要先创建一个账户。你可以在 [LangSmith UI](https://smith.langchain.com) 中注册免费账户。LangSmith 支持使用 Google、GitHub 和邮箱登录。

## API 密钥

LangSmith 支持两种 API 密钥。两种令牌都可以用于向 LangSmith API 发起认证请求，但适用场景不同：

- [**个人访问令牌（PAT）**](/langsmith/administration-overview#personal-access-tokens-pats) 会继承创建它的用户权限。适用于个人脚本或工具。
- [**服务密钥**](/langsmith/administration-overview#service-keys) 可以限定到特定[工作区](/langsmith/administration-overview#workspaces)或整个[组织](/langsmith/administration-overview#organizations)。适用于应用程序和生产服务。

要使用 LangSmith 记录 [traces](/langsmith/observability-concepts#traces) 并运行[评估](/langsmith/evaluation)，请创建一个 API 密钥来认证你的请求。

<Steps>
  <Step title="打开 API Keys 设置" icon="settings">
    前往 [**Settings** 页面](https://smith.langchain.com/settings)，然后选择 **API Keys** 区域。
  </Step>
  <Step title="配置密钥类型" icon="key">
    对于服务密钥，你需要在组织级和工作区级之间进行选择。如果密钥作用域是工作区级，就必须指定对应工作区。

    [企业版](/langsmith/pricing-plans)用户还可以为服务密钥[分配特定的工作区角色](/langsmith/administration-overview#workspace-roles-rbac)，从而独立于任何用户来调整其权限。
  </Step>
  <Step title="设置过期时间" icon="calendar">
    设置密钥的有效期。你可以选择若干天后失效，或者选择永不过期。
  </Step>
  <Step title="创建密钥" icon="circle-check">
    点击 **Create API Key**。LangSmith 只会显示一次 API 密钥，因此请务必复制并妥善保存。
  </Step>
</Steps>

<Tip>
  [企业版](/langsmith/pricing-plans)组织管理员可以在不轮换密钥的情况下，编辑现有服务密钥的[角色](/langsmith/administration-overview#workspace-roles-rbac)。在 [**Settings** 页面](https://smith.langchain.com/settings) 的 **API Keys** 区域切换到 **Service** 标签页，点击任意服务密钥行打开编辑对话框。更新工作区角色，如果是组织级密钥，也可以更新组织角色，然后点击 **Save**。密钥字符串本身不会变化。
</Tip>

## 停用或删除 personal access token

停用会临时使 PAT 停止认证；删除则会将其永久移除。当你需要保留 token 记录并稍后重新启用时，请选择停用。

成员可以停用、重新启用和删除自己的 PAT。[Organization Admins](/langsmith/rbac#organization-admin) 和 [Organization Operators](/langsmith/rbac#organization-operator) 还可以管理任意成员的 PAT。

| 操作 | 效果 | 是否可逆 |
| --- | --- | --- |
| **Deactivate** | 停止认证，但保留记录，且所有者和最近使用时间会带着 **Deactivated** 徽标继续可见。 | 是。选择 **Reactivate key** 即可再次使用同一个 token。 |
| **Reactivate** | 允许同一个 token 再次认证，并保留其原始过期时间。 | 是。可以随时再次停用该 token。 |
| **Delete** | 永久移除 token 及其记录。 | 否。如果需要再次访问，请新建一个 token。 |

停用不会改变 token 的过期时间，一旦过期时间已过，**Reactivate key** 便不可用。此时请新建一个 token。

如需停用或删除 PAT：

1. 前往 [**Settings**](https://smith.langchain.com/settings) > **API Keys**，打开 **Personal** 标签页。
2. 在 **My keys** 下找到该 token。要管理其他成员的 token，请切换到 **All members**。
3. 在 **Actions** 列中选择 **Deactivate key** 或 **Delete key**。每个操作都会打开各自对应的确认对话框。
4. 输入对话框中显示的 token 描述。对于没有描述的 token，请改为输入 **Key** 列中的短 key。
5. 选择 **Deactivate** 或 **Delete** 进行确认。成功后会显示确认通知。

要重新启用已停用的 PAT，请在 **Actions** 列中选择 **Reactivate key**。重新启用只需点击一次，无需确认对话框，完成后会显示成功通知。

认证结果会被缓存，因此被停用或删除的 token 会在一分钟内停止工作，而不是立即失效。重新启用的 token 也可能要等到缓存的拒绝结果过期后才能使用。

[审计日志](/langsmith/audit-logs)会将停用记录为 `revoke_personal_access_token`，将重新启用记录为 `reinstate_personal_access_token`。

Service keys 只能删除，不能停用。打开 **Service** 标签页，在 **Actions** 列中选择 **Delete key**，然后像删除 PAT 一样输入描述进行确认。

## 配置 SDK

先安装对应语言的 SDK：

<Tabs>
  <Tab title="Python">
    <CodeGroup>
      ```bash pip
      pip install langsmith
      ```
      ```bash uv
      uv add langsmith
      ```
    </CodeGroup>
  </Tab>
  <Tab title="TypeScript">
    ```bash
    npm install langsmith
    ```
  </Tab>
</Tabs>

完整细节请参阅 [Python SDK](/langsmith/smith-python-sdk) 或 [JS/TS SDK](/langsmith/smith-js-ts-sdk) 参考文档。

然后，设置你的 API 密钥并启用 tracing：

```bash
export LANGSMITH_API_KEY=<your-api-key>
export LANGSMITH_TRACING=true
```

你可能还需要设置以下额外环境变量：

- `LANGSMITH_ENDPOINT` 用于控制 SDK 将数据发送到哪个 LangSmith 服务器。默认值是 `https://api.smith.langchain.com`（GCP US）。只有在你使用其他部署时才需要设置它。对于区域化 SaaS，请将其设置为你所在区域的 API URL：

    <SaasRegionUrls prefix="api.smith" />

- `LANGSMITH_WORKSPACE_ID` 只有在你的 API 密钥可以访问多个[工作区](/langsmith/administration-overview#workspaces)时才需要。你可以在 [**Settings** 页面](https://smith.langchain.com/settings) 的 **General** 区域找到 Workspace ID：

    `LANGSMITH_WORKSPACE_ID=<Workspace ID>`

如果你想在本地 shell 或远程运行时之间复用端点、API 密钥和工作区设置，请参阅 [Profile configuration](/langsmith/profile-configuration)。
