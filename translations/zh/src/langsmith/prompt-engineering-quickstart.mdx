Prompts 会引导 Large Language Models（LLM）的行为。[_Prompt engineering_](/langsmith/prompt-engineering-concepts) 指的是设计、测试和不断改进你提供给 LLM 的指令，从而让它产出稳定且有用的响应。

LangSmith 提供了创建、版本管理、测试和协作编辑 prompts 的工具。你也会接触到一些常见概念，例如 [_prompt templates_](/langsmith/prompt-engineering-concepts#prompts-vs-prompt-templates)，它能帮助你复用结构化 prompts；还有 [_variables_](/langsmith/prompt-engineering-concepts#f-string-vs-mustache)，它允许你把值（例如用户问题）动态插入 prompt。

在这个 quickstart 中，你将使用 UI 或 SDK 来创建、测试并改进 prompts。这里会以 OpenAI 作为示例 LLM provider，但同样的工作流也适用于其他 providers。

## 前置条件

开始前，请确保你已经准备好：

- **一个 LangSmith 账号**：在 [smith.langchain.com](https://smith.langchain.com) 注册或登录。
- **一个 LangSmith API key**：参考 [Create an API key](/langsmith/create-account-api-key)。
- **一个 OpenAI API key**：从 [OpenAI dashboard](https://platform.openai.com/account/api-keys) 生成。

## 4. 迭代 prompt

LangSmith 支持团队协作式的 prompt 迭代。[Workspace](/langsmith/administration-overview#workspaces) 成员可以在 Playground 中试验 prompts，并在准备好后，把更改保存为新的 [_commit_](/langsmith/prompt-engineering-concepts#commits)。

如果要改进 prompts：

- 参考你的模型 provider 官方文档中关于 prompt 创建的最佳实践，例如：
    - [Best practices for prompt engineering with the OpenAI API](https://help.openai.com/en/articles/6654000-best-practices-for-prompt-engineering-with-the-openai-api)
    - [Gemini's Introduction to prompt design](https://ai.google.dev/gemini-api/docs/prompting-intro)
- 使用 LangSmith 中的交互式工具 Prompt Canvas 来构建和打磨 prompts。详情请参见 [Prompt Canvas guide](/langsmith/write-prompt-with-ai)。
- 为特定 commits 打上 tag，用来标记 commit 历史中的关键节点。
    1. 若要创建 commit，请进入 **Playground**，点击 **Commit**。选择你要提交更改的 prompt，然后点击 **Commit**。
    1. 进入左侧菜单中的 **Prompts**，选择对应 prompt。在 prompt 详情页右上角点击 **Tag**，添加一个 [commit tag](/langsmith/manage-prompts#commit-tags)。

## 2. 创建 prompt

要创建 prompt，你需要先定义一个消息列表，描述你希望这个 prompt 包含的内容，然后把它 push 到 LangSmith。

请使用对应语言的构造方式和 push 方法：

- Python：@[`ChatPromptTemplate`] → [`client.push_prompt(...)`](https://docs.smith.langchain.com/reference/python/client/langsmith.client.Client#langsmith.client.Client.push_prompt)
- TypeScript：[`ChatPromptTemplate.fromMessages(...)`](https://reference.langchain.com/javascript/langchain-core/prompts/ChatPromptTemplate) → [`client.pushPrompt(...)`](https://reference.langchain.com/javascript/langsmith/client/Client/pushPrompt)

1. 把以下代码加入一个名为 `create_prompt` 的文件中：

    <CodeGroup>

    ```python Python
    from langsmith import Client
    from langchain_core.prompts import ChatPromptTemplate

    client = Client()

    prompt = ChatPromptTemplate([
        ("system", "You are a helpful chatbot."),
        ("user", "{question}"),
    ])

    client.push_prompt("prompt-quickstart", object=prompt)
    ```

    ```typescript TypeScript
    import { Client } from "langsmith";
    import { ChatPromptTemplate } from "@langchain/core/prompts";

    const client = new Client();

    const prompt = ChatPromptTemplate.fromMessages([
    ["system", "You are a helpful chatbot."],
    ["user", "{question}"],
    ]);

    await client.pushPrompt("prompt-quickstart", {
    object: prompt,
    });
    ```

    </CodeGroup>

    这段代码会创建一个有序消息列表，用 `ChatPromptTemplate` 包装后，再通过名称 push 到你的 [workspace](/langsmith/administration-overview#workspaces) 中，以便版本管理和复用。

1. 运行 `create_prompt`：

    <CodeGroup>

    ```python Python
    python create_prompt.py
    ```

    ```typescript TypeScript
    npx tsx create_prompt.ts
    ```

    </CodeGroup>

执行后，打开输出的链接，就可以在 LangSmith UI 中查看新建的 Prompt Hub prompt。

## 3. 测试 prompt

在这一步中，你会按名称（`"prompt-quickstart"`）pull 出你在[第 2 步](#2-create-a-prompt)中创建的 prompt，用一个测试输入对它进行格式化，把它转换成 OpenAI 的 chat 格式，然后调用 OpenAI Chat Completions API。

接着，你还会通过创建新版本来继续迭代这个 prompt。Workspace 成员可以打开已有 prompt，在 [UI](https://smith.langchain.com) 中试验各种修改，并把这些修改保存为同一个 prompt 上的新 commit，从而为整个团队保留历史。

1. 把以下内容加入一个名为 `test_prompt` 的文件中：

    <CodeGroup>

    ```python Python
    from langsmith import Client
    from openai import OpenAI
    from langchain_core.messages import convert_to_openai_messages

    client = Client()
    oai_client = OpenAI()

    prompt = client.pull_prompt("prompt-quickstart")

    # Since the prompt only has one variable you could also pass in the value directly
    # Equivalent to formatted_prompt = prompt.invoke("What is the color of the sky?")
    formatted_prompt = prompt.invoke({"question": "What is the color of the sky?"})

    response = oai_client.chat.completions.create(
        model="gpt-5.5",
        messages=convert_to_openai_messages(formatted_prompt.messages),
    )
    ```

    ```typescript TypeScript
    import { OpenAI } from "openai";
    import { pull } from "langchain/hub"
    import { convertPromptToOpenAI } from "@langchain/openai";

    const oaiClient = new OpenAI();

    const prompt = await pull("prompt-quickstart");

    // Format the prompt with the question
    const formattedPrompt = await prompt.invoke({ question: "What is the color of the sky?" });

    const response = await oaiClient.chat.completions.create({
        model: "gpt-5.5",
        messages: convertPromptToOpenAI(formattedPrompt).messages,
    });
    ```
    </CodeGroup>

    这段代码会使用 `pull` 按名称加载 prompt，并获取该 prompt 最新 commit 的版本来做测试。如果你想指定某个具体 commit，也可以传入 `"<prompt-name>:<commit-hash>"` 这样的形式。

1. 运行 `test_prompt`：

    <CodeGroup>

    ```python Python
    python test_prompt.py
    ```

    ```typescript TypeScript
    npx tsx test_prompt.ts
    ```

    </CodeGroup>

1. 如果想为某个 prompt 创建一个新版本，请再次使用与你最初相同的 push 方法，继续使用同一个 prompt 名称，并传入更新后的模板。LangSmith 会把它记录为新的 commit，同时保留之前的版本。

    把下面代码复制到一个名为 `iterate_prompt` 的文件中：

    <CodeGroup>

    ```python Python
    from langsmith import Client
    from langchain_core.prompts import ChatPromptTemplate

    client = Client()

    new_prompt = ChatPromptTemplate([
        ("system", "You are a helpful chatbot. Respond in Spanish."),
        ("user", "{question}"),
    ])

    client.push_prompt("prompt-quickstart", object=new_prompt)
    ```

    ```typescript TypeScript
    import { Client } from "langsmith";
    import { ChatPromptTemplate } from "@langchain/core/prompts";

    const client = new Client();

    const newPrompt = ChatPromptTemplate.fromMessages([
        ["system", "You are a helpful chatbot. Speak in Spanish."],
        ["user", "{question}"]
    ]);

    await client.pushPrompt("prompt-quickstart", {
        object: newPrompt
    });
    ```

    </CodeGroup>

1. 运行 `iterate_prompt`：

    <CodeGroup>

    ```python Python
    python iterate_prompt.py
    ```

    ```typescript TypeScript
    npx tsx iterate_prompt.ts
    ```
    </CodeGroup>

    现在你的 prompt 将会包含两个 commits。
