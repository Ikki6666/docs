有些应用围绕多模态内容构建，例如一个可以回答 PDF 或图片相关问题的 chatbot。在这类场景中，你会希望在 prompt 中包含多模态内容，并测试模型是否能够围绕这些内容回答问题。

Playground 支持两种方式将多模态内容纳入 prompt：

1. Inline content：将静态文件（图片、PDF、音频）直接嵌入 prompt 中。当你希望在 prompt 的所有使用场景中始终包含同一份多模态内容时，这种方式最合适。例如，你可能会放入一张参考图片，用来帮助模型的回答更有依据。

2. Template variables：为附件创建动态占位符，以便每次填充不同内容。这种方式更灵活，允许你：

   * 测试模型如何处理不同输入
   * 创建可复用的 prompts，以适配不同内容

<Note>
并非所有模型都支持多模态内容。在 Playground 中使用多模态功能前，请先确认你选择的模型支持你要使用的文件类型。
</Note>

## Inline content

在你希望添加多模态内容的消息中，点击文件图标。在 `Upload content` 标签下，你可以上传文件，并将其以内联方式包含到 prompt 中。

![Upload inline multimodal content](/langsmith/images/upload-inline-multimodal-content.png)

## Template variables

在你希望添加多模态内容的消息中，点击文件图标。在 `Template variables` 标签下，你可以为特定附件类型创建 template variable。目前只支持图片、PDF 和音频文件（`.wav`、`.mp3`）。

![Template variable multimodal content](/langsmith/images/template-variable-multimodal-content.png)

## Populate the template variable

添加 template variable 后，你可以使用屏幕右侧面板为其提供内容。只需点击 `+` 按钮上传或选择内容，该内容就会用于填充 template variable。

![Manual prompt multimodal](/langsmith/images/manual-prompt-multimodal.png)

## Run an evaluation

在手动测试 prompt 之后，你可以[运行评估](/langsmith/evaluate-with-attachments?mode=ui)，查看该 prompt 在一组 golden dataset examples 上的表现。
