---
title: 如何定义 code evaluator
sidebarTitle: Code evaluator
---

[LangSmith UI](https://smith.langchain.com) 中的 code evaluators 允许你直接在界面中用 Python 或 TypeScript 代码编写自定义评估逻辑。不同于依赖模型来评估输出的 [LLM-as-a-judge](/langsmith/llm-as-judge) evaluators，code evaluators 使用的是你自己定义的确定性逻辑。

<Note>
如果你想通过 SDK 以编程方式定义 code evaluators，请参阅[如何定义 code evaluator（SDK）](/langsmith/code-evaluator-sdk)。如果你想基于 dataset examples 中保存的 assertions 来给输出打分，请参阅[使用 assertions](/langsmith/assertions)。
</Note>

## 第 1 步：创建 evaluator

1. 从 [LangSmith UI](https://smith.langchain.com) 中以下任一页面创建 evaluator：
    - 在 Playground 中，或从某个 dataset 页面：选择 **+ Evaluator** 按钮。
    - 选择 **Add rules**，配置你的规则，然后选择 **Apply evaluator**。
1. 为 evaluator 起一个清晰名称，准确描述它要衡量的内容（例如 “Exact Match”）。
1. 从 evaluator 类型选项中选择 **Create code evaluator**。

## 第 2 步：编写 evaluator 代码

<Note>
**Custom code evaluators 限制**

**允许使用的库**：你可以导入所有标准库函数，以及以下公开包：

```
numpy (v2.2.2): "numpy"
pandas (v1.5.2): "pandas"
jsonschema (v4.21.1): "jsonschema"
scipy (v1.14.1): "scipy"
sklearn (v1.26.4): "scikit-learn"
```

**网络访问**：在 custom code evaluator 中，不能访问互联网。
</Note>

在 **Add Custom Code Evaluator** 页面中，使用 Python 或 TypeScript 定义你的评估逻辑。

你的 evaluator 函数必须命名为 `perform_eval`，并且应当：

1. 接收 `run` 和 `example` 两个参数。
1. 通过 `run['inputs']`、`run['outputs']` 和 `example['outputs']` 访问数据。
1. 返回一个字典，其中每个 key 都是一个指标名称，每个 value 都是该指标对应的分数。每个 key 都表示一条你希望返回的 feedback。例如，`{"correctness": 1, "silliness": 0}` 会在该 run 上创建两条 feedback。

### 函数签名

```python
def perform_eval(run, example):
    # Access the data
    inputs = run['inputs']
    outputs = run['outputs']
    reference_outputs = example['outputs']  # Optional: reference/expected outputs

    # Your evaluation logic here
    score = ...

    # Return a dict with your metric name
    return {"metric_name": score}
```

### 示例：精确匹配 evaluator

```python
def perform_eval(run, example):
    """Check if the answer exactly matches the expected answer."""
    actual = run['outputs']['answer']
    expected = example['outputs']['answer']

    is_correct = actual == expected
    return {"exact_match": is_correct}
```

### 示例：基于输入的 evaluator

```python
def perform_eval(run, example):
    """Check if the input text contains toxic language."""
    text = run['inputs'].get('text', '').lower()
    toxic_words = ["idiot", "stupid", "hate", "awful"]

    is_toxic = any(word in text for word in toxic_words)
    return {"is_toxic": is_toxic}
```

## 第 3 步：测试并保存

1. 用示例数据测试 evaluator，确保其行为符合预期
2. 点击 **Save**，使该 evaluator 可供后续使用

## 使用你的 code evaluator

创建完成后，你可以在以下场景使用 code evaluator：

- 在 [Playground](/langsmith/prompt-engineering-concepts#playground) 中运行评估时
- 作为 dataset 的一部分，用于[自动在实验上运行评估](/langsmith/bind-evaluator-to-dataset)
