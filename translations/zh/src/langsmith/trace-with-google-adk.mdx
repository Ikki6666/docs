本指南介绍如何在 LangSmith 中追踪 [Google Agent Development Kit (ADK)](https://github.com/google/adk-python) agents。你将为 ADK 应用配置自动 tracing，以捕获 agent 调用、工具调用以及 LLM 交互。

<Note>
本指南覆盖 ADK 的标准执行路径（文本 agent、tools 和 multi-agent workflows）。如果要追踪 **Gemini Live** 语音 agent，它使用的是 ADK 的 `Runner.run_live` 流式循环，请参阅[追踪 Gemini Live 应用](/langsmith/trace-gemini-live)。
</Note>

## 配置 tracing

要追踪 ADK agents，请使用 LangSmith SDK 中的 `configure_google_adk()`。在创建任何 ADK agents 之前，于应用启动时调用一次该函数：

```python
from langsmith.integrations.google_adk import configure_google_adk

configure_google_adk(
    project_name="my-adk-project",  # Optional: defaults to LANGSMITH_PROJECT env var
)
```

该函数支持以下可选参数：

- `project_name`：要发送 traces 的 LangSmith project。默认为 `LANGSMITH_PROJECT` 环境变量。
- `name`：根 trace 的名称。默认为 `"google_adk.session"`。
- `metadata`：附加上下文的键值对字典。
- `tags`：用于对 traces 进行分类的字符串列表。

## 在 LangSmith 中查看 traces

运行应用后，可以在 [LangSmith UI](https://smith.langchain.com) 中看到这些 traces，其中包括：

- **Agent invocations**：穿过 ADK agents 的完整执行流程
- **Tool calls**：agents 发起的单次函数调用
- **LLM interactions**：来自 Gemini 模型的请求与响应
- **Multi-agent workflows**：来自串行和并行 agent 组合的 traces

## 自定义 metadata 和 tags

在配置 tracing 时加入 metadata 和 tags，以便对 traces 做分类和筛选：

```python
from langsmith.integrations.google_adk import configure_google_adk

configure_google_adk(
    project_name="production-agents",
    metadata={
        "environment": "production",
        "team": "ml-platform",
    },
    tags=["adk", "weather", "v2"],
)
```
