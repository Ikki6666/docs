## 法务与合规

#### *LangSmith 及其各区域实例符合哪些隐私与数据保护框架？*

LangSmith 遵守《通用数据保护条例》（GDPR）以及其他适用于 LangSmith 服务的法律法规。我们也已通过 SOC 2 Type 2 认证，并符合 HIPAA。你可以在 [trust.langchain.com](https://trust.langchain.com) 申请了解更多关于我们安全策略和安全态势的信息。如果你想与我们签署数据处理附录（DPA），请通过 [support.langchain.com](https://support.langchain.com) 联系支持团队。

关于 LangSmith Engine 的安全态势，包括其模型子处理方和数据处理，请参见 [Engine 安全](/langsmith/engine-security)。

#### *我的公司不在某个区域，也可以把数据托管在那里吗？*

可以。无论你的公司位于哪里，都可以把 LangSmith 数据托管在受支持的区域实例中。

#### *你们在欧盟有可签约的法律实体吗？*

目前我们没有位于欧盟、可与客户签约的法律实体。

#### *如果我选择特定区域，法律条款会不同吗？*

所有受支持云区域的条款都是一致的。

## 功能

#### *如何使用某个特定区域实例？*

请按[账户与 API 密钥设置指南](/langsmith/create-account-api-key)创建账户和 API 密钥，并确保在区域下拉框中选择正确的区域。

#### *不同的云托管 LangSmith 区域在功能上有差别吗？*

不同区域之间在某些功能发布上可能会有轻微延迟。除此之外，各受支持的云区域在功能上是等价的。

#### *一个组织可以在不同区域拥有工作区吗？*

LangSmith 目前不支持这一点。如果你有这个需求，请通过 [support.langchain.com](https://support.langchain.com) 联系支持团队，并说明你的使用场景。

#### *可以把不同区域的组织连接起来并共享计费吗？*

LangSmith 目前不支持这一点。如果你对这个能力感兴趣，请通过 [support.langchain.com](https://support.langchain.com) 联系支持团队，并说明你的使用场景。

#### *我所选区域中会存储哪些数据？*

详情请参见[云架构参考](/langsmith/cloud#cloud-architecture-and-scalability)。

#### *如何查看我的组织属于哪个区域？*

查看你的 URL 即可：位于 [https://smith.langchain.com](https://smith.langchain.com) 的组织属于 GCP US，位于 [https://eu.smith.langchain.com](https://eu.smith.langchain.com) 的组织属于 GCP EU，位于 [https://apac.smith.langchain.com](https://apac.smith.langchain.com) 的组织属于 GCP APAC，而位于 [https://aws.smith.langchain.com](https://aws.smith.langchain.com) 的组织属于 AWS US。

#### *可以在区域之间切换组织吗？*

目前我们不支持跨区域迁移。如果你希望支持这一能力，请通过 [support.langchain.com](https://support.langchain.com) 联系支持团队。

## 方案与定价

#### *所有 LangSmith 方案都支持区域实例吗？*

是的，所有方案都可以注册使用受支持的区域实例，包括免费方案。

#### *不同区域的定价会不同吗？*

不会，所有受支持云区域的定价一致。

#### *如果我使用区域实例，支付时用什么货币？*

所有 LangSmith 方案都以美元结算。
