## 项目布局

<ManagedDeepAgentsProjectLayout />

:::python
唯一必需的文件是项目根目录下的 `agent.py`，它包含[agent 定义](/langsmith/managed-deep-agents-agent-definition)，即一个名为 `agent` 的导出。它必须导出一个用 `define_deep_agent` 创建的名为 `agent` 的导出。一个项目中只能使用一个 agent 入口。
:::

:::js
唯一必需的文件是项目根目录下的 `agent.ts` 或 `agent.tsx`，它包含[agent 定义](/langsmith/managed-deep-agents-agent-definition)，即一个名为 `agent` 的导出。它必须导出一个用 `defineDeepAgent` 创建的名为 `agent` 的导出。一个项目中只能使用一个 agent 入口。

上面的布局展示的是常见的 `.ts` 名称。TypeScript 托管声明也接受受支持的 `.tsx`、`.mts` 或 `.cts` 变体。
:::

## MDA 如何对待项目文件

:::python
- **托管 context**：[`instructions.md`](/langsmith/managed-deep-agents-instructions) 定义 system prompt。[`skills/`](/langsmith/managed-deep-agents-skills) 下的每个目录包含特定任务的 instructions，例如一个 `SKILL.md` 和任意支持文件。MDA 会将 `instructions.md` 和 `skills/` 都同步到 [Context Hub](/langsmith/managed-deep-agents-context-hub)。可选的 [durable memory](/langsmith/managed-deep-agents-memory) 同样由 Context Hub 提供支持。
- **应用代码**：[`tools/`](/langsmith/managed-deep-agents-tools) 和 [`middleware/`](/langsmith/managed-deep-agents-middleware) 下的文件是普通的项目模块。从 agent 入口导入它们。其他本地模块的工作方式相同。
- **托管配置**：某些路径在存在时会启用相应能力。对于 `channels/` 和 `schedules/`，只有直接子项是托管声明；嵌套的模块不是。

    | 路径 | 启用的能力 |
    | --- | --- |
    | `identity.py` | [调用者身份验证](/langsmith/managed-deep-agents-identity) |
    | `memory.py` | [Durable memory](/langsmith/managed-deep-agents-memory) |
    | `channels/<name>.py` | [消息 channels](/langsmith/managed-deep-agents-channels) |
    | `tools/mcp.py` | [MCP connectors](/langsmith/managed-deep-agents-mcp-connectors) |
    | `schedules/<name>.py` | [Cron schedules](/langsmith/managed-deep-agents-schedules) |
    | `sandbox/__init__.py` | [Sandbox 文件系统和 shell](/langsmith/managed-deep-agents-sandboxes) |

    `tools/` 存放普通模块，只有一个例外。`tools/mcp.py` 是托管声明，导出一个模块级 `mcp`。`tools/` 下的其他所有模块都是你导入的应用代码。

- **依赖和 secret**：在 `pyproject.toml` 中声明依赖，它还设置 [deployment 的 Python 版本](/langsmith/managed-deep-agents-deploy#set-the-python-version)。MDA 在本地加载 `.env`，并将非保留值转发为 deployment secret。保留的平台变量和 `.env` 文件不会包含在 build 归档中。更多信息请参阅 [Deploy a Managed Deep Agent](/langsmith/managed-deep-agents-deploy)。
- **Evals**：Managed Deep Agents 的 [evals](/langsmith/managed-deep-agents-evals) 是 Harbor evals。运行 `mda evals init -i`，并配合 coding agent 和 `eval-engineering` skill 开发任务。生成的运行时文件保存在 `.mda/evals/` 下，不会包含在已部署的 agent build 中。
:::
