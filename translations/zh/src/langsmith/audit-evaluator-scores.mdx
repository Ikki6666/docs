---
title: 如何审核 evaluator 分数
sidebarTitle: 审核 evaluator 分数
---

LLM-as-a-judge evaluator 并不总是判断正确。因此，人工手动审核 evaluator 留下的分数，并在必要时进行纠正，通常会很有帮助。LangSmith 允许你在 UI 或 SDK 中修正 evaluator 分数。

## 在 comparison view 中

在 comparison view 中，你可以点击任意 feedback tag 来打开 feedback 详情。然后点击右侧的 `"edit"` 图标，进入 correction 视图。接着，你可以在 `"Make correction"` 下方的文本框中输入期望的分数。如果你愿意，也可以为这次纠正附加解释。如果你正在使用 [few-shot evaluator](/langsmith/create-few-shot-evaluators)，这个解释会自动替换 `few_shot_explanation` prompt 变量，并插入到你的 few-shot 示例中。

![Audit Evaluator Comparison View](/langsmith/images/corrections-comparison-view.png)

## 在 runs table 中

在 runs table 中，找到 `"Feedback"` 列并点击 feedback tag，打开 feedback 详情。同样，点击右侧的 `"edit"` 图标即可进入 correction 视图。

![Audit Evaluator Runs Table](/langsmith/images/corrections-runs-table.png)

## 在 SDK 中

可以通过 SDK 的 `update_feedback` 函数，配合 `correction` 字典来完成修正。你必须提供一个 `score` 键，对应数值类型，这样它才会在 UI 中正确渲染。

<CodeGroup>

```python Python
import langsmith

client = langsmith.Client()

client.update_feedback(
    my_feedback_id,
    correction={
        "score": 1,
    },
)
```

```typescript TypeScript
import { Client } from 'langsmith';

const client = new Client();

await client.updateFeedback(
    myFeedbackId,
    {
        correction: {
            score: 1,
        }
    }
)
```

</CodeGroup>
