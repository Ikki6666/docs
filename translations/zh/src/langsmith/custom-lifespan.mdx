---
title: 如何添加自定义 lifespan 事件
sidebarTitle: 添加自定义 lifespan 事件
---
当把 agents 部署到 LangSmith 时，通常需要在服务启动时初始化数据库连接等资源，并在服务关闭时正确释放它们。Lifespan 事件允许你挂接到服务的启动和关闭流程中，以处理这些关键的初始化与清理任务。

这与[添加自定义 routes](/langsmith/custom-routes)的方式完全相同。只需要提供自己的 [`Starlette`](https://www.starlette.io/applications/) app（包括 [`FastAPI`](https://fastapi.tiangolo.com/)、[`FastHTML`](https://fastht.ml/) 以及其他兼容应用）。

下面是一个使用 FastAPI 的示例。

<Note>
"仅 Python"
目前只支持在使用 `langgraph-api>=0.0.26` 的 Python 部署中添加自定义 lifespan 事件。
</Note>

## 创建 app

从一个**已有的** LangSmith 应用开始，将下面的 lifespan 代码添加到 `webapp.py` 文件中。如果是从零开始，也可以通过 CLI 从模板创建一个新应用。

```bash
langgraph new --template=new-langgraph-project-python my_new_project
```

有了 LangGraph 项目后，加入以下 app 代码：

```python {highlight={19}}
# ./src/agent/webapp.py
from contextlib import asynccontextmanager
from fastapi import FastAPI
from sqlalchemy.ext.asyncio import create_async_engine, AsyncSession
from sqlalchemy.orm import sessionmaker

@asynccontextmanager
async def lifespan(app: FastAPI):
    # for example...
    engine = create_async_engine("postgresql+asyncpg://user:pass@localhost/db")
    # Create reusable session factory
    async_session = sessionmaker(engine, class_=AsyncSession)
    # Store in app state
    app.state.db_session = async_session
    yield
    # Clean up connections
    await engine.dispose()

app = FastAPI(lifespan=lifespan)

# ... can add custom routes if needed.
```

## 配置 `langgraph.json`

将以下内容添加到 `langgraph.json` 配置文件中。请确保路径指向上面创建的 `webapp.py` 文件。

```json
{
  "dependencies": ["."],
  "graphs": {
    "agent": "./src/agent/graph.py:graph"
  },
  "env": ".env",
  "http": {
    "app": "./src/agent/webapp.py:app"
  }
  // Other configuration options like auth, store, etc.
}
```

## 启动服务

先在本地测试服务：

```bash
langgraph dev --no-browser
```

当服务启动时，应该能看到启动信息被打印出来；当使用 `Ctrl+C` 停止服务时，也会看到清理信息。

## 部署

可以保持原样将应用部署到 cloud，或者部署到自己的自托管平台。
