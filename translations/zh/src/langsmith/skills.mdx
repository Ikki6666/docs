Agent Skills 是可复用、按需启用的能力包，包含说明以及可选的辅助脚本。本页总结了面向 LangSmith 的 skills，你可以将它们添加到兼容的 coding agent 中，用来查询 traces、生成 datasets，以及定义 evaluators。如果希望直接在终端中处理同一批 LangSmith 数据，请使用 [LangSmith CLI](/langsmith/langsmith-cli)。

<Note>
这些 skills 遵循 Agent Skills 规范，并维护在 [`langsmith-skills` GitHub repository](https://github.com/langchain-ai/langsmith-skills) 中。你可以将 `SKILL.md` 和其中引用的 `scripts/` 复制到 agent 的 skills 目录中。下方安装器只会安装 LangSmith skills（trace、dataset、evaluator）。
</Note>

## 快速安装

使用 `npx skills` 仅安装 LangSmith skills（trace、dataset、evaluator）：

<CodeGroup>
```bash Local (current project)
npx skills add langchain-ai/langsmith-skills --skill '*' --yes
```

```bash Global (all projects)
npx skills add langchain-ai/langsmith-skills --skill '*' --yes --global
```

```bash Link to a specific agent (e.g., Claude Code)
npx skills add langchain-ai/langsmith-skills --agent claude-code --skill '*' --yes --global
```
</CodeGroup>

<Tip>
如需更新，重新运行该命令即可。如果目标 skill 文件夹已经存在，请先删除它们（例如 `rm -rf ~/.claude/skills/langsmith-*`）。
</Tip>

## 配置环境

安装完成后，设置所有 LangSmith skills、辅助脚本以及 [LangSmith CLI](/langsmith/langsmith-cli) 共用的环境变量：

```bash
export LANGSMITH_API_KEY=<your-key>
# Optional defaults
export LANGSMITH_PROJECT=<default-project>
# Advanced: multi-workspace or certain self-hosted setups only
# export LANGSMITH_WORKSPACE_ID=<workspace-id>
```

## 这些 skills 覆盖什么

- [Traces](/langsmith/observability-concepts#traces)：为应用添加 tracing；列出、筛选、检查并导出 traces，用于调试和分析。
- [Datasets](/langsmith/evaluation-concepts#datasets)：将 traces 转成评估 datasets（final_response、single_step、trajectory、RAG），并可选上传到 LangSmith。
- [Evaluators](/langsmith/evaluation-concepts#evaluators)：定义 code 或 LLM-as-judge evaluators，并将它们附加到 datasets（离线）或 projects（在线）。

每个 skill 目录都包含一个 `SKILL.md`，以及可选的 `scripts/` 辅助脚本，供你直接运行或自行调整。这些 skills 旨在接入兼容的 coding agents（例如 Claude Code 或 Deep Agents Code），不过如果你不想接入完整 agent，也可以直接复用这些辅助脚本。对于更重的查询、导出或自动化需求，你还可以将这些 skills 与 [LangSmith CLI](/langsmith/langsmith-cli) 搭配使用，在终端中对同一批 projects、datasets 和 evaluators 编写脚本。

## 手动安装

克隆仓库后，运行安装脚本可获得更多选项：

```bash
git clone https://github.com/langchain-ai/langsmith-skills.git
cd langsmith-skills

# Install for Claude Code in current directory (default)
./install.sh

# Install for Claude Code globally
./install.sh --global

# Install for Deep Agents Code in current directory
./install.sh --deepagents

# Install for Deep Agents Code globally (includes agent persona)
./install.sh --deepagents --global

# Install only LangSmith skills (any target)
./install.sh --langsmith
```

如果只想复制特定 skills，可以将 `config/skills/` 中对应目录复制到 agent 的 skills 文件夹中。

内置的 LangSmith skills 包括：
- langsmith-trace — Traces（查询/导出）
- langsmith-dataset — Datasets（生成/上传）
- langsmith-evaluator — Evaluators（创建/附加）
