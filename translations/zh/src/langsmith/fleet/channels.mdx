---
title: Channels
description: 配置 channels，让 Fleet agent 自动触发运行。
---

Channels 定义 agent 何时开始运行。将 agent 连接到外部事件后，它就可以自动响应消息、邮件或其他事件。

<Tip>
如果要按固定周期触发 agent，请使用[schedules](/langsmith/fleet/schedules)。
</Tip>

## 添加 channel

要添加 channel：

<Steps>
  <Step title="编辑 agent">
    在 [Fleet](https://smith.langchain.com/agents) 收件箱中打开 agent。
    在 agent 名称旁，点击 <Icon icon="pencil"/> **Edit Agent** 图标。
  </Step>
  <Step title="添加 channel">
    1. 在 **Channels** 部分，点击 **+ Add**，然后选择要添加的 channel。
    1. 按照提示添加 channel 并完成认证。
  </Step>
</Steps>

### 添加 Gmail channel

当收件箱中有新邮件到达时，Gmail channel 会激活 agent。若要让 agent 读取并回复邮件，请在 **Tools** 部分添加 Gmail 工具。可用的 Gmail 工具包括读取邮件、发送回复、创建草稿、管理标签，以及将消息标记为已读。详情请参阅[工具集成](/langsmith/fleet/tools)。

<Warning>
Gmail channel 只监控主收件箱。以下邮件不会触发该 channel：

- **Alias emails**：发送到邮件别名而不是主地址的消息。
- **Mailing list emails**：通过邮件列表或群组接收的消息。
- **Emails outside the inbox**：由于过滤规则跳过收件箱的消息，或进入垃圾邮件、回收站或其他文件夹的消息。
</Warning>

### 添加 Slack channel

默认 Slack bot 会在已连接的 Slack channel 中有消息发布时激活 agent。它会对该 channel 中的每条消息触发，并且不能接收 DM。若要让 agent 在 Slack 中回复，请[添加 Slack tools](/langsmith/fleet/slack-app#add-slack-tools)。

<Tip>
如果需要仅在被提及时触发，或需要支持 DM，请改为[创建自定义 Slack bot](/langsmith/fleet/slack-app)。对比说明请参阅[Custom vs. default bot](/langsmith/fleet/slack-app#custom-vs-default-bot)。
</Tip>

### 添加 Microsoft Teams channel

当在 Microsoft Teams 会话中发送消息时，Teams channel 会激活 agent。

如需完整的设置说明，包括 Azure Bot 创建、凭证注册和工具配置，请参阅[将 Teams 与 agent 集成](/langsmith/fleet/teams-app)。

## 暂停和恢复 channels

可以在不移除 channel 的情况下暂停和恢复它们。要暂停所有 channels：

1. 在 [Fleet](https://smith.langchain.com/agents) 收件箱中打开 agent。
1. 在 agent 名称旁，点击 <Icon icon="pencil"/> **Edit Agent** 图标。
1. 在 **Channels** 部分，点击 <Icon icon="player-pause"/> **Pause channels** 按钮，暂停所有 channels。

要恢复所有 channels，请点击 <Icon icon="player-play"/> **Resume channels** 按钮。

## Thread 行为

Thread 的标记方式取决于 agent 是否使用 channels：

- **Chat agents（无 channel）**：响应会将 thread 标记为 **unread**。查看该 thread 后会将其标记为已读。
- **基于 channel 的 agents**：响应默认会让 thread 保持为 **read**。

可以随时手动将任意 thread 标记为已读或未读。
