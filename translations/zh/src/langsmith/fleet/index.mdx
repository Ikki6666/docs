<Callout icon="speakerphone" color="#4F46E5" iconType="regular">
**Agent Builder 现已更名为 LangSmith Fleet。** 所有现有 agents、配置和集成都将继续正常工作，无需采取任何操作。
</Callout>

LangSmith Fleet 是一个用于创建和管理 AI agents 的无代码平台。它允许你从模板创建 agents、连接自己的账号，并让 agent 处理日常工作，同时你依然保持控制权。

使用 Fleet 可以：

- 自动化处理日常任务，例如起草邮件、总结更新和整理信息。
- 连接常用应用，把上下文带入 agent 的工作中。
- 在聊天中或工作场景中（例如 Slack）使用 agent，在工作流里直接获得帮助。
- 通过简单审批机制，对重要操作保持控制。

## 开始构建

<CardGroup cols={2}>
  <Card title="从模板创建" icon="layout-grid" href="/langsmith/fleet/quickstart">
    选择一个现成的起始模板（例如邮件助理或团队更新），然后进行自定义。
  </Card>
  <Card title="使用 AI 创建" icon="wand">
    用自然语言描述目标，让 AI 为你起草 agent 配置。运行前可以先审阅并编辑。
  </Card>
</CardGroup>

## 开始使用

<Steps>
  <Step title="注册" icon="login">
    注册一个 [LangSmith 账号](https://smith.langchain.com/agents?skipOnboarding=true)。
  </Step>
  <Step title="创建 agent" icon="circle-plus">
    从现成模板开始，或者直接描述目标，让 AI 起草 agent 指令。运行前可以编辑细节。[浏览模板](https://www.langchain.com/templates)。
  </Step>
  <Step title="连接账号" icon="link">
    安全登录你希望 agent 使用的各项服务。
  </Step>
  <Step title="试运行" icon="rocket">
    运行 agent，并通过少量点击持续迭代它的指令。
  </Step>
</Steps>

## 隐私政策与免责声明

LangSmith Fleet 的 Slack App 会按照我们的隐私政策收集、管理并存储第三方数据。关于你的数据如何被处理的完整说明，请参阅[隐私政策](https://www.langchain.com/privacy-policy)。

Fleet 对 AI 的使用方式如下：

- **模型**：使用通过 LangSmith 平台提供的 LLMs
- **数据保留**：用户数据按照 LangSmith 的数据保留策略进行保存
- **数据租户隔离**：数据会依据你的 LangSmith 组织设置进行处理
- **数据驻留**：数据驻留策略遵循你的 LangSmith 配置

<Warning>
免责声明：
- **AI 生成内容**：所有 agent 响应均由 AI 生成，可能包含错误或不准确之处。对于重要信息，请始终自行核实。
- **数据使用**：Slack 数据不会用于训练 LLMs。你的工作区数据保持私有，仅用于提供 agent 功能。
- **透明性**：Fleet 会清楚说明在被添加到工作区后将执行哪些操作，相关内容见上文权限部分。
</Warning>
