---
title: Schedules
description: 配置 schedules，让你的 Fleet agents 按周期重复运行。
---

Schedules 会让你的 agent 按固定的时间计划重复运行。当你的 agent 需要主动执行工作，而不是仅对某条消息或事件作出响应时，就应使用 schedules。

常见用例包括：

- **Daily briefings**：每天早晨汇总 emails、calendar events 或 Slack activity。
- **Memory synthesis**：定期回顾并整理 agent 的 memory files，以保持上下文干净且相关。
- **Proactive outreach**：起草每周状态更新、跟进提醒或周期性报告。
- **Data monitoring**：按设定节奏检查 dashboards、metrics 或 feeds，并把值得关注的内容呈现出来。

<Tip>
如果你希望 agent 基于某个事件启动（例如 Slack message 或 email），请改用 [channels](/langsmith/fleet/channels)。
</Tip>

## Add a schedule

要添加一个 schedule：

1. 在 **Schedules** 部分点击 **+ Add**。
1. 选择 schedule 的运行时间。

    <Note>
    Schedules 使用 UTC。配置 schedule 时，请先将你期望的执行时间转换为 UTC。
    </Note>

1. （可选）添加 **Prompt**。通过自定义 prompt，你可以告诉 agent 在每次按计划运行时应执行什么任务。例如：

    - "Summarize my unread emails from the last 24 hours and post a digest to #team-updates in Slack."
    - "Review your memory files and consolidate any redundant or outdated entries."

1. 点击 **Create schedule**。
1. 点击 **Save changes**。
