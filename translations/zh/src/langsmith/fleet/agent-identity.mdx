Agent identity 用于控制 agent 在与 apps 和 services 交互时使用谁的[凭证](/langsmith/fleet/workspace-admin)。

<Warning>
一旦设置了 agent identity，就无法再修改。
</Warning>

## Fixed credentials ("Claws")

无论是谁在与 agent 交互，agent 始终使用同一组 API keys 和 OAuth tokens 进行认证。

以下场景适合使用 fixed credentials：

- agent 作为共享服务运行，例如团队 Slack bot 或每日简报 agent。
- 你希望所有用户共用同一组已认证账户。
- agent 需要运行在 [channels](/langsmith/fleet/channels) 或 [schedules](/langsmith/fleet/schedules) 上，而这些都要求 fixed credentials。

使用 fixed credentials 时，agent 执行的所有操作（发送邮件、发布消息、读取日历）都会使用 agent 所有者在设置期间连接的那个账户。

## User credentials ("Assistants")

agent 会使用当前与它交互的用户的 API keys 和 OAuth tokens 进行认证，以该用户的身份执行操作。

以下场景适合使用 user credentials：

- 每位用户都应通过自己的账户执行操作，例如一个读取并发送用户本人邮箱内容的邮件 assistant。
- 你需要按用户进行访问控制，让 agent 只能看到该用户有权访问的内容。
- 审计轨迹需要准确反映到底是哪位用户执行了某个操作。

使用 user credentials 时，每位用户在第一次与 agent 交互时都需要单独完成认证。之后，该 agent 会在该用户的 threads 中持续使用该用户的 tokens 执行后续操作。

## Set agent identity

要为 agent 设置 identity：

1. 在 [LangSmith UI](https://smith.langchain.com) 中，进入你要编辑的 agent。
1. 点击右上角的 <Icon icon="pencil" /> **Edit**。
1. 点击 **Set identity**，并选择你要使用的 identity。
1. 点击 **Save**。
