本页说明如何在 LangSmith Fleet 中管理 agents 的设置。

## 更换模型

如果你想更换 agent 使用的模型：

1. 在 [LangSmith UI](https://smith.langchain.com) 中，进入你的 agent inbox。
1. 在 agent 名称旁边，点击 <Icon icon="pencil" /> **Edit Agent** 图标。
1. 在右上角点击 <Icon icon="settings" /> **Settings** 图标。
1. 选择你想使用的 **Model**。
1. 输入该模型对应的 API key。

关于如何添加 custom model，请参阅 [Custom models](/langsmith/fleet/essentials#custom-models)。

## 重新连接工具集成

如果要为某个 agent 重新连接工具集成：

1. 在 [LangSmith UI](https://smith.langchain.com) 中，进入你的 agent inbox。
1. 在 agent 名称旁边，点击 <Icon icon="pencil" /> **Edit Agent** 图标。
1. 在右上角点击 <Icon icon="settings" /> **Settings** 图标。
1. 在 **Connected Integrations** 区域，点击你希望重新连接的工具旁边的 **Connect** 按钮。

## 下载 agent 文件

如果要下载 agent 的文件，请点击 agent 右上角的 <Icon icon="settings" /> **Settings** 图标，然后选择 **Download ZIP**。这会把 agent 配置导出为一个 ZIP 文件。

## 修改 agent 的访问范围

Agents 可以是仅创建者可见的 private agent，也可以在 LangSmith workspace 中共享。

| Feature | Private agents | [Workspace agents](#workspace-scoped-agent-details) |
| --- | --- | --- |
| **Ownership and access** | 仅创建者可见 | 同一个 LangSmith workspace 中的所有人都可见 |
| **OAuth authentication** | OAuth 凭证绑定到创建者 | OAuth 凭证按用户分别绑定；新用户克隆 workspace agents 后，需对所选工具重新认证 |
| **Secrets** | 使用 workspace 范围的 LangSmith secrets | 同样使用 workspace 范围的 LangSmith secrets |

如果要修改 agent 可见性，请点击 agent 右上角的 <Icon icon="lock" /> **Visibility settings** 图标，然后选择 **Only me** 或 **Workspace**。

### Workspace 范围 agent 的细节

虽然 workspace 范围的 agents 会被共享，但其中有些信息是公开的，有些则保持私有：

- **Threads 始终是按用户隔离的**。因此，即使某个 agent 是 workspace 范围共享的，在该 agent 中产生的聊天历史仍然只对创建这些 threads 的具体用户可见。
- **system prompt、选中的 tools 和 sub-agents 在 workspace 范围的 agents 上是公开的。** 用户无法直接修改原始 workspace agent 上这些字段，但在克隆 agent 之后可以自行修改。
- **workspace 范围 agent 的 channel 类型是公开的**（例如 Slack 消息触发），但与该 channel 的具体连接信息（例如具体 Slack 频道或 Gmail 地址）不会共享。这样用户在克隆 agent 时知道应该使用什么类型的 channel，但不会因此获得对原始用户连接配置的未授权访问。

## 更新 memory

你的 agent 可以记住之前对话中的信息，并在未来对话中利用这些信息做出更好的决策。Agents 会通过 `write_file` 和 `edit_file` 工具调用，将文件写入 **memories folder** 的方式来持久化 memory。

默认情况下，agent 在保存到 memories folder 之前需要获得审批。开启这一设置后，agent 会暂停，并在 Fleet UI 中等待你对每一次 memory 更新执行接受、编辑或拒绝操作，然后才继续。

<Tip>
如果你的 agent 运行在某个 [schedule](/langsmith/fleet/schedules#add-a-schedule) 上，或其他自动化调度场景中，请关闭 memory 审批要求。否则，只要某次定时运行涉及 memory 更新，agent 就会在每一次运行时暂停，并无限期等待人工批准。
</Tip>

### 关闭 memory 更新所需审批

如果要关闭 memory 更新的审批要求：

1. 在 [LangSmith UI](https://smith.langchain.com) 中，进入你的 agent inbox。
1. 在 agent 名称旁边，点击 <Icon icon="pencil" /> **Edit Agent** 图标。
1. 在右上角点击 <Icon icon="settings" /> **Settings** 图标。
1. 在 **Memory** 区域，将 **Require approval to update memories** 关闭。

## 以编程方式使用 agent

你可以使用 [LangGraph SDK](/langsmith/reference) 通过代码连接你的 agent。若要查看调用该 agent 所需的代码片段：

1. 在 [LangSmith UI](https://smith.langchain.com) 中，进入你的 agent inbox。
1. 在 agent 名称旁边，点击 <Icon icon="pencil" /> **Edit Agent** 图标。
1. 在右上角点击 <Icon icon="settings" /> **Settings** 图标。
1. 点击 **View code snippets** 按钮。
1. 复制为该 agent 预填好的代码片段。

更多信息请参阅 [Call agents from code](/langsmith/fleet/code)。

## 暂停 agent

如果要暂停 agent，请暂停它的 channels：

1. 在 [LangSmith UI](https://smith.langchain.com) 中，进入你的 agent inbox。
1. 在 agent 名称旁边，点击 <Icon icon="pencil" /> **Edit Agent** 图标。
1. 在 graph 视图中，点击 **Channels** 框中的 **Pause** 按钮。
1. 点击 **Save Changes**。

<Tip>
如果要恢复，点击 **Channels** 框中的 **Resume channels** 按钮即可。
</Tip>

## 删除 agent

如果要永久删除一个 agent：

1. 在 [LangSmith UI](https://smith.langchain.com) 中，进入你的 agent inbox。
1. 在 agent 名称旁边，点击 <Icon icon="pencil" /> **Edit Agent** 图标。
1. 在右上角点击 <Icon icon="settings" /> **Settings** 图标。
1. 点击 **Delete Agent** 按钮。
1. 点击 **Delete** 按钮确认删除。

<Warning>
此操作无法撤销。它会永久删除该 agent、与该 agent 关联的所有 threads，并解除所有已连接 channels 的绑定。
</Warning>
