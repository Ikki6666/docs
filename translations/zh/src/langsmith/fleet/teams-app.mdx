通过 LangSmith Fleet，你可以通过注册自定义 Azure Bot，将 agents 连接到 Microsoft Teams。连接完成后，agents 将可以：

- 接收来自 Teams 用户的消息，并以消息内容启动新的 run。
- 使用 Bot Framework 直接在 Teams 对话中进行响应。
- 通过 Microsoft Graph API tools 访问 Teams 频道和消息。

<Note>
在频道对话中，bot 只有在被明确提及时才会响应。而在私聊和群聊中，bot 会对所有消息作出响应。
</Note>

## 前置要求

- Fleet 中已经存在一个 agent（可参考 [Quickstart](/langsmith/fleet/quickstart) 创建）
- 一个拥有创建资源权限的 [Azure 账号](https://portal.azure.com)
- 对 Microsoft Teams workspace 具有管理员权限，或至少拥有安装应用的权限

## 创建 Azure Bot

在 Fleet 中注册之前，你需要先创建一个 Azure Bot 资源并拿到它的凭证。

<Steps>
  <Step title="Create an Azure Bot resource">
    1. 打开 [Azure Portal](https://portal.azure.com)。
    1. 搜索 **Azure Bot** 并点击 **Create**。
    1. 填写必填字段：
       - **Bot handle**：bot 的唯一标识符。
       - **Subscription**：选择你的 Azure 订阅。
       - **Resource group**：新建一个或选择已有的。
       - **Type of App**：选择 **Multi Tenant**。
       - **Creation type**：选择 **Create new Microsoft App ID**。
    1. 点击 **Review + create**，然后点击 **Create**。
  </Step>

  <Step title="Get your app credentials">
    资源创建完成后：

    1. 进入你的 bot 资源，在左侧边栏点击 **Configuration**。
    1. 复制 **Microsoft App ID**，稍后会用到。
    1. 点击 App ID 旁边的 **Manage Password**。
    1. 点击 **New client secret**，添加描述后点击 **Add**。
    1. 立刻复制新 secret 的 **Value**，它只会显示一次。

    <Warning>
    请在创建后立刻复制 client secret 的 value。之后你将无法再次查看它。如果丢失，只能重新创建一个新的 secret。
    </Warning>
  </Step>

  <Step title="Configure the messaging endpoint">
    Messaging endpoint 需要在 bot 注册到 Fleet 之后再设置。这个字段现在先跳过，稍后你会回到这里完成它。
  </Step>
</Steps>

## 在 Fleet 中注册 bot

<Steps>
  <Step title="Open the integrations page">
    1. 在 [LangSmith UI](https://smith.langchain.com) 中进入 **Fleet**。
    1. 打开 **Integrations** 页面。
    1. 点击 **Add Teams App**。
  </Step>

  <Step title="Enter your credentials">
    填写以下字段：

    - **App Name**：该 bot 在 Fleet 中显示的名称。
    - **Azure App ID**：来自 Azure Bot 资源的 Microsoft App ID。
    - **Azure App Password**：你前面复制的 client secret value。
    - **Azure Tenant ID**（可选）：你的 Azure AD tenant ID。多租户 bot 可保留默认值。

    点击 **Create** 完成 bot 注册。
  </Step>

  <Step title="Copy the webhook URL">
    注册完成后，Fleet 会显示一个 **webhook URL**。请复制这个 URL，后续完成 Azure Bot 配置时要用到。
  </Step>

  <Step title="Set the messaging endpoint in Azure">
    1. 返回 [Azure Portal](https://portal.azure.com) 中你的 Azure Bot 资源。
    1. 进入 **Configuration**。
    1. 将 Fleet 中复制的 webhook URL 粘贴到 **Messaging endpoint** 字段。
    1. 点击 **Apply**。
  </Step>
</Steps>

## 将 bot 添加到 Teams

<Steps>
  <Step title="Open the Teams channel">
    1. 在 Azure Portal 中进入你的 bot 资源。
    1. 点击左侧边栏的 **Channels**。
    1. 选择 **Microsoft Teams** 并点击 **Apply**。
    1. 同意服务条款。
  </Step>

  <Step title="Install the bot in Teams">
    1. 在 Teams 中点击左侧边栏的 **Apps**。
    1. 点击 **Manage your apps**，然后点击 **Upload an app**。
    1. 上传一个引用你的 Azure App ID 的 [Teams app manifest](https://learn.microsoft.com/en-us/microsoftteams/platform/resources/schema/manifest-schema)，或者使用 Azure Bot Channels 页面中的 **Open in Teams** 链接。
    1. 将 bot 添加到目标 team 或 chat。
  </Step>
</Steps>

## 将 bot 关联到 agent

你可以在 integrations 页面或 agent editor 中，把 Teams bot 关联到某个 agent。

### 从 integrations 页面关联

1. 进入 Fleet 中 **Integrations** 页的 **Teams Apps** 区域。
1. 选择你要关联的 bot。
1. 在下拉菜单中选择要关联的 agent。

### 从 agent editor 关联

1. 在左侧导航的 **My Agents** 中选择你的 agent。
1. 点击 <Icon icon="pencil"/> **Edit Agent**。
1. 滚动到 **Channels** 区域。
1. 点击 **Teams**。
1. 在下拉菜单中选择你想关联的 Teams app。

## 添加 Teams 工具

Tools 让你的 agent 可以在 Teams 中执行操作。要实现对消息的响应和与 Teams 的交互，需要添加相应的工具。

<Tip>
你也可以直接要求 agent 自己把这些工具加上。在 agent 聊天中可以试试：“Add the Teams tools so you can respond to messages.”
</Tip>

1. 在 agent editor 中滚动到 **Tools** 区域。
1. 点击 **+ Add**。
1. 搜索 “Teams”，并添加你需要的工具：
   - **teams_bot_send_proactive_message** — 向 Teams 对话回发消息
   - **microsoft_teams_list_my_teams** — 列出当前认证用户所属的 teams
   - **microsoft_teams_list_channels** — 列出某个 team 中的 channels
   - **microsoft_teams_post_channel_message** — 向某个 channel 发消息
   - **microsoft_teams_read_channel_messages** — 读取 channel 中的最近消息
1. 如有提示，点击 **Connect** 来授权 Microsoft Graph 工具。
1. 点击 **Save changes**。

<Note>
`teams_bot_send_proactive_message` 使用的是 Bot Framework 凭证，因此不需要单独的 OAuth 授权。其余 Teams 工具使用 Microsoft Graph API，可能会要求 OAuth 授权。
</Note>

## 配置 agent 行为（可选）

你的 agent 需要知道如何处理来自 Teams 的消息。你可以直接在 agent 聊天中通过提示来更新它的 instructions：

```
Update your instructions to handle the Teams Trigger and Teams Tools
for bidirectional communication
```

根据你的使用场景调整 instructions，例如你可能希望 agent 只回复特定类型的问题，或在回复前先从特定来源获取信息。

## 故障排查

### Agent 没有响应

- 查看 Fleet 中对应的 thread，确认是否有等待人工处理的审批。
- 在频道对话里，确保你使用了 **@mention** 来提及 bot。未被提及的频道消息会被忽略。
- 查看 **Feed** 标签页中是否有错误。
- 确认 Azure Bot 资源中的 messaging endpoint 与 Fleet 中的 webhook URL 一致。
- 确认该 bot 在 Fleet 中没有被暂停。

### 注册时提示凭证无效

- 确认 **Azure App ID** 和 **App Password**（client secret）填写正确。
- 确认 client secret 没有过期，如有需要，请在 Azure 中新建一个。
- 检查 Azure 中该 bot 的类型是否设置为 **Multi Tenant**。

### Bot 在私聊里能用，但在频道中不能用

- 在频道对话中，必须显式 **@mention** bot。
- 确认 bot 已经被添加到目标 team，并拥有读取该频道消息的权限。
