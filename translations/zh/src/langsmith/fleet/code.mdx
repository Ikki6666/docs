以编程方式使用 Fleet agent 主要有两种方式：

- **[Call from code](#call-from-code)**：通过 LangGraph SDK 或 REST API 远程调用你的 agent，无需下载任何内容。
- **[Export to code](#export-to-code)**：下载 agent 配置，并使用 `fleet-deepagents-export` package，把它作为一个独立的 Python project 在本地运行。


## Call from code

你可以通过 [LangGraph SDK](/langsmith/reference) 或 REST API，从自己的应用中调用 LangSmith Fleet agent。Fleet agent 运行在 [Agent Server](/langsmith/agent-server) 上，因此你可以使用与其他 [LangSmith deployment](/langsmith/deployment) 相同的 API 方法。

REST API 允许你从任何支持 HTTP request 的语言或平台调用 agent。

### Prerequisites

- 一个带有 Fleet agent 的 LangSmith account
- 一个用于认证的 [Personal Access Token (PAT)](/langsmith/create-account-api-key)
- 仅 SDK 方式需要：安装 [LangGraph SDK](/langsmith/reference)：

<CodeGroup>
    ```bash Python
    pip install langgraph-sdk python-dotenv
    ```

    ```bash TypeScript
    yarn add @langchain/langgraph-sdk
    ```
</CodeGroup>

### Authentication
要对 Fleet deployment 中的 agent 进行认证，请在创建 LangGraph SDK client 时，把 LangSmith 的 [Personal Access Token (PAT)](/langsmith/create-account-api-key) 传给 `api_key` 参数，或者通过 `X-API-Key` header 提供。如果使用 `X-API-Key`，你还必须同时设置 `X-Auth-Scheme: langsmith-api-key`。


如果你传入的 PAT 不属于该 agent 的 owner，那么请求会被拒绝，并返回 `404 Not Found`。

如果你要调用的 agent 是一个 <Tooltip tip="Agents shared with all members of a LangSmith workspace. Private agents are only visible to the creator." cta="Learn more" href="/langsmith/fleet/manage-agent-settings">workspace agent</Tooltip>，并且你不是 owner，那么你仍然可以执行与 UI 中相同的只读操作。

### 1. Get the agent ID and URL

要获取 agent 的 `agent_id` 和 `api_url`：

1. 在 [LangSmith UI](https://smith.langchain.com) 中，打开你的 agent。
1. 在侧边栏中展开 **Advanced settings** 抽屉。
1. 在 **Developer** 下，点击 **View code snippets**，即可看到已经为你的 agent 预填好的值。

复制下面的代码，并把 `agent_id` 和 `api_url` 替换为 agent 代码片段中提供的值。

在项目根目录创建一个 `.env` 文件，并写入你的 [Personal Access Token](/langsmith/create-account-api-key)：

```bash .env
LANGGRAPH_API_KEY=your-personal-access-token
```

### 3. Invoke agent

下面的示例展示了如何向 agent 发送消息并接收响应。你既可以使用 **stateless** run，不创建 thread，也不保留对话历史，也可以使用 **stateful** run，通过 thread 在多轮交互之间保留对话历史。

#### Stateless run

Stateless run 发送单次请求，并返回完整响应。不会持久化任何对话历史。这是调用 agent 最简单的方式：

<Tabs>
    <Tab title="Python">
```python
import os
from dotenv import load_dotenv
from langgraph_sdk.client import get_client

load_dotenv()

agent_id = "your-agent-id"

api_key = os.getenv("LANGGRAPH_API_KEY")
api_url = "https://<AGENT-BUILDER-URL>.us.langgraph.app"

client = get_client(
    url=api_url,
    api_key=api_key,
    headers={
        "X-Auth-Scheme": "langsmith-api-key",
    },
)

result = await client.runs.wait(
    None,
    agent_id,
    input={
        "messages": [
            {"role": "user", "content": "What can you help me with?"}
        ]
    },
)
print(result)
```
    </Tab>

#### Stateless streaming run

如果你希望在响应生成过程中实时流式获取内容，而不是等待完整结果返回，请使用 streaming endpoint：

<Tabs>
    <Tab title="Python">
```python
async for chunk in client.runs.stream(
    None,
    agent_id,
    input={
        "messages": [
            {"role": "user", "content": "What can you help me with?"}
        ]
    },
    stream_mode="updates",
):
    if chunk.data and "run_id" not in chunk.data:
        print(chunk.data)
```
    </Tab>
    <Tab title="TypeScript">
```ts
const streamResponse = client.runs.stream(
  null,

      ]

    streamMode: "updates"
  }

for await (const chunk of streamResponse) {
```

#### Stateful run with a thread

如果你希望在多轮交互中保留对话历史，请先创建一个 thread，再在该 thread 上运行 agent。之后，同一 thread 上的每次 run 都会访问完整消息历史：

<Tabs>
    <Tab title="Python">
```python
import os
from dotenv import load_dotenv
from langgraph_sdk.client import get_client

load_dotenv()

agent_id = "your-agent-id"

api_key = os.getenv("LANGGRAPH_API_KEY")
api_url = "<AGENT-BUILDER-URL>.us.langgraph.app"

client = get_client(
    url=api_url,
    api_key=api_key,
    headers={
        "X-Auth-Scheme": "langsmith-api-key",
    },
)

thread = await client.threads.create()

async for chunk in client.runs.stream(
    thread["thread_id"],
    agent_id,
    input={
        "messages": [
            {"role": "user", "content": "Hi, my name is Alice."}
        ]
    },
    stream_mode="updates",
):
    if chunk.data and "run_id" not in chunk.data:
        print(chunk.data)

async for chunk in client.runs.stream(
    thread["thread_id"],
    agent_id,
    input={
        "messages": [
            {"role": "user", "content": "What is my name?"}
        ]
    },
    stream_mode="updates",
):
    if chunk.data and "run_id" not in chunk.data:
        print(chunk.data)
```
    </Tab>

### REST API reference

下表汇总了关键 endpoint。请把 `<API_URL>` 替换为 agent 的 deployment URL。

| Operation | Method | Endpoint |
|---|---|---|
| [Get agent info](/langsmith/agent-server-api/assistants/get-assistant) | `GET` | `<API_URL>/assistants/<AGENT_ID>` |
| [Create a thread](/langsmith/agent-server-api/threads/create-thread) | `POST` | `<API_URL>/threads` |
| [Run (wait for result)](https://docs.langchain.com/langsmith/agent-server-api/stateless-runs/create-run-wait-for-output) | `POST` | `<API_URL>/runs/wait` |
| [Run (streaming)](/langsmith/agent-server-api/stateless-runs/create-run-stream-output) | `POST` | `<API_URL>/runs/stream` |
| [Run on thread (wait)](/langsmith/agent-server-api/thread-runs/create-run-wait-for-output) | `POST` | `<API_URL>/threads/<THREAD_ID>/runs/wait` |
| /langsmith/agent-server-api/thread-runs/create-run-stream-output | `POST` | `<API_URL>/threads/<THREAD_ID>/runs/stream` |

所有 endpoint 都要求以下 header：
- `Content-Type: application/json`
- `X-Api-Key:` 你的 [Personal Access Token](/langsmith/create-account-api-key)
- `X-Auth-Scheme: langsmith-api-key`

完整 API 规范请参阅 [Agent Server API reference](/langsmith/server-api-ref)。


## Export to code

**Export to code** 功能允许你把 Fleet agent 下载为一个独立的 Python project，并在本地运行。在以下场景中，它会很有用：

- 你希望在自己的基础设施中运行 agent，而不是调用 Fleet API
- 你希望在 Fleet UI 所支持范围之外扩展或定制 agent，例如添加 custom tool、middleware 或 skill
- 你希望检查或纳入版本控制完整的 agent 实现
- 你希望使用 LangGraph Studio 做本地开发和 graph inspection

[`fleet-deepagents-export`](https://pypi.org/project/fleet-deepagents-export/) package，及其 [GitHub](https://github.com/langchain-ai/fleet-deepagents-export)，负责读取导出的配置，并把 agent 与 MCP tool、subagent 和 skill 连接起来。

### Prerequisites

- Python 3.11+
- 推荐使用 [`uv`](https://docs.astral.sh/uv/getting-started/installation/) 做依赖管理
- 一个 LangSmith Fleet agent，可供导出

### 1. Copy the starter project

位于 [`examples/template-agent/`](https://github.com/langchain-ai/fleet-deepagents-export/tree/main/examples/template-agent) 的 starter project 是推荐的起点。克隆仓库并复制这个 starter：

```bash
git clone https://github.com/langchain-ai/fleet-deepagents-export.git
cp -R fleet-deepagents-export/examples/template-agent my-agent
cd my-agent
```

### 2. Export your agent from Fleet

在 [LangSmith UI](https://smith.langchain.com) 中，打开你的 agent，并将其导出为 `.zip` 文件。

![fleet-export-code](/langsmith/images/fleet-export-code.gif)

然后把压缩包内容放进 starter project 的 `fleet/` 目录中：

```bash
unzip path/to/my-export.zip -d fleet/
```

`fleet/` 目录中包含了 agent 运行所需的一切：
- `AGENTS.md`，system prompt
- `config.json`，model configuration 和 workspace metadata
- `tools.json`，MCP server connection
- `subagents/`，可选，subagent definition
- `skills/`，可选，skill instruction

### 3. Configure your environment

复制示例 env 文件，并填入所需值：

```bash
cp .env.example .env
```

三个 `LANGSMITH_*_ID` 值都可以在 `fleet/config.json` 的 `metadata` 下找到。打开该文件，把其中的 `tenant_id`、`organization_id` 和 `ls_user_id` 复制到你的 `.env`：

```bash .env
# Model provider — set the key for whichever provider your agent uses
ANTHROPIC_API_KEY=your-anthropic-api-key

# LangSmith credentials — copy IDs from fleet/config.json → metadata
LANGSMITH_API_KEY=your-langsmith-pat
LANGSMITH_TENANT_ID=your-tenant-id
LANGSMITH_ORGANIZATION_ID=your-organization-id
LANGSMITH_USER_ID=your-user-id       # required if your agent uses OAuth tools

# Built-in MCP tools (Gmail, Calendar, GitHub)
BUILTIN_MCP_URL=https://tools.langchain.com/mcp
```

### 4. Install dependencies and run

```bash
make setup    # installs dependencies via uv sync
```

然后选择你希望如何与 agent 交互：

```bash
make dev    # LangGraph Studio — browser UI for chat and graph inspection
make run    # terminal REPL via cli.py — text-only chat
```

### 5. Customize the agent

这个 starter 把 Fleet 持有的文件与你自己持有、可自由编辑的文件分开管理：

| File / Directory | Owner | Purpose |
|---|---|---|
| `fleet/` | Fleet | 把导出内容放到这里。更新时重新 unzip 即可，不需要改别的内容。 |
| `agent.py` | You | Graph wiring。如果你要覆盖 model，可替换 `model = components.pop("model")` 这一行。 |
| `custom_tools.py` | You | 添加代码定义的 tool；运行时会与 Fleet MCP tool 合并。 |
| `custom_middleware.py` | You | 添加 `AgentMiddleware` 实例，用于 logging、filter、pre/post hook 等。 |
| `custom_skills/` | You | 放置 `<skill-name>/SKILL.md` 文件；它会叠加在 `fleet/skills/` 之上。 |
| `cli.py` | You | 终端 REPL；可自由编辑。 |

下面是 starter 中完整的 `agent.py`：

```python
"""Standalone deepagent exported from LangSmith Fleet.

LangGraph Studio / dev server:  make dev
Terminal:                        make run  (see cli.py)

Extension points (edit these, not this file):
- ``custom_tools.py``      — add code-defined tools
- ``custom_middleware.py`` — wrap the agent loop with logging, filters, etc.
- ``custom_skills/``       — drop ``<skill-name>/SKILL.md`` files
"""

from __future__ import annotations

from pathlib import Path
from typing import Any

from dotenv import load_dotenv

load_dotenv()

from custom_middleware import custom_middleware
from custom_tools import custom_tools
from deepagents import create_deep_agent
from fleet_deepagents_export import StaticSkillsLoader, load_agent_components

PROJECT_DIR = Path(__file__).parent
FLEET_DIR = PROJECT_DIR / "fleet"
CUSTOM_SKILLS_DIR = PROJECT_DIR / "custom_skills"

# Read SKILL.md from disk once; middleware injects into state on first turn.
_SKILL_LOADER = StaticSkillsLoader(
    [
        (FLEET_DIR / "skills", "/skills/fleet"),
        (CUSTOM_SKILLS_DIR, "/skills/custom"),
    ]
)


async def graph(runtime: Any):
    """Build and return the agent graph."""
    components = await load_agent_components(FLEET_DIR)
    model = components.pop("model")  # from fleet/config.json; replace to override
    components["tools"] = list(components["tools"]) + list(custom_tools)

    if _SKILL_LOADER.files:
        components["skills"] = _SKILL_LOADER.skill_paths

    return create_deep_agent(
        model=model,
        middleware=[_SKILL_LOADER, *custom_middleware],
        **components,
    ).with_config({"recursion_limit": 1000})
```

### Re-exporting

当你从 Fleet 导出 agent 的新版本时，只需清空并重新 unzip，自己的定制内容不会被动到：

```bash
rm -rf fleet && unzip path/to/my-new-export.zip -d fleet/
```

### Supported model providers

starter 默认内置了 `langchain-anthropic`、`langchain-openai` 和 `langchain-google-genai`。如果你要使用其他 provider，例如 `bedrock`、`fireworks`，请把对应的 `langchain-<provider>` package 添加到 `pyproject.toml` 中。

### MCP authentication

启动时，每个 tool 的 `mcp_server_url` 都会先根据 LangSmith 的 MCP server registry 解析：

- **Built-in LangSmith tools**，例如 Gmail、Calendar、GitHub，通过你的 `LANGSMITH_API_KEY` 完成认证。
- **Static-credential servers**，`auth_type: "headers"`，其 credential 来自 registry 记录。要求具备 `mcp-servers:invoke` 权限。
- **OAuth servers**，`auth_type: "oauth"`，bearer token 会从 LangSmith 的 OAuth broker 获取。对于尚未授权的 per-user server，首次运行时会打开浏览器窗口要求授权。
