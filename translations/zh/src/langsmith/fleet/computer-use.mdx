---
title: Computer use
description: 在连接到 Fleet agent 的持久虚拟计算机上运行代码、管理文件，并调用需要认证的 API。
---

Computer use 会给你的 Fleet agent 提供一台隔离的虚拟计算机。Agent 可以在其中编写和执行代码、管理文件、安装包，以及调用需要认证的外部 API，而无需把凭据暴露给语言模型。

<Note>
Computer use 在 [Plus 和 Enterprise plans](https://langchain.com/pricing) 中可用。
</Note>

## Computer 模式

选择虚拟计算机在 agent 会话 threads 之间的共享方式：

| Mode | Description |
|------|-------------|
| **Shared computer** | 所有 threads 共享同一台计算机。文件系统、已安装的包以及运行中的进程都会在不同 threads 间持续保留。如果你希望文件、依赖或环境配置能在多次对话之间不断累积，请使用这个模式。Shared computers 不会被自动删除。 |
| **Computer per thread** | 每个 thread 拥有各自隔离的计算机，启动时是全新的，并会在空闲后归档。这个模式适合软件工程 agent，以及其他会运行大量并行、写入密集型任务的工作负载，也适用于不同 threads 不应互相看到彼此状态的场景。 |

## 配置 computer use

<Warning>
Computer 模式在 agent 创建时就会确定，之后无法修改。如果想切换模式，需要重新创建一个新 agent。
</Warning>

<Steps>
  <Step title="打开 Create agent 对话框">
    在 [Fleet](https://smith.langchain.com/agents) 左侧导航的 **My Agents** 下，点击 <Icon icon="plus" />，然后选择 **Create with AI** 或 **Blank agent**。输入 agent 名称。
  </Step>
  <Step title="启用 computer use">
    在 **Should your agent use a computer?** 下选择 **Yes**，然后在 **Shared computer** 和 **Computer per thread** 之间做选择。如果你选择 **No**（默认值），该 agent 将在无计算机访问权限的情况下创建。
  </Step>
  <Step title="设置基础 snapshot（可选）">
    展开 **Advanced**，为新计算机选择一个 **Snapshot**。
  </Step>
  <Step title="创建 agent">
    点击 **Create Agent**。
  </Step>
</Steps>

## Access profiles

使用 access profiles，可以让 agent 调用需要认证的外部 API，而不必把凭据写进 prompt，也不会把凭据暴露给语言模型。发往匹配主机的出站 HTTP 请求会被路由到一个代理，该代理会先注入配置好的 headers，再将请求转发出去。

一个 profile 包含一条或多条 **Custom rules**。每条规则会指定：

- **Match Hosts**：规则适用的目标主机名。可以使用 `*` 作为通配符（例如，`*.example.com` 可以匹配 `api.example.com`）。
- **Source Type and Provider**：凭据来源。选择 **Connection** 表示用户委托 OAuth，选择 **Workspace Secret** 表示静态 API keys。
- **Inject Headers**：代理会为匹配请求添加的 HTTP headers。使用 `{access_token}` 之类的模板值来引用凭据（例如 `Authorization: Bearer {access_token}`）。

Profile 还带有一个 **Network scope**，用于控制 agent 计算机的出站网络流量。默认值是 **None (all traffic allowed)**。

### 添加 access profile

<Steps>
  <Step title="创建 access profile">
    前往 [Fleet Integrations tab](https://smith.langchain.com/agents/tools)，并导航到 **Computer** 部分。点击 **+ Create profile**，按提示配置主机模式和凭据。
  </Step>
  <Step title="把 profile 附加到 agent">
    在 agent 编辑器中，点击 **Computer** 节点。在 **Access profiles** 旁点击 **+ Add**，然后选择你刚创建的 profile。
  </Step>
  <Step title="保存变更">
    点击 **Save changes**。
  </Step>
</Steps>

## Computer 生命周期

每个 agent 都有两项生命周期设置，用来控制一台计算机会保持活跃多久，以及停止之后还会被保留多久。[可以在 settings popover 中一起配置这两项](#configure-lifecycle-and-snapshot)。

- **Idle timeout**：如果计算机在这段时间内没有收到任何命令，它就会暂停，磁盘会被归档。之后 agent 还可以在不丢失数据的情况下恢复同一台计算机。默认值：**15 分钟**。
- **Stopped computer cleanup**：一台计算机停止运行一段时间后，会被永久删除，同时所有磁盘数据也会被删除。默认值：**14 天**。

<Note>
**Stopped computer cleanup** 只适用于 **Computer per thread** 模式。Shared computers 不会被自动删除。
</Note>

## Base snapshot

Snapshot 是用来启动计算机的磁盘镜像。默认情况下，所有 Fleet agents 都会使用工作区默认 snapshot。要构建、捕获或配置自定义 snapshots，请参阅[Sandbox snapshots](/langsmith/sandbox-snapshots)。你可以在 settings popover 中为 agent[修改 snapshot](#configure-lifecycle-and-snapshot)。

<Note>
Snapshot 变更只会影响该 agent 后续创建的新计算机。在 **Shared computer** 模式下，唯一那台共享计算机会在整个生命周期中保持其原始 snapshot 不变。
</Note>

## 配置 lifecycle 和 snapshot

Agent 的 snapshot、idle timeout 和 stopped computer cleanup 都在 settings popover 的 **Computer lifecycle** 部分进行设置。

<Steps>
  <Step title="打开 settings popover">
    在 [Fleet](https://smith.langchain.com/agents) 中打开 agent，然后点击 agent 编辑器里的 <Icon icon="settings" /> 设置图标。
  </Step>
  <Step title="设置 lifecycle 字段">
    滚动到 **Computer lifecycle** 部分。设置 **Snapshot**、**Idle timeout**，以及（如果是 **Computer per thread** 模式）**Stopped computer cleanup**。
  </Step>
  <Step title="保存变更">
    点击 **Save changes**。
  </Step>
</Steps>
