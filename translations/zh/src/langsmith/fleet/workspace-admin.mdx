为 Fleet agent 和用户配置工作区密钥，并管理支出上限。

## 工作区密钥

Fleet 使用[工作区密钥](/langsmith/set-up-hierarchy#configure-workspace-settings)来存储模型和工具的 API key。可用的密钥类型如下：

- **模型提供商 key**：默认情况下，Fleet 使用由 LangChain 管理的模型，不需要模型提供商的 API key。只有在使用[自定义模型](/langsmith/fleet/essentials#custom-models)时，才需要 OpenAI 或 Anthropic API key。设置后，agent graph 会从工作区密钥中读取这些 key 进行推理
- **Fleet 专用密钥**：带有 `FLEET_` 前缀的密钥在 Fleet 内部优先级高于普通工作区密钥。这样你可以更好地区分 Fleet 与 LangSmith 其他部分对同一批密钥的使用情况。如果你同时设置了 `OPENAI_API_KEY` 和 `FLEET_OPENAI_API_KEY`，则会优先使用 `FLEET_OPENAI_API_KEY`
- **可选工具 key**：为你启用的任意工具添加对应 key。运行时会从工作区密钥中读取
  - `EXA_API_KEY`：Exa 搜索工具需要，包括通用网页搜索和 LinkedIn 资料搜索
  - `TAVILY_API_KEY`：Tavily 网页搜索需要
  - `TWITTER_API_KEY` 和 `TWITTER_API_KEY_SECRET`：Twitter 或 X 的只读操作需要，使用 app-only bearer。当前不支持发帖或媒体上传
- **MCP server 配置**：Fleet 可以从一个或多个远程 [Model Context Protocol, MCP](https://modelcontextprotocol.io/) server 拉取工具。在你的[工作区](/langsmith/administration-overview#workspaces)设置中配置 MCP server 和请求头。Fleet 在调用时会自动发现工具，并应用已配置的请求头。更多信息请参阅[远程 MCP servers](/langsmith/fleet/remote-mcp-servers)

<Note icon="wand" iconType="regular">
  自定义模型适用于企业部署。更多信息请参阅[自定义模型](/langsmith/fleet/essentials#custom-models)。
</Note>

### 添加密钥

要添加密钥：

1. 在 [LangSmith UI](https://smith.langchain.com) 中，进入 <Icon icon="settings" /> **Settings**，然后切换到 **Secrets** 标签
1. 选择 **Add secret**，输入密钥的 **name**，例如 `OPENAI_API_KEY` 或 `ANTHROPIC_API_KEY`，再把你的 key 作为 **value** 填入

    <Note>
    请确保密钥名称与模型提供商所期望的环境变量名一致。
    </Note>

1. 选择 **Save secret**

## 使用量与支出上限

**Usage** 页面会为工作区管理员展示 Fleet 的支出情况，并允许为 agent 和用户设置支出上限。只有拥有 `fleet:read-admin-config` 权限的用户才能看到该页面。

### 查看当前支出

**Usage** 页面会显示工作区在所选时间段内的总支出，支持 **Last 7 days** 或 **Last 14 days**，同时也会显示总 threads 数和总 runs 数。

每日支出图表会直观拆分所选时间段内的成本。**Breakdown** 区块则提供两种查看方式：

- **By agent**：查看每个 agent 的总成本、run 数量、首次使用和最后使用日期、owner，以及每周限额
- **By user**：查看每个用户的支出和活动情况

### 设置支出上限

支出上限可以帮助你控制 agent 和用户的花费。管理支出上限需要 `fleet:write-admin-config` 权限。

#### 默认每周支出上限

在 **Default Weekly Spend Limits** 区块中，你可以配置：

- **Per-Agent Default Limit (USD)**：为工作区中的所有 agent 设置默认每周支出上限
- **Per-User Default Limit (USD)**：为工作区中的所有用户设置默认每周支出上限

这些限额按周累计，并会在每周一重置。

#### 为单个 agent 或用户覆盖默认限额

你可以为单个 agent 或用户覆盖默认支出上限，设置自定义每周限额。

#### 支出上限行为

- 支出上限的变更可能需要几分钟才能传播到所有正在运行的 agent
- 支出上限会在每次 run 开始时检查。如果 run 开始时使用量仍低于上限，则即使最终成本超过上限，也会允许该 run 执行完成
- 支出计算基于 traces。删除 traces 会影响已报告的使用量和支出限制执行
