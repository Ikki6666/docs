某些 [tools](/langsmith/fleet/tools) 需要用户授权（例如 Google、Slack、GitHub）。LangSmith Fleet 内置了 middleware，可检测某个工具何时需要授权，并通过清晰的提示暂停 run。用户完成认证后，会自动重试同一次工具调用。

## Return shape to request auth

如果某个工具检测到缺少授权，请返回一个包含以下字段的 JSON 字符串：

```json
{
  "auth_required": true,
  "auth_url": "https://auth.example.com/start",
  "auth_id": "opaque-tracking-id"
}
```

- `auth_required`：设为 `true`，表示需要触发一次 interrupt。
- `auth_url`：用户应被重定向到该地址完成授权。
- `auth_id`：可选的 correlation ID，用于追踪本次 auth 会话。

当 Fleet 检测到该响应时，它会中断 run，向用户显示认证 UI，并在授权完成后自动重试该工具调用。

如果你希望自定义 tools 复用同样的“需要认证” interrupt 和 UI，请确保你的工具返回相同结构的 JSON。

<Note>
工具输出只返回这段 JSON。避免包含其他文本或内容。Fleet 会解析该响应来触发认证流程。
</Note>
