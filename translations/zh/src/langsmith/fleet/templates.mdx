LangSmith Fleet 提供了[入门 templates](https://www.langchain.com/templates)，帮助你快速创建 agents。Templates 内含预定义的 instructions、[tools](/langsmith/fleet/tools) 以及适用时的 [channels](/langsmith/fleet/essentials#channels)，覆盖常见用例。你既可以直接使用这些 templates，也可以将其作为定制的基础。

<Tip>
如果你是 Fleet 新手，建议先从分步的 [quickstart](/langsmith/fleet/quickstart) 开始，使用 template 构建你的第一个 agent。
</Tip>

## Features

Templates 是针对特定用例预先配置好的 agents。每个 template 都包含以下组件：

### Pre-configured tools

Templates 会附带一组精心挑选的 [tools](/langsmith/fleet/essentials#tools)，让 agent 能执行特定操作。例如，email assistant template 会包含读取、发送和整理邮件的 tools。Tools 通过 OAuth authentication 连接外部服务，使 agent 可以与 Gmail、Slack 或 Linear 等应用交互。完整列表请参阅 [Supported tools](/langsmith/fleet/tools)。

### System instructions

每个 template 都包含一个 _system prompt_（也称 _instructions_），用于定义 agent 的行为、个性和能力。System prompt 会指导 agent 如何理解用户请求，以及如何使用它可用的 tools。你可以根据自己的需求自定义这些 instructions。

### Channels (optional)

某些 templates 包含 [channels](/langsmith/fleet/essentials#channels)，使 agent 可以自动响应外部事件。例如，一个 Slack bot template 可能会带有一个 channel，当有人在 Slack 对话中提到该 agent 时自动触发。Channels 让 agent 除了聊天式交互之外，还能主动工作。

### Cloning and customization

Templates 是用来 clone 后创建你自己 agent 的起点。当你 clone 一个 template 时，会得到一个独立副本，你可以自由定制而不会影响原始 template。你可以修改 prompts、添加或移除 tools、挂接不同 channels，或切换 models，以让 agent 更贴合你的需求。
