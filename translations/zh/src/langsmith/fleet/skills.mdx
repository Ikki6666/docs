Skills 是可复用的能力模块，用来为 agent 提供专门的工作流和领域知识。每个 skill 都存放在 agent 的长期记忆目录 `memories/skills/<skill-name>` 中。agent 启动时会加载 skill 的名称和描述，并基于这些信息决定是否使用该 skill。只有当 agent 判断该 skill 与当前任务相关时，才会继续加载完整的 skill 文件。如果 skill 引用了额外资源，agent 也会在它们变得相关时按需加载。

使用 skills 可以帮助你：

- 只在当前任务相关时提供上下文，从而节省 token 用量。
- 避免 system prompt 中上下文过多，否则容易导致 hallucination 和错误响应。

<Info>
Fleet skills 基于 [Deep Agents](/oss/deepagents/skills)，并遵循 [Agent Skills specification](https://agentskills.io/specification)。关于 skill 结构、`SKILL.md` 格式以及编写最佳实践，请参阅 [Deep Agents skills documentation](/oss/deepagents/skills)。
</Info>

## 私有 skills 与共享 skills

Skills 可以是某个 agent 独有的 **private** skill，也可以是在整个 workspace 中共享的 **shared** skill：

- **Private skills**：仅属于它所在的 agent，保存在该 agent 的长期记忆中。
- **Shared skills**：在 workspace 内共享，并列在 [**Skills**](https://smith.langchain.com/agents/skills) 页面上。
    - 对 workspace 中所有 agents 可见。
    - 只有 skill 的创建者可以编辑或删除它。
    - 可以添加到 workspace 中任意 agent，并且随着 skill 更新保持同步。
    - 通用聊天也会自动访问这些 shared skills。

## 编写有效的 skill 描述

请把 description 写成“何时使用这个 skill”的说明，而不是“这个 skill 做什么”的标签。agent 是仅基于 description 来进行路由的，只有在决定使用 skill 之后才会去读取完整 skill 文件。

例如，不要写成 “Helps with email”，而应写成：“Use when drafting, replying to, or summarizing emails. Covers tone adjustments, follow-up scheduling, and inbox triage.”

如果 description 过于宽泛，agent 可能在合适场景下反而不会使用这个 skill；如果 description 与另一个 skill 有重叠，agent 可能会路由到错误 skill，或者根本无法做出选择。随着 skill 库不断增长，请定期检查 descriptions 是否存在重叠，并收紧那些含义模糊的描述。

## 创建 skill

你可以通过两种方式创建 skill：

- **With AI**：用自然语言描述 skill，agent 会为你生成。你也可以添加额外资源。任何附加文件都必须在 `SKILL.md` 中被引用，agent 才会知道它们存在。
- **Manually**：手动创建一个包含 `SKILL.md` 文件的 skill。

<Note>
默认情况下，skills 都是该 agent 独有的 **private** skills，并保存在 agent 的长期记忆中。你之后也可以[把 skill 共享到 workspace](#share-a-skill)。
</Note>

<Tabs>
    <Tab title="With AI">
    在 [Fleet](https://smith.langchain.com/agents) 中，选择一个 agent，并提示它创建 skill：

    <Prompt description="Create a skill that helps the agent use the web to research a topic.">
    Create a skill that helps the agent use the web to research a topic. Use when asked to research a topic, person, company, technology, event, or any question that requires gathering and synthesizing information from the web. Covers news lookups, competitive analysis, background research, and fact-finding tasks. Prefer `tavily_web_search` for most queries.
    </Prompt>

    你也可以随时把之前的一段对话转成可复用的 skill。完成某个任务后，可以要求 agent 把这套流程固化下来：

    <Prompt description="Turn this conversation into a reusable skill.">
    Turn what we just did into a skill so you can repeat it in the future.
    </Prompt>

    </Tab>
    <Tab title="From a template">

    1. 进入 [**Fleet > Skills**](https://smith.langchain.com/agents/skills)。
    1. 浏览可用模板，并选择一个添加到你的 agent 中。

    </Tab>

    <Tab title="Manually">

    1. 在 [Fleet](https://smith.langchain.com/agents) 中选择一个 agent。
    1. 点击 <Icon icon="pencil"/> **Edit Agent**。
    1. 在 **Skills** 区域点击 **Create**。
    1. 输入 skill 名称、description 和 instructions。
    1. 点击 **Save Changes**。

    </Tab>
</Tabs>

<Tip>
创建新 agent 时，如果 Fleet 判断该 agent 适合使用某些 skills，就会自动生成相关 skills。这些 skills 默认是私有的。你可以在 agent editor 中把它们[共享到 workspace](#share-a-skill)。
</Tip>

## 修复重复出现的错误

面对 agent 的错误，默认做法通常只是当场纠正。但 skill 的价值在于：它能把规则显式固化下来，让 agent 在今后遇到同类任务时都遵循相同处理方式，从而避免同一个错误一再发生。

当 agent 某次任务处理不正确时，先纠正它，再让它把这次修正固化为 skill：

<Prompt description="Capture this fix as a skill.">
Turn this correction into a skill so you always handle it this way.
</Prompt>

这样，agent 就会创建一个编码了正确行为的 `SKILL.md`。在未来会话中，它会先读取这个 skill，再处理这类任务，而不是每次都从零开始重新推理。

## 编辑 private skill

1. 在 [Fleet](https://smith.langchain.com/agents) 中选择一个 agent。
1. 点击 <Icon icon="pencil"/> **Edit Agent**。
1. 在 **Skills** 区域选择要编辑的 skill。
1. 更新 skill 的名称、description 或 instructions。
1. 点击 **Save Changes**。

## 编辑 shared skill

<Note>
只有 shared skill 的创建者可以编辑它。
</Note>

1. 进入 [**Fleet > Skills**](https://smith.langchain.com/agents/skills)。
1. 选择要编辑的 skill。
1. 更新 skill 的名称、description 或 instructions。
1. 点击 **Save Changes**。

## 分享 skill

1. 在 [Fleet](https://smith.langchain.com/agents) 中选择一个 agent。
1. 点击 <Icon icon="pencil"/> **Edit Agent**。
1. 在 graph 视图的 **Skills** 区域中，选中你想分享的 skill。
1. 点击 <Icon icon="share"/>**Share**。

共享后，这个 skill 会出现在 [**Skills**](https://smith.langchain.com/agents/skills) 页面中。你可以在 agent editor 中把 shared skills 添加到 workspace 中任意 agent，通用聊天也会自动拾取它们。

<Note>
只有 shared skill 的创建者可以编辑或删除它。
</Note>

## 删除 private skill

删除 private skill 会将其永久移除，因为它是存放在该 agent 自己的 memory 中的。

1. 在 [Fleet](https://smith.langchain.com/agents) 中选择该 agent。
1. 点击 <Icon icon="pencil"/> **Edit Agent**。
1. 在 **Skills** 区域中，点击对应 skill 旁边的 <Icon icon="trash"/> 图标。

## 删除 shared skill

只有 shared skill 的创建者可以删除它。

<Warning>
删除 skill 会把它从 workspace 以及所有使用该 skill 的 agents 中移除。此操作无法撤销。
</Warning>

1. 进入 [**Fleet > Skills**](https://smith.langchain.com/agents/skills)。
1. 选择要删除的 skill。
1. 点击 <Icon icon="trash"/> **Delete skill** 图标。

## 在本地开发中使用 Fleet skills

你可以通过 LangSmith CLI 从 Fleet workspace 下载 skills，并在 Claude Code、Cursor、Codex 这类 coding agents 中本地安装使用。

默认情况下，文件会保存到 `~/.agents/skills/[skill-name]/`，并通过符号链接挂载到 `~/.claude/skills/[skill-name]/`。

```bash
langsmith fleet skills pull [skill-name] [flags]
```

| Flag | Description |
|------|-------------|
| `--global=false` | 安装到项目级目录（`.agents/` 和 `.claude/`），而不是 home 目录。 |
| `--agent` | 指定目标 agent（`claude`、`cursor`、`codex`）。 |
| `--copy` | 直接复制文件，而不是创建符号链接。 |
| `--format pretty` | 显示已安装 skill 的文件树。 |

例如：

```bash
$ langsmith fleet skills pull web-research --format pretty
Installed skill "web-research" to ~/.agents/skills/web-research
  Linked: ~/.claude/skills/web-research

web-research/
├── SKILL.md
└── references/
    └── search-tips.md
```
