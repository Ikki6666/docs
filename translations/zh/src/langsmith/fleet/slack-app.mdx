通过 LangSmith Fleet，你可以安全地将 agents 连接到 Slack workspace，让 agents 能够在 Slack 中与用户沟通。

集成完成后，agents 将能够：

- 直接接收来自 Slack bot 的消息，并以消息内容启动新的 run。
- 在处理完消息后，把结果发送回 Slack workspace。
- 通过读取 thread 消息和对话历史，从 Slack 中获取相关上下文。

LangSmith Fleet 提供两种把 agent 连接到 Slack 的方式：**custom Slack bot**（推荐）和 **default Slack bot**。

## Custom bot 与 default bot 的区别

| | [Custom Slack bot](#set-up-a-custom-slack-bot) | [Default Slack bot](#set-up-the-default-slack-bot) |
|---|---|---|
| **Slack app** | 你自己的 app，通过 LangSmith 创建 | LangSmith 提供的 Slack 账号 |
| **Trigger** | 通过 `@Bot_Name` 直接提及 bot | 频道中的每一条消息都会触发 |
| **DMs** | ✅ | ❌ |
| **Best for** | 在 Slack 中进行直接的双向沟通。 | 每当某个特定频道里有新消息时都启动一个 run。 |

<Info>
Fleet 的 Slack 集成本身没有单独定价。不过，agent runs 和 traces 会按照你组织的套餐，通过 [LangSmith 平台](https://smith.langchain.com)计费。

最新定价信息请参阅 [LangSmith pricing page](https://www.langchain.com/pricing)。
</Info>

## 设置 custom Slack bot

Custom Slack bot 能让你的 agent 与 Slack 之间实现完整的双向通信。

### 前置要求

- Fleet 中已经存在一个 agent（可参考 [Quickstart](/langsmith/fleet/quickstart) 创建）
- 对 Slack workspace 拥有管理员权限，或具有安装应用的权限

### 创建 Slack app

<Steps>
  <Step title="Create a new Slack app">
    1. 进入 Fleet 中的 **Integrations** 页面，并切换到 **Apps** 区域。
    1. 点击 **Add Slack App**。
    1. 输入 bot 名称。
    1. 点击 **Create Slack App**。随后会跳转到 Slack API 网站，并弹出一个窗口让你选择 workspace。

    <Warning>
    不要在这个流程之外单独创建 Slack app。这个 app 必须通过这里的弹窗来创建。
    </Warning>
  </Step>

  <Step title="Select your workspace">
    1. 选择你要安装 bot 的 workspace。
    1. 点击 **Next**。
    1. 点击 **Create Bot**。
  </Step>

  <Step title="Enter your app credentials">
    创建 bot 后，你会拿到应用凭证。请在 Fleet 中填写以下内容：
    - App ID
    - Client ID
    - Client secret
    - Signing secret

    <Note>
    请仔细复制完整的 client secret 和 signing secret，以确保连接成功。
    </Note>
  </Step>

  <Step title="Connect OAuth">
    1. 点击 **Connect OAuth**。
    1. 点击 **Allow**，授予 Fleet 访问你的 app。
  </Step>

  <Step title="Finish setup">
    将 Slack bot 关联到某个已有 agent，或者点击 **Finish**，稍后再关联。
  </Step>
</Steps>

### 将 Slack bot 关联到 agent

你可以从 integrations 页面或 agent editor 中，把 Slack bot 关联到 agent。每个 agent 只能关联一个 Slack app，而每个 Slack app 也只能关联到一个 agent。
<Tabs>
  <Tab title="From the Integrations page">
    1. 进入 Fleet 的 **Integrations** 页面中的 **Slack Apps** 区域。
    1. 选择你想关联的 bot。
    1. 在下拉菜单中选择要关联的 agent。
    1. 确认 bot 名称旁边出现了 **\<Agent Name\>**。

  </Tab>
  <Tab title="From the agent editor">
    1. 在左侧导航的 **My Agents** 中选择你的 agent。
    1. 点击 <Icon icon="pencil"/> **Edit Agent**。
    1. 滚动到 **Channels** 区域。

       <Note>
       你可能需要先设置 agent identity。点击右上角的 **Set Identity**。
       </Note>

    1. 点击 **Slack**。
    1. 从下拉菜单中选择你要关联的 Slack app。

  </Tab>
</Tabs>

### 把 bot 邀请到你的频道

1. 在 Slack 中打开你想使用该 bot 的频道。
1. 输入 `/invite @YourSlackBotName`，将 bot 邀请进频道。
1. 发送一条提及 bot 的消息，确认它能够响应。

### 配置 agent 行为（可选）

你的 agent 需要知道如何处理来自 Slack 的消息。你可以直接在 agent 聊天中通过提示来更新它的 instructions：

```
Update your instructions to handle the Slack Trigger and Slack Tools
for bidirectional communication
```

根据你的实际使用场景调整 instructions，例如你可能希望 agent 只回答特定类型的问题，或在回复前先从某些特定来源拉取信息。

## 设置 default Slack bot

Default Slack bot 使用的是 LangSmith 的 Slack 账号，并会在连接的频道中，对每一条发送的消息触发你的 agent。它不能接收 DMs。

<Steps>
  <Step title="Authenticate with Slack and get the channel ID">
    1. 在 [Fleet > Integrations 页面](https://smith.langchain.com/agents/tools)上，用 Slack 完成认证。
    1. 在 Slack 中，把默认 app（`@LangSmith Fleet`）邀请进某个频道。
    1. 复制该频道的 channel ID。
  </Step>
  <Step title="Open the agent editor">
    在 [Fleet](https://smith.langchain.com/agents) 中选择你的 agent，并点击 <Icon icon="pencil"/> **Edit Agent** 图标。
  </Step>
  <Step title="Add a Slack channel">
    1.在 **Channels** 区域点击 **Slack**。
    1. 进入 **LangSmith Bot**，点击 **Add Channel**。
    1. 粘贴 channel ID 和 channel 名称。
  </Step>
  <Step title="Start a run">
    在该频道中发送任意消息即可启动一个 run。
  </Step>
</Steps>

## 添加 Slack 工具

Slack 工具可以让 agent 发送消息、在线程中回复，并读取频道历史。无论 agent 是通过 Slack、Fleet UI、schedule，还是 webhook 被触发，这些工具都能工作。

例如，你可以先在 Fleet 聊天 UI 中启动一个长期运行的研究任务，再让 agent 在完成后给你发一条 Slack 消息。

<Tip>
你也可以直接要求 agent 自己把这些工具加上。在 agent 聊天中可以试试：“Add the Slack tools so you can respond to messages.”
</Tip>

1. 在 agent editor 中滚动到 **Tools** 区域。
1. 点击 **+ Add**。
1. 搜索 “Slack”，如果还没添加，就加入你需要的工具：
   - **slack_send_channel_message**——向频道发送消息
   - **slack_reply_to_message**——在线程中回复
   - **slack_write_private_message**——发送私信
   - **slack_read_channel_history**——读取最近消息
   - **slack_read_thread_messages**——读取线程回复
1. 如有提示，点击 **Connect** 来授权 Slack 工具。
1. 点击 **Save changes**。

## 故障排查

### Agent 没有响应

如果你的 agent 没有响应，可以尝试以下检查：

- 查看 Fleet 中该 thread，确认是否有等待人工处理的审批。
- 确认 bot 已被邀请到目标频道。
- 查看 **Feed** 标签页中是否有错误。
- 确认 **Channels** 区域中该 channel 没有被暂停。
- 重新进行 Slack 认证，确保 Fleet 存储的是你最新的 Slack user ID。

### 不允许提及 bot

如果你收到一条私信，提示你无权提及该 bot，说明你的 Slack ID 没有被授权使用这个 agent。该 agent 的所有者需要把 agent 分享给你，可以是把 run 权限共享给整个 workspace，或单独共享给你。
