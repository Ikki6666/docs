通过 LangSmith Fleet，你可以把 agent 添加到你的 Slack workspace，让团队直接在 Slack 中使用它。

把 agent 添加到 Slack 之后，它可以：

- 接收来自 Slack 的消息，并以消息内容启动一次 run。
- 在处理完消息后，在你的 Slack workspace 中回复。
- 读取 thread 消息和对话历史，获取相关上下文。
- 读取 Slack 消息中包含的文件附件。

Fleet 会把每个 agent 映射到一个单独的 Slack app，因此用户感受到的是这个 agent 已部署在 Slack 中，而不是一个中转消息的独立服务。

<Warning>
免责声明：

**AI 生成内容**：agent 在 Slack 中的所有响应均由 AI 生成，可能包含错误或不准确之处。对于重要信息，请始终自行核实。
</Warning>

<Info>
Fleet 的 Slack 集成本身没有单独定价。不过，agent runs 和 traces 会按照你组织的套餐，通过 [LangSmith 平台](https://smith.langchain.com)计费。

最新定价信息请参阅 [LangSmith pricing page](https://www.langchain.com/pricing)。
</Info>

## 把你的 agent 添加到 Slack

你只需向 Slack 认证一次，之后就可以一键把任意 agent 添加到 Slack。Fleet 会为该 agent 创建一个 Slack app，并使用 agent 的名称、描述和图标进行配置。

<Note>
一键 Slack 设置适用于 LangSmith Cloud。在[自托管](/langsmith/deploy-self-hosted-full-platform#enable-fleet-insights-and-chat)环境下，请改为手动创建并关联一个 custom Slack app。请参阅[连接 custom Slack app（自托管）](#connect-a-custom-slack-app-self-hosted)。
</Note>

### 前置要求

- Fleet 中已经存在一个 agent（可参考 [Quickstart](/langsmith/fleet/quickstart) 创建）。
- 一个允许你安装应用的 Slack workspace。

### 连接 Slack

<Steps>
  <Step title="Open the Channels drawer">
    打开你的 agent，然后在侧边栏中展开 **Channels** 抽屉。
  </Step>
  <Step title="Connect Slack">
    1. 点击 **Connect your first channel**，然后选择 **Slack**。
    1. 首次连接时，请通过 Slack 完成认证并授权 Fleet。此后，把 agent 添加到 Slack 只需一键。
  </Step>
  <Step title="Confirm the Slack app">
    Fleet 会创建一个以你的 agent 命名的 Slack app，并将其关联到该 agent。每个 agent 对应一个 Slack app，每个 Slack app 也只关联到一个 agent。
  </Step>
</Steps>

<Note>
当你的 agent 首次被添加到某个 Slack workspace 时，它会给你发一条私信，介绍如何把它邀请到频道以及如何提及它。
</Note>

### 把 agent 邀请到频道

1. 在 Slack 中打开你想使用该 agent 的频道。
1. 输入 `/invite @YourAgentName`，将 agent 邀请进频道。
1. 用 `@YourAgentName` 提及该 agent 来启动一次 run。agent 会在一个 thread 中回复。

## 在 Slack 中批准或拒绝操作

当 agent 在某个需要审批的工具上暂停时，它会直接在 Slack 中提出请求。消息中会标明工具和操作名称，并附带 **Approve** 和 **Deny** 按钮，让你无需离开 Slack 即可做出回应。

关于审批的更多信息，请参阅 [Human-in-the-loop](/langsmith/fleet/essentials#human-in-the-loop)。

## Slack 中的错误消息

如果 agent 在某次 run 中遇到错误，它会在 Slack thread 中回复，而不是静默无响应。对于某些错误类型（例如认证错误），回复中会包含更多细节，方便你解决问题。

## 添加 Slack 工具

Slack 工具可以让 agent 发送消息、在线程中回复、读取历史，并发送私信。无论 agent 是通过 Slack、Fleet UI、schedule，还是 webhook 被触发，这些工具都能工作。

例如，你可以先在 Fleet 聊天 UI 中启动一个长期运行的研究任务，再让 agent 在完成后给你发一条 Slack 消息。

要添加 Slack 工具：

1. 打开你的 agent，然后在侧边栏中展开 **Connections** 抽屉。
1. 点击 **Add connection**，如果 Slack 尚未连接，则添加 Slack。
1. 添加你需要的 Slack 工具：
   - **Send Channel Message**：向频道发送消息。
   - **Reply to Message**：在线程中回复。
   - **Write Private Message**：发送私信。
   - **Read Channel History**：读取最近的频道消息。
   - **Read Thread Messages**：读取线程中的回复。
1. 如有提示，请授权 Slack 连接。

<Tip>
你也可以直接要求 agent 自己把这些工具加上。在 agent 聊天中可以试试：“Add the Slack tools so you can respond to messages.”
</Tip>

<Note>
将每个工具设为 **Auto** 可在无需审批的情况下运行，或设为 **Ask** 以在运行前要求审批。更多信息请参阅 [Human-in-the-loop](/langsmith/fleet/essentials#human-in-the-loop)。
</Note>

## 连接 custom Slack app（自托管）

在自托管环境下，一键 Slack 设置不可用。请改为在 **Integrations** 页面中，手动创建并关联一个 custom Slack app，即把你的 Slack app 凭证复制到 Fleet 中。

### 创建 Slack app

<Steps>
  <Step title="Create a new Slack app">
    1. 进入 Fleet 中的 **Integrations** 页面，并切换到 **Apps** 区域。
    1. 点击 **Add Slack App**。
    1. 输入 bot 名称。
    1. 点击 **Create Slack App**。随后会跳转到 Slack API 网站，并弹出一个窗口让你选择 workspace。

    <Warning>
    不要在这个流程之外单独创建 Slack app。这个 app 必须通过这里的弹窗来创建。
    </Warning>
  </Step>

  <Step title="Select your workspace">
    1. 选择你要安装 bot 的 workspace。
    1. 点击 **Next**。
    1. 点击 **Create Bot**。
  </Step>

  <Step title="Enter your app credentials">
    创建 bot 后，你会拿到应用凭证。请在 Fleet 中填写以下内容：
    - App ID
    - Client ID
    - Client secret
    - Signing secret

    <Note>
    请仔细复制完整的 client secret 和 signing secret，以确保连接成功。
    </Note>
  </Step>

  <Step title="Connect OAuth">
    1. 点击 **Connect OAuth**。
    1. 点击 **Allow**，授予 Fleet 访问你的 app。
  </Step>

  <Step title="Finish setup">
    将 Slack bot 关联到某个已有 agent，或者点击 **Finish**，稍后再关联。
  </Step>
</Steps>

### 把 custom app 关联到 agent

你可以从 **Integrations** 页面或 agent sidebar 中，把 custom Slack app 关联到 agent。每个 agent 只能关联一个 Slack app，而每个 Slack app 也只能关联到一个 agent。
<Tabs>
  <Tab title="From the Integrations page">
    1. 进入 Fleet 的 **Integrations** 页面中的 **Slack Apps** 区域。
    1. 选择你想关联的 app。
    1. 在下拉菜单中选择要关联的 agent。
    1. 确认 app 名称旁边出现了 **\<Agent Name\>**。
  </Tab>
  <Tab title="From the agent sidebar">
    1. 在左侧导航的 **My Agents** 中打开你的 agent。
    1. 在侧边栏中展开 **Channels** 抽屉。
    1. 选择 **Slack**。
    1. 从下拉菜单中选择你要关联的 Slack app。
  </Tab>
</Tabs>

## 故障排查

### Agent 没有响应

如果你的 agent 没有响应，可以尝试以下检查：

- 查看 Fleet UI 中该 thread 是否有错误。
- 确认 agent 已被邀请到目标频道。
- 尝试在 **Channels** 抽屉中删除该 Slack app，然后重新走一遍[设置流程](#add-your-agent-to-slack)。

### 不允许提及 bot

如果你收到一条私信，提示你无权提及该 bot，说明你的 Slack ID 没有被授权使用这个 agent。该 agent 的所有者需要把 agent 分享给你，可以是把 run 权限共享给整个 workspace，或单独共享给你。
