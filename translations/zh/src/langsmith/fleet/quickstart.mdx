完成本 quickstart 后，你将拥有一个 Executive Assistant：它会给需要你关注的 Gmail 邮件打上标签，并在执行操作前暂停等待你的批准——所有这些都无需编写代码、无需 model API key，并通过聊天来控制。

<Callout icon="message" color="#8B5CF6" iconType="regular">
你将通过聊天与 agent 交互，就像给一个乐于助人的助手发消息一样。
</Callout>

你将从预构建的 **Executive Assistant** [template](/langsmith/fleet/templates) 起步，它可以帮你管理收件箱、日历和每日简报。

## 开始之前

你需要准备：
- 一个 LangSmith 账号（[在这里注册](https://smith.langchain.com/agents?skipOnboarding=true)）。
- 一个 Gmail 账号。
- 一个 Google Calendar。

Fleet 会代为管理 AI model，因此你不需要自己的 model provider API key。更多信息请参阅 [Models](/langsmith/fleet/essentials#models)。

## 1. 创建你的 agent

<Steps>
  <Step title="Navigate to Fleet">
    1. 在 [LangSmith UI](https://smith.langchain.com) 中，点击左侧导航顶部的 <Icon icon="pointer"/> **Switch to Fleet**。
  </Step>

  <Step title="Choose a template">
    1. 在左侧导航中选择 **Templates**，或者点击 **My Agents** 中的 **+** 并选择 **From template**。
    1. 选择 **Executive Assistant** 模板来创建你的 agent。
    1. 点击右上角的 **Create Agent**。

    <Tip>
    如果你不想从模板开始，在创建 agent 时选择 **Build with AI** 或 **New agent**，并描述你想要的 agent。该 agent 会自行配置，并在关键节点暂停以获取你的输入。
    </Tip>
  </Step>

  <Step title="Skip channel setup for now">
    当 agent 提示你连接 channel 时，点击 **Skip for now**。你会在[后面的步骤](#3-configure-your-agent)中连接 channels。
  </Step>

  <Step title="Answer onboarding questions">
    提供相关信息，让 agent 知道如何按你偏好的方式工作。
  </Step>

</Steps>

## 2. 连接工具

你的 agent 会请求你连接 Gmail 和 Google Calendar 账号。

connection 赋予 agent 使用某个服务的[工具](/langsmith/fleet/tools)；而 [channel](/langsmith/fleet/channels) 则让该服务能够触发 agent。你在这里连接 Gmail 和 Google Calendar，随后在[配置你的 agent](#3-configure-your-agent) 中把 Gmail 添加为 channel。

<Steps>
  <Step title="Connect Gmail">
    1. 在 **Gmail** 行中，点击右侧的 **Connect**。
    2. 在对话框中，点击 **+ Connect new account**。
    3. 选择你的账号并点击 **Continue**。
    4. 查看权限说明并点击 **Allow**。
    5. LangSmith 会把你重定向回 Fleet。选择 **Gmail** 以展开该行。
    6. 点击 **Choose account**，并选择你在第 3 步中选择的账号。
  </Step>

  <Step title="Connect Google Calendar">
    1. 连接 Gmail 时，只为 Gmail 授权了你的 Google 账号，并未包含 Google Calendar。要授予日历访问权限，请在 **Google Calendar** 行右侧点击 **Update permissions**。
    2. 在对话框中，点击 **Reauthorize**。
    3. 选择你的账号并点击 **Continue**。
    4. 查看权限说明并点击 **Allow**。
    5. LangSmith 会把你重定向回 Fleet。关闭对话框。
    6. 点击 **Save and continue**。
  </Step>

</Steps>

<Info>
只有在执行你明确交给它的任务时，agent 才会访问你的账号。你也可以随时在 [agent sidebar](/langsmith/fleet/essentials#agent-sidebar) 或 Google 账号设置中撤销访问权限。
</Info>

## 3. 配置你的 agent

配置 agent 有两种方式：

- 直接与你的 agent 聊天
- 在 [agent sidebar](/langsmith/fleet/essentials#agent-sidebar) 中修改设置

本节介绍如何使用 agent sidebar 来配置 agent。

<Steps>

  <Step title="Open the agent sidebar">
    点击右上角的 **<Icon icon="settings"/> Configure**，打开 agent sidebar。
  </Step>

  <Step title="View connections">
    展开 **Connections** 抽屉。**Gmail** 和 **Google Calendar** 会显示为 **Connected**。如果其中任何一个显示为未连接，请先完成[2. 连接工具](#2-connect-tools)再继续。
  </Step>

  <Step title="Configure a tool to ask for approval">
    在 **Connections** 抽屉中，点击 **Gmail** 查看可用工具。默认情况下，这些工具已启用并设为 **Auto**，即无需你的批准即可运行。

    对于 **Apply Label**，点击 **Ask**，这样 agent 在继续之前会暂停并等待你的批准。你可以接受提议的操作，也可以拒绝并告诉 agent 需要修改什么。更多信息请参阅 [Human-in-the-loop](/langsmith/fleet/essentials#human-in-the-loop)。
  </Step>

  <Step title="Connect channels">
    展开 **Channels** 抽屉。点击 **Gmail**。选择你在 **Connections** 中设置的那个账号。点击 **Confirm**。
  </Step>

  <Step title="Save your changes">
    点击侧边栏顶部的 **Save** 保存你的更改，然后点击 **X** 关闭该面板。
  </Step>

</Steps>

## 4. 测试你的 agent

<Steps>

  <Step title="Send your agent a task">
    在 agent 聊天中，试用这个 Executive Assistant，例如：

        > _Apply a "Review" label to emails that I receive, which require some kind of review from me._
  </Step>

  <Step title="Accept or reject the agent's action">
    点击 **Accept** 批准 agent 提议的操作；或者告诉 agent 它哪里做错了，然后点击 **Reject**。
  </Step>

  <Step title="Check your inbox in Gmail">
    如果你点击了 **Accept**，收件箱中需要 review 的邮件现在就会带有 **Review** 标签。
  </Step>

</Steps>

## 编辑你的 agent

你可能还想更新 agent 的 instructions，或者增加更多工具。你既可以直接通过聊天让 agent 帮你更新，也可以通过 [agent sidebar](/langsmith/fleet/essentials#agent-sidebar) 来配置它：

- 在 **Knowledge** 抽屉中编辑 agent 的 instructions（即它的 `AGENTS.md`）。请参阅 [Instructions](/langsmith/fleet/essentials#instructions)。
- 在 **Connections** 抽屉中添加集成和工具，并将每个工具设为自动运行或[需要审批](/langsmith/fleet/essentials#human-in-the-loop)。请参阅 [Tools](/langsmith/fleet/tools)。
- 在 **Channels** 抽屉中连接 [Slack](/langsmith/fleet/slack-app)、[Gmail](/langsmith/fleet/channels#add-a-gmail-channel) 或 [Microsoft Teams](/langsmith/fleet/teams-app)。
- 在 **Schedules** 抽屉中按 [schedule](/langsmith/fleet/schedules) 运行你的 agent。
- 在 **Advanced settings** 抽屉中更换 [model](/langsmith/fleet/manage-agent-settings#change-the-model)。
