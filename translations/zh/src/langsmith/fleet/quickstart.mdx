在这个 quickstart 中，你将使用预定义的 **Email Assistant** [template](/langsmith/fleet/templates)，它可以帮你整理和管理收件箱。
- 你也可以选择其他模板。

<Callout icon="message" color="#8B5CF6" iconType="regular">
你将通过聊天与 agent 交互，就像给一个乐于助人的助手发消息一样。
</Callout>

## 开始之前

你需要准备：
- 一个 LangSmith 账号（[在这里注册](https://smith.langchain.com/agents?skipOnboarding=true)）。
- 一个 Gmail 账号。
- 一个 Google calendar。
- 一个 OpenAI 或 Anthropic API key（第 1 步会说明如何获取）。

## 1. 获取模型 API key

你的 agent 需要一个 API key 才能连接到 AI 模型。AI 模型负责理解并响应你的请求。

<Tabs>
  <Tab title="OpenAI (ChatGPT)">
    1. 前往 [platform.openai.com/api-keys](https://platform.openai.com/api-keys)。
    1. 点击 **Create new secret key**。
    1. 给它起一个名字，例如 “Fleet”。
    1. 复制这个 key（它以 `sk-` 开头）。
    1. 把它保存在安全的地方，第 2 步会用到。
  </Tab>

  <Tab title="Anthropic (Claude)">
    1. 前往 [console.anthropic.com/settings/keys](https://console.anthropic.com/settings/keys)。
    2. 点击 **Create Key**。
    3. 给它起一个名字，例如 “Fleet”。
    4. 复制这个 key（它以 `sk-ant-` 开头）。
    5. 把它保存在安全的地方，第 2 步会用到。
  </Tab>
</Tabs>

<Warning>
这两项服务都会按用量收费。
</Warning>

## 2. 把你的 API key 添加到 LangSmith

接下来你需要把 API key 添加到 LangSmith，这样 agents 才能使用它：

<Steps>
  <Step title="Open Settings">
    1. 打开 [smith.langchain.com](https://smith.langchain.com)。
    2. 点击左下角的 <Icon icon="settings" /> **Settings** 图标。
  </Step>

  <Step title="Go to Secrets">
    点击顶部的 **Secrets** 标签页。
  </Step>

  <Step title="Add your key">
    1. 点击 **Add secret**。
    2. 在 **Key** 中填写：
       - `OPENAI_API_KEY`（如果你使用 OpenAI）
       - `ANTHROPIC_API_KEY`（如果你使用 Anthropic）
    3. 在 **Value** 中粘贴你在第 1 步复制的 API key。
    4. 点击 **Save secret**。
  </Step>
</Steps>

<Callout type="success" icon="check" color="#10B981" iconType="regular">
现在你的 agent 已经可以访问 AI 模型来理解和响应请求了。接下来，你将创建自己的 agent。
</Callout>

## 3. 创建你的 agent

<Steps>
  <Step title="Navigate to Fleet">
    1. 在 [LangSmith UI](https://smith.langchain.com) 中，点击左侧导航顶部的 <Icon icon="pointer"/> **Switch to Fleet**。
  </Step>

  <Step title="Choose a template">
    1. 在左侧导航中选择 **Templates**。
    1. 选择 **Email Assistant** 模板。
    1. 点击 **Use this template**。

    <Tip>
    如果你不想从模板开始，还有另外两种方式。在 **+ New Agent** 页面中：
    - **Chat**：通过聊天界面描述你想要的 agent，它会一步步帮你创建。
    - **Manually**：选择 **Create manually instead**，在配置页面中不使用任何预填内容，手动搭建 agent。
    </Tip>
  </Step>

  <Step title="Authorize accounts">
    你的 agent 会请求你连接 Google 账号：

    1. 点击 **Connect**。
    2. 使用你的 Google 账号登录。
    3. 查看权限说明并点击 **Allow**。
    4. 你会被重定向回 LangSmith，此时 agent 会被创建。
  </Step>

</Steps>

<Info>
只有在执行你明确交给它的任务时，agent 才会访问你的账号。你也可以随时在 Google 账号设置中撤销访问权限。
</Info>

## 4. 查看 agent 模板

<Steps>

  <Step title="View and customize the template">

    这时你可以查看 email assistant 的模板 instructions。如有需要，也可以对 instructions 做调整。

    如果你做了修改，请点击 **Save changes**。
  </Step>

  <Step title="Start a test chat">
    1. 在配置页面右侧面板中，选择 **Test Chat** 标签页。
    2. 在聊天界面中试用这个 email assistant，例如：

        > _Apply a "Review" label to emails that I receive, which require some kind of review from me_
  </Step>

  <Step title="Agent starts working">
    agent 会开始工作，并在每一步需要你批准时提供 **Continue** 选项。

    3. 在测试 agent 的过程中，你可以继续修改 instructions，或添加你需要的工具。确认效果满意后，点击 **Save changes**。

  </Step>

</Steps>

## 编辑你的 agent

你可能还想更新 agent 的 instructions，或者增加更多工具。你既可以直接通过聊天让 agent 帮你更新，也可以：

1. 在左侧导航的 **My Agents** 中选择你想编辑的 agent。
1. 选择 <Icon icon="pencil"/> **Edit Agent**。

进入 agent 的编辑页面后，你可以：

- 使用 **+ Add tool** 添加更多工具，连接 Slack、GitHub、Linear 等应用和服务。
- 使用 **+ Add sub-agent** 添加更多辅助 agent，把复杂任务拆成更细的子任务。
- 为现有工具添加审批暂停点。
- 修改已有工具。
- 探索可自动触发 agent 的 channels。
