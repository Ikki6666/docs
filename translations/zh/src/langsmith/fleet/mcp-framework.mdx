LangSmith Tool Server 是一个独立的 MCP framework，用于构建和部署自带认证与授权能力的工具。以下情况适合使用 Tool Server：

- [创建自定义工具](#create-a-custom-toolkit)，并与 LangSmith 的 [Agent Auth](/langsmith/agent-auth) 集成，实现 OAuth 认证
- [构建 MCP gateway](#use-as-an-mcp-gateway)，供你在 Fleet 之外自行构建的 agents 使用

<Note>
如果你正在使用 [Fleet](/langsmith/fleet/index)，通常不需要直接与 Tool Server 交互。Fleet 已经提供了[内置 tools](/langsmith/fleet/tools)，并支持[远程 MCP servers](/langsmith/fleet/remote-mcp-servers)，无需单独设置 Tool Server。

不过，你仍然可以把与之关联的 tool server 实例配置成一个 MCP server，这样你就能在 agent 中使用自定义 MCP servers。
</Note>

可以从 [PyPI package](https://pypi.org/project/langsmith-tool-server/) 开始。

## 创建自定义 toolkit

安装 LangSmith Tool Server 和 LangChain CLI：

```bash
pip install langsmith-tool-server
pip install langchain-cli-v2
```

创建一个新的 toolkit：

```bash
langchain tools new my-toolkit
cd my-toolkit
```

这会生成如下结构的 toolkit：

```
my-toolkit/
├── pyproject.toml
├── toolkit.toml
└── my_toolkit/
    ├── __init__.py
    ├── auth.py
    └── tools/
        ├── __init__.py
        └── ...
```

使用 `@tool` 装饰器定义你的工具。关于工具 schema、返回值、错误处理和 `ToolRuntime` 的更多信息，请参阅 [Tools guide](/oss/langchain/tools)。

```python
from langsmith_tool_server import tool

@tool
def hello(name: str) -> str:
    """Greet someone by name."""
    return f"Hello, {name}!"

@tool
def add(x: int, y: int) -> int:
    """Add two numbers."""
    return x + y

TOOLS = [hello, add]
```

运行服务端：

```bash
langchain tools serve
```

你的 tool server 会启动在 `http://localhost:8000`。

## 通过 MCP 协议调用工具

下面的示例展示了如何列出可用工具并调用 `add` 工具：

```python
import asyncio
import aiohttp

async def mcp_request(url: str, method: str, params: dict = None):
    async with aiohttp.ClientSession() as session:
        payload = {"jsonrpc": "2.0", "method": method, "params": params or {}, "id": 1}
        async with session.post(f"{url}/mcp", json=payload) as response:
            return await response.json()

async def main():
    url = "http://localhost:8000"

    tools = await mcp_request(url, "tools/list")
    print(f"Tools: {tools}")

    result = await mcp_request(url, "tools/call", {"name": "add", "arguments": {"a": 5, "b": 3}})
    print(f"Result: {result}")

asyncio.run(main())
```

## 用作 MCP gateway

LangSmith Tool Server 也可以作为 MCP gateway，把多个 MCP servers 的工具聚合到一个端点中。你可以在 `toolkit.toml` 中配置这些 MCP servers：

```toml
[toolkit]
name = "my-toolkit"
tools = "./my_toolkit/__init__.py:TOOLS"

[[mcp_servers]]
name = "weather"
transport = "streamable_http"
url = "http://localhost:8001/mcp/"

[[mcp_servers]]
name = "math"
transport = "stdio"
command = "python"
args = ["-m", "mcp_server_math"]
```

所有已连接 MCP servers 的工具，都会通过你这个 server 的 `/mcp` 端点暴露出来。为避免命名冲突，MCP 工具会自动加上所属 server 名作为前缀（例如 `weather_get_forecast`、`math_add`）。

## 认证

### 面向第三方 API 的 OAuth

对于需要访问第三方 API 的工具（例如 Google、GitHub、Slack 等），你可以通过 [Agent Auth](/langsmith/agent-auth) 使用 OAuth 认证。

在你的工具中使用 OAuth 之前，需要先在 LangSmith workspace settings 中配置好一个 OAuth provider。具体设置请参阅 [Agent Auth documentation](/langsmith/agent-auth)。

配置完成后，在工具装饰器中指定 `auth_provider`：

```python
from langsmith_tool_server import tool, Context
from google.oauth2.credentials import Credentials
from googleapiclient.discovery import build

@tool(
    auth_provider="google",
    scopes=["https://www.googleapis.com/auth/gmail.readonly"],
    integration="gmail"
)
async def read_emails(context: Context, max_results: int = 10) -> str:
    """Read recent emails from Gmail."""
    credentials = Credentials(token=context.token)
    service = build('gmail', 'v1', credentials=credentials)
    # ... Gmail API calls
    return f"Retrieved {max_results} emails"
```

带 `auth_provider` 的工具必须满足：
- 第一个参数必须是 `context: Context`
- 必须至少指定一个 scope
- 必须使用 `context.token` 来发起已认证的 API 调用

### 自定义请求认证

自定义认证允许你验证请求，并与自己的身份提供方集成。你可以在 `auth.py` 文件中定义一个认证处理器：

```python
from langsmith_tool_server import Auth

auth = Auth()

@auth.authenticate
async def authenticate(authorization: str = None) -> dict:
    """Validate requests and return user identity."""
    if not authorization or not authorization.startswith("Bearer "):
        raise auth.exceptions.HTTPException(
            status_code=401,
            detail="Unauthorized"
        )

    token = authorization.replace("Bearer ", "")
    # Validate token with your identity provider
    user = await verify_token_with_idp(token)

    return {"identity": user.id}
```

该处理器会在每次请求时运行，并且必须返回一个包含 `identity` 的字典（也可以额外返回 `permissions`）。
