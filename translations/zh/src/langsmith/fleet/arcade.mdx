[Arcade](https://arcade.dev) 提供托管的 MCP gateways，让你的 agents 能够通过一个统一 integration 访问成千上万的第三方工具。它支持的服务涵盖邮件、日历、代码托管、项目管理、CRM、消息、搜索等多个领域，包括 GitHub、Gmail、Google Drive、Slack、Notion、Jira、Salesforce、Linear 和 HubSpot。

当你把 Arcade 连接到工作区时，工作区管理员会选择一个 Arcade organization 和 project，然后从该 project 中安装 MCP gateways。之后，每个用户都连接自己的 Arcade 账号，这样工具调用就会使用用户各自的凭据来认证。

## 前置条件

- 一个拥有 **admin** 权限的 LangSmith 工作区（用于配置 integration）
- 一个至少包含一个 organization 和一个 project 的 [Arcade](https://arcade.dev) 账号

## 作为工作区管理员设置 Arcade

只有[工作区管理员](/langsmith/rbac#workspace-admin)才能配置 Arcade integration，包括添加或删除 MCP Gateways。配置完成后，该 integration 会对工作区内所有用户可用。

<Steps>
  <Step title="打开 Integrations 标签页">
    进入 [**Fleet** > **Integrations**](https://smith.langchain.com/agents/tools)。在左侧菜单的 **Apps** 下，点击 **Arcade**。
  </Step>
  <Step title="连接你的 Arcade 账号">
    点击 **Connect**，通过 OAuth 与 Arcade 完成认证。这会把你的 Arcade 账号链接到工作区。
  </Step>
  <Step title="选择 organization 和 project">
    为工作区选择 Arcade **Organization** 和 **Project**。工作区中安装的所有 MCP gateways 都来自这个 project。
  </Step>
  <Step title="安装 MCP gateways">
    浏览该 Arcade project 中可用的 gateways，并点击 **Add to workspace** 进行安装。安装后的 gateways 会以 MCP servers 的形式出现，并可供工作区中所有 agents 使用。
  </Step>
</Steps>

## 作为工作区成员连接

当管理员完成 Arcade 配置后，其他用户必须连接自己的 Arcade 账号才能使用这些工具。每位用户都单独完成认证，因此工具调用使用的是他们自己的凭据，而不是管理员的凭据。

<Steps>
  <Step title="获取 Arcade project 邀请">
    请工作区管理员把你邀请到他们的 Arcade organization 和 project 中。你必须是同一个 project 的成员，才能访问该 project 的 gateways。
  </Step>
  <Step title="连接你的账号">
    进入 [**Fleet** > **Integrations**](https://smith.langchain.com/agents/tools)。在左侧菜单的 **Apps** 下点击 **Arcade**，然后点击 **Connect**，通过 OAuth 完成认证。
  </Step>
  <Step title="浏览可用工具">
    连接完成后，管理员安装的 MCP servers 会自动显示出来。你可以在 agent 编辑器中把这些工具添加到自己的 agents 中。
  </Step>
</Steps>

<Note>
工作区成员不能修改 Arcade organization 或 project。只有管理员可以调整工作区级配置。
</Note>

## 为 agent 使用 Arcade 工具

连接完成后，把 Arcade 工具添加到某个具体 agent：

1. 在 [Fleet](https://smith.langchain.com/agents) 中打开你的 agent，并点击 <Icon icon="pencil"/> **Edit Agent** 图标。
1. 在 **Toolbox** 部分，点击 **+ Add**。
1. 选择你希望为该 agent 启用的 Arcade 工具。
1. 点击 **Save changes**。

该 agent 现在就可以在运行时调用这些工具。当某个工具需要授权时，Arcade 会提示用户通过 OAuth 授予访问权限。

## 修改 organization 或 project

管理员可以随时更新工作区级别的 Arcade organization 和 project。

<Warning>
修改 organization 或 project 会**移除工作区中所有已安装的 MCP servers**。修改后，你需要从新的 project 重新安装 gateways。
</Warning>

<Steps>
  <Step title="打开配置">
    进入 [**Fleet** > **Integrations**](https://smith.langchain.com/agents/tools)。在左侧菜单的 **Apps** 下点击 **Arcade**。再点击设置图标，打开 **Arcade Workspace Configuration** 对话框。
  </Step>
  <Step title="选择新的 organization 和 project">
    从下拉框中选择新的 organization 和 project。
  </Step>
  <Step title="确认变更">
    点击 **Save Changes**。如果这次修改会移除现有 MCP servers，请在随后弹出的对话框中确认。所有之前安装的 gateways 都会被移除，你可以随后从更新后的 project 中安装新的 gateways。
  </Step>
</Steps>

## 断开 Arcade 连接

进入 [**Fleet** > **Integrations**](https://smith.langchain.com/agents/tools)。在左侧菜单的 **Apps** 下点击 **Arcade**，然后点击 **Disconnect**。这样会撤销你的 OAuth token，但不会影响工作区配置或其他用户。

管理员可以通过删除工作区配置来完全移除 Arcade integration，这也会一并删除所有已安装的 Arcade MCP servers。
