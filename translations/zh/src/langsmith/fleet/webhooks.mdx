当 webhook 被触发时，它会把你的 agent 配置和文件完整打包，并发送到指定端点。

<Callout icon="lock" color="#4F46E5" iconType="regular">
**安全说明：**

- Webhook URLs 必须使用 HTTPS。
- 自定义 headers（例如 API keys）会以加密形式存储。
- payload 中会包含发布者身份，以满足审计追踪需求。
- Webhooks 仅对 agent 的所有者可见。
</Callout>

## 添加 webhook

1. 进入 [Settings > Fleet webhooks](https://smith.langchain.com/settings/workspaces/agent-builder-webhooks)。
2. 点击 **Add webhook**。
3. 配置以下内容：
   - **Name**：描述性名称（例如 “Publish Agent”、“Deploy to Production”）。
   - **URL**：接收 webhook 的 HTTPS endpoint。
   - **Headers**（可选）：用于认证的自定义 headers（以加密形式存储）。
   - **Form Schema**（可选）：定义触发时用户必须填写的自定义输入字段。
4. 点击 **Save**。

## 触发 webhook

1. 在 Fleet editor 中打开你的 agent。
2. 点击 **Settings** 菜单（齿轮图标）。
3. 在 **Webhooks** 区域下，点击 webhook 名称。
4. 填写 form schema 中定义的所有自定义字段。
5. 点击 **Run Webhook**。

## 编辑 webhook

1. 进入 [Settings > Fleet webhooks](https://smith.langchain.com/settings/workspaces/agent-builder-webhooks)。
1. 对于你要编辑的 webhook，点击 **Edit**。
1. 完成修改后点击 **Save**。

## 删除 webhook

1. 进入 [Settings > Fleet webhooks](https://smith.langchain.com/settings/workspaces/agent-builder-webhooks)。
1. 对于你要删除的 webhook，点击 **Delete**。
1. 再次点击 **Delete** 以确认删除。

## Webhook payload

Webhook payload 是一个 JSON 对象，包含以下字段：

| Field | Description |
|-------|-------------|
| `action` | webhook 的名称。 |
| `input` | 自定义表单字段的值（如果没有自定义字段，则为空对象）。 |
| `publisher` | 触发该 webhook 的用户 ID 和邮箱。 |
| `agent` | agent 的名称和描述。 |
| [`tool_auth_requirements`](#tool-auth-requirements) | agent 所使用每个工具的认证要求。 |
| [`files`](#zip-file-structure) | 包含所有 agent 文件的 base64 编码 ZIP。 |
| [`fields`](#custom-input-fields) | 自定义输入字段。 |

例如：

```json
{
  "action": "Webhook Name",
  "input": {
    "notes": "User-provided value",
    "environment": "prod",
    "dry_run": true
  },
  "publisher": {
    "user_id": "uuid-of-publishing-user",
    "email": "user@example.com"
  },
  "agent": {
    "name": "My Agent",
    "description": "Agent description text"
  },
  "tool_auth_requirements": [
    {
      "tool_name": "tavily_web_search",
      "auth_type": "api_key",
      "required_env_vars": ["TAVILY_API_KEY"]
    },
    {
      "tool_name": "google_calendar",
      "auth_type": "oauth",
      "auth_provider": "google",
      "scopes": ["calendar.readonly"]
    }
  ],
  "files": {
    "type": "zip",
    "filename": "My_Agent.zip",
    "content_base64": "<base64-encoded-zip>"
  },
  "fields": [
    {
      "name": "notes",
      "label": "Deployment Notes",
      "type": "textarea"
    }
  ]
}
```

### 工具认证要求

`tool_auth_requirements` 数组用于描述每个工具所需的认证方式：

| Auth Type | Fields | Description |
|-----------|--------|-------------|
| `none` | - | 工具不需要认证 |
| `api_key` | `required_env_vars` | 工具需要通过环境变量提供 API key |
| `oauth` | `auth_provider`, `scopes` | 工具需要具备指定 scope 的 OAuth token |

你可以利用这些信息为部署环境配置所需凭证。

### ZIP 文件结构

`files.content_base64` 字段中包含一个 ZIP 压缩包，结构如下：

```
.
├── AGENTS.md           # Agent system prompt and instructions
├── config.json         # Agent metadata (name, description, visibility)
├── tools.json          # Tool configurations and interrupt settings
├── skills/             # Optional skill definitions
│   └── skill-name/
│       └── SKILL.md
└── subagents/          # Optional subagent configurations
    └── research_worker/
        ├── AGENTS.md
        └── tools.json
```

其中 `config.json` 和 `tools.json` 的结构如下：

<Tabs>
  <Tab title="`config.json`">
    ```json
    {
      "name": "My Agent",
      "description": "Agent description",
      "visibility_scope": "tenant",
      "triggers_paused": false
    }
    ```
  </Tab>
  <Tab title="`tools.json`">
    ```json
    {
      "tools": [
        {
          "name": "tavily_web_search",
          "mcp_server_url": "http://localhost:8084",
          "mcp_server_name": "Fleet",
          "display_name": "tavily_web_search"
        }
      ],
      "interrupt_config": {
        "http://localhost:8084::tavily_web_search::Fleet": false
      }
    }
    ```
  </Tab>
</Tabs>

### 自定义输入字段

你可以定义自定义输入字段，用于在触发 webhook 时收集信息。支持的字段类型如下：

| Type | Description |
|------|-------------|
| `string` | 单行文本输入（默认）。 |
| `number` | 数字输入。 |
| `boolean` | 复选框（true/false）。 |
| `textarea` | 多行文本输入。 |
| `json` | JSON 编辑器。 |
| `select` | 预定义选项的下拉框。 |

例如：

```json
{
  "fields": [
    {
      "name": "notes",
      "label": "Deployment Notes",
      "type": "textarea"
    },
    {
      "name": "environment",
      "label": "Environment",
      "type": "select",
      "options": [
        { "label": "Development", "value": "dev" },
        { "label": "Staging", "value": "staging" },
        { "label": "Production", "value": "prod" }
      ]
    },
    {
      "name": "dry_run",
      "label": "Dry Run",
      "type": "boolean",
      "default": true
    }
  ]
}
```

## 示例：Webhook server

下面是一个 Python 编写的示例 webhook server：

```python
from http.server import HTTPServer, BaseHTTPRequestHandler
import json
import base64
import zipfile
import io

class WebhookHandler(BaseHTTPRequestHandler):
    def do_POST(self):
        content_length = int(self.headers['Content-Length'])
        body = json.loads(self.rfile.read(content_length))

        action = body.get("action")
        input_data = body.get("input", {})
        publisher = body.get("publisher", {})
        agent = body.get("agent", {})
        tool_auth = body.get("tool_auth_requirements", [])
        files = body.get("files", {})

        print(f"Webhook: {action}")
        print(f"Publisher: {publisher.get('email')}")
        print(f"Agent: {agent.get('name')}")
        print(f"Custom Input: {input_data}")

        # Extract ZIP contents
        if files.get("content_base64"):
            zip_bytes = base64.b64decode(files["content_base64"])
            with zipfile.ZipFile(io.BytesIO(zip_bytes)) as zf:
                print(f"Files: {zf.namelist()}")

        self.send_response(200)
        self.send_header("Content-Type", "application/json")
        self.end_headers()
        self.wfile.write(json.dumps({"status": "ok"}).encode())

HTTPServer(("", 8000), WebhookHandler).serve_forever()
```
