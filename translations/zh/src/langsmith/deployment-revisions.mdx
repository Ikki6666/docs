---
title: Revisions
description: 为 LangSmith Cloud deployment 创建和管理 revisions。
---

Revision 将应用的一个版本部署到已有的 Cloud deployment 上。创建 revision 可以在发布代码变更的同时，不必创建另一个 deployment。

## 创建 revision

当你[创建 deployment](/langsmith/deploy-to-cloud) 时，LangSmith 会创建其第一个 revision。使用 LangSmith UI 或 LangGraph CLI 创建后续 revisions。

<Tabs>
  <Tab title="LangSmith UI">
    在 [LangSmith UI](https://smith.langchain.com) 中，选择 **Deployments**，然后选择一个 deployment。

    1. 在 **Deployment** 视图的右上角，选择 **+ New Revision**。
    1. 在 **New Revision** 模态框中，指定 [API configuration file](/langsmith/cli#configuration-file) 的完整路径，包括文件名。例如，如果文件位于 repository 根目录，请输入 `langgraph.json`。
    1. 选择是否让该 deployment 可以通过 [Studio](/langsmith/studio) 共享。
    1. 添加、移除或更新 environment variables 和 secrets。已有值会预先填充。更多信息请参阅 [Environment variables](/langsmith/env-var-cloud)。
    1. 选择 **Submit**。LangSmith 会将该 revision 加入部署队列。
  </Tab>
  <Tab title="LangGraph CLI">
    在项目目录中再次运行 `langgraph deploy`。该命令会按名称找到已有的 deployment，并使用你最新的代码变更创建一个 revision：

    ```shell
    langgraph deploy
    ```

    要按 ID 指定某个 deployment，请运行：

    ```shell
    langgraph deploy --deployment-id <DEPLOYMENT_ID>
    ```

    要查看 deployment IDs，请运行：

    ```shell
    langgraph deploy list
    ```

    <Note>
    `langgraph deploy` 只能更新最初通过 `langgraph deploy` 创建的 deployments。要更新通过 UI 或 GitHub integration 创建的 deployments，请使用 LangSmith UI。
    </Note>
  </Tab>
</Tabs>

## 中断 revision

只有当 revision 卡住并阻止你部署另一个 revision 时，才中断它。

<Warning>
被中断的 revisions 行为未定义。LangChain 未来可能会移除此功能。
</Warning>

要中断一个 revision：

1. 在 **Deployments** 视图中，选择一个 deployment。
1. 在 **Revisions** 表格中，选择该 revision 的菜单图标。
1. 选择 **Interrupt**。
1. 阅读确认消息，然后选择 **Interrupt revision**。
