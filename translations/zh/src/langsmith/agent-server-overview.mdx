在 [Agent Server](/langsmith/agent-server) runtime 上配置和构建 application。部署完成后，agents 通过三个原语协作：用于配置的 [**assistants**](/langsmith/assistants)、用于状态的 [**threads**](/langsmith/use-threads)，以及用于工作负载的 [**runs**](/langsmith/runs)。本标签页中的内容涵盖 Agent Server 提供的 capabilities、如何[组织你的 application](/langsmith/application-structure)，以及如何[保护](/langsmith/auth)和[定制](/langsmith/custom-routes)服务端。
