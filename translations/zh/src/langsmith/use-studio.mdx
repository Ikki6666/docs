本页介绍你会在 Studio 中使用到的核心工作流。它说明如何运行应用、管理 assistant 配置，以及处理对话 threads。每个部分都同时包含 graph mode，即图执行的完整功能视图，和 chat mode，即轻量级对话界面，中的操作步骤：

- [运行应用](#run-application)：执行你的应用或智能体，并观察其行为。
- [管理 assistants](#manage-assistants)：创建、编辑并选择应用使用的 assistant 配置。
- [管理 threads](#manage-threads)：查看并组织 threads，包括 fork 过去的 runs 或编辑它们以进行调试。

## 运行应用

<Tabs>
<Tab title="Graph">

### 指定输入

1. 在页面左侧、图界面下方的 **Input** 区域中定义传给 graph 的输入。Studio 会根据 graph 定义的[state schema](/oss/langgraph/graph-api/#schema)尝试为你的输入渲染一个表单。要禁用这一行为，请点击 **View Raw** 按钮，此时会显示一个 JSON 编辑器。
1. 点击 **Input** 区域顶部的上下箭头，可以切换并复用此前提交过的输入。

### 运行设置

#### Assistant

如需指定本次 run 使用的 [assistant](/langsmith/assistants)：

1. 点击左下角的 **Settings** 按钮。如果当前已经选中了 assistant，按钮上也会显示 assistant 名称。如果没有选中，则会显示 **Manage Assistants**。
1. 选择要运行的 assistant。
1. 点击弹窗顶部的 **Active** 开关将其激活。

更多信息请参阅[管理 assistants](#manage-assistants)。

#### Streaming

点击 **Submit** 旁边的下拉菜单，并切换开关以启用或禁用 streaming。

#### Breakpoints

如需带断点运行你的 graph：

1. 点击 **Interrupt**。
1. 选择一个节点，以及是在该节点执行前还是执行后暂停。
1. 在 thread log 中点击 **Continue** 恢复执行。

有关 breakpoints 的更多信息，请参阅 [Human-in-the-loop](/oss/langchain/human-in-the-loop)。

### 提交 run

如需使用指定的输入和运行设置提交 run：

1. 点击 **Submit** 按钮。这会将一个 [run](/langsmith/runs) 添加到当前选中的 [thread](/oss/langgraph/checkpointers#threads) 中。如果当前没有选中 thread，则会自动创建一个新 thread。
1. 如需取消正在进行的 run，点击 **Cancel** 按钮。

</Tab>
<Tab title="Chat">

在对话面板底部，为你的 chat 应用指定输入。

1. 点击 **Send message** 按钮，以 Human message 的形式提交输入，并让响应以流式方式返回。

如需取消正在进行的 run：

1. 点击 **Cancel**。
1. 点击 **Show tool calls** 开关，以隐藏或显示对话中的工具调用。

</Tab>
</Tabs>

## 管理 assistants

Studio 支持你查看、编辑和更新 assistants，并允许你使用这些 assistant 配置来运行 graph。

如需了解更多概念说明，请参阅 [Assistants overview](/langsmith/assistants/)。

<Tabs>
<Tab title="Graph">

如需查看你的 assistants：

1. 点击左下角的 **Manage Assistants**。这会打开一个弹窗，用于查看当前选中 graph 的所有 assistants。
1. 指定你想标记为 **Active** 的 assistant 及其版本。提交 runs 时，LangSmith 会使用这个 assistant。

**Default configuration** 选项会处于激活状态，它反映的是 graph 中定义的默认配置。对该配置所做的编辑会用于更新运行时配置，但除非你点击 **Create new assistant**，否则不会更新已有 assistant，也不会创建新的 assistant。

</Tab>
<Tab title="Chat">

在 chat mode 中，你可以通过页面顶部的下拉选择器切换 graph 中不同的 assistants。如需创建、编辑或删除 assistants，请使用 Graph mode。

</Tab>
</Tabs>

## 管理 threads

Studio 提供了查看服务器上所有已保存 [threads](/oss/langgraph/checkpointers#threads) 并编辑其状态的工具。你可以创建新 threads、在线程之间切换，并在 graph mode 和 chat mode 中修改过去的状态。

<Tabs>
<Tab title="Graph">

### 查看 threads

1. 在右侧面板顶部，选择下拉菜单以查看现有 threads。
1. 选择所需的 thread，thread 历史会显示在页面右侧。
1. 如需创建新 thread，点击 **+ New Thread**，然后[提交一个 run](#run-application)。
1. 如需在线程中查看更细粒度的信息，请将页面顶部的滑块向右拖动。若要减少信息量，则向左拖动。此外，你还可以单独折叠或展开状态中的 turns、nodes 和 keys。
1. 在 `Pretty` 和 `JSON` 模式之间切换，以查看不同的渲染格式。

### 编辑 thread 历史

如需编辑 thread 的状态：

1. 在目标节点旁点击 <Icon icon="pencil"/> **Edit node state**。
1. 按需编辑该节点的输出，然后点击 **Fork** 确认。这会从所选节点的 checkpoint 创建一个新的 forked run。

如果你想从某个 checkpoint 重新运行 thread，而不编辑状态，请点击 **Re-run from here**。这同样会从所选 checkpoint 创建一个新的 forked run。这适合用于重跑那些不是状态本身变化引起的情况，例如更换了选中的 assistant。

</Tab>
<Tab title="Chat">

1. 在页面右侧面板中查看所有 threads。
1. 选择所需 thread，其历史会显示在中间面板中。
1. 如需创建新 thread，点击 **+**，然后提交一个 run。

如需编辑 thread 中的一条 human message：

1. 在该 human message 下方点击 <Icon icon="pencil"/> **Edit node state**。
1. 按需编辑消息后提交。这会创建一个新的对话历史 fork。
1. 如需重新生成一条 AI message，点击该 AI message 下方的重试图标。

</Tab>
</Tabs>
