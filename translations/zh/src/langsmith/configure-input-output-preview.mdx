默认情况下，LangSmith 会使用启发式规则，决定在 **Runs** 表格的 **Input** 和 **Output** 列中显示什么内容。不过，你也可以通过为特定 trace 类型配置自定义预览路径，精确控制这些列中显示的内容。

在以下场景下，这尤其有用：

- 你的 traces 拥有很深的嵌套结构。
- 你只想聚焦数据中的特定字段。
- 默认启发式规则没有展示对你的场景最相关的信息。

## 在 UI 中配置预览格式

### 访问预览设置

1. 进入你项目中的某条 trace。
1. 选择 **Runs** 标签页。
1. 在 runs 表格右上角找到格式图标 <Icon icon="adjustments-horizontal" />。
1. 在 **Configure Input and Output previews** 侧边窗口中，从下拉菜单中选择一个 trace 名称。


当你选择某个 trace 名称后，LangSmith 会加载一条成功的 trace 示例，并把它的结构渲染为可展开的树形视图。树中的每个节点都代表你数据中的一个字段，并展示：

- 字段名称（例如 `messages`、`output`、`metadata`）。
- 数组索引（例如 [0]、[1]、[-1] 表示最后一项）。
- 数组项数量（例如 (3) 表示共有 3 个元素）。
- 行内显示的字符串和数字预览值。

### 设置路径

1. 选择 **Input** 或 **Output** 标签。然后使用以下任一方式：
    - 通过下拉框，直接指定应从输入数据中取哪一路径显示在预览中。
    - 通过示例 trace 数据结构的交互式树视图，浏览并精确选择你想显示的字段。

    要选择一个字段：

    1. 点击箭头图标（▶）展开或折叠嵌套对象和数组，在树中逐层导航。
    1. 点击你想显示在预览中的字段旁的复选框。选中的路径会显示在树视图上方的文本输入框中。

    选中复选框时，系统会自动按正确语法构建路径（例如 `messages[-1].content`）。


| Method | Best For | Example |
| --- | --- | --- |
| Tree selection | 探索不熟悉的数据结构、查看示例值 | 逐层点击：messages → [-1] → content |
| Manual typing | 当你已经清楚目标路径时，适合快速输入深层路径 | 输入：output.data.results[0].answer |

超过 3 项的数组会被自动折叠，以避免视图过于拥挤：

```
☐ messages (15)
  ☐ [0]
  ☐ [1]
  ... (click to expand all 15 items)
```

点击 **...** 按钮即可展开并查看数组中的所有元素。

## 示例

例如，你的 trace 输入如下：

```json
{
  "messages": [
    {"role": "system", "content": "You are a helpful assistant"},
    {"role": "user", "content": "What is the weather today?"}
  ],
  "metadata": {
    "user_id": "user123",
    "session_id": "sess456"
  }
}
```

在这个例子中，`messages` 是一个消息对象数组，每个对象都有 `role`（例如 `system` 或 `user`）以及 `content` 字段。

如果你想显示用户的问题：

1. 展开 **messages** 节点（显示数组项）。
1. 展开 `[1]`（第二条消息，也就是用户消息）。
1. 点击 **content** 旁边的复选框。
1. 输入框中会显示：`messages[1].content`。

或者，也可以用负索引来表示最后一条消息：

1. 展开 **messages**。
1. 展开 `[-1]`。
1. 点击 **content**。
1. 结果为：`messages[-1].content`（始终显示最后一条消息）。

<Note>
如果你在树视图中看到 `"No paths available"`：

- 请确认过去 7 天内，至少有一条使用所选 trace 名称的成功 trace。
- 该 trace 在你正在配置的 input/output 字段中必须有数据。
- 如有需要，请先发送一条测试 trace。
</Note>
