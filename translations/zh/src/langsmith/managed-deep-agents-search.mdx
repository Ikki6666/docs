[Managed Deep Agents](/langsmith/managed-deep-agents-overview) 内置由 [Parallel](https://parallel.ai) 驱动的网页搜索。为你的 agent 提供来自网络的最新信息，帮助回答问题。

搜索基础设施由 LangSmith 管理，因此你无需托管服务或创建单独的 Parallel 账号和 API key，即可添加搜索。该集成提供零数据保留。

<Note>
内置搜索仅在 LangSmith Plus 和 Startup 计划中可用。私有 beta 期间免费使用。
</Note>

## 开始之前

你需要一个已有的 [Managed Deep Agents 项目](/langsmith/managed-deep-agents-quickstart)、你的 LangSmith workspace ID，以及一个用于 Studio 的个人 LangSmith API key。

## 添加 Parallel 搜索

要将 Parallel 搜索添加到你的 agent：

### 第 1 步：设置你的 workspace ID

在项目的 `.env` 文件中，设置你的 LangSmith workspace ID：

```shell .env
LANGSMITH_WORKSPACE_ID=YOUR_WORKSPACE_ID
```

### 第 2 步：设置你的 LangSmith API key

在同一个 `.env` 文件中，设置一个用于 Studio 的个人 LangSmith API key：

```shell .env
LANGSMITH_API_KEY=YOUR_LANGSMITH_API_KEY
```

你不需要 Parallel API key。

### 第 3 步：配置搜索服务器

如果该文件已经定义了 `mcp`，请在现有的 `servers` 映射中添加 `Parallel`。`mcp` 只定义一次。

<Tabs>
<Tab title="Python">
在 `tools/mcp.py` 中将 `Parallel` 添加到 `servers` 映射。

```python tools/mcp.py
from managed_deepagents import define_mcp

mcp = define_mcp(
    servers={
        "Parallel": {
            "transport": "http",
            "url": "https://api.smith.langchain.com/v1/managed-tools/servers/parallel/mcp",
        },
    },
)
```
</Tab>
<Tab title="TypeScript">
在 `tools/mcp.ts` 中将 `Parallel` 添加到 `servers` 映射。

```typescript tools/mcp.ts
import { defineMcp } from "managed-deepagents";

export const mcp = defineMcp({
  servers: {
    "Parallel": {
      transport: "http",
      url: "https://api.smith.langchain.com/v1/managed-tools/servers/parallel/mcp",
    },
  },
});
```
</Tab>
</Tabs>

你的 agent 现在可以将其其他 tools 与 Parallel 搜索一起使用。

## 使用条款

你对该集成的使用必须遵守 Parallel 的服务条款，包括其对禁止或滥用行为的限制。
