**LangSmith Chat**（原名 Polly）直接内置在你的 LangSmith [workspace](/langsmith/administration-overview#workspaces) 中，帮助你分析和理解应用数据。

Chat 通过自然语言问答来帮助你理解 trace、对话线程和 prompt，而不必手动在数据中翻找。你可以更快理解 agent 表现、排查问题，以及分析用户情绪。

<img src="/images/brand/polly-icon.png" alt="LangSmith Chat icon" style={{float: 'left', marginRight: '20px', marginTop: '-1px', marginBottom: '20px', maxWidth: '100px'}} /> Chat 会出现在 [LangSmith UI](https://smith.langchain.com) 中以下位置的右下角：

<br></br><br></br>**Observability 与 Debugging：**
- [Projects](#projects)：浏览并筛选某个项目中的 run。
- [Trace pages](#trace-pages)：分析单个 run 和执行 trace。
- [Thread views](#thread-views)：理解对话线程和用户交互。

**Prompt Engineering：**
- [Playground](#playground)：编辑并优化 prompt。
- [Prompt Hub pages](#prompt-hub-pages)：探索并理解共享 prompt。

**Evaluation 与 Testing：**
- [Dataset Experiments](#dataset-experiments)：分析实验结果并比较 run。
- [Dataset Examples](#dataset-examples)：浏览并理解数据集结构。
- [Annotation Queues](#annotation-queues)：审查 run，并据此做出更有依据的标注决策。
- [Evaluators](#evaluators)：借助 AI 辅助构建和改进 evaluator。

## 开始使用

在开始使用 Chat 之前，你需要为所用模型添加 API key：

<secret/>

<Note>
Chat 会从 LangSmith 的出口 IP 地址调用模型提供商。如果你的模型提供商，或者其前面的代理，按 IP 限制流量，请将 [Allowlist IP addresses](/langsmith/deploy-to-cloud#allowlist-ip-addresses) 中列出的 LangSmith 出口 IP 加入 allowlist。
</Note>

### 支持的模型

Chat 原生支持以下模型提供商：

- Anthropic (Claude)
- OpenAI
- Google Gemini
- AWS Bedrock
- Groq
- Mistral
- xAI
- DeepSeek
- Fireworks AI

你也可以使用已在 [Playground Settings](/langsmith/prompt-engineering-concepts#playground) 中配置的任意自定义模型，只需在对应配置上启用 **Available in Chat** 开关。可用的自定义模型由 workspace 管理员管理。

### 键盘快捷键

| 操作 | Mac | Windows/Linux |
|---|---|---|
| 打开或关闭 Chat | `Cmd+I` | `Ctrl+I` |
| 清空当前线程 | `Cmd+Shift+O` | `Ctrl+Shift+O` |

## Observability

### Projects

在项目的 run 列表中，Chat 可以浏览和筛选整个项目内的 run、创建数据集，以及添加 example。你可以用 Chat 快速探索 trace 中发生了什么，而不必手动翻页查找结果。

**示例问题：**
- “Show me all the failed runs from the last 24 hours”
- “Which runs took the longest?”
- “Add the failing runs to my test dataset”
- “How many runs errored this week?”

### Trace pages

在单个 [trace](/langsmith/observability-concepts#traces) 页面中，Chat 会分析 [run](/langsmith/observability-concepts#runs) 数据和执行轨迹。Chat 会检查完整 trace 上下文，包括 [run metadata](/langsmith/observability-concepts#metadata)、输入、输出、中间步骤和配置，帮助你理解发生了什么，并识别可改进的地方。

**示例问题：**
- “Is there anything that the agent could have done better here?”
- “Why did this run fail?”
- “What took the most time in this trace?”
- “Summarize what happened in this trace”

### Thread views

在 **Threads** 标签页下，Chat 会分析对话 [threads](/langsmith/observability-concepts#threads)，帮助你理解用户情绪、对话结果和交互模式。你可以用 Chat 识别用户痛点，并判断问题是否已经解决。

**示例问题：**
- “Did the user seem frustrated?”
- “What issues is the user experiencing?”
- “Was the user's problem solved?”
- “What was the main topic of this thread?”

## Prompt engineering

### Playground

在 [Playground](/langsmith/prompt-engineering-concepts#playground) 中，Chat 可以帮助你编辑和优化 [prompts](/langsmith/prompt-engineering-concepts#prompts-in-langsmith)。你可以使用 **Optimize prompt**、**Generate a tool**、**Generate an output schema** 等自动化选项，也可以给 Chat 自定义编辑指令。Chat 可以直接修改 playground 状态，更新消息、工具、输出 schema 和 example，让你以对话方式迭代 prompt。

**示例问题：**
- “Make it respond in Italian”
- “Add more context about the user's role”
- “Make the tone more professional”
- “Simplify the instructions”

### Prompt Hub pages

在 [LangSmith Hub](/langsmith/prompt-engineering-concepts#prompts-in-langsmith) 中查看 prompt 时，Chat 可以帮助你理解该 prompt 的结构、消息、工具和配置。这对于探索和学习共享 prompt 很有帮助。

**示例问题：**
- “What does this prompt do?”
- “What tools does this prompt use?”
- “Explain the structure of this prompt”
- “What are the key instructions in this prompt?”

## Evaluation

### Dataset Experiments

在 **Datasets** 页面下的 **Experiments** 标签页中，Chat 会分析实验结果，并帮助你比较不同实验中的 run。Chat 可以识别模式、总结表现，并帮助你理解哪种方法效果最好。

**示例问题：**
- “Which experiment performed best?”
- “What are the main differences between these runs?”
- “Summarize the results of this experiment”
- “What patterns do you see in the failures?”

### Dataset Examples

在 **Datasets** 页面下的 **Examples** 标签页中，Chat 可以帮助你理解数据集结构、浏览 example，并识别数据模式。这有助于你了解正在处理的数据，并为实验准备数据集。

**示例问题：**
- “What type of data is in this dataset?”
- “Show me examples with errors”
- “What patterns do you see in the inputs?”
- “How many examples are in this dataset?”

### Annotation Queues

在 **Annotation Queues** 中，Chat 可以在你做出标注决策之前帮助分析 run。无论你是在单独审查 run，还是成对比较 run，Chat 都会提供有关 run 行为、错误和执行模式的洞察，帮助你更准确地打分。

**示例问题：**
- “What went wrong in this run?”
- “Summarize what happened in this run”
- “Compare these two runs”
- “What should I consider when scoring this?”

### Evaluators

在 **Evaluators** 构建器中，Chat 可以帮助你编写和改进 evaluator 逻辑。Chat 能生成 evaluator 代码、提出改进建议，并帮助你基于 example 测试 evaluator。

**示例问题：**
- “Write an evaluator that checks for hallucinations”
- “Improve the accuracy of this evaluator”
- “What does this evaluator check for?”
- “Add handling for edge cases”
