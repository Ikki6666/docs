要将一个应用部署到 LangSmith，或用于 self-hosted，必须先通过一个[配置文件](/langsmith/cli#configuration-file)完成配置。本篇 how-to 指南介绍如何使用 `requirements.txt` 来声明项目依赖，并完成一个应用的部署准备。

本示例基于[这个仓库](https://github.com/langchain-ai/langgraph-example)，它使用的是 LangGraph 框架。

最终的仓库结构大致如下：

```bash
my-app/
├── my_agent # all project code lies within here
│   ├── utils # utilities for your graph
│   │   ├── __init__.py
│   │   ├── tools.py # tools for your graph
│   │   ├── nodes.py # node functions for your graph
│   │   └── state.py # state definition of your graph
│   ├── requirements.txt # package dependencies
│   ├── __init__.py
│   └── agent.py # code for constructing your graph
├── .env # environment variables
└── langgraph.json # configuration file for LangGraph
```

你也可以使用以下方式进行设置：

- `pyproject.toml`：如果你更喜欢用 poetry 管理依赖，可查看[这篇 how-to 指南](/langsmith/setup-app-requirements-txt)，了解如何用 `pyproject.toml` 配置 LangSmith。
- monorepo：如果你想部署位于 monorepo 内部的 graph，可参考[这个仓库](https://github.com/langchain-ai/langgraph-example-monorepo)，查看具体做法。

每个步骤之后，都会给出一个示例文件目录，用于展示代码可以如何组织。

## 定义 graphs

实现你的 graphs。Graphs 可以定义在单个文件中，也可以拆分到多个文件中。请记下应用中每个 @[CompiledStateGraph] 的变量名。稍后创建 [LangGraph 配置文件](/langsmith/cli#configuration-file)时，会用到这些变量名。

示例 `agent.py` 文件，它演示了如何从你自己定义的其他模块中导入内容，这些模块的代码此处未展示，具体实现请参阅[这个仓库](https://github.com/langchain-ai/langgraph-example)：

```python
# my_agent/agent.py
from typing import Literal
from typing_extensions import TypedDict

from langgraph.graph import StateGraph, END, START
from my_agent.utils.nodes import call_model, should_continue, tool_node # import nodes
from my_agent.utils.state import AgentState # import state

# Define the runtime context
class GraphContext(TypedDict):
    model_name: Literal["anthropic", "openai"]

workflow = StateGraph(AgentState, context_schema=GraphContext)
workflow.add_node("agent", call_model)
workflow.add_node("action", tool_node)
workflow.add_edge(START, "agent")
workflow.add_conditional_edges(
    "agent",
    should_continue,
    {
        "continue": "action",
        "end": END,
    },
)
workflow.add_edge("action", "agent")

graph = workflow.compile()
```

示例文件目录：

```bash
my-app/
├── my_agent # all project code lies within here
│   ├── utils # utilities for your graph
│   │   ├── __init__.py
│   │   ├── tools.py # tools for your graph
│   │   ├── nodes.py # node functions for your graph
│   │   └── state.py # state definition of your graph
│   ├── requirements.txt # package dependencies
│   ├── __init__.py
│   └── agent.py # code for constructing your graph
└── .env # environment variables
```

## 创建配置文件

创建一个名为 `langgraph.json` 的[配置文件](/langsmith/cli#configuration-file)。关于该配置文件 JSON 对象中各个 key 的详细说明，请参阅[配置文件参考](/langsmith/cli#configuration-file)。

示例 `langgraph.json` 文件：

```json
{
  "dependencies": ["./my_agent"],
  "graphs": {
    "agent": "./my_agent/agent.py:graph"
  },
  "env": ".env"
}
```

注意，`CompiledGraph` 的变量名会出现在顶层 `graphs` key 的每个子项值末尾，也就是 `:<variable_name>`。

<Warning>
**配置文件位置**
配置文件必须放在一个目录中，该目录需要与包含已编译 graph 及其相关依赖的 Python 文件处于同级，或更高层级。
</Warning>

示例文件目录：

```bash
my-app/
├── my_agent # all project code lies within here
│   ├── utils # utilities for your graph
│   │   ├── __init__.py
│   │   ├── tools.py # tools for your graph
│   │   ├── nodes.py # node functions for your graph
│   │   └── state.py # state definition of your graph
│   ├── requirements.txt # package dependencies
│   ├── __init__.py
│   └── agent.py # code for constructing your graph
├── .env # environment variables
└── langgraph.json # configuration file for LangGraph
```
