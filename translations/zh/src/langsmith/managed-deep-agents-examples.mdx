本页讲解一个完整的 Managed Deep Agents 项目：一个客服 agent，会通过 tool 查询数据，借助 middleware 脱敏 PII 并记录审计日志，在敏感操作前暂停等待人工审核，按 schedule 每日运行检查，按需加载研究 skill，并在托管 sandbox 中运行。你可以把它当作一份参考，用来理解这些部件如何组合在一起。

## 项目结构

每项能力都放在一个由文件位置决定角色的文件中：

```text
support-agent/
  agent.py | agent.ts                  # 组合 model、tools、middleware、interrupts
  instructions.md                      # 客服 agent 的 system prompt
  tools/query_db.py | query-db.ts      # 只读数据库查询 tool
  middleware/audit.py | audit.ts       # 每次模型调用前记录审计日志
  connectors/mcp.py | mcp.ts           # LangChain docs MCP server
  schedules/daily_check_in.py | daily-check-in.ts  # 每天上午 9 点 cron 运行
  skills/research/SKILL.md             # 按需触发的研究流程
  sandbox/index.ts | __init__.py       # 托管 LangSmith sandbox
  sandbox/setup.sh                     # 初始化工作区参考文件
```

关于这个布局背后的打包规则，请参见 [How Managed Deep Agents work](/langsmith/managed-deep-agents-how-it-works#compilation) 和 [CLI project file reference](/langsmith/managed-deep-agents-cli#project-file-reference)。

## 组合 agent

Agent 入口文件就是项目的接线图。它会导入自定义 tool 和 middleware，然后声明 model、middleware 顺序，以及哪些工具在执行前需要人工审核。托管运行时负责 backend、store、checkpointer、memory、skills 和 system prompt，因此这里不需要配置这些内容。

<CodeGroup>

```python agent.py
from managed_deepagents import define_deep_agent
from langchain.agents.middleware import PIIMiddleware

from middleware.audit import audit_middleware
from tools.query_db import query_db

agent = define_deep_agent(
    model="openai:gpt-5.5",
    tools=[query_db],
    middleware=[
        PIIMiddleware("email", strategy="redact"),
        audit_middleware(),
    ],
    interrupt_on={"query_db": True},
)
```

```ts agent.ts
import { defineDeepAgent } from "managed-deepagents";
import { piiMiddleware } from "langchain";

import { auditMiddleware } from "./middleware/audit";
import { queryDB } from "./tools/query-db";

export const agent = defineDeepAgent({
  model: "openai:gpt-5.5",
  tools: [queryDB],
  middleware: [
    piiMiddleware("email", { strategy: "redact" }),
    auditMiddleware(),
  ],
  interruptOn: {
    query_db: true,
  },
});
```

</CodeGroup>

`interrupt_on`（Python）和 `interruptOn`（TypeScript）会在执行 `query_db` tool 之前暂停 run，以便人工批准该调用。关于决策类型及如何响应 interrupt，请参见 [Human-in-the-loop](/langsmith/managed-deep-agents-middleware#human-in-the-loop)。完整字段列表请参见 [agent definition reference](/langsmith/managed-deep-agents-cli#agent-definition-reference)。

## 编写 instructions

`instructions.md` 保存托管 system prompt。它定义 agent 的角色，引用 tools 和 sandbox workspace，并声明 memory 规则：

```markdown instructions.md
# Support Agent

You are a helpful, careful customer-support Deep Agent.

## Role

- Answer customer questions about their account and orders.
- Use the `query_db` tool to look up data instead of guessing.

## Behavior

- Be concise and friendly.
- Never expose internal database identifiers to the customer.
- When an action would send an email, pause for human review before sending.
```
