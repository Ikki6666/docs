这个 schema 是 coding agents 附加到 LangSmith runs 上的 metadata 的权威约定。它定义了哪些字段在每个 run 上都是必需的，哪些字段在运行时能够提供时应当出现，以及哪些字段只适用于特定 run 类型。

Coding agent integrations 使用这个 schema，确保它们的 traces 在结构上保持一致、可查询，并兼容 LangSmith 的可观测性与筛选能力。

## 支持的 integrations

以下 integrations 实现了这个 schema：

| Integration | `ls_integration` value |
|---|---|
| [Claude Code](/langsmith/trace-claude-code) | `claude-code` |
| [OpenAI Codex](/langsmith/trace-with-codex) | `openai-codex` |
| [Deep Agents](/langsmith/trace-deep-agents) | `deepagents-code` |
| [Cursor](/langsmith/trace-with-cursor) | `cursor` |
| [Pi](/langsmith/trace-with-pi) | `pi` |
| [Opencode](/langsmith/trace-with-opencode) | `opencode` |
| [GitHub Copilot](/langsmith/trace-with-vscode-copilot) | `copilot` |

## 全局身份字段块

每一种 run 类型都必须在 metadata 中包含以下身份字段：

| Field | Description |
|---|---|
| `ls_agent_type` | 该 run 在 agent 中的类型。应为 `"root"`、`"subagent"`、`"middleware"` 或 `"compaction"` 之一。 |
| `ls_agent_purpose` | agent 的高层用途，例如 `"coding"`。 |
| `ls_integration` | 产出该 run 的 integration 标识符（参见[支持的 integrations](#supported-integrations)）。 |
| `ls_agent_runtime` | 人类可读的 runtime 名称，例如 `"Claude Code 1.0.28"`。 |
| `thread_id` | 会话 thread 的稳定标识符。它用于在 LangSmith 的 Threads 视图中归组相关 runs。 |
| `ls_trace_schema_version` | 当前值固定为 `"coding-agent-v1"`。 |

## 可用性层级

这个 schema 中的字段会被标记为以下三种可用性层级之一：

| Tier | Meaning |
|---|---|
| **always** | 必须出现在每一个 run 上。 |
| **where_known** | 只要 runtime 能暴露出这个值，就必须提供。只有在 runtime 的确无法给出该信息时才允许省略。 |
| **contextual** | 可选 metadata。在不适用时可以省略。 |

## Run 类型

这个 schema 区分五种 run 类型。某些字段只适用于其中一部分 run 类型。

| Run type | Description |
|---|---|
| `root` | 表示完整 agent 回合或会话的顶层 run。 |
| `llm` | 某个回合中的语言模型调用。 |
| `tool` | 某个回合中的工具调用。 |
| `subagent` | 嵌套的或被委托执行的 agent run。 |
| `interrupted` | 在完成前被中断的 run。 |

## 各 run 类型的必需字段

### 所有 run 类型

[全局身份字段块](#global-identity-block)中的字段在所有 run 类型上都**始终必需**。

所有 run 类型还需要以下附加字段：

| Field | Tier | Description |
|---|---|---|
| `ls_agent_version` | `where_known` | agent runtime 的版本字符串，例如 `"1.0.28"`。 |
| `git_branch` | `where_known` | 正在编辑的仓库当前所在的 Git 分支。 |
| `git_commit_sha` | `where_known` | 当前 Git commit 的完整 SHA。 |
| `git_repo_url` | `where_known` | 仓库的远程 URL。 |
| `working_directory` | `where_known` | 工作目录的绝对路径。 |

### `llm` runs

| Field | Tier | Description |
|---|---|---|
| `ls_model_name` | `where_known` | 模型标识符，例如 `"claude-opus-4-5"`。 |
| `ls_provider` | `where_known` | 模型提供商，例如 `"anthropic"`。 |

### `tool` runs

| Field | Tier | Description |
|---|---|---|
| `ls_tool_name` | `always` | 被调用工具的名称，例如 `"bash"` 或 `"computer"`。 |

### `subagent` runs

| Field | Tier | Description |
|---|---|---|
| `ls_subagent_id` | `always` | subagent 的稳定标识符。 |
| `ls_subagent_type` | `always` | subagent 的类型或角色，例如 `"researcher"`。 |

### `interrupted` runs

Interrupted runs 与 `root` runs 携带相同字段。Run 类型本身就用来表示异常终止状态，因此不会再增加其他必需字段。
