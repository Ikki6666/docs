Playground 允许你使用任何兼容 OpenAI API 的模型。你可以在 Playground 中设置 Proxy Provider，从而使用自己的模型。

## Deploy an OpenAI compliant model

许多提供商都提供 OpenAI 兼容模型或代理服务，其中一些示例如下：

* [LiteLLM Proxy](https://github.com/BerriAI/litellm?tab=readme-ov-file#quick-start-proxy---cli)
* [Ollama](https://ollama.com/)

你可以使用这些提供商来部署模型，并获得一个兼容 OpenAI API 的 API endpoint。

更多信息请参阅完整的 [specification](https://platform.openai.com/docs/api-reference/chat)。

## Use the model in the Playground

部署好模型服务后，你就可以在 [Playground](/langsmith/prompt-engineering-concepts#playground) 中使用它。

要访问 **Prompt Settings** 菜单：

1. 在 **Prompts** 标题下，点击模型名称旁边的齿轮 <Icon icon="settings" iconType="solid" /> 图标。
1. 在 **Model Configuration** 标签中，从下拉菜单里选择要编辑的模型。
1. 在 **Provider** 下拉菜单中，选择 **OpenAI Compatible Endpoint**。
1. 在 **Base URL** 输入框中添加你的 OpenAI Compatible Endpoint。示例请参阅 [Base URL format](#base-url-format)。

如果一切设置正确，你应当能在 Playground 中看到模型响应。你也可以借助这项能力调用下游 pipelines。

关于如何存储模型配置，请参阅 [Configure prompt settings](/langsmith/managing-model-configurations)。

如果你的 OpenAI-compatible endpoint 位于 OAuth2 gateway 之后，请把 OAuth `client_credentials` 存储在模型配置中，而不是把静态 API key 当作 workspace secret 分发。请参阅 [OAuth client credentials](/langsmith/model-configurations#oauth-client-credentials)。

## Base URL format

**Base URL** 应指向你的 OpenAI-compatible API server 的根路径。
LangSmith 会自动追加 `/chat/completions`，因此不要把它写进 Base URL 中。

### Example Base URLs

| Provider | Example Base URL |
|----------|-----------------|
| [Ollama](https://ollama.com/)（本地） | `http://localhost:11434/v1` |
| [LiteLLM Proxy](https://github.com/BerriAI/litellm)（本地） | `http://localhost:4000` |
| [vLLM](https://docs.vllm.ai/)（本地） | `http://localhost:8000/v1` |
| Self-hosted（远程） | `https://my-model-server.example.com/v1` |

支持自定义路径前缀。如果你的 server 在 `/api/v2/chat/completions` 暴露 completions，
那么 Base URL 应设置为 `https://my-server.example.com/api/v2`。
