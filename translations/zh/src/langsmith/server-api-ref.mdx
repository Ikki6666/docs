Agent Server API reference 可在每个 [deployment](/langsmith/deployment) 的 `/docs` endpoint 中查看（例如 `http://localhost:8124/docs`）。

你可以在侧边栏的 **Agent Server API** 部分浏览完整 API 参考，或者查看下列 endpoint 分组：

- [Assistants](/langsmith/agent-server-api/assistants) - 已配置的 graph 实例
- [Threads](/langsmith/agent-server-api/threads) - 一组 runs 的累计输出
- [Thread Runs](/langsmith/agent-server-api/thread-runs) - 在某个 thread 上对 graph/assistant 的调用
- [Stateless Runs](/langsmith/agent-server-api/stateless-runs) - 无状态持久化的调用
- [Crons](/langsmith/agent-server-api/crons) - 按计划周期性运行的任务
- [Store](/langsmith/agent-server-api/store) - 用于长期记忆的持久化键值存储
- [A2A](/langsmith/agent-server-api/a2a) - Agent-to-Agent Protocol endpoints
- [MCP](/langsmith/agent-server-api/mcp) - Model Context Protocol endpoints
- [System](/langsmith/agent-server-api/system) - 健康检查与服务器信息

## Authentication

对于部署到 LangSmith 的 Agent Server，请求必须携带认证信息。请在每个请求中向 Agent Server 传递 `X-Api-Key` header。该 header 的值应设置为 Agent Server 所部署组织中的有效 LangSmith API key。

示例 `curl` 命令：

```shell
curl --request POST \
  --url http://localhost:8124/assistants/search \
  --header 'Content-Type: application/json' \
  --header 'X-Api-Key: LANGSMITH_API_KEY' \
  --data '{
  "metadata": {},
  "limit": 10,
  "offset": 0
}'
```
