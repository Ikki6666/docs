[Insights](/langsmith/insights) 分析 traces，[Chat](/langsmith/chat)（前身为 Polly）帮助你处理 LangSmith 数据。两者都是基础安装的一部分，在 Helm chart 0.15.1 或更高版本中默认启用。它们不需要任何[附加功能](/langsmith/self-host-additional-features)，例如 Sandboxes、Fleet 或 LangSmith Deployment。

<Note>
对于 0.15.1 之前的 chart，Insights 和 Chat 默认不启用。请使用你所固定版本 chart 支持的配置，或在遵循本指南之前先进行升级。
</Note>

每个功能都需要自己的 Fernet 加密 key 和模型访问。如果你遵循了 [Kubernetes 安装指南](/langsmith/kubernetes)，说明你已经是在 `langsmith_config.yaml` 中设置了这些 key。请继续[配置模型访问](#configure-model-access)。

## 设置加密 key

要为每个功能生成一个 key，请参阅 [Keys and secrets](/langsmith/kubernetes#keys-and-secrets)。不要将加密 key 提交到版本控制。

可以通过以下两种方式之一提供 key：

- **内联**：在 `langsmith_config.yaml` 中设置 `insights.encryptionKey` 和 `polly.encryptionKey`，如[最小配置](/langsmith/kubernetes#configure-your-helm-charts)所示。
- **Existing Secret**：将 `insights_encryption_key` 和 `polly_encryption_key` 添加到你[现有的 LangSmith app Secret](/langsmith/self-host-using-an-existing-secret#parameters) 中。通过 `config.existingSecretName` 引用它。

应用你的 Helm 配置：

```bash
helm upgrade -i langsmith langchain/langsmith --values langsmith_config.yaml --version <version> -n <namespace> --wait --debug
```

## 配置模型访问

Insights 和 Chat 通过你的 [provider 凭据和模型配置](/langsmith/model-configurations)调用模型。关于 GKE 上的无密钥 Vertex AI，请参阅[使用 GKE workload identity 对 Vertex AI 进行认证](/langsmith/self-host-gke-vertex-ai-workload-identity)。

## 禁用 Insights 或 Chat

当你的安装不需要某个功能时，可以禁用它。在你的 [`langsmith_config.yaml`](/langsmith/kubernetes#configure-your-helm-charts) 中将相应的顶层标志设为 `false`。禁用的功能不需要加密 key。

```yaml
insights:
  enabled: false

polly:
  enabled: false
```

应用你的 Helm 配置：

```bash
helm upgrade -i langsmith langchain/langsmith --values langsmith_config.yaml --version <version> -n <namespace> --wait --debug
```

当 `engine.enabled` 为 `true` 时，禁用 Insights 不会禁用 Engine，也不会移除它们共享的 deployment。

## 升级现有配置

本节仅适用于从较早 chart 版本升级的安装。

当前 chart 会拒绝旧版 `config.insights`、`config.polly` 和 `backend.agentBootstrap` 设置。请移除这些设置，而不是将它们设为 `false`。关于旧版 deployment 的迁移指导，请通过 [Support Portal](https://support.langchain.com) 联系技术支持。

从 chart 0.16.0 开始，Insights 和 Engine 共享 `langsmith-insights-engine` 镜像和 deployment。这不会启用 Engine。将旧版的 `insights.apiServer`、`insights.queue`、`insights.postgres`、`insights.redis` 和 `insights.namePrefix` 值移至 `engineInsightsAgent`。将 `insights.enabled` 和 `insights.encryptionKey` 保留在 `insights` 下。

如果你固定了已停用的 `langsmith-clio` 镜像，请在升级前移除或更新该固定。对于私有 registry，请同步 `langsmith-insights-engine` 镜像。请参阅[同步镜像](/langsmith/self-host-mirroring-images#additional-images-for-engine)。

关于常规升级流程，请参阅[升级安装](/langsmith/self-host-upgrades)。
