**LangSmith Deployment** 是一个专为 agent 工作负载构建的 workflow orchestration runtime。它提供 agent 在生产环境中可靠、大规模运行所需的托管基础设施，并覆盖从本地开发到部署的完整生命周期。

<Note>
本页介绍你的 **agent** 如何借助 **LangSmith Deployment** 在生产环境中运行。

你在哪里运行用于 observability、evaluation 和 prompt engineering 的 LangSmith 是相互独立的；详情请参阅 [Platform setup](/langsmith/platform-setup)。
</Note>

## LangSmith Deployment environments

根据你希望 [control plane](/langsmith/control-plane) 和 [data plane](/langsmith/data-plane)（Agent Server 及其数据库）运行的位置来选择一种环境。所有基础设施类型都使用同一个 [Agent Server](/langsmith/agent-server) runtime。

<CardGroup cols={2}>

<Card
  title="Cloud"
  cta="View guide"
  href="/langsmith/deploy-to-cloud-overview"
  icon="cloud"
>
由 LangChain 在 AWS 和 GCP 上全托管。你可以在 LangSmith UI 中从 GitHub 创建 deployment，或使用 [`langgraph deploy`](/langsmith/cli#deploy)。需要 [Plus plan 或更高版本](https://www.langchain.com/pricing)。
</Card>

<Card
  title="Self-hosted with control plane"
  cta="View guide"
  href="/langsmith/deploy-with-control-plane"
  icon="buildings"
>
在你自己的 Kubernetes 集群中运行 LangSmith Deployment 的 control plane 和 Agent Server，与 self-hosted LangSmith 并存。需要开启 LangSmith Deployment 的 [Enterprise plan](https://www.langchain.com/pricing)。
</Card>

<Card
  title="Hybrid"
  cta="View guide"
  href="/langsmith/hybrid"
  icon="cloud-network"
>
由 LangChain 托管的 control plane，配合部署在你自己基础设施中的 Agent Server 及其 data plane。Trace 会发送到 LangSmith Cloud 或 self-hosted LangSmith。
</Card>

<Card
  title="Standalone server"
  cta="View guide"
  href="/langsmith/deploy-standalone-server"
  icon="server"
>
使用 Docker、Compose 或 Kubernetes 部署 Agent Server。你需要自备 PostgreSQL、Redis 和 LangSmith license；不包含 control plane。可选地把 [LangSmith tracing](/langsmith/observability) 连接到 Cloud 或 self-hosted 实例。
</Card>

</CardGroup>

## Common setups

- **全托管的 agent 托管。** 基于 [Cloud](/langsmith/deploy-to-cloud-overview) 的 LangSmith Deployment。由 LangChain 托管 control plane、data plane 和数据库。与 LangSmith Cloud 搭配使用。
- **agent 在你的 VPC 内，control plane 托管。** 基于 [Hybrid](/langsmith/hybrid) 的 LangSmith Deployment。LangChain 托管 control plane；你托管 Agent Server 及其 data plane。与 LangSmith Cloud 或 self-hosted LangSmith 搭配使用。
- **完整数据驻留或离线环境。** [Self-hosted LangSmith Deployment](/langsmith/deploy-with-control-plane)。你将 control plane 和 Agent Server 与 self-hosted LangSmith 一起部署在自己的基础设施中。
- **仅 agent runtime，不含 control plane。** [Standalone Agent Server](/langsmith/deploy-standalone-server)。使用 Docker 或 Kubernetes 运行 Agent Server container，无需 control plane，可选地把 trace 发送到 LangSmith Cloud 或 self-hosted。

如需了解 LangSmith 平台运行在哪里，请参阅 [Platform setup](/langsmith/platform-setup)。

## After deployment

部署完成后，agent 会遵循 [Agent Server](/langsmith/assistants) 的执行模型：使用 **assistants** 管理配置，使用 **threads** 管理状态，使用 **runs** 表示工作负载。关于能力、教程、server 定制和运维，请参阅 [Develop agents](/langsmith/develop-agents-overview)。
