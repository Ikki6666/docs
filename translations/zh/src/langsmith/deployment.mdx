LangSmith Deployment 是一个专为 agent 工作负载构建的 workflow orchestration runtime。它提供 agent 在生产环境中可靠、大规模运行所需的托管基础设施，并覆盖从本地开发到部署的完整生命周期。

## Deployable products

LangSmith Deployment 与 framework 无关，这意味着你可以部署使用以下框架构建的 agent：

## Deployment environments

你可以在多种托管模型中运行同一个 [Agent Server](/langsmith/agent-server) runtime。**standalone server** 是最轻量的选项：你自行运行 container，而不使用 LangSmith [control plane](/langsmith/control-plane)。如果你希望通过 UI 和 API 使用托管部署，则应选择 **Cloud** 或 **Self-hosted**，也就是在你自己的基础设施中运行完整平台。

<CardGroup cols={2}>

<Card
  title="Cloud"
  cta="View guide"
  href="/langsmith/deploy-to-cloud"
  icon="cloud"
>
  由 LangChain 全托管，运行在 AWS 和 GCP 上。你可以在 LangSmith UI 中从 GitHub 创建 deployment，或使用 [`langgraph deploy`](/langsmith/cli#deploy)。需要 [Plus plan 或更高版本](https://www.langchain.com/pricing)。
</Card>

<Card
  title="Standalone server"
  cta="View guide"
  href="/langsmith/deploy-standalone-server"
  icon="server"
>
  使用 Docker、Compose 或 Kubernetes 部署 Agent Server。你需要自备 PostgreSQL、Redis 和 LangSmith license；不包含 control plane。可选地把 [LangSmith tracing](/langsmith/observability) 连接到 Cloud 或 self-hosted 实例。
</Card>

<Card
  title="Self-hosted"
  cta="View guide"
  href="/langsmith/self-hosted"
  icon="buildings"
>
  在你自己的云环境中运行完整 LangSmith 平台，包括 control plane 和 data plane，例如部署在 Kubernetes 上。需要 [Enterprise plan](https://www.langchain.com/pricing)。它将 observability、evaluation 和 agent deployment 整合在同一套私有栈中。
</Card>

</CardGroup>

如需查看按功能级别的对比以及基础设施配置方式，请参阅 [Platform setup](/langsmith/platform-setup)。

## After deployment

部署完成后，agent 会遵循 [Agent Server](/langsmith/assistants) 的执行模型：使用 **assistants** 管理配置，使用 **threads** 管理状态，使用 **runs** 表示工作负载。关于能力、教程、server 定制和运维，请参阅 [Develop agents](/langsmith/develop-agents-overview)。

## Full-stack web apps

将 LangChain.js agent 和 chat UI 一起作为单个 web app 发布。Vite 示例会把 LangSmith Deployment 作为独立 UI 背后的 agent backend。其他示例则会把 agent 嵌入到 web framework 的 route handler 中，并直接发布到对应托管平台。
