LLM Gateway 的 **Usage** 标签页会显示一个[工作区](/langsmith/administration-overview#workspaces)通过 gateway 累计的 LLM 成本。用它比较一段时间内的支出，并找出构成这些支出的用户、API key、模型、providers 和请求 header 值。

查看 **Usage** 标签页需要工作区中的 `runs:read-stats` 和 `projects:read` [权限](/langsmith/rbac)，以及 Plus 或 Enterprise [方案](/langsmith/pricing-plans)。

## 打开 Usage 标签页

要查看某个工作区经 gateway 路由的请求总成本：

1. 在 [LangSmith UI](https://smith.langchain.com) 中，通过左上角的工作区选择器选择工作区。
1. 在左侧导航中选择 **LLM Gateway**。
1. 选择 **Usage**。

## 设置时间范围和粒度

使用这些控件定义页面上每个汇总、图表和表格覆盖的时间段：

- **Time range**：选择从一天到一年的预设范围，或选择自定义日期。日期和时间 bucket 使用 UTC。
- **Aggregation granularity**：把支出按小时、按天或按周分桶。可用选项取决于所选时间范围的长度。
- **Previous or next period**：向前或向后移动一个等长时间段，以比较相邻的时间范围。

## 拆分和筛选支出

选择 **Breakdown by**，按以下维度之一对支出分组：

- **User**：把支出归因于调用 gateway 的 personal access token 所关联的用户。使用工作区或组织范围 service key 发出的请求会显示为 **Unaffiliated with any user**。
- **API key**：把支出归因于调用 gateway 的 LangSmith API key。
- **Model**：把支出归因于请求所使用的模型。
- **Model Provider**：把支出归因于处理该请求的 provider，例如 OpenAI 或 Anthropic。
- **Custom Dimension**：把支出归因于你指定的某个请求 header 的值。请参阅[按 custom header 分组支出](#按-custom-header-分组支出)。

选择维度后，使用相邻的筛选器只显示你选中的实体。要移除筛选器，请选择列表底部的 **All** 选项。

## 解读支出汇总

图表上方的卡片汇总所选工作区、时间范围、维度和筛选器的用量：

- **Total Spend**：所选时间范围内 gateway 支出的总和。
- **Hourly、Daily 或 Weekly Avg**：总支出除以所选范围内的时间 bucket 数量。
- **Hourly、Daily 或 Weekly Avg / dimension**：每个时间 bucket 中，所选实体的平均支出。当你没有应用实体筛选时，该指标使用按支出排名前 10 的实体。
- **Total Tokens**：所选时间范围内经 gateway 路由的请求中的 token 数量。

## 分析图表和表格

堆叠柱状图显示每个实体在每个时间 bucket 中对支出的贡献。悬停在柱子上可以查看该 bucket 的总量以及每个可见实体的贡献。当未应用筛选时，图表会把支出最高的六个实体显示为独立序列，并把剩余实体合并为 **Other**。

表格以每个可见实体一行的方式汇总同一选择。用它比较：

- **Hourly、Daily 或 Weekly Avg**：该实体的总支出除以时间 bucket 数量。
- **Spend Share**：归因于该实体的支出百分比。
- **Total Spend**：该实体在所选时间范围内的总支出。

要下钻查看，请选择某一行，打开该实体的详细视图。从 **Group by** 中选择一个维度，可以进一步拆分它的支出，例如按用户拆分某个 API key 的支出。详细视图拥有自己的筛选器、时间范围和粒度控件，它们不会更改主视图上的控件。

<Tip>
在用户、API key 或 custom header 值的详细视图中，点击 **View traces** 会打开 **Traces** 标签页，并按该实体在详细视图时间范围内的请求进行筛选。关于每条 trace 记录的内容，请参见[查看 LLM Gateway traces](/langsmith/llm-gateway-traces)。
</Tip>

## 按 custom header 分组支出

**Custom Dimension** 拆分按你的应用发送的 `X-Gateway-*` 请求 header 的值对支出分组，例如 `X-Gateway-Customer-Id`。用它比较不同终端客户、团队或服务之间的支出。关于如何发送这些 header，请参见[按客户划分的策略](/langsmith/llm-gateway-header-policies)。

从 **Breakdown by** 中选择 **Custom Dimension**，然后输入 header 名称。`X-Gateway-` 前缀是可选的。不带该 header 的请求会显示在 **No value** 下。在 API key 的详细视图中，也可以从 **Group by** 中选择 **Custom Dimension**。
