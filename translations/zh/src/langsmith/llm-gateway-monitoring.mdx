LLM Gateway 的 **Usage** 标签页会显示一个[工作区](/langsmith/administration-overview#workspaces)通过 gateway 累计的 LLM 成本。使用它可以：

- 比较一段时间内的支出。
- 找出构成这些支出的用户、API key、模型、provider 和请求 header 值。
- 将这些支出归因到对应的客户、租户或成本中心，以便进行[费用回摊](#attribute-spend-for-chargebacks)。

查看 **Usage** 标签页需要工作区中的 `runs:read-stats` 和 `projects:read` [权限](/langsmith/rbac)，以及 Plus 或 Enterprise [方案](/langsmith/pricing-plans)。

## 分组和筛选 LLM 支出

在 Usage 标签页中，选择 **Breakdown by**，按以下维度之一对支出分组：

- **User**：把支出归因于调用 gateway 的 personal access token 所关联的用户。使用工作区或组织范围 service key 发出的请求会显示为 **Unaffiliated with any user**。
- **API key**：把支出归因于调用 gateway 的 LangSmith API key。
- **Model**：把支出归因于请求所使用的模型。
- **Model Provider**：把支出归因于处理该请求的 provider，例如 OpenAI 或 Anthropic。
- **Custom Dimension**：把支出归因于你的应用发送的 `X-Gateway-*` 请求 header 的值。

当你选择 **Custom Dimension** 时，在出现的字段中输入 header 名称。该字段默认为 `X-Gateway-Service`，且 `X-Gateway-` 前缀是可选的。不带该 header 的请求会显示在 **No value** 下。关于如何发送这些 header，请参见[基于 header 的策略](/langsmith/llm-gateway-header-policies)。

选择维度后，使用相邻的筛选器只显示你选中的实体。

## 设置时间范围和粒度

使用图表右上角的控件定义页面上每个汇总、图表和表格覆盖的时间段：

- **Time range**：选择从一天到一年的预设范围，或选择自定义日期。日期和时间 bucket 使用 UTC。
- **Aggregation granularity**：把支出按小时、按天或按周分桶。可用选项取决于所选时间范围的长度。
- **Previous or next period**：向前或向后移动一个等长时间段，以比较相邻的时间范围。

## 解读支出汇总

图表上方的卡片汇总所选工作区、时间范围、维度和筛选器的支出和 token：

- **Total Spend**：所选时间范围内 gateway 支出的总和。
- **Hourly、Daily 或 Weekly Avg**：总支出除以所选范围内的时间 bucket 数量。
- **Hourly、Daily 或 Weekly Avg / dimension**：每个时间 bucket 中，所选实体的平均支出。当你没有应用实体筛选时，该指标使用按支出排名前 10 的实体。
- **Total Tokens**：所选时间范围内经 gateway 路由的请求中的 token 数量。

## 分析图表和表格

堆叠柱状图显示每个实体在每个时间 bucket 中对支出的贡献。悬停在柱子上可以查看该 bucket 的总量以及每个可见实体的贡献。

表格以每个可见实体一行的方式汇总同一选择。用它比较：

- **Hourly、Daily 或 Weekly Avg**：该实体的总支出除以时间 bucket 数量。
- **Spend Share**：归因于该实体的支出百分比。
- **Total Spend**：该实体在所选时间范围内的总支出。

要下钻查看，请选择某一行，打开该实体的详细视图。从 **Group by** 中选择一个维度，可以进一步拆分它的支出，例如按用户或按 custom header 拆分某个 API key 的支出。详细视图拥有自己的筛选器、时间范围和粒度控件，它们不会更改主视图上的控件。

<Tip>
在用户、API key 或 custom header 值的详细视图中，点击 **View traces** 会打开 **Traces** 标签页，并按该实体在详细视图时间范围内的请求进行筛选。关于每条 trace 记录的内容，请参见[查看 LLM Gateway traces](/langsmith/llm-gateway-traces)。
</Tip>

## 为费用回摊归因支出

费用回摊（chargeback）会把 LLM 成本计回产生这些成本的客户、租户或成本中心。由于每个请求都会经过 gateway，**Usage** 标签页可以按照你计费时使用的同一套划分方式拆分支出。选择与你计费对象相匹配的维度：

- **成本中心，例如部门、内部团队或产品**：为每个成本中心分配各自的 [service key](/langsmith/llm-gateway-authentication#choose-a-key-type)，然后按 **API key** 拆分。或者，让每个成本中心的应用发送形如 `X-Gateway-Cost-Center` 的 header，再按 **Custom Dimension** 拆分。
- **应用的终端客户**：让后端为每个客户发出的每个请求都携带形如 `X-Gateway-Customer-Id` 的 header，然后按 **Custom Dimension** 拆分。如需同时限制每个客户的支出，请参见[为每个终端客户设置支出上限](/langsmith/llm-gateway-header-policies#cap-spend-per-end-customer)。
- **单个用户**：让每个用户使用各自的 personal access token 调用 gateway，然后按 **User** 拆分。
- **自定义维度**：如需按任何其他属性（例如环境）计费，让应用把该属性的值放在 `X-Gateway-*` header 中发送，然后按 **Custom Dimension** 拆分。
