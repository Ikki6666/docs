[Claude Cowork](https://claude.com/docs/cowork/guide/plugins) 运行与 Claude Code 相同的插件，因此 [适用于 Claude Code 的 LangSmith tracing 插件](/langsmith/trace-claude-code)也会追踪 Cowork 任务。每个 turn 都会成为一条 trace，一个任务的 turns 会归入一个 thread。

## 前置条件

- 可以在 Claude 桌面应用中访问 Claude Cowork。
- 拥有一个 LangSmith 账户。

## 安装插件

Cowork 会从你的 claude.ai 账户安装插件。要为自己安装该插件：

1. 在 claude.ai 中进入 **Customize** > **Plugins**。
2. 添加 `langchain-ai/langsmith-claude-code-plugins` 或 `https://github.com/langchain-ai/langsmith-claude-code-plugins` 作为 marketplace。
3. 从该 marketplace 安装 `langsmith-tracing` 插件。

插件会加载到你启动的下一个 Cowork 任务中。要为所有人安装，请参见 [Deploy to your organization](#deploy-to-your-organization)。关于安装插件的更多信息，请参见 Claude 文档中的 [Cowork plugins](https://claude.com/docs/cowork/guide/plugins)。

## 登录

使用 LangSmith CLI 登录一次。如果尚未安装，请参见 [Install the LangSmith CLI](/langsmith/langsmith-cli#install)。

```bash
langsmith auth login
```

如果你使用 CLI 登录并且有多个 profile，请在配置文件中将 `profile` 设置为插件应使用的 profile。你自己的 `api_key` 会忽略此设置，但在设置了 `profile` 时，通用的 `LANGSMITH_API_KEY` 不会作为回退使用。

如果改用 API key，请将其添加到 `~/.claude/langsmith.json`，这与 Claude Code 读取的是同一个文件：

```json
{ "enabled": true, "api_key": "lsv2_pt_...", "agent_id": "shared-claude" }
```

如果设置了多个凭据，插件会使用它找到的第一个：

1. 插件自己的 key，来自 `api_key` 或 `CC_LANGSMITH_API_KEY`。
2. 你的 `langsmith auth login` 登录。
3. 环境中的通用 `LANGSMITH_API_KEY`。

登录过期或 key 被拒绝时，tracing 会停止，该时间段内的 turns 永远不会上传。管理员还可以要求每个 prompt 都使用[有效的登录](#require-a-working-sign-in)。

## 开启 tracing

除非管理员已通过[托管文件](#lock-settings)开启 tracing，否则在你于 `~/.claude/langsmith.json` 中开启之前，tracing 处于关闭状态。使用 `agent_id` 将 traces 发送到某个 [agent](/langsmith/log-traces-to-agent#send-traces-to-an-agent)：

```json
{ "enabled": true, "agent_id": "shared-claude" }
```

或使用 `project` 将它们发送到某个项目：

```json
{ "enabled": true, "project": "shared-claude" }
```

二者择其一。如果同时设置，`agent_id` 优先。

启动一个 Cowork 任务，并在 [LangSmith](https://smith.langchain.com) 中打开你的 agent 或项目。Skill 调用会记录运行的是哪个 skill，因此你可以按 skill 筛选 traces。

## 部署到你的组织

管理员可以为所有人安装插件，并集中控制其 tracing 方式。

### 为所有人安装

组织所有者可以将插件添加到每位成员的 claude.ai 账户，从而同时覆盖 Cowork 和 Claude Code。有关设置方法，请参见 [Choose a rollout route](https://claude.com/docs/plugins/org-rollout)。

## 隐藏对话

在 Cowork 任务中运行 `/langsmith-tracing:mute` 可使其内容不进入 LangSmith，运行 `/langsmith-tracing:unmute` 可重新开启。要默认静音每个任务，请将 `defaultMuted` 设置为 `true`。
