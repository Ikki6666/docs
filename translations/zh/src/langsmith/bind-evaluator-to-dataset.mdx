LangSmith 支持通过两种方式为使用 SDK 创建的 experiments 打分：

* **以编程方式**，在代码中指定 evaluators（详情参阅[如何评估 LLM 应用](/langsmith/evaluate-llm-application)）
* 在 UI 中**将 evaluators 绑定到 dataset**。这样一来，除了已通过 SDK 配置的 evaluators 之外，任何新创建的 experiment 都会自动运行这些 evaluators。当正在迭代应用（target function），并希望为所有 experiments 运行一组固定 evaluators 时，这种方式非常有用。

## 在 dataset 上配置 evaluator

1. 在 [LangSmith UI](https://smith.langchain.com) 中选择一个 dataset。
1. 点击 **Evaluators** 标签页。
1. 点击 **+ Evaluator** 打开 **Add Evaluator** 面板。
1. 选择以下方式之一：
   - **Create from scratch**：新建一个 [LLM-as-a-Judge](/langsmith/llm-as-judge)、[Code](/langsmith/online-evaluations-code) 或 [Composite](/langsmith/composite-evaluators-ui) evaluator，或者选择 **From labeled data**，创建一个[与人工反馈对齐](/langsmith/improve-judge-evaluator-feedback)的 LLM-as-a-judge evaluator。
   - **Attach an existing evaluator**：从工作区中选择一个已有 evaluator 复用。
   - **Create from a template**：从现成 evaluator 模板开始。

<Note>
当为 dataset 配置 evaluator 后，它只会影响在该 evaluator 配置完成之后创建的 experiment runs。它不会影响在此之前创建的 experiment runs 的评估结果。
</Note>

## LLM-as-a-judge evaluators

将 evaluator 绑定到 dataset 的流程，与在 Playground 中配置 LLM-as-a-judge evaluator 的流程非常相似。请参阅[在 Playground 中配置 LLM-as-a-judge evaluator](/langsmith/llm-as-judge?mode=ui)的说明。

## 自定义代码 evaluators

将代码 evaluator 绑定到 dataset 的流程，与在 online evaluation 中配置代码 evaluator 的流程非常相似。请参阅[配置代码 evaluators](/langsmith/online-evaluations-code)的说明。

在 online evaluation 中配置代码 evaluator 与将代码 evaluator 绑定到 dataset 之间，唯一的区别是：绑定到 dataset 的自定义代码 evaluator 可以引用 dataset 的 `Example` 中包含的输出。

对于绑定到 dataset 的自定义代码 evaluator，evaluator 函数接收两个参数：

* 一个 `Run`（[reference](/langsmith/run-data-format)）。它表示 experiment 中的新 run。例如，如果通过 SDK 运行了一个 experiment，那么这里会包含正在测试的 chain 或 model 的输入和输出。
* 一个 `Example`（[reference](/langsmith/example-data-format)）。它表示 dataset 中对应的参考样例，供正在测试的 chain 或 model 使用。`Run` 和 `Example` 的 `inputs` 应保持一致。如果 `Example` 中有参考 `outputs`，就可以用它与 run 的输出进行比较并打分。

下面的代码展示了一个简单 evaluator 函数示例，用于检查输出是否与参考输出完全一致。

<CodeGroup>

```python Python
import numpy as np

def perform_eval(run, example):
    # run is a Run object
    # example is an Example object
    output = run['outputs']['output']
    ref_output = example['outputs']['outputs']
    output_match = np.array_equal(output, ref_output)

    return { "exact_match": output_match }
```

```javascript JavaScript
function perform_eval(run, example) {
    // run is a Run object
    // example is an Example object
    const output = run.outputs.output;
    const refOutput = example.outputs.outputs;

    // Deep equality check for arrays/objects
    const outputMatch = JSON.stringify(output) === JSON.stringify(refOutput);

    return { "exact_match": outputMatch };
}
```

</CodeGroup>
