## Sandboxes

## Admin and billing

## Fixes

<Update label="June 15-19, 2026" rss={{ title: "2026-06-15 - Cloud update" }}>

## Observability and evaluations

### Automations

- [Automations](/langsmith/rules) 现在允许你按 action 控制 trace retention，因此 rule 匹配到的 trace 可以保持基础保留期，而不会被升级。

### Engine

- 当 GitHub 尚未连接时，[Engine](/langsmith/engine) issue board 现在会显示一个 Connect GitHub action，因此你可以不用离开 board 就完成 pull request 创建配置。
- [Engine](/langsmith/engine) 现在拥有统一的启用页面，支持 access request，并且组织设置将 Engine 的使用情况和限制统一到一个位置。
- 当支出跨过各个已配置阈值时，organization admin 现在会收到 [Engine](/langsmith/engine) spend email，并且暂停或禁用 Engine 时现在会要求确认。

### Datasets and experiments

- [Experiments](/langsmith/analyze-an-experiment) 现在会在 header 和 Progress 列中显示实时加载进度，因此你可以实时跟踪已完成和已评估的 run。
- [Evaluators](/langsmith/evaluators) 现在在高级选项中提供 trace-retention 开关，因此打分后的 trace 可以在适合你的工作流时保持基础保留期。
- [Evaluator](/langsmith/evaluators) prompt 编辑现在提供 advanced mode，可直接编辑 Mustache template，并分别管理变量映射。
- 创建 [dataset](/langsmith/manage-datasets) 时现在可以应用 resource tag，包括从零创建、文件上传或 clone 场景。
- 自动附加的 Assertions [evaluators](/langsmith/evaluators) 现在会从 reference output 读取 assertion，因此 experiment score 能反映真实的 pass/fail 结果。

### Prompts and playground

- [OAuth client credentials](/langsmith/model-configurations#oauth-client-credentials) 现在支持按 workspace 配置 model configuration，因此 workspace admin 可以自助为保存的 prompt 和 model 配置 OAuth。
- [Playground](/langsmith/playground-model-providers) 现在在 OpenAI reasoning model 的 Responses API 上提供 Reasoning Summary 选项。
- model dropdown 现在不会再为 OpenAI Compatible Endpoint 推荐 OpenAI model，因此你可以输入自己的 [custom model name](/langsmith/model-configurations)。

### Tracing

- [Trace query syntax](/langsmith/trace-query-syntax) 现在提供完整的 operator 参考、字段表和快速示例，因此更容易发现 API 过滤功能。
- [OpenTelemetry guide](/langsmith/trace-with-opentelemetry) 现在解释了如何把 span 关联到现有的 LangSmith SDK trace，以及 parent span 永远未到达时会发生什么，因此跨进程 trace 更容易调试。

### Monitoring and alerting

- [Dashboards](/langsmith/dashboards) 现在包含 chart builder、chart template、create/edit pane，以及时间序列图中的 brush 和 series 控件，因此监控可视化更加完整。
- 现在你可以将 [alerts](/langsmith/alerts) 原生发送到 Slack，并在 UI 中连接或断开 Slack app。

## Deployment

- Preview [deployments](/langsmith/deployment) 现在会为 preview commit 构建镜像，而不是复用父 deployment 的镜像。

## Sandboxes

- [Sandbox auth proxy](/langsmith/sandbox-auth-proxy) 现在记录了 GCP rule 和 service-account 处理方式，因此通过 proxy 访问 Google API 更清晰。
- [Sandboxes](/langsmith/sandboxes) 现在将 AWS US SaaS 可用性标记为 generally available，因此区域表与当前 rollout 状态保持一致。
- [Sandboxes](/langsmith/sandboxes) 现在支持 Git mount 和 Google Cloud Storage bucket mount。

## Admin and billing

### Administration

- [Organization settings](/langsmith/administration-overview) 现在明确指出 SSO/SCIM group name 可以省略空格，因此即使 enterprise IdP 不允许空格，也能正常工作。
- Vanta MCP integration 现在已对所有 workspace generally available。
- 在创建 dataset、prompt 和 project 时应用 tag，现在受专门的 [tag-on-create permissions](/langsmith/administration-overview) 控制。

### LLM Gateway

- [LLM gateway](/langsmith/llm-gateway) 现在支持 Vertex AI 的原生 Gemini route，以及 OpenAI embeddings endpoint。
- [Gateway guard](/langsmith/llm-gateway) policy 现在支持更细粒度的 PII 配置，以及可配置的 timeout action。

### Usage and billing

- [Granular billable usage](/langsmith/granular-usage) 现在更清楚地说明了组织级作用域，因此你可以更准确地理解 usage total。

</Update>

## Observability and evaluations

### Engine

- [Engine](/langsmith/engine) 现在在 project 视图中只显示 project 级 spend，因此组织级 spend 保持在组织设置界面中。
- [Engine](/langsmith/engine) 现在会把 Slack issue-alert deck 固定在滚动 issue 列表上方，因此在浏览 issue 时 callout 会保持可见。

### Datasets and experiments

experiment table 现在显示加载进度条，展示已完成和已评估的 run 数量，而在该功能之前创建的 experiment 会显示占位进度条。
- [Dashboards](/langsmith/dashboards) 现在支持基于 v2 chart API 的时间序列柱状图和折线图，因此监控指标可以使用更新的图表类型。
- 分类反馈，categorical feedback，现在会在 experiment table 中显示推导出的百分比，因此 pass/fail 指标更容易浏览。

### Prompts and playground

- [Playground](/langsmith/playground-model-providers) 现在可以端到端为启用了 OAuth 的 preset 生成 OAuth bearer，因此长时间运行的 batch 和 stream 也能正常工作。

## Sandboxes

- [Sandbox auth proxy](/langsmith/sandbox-auth-proxy) 现在支持 GCP auth flow，因此 sandbox workload 可以通过 proxy 访问 Google API。

## Fixes

- Engine 试用 modal 不再显示粗略估算的 LCU bullet，因此定价文案不再那么容易误导。

</Update>

<Update label="June 1-5, 2026" rss={{ title: "2026-06-01 - LangSmith Cloud update" }}>

## Observability and evaluations

### Automations

- [Run rule](/langsmith/rules) webhook payload 现在会为每个 run 包含 trace deep link，因此下游系统可以直接跳回该 trace。

### Engine

- 按 workspace 统计的 [Engine](/langsmith/engine) spend 现在 generally available：你可以直接在 Engine settings 页面查看 LCU 和 USD spend，包括 session-level spend。
- Engine settings 页面现在会在一个位置展示更多 Engine 细节。
- 现在你可以通过 API 和 webhook settings UI 轮换 [Engine issue-board webhook](/langsmith/engine-webhooks) 的 signing secret。
- Engine issue 列表新增了按 trace count 排序的选项。

### Datasets and experiments

- 全新的开箱即用 [Assertions evaluator](/langsmith/assertions) 会根据 reference output 中明确定义的 criteria 对输出打分，并且当你向 dataset 添加 assertion 风格 example 时，会自动附加一条 Assertions rule。
- experiment detail、[comparison](/langsmith/compare-experiment-results) 和全局 experiment table 中的 evaluator metrics 得到了改进。

### Prompts and playground

- [Playground](/langsmith/playground-model-providers) 现在支持 Amazon Bedrock API key authentication，因此你可以使用 bearer token 而不是 AWS credential 来认证。

### Tracing

- [trace view](/langsmith/view-traces) 现在会在某个 run 的 actions menu 上显示未读指示器，当该 run 有你尚未查看的 reviewer note 时会高亮。
- waterfall view 现在是全高显示，并带有 sticky turn header，因此在浏览长 trace 时不容易迷失位置。
- global search 现在包含 context 和 sandbox。

## Deployment

- 现在你可以直接从 [Studio](/langsmith/studio) 页面触发 LangSmith Deployment。
- LangSmith Deployment 现在支持 [deploying Google Agent Development Kit (ADK) agents](/langsmith/deploy-google-adk)。

## Sandboxes

- [Sandbox proxy rules](/langsmith/sandbox-auth-proxy) 现在支持配置 AWS authentication，因此 sandbox 可以通过 proxy 使用签名请求访问 AWS 服务。
- Sandboxes 现在可以从 Dockerfile 构建源创建 [snapshots](/langsmith/sandbox-snapshots)。

## Admin and billing

### Administration

- organization admin 现在可以在 [organization settings](/langsmith/administration-overview) 页面中禁用 personal access token 创建。

### Usage and billing

- [Granular billable usage](/langsmith/granular-usage) 现在支持按 retention tier 过滤和分组，将 long-lived trace 与 short-lived trace 区分开来。
- Granular Billable Usage 页面现在会展示 LangSmith Deployment usage，包括 nodes executed、agent runs 和 agent uptime，并与 trace usage 一起呈现。

## Fixes

- 加载大 trace 时的性能得到提升。
- 现在重新打开 filter dropdown 编辑时，metadata 的 filter value 会被保留。
- 创建 dataset 时现在使用 multi-select dropdown 来选择 CSV 字段。

</Update>

<Update label="February 16-20, 2026" rss={{ title: "2026-02-16 - Cloud update" }}>

## Observability and evaluations

### Insights

- [Insights Agent](/langsmith/insights) 现在支持按 daily、weekly 或自定义 cron interval 调度 report，因此报告生成无需手动触发。时间范围会动态计算，因此 “last 24 hours” 报告在每次运行时反映的都是最新时间窗口，而不是你配置时的那个时间窗口。

### Datasets and experiments

- 现在你可以把任意 experiment 固定为 baseline。被固定的 experiment 会保持在 [Experiments](/langsmith/compare-experiment-results) 视图顶部，并作为后续运行的自动比较对象，在所有列中直接显示性能差异，因此改进和回归都能立即体现。

</Update>

<Update label="February 2-6, 2026" rss={{ title: "2026-02-02 - Cloud update" }}>

## Observability and evaluations

### Cost tracking

- [Cost tracking](/langsmith/cost-tracking) 现在不再局限于 LLM 调用。你可以为任意 run 提交自定义 cost metadata，例如昂贵的 tool call、第三方 API，或 retrieval step，从而在单一 dashboard 中监控、调试并优化整个 agent stack 的支出。

### Tracing

- 现在你可以 [configure which parts of a trace's inputs and outputs](/langsmith/configure-input-output-preview) 会显示在 tracing table 中，因此使用自定义 trace 格式的团队可以突出最相关的字段、减少噪音，并更快定位需要深入查看的 trace。

</Update>

## Observability and evaluations

### Annotation and human feedback

- 全新的成对 [annotation queues](/langsmith/annotation-queues) 允许 reviewer 并排比较两个 run，并选择 A 更好、B 更好，或二者在 rubric 各项上相等。LangSmith 会自动在两个 experiment 之间为 run 配对，并管理 queue、reviewer 分配和 trace 访问，因此你可以在 agent、prompt 和 model 之间执行 A/B 评估，包括语气、正确性、实用性或风格等主观维度。

</Update>

- [Studio](/langsmith/studio) 现在允许你通过给配置字段加上 `langgraph_nodes` tag 的方式，在 UI 中查看和编辑 node 逻辑、无需改代码即可编辑 prompt，并把 Playground experiment 同步回 graph。

</Update>

<Update label="March 10-14, 2025" rss={{ title: "2025-03-10 - Cloud update" }}>

## Observability and evaluations

### Tracing

- LangSmith 现在支持对 [OpenAI Agents SDK](/langsmith/trace-with-openai-agents-sdk) 应用进行 tracing，只需两行代码，即可获得对 agent 执行与推理过程的逐步 observability。

### Datasets and experiments

- 现在你可以在 UI 中重命名 [experiment](/langsmith/analyze-an-experiment)，既可以在运行后的 Playground table header 中完成，也可以在 Experiments 视图中通过铅笔图标操作。

</Update>

<Update label="February 24-28, 2025" rss={{ title: "2025-02-24 - Cloud update" }}>

## Observability and evaluations

### Datasets and experiments

- 现在你可以按 metadata 对 [experiment results](/langsmith/analyze-an-experiment) 进行分组，从而按用户群体或主题领域等分段分析评估表现。

## Fixes

- 新的 ingest-backend service 将 trace ingest 与前端请求处理分离，从而提升了平均请求处理速度以及高流量场景下的响应时间。

</Update>

## Observability and evaluations

### Prompts and playground

- [Playground](/langsmith/playground-model-providers) 现在可以使用保存在 LangSmith 中的 workspace secret，从而在不同环境之间实现一致的 credential 管理。

</Update>

<Update label="February 3-7, 2025" rss={{ title: "2025-02-03 - Cloud update" }}>

## Observability and evaluations

### Datasets and experiments

- 新的 [experiment view](/langsmith/analyze-an-experiment) 会为每个 feedback key 提供独立列，并新增 filtering、sorting 和 heat map，用于发现模式和性能问题区域。

## Deployment

- 现在你可以在 [Studio](/langsmith/studio) 中把 LLM run 打开到 LangSmith Playground 中，用于调试、可视化和在 thread 内进行 prompt 实验。

</Update>
