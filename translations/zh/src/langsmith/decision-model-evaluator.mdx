Decision model evaluator 使用 [decision model](/langsmith/online-evaluations-decision-models#decision-models)（例如 Jev）作为 judge。你定义的每个问题都会返回一个带类型的答案，LangSmith 会将它记录在自己的 feedback key 下。

本指南介绍如何在 [LangSmith UI](https://smith.langchain.com) 中定义 decision model evaluator。你可以在 dataset 上使用它以[在 experiments 上自动运行 evaluations](/langsmith/bind-evaluator-to-dataset)，也可以在 tracing project 上将其用作 [online evaluator](/langsmith/online-evaluations-decision-models)。要改为使用 LLM 作为 judge，请参阅 [How to define an LLM-as-a-judge evaluator](/langsmith/llm-as-judge)。

<Note>
你只能在 LangSmith UI 中创建 decision model evaluators。LangSmith SDKs 暂不支持创建它们。
</Note>

## Step 1. 创建 evaluator

1. 添加 TypeSafe API key。从你的 TypeSafe 账户生成一个 API key。在 LangSmith 中，前往 **Settings > Integrations > Provider secrets** 并点击 **+ Secret**。选择 **TypeSafe** 作为 provider 并粘贴你的 key。LangSmith 会将其存储为 workspace secret `TYPESAFE_API_KEY`。要以其他名称存储，请选择 **Custom** 并输入你自己的 secret 名称。更多信息请参阅 [Add provider secrets](/langsmith/llm-gateway-admin-setup#1-add-provider-secrets)。
1. 在 LangSmith UI 中，打开某个 dataset 或 tracing project 的 **Evaluators** 标签页并点击 **+ Evaluator**。
1. 在 **Configure Evaluator** 面板中，在 **Create from scratch** 下选择 **LLM-as-a-Judge Evaluator**。
1. 为你的 evaluator 命名。

## Step 2. 配置 evaluator

Decision model evaluators 支持 TypeSafe models（例如 Jev），采用 bring-your-own-key (BYOK) 方式。你在 evaluator 本身中定义 state 和 questions。Decision model evaluators 不能从 [Prompt Hub](/langsmith/prompt-context-hub#prompts) 加载 prompt，也不能使用自定义 output schema。它们也不支持 [few-shot examples](/langsmith/create-few-shot-evaluators)。要在另一个 dataset 或 tracing project 上复用某个 decision model evaluator，请在 **Configure Evaluator** 面板中选择 **Attach an existing evaluator**。

### Model

在 **Prompt & Model** 下，打开 **Model Configuration** 并选择一个 provider 和 model：

- 对于 Jev，选择 **TypeSafe** 作为 provider，然后选择一个 Jev model。如果你的 key 以 `TYPESAFE_API_KEY` 之外的名称存储，请在 **API Key Name** 中输入该名称。点击 **Apply**。
- 对于 TypeSafe-compatible endpoint，选择其保存的配置。请参阅 [Use a TypeSafe-compatible endpoint](#use-a-typesafe-compatible-endpoint)。

受支持的 models 请参阅 [Supported models](/langsmith/online-evaluations-decision-models#supported-models)。

#### 使用 TypeSafe-compatible endpoint

TypeSafe-compatible endpoint 将 evaluator 指向任何实现了 [TypeSafe System One API](https://docs.typesafe.ai) 的服务器。示例包括 OpenRouter 或你自己托管的 decision model。只有在你将其保存为 model configuration 之后，evaluator 才能使用它。关于设置、配置步骤和示例 base URLs，请参阅 [Connect to a TypeSafe-compatible model provider](/langsmith/typesafe-compatible-model)。

### State

**State** 是 decision model 评估的上下文。将来自你的 run 或 example 的变量映射到其中：

- 在 dataset 上，映射 input、output 或 reference output。
- 在 tracing project 上，映射 run 或 thread 变量，例如 run 的 inputs 和 outputs。

与 LLM judge 的 prompt 不同，state 不应包含评分指令。请把评分标准放在 questions 中。

### Questions

Questions 是你的 decision model evaluator 使用的评分标准。每个 question 的名称都会成为被评估的 run 或 thread 上的一个 feedback key。要定义 questions：

1. 在 **Feedback Configuration** 下，为你要评估的每个标准添加一个 question。
1. 为每个 question 输入 **Name**、选择一个 **Type**，并编写 **Instructions**。
1. 为该 question 类型定义 true 和 false 的含义、选项或等级。

要以 JSON 形式编辑 questions，请点击 **Advanced**。

关于每种 question 类型返回什么以及答案如何映射到 feedback，请参阅 [Question types](/langsmith/online-evaluations-decision-models#question-types) 和 [Map answers to feedback keys](/langsmith/online-evaluations-decision-models#map-answers-to-feedback-keys)。

## Step 3. 保存 evaluator

要保存 evaluator，请点击 **Create** 或 **Save**。

在 dataset 上，evaluator 会在每个新 experiment 上运行。在 tracing project 上，它会评估匹配其过滤条件的传入 runs 或 threads。关于过滤条件、采样率和回填，请参阅 [Set up decision model online evaluators](/langsmith/online-evaluations-decision-models)。
