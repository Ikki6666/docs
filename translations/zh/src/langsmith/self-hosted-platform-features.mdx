本页介绍仅适用于 [self-hosted](/langsmith/self-hosted) 部署的平台特性。

## Custom PostgreSQL

你可以使用自定义 PostgreSQL 实例，替代[control plane 自动创建的实例](/langsmith/cloud-platform-features#database-provisioning)。请指定 [`POSTGRES_URI_CUSTOM`](/langsmith/env-var-self-hosted) 环境变量来使用自定义 PostgreSQL 实例。

多个 deployments 可以共享同一个 PostgreSQL 实例。例如，对于 `Deployment A`，`POSTGRES_URI_CUSTOM` 可以设置为 `postgres://<user>:<password>@/<database_name_1>?host=<hostname_1>`；对于 `Deployment B`，`POSTGRES_URI_CUSTOM` 可以设置为 `postgres://<user>:<password>@/<database_name_2>?host=<hostname_1>`。其中 `<database_name_1>` 和 `<database_name_2>` 是同一实例中的不同数据库，而 `<hostname_1>` 相同。**不同 deployment 不能共用同一个数据库**。

## Custom Redis

你可以使用自定义 Redis 实例，替代 control plane 自动创建的 Redis 实例。请指定 [`REDIS_URI_CUSTOM`](/langsmith/env-var-self-hosted) 环境变量来使用自定义 Redis 实例。

多个 deployments 也可以共享同一个 Redis 实例。例如，对于 `Deployment A`，`REDIS_URI_CUSTOM` 可以设置为 `redis://<hostname_1>:<port>/1`；对于 `Deployment B`，`REDIS_URI_CUSTOM` 可以设置为 `redis://<hostname_1>:<port>/2`。其中 `1` 和 `2` 是同一实例中的不同数据库编号，而 `<hostname_1>` 相同。**不同 deployment 不能共用相同的数据库编号**。

## Listeners

listener 是 [listener application](/langsmith/data-plane#listener-application) 的一个实例。listener 中包含关于应用本身的元数据（例如版本），以及关于可供其部署的计算基础设施的元数据（例如 Kubernetes namespaces）。

listener 数据模型仅适用于 self-hosted 部署。control plane 与 listener 会共同协作，在你的基础设施上完成 deployment 的创建与状态协调。

## Resource customization

self-hosted deployments 的资源可以完全自定义。不同于 Cloud 只暴露固定的 `Development` 和 `Production` [deployment types](/langsmith/cloud-platform-features#deployment-types)，self-hosted deployments 会依据你的基础设施配置来设定 CPU、内存、副本数和存储。关于调优建议，请参阅 [Configure Agent Server for scale](/langsmith/agent-server-scale)。
