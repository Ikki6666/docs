title: 使用邮箱和密码进行基础身份验证

基础身份验证允许用户在 [Self-hosted LangSmith](/langsmith/self-hosted) 中直接使用邮箱和密码登录，而无需配置外部身份提供方。[Organization Admins](/langsmith/rbac#organization-admin) 直接在 LangSmith 中管理用户，因此整个认证流程是自包含的，不依赖 [OAuth 或 SSO](/langsmith/self-host-sso)。

<Tip>
关于 LangSmith Self-hosted 支持的认证方式说明，请参阅[认证方式](/langsmith/authentication-methods#self-hosted)页面。
</Tip>

## 注意事项

- 你可以通过替换配置参数，将基础身份验证安装升级为[带 client secret 的 OAuth](/langsmith/self-host-sso#with-client-secret-recommended)，但从任意 OAuth 模式都不能再切回基础身份验证。
- 你不能在基础身份验证和带 PKCE 的 OAuth（已弃用）之间双向切换。
- 一个新的基础身份验证安装需要全新安装，并使用独立的 PostgreSQL 数据库或 schema，除非你是从现有的 [None](/langsmith/authentication-methods#none) auth 安装迁移过来，参阅[从 none auth 迁移](#从-none-auth-迁移)。
- 用户在被邀请时会收到一个自动生成的初始密码，需要通过系统外方式发给他们。之后任何 Organization Admin 都可以修改该密码。
- 不能同时启用基础身份验证和带 client secret 的 OAuth。
- 所有基础身份验证用户共享安装时预置的单个 `Default` [organization](/langsmith/administration-overview#organizations)，不支持创建额外组织。

## 要求与特性

- 初始密码必须至少包含 12 个字符，并且至少包含一个小写字母、一个大写字母和一个符号，参阅[配置](#配置)。
- 用于签发 JWT 的 secret 没有严格格式要求，但应安全地生成一个至少 32 个字符的字符串。例如，[`openssl rand -base64 32`](https://docs.openssl.org/1.0.2/man1/rand/#description)。

## 从 none auth 迁移

<Note>
仅支持 [0.7 及之后版本](/langsmith/self-hosted-changelog)。
</Note>

从 [None](/langsmith/authentication-methods#none) auth 模式迁移到基础身份验证时，会保留现有 traces、datasets 以及其他资源。LangSmith 会用你在[配置文件](#配置)中设置的基础身份验证凭证创建新用户，并替换原本唯一的 `"default"` 用户。已有工作区会继续保留它原来的 ID（`00000000-0000-0000-0000-000000000000`），因此现有资源仍然绑定在该工作区上。除了这个用户替换动作之外，迁移后的安装行为与全新基础身份验证安装相同。

要迁移，请应用下方[配置](#配置)中的基础身份验证设置，然后运行 `helm upgrade`。

## 配置

<Note>
更改 JWT secret 会让所有用户退出登录。
</Note>

在 LangSmith Helm values 中加入以下配置块以启用基础身份验证。首次安装时，LangSmith 会使用这些值为 `Default` organization 创建初始的 Organization Admin 用户：

```yaml Helm
config:
  authType: mixed
  basicAuth:
    enabled: true
    initialOrgAdminEmail: <YOUR EMAIL ADDRESS>
    initialOrgAdminPassword: <PASSWORD> # Must be at least 12 characters long and contain at least one lowercase, uppercase, and symbol
    jwtSecret: <SECRET>
```

配置完成后，LangSmith 会显示一个邮箱和密码登录界面。使用 `initialOrgAdminEmail` 和 `initialOrgAdminPassword` 的值登录后，该用户会被自动授予 `Organization Admin` 角色。更多细节请参阅[组织角色](/langsmith/administration-overview#organization-roles)。
