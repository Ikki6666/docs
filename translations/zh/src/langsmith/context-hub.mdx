Context Hub 让你的团队能够以版本控制、环境感知的方式，管理生产环境中 agents 使用的指令和工具。_context_ 是一组带版本的 agent 指令与工具包，可以是 skill，也可以是完整 agent。你可以在 LangSmith 中管理它，并将其提升到某个环境，供 agents 拉取使用。
