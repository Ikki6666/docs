[n8n](https://n8n.io/) 是一个工作流自动化平台，内置基于 LangChain 的高级 AI 能力。你可以将 n8n 实例连接到 LangSmith，以记录和监控 AI workflow runs。

<Note>
LangSmith tracing **仅适用于 self-hosted 的 n8n 实例**。
</Note>

## Prerequisites

- 一个 [LangSmith 账户](https://smith.langchain.com) 和 [API key](/langsmith/create-account-api-key)
- 一个 self-hosted 的 n8n 实例

## Set up tracing

1. 在托管 n8n 实例的环境中，以与你其余 [n8n configuration](https://docs.n8n.io/hosting/configuration/configuration-methods/) 相同的方式设置以下环境变量。

   必需环境变量：
   - `LANGCHAIN_TRACING_V2`，设为 `true` 以启用 tracing。
   - `LANGCHAIN_API_KEY`，填写你的 LangSmith API key。

   可选环境变量：
   - `LANGCHAIN_ENDPOINT`，LangSmith API endpoint。默认值为 `https://api.smith.langchain.com`。如果你使用 self-hosted LangSmith、GCP EU（`https://eu.api.smith.langchain.com`）、GCP APAC（`https://apac.api.smith.langchain.com`）或 AWS US（`https://aws.api.smith.langchain.com`），请设置此项。
   - `LANGCHAIN_PROJECT`，用于存放 traces 的项目名称。默认值为 `"default"`。
   - `LANGCHAIN_CALLBACKS_BACKGROUND`，设为 `true` 使用异步 trace 上传（默认），或设为 `false` 使用同步上传。（默认值：`true`）

1. 重启你的 n8n 实例，使环境变量生效。

## View traces in LangSmith

在运行一个 AI workflow 后：

1. 打开 [LangSmith](https://smith.langchain.com)。
1. 选择你的项目。如果你刚创建账户，那么在第一条 trace 发送后会看到 `"default"` 项目。
1. 找到与你的 workflow 执行对应的 trace。
