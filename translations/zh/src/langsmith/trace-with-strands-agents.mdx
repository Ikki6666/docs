[Strands Agents](https://strandsagents.com/) 是一个用于构建模型驱动型智能体的 SDK。LangSmith 提供了一个 Strands Agents 集成，可将 Strands OpenTelemetry span 导出为兼容 LangSmith 的格式，其中包括智能体运行、模型调用、工具调用、提示词、补全内容和 token 用量。

## 安装

安装带有 Strands Agents 支持的 LangSmith：

<CodeGroup>

```bash pip
pip install "langsmith[strands-agents]"
```

```bash uv
uv add "langsmith[strands-agents]"
```

</CodeGroup>

这样会安装 LangSmith、Strands Agents、Strands Agents 工具，以及 OpenTelemetry OTLP HTTP exporter。

## 设置

### 1. 配置环境变量

设置 [LangSmith API 密钥](/langsmith/create-account-api-key)和项目名称。如果你把 Amazon Bedrock 用作 Strands Agents 的模型提供方，还需要使用你偏好的 AWS 认证方式配置 AWS 凭证。

```bash
export OTEL_EXPORTER_OTLP_ENDPOINT=https://api.smith.langchain.com/otel/v1/traces
export OTEL_EXPORTER_OTLP_HEADERS="x-api-key=<your_langsmith_api_key>,Langsmith-Project=<your_project_name>"

# Required when using Amazon Bedrock.
export AWS_REGION=<your_aws_region>
```

<Note>
Strands Agents 集成使用标准的 OpenTelemetry OTLP exporter。在调用 `setup_langsmith_telemetry()` 之前，先配置好 LangSmith endpoint 和 headers。
</Note>

### 2. 启用 Strands Agents telemetry

在创建或调用智能体之前，于应用启动时调用一次 `setup_langsmith_telemetry()`：

```python
from langsmith.integrations.strands_agents import setup_langsmith_telemetry

setup_langsmith_telemetry()
```

如需本地调试，可传入 `console=True`，同时将转换后的 spans 打印到 stdout：

```python
setup_langsmith_telemetry(console=True)
```

### 3. 创建并运行智能体

完成配置后，Strands Agents traces 会自动导出到 LangSmith：

```python
from langsmith.integrations.strands_agents import setup_langsmith_telemetry
from strands import Agent

setup_langsmith_telemetry()

agent = Agent(
    system_prompt="You are a concise assistant.",
)

response = agent("Explain what LangSmith tracing is in one sentence.")
print(response)
```

## 在 LangSmith 中查看 traces

运行应用后，打开你的 LangSmith 项目，即可查看包含以下内容的 traces：

- 智能体调用 spans
- 事件循环周期 spans
- 带有提示词、补全内容和 token 用量的 LLM 调用 spans
- 当智能体使用工具时，包含工具输入和输出的工具调用 spans

## 自定义 OTLP exporter

如果你需要向底层 OpenTelemetry exporter 传递自定义选项，可以使用 `create_langsmith_exporter()` 创建一个 `LangSmithSpanExporter`，然后把它手动附加到 Strands tracer provider：

```python
from langsmith.integrations.strands_agents import create_langsmith_exporter
from opentelemetry.sdk.trace.export import BatchSpanProcessor
from strands.telemetry import StrandsTelemetry

telemetry = StrandsTelemetry()
exporter = create_langsmith_exporter(
    endpoint="https://api.smith.langchain.com/otel/v1/traces",
    headers={
        "x-api-key": "<your_langsmith_api_key>",
        "Langsmith-Project": "<your_project_name>",
    },
)
telemetry.tracer_provider.add_span_processor(BatchSpanProcessor(exporter))
```

当你希望在代码中而不是通过环境变量配置 exporter 选项时，请使用这种方式。
