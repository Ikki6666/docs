[Online evaluations](/langsmith/evaluation-concepts#online-evaluations) 会对生产环境中的 [traces](/langsmith/observability-concepts#traces) 提供实时反馈。这有助于持续监控应用性能，以发现问题、衡量改进效果，并确保长期稳定的一致质量。

[**Composite evaluators**](/langsmith/composite-evaluators-ui) 允许你将多个 evaluator 分数组合为一个单独的 [score](/langsmith/evaluation-concepts#evaluator-outputs)。当你希望评估应用的多个方面，并将结果汇总为单一结果时，这会非常有用。

<Note>当在线 evaluator 在 trace 中任意一个 run 上运行时，该 trace 会自动升级到[extended data retention](/langsmith/usage-and-billing#data-retention-auto-upgrades)。这会影响 trace 定价，但也能确保那些符合评估标准、通常更值得分析的 traces 被保留下来供后续调查。 </Note>

## View online evaluators

进入 **Tracing Projects** 标签页并选择一个 tracing project。要查看该 project 已有的 online evaluators，请点击 **Evaluators** 标签页。

## Configure composite online evaluators

你可以在某个 [tracing project](/langsmith/observability-concepts#projects) 上为 [online evaluations](/langsmith/evaluation-concepts#online-evaluations) 创建 composite evaluators。通过 UI 中的 composite evaluators，你可以对多个 evaluator scores 计算加权平均值或加权总和，并可自定义权重。

### 1. Navigate to the tracing project

要开始配置 composite evaluator，请进入 **Tracing** 页面并选择一个 tracing project。

在 tracing project 视图中，进入 **Evaluators** 标签页。点击 **+ Evaluator** 打开 **Add Evaluator** 面板，再在 **Create from scratch** 下点击 **Composite Score**。

### 2. Configure the composite evaluator

1. 为 evaluator 命名。
2. 选择聚合方式，**Average** 或 **Sum**。
    - **Average**：∑(weight*score) / ∑(weight)。
    - **Sum**：∑(weight*score)。
3. 添加你希望纳入 composite score 的 feedback keys。
4. 为各个 feedback keys 设置权重。默认情况下，各 feedback key 的权重相等。你可以调整权重，以提高或降低某些 feedback key 在最终分数中的重要性。
5. 点击 **Create** 保存 evaluator。

<Tip> 如果你之后需要调整 composite scores 的权重，也可以在 evaluator 创建后再修改。修改后，所有已配置该 evaluator 的 runs 对应结果分数都会同步更新。 </Tip>

### 3. View composite evaluator results

Composite scores 会像单个 evaluator 产生的 feedback 一样，以 **feedback** 的形式附加在 run 上。

**在 tracing project 中**：
- Composite scores 会显示为 runs 上的 feedback。
- 你可以[过滤 runs](/langsmith/filter-traces-in-application)，筛选出具有 composite score 的 runs，或 composite score 满足某个阈值的 runs。
- 你可以[创建 chart](/langsmith/dashboards#custom-dashboards) 来可视化 composite score 随时间变化的趋势。

<Note> 如果 run 上未配置任意一个组成该 composite 的 evaluator，那么该 run 不会计算 composite score。 </Note>
