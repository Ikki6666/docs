有些指标只能在整个 experiment 级别定义，而不能在 experiment 中的单个 run 级别定义。例如，你可能想计算评估目标在整个数据集上的总体通过率或 f1 score。这类 evaluator 被称为 summary evaluator。

## Basic example

这里我们计算 f1-score，它结合了 precision 和 recall。

这类指标只能基于 experiment 中的全部 example 来计算，因此 evaluator 接收的是输出列表 `outputs` 和参考输出列表 `reference_outputs`。

<CodeGroup>

```python Python
def f1_score_summary_evaluator(outputs: list[dict], reference_outputs: list[dict]) -> dict:
    true_positives = 0
    false_positives = 0
    false_negatives = 0

    for output_dict, reference_output_dict in zip(outputs, reference_outputs):
        output = output_dict["class"]
        reference_output = reference_output_dict["class"]

        if output == "Toxic" and reference_output == "Toxic":
            true_positives += 1
        elif output == "Toxic" and reference_output == "Not toxic":
            false_positives += 1
        elif output == "Not toxic" and reference_output == "Toxic":
            false_negatives += 1

    if true_positives == 0:
        return {"key": "f1_score", "score": 0.0}

    precision = true_positives / (true_positives + false_positives)
    recall = true_positives / (true_positives + false_negatives)
    f1_score = 2 * (precision * recall) / (precision + recall)

    return {"key": "f1_score", "score": f1_score}
```

```typescript TypeScript
function f1ScoreSummaryEvaluator({ outputs, referenceOutputs }: {
    outputs: Record<string, any>[],
    referenceOutputs: Record<string, any>[]
}) {
    let truePositives = 0;
    let falsePositives = 0;
    let falseNegatives = 0;

    for (let i = 0; i < outputs.length; i++) {
        const output = outputs[i]["class"];
        const referenceOutput = referenceOutputs[i]["class"];

        if (output === "Toxic" && referenceOutput === "Toxic") {
            truePositives += 1;
        } else if (output === "Toxic" && referenceOutput === "Not toxic") {
            falsePositives += 1;
        } else if (output === "Not toxic" && referenceOutput === "Toxic") {
            falseNegatives += 1;
        }
    }

    if (truePositives === 0) {
        return { key: "f1_score", score: 0.0 };
    }

    const precision = truePositives / (truePositives + falsePositives);
    const recall = truePositives / (truePositives + falseNegatives);
    const f1Score = 2 * (precision * recall) / (precision + recall);

    return { key: "f1_score", score: f1Score };
}
```

</CodeGroup>

然后你可以像下面这样把这个 evaluator 传给 `evaluate` 方法：

```python Python
from langsmith import Client

ls_client = Client()

def bad_classifier(inputs: dict) -> dict:
    return {"class": "Not toxic"}

def correct(outputs: dict, reference_outputs: dict) -> bool:
    """Row-level correctness evaluator."""
    return outputs["class"] == reference_outputs["label"]

results = ls_client.evaluate(
    bad_classified,
    data=dataset,
    evaluators=[correct],
    summary_evaluators=[pass_50],

```

```typescript TypeScript
import { Client } from "langsmith";
import { evaluate } from "langsmith/evaluation";
import type { EvaluationResult } from "langsmith/evaluation";

const client = new Client();
const datasetName = "Toxic queries";
const dataset = await client.clonePublicDataset(
    "https://smith.langchain.com/public/3d6831e6-1680-4c88-94df-618c8e01fc55/d",
    { datasetName: datasetName }
);

function correct({ outputs, referenceOutputs }: {
    outputs: Record<string, any>,
    referenceOutputs?: Record<string, any>
}): EvaluationResult {
    const score = outputs["class"] === referenceOutputs?.["label"];
    return { key: "correct", score };
}

function badClassifier(inputs: Record<string, any>): { class: string } {
    return { class: "Not toxic" };
}

await evaluate(badClassifier, {
    data: datasetName,
    evaluators: [correct],
    summaryEvaluators: [summaryEval],
    experimentPrefix: "Toxic Queries",
});
```

## Summary evaluator args

Summary evaluator function 必须使用特定的参数名。它们可以接收以下参数中的任意子集：

* `inputs: list[dict]`：与数据集中单个 example 对应的输入列表。
* `outputs: list[dict]`：每个 experiment 在给定输入上产生的 dict 输出列表。
* `reference_outputs/referenceOutputs: list[dict]`：该 example 对应的参考输出列表，如果存在。
* `runs: list[Run]`：两个 experiment 在该 example 上生成的完整 [Run](/langsmith/run-data-format) 对象列表。如果你需要访问中间步骤或每个 run 的 metadata，可使用这个参数。
* `examples: list[Example]`：数据集中的全部 [Example](/langsmith/example-data-format) 对象，包括 example 输入、输出，如果有，以及 metadata，如果有。

## Summary evaluator output

Summary evaluator 预期返回以下类型之一：

Python and JS/TS

* `dict`：形如 `{"score": ..., "name": ...}` 的 dict，可用于传入数值型或布尔型 score，以及指标名称。

Currently Python only

* `int | float | bool`：会被解释为可用于平均、排序等操作的连续型指标。函数名会被用作指标名。
