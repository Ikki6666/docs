<Note>
该功能适用于 Helm chart 0.9.5 及之后的版本。
</Note>

LangSmith 会为 self-hosted 安装自动生成并同步组织使用量图表。

这些图表位于 `Settings > Usage and billing > Usage graph`：

* Usage by Workspace：按工作区统计 traces，也就是 root runs
* Organization Usage：统计整个组织中的所有 traces，也就是 root runs

图表每 5 分钟刷新一次，以包含新增工作区。请注意，这些图表不可编辑。

## 以编程方式获取 trace 数量

你可以通过两种不同方式，以编程方式获取 trace 数量：

### 方法 1：使用 LangSmith REST API

如果你的 self-hosted 安装使用的是 online key，可以使用 [LangSmith REST API](/langsmith/smith-api/orgs/get-org-usage) 获取组织使用量数据。

```bash
curl -X GET "https://your-langsmith-instance.com/api/v1/orgs/current/billing/usage" \
  -H "Accept: application/json" \
  -H "X-API-Key: your-api-key" \
  -G \
  -d "starting_on=2025-09-01T00:00:00Z" \
  -d "ending_before=2025-10-01T00:00:00Z" \
  -d "on_current_plan=true"
```

### 方法 2：使用 PostgreSQL 支持查询

对于使用 offline key 的安装，或者当你需要更细的导出能力时，可以直接针对 PostgreSQL 数据库执行支持查询。所有可用脚本都位于 [support queries repository](https://github.com/langchain-ai/helm/tree/main/charts/langsmith/scripts/support_queries/postgres)。

```bash
sh run_support_query_pg.sh "postgres://postgres:postgres@localhost:5432/postgres" \
  --input support_queries/postgres/pg_get_historic_trace_counts_daily.sql \
  --output trace_counts.csv
```

关于如何运行支持查询的更多细节，请参阅[针对 PostgreSQL 运行支持查询](/langsmith/script-running-pg-support-queries)指南。
