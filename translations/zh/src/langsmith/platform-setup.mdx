        <h1 class="flex whitespace-pre-wrap group font-semibold text-2xl sm:text-3xl mt-8">设置 LangSmith</h1>

        设置 **LangSmith**，用于[可观测性](/langsmith/observability)、[评估](/langsmith/evaluation)和[prompt engineering](/langsmith/prompt-engineering)。LangSmith 提供两种托管模式：全托管的 Cloud，或用于完全控制的 Self-hosted（Enterprise）。

        如果你同时想在生产环境中部署 agent，可以在任一托管模式下搭配 [**LangSmith Deployment**](/langsmith/deployment) 使用。

        <h2 class="flex whitespace-pre-wrap group font-semibold">比较 Cloud 与 Self-hosted</h2>

        | Feature | **Cloud** | **Self-hosted** |
        |---------|-----------|-----------------|
        | **基础设施位置** | LangChain 的云 | 你的基础设施 |
        | **谁负责更新** | LangChain | 你 |
        | **可观测性数据位置** | LangChain 云 | 你的基础设施 |
        | **是否可与 LangSmith Deployment 搭配** | 是 | 启用 LangSmith Deployment 后可以 |
        | **[Pricing](https://www.langchain.com/pricing)** | Plus tier | Enterprise |
        | **最适合** | 快速搭建、托管基础设施 | 完全控制、数据隔离 |

        两种托管模式都支持将 [LangSmith Deployment](/langsmith/deployment) 用于 agent 工作负载。请参阅 [LangSmith Deployment 概览](/langsmith/deployment) 来选择一种拓扑（Cloud 托管、Hybrid、带 control plane 的 self-hosted 或 standalone）。

        <h2 class="flex whitespace-pre-wrap group font-semibold">常见搭建方式</h2>

        - **最快上手，一切全托管。** [LangSmith Cloud](/langsmith/cloud) 搭配基于 Cloud 的 [LangSmith Deployment](/langsmith/deployment)。LangChain 托管平台，并且当你使用 LangSmith Deployment 时，还会托管你的 [Agent Servers](/langsmith/agent-server)。
        - **可观测性数据必须留在你的基础设施中。** Self-hosted LangSmith，搭配任意 LangSmith Deployment 拓扑，包括用于 agent 工作负载的 [self-hosted LangSmith Deployment](/langsmith/deploy-with-control-plane)。
        - **可观测性托管，agent 在你的 VPC 内。** LangSmith Cloud 搭配 [Hybrid](/langsmith/hybrid) LangSmith Deployment。Trace 和 evaluation 留在 SaaS，而 agent 工作负载留在你的基础设施中。
        - **仅可观测性，不托管 agent。** LangSmith Cloud 或 self-hosted，不使用 LangSmith Deployment。在你已有的应用运行环境中运行 agent，并把 trace 发送到 LangSmith。
