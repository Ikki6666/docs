        <h1 class="flex whitespace-pre-wrap group font-semibold text-2xl sm:text-3xl mt-8">设置 LangSmith</h1>

        本节介绍如何为[可观测性](/langsmith/observability)、[评估](/langsmith/evaluation)和[prompt engineering](/langsmith/prompt-engineering)托管并管理 LangSmith 基础设施。

        <h2 class="flex whitespace-pre-wrap group font-semibold">选择如何设置 LangSmith</h2>

        你可以用以下两种模式之一部署 LangSmith：

        <CardGroup cols={2}>

        <Card
          title="Cloud"
          cta="开始使用"
          href="/langsmith/cloud"
          icon="cloud"
          iconType="solid"
        >
        完全托管的可观测性、评估和 prompt engineering。
        </Card>

        <Card
          title="Self-hosted"
          cta="运行自托管版"
          href="/langsmith/self-hosted"
          icon="server"
          iconType="solid"
        >
        **（Enterprise）** 在你的基础设施中获得对可观测性、评估和 prompt engineering 的完全控制。
        </Card>

        </CardGroup>

        <Callout>
        自托管版仅在 [Enterprise plan](/langsmith/pricing-plans) 中提供。[预约演示](https://www.langchain.com/contact-sales)以了解更多。
        </Callout>

        <h2 class="flex whitespace-pre-wrap group font-semibold">比较 Cloud 与 Self-hosted</h2>

        | Feature | **Cloud** | **Self-hosted** |
        |---------|-----------|-----------------|
        | **基础设施位置** | LangChain 的云 | 你的基础设施 |
        | **谁负责更新** | LangChain | 你 |
        | **能否部署 agents？** | ✅ Yes | ✅ Yes（启用 LangSmith Deployment 后） |
        | **可观测性数据位置** | LangChain 云 | 你的基础设施 |
        | **[Pricing](https://www.langchain.com/pricing)** | Plus tier | Enterprise |
        | **最适合** | 快速搭建、托管基础设施 | 完全控制、数据隔离 |

        <Note>
        如果你想为 [LangSmith Deployment](/langsmith/deployment) 自托管 Agent Servers（即在生产环境中部署并运行 agents），请参阅 [Hybrid](/langsmith/hybrid) 页面。Hybrid 是一种平台搭建方式，它让 Agent Servers 运行在你的基础设施中，同时把 traces 发送到 [Cloud](/langsmith/cloud) 或 [Self-hosted](/langsmith/self-hosted) LangSmith。
        </Note>
