        <h2 class="flex whitespace-pre-wrap group font-semibold">比较 Cloud、BYOC 与 Self-hosted</h2>

        | Feature | **Cloud** | **BYOC** | **Self-hosted** |
        |---------|-----------|----------|-----------------|
        | **谁运行基础设施** | LangChain | LangChain 运行 control plane，你运行 data plane | 你 |
        | **敏感数据存放位置** | LangChain 的云 | 你的 VPC | 你的 VPC |
        | **升级与补丁** | 自动 | 自动 | 手动 |
        | **扩缩容** | 自动 | 自动，由 LangChain 管理 | 手动 |

        Cloud、BYOC 和 Self-hosted 都支持将 [LangSmith Deployment](/langsmith/deployment) 用于 agent 工作负载。请参阅 [LangSmith Deployment 概览](/langsmith/deployment) 来选择一种拓扑（Cloud 托管、BYOC、Hybrid、带 control plane 的 self-hosted 或 standalone）。

        <h2 class="flex whitespace-pre-wrap group font-semibold">常见搭建方式</h2>

        - **最快上手，一切全托管。** [LangSmith Cloud](/langsmith/cloud) 搭配基于 Cloud 的 [LangSmith Deployment](/langsmith/deployment)。LangChain 托管平台，并且当你使用 LangSmith Deployment 时，还会托管你的 [Agent Servers](/langsmith/agent-server)。
        - **Bring Your Own Cloud。** 数据留在你的 VPC 中，基础设施由 LangChain 管理。请参阅 [BYOC 概览](/langsmith/byoc)。
        - **可观测性数据必须留在你的基础设施中。** Self-hosted LangSmith，搭配任意 LangSmith Deployment 拓扑，包括用于 agent 工作负载的 [self-hosted LangSmith Deployment](/langsmith/deploy-with-control-plane)。
        - **可观测性托管，agent 在你的 VPC 内。** LangSmith Cloud 搭配 [Hybrid](/langsmith/hybrid) LangSmith Deployment。Trace 和 evaluation 留在 SaaS，而 agent 工作负载留在你的基础设施中。
        - **仅可观测性，不托管 agent。** LangSmith Cloud 或 self-hosted，不使用 LangSmith Deployment。在你已有的应用运行环境中运行 agent，并把 trace 发送到 LangSmith。
