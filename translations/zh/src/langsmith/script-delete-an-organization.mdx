title: 删除组织

LangSmith UI 目前不支持从 self-hosted LangSmith 实例中删除单独的组织。不过，可以通过直接从 ClickHouse 的所有物化视图，除了 runs_history 视图，以及 runs 和 feedbacks 表中移除所有 traces，然后再从 Postgres 的 tenants 表中删除该 Organization 来完成。

下面这个命令会把 Organization ID 作为参数传入。

### 前置条件

请确保你已经准备好以下工具或信息。

1. kubectl

   * [https://kubernetes.io/docs/tasks/tools/](https://kubernetes.io/docs/tasks/tools/)

2. PostgreSQL client

   * [https://www.postgresql.org/download/](https://www.postgresql.org/download/)

3. PostgreSQL 数据库连接信息：

   * Host
   * Port
   * Username
     * 如果使用 bundled 版本，这里是 `postgres`
   * Password
     * 如果使用 bundled 版本，这里是 `postgres`
   * Database name
     * 如果使用 bundled 版本，这里是 `postgres`

4. Clickhouse 数据库凭证

   * Host
   * Port
   * Username
     * 如果使用 bundled 版本，这里是 `default`
   * Password
     * 如果使用 bundled 版本，这里是 `password`
   * Database name
     * 如果使用 bundled 版本，这里是 `default`

5. 从你将执行迁移脚本的机器，能够连接 PostgreSQL 数据库

   * 如果你使用的是 bundled 版本，可能需要把 postgresql service 做端口转发到本地机器
   * 运行 `kubectl port-forward svc/langsmith-postgres 5432:5432`，把 postgresql service 转发到本地机器

6. 从你将执行迁移脚本的机器，能够连接 Clickhouse 数据库

   * 如果你使用的是 bundled 版本，可能需要把 clickhouse service 做端口转发到本地机器
     * 运行 `kubectl port-forward svc/langsmith-clickhouse 8123:8123`，把 clickhouse service 转发到本地机器
   * 如果你使用的是 Clickhouse Cloud，则需要指定 `--ssl` 标志，并使用 `8443` 端口

7. 用于删除组织的脚本

   * 下载 [delete organization script](https://github.com/langchain-ai/helm/blob/main/charts/langsmith/scripts/delete_organization_sh)

### 为单个组织运行删除脚本

运行以下命令来执行组织删除脚本：

```bash
sh delete_organization.sh <postgres_url> <clickhouse_url> --organization_id <organization_id>
```

例如，如果你使用的是 bundled 版本并通过端口转发连接，那么命令看起来会是这样：

```bash
sh delete_organization.sh "postgres://postgres:postgres@localhost:5432/postgres" "clickhouse://default:password@localhost:8123/default" --organization_id 4ec70ec7-0808-416a-b836-7100aeec934b
```

如果你访问 LangSmith UI，此时应该就能看到该组织已经不存在了。
