## 前置条件

开始之前，请确认：

- 你的 [Organization admin](/langsmith/rbac#organization-admin) 已启用 LLM Gateway，并已把 provider API keys 添加到工作区密钥中。具体设置请参阅[管理员设置](/langsmith/llm-gateway-admin-setup)
- 你拥有一个工作区级别的 [LangSmith API key](/langsmith/create-account-api-key)，并且它关联的角色具备 `gateway:invoke` 和 `workspaces:read` [permissions](/langsmith/organization-workspace-operations)。如果不确定，请咨询你的 org admin

## 1. 设置环境变量

在终端中设置以下环境变量，或者把它们写入 `~/.zshrc` 来持久化：

```bash
export BASE_URL="https://gateway.smith.langchain.com"

export ANTHROPIC_BASE_URL="$BASE_URL/anthropic"
export OPENAI_BASE_URL="$BASE_URL/openai/v1"
export GOOGLE_GEMINI_BASE_URL="$BASE_URL/gemini"

export LANGSMITH_API_KEY="lsv2_..._....cbed3e"

export ANTHROPIC_API_KEY="$LANGSMITH_API_KEY"
export OPENAI_API_KEY="$LANGSMITH_API_KEY"
export GEMINI_API_KEY="$LANGSMITH_API_KEY"
export GOOGLE_API_KEY="$LANGSMITH_API_KEY"
```

这样会把所有 provider SDK 都指向 LangSmith Gateway，并使用你的 LangSmith API key 进行身份验证。gateway 会从你工作区的 Provider Secrets 中解析出真实的 provider keys，因此你本地永远不需要保留 provider API keys。

## 2. 发起调用

<CodeGroup>

```bash curl
curl https://gateway.smith.langchain.com/openai/v1/chat/completions \
    -H "Authorization: Bearer $LANGSMITH_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{"model":"gpt-4o-mini","messages":[{"role":"user","content":"ping"}]}'
```

```python OpenAI SDK
import os

from openai import OpenAI

client = OpenAI(
    base_url=os.environ["OPENAI_BASE_URL"],
    api_key=os.environ["LANGSMITH_API_KEY"],
)
response = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "ping"}],
)
print(response.choices[0].message.content)
```

```python Anthropic SDK
import os

import anthropic

client = anthropic.Anthropic(
    base_url=os.environ["ANTHROPIC_BASE_URL"],
    api_key=os.environ["LANGSMITH_API_KEY"],
)
message = client.messages.create(
    model="claude-sonnet-4-6",
    max_tokens=1024,
    messages=[{"role": "user", "content": "ping"}],
)
print(message.content[0].text)
```

```python LangChain
import os

from langchain.agents import create_agent
from langchain.chat_models import init_chat_model

# Anthropic shown here; OpenAI and Gemini are also supported by swapping base_url and model_provider.
model = init_chat_model(
    model="claude-sonnet-4-6",
    model_provider="anthropic",
    base_url=os.environ["ANTHROPIC_BASE_URL"],
    api_key=os.environ["LANGSMITH_API_KEY"],
)
agent = create_agent(model=model, system_prompt="You are a helpful assistant.")
result = agent.invoke({"messages": [{"role": "user", "content": "ping"}]})
print(result["messages"][-1].content)
```

</CodeGroup>

如果返回 `200` 且包含 chat completion，就说明 gateway、本次 API key 以及你的角色权限都工作正常。

## 3. 查看 trace

打开 [LangSmith UI](https://smith.langchain.com)，进入与你的 API key 关联工作区中的 tracing project，名称通常是 `gateway` 或 `gateway-<short_api_key>-<api_key_id>`。你应该能看到刚才那次调用生成的新 trace。

<Note>
如果你的应用本身也会产出 LangSmith traces，例如通过 [LangChain 或 LangGraph tracing](/langsmith/observability)，那么 gateway 侧 trace 和应用侧 trace 会显示为两个独立 run。当前还不支持把 gateway trace 链接到上层应用 run。
</Note>

## 4. 设置支出策略，可选

前往 LangSmith 中的 **Settings → Gateway → LLM Gateway**，创建一条支出策略。例如，你可以为 API key 设置每日 10 美元的上限。当达到上限时，gateway 会返回 `402` 响应，并带有如下消息：`"Request blocked by gateway policies: R&D Spend Cap"`。

关于策略维度、时间窗口和冲突处理的完整说明，请参阅[支出策略](/langsmith/llm-gateway-spend-policies)。

## Gateway 如何处理请求

你发起调用时，gateway 实际做了以下事情：

1. **Authenticated**：使用 LangSmith API key 对请求进行身份验证
1. **Resolved**：从工作区的 Provider Secrets 中解析出真实的 provider API key，例如 `OPENAI_API_KEY`
1. **Evaluated**：检查所有已启用的策略，例如支出上限、PII 脱敏、密钥脱敏
1. **Proxied**：把请求转发给上游 provider
1. **Traced**：将本次调用记录到 LangSmith，包括 token 数量、成本和相关策略事件

通过 gateway 路由请求，不需要修改应用代码。
