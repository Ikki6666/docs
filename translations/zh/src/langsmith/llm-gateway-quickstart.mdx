<Note>
**Beta：**LLM Gateway 当前处于 [beta](/langsmith/release-stages) 阶段。
</Note>

LLM Gateway 让你可以通过一个标准 endpoint，使用一个 LangSmith API key 调用多家已配置 provider 的模型。本快速开始使用 OpenAI Chat Completions 格式来调用 Anthropic 模型。

## 前置条件

开始之前，请确认：

- 你的 [Organization admin](/langsmith/rbac#organization-admin) 已启用 LLM Gateway。对于 bring-your-own-key 模型，管理员还需要把 provider API key 添加到工作区密钥中。具体设置请参阅[管理员设置](/langsmith/llm-gateway-admin-setup)。
- 你拥有一个工作区级别的 [LangSmith API key](/langsmith/create-account-api-key)，并且它关联的角色具备 `gateway:invoke` 和 `workspaces:read` [permissions](/langsmith/organization-workspace-operations)。如果不确定，请咨询你的 organization admin。

你可以在没有 provider secret 的情况下调用 [Gateway Credits 模型](/langsmith/llm-gateway-credits)。下面的示例使用一个 bring-your-own-key 的 Anthropic 模型。

## 1. 设置环境变量

设置标准 gateway base URL 和你的 LangSmith API key：

```bash
export LANGSMITH_GATEWAY_BASE_URL="https://gateway.smith.langchain.com/v1"
export LANGSMITH_API_KEY="lsv2_..._....cbed3e"
```

统一的 base URL 接受带 provider 前缀的 bring-your-own-key model ID（例如 `anthropic/claude-opus-5`）和托管 model slug（例如 `moonshotai/kimi-k3`）。model ID 决定上游路由。

<Note>
如果你的 LangSmith 账号位于区域实例，请使用对应的[区域 gateway](/langsmith/llm-gateway-api-formats#use-a-regional-gateway)。
</Note>

如果你希望保留 provider 的原生 API 而不做格式转换，请改用[直接 provider 路由](/langsmith/llm-gateway-direct-model-access)。

### 使用 LangChain 和 Deep Agents

[LangChain](/oss/langchain/overview) chat models 和 [Deep Agents](/oss/deepagents/overview)（包括 [Deep Agents Code](/oss/deepagents/code/overview)）通过两个便捷环境变量支持 gateway：

<CodeGroup>

```bash Bash
export LANGSMITH_GATEWAY="true"
export LANGSMITH_GATEWAY_API_KEY="$LANGSMITH_API_KEY"
```

```python Python
import os

os.environ["LANGSMITH_GATEWAY"] = "true"
os.environ["LANGSMITH_GATEWAY_API_KEY"] = os.environ["LANGSMITH_API_KEY"]
```

</CodeGroup>

这会把所有受支持的 chat models 通过 `https://gateway.smith.langchain.com` 的 gateway 路由。要使用其他 gateway（例如 EU 实例），请将其 URL 设置为 `true` 以外的值：

```bash
export LANGSMITH_GATEWAY="https://eu.gateway.smith.langchain.com"
export LANGSMITH_GATEWAY_API_KEY="$LANGSMITH_API_KEY"
```

<Note>
如果 gateway 已启用但 `LANGSMITH_GATEWAY_API_KEY` 未设置，gateway 会回退到 `LANGSMITH_API_KEY`。
</Note>

你还可以为各个 provider 单独配置 base URL 和 API key。关于 provider 支持以及与 provider 专属环境变量的交互，请参见下方的 accordion。

## 2. 发起调用

<CodeGroup>

```bash cURL
curl "$LANGSMITH_GATEWAY_BASE_URL/chat/completions" \
    -H "Authorization: Bearer $LANGSMITH_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{"model":"anthropic/claude-opus-5","messages":[{"role":"user","content":"ping"}]}'
```

```python OpenAI SDK
import os

from openai import OpenAI

client = OpenAI(
    base_url=os.environ["LANGSMITH_GATEWAY_BASE_URL"],
    api_key=os.environ["LANGSMITH_API_KEY"],
)
response = client.chat.completions.create(
    model="anthropic/claude-opus-5",
    messages=[{"role": "user", "content": "ping"}],
)
print(response.choices[0].message.content)
```

```typescript OpenAI SDK (TypeScript)
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: process.env.LANGSMITH_GATEWAY_BASE_URL,
  apiKey: process.env.LANGSMITH_API_KEY,
});
const response = await client.chat.completions.create({
  model: "anthropic/claude-opus-5",
  messages: [{ role: "user", content: "ping" }],
});
console.log(response.choices[0].message.content);
```

```python LangChain
import os

from langchain.agents import create_agent
from langchain.chat_models import init_chat_model

model = init_chat_model(
    model="anthropic/claude-opus-5",
    model_provider="openai",
    base_url=os.environ["LANGSMITH_GATEWAY_BASE_URL"],
    api_key=os.environ["LANGSMITH_API_KEY"],
)
agent = create_agent(model=model, system_prompt="You are a helpful assistant.")
result = agent.invoke({"messages": [{"role": "user", "content": "ping"}]})
print(result["messages"][-1].content)
```

</CodeGroup>

如果返回 `200` 且包含 chat completion，就说明 gateway、你的 API key、角色权限以及所选模型路由都工作正常。

## 3. 查看 trace

打开 [LangSmith UI](https://smith.langchain.com)，进入与你的 API key 关联工作区中的 tracing project，名称通常是 `gateway` 或 `gateway-<short_api_key>-<api_key_id>`。你应该能看到刚才那次调用生成的新 trace。

<Note>
如果你的应用本身也会产出 LangSmith traces（例如通过 [LangChain 或 LangGraph tracing](/langsmith/observability)），那么 gateway 侧 trace 和应用侧 trace 会显示为两个独立 run。当前还不支持把 gateway trace 链接到上层应用 run。
</Note>

## 4. 设置支出策略，可选

前往 LangSmith 中的 **Settings → Gateway → LLM Gateway**，创建一条支出策略。例如，你可以为 API key 设置每日 10 美元的上限。当达到上限时，gateway 会返回 `402` 响应，并带有如下消息：`"Request blocked by gateway policies: R&D Spend Cap"`。

关于策略维度、时间窗口和冲突处理的完整说明，请参阅[支出策略](/langsmith/llm-gateway-spend-policies)。

## Gateway 如何处理请求

gateway 对每个标准 endpoint 请求会执行以下步骤：

1. **Authenticates**：使用 LangSmith API key 对请求进行身份验证
1. **Selects**：根据 model ID 选择托管模型或已配置的 bring-your-own-key provider
1. **Resolves**：解析上游凭据。托管模型使用 Gateway Credits，bring-your-own-key 模型使用工作区 Provider Secrets
1. **Evaluates**：检查所有已启用的策略，包括支出上限、PII 脱敏、密钥脱敏
1. **Translates**：当所选 provider 使用不同的 API 格式时，对请求和响应进行转换
1. **Traces**：将本次调用记录到 LangSmith，包括 token 数量、成本和相关策略事件
