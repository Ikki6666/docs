Service URLs 让你无需 tunnel、端口转发或 CLI 工具，就能访问运行在 sandbox 内部的 HTTP 服务，例如 REST API、Streamlit 应用、Jupyter notebook 或 API 文档。每个 sandbox + port 组合都会得到一个独立 URL，你可以在浏览器中打开、在代码里调用，或者直接分享给队友。

![Service URLs view](/images/langsmith/sandboxes/sb-service-feature.png)

## Quick start

先在 sandbox 内启动一个 HTTP server，再获取可访问它的 URL：

```python
from langsmith.sandbox import SandboxClient

client = SandboxClient()

with client.sandbox() as sb:
    handle = sb.run("python -m http.server 8000", timeout=0, wait=False)

    svc = sb.service(port=8000)

    # Open in a browser
    print(svc.browser_url)

    # Or make requests programmatically
    resp = svc.get("/")
    print(resp.status_code)

    handle.kill()
```

## Use cases

| Scenario | How |
|----------|-----|
| 预览 Web 应用（Streamlit、Jupyter 等） | `sb.service(port=<PORT>)`，然后打开 `browser_url` |
| 从代码或 CI 中调用 API | `svc.get(...)` / `svc.post(...)`，或者带上 service token 的 `curl` |
| 和队友分享一个在线演示 | 在 UI 中点击 **Share Link**，然后把 URL 发给对方 |

## 从 UI 打开一个 service

1. 打开 sandbox 详情页。
2. 找到 **Open service** 组件。
3. 输入端口号，例如 `3000`。
4. 点击 **Open** 在新标签页中打开，或者点击 **Share Link** 复制一个可发送给队友的 URL。

任何拿到该链接的人都可以访问这个 service，即使对方没有 LangSmith 账号。等 token 过期后，可以在 UI 中重新生成新链接。

## 从 SDK 打开一个 service

### 获取 service URL

在 sandbox 实例上，或者直接在 client 上调用 `service()`：

```python
svc = sb.service(port=3000)

# Or from the client, by sandbox name
svc = client.service("my-sandbox", port=3000)

# Customize token lifetime (default: 10 minutes, max: 24 hours)
svc = sb.service(port=3000, expires_in_seconds=3600)
```

<Note>
在你请求 service URL 之前，该 service 必须已经启动，并且正在指定端口上监听。这个 URL 只负责转发流量，不会替你启动服务。
</Note>

### 发起请求

返回的 `ServiceURL` 对象内置了 HTTP helper，并会自动处理认证。token 会在过期前透明刷新，因此不需要手动管理。

```python
svc = sb.service(port=8000)

resp = svc.get("/api/items")
resp = svc.post("/api/items", json={"name": "widget"})
resp = svc.put("/api/items/1", json={"name": "updated"})
resp = svc.patch("/api/items/1", json={"status": "active"})
resp = svc.delete("/api/items/1")
```

### 使用你自己的 HTTP client

如果你更喜欢其他 HTTP client，可以直接使用原始 URL 和 token：

```python
import httpx

svc = sb.service(port=8000)

resp = httpx.get(
    svc.service_url + "api/items",
    headers={"X-Langsmith-Sandbox-Service-Token": svc.token},
)
```

### 在浏览器中打开

使用 `browser_url` 可以在浏览器中打开该 service。它会自动设置认证 cookie，因此后续页面加载、图片请求和 API 调用都能完成认证，而不需要把 token 放在 URL 中。

```python
svc = sb.service(port=8000)
print(svc.browser_url)
```

你可以把这个 URL 直接分享给队友。访问它不需要登录 LangSmith。

### 通过 REST API 生成 URL

```bash
curl -X POST \
  "$LANGSMITH_ENDPOINT/api/v2/sandboxes/boxes/{sandbox_name}/service-url" \
  -H "x-api-key: $LANGSMITH_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"port": 3000, "expires_in_seconds": 3600}'
```

响应：

```json
{
  "browser_url": "https://{sandbox-id}--3000.smithbox.dev/_svc/auth?token=ey...",
  "service_url": "https://{sandbox-id}--3000.smithbox.dev/",
  "token": "ey...",
  "expires_at": "2026-04-08T15:30:00Z"
}
```

## 示例：提供一个 FastAPI 应用

```python
from langsmith.sandbox import SandboxClient

client = SandboxClient()

with client.sandbox() as sb:
    sb.write("/app/main.py", """
from fastapi import FastAPI

app = FastAPI()
items = []

@app.get("/items")
def list_items():
    return items

@app.post("/items")
def create_item(item: dict):
    items.append(item)
    return item
""")

    sb.run("pip install fastapi uvicorn", timeout=120)
    handle = sb.run(
        "uvicorn main:app --host 0.0.0.0 --port 8000",
        timeout=0,
        wait=False,
        env={"PYTHONPATH": "/app"},
    )

    import time
    time.sleep(3)

    svc = sb.service(port=8000)

    svc.post("/items", json={"name": "widget", "price": 9.99})
    svc.post("/items", json={"name": "gadget", "price": 24.99})

    resp = svc.get("/items")
    print(resp.json())
    # [{"name": "widget", "price": 9.99}, {"name": "gadget", "price": 24.99}]

    # Open the auto-generated API docs in a browser
    print(svc.browser_url)

    handle.kill()
```

## Service URLs 与 TCP tunnels 的区别

| | Service URLs | TCP tunnels |
|---|---|---|
| **Protocol** | HTTP | 任意 TCP（数据库、Redis、SSH、HTTP） |
| **Setup** | 零配置，只需要一个 URL | 需要 SDK 或 CLI |
| **Access from** | 浏览器、脚本、CI、任意位置 | 仅限本地机器 |
| **Sharing** | 复制 URL 即可分享 | 无法分享 |
| **Multi-page web apps** | 完整支持（子域名路由） | 完整支持（本地端口） |
| **Non-HTTP services** | 不支持 | 完整支持 |

如果你要访问的是 HTTP 服务，并且希望在浏览器中打开或分享给他人，请使用 **service URLs**。如果你处理的是非 HTTP 协议（例如 `psql` 或 `redis-cli`），或只需要本地访问，请使用 **[TCP tunnels](/langsmith/sandbox-sdk#tcp-tunnels-python)**。

## Troubleshoot

| Error | Cause | Fix |
|-------|-------|-----|
| **"Service link has expired"** | token 生命周期已到期 | 在 LangSmith 中重新打开该 service，或调用 `sb.service()` 生成新 URL |
| **"Service is not reachable"** | 该端口上没有服务在监听 | 确认 server 已在 sandbox 内启动 |
| **"Authentication required"** | header 或 cookie 中没有 token | 浏览器访问请使用 `browser_url`，或手动设置 `X-Langsmith-Sandbox-Service-Token` header |
