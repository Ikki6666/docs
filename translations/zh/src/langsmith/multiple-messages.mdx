本 how-to 指南将带你了解在 Playground 中设置多轮对话的多种方式，这样你就可以在更长的消息线程中测试不同的工具配置和系统 prompts。

![Multiturn diagram](/langsmith/images/multiturn-diagram.png)

## From an existing run

首先，确保你已经正确地为一段多轮对话进行了[traced](/langsmith/observability)，然后进入你的 tracing project。进入后，打开对应 run，选择 LLM call，并按如下方式在 Playground 中打开它：

![Multiturn from run](/langsmith/images/multiturn-from-run.gif)

然后你就可以编辑 system prompt、调整 tools 和/或 output schema，并观察多轮对话输出会如何变化。

## From a dataset

开始前，请先确保你已经[设置好 dataset](/langsmith/manage-datasets-in-application)。由于你要评估多轮对话，因此请确认 inputs 中有一个键包含消息列表。

创建好 dataset 后，进入 Playground，并[加载你的 dataset](/langsmith/manage-datasets-in-application#from-the-playground)以开始评估。

然后，在 prompt 中添加一个 messages list 变量，并确保它的名称与 inputs 中包含消息列表的那个键一致：

![Multiturn from dataset](/langsmith/images/multiturn-from-dataset.gif)

当你运行 prompt 时，每个 example 中的 messages 都会以列表形式填入 `'Messages List'` 变量所在的位置。

## Manually

手动创建多轮对话有两种方式。第一种方式是直接在 prompt 中追加消息：

![Multiturn manual](/langsmith/images/multiturn-manual.gif)

这种方式适合快速迭代，但不够灵活，因为多轮对话内容被硬编码了。另一种方式是添加一个 `'Messages List'` 变量，并将你的多轮对话填入其中：

![Multiturn manual list](/langsmith/images/multiturn-manual-list.gif)

这样你就只需调整 system prompt 或 tools，而让任意多轮对话都可以填入 `Messages List` 变量，从而让这个 prompt 能在不同 runs 之间复用。

## Next steps

现在你已经知道如何在 Playground 中设置多轮交互，你可以手动检查并判断输出结果，或者你也可以[添加 evaluators](/langsmith/code-evaluator-ui) 来对结果进行分类。

你还可以阅读[这些 how-to 指南](/langsmith/create-a-prompt)，以进一步了解如何使用 Playground 运行评估。
