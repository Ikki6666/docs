Tool Gateway API 用于配置 [Tool Gateway](/langsmith/tool-gateway)，并通过它发送 MCP 调用。每个路径都以 `/v1/managed-tools` 开头。

## Base URL

将请求发送到你所在 LangSmith 区域的 API 主机：

<SaasRegionUrls azure={false} />

Tool Gateway 不在 Azure US 区域提供。

在每个端点的 playground 的服务器菜单中选择你的区域。

在侧边栏的 **Tool Gateway API** 部分浏览完整 API 参考。它包含两类端点：

- **管理端点**用于配置 Tool Gateway：`/servers` 添加并列出 MCP 服务器，`/servers/{id}/credential` 管理你为某个服务器使用的凭证，`/kits` 管理工具包，`/profiles` 管理 profiles，`/oidc-connection` 关联你的身份提供商。
- **MCP 端点**使用标准 MCP 方法（如 `tools/list` 和 `tools/call`）列出并调用工具：`/servers/{id}/mcp` 暴露一个服务器，`/kits/{kit_id}/mcp` 暴露一个工具包。

## 认证

在 `X-Api-Key` 请求头中发送 LangSmith API 密钥，或在 `Authorization: Bearer` 请求头中发送令牌。在 `X-Tenant-Id` 请求头中发送工作区 ID。`X-Tenant-Id` 用于选择工作区；它不会对你进行身份验证。

要以最终用户、agent 或 profile 的身份调用工具，请参见[以用户和 agent 的身份调用](/langsmith/tool-gateway-identity)。

必须为你的组织启用 Tool Gateway。每个端点都会列出其所需的工作区权限。
