这个 Helm 仓库中包含了一些查询，用于生成当前 LangSmith UI 尚不直接支持的输出（例如获取 Clickhouse 的 query exception logs）。

该命令接受一个 Clickhouse 连接字符串，其中嵌入了用户名和密码（这些可以通过 secrets manager 调用传入），然后执行某个输入文件中的查询。在下方示例中，我们使用的是 `support_queries/clickhouse` 目录里的 `ch_get_query_exceptions.sql` 输入文件。

### Prerequisites

请确保你准备好以下工具或信息：

1. kubectl

   * [https://kubernetes.io/docs/tasks/tools/](https://kubernetes.io/docs/tasks/tools/)

2. Clickhouse 数据库凭据

   * Host
   * Port
   * Username
     * 如果使用 bundled 版本，这里是 `default`
   * Password
     * 如果使用 bundled 版本，这里是 `password`
   * Database name
     * 如果使用 bundled 版本，这里是 `default`

3. 你运行该迁移脚本的机器需要能够连接到 Clickhouse 数据库。

   * 如果你使用 bundled 版本，可能需要先把 clickhouse service 端口转发到本地机器。
   * 运行 `kubectl port-forward svc/langsmith-clickhouse 8123:8123`，即可将 clickhouse service 端口转发到本地机器。

4. 用于运行 support query 的脚本

   * 下载 [ClickHouse support query script](https://github.com/langchain-ai/helm/blob/main/charts/langsmith/scripts/run_support_query_ch.sh)

### Running the query script

运行以下命令即可执行目标查询：

```bash
sh run_support_query_ch.sh <clickhouse_url> --input path/to/query.sql
```

例如，如果你使用 bundled 版本并配合 port-forwarding，命令可能类似这样：

```bash
sh run_support_query_ch.sh "clickhouse://default:password@localhost:8123/default" --input support_queries/clickhouse/ch_get_query_exceptions.sql
```

这会输出过去 7 天内在 Clickhouse 中抛出异常的所有查询日志。若要将结果保存到文件中，可加上 `--output path/to/file.csv` 参数。
