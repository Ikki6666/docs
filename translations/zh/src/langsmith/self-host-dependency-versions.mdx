本页列出了自托管 LangSmith 所使用的数据库、工具和基础设施的最低支持版本。在部署或升级前，请安装满足或高于最低要求的版本。低于最低要求的版本不受支持，可能导致安装或运行时失败。

<Tip>
如果你使用的是托管服务（例如 Amazon RDS、Google Cloud SQL 或 Azure Database），请选择不低于本页列出的最低版本。有关连接和认证细节，请参阅对应的 “External services” 页面。
</Tip>

## Datastores

| Dependency | Minimum version | Notes |
|------------|------------------|-------|
| [PostgreSQL](/langsmith/self-host-external-postgres) | 14 | 运行时数据的主关系型存储。LangSmith 和独立 Agent Server deployments 都需要它。用于安装 `btree_gin`、`btree_gist`、`pgcrypto`、`citext`、`ltree` 和 `pg_trgm` 扩展。 |
| [Redis](/langsmith/self-host-external-redis) | 5 | 用于队列和缓存。支持 Standalone 和 Redis Cluster 模式。 |
| [Valkey](/langsmith/self-host-external-redis) | 8 | 官方支持作为 Redis 的 drop-in replacement。支持 Standalone 和 Cluster 模式。 |
| [ClickHouse](/langsmith/self-host-external-clickhouse) | [LangSmith Helm chart](https://github.com/langchain-ai/helm/releases) 中指定的版本或更高 | 用于存储 traces 和 feedback。ClickHouse 版本 >= 24.2 需要 LangSmith v0.6 或更高。**不支持降级**。 |

<Warning>
**不支持 Redis < 5 和 PostgreSQL < 14。** 如果 LangSmith 安装实例连接到了更低版本的 Redis 或 PostgreSQL，可能会启动失败或出现不可预测的行为。请先升级 datastore，再安装或升级 LangSmith。
</Warning>

## Compute and orchestration

| Dependency | Minimum version | Notes |
|------------|------------------|-------|
| [Kubernetes](/langsmith/kubernetes) | [upstream Kubernetes release cycle](https://kubernetes.io/releases/) 当前支持的任意版本 | LangSmith 会定期在 GKE、EKS、AKS、Minikube 和 Kind 上进行测试。 |
| [OpenShift](/langsmith/kubernetes) | 4.14 | 作为 LangSmith 支持的 Kubernetes 发行版。 |
| [Helm](https://helm.sh/docs/intro/install/) | 3 | 用于安装和升级 LangSmith Helm chart。 |
| Docker | 与 [Docker Compose v2](https://docs.docker.com/compose/) 兼容的版本 | Docker 方式部署独立 Agent Server 时需要。 |

## LangSmith chart and platform

| Dependency | Minimum version | Notes |
|------------|------------------|-------|
| [LangSmith Helm chart](https://github.com/langchain-ai/helm/releases) | 最新稳定版本 | 建议固定到最新稳定 chart 版本。每个版本的升级说明请参阅 [self-hosted changelog](/langsmith/self-hosted-changelog)。 |
| 到 `https://beacon.langchain.com` 的 Egress | LangSmith 0.9.0 或更高 | 用于 license 校验和用量上报，除非你运行在[离线模式](/langsmith/self-host-egress)。 |

## Where these versions are enforced

- PostgreSQL `>= 14`：请参阅 [Connect to an external PostgreSQL database](/langsmith/self-host-external-postgres#requirements)。
- Redis `>= 5` 和 Valkey `8`：请参阅 [Connect to an external Redis or Valkey database](/langsmith/self-host-external-redis#requirements)。
- ClickHouse：使用 [LangSmith Helm chart](https://github.com/langchain-ai/helm/releases) 中指定的版本或更高版本。请参阅 [Connect to an external ClickHouse database](/langsmith/self-host-external-clickhouse#requirements)。
- Kubernetes 集群前置要求：请参阅 [Self-host LangSmith on Kubernetes](/langsmith/kubernetes#prerequisites)。

如果你不确定当前运行的是哪个版本，请联系数据库管理员，或查看云服务提供商控制台。如果你需要先升级某个依赖，再升级 LangSmith，请参阅对应厂商的文档。
