---
title: 创建 deployment
description: 从 LangSmith UI 或 LangGraph CLI 创建 LangSmith Cloud deployment。
---

你可以从已连接的 GitHub 仓库或直接从本地项目创建 Cloud deployment。LangSmith UI 从 GitHub 部署，而 `langgraph deploy` CLI 则从本地机器构建并推送。

<Callout icon="bolt" color="#4F46E5" iconType="regular">
如需更简短的说明，请参阅[deployment 快速开始](/langsmith/deployment-quickstart)。
</Callout>

## 前置条件

- 一个 [Plus plan 或更高版本](https://www.langchain.com/pricing) 的 LangSmith 账户。
- 一个可以在本地通过 `langgraph dev` 运行的应用。详情请参阅[本地开发与测试](/langsmith/local-dev-testing)。

## 创建 deployment

<Tabs>
  <Tab title="LangSmith UI">
    GitHub organization owner 或 admin 必须一次性为 workspace 授权 LangChain 的 `hosted-langserve` GitHub app。授权后，任何拥有部署权限的用户都可以从该 app 可访问的仓库创建 deployments。

    创建 deployment 的方法如下：

    1. 在 [LangSmith UI](https://smith.langchain.com) 中选择 **Deployments**。
    1. 在右上角选择 **+ New Deployment**。
    1. 选择 **Import from GitHub**，如果出现提示则完成 GitHub 授权流程。
    1. 选择一个仓库。
    1. 输入 deployment 名称。
    1. 选择要部署的 **Git Branch**。
    1. 输入 [LangGraph API 配置文件](/langsmith/cli#configuration-file) 的完整路径，包括文件名。例如，如果文件位于仓库根目录，请输入 `langgraph.json`。
    1. 选择是否开启 **Automatically update deployment on push to branch**。你之后可以在[Deployment Settings](/langsmith/manage-deployment#configure-deployment-settings)中更改此项设置。
    1. 选择 deployment 类型：
       - **Serverless**：非常适合后台、开发、测试和预览工作负载。有关缩容到零的可用性，请参阅[Serverless deployments](/langsmith/cloud-platform-features#serverless)。
       - **Dedicated**：为生产工作负载提供始终在线的基础设施、高可用性和自动数据库备份。
    1. 选择是否通过 [Studio](/langsmith/studio) 共享该 deployment。
    1. 添加环境变量和 secrets。详情请参阅[环境变量](/langsmith/env-var-cloud)。
    1. 选择 **Submit**。LangSmith 会将 deployment 加入 provisioning 队列，并创建一个同名的 tracing project。

    <Note>
    授权 `hosted-langserve` app 的 GitHub 用户必须是该 GitHub organization 或账户的 owner。完成首次授权后，其他拥有部署权限的用户不再需要 GitHub 管理员权限。
    </Note>
  </Tab>
  <Tab title="LangGraph CLI">
    <Note>
    `langgraph deploy` 命令当前处于[beta](/langsmith/release-stages)。它需要 Docker。在 Apple silicon 上，还需要 Docker Buildx 来交叉编译 `linux/amd64`。
    </Note>

    创建 deployment 的方法如下：

    1. 安装 [LangGraph CLI](/langsmith/cli)：

       ```shell
       uv tool install langgraph-cli
       ```

    1. 在项目根目录的 `.env` 文件中添加 LangSmith API key：

       ```shell
       LANGSMITH_API_KEY=lsv2_...
       ```

    1. 运行：

       ```shell
       langgraph deploy
       ```

       该命令会创建一个以项目目录命名的 Serverless deployment。若要设置其他名称或 deployment 类型，请传入相应的选项：

       ```shell
       langgraph deploy --name my-agent --deployment-type dedicated
       ```

       <Note>
       使用旧版定价的组织在 2026 年 10 月 1 日之前使用 `--deployment-type prod` 或 `--deployment-type dev`。详情请参阅[`langgraph deploy`](/langsmith/cli#deploy) 和 [Manage billing](/langsmith/billing#langsmith-deployment-billing)。
       </Note>

    LangSmith 会将 deployment 加入 provisioning 队列。你可以在 LangSmith UI 中管理环境变量，也可以在[`langgraph.json` 的 `env` 字段](/langsmith/cli#configuration-file)中配置。
  </Tab>
</Tabs>

## 管理 GitHub 仓库访问权限

完成 `hosted-langserve` GitHub app 授权后，配置它可以访问哪些仓库：

1. 在 GitHub 中，进入 **Settings** > **Applications**。
1. 找到 `hosted-langserve`，然后选择 **Configure**。
1. 在 **Repository access** 下，选择 **All repositories** 或 **Only select repositories**。
1. 如果你选择了 **Only select repositories**，请根据需要添加或移除仓库。
1. 选择 **Save**。

**Create New Deployment** 面板中的仓库列表会反映更新后的访问权限。
