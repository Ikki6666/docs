运行多次 repetitions 能更准确地估计系统性能，因为 LLM 输出并不是确定性的。不同 repetition 之间的输出可能不同。对于像 agents 这样波动较大的系统，repetitions 是降低噪声的一种方式。

## Configuring repetitions on an experiment

向 `evaluate` / `aevaluate` 函数添加可选的 `num_repetitions` 参数（[Python](https://docs.smith.langchain.com/reference/python/evaluation/langsmith.evaluation._runner.evaluate)，[TypeScript](https://docs.smith.langchain.com/reference/js/interfaces/evaluation.EvaluateOptions#numrepetitions)），即可指定对 dataset 中每个 example 评估多少次。例如，如果 dataset 中有 5 个 examples，并设置 `num_repetitions=5`，那么每个 example 会运行 5 次，总共得到 25 次 runs。

<CodeGroup>

```python Python
from langsmith import evaluate

results = evaluate(
    lambda inputs: label_text(inputs["text"]),
    data=dataset_name,
    evaluators=[correct_label],
    experiment_prefix="Toxic Queries",
    num_repetitions=3,
)
```

```typescript TypeScript
import { evaluate } from "langsmith/evaluation";

await evaluate((inputs) => labelText(inputs["input"]), {
  data: datasetName,
  evaluators: [correctLabel],
  experimentPrefix: "Toxic Queries",
  numRepetitions: 3,
});
```

</CodeGroup>

## Viewing results of experiments run with repetitions

如果你的 experiment 是通过 [repetitions](/langsmith/repetition) 运行的，那么输出结果列中会出现箭头，方便你在表格中查看多个输出。要查看每次 repetition 的 run，请悬停在输出单元格上并点击展开视图。运行带 repetitions 的 experiment 时，LangSmith 会在表格中显示每个反馈分数的平均值。点击某个反馈分数，可以查看单独每次 run 的反馈分数，或查看 repetitions 之间的标准差。
