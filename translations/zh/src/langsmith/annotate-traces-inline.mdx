---
title: 直接在界面中标注 traces 和 runs
sidebarTitle: 直接在界面中标注 traces 和 runs
---

LangSmith 允许你在应用内通过反馈手动标注 traces。这对于给 trace 添加上下文很有帮助，例如用户评论或某个具体问题的备注。
你既可以直接在界面中标注 trace，也可以将 trace 发送到 annotation queue，从而逐条检查并记录 runs 上的反馈。
反馈标签与你的 [workspace](/langsmith/administration-overview#workspaces) 相关联。

<Note>
**你可以将用户反馈附加到 trace 的任意中间 run（span）上，而不仅仅是根 span。**

这对于评审 LLM 应用中的特定部分很有用，例如 RAG pipeline 的 retrieval 步骤或 generation 步骤。

</Note>

要直接标注 trace，请在 trace 视图中打开任意属于该 trace 的 run 的三点菜单（`...`），然后点击 **Notes**。


这会打开一个面板，你可以从与 workspace 关联的反馈标签中进行选择，并为特定标签添加分数。你还可以添加一条独立评论。请按照 [Set up feedback criteria](/langsmith/set-up-feedback-criteria) 为你的 workspace 设置反馈标签。
你也可以直接在这个面板内创建新的反馈标准。

![Annotation sidebar](/langsmith/images/annotation-sidebar.png)

你可以使用标注出的键盘快捷键来加快标注流程。
