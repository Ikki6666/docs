自定义输出渲染允许你使用自己的自定义 HTML 页面来可视化 run outputs 和 dataset reference outputs。这在以下场景中特别有用：

-   **领域专用格式化**：以原生格式显示病历、法律文书或其他专业化数据类型。
-   **自定义可视化**：从数值型或结构化输出数据中创建图表、图形或示意图。

本页会介绍如何：

-   在 LangSmith UI 中**[配置自定义渲染](#configure-custom-output-rendering)**。
-   **[构建一个自定义 renderer](#build-a-custom-renderer)** 来显示输出数据。
-   **[理解自定义渲染会出现在哪里](#where-custom-rendering-appears)**。

## 配置自定义输出渲染

你可以在两个层级配置自定义渲染：

-   **For datasets**：将自定义渲染应用到与该 dataset 关联的所有 runs，无论它们出现在哪儿，例如 experiments、run detail panes 或 annotation queues。
-   **For annotation queues**：将自定义渲染应用到某个特定 annotation queue 中的所有 runs，无论它们来自哪个 dataset。这个层级的优先级高于 dataset 级配置。

### For tracing projects

若要为 tracing project 配置自定义输出渲染：

![Tracing project settings showing custom output rendering configuration](/langsmith/images/tracing-project-custom-output-rendering-settings.png)

1. 前往 **Tracing Projects** 页面。
2. 点击一个已有 tracing project，或新建一个。
3. 在编辑 tracing project 的面板中，滚动到 **Custom Output Rendering** 部分。
4. 打开 **Enable custom output rendering** 开关。
5. 在 **URL** 字段中输入网页地址。
6. 点击 **Save**。

### For datasets

若要为 dataset 配置自定义输出渲染：

![Dataset page with three-dot menu showing Custom Output Rendering option](/langsmith/images/custom-output-rendering-menu.png)

1. 在 **Datasets & Experiments** 页面中进入你的 dataset。
2. 点击右上角的 **⋮**（三点菜单）。
3. 选择 **Custom Output Rendering**。
4. 打开 **Enable custom output rendering** 开关。
5. 在 **URL** 字段中输入网页地址。
6. 点击 **Save**。

![Custom Output Rendering modal with fields filled in](/langsmith/images/custom-output-rendering-modal.png)

### For annotation queues

若要为 annotation queue 配置自定义输出渲染：

![Annotation queue settings showing custom output rendering configuration](/langsmith/images/annotation-queue-custom-output-rendering-settings.png)

1. 前往 **Annotation Queues** 页面。
2. 点击一个已有 annotation queue，或新建一个。
3. 在 annotation queue settings 面板中，滚动到 **Custom Output Rendering** 部分。
4. 打开 **Enable custom output rendering** 开关。
5. 在 **URL** 字段中输入网页地址。
6. 点击 **Save** 或 **Create**。

<Info>当多个层级同时配置了自定义渲染时，优先级顺序为：annotation queue > dataset > tracing project。</Info>

## 构建自定义 renderer

### 理解消息格式

你的 HTML 页面会通过 [postMessage API](https://developer.mozilla.org/en-US/docs/Web/API/Window/postMessage) 接收输出数据。LangSmith 发送的消息结构如下：

```typescript
{
  type: "output" | "reference",
  data: {
    // The outputs (actual output or reference output)
    // Structure varies based on your application
  },
  metadata: {
    inputs: {
      // The inputs that generated this output
      // Structure varies based on your application
    }
  }
}
```

-   `type`：表示这是实际输出（`"output"`）还是参考输出（`"reference"`）。
-   `data`：输出数据本身。
-   `metadata.inputs`：生成该输出的输入数据，用于提供上下文。

<Note>**消息投递时机**：LangSmith 使用指数退避重试机制，确保即使你的页面加载较慢，也能收到数据。消息最多会发送 6 次，延迟依次增加（100ms、200ms、400ms、800ms、1600ms、3200ms）。</Note>

### 示例实现

下面的示例会监听进入的 postMessage 事件，并将其显示在页面上。每条消息都会编号，并以 JSON 格式呈现，方便你检查 LangSmith 发送给 renderer 的数据结构。

```html
<!DOCTYPE html>
<html>
    <head>
        <meta charset="UTF-8" />
        <title>PostMessage Echo</title>
        <link rel="stylesheet" href="https://unpkg.com/sakura.css/css/sakura.css" />
    </head>
    <body>
        <h1>PostMessage Messages</h1>
        <div id="messages"></div>
        <script>
            let count = 0;
            window.addEventListener("message", (event) => {
                count++;
                const header = document.createElement("h3");
                header.appendChild(document.createTextNode(`Message ${count}`));
                const code = document.createElement("code");
                code.appendChild(document.createTextNode(JSON.stringify(event.data, null, 2)));
                const pre = document.createElement("pre");
                pre.appendChild(code);
                document.getElementById("messages").appendChild(header);
                document.getElementById("messages").appendChild(pre);
            });
        </script>
    </body>
</html>
```

## 自定义渲染会出现在哪里

启用后，你的自定义渲染会替换以下位置中的默认输出视图：

-   **Experiment comparison view**：在比较多个实验的输出时：

![Experiment comparison view showing custom rendering](/langsmith/images/custom-output-rendering-experiment-comparison.png)

-   **Run detail panes**：当你查看与某个 dataset 关联的 runs 时：

![Run detail pane showing custom rendering](/langsmith/images/custom-output-rendering-run-details.png)

-   **Annotation queues**：在 annotation queues 中审核 runs 时：

![Annotation queue showing custom rendering](/langsmith/images/custom-output-rendering-annotation-queue.png)
