LangSmith 让你可以很方便地把[反馈](/langsmith/observability-concepts#feedback)附加到[traces](/langsmith/observability-concepts#traces)上。这些反馈可以来自用户、标注者、自动化 evaluators 等等，对于监控和评估 agent 都非常关键。

本页详细介绍如何使用 [SDK](/langsmith/reference) 记录 feedback。关于 feedback 对象的结构，请参阅[Feedback 数据格式](/langsmith/feedback-data-format)。

## 使用 `create_feedback()` / `createFeedback`

<Info>
**Child runs**
你可以把用户反馈附加到 trace 的**任何** child run 上，而不只是 trace（root run）本身。
这对于点评 agent 中的某个具体步骤很有用，例如 RAG pipeline 的检索步骤或生成步骤。
</Info>

<Tip>
**非阻塞创建（仅 Python）**
如果在 @[`create_feedback()`][create_feedback] 中传入 `trace_id=`，Python 客户端会自动在后台创建 feedback。
这对于低延迟环境非常重要，因为你会希望 agent 本身不要被 feedback 创建过程阻塞。
</Tip>

下面的示例会创建一条带有两个 child runs 的 trace，然后分别对 root run 和其中一个 child run 记录反馈。TypeScript 片段展示了等价的 `createFeedback` 调用形状，假设你的 agent 里已经能拿到 `runId`。

<CodeGroup>

```python Python
import asyncio

from langsmith import Client, trace, traceable

@traceable
def foo(x):
    return {"y": x * 2}

@traceable
def bar(y):
    return {"z": y - 1}

client = Client()

inputs = {"x": 1}
with trace(name="foobar", inputs=inputs) as root_run:
    result = foo(**inputs)
    result = bar(**result)
    root_run.outputs = result
    trace_id = root_run.id
    child_runs = root_run.child_runs

# Resolve the session_id for the agent environment
if root_run.address is not None:
    resolved = asyncio.run(client.sessions.resolve(**root_run.address))
    session_id = resolved.session_id
else:
    session_id = client.read_project(project_name=root_run.session_name).id

# Provide feedback for a trace (a.k.a. a root run)
client.create_feedback(
    key="user_feedback",
    score=1,
    trace_id=trace_id,
    session_id=session_id,
    comment="the user said that ..."
)

# Provide feedback for a child run
foo_run_id = [run for run in child_runs if run.name == "foo"][0].id
client.create_feedback(
    key="correctness",
    score=0,
    run_id=foo_run_id,
    # trace_id= is optional but recommended to enable batched and backgrounded
    # feedback ingestion.
    trace_id=trace_id,
    session_id=session_id,
)
```

```typescript TypeScript
import { AgentAddress, Client } from "langsmith";
const client = new Client();

    // ... Run your agent and get the run_id...
    // This information can be the result of a user-facing feedback form

// Resolve the session_id for the agent environment
const address = new AgentAddress("<your-agent-id>", "production");
const { session_id: sessionId } = await client.sessions.resolve(address);

await client.createFeedback({
    runId,
    sessionId,
    key: "feedback-key",
    score: 1.0,
    comment: "comment",
});
```

</CodeGroup>

对于基于项目的 traces，请改用 `readProject` 并传入现有项目名来获取其 ID，而不是解析 agent 地址。解析要求请参阅[解析 agent 环境](/langsmith/resolve-an-agent)。

你甚至可以对尚在运行中的 runs 使用 @[`create_feedback()`][create_feedback] / [`createFeedback`](https://reference.langchain.com/javascript/classes/langsmith.client.Client.html#createfeedback) 记录 feedback。关于如何获取一个进行中 run 的 run ID，请参阅[在被追踪函数内部访问当前 run（span）](/langsmith/access-current-span)。

## 从用户界面采集反馈

如果你需要在浏览器或其他客户端环境中采集 feedback，但又不想暴露 API key，请使用 **presigned feedback tokens**。它们会生成一个绑定到特定 run 和 feedback key 的 URL，客户端可以直接调用。

完整说明请参阅[使用 presigned URLs 采集反馈](/langsmith/presigned-feedback-tokens)。

如果你想进一步了解如何根据各种属性（包括用户反馈）筛选 traces，请参阅[筛选 traces](/langsmith/filter-traces)。
