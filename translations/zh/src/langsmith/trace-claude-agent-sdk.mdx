[Claude Agent SDK](https://platform.claude.com/docs/en/agent-sdk/overview) 是一个用于使用 Claude 构建 agentic applications 的 SDK。LangSmith 为 Claude Agent SDK 提供原生集成，可自动追踪你的 agent 执行、工具调用以及与 Claude 模型的交互。

## Installation

安装 Claude Agent SDK 的 LangSmith 集成

<InstallClaudeAgentSdk/>

## Setup

设置你的 [API keys](/langsmith/create-account-api-key)：

<SetupClaudeAgentSdk/>

你可以在 [LangSmith UI](https://smith.langchain.com) 的 **Settings** 中找到 LangSmith API key 和项目名称。

Anthropic API key 请参阅 [Claude console](https://claude.ai/login)。

## Quickstart

要为 Claude Agent SDK 应用启用 LangSmith tracing，请在应用启动时调用 `configure_claude_agent_sdk()`：

<ExampleQuickstart/>

配置完成后，所有 Claude Agent SDK 操作都会自动被追踪到 LangSmith，包括：

-   Agent 查询与响应
-   Tool 调用及结果
-   Claude 模型交互
-   MCP server 操作
