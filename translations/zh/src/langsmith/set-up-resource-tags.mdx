<Info>
资源标签适用于 [Plus 和 Enterprise 方案](/langsmith/pricing-plans)。
</Info>

虽然[工作区](/langsmith/administration-overview#workspaces)帮助你分隔信任边界和访问控制，但标签可以帮助你在工作区内部组织资源。标签是可以附加到资源上的键值对。

<Note>
**不要与 commit tag 混淆**：资源标签是用于组织和筛选工作区资源（项目、数据集、提示词等）的键值对。[Commit tag](/langsmith/manage-prompts#commit-tags) 则是引用提示词 commit 历史中特定版本的标签。虽然两者都可能使用类似 `prod` 或 `staging` 这样的术语，但资源标签帮助你在整个工作区内*组织资源*，而 commit tag 控制你的代码使用提示词的*哪个版本*。
</Note>

你可以通过 [LangSmith UI](https://smith.langchain.com) 或通过 [REST API](/langsmith/smith-api-ref) 以编程方式管理资源标签：

## 创建标签

<Note>
要创建资源标签，你必须拥有 [`workspaces:manage` 权限](/langsmith/organization-workspace-operations)（默认授予[工作区管理员](/langsmith/rbac#workspace-admin)角色）。Editor 可以对自己拥有更新权限的资源应用 **Application** 标签，但创建新的标签键，或应用其他标签类型，都需要此权限。关于如何把标签应用到资源，请参见工作区操作文档中的[标签部分](/langsmith/organization-workspace-operations#tags)。
</Note>

创建标签的方法如下：

1. 前往工作区的 **Settings** 页面，然后点击左侧边栏中的 **Resource tags**。
1. 这里会按键分组显示现有标签值。LangSmith 默认会创建 **Application** 和 **Environment** 这两个键。你可以使用 **Application** 键来过滤 UI 中显示的资源。
1. 点击页面顶部的 <Icon icon="tag" /> **New Tag**。随后输入标签的 key 和 value。你既可以复用已有 key，也可以创建新的 key。

## 给资源分配标签

在创建新标签的同一侧边栏中，你也可以把资源分配到标签下。在 **Assign resources** 区域搜索对应资源，然后选择要打标签的资源。

<Note>
只有工作区作用域的资源可以使用资源标签。这包括 Tracing Projects、Annotation Queues、Deployments、Experiments、Datasets 和 Prompts。
</Note>

若要取消资源上的标签分配，请在标签面板或资源标签面板中点击该标签旁边的 <Icon icon="trash" /> 删除图标。

## 删除标签

你可以在 [**Settings** 页面 > **Resource tags** 页面](https://smith.langchain.com/settings/workspaces/resource_tags) 删除某个标签的 key 或 value。删除 key 时，点击 key 旁边的 <Icon icon="trash" /> 删除图标；删除 value 时，点击该 value 旁边的 <Icon icon="trash" /> 删除图标。

如果删除某个 key，LangSmith 会删除与该 key 关联的所有 values。删除某个 value 时，你会失去该 value 与所有资源之间的关联关系。

## 通过 API 管理标签

你可以使用 LangSmith REST API 以编程方式创建、分配和查询资源标签。所有标签端点都位于 `/api/v1/workspaces/current/` 下，并需要[API 密钥](/langsmith/create-account-api-key)。

### 设置

导入 `requests` 库，并配置 API 密钥和请求头。以下所有示例都假设这些变量已经在作用域中：

```python
import os
import requests

LANGSMITH_API_URL = "https://api.smith.langchain.com"
LANGSMITH_API_KEY = os.environ["LANGSMITH_API_KEY"]
headers = {"x-api-key": LANGSMITH_API_KEY, "Content-Type": "application/json"}
```

### 创建标签键

<Note>
创建标签键需要 [`workspaces:manage`](/langsmith/organization-workspace-operations) 权限。
如果你只是想使用默认的 **Application** 键，可以跳过这一步，直接列出现有键。
</Note>

```python
response = requests.post(
    f"{LANGSMITH_API_URL}/api/v1/workspaces/current/tag-keys",
    headers=headers,
    json={"key": "Environment", "description": "Deployment environment"},
)
response.raise_for_status()
tag_key = response.json()
tag_key_id = tag_key["id"]
```

### 创建标签值

```python
response = requests.post(
    f"{LANGSMITH_API_URL}/api/v1/workspaces/current/tag-keys/{tag_key_id}/tag-values",
    headers=headers,
    json={"value": "production"},
)
response.raise_for_status()
tag_value = response.json()
tag_value_id = tag_value["id"]
```

### 给资源分配标签

```python
response = requests.post(
    f"{LANGSMITH_API_URL}/api/v1/workspaces/current/taggings",
    headers=headers,
    json={
        "tag_value_id": tag_value_id,
        "resource_type": "project",
        "resource_id": "<project-uuid>",
    },
)
response.raise_for_status()
tagging_id = response.json()["id"]
```

有效的 `resource_type` 值包括：`project`、`dataset`、`prompt`、`experiment`、`queue`、`deployment`、`dashboard`、`evaluator`、`mcp_server`、`fleet_integration`。

<Note>
**权限说明**：如果分配的是 **Application** 标签，只需要对目标资源拥有更新权限，因此 editor 无需 `workspaces:manage` 也可以执行。分配其他任意标签键则需要 `workspaces:manage`。
</Note>

**应用已有标签**：如果 key 和 value 已经存在（例如默认的 **Application** 键），先获取它们的 ID，然后直接执行分配步骤：

```python
tags = requests.get(
    f"{LANGSMITH_API_URL}/api/v1/workspaces/current/tags",
    headers=headers,
).json()
# tags is a list of {id, key, values: [{id, value}, ...]}
```

### 在创建资源时直接打标签

你可以在创建 project、dataset 或 prompt 时直接提供 `tag_value_ids`，包括 fork 和 clone 操作。标签会与资源创建在同一个事务中原子地应用，因此资源不会在短时间内处于“未打标签”状态。这一点在启用了 [ABAC policies](/langsmith/abac) 时尤其重要。

这些 tag value 必须已经存在。请以列表形式传入它们的 UUID，最多支持 100 个：

```python
# Look up the tag value IDs you want to apply
tags = requests.get(
    f"{LANGSMITH_API_URL}/api/v1/workspaces/current/tags",
    headers=headers,
).json()
# tags is a list of {id, key, values: [{id, value}, ...]}
env_tag_value_id = next(
    v["id"]
    for t in tags if t["key"] == "Environment"
    for v in t["values"] if v["value"] == "production"
)

# Create a project and tag it immediately
response = requests.post(
    f"{LANGSMITH_API_URL}/api/v1/sessions",
    headers=headers,
    json={
        "name": "my-project",
        "tag_value_ids": [env_tag_value_id],
    },
)
response.raise_for_status()
project = response.json()
```

以下端点同样接受 `tag_value_ids` 字段：

| Endpoint | Description |
|----------|-------------|
| `POST /api/v1/sessions` | 创建 tracing project |
| `POST /api/v1/datasets` | 创建 dataset，也适用于 CSV upload 和 experiment upload 变体 |
| `POST /api/v1/datasets/{dataset_id}/clone` | 克隆 dataset |
| `POST /api/v1/repos` | 创建 prompt |
| `POST /api/v1/repos/{repo_id}/fork` | fork 一个 prompt |

<Note>
**权限说明**：如果是在创建时应用 **Application** 标签，只需要对相应资源类型拥有更新权限。若应用任何其他标签键，则需要 [`workspaces:manage`](/langsmith/organization-workspace-operations) 权限。
</Note>

<Tip>
如果你使用的是 LangSmith SDK tracing，并且 project 是在 trace ingest 过程中自动创建的，那么这条自动创建路径不支持 `tag_value_ids` 参数。若你希望从一开始就让 ABAC policies 生效，请先通过 `POST /api/v1/sessions` 预创建 project，并附带所需的 `tag_value_ids`，然后再开始 trace session。
</Tip>

### 查询标签

```python
# All tag keys and values in the workspace
tags = requests.get(
    f"{LANGSMITH_API_URL}/api/v1/workspaces/current/tags",
    headers=headers,
).json()

# Tags on a specific resource
resource_tags = requests.get(
    f"{LANGSMITH_API_URL}/api/v1/workspaces/current/tags/resource",
    headers=headers,
    params={"resource_type": "project", "resource_id": "<project-uuid>"},
).json()

# All resources tagged with a specific value
taggings = requests.get(
    f"{LANGSMITH_API_URL}/api/v1/workspaces/current/taggings",
    headers=headers,
    params={"tag_value_id": tag_value_id},
).json()
```

### 从资源上移除标签

```python
requests.delete(
    f"{LANGSMITH_API_URL}/api/v1/workspaces/current/taggings/{tagging_id}",
    headers=headers,
)
```

### 删除标签键或标签值

```python
# Delete a value (removes all resource assignments for that value)
requests.delete(
    f"{LANGSMITH_API_URL}/api/v1/workspaces/current/tag-keys/{tag_key_id}/tag-values/{tag_value_id}",
    headers=headers,
)

# Delete a key (also deletes all its values)
requests.delete(
    f"{LANGSMITH_API_URL}/api/v1/workspaces/current/tag-keys/{tag_key_id}",
    headers=headers,
)
```

完整的请求和响应字段列表，请参见 [API reference](/langsmith/smith-api-ref)。
