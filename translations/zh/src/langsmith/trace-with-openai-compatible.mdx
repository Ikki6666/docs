title: 跟踪 OpenAI 兼容提供方
sidebarTitle: OpenAI-compatible APIs
description: 将任意 OpenAI-compatible provider 的 LLM 调用跟踪到 LangSmith。
---

许多 LLM 提供方都接受与 OpenAI API 相同格式的请求。要将这些提供方的调用跟踪到 LangSmith，请构造一个指向该提供方 base URL 的 OpenAI client，然后用 @[`wrap_openai`] / [`wrapOpenAI`](https://reference.langchain.com/javascript/modules/langsmith.html) 对它进行包装。

直接调用 API 时，请使用 `wrap_openai` / `wrapOpenAI`。如果你需要跟踪调用周围的应用逻辑，或按每次调用设置 metadata，请使用 @[`@traceable`]。

| | `wrap_openai` / `wrapOpenAI` | `@traceable` / `traceable` |
|---|---|---|
| Token tracking | 自动 | 需要 `run_type="llm"` |
| Run type | LLM，自动设置 | 默认为 Chain |
| Traces | API 调用本身 | 被包装的函数 |
| Metadata | 仅 client 级别，Python，或 client 级别 / 每次调用级别，TypeScript | 通过 @[`langsmith_extra`] 按调用设置 |

<Note>如需直接跟踪 OpenAI，请参阅[跟踪 OpenAI 应用](/langsmith/trace-openai)。</Note>

<CodeGroup>

```bash Python
pip install langsmith openai
```

```

</CodeGroup>

```

## 跟踪 API 调用

<CodeGroup>

```python Python
import os

import openai
from langsmith import wrappers

client = wrappers.wrap_openai(
    openai.OpenAI(
        base_url="https://<provider-base-url>/v1",
        api_key=os.environ["PROVIDER_API_KEY"],
    )
)

completion = client.chat.completions.create(
    model="<provider-model-name>",
    messages=[{"role": "user", "content": "Hello!"}],
)
print(completion.choices[0].message.content)
```

```typescript TypeScript
import OpenAI from "openai";
import { wrapOpenAI } from "langsmith/wrappers/openai";

const client = wrapOpenAI(
  new OpenAI({
    baseURL: "https://<provider-base-url>/v1",
    apiKey: process.env.PROVIDER_API_KEY!,
  })
);

const completion = await client.chat.completions.create({
  model: "<provider-model-name>",
  messages: [{ role: "user", content: "Hello!" }],
});
console.log(completion.choices[0].message.content);
```

</CodeGroup>

## 添加 metadata

<Tabs>
<Tab title="Python">

在包装 client 时传入 `tracing_extra`。这些 metadata 会应用到该 client 发起的所有调用上。

```python
import os

import openai

from langsmith import wrappers

client = wrappers.wrap_openai(
    openai.OpenAI(
        base_url="https://<provider-base-url>/v1",
        api_key=os.environ["PROVIDER_API_KEY"],
    ),
    tracing_extra={"metadata": {"environment": "production"}},
)
```

</Tab>
<Tab title="TypeScript">

将选项作为第二个参数传给 `wrapOpenAI` 可设置 client 级 metadata，或者在每次调用时传入 [`langsmithExtra`](https://reference.langchain.com/javascript/modules/langsmith.html)。

```typescript
import OpenAI from "openai";
import { wrapOpenAI } from "langsmith/wrappers/openai";

const client = wrapOpenAI(
  new OpenAI({
    baseURL: "https://<provider-base-url>/v1",
    apiKey: process.env.PROVIDER_API_KEY!,
  }),
  { metadata: { environment: "production" } }
);

// Per-call metadata
const completion = await client.chat.completions.create(
  {
    model: "<provider-model-name>",
    messages: [{ role: "user", content: "Hello!" }],
  },
  { langsmithExtra: { metadata: { request_id: "abc123" } } }
);
```

</Tab>
</Tabs>

## 相关指南

有些 provider 提供了专门的设置指南，使用 `@traceable` 或原生 callback。这些方式是在函数级别进行跟踪，而不是直接包装 client，或者会与 provider 自己的 SDK 与路由层集成。

- [DeepSeek](/langsmith/trace-deepseek)：OpenAI-compatible API，本指南使用 `@traceable` 并附带自定义 provider metadata
- [LiteLLM](/langsmith/trace-litellm)：暴露 OpenAI-compatible endpoint 的代理，本指南涵盖 `@traceable` 和 LiteLLM 内置的 LangSmith callback
