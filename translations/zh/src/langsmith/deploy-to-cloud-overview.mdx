[LangSmith Cloud](/langsmith/cloud) 是一个**用于部署 agents 的托管平台**。LangChain 在 AWS 和 GCP 上托管并运维 [control plane](/langsmith/control-plane)、[data plane](/langsmith/data-plane)、[Agent Server](/langsmith/agent-server) 运行时，以及支撑数据库。只需将代码推送到已连接的 GitHub 仓库，或调用 `langgraph deploy` CLI，平台就会负责构建、资源配置、扩缩容以及持续运维。

<Callout icon="clipboard-check" color="#4F46E5" iconType="regular">
运行在 Cloud 上的 agent deployments 需要 [Plus plan 或更高版本](https://www.langchain.com/pricing)。在创建第一个 agent deployment 之前，请先确认你的应用能通过 `langgraph dev` 在本地运行。请参阅 [Local development and testing](/langsmith/local-dev-testing)。
</Callout>
