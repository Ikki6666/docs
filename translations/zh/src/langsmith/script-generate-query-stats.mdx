在排查你的自托管 LangSmith 实例问题时，LangChain 团队可能会要求你生成 LangSmith query 统计信息，以帮助我们了解支撑 LangSmith 产品体验的各类查询性能。

该命令会生成一个 CSV，可共享给 LangChain 团队。

### Prerequisites

请确保你准备好以下工具或信息：

1. kubectl

   * [https://kubernetes.io/docs/tasks/tools/](https://kubernetes.io/docs/tasks/tools/)

2. Clickhouse 数据库凭据

   * Host
   * Port
   * Username
     * 如果使用 bundled 版本，这里是 `default`
   * Password
     * 如果使用 bundled 版本，这里是 `password`
   * Database name
     * 如果使用 bundled 版本，这里是 `default`

3. 你运行 `get_query_stats` 脚本的机器需要能够连接到 Clickhouse 数据库。

   * 如果你使用 bundled 版本，可能需要先把 clickhouse service 端口转发到本地机器。
   * 运行 `kubectl port-forward svc/langsmith-clickhouse 8123:8123`，即可将 clickhouse service 端口转发到本地机器。

4. 用于生成 query 统计信息的脚本

   * 下载 [query stats script](https://github.com/langchain-ai/helm/blob/main/charts/langsmith/scripts/get_query_stats.sh)

### Running the query stats generation script

运行以下命令来执行统计信息生成脚本：

```bash
sh get_query_stats.sh <clickhouse_url> --output path/to/file.csv
```

例如，如果你使用 bundled 版本并配合 port-forwarding，命令会类似这样：

```bash
sh get_query_stats.sh "clickhouse://default:password@localhost:8123/default" --output query_stats.csv
```

运行后，你应当会看到生成了一个名为 `query_stats.csv` 的文件，其中包含 LangSmith query 统计信息。
