Sandbox 是隔离环境，允许 agent 安全地执行潜在高风险操作，例如运行任意代码或访问文件系统，而不会影响你的主基础设施。

在 [LangSmith homepage](https://smith.langchain.com) 中选择 **Sandboxes**，即可统一管理你的所有 sandbox 资源。

![Sandboxes overview page](/images/langsmith/sandboxes/sb-overview.png)

<Warning>
在 BYOC 上，请使用归属于某个 BYOC workspace 的 API key。
</Warning>

对于自托管 LangSmith 部署，请参阅[在自托管部署上启用 Sandboxes](/langsmith/deploy-self-hosted-full-platform#enable-sandboxes)。

## Get started

### 1. Install the SDK

<CodeGroup>

```bash Python
# uv
uv add "langsmith[sandbox]"

# pip
pip install "langsmith[sandbox]"
```

```bash TypeScript
npm install langsmith
```

</CodeGroup>

### 2. Set your API key

```bash
export LANGSMITH_API_KEY="<your-api-key>"
```

### 3. Create and run a sandbox

<CodeGroup>

```python Python
from langsmith.sandbox import SandboxClient

client = SandboxClient()

with client.sandbox() as sb:
    result = sb.run("python -c 'print(2 + 2)'")
    print(result.stdout)  # "4\n"
```

```ts TypeScript
import { SandboxClient } from "langsmith/sandbox";

const client = new SandboxClient();
const sandbox = await client.createSandbox();
const result = await sandbox.run("node -e 'console.log(2 + 2)'");
console.log(result.stdout); // "4\n"
await sandbox.delete();
```

</CodeGroup>

<Tip>
  更偏好命令行方式？[Sandbox CLI](/langsmith/sandbox-cli) 允许你无需写代码就创建 sandbox、执行命令，并打开交互式 shell。
</Tip>

### 4. Use sandboxes with your agents

要把 sandbox 接入 agent 代码，请参阅 Open Source 文档：

- **Deep Agents**：[Use `LangSmithSandbox` as a backend](/oss/integrations/sandboxes/langsmith)，涵盖安装、backend 创建和清理。
- **Sandboxes as agent backends**：[Configure any sandbox as the execution backend](/oss/deepagents/sandboxes)，为 agent 自动提供 `execute` 和 filesystem tool。
- **LangChain / LangGraph integrations**：把 LangSmith sandbox 作为 first-party 选项使用，或 [connect third-party providers](/oss/integrations/sandboxes)，例如 AgentCore、Daytona、E2B、Modal、Runloop 和 Vercel。
