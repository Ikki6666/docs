**Feedback** 是 LangSmith 用来存储某个特定 trace 或中间 run（span）上的评估标准与分数的方式。Feedback 可以通过多种方式产生，例如：

1. 由 LLM application [随 trace 一起上报](/langsmith/attach-user-feedback)
2. 由用户在应用中 [inline](/langsmith/annotate-traces-inline) 或在 [annotation queue](/langsmith/annotation-queues) 中生成
3. 由自动 evaluator 在[离线评估](/langsmith/evaluate-llm-application)期间生成
4. 由[在线 evaluator](/langsmith/online-evaluations-llm-as-judge)生成
