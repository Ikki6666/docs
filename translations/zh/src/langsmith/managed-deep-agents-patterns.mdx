## 模式

- [每日摘要](/langsmith/managed-deep-agents-tutorial)：在 durable memory 中记住主题，并发送工作日新闻摘要。
- [监视模式](/langsmith/managed-deep-agents-watch-mode)：监控 Slack channel，默认保持安静，并安排后续检查。
- [目标](/langsmith/managed-deep-agents-goal-oriented)：安排周期性进度检查，直到多轮工作完成。
- [Dreaming](/langsmith/managed-deep-agents-dreaming)：每晚回顾某个人的 traces，以更新其 memory 并提出改进建议。
- [Swarm](/langsmith/managed-deep-agents-swarm)：将一次事件调查分发到多个并行异步 subagents。
