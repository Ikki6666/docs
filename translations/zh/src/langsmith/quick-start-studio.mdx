[LangSmith Deployment UI](https://smith.langchain.com) 中的 [Studio](/langsmith/studio) 支持连接两类图：

- 部署在[云端或自托管环境](#deployed-graphs)中的图。
- 通过 [Agent Server](#local-development-server) 在本地运行的图。

## Deployed graphs

你可以在 [LangSmith UI](https://smith.langchain.com) 的 **Deployments** 导航中进入 Studio。

对于已经[部署](/langsmith/deployment-quickstart)的应用，你可以直接把 Studio 当作该部署的一部分来使用。做法是进入该部署的页面，然后选择 **Studio**。

这样会加载一个连接到线上部署的 Studio，你可以在其中创建、读取和更新该部署里的 [threads](/oss/langgraph/checkpointers#threads)、[assistants](/langsmith/assistants) 和 [memory](/oss/concepts/memory)。

## Local development server

### Prerequisites

如果要用 Studio 在本地测试应用：

- 先完成[本地应用快速开始](/langsmith/local-dev-testing)。
- 如果你不希望数据被 [traced](/langsmith/observability-concepts#traces) 到 LangSmith，请在应用的 `.env` 文件中设置 `LANGSMITH_TRACING=false`。关闭 tracing 后，数据不会离开你的本地服务器。

### Setup

1. 安装 [LangGraph CLI](/langsmith/cli)：

    <CodeGroup>
    ```bash pip
    pip install -U "langgraph-cli[inmem]"
    langgraph dev
    ```

    ```bash uv
    uv add "langgraph-cli[inmem]"
    langgraph dev
    ```

    ```bash npm
    npx @langchain/langgraph-cli dev
    ```
    </CodeGroup>

    <Warning>
    **Browser Compatibility**
    Safari 会阻止 `localhost` 与 Studio 建立连接。要绕过这个限制，请在命令中加上 `--tunnel`，通过安全隧道访问 Studio。随后你需要在 Studio UI 中点击 **Connect to a local server**，手动把该隧道 URL 加入允许的来源。具体步骤请参见[故障排查指南](/langsmith/troubleshooting-studio#safari-connection-issues)。
    </Warning>

    这会在本地启动 Agent Server，并使用 in-memory 运行。服务器会以 watch mode 运行，监听代码变更并自动重启。关于启动 API server 的全部选项，请参见这份[参考文档](/langsmith/cli#dev)。

    你会看到如下日志：

    ```
    > Ready!
    >
    > - API: [http://localhost:2024](http://localhost:2024/)
    >
    > - Docs: http://localhost:2024/docs
    >
    > - LangSmith Studio Web UI: https://smith.langchain.com/studio/?baseUrl=http://127.0.0.1:2024
    ```

    启动后，系统会自动把你带到 Studio。

1. 对于一个已经在运行的服务器，可以通过以下任一方式访问 Dbugger：
    1. 直接打开以下 URL：`https://smith.langchain.com/studio/?baseUrl=http://127.0.0.1:2024`。
    1. 在 UI 中进入 **Deployments**，点击某个部署上的 **Studio** 按钮，输入 `http://127.0.0.1:2024`，然后点击 **Connect**。

    如果你的服务器运行在不同的 host 或 port 上，请相应更新 `baseUrl`。

### (Optional) Attach a debugger

如果你想通过断点和变量检查进行逐步调试，请运行以下命令：

    <CodeGroup>
    ```bash pip
    # Install debugpy package
    pip install debugpy
    # Start server with debugging enabled
    langgraph dev --debug-port 5678
    ```

    ```bash uv
    # Install debugpy package
    uv add debugpy
    # Start server with debugging enabled
    langgraph dev --debug-port 5678
    ```
    </CodeGroup>

然后连接你偏好的调试器：

<Tabs>
    <Tab title="VS Code">
    把下面这段配置加入 `launch.json`：

    ```json
    {
        "name": "Attach to LangGraph",
        "type": "debugpy",
        "request": "attach",
        "connect": {
          "host": "0.0.0.0",
          "port": 5678
        }
    }
    ```
    </Tab>
    <Tab title="PyCharm">
    1. 前往 Run → Edit Configurations
    2. 点击 +，然后选择 "Python Debug Server"
    3. 将 IDE host name 设为 `localhost`
    4. 将 port 设为 `5678`（或你在前一步选择的端口号）
    5. 点击 "OK"，然后启动调试
    </Tab>
</Tabs>

<Tip>
如果启动过程中遇到问题，请参见[故障排查指南](/langsmith/troubleshooting-studio)。
</Tip>
