---
title: 指定自定义 run ID
description: 在使用 LangSmith tracing 时，如何指定自定义 run ID。
---

默认情况下，LangSmith 会为每个 [run](/langsmith/observability-concepts#runs) 分配一个随机 ID。在以下场景中，你可以用自定义 ID 覆盖它：

- 需要提前知道 run ID（例如，在 run 结束后立刻附加[feedback](/langsmith/observability-concepts#feedback)）。
- 将 LangSmith runs 与外部系统中的 ID 做关联。
- 通过复用一个确定性的 ID，让 runs 具备幂等性。

<Note>
我们建议使用 **UUID v7** 作为自定义 run ID。UUIDv7 内嵌时间戳，这样可以在 trace 中保持 runs 的正确时间排序。当前如果传入的不是 UUIDv7，会发出 warning；未来版本将强制要求 UUIDv7。

[LangSmith SDK](/langsmith/reference) 导出了一个 `uuid7` 辅助函数（Python v0.4.43+，JS v0.3.80+）：

- **Python**：`from langsmith import uuid7`
- **JS/TS**：`import { uuid7 } from 'langsmith'`
</Note>

任何 UUID v7 字符串都可以使用。你可以使用 LangSmith SDK helper 生成，也可以使用你自己系统中已有的 UUID v7 标识符。

<Tabs>
  <Tab title="Python">
    ### 使用 `@traceable`

    调用 @[`@traceable`] 函数时，在 `langsmith_extra` 中传入 `run_id`：

    ```python Python
    from langsmith import traceable, uuid7

    @traceable
    def my_pipeline(question: str) -> str:
        return "answer"

    run_id = uuid7()
    my_pipeline("What is the capital of France?", langsmith_extra={"run_id": run_id})

    # run_id can now be used to attach feedback, query the run, etc.
    ```

    ### 使用 `trace` 上下文管理器

    将 `run_id` 直接传给 @[trace] 上下文管理器构造函数，以设置该被追踪代码块的 ID：

    ```python Python
    from langsmith import trace, uuid7

    run_id = uuid7()

    with trace("my-pipeline", run_id=run_id) as run:
        result = "answer"
        run.end(outputs={"result": result})

    # run_id can now be used to attach feedback, query the run, etc.
    ```
  </Tab>
  <Tab title="TypeScript">
    ### 使用 `traceable`

    在传给 [`traceable`](https://reference.langchain.com/javascript/langsmith/traceable/traceable) 的配置对象中传入 `id`：

    ```typescript TypeScript
    import { traceable } from "langsmith/traceable";
    import { uuid7 } from "langsmith";

    const runId = uuid7();

    const myPipeline = traceable(
      async (question: string) => {
        return "answer";
      },
      { name: "my-pipeline", id: runId }
    );

    await myPipeline("What is the capital of France?");

    // runId can now be used to attach feedback, query the run, etc.
    ```

  </Tab>
</Tabs>
