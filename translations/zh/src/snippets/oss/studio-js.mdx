在本地使用 LangChain 构建智能体时，能够可视化智能体内部发生的情况、实时与其交互并在问题发生时调试，会很有帮助。**LangSmith Studio** 是一个免费的可视化界面，用于在本地机器上开发和测试 LangChain 智能体。

Studio 会连接到本地运行的智能体，并展示智能体执行的每一步，包括发送给模型的提示、工具调用及其结果，以及最终输出。你可以测试不同输入、检查中间状态，并在无需额外代码或部署的情况下迭代智能体行为。

本页介绍如何为本地 LangChain 智能体设置 Studio。

## 前提条件

开始前，请确保你具备以下内容：

- **LangSmith 账户**：在 [smith.langchain.com](https://smith.langchain.com) 免费注册或登录。
- **LangSmith API 密钥**：按照[创建 API 密钥](/langsmith/create-account-api-key)指南操作。
- 如果你不希望数据被[追踪](/langsmith/observability-concepts#traces)到 LangSmith，请在应用的 `.env` 文件中设置 `LANGSMITH_TRACING=false`。禁用追踪后，不会有数据离开你的本地服务器。

## 设置本地 Agent 服务器

### 1. 安装 LangGraph CLI

[LangGraph CLI](/langsmith/cli) 提供一个本地开发服务器，也称为 [Agent Server](/langsmith/agent-server)，用于将智能体连接到 Studio。

```shell
npx @langchain/langgraph-cli
```

### 2. 准备你的智能体

如果你已经有一个 LangChain 智能体，可以直接使用。这个示例使用一个简单的邮件智能体：

```typescript title="agent.ts"
import { createAgent } from "@langchain/agents";

function sendEmail(to: string, subject: string, body: string): string {
  const email = {
    to,
    subject,
    body,
  };
  // ... email sending logic

  return `Email sent to ${to}`;
}

const agent = createAgent({
  model: "gpt-5.5",
  tools: [sendEmail],
  systemPrompt: "You are an email assistant. Always use the send_email tool.",
});
```

### 3. 环境变量

Studio 需要使用 LangSmith API 密钥连接到你的本地智能体。在项目根目录创建一个 `.env` 文件，并添加你从 [LangSmith](https://smith.langchain.com/settings) 获取的 API 密钥。

<Warning>
    确保 `.env` 文件不会被提交到 Git 等版本控制系统中。
</Warning>

```bash .env
LANGSMITH_API_KEY=lsv2...
```

### 4. 创建 LangGraph 配置文件

LangGraph CLI 使用配置文件定位你的智能体并管理依赖。在应用目录中创建一个 `langgraph.json` 文件：

```json title="langgraph.json"
{
  "dependencies": ["."],
  "graphs": {
    "agent": "./src/agent.ts:agent"
  },
  "env": ".env"
}
```

@[`createAgent`] 函数会自动返回一个已编译的 LangGraph 图，这正是配置文件中 `graphs` 键所期望的内容。

<Info>
有关配置文件中 JSON 对象各个键的详细说明，请参阅 [LangGraph 配置文件参考](/langsmith/cli#configuration-file)。
</Info>

此时，项目结构如下所示：

```bash
my-app/
├── src
│   └── agent.ts
├── .env
└── langgraph.json
```

### 5. 安装依赖

```shell
yarn install
```

### 6. 在 Studio 中查看你的智能体

启动开发服务器，将智能体连接到 Studio：

```shell
npx @langchain/langgraph-cli dev
```

<Warning>
Safari 会阻止 `localhost` 到 Studio 的连接。若要绕过此限制，请在上述命令中添加 `--tunnel`，通过安全隧道访问 Studio。
</Warning>

服务器启动后，你的智能体既可以通过 `http://127.0.0.1:2024` 上的 API 访问，也可以通过 `https://smith.langchain.com/studio/?baseUrl=http://127.0.0.1:2024` 上的 Studio UI 访问：

<Frame>
![Studio UI 中的智能体视图](/oss/images/studio_create-agent.png)
</Frame>

当 Studio 连接到本地智能体后，你可以快速迭代智能体行为。运行测试输入，检查完整的执行追踪，包括提示、工具参数、返回值，以及 token 和延迟指标。出现问题时，Studio 会连同周边状态一起捕获异常，帮助你理解发生了什么。

开发服务器支持热重载。修改代码中的提示或工具签名后，Studio 会立即反映这些变化。你可以从任一步重新运行对话线程来测试更改，而无需从头开始。这个工作流既适用于只有单个工具的简单智能体，也适用于复杂的多节点图。
