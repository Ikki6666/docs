为我的 coding agent 安装 LangChain Skills，让它在处理 LangChain、LangGraph 和 Deep Agents 任务时表现更好。

使用 https://github.com/langchain-ai/langchain-skills 提供的 Agent Skills installer：

```bash
npx skills add langchain-ai/langchain-skills --skill '*' --yes
```

如果我要求全局安装，则使用：

```bash
npx skills add langchain-ai/langchain-skills --skill '*' --yes --global
```

检测我正在使用的 agent 或编辑器。如果我使用 Claude Code 且偏好插件方式，请按照该仓库 README 中的 marketplace 安装步骤操作（先 `/plugin marketplace add`，再 `/plugin install`）。不要编造其他 skill 包名或安装 URL。安装完成后，确认这些 skills 对 agent 可用。
