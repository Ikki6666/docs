        <h1 class="flex whitespace-pre-wrap group font-semibold text-2xl sm:text-3xl mt-8">构建</h1>

        LangChain 开源栈提供了你设计、测试和发布 agent 所需的基础构件。每一层都由你配置：模型、工具、agent 所依赖的上下文与记忆，以及围绕模型循环的 harness。

        <h2 class="flex whitespace-pre-wrap group font-semibold">选择起点</h2>

        Deep Agents、LangChain 和 LangGraph 共享同一套开源技术栈，所以你可以根据自己需要的控制程度来选择。如果需要托管部署或无代码方式，请从 Managed Deep Agents 或 Fleet 开始：
