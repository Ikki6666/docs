        ## UI 框架集成

        开箱即用、可直接配合 `@langchain/react` 的 UI 组件库。

        <CardGroup cols={1}>
        <Card title="ai-elements" icon="package" href="https://ui-patterns.langchain.com/ai-elements/" cta="打开预览" target="_blank">
            用于构建 AI chat UI 的 headless、可组合 React 组件。底层使用 @[`useStream`]，并完整兼容 shadcn/ui。

            - 滚动吸附的对话容器
            - 带语法高亮的流式代码块
            - 可折叠的 reasoning / thinking 区块
            - 展示 args 和 results 的 tool call 显示组件
            - Shimmer 加载状态和 suggestion chips
        </Card>
        <Card title="assistant-ui" icon="package" href="https://ui-patterns.langchain.com/assistant-ui/" cta="打开预览" target="_blank">
            使用 `@assistant-ui/react` primitives 构建的 Claude 风格 assistant UI，通过 `useExternalStoreRuntime` 接入 LangChain。

            - Claude 风格的暖色羊皮纸主题
            - 可折叠的 chain-of-thought reasoning
            - 图片附件支持
            - 复制 / 点赞 / 点踩操作栏
            - 完整 dark mode 支持
        </Card>
        <Card title="OpenUI" icon="package" href="https://ui-patterns.langchain.com/openui/" cta="打开预览" target="_blank">
            Generative UI chat，其中 LangChain agent 会把任意 React 组件作为 message stream 的一部分发出，并在浏览器中实时渲染。

            - Agent 驱动的动态组件渲染
            - 流式 message composition
            - 自定义组件注册表
            - 生成界面的实时预览
        </Card>
        </CardGroup>
