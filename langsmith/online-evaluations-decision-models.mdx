[Online evaluations](/langsmith/evaluation-concepts#online-evaluations) 为你的生产 traces 提供实时反馈。Online evaluator 可以使用 decision model（例如 Jev）代替 LLM 作为 judge。要使用 LLM 作为 judge，请参阅[设置 LLM-as-a-judge online evaluators](/langsmith/online-evaluations-llm-as-judge)。

<Note>
当 online evaluator 在 trace 中的任意 run 上运行时，LangSmith 会将该 trace 升级到 [extended data retention](/langsmith/usage-and-billing#data-retention-auto-upgrades)。此升级会影响 trace 定价。
</Note>

## Decision models

Decision models 回答关于文本的结构化问题，并返回类型化的答案，例如概率、选中的选项或分数，而不是自由格式的文本。关于它们的工作原理，请参阅 [Decision models in the LLM Gateway](/langsmith/llm-gateway-decision-models)。使用 decision model 作为 judge 时，LangSmith 会把你定义的每个问题的答案记录在各自的 feedback key 下。你不需要编写 output schema 或解析自由文本的推理。

### 支持的模型

LangSmith 为 evaluators 支持 Jev decision model，既适用于 tracing projects，也适用于 datasets。要通过其他提供商调用 decision model 或在你自己的服务器上调用，请使用 [TypeSafe-compatible endpoint](/langsmith/typesafe-compatible-model)。

| Model | Provider | Setup |
|-------|----------|-------|
| [Jev](/langsmith/llm-gateway-decision-models#use-typesafe-jev) | **TypeSafe** | 需要将 TypeSafe API key 存储为 workspace secret。默认为 `TYPESAFE_API_KEY`。 |

<Note>
你只能在 LangSmith UI 中创建 decision model evaluators。LangSmith SDK 尚不支持创建它们。要在代码中直接调用 decision model，请参阅 [Decision models in the LLM Gateway](/langsmith/llm-gateway-decision-models)。
</Note>

### 问题类型

添加到 decision model evaluator 的每个问题都有三种类型之一。完整定义请参阅 [TypeSafe primitives documentation](https://docs.typesafe.ai/primitives)。

- **Noul**：连续布尔值。返回某个陈述为真的概率，取值范围为 0 到 1。接近 1 表示是，接近 0 表示否，接近 0.5 表示模型不确定。用于是或否的检查，例如输出是否包含 personally identifiable information。将指令表述为一个是或否的问题，并可以选择描述 true 和 false 的含义。
- **Choice**：从固定的无序列表中选取一个选项，例如分类用户是在提出 `question`、发出 `request`，还是两者都不是（`other`）。为每个选项指定一个名称，如果名称不够直观，还要提供描述。
- **Score**：按有序等级对状态进行评分，例如用户的沮丧程度，从平静到非常愤怒。按顺序定义等级，从等级 0 开始。分数可以落在两个等级之间。

Jev 对问题施加以下限制：

| Limit | Jev |
|-------|-----|
| Options per choice question | 2 to 255 |
| Levels per score question | 2 to 10 |

### 将答案映射到 feedback keys

每个问题的名称会成为被评估 run 或 thread 上的 feedback key。LangSmith 按以下方式将每个类型化的答案转换为 feedback：

| Question type | Feedback field | Value |
|---------------|----------------|-------|
| Noul | `score` | 0 到 1 之间的数字 |
| Choice | `value` | 所选选项的名称 |
| Score | `score` | 0 到最高等级索引之间的数字。例如，一个有四个等级的问题返回 0 到 3 的分数。 |

LangSmith 还会在每个 feedback 条目上存储模型的完整答案，位于 feedback source metadata 的 `typesafe` 字段下。对于 choice 和 score 问题，答案包含 `probabilities` 和 `confidence`。由于每个答案都是标准 feedback，你可以像使用任何其他 evaluator 的 feedback 一样，对它进行过滤、绘制图表、设置告警，并据此触发 [automations](/langsmith/rules)。

问题名称遵循与其他 feedback keys 相同的限制，且每个名称在 evaluator 内必须唯一。

## 添加 decision model online evaluator

要添加 decision model online evaluator：

1. 在 [LangSmith UI](https://smith.langchain.com?utm_source=docs&utm_medium=cta&utm_campaign=langsmith-signup&utm_content=langsmith-online-evaluations-decision-models) 中，进入 **Tracing** 页面并选择一个 tracing project。
1. 点击 **Evaluators** 标签页。
1. 点击 **+ Evaluator**，打开 **Configure Evaluator** 面板。
1. 在 **Create from scratch** 下，选择 **LLM-as-a-Judge Evaluator**，然后为 evaluator 命名。
1. 选择一个 decision model，将 run 或 thread 变量映射到 **State** 中，然后添加问题。每项设置请参阅[如何定义 decision model evaluator](/langsmith/decision-model-evaluator)。
1. （可选）应用 [filter](/langsmith/online-evaluations-llm-as-judge#apply-a-filter-to-runs-that-trigger-the-evaluator)、设置 [sampling rate](/langsmith/online-evaluations-llm-as-judge#configure-a-sampling-rate)，或[将规则应用到过去的 runs 或 threads](/langsmith/online-evaluations-llm-as-judge#apply-a-rule-to-past-runs-or-threads)。这些设置的工作方式与 LLM-as-a-judge online evaluators 相同。
1. 要保存 evaluator，请点击 **Create** 或 **Save**。

该 evaluator 会检查匹配其 filter 的每个新 run 或 thread。每个问题的答案都会显示在各自的 feedback key 下。
