LangSmith 会按如下格式在 datasets 中存储 examples：

| Field Name          | Type     | Description                                                                                                       |
| ------------------- | -------- | ----------------------------------------------------------------------------------------------------------------- |
| **id**              | UUID     | Example 的唯一标识符。                                                                                |
| **name**            | string   | Example 的名称。                                                                                          |
| **created\_at**     | datetime | 该 example 的创建时间。                                                                                 |
| **modified\_at**    | datetime | 该 example 的最后修改时间。                                                                           |
| **inputs**          | object   | Example 的输入映射。                                                                                  |
| **outputs**         | object   | 由 run 生成的输出映射或输出集合。                                                                     |
| **dataset\_id**     | UUID     | 该 example 所属的 dataset。                                                                                |
| **source\_run\_id** | UUID     | 对于由 LangSmith [`Run`](/langsmith/run-data-format) 创建的 examples，此字段为该 run 的 ID。 |
| **source\_thread\_id** | string   | 对于由[thread](/langsmith/observability-concepts#threads)或 thread 中的某个 run 创建的 examples，此字段为该 thread 的 ID。 |
| **metadata**        | object   | 可存储在 example 上的附加信息映射，由用户或 SDK 定义。                            |

要了解 examples 如何用于评估，请阅读我们的 [evaluating LLM applications](/langsmith/evaluate-llm-application) how-to 指南。

<Tip>
`outputs` 字段还可以包含 [assertions](/langsmith/assertions)，也就是评审者针对正确答案写下的自由形式断言。离线 evaluators 会从 `reference_outputs["assertions"]` 中读取这些内容。
</Tip>
