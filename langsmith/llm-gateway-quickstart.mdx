<LLMGatewayBetaNote />

LLM Gateway 通过一个 endpoint 和一个 [LangSmith API key](/langsmith/create-account-api-key)，调用多家已配置 provider 的模型。发送一个请求，查看其 trace，然后设置支出上限。

<Note>
本快速开始使用美国区域的 LangSmith Cloud：gateway 位于 `gateway.smith.langchain.com`，LangSmith UI 位于 `smith.langchain.com`。在 Deep Agents 示例中设置 `LANGSMITH_GATEWAY="true"` 也会解析到美国区域的 gateway。

- **其他 Cloud 区域和 BYOC**：将每个示例中的 gateway 主机名替换为你的[区域 gateway](/langsmith/llm-gateway-how-it-works#use-a-regional-gateway) 或 [BYOC data plane](/langsmith/llm-gateway-how-it-works#use-a-byoc-data-plane) base URL。对于 Deep Agents，请将 `LANGSMITH_GATEWAY` 设置为该 gateway 的根 URL，而不是 `true`。
- **自托管**：请按照[在自托管上启用 LLM Gateway](/langsmith/llm-gateway-self-hosted) 操作，其中包含它自己的首次调用。
</Note>

<Info>
管理员必须为你的 workspace 一次性[启用 gateway、添加 provider secret 并授予访问权限](/langsmith/llm-gateway-admin-setup)。之后，你只需要一个关联到具备 `gateway:invoke` 和 `workspaces:read` [权限](/langsmith/organization-workspace-operations)角色的、工作区级别的 LangSmith API key。
</Info>

<Steps>

<Step title="发送一个请求" icon="send" id="send-a-request">

一次 gateway 调用就是一个指向 gateway base URL、并使用你的 LangSmith API key 认证的普通模型请求。使用 Chat completions 从你已有的应用中调用 gateway，或使用 Deep Agents 构建一个通过它路由的 agent。

<Tabs>

<Tab title="Chat completions">

把任何 OpenAI 兼容客户端指向 `https://gateway.smith.langchain.com/v1`，并将 `model` 设置为带 provider 前缀的 ID。

<CodeGroup>

```bash cURL
export LANGSMITH_API_KEY="lsv2_..."

curl https://gateway.smith.langchain.com/v1/chat/completions \
    -H "Authorization: Bearer $LANGSMITH_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{"model":"anthropic/claude-opus-5","messages":[{"role":"user","content":"Explain what an LLM gateway does in one sentence."}]}'
```

```python Python
import os

from openai import OpenAI

client = OpenAI(
    base_url="https://gateway.smith.langchain.com/v1",
    api_key=os.environ["LANGSMITH_API_KEY"],
)
response = client.chat.completions.create(
    model="anthropic/claude-opus-5",
    messages=[{"role": "user", "content": "Explain what an LLM gateway does in one sentence."}],
)
print(response.choices[0].message.content)
```

```typescript TypeScript
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://gateway.smith.langchain.com/v1",
  apiKey: process.env.LANGSMITH_API_KEY,
});
const response = await client.chat.completions.create({
  model: "anthropic/claude-opus-5",
  messages: [{ role: "user", content: "Explain what an LLM gateway does in one sentence." }],
});
console.log(response.choices[0].message.content);
```

</CodeGroup>

同一个 endpoint 也接受 Anthropic Messages 和 OpenAI Responses 请求。请参阅 [API formats](/langsmith/llm-gateway-api-formats)。

</Tab>

<Tab title="Deep Agents">

设置 `LANGSMITH_GATEWAY`，把进程中所有受支持的 chat models 都通过 gateway 路由。

<CodeGroup>

```python Python
# pip install "deepagents>=0.1.0"
# export LANGSMITH_API_KEY="lsv2_..."
# export LANGSMITH_GATEWAY="true"
from deepagents import create_deep_agent

agent = create_deep_agent(model="anthropic:claude-opus-5")
result = agent.invoke({"messages": [{"role": "user", "content": "Explain what an LLM gateway does in one sentence."}]})
print(result["messages"][-1].content)
```

```typescript TypeScript
// npm install deepagents
// export LANGSMITH_API_KEY="lsv2_..."
// export LANGSMITH_GATEWAY="true"
import { createDeepAgent } from "deepagents";

const agent = createDeepAgent({ model: "anthropic:claude-opus-5" });
const result = await agent.invoke({
  messages: [{ role: "user", content: "Explain what an LLM gateway does in one sentence." }],
});
console.log(result.messages[result.messages.length - 1].content);
```

</CodeGroup>

要路由特定调用而不是全部调用，请在 Chat completions 标签页中使用标准 endpoint，并将 `model` 设置为带 provider 前缀的 ID。

</Tab>

</Tabs>

</Step>

<Step title="查看 trace" icon="activity" id="view-the-trace">

打开 [LangSmith](https://smith.langchain.com?utm_source=docs&utm_medium=cta&utm_campaign=langsmith-signup&utm_content=langsmith-llm-gateway-quickstart)，进入你的 workspace 中名为 `gateway` 的 tracing project。你的请求会出现在那里，带有其 token 计数、成本和延迟。

</Step>

<Step title="设置支出上限" icon="shield" id="set-a-spend-limit">

前往 LangSmith 中的 **LLM Gateway**，创建一条支出策略，例如对你的 API key 设置每日 10 美元的上限。当达到上限时，gateway 会返回 `402`，并带有指明阻止该请求的策略的消息：

```json
{"type": "error", "error": {"message": "request blocked by gateway policies: R&D Spend Cap"}}
```

完整指南请参阅[支出策略](/langsmith/llm-gateway-spend-policies)。

</Step>

</Steps>
