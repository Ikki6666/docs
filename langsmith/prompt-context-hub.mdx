Prompts、retrieval context、skills 和 task instructions 的变更频率往往高于围绕它们的应用程序代码，而且经常需要由非工程师的人来编辑。使用 Prompt & Context Hub 存储、版本化、审核并更新 agent 中非代码的部分，这样你无需完整部署就能改变行为，并让领域专家拥有他们最了解的 context。

[Prompts](#prompts) 是你发送给模型的单个 message 模板。[Contexts](#context-hub) 是定义一个 skill 或完整 agent 的 instructions 和 tools 的版本化 bundle，通过环境晋升（promote）让 agents 拉取正确的版本。
