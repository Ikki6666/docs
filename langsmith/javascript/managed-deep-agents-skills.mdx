Skills 将特定任务的流程和支持文件打包为可复用的目录。MDA 会自动发现它们。只有当任务与 frontmatter 中的 description 匹配时，agent 才会加载某个 skill 的完整内容。

<ManagedDeepAgentsPublicBetaNote />

将每个 skill 放到项目根目录的 `skills/` 下：



```text
my-agent/
  agent.ts
  skills/
    research/
      SKILL.md
```


完整的项目布局请参见 [Project structure](/langsmith/javascript/managed-deep-agents-project-structure)。

## 添加 skill

当某个流程只应在任务与 frontmatter 中的 description 匹配时才被 agent 遵循，请使用 skill：

<Steps>
  <Step title="创建 skill 目录" id="create-a-skill-directory">

每个 skill 目录都需要一个带有 `name` 和 `description` frontmatter 的 `SKILL.md` 文件：

```markdown skills/research/SKILL.md
---
name: research
description: Gather and synthesize context before answering complex questions.
---

# Research

Use this skill when a task needs more than a direct answer.

1. Identify what information is missing.
2. Use `query_db` to look up relevant records.
3. Summarize findings before responding to the user.
```

skill 编写模式和完整格式请参阅 [Skills](/oss/javascript/deepagents/skills)。

要了解渐进式披露，请参阅 [How the agent uses skills](#how-the-agent-uses-skills)。

  </Step>
  <Step title="添加支持文件（可选）" id="add-supporting-files">

skill 目录还可以包含支持脚本、参考文件和模板。在 `SKILL.md` 中引用这些文件，让 agent 知道何时使用它们：



```text
skills/
  research/
    SKILL.md
    templates/
      report.md
    scripts/
      fetch_sources.ts
```


  </Step>
</Steps>

## agent 如何使用 skills

启动时，agent 会看到每个 skill 的 `name` 和 `description`。当任务与某个 skill 的 description 匹配时，agent 会读取完整的 `SKILL.md` 并遵循其 instructions。支持文件只在需要时才加载。

Agent 无法在运行时修改 skills。

## Deployment

运行 `mda deploy` 时，MDA 会将 `skills/` 下的每个 UTF-8 文件同步到该 agent 的 [Context Hub](/langsmith/javascript/managed-deep-agents-context-hub)。

之后，你可以在 LangSmith UI 中编辑 skills，并将这些更改应用到 agent。

对于持久性更改，最好将 skill 文件保留在仓库中作为唯一依据，因为后续的部署会再次同步项目副本，并删除本地不存在的已部署 skill 文件。

关于哪些内容会同步、哪些不会，以及如何从 deployment 打开仓库，请参阅 [Context Hub](/langsmith/javascript/managed-deep-agents-context-hub)。

## 何时使用 skills

| 概念 | 角色 | 加载时机 |
| --- | --- | --- |
| **[Instructions](/langsmith/javascript/managed-deep-agents-instructions)** | 始终生效的 system prompt | 每次 run |
| **Skills** | 特定任务的流程 | 当 agent 选中它们时 |
| **[Memory](/langsmith/javascript/managed-deep-agents-memory)** | agent 可以更新的知识 | 当 durable memory 启用时 |

更多信息请参见 [Project structure](/langsmith/javascript/managed-deep-agents-project-structure)。
