Instructions 定义始终生效的 agent 行为。它们构成 agent system prompt 的核心。

<ManagedDeepAgentsPublicBetaNote />

把 agent 的 instructions 放到项目根目录的 `instructions.md` 中：



```text
my-agent/
  instructions.md
```


完整的项目布局请参见 [Project structure](/langsmith/javascript/managed-deep-agents-project-structure)。

## 添加 instructions

创建或修改 `instructions.md` 来定义 agent 的角色、行为、约束以及使用其 tools 的指引：

```markdown instructions.md
# Assistant

You are a helpful assistant.
```

MDA 会在每次 run 时把 instructions 插入 agent 的 system prompt。
Agent 无法在运行时修改这些 instructions。

## 部署

当你运行 `mda deploy` 时，MDA 会把 `instructions.md` 同步到 agent 的 [Context Hub](/langsmith/javascript/managed-deep-agents-context-hub)。

之后你可以在 LangSmith UI 中编辑 instructions，并让这些更改应用到 agent。

对于持久更改，最好把 `instructions.md` 保留在 repo 中作为事实来源，因为后续部署会再次同步项目副本。

关于什么会同步、什么不会同步，以及如何从 deployment 打开 repo，请参见 [Context Hub](/langsmith/javascript/managed-deep-agents-context-hub)。

## 何时使用 instructions

| 概念 | 角色 | 加载时机 |
| --- | --- | --- |
| **Instructions** | 始终生效的 system prompt | 每次 run |
| **[Skills](/langsmith/javascript/managed-deep-agents-skills)** | 特定任务的操作流程 | 当 agent 选择它们时 |
| **[Memory](/langsmith/javascript/managed-deep-agents-memory)** | Agent 可以更新的知识 | 当持久 memory 启用时 |

更多信息请参见 [Project structure](/langsmith/javascript/managed-deep-agents-project-structure)。
