Managed Deep Agents (MDA) 是构建和部署生产级 agent 最简单的方式。你专注于 agent 做什么，MDA 负责运行它。无需运行服务器，也无需拼接基础设施。

你编写 agent 的智能部分：它的 instructions、可以调用的 tools、遵循的 skills，并选择驱动它的模型。MDA 提供底层的一切：

- **Deep Agents harness**：负责规划、调用 tools、管理文件系统以及委派给 subagents 的 agent loop。参见 [Deep Agents](/oss/javascript/deepagents/overview)。
- **托管运行时**：每个 deployment 都运行在 [LangSmith Agent Server](/langsmith/agent-server-overview) 上。你无需自己运维服务器，即可获得 Agent Server API、threads、runs、streaming 和 [MCP endpoint](/langsmith/javascript/managed-deep-agents-mcp-endpoint)。

## 核心能力

agent 的每个部分都映射到一个文件或目录。根据 agent 的需要添加相应部分：



| 能力 | 路径 | 说明 |
| --- | --- | --- |
| [模型与配置](/langsmith/javascript/managed-deep-agents-agent-definition) | `agent.ts` | 模型和核心选项。必填。 |
| [Instructions](/langsmith/javascript/managed-deep-agents-instructions) | `instructions.md` | 定义 agent 行为方式的 system prompt。 |
| [Skills](/langsmith/javascript/managed-deep-agents-skills) | `skills/` | agent 在相关时加载的、特定任务的 playbooks。 |
| [Tools](/langsmith/javascript/managed-deep-agents-tools) | `tools/` | agent 调用以运行你的应用逻辑或访问外部服务的函数。 |
| [MCP connectors](/langsmith/javascript/managed-deep-agents-mcp-connectors) | `tools/mcp.ts` | 为 agent 提供工具的远程 MCP 服务器。 |
| [Middleware](/langsmith/javascript/managed-deep-agents-middleware) | `middleware/` | 围绕模型和工具调用的自定义逻辑。 |
| [Sandbox](/langsmith/javascript/managed-deep-agents-sandboxes) | `sandbox/` | 用于运行 agent 编写代码的隔离文件系统和 shell。 |
| [Memory](/langsmith/javascript/managed-deep-agents-memory) | `memory.ts` | 跨 threads 持久化的偏好和知识。 |
| [Identity](/langsmith/javascript/managed-deep-agents-identity) | `identity.ts` | 多用户部署中每个调用者的私有 threads、memory 和凭据。 |
| [Channels](/langsmith/javascript/managed-deep-agents-channels) | `channels/` | 连接到消息服务（例如 Slack）的连接，用于启动 runs 并接收响应。 |
| [Schedules](/langsmith/javascript/managed-deep-agents-schedules) | `schedules/` | 按周期运行 agent 的托管 cron 调度。 |
| [Evals](/langsmith/javascript/managed-deep-agents-evals) | `evals/` | 用于测试 agent 的 Harbor 任务。 |


完整布局请参见 [Project structure](/langsmith/javascript/managed-deep-agents-project-structure)。Instructions、skills 和可选的持久 memory 存储在 [Context Hub](/langsmith/javascript/managed-deep-agents-context-hub) 中。

## 与 Deep Agents 的关系

Managed Deep Agents 运行的是开源 [Deep Agents](/oss/javascript/deepagents/overview) harness，而不是另一套框架。agent loop、文件系统 tools、subagents 和 skills 都相同，因此无需学习第二套 API，你已构建的 agent 也能继续工作。

Managed Deep Agents 增加的是 agent 外围的那一层。上文中的 sandbox、持久 memory、channels 和 schedules 都是项目文件中的声明，而不是你需要自行搭建和运维的服务。[Connections](/langsmith/javascript/managed-deep-agents-connections) 走 OAuth，由最终用户授权自己的账号，而不是由你为每个人预置凭据。LangSmith 将结果托管在 [Agent Server](/langsmith/agent-server-overview) 上。在代码层面，差异更小：由谁来编译 agent。



- [createDeepAgent](https://reference.langchain.com/javascript/deepagents/agent/createDeepAgent) 返回一个已编译的 agent。你负责运行它，并拥有它周围的 backend、store、checkpointer 和 server。
- `defineDeepAgent` 返回一个定义。`mda` CLI 会把它交给托管运行时，由运行时提供这些组件以及 memory、skills 和 system prompt，然后使用 [createDeepAgent](https://reference.langchain.com/javascript/deepagents/agent/createDeepAgent) 编译 agent。

因此 `defineDeepAgent` 接受与 [createDeepAgent](https://reference.langchain.com/javascript/deepagents/agent/createDeepAgent) 相同的选项，只是去掉了托管的部分，并增加一个必填的静态 `name`。每个 `define*` 函数都是如此：声明 agent 需要什么，把生命周期交给运行时。


当你需要自己运行 agent，或需要自己的 [backend](/oss/javascript/deepagents/backends)、store 或 checkpointer 时，请留在 Deep Agents。关于两者的详细对比，以及转换已有 agent 的步骤，请参见 [Move from Deep Agents](/langsmith/javascript/managed-deep-agents-migrate)。
