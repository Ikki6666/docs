---
title: 工作区密钥
description: 查找、添加、编辑和删除 LangSmith 在 LangSmith Cloud 和自托管 LangSmith 上调用模型 provider 和工具时使用的工作区密钥。
---

工作区密钥用于存储 LangSmith 调用模型 provider 和工具时使用的 API key。读取这些密钥的功能包括 [Playground](/langsmith/playground-model-providers)、[评估器](/langsmith/evaluation)、[Fleet](/langsmith/fleet/index) 和 [LLM Gateway](/langsmith/llm-gateway)。每个密钥都属于一个工作区。需要调用某个 provider 的工作区必须拥有该 provider key 的一份自己的副本。

## 所需权限

添加、编辑或删除工作区密钥需要在该工作区中拥有 `workspaces:manage-secrets` 权限。[Workspace Admins](/langsmith/rbac#workspace-admin) 默认拥有该权限。若无此权限，密钥页面会列出已有密钥，但隐藏添加按钮。在 LangSmith Cloud 和自托管 v0.18 或更高版本上，该页面还会显示通知，要求你联系工作区管理员。请让工作区管理员为你添加密钥，或授予你访问权限。

## 打开密钥页面

密钥页面在 **Settings** 中的位置取决于你的 LangSmith 版本：

<Tabs>
<Tab title="Cloud 和自托管 v0.18 或更高版本">
1. 打开 <Icon icon="settings" /> **Settings**。
1. 在侧边栏顶部选择 **Workspace**，然后选择需要该密钥的工作区。
1. 在 **Configuration** 下选择 **Secrets**（自托管 v0.18 上为 Provider Credentials）。

在个人组织中，侧边栏没有 **Workspace** 切换器。请在 **Configuration** 下选择 **Secrets**。

页面标题为 **Workspace Secrets**。你也可以在 **Settings** 搜索框中输入 `secrets` 来找到它。
</Tab>
<Tab title="自托管 v0.16 和 v0.17">
1. 为需要该密钥的工作区打开 <Icon icon="settings" /> **Settings**。
1. 选择 **Integrations** > Provider secrets。
</Tab>
</Tabs>

## 添加密钥

要添加工作区密钥：

1. [打开密钥页面](#open-the-secrets-page)。
1. 点击 **+ Secret**。
1. 在 **Provider** 下选择你的模型 provider。表单会显示一个以该 provider 期望的环境变量命名的字段，例如 `OPENAI_API_KEY`，并以该名称保存密钥。在该字段中输入你的 key；空输入框会显示 **Enter secret value**。某些 provider（例如 Amazon Bedrock）会要求你选择一种认证方式，并显示不同的字段。

   对于工具 key，或未列出的 provider，请将 **Custom** 保留为 provider。在 **Key** 中输入 provider 或工具期望的环境变量名称，并在 **Value** 中输入你的 key。

   在自托管 v0.16 上，该对话框没有 **Provider** 列表。请在 **Key** 中输入环境变量名称，并在 **Value** 中输入你的 key。
1. 点击 **Save**。

LangSmith 在保存密钥时不会检查该 key。错误的 key 会在第一次使用它的请求中表现为 provider 的错误。

## 编辑或删除密钥

要删除密钥，请点击其所在行中的 <Tooltip tip="Delete secret"><Icon icon="trash" /></Tooltip> 删除图标。如果页面显示 **Allowed hosts** 列，每一行还会有一个 <Tooltip tip="Edit secret"><Icon icon="pencil" /></Tooltip> 编辑图标，用于更改密钥的值、hosts 或 header。

## 各功能的密钥名称和设置

每个功能都会读取特定的密钥名称。provider 的默认名称由 **Provider** 列表自动填入。完整列表以及需要多个密钥的 provider，请参见：

- LLM Gateway 的 [Provider 密钥名称](/langsmith/llm-gateway-provider-authentication#add-a-provider-key)，包括 [Amazon Bedrock](/langsmith/llm-gateway-provider-authentication#configure-amazon-bedrock) 和 [Azure Foundry](/langsmith/llm-gateway-provider-authentication#configure-azure-foundry)。
- 高级代码评估器发送到外部服务的密钥的 [Allowed hosts](/langsmith/advanced-code-evaluators#configure-allowed-hosts-for-a-secret)。
- [Fleet 密钥](/langsmith/fleet/workspace-admin#workspace-secrets)，包括工具 key 以及在 Fleet 内优先的 `FLEET_` 前缀密钥。
- 决策模型评估器的[决策模型 provider](/langsmith/decision-model-evaluator)。

## 其他存储凭据的位置

- **OAuth 客户端凭据**：如果你的 provider 使用 OAuth2 `client_credentials` 进行认证，请改为在模型配置上配置这些凭据。请参见 [OAuth 客户端凭据](/langsmith/model-configurations#oauth-client-credentials)。
- **组织密钥**：存储在组织级别而不是某个工作区中的密钥。[组织范围的模型配置](/langsmith/llm-gateway-model-configurations)会读取组织密钥，而不是工作区密钥。
