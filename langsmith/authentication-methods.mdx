LangSmith 支持多种认证方式，方便你完成注册和登录。

## Cloud

LangSmith Cloud 支持以下登录方式。[BYOC](/langsmith/byoc) 组织通过 LangSmith Cloud control plane 登录，因此这些方式同样适用于它们。

- **邮箱和密码**：用户使用邮箱地址和密码注册并登录 LangSmith。
- **社交登录提供方**：用户使用 GitHub 或 Google 凭证登录。
- **SAML SSO**：企业版客户可以配置 [SAML SSO](/langsmith/user-management#set-up-saml-sso-for-your-organization) 和 [SCIM](/langsmith/user-management#set-up-scim-for-your-organization)。如需了解更多，请[预约演示](https://www.langchain.com/contact-sales)。
- **OIDC SSO**：企业版客户可以申请 [OIDC SSO](/langsmith/user-management#set-up-oidc-sso-for-your-organization)，使用自己的 OpenID Connect 身份提供方登录。请[联系支持团队](https://support.langchain.com)启用该功能。

## Self-Hosted

自托管客户可以更灵活地控制用户如何登录 LangSmith。关于更详细的配置选项，请参阅[自托管文档](/langsmith/self-hosted)和 [Helm chart](https://github.com/langchain-ai/helm/tree/main/charts/langsmith)。

### 使用 OAuth 2.0 和 OIDC 的 SSO

生产环境安装应配置 SSO，以便使用外部身份提供方。这样用户就可以通过 Auth0 或 Okta 之类的身份平台登录。LangSmith 支持几乎所有符合 OIDC 标准的提供方。更多信息请参阅 [SSO 配置指南](/langsmith/self-host-sso)。如需在 IdP 不可用时使用应急凭证，请参阅[恢复管理员登录](/langsmith/self-host-sso-recovery)。

### 邮箱/密码，也就是 basic auth

这种认证方式几乎不需要额外配置，因为它不依赖外部身份提供方。它最适合用于自托管试用环境。更多信息请参阅 [basic auth 配置指南](/langsmith/self-host-basic-auth)。

### None

<Warning>
这种认证模式会在 Basic Auth 发布后移除。
</Warning>

如果没有启用任何认证方式，自托管安装就不需要登录或注册。这种配置只适合在基础设施层验证安装是否成功，因为在该模式下支持的功能集会受到限制，只能使用单个组织和单个工作区。
