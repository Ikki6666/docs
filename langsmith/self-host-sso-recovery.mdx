---

如果你的身份提供方（IdP）发生故障或配置错误，[SSO 登录](/langsmith/self-host-sso)将停止工作，任何人都无法登录。恢复管理员登录允许指定的组织管理员使用本地密码登录，而不通过 IdP 登录。

当 SSO 对所有用户都失效时使用该功能，例如由于网络中断、证书过期、已下线的 IdP 租户，或任一侧的配置变更。它不是通用登录方式。请提前配置，并仅在故障期间使用。

<Note>
配置恢复管理员登录需要 v18 稳定线上的 LangSmith chart 版本 0.18.2（应用版本 0.18.2026112200）或更高版本，或 v19 线上的 chart 版本 0.19.0-rc.8（应用版本 0.19.3rc1）或更高版本。
</Note>

## 前置条件 {#prerequisites}

- [自托管](/langsmith/self-hosted) LangSmith，已配置带 client secret 的 [OAuth2.0/OIDC SSO](/langsmith/self-host-sso)（`authType: mixed`、`oauth.enabled: true`，并设置了 `oauthClientSecret`）。不支持使用 PKCE 的 OAuth，且必须禁用 basic auth。
- 一个现有且已启用的组织管理员身份，并且已通过 SSO 完成预配。恢复管理员登录以该身份进行身份验证；它不会创建新用户，也不会创建单独的凭据存储。

## 配置恢复管理员

要配置恢复管理员，请生成密码哈希，然后将该哈希值和管理员的邮箱添加到 Helm values 中。

### 1. 生成密码哈希

<Note>
需要 LangSmith CLI `v0.5.1` 或更高版本。
</Note>

你的 Helm 配置中仅保存恢复密码的哈希值，绝不保存明文。请使用 [LangSmith CLI](/langsmith/langsmith-cli#hash-a-recovery-password) 在本地生成 PBKDF2-SHA256 哈希：

```bash
langsmith auth hash-password
```

该命令会提示输入密码且不会回显，随后输出哈希值。它不需要登录或 API key。

### 2. 设置 Helm values

在你的 Helm values 中启用恢复管理员登录。将 `email` 设置为[前置条件](#prerequisites)中的组织管理员，并以内联方式或通过现有 Kubernetes secret 提供密码哈希：

<Tabs>
  <Tab title="内联">
    ```yaml Helm
    config:
      authType: mixed
      oauth:
        enabled: true
        # ...your existing OAuth configuration
      recoveryAdmin:
        enabled: true
        email: admin@example.com # Existing, enabled SSO organization admin
        passwordHash: "pbkdf2_sha256$600000$<salt>$<hash>" # From step 1
    ```
  </Tab>
  <Tab title="现有 secret">
    将该哈希添加到 secret 的 `recovery_admin_password_hash` 键下，并在 values 中省略 `passwordHash`。关于该 secret 包含的其他键，请参见[使用现有 secret](/langsmith/self-host-using-an-existing-secret#parameters)。

    ```yaml Helm
    config:
      existingSecretName: "langsmith-secrets"
      recoveryAdmin:
        enabled: true
        email: admin@example.com
    ```

    chart 不会将 `email` 视为敏感信息，因此即使哈希来自 secret，也请始终在 values 中设置它。
  </Tab>
</Tabs>

如果管理员身份已被禁用，或属于已禁用的组织，LangSmith 会像处理普通登录一样拒绝恢复登录。

## 在故障期间登录

登录界面没有恢复管理员登录的按钮。在未登录状态下，将 `?recovery=true` 追加到实例 URL：

```txt
https://langsmith.example.com/?recovery=true
```

**Log in via SSO** 界面会变为邮箱和密码表单。使用 `config.recoveryAdmin.email` 中的邮箱和第 1 步中生成哈希的密码登录。该会话以该组织管理员的身份进行身份验证，拥有该管理员现有的权限，并在 15 分钟后过期。

<Tip>
请将此 URL 记录到事件响应 runbook 中。UI 中没有任何链接指向它。
</Tip>
