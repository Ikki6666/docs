在 [LangSmith Agent Server](/langsmith/agent-server) 上将 agent 部署到生产环境。Agent Server 是面向 agent 工作负载的运行时，具备持久执行、实时流式输出和水平扩展能力。Agent Server hosting 围绕它提供基础设施和 deployment 管理。你可以部署到 Cloud、BYOC 或自己的基础设施，也可以在不使用 control plane 的情况下运行 standalone Agent Server。

<AgentServerRenameNote />

<Tip>
本页介绍你的 agent 在哪里运行。你在哪里运行 LangSmith 本身（用于 observability、evaluation 和 prompt engineering）是另一项独立的选择。更多信息请参阅 [Platform setup](/langsmith/platform-setup)。
</Tip>

## 选择托管环境

根据你希望 [control plane](/langsmith/control-plane) 和 [data plane](/langsmith/data-plane)（Agent Servers 及其数据库）运行的位置来选择一种环境。所有基础设施类型都使用同一个 [Agent Server](/langsmith/agent-server) runtime。

<CardGroup cols={2}>

<Card
  title="Cloud"
  cta="View guide"
  href="/langsmith/deploy-to-cloud-overview"
  icon="cloud"
>
由 LangChain 在 AWS、Azure 和 GCP 上全托管。你可以在 LangSmith UI 中从 GitHub 创建 deployment，或使用 [`langgraph deploy`](/langsmith/cli#deploy)。需要 [Plus plan 或更高版本](https://www.langchain.com/pricing)。
</Card>

<Card
  title="Self-hosted with control plane"
  cta="View guide"
  href="/langsmith/deploy-with-control-plane"
  icon="buildings"
>
在你自己的 Kubernetes 集群中运行 LangSmith Agent Server 的 control plane 和 Agent Server，与 self-hosted LangSmith 并存。需要开启 Agent Server hosting 的 [Enterprise plan](https://www.langchain.com/pricing)。
</Card>

<Card
  title="Hybrid"
  cta="View guide"
  href="/langsmith/hybrid"
  icon="cloud-network"
>
由 LangChain 托管的 control plane，配合部署在你自己基础设施中的 Agent Server 及其 data plane。Trace 会发送到 LangSmith Cloud 或 self-hosted LangSmith。
</Card>

<Card
  title="Standalone server"
  cta="View guide"
  href="/langsmith/deploy-standalone-server"
  icon="server"
>
使用 Docker、Compose 或 Kubernetes 部署 Agent Server。你需要自备 PostgreSQL、Redis 和 LangSmith license；不包含 control plane。可选地把 [LangSmith tracing](/langsmith/observability) 连接到 Cloud 或 self-hosted 实例。
</Card>

</CardGroup>

## 常见配置

- **为你的 agent 提供托管运行环境。** 基于 [Cloud](/langsmith/deploy-to-cloud-overview) 的 LangSmith Agent Server。由 LangChain 托管 control plane、data plane 和数据库。与 LangSmith Cloud 搭配使用。
- **agent 在你的 VPC 内，control plane 托管。** 基于 [Hybrid](/langsmith/hybrid) 的 LangSmith Agent Server。LangChain 托管 control plane；你托管 Agent Server 及其 data plane。与 LangSmith Cloud 或 self-hosted LangSmith 搭配使用。
- **完整数据驻留或离线环境。** [Self-hosted Agent Server hosting](/langsmith/deploy-with-control-plane)。你将 control plane 和 Agent Server 与 self-hosted LangSmith 一起部署在自己的基础设施中。
- **仅 agent runtime，不含 control plane。** [Standalone Agent Server](/langsmith/deploy-standalone-server)。使用 Docker 或 Kubernetes 运行 Agent Server container，无需 control plane，可选地把 trace 发送到 LangSmith Cloud 或 self-hosted。

## 了解计费

LangSmith Cloud 上的 Agent Servers 按每个 Agent Server 所请求的计算和数据库资源计费。

</Note>

## 部署之后

部署后的 agent 会采用 Agent Server 的执行模型：使用 **assistants** 管理配置，使用 **threads** 管理状态，使用 **runs** 表示工作负载。关于能力、认证、server 定制和教程，请参阅 [Agent Server](/langsmith/agent-server)。
