决策模型会对文本进行分类或打分，返回结构化的答案而不是生成的 chat 消息。通过 [LLM Gateway](/langsmith/llm-gateway) 调用它们，每个模型使用自己的 API：

| 模型 | API | Endpoint | 凭证 |
|-------|-----|----------|-------------|
| [TypeSafe (Jev)](#use-typesafe-jev) | System One | `/v1/systemone` | `TYPESAFE_API_KEY` provider secret |
| [OpenAI 决策模型](#use-openai-decision-models) | OpenAI Decisions | `/openai/v1/decisions` | `OPENAI_API_KEY` provider secret |

两种模型都需要工作区范围的 [LangSmith API key](/langsmith/create-account-api-key) 和对应的工作区 [provider secret](/langsmith/llm-gateway-admin-setup#1-add-provider-secrets)。在运行本页示例之前，请先设置你的 LangSmith API key：

```bash
export LANGSMITH_API_KEY="<your-api-key>"
```

## 使用 TypeSafe (Jev)

TypeSafe 决策模型通过 BYOK（自带 key）使用。把 `TYPESAFE_API_KEY` 配置为工作区 [provider secret](/langsmith/llm-gateway-admin-setup#1-add-provider-secrets)。创建 key 和安装 LangChain 集成请参见 [TypeSafe setup](/oss/python/integrations/providers/typesafe#setup)。

TypeSafe (Jev) 使用 System One API。把要评估的文本传入 `state`，把一个或多个命名问题传入 `questions`。System One 支持三种问题类型：

- **`noul`**：返回答案为真的概率。
- **`choice`**：把 state 分类到提供的选项之一。
- **`score`**：按 rubric 对 state 打分。

响应包含以问题名称为键的 `answers`，而不是 chat 消息。不支持流式。

`typesafe/` 前缀会把请求路由到你工作区的 TypeSafe provider secret。把 LangSmith API key（而不是 TypeSafe API key）传给 SDK 的 `api_key` 或 `apiKey`。SDK 请使用不带 `/v1` 的 gateway base URL：

<Tabs>
<Tab title="Python">

安装 TypeSafe SDK：

```bash
pip install typesafe-sdk
```

```python
import os

from typesafe_sdk import Noul, TypeSafeClient

client = TypeSafeClient(
    api_key=os.environ["LANGSMITH_API_KEY"],
    base_url="https://gateway.smith.langchain.com",
)

response = client.system_one(
    state="Hello!",
    model="typesafe/jev-1.13.0",
    questions={
        "is_helpful": Noul(
            instructions="Does this explain what an LLM gateway does?"
        ),
    },
)
```

</Tab>
<Tab title="JavaScript">

安装 TypeSafe SDK：

```bash
npm install @typesafe-ai/sdk
```

```javascript
import { noul, TypeSafeClient } from "@typesafe-ai/sdk";

const client = new TypeSafeClient({
  apiKey: process.env.LANGSMITH_API_KEY,
  baseURL: "https://gateway.smith.langchain.com",
});

const response = await client.systemOne({
  state: "Hello!",
  model: "typesafe/jev-1.13.0",
  questions: {
    is_helpful: noul("Does this explain what an LLM gateway does?"),
  },
});
```

## 使用 OpenAI 决策模型

OpenAI 决策模型使用 OpenAI Decisions API，它有自己的请求和响应格式，独立于 System One。gateway 通过 [direct model access](/langsmith/llm-gateway-direct-model-access) 支持 OpenAI Decisions API。把 `OPENAI_API_KEY` 配置为工作区 [provider secret](/langsmith/llm-gateway-admin-setup#1-add-provider-secrets)。

使用你工作区范围的 LangSmith API key，把请求发送到 `POST /openai/v1/decisions`。把 `model` 设置为不带 `openai/` 前缀的原生 OpenAI 模型名称：

```bash
curl https://gateway.smith.langchain.com/openai/v1/decisions \
    -H "Authorization: Bearer $LANGSMITH_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{
      "model": "gpt-6-luna",
      "input": "The package arrived with a broken screen.",
      "questions": [
        {
          "type": "predicate",
          "name": "damaged",
          "instructions": "Does the customer report a damaged item?"
        }
      ]
    }'
```

gateway 会保留原生的请求和响应格式：

```json
{
  "model": "gpt-6-luna",
  "answers": [
    {
      "type": "predicate",
      "name": "damaged",
      "probability": 1.0
    }
  ],
  "usage": {
    "input_tokens": 164,
    "input_tokens_details": {
      "cached_tokens": 0,
      "cache_write_tokens": 0
    },
    "output_tokens": 0,
    "output_tokens_details": {
      "reasoning_tokens": 0
    },
    "total_tokens": 164
  }
}
```

Gateway [访问](/langsmith/llm-gateway-model-access-policies)、[速率限制](/langsmith/llm-gateway-rate-limit-policies)和[预算策略](/langsmith/llm-gateway-spend-policies)适用于 Decisions 请求，token 用量也计入支出上限。gateway 会把每个请求追踪到 LangSmith，以请求作为输入，以答案和 token 用量作为输出。
