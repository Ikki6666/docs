[Claude Agent SDK](https://platform.claude.com/docs/en/agent-sdk/overview) 是一个用于使用 Claude 构建 agent 的 SDK。LangSmith 为 Claude Agent SDK 提供原生集成，可自动追踪你的 agent 执行、工具调用以及与 Claude 模型的交互。

<AgentTracingPrerequisite />

## Installation

安装 Claude Agent SDK 的 LangSmith 集成

<InstallClaudeAgentSdk/>

## Setup

将 traces 发送到 agent 在 Python 中需要 `langsmith>=0.14.9`，在 TypeScript 中需要 `langsmith@>=0.11.0`。

设置你的 [API keys](/langsmith/create-account-api-key)、agent 标识符和环境：

<CodeGroup>

```bash shell
export LANGSMITH_TRACING=true
export LANGSMITH_ENDPOINT=https://api.smith.langchain.com
export LANGSMITH_API_KEY=<your_langsmith_api_key>
export LANGSMITH_AGENT_ID="<your-agent-id>"
export LANGSMITH_AGENT_ENVIRONMENT="local"

export ANTHROPIC_API_KEY=<your_anthropic_api_key>
```

```dotenv .env
LANGSMITH_TRACING=true
LANGSMITH_ENDPOINT=https://api.smith.langchain.com
LANGSMITH_API_KEY=<your_langsmith_api_key>
LANGSMITH_AGENT_ID="<your-agent-id>"
LANGSMITH_AGENT_ENVIRONMENT="local"

ANTHROPIC_API_KEY=<your_anthropic_api_key>
```

</CodeGroup>

你可以在 [LangSmith UI](https://smith.langchain.com?utm_source=docs&utm_medium=cta&utm_campaign=langsmith-signup&utm_content=langsmith-trace-claude-agent-sdk) 的 **Settings** 中获取 LangSmith API key。请使用设置阶段选择的 agent 标识符和环境。

Anthropic API key 请参阅 [Claude console](https://console.anthropic.com/settings/keys)。

## Quickstart

要为 Claude Agent SDK 代码启用 LangSmith tracing，请在运行 agent 之前调用 `configure_claude_agent_sdk()`：

<ExampleQuickstart/>

配置完成后，所有 Claude Agent SDK 操作都会自动被追踪到 LangSmith，包括：

-   Agent 查询与响应
-   Tool 调用及结果
-   Claude 模型交互
-   MCP server 操作
