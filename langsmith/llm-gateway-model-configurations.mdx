[模型配置](/langsmith/model-configurations)是命名的、可复用的定义，它把 provider 和 model 与凭证及设置组合在一起。把 model ID 设置为 `custom/<name>` 时，LLM Gateway 就能通过一条已保存的配置来路由请求。当需要访问带 provider 前缀的 model ID 无法寻址的 endpoint 时，可以使用配置，例如自定义的 OpenAI 兼容 endpoint。

## 了解 gateway 使用了什么

bring-your-own-key gateway 调用通常指向一个带 provider 前缀 ID 的模型，例如 `openai/gpt-5.4-mini`。当 model ID 为 `custom/<name>` 时，gateway 会改为从已保存的配置中读取以下内容：

- **Provider 和 model**：gateway 会向上游发送配置中的模型名称，替换请求体中的 `custom/<name>` 值。
- **API key secret**：gateway 使用配置中指定的 workspace secret 向 provider 进行认证。
- **连接设置**：base URL、OpenAI provider API（Chat Completions 或 Responses），以及 Vertex AI 的 project 和 location，provider 会按需使用这些设置。

gateway 会忽略保存在配置上的生成参数，例如 temperature、top P 和 max output tokens。请改为在每次 API 请求中传入这些参数。

工作区管理员可以在 **Settings** > **Model configurations** 下创建配置。具体步骤请参见[创建配置](/langsmith/model-configurations#create-a-configuration)。

## 通过 gateway 调用配置

在任意标准 gateway 请求中，把 `custom/<name>` 用作 model ID，并将 `<name>` 替换为该配置在 **Settings** > **Model configurations** 中显示的准确名称：

<CodeGroup>

```bash Cloud
curl https://gateway.smith.langchain.com/v1/responses \
    -H "Authorization: Bearer $LANGSMITH_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{"model":"custom/my-openai-config","input":"Hello!"}'
```

```bash BYOC
curl https://<data_plane_host>/gateway/v1/responses \
    -H "Authorization: Bearer $LANGSMITH_API_KEY" \
    -H "Content-Type: application/json" \
    -d '{"model":"custom/my-openai-config","input":"Hello!"}'
```

</CodeGroup>

gateway 会在 API key 所属工作区中按名称查找配置，包括[组织范围的模型配置](/langsmith/model-configurations#organization-scoped-model-configurations)，将请求路由到配置的 provider 和 endpoint，并以 client 所使用的 [API 格式](/langsmith/llm-gateway-api-formats)返回响应。

已保存的配置不会出现在 `GET /v1/models` 列表中，因此请直接与开发者共享配置名称。

如果某条[模型访问策略](/langsmith/llm-gateway-model-access-policies#allow-saved-model-configurations)适用于该请求，该策略必须允许已保存的模型配置，否则 gateway 会返回 `403` 响应。

## 在 fallback 链中使用配置

一条 [fallback 链](/langsmith/llm-gateway-fallbacks)可以在两个位置使用已保存的配置：

- **作为主模型**：将该配置选为链的主模型。发往 `custom/<name>` 的请求随后会回退到链的备用模型。
- **作为 fallback candidate**：将该配置添加为备用模型之一。发往链主模型 model ID 的请求随后可以回退到该配置的 endpoint。

要让 Playground prompt 拥有自己的 fallback 行为，把 prompt 的模型设置为 `custom/<name>`，并将一条链附加到该配置。具体步骤请参见[为 prompt 设置 fallback](/langsmith/llm-gateway-fallbacks#set-fallbacks-for-a-prompt)。
