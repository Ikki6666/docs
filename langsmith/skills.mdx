Agent Skills 是可复用、按需启用的能力包，包含面向 coding agent 的说明。[`langchain-skills`](https://github.com/langchain-ai/langchain-skills) 插件包含用于处理 LangSmith 的 skills：添加 tracing、构建 datasets 和 evaluators、运行 experiments，以及在生产环境中监控 agents。同一插件还涵盖使用 LangChain、LangGraph 和 Deep Agents 构建 agents。如果希望直接在终端中处理 LangSmith 数据，请使用 [LangSmith CLI](/langsmith/langsmith-cli)。

这些 skills 会随版本变化。要查看当前列表，请浏览 [`skills` 目录](https://github.com/langchain-ai/langchain-skills/tree/main/skills)，或者在 agent 中列出 skills。

<Note>
LangSmith skills 已从已弃用的 `langsmith-skills` repository 迁移到 `langchain-skills`，旧仓库不再接收更新。要切换，请参阅[从 `langsmith-skills` 迁移](#migrate-from-langsmith-skills)。
</Note>

## 安装插件 {#install-the-plugin}

该插件将 skills 与连接 LangChain 文档和 API reference 的 MCP 连接打包在一起。推荐通过安装插件来使用。

<CodeGroup>
```text Claude Code
/plugin marketplace add langchain-ai/langchain-skills
/plugin install langchain-skills@langchain-skills
```

```bash Codex
codex plugin marketplace add langchain-ai/langchain-skills
codex plugin add langchain-skills@langchain-skills
```

```bash Deep Agents Code
dcode plugin marketplace add langchain-ai/langchain-skills
dcode plugin install langchain-skills@langchain-skills
```
</CodeGroup>

请在 Claude Code 会话中运行这些 Claude Code 命令。使用 Claude Code v2.1.292 或更高版本时，也可以改为在 shell 中用一条命令安装：

```bash
claude plugin install langchain-skills --marketplace langchain-ai/langchain-skills
```

## 开启自动更新 {#turn-on-auto-update}

这些 skills 经常会变化。请开启自动更新，以便 agent 加载当前指南，而不是过时的副本：

- **Claude Code**：Claude Code 对第三方 marketplaces 默认关闭自动更新。运行 `/plugin`，前往 **Marketplaces**，选择 `langchain-skills`，然后选择 **Enable auto-update**。如需立即更新，请运行 `/plugin marketplace update langchain-skills`。
- **Deep Agents Code**：该插件默认加入后台更新。更新后，请运行 `/reload` 或启动新会话。
- **Codex**：通过本地 Git marketplace 安装时没有文档化的自动更新设置。请运行 `codex plugin marketplace upgrade langchain-skills` 进行更新。

更新后，请启动新的 agent 会话以加载更新后的 skills。对于脚本化设置和托管工作区，请参阅仓库 README 中的 [Updates](https://github.com/langchain-ai/langchain-skills#updates) 部分。

## 仅安装 skills {#install-skills-only}

如果要在不安装插件的情况下安装 skills，请使用 `npx skills`。此方式不会注册文档 MCP servers。

<CodeGroup>
```bash Local (current project)
npx skills add langchain-ai/langchain-skills --skill '*' --yes
```

```bash Global (all projects)
npx skills add langchain-ai/langchain-skills --skill '*' --yes --global
```

```bash Link to a specific agent (for example, Claude Code)
npx skills add langchain-ai/langchain-skills --agent claude-code --skill '*' --yes --global
```
</CodeGroup>

<Tip>
`npx skills` 不会自动更新。要更新，请运行 `npx skills update`，然后启动新的 agent 会话。
</Tip>

针对其他 agents 以及从克隆的代码检出中安装，请参阅仓库 README 中的 [Installation](https://github.com/langchain-ai/langchain-skills#installation) 部分。

## 连接到 LangSmith {#connect-to-langsmith}

安装插件或 skills 不需要 LangSmith API key。要让 coding agent 查询或管理 LangSmith workspace，请在同一台机器上安装 [LangSmith CLI](/langsmith/langsmith-cli#install) 并进行身份验证：

```bash
langsmith auth login
```

身份验证期间请选择目标 workspace。对于自托管实例和 profiles，请参阅 [Authenticate](/langsmith/langsmith-cli#authenticate)。

要追踪或评估你构建的应用，请使用 [LangSmith API key](/langsmith/create-account-api-key) 配置 LangSmith SDK。将 key 设置为 `LANGSMITH_API_KEY` 环境变量，并使其远离源代码管理。

## 从 `langsmith-skills` 迁移 {#migrate-from-langsmith-skills}

在安装 `langchain-skills` 之前，请先移除 `langsmith-skills` skills，以免 agent 加载两套重叠的指南：

- **Claude Code plugin**：运行 `claude plugin marketplace remove langsmith-skills`，这也会卸载该 plugin。
- **`npx skills`**：先运行以下命令一次，然后在每个安装过 skills 的项目中，去掉 `--global` 再运行一次：

  ```bash
  npx skills remove langsmith-trace langsmith-dataset langsmith-evaluator \
    langsmith-custom-apps langsmith-experiment-diagnosis \
    langsmith-graph-evaluator langsmith-online-eval-engineering --global --yes
  ```

- **`install.sh` 或复制的文件夹**：从你安装过的每个 skills 目录中删除 `langsmith-*` 文件夹，例如 `~/.claude/skills/`、`.claude/skills/`、`~/.agents/skills/` 或 `.agents/skills/`。

有关每种安装方式的准确命令，请参阅仓库 README 中的[从独立 skills 迁移](https://github.com/langchain-ai/langchain-skills#migrate-from-the-standalone-skills)部分。然后[安装插件](#install-the-plugin)并[开启自动更新](#turn-on-auto-update)。
