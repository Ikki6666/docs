## 在 agents 之间切换

agent 切换器位于顶栏左侧，在 workspace 切换器和面板折叠开关之后。它显示 **All agents** 或你当前所在 agent 的名称。在 Overview 以外的 section 中，切换器后面会跟随一个 breadcrumb，标明该 section。

它背后的地址为 `/o/<workspaceId>/a/<agentIdentifier>/...`。workspace 位置接受 UUID，agent 位置接受该 agent 的 [identifier](/langsmith/agents#identifiers-and-display-names)。agent 位置中的连字符表示所有 agents，因此 `/a/-` 是 **All agents** 视图，`/a/<agentIdentifier>` 是单个 agent。两种状态都可以通过地址栏设置，这也是直接链接到其中某个视图的方式。

## All agents 与单 agent 视图

切换器在两个视图之间切换：

- **All agents**：agent 列表，workspace 中的每个 agent 对应一张卡片。在空的 workspace 中，它会转而显示一个 get-started 界面，介绍 [**New Agent** 面板](/langsmith/create-an-agent#start-from-the-new-agent-panel)中的选项，并通过一个 **Get started** 按钮打开该面板。
- **单个 agent**：该 agent 的 Overview。

左侧导航在两种视图中列出相同的条目，只是第一行在 agent 列表中显示为 **All agents**，在 agent 内部显示为 **Overview**。以下两点有所不同：

- **Badge 计数**：在 agent 列表中隐藏（Deployments 除外）。选择某个 agent 后，计数会显示出来，并且只涵盖该 agent。
- **Section 可用性**：某些 section 会要求你先选择一个 agent。请参阅[需要选择 agent 的 section](#需要选择-agent-的-section)。

## 需要选择 agent 的 section

大多数 section 在选中 **All agents** 时都能正常工作，包括列出 workspace 中每个 agent 的 agent 列表，以及列出 workspace 中每个 deployment 的 Deployments。Engine、Studio、Build、Tracing 和 Monitoring 则需要你选择一个 agent。如果在选中 **All agents** 的情况下打开这些 section，你看到的内容取决于 workspace 中是否已有 agents。

如果 workspace 中已有 agents，该 section 会显示一个可搜索的 agent 列表供你选择，标题为 **Pick an agent to view**。在 Build 中，该列表则显示在 "Configure an existing agent or build a new one." 文案下方。顶栏保持不变，因此你也可以从切换器中选择。列表下方，Studio 显示 **Connect Agent Server**，Build 显示 **+ New agent**。对于可以创建 projects 的用户，Tracing 也会显示 **+ New agent**。Build 只列出[在 UI 中构建的](/langsmith/build-an-agent) agents。其他 section 则列出 workspace 中的所有 agents。

如果 workspace 中没有 agents，Engine、Studio、Tracing 和 Monitoring 会显示空列表，并提示 **No agents available**。只要 workspace 中没有在 UI 中构建的 agents，Build 就会显示同样的空列表，即使存在其他 agents 也是如此，此时其 **+ New agent** 按钮仍可用于创建新 agent。Deployments 会显示自己的页面，在 workspace 中还没有 deployment 时提供创建首个 deployment 的方式。

选择某个 agent 后，在这些 section 之间切换时 LangSmith 会保持该 agent 处于选中状态。要查看 **All agents** 的 agent 列表，请在切换器中悬停于所选 agent 的名称上，然后选择旁边出现的 **X**。

## 打开 Settings

Settings 在其独立的布局中打开：agent 切换器消失，导航拆分为 Organizations 和 Workspace 两个部分，并有一个 **Back to LangSmith** 链接可返回 agent 视图。

## 查看 agent Overview

选择某个 agent 后，LangSmith 会打开其 Overview。

切换器显示该 agent 的 display name。一个标有 **ID** 的字段旁边带有复制按钮，其中保存的是 identifier，也就是地址栏携带的值。**ID** 字段会在中间缩短较长的 identifier。

在 tracing 中需要该值时，请使用 **ID** 旁边的复制按钮。[Agent 寻址](/langsmith/log-traces-to-agent)使用的是 identifier，而不是 display name。关于哪个值对应哪个，请参阅[Identifiers and display names](/langsmith/agents#identifiers-and-display-names)。

在 **ID** 字段下方，Overview 依次显示以下内容：

- **Metrics**：trace 数量、错误率、token 数量和总成本，各自覆盖所有环境中最近 7 天的固定周期。行首是 traces 随时间变化的 sparkline。
- **Tracing**：该 agent 的每个 environment 对应一行，包括没有 traces 的环境，显示最近的 run、trace 数量、错误率、P50 latency、P99 latency 和 description。
- **Engine**：[Engine](/langsmith/engine-overview) 在该 agent 的各环境中发现的活动 issues 数量，以及一个 **Go to Engine** 链接。
- **Evaluate your agent**：介绍基于 datasets 和线上生产 traces 的评估，并提供指向 [evaluators](/langsmith/evaluators) 的 **Go to evaluators** 链接。
- **Monitor your agent**：介绍如何使用 dashboards、alerts 和 feedback 监控 agent，从单个 traces 到覆盖生产的 metrics，并提供指向 [dashboards](/langsmith/dashboards) 的 **Go to dashboards** 链接。
- **Deployments**：通过[部署到 agent environment](/langsmith/deploy-to-agent-environment) 中的步骤绑定到该 agent 的 [deployments](/langsmith/deployment)。每行都链接到对应的 deployment。没有 deployments 时，该 section 会说明 deployment 是什么，并且不显示任何行。关于哪些 agent 会显示此 section，请参阅[对比四种路径](/langsmith/create-an-agent#compare-the-four-routes)。
