---
title: Preview builds
description: 为 pull requests 创建临时的 preview Agent Server，以便在合并之前测试 Agent Server 的变更。
---

Preview builds 为 pull requests 创建临时的 **preview Agent Servers**。使用 preview Agent Server 可以在将变更合并到运行 parent Agent Server 的分支之前，先在隔离环境中测试它们。

当 pull request 触发 preview build 时，LangSmith 会将源分支上的最新 commit 构建为 preview Agent Server 的第一个 revision。之后对该分支的每个 commit 都会触发一个新的 revision。

<Note>
Preview builds 目前处于 public beta 阶段，仅适用于 LangSmith Cloud 上通过 GitHub integration 创建的 Agent Server。
</Note>

## 启用 preview builds

要启用 preview builds：

1. 在 **Agent Servers** 视图中，选择一个 Agent Server。
1. 在右上角，选择齿轮图标（**Agent Server Settings**）。
1. 滚动到 **Preview Builds** 部分。
1. 选择 **Enable preview builds**。
1. 设置 **Base Branch**，或将其留空以使用该 Agent Server 的 Git ref。
1. 在 **Create Previews For** 中，选择一种触发模式：
   - **Every pull request**：进入 base branch 的 pull requests 都会触发 preview builds，来自 fork 的除外。
   - **Labeled pull requests**：当 pull request 带有精确的 **Trigger Label** 时触发 preview build。移除该 label 会删除对应的 preview。
1. 配置 preview 限制：
   - **Idle Timeout (Hours)**：在超过该时长没有 pull request 活动（例如新的 commits）后删除 preview。留空则保留该 preview，直到 pull request 关闭。此设置适用于新的 previews。
   - **Preview Limit**：parent Agent Server 可拥有的 preview Agent Servers 最大数量。超过限制的 pull requests 在另一个 preview 关闭之前不会获得 preview。
1. 选择 **Save**。

## 管理 secrets

LangSmith 创建 preview Agent Server 时，它会继承 parent Agent Server 的 secrets。你可以在 preview Agent Server 上覆盖这些继承的 secrets。

对 parent Agent Server 的 secrets 所做的变更不会传播到已有的 preview Agent Servers。

## 删除 preview Agent Server {#delete-preview-deployments}

当 preview Agent Server 的 pull request 关闭、其 trigger label 被移除，或配置的 idle timeout 过期时，LangSmith 会将其删除。你也可以随时手动删除它。

删除 parent Agent Server 会删除它的所有 preview Agent Servers。
