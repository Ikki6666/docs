---
title: 监控 deployment
description: 查看 LangSmith Cloud deployment 的 build logs、server logs 和指标。
---

使用 build logs、Agent Server logs 和 runtime metrics 监控 Cloud deployment。使用 logs 调查特定的 revision，使用 metrics 跟踪 deployment 随时间的表现。

## 查看 deployment logs

每个 revision 都包含 build logs 和 server logs。

<Tabs>
  <Tab title="LangSmith UI">
    在 **Deployments** 视图中：

    1. 选择一个 deployment。
    1. 在 **Revisions** 表格中，选择一个 revision。详细信息面板会打开，并选中 **Build** 标签页。
    1. 查看 build logs。
    1. 选择 **Server** 标签页查看 server logs。Server logs 在 LangSmith 部署该 revision 之后可用。
    1. 根据需要调整日期和时间范围。默认范围为 **Last 7 days**。
  </Tab>
  <Tab title="LangGraph CLI">
    要查看 server logs，请运行：

    ```shell
    langgraph deploy logs
    ```

    要查看 build logs，请运行：

    ```shell
    langgraph deploy logs --type build
    ```

    要流式查看新 logs，请运行：

    ```shell
    langgraph deploy logs --follow
    ```

    按时间范围、日志级别或搜索字符串过滤 logs：

    ```shell
    langgraph deploy logs --start-time 2026-03-01T00:00:00Z --level ERROR
    ```

    要选择一个 deployment，请传入其名称或 ID：

    ```shell
    langgraph deploy logs --name my-agent
    langgraph deploy logs --deployment-id <DEPLOYMENT_ID>
    ```

    所有选项请参阅 [`deploy logs` CLI reference](/langsmith/cli#deploy-logs)。
  </Tab>
</Tabs>

## 将 server logs 转发到 Datadog

要将 Agent Server logs 转发到 Datadog，在该 deployment 上配置这些环境变量或 secrets：

- **`DD_API_KEY`**：你的 [Datadog API key](https://docs.datadoghq.com/account_management/api-app-keys/)。
- **`DD_LOGS_ENABLED=true`**：启用日志转发。

要将 logs 与 traces 关联，同时设置 `DD_LOGS_INJECTION=true`。所有受支持的 Datadog 变量请参阅 [Supported Datadog environment variables](/langsmith/env-var#dd_api_key)。

## 查看 deployment 指标

要查看 deployment 指标：

1. 在 [LangSmith UI](https://smith.langchain.com?utm_source=docs&utm_medium=cta&utm_campaign=langsmith-signup&utm_content=langsmith-monitor-deployment) 中，选择 **Deployments**。
1. 选择一个 deployment。
1. 选择 **Monitoring** 标签页。指标定义请参阅 [Control plane monitoring](/langsmith/control-plane#monitoring)。
1. 根据需要调整日期和时间范围。默认范围为 **Last 15 minutes**。
