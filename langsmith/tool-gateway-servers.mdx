MCP 服务器是 [Tool Gateway](/langsmith/tool-gateway) 提供给 agent 的工具的来源。Tool Gateway 支持两种类型的服务器：

- **你添加的服务器**：你注册的任何远程 MCP 服务器，以及它所需的凭证类型。
- **内置服务器**：LangSmith 为常用服务托管的服务器。它们在每个工作区中都可使用，无需注册。

添加服务器只是声明它需要什么凭证，并不会存储凭证。随后由每个用户、agent 或 profile 连接各自的账户。请参阅[连接账户](/langsmith/tool-gateway-connect-accounts)。

## 添加你自己的 MCP 服务器

服务器必须使用基于 HTTPS 的 Streamable HTTP。Workspace Admin 可以为整个工作区添加服务器。Workspace Editor 只能添加个人服务器。

在 UI 中：

1. 进入 **Tools** > **MCP servers**，然后点击 **Add MCP server**。
1. 输入名称和该服务器的 URL。
1. 如下一节所述，选择该服务器需要什么凭证，然后保存。

在 API 中，发送 `POST /v1/managed-tools/servers`，携带 `name`、`upstream_url` 和 `connection`。请使用个人访问令牌，因为服务密钥不能添加服务器。完整请求示例请参阅[快速入门的第 1 步](/langsmith/tool-gateway-quickstart#step-1-add-mcp-servers)。

### 选择服务器所需的凭证

每个服务器都会声明它在每次调用时对 Tool Gateway 的期望。在 API 中，`connection` 字段承载这一声明。如果你添加的是使用 **API key** 的工作区服务器，并希望存储一个共享密钥，还需发送 `credential` 字段；请参阅[连接账户](/langsmith/tool-gateway-connect-accounts)。

- **Public**：该服务器无需登录。
  - UI：**Public**
  - API：`"connection": {"type": "none"}`
- **OAuth**：每个所有者在连接时使用该服务登录。
  - **Automatic OAuth**：LangSmith 根据服务器自身的 OAuth 设置来配置 OAuth。在 UI 中，选择 **OAuth** > **Automatic OAuth**。在 API 中，使用 `"connection": {"type": "oauth"}`。
  - **Manual OAuth**：使用已有的 [Agent Auth](/langsmith/agent-auth) 连接，例如你自己的 OAuth 应用。仅限管理员。在 UI 中，选择 **OAuth** > **Manual OAuth**，然后选择该连接。在 API 中，使用 `"connection": {"type": "oauth", "agent_auth_connection_slug": "<slug>"}`。
- **API key**：该服务器期望在某个请求头中携带 API 密钥。请指定该请求头，每个所有者在连接时输入自己的密钥。
  - UI：选择 **API key**，然后输入请求头名称，例如 `X-Api-Key`。
  - API：

    ```json
    "connection": {
      "type": "secret",
      "fields": [{"name": "X-Api-Key", "injection": {"type": "header", "name": "X-Api-Key"}}]
    }
    ```

对于使用 **API key** 的工作区服务器，管理员也可以为所有调用方存储一个共享密钥。请参阅[连接账户](/langsmith/tool-gateway-connect-accounts)。

如果添加服务器时返回 “This MCP server isn't supported yet”，说明 Tool Gateway 无法自动配置 OAuth。响应中的 `detail` 会给出原因。如果该服务器不使用 OAuth，请以 **Public** 或 **API key** 方式添加。如果它需要你在提供商处注册的 OAuth 应用，请使用 **Manual OAuth**。

### 选项

- **Personal server**：在添加服务器前选择 **Personal**（API：`"scope": "personal"`）。只有你能使用它，工作区工具包也不能包含它。
- **Private network**：使用[隧道](/langsmith/tunnels) URL 作为服务器 URL，并配合 **Manual OAuth** 或 **API key**。

## 使用内置服务器

内置服务器列在 **Tools** > **MCP servers** 上。在 API 中，内置服务器的 `"owner"` 为 `"langsmith"`，其 `id` 是一个固定的 key，例如 `parallel`。

| 凭证 | 内置服务器 |
|------------|------------------|
| 无 | Base、Parallel |
| OAuth | Excel、GitHub、Gmail、Google BigQuery、Google Calendar、Google Docs、Google Drive、Google Meet、Google Sheets、Google Slides、Linear、LinkedIn、OneDrive、Outlook、PowerPoint、Salesforce、SharePoint、Slack、Teams、Word、X |
| API key | Apollo、Ashby、Exa、Pylon、Tavily |

需要凭证的内置服务器仍需要一个[已连接的账户](/langsmith/tool-gateway-connect-accounts)。

## 列出服务器

```bash
curl -sS "$LANGSMITH_ENDPOINT/v1/managed-tools/servers" \
  -H "X-Api-Key: $LANGSMITH_API_KEY" \
  -H "X-Tenant-Id: $LANGSMITH_WORKSPACE_ID"
```

该列表包含工作区服务器、你的个人服务器以及内置服务器。如果 `next_cursor` 不为 null，请将其作为 `cursor` 查询参数传入以获取下一页。

## 移除服务器

在 UI 中，打开该服务器所在行的操作菜单并将其删除。在 API 中：

```bash
curl -sS -X DELETE "$LANGSMITH_ENDPOINT/v1/managed-tools/servers/<server-id>" \
  -H "X-Api-Key: $LANGSMITH_API_KEY" \
  -H "X-Tenant-Id: $LANGSMITH_WORKSPACE_ID"
```
