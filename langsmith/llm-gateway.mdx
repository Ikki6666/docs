LLM Gateway 是你所运行的 agents 和应用与工作区已配置的 model providers 之间的控制层。由于 gateway 是 LangSmith 的一部分，它路由的每次调用都会成为一条 LangSmith trace，记录为该调用做出的路由和策略决策。你的应用使用 [LangSmith API key](/langsmith/create-account-api-key) 进行认证。gateway 会把每个请求路由到其 model ID 所指定的 provider，追踪这次调用，并应用你组织的治理策略。

如果不使用 gateway，每个应用程序和部署都各自持有 provider keys，可靠性、支出和数据控制也需要针对每个 provider 账户分别设置。使用 gateway 后，provider keys 保留在 LangSmith 中，并且[模型回退](/langsmith/llm-gateway-fallbacks)、[支出限制](/langsmith/llm-gateway-spend-policies)、[速率限制](/langsmith/llm-gateway-rate-limit-policies)和 [data policies](/langsmith/llm-gateway-data-policy) 会作用于其范围内的每次调用。当触发 fallback 或策略阻止某次调用时，[trace](/langsmith/llm-gateway-traces) 会显示每次尝试和策略检查。此外，策略违规会出现在 [LangSmith Engine](/langsmith/engine) 中，以便分类处理。

## 选择请求格式

gateway 接受 OpenAI Chat Completions、Anthropic Messages 和 OpenAI Responses 请求。请求格式与 provider 相互独立：一个 Chat Completions 请求可以调用 Anthropic 模型，当 provider 使用不同的原生格式时，gateway 会转换请求和响应。请保留应用当前使用的格式，并通过更改 model ID 来切换 provider。有关 endpoint、model ID 语法和转换行为，请参见 [API 格式](/langsmith/llm-gateway-api-formats)。

LangChain chat models 和 Deep Agents 通过 `LANGSMITH_GATEWAY` 环境变量访问 gateway，该变量使用 [direct model access](/langsmith/llm-gateway-direct-model-access)，采用各 provider 的原生格式，因此不会发生转换。

## 选择凭证的管理方式

gateway 使用 LangSmith 持有的凭证调用每个 provider：你自己的 provider key（以工作区 secret 的形式存储），或者 [Gateway Credits](/langsmith/llm-gateway-credits)（由 LangChain 计入你的 LangSmith 账户）。关于所有凭证来源及各自的计费方，请参见 [Provider 认证](/langsmith/llm-gateway-provider-authentication#choose-a-credential-source)。
