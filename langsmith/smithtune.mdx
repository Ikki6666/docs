<Note>
Smithtune 处于 [beta](/langsmith/release-stages) 阶段。
</Note>

Smithtune 是一个命令行工具，用于基于 LangSmith 中记录的 [trajectories](/langsmith/observability-concepts#trajectories) 微调模型。它使用 [Fireworks](https://fireworks.ai/) 或 [Baseten](https://www.baseten.co/) 训练模型，并在 LangSmith [experiment](/langsmith/evaluation-concepts#experiment) 中比较基础模型和微调后的模型。你可以选择将微调后的模型部署为应用程序可用的 endpoint。

## Smithtune 的工作方式

<Steps>
  <Step title="创建 dataset">
    使用 [trace query](/langsmith/trace-query-syntax) filter、model judge 或两者，从 tracing project 中选择 trajectories。
  </Step>
  <Step title="准备数据">
    验证 trajectories，然后将它们划分为训练、验证和测试数据。每条 trajectory 只保留在一个划分中。
  </Step>
  <Step title="训练模型">
    预览 run，然后使用你的 provider 微调受支持的模型。
  </Step>
  <Step title="比较结果">
    在测试数据上评估基础模型和微调后的模型，然后在 LangSmith 中[比较 experiments](/langsmith/compare-experiment-results)。评估不需要已部署的 endpoint。
  </Step>
  <Step title="部署 endpoint（可选）">
    为你的应用程序提供微调后的模型。要在生产中运行使用它的 agent，请参阅 [LangSmith Deployment](/langsmith/deployment)。
  </Step>
</Steps>

<Tip>
要让你的 coding agent 端到端地驱动微调流程，请使用 [Smithtune skill](https://github.com/langchain-ai/smithtune/blob/main/src/smithtune/skills/smithtune/SKILL.md)。
</Tip>

评估分数衡量的是每个模型与已记录行为的接近程度，而不是它能否端到端地完成任务。Smithtune 不会执行模型生成的 tool calls。

## 设置 Smithtune

Smithtune 需要 tracing project 或 LangSmith trajectory dataset 中的 trajectories。你还需要 LangSmith、你的训练 provider 以及 judge model 的 API keys。训练、评估和已部署的 endpoints 会产生你所使用服务的费用。

设置 Smithtune 的步骤：

1. 安装 Smithtune 和 [LangSmith CLI](/langsmith/langsmith-cli)，并设置你的 API keys。安装命令和每个 provider 所需的环境变量请参阅 [Smithtune README](https://github.com/langchain-ai/smithtune#readme)。
1. 阅读 [README](https://github.com/langchain-ai/smithtune#readme) 中链接的[data rights and permitted use terms](https://github.com/langchain-ai/smithtune/blob/main/docs/data-rights-and-permitted-use.md)，然后在首次运行前确认接受：

    ```bash
    smithtune acknowledge-data-rights
    ```

1. 检查你的本地设置：

    ```bash
    smithtune doctor
    ```

每个步骤中的命令请参阅 [README](https://github.com/langchain-ai/smithtune#readme)，或运行 `smithtune --help`。
