<Warning>
以下数字仅供估算。Google Cloud 可能随时调整价格，恕不另行通知。实际费用取决于 region、用量和你享有的 Google Cloud 折扣，例如承诺使用折扣。
</Warning>

以下为 [GCP 上的 LangSmith BYOC data plane](/langsmith/byoc-architecture-gcp) 的月度成本估算。GCP data plane 使用 SmithDB，且不运行 ClickHouse。

估算采用 `us-west1` 的美元按需标价，按每月 730 小时计算。估算未计入 Google Cloud 自动应用于 N2 和 N2D 虚拟机的持续使用折扣。数据库、Redis 和节点池使用新建 data plane 的默认规格。应用和 SmithDB 的节点数以 LangChain 运营的低追踪量测试 data plane 为基准。LangSmith 根据追踪量增加容量。

<Note>
只要部署仍在安全运行范围内，就可以按需降低任何资源的扩容上限。
</Note>

<a id="rough-monthly-estimate"></a>

## 月度成本估算

下表不含沙箱。参见[沙箱附加费用](#sandbox-add-on)。

| 项目 | 月度成本估算 | 说明 |
| --- | --- | --- |
| GKE 集群管理 | 约 \$73 | 一个区域级 GKE 集群，每小时 \$0.10。 |
| 系统节点池 | 约 \$455 | 3 个 `n2-standard-4` 节点，每个可用区一个。每个节点配备 100 GB 平衡永久磁盘作为启动盘。 |
| 应用工作节点 | \$800–\$1,600 | GKE 节点自动预配为 LangSmith pod 创建 4 到 8 个 `e2-standard-8` 节点，每个配备 100 GB 标准永久磁盘作为启动盘。 |
| SmithDB 节点 | \$637–\$1,274 | 1 到 2 个 `n2-standard-16` 节点，每个配有 2 块本地 SSD（750 GB），供 SmithDB 查询、摄取和压缩工作进程使用。节点池最多可扩容到 16 个节点。 |
| Cloud SQL for PostgreSQL（LangSmith） | 约 \$214 | PostgreSQL 18，Enterprise 版，`db-custom-2-7680`（2 个 vCPU，7.5 GB），启用高可用性，配备 50 GB SSD 存储。 |
| Cloud SQL for PostgreSQL（SmithDB metastore） | 约 \$195 | PostgreSQL 18，Enterprise 版，`db-custom-2-4096`（2 个 vCPU，4 GB），启用高可用性，配备 100 GB SSD 存储。 |
| Memorystore for Redis Cluster | 约 \$46 | 1 个分片，1 个副本，共 2 个 `REDIS_SHARED_CORE_NANO` 节点。 |
| 网络 | \$50–\$150 | Cloud NAT、入口负载均衡器、连接 LangSmith control plane 的 Private Service Connect endpoint、外部 IP 地址，以及少量数据处理。 |
| Cloud Storage、Secret Manager、Cloud Logging、Cloud Monitoring | \$25–\$200 | 低用量基准。费用随 trace 载荷大小、保留时长和日志量增加。 |

每月总费用估算为 **\$2,495–\$4,207**，不含沙箱。

<a id="notes-on-the-estimate"></a>

### 估算说明

- **Cloud SQL** 对高可用性配置中的主实例和备用实例均收费。存储会自动扩展，超出内含额度的备份存储另行收费。
- **SmithDB** 将缓存保存在本地 SSD 上，因此没有单独的永久磁盘费用。如果首选 SmithDB 节点池无法添加节点，例如某个可用区资源不足，GKE 会选择一个备用节点池进行扩容，优先顺序为 `n2d-standard-16`、`c3-standard-22-lssd`、`c3d-standard-30-lssd`。
- **Cloud NAT** 对每台虚拟机按每小时 \$0.0014 收费，另按处理量收取每 GB \$0.045。
- **Cloud Logging** 接收每个 data plane 子网的 VPC 流日志。超出每月免费额度的日志摄取量按 GB 计费。

<a id="smithdb-object-store-pricing"></a>

### SmithDB 对象存储定价

SmithDB 将 trace 数据存储在 data plane 的 Cloud Storage 存储桶中。`us-west1` 的 Standard 存储价格为每 GB 每月 \$0.020。下表按每月约 200 万条 trace 估算。

| 每条 trace 的存储大小 | 保留 14 天 | 保留 400 天 |
| --- | --- | --- |
| 10 KB | 每年 \$2 | 每年 \$64 |
| 50 KB | 每年 \$11 | 每年 \$320 |
| 200 KB | 每年 \$45 | 每年 \$1,280 |

有关 SmithDB 基础设施的详细信息，请参阅[准备 SmithDB 配套基础设施](/langsmith/self-host-smithdb-infrastructure)。

<a id="sandbox-add-on"></a>

## 沙箱附加费用

如果你的 data plane 运行沙箱，请单独为以下资源编列预算。

| 项目 | 月度成本估算 | 说明 |
| --- | --- | --- |
| 沙箱节点池 | \$637–\$1,911 | 1 到 3 个 `n2-standard-16` 节点，每个配有 2 块本地 SSD（750 GB）。节点池始终至少运行 1 个节点。 |
| Memorystore for Redis Cluster | 增加 \$162 | 沙箱将文件系统元数据保存在 Redis 中，因此 Redis 改用 2 个 `REDIS_STANDARD_SMALL` 节点，每月合计约 \$208。 |
| Cloud Storage | 按用量计费 | 沙箱文件系统存储在 data plane 的存储桶中。 |
