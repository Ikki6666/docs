## API 速率限制

LangSmith 会对 API 端点实施速率限制，以确保服务稳定性和公平使用。下表列出了 GCP US 和 GCP EU 区域中不同端点的速率限制。GCP APAC 和 AWS US 会实施相近的服务专属限制；如果你需要了解适用于你所在组织的准确限制，请联系支持团队。请注意：

- 速率限制表示为 `count / interval`，其中 count 是在该时间间隔内（以秒为单位）允许的请求数。例如，`2000 / 10` 表示每 10 秒 2000 个请求。
- 如果端点列中未指定 HTTP 方法，则该速率限制适用于该端点的所有 HTTP 方法。
- 如果列出了特定方法（例如 `POST`、`GET`），则该速率限制仅适用于该方法。

| --- | --- | --- | --- | --- |
| OPTIONS、`/info`、`*/v1/metadata/submit` | IP | 2000 / 10 | 2000 / 10 | [高吞吐量](#rate-limit-categories) |
| `/auth` | `x-api-key` | 2000 / 10 | 2000 / 10 | [高吞吐量](#rate-limit-categories) |
| `/auth` | `x-user-id` + IP | 2000 / 10 | 2000 / 10 | [高吞吐量](#rate-limit-categories) |

### 速率限制分类

- **高吞吐量**：用于身份认证、元数据、feedback 等核心操作的通用高流量端点。
- **仓库**：仓库和 prompt 管理操作。
- **Run 摄取**：用于可观测性的单个 trace/run 摄取端点。
- **图表**：图表生成和可视化端点。
- **Multipart 摄取**：通过 multipart 上传进行批量 run 摄取，用于高流量 tracing。
- **Run 查询（API）**：基于 API key 的 run 查询操作，对复杂查询设置更严格的限制。
- **Run 查询（用户）**：基于用户的 run 查询操作，为交互式使用提供更高的限制。
- **生成**：AI 驱动的代码和内容生成端点（限制以防止滥用）。
- **提交**：prompt 版本管理和提交操作。
- **删除**：会话删除和工作流触发操作。
- **Run 查找**：按 UUID 检索特定的 run。
- **示例**：获取数据集示例，用于 few-shot prompting。
- **默认（API key）**：对于未匹配特定模式的已认证 API 请求的兜底速率限制。
- **默认（用户）**：对于未匹配特定模式的已认证用户请求的兜底速率限制。
- **公开下载**：用于共享资源的高流量公开下载端点。
- **统计**：run 统计和分析端点（适用区域专属限制）。
- **公开（兜底）**：未认证公开访问的默认速率限制。

有关速率限制和其他服务限制的更多信息，请参阅[管理概览](/langsmith/usage-and-billing#rate-limits)。
