LLM Gateway **Spend Monitoring** 仪表板会显示一个[工作区](/langsmith/administration-overview#workspaces)通过 gateway 累计的 LLM 成本。用它比较一段时间内的支出，并识别构成这些支出的用户、[API keys](/langsmith/create-account-api-key) 和模型。仪表板一次只覆盖一个工作区；切换工作区即可比较它们。

查看该仪表板需要 [Organization Admin](/langsmith/rbac#organization-admin) 角色以及 Plus 或 Enterprise [plan](/langsmith/pricing-plans)。两者缺一不可，否则 **Usage** 标签页不会出现。

<Warning>
该仪表板目前在 EU、APAC 和 AWS 环境中不可用。
</Warning>

## 打开仪表板

查看 gateway 支出的步骤：

1. 在 [LangSmith UI](https://smith.langchain.com?utm_source=docs&utm_medium=cta&utm_campaign=langsmith-signup&utm_content=langsmith-llm-gateway-monitoring) 中，在左侧导航中选择 **LLM Gateway**。
1. 选择 **Usage**。
1. 选择要分析的工作区。

所选工作区通过 LLM Gateway 发送流量后，仪表板才会显示数据。如果该工作区没有 gateway 流量，仪表板会显示空状态。

## 设置时间范围和粒度

使用时间控件定义页面中每个汇总、图表和表格覆盖的时间段：

- **Time range**：选择从一天到一年的预设范围，或选择自定义日期。日期和时间 bucket 使用 UTC。
- **Granularity**：把支出按小时、按天或按周分桶。可用选项取决于所选时间范围的长度。
- **Previous or next period**：向前或向后移动一个等长时间段，以比较相邻的时间范围。

## 拆分和筛选支出

选择 **Breakdown by** 按以下维度之一对支出分组：

- **User**：把支出归因于调用 gateway 的 personal access token 所关联的用户。使用工作区或组织范围的 service key 发出的请求会显示为 **Unaffiliated with any user**。
- **API key**：把支出归因于调用 gateway 的 LangSmith API key。
- **Model**：把支出归因于请求所使用的模型。

选择维度后，使用相邻的筛选器聚焦特定的用户、API keys 或模型。一次最多可以选择六个实体。要移除筛选器，请选择列表底部的 **All** 选项。

## 解读支出汇总

汇总卡片描述所选工作区、时间范围、维度和筛选器的支出：

- **Total Spend**：所选时间范围内 gateway 支出的总和。
- **Hourly、Daily 或 Weekly Avg**：总支出除以所选范围内的时间 bucket 数量。
- **Hourly、Daily 或 Weekly Avg / dimension**：每个时间 bucket 中，所选用户、API key 或模型的平均支出。当你没有应用实体筛选时，该指标使用按支出排名前 10 的实体。

## 分析图表和表格

堆叠柱状图显示每个实体在每个时间 bucket 中对支出的贡献。悬停在柱子上可以查看该 bucket 的总量以及每个可见实体的贡献。当未应用筛选时，图表会把支出最高的六个实体显示为独立序列，并把剩余实体合并为 **Other**。

表格以每个可见实体一行的方式汇总同一选择。用它比较：

- **Hourly、Daily 或 Weekly Avg**：该实体的总支出除以时间 bucket 数量。
- **Spend Share**：归因于该实体的支出百分比。
- **Total Spend**：该实体在所选时间范围内的总支出。

选择列标题可以对表格排序。

## 下钻到某个用户或 API key

选择一个用户或 API key 行可以打开详细视图：

- 从用户进入，可查看按 API key 分组的支出。
- 从 API key 进入，可查看按用户分组的支出。

详细视图拥有自己的实体筛选器、时间范围和粒度控件。在该视图中的更改不会更改主仪表板上的控件。
