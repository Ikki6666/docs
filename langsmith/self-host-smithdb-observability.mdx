SmithDB 组件会暴露应用指标，并可以把 logs 和 traces 导出到你已有的 observability 栈。请在部署 SmithDB 服务之后、调优容量或迁移历史数据之前完成此项设置。它提供用于验证那些变更和排查故障的信号。

## Metrics

每个 SmithDB 组件会在其 HTTP 端口上的固定 `/metrics` 路径暴露应用指标。通过为每个组件添加抓取注解，配置你的监控栈来发现 pods：

<Accordion title="Sample Prometheus configuration">

```yaml
smithdb:
  query:
    deployment:
      annotations:
        prometheus.io/scrape: "true"
        prometheus.io/path: "/metrics"
        prometheus.io/port: "8060"
  ingestion:
    deployment:
      annotations:
        prometheus.io/scrape: "true"
        prometheus.io/path: "/metrics"
        prometheus.io/port: "8050"
  compaction:
    deployment:
      annotations:
        prometheus.io/scrape: "true"
        prometheus.io/path: "/metrics"
        prometheus.io/port: "8070"
  compactionWorker:
    deployment:
      annotations:
        prometheus.io/scrape: "true"
        prometheus.io/path: "/metrics"
        prometheus.io/port: "9000"
  clusterManager:
    deployment:
      annotations:
        prometheus.io/scrape: "true"
        prometheus.io/path: "/metrics"
        prometheus.io/port: "8090"
  migration:
    job:
      annotations:
        prometheus.io/scrape: "true"
        prometheus.io/path: "/metrics"
        prometheus.io/port: "9040"
```

在 LangSmith 0.16 上，在 `smithdb.migration.deployment.annotations` 下设置 migration 注解。

</Accordion>

这些是 Prometheus 风格的注解。有自己发现格式的 provider（例如 Datadog）需要把该格式应用到相同的端口和路径。用你已有的基础设施监控来监控 PostgreSQL metastore、Kubernetes 节点和云服务。

关于关注哪些指标以及如何解读，请参见 [SmithDB 指标参考](/langsmith/self-host-smithdb-metrics)。

## Logs 和 traces

SmithDB 使用[将 LangSmith telemetry 导出到你的 observability backend](/langsmith/export-backend) 中描述的 chart 级 OpenTelemetry tracing 配置，但有一点不同：SmithDB 只通过 OTLP gRPC 导出。把 `config.observability.tracing.exporter` 设置为 `grpc`。使用 `http` 时，SmithDB 导出保持禁用，SmithDB logs 仍然只输出到 console。chart 会自动把 SmithDB pod 和 container 名称添加为 OpenTelemetry resource attributes。

要自定义 SmithDB log 过滤，通过 `smithdb.commonEnv` 为所有 SmithDB workloads 设置 `RUST_LOG`：

```yaml
smithdb:
  commonEnv:
    - name: RUST_LOG
      value: "warn,smithdb_query=debug,vortex=warn"
```

确认 collector 可以从 LangSmith namespace 访问，应用 chart，然后确认 telemetry 到达。设置或调优 collector 请参见[为 LangSmith telemetry 配置你的 collector](/langsmith/langsmith-collector)。
