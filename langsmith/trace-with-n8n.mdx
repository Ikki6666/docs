[n8n](https://n8n.io/) 是一个工作流自动化平台，内置基于 LangChain 的高级 AI 能力。你可以将 n8n 实例连接到 LangSmith，以记录和监控 AI workflow runs。

<Note>
LangSmith tracing **仅适用于 self-hosted 的 n8n 实例**。
</Note>

<ProjectTracingCompatibility />

## Prerequisites

- 一个 [LangSmith 账户](https://smith.langchain.com?utm_source=docs&utm_medium=cta&utm_campaign=langsmith-signup&utm_content=langsmith-trace-with-n8n) 和 [API key](/langsmith/create-account-api-key)
- 一个 self-hosted 的 n8n 实例
- LangSmith 中的一个 [agent](/langsmith/create-an-agent)。n8n 不支持 agent addressing，因此它会按名称将 traces 发送到该 agent 的某个 environment。

## Set up tracing

1. 在托管 n8n 实例的环境中，以与你其余 [n8n configuration](https://docs.n8n.io/hosting/configuration/configuration-methods/) 相同的方式设置以下环境变量。

   必需环境变量：
   - `LANGCHAIN_TRACING_V2`：设为 `true` 以启用 tracing。
   - `LANGCHAIN_API_KEY`：填写你的 LangSmith API key。

   可选环境变量：
   - `LANGCHAIN_ENDPOINT`：LangSmith API endpoint。默认值为 `https://api.smith.langchain.com`。如果你使用 self-hosted LangSmith、GCP EU（`https://eu.api.smith.langchain.com`）、GCP APAC（`https://apac.api.smith.langchain.com`）或 AWS US（`https://aws.api.smith.langchain.com`），请设置此项。
   - `LANGCHAIN_PROJECT`：设为 agent environment 的 [`tracer_session_name`](/langsmith/create-an-agent#use-an-environment-project)。如果省略，traces 会发送到名为 `default` 的 agent。
   - `LANGCHAIN_CALLBACKS_BACKGROUND`：设为 `true` 使用异步 trace 上传（默认），或设为 `false` 使用同步上传。（默认值：`true`）

1. 重启你的 n8n 实例，使环境变量生效。

## View traces in LangSmith

在运行一个 AI workflow 后：

1. 打开 [LangSmith](https://smith.langchain.com?utm_source=docs&utm_medium=cta&utm_campaign=langsmith-signup&utm_content=langsmith-trace-with-n8n)。
1. 选择你的 agent，前往 **Tracing**，然后选择你在 `LANGCHAIN_PROJECT` 中设置其 `tracer_session_name` 的 environment。
1. 找到与你的 workflow 执行对应的 trace。
